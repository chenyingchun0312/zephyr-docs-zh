Hello World for multiple board targets using Sysbuild

Browse source code on GitHub

概述

本示例演示如何使用 Sysbuild（系统构建） 为两个开发板目标构建 Hello World 应用程序。本示例可用于测试多核 SoC 等场景，因为每个核都作为一个开发板目标呈现。其他场景还包括集成了多个 SoC 的开发板。使用 Zephyr Sysbuild 构建时，构建系统会根据项目附加配置和构建文件中选择的选项添加额外的镜像。

所有镜像使用同一个 main.c，它会打印应用程序所烧录到的开发板目标。

构建与运行

本示例需要使用 --sysbuild 选项通过 Sysbuild 构建。远端开发板需要通过 SB_CONFIG_REMOTE_BOARD 指定。根据平台不同，可能还需要一些额外设置，例如用于启动远端核。

备注

建议通过 -T 选项使用 samples/sysbuild/hello_world/tests.yaml 中的示例配置。这样可以确保所有额外设置（远端开发板、代码片段等）都会自动应用。

以下示例为 nRF54H20 DK 构建并烧录本示例，使用应用核和无线电核：

west build -b nrf54h20dk/nrf54h20/cpuapp --sysbuild samples/sysbuild/hello_world -- -DSB_CONFIG_REMOTE_BOARD='"nrf54h20dk/nrf54h20/cpurad"'
west flash

使用 samples/sysbuild/hello_world/tests.yaml 中的配置也可以达到同样的效果：

west build -b nrf54h20dk/nrf54h20/cpuapp -T sample.sysbuild.hello_world.nrf54h20dk_cpuapp_cpurad samples/sysbuild/hello_world
west flash

将示例烧录到开发板后，应能在每个目标所配置的 Zephyr 控制台上看到 hello world 消息。例如，对于上面的示例：

应用核

*** Booting Zephyr OS build v3.6.0-274-g466084bd8c5d ***
Hello world from nrf54h20dk/nrf54h20/cpuapp

无线电核

*** Booting Zephyr OS build v3.6.0-274-g466084bd8c5d ***
Hello world from nrf54h20dk/nrf54h20/cpurad
