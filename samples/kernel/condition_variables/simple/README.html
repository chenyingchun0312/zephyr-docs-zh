条件变量

概述

本示例演示在多线程应用程序中使用条件变量。条件变量与互斥量配合使用，从工作线程向主线程通知状态（条件）的变化。主线程使用条件变量等待某个条件成立。主线程和工作线程根据工作线程何时通知在条件变量上等待的主线程而交替执行。本示例可用于任何 受支持的开发板，并将所示的示例输出打印到控制台。

构建与运行

本应用程序可以按如下方式在 native_sim 上构建并运行：

west build -b native_sim samples/kernel/condition_variables/simple
west build -t run

要为其他开发板构建，请将上面的 native_sim 改为该开发板的名称。
