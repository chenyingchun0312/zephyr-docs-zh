Eclipse hawkBit Direct Device Integration API

Browse source code on GitHub

概述

Eclipse hawkBit 更新服务器提供 REST 资源，设备通过这些资源获取软件更新任务。该 API 基于 HTTP 标准和轮询机制。

本示例展示如何在轮询和手动两种更新模式下使用 hawkBit DDI API。

轮询模式按预定周期自动运行，探测服务器上的更新并进行安装，无需用户干预。该模式的示例源代码见 hawkbit_polling。

手动模式需要用户调用服务器探测，如果有可用更新，就会安装该更新。该模式的示例源代码见 hawkbit_manual

注意事项

  • hawkBit 的 Zephyr 移植默认配置为在 STM32H573I-DK MCU 上运行。该应用程序也应能在其他支持互联网连接的平台上构建和运行，部分平台需要做一些修改。要支持 Bluetooth LE、6lowpan、802.15.4 或 OpenThread 配置，需要覆盖文件；还需要注意，大多数其他连接方式都需要某种边缘网关（边界路由器等）。

  • hawkBit 需要 MCUboot 引导加载程序才能正常工作。有关设备固件升级子系统和 MCUboot 的更多信息，请参阅 MCUboot。

构建与运行

以下步骤介绍如何在 Zephyr 中构建并运行 hawkBit 示例。给出的例子假定示例是为 STM32H573I-DK（BOARD=stm32h573i_dk）构建的。

步骤 1：启动 hawkBit Docker

默认情况下，hawkbit 应用程序在 http 上运行，Web UI 使用端口 8088，DDI API 使用端口 8080。

git clone https://github.com/eclipse-hawkbit/hawkbit.git
cd hawkbit/docker/postgres
docker compose -fdocker-compose-monolith-dbinit-with-ui-postgres.yml up -d

这会在主机系统上启动 hawkbit 服务器。

步骤 2：访问 hawkBit UI 并配置服务器

在浏览器中打开服务器 URL <your-ip-address>:8088，并使用默认用户名和密码 admin 登录服务器。

继续之前，需要为服务器启用网关安全认证，并设置网关安全令牌。

为此，请点击 UI 左侧窗格中的 Config。

将 authentication.gatewaytoken.key 字段设置为 abcd1234，该值必须与 CONFIG_HAWKBIT_DDI_SECURITY_TOKEN 相同。如果使用 CONFIG_HAWKBIT_SET_SETTINGS_RUNTIME，可以在运行时设置令牌，请确保设置的值与服务器中设置的值相同。

还要确保启用 authentication.gatewaytoken.enabled，以启用网关令牌认证。

步骤 3：构建 hawkBit 示例和 mcuboot

可以按如下方式为 STM32H573I-DK 构建 hawkBit：

west build -b stm32h573i_dk --sysbuild samples/subsys/mgmt/hawkbit

如果希望构建时支持在运行时设置 hawkBit 服务器地址和端口，请在 prj.conf 文件中启用 CONFIG_HAWKBIT_SET_SETTINGS_RUNTIME 选项。

构建系统会使用 root-rsa-2048.pem 密钥自动为固件签名。该密钥位于 MCUboot 仓库中。

步骤 4：烧录引导加载程序和示例应用程序

如果使用 sysbuild 同时构建了引导加载程序和示例应用程序，只需运行以下命令即可烧录这两个镜像：

west flash

镜像烧录并启动后，示例会将镜像的构建时间打印到控制台。连接到互联网后，在 hawkbit 服务器 UI 的 Targets 窗格中应能看到 stm32h573i_dk。接下来就可以向服务器上传固件二进制文件，并通过该 UI 进行更新。

步骤 5：构建测试镜像并签名

这次需要构建目录中的 zephyr.signed.bin 文件。

进入 hawkBit UI，点击 UI 左侧窗格中的 Software Modules。点击 + 图标添加新的软件模块。将类型设置为 Application，并填写名称和版本字段，这些值可以任意设置。点击 Create 按钮之前，请确保同时启用 Create single software module distribution set 选项，然后将 Distribution Set Type 选择为 App(s) only。这样 hawkBit 会用创建的软件模块创建一个分发集（distribution set）。对 Zephyr 而言，软件模块与分发集是一一对应的关系。点击 Create 按钮后，会进入上传制品（artifact）的对话框，在此上传 zephyr.signed.bin 文件，然后点击 Finish 按钮。

进入 UI 左侧窗格中的 Targets 并选择一个目标，其名称应以开发板名称开头。然后点击回形针图标，为该目标分配分发集。选择刚刚创建的分发集，并点击 Assign 按钮。

步骤 6：执行更新

回到用于调试开发板的终端会话，可以等待 hawkbit 客户端自动检查更新（默认每 5 分钟一次），也可以重启开发板，或者输入以下命令：

hawkbit run

然后等待即可。开发板会访问服务器，检查是否有新的更新，然后下载刚刚创建的更新。如果一切正常，终端上会打印消息 Update installed。

开发板会自动重启，然后使用新镜像启动。重启后，开发板会打印不同的镜像构建时间，然后再次自动访问服务器，终端上会打印消息 Image is already updated。
