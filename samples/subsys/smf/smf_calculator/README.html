SMF Calculator

Browse source code on GitHub

概述

本示例创建一个基础的桌面计算器，由使用 状态机框架 编写的状态机驱动。

计算器的“业务逻辑”基于 Miro Samek 所著 Practical UML Statecharts in C/C++ 第 2 版图 2.18 中给出的状态图。它使用三层层次状态图来处理诸如忽略前导零、禁止输入多个小数点等情况。

该状态图做了少量修改：在 op_entered 状态中，根据是否存在上一次的结果，在屏幕上显示不同的输出。

图形界面基于 samples/drivers/display 中的示例，使用 LVGL 按钮矩阵作为输入，使用文本标签作为输出。每次调用 smf_run_state() 后，状态机都会更新输出文本标签。

CONFIG_LV_Z_VDB_SIZE 已减小到 14%，以便能在 Disco L475 IOT01 (B-L475E-IOT01A) 等 RAM 受限的开发板上运行。

要求

该 GUI 应能与 Zephyr 支持的任何触摸屏显示器配合使用。必须使用 --shield 选项将扩展板传给 west build，例如 --shield adafruit_2_8_tft_touch_v2

基于 Arduino 的触摸屏扩展板列表：

  • Adafruit 2.8" TFT Touch Shield v2

  • Buydisplay 2.8" TFT Touch Shield with Arduino adapter

  • Buydisplay 3.5" TFT Touch Shield with Arduino adapter

该演示也应能在带有内置触摸屏的 STM32 Discovery 套件上运行，例如

  • STM32F412G Discovery

  • ST25DV Discovery, MB1283 version

  • STM32F7508-DK Discovery Kit

  • STM32F769I Discovery

等等。由于触摸屏是内置的，这些开发板不需要定义扩展板。

构建与运行

下面是为带有 Adafruit 2.8" TFT Touch Shield v2 的 Disco L475 IOT01 (B-L475E-IOT01A) 开发板构建的例子。

west build -b disco_l475_iot1 --shield adafruit_2_8_tft_touch_v2 samples/subsys/smf/smf_calculator

为了在无需任何硬件的情况下进行测试，也支持 native_sim 开发板，可按如下方式构建：

west build -b native_sim samples/subsys/smf/smf_calculator

命令行控制

除了通过 GUI 控制外，还可以通过 shell 控制计算器，这表明状态机可以接收来自多个来源的输入。key <key> 命令向状态机发送一次按键。有效的按键包括：数字 0 到 9；执行相应功能的 .、+、-、*、/ 和 =；表示清除（Cancel）的 C；以及表示清除输入（Cancel Entry）的 E。

在带有 Adafruit 2.8" TFT Touch Shield v2 触摸屏的 Disco L475 IOT01 (B-L475E-IOT01A) 上，GUI 的更新速度约为 0.8 秒，这是因为按下按钮矩阵时会使整个矩阵区域失效，而不仅仅是被选中的按钮。使用 18 个独立按钮代替单个矩阵可以加快速度，但对本演示而言已经足够。
