ZMS Cycle Count Verification

Browse source code on GitHub

概述

本示例调用并验证 ZMS 扇区周期计数 API：

  • zms_get_num_cycles()

  • zms_get_sector_num_cycles()

  • zms_sector_use_next()

它检查在多次强制推进扇区后，ZMS 返回的回收计数是否与预期值一致；并检查当计数超过原来 uint8_t 周期计数器的范围（256）后，计数是否仍能正确增长。旧字段正是在这个位置发生回绕。

本示例分三个阶段运行：

  1. 阶段 1：挂载分区，将其清空，并执行 30 次扇区推进。将周期计数与预期值（base + PHASE1_ITERATIONS / SECTOR_COUNT）进行比较。

  2. 阶段 2：继续执行扇区推进，直到相对周期计数超过 256，以验证计数器越过以往 uint8_t 的回绕点后仍会继续递增。

  3. 阶段 3：通过 zms_get_sector_num_cycles() 读取每个扇区的周期计数，确保它们都不为零，并验证超出范围的扇区索引会返回 -EINVAL。

成功时，示例会打印 PASS: cycle count verification succeeded。

要求

  • 支持 Flash 的开发板，或 native_sim 目标

构建与运行

本示例可以为多个平台构建，已在 native_sim、qemu_x86 和 nrf7002dk/nrf5340/cpuapp 上测试过。

west build -b None samples/subsys/kvss/zms/zms_cycle_count

示例输出

base 的确切值取决于存储分区的现有状态（每次在持久 Flash 上重新运行示例，它都会增加一个完整周期）。下面的例子展示的是在全新 Flash 上运行、base=1 的情况；之后的运行只是从更高的 base 开始，并以更高的最终值结束，但相对增长量和 PASS 行是相同的。
