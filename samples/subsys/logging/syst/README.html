构建与运行

本项目以 MIPI Sys-T 格式输出几条示例日志消息。这些 Sys-T 消息可以由 <workspace>/modules/debug/mipi-sys-t/printer/ 中的工具解析。

构建 Sys-T 消息解析器

cd <workspace>/modules/debug/mipi-sys-t/printer/
mkdir build
cd build
cmake ../
make

新构建的可执行文件 systprint 位于 <workspace>/modules/debug/mipi-sys-t/printer/build 下。

MIPI Sys-T 文本消息

Sys-T 文本消息是自包含的字符串，处理时不需要额外的产物。

在 qemu_x86 下构建打印文本消息的示例：

west build -b qemu_x86 samples/subsys/logging/syst -- -DCONFIG_LOG_BACKEND_SHOW_COLOR=n

运行示例，并将输出捕获到文本文件中：

west build -t run > /tmp/syst

由于输出被重定向到文本文件，终端上不会打印任何输出。因此请按 CTRL+A x 退出 QEMU。

MIPI Sys-T 目录消息

目录（catalog）消息与字典日志类似：格式字符串通过标识哈希值引用，字符串参数则编码在 Sys-T 消息载荷中。可以离线将这些哈希值和编码后的参数与附属文件（其中包含哈希值与对应格式字符串之间的映射）结合，还原出实际的消息。

在 qemu_x86 下构建打印目录消息的示例：

west build -b qemu_x86 samples/subsys/logging/syst -- -DCONFIG_LOG_BACKEND_SHOW_COLOR=n -DCONFIG_LOG_MIPI_SYST_USE_CATALOG=y

运行示例，并将输出捕获到文本文件中：

west build -t run > /tmp/syst

由于输出被重定向到文本文件，终端上不会打印任何输出。因此请按 CTRL+A x 退出 QEMU。
