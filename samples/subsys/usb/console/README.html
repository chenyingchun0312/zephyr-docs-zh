Console over USB CDC ACM

Browse source code on GitHub

概述

本示例应用程序展示如何将新的实验性 USB 设备栈提供的 CDC ACM UART 用作控制台的串行后端。

要求

本项目需要实验性的 USB 设备驱动（UDC API）。

构建与运行

本示例可以为多款开发板构建，本例中为 reel_board 开发板构建：

west build -b reel_board samples/subsys/usb/console
west flash

将开发板插入主机设备，例如运行 Linux 操作系统的 PC。开发板会被识别为 CDC ACM 串口设备。要查看示例的控制台输出，请使用类似 minicom -D /dev/ttyACM1 的命令。
