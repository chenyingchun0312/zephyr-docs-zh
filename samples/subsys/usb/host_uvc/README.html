USB Host UVC Camera

Browse source code on GitHub

概述

本示例演示如何使用 USB Host UVC（USB 视频类）驱动，从连接到作为 USB 主机的 Zephyr 设备上的 USB 摄像头捕获视频帧。

连接后，USB 摄像头会被自动检测和配置。示例捕获视频帧并记录帧统计信息。

要求

本示例使用 USB 主机协议栈，需要 USB 主机控制器驱动。

需要一个支持 UVC（USB 视频类）规范的 USB 摄像头。

构建与运行

可以按如下方式构建并烧录本示例：

west build -b rd_rw612_bga/rw612 samples/subsys/usb/host_uvc
west flash

连接 USB 摄像头后，设备应能自动检测到它。

配置选项

可以通过 prj.conf 配置本示例：

视频格式

  • CONFIG_APP_VIDEO_PIXEL_FORMAT：像素格式（YUYV、MJPEG 等）

  • CONFIG_APP_VIDEO_FRAME_WIDTH：帧宽度

  • CONFIG_APP_VIDEO_FRAME_HEIGHT：帧高度

  • CONFIG_APP_VIDEO_TARGET_FPS：目标帧率

内存配置

  • CONFIG_VIDEO_BUFFER_POOL_NUM_MAX：视频缓冲区数量

  • CONFIG_VIDEO_BUFFER_POOL_HEAP_SIZE：缓冲池大小（字节）

  • CONFIG_VIDEO_BUFFER_POOL_ALIGN：缓冲区对齐

  • CONFIG_HEAP_MEM_POOL_SIZE：通用堆大小

  • CONFIG_MAIN_STACK_SIZE：主线程栈大小

USB 传输配置

  • CONFIG_USBH_VIDEO_CONCURRENT_TRANSFERS：并发 ISO 传输数

  • CONFIG_USBH_USB_DEVICE_HEAP：USB 设备堆大小

  • CONFIG_UHC_XFER_COUNT：最大传输请求数

  • CONFIG_UHC_BUF_COUNT：传输缓冲区数量

  • CONFIG_UHC_BUF_POOL_SIZE：传输缓冲池大小

日志配置

  • CONFIG_LOG：启用日志

  • CONFIG_LOG_BUFFER_SIZE：日志缓冲区大小

  • CONFIG_USBH_UVC_LOG_LEVEL_INF：UVC 驱动日志级别

故障排除

内存分配失败

如果出现内存分配错误，请增大堆大小或减少缓冲区数量：

  • CONFIG_HEAP_MEM_POOL_SIZE：增大通用堆大小

  • CONFIG_VIDEO_BUFFER_POOL_NUM_MAX：减少视频缓冲区数量

  • CONFIG_APP_VIDEO_FRAME_WIDTH：减小帧宽度以降低内存占用

  • CONFIG_APP_VIDEO_FRAME_HEIGHT：减小帧高度以降低内存占用

丢帧或帧损坏

如果出现丢帧或帧损坏，请增加缓冲资源或降低数据速率：

  • CONFIG_VIDEO_BUFFER_POOL_NUM_MAX

  • CONFIG_UHC_BUF_POOL_SIZE

  • CONFIG_UHC_BUF_COUNT

  • CONFIG_APP_VIDEO_TARGET_FPS

  • CONFIG_USBH_VIDEO_CONCURRENT_TRANSFERS

  • CONFIG_APP_VIDEO_FRAME_WIDTH

  • CONFIG_APP_VIDEO_FRAME_HEIGHT

性能问题

如果视频捕获缓慢或卡顿，可以尝试降低数据速率或减少日志，或者启用优化：

  • CONFIG_APP_VIDEO_FRAME_WIDTH

  • CONFIG_APP_VIDEO_FRAME_HEIGHT

  • CONFIG_APP_VIDEO_TARGET_FPS

  • CONFIG_USBH_UVC_LOG_LEVEL_WRN

  • CONFIG_DEBUG_OPTIMIZATIONS

  • CONFIG_SPEED_OPTIMIZATIONS

UVC 缓冲区的分配由 USB Host 和 Video 两部分的配置决定，在出现内存分配问题或需要维持更高 FPS 时，这些配置会很有用：

  • CONFIG_UHC_BUF_COUNT

  • CONFIG_UHC_BUF_POOL_SIZE

  • CONFIG_UHC_XFER_COUNT

  • CONFIG_USBH_VIDEO_CONCURRENT_TRANSFERS

  • CONFIG_VIDEO_BUFFER_POOL_HEAP_SIZE

  • CONFIG_VIDEO_BUFFER_POOL_NUM_MAX
