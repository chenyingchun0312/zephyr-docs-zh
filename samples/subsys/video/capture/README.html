Video capture

Browse source code on GitHub

说明

本示例应用程序使用 视频 从视频捕获设备捕获帧，然后使用 显示 将其显示在 LCD 屏幕上（如果有的话）。

要求

本示例需要一个视频捕获设备（例如摄像头），但这并非必需。受支持的开发板和摄像头模块包括：

  • Camera iMXRT [1]

  • 带 MT9M114 camera module [2] 的 MIMXRT1064-EVK

  • 带 OV5640 camera module [3] 的 MIMXRT1170-EVK

  • 带任意 arducam,dvp-20pin-connector 摄像头模块（例如 DVP 20-pin OV7670 Camera Module）的 FRDM-MCXN947。

  • 带 ST B-CAMS-OMV-MB1683 扩展板和兼容摄像头模块的 STM32H7B3I Discovery kit。

  • 带 ST B-CAMS-IMX-MB1854 摄像头模块的 STM32N6570-DK。

  • 带 Seeed Studio XIAO 圆形显示屏 扩展板的 XIAO ESP32S3（“sense”版本）。

Arduino Nicla Vision 也可以在本示例中用作捕获设备，此时用户可以通过板载 USB 传输捕获的帧。

接线

在 MIMXRT1064-EVK 上，MT9M114 摄像头模块应插入 J35 摄像头连接器。应使用 USB 线缆将主机连接到 micro USB 调试连接器（J41），以便通过 freelink 接口获取控制台输出。

在 MIMXRT1170-EVK 上，OV5640 摄像头模块应插入 J2 摄像头连接器。应使用 USB 线缆将主机连接到 micro USB 调试连接器（J11），以便通过 daplink 接口获取控制台输出。

在 STM32H7B3I Discovery kit 上，将 ST B-CAMS-OMV-MB1683 扩展板连接到开发板的 CN7 连接器。应使用 USB 线缆将主机连接到 micro USB 连接器，以获取控制台输出。

在 STM32N6570-DK 上，将 ST B-CAMS-IMX-MB1854 摄像头模块连接到 J4 CSI 连接器。应使用 USB 线缆将主机连接到两个 USB-C 端口，用于供电、烧录和控制台输出。

在 XIAO ESP32S3 上，将“sense”摄像头模块和 Seeed Studio XIAO 圆形显示屏 连接到各自的连接器。

对于 Arduino Nicla Vision，不需要额外接线。

构建与运行

对于 MIMXRT1064-EVK，使用以下命令构建本示例应用程序：

west build -b mimxrt1064_evk --shield dvp_fpc24_mt9m114 --shield rk043fn66hs_ctg samples/subsys/video/capture

对于 MIMXRT1170-EVK，使用以下命令构建本示例应用程序：

west build -b mimxrt1170_evk/mimxrt1176/cm7 --shield nxp_btb44_ov5640 --shield rk055hdmipi4ma0 samples/subsys/video/capture

对于 Arduino Nicla Vision，使用以下命令构建本示例应用程序：

west build -b arduino_nicla_vision/stm32h747xx/m7 samples/subsys/video/capture

对于 FRDM-MCXN947，在开发板上连接 DVP 20-pin OV7670 Camera Module 和 NXP LCD_PAR_S035 TFT LCD Module，然后使用以下命令构建本示例应用程序：

west build -b frdm_mcxn947/mcxn947/cpu0 --shield dvp_20pin_ov7670 --shield lcd_par_s035_8080 samples/subsys/video/capture

对于 STM32H7B3I Discovery kit，使用带兼容摄像头模块的 ST B-CAMS-OMV-MB1683 扩展板，并使用以下命令构建本示例应用程序：

west build -b stm32h7b3i_dk --shield st_b_cams_omv_mb1683 samples/subsys/video/capture

对于 STM32N6570-DK，使用 ST B-CAMS-IMX-MB1854 摄像头模块，并使用以下命令构建本示例应用程序：

west build -b stm32n6570_dk --shield st_b_cams_imx_mb1854 samples/subsys/video/capture

对于 XIAO ESP32S3，使用 Seeed Studio XIAO 圆形显示屏 扩展板，并使用以下命令构建本示例应用程序：

west build -b xiao_esp32s3/esp32s3/procpu/sense --shield seeed_xiao_round_display samples/subsys/video/capture

出于测试目的，如果没有任何真实的视频捕获和/或显示硬件，上述构建命令在不指定扩展板的情况下也支持视频软件图案生成器，此时需使用 视频软件生成器代码片段（video-sw-generator）：

west build -b native_sim/native/64 -S video-sw-generator samples/subsys/video/capture

同样无需任何硬件，视频 Native FIFO 代码片段（video-native-fifo） 可以将主机上生成的帧（而不是在设备上生成的帧）提供给示例，这样就可以使用真实的网络摄像头、视频文件或某个 ffmpeg 测试源：

west build -b native_sim/native/64 -S video-native-fifo samples/subsys/video/capture

该驱动默认使用 320x240 RGB565，这也是 native_sim SDL 显示屏 的尺寸和像素格式，因此无需进一步配置，帧就会显示在 SDL 窗口中。创建 FIFO 并启动应用程序：

$ mkfifo /tmp/zephyr-cam.fifo
$ build/zephyr/zephyr.exe --video-fifo=/tmp/zephyr-cam.fifo

然后在另一个终端中向其输入测试图案：

$ ffmpeg -re -f lavfi -i testsrc2=size=320x240:rate=10 \
    -pix_fmt rgb565le -f rawvideo -y /tmp/zephyr-cam.fifo

将 ffmpeg 的输入替换为 -f v4l2 -i /dev/video0 可以从真实网络摄像头捕获，替换为 -i <file> 可以回放视频文件，并将其缩放到 320x240。网络摄像头的例子请参阅 驱动文档。

如果要使用 shell 命令控制摄像头设备，而不是持续捕获数据，请在构建命令后追加 -DCONFIG_VIDEO_SHELL=y：

west build -b mimxrt1064_evk --shield dvp_fpc24_mt9m114 --shield rk043fn66hs_ctg samples/subsys/video/capture -- -DCONFIG_VIDEO_SHELL=y

对于使用 shell 命令的 STM32H7B3I Discovery kit：

west build -b stm32h7b3i_dk --shield st_b_cams_omv_mb1683 samples/subsys/video/capture -- -DCONFIG_VIDEO_SHELL=y
