基础

这些示例演示 Zephyr 内核的基本功能。

  • Basic thread manipulation创建多个线程，让 LED 闪烁并向控制台打印信息。
  • Blinky使用 GPIO API 让 LED 无限闪烁。
  • Button使用输入子系统处理 GPIO 按键输入。
  • Fade LED使用 PWM API 让 LED 渐变。
  • GPIO with custom Devicetree binding使用自定义设备树绑定控制 GPIO。
  • Minimal footprint测量 Zephyr 在不同配置下的最小 ROM 占用。
  • PWM Blinky使用 PWM API 让 LED 闪烁。
  • PWM RGB LED使用 PWM API 驱动 RGB LED。
  • Servomotor使用 PWM API 驱动伺服电机。
  • System hashmap在哈希表中插入、替换和删除条目。
  • System heap将系统堆的使用情况打印到控制台。
