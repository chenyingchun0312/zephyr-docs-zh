Basic thread manipulation

Browse source code on GitHub

概述

本示例演示如何使用 K_THREAD_DEFINE() 创建多个线程。它创建三个线程，每个线程都在编译时用 K_THREAD_DEFINE 定义。

前两个线程各控制一个 LED。这两个 LED（led0 和 led1）的循环控制和定时逻辑由各自独立的函数控制。

  • blink0() 控制 led0，睡眠周期为 100ms

  • blink1() 控制 led1，睡眠周期为 1000ms

其中任一线程翻转其 LED 时，还会向一个 FIFO 推入信息，标明是哪个线程/LED 以及已翻转的次数。

第三个线程使用 printk() 将加入 FIFO 的信息打印到设备控制台。

要求

开发板必须有两个通过 GPIO 引脚连接的 LED。在 Zephyr 的许多 开发板 上，这些 LED 称为“用户 LED”。这两个 LED 必须通过 led0 和 led1 设备树 别名配置，通常在 BOARD.dts 文件 中。

如果尝试为不受支持的开发板构建本示例，会看到以下错误之一：

Unsupported board: led0 devicetree alias is not defined
Unsupported board: led1 devicetree alias is not defined

构建

例如，为 96Boards Carbon 构建本示例：

west build -b 96b_carbon/stm32f401xe samples/basic/threads
west flash

对于其他受支持的开发板，请相应修改 96b_carbon/stm32f401xe。
