GPIO with custom Devicetree binding

Browse source code on GitHub

概述

在 Zephyr 中，所有硬件相关配置都在设备树中描述。

因此，GPIO 引脚也在设备树中配置，并通过 compatible 分配特定用途。

这与 Arduino 等其他嵌入式环境不同，在那些环境中，例如 GPIO 引脚的方向（输入/输出）是在应用程序固件中配置的。

对于 LED 或按键等典型用例，可以使用现有的 gpio-leds 或 gpio-keys compatible。

本示例演示如何通过自定义设备树绑定将 GPIO 引脚用于其他用途。

假设需要通过 MOSFET 开关一个大电流负载。由 GPIO 引脚控制的电源输出的自定义设备树绑定定义在文件 samples/basic/custom_dts_binding/dts/bindings/power-switch.yaml 中。MOSFET 的栅极驱动器连接到 boards 文件夹中 .overlay 文件所指定的引脚。

构建与运行

对于每一款需要支持的开发板，都必须在 boards 子文件夹中定义一个 .overlay 文件。

之后可以按如下方式为 <board> 构建并运行本示例：

west build -b <board> samples/basic/custom_dts_binding
west flash

出于演示目的，部分开发板使用内置 LED 的 GPIO 引脚。

在 Native simulator - native_sim 上，该引脚由仿真的 GPIO 控制器提供，因此无需任何硬件即可运行本示例。

示例输出

一秒后，GPIO 引脚应切换到有效电平。

会打印以下输出：

Initializing pin with inactive level.
Waiting one second.
Setting pin to active level.
