System hashmap

Browse source code on GitHub

概述

这是一个简单的示例，它会反复执行以下操作：

  • 插入最多 CONFIG_TEST_LIB_HASH_MAP_MAX_ENTRIES 个条目

  • 替换与之前插入数量相同的条目

  • 删除之前插入的所有键

构建

本应用程序可以按如下方式在 native_sim 上构建：

west build -b native_sim samples/basic/hash_map

要为其他开发板构建，请将上面的 "native_sim" 改为该开发板的名称。

此外，还可以通过指定以下选项使用其他哈希表实现

  • CONFIG_SYS_HASH_MAP_CHOICE_SC=y（分离链接法）

  • CONFIG_SYS_HASH_MAP_CHOICE_OA_LP=y（开放寻址法/线性探测）

  • CONFIG_SYS_HASH_MAP_CHOICE_CXX=y（对 C++ std::unordered_map 的 C 封装）

要对哈希表实现进行压力测试，请调整 CONFIG_TEST_LIB_HASH_MAP_MAX_ENTRIES。

运行

Run build/zephyr/zephyr.exe
