Blinky

Browse source code on GitHub

概述

Blinky 示例使用 GPIO API 让 LED 无限闪烁。

源代码展示了如何：

  1. 从 设备树 获取引脚规格，形式为 gpio_dt_spec

  2. 将 GPIO 引脚配置为输出

  3. 无限翻转引脚电平

使用 PWM API 的类似示例请参阅 PWM Blinky。

要求

你的开发板必须：

  1. 有一个通过 GPIO 引脚连接的 LED（在 Zephyr 的许多 开发板 上称为“用户 LED”）。

  2. 使用 led0 设备树别名配置该 LED。

构建与运行

按如下方式构建并烧录 Blinky，将 reel_board 换成你的开发板：

west build -b reel_board samples/basic/blinky
west flash

烧录后，LED 开始闪烁，控制台上会打印包含当前 LED 状态的信息。如果发生运行时错误，示例会直接退出，不在控制台上打印任何内容。

构建错误

如果尝试为不受支持的开发板构建 Blinky，会在定义 struct gpio_dt_spec led 变量的源代码行看到构建错误。

在基于 GCC 的工具链上，错误如下所示：

error: '__device_dts_ord_DT_N_ALIAS_led_P_gpios_IDX_0_PH_ORD' undeclared here (not in a function)

添加开发板支持

要为你的开发板添加支持，请在设备树中添加类似以下内容：

/ {
     aliases {
             led0 = &myled0;
     };

     leds {
             compatible = "gpio-leds";
             myled0: led_0 {
                     gpios = <&gpio0 13 GPIO_ACTIVE_LOW>;
             };
     };
};

上述配置将开发板的 led0 别名设为使用 GPIO 控制器 gpio0 的 13 号引脚。引脚标志 GPIO_ACTIVE_LOW 表示引脚置为低电平时 LED 点亮，置为高电平时 LED 熄灭。

提示：

  • 关于在设备树中定义基于 GPIO 的 LED 的更多信息，请参阅 gpio-leds。

  • 如果不确定该怎么做，可以查看与目标使用相同 SoC 的受支持开发板的设备树。详情请参阅 获取设备树和生成的头文件。

  • 可在设备树中使用的标志请参阅 include/zephyr/dt-bindings/gpio/gpio.h。

  • 如果 LED 内置于开发板硬件上，该别名应定义在 BOARD.dts 文件 中；否则可以在 设备树覆盖文件（overlay） 中定义。
