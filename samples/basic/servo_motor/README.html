Servomotor

Browse source code on GitHub

概述

这是一个使用 PWM API 驱动伺服电机的示例应用程序。

本示例用 PWM 控制信号使伺服电机在 180 度范围内来回转动。

本应用程序针对 ROB-09065 伺服电机。0 到 180 度范围对应的 PWM 脉冲宽度分别为 700 到 2300 微秒。不同的伺服电机可能需要不同的 PWM 脉冲宽度，如果使用其他伺服电机，可能需要修改源代码。

要求

本示例需要一个伺服电机，其信号引脚连接到由 PWM 驱动的引脚。伺服电机必须在设备树中使用 pwm-servo compatible（属于本示例的一部分）定义，并将其节点标签设为 servo。需要编写类似以下的内容：

/ {
    servo: servo {
        compatible = "pwm-servo";
        pwms = <&pwm0 1 PWM_MSEC(20) PWM_POLARITY_NORMAL>;
        min-pulse = <PWM_USEC(700)>;
        max-pulse = <PWM_USEC(2500)>;
    };
};

注意，常用的周期值为 20 ms。示例请参阅 samples/basic/servo_motor/boards/bbc_microbit.overlay。

接线

BBC micro:bit

需要将电机的红线接外部 5V，黑线接地，白线接 SCL 引脚，即边缘连接器上的 P19 引脚。

构建与运行

本示例为 micro:bit 提供了设备树覆盖文件。

本示例可以为多款开发板构建，本例中为 bbc_microbit 开发板构建：

west build -b bbc_microbit samples/basic/servo_motor
west flash
