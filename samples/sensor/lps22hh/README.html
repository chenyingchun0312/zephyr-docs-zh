LPS22HH Temperature and Pressure Sensor

Browse source code on GitHub

概述

本示例周期性地从 LPS22HH MEMS 压力传感器读取压力并显示在控制台上。

要求

此示例使用通过 I2C 接口控制的 LPS22HH 传感器。

参考资料

  • LPS22HH: https://www.st.com/en/mems-and-sensors/lps22hh.html

构建与运行

该项目将传感器数据输出到控制台。它需要一个 LPS22HH 传感器，X-NUCLEO-IKS01A3 扩展板上带有该传感器。

west build -b nrf52dk/nrf52832 --shield x_nucleo_iks01a3 samples/sensor/lps22hh

示例输出

Configured for triggered collection at 1 Hz
Observation: 1
Pressure: 97.474 kPa
Temperature: 22.19 C
Observation: 2
Pressure: 97.466 kPa
Temperature: 22.21 C
Observation: 3
Pressure: 97.473 kPa
Temperature: 22.21 C
Observation: 4
Pressure: 97.455 kPa
Temperature: 22.21 C

<repeats endlessly every second>
