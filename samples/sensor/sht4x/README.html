SHT4X：高精度数字 I2C 湿度传感器

说明

此示例应用程序周期性地从 SHT4X 设备读取环境温度和湿度，并将结果写入控制台。

SHT4X 传感器带有一个可选的加热器，在特定环境或应用中可能很有用（更多信息请参阅数据手册）。要使用加热器，请查看此应用程序的 Kconfig 选项。

参考资料

  • SHT4X sensor

接线

此示例使用通过 I2C 接口控制的 SHT4X 传感器。连接电源：VDD、GND，接口：SDA、SCL。电源电压范围为 1.7V 到 3.6V。根据所用的底板，SDA 和 SCL 线可能需要上拉电阻。

构建与运行

该项目将传感器数据输出到控制台。它需要一个 SHT4X 传感器。它应该可以在任何带 I2C 外设接口的平台上运行。此示例包含一个适用于 Black Pill V2.0 开发板的设备树覆盖文件。

# From the root of the zephyr repository
west build -b blackpill_f411ce samples/sensor/sht4x
west flash

示例输出

*** Booting Zephyr OS build v2.6.0-rc1-315-g50d8d1187138  ***
SHT4X: 23.64 Temp. [C] ; 30.74 RH [%]
SHT4X: 23.66 Temp. [C] ; 32.16 RH [%]
SHT4X: 23.63 Temp. [C] ; 30.83 RH [%]

数据手册指出，该传感器测量的温度和湿度分别以摄氏度和相对湿度百分比表示。
