TF-M 集成

这些 TF-M 集成示例可用于受支持的 Armv8-M 开发板，演示如何在 Zephyr 中使用 TF-M API。

  • TF-M Firmware Update使用 PSA 固件更新 API 执行固件更新。
  • TF-M IPC使用 IPC 实现安全镜像与非安全镜像之间的通信。
  • TF-M PSA crypto使用 PSA 加密 API 进行加密运算和生成设备证书签名请求。
  • TF-M PSA Protected Storage使用受保护存储（PS）API 存储加密数据。
  • TF-M Secure Partition创建一个提供安全服务的安全分区。

概述

安全处理环境（S）使用 Trusted Firmware 平台安全架构（PSA）API，Zephyr 运行在非安全处理环境（NS）中。

在标准构建流程中，除了 TF-M S 和 Zephyr NS 二进制镜像外，通常还会构建安全引导加载程序（BL2）。随后，S 和 NS 镜像会被合并，并使用私有签名密钥进行签名，对应的公钥存储在安全引导加载程序中。这样，启动时的镜像验证过程就能基于由你掌控的一对私钥来验证应用程序镜像，并决定接受或拒绝。

什么是 Trusted Firmware-M（TF-M）？

Trusted Firmware-M（TF-M）是 平台安全架构（PSA） 的参考实现。

TF-M 提供了一组高度可配置的软件组件，用于构建可信执行环境。这是通过一组安全运行时服务实现的，例如安全存储、加密、审计日志和证明。此外，TF-M 中的安全启动可确保运行时软件的完整性，并支持固件升级。

当前的 TF-M 实现专门面向 ARMv8-M 的 TrustZone。

Trusted Firmware-M 的源代码可在 git.trustedfirmware.org 获取，不过为方便起见，Zephyr 项目在 https://github.com/zephyrproject-rtos/trusted-firmware-m 维护了该源代码的一个分支，作为模块使用。

更多信息请参阅官方 TF-M documentation
