TF-M Secure Partition

Browse source code on GitHub

概述

安全分区（Secure Partition）是位于 TF-M 中的隔离模块。它向其他分区和/或非安全固件提供若干函数，即“安全服务”。TF-M 已包含 crypto、protected_storage 或 firmware_update 等标准分区，但也可以创建自己的分区。

本示例为 TF-M 创建了一个虚拟（dummy）安全分区和安全服务，并让 TF-M 构建系统将其构建到安全固件中。然后在（非安全固件的）main 文件中调用该虚拟安全服务。

这个虚拟分区只有一个安全服务，它可以索引分区内 5 个虚拟密钥中的一个，并获取该密钥的哈希值。

该分区位于 dummy_partition 目录中，包含分区源代码、构建文件和构建配置文件。分区由 TF-M 构建系统构建，详情请参阅 TF-M 构建系统。

有关如何添加自定义安全分区的更多信息，请参阅 TF-M 指南：https://tf-m.docs.trustedfirmware.org/en/latest/integration_guide/services/tfm_secure_partition_addition.html

将此分区改作自己的用途时，请将所有出现的“dummy_partition”“DUMMY_PARTITION”“dp”和“DP”改为自己的分区名称。此外，还要检查安全和非安全的 CMakeLists.txt 文件以及“partition”中的 yaml 文件，并进行相应修改。
