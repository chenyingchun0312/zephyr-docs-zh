TF-M PSA Protected Storage

Browse source code on GitHub

概述

本示例演示如何使用受保护存储（Protected Storage，PS）API 存储数据。

受保护存储提供键/值存储接口，数据（默认）经过加密，并可选择启用认证和回滚保护。默认加密算法为 AES-128-GCM。加密密钥派生自硬件唯一密钥（HUK），HUK 通常通过设备熔丝等方式设置。

本示例使用 PS API 将数据存储到非易失性存储器中。示例展示了如何向 UID 存储和读取数据，以及如何通过标志启用覆盖保护。

TF-M 规定了 PS 记录的最大数量（通过 PS_NUM_ASSETS 设置，TF-M 1.3.0 中默认为 10）和单条记录的最大大小（通过 PS_MAX_ASSET_SIZE 设置，TF-M 1.3.0 中默认为 2048）。这些默认值可能因所用平台而异，构建系统会在 TF-M 编译阶段打印当前值。

有关受保护存储的更多信息，请参阅平台安全架构（PSA）安全存储 API：https://developer.arm.com/architectures/architecture-security-features/platform-security

本示例适用于 trusted-firmware-m 仓库所支持的平台：https://git.trustedfirmware.org/TF-M/trusted-firmware-m.git/ 支持的平台列表请参阅 tests.yaml。

构建与运行

在目标设备上

注意，烧录本示例前需要完全擦除开发板，因为所用的 Flash 区域可能包含之前的数据。每次运行本示例之间也必须擦除开发板，因为断电复位不会解除覆盖保护。

On QEMU

详细说明请参阅 TF-M IPC。下面是一个基于 west build 的示例

$ west build samples/tfm_integration/psa_protected_storage/ -p -b mps2/an521/cpu0/ns -t run
