Stepper

Browse source code on GitHub

说明

本示例演示如何使用步进电机驱动 API 控制步进电机。示例会让步进电机旋转、使能、禁用、停止，并将事件输出到控制台。

步进电机以 4 种不同模式旋转：ping_pong_relative、ping_pong_absolute、continuous_clockwise 和 continuous_anticlockwise。微步间隔（单位为纳秒）可以通过 CONFIG_STEP_INTERVAL_NS 配置。示例还演示了如何使用步进电机回调在走过一定步数后改变步进电机的方向。

按下任意按键都会切换步进电机的模式。模式会打印到控制台上。支持以下模式：enable、ping_pong_relative、ping_pong_absolute、rotate_cw、rotate_ccw、stop 和 disable。

示例还有一个监视线程，每隔 CONFIG_MONITOR_THREAD_TIMEOUT_MS 毫秒打印一次步进电机的实际位置。

构建与运行

本项目让步进电机旋转，并将事件输出到控制台。

# From the root of the zephyr repository
west build -b nucleo_g071rb samples/drivers/stepper/generic
west flash
