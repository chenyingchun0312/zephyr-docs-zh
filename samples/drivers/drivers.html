驱动

这些示例演示如何使用 Zephyr 支持的各种驱动。

  • Analog-to-Digital Converter (ADC) sequence sample使用序列从 ADC 通道读取模拟输入。
  • Analog-to-Digital Converter (ADC) with devicetree从 ADC 通道读取模拟输入。
  • AT45 DataFlash driver使用 AT45 系列 DataFlash 驱动通过 SPI 与 Flash 存储器交互。
  • audio codec麦克风到扬声器回环。
  • Auxiliary digits display向辅助显示屏输出递增的数字。
  • Auxiliary display向辅助显示屏输出 "Hello World"。
  • Buzzer TonePlay a short beep and a few tones through the buzzer device aliased as buzzer0.
  • Charger使用充电器驱动 API 为电池充电。
  • Clock Monitor Frequency Check持续将时钟与可编程的频率阈值进行比较。
  • Clock Monitor Frequency Meter测量一次时钟频率并打印结果。
  • Controller Area Network (CAN) babbling node模拟一个“喋喋不休”的 CAN 节点。
  • Controller Area Network (CAN) counter发送和接收 CAN 消息。
  • Counter Alarm使用计数器 API 实现闹钟应用程序。
  • Crypto使用加密 API 执行各种加密/解密操作。
  • Cyclic Redundancy Check Drivers (CRC)使用 CRC 驱动 API 计算并验证 CRC 校验和。
  • Digital Addressable Lighting Interface (DALI)让连接到 DALI 总线的 LED 控制器闪烁。
  • Digital Microphone (DMIC)使用不同配置执行 PDM 传输。
  • Digital-to-Analog Converter (DAC)使用 DAC 驱动 API 生成模拟锯齿波信号。
  • Display在显示设备上绘制基本矩形。
  • EEPROM在 EEPROM 中保存启动计数值。
  • Enhanced Serial Peripheral Interface (eSPI)使用 eSPI 连接从设备并交换虚拟线数据包。
  • Fingerprint sensorDemonstrate fingerprint sensor enrollment, verification, identification, and template management using the biometric driver API.
  • Flash shell使用 shell 命令探查 Flash 设备。
  • Fuel Gauge使用电量计 API 访问电量计属性并获取电量信息。
  • Generic ADC stream使用流（stream）从 ADC 获取数据。
  • GNSS连接 GNSS 设备以获取时间、导航数据和卫星信息。
  • Hash HW benchmark测量加密哈希 API 实现的吞吐量和 CPU 负载。
  • HD44780 LCD controller使用 GPIO 引脚控制基于 HD44780 的 LCD 显示屏。
  • HT16K33 LED driver with keyscan控制最多 128 个连接到 HT16K33 LED 驱动芯片的 LED，并记录键盘扫描事件。
  • HWSPINLOCKDemonstrate cross-core synchronization using the HWSPINLOCK API together with the MBOX API.
  • JEDEC SPI-NOR flash使用 Flash API 与 SPI NOR 串行 Flash 存储设备交互。
  • JESD216 flash使用 JESD216 Flash API 从兼容的串行存储设备中提取信息。
  • LiteX clock control driver使用 LiteX 时钟控制驱动生成多个时钟信号。
  • MBOX使用 MBOX API 实现处理器间邮箱通信。
  • MBOX Data使用 MBOX API 进行带数据的处理器间邮箱通信。
  • Memory controller (MEMC) driver读写外部存储器
  • Multi-Function Device (MFD) with Charger, Fuel Gauge, and Regulators使用充电器、电量计和稳压器子系统演示多功能设备。
  • nRF SoC Internal Storage使用 Flash API 与 SoC Flash 交互。
  • PECI interface使用 PECI 监视 CPU 温度。
  • PS/2 interface与 PS/2 鼠标通信。
  • PSI5 interface使用 PSI5（外设传感器接口）驱动。
  • Real-Time Clock (RTC)设置和读取实时时钟的日期/时间。
  • SENT interface使用 SENT（单边沿半字节传输）驱动。
  • SMBus shell使用 shell 命令与 SMBus 外设交互。
  • SPI bitbang使用 bitbang SPI 驱动与外设通信。
  • Time-aware GPIO同步时钟。
  • Watchdog使用看门狗驱动 API，在开发板陷入无限循环时将其复位。

Ethernet

  • Inter-VM Shared Memory (ivshmem) Ethernet使用 IVSHMEM 以太网与 Jailhouse 虚拟机监控程序中的另一个“cell”通信。

Firmware Samples

  • SCMI Platform Interaction使用各种协议与 SCMI 平台交互。

FPGA

  • FPGA Controller将比特流加载到 FPGA 中并对其执行基本操作。

General Purpose I/O (GPIO)

  • Bouffalolab GPIO FIFO / Wire Out UART使用 Wire Out 输出 UART
  • Button interrupt使用中断处理 GPIO 输入。

Haptics

  • CS40L26 Haptic Driver使用 CS40L26/27 触觉反馈驱动芯片驱动 LRA。
  • CS40L5x Haptic Driver使用 CS40L5x 触觉反馈驱动芯片驱动 LRA。
  • DRV2605 Haptic Driver使用 DRV2605 触觉反馈驱动芯片驱动 LRA。
  • TM6605 Haptic Driver使用天微电子（Titan Micro Electronics）TM6605 触觉反馈驱动芯片驱动 LRA。

Inter-Integrated Circuit (I2C) Bus

  • I2C Custom Target在 I2C 接口上设置自定义 I2C 目标设备。
  • I2C RTIO loopback使用 RTIO 在 I2C 控制器与自定义 I2C 目标设备之间执行 I2C 传输。
  • I2C Target在 I2C 接口上设置 I2C 目标设备。

I2S

  • I2S codec处理音频流并发送到编解码器。
  • I2S echo处理音频流以添加回声效果。
  • I2S output发送 I2S 输出流

Interrupt controller

  • RISC-V AIA SMP UART echo在 SMP 系统上使用 RISC-V AIA 中断投递回显 UART 输入。
  • RISC-V AIA UART echo通过 APLIC 和 IMSIC 使用 RISC-V AIA 中断投递回显 UART 输入。

Inter-Processor Mailbox (IPM)

  • IPM on ESP32在 ESP32 的 APP 与 PRO CPU 之间实现处理器间邮箱（IPM）。
  • IPM on NXP i.MX在带有消息单元外设的 i.MX SoC 上实现处理器间邮箱（IPM）。
  • IPM on NXP LPC在 NXP LPC 系列上实现处理器间邮箱（IPM）。
  • IPM over IVSHMEM通过 IVSHMEM（虚拟机间共享内存）实现处理器间邮箱（IPM）
  • IPM with ARM MHU使用 MHU（消息处理单元）实现处理器间邮箱（IPM）

Light-Emitting Diode (LED)

  • Breathing-blinking LED (BBLED)使用 Microchip XEC 驱动控制 BBLED（呼吸/闪烁 LED）。
  • IS31FL319x RGB LEDCycle colors on an RGB LED connected to the IS31FL3193, IS31FL3194 or IS31FL3197 using the LED API.
  • IS31FL3216A LED控制最多 16 个连接到 IS31FL3216A 驱动芯片的 PWM LED。
  • IS31FL3733 LED Matrix控制最多 192 个连接到 IS31FL3733 驱动芯片的 LED 组成的矩阵。
  • LED PWM使用 LED API 控制 PWM LED。
  • LED strip控制 LED 灯带。
  • LP3943 RGBW LED控制最多 16 个连接到 LP3943 驱动芯片的 RGBW LED。
  • LP50XX RGB LED控制最多 12 个连接到 LP50xx 驱动芯片的 RGB LED。
  • LP5562 RGB LED控制 4 个连接到 LP5562 驱动芯片的 RGB LED。
  • LP5569 9-channel LED controller控制 9 个连接到 LP5569 驱动芯片的 LED。
  • LP586x LED matrix控制 LP586x LED 矩阵控制器上的 LED 点。
  • PCA9633 LED控制 4 个连接到 PCA9633 驱动芯片的 LED。
  • SCT2024 LED Controller控制最多 16 个连接到 SCT2024 芯片的 LED。
  • SX1509B RGB LED控制连接到 SX1509B 驱动芯片的 RGB LED。

Local Interconnect Network (LIN)

  • NCV7430 LED Controller over LIN通过 Zephyr 的 LIN API 使用 NCV7430 LED 控制器的示例应用程序。
  • NCV7430 mock LIN responder将 NCV7430 LED 控制器模拟为 LIN 从节点的示例应用程序。

LoRa

  • LoRa duty cycle使用硬件 RX 占空比（无线唤醒）接收 LoRa 数据包。
  • LoRa receiveReceive packets in both synchronous and asynchronous mode using the LoRa radio.
  • LoRa send使用 LoRa 射频模块每秒发送一次预先配置的负载。

Miscellaneous

  • FT800使用 FT800 嵌入式视频引擎显示各种图形和文本。
  • Grove LCD显示一个递增的计数器并改变背光颜色。
  • TMC6460 Voltage Mode使用 Trinamic TMC6460 以开环电压模式驱动 BLDC 电机。

Modem

  • AT Command Client在控制台与调制解调器之间建立双向 UART 桥接，用于 AT 命令通信。
  • Hello hl78xx modem driver使用 HL78XX 调制解调器 API 获取和设置 hl78xx 调制解调器的基本信息与功能

Multi-bit SPI Bus (MSPI)

  • Ambiq MSPI timing scan为给定开发板上的给定设备找到合适的时序。
  • JEDEC MSPI-NOR flash使用 Flash API 与 MSPI NOR 串行 Flash 存储设备交互。
  • MSPI asynchronous transfer使用 MSPI API 与 MSPI 存储设备进行异步交互。
  • MSPI throughput performance test测量不同缓冲区大小和数据包数量下的 MSPI 吞吐量性能。

OPAMP

  • nPM10xx UICR演示 Nordic nPM10 系列 PMIC 的 UICR 编程流程。

Pulse IO

  • pulse_io byte transfer使用编解码辅助函数通过 pulse_io 控制器传输字节。

PWM

  • PWM EventPWM 信号上的事件。

SPI

  • SPI RTIO loopback使用 RTIO 在 SPI 控制器与 SPI 目标设备之间执行 SPI 传输。

Stepper

  • TMC50XX stepper旋转 TMC50XX 步进电机并在运行时改变速度。
  • TMCM-3216 stepperControl a stepper motor using the ADI TMCM-3216 standalone stepper motor controller and driver board over RS485.

Universal Asynchronous Receiver-Transmitter (UART)

  • Native TTY UART使用原生 TTY 驱动在两个 UART 转 USB 桥接适配器之间收发数据。
  • UART ASYNC API演示异步 API 的用法
  • UART echo从控制台读取数据并回显。
  • UART Passthrough在控制台与另一个 UART 接口之间直接传递数据。

Virtualization

  • IVSHMEM doorbellUse Inter-VM Shared Memory to exchange messages between two processes running on different operating systems.

1-Wire
