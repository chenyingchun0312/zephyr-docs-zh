UART echo

Browse source code on GitHub

概述

本示例通过一个简单的回显机器人演示如何使用 UART 串口驱动。它从控制台读取数据，并在收到行结束符（回车键）后将字符回显。

发送数据使用轮询 API，接收数据使用中断驱动 API，因此理论上线程可以在等待输入数据时做其他事情。

默认使用通常用于 Zephyr shell 的 UART 外设，因此几乎所有开发板都应受支持。

构建与运行

按如下方式构建并烧录本示例，将 nrf52840dk/nrf52840 换成你的开发板：

west build -b nrf52840dk/nrf52840 samples/drivers/uart/echo_bot
west flash

示例输出

Hello! I\'m your echo bot.
Tell me something and press enter:
# Type e.g. "Hi there!" and hit enter!
Echo: Hi there!
