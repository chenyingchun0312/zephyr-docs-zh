Inter-VM Shared Memory (ivshmem) Ethernet

Browse source code on GitHub

概述

本应用程序演示如何使用 IVSHMEM 以太网与 Jailhouse 虚拟机监控程序（hypervisor）中的另一个“cell”通信。目前仅支持 qemu_cortex_a53 开发板。

为 QEMU 构建 Jailhouse Linux

克隆 Jailhouse yocto 项目。撰写本文时，“next”分支包含一些尚未合入“master”分支的修复：

git clone https://github.com/siemens/jailhouse-images.git
cd jailhouse-images
git switch --detach origin/next

打开菜单，选择“QEMU ARM64 virtual target”，然后选择“Save & Build”（这需要一段时间）：

./kas-container menu
编辑“start-qemu.sh”：

  • 在 arm64|aarch64 分支下将 -cpu cortex-a57 改为 -cpu cortex-a53

  • 在 QEMU 进程参数中的 -netdev user,id=net 后追加 ,hostfwd=tcp::2222-:22 以启用 SSH 访问（2222 可以替换为任意未使用的端口）

启动 QEMU：

./start-qemu.sh arm64

这样应会启动 Linux 并进入 shell。

构建 Zephyr 示例

# From the root of the zephyr repository
west build -b qemu_cortex_a53 samples/drivers/ethernet/eth_ivshmem

运行示例

将生成的 zephyr.bin 复制到 Jailhouse Linux 根 cell：

scp -P 2222 path/to/zephyr.bin root@localhost:/root

Jailhouse 提供了适用于本示例的预构建 Zephyr cell 配置“qemu-arm64-zephyr-demo”。

回到 Jailhouse Linux shell，创建 Zephyr cell：

jailhouse enable /etc/jailhouse/qemu-arm64.cell
jailhouse console
jailhouse cell create /etc/jailhouse/qemu-arm64-zephyr-demo.cell

这里可能会遇到 Linux shell 不再接受输入的怪异现象……如果出现这种情况，请通过 SSH 打开第二个 shell：

ssh -p 2222 root@localhost

加载并启动 Zephyr cell：

jailhouse cell load qemu-arm64-zephyr-demo zephyr.bin --address 0x70000000
jailhouse cell start qemu-arm64-zephyr-demo

现在可以运行 Zephyr 和 Linux 的 shell 命令，在两个 cell 之间通信。

从 Zephyr ping Linux

运行 zperf / iPerf

可以使用 zperf：网络流量生成器 / iPerf 测量网络吞吐量。

在 Zephyr 中：

# Start zperf TCP server
zperf tcp download 5001

在 Linux 中：

# Install iPerf 2.0.5
apt install wget
wget https://iperf.fr/download/ubuntu/iperf_2.0.5+dfsg1-2_arm64.deb
apt install ./iperf_2.0.5+dfsg1-2_arm64.deb
rm iperf_2.0.5+dfsg1-2_arm64.deb

# Connect iPerf TCP client
iperf -l 1K -V -c 192.168.19.2 -p 5001

Zephyr 输出：

New TCP session started.
TCP session ended
 Duration:              10.01 s
 rate:                  57.72 Mbps
