MBOX Data

Browse source code on GitHub

概述

本示例演示如何在数据传输模式下使用 MBOX API。它只能与支持数据传输模式的 mbox 驱动一起使用。

示例通过两个 mbox 通道在两个内核之间来回传递数据。数据大小取决于驱动的 MTU（最大传输单元），不同平台各不相同。每个内核收到数据后，将计数器加一，再发回另一个内核。

配置

示例使用 CONFIG_MBOX_DATA_MAX_MSG_SIZE 选项（默认 4 字节）确定消息缓冲区的大小。如果开发板的 mbox 驱动支持更大的 MTU，应在特定于开发板的配置片段（boards/<board>.conf）中覆盖该值，例如 CONFIG_MBOX_DATA_MAX_MSG_SIZE=32。实际的 MTU 会在运行时通过 mbox_mtu_get_dt() 查询，并与所配置的容量进行校验。

构建与运行

本示例可以在支持数据传输模式 MBOX 的开发板上构建并运行。

为 mimxrt1160_evk_cm7 构建应用程序

# From the root of the zephyr repository
west build -b mimxrt1160_evk_cm7 --sysbuild samples/drivers/mbox_data/
west debug

为 mimxrt1170_evk_cm7 构建应用程序

# From the root of the zephyr repository
west build -b mimxrt1170_evk_cm7 --sysbuild samples/drivers/mbox_data/
west debug

为 lpcxpresso55s69_cpu1 构建应用程序

# From the root of the zephyr repository
west build -b lpcxpresso55s69_cpu1 --sysbuild samples/drivers/mbox_data/
west debug

为 frdm_mcxn947/mcxn947/cpu0 构建应用程序

# From the root of the zephyr repository
west build -b frdm_mcxn947/mcxn947/cpu0 --sysbuild samples/drivers/mbox_data/
west debug

为 ek_ra8p1/r7ka8p1kflcac/cm85 构建应用程序

# From the root of the zephyr repository
west build -b ek_ra8p1/r7ka8p1kflcac/cm85 --sysbuild samples/drivers/mbox_data/
west debug

示例输出

打开串口终端（minicom、putty 等），使用以下设置连接开发板：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1
