LiteX clock control driver

Browse source code on GitHub

简介

本示例概述 LiteX 时钟控制驱动的功能。该驱动使用混合模式时钟管理器（MMCM）模块生成最多 7 个具有指定相位、频率和占空比的时钟。

要求

  • 支持 LiteX 且带有 MMCM 模块的 FPGA 平台（例如 Digilent Arty A7 开发板）

  • LiteX 中带有 VexRiscv 软核 CPU 和 Xilinx 7 系列 MMCM 接口（S7MMCM 模块）的 SoC 配置

  • 可选：将时钟输出信号引到输出引脚以便测试

配置

驱动的基本配置（包括时钟输出的默认设置）保存在设备树的时钟控制节点中。

clk0: clock-controller@0 {
	#clock-cells = <1>;
	reg = <0>;
	compatible = "litex,clkout";
	clock-output-names = "CLK_0";
	litex,clock-frequency = <11289600>;
	litex,clock-phase = <0>;
	litex,clock-duty-num = <1>;
	litex,clock-duty-den = <2>;
	litex,clock-margin = <1>;
	litex,clock-margin-exp = <2>;
	status = "okay";
};

clk1: clock-controller@1 {
	#clock-cells = <1>;
	reg = <1>;
	compatible = "litex,clkout";
	clock-output-names = "CLK_1";
	litex,clock-frequency = <22579200>;
	litex,clock-phase = <0>;
	litex,clock-duty-num = <1>;
	litex,clock-duty-den = <2>;
	litex,clock-margin = <1>;
	litex,clock-margin-exp = <2>;
	status = "okay";
};

clock0: clock@e0004800 {
	compatible = "litex,clk";
	reg = <0xe0004800 0x4>,
	      <0xe0004804 0x4>,
	      <0xe0004808 0x4>,
	      <0xe000480c 0x4>,
	      <0xe0004810 0x4>,
	      <0xe0004814 0x4>,
	      <0xe0004818 0x4>,
	      <0xe000481c 0x4>;
	reg-names = "drp_reset",
		    "drp_locked",
		    "drp_read",
		    "drp_write",
		    "drp_drdy",
		    "drp_adr",
		    "drp_dat_w",
		    "drp_dat_r";
	#clock-cells = <1>;
	clocks = <&clk0 0>, <&clk1 1>;
	clock-output-names = "CLK_0", "CLK_1";
	litex,lock-timeout = <10>;
	litex,drdy-timeout = <10>;
	litex,divclk-divide-min = <1>;
	litex,divclk-divide-max = <107>;
	litex,clkfbout-mult-min = <2>;
	litex,clkfbout-mult-max = <65>;
	litex,vco-freq-min = <600000000>;
	litex,vco-freq-max = <1200000000>;
	litex,clkout-divide-min = <1>;
	litex,clkout-divide-max = <126>;
	litex,vco-margin = <0>;
	status = "okay";
};

此配置定义了 2 个时钟输出：clk0 和 clk1，默认频率为 100MHz，相位偏移 0 度，占空比 50%。定义 FPGA 特定配置的值（从 litex,divclk-divide-min 到 litex,vco-margin 的参数）时需要特别小心。

重要提示： clk0 和 clk1 节点中的 reg 属性表示时钟输出编号（clkout_nr）

驱动用法

驱动通过 时钟控制 API 函数 clock_control_on() 和 LiteX 驱动专用的结构体（litex_clk_setup）进行调用。

要修改时钟参数，需要将指向 litex_clk_setup 结构体的指针强制转换为 clock_control_subsys_t，并将其用于 clock_control_on()。
这段代码会尝试将 clk0 设置为频率 50MHz、相位偏移 90 度、占空比 75%。
struct device *dev;
int ret;
struct litex_clk_setup setup = {
        .clkout_nr = 0,
        .rate = 50000000,
        .duty = 75,
        .phase = 90
};
dev = DEVICE_DT_GET(MMCM);
clock_control_subsys_t sub_system = (clock_control_subsys_t)&setup;
if ((ret = clock_control_on(dev, sub_system)) != 0) {
        LOG_ERR("Set CLKOUT%d param error!", setup.clkout_nr);
        return ret;
}

时钟输出状态（频率、占空比和相位偏移）可以通过函数 clock_control_get_status() 获取，若只需查询时钟输出频率，可以使用 clock_control_get_rate()

两个获取函数的基本用法都与 clock_control_on() 类似。使用结构体 litex_clk_setup 设置要获取数据的时钟输出的 clkout_nr。

使用示例

本示例提供了一种检查各种时钟输出设置的简单方法。用户可以从 4 种场景中选择一种：

  • 频率范围，

  • 占空比范围，

  • 相位范围，

  • 同时设置频率、占空比和相位，然后检查时钟状态和频率，

通过将 LITEX_CLK_TEST 定义为以下值之一来选择场景：

  • LITEX_TEST_FREQUENCY

  • LITEX_TEST_DUTY

  • LITEX_TEST_PHASE

  • LITEX_TEST_SINGLE

代码在 clkout_nr 由 LITEX_CLK_TEST_CLK1 和 LITEX_CLK_TEST_CLK2 定义的 2 个时钟输出上运行。每种场景的测试由各自的宏定义控制。

构建

west build -b litex_vexriscv zephyr/samples/drivers/clock_control

驱动会向日志打印大量有用的调试信息。强烈建议启用日志及日志消息的同步处理，并将日志级别设置为 Info。
