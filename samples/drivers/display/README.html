Display

Browse source code on GitHub

概述

本示例使用 显示 API 在显示屏上绘制一些基本图形。

对于大多数显示控制器，这些图形是矩形，其颜色和位置经过选择，可用于检查 LCD 的方向和 RGB 位序是否正确。矩形从左上角开始按顺时针顺序绘制：红、绿、蓝、灰。灰色的深浅会从黑色变为白色。

小技巧

如果灰色在任何时候看起来偏绿或偏红，或者各角的顺序与上述描述不符，则 LCD 可能存在字节序颠倒的问题！

在一次只能绘制整行的显示屏上（参见 SCREEN_INFO_X_ALIGNMENT_WIDTH），例如使用 sharp,ls0xx 驱动的显示屏，RGB 标签页中描述的矩形会被替换为占满显示屏整个宽度的条带。

只有绿色和灰色的条带可见（每个角的绘制都使用整个宽度，因此左上角和右上角的绘制在顶部重叠，右下角和左下角的绘制在底部重叠）。

在使用多位亮度格式（例如 PIXEL_FORMAT_L_8）的显示屏上，每个角显示不同的灰度级；左下角的色块仍会从黑色渐变为白色。其他多位单色格式的行为类似（每个角显示不同的灰度）。

在每像素 1 位的显示屏上，底部矩形（或条带）的灰度动画会表现为在黑白之间闪烁。其他角保持固定颜色，该颜色与当前像素格式下的显示背景一致。

通过查询显示控制器的能力，检查 display_capabilities.screen_info 中是否设置了 SCREEN_INFO_EPD 位，即可判断显示屏是否为电子纸显示屏。

对于此类显示屏，左下角颜色的变化速度会比普通 LCD 慢得多，以适应电子墨水技术通常的刷新率。

构建与运行

这是一个通用示例，应可用于 Zephyr 支持的任何显示屏。

下面是为搭配 Adafruit 2.8" TFT Touch Shield v2 的 nRF52840 DK 开发板构建的示例。

west build -b nrf52840dk/nrf52840 --shield adafruit_2_8_tft_touch_v2 samples/drivers/display

为了在无需任何硬件的情况下进行测试，也支持 native_sim 开发板，可按如下方式构建：

west build -b native_sim samples/drivers/display
