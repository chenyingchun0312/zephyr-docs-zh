IPM over IVSHMEM

Browse source code on GitHub

前提条件

  • 需要有可用的 QEMU。

需要有可用且正在运行的 ivshmem-server。该服务器包含在 Zephyr SDK 中，部分发行版也提供预构建版本。此外，QEMU 源码树中也包含它。

需要有 ivshmem-client，因为本示例将其用作外部应用程序。ivshmem-client 的获取方式与 ivshmem-server 相同，它也随 QEMU 提供。

准备 IVSHMEM 服务器

  1. QEMU 的 ivshmem-server 工具位于 Zephyr SDK 目录中：/path/to/your/zephyr-sdk/zephyr-<version>/sysroots/x86_64-pokysdk-linux/usr/xilinx/bin/

  2. 该目录中还有 ivshmem-client 工具，可用于检查一切是否按预期工作。

  3. 运行 ivshmem-server。对于 ivshmem-server，向量数和共享内存大小都在运行时（执行服务器时）决定。对于 Zephyr，ivshmem 的向量数在编译时决定，共享内存大小在运行时决定。在 Arm64 上，本示例的项目配置使用 vectors == 2。下面是一个例子：

    # n = number of vectors
$ sudo ivshmem-server -n 2
$ *** Example code, do not use in production ***

  4. 根据你的部署场景，适当设置 /dev/shm/ivshmem 和 /tmp/ivshmem_socket 的所有权。例如：

    $ sudo chgrp $USER /dev/shm/ivshmem
$ sudo chmod 060 /dev/shm/ivshmem
$ sudo chgrp $USER /tmp/ivshmem_socket
$ sudo chmod 060 /tmp/ivshmem_socket

构建与运行

准备好 QEMU 后，先创建两个输出文件夹：打开两个终端并分别创建，这些文件夹将接收 Zephyr west 命令的输出：

$ mkdir -p path/to/instance_1

在另一个终端窗口中执行：

$ mkdir -p path/to/instance_2

然后按如下方式构建示例。注意，测试本示例需要两次构建，因此请追加选项 -d path/to/instance_1，并在另一个终端窗口中同样操作，即追加 -d path/to/instance_2

west build -b qemu_cortex_a53 samples/drivers/ipm/ipm_ivshmem

要运行两侧的 QEMU，请重复 west build 命令并加上 -d path/to/instance_x（x 根据终端窗口为 1 或 2），使用 run 目标：

west build -b qemu_cortex_a53 samples/drivers/ipm/ipm_ivshmem
west build -t run

预期输出

在控制台上使用 ivshmem_ipm_send 命令并跟上目标 peer-id 即可。要获取目标 peer-id，请到另一个终端窗口用 ivshmem 命令查看：

*** Booting Zephyr OS build zephyr-v3.4.0-974-g7fba7d395750 ***


uart:~$ ivshmem
IVshmem up and running:
   Shared memory: 0xafa00000 of size 4194304 bytes
   Peer id: 12
   Notification vectors: 2
uart:~$

例如，其中一个实例的 peer-id 为 12，则到另一个实例中使用该命令并跟上这个 peer-id，发送 IPM 通知：

*** Booting Zephyr OS build zephyr-v3.4.0-974-g7fba7d395750 ***


uart:~$ ivshmem
IVshmem up and running:
   Shared memory: 0xafa00000 of size 4194304 bytes
   Peer id: 11
   Notification vectors: 2
uart:~$ ivshmem_ipm_send 12

然后回到另一个终端窗口，用户可以在终端上看到收到的通知：

uart:~$ ivshmem
IVshmem up and running:
   Shared memory: 0xafa00000 of size 4194304 bytes
   Peer id: 12
   Notification vectors: 2
uart:~$ Received IPM notification over IVSHMEM
