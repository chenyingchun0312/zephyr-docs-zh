Button interrupt

Browse source code on GitHub

概述

一个简单的按键演示，展示带中断的 GPIO 输入用法。每次按下按键时，示例都会向控制台打印一条消息。

要求

开发板硬件必须有一个通过 GPIO 引脚连接的按键。在 Zephyr 的许多 开发板 上，这类按键称为“用户按键”。

必须使用 sw0 设备树 别名配置按键，通常在 BOARD.dts 文件 中配置。如果尝试为不受支持的开发板构建本示例，会看到以下错误：

Unsupported board: sw0 devicetree alias is not defined

如果 sw0 别名存在但定义不正确，可能还会看到其他构建错误。

本示例还支持可选的 led0 设备树别名。这与 Blinky 示例使用的别名相同。如果提供了该别名，按下按键时 LED 点亮，松开按键时 LED 熄灭。

设备树细节

本节详细介绍设备树配置。

下面是支持本示例的最小设备树片段。为简单起见，其中只包含 sw0 别名，省略了可选的 led0 别名。

/ {
        aliases {
                sw0 = &button0;
        };

        soc {
                gpio0: gpio@0 {
                        status = "okay";
                        gpio-controller;
                        #gpio-cells = <2>;
                        /* ... */
                };
        };

        buttons {
                compatible = "gpio-keys";
                button0: button_0 {
                        gpios = <&gpio0 PIN FLAGS>;
                        label = "User button";
                };
                /* ... other buttons ... */
        };
};

如上所示，sw0 设备树别名必须指向一个 compatible 为 "gpio-keys" 的节点的子节点。

上述情况适用于以下常见场景：

  • gpio0 是一个示例节点标签，指向某个 GPIO 控制器

  • PIN 应为引脚编号，例如 8 或 0

  • FLAGS 应为要应用于按键的 GPIO 配置标志 的按位或，例如 (GPIO_PULL_UP | GPIO_ACTIVE_LOW)

这里假定常见情况：gpio0 节点中 #gpio-cells = <2>，且 GPIO 控制器的设备树绑定将这两个 cell 命名为 "pin" 和 "flags"，如下所示：

gpio-cells:
  - pin
  - flags

本示例要求 gpios 属性中有 pin cell。flags cell 是可选的，即使 GPIO cell 中不包含 flags，示例仍可正常工作。

构建与运行

本示例可以为多款开发板构建，本例中为 nucleo_f103rb 开发板构建：

west build -b nucleo_f103rb samples/drivers/gpio/button_interrupt

启动后，程序查找预定义的 GPIO 设备，将引脚配置为输入模式，并启用下降沿中断。在主循环的每次迭代中，都会监视 GPIO 线的状态并将其打印到串口控制台。按下输入按键时，中断处理程序会打印有关该事件的信息及其时间戳。
