I2C RTIO loopback

Browse source code on GitHub

概述

本示例演示如何使用 RTIO 同步和异步地执行 I2C 传输。它最多使用两个 I2C 控制器，分别充当 I2C 控制器和目标设备。

要求

本示例需要满足以下条件之一：

  • 两个 I2C 控制器，一个支持 I2C 控制器角色，另一个支持 I2C 外设角色，两者连接到同一条 I2C 总线。

  • 一个同时支持 I2C 控制器和外设角色的 I2C 控制器。

备注

记得设置好 I2C 总线：连接 SCL 和 SDA 的上拉电阻，并将相关 I2C 控制器物理连接到总线上。

开发板支持

任何满足要求的开发板都必须使用覆盖文件指定哪个 I2C 控制器充当控制器、哪个充当外设，注意两者可以是同一个控制器。分别通过设备树别名 i2c-controller 和 i2c-controller-target 指定：

/ {
        aliases {
                i2c-controller = &i2c1;
                i2c-controller-target = &i2c2;
        };
};

如有需要，请在特定于开发板的覆盖配置中添加开发板特有的配置：

CONFIG_I2C_TARGET_BUFFER_MODE=y

传输的数据大小

可以使用配置选项 CONFIG_I2C_RTIO_LOOPBACK_DATA_READ_MAX_SIZE 和 CONFIG_I2C_RTIO_LOOPBACK_DATA_WRITE_MAX_SIZE 调整测试期间交换的数据字节数。
