Fuel Gauge

Browse source code on GitHub

概述

本示例展示如何使用 Zephyr 电量计 API 驱动。

首先，示例尝试读取所有公开的电量计属性，以确认所用的电量计驱动支持哪些属性。然后，示例使用 FUEL_GAUGE_RELATIVE_STATE_OF_CHARGE_PCT 和 FUEL_GAUGE_VOLTAGE_UV 属性定期读取电池电量百分比和电压。

备注

为避免错误配置芯片，本示例不设置/写入任何属性。

构建与运行

本示例可以配置为支持某个电量计。

特性

使用该电量计可以获得以下信息：

  • 读取所有公开的电量计属性

  • 电池电量百分比（定期）

  • 电池电压（定期）
