OpenAMP Linux Zephyr RPMsg

Browse source code on GitHub

概述

本应用程序演示如何使用 OpenAMP 在 Zephyr 与 Linux 之间通信，双方都使用 OpenAMP 库。

在 Linux 端，应用程序使用 meta-openamp 提供的 OpenAMP 库，从而以一致、标准化的方式实现核间通信。

构建应用程序

Zephyr

RZ/G3S-SMARC 的构建命令

west build -b rzg3s_smarc/r9a08g045s33gbg/cm33 samples/boards/renesas/openamp_linux_zephyr

RZ/V2L-SMARC 的构建命令

west build -b rzv2l_smarc/r9a07g054l23gbg/cm33 samples/boards/renesas/openamp_linux_zephyr

运行示例

Linux 端设置

For RZ/G3S-SMARC

本示例目前支持 Linux RZ/G Multi-OS Package v3.0.0。Renesas Multi-OS Package 的构建步骤如下。

  1. 按照 Quick Start Guide for RZ/G3S Multi-OS Package [1] 中“3.2 Integration of Multi-OS Package related stuff”一节的步骤操作，但不要启动构建过程。

  2. 对于 RZ/G3S，请按照以下指南添加 PLAT_M33_BOOT_SUPPORT=1：RZ/G3S SMARC Evaluation Board Kit [2]

  3. 将高亮的代码行插入以下文件：meta-rz-features/meta-rz-multi-os/meta-rzg3s/recipes-example/rpmsg-sample/files/platform_info.c

    if (ret) {
LPRINTF("failed rpmsg_init_vdev");
goto err;
}
/* RPMsg virtio enables callback for avail flags */
ret = virtqueue_enable_cb(rpmsg_vdev->rvq);
if (ret) {
   LPRINTF("Failed release availability flags");
   goto err;
}
#ifndef __linux__ /* uC3 */
start_ipi_task(rproc);
#endif
return rpmsg_virtio_get_rpmsg_device(rpmsg_vdev);

  4. 开始构建。

  5. 关于如何部署引导加载程序文件、Linux 内核镜像、设备树和根文件系统，请参阅：SMARC EVK of RZ/G3S Linux Start-up Guide [3]

For RZ/V2L-SMARC

本示例目前支持 Linux RZ/V Multi-OS Package v3.1.1。Renesas Multi-OS Package 的构建步骤如下。

  1. 按照 RZ/V2L SMARC Evaluation Board Kit [4] 中“Flashing”一节的步骤 (1) 和 (2) 操作

  2. 将高亮的代码行插入以下文件：meta-rz-features/meta-rz-multi-os/meta-rzv2l/recipes-example/rpmsg-sample/files/platform_info.c

    if (ret) {
LPRINTF("failed rpmsg_init_vdev");
goto err;
}
/* RPMsg virtio enables callback for avail flags */
ret = virtqueue_enable_cb(rpmsg_vdev->rvq);
if (ret) {
   LPRINTF("Failed release availability flags");
   goto err;
}
#ifndef __linux__ /* uC3 */
start_ipi_task(rproc);
#endif
return rpmsg_virtio_get_rpmsg_device(rpmsg_vdev);

  3. 开始构建。

4. For deploying bootloader files, Linux kernel image, device tree and rootfs, follow the steps (4) to (8) from the ''Flashing'' section of RZ/V2L SMARC Evaluation Board Kit [4]

Zephyr 端设置

  1. 按照开发板的“Flashing”说明将示例烧录到开发板。

  2. 打开串口终端（minicom、putty 等），使用以下设置连接开发板：

    • 波特率：115200

    • 数据位：8 位

    • 校验位：无

    • 停止位：1

Linux 控制台

  1. 打开 Linux shell（minicom、ssh 等），以 root 身份登录：

    smarc-<device> login: root

  2. 运行以下命令：

    root@smarc-<device>:~# rpmsg_sample_client 0 0
