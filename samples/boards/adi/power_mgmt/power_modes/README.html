ADI Power Modes

Browse source code on GitHub

概述

ADI 电源管理示例会运行给定 SoC 的各种电源模式，用于演示和功耗测量。

prj.conf 展示了启用电源管理所需的 Kconfig，设备树覆盖文件展示了如何按存储体（memory bank）配置 RAM 保持。

要求

开发板应支持电源管理，并有一个可用作系统定时器辅助的计数器设备。

构建与运行

按如下方式构建并烧录 ADI 电源模式示例：

west build -b max32657evkit/max32657 samples/boards/adi/power_mgmt/power_modes
west flash

烧录后，应用程序会反复循环进入设备树中定义的所有电源模式，每种模式至少睡眠该模式所需的最短驻留时间。

提示：

  • 在测试电源模式或在设备上启用电源管理时，最好启用 CONFIG_BOOT_DELAY，以免调试器被锁在外面。
