NXP

这些示例展示如何在 Zephyr 中使用 NXP 开发板。

  • Audio output AMP sample.NXP i.MX RTxxx 平台的 AMP 系统示例：音频回环。
  • Audio output AMP sample.NXP i.MX RTxxx 平台的 AMP 系统示例：音频输出。
  • Blinky AMP sampleNXP i.MX RTxxx 平台的 AMP 系统示例：LED 闪烁。
  • FLEXRAM magic address配置一个在访问任意 RAM/TCM 地址时触发的中断。
  • FRDM-MCXA156 lpdac opamp lpadc example放大 OPAMP 的输入，并使用 ADC 对其采样。
  • mbox API AMP sampleAMP system example for NXP i.MX RTxxx platforms - IPC using the mbox API.
  • Number crunching using optimized library为复杂数学运算设置并使用不同的后端。
  • NXP MCX suspend-to-RAMSuspend an NXP MCXA/MCXN SoC to RAM and resume on an LPTMR timer (or button) wakeup delivered through the WUU wakeup controller.
  • NXP MCX system offUse system off (Deep Power Down) on NXP MCXA/MCXN SoCs and wake through the WUU wakeup controller.
  • NXP SmartDMA memory-to-memoryUse the NXP SmartDMA coprocessor to perform a memory-to-memory transfer through the Zephyr DMA API.
  • OpenAMP DSP AMP Sample使用 OpenAMP 通过并发通信信道在多个内核之间发送消息。
  • RT1060 System Off在 MIMXRT1060-EVK 上使用软关机（soft-off）。
  • RT595 System Off在 MIMXRT595-EVK 上使用软关机（soft-off）。
  • RT700 EVK dual-core power managementExercise active, sleep, deep-sleep and deep-sleep-retention combinations on both RT700 EVK Cortex-M33 cores.
  • RT700 System Off在 MIMXRT700-EVK 上使用系统关闭（system off）。
  • RW612 PM flash check检查外部 NOR Flash 在 RW612 各低功耗模式下是否正常。
  • S32 Network Controller (NETC)配置 NXP S32 网络控制器（NETC）
  • System Off (MCXE31B standby)在 FRDM-MCXE31B 上使用待机（唯一的低功耗模式），并通过 RTC 告警唤醒。
  • TensorFlow Lite for Microcontrollers on NXP Neutron在 NXP Neutron NPU 上使用 MobileNet 模型运行推理。
