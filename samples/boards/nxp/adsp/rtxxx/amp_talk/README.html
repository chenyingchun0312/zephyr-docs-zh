OpenAMP DSP AMP Sample

Browse source code on GitHub

概述

本应用程序演示如何在 NXP RT700 系列处理器上使用 OpenAMP 进行多核通信。它展示了从主核（CM33_0）同时与多个远端内核进行 OpenAMP 通信：

  • CM33_0 ↔ CM33_1：Cortex-M33 内核之间的处理器间通信

  • CM33_0 ↔ HiFi4 DSP：ARM Cortex-M33 与 Cadence HiFi4 DSP 之间的通信

本应用程序演示：

  • 多个并发的 OpenAMP/RPMSG 实例

  • 每个通信信道使用独立的共享内存区域

  • 与不同远端内核之间独立的消息传递

  • 适当的资源隔离与同步

架构

本示例由三个独立的应用程序组成：

  1. Primary Core (CM33_0):

    • 运行两个并发线程

    • 管理与 CM33_1 和 HiFi4 DSP 的通信

    • 作为两个信道的 RPMSG 主机（host）

  2. Remote CM33 Core (CM33_1):

    • 作为 RPMSG 远端（remote）运行

    • 通过专用共享内存与 CM33_0 通信

  3. Remote DSP Core (HiFi4):

    • 作为 RPMSG 远端（remote）运行

    • 通过独立的共享内存区域与 CM33_0 通信

为 mimxrt700_evk 构建应用程序

# From the root of the zephyr repository
west build -b mimxrt700_evk/mimxrt798s/cm33_cpu0 --sysbuild samples/boards/nxp/adsp/rtxxx/amp_talk/
west debug

打开串口终端（minicom、putty 等），使用以下设置连接开发板：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

主要特性

  • 并发通信：主核同时管理两个独立的 OpenAMP 信道

  • 资源隔离：每个通信信道使用独立的共享内存区域和 IPM 实例

  • 多架构支持：演示 ARM Cortex-M33 与 Cortex-M33 之间以及 ARM 与 DSP 之间的通信

  • 可扩展设计：该架构可以扩展以支持更多远端内核

技术细节

实现中使用了：

  • 为每个通信信道使用独立的 RPMSG virtio 设备

  • 独立的共享内存池和区域

  • 专用的 IPM（处理器间消息）实例

  • 适当的 OpenAMP 资源管理和清理

本示例可作为在嵌入式系统中使用 OpenAMP 框架实现复杂多核通信场景的参考。
