S32 Network Controller (NETC)

Browse source code on GitHub

概述

本示例应用程序展示了如何针对不同用例配置 NXP S32 网络控制器（NETC）：

  1. Zephyr 应用程序控制物理站接口（PSI），并通过 EMDIO 控制以太网 PHY。

  2. Zephyr 应用程序控制 PSI、虚拟 SI 1，并通过 EMDIO 控制以太网 PHY。

本示例启用了 net-shell 和 mdio-shell（仅在 Zephyr 控制 PSI 时可用），方便用户查看网络设置。同时还启用了 Telnet shell 及其后端。

本示例应用程序的源代码位于：samples/boards/nxp/s32/netc。

要求

运行本示例需要准备一台运行 GNU/Linux 或 Windows 的主机，其网络适配器通过以太网线连接到目标开发板的 ETH0 端口。

构建与运行

针对用例 1 构建并运行示例应用程序：

# From the root of the zephyr repository
west build -b s32z2xxdc2/s32z270/rtu0 samples/boards/nxp/s32/netc
west flash

设置主机

为了能从主机访问开发板，需要配置主机网络接口的 IP 地址和默认路由。本指南假定主机的 IPv4 和 IPv6 地址分别为 192.0.2.3 和 2001:db8::3。例如，在 GNU/Linux 主机上使用名为 enp1s0 的网络接口，或在 Windows 主机上使用名为 Ethernet 的网络接口时，可以用以下命令完成配置：

ip -4 addr add 192.0.2.3/24 dev enp1s0
ip -6 addr add 2001:db8::3/128 dev enp1s0
route -A inet6 add default dev enp1s0

netsh interface ipv4 set address "Ethernet" static 192.0.2.3 255.255.255.0
netsh interface ipv6 add address "Ethernet" 2001:db8::3/128
netsh interface ipv6 add route ::/0 "Ethernet" ::

备注

以上命令必须以特权用户身份运行。

如果一切配置正确，你就能在 Zephyr shell 中成功执行以下命令：

net ping -I<iface> 192.0.2.3
net ping -I<iface> 2001:db8::3

其中 <iface> 是从 1 开始的接口编号。
