RT595 System Off

Browse source code on GitHub

概述

本示例可用于基本的功耗测量，也可作为 NXP i.MX RT 平台上软关机（soft off）的示例。其功能行为如下：

  • 忙等待 2 秒

  • 启用 RTC 唤醒后关闭系统，并设置一个 10 秒后的告警来唤醒处理器

要求

本应用程序使用 MIMXRT595-EVK 进行演示。

构建、烧录与运行

west build -b mimxrt595_evk/mimxrt595s/cm33 samples/boards/nxp/mimxrt595_evk/system_off
west flash

运行：

  1. 打开 UART 终端。

  2. 对设备重新上电。

  3. 设备将上电并空闲 2 秒

  4. 设备会使用深度掉电模式自行关闭。RTC 告警会唤醒设备，并通过热复位重新启动应用程序。

示例输出

MIMXRT595-EVK 内核输出

*** Booting Zephyr OS build zephyr-v3.2.0-1045-g07228f716c78  ***

Wake-up alarm set for 10 seconds
Powering off
用于从深度掉电唤醒并复位 Flash 的 OTP 熔丝设置

背景

在默认设置的 EVK 上，本示例从深度掉电（DPD）模式唤醒后不会恢复应用程序运行。原因是从 DPD 唤醒时通常不会复位 Flash。本示例从外部 Flash 原地执行（XIP）。MCU 从 DPD 唤醒时会走复位流程，但如果外部 Flash 没有复位，MCU 与 Flash 就不再同步，MCU 无法进行 XIP。在这种默认状态下，可以确认 RTC 确实将 MCU 从 DPD 中唤醒了，因为 MCU 会将 PMIC_MODE 引脚设为 0b00，请求 PMIC 进入默认启动模式，PMIC 会使能驱动 VDDCORE 电源轨的 1.0V 稳压器。但 MCU 无法从 Flash 进行 XIP 以恢复运行。此时可以按复位按键重新启动应用程序。

要从 DPD 唤醒并恢复从 Flash 的 XIP，需要将 MCU 配置为复位外部 Flash。这可以通过烧写 MCU 中的一次性可编程（OTP）熔丝实现。以下步骤详细说明如何烧写 OTP BOOT_CFG1 熔丝，将 GPIO 引脚 PIO4_5 用作 Flash 复位。该熔丝设置指示 ROM 引导加载程序在复位 Flash 时翻转 PIO4_5。注意，MIMXRT595-EVK 开发板的设计是由 PIO4_5 驱动 FlexSPI0 上八线 Flash 的复位引脚。使用这款 MCU 的其他开发板可能使用不同的 GPIO 引脚，OTP 熔丝中的设置必须与连接到复位的 GPIO 引脚一致。烧写熔丝之前，最好先写入 OTP 影子寄存器并确认操作，确认设置正确后再烧写 OTP 熔丝。关于 OTP 熔丝和影子寄存器的更多细节，请参阅这款 MCU 的参考手册，以及参考手册 PDF 中作为附件提供的 OTP Fuse Map 电子表格。

所需工具

这些步骤使用 blhost 工具，它可在运行 Linux、Windows 或 macOS 的主机上运行。下载 blhost，找到适合你主机操作系统的 blhost 可执行文件，然后按以下命令行步骤烧写 OTP 熔丝。下载时请访问 https://www.nxp.com/mcuboot，在 Downloads 下找到 Blhost 软件包。

在 MIMXRT595-EVK 上烧写 OTP 熔丝的步骤

这些步骤详细说明如何使用 USB 作为 blhost 与 ROM 引导加载程序之间的接口。UART 是另一种选择，详情请参阅 blhost 文档以及 MCU 参考手册中的 Boot ROM 一章。

  1. 给 EVK 上电，并将 USB J38 连接到主机。J38 用于 MCU 的 USB 外设，同时也为 EVK 供电。

  2. 将 SW7 的拨码开关设为 On-Off-On（123），以 ISP USB HID 模式启动。

  3. 按下复位按键 SW3，以 ISP 模式启动。EVK 应在主机上枚举为一个 USB HID 设备。

  4. 以下命令确认 BOOT_CFG1 熔丝的当前设置：blhost -u 0x1fc9,0x0023 -- efuse-read-once 0x61

  5. 以下命令烧写 BOOT_CFG1，启用使用 PIO4_5 的 Flash 复位引脚：blhost -u 0x1fc9,0x0023 -- efuse-program-once 0x61 0x164000

  6. 以下命令确认 BOOT_CFG1 中已烧写的熔丝：blhost -u 0x1fc9,0x0023 -- efuse-read-once 0x61

  7. 将 SW7 的拨码开关设为 Off-Off-On（123），从 FlexSPI0 上的外部 Flash 启动。

  8. 按下复位按键 SW3，从 Flash 启动并运行应用程序。
