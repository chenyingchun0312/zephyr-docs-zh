Microphone

Browse source code on GitHub

概述

本示例展示如何通过板载 MP34DT05 麦克风采集音频。麦克风产生 PDM 流，通过 I2S 采集。随后使用 OpenPDMFilter 库将 PDM 流转换为 PCM，该库的源代码包含在本示例中。

要求

本示例需要 ArgonKey 开发板，外加一根 USB 转 TTL 1V8 串口线来获取输出的音频流。开发板可以通过以下两种方式之一供电：

  • 夹层（mezzanine）模式：通过 96Board 低速连接器将 ArgonKey 插到 HiKey 开发板上

  • 独立模式：直接在 P1 连接器上提供 5V 电源

参考资料

  • Argonkey

构建与运行

west build -b 96b_argonkey samples/boards/96boards/argonkey/microphone
west build -t run

示例输出

示例采集 5 秒音频，并在 COM 端口上打印 PCM 流。可以将 USB 转 TTL 1V8 串口线接到开发板背面低速连接器的 P3.5（TX）和 P3.7（RX）上。

采集一开始，绿色 LED 点亮。采集结束时，绿色和红色 LED 都点亮，并在 COM 端口上发送 PCM 流。输出完成后，绿色 LED 熄灭，红色 LED 保持点亮。按下 RST 按键可以重复这一过程。

  • 音频采集开始： GRN 亮 - RED 灭

  • 音频采集结束： GRN 亮 - RED 亮

  • 音频输出结束： GRN 灭 - RED 亮

PCM 音频的参数在示例中是硬编码的：

  • 16KHz 采样率

  • 每个采样 16 位

  • 1 个声道（单声道），因为只有 1 个麦克风

以 16KHz 采样率采集 5 秒，得到 80,000 个 16 位采样。所请求的麦克风 PDM 时钟应使 MP34DT05 驱动选择等于 128 的过采样/抽取因子，从而得到 2.048MHz 的位时钟。

PCM 和 PDM 配置请参阅文件 samples/boards/96boards/argonkey/microphone/src/main.c。

备注

可以将 AUDIO_FREQ 改为 32000，只采集 2500 ms。这种情况下过采样/抽取因子为 64。

采集结束时，PCM 数据会以二进制或 ASCII 格式打印到终端仿真程序上。输出格式由 samples/boards/96boards/argonkey/microphone/src/main.c 中的以下宏控制，默认关闭：

  • PCM_OUTPUT_IN_ASCII

二进制 PCM 输出

ttyUSB0 端口必须配置为原始（raw）模式，以免字符被“加工”（cooked）。

stty -F /dev/ttyUSB0 115200 raw
cat /dev/ttyUSB0 > /tmp/sound.raw

备注

"cat /dev/ttyUSB0 > /tmp/sound.raw" 命令应在音频采集开始后（绿色 LED 点亮后）、音频采集结束前（红色 LED 点亮前）执行，以免初始启动信息进入文件。

备注

如果字符 0x0a 被解释为 NL 并被加上了 0x0d（CR），可能需要将其删除:

dos2unix -f /tmp/sound.raw

ASCII PCM 输出

也可以重新编译，使 PCM 以 ASCII 格式输出，之后需要再转换为二进制。输出格式如下：

ArgonKey test!!
-- start
0xfbe0,
0xfbf0,
0xfc0c,
0xfc24,
0xfc3c,
0xfc4c,
0xfc68,
0xfc48,

[...]

0xfb98,
0xfb98,
0xfbb8,
0xfbac,
0xfbc4,
0xfbe8,
0xfbf4,
-- end

播放 PCM 音频

得到二进制 PCM 文件（例如 sound.raw）后，可以使用开源编辑器/播放器 audacity 等工具加载并播放它。使用 'Import->Raw Data' 菜单，以有符号 16 位 PCM、小端序、单声道、16KHz 格式加载 sound.raw 文件。
