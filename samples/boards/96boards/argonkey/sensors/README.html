Sensors

Browse source code on GitHub

概述

本示例展示如何从 ArgonKey 开发板读取传感器数据，结果显示在控制台上。它同时使用了触发和轮询两种方式。

要求

本示例只需要 ArgonKey 开发板。开发板可以通过以下两种方式之一供电：

  • 夹层（mezzanine）模式：通过 96Board 低速连接器将 ArgonKey 插到 HiKey 开发板上

  • 独立模式：直接在 P1 连接器上提供 5V 电源

用户可以在 samples/boards/96boards/argonkey/sensors/prj.conf 中选择或取消选择传感器。

请注意，所有与传感器相关的代码都使用 #ifdef 指令进行条件编译，因此本示例应总能正确构建。例如：

#ifdef CONFIG_HTS221
  struct device *hum_dev = DEVICE_DT_GET_ONE(st_hts221);

  if (!device_is_ready(hum_dev)) {
    printk("%s: device not ready.\n", hum_dev->name);
    return;
  }
#endif

参考资料

  • Argonkey

构建与运行

west build -b 96b_argonkey samples/boards/96boards/argonkey/sensors
west build -t run

示例输出

可以将 USB 转 TTL 1V8 串口线接到开发板背面低速连接器的 P3.5（TX）和 P3.7（RX）上。用户可以使用 minicom 等简单的终端仿真程序捕获输出。

proxy: 1  ;
distance: 0 m -- 09 cm;
temp: 30.35 C; press: 97.466259 kPa
humidity: 43.500000 %RH
accel (0.004000 -0.540000 9.757000) m/s^2
gyro (0.065000 -0.029000 -0.001000) rad/s
magn (0.049500 0.208500 -0.544500) G
- (6) (trig_cnt: 1878)

<repeats endlessly every 2s>

本例中，输出通过每 2 秒轮询一次传感器生成。

传感器数据按以下顺序打印（未启用的传感器不打印数据）：

  1. VL53L0x 接近传感器

  2. LPS22HB baro/temp

  3. HTS221 湿度传感器

  4. LSM6DSL 加速度计

  5. LSM6DSL 陀螺仪

  6. LIS2MDL 磁力计（连接到 LSM6DSL）

接近传感器显示两行：

  • 一个标志（proxy），当距离小于 10cm 时置位

  • 与障碍物之间的绝对距离

最后一行显示已收到的触发中断次数的计数器。启用 ARGONKEY_TEST_LOG 宏后，可以显示每次触发时读取的传感器数据。
