Sound

Browse source code on GitHub

概述

本示例演示如何使用连接到 BBC micro:bit v1 边缘连接器 P0 端口的压电蜂鸣器，或使用 BBC micro:bit v2 上的板载蜂鸣器。

要求

使用 BBC micro:bit v1 时，必须将一个单独的压电蜂鸣器连接到开发板。例如 MI:Power 板，它除了一颗纽扣电池外还带有一个压电蜂鸣器。通过网上搜索可以很容易找到这款板的经销商。

升级后的 BBC micro:bit v2 开发板不需要单独的蜂鸣器，因为其背面内置了一个（标为 'speaker'）。

构建与运行

可以按如下方式构建本示例：

为 BBC micro:bit v1 构建

west build -b bbc_microbit samples/boards/bbc/microbit/sound
west flash

为 BBC micro:bit v2 构建

west build -b bbc_microbit_v2 samples/boards/bbc/microbit/sound
west flash

示例输出

本示例根据两个主按键的按下情况，通过压电蜂鸣器输出声音。每次按下按键时，当前的输出频率会显示在 5x5 LED 显示屏上。
