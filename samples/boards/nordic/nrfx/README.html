nrfx

Browse source code on GitHub

概述

本示例演示如何在 Zephyr 中使用 nrfx 库，以 GPIOTE 和 DPPI/PPI 作为 nrfx 驱动的示例。

代码展示了如何在 Zephyr 中初始化 GPIOTE 中断，以便 nrfx_gpiote 驱动使用它。此外，它还展示了如何使用 DPPI/PPI 子系统连接 nRF 外设的任务和事件，使这些外设无需 CPU 干预即可相互交互。

Zephyr GPIO 驱动被禁用，以免它为 GPIOTE 中断注册自己的处理程序。按键 1 被配置为按下时产生一个事件，该事件会调用 button_handler() 回调，并触发 LED 1 引脚的 OUT 任务，从而翻转 LED。

请注意，按键没有使用任何消抖机制，因此一次按下可能会产生多个事件。而且由于事件与任务的连接是在硬件中处理的，对于非常快速到来的事件，LED 的翻转有时甚至可能察觉不到。

要求

本示例已在 Nordic Semiconductor nRF9160 DK（nrf9160dk/nrf9160）和 nRF52840 DK（nrf52840dk/nrf52840）开发板上测试过。

构建与运行

代码位于 samples/boards/nordic/nrfx。

构建并烧录应用程序：

west build -b nrf9160dk/nrf9160 samples/boards/nordic/nrfx
west flash

按下按键 1 翻转 LED 1。

连接串口，可以看到每次按下按键时都会调用 button_handler() 函数。

关于 nrfx 的更多信息，请参阅 nrfx_repository。
