Synchronized RTC

Browse source code on GitHub

概述

本示例展示如何同步应用核与网络核上用作系统时钟的 RTC 时钟。同步的结果是网络核上的一个偏移值，可以将其应用到系统节拍上，用于日志时间戳。

本示例使用 IPM 驱动和 IPC HAL 产生在两个内核上同时发生的事件。应用核周期性地读取当前系统节拍，将其存入共享内存，并触发 IPC 任务，从而在网络核上产生中断。在 IPC 中断处理程序的上下文中，网络核记录共享内存中的时间戳，以及经过偏移校正的本地系统节拍。可以观察到，在同步流程完成之前，两个时间戳相差很大；流程完成后，时间戳即保持同步。由于中断处理引入的延迟，网络核的时间戳可能略微滞后（通常为 1 个节拍）。

为了简单和低延迟，本示例没有使用更复杂的 IPM 协议。

为 nrf5340dk/nrf5340/cpuapp 构建应用程序

# From the root of the zephyr repository
west build -b nrf5340dk/nrf5340/cpuapp --sysbuild samples/boards/nordic/nrf53_sync_rtc
west flash --hex-file build/nrf53_sync_rtc/zephyr/zephyr.hex

打开串口终端（例如 Minicom 或 PuTTY），使用以下设置连接开发板：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

为模拟的 nrf5340bsim 构建应用程序

# From the root of the zephyr repository
west build -b nrf5340bsim/nrf5340/cpuapp --sysbuild samples/boards/nordic/nrf53_sync_rtc

然后可以使用以下命令运行应用程序：

$ ./build/zephyr/zephyr.exe -nosim
# Press Ctrl+C to exit

在调用的控制台中可以看到与真实硬件上类似的输出。
