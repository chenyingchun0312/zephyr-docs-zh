nRF5x Clock Skew

Browse source code on GitHub

概述

本示例使用时间源关联 API 测量 HFCLK（用于 CPU）与 LFCLK（用于系统时间）之间的偏差。它还展示如何利用该偏差，将在 LFCLK 域中测得的时长校正为 HFCLK 域中的时长。

可以选择 CONFIG_APP_ENABLE_HFXO Kconfig 选项，将高频时钟配置为使用晶体振荡器，而不是默认的 RC 振荡器。（蓝牙等需要精确高频时钟的功能通常会自动启用该时钟源。）启用 HFXO 后，相对误差会显著降低。

要求

本应用程序可使用任意 nRF51 DK 或 nRF52 DK 开发板进行演示。

构建、烧录与运行

west build -b nrf52dk/nrf52832 samples/boards/nordic/clock_skew
west flash
