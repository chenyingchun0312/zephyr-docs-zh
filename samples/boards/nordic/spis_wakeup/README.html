SPIS wake up

Browse source code on GitHub

概述

本示例展示如何使用 nrf-spis 驱动中额外的唤醒线。配置为 SPIS 的应用程序在等待 SPI 传输时进入睡眠。一个作为 SPIM 工作并同时控制唤醒线的外部设备（本示例中为另一个内核）会在传输开始前唤醒应用程序。为了模拟两台独立的设备，本示例使用 Nordic Semiconductor nRF54H20 DK，SPIS / SPIM 驱动由两个独立的内核控制：

  • nrf54h20dk/nrf54h20/cpuapp 作为 SPIS 控制器设备工作

  • nrf54h20dk/nrf54h20/cpurad 作为 SPIM 控制器设备工作

要求

本示例可以在 nRF54H20 等多核 SoC 上运行，需要按下文进行额外接线。

接线

需要用导线（跳线）连接 SPIS 和 SPIM 设备：

  • SPIS WAKE <-> WAKE SPIM

  • SPIS CS <-----> CS SPIM

  • SPIS SCK <---> SCK SPIM

  • SPIS MOSI <-> MOSI SPIM

  • SPIS MISO <-> MISO SPIM

构建与运行

代码位于 samples/boards/nordic/spis_wakeup。

构建并烧录应用程序：

west build -b nrf54h20dk/nrf54h20/cpuapp samples/boards/nordic/spis_wakeup
west flash
