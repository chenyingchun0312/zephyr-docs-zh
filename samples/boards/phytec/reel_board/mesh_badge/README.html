Bluetooth Mesh badge

Browse source code on GitHub

概述

这个面向 reel board 的示例应用展示了 Bluetooth Mesh。

应用启动时是一个普通的 Bluetooth GATT 外设应用。在手机上安装“nRF Connect”应用（Android 和 iOS 均可用），即可访问该应用提供的服务。也可以在 PC 上用任意 Bluetooth LE GATT 客户端访问该服务，不过以下说明侧重于手机上的操作步骤。

设置步骤

  1. 在手机上使用 nRF Connect 应用扫描设备，查找“reel board”

  2. 连接该设备。你会看到一个服务，选中它

  3. 点击向上箭头图标，请求写入该特征

  4. 选择“Text”以输入文本而不是十六进制数据

  5. 输入你的名字（或任意其他文本）。可以输入以空格分隔的多个单词。reel 显示屏所用的字体最多可显示三行、每行 12 个字符宽的文本。可以用逗号强制换行。

  6. 点击“Send”，由于这是受保护的特征，此操作会触发配对。配对所需的配对码（passkey）会显示在开发板的屏幕上。在手机上输入该配对码。

  7. 配对完成后，开发板会显示你发送的文本。如果不满意，可以尝试写入其他内容。

  8. 对文本满意后，断开与开发板的连接（退出应用或返回设备扫描页面）

  9. 断开连接后，开发板切换到 Bluetooth Mesh 模式，此后无法再通过 GATT 连接它。

如果按此方式配置多块开发板，它们可以通过 mesh 相互通信：按下开发板上的用户按键，所存文本的第一个单词（名字）就会发送给网络中的所有其他开发板，使它们显示“<name> says hi!”。

要将开发板恢复到初始状态（禁用 mesh、擦除所存文本，并使其可通过 GATT 连接）：

  1. 上电时按住用户按键（或在通电状态下按复位键）

  2. 等待显示“Resetting Device”
