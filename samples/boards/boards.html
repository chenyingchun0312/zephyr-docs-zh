开发板

这些示例演示 Zephyr 中某些开发板专有的功能。

  • ADI MAX32 GPIO Wakeup使用 GPIO 将系统从低功耗状态唤醒
  • ADI Power Modes运行给定 SoC 的各种电源模式
  • AXI Clocking Wizard使能、重新配置并读回 AXI Clocking Wizard 的输出时钟。
  • LED matrix display使用 BBC micro:bit 开发板上的 5x5 LED 点阵显示屏。
  • Line following robot使用 BBC micro:bit 开发板和机器人底盘实现一台循迹机器人。
  • Microphone通过 ArgonKey 板载的 MP34DT05 麦克风采集音频。
  • Pong game单人玩乒乓球游戏，或在两台 micro:bit 设备之间通过蓝牙对战。
  • Sensors从 ArgonKey 开发板的板载传感器读取数据。
  • Sound使用 BBC micro:bit 开发板上的压电蜂鸣器。

  • Deep Sleep在 ESP32 上使用深度睡眠，并通过定时器、GPIO 和 EXT1 唤醒源唤醒。

  • Memory-Mapped Flash将数据写入存储分区，并使用 Flash API 和内存映射指针读取。
  • Pixel processing accelerator使用像素处理加速器缩放、旋转和镜像图像。

  • XTAL32K Watchdog Timer (WDT)在外部 32K 晶体故障时触发看门狗中断。
