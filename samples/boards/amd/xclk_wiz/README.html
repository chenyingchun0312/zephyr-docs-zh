AXI Clocking Wizard

Browse source code on GitHub

概述

本示例演示 AMD Versal Gen 2（Telluride / VERSAL_NET）上由 Xilinx AXI Clocking Wizard 驱动（xlnx,clkx5-wiz-1.0）实现的三个早期访问（EA）clock_control API：

  • EA1：clock_control_on / clock_control_off（时钟输出使能）

  • EA2：clock_control_set_rate（动态重新配置 CLKOUT 频率）

  • EA3：clock_control_get_rate（读回已设置的输出频率）

本示例以第一个 AXI Clocking Wizard 实例（位于 0xb2000000 的 clk_wiz_0）的 CLKOUT0 为目标，依次设置一组目标频率：100 MHz、200 MHz 和 300 MHz。

当另一个 CLKOUT 处于活动状态时，clock_control_set_rate 会保留共享的 MMCM VCO，只修改所选输出的分频器。请求的频率必须能由当前 VCO 精确得到，否则调用失败，且不会改变 MMCM 配置。

硬件要求

  • AMD Versal Gen 2（VEK385 或同类）开发板

  • Vivado 比特流，其中 AXI Clocking Wizard IP 实例化于

    0xb2000000，参考时钟输入为 100 MHz

  • 用于串口输出的 JTAG 或 UART 连接

构建与运行

west build -b versal2_apu samples/boards/amd/xclk_wiz
west flash   # or load via XSDB / JTAG

示例输出

Clocking Wizard sample application
Device: clock-controller@b2000000, testing CLKOUT0
Initial CLKOUT0 rate: 100000000 Hz
CLKOUT0 enabled (clock_control_on OK)
Requesting CLKOUT0 = 100000000 Hz ...
Actual  CLKOUT0 = 100000000 Hz
Requesting CLKOUT0 = 200000000 Hz ...
Actual  CLKOUT0 = 200000000 Hz
Requesting CLKOUT0 = 300000000 Hz ...
Actual  CLKOUT0 = 300000000 Hz
CLKOUT0 disabled (clock_control_off OK)

配置

  • 一个 misc_clk_0 固定时钟节点（100 MHz 参考时钟）

  • 一个位于 0xb2000000 的 clk_wiz_0 时钟控制器节点

调整覆盖文件中的 xlnx,num-out-clks，使其与开发板设计中配置的输出数量一致。父时钟声明的频率必须与 Clocking Wizard 的硬件参考时钟频率一致。

相关文件

  • 驱动：drivers/clock_control/clock_control_xclk_wiz.c

  • DTS 绑定：dts/bindings/clock/xlnx,clkx5-wiz-1.0.yaml

  • Kconfig：drivers/clock_control/Kconfig.xclk_wiz
