Deep Sleep

Browse source code on GitHub

概述

ESP32 系列的深度睡眠模式是一种省电模式，会关闭 CPU、大部分 RAM 以及由 APB_CLK 提供时钟的数字外设的电源。

本示例展示如何设置唤醒源、触发深度睡眠，然后利用预先配置的唤醒源将系统重新唤醒。

本例演示以下唤醒源：

  1. Timer：一个 RTC 定时器，可编程为在预设时间后触发唤醒。本例每 20 秒触发一次唤醒。

  2. EXT1：外部唤醒 1 关联多个 RTC GPIO。本例使用 GPIO2 和 GPIO4，当两个引脚中任意一个为高电平时触发唤醒。

  3. GPIO：仅部分 Espressif SoC 支持，例如在 ESP32-C3 上，GPIO0~5 可用作唤醒源。

目标 SoC 会一直重复以下过程：启用定时器作为唤醒源，深度睡眠 CONFIG_EXAMPLE_WAKEUP_TIME_SEC 秒，然后唤醒。

要求

如果只使用 Timer 作为唤醒源，本例应能在任何常见的 ESP32-DevKitC 开发板上运行，无需额外硬件。

但启用 EXT1 时，GPIO2 和 GPIO4 必须配置下拉，以免引脚悬空。这通常通过设备树完成（例如使用 GPIO_PULL_DOWN）。触发唤醒时，必须将其中一个或两个引脚驱动为高电平。悬空的引脚可能触发误唤醒。

用于 EXT1 或 GPIO 唤醒的 GPIO 引脚及其电气特性（例如引脚编号、上下拉配置和有效电平）定义在示例的设备树覆盖文件中，可根据测试需要修改。

构建、烧录与运行

west build -b esp32_devkitc/esp32/procpu samples/boards/espressif/deep_sleep
west flash
