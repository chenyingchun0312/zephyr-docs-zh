ESP32 qdec per-unit threshold trigger

Browse source code on GitHub

概述

每个 PCNT 单元有两个可编程的阈值观察点，计数器达到其中任一个时会产生中断。Zephyr 的 sensor_trigger 没有 chan_idx 字段，因此驱动允许调用者通过 <zephyr/drivers/sensor/pcnt_esp32.h> 中的旧式 SENSOR_CHAN_PCNT_ESP32_UNIT 辅助宏指定某个单元。单元 0 也可以用 SENSOR_CHAN_ROTATION 或 SENSOR_CHAN_ENCODER_COUNT 指定。

示例在单元 0 上设置上限阈值，在单元 1 上设置下限阈值，每次观察点触发时递增对应单元的计数器。累计的触发次数每秒打印一次。

本示例是 ESP32 专用的，因为它使用了 SENSOR_CHAN_PCNT_ESP32_UNIT(n) 辅助宏。只有当 Zephyr 的传感器触发 API 带上通道索引后，才可能实现可移植的等效示例（参见 PR 描述中后续的 RFC）。

要求

任何带 PCNT 外设的 Espressif SoC。将两个脉冲源接到相应 boards/<board>.overlay 文件中所配置的引脚。没有脉冲源时，计数器永远不会达到阈值，也不会触发任何回调。

构建与运行

west build -b esp32s3_devkitc/esp32s3/procpu samples/boards/espressif/qdec_trigger
west flash

示例输出

*** Booting Zephyr OS build ... ***
unit0 upper_thresh=100: rc=0
unit1 lower_thresh=-100: rc=0
triggers armed: rc=0
hits unit0=0 unit1=0
hits unit0=1 unit1=0
hits unit0=1 unit1=1
