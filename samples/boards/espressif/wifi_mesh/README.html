Wi-Fi Mesh

Browse source code on GitHub

概述

本示例在一组 ESP32 开发板之间组建一个自组织的 Wi-Fi mesh 网络。每个节点以 AP 与 station 组合模式运行 Wi-Fi：station 接口向上连接父节点，softAP 接口接受下游的子节点。各节点之间自行选举出一个根节点。只有根节点会关联所配置的路由器以访问外部网络；内部节点之间只通过 mesh 使用 esp_wifi_mesh_send() 和 esp_wifi_mesh_recv() 交换数据。

mesh 通过 mesh shell 交互式操作。收到的 mesh 消息会在到达时记录到日志中。

本示例不承载 IP：没有任何节点在 mesh 上运行网络协议栈，就连根节点到路由器的链路也不例外。它只使用 esp_wifi_mesh_send()/esp_wifi_mesh_recv() 在节点之间传送不透明的应用载荷。它适合在 mesh 上定义自己的轻量协议、不需要套接字、DHCP 或互联网访问的应用，例如向根节点汇集传感器读数，或向各节点下发命令。

如果节点需要访问外部网络，或需要在 mesh 上运行标准 IP（套接字、DHCP、mDNS），请改用 Wi-Fi Mesh IP 示例。在那个示例中，根节点通过 NAT 将子节点的流量转发到路由器，因此每个节点都能通过根节点访问互联网，代价是要接受该示例文档中所述的 IP-over-mesh 限制。

Shell 命令

命令

说明

mesh status

显示本节点的层级、角色（根节点或普通节点）、路由表大小以及 toDS 可达性。

mesh send <text>

通过 mesh 发送一条文本消息。非根节点向根节点发送；根节点向其路由表中的每个节点发送。

mesh table

转储路由表（本节点路由到的节点地址）。

mesh autotx <on|off>

开关一个周期性后台发送器，每隔几秒发送一次 hello seq=N，默认关闭。

要求

  • 至少两块受支持的 ESP32 开发板（esp32、esp32s2、esp32s3、esp32c3、esp32c5、esp32c6）。ESP32-C2 和 ESP32-H2 不提供 mesh 库。

  • 一台 2.4 GHz 路由器。在本示例使用的自组织模式下，根节点按路由器可达性选举，因此即使本示例不使用外部网络，组建 mesh 也需要路由器。

构建与运行

west build -b esp32c6_devkitc/esp32c6/hpcore samples/boards/espressif/wifi_mesh
west flash

在运行时于 src/main.c 中通过 esp_wifi_mesh_set_config() 配置 mesh 信道和路由器凭据（参见 esp_wifi_mesh.h）。路由器凭据默认为占位值 myssid/mypassword，必须设置为实际使用的路由器；保留占位值的节点找不到该网络，会一直搜索父节点。将信道设置为路由器所用的信道。将同一镜像烧录到每块开发板。

节点角色

CONFIG_WIFI_ESP32_MESH_ROLE 选项决定节点如何在树中占据位置：

  • CONFIG_WIFI_ESP32_MESH_ROLE_AUTO（默认）：自组织。节点进行扫描，如果能连上路由器，就投票成为根节点并连接路由器；否则作为子节点加入范围内的某个 mesh 节点。由于选举由路由器可达性驱动，因此需要路由器。

  • CONFIG_WIFI_ESP32_MESH_FORCE_ROOT：本节点是固定的根节点。它从不参与选举，始终位于树的顶端。配置了路由器时，它仍会关联路由器并维持该上行链路；只有在没有路由器的设置中才会停止父节点搜索，否则它会一直扫描一个不存在的父节点。

  • CONFIG_WIFI_ESP32_MESH_FORCE_CHILD：本节点从不成为根节点，始终作为子节点接入。

每种角色都需要路由器：子节点通过自组织的父节点搜索接入，而这一搜索以根节点与路由器的关联为基础。完全没有路由器的 mesh 需要为每个子节点显式指定父节点，本示例没有这样做。

在自动角色下，由于根节点选举由路由器可达性驱动，所有都在路由器范围内的开发板会各自成为根节点；只有超出路由器范围时，节点才会作为子节点加入 mesh。在所有开发板都靠近路由器的台架测试中，请使用 CONFIG_WIFI_ESP32_MESH_FORCE_CHILD=y 构建预定的子节点，使它们接入选出的根节点，而不是各自成为根节点。

要在台架上固定拓扑，请将一块开发板使用 CONFIG_WIFI_ESP32_MESH_FORCE_ROOT=y 构建，其余开发板使用 CONFIG_WIFI_ESP32_MESH_FORCE_CHILD=y 构建。固定的根节点位于第 1 层，子节点接入其下。
