Flash Encryption

Browse source code on GitHub

概述

Flash 加密用于加密 ESP32 片外 Flash 存储器的内容。启用此功能后，固件以明文形式烧录，然后在首次启动时就地加密数据。因此，仅通过物理读取 Flash 无法恢复大部分 Flash 内容。这是一项硬件功能，可在 MCUboot 构建过程中启用，是 MCUboot 现有功能之外的一项额外安全措施。

提供以下 Flash 加密模式：

  • 开发模式

    建议仅在开发期间使用，因为它无法阻止对已加密 Flash 内容的修改和读取。

  • 发布模式

    建议在制造和量产时使用，以防止物理读取已加密的 Flash 内容。选择发布模式时……

启用 Flash 加密后，默认加密以下类型的数据：

  • 引导加载程序区域

  • 应用程序区域

  • 存储区域

详情请参阅 ESP32 Flash Encryption 和 MCUBoot Readme。

软件需求

构建 Flash 加密示例时需要以下 Python 模块：

  • cryptography

  • imgtool>=1.9.0

设置

本示例代码只用于显示加密/解密后的数据，不足以启用 Flash 加密。它需要事先配置好并启用该功能的 MCUBoot 引导加载程序。运行本示例之前，请按照 MCUBoot Readme 中的说明操作。

警告

启用 Flash 加密时，用户可以使用设备生成的密钥（保持未知且不可读取）或主机生成的密钥（所有者负责以 .bin 文件形式妥善保管密钥）来加密内容。通过在设备上烧写 eFuse 启用 Flash 加密后，所有读写操作都会在运行时进行解密/加密。

支持的 SoC

目前本示例代码支持以下 SoC：

  • ESP32

构建与运行

确保开发板已通过 USB 端口连接。

west build -b esp32_devkitc/esp32/procpu samples/boards/espressif/flash_encryption
west flash

示例输出

要查看本示例的输出，请运行 west espressif monitor 或任何其他串口控制台程序（例如 minicom、putty、screen 等）。本例使用 west espressif monitor，它会自动检测位于 /dev/ttyUSB0 的串口：

$ west espressif monitor

示例代码将一个已知缓冲区写入 DTS 文件中定义的存储区域，然后以明文模式转储同一内存区域的 32 字节。内容是加密的，这意味着针对片外存储器的读取攻击是安全的。最后一步使用相应的 spi_flash 调用读取内存，如预期那样得到解密后的内容。
