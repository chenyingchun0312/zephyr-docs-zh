AutAnalog ADC FIR+FIFO

Browse source code on GitHub

概述

本示例演示 AutAnalog SAR ADC 的 FIR 和 FIFO 功能：

  • 每秒采样四个 ADC 通道：一个原始 GPIO 输入（P15.0）、通过内部 MUX 的同一输入，以及两个 FIR 滤波器伪通道。

  • FIR0 是在设备树中配置的 4 抽头移动平均滤波器（四个 Q1.15 定点格式的 0x2000 系数）。

  • FIR1 是由应用程序在运行时加载的 4 抽头移动平均滤波器。

  • 每个通道将其结果送入一个专用的 FIFO 缓冲区。达到 FIFO 水位线时，驱动会触发回调，应用程序随后批量读空全部四个缓冲区。

构建与运行

本示例需要：

  • zephyr,user 节点 io-channels 属性中的 ADC 通道。

  • ADC 控制器下的两个 FIR 子节点。

  • ADC 控制器下的一个 fifo 子节点。

对于 PSOC™ Edge E84 Evaluation Kit，kit_pse84_eval/pse846gps2dbzc4a/m55 覆盖文件配置了：

  • 通道 0：原始 GPIO 输入 P15.0，送入 FIFO 缓冲区 0。

  • 通道 8：经过 MUX 的 P15.0，送入 FIFO 缓冲区 1。

  • 通道 24：FIR0 伪通道，送入 FIFO 缓冲区 2。

  • 通道 25：FIR1 伪通道，送入 FIFO 缓冲区 3。

  • FIR0 系数从设备树加载；FIR1 系数在运行时加载。

  • FIFO 水位线设为每个缓冲区 4 个字。

可以按如下方式构建并烧录本示例：

west build -b kit_pse84_eval/pse846gps2dbzc4a/m55 samples/boards/infineon/autanalog/fir_fifo
west flash

示例输出

应得到与下面类似的输出：

ADC reading[0]:
- adc0, channel 0: 36 = 65 mV
- adc0, channel 8: 36 = 65 mV
- adc0, channel 24: 36 = 65 mV
- adc0, channel 25: 36 = 65 mV
FIFO: watermark event (status=0x0000000f)
FIFO[0] GPIO: 4 words - 36 36 36 36
FIFO[1] MUX : 4 words - 36 36 36 36
FIFO[2] FIR0: 4 words - 36 36 36 36
FIFO[3] FIR1: 4 words - 36 36 36 36
