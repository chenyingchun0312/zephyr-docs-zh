I2C V2 timings

Browse source code on GitHub

概述

本示例简单演示 stm32 I2C 驱动的 get_config API。会检查 I2C 外设配置中的 I2C 比特率，其取值可以是：

  • <I2C_BITRATE_FAST_STANDARD>

  • <I2C_BITRATE_FAST>

  • <I2C_BITRATE_FAST_PLUS>

对于 I2C V2，STM32 微控制器的 I2C 外设有一个 TIMING 寄存器，需要写入该寄存器才能生成正确的 I2C 时钟信号。该值取决于外设输入时钟和 I2C 速率。TIMING 值可以由 STM32CubeMX 应用计算得出，或者 由本示例计算得出。

由于计算 I2C V2 TIMING 值的代码开销较大，不建议在量产固件中启用。启用 CONFIG_I2C_STM32_V2_TIMING 标志后，本示例可以针对所定义的 clock-frequency 获取 timing 寄存器配置。随后用户可以根据本示例的输出修改以下 dts 片段，在自己的应用程序中配置 timing：

&i2c {
    timings = <160000000 I2C_BITRATE_STANDARD  0xB0C03E40>,
                <160000000 I2C_BITRATE_FAST  0xC041090F>,
                <160000000 I2C_BITRATE_FAST_PLUS  0x6021050A>;
}

构建与运行

要运行本示例，请确保：

  • 在开发板设备树文件中启用 i2c 节点。

  • 在开发板的 conf 文件中启用 CONFIG_I2C_STM32_V2_TIMING=y

  • 在开发板的 overlay 文件中将别名 i2c-0 指向你的 i2c 节点

west build -b b_u585i_iot02a samples/boards/st/i2c_timing

示例输出

将 b_u585i_iot02a.overlay 设置为

/ {
    aliases {
     i2c-0 = &i2c2;
  };
};
&i2c2 {
    /delete-property/ clock-frequency;
    clock-frequency = <I2C_BITRATE_FAST>;
};

示例会给出需要填写到设备树中的相应 TIMING 值：

I2C timing value, report to the DTS :
timings = <160000000 I2C_BITRATE_FAST  0xC041090F>;

I2C config : I2C_BITRATE_FAST
