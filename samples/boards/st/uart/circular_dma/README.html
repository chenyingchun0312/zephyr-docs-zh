UART circular mode

Browse source code on GitHub

概述

本示例演示如何在循环模式下使用带 DMA 的 STM32 UART 串口驱动。它从控制台读取数据并回显。

默认使用通常分配给 Zephyr shell 的 UART 外设，因此大多数开发板都应能运行本示例。

构建与运行

按如下方式构建并烧录本示例，将 nucleo_g071rb 替换为你的开发板：

west build -b nucleo_g071rb samples/boards/st/uart/circular_dma
west flash
