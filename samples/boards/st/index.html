STMicroelectronics

演示 STM32 硬件上开发板特有或 SoC 特有功能的示例。

  • Backup SRAM使用备份 SRAM 存储一个在重新上电后仍能保留的变量。
  • Bluetooth: ST Interactive GUI通过 UART 开放 ST BlueNRG Bluetooth 网络协处理器。
  • Core Coupled Memory (CCM)在内核耦合存储器（CCM）中放置并使用变量。
  • Hardware Semaphore (HSEM) Inter-Processor Communication on STM32 H7使用硬件信号量（HSEM）从一个内核触发另一个内核上的 LED 闪烁。
  • I2C V2 timings在运行时获取 I2C V2 timing 值。
  • Master Clock Output (MCO)输出内部时钟，供应用程序在外部使用。
  • SensorTile.box Pro sensors从 SensorTile.box Pro 的各个传感器读取数据。
  • SensorTile.box sensors从 SensorTile.box 的各个传感器读取数据。
  • ST Bluetooth LE Sensor Demo通过 Bluetooth 提供厂商自定义的 GATT 服务。
  • STWIN.box sensors从 STWIN SensorTile 无线工业节点的各个传感器读取数据。

Power Management

  • ADC power management在 STM32 上的低功耗环境中使用 ADC。
  • Blinky with power management在 STM32 上的低功耗环境中使用 GPIO API 闪烁 LED
  • Bluetooth Low Energy Power Management on STM32WB在 STM32WB 上启用 Zephyr 电源管理的情况下执行 Bluetooth LE 操作。
  • GPIO as wake-up pin将 GPIO 引脚用作唤醒引脚。
  • Serial wakeup在 STM32 上通过串口活动唤醒。
  • STOP3 mode在 STM32U5 上使用 STOP3 低功耗模式。
  • Suspend to RAM在 STM32 上使用挂起到 RAM 低功耗模式。

PWM

  • STM32 pwm mastermodeDevicetree configuration for utilizing master/slave capabilities to synchronize timer instances.

UART

  • Single-wire UART使用 STM32 器件的单线/半双工 UART 功能。
  • UART circular mode使用循环 DMA 配置从控制台读取数据并回显。
