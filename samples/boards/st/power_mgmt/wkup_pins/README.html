GPIO as wake-up pin

Browse source code on GitHub

概述

本示例是一个最小应用程序，演示在 STM32 SoC 上将 GPIO 用作唤醒引脚的两种场景：断电（Poweroff）和挂起到 RAM（Suspend-to-RAM）。启用相应的 Kconfig 选项即可选择场景：

  • CONFIG_SAMPLE_SCENARIO_POWEROFF：断电场景（本示例的默认场景）

  • CONFIG_SAMPLE_SCENARIO_S2RAM：挂起到 RAM 场景

本示例需要一个设备树别名 wkup-src，指向带有 gpios 属性的节点。

在大多数 STM32 开发板上，至少有一个板载按键连接到可用作唤醒引脚的 GPIO 引脚。在这些开发板上，将 wkup-src 设为代表该按键的节点（节点 /gpio_keys 的某个子节点）的别名。

有些开发板的板载按键都没有连接到可用作唤醒引脚的 GPIO 引脚。在这些开发板上，需要在开发板覆盖文件中新建一个 /gpio_keys 子节点，使其 gpios 属性对应某个唤醒引脚 GPIO，并将其用作 wkup-src 别名；这种情况下，必须用跳线使唤醒引脚进入有效状态。

在下文中，术语 WAKEUP 按键引脚 指 wkup-src 别名所指定的 GPIO 引脚，按下 WAKEUP 按键 指使 WAKEUP 按键引脚进入有效状态的操作，无论该引脚实际上是否连接到按键。

在断电模式下使用唤醒引脚

在断电场景中，WAKEUP 按键引脚被配置为 GPIO 输入和唤醒引脚，然后在经过 CONFIG_SAMPLE_BUSY_WAIT_TIME_MS 指定的毫秒数（默认 4000）后，调用 sys_poweroff() 函数使系统断电。

进入断电状态后按下 WAKEUP 按键，应会使 SoC 上电，其启动方式与拉低 nRESET 引脚时相同。在大多数 STM32 系列上，软件可以区分由唤醒引脚触发的复位与由 nRESET 引脚触发的复位：如果可以区分，示例会在控制台上打印专门的消息：

Reset from low-power state detected.
Continuing sample execution...

备注

在 STM32 平台上，断电状态对应功耗最低的 STM32 低功耗模式，通常称为 Standby 或 Shutdown（取决于 SoC 系列）。

在挂起到 RAM 模式下使用唤醒引脚

在挂起到 RAM 场景中，WAKEUP 按键引脚被配置为 GPIO 输入和唤醒引脚，然后注册 GPIO 回调并在该引脚上启用中断。这样，无论系统处于运行模式还是挂起到 RAM 状态，按下 WAKEUP 按键时都会调用 GPIO 回调（前一种情况下由 GPIO 控制器检测到中断，后一种情况下由电源控制器检测到）。GPIO 回调会向控制台打印一条消息，然后释放信号量。

随后示例进入永久重复的演示循环：* 打印一条消息，然后示例（忙）等待 CONFIG_SAMPLE_BUSY_WAIT_TIME_MS 毫秒。

  • 示例尝试以 CONFIG_SAMPLE_BUTTON_PRESS_TIMEOUT_MS 为超时获取信号量。如果按键尚未按下，系统应进入挂起到 RAM 状态。

  • 处于挂起到 RAM 状态时，按下 WAKEUP 按键会唤醒系统。已注册的 GPIO 回调会被调用，打印其消息并释放信号量。这样，（正在等待该信号量的）示例主线程就能恢复执行，从而确保系统不会（因为没有可运行的线程而）立即再次进入挂起到 RAM 状态。

  • 信号量被释放或超时到期后，示例继续执行：

    • 如果获取到了信号量，则打印成功消息并重新开始循环。

    • 如果超时到期，则打印超时消息，示例暂停直到按下 WAKEUP 按键，然后重新开始循环。

备注

唤醒引脚仅支持 单边沿 检测（上升沿或下降沿）。

要求

SoC 必须实现对 硬件信息 API 和 关机 API 的支持。

此外，挂起到 RAM 场景要求目标 SoC 具有这种低功耗模式，且软件支持该功能（体现为设备树中存在一个 zephyr,power-state 节点，其 power-state-name 属性值为 "suspend-to-ram"）。

必须为本示例添加每块开发板各自的覆盖文件，以提供 wkup-src 别名。

构建与运行

按如下方式构建并烧录 wkup_pins，将 nucleo_u5a5zj_q 替换为你的开发板：

west build -b nucleo_u5a5zj_q samples/boards/st/power_mgmt/wkup_pins
west flash

复位后，开发板的 LED 点亮。系统断电或进入挂起到 RAM 状态（取决于所选场景）时，LED 会熄灭。
