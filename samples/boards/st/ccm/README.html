Core Coupled Memory (CCM)

Browse source code on GitHub

概述

展示多款 STM32 器件上提供的内核耦合存储器（CCM）的用法。它与普通 RAM 的一个非常重要的区别是 CCM 不能用于 DMA。

本示例中，CCM 用于存储数据（即用作 DTCM）。在变量前加上 __dtcm_data_section、__dtcm_bss_section 或 __dtcm_noinit_section 前缀，即可将这些变量放入 CCM。

__dtcm_data_section 前缀应用于有初始值的变量。与普通 data 段一样，初始值会占用 Flash 镜像的空间。

__dtcm_bss_section 前缀应用于需要初始化为 0 的变量。与普通 bss 段一样，它们不占用 Flash 空间。

__dtcm_noinit_section 前缀应用于不需要确定初始值的变量（例如用于接收数据的缓冲区）。与 bss 或 data 段相比，内核无需初始化 noinit 段，因此启动会稍快一些。

要为开发板添加 CCM 支持，请在开发板 DTS 文件的 chosen 部分添加以下一行：

zephyr,dtcm = &ccm0;

west build -b None samples/boards/st/ccm
west flash
