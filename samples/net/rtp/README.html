RTP

Browse source code on GitHub

概述

此示例演示如何使用 Zephyr RTP API 通过 UDP 组播套接字发送和接收音频流。角色在构建时通过额外的配置文件选择：发送端使用 source.conf，接收端使用 sink.conf。两种角色共用组播地址 239.0.1.1 和端口 5004。添加额外配置文件 ipv6.conf 后，会话会改用 IPv6 组播地址 ff02::5004，端口不变。

source 角色以 RTP 数据包的形式发送 100 Hz 正弦波（16 位单声道，8000 采样/秒），负载类型为 97。每 50 ms 发送一个数据包，每个数据包携带 400 个采样（即该音调的五个完整周期）。

sink 角色加入组播组，并使用基于回调的 API 接收音频流。它每 5 秒记录一次心跳日志，其中包含已接收的数据包数量；如果 500 ms 内没有收到数据包，则记录一条警告。

要求

  • 与主机系统联网

在 native_sim 上运行

要在 Native simulator - native_sim 开发板上运行此示例，首先按照 与主机系统联网 在主机上设置 zeth tap 接口。

使用 FFmpeg 测试时，Linux 内核需要为组播地址显式添加路由，才能在 zeth 而不是默认网络接口上投递数据包。zeth 接口启用后，运行：

sudo ip route add 239.0.1.1 dev zeth

构建

构建为 source（发送端）：

west build -b <board to use> samples/net/rtp -- -DCONF_FILE=source.conf

构建为 sink（接收端）：

west build -b <board to use> samples/net/rtp -- -DCONF_FILE=sink.conf

使用 net_pkt 加速 RTP 协议栈

额外配置文件 net_pkt.conf 会调整网络数据包池以提高吞吐量。它可以与任一角色组合使用：

west build -b <board to use> samples/net/rtp -- -DCONF_FILE="source.conf net_pkt.conf"
west build -t run

west build -b <board to use> samples/net/rtp -- -DCONF_FILE="sink.conf net_pkt.conf"
west build -t run

使用 IPv6 构建

额外配置文件 ipv6.conf 会将 RTP 会话切换为 IPv6 组播地址 ff02::5004。它可以与任一角色组合使用，也可以与 net_pkt.conf 组合使用：

west build -b <board to use> samples/net/rtp -- -DCONF_FILE="source.conf ipv6.conf"
west build -t run

west build -b <board to use> samples/net/rtp -- -DCONF_FILE="sink.conf ipv6.conf"
west build -t run

使用 FFmpeg 测试

可以在任一端使用 FFmpeg 测试此示例。

测试 source

要使用 FFmpeg 接收 source 角色发出的音频流，首先创建一个描述 RTP 会话的 stream.sdp 文件：

v=0
o=- 0 0 IN IP4 127.0.0.1
s=No Name
c=IN IP4 239.0.1.1
t=0 0
a=tool:libavformat 58.76.100
m=audio 5004 RTP/AVP 97
a=rtpmap:97 L16/8000/1

然后运行 FFmpeg 接收音频流并保存为 WAV 文件：

ffmpeg -protocol_whitelist file,udp,rtp -i stream.sdp \
       -acodec pcm_s16le -ar 8000 -ac 1 \
       -f wav out.wav

测试 sink

要从 FFmpeg 向 sink 角色输送数据，运行以下命令，通过 RTP 组播发送一个 8 kHz 的静音单声道音频流：

ffmpeg -re -f lavfi -i anullsrc=r=8000:cl=mono \
       -acodec pcm_s16le \
       -f rtp -rtp_flags latm \
       -pkt_size 1440 \
       rtp://239.0.1.1:5004
