Prometheus Sample

Browse source code on GitHub

概述

此示例应用程序演示 prometheus 库的用法。该库提供了 Prometheus 客户端库（拉取方式）的实现。将此库集成到代码中后，即可在应用程序实例上通过 HTTP 端点公开内部指标，使 Prometheus 能够抓取并收集这些指标。

要求

QEMU Networking

构建并运行服务器

构建并运行应用程序：

west build -b <board to use> samples/net/prometheus -- -DCONF_FILE=<config file to use>

服务器启动后，可以使用 HTTP/1.1 向服务器发出请求。

With HTTP/1.1:

  • 使用浏览器：http://192.0.2.1/metrics

See Prometheus client library documentation.

指标服务器定制

服务器示例包含若干可根据需求定制的参数。可配置参数如下：

  • CONFIG_NET_SAMPLE_HTTP_SERVER_SERVICE_PORT：配置服务端口。

  • CONFIG_HTTP_SERVER_MAX_CLIENTS：定义服务器可同时处理的 HTTP/2 客户端的最大数量。

  • CONFIG_HTTP_SERVER_MAX_STREAMS：指定每个客户端可建立的 HTTP/2 流的最大数量。

  • CONFIG_HTTP_SERVER_CLIENT_BUFFER_SIZE：定义为每个客户端分配的缓冲区大小。这限制了所支持的单个 HTTP 头部的最大长度。

  • CONFIG_HTTP_SERVER_MAX_URL_LENGTH：指定服务器可处理的 HTTP URL 的最大长度。

要定制这些选项，可以运行 west build -t menuconfig，它提供交互式配置界面。然后从顶层菜单导航到：-> Subsystems and OS Services -> Networking -> Network Protocols。

Prometheus 配置

scrape_configs:
  - job_name: 'your_server_metrics'
    static_configs:
      - targets: ['your_server_ip:your_server_port']
    # Optional: Configure scrape interval
    # scrape_interval: 15s

将 'your_server_metrics' 替换为描述该任务（job）的名称，将 'your_server_ip' 替换为服务器的 IP 地址或主机名，将 'your_server_port' 替换为服务器公开 Prometheus 指标的端口号。

请务必根据服务器的设置和需求调整配置。

更新配置后，保存文件并重启 Prometheus 服务器。重启后，Prometheus 会按照定义的抓取配置开始从服务器抓取指标。可以通过查看 Prometheus 的 targets 页面，或在 Prometheus 中查询来自服务器的指标，来验证服务器的指标是否正在被抓取。

See Prometheus configuration docs.
