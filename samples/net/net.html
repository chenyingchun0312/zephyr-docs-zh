网络

这些示例演示如何使用网络子系统。

  • 10BASE-T1S tests (OA_TC6)设置测试以检验 10BASE-T1S 通信的长期稳定性
  • 802.15.4 "serial-radio"实现一个用于基于 Contiki 的边界路由器的 slip-radio 设备。
  • AWS IoT Core MQTT连接 AWS IoT Core 并使用 MQTT 发布消息。
  • bridge测试和调试以太网网桥
  • Cellular modem使用蜂窝调制解调器与 UDP 服务器通信。
  • DHCPv4 client启动 DHCPv4 客户端，从 DHCPv4 服务器获取 IPv4 地址。
  • DHCPv6 prefix delegation使用 DHCPv6（RFC 8415）获取并委派 IPv6 前缀。
  • DNS resolve解析给定主机名的 IP 地址。
  • DSA (Distributed Switch Architecture)测试和调试分布式交换架构（DSA）
  • FTP client shell sample通过 Zephyr shell 与 FTP 服务器交互的 FTP 客户端示例。
  • gPTP启用 gPTP 支持，并使用 net-shell 监视其功能。
  • IPv4 autoconf client执行 IPv4 自动配置，为自己分配一个随机 IPv4 地址
  • Latmon ClientMeasures delta time between GPIO events and reports the latency metrics via latmon to the latmus service executing on the SUT.
  • Link Layer Discovery Protocol (LLDP)启用 LLDP 支持并设置 VLAN。
  • LwM2M client实现一个连接到 LwM2M 服务器的 LwM2M 客户端。
  • MCP Server Hello WorldThis code sample shows two very basic tool definitions to introduce users to the Zephyr MCP Server library.
  • mDNS responder监听并响应 mDNS 查询。
  • Microsoft Azure IoT Hub MQTT连接 Azure IoT Hub 并使用 MQTT 发布消息。
  • MIDI2 network transport通过 Network MIDI 2.0 协议交换通用 MIDI 数据包（UMP）
  • MQTT publisher向 MQTT 服务器发送 MQTT PUBLISH 消息。
  • MQTT-SN publisher向 MQTT-SN 网关发送 MQTT-SN PUBLISH 消息。
  • Network packet capture捕获网络数据包，并通过 IPIP 隧道发送到远程主机。
  • Network packet filter安装网络数据包过滤器钩子。
  • Network statistics在用户应用程序中查询并显示网络统计信息。
  • OCPP charge pointImplement an OCPP charge point that connects to a Central System server and simulates the meter readings.
  • Prometheus Sample实现一个演示多种指标类型的 Prometheus 指标服务器。
  • Promiscuous mode在所有接口上启用混杂模式，并打印传入数据包的信息。
  • PTP启用 PTP 支持，并通过日志监视消息和事件。
  • Remote syslog启用远程 syslog 服务，将 syslog 消息发送到远程服务器
  • RTP通过 UDP 组播发送或接收 RTP 音频流。
  • Secure MQTT Sensor/Actuator实现一个基于 MQTT 的物联网传感器/执行器设备
  • SSH server and client实现 SSH 服务器和客户端的 shell 支持。
  • TagoIO HTTP Post使用 HTTP 向 TagoIO IoT 云平台发送随机温度值。
  • Telnet console通过 telnet 访问 Zephyr shell。
  • TFTP client使用 TFTP 客户端库从 TFTP 服务器获取文件或向其上传文件。
  • TSN Switch测试和调试 TSN 交换机
  • Virtual LAN设置两个虚拟局域网，并使用 net-shell 查看网络设置。
  • Virtual network interface创建一个示例虚拟网络接口。
  • Wireguard VPNImplement a echo-server application that sends received packets back to the sender over Wireguard VPN connection.
  • zperf: Network Traffic Generator使用 zperf shell 工具评估网络带宽。

OpenThread

  • OpenThread BorderRouter使用 OpenThread 边界路由器测试 Wi-Fi 和 IEEE 802.15.4。
  • OpenThread co-processor使用 OpenThread 的协处理器设计构建 Thread 边界路由器。
  • OpenThread CoAP client and server application构建全功能 Thread 设备（Full Thread Device，FTD）CoAP 服务器和客户端。
  • OpenThread shell使用 OpenThread shell 测试 Thread 和 IEEE 802.15.4。

Quality of Service

  • Quality of Service实现一个以太网层服务质量的演示。

QUIC API

  • Echo client (QUIC)使用 QUIC API 和套接字服务 API 实现一个简单的 IPv4/IPv6 回显客户端。
  • Echo server (QUIC)使用 QUIC API 和套接字服务 API 实现一个简单的 IPv4/IPv6 回显服务器。

Sockets API

  • Asynchronous echo server using poll()使用 BSD 套接字和 poll() 实现一个异步 IPv4/IPv6 TCP 回显服务器
  • Asynchronous echo server using select()使用 BSD 套接字和 select() 实现一个异步 IPv4/IPv6 TCP 回显服务器
  • CoAP client使用 CoAP 库实现一个获取资源的客户端。
  • CoAP download使用 CoAP 客户端 API 通过 GET 请求下载数据
  • CoAP service使用 CoAP 服务器子系统注册 CoAP 资源。
  • CoAP TCP Client使用 CoAP over TCP 客户端与 CoAP 服务器通信。
  • CoAP upload使用 CoAP 客户端 API 通过 PUT 请求上传数据
  • Dumb HTTP server使用 BSD 套接字实现一个简单、可移植的 HTTP 服务器。
  • Dumb HTTP server (multi-threaded)使用 BSD 套接字实现一个支持并发连接的简单 HTTP 服务器。
  • Echo client (advanced)实现一个发送 IP 数据包、等待数据被发回并进行验证的客户端。
  • Echo server (advanced)实现一个将收到的数据包发回给发送方的 UDP/TCP 服务器。
  • Echo server (service)使用 BSD 套接字和套接字服务 API 实现一个简单的 IPv4/IPv6 TCP 回显服务器。
  • Echo server (simple)使用 BSD 套接字实现一个简单的 IPv4/IPv6 TCP 回显服务器。
  • HTTP Client实现一个发出多种 HTTP 请求的 HTTP(S) 客户端。
  • HTTP GET using plain sockets使用普通 BSD 套接字实现一个 HTTP(S) 客户端。
  • HTTP Server实现一个演示多种资源类型的 HTTP(S) 服务器。
  • Large HTTP download使用 BSD 套接字从 Web 服务器下载大文件。
  • Network management socket使用网络管理套接字监听网络管理事件。
  • Packet socket在以太网上使用原始数据包套接字。
  • SNTP client使用 SNTP 从主机获取当前时间。
  • SNTP server为网络上的 SNTP 客户端提供当前时间。
  • SocketCAN使用 BSD 套接字 API 收发原始 CAN 帧。
  • Socketpair使用套接字对实现线程间通信。
  • UDP sender using SO_TXTIME使用 SO_TXTIME 套接字选项控制数据包的发送时间。
  • WebSocket Client实现一个连接到 Websocket 服务器的 Websocket 客户端。

Wi-Fi

  • Wi-Fi provisioning over BLEReceive Wi-Fi credentials over a BLE GATT service and connect to the access point.
