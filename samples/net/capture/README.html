Network packet capture

Browse source code on GitHub

概述

本应用程序对设备进行设置，使 net-shell 可用于启用网络数据包捕获。

捕获的数据包通过 IPIP 隧道发送到远程主机。隧道可以配置为与被捕获数据包所在的连接相同，也可以使用单独的承载。例如，如果你正在捕获接口 1 的网络流量，那么接收捕获数据包的远程主机既可以通过接口 1 访问，如果设备连接了多个网络接口，也可以通过其他网络接口访问。

要求

  • 与主机系统联网

构建与运行

按如下方式构建示例应用程序：

west build -b <board to use> samples/net/capture

为 Native simulator - native_sim 构建的示例：

west build -b native_sim samples/net/capture -- -DEXTRA_CONF_FILE=overlay-tunnel.conf

网络配置

net-tools 项目中的 net-setup.sh 脚本可用于设置隧道。

在终端 #1 中输入：

./net-setup.sh -c zeth-tunnel.conf

网络捕获配置

在 Zephyr 控制台中输入：

uart:~$ net iface

Interface 0x807df74 (Virtual) [1]
=================================
Interface is down.

Interface 0x807e040 (Ethernet) [2]
==================================
Link addr : 02:00:5E:00:53:3B
MTU       : 1452
Flags     : AUTO_START,IPv4,IPv6
Ethernet capabilities supported:
IPv6 unicast addresses (max 4):
     fe80::5eff:fe00:533b autoconf preferred infinite
     2001:db8::1 manual preferred infinite
IPv6 multicast addresses (max 4):
     ff02::1
     ff02::1:ff00:533b
     ff02::1:ff00:1
IPv6 prefixes (max 2):
     <none>
IPv6 hop limit           : 64
IPv6 base reachable time : 30000
IPv6 reachable time      : 43300
IPv6 retransmit timer    : 0
IPv4 unicast addresses (max 2):
     192.0.2.1 manual preferred infinite
IPv4 multicast addresses (max 1):
     <none>
IPv4 gateway : 0.0.0.0
IPv4 netmask : 255.255.255.0

接下来设置监视，使捕获的数据包作为 IPv6/UDP 数据包的负载发送。

uart:~$ net capture setup 192.0.2.2 2001:db8:200::1 2001:db8:200::2
Capture setup done, next enable it by "net capture enable <idx>"

net capture 命令会显示当前配置。由于尚未启用捕获，接口还未设置。

uart:~$ net capture
Network packet capture disabled
                Capture  Tunnel
Device          iface    iface   Local                  Peer
NET_CAPTURE0    -        1      [2001:db8:200::1]:4242  [2001:db8:200::2]:4242

接下来为接口 2 启用网络数据包捕获。

uart:~$ net capture enable 2

隧道接口将处于 UP 状态，捕获的数据包会发送到对端主机。

uart:~$ net iface 1

Interface 0x807df74 (Virtual) [1]
=================================

Attached  : 2 (Ethernet / 0x807e040)

MTU       : 1452

IPv6 unicast addresses (max 4):
     fe80::aee6:fbff:fe50:28c0 autoconf preferred infinite
     2001:db8:200::1 manual preferred infinite
IPv6 multicast addresses (max 4):
     <none>
IPv6 prefixes (max 2):
     <none>

如果现在执行：

uart:~$ net ping -c 1 192.0.2.2

你应该会看到一条 ICMPv4 消息发送到 192.0.2.2，同时捕获的数据包也会经由通往 2001:db8:200::2 地址的隧道发送到 192.0.2.2。UDP 端口默认为 4242，但可以在设置隧道端点地址时修改。
