Network packet filter

Browse source code on GitHub

概述

此示例演示如何在用户应用程序中设置网络数据包过滤器。

此示例应用程序的源代码位于：samples/net/pkt_filter。

要求

  • 与主机系统联网

构建与运行

运行本示例应用程序的一个好方法是使用 QEMU 或 native_sim 开发板，具体见 与主机系统联网。

为便于演示，需要按如下方式在主机端启用 VLAN 支持。在终端窗口中执行以下命令：

$ cd tools/net-tools
$ ./net-setup.sh  -c zeth-vlan.conf

然后按照以下步骤为 qemu_x86 或 native_sim 开发板构建网络数据包过滤器示例应用程序：

west build -b <board to use> samples/net/pkt_filter -- -DCONF_FILE="prj.conf overlay-vlan.conf"

本例中，我们通过以下设置启用 VLAN 支持：

VLAN 覆盖配置文件 samples/net/pkt_filter/overlay-vlan.conf 使用以下设置创建两个虚拟局域网：

  • VLAN 标签 100：IPv4 198.51.100.1 和 IPv6 2001:db8:100::1

  • VLAN 标签 200：IPv4 203.0.113.1 和 IPv6 2001:db8:200::1

在网络 shell 中，可以查看网络数据包过滤器：

uart:~$ net filter
Rule  Type        Verdict   Pkt-Prio  Queue  Thread-Prio  Tests
[ 1]  recv        OK             N/A    N/A          N/A  3    iface[2],eth vlan type[0x0800],size max[200]
[ 2]  recv        OK             N/A    N/A          N/A  3    iface[3],eth vlan type[0x0800],size min[100]
[ 3]  recv        OK             N/A    N/A          N/A  1    iface[1]
[ 4]  recv        OK             N/A    N/A          N/A  2    iface[2],eth vlan type[0x0806]
[ 5]  recv        OK             N/A    N/A          N/A  2    iface[3],eth vlan type[0x0806]
[ 6]  recv        DROP           N/A    N/A          N/A  0
[ 7]  IPv4 recv   OK             N/A    N/A          N/A  1    ip src block[192.0.2.2,198.51.100.2]
[ 8]  IPv6 recv   OK             N/A    N/A          N/A  1    ip src block[2001:db8::2,2001:db8::100:2]

上述示例应用程序的网络数据包过滤规则可以这样理解：

  • 规则 1：允许最大 200 字节的 IPv4（以太网类型 0x0800）数据包进入网络接口 2，即第一个 VLAN 接口。

  • 规则 2：允许最小 100 字节的 IPv4 数据包进入网络接口 3，即第二个 VLAN 接口。

  • 规则 3：允许所有传入流量进入以太网接口 1

  • 规则 4：允许 ARP 数据包（以太网类型 0x0806）进入 VLAN 接口 2

  • 规则 5：允许 ARP 数据包（以太网类型 0x0806）进入 VLAN 接口 3

  • 规则 6：丢弃所有其他数据包。这也意味着 IPv6 数据包会被丢弃。

  • 规则 7：丢弃源地址为 192.0.2.2 或 198.51.100.2 的 IPv4 数据包。

  • 规则 8：丢弃源地址为 2001:db8::2 或 2001:db8::100:2 的 IPv6 数据包。

如果启用网络数据包优先级选项 CONFIG_NET_SAMPLE_USE_PACKET_PRIORITIES，示例会额外安装用于设置优先级的规则。

uart:~$ net filter Rule Type Verdict Pkt-Prio Queue Thread-Prio Tests [ 1] recv CONTINUE 1 0 1 1 iface[1] [ 2] recv CONTINUE 7 2 SKIP 2 iface[1],eth type[0x88f7] [ 3] recv CONTINUE 2 0 1 2 iface[1],eth type[0x8100] [ 4] recv CONTINUE 1 0 1 2 iface[2],eth vlan type[0x0806] [ 5] recv CONTINUE 1 0 1 2 iface[3],eth vlan type[0x0806] [ 6] recv OK N/A N/A N/A 3 iface[2],eth vlan type[0x0800],size max[200] [ 7] recv OK N/A N/A N/A 3 iface[3],eth vlan type[0x0800],size min[100] [ 8] recv OK N/A N/A N/A 1 iface[1] [ 9] recv OK N/A N/A N/A 2 iface[2],eth vlan type[0x0806] [10] recv OK N/A N/A N/A 2 iface[3],eth vlan type[0x0806] [11] recv DROP N/A N/A N/A 0 [12] IPv4 recv OK N/A N/A N/A 1 ip src block[192.0.2.2,198.51.100.2] [13] IPv6 recv OK N/A N/A N/A 1 ip src block[2001:db8::2,2001:db8::100:2]

上述示例应用程序的网络数据包过滤规则可以这样理解：

  • 规则 1 - 5：添加规则，为特定类型的数据包设置网络数据包优先级。

  • 规则 6 - 13：与前一个规则列表中的相同。

可以通过网络统计信息查看数据包被丢弃的情况。使用 net stats 命令监视统计信息。
