Cellular modem

Browse source code on GitHub

概述

本示例包含一个简单的应用程序：它为调制解调器上电，启动网络接口，然后向端点 test-endpoint.com 发送一个带有伪随机数据的数据包。test-endpoint.com 是一个公开托管的服务器，运行 server 文件夹中的 Python 脚本。示例使用 DNS 查询 test-endpoint.com 的 IP。

备注

本示例使用设备树别名 modem 确定要使用的调制解调器实例。示例还假定调制解调器驱动创建的是唯一的 PPP 网络接口。

设置

首先在设备树中设置所需的设备树节点：

/dts-v1/;

/ {
        aliases {
                modem = &modem;
        };
};

&usart2 {
        pinctrl-0 = <&usart2_tx_pa2 &usart2_rx_pa3 &usart2_rts_pa1 &usart2_cts_pa0>;
        pinctrl-names = "default";
        current-speed = <115200>;
        hw-flow-control;
        status = "okay";

        modem: modem {
                compatible = "quectel,bg9x";
                mdm-power-gpios = <&gpioe 2 GPIO_ACTIVE_HIGH>;
                mdm-reset-gpios = <&gpioe 3 GPIO_ACTIVE_HIGH>;
                status = "okay";
        };
};

接下来，必须使用 CONFIG_UART_INTERRUPT_DRIVEN=y 或 CONFIG_UART_ASYNC_API=y 指定 UART API。该驱动不支持 UART 轮询。

最后，必须使用 CONFIG_MODEM_CELLULAR_APN="" 配置 APN。

Shell 命令

本示例启用了 CONFIG_MODEM_CELLULAR_SHELL，它添加了一个 modem_cellular shell 命令，用于在运行时控制 cellular_modem 驱动的周期性 chat 脚本：

modem_cellular pause <device>
modem_cellular resume <device>

在命令通道上执行耗时较长的 AT 操作（固件更新、eSIM 配置、工厂测试）时，使用 modem_cellular pause 暂停周期性的 CSQ/CREG 轮询。modem_cellular resume 重新启用轮询；如果暂停期间跳过了某次计划的运行，下一次周期性调用会立即触发。已暂停时再次暂停，或未暂停时恢复，都会返回 -EINVAL。

服务器设置

将服务器部署到可公开访问的主机上，然后将 prj.conf 中的 CONFIG_SAMPLE_CELLULAR_MODEM_ENDPOINT_HOSTNAME 变量设置为服务器的主机名。

git clone --depth=1 https://github.com/zephyrproject-rtos/zephyr.git
cd zephyr/samples/net/cellular_modem/server
python te.py
