TFTP client

Browse source code on GitHub

概述

简单文件传输协议（Trivial File Transfer Protocol，TFTP）是一种基于 UDP 的简单锁步式文件传输协议，用于从远程主机获取文件或向远程主机上传文件。

这个面向 Zephyr 的 TFTP 客户端示例应用程序使用 TFTP 客户端库，并在标准端口 69 上与 TFTP 服务器建立连接。

此示例应用程序的源代码位于：samples/net/tftp_client。

要求

  • 使用 QEMU 以太网联网, 使用 QEMU 联网 or 使用 native_sim 开发板联网

  • Linux 主机

构建与运行

samples/net/tftp_client 目录中提供了适用于各种设置的配置文件：

  • prj.conf 这是标准的默认配置。

按如下方式构建 tftp-client 示例应用程序：

west build -b <board to use> samples/net/tftp_client -- -DCONF_FILE=<config file to use>

设置本示例应用程序最简单的方法是使用默认配置 prj.conf，将其作为 native_sim 应用程序或 QEMU 目标构建并运行。这需要进行少量设置，具体见 使用 QEMU 以太网联网、使用 QEMU 联网 和 使用 native_sim 开发板联网。

按如下方式为 native_sim 构建 tftp-client 示例应用程序：

west build -b native_sim samples/net/tftp_client
west build -t run

下载并运行一个 TFTP 服务器（例如 TFTPd），然后创建 file1.bin（包含数据）和 newfile.bin。

请注意，默认的服务器 IP 地址为 192.0.2.2，默认端口为 69。要指定服务器 IP 地址和/或端口，请在 prj.conf 中修改以下配置：

CONFIG_TFTP_APP_SERVER="10.0.0.10"
CONFIG_TFTP_APP_PORT="70"

要使用主机名连接服务器，请在 prj.conf 中修改以下两项配置以启用 DNS 解析器：

CONFIG_DNS_RESOLVER=y
CONFIG_TFTP_APP_SERVER="my-tftp-server.org"

示例输出

可以在主机上运行 TFTP 服务器的同时，在 native_sim 上运行此示例。

在 net-tools 中启动 net-setup.sh：

net-setup.sh

<inf> net_config: Initializing network
<inf> net_config: IPv4 address: 192.0.2.1
<inf> net_tftp_client_app: Run TFTP client
<inf> net_tftp_client_app: Received data:
        74 65 73 74 74 66 74 70  66 6f 72 7a 65 70 68 79 |testtftp forzephy
        72 0a                                            |r.
<inf> net_tftp_client_app: TFTP client get done
<inf> net_tftp_client_app: TFTP client put done
