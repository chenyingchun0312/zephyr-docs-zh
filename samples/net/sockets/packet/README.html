Packet socket

Browse source code on GitHub

概述

此示例是一个简单的数据包套接字（packet socket）应用程序，展示如何在以太网上使用数据包套接字。示例会打印收到的每个数据包，并每 5 秒发送一个虚拟数据包。Zephyr 网络子系统不会改动任何报头（L2、L3 等）。

构建与运行

应用程序运行时，会打开一个数据包套接字并打印收到的数据包长度。之后每 5 秒发送一个虚拟数据包。可以使用 Wireshark 观察这些收发的数据包。

接收套接字还会加入一个以太网组播组，使网络接口开始额外监听一个组播 MAC 地址。这是通过 PACKET_ADD_MEMBERSHIP 套接字选项实现的，示例停止时会通过 PACKET_DROP_MEMBERSHIP 再退出该组。可以设置 CONFIG_NET_SAMPLE_MCAST_ADDR 来选择地址，或者禁用 CONFIG_NET_SAMPLE_MCAST_MEMBERSHIP 以完全跳过加入操作。

加入和退出也会作为网络管理事件上报，可以在 shell 中通过以下命令查看：

uart:~$ net events on

详情请参阅 net-tools 项目。

本示例可以在 QEMU 或 native_sim 开发板上构建并运行，具体方法见 与主机系统联网。
