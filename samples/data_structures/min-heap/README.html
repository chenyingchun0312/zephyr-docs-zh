Min-Heap Data Structure

Browse source code on GitHub

概述

本示例演示在 Zephyr 应用程序中将最小堆（Min-Heap）数据结构实现用作优先级队列。示例展示了插入、删除、弹出和判空等基本堆操作。

构建与运行

在受支持的开发板上构建并运行本示例：

west build -b <your_board> samples/data_structures/min_heap
west flash

将 <your_board> 替换为实际的开发板名称（例如 native_sim）。

示例输出

启动时，示例应用程序会执行一系列堆操作并打印结果。预期输出类似于：

*** Booting Zephyr OS build 9c0c063db09d ***
Min-heap sample using static storage
Heap elements by order of priority:
key=2 value=400
key=5 value=200
key=30 value=300
key=10 value=100
Top of heap: key=2 value=400
Found element with key 5 at index 1,removing it...
Heap after removal:
key=2 value=400
key=10 value=100
key=30 value=300

要求

运行本示例不需要外部硬件。它可以在任何具有标准控制台输出的 Zephyr 支持的开发板或 native_sim 上运行。
