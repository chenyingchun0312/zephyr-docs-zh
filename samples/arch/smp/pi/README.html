SMP Pi

Browse source code on GitHub

概述

本示例应用程序在多个线程中各自独立地计算圆周率，演示当计算密集型任务可以并行运行、且彼此没有依赖或共享资源时，多个执行单元（CPU 核）带来的好处。

在 SMP 系统上修改 CONFIG_MP_MAX_NUM_CPUS 的值，可以看到使用的核越多，完成计算任务所需的时间几乎线性减少。

也可以编辑示例源代码，修改计算的位数（DIGITS_NUM）和使用的线程数（THREADS_NUM）。

构建与运行

本项目输出每个线程计算出的圆周率值，最后输出完成全部计算所需的总时间。可以按如下方式在 Synopsys ARC HSDK 开发板上构建并运行：

west build -b qemu_x86_64 samples/arch/smp/pi
west build -t run
