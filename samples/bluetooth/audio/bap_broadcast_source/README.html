Basic Audio Profile (BAP) Broadcast Audio Source

Browse source code on GitHub

概述

演示 BAP 广播源（Broadcast Source）功能的应用程序。它会开始发送带音频标志的扩展广播、带广播音频源端点（BASE）的周期性广播，最后发送 BIGInfo 以及（模拟的）音频（ISO）数据。

BAP 广播源每 30 秒复位一次，以展示完整的 API。

通用信息请参阅 Bluetooth 示例。

要求

  • 在主机上运行的 BlueZ，或

  • 一块支持低功耗蓝牙 5.2 的开发板

构建与运行

使用 Zephyr 蓝牙控制器为 nrf52 系列开发板构建时，请使用 -DEXTRA_CONF_FILE=overlay-bt_ll_sw_split.conf 启用所需的 ISO 功能支持。本示例默认对 BIS 子事件采用顺序打包，添加 -DCONFIG_ISO_PACKING_INTERLEAVED=y 可使用交错打包。

为 nrf5340dk 构建

可以用以下命令同时构建应用核镜像和用于网络核的相应控制器镜像：

# From the root of the zephyr repository
west build -b nrf5340dk/nrf5340/cpuapp --sysbuild samples/bluetooth/audio/bap_broadcast_source/

如果只想构建应用核镜像，可以改用以下命令：

# From the root of the zephyr repository
west build -b nrf5340dk/nrf5340/cpuapp samples/bluetooth/audio/bap_broadcast_source/

这种情况下，可以将该应用核镜像与使用 samples/bluetooth/hci_ipc/extra-iso-bt_ll_sw_split.conf 额外配置的 HCI IPC 示例搭配使用。

为模拟的 nrf5340bsim 构建

与针对真实硬件的做法类似，可以执行：

# From the root of the zephyr repository
west build -b nrf5340bsim/nrf5340/cpuapp --sysbuild samples/bluetooth/audio/bap_broadcast_source/

注意，这会在 ./build/zephyr/zephyr.exe 生成一个 Linux 可执行文件。更多信息请参阅 该开发板的文档。

为模拟的 nrf52_bsim 构建

# From the root of the zephyr repository
west build -b nrf52_bsim samples/bluetooth/audio/bap_broadcast_source/ -- -DEXTRA_CONF_FILE=overlay-bt_ll_sw_split.conf
