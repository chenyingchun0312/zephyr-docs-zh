HCI UART async

Browse source code on GitHub

概述

通过标准的蓝牙 HCI UART 接口提供蓝牙控制器支持。

本示例执行与 HCI UART 示例相同的基本功能，但使用 UART_ASYNC_API 而不是 UART_INTERRUPT_DRIVEN API。并非所有开发板都实现了这两种 UART API，因此其开发板支持情况可能与 HCI UART 示例不同。

要求

  • 一块支持低功耗蓝牙（Bluetooth LE）的开发板

默认 UART 设置

默认情况下，控制器构建使用以下设置：

  • 波特率：1Mbit/s

  • 8 位数据位，无校验，1 位停止位

  • 启用硬件流控（RTS/CTS）

构建与运行

本示例位于 Zephyr 源码树中的 samples/bluetooth/hci_uart_async，按标准 Zephyr 应用程序构建。

将控制器与仿真器和 BlueZ 配合使用

以下说明介绍如何将 Nordic nRF5x 设备用作 Zephyr 蓝牙控制器，并将其提供给 Linux 的 BlueZ 使用。

首先，按照 在 Zephyr 中使用 BlueZ 一节中的说明，确保安装了较新版本的 BlueZ。

然后为你选择的 Nordic nRF5x 开发板构建并烧录本示例。所有 Nordic 开发套件都带有一颗 Segger IC，提供调试接口和 CDC ACM 串口桥。更多信息请参阅 Nordic nRF5x Segger J-Link。

例如，为 nRF52832 开发套件构建：

# From the root of the zephyr repository
west build -b nrf52dk/nrf52832 samples/bluetooth/hci_uart_async
west flash

将控制器与 QEMU 或 native_sim 配合使用

要将 HCI UART 控制器与 QEMU 或 native_sim 配合使用，需要先将其挂接到 Linux 主机。为此，只需构建本示例，将 UART 连接到 Linux 主机，然后使用以下命令挂接：

sudo btattach -B /dev/ttyACM0 -S 1000000 -R

备注

根据所用的串口，需要修改 /dev/ttyACM0 字符串，使其指向控制器所连接的串行设备。

备注

传给 btattach 的 -R 标志指示内核不要与控制器交互，只需知道它的存在，以便之后将其代理给 QEMU。

如果正在运行 btmon，应能看到一段简短的日志，显示 Linux 内核如何识别所连接的控制器。

控制器连接好后，按照 在 QEMU 或 native_sim 上运行 一节中的说明将其与 QEMU 配合使用。

将控制器与 BlueZ 配合使用

要将 HCI UART 控制器与 BlueZ 配合使用，需要先将其挂接到 Linux 主机。为此，只需构建本示例，将 UART 连接到 Linux 主机，然后使用以下命令挂接：

sudo btattach -B /dev/ttyACM0 -S 1000000

备注

根据所用的串口，需要修改 /dev/ttyACM0 字符串，使其指向控制器所连接的串行设备。

如果正在运行 btmon，应能看到一段完整的日志，显示 BlueZ 如何加载并初始化所连接的控制器。

控制器连接好后，按照 在 BlueZ 中使用基于 Zephyr 的控制器 一节中的说明将其与 BlueZ 配合使用。

调试控制器

由于 UART 已保留给本应用程序使用，可以通过 RTT 调试本示例。使用调试配置文件即可启用 RTT 调试。

west build samples/bluetooth/hci_uart_async -- -DEXTRA_CONFIG='debug.mixin.conf'

然后按此处的说明连接 RTT：使用 Segger J-Link

将控制器与 Zephyr 主机协议栈配合使用

本节介绍如何将运行本示例的开发板连接到另一块运行使用 Zephyr 主机协议栈的应用程序的开发板。

在控制器端，使用 chosen 块中的 zephyr,bt-c2h-uart DTS 属性选择所用的 UART 设备。例如，如果想保留控制台日志，可以让控制台使用 uart0，HCI 使用 uart1，如下所示：

/ {
   chosen {
      zephyr,console = &uart0;
      zephyr,shell-uart = &uart0;
      zephyr,bt-c2h-uart = &uart1;
   };
};

在主机应用程序中，需要使用一些配置选项来选择 H4 驱动，而不是内置控制器：

CONFIG_BT_HCI=y
CONFIG_BT_LL_SW_SPLIT=n

类似地，zephyr,bt-hci DTS 属性用于选择所用的 HCI 实例。该 UART 需要有一个 HCI UART 节点作为子节点：

/ {
   chosen {
      zephyr,console = &uart0;
      zephyr,shell-uart = &uart0;
      zephyr,bt-hci = &bt_hci_uart;
   };
};

&uart1 {
   status = "okay";
   bt_hci_uart: bt_hci_uart {
      compatible = "zephyr,bt-hci-uart";
      status = "okay";
   };
};
