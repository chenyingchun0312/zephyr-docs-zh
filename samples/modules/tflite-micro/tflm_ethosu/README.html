TensorFlow Lite for Microcontrollers on Arm(R) Ethos(TM)-U55, U65, and U85 NPUs

Browse source code on GitHub

概述

本示例应用程序演示如何使用 TFLM 框架和 Arm Ethos-U NPU 运行推理。

本示例应用程序运行一个从 Arm model zoo 下载的模型。该模型随后使用 Vela 编译器 进行了优化。

Vela 以一个 tflite 文件为输入，输出另一个 tflite 文件，其中 Arm Ethos-U NPU 支持的算子已被替换为 Ethos-U 自定义算子。理想情况下，整个网络会被替换为单个 Ethos-U 自定义算子。

生成经 Vela 编译的模型

按照以下步骤生成经 Vela 编译的模型以及测试输入/输出数据。本示例使用 keyword_spotting_cnn_small_int8 模型：

备注

默认的 Vela 编译模型面向 MPS3 目标上的 Arm Ethos-U55 NPU 和 128 MAC。由于一个模型可能多达数百 KB，请不要尝试为其他目标向代码库中添加更多模型。

  1. 从 keyword_spotting_cnn_small_int8 下载以下文件：

    • cnn_s_quantized.tflite

    • testing_input/input/0.npy

    • testing_output/identity/0.npy

  2. 使用 Vela 针对 Arm Ethos-U NPU 优化模型

    假定目标为 Arm Ethos-U55 NPU 和 128 MAC：

    $ vela cnn_s_quantized.tflite \
--output-dir . \
--accelerator-config ethos-u55-128 \
--system-config Ethos_U55_High_End_Embedded \
--memory-mode Shared_Sram

  3. 删除不需要的文件头

    testing_input/input/0.npy 和 testing_output/0.npy 带有 128 字节的文件头。要与本示例集成，必须删除这些文件头。

    $ dd if=testing_input/input/0.npy of=testing_input/input/0_no-header.npy bs=1 skip=128
$ dd if=testing_output/identity/0.npy of=testing_output/identity/0_no-header.npy bs=1 skip=128

  4. 转换为 C 数组

    $ xxd -c 16 -i cnn_s_quantized.tflite cnn_s_quantized.tflite.h
$ xxd -c 16 -i cnn_s_quantized_vela.tflite cnn_s_quantized_vela.tflite.h
$ xxd -c 16 -i testing_input/input/0_no-header.npy testing_input/input/0_no-header.npy.h
$ xxd -c 16 -i testing_output/identity/0_no-header.npy testing_output/identity/0_no-header.npy.h

  5. 与本示例同步

    将以下文件同步到本示例的 keyword_spotting_cnn_small_int8 目录：

    • cnn_s_quantized_vela.tflite.h > model.h

    • testing_input/input/0_no-header.npy.h > input.h

    • testing_output/identity/0_no-header.npy.h > output.h

    备注

    要运行未经 Vela 编译的模型（CONFIG_TAINT_BLOBS_TFLM_ETHOSU=n），请改为同步 cnn_s_quantized.tflite.h。

构建与运行

将 tflite-micro 模块添加到 West 清单（manifest）中并拉取：

west config manifest.project-filter -- +tflite-micro
west update

本应用程序可以在任何支持 Arm Ethos-U NPU 的平台上构建并运行，例如 Corstone(TM)-300 或 Corstone-320。

运行目标的前提条件

使用 CMake run 目标（-t run）时，请为你的平台设置 FVP 二进制文件路径；对于 Arm Ethos-U85 NPU，还需将 NPU 配置传给命令行：

# Arm Ethos-U55/U65 NPU (Corstone-300 FVP)
export ARMFVP_BIN_PATH=/path/to/FVP_Corstone_SSE-300_<ver>/models/Linux64_GCC-<gcc>/

# Arm Ethos-U85 (Corstone-320 FVP)
export ARMFVP_BIN_PATH=/path/to/FVP_Corstone_SSE-320_<ver>/models/Linux64_GCC-<gcc>/
export ARMFVP_EXTRA_FLAGS='-C;mps4_board.subsystem.ethosu.num_macs=2048'  # match chosen ETHOS_U85_* Kconfig

在 FVP 上构建并运行

# From the root of the zephyr repository
west build -b mps3/corstone300/fvp samples/modules/tflite-micro/tflm_ethosu -- -DCONFIG_SAMPLE_TFLM_ETHOSU_MEM_MODE_SHARED_SRAM=y
-DCONFIG_ETHOS_U55_128=y
west build -t run

Vela 内存模式与覆盖文件

Vela 支持多种 Arm Ethos NPU 内存放置模式。本示例在构建时通过 CONFIG_SAMPLE_TFLM_ETHOSU_MEM_MODE_* 复现这些模式：

  • CONFIG_SAMPLE_TFLM_ETHOSU_MEM_MODE_SHARED_SRAM

  • CONFIG_SAMPLE_TFLM_ETHOSU_MEM_MODE_DEDICATED_SRAM

  • CONFIG_SAMPLE_TFLM_ETHOSU_MEM_MODE_SRAM_ONLY

Board overlays

使用覆盖文件将 TensorFlow Lite 缓冲区放到相应的内存区域：

  • boards/mps3_corstone300_fvp.sram_only.overlay

  • boards/mps4_corstone320_fvp.sram_only.overlay

  • boards/mps3_corstone300_fvp.dedicated_sram.overlay

  • boards/mps4_corstone320_fvp.dedicated_sram.overlay

Dedicated_Sram 还要求在覆盖文件中声明一个 ETHOSU_FAST 区域。

Example builds

Shared_Sram（默认）：

# From the root of the zephyr repository
west build -b mps3/corstone300/fvp samples/modules/tflite-micro/tflm_ethosu -- -DCONFIG_SAMPLE_TFLM_ETHOSU_MEM_MODE_SHARED_SRAM=y
-DCONFIG_ETHOS_U55_128=y
west build -t run

Sram_Only（Corstone-300 上的 Arm Ethos-U65 NPU）：

# From the root of the zephyr repository
west build -b mps3/corstone300/fvp samples/modules/tflite-micro/tflm_ethosu -- -DCONFIG_SAMPLE_TFLM_ETHOSU_MEM_MODE_SRAM_ONLY=y
-DCONFIG_ETHOS_U65_256=y
-DDTC_OVERLAY_FILE=boards/mps3_corstone300_fvp.sram_only.overlay
west build -t run

Dedicated_Sram（Corstone-320 上的 Arm Ethos-U85 NPU）：

# From the root of the zephyr repository
west build -b mps4/corstone320/fvp samples/modules/tflite-micro/tflm_ethosu -- -DCONFIG_SAMPLE_TFLM_ETHOSU_MEM_MODE_DEDICATED_SRAM=y
-DCONFIG_ETHOS_U85_2048=y
-DDTC_OVERLAY_FILE=boards/mps4_corstone320_fvp.dedicated_sram.overlay
west build -t run

备注

  • Arm Ethos-U55 NPU 不支持 Dedicated_Sram。

  • 确保模型的 Vela 模式与所选的构建模式一致。

内存区域

Arm Ethos-U NPU 命令流使用 区域索引（0-3）对内存区域寻址，这些索引对应 NPU 配置中的 REGIONCFG 值。Vela 在编译模型时分配这些索引，HAL 再根据 NPU 型号将每个索引映射到物理 AXI 接口或 MEM_ATTR 条目。

本示例使用的映射 由所选的 CONFIG_SAMPLE_TFLM_ETHOSU_MEM_MODE_* 选项定义。下表列出了本示例的 CMake 和 Kconfig 逻辑实现的区域索引分配：

这些索引值在构建时通过 zephyr_compile_definitions() 以 NPU_REGIONCFG_n 和 NPU_QCONFIG 宏的形式应用，确保 HAL 和驱动使用一致的区域配置：

  • NPU_REGIONCFG_0：权重

  • NPU_REGIONCFG_1：暂存区

  • NPU_REGIONCFG_2：快速暂存区

  • NPU_QCONFIG：命令流区域

这些索引按如下方式映射到硬件接口：

Architectural mapping

  • Arm Ethos-U55/U65 NPU： 区域 0-1 路由到 AXI0（片上 SRAM），2-3 路由到 AXI1（外部存储器）。该映射由架构固定。

  • Arm Ethos-U85 NPU： 区域 0-3 选择可编程的 MEM_ATTR[0-3] 条目。默认情况下，HAL 将 MEM_ATTR[0-1] 配置为映射到 SRAM，将 MEM_ATTR[2-3] 配置为映射到外部 DDR。如果系统使用自定义的内存拓扑，可以覆盖这些默认值。

使用 Dedicated_Sram 时，请确保设备树覆盖文件中存在 ETHOSU_FAST 节点，为 NPU 的 fast_scratch 区域提供有效的内存区域。

通过 CMake 配置 PMU 事件

如果启用了 CONFIG_SAMPLE_TFLM_ETHOSU_PMU，示例会报告每次推理的 PMU 计数器。可以通过设置 ETHOSU_PMU_EVENT_0..3（如果支持，还有 4-7）覆盖要计数的事件。

# From the root of the zephyr repository
west build -b mps3/corstone300/fvp samples/modules/tflite-micro/tflm_ethosu -- -DCONFIG_SAMPLE_TFLM_ETHOSU_MEM_MODE_SHARED_SRAM=y
-DCONFIG_SAMPLE_TFLM_ETHOSU_PMU=y
-DETHOSU_PMU_EVENT_0=ETHOSU_PMU_AXI0_RD_DATA_BEAT_RECEIVED
-DETHOSU_PMU_EVENT_1=ETHOSU_PMU_AXI1_RD_DATA_BEAT_RECEIVED
west build -t run

PMU 报告格式

启用后，示例会在每次推理后打印一份简短的 PMU 报告：

Ethos-U PMU report:
ethosu_pmu_cycle_cntr : 134869
ethosu_pmu_cntr0 : 133577
ethosu_pmu_cntr1 : 0
ethosu_pmu_cntr2 : 111744
ethosu_pmu_cntr3 : 0
# (if supported, counters 4..7 are also printed.)

时序适配器（TA）

时序适配器（Timing Adapter）可以在受支持的平台（FVP 或 FPGA）上模拟内存带宽和延迟限制。使用 -DDTC_OVERLAY_FILE=... 显式应用 TA 覆盖文件。TA 覆盖文件可以与任意 Vela 内存模式组合使用，以研究时序的影响。

完整的 TA 文档请参阅 Evaluation Kit 文档。

TA 覆盖文件搭配 Sram_Only（Corstone-320）

# From the root of the zephyr repository
west build -b mps4/corstone320/fvp samples/modules/tflite-micro/tflm_ethosu -- -DCONFIG_SAMPLE_TFLM_ETHOSU_MEM_MODE_SRAM_ONLY=y
-DCONFIG_ETHOS_U85_2048=y
-DDTC_OVERLAY_FILE="boards/mps4_corstone320_fvp.ta.overlay;boards/mps4_corstone320_fvp.sram_only.overlay"
west build -t run

仅使用 TA 覆盖文件（Corstone-300）

# From the root of the zephyr repository
west build -b mps3/corstone300/fvp samples/modules/tflite-micro/tflm_ethosu -- -DCONFIG_SAMPLE_TFLM_ETHOSU_MEM_MODE_SHARED_SRAM=y
-DCONFIG_ETHOS_U55_128=y
-DDTC_OVERLAY_FILE=boards/mps3_corstone300_fvp.ta.overlay
west build -t run
