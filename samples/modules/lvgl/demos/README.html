LVGL demos

Browse source code on GitHub

概述

展示上游 LVGL 演示的示例。

音乐

音乐播放器演示展示了可以用 LVGL 创建什么样的、类似智能手机的现代用户界面。

基准测试

基准测试演示在各种情况下测试性能，例如矩形、边框、阴影、文本、图像混合、图像变换、混合模式等。

压力测试

LVGL 的压力测试。其中包含大量对象创建、删除、动画、样式使用等操作，可用于排查高负载使用期间的内存损坏或内存泄漏问题。

控件

展示使用内置 Material 主题时各控件的默认外观。

键盘与编码器

展示如何使用键盘和硬件编码器控制控件。

渲染

多种渲染测试的集合。

更多细节请参阅 LVGL demos Readme [1]。

要求

  • 一块带有显示屏的开发板，分辨率最好为 480x272 或更高。

  • 一个指针输入设备：触摸板、鼠标或支持触摸的显示屏，与 zephyr,lvgl-pointer-input 兼容。

注意，这些演示没有展示其他类型的输入设备，即键盘、小键盘（zephyr,lvgl-keypad-input）和硬件按键（zephyr,lvgl-button-input）。

在 native_sim 上运行键盘与编码器演示

在 Native simulator - native_sim 上，键盘与编码器演示由一个用 SDL 鼠标模拟的旋转编码器（zephyr,lvgl-encoder-input）驱动：鼠标滚轮转动编码器，中键（滚轮按下）充当 ENTER。不需要额外的硬件。

由于该演示需要用编码器导航，因此为它禁用了原本由 zephyr,touch chosen 设备派生的 LVGL 指针，以免指针点击绕过编码器导航。其他演示仍保留指针。

构建与运行

这些演示可以按如下方式为模拟显示环境构建。将 native_sim 替换为你的开发板名称，即可为真实开发板构建。

west build -b native_sim samples/modules/lvgl/demos -- -DCONFIG_LV_Z_DEMO_MUSIC=y
west build -t run

west build -b native_sim samples/modules/lvgl/demos -- -DCONFIG_LV_Z_DEMO_BENCHMARK=y
west build -t run

west build -b native_sim samples/modules/lvgl/demos -- -DCONFIG_LV_Z_DEMO_STRESS=y
west build -t run

west build -b native_sim samples/modules/lvgl/demos -- -DCONFIG_LV_Z_DEMO_WIDGETS=y
west build -t run

west build -b native_sim samples/modules/lvgl/demos -- -DCONFIG_LV_Z_DEMO_KEYPAD_AND_ENCODER=y
west build -t run

west build -b native_sim samples/modules/lvgl/demos -- -DCONFIG_LV_Z_DEMO_RENDER=y
west build -t run

另外，如果在 64 位主机上构建，也可以将前面的目标开发板参数替换为 native_sim/native/64。
