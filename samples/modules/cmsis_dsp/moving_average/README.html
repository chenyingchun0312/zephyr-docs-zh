CMSIS-DSP moving average

Browse source code on GitHub

概述

本示例演示如何使用 CMSIS-DSP 库计算信号的移动平均值。

它可以在 Zephyr 支持的任何开发板上运行，但请注意，CMSIS-DSP 是专门针对 ARM Cortex-A 和 Cortex-M 处理器优化的。

移动平均 滤波器是对含噪数据进行平滑处理的常用方法。它可以实现为有限冲激响应（FIR）滤波器，其滤波器系数全部等于 1/N，其中 N 为“抽头”数（即移动平均窗口的大小）。

示例使用一个非常简单的 32 个采样点的输入信号，以 10 个采样点的“窗口”计算移动平均值。结果通过对 CMSIS-DSP 函数 arm_fir_q31() 的一次调用计算得出，并显示在控制台上。

备注

为了便于比较 CMSIS-DSP 库在 ARM 处理器与其他架构上的运行效率，示例会输出计算移动平均值所花费的时间和周期数。

要求

CMSIS-DSP 是一个可选模块，需要显式添加到 Zephyr 工作区中：

west config manifest.project-filter -- +cmsis-dsp
west update cmsis-dsp

构建与运行

可以按如下方式构建该演示：

west build -b qemu_cortex_m0 samples/modules/cmsis_dsp/moving_average
west build -t run

示例会输出计算移动平均值所花费的周期数，以及输入信号每个 10 采样点窗口的平均值计算结果。
