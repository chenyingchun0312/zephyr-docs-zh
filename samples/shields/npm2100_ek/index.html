nPM2100 EK

Browse source code on GitHub

概述

此示例用于评估 nPM2100 EK。它演示如何使用 nPM2100 GPIO 引脚和 shell 接口控制以下功能：

  • 稳压器（BOOST、LDOSW）

  • GPIO

要求

该示例支持以下开发板：nRF52840 DK、nRF5340 DK

该示例还需要一个 nPM2100 评估套件（EK），需要按照 Wiring 中的说明将其连接到开发套件。

接线

在这种配置下，nPM2100 EK 的接线方式使其为 DK 供电。这可以确保 TWI 通信处于兼容的电压等级，同时也代表了 nPM2100 PMIC 的实际使用场景。

备注

为了防止漏电流并能对 DK 进行编程，请不要移除 USB 连接。

接线时，请从 nPM2100 EK 上拔下电池，并将 DK 的电源开关拨到 "OFF"。如果接线后与 DK 通信或对其编程时遇到问题，请尝试对 DK 和 EK 重新上电。

要将 DK 连接到 nPM2100 EK，请完成以下步骤：

  1. 准备由 nPM2100 EK 为 DK 供电：

    • 将开关 SW9（"nRF power source"）拨到 "VDD" 位置。

    • 将开关 SW10（"VEXT -> VnRF"）拨到 "ON" 位置。

  2. 按照下表连接所选 DK 与 nPM2100 EK 之间的 TWI 接口和电源：

    nPM2100 EK 引脚

    SDA

    SCL

    VOUT

    GND

    nRF52840 DK 引脚

    P0.26

    P0.27

    P21 外部电源 +

    GND

    nRF5340 DK 引脚

    P1.02

    P1.03

    P21 外部电源 +

    GND

  3. 在 nPM2100 EK 上完成以下连接：

    • 从 J4 连接器上移除 USB 电源。

    • 在 P6 排针上，用跳线帽连接引脚 1 和 2。

    • 在 BOOTMON 排针上，用跳线帽选择 OFF。

    • 在 VSET 排针上，用跳线帽选择 3.0V。

    • 在 VBAT SEL 开关上，选择 VBAT 位置。

    • 将电池板连接到 BATTERY INPUT 连接器。

构建与运行

使用以下命令构建示例：

west build -b nrf52840dk/nrf52840 samples/shields/npm2100_ek

备注

此示例会自动将 SHIELD 设置为 npm2100_ek。将软件烧录到设备后，启动进入 shell 接口。使用 regulator 命令测试 PMIC。有关子命令的详细信息，请参阅下一节。

稳压器控制

如果初始化成功，终端会显示以下包含状态信息的消息：

PMIC device ok

该示例还会每两秒报告一次电池电压、升压输出电压以及测得的芯片温度。

按如下方式使用 EK 上的按键控制稳压器：

操作

结果

按下 GPIO0 按键

BOOST 输出被强制进入 HP 模式

松开 GPIO0 按键

BOOST 输出工作在 LP 模式

按下 GPIO1 按键

负载开关打开

松开 GPIO1 按键

负载开关关闭

regulator shell 接口提供了若干子命令，用于测试 PMIC 中集成的稳压器。

要列出某个稳压器支持的所有电压，请运行以下命令：

uart:~$ regulator vlist BOOST
1.800000 V
1.850000 V
...

要启用或禁用某个稳压器，请运行以下命令：

uart:~$ regulator enable LDOSW
uart:~$ regulator disable LDOSW

备注

BOOST 稳压器始终处于启用状态。

要设置某个稳压器的输出电压，请运行以下命令：

uart:~$ regulator vset BOOST 2.5v
uart:~$ regulator vget BOOST
2.500000 V

备注

BOOST 稳压器无法提供低于电池电压的电压。

要获取 GPIO 状态，请运行以下命令：

uart:~$ gpio get npm2100_gpio 0
0
