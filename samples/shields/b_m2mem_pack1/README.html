B-M2MEM-PACK1 shield

Browse source code on GitHub

概述

ST B-M2MEM-PACK1 M.2 串行存储器套件 上有两个器件：一个串行 NOR Flash 和一个描述该模块的 I2C EEPROM。此示例读取 EEPROM，打印模块声明的身份，然后对 Flash 运行三项测试，检查该声明是否属实以及存储器是否可用。

测试项目如下：

  1. 比较 JEDEC ID。 在运行时从 Flash 读取 JEDEC ID，并与标识 EEPROM 为该存储器位置报告的值进行比较。不一致说明模块与其 EEPROM 所声明的不符。

  2. 擦除。 擦除一个扇区并检查操作是否成功。剩下的测试依赖这一项，因此如果失败，示例会停止。

  3. 写入并回读。 向已擦除的扇区写入已知的数据模式并读回。

第一项测试需要 Flash 节点上有 jedec-id 属性。不带该属性的扩展板变体会跳过该测试，只运行另外两项。

结果会输出到控制台和扩展板上的两个 LED，因此即使没有串口终端也能使用此示例：

要求

一块带有 M.2 Key A 插槽的开发板，该插槽按照 ST 串行存储器连接器引脚定义（参见 UM3611）接线，提供 m2mem_connector 节点以及 ST B-M2MEM-PACK1 M.2 串行存储器套件 扩展板文档中列出的标签，并装有 B-M2MEM-PACK1 模块。测试会写入 Flash 偏移 0xff000 处，因此该处存储的任何数据都会丢失。

构建与运行

本例使用 Nucleo U3C5ZI Q 开发板。请选择与所装模块相匹配的扩展板变体：

west build -b nucleo_u3c5zi_q --shield b_m2mem_pack1_mb1928_33lb samples/shields/b_m2mem_pack1
west flash

其他变体有 b_m2mem_pack1_mb1927_18ba、b_m2mem_pack1_mb1927_33ba 和 b_m2mem_pack1_mb1928_33la。

MB1928-33LB 上的已知结果

上面所示的运行结果是该模块的预期结果。其 EEPROM 记录的 JEDEC ID 为 ef 70 15，但实际装配的 W25Q16JV 返回 ef 40 15。第二个字节是存储器类型，用于区分同一器件的两种订购选项：40 是实际装配的普通 SPI 版本，70 是 DTR 版本。

设备树中的值是正确的，并且每次启动时都会被验证：Flash 驱动会在切换到四线模式之前读取 JEDEC ID 并与 jedec-id 属性进行比较，如果二者不一致，设备将不会就绪。

错误出在 ST 发布的参考 EEPROM 记录中，而不是某个单独的编程错误模块，因此 TEST 1 保持严格检查。它报告的是真实的不一致，两项 Flash 测试仍会运行并通过。
