X-NUCLEO-IKS01A3 shield - Standard (Mode 1)

Browse source code on GitHub

概述

此示例用于测试配置为标准模式（模式 1）的 X-NUCLEO-IKS01A3 扩展板。有关此配置的更多信息，请参阅 X-NUCLEO-IKS01A3：MEMS 惯性和环境多传感器扩展板。

此示例启用 X-NUCLEO-IKS01A3 扩展板的所有传感器，然后周期性地读取并显示扩展板传感器的数据：

  • HTS221：环境温度和相对湿度

  • LPS22HH 环境温度和大气压力

  • LIS2MDL 三轴磁场强度

  • LIS2DW12 三轴加速度

  • LSM6DSO 六轴加速度和角速度

  • STTS751 温度传感器

要求

本示例通过 I2C 与 X-NUCLEO-IKS01A3 扩展板（shield）通信，该扩展板堆叠在带有 Arduino 连接器的开发板上。开发板的 I2C 必须配置为 Arduino 连接器上的 I2C（包括引脚复用和设备树）。例如可参考 Nucleo F401RE 开发板的源代码：

  • $ZEPHYR_BASE/boards/arm/nucleo_f401re/nucleo_f401re.dts

  • $ZEPHYR_BASE/boards/arm/nucleo_f401re/pinmux.c

请注意，本示例不能用于已经板载该扩展板（shield）上某个传感器的开发板（例如 disco_l475_iot1），因为不支持同一传感器的多个实例。

参考资料

  • X-NUCLEO-IKS01A3: https://www.st.com/en/ecosystems/x-nucleo-iks01a3.html

DIL24 插座

除了板载传感器之外，还可以在 DIL24 插座上安装任何其他兼容的传感器。示例的编写方式使得在传感器不存在时会直接跳过。

此示例目前在 DIL24 上支持的传感器列表：

  • LIS2DE12

构建与运行

本示例可在 X-NUCLEO-IKS01A3 堆叠于任何具有匹配 Arduino 连接器的开发板上时运行。本例中使用 Nucleo F401RE 开发板。

west build -b nucleo_f401re samples/shields/x_nucleo_iks01a3/standard/
