nPM13xx EK

Browse source code on GitHub

概述

此示例用于评估 nPM1300 EK 和 nPM1304 EK。示例演示了稳压器 API 的动态电压调节（Dynamic Voltage Scaling，DVS）功能的用法，该功能允许通过一次稳压器 API 调用翻转所配置的 GPIO，从而在选定的电压等级或稳压器模式之间切换。

它还提供一个 shell 接口，用于支持 nPM1300 和 nPM1304 PMIC 的功能，包括：

  • 稳压器（BUCK1/2、LDO1/2）

  • GPIO

要求

该扩展板需要接到带 Arduino I2C 连接器的主机开发板。PMIC 的 GPIO3 用作中断输出，GPIO1 和 GPIO2 引脚配置为控制稳压器模式（由 MCU 软件通过 DVS 控制）。

此外，PMIC 的 VDDIO 引脚应连接到合适的参考电压。

例如，对于 nRF52 系列 DK，接线如下：

构建与运行

该示例设计为可在任何平台上运行（需要更新 npm13xx.overlay 文件中连接到 nPM13xx EK 的主机 GPIO 引用，以反映所选硬件）。

例如，为 nRF52 DK 和 nPM1300 EK 构建时，可以使用以下命令：

west build -b nrf52dk/nrf52832 --shield npm1300_ek samples/shields/npm13xx_ek

测试

烧录示例固件后，需要连接到 shell 接口。如果初始化成功，会看到 nPM13xx PMIC 状态消息，其中包含充电器状态以及电池电压、电流和温度。按下并松开 EK 上的 SHPHLD 按键会产生中断，这些事件也会打印到 shell 中。

按下主机 DK 上的专用按键（nRF52 系列 DK 上的 Button 1）会循环切换 DVS 状态。

备注

在 nRF52 系列 DK 上，DVS 引脚也用于板载 LED1 和 LED2，因此可以直观地观察 DVS 状态引脚：相应引脚为低电平时 LED 点亮

稳压器

regulator shell 接口提供了若干子命令，用于测试 PMIC 中集成的稳压器。下面是一些命令示例。

# list all the supported voltages by BUCK1
uart:~$ regulator vlist BUCK1
1.000 V
1.100 V
...

# enable BUCK2
uart:~$ regulator enable BUCK2
# disable BUCK2
uart:~$ regulator disable BUCK2

# set BUCK2 voltage to exactly 2V
uart:~$ regulator vset BUCK2 2V
# obtain the actual BUCK1 configured voltage
uart:~$ regulator vget BUCK1
1.800 V
# set BUCK1 voltage to a value between 2.35V and 2.45V
uart:~$ regulator set BUCK1 2.35V 2.45V
# obtain the actual BUCK1 configured voltage
uart:~$ regulator get BUCK1
2.400 V
