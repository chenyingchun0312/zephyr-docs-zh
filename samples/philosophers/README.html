Dining Philosophers

Browse source code on GitHub

概述

哲学家就餐问题（一个经典的多线程同步问题）的一种解决方案实现。该实现演示了不同优先级的多个可抢占线程和协作式线程的用法，以及动态互斥量和线程休眠。

哲学家总是先尝试拿编号最小的叉子（先 f1 后 f2）。用餐完毕后，他会按相反的顺序放回叉子（先 f2 后 f1）。如果他拿到两把叉子，就处于 EATING 状态；否则处于 THINKING 状态。过渡状态也会显示，例如哲学家饥饿但叉子不可用时显示 STARVING，哲学家正在等待第二把叉子可用时显示 HOLDING ONE FORK。

每位哲学家会在 EATING 和 THINKING 状态之间随机交替。

可以在 coop-only 或 preempt-only 模式下运行该演示。为此，请在 prj.conf 中为 CONFIG_NUM_COOP_PRIORITIES 和 CONFIG_NUM_PREEMPT_PRIORITIES 设置以下值：

preempt-only（仅抢占式）
CONFIG_NUM_PREEMPT_PRIORITIES=6
CONFIG_NUM_COOP_PRIORITIES=0
coop-only（仅协作式）
CONFIG_NUM_PREEMPT_PRIORITIES=0
CONFIG_NUM_COOP_PRIORITIES=6

在这些情况下，哲学家线程将以优先级 0 到 5（preempt-only）以及 -7 到 -2（coop-only）运行。

构建与运行

本项目输出到控制台。可以按如下方式在 QEMU 上构建并运行：

west build -b qemu_x86 samples/philosophers
west build -t run

示例输出

Philosopher 0 [P: 3]  HOLDING ONE FORK
Philosopher 1 [P: 2]  HOLDING ONE FORK
Philosopher 2 [P: 1]  EATING  [ 1900 ms ]
Philosopher 3 [P: 0]  THINKING [ 2500 ms ]
Philosopher 4 [C:-1]  THINKING [ 2200 ms ]
Philosopher 5 [C:-2]  THINKING [ 1700 ms ]

按 CTRL+A x 退出 QEMU。

调试线程

philosophers 示例默认启用 CONFIG_DEBUG_THREAD_INFO。这使 OpenOCD 和 J-Link 等工具能够使用 info threads 检查线程数据。

west build -b <board_name> samples/philosophers
west debug
