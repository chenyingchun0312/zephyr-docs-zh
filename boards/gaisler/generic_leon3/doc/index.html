Generic LEON3

Board Overview

Name:
generic_leon3
Vendor:

Gaisler

Status:

Not actively maintained

Architecture:

sparc

SoC:

leon3

Browse board sources

概述

该开发板配置适用于 GRLIB GPL 发行版中提供的 LEON3 处理器模板设计，也可以与 TSIM3 LEON3 模拟器的评估版一起使用。

硬件

该开发板配置兼容大多数 GRLIB LEON3 FPGA 模板设计，例如 Digilent Arty A7、Terasic DE0-Nano 和 Microsemi M2GL-EVAL-KIT。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

构建

generic_leon3 开发板配置的应用程序可以按常规方式构建（参见 构建应用程序）。要为 generic_leon3 构建应用程序，请将 BOARD 变量设置为 generic_leon3。

在硬件上运行

使用 GRMON 连接，然后加载并运行应用程序。下面的示例使用 Terasic DE2-115 Cyclone IV FPGA 开发板。
