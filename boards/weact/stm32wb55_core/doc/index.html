STM32WB55 Core Board V1.0

Board Overview

Name:
weact_stm32wb55_core
Vendor:

WeAct Studio

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32wb55xx

Browse board sources

概述

WeAct Studio STM32WB55 核心板是一款紧凑型多协议无线、超低功耗开发板，内置符合 Bluetooth® 低功耗（BLE）SIG 规范 v5.0 和 IEEE 802.15.4-2011 标准的高性能射频。

  • UFQFPN48 封装的 STM32WB55CGU6 微控制器

  • 2.4 GHz RF 收发器，支持 Bluetooth® v5.0 规范以及 IEEE 802.15.4-2011 PHY 和 MAC

  • 专用于实时射频层的 Arm® 32 位 Cortex® M0+ CPU

  • 一个用户 LED（蓝色）

  • 一个 BOOT 按键

  • 一个 RESET 按键

  • USB Type-C 连接器

  • 板载 3.3V LDO 稳压器（ME6231A33M3G）

  • 集成 PCB 天线，带 2.4GHz 射频滤波器

  • 32 MHz HSE 晶体振荡器

  • 用于 RTC 的 32.768 kHz LSE 晶体振荡器

  • 2.54mm 间距排针（P1：20 针，P2：15 针）

  • 4 针 SWD 调试排针

硬件

STM32WB55CGU6 是一款超低功耗双核 SoC，包含 64 MHz Arm Cortex-M4 MCU 和 32MHz Cortex-M0+，带 1 MB Flash 存储器，支持 Bluetooth 5、802.15.4、USB 和 AES-256，并提供以下硬件功能：

  • 采用 FlexPowerControl 的超低功耗（带 RTC 和 32KB RAM 的待机模式低至 600 nA）

  • 内核：带 FPU 的 ARM® 32 位 Cortex®-M4 CPU，频率最高 64 MHz

  • 射频：

    • 2.4GHz

    • RF 收发器，支持 Bluetooth® 5 规范以及 IEEE 802.15.4-2011 PHY 和 MAC，支持 Thread 和 ZigBee® 3.0

    • 接收灵敏度：-96 dBm（Bluetooth® Low Energy，1 Mbps），-100 dBm（802.15.4）

    • 可编程输出功率最高 +6 dBm，步进 1 dB

    • 集成巴伦（balun），减少 BOM

    • 支持 2 Mbps

    • 专用于实时射频层的 Arm® 32 位 Cortex® M0+ CPU

    • 精确的 RSSI，可实现功率控制

  • 时钟源：

    • 32 MHz 晶体振荡器，集成调谐电容（用于射频和 CPU 时钟）

    • 用于 RTC 的 32 kHz 晶体振荡器（LSE）

    • 内部低功耗 32 kHz RC

    • 内部多速振荡器，100 kHz 至 48 MHz，由 LSE 自动校准

    • 2 个 PLL，用于系统时钟、USB 和 ADC

  • 带硬件日历、闹钟和校准功能的 RTC

  • 最多 24 个电容感应通道

  • 16 个定时器：

    • 2 个 16 位高级电机控制定时器

    • 2 个 32 位和 5 个 16 位通用定时器

    • 2 个 16 位基本型

    • 2 个低功耗 16 位定时器（在 Stop 模式下可用）

    • 2 个看门狗

    • SysTick 定时器

  • 存储器

    • 1 MB Flash，2 个 bank，支持边读边写

    • 最多 256 KB SRAM

  • 丰富的模拟外设

    • 12 位 ADC，4.26 Msps，硬件过采样下最高 16 位

    • 2 个超低功耗比较器

SMBus/PMBus)

  • 1 个 USB 2.0 FS 设备，无需晶体，支持 BCD 和 LPM

  • 安全与 ID

    • 3 个硬件 AES 加密，最高 256 位

    • 硬件公钥加速器（PKA）

    • 真随机数发生器（RNG）

    • 96 位唯一 ID

  • STM32WB55CG on www.st.com

  • STM32WB55 datasheet

  • STM32WB55 reference manual

支持的功能

weact_stm32wb55_core 开发板支持下列硬件功能。

说明

The list of supported hardware features was not generated. Run a full documentation build for the required metadata to be available.

Bluetooth 与 STM32WB 协处理器无线二进制文件

重要：WeAct STM32WB55 核心板出厂时在 Cortex-M0+ 协处理器上预装了“Full Stack”无线二进制文件。该二进制文件与 Zephyr 不兼容，在使用 Bluetooth 功能之前必须将其替换为“HCI Layer”二进制文件。

要在 WeAct STM32WB55 核心板上使用 Bluetooth，必须为 Cortex-M0+ 内核烧录有效的 STM32WB 协处理器 HCI 二进制文件。这些二进制文件随 STM32WB Cube 软件包提供，位于 Projects/STM32WB_Copro_Wireless_Binaries/STM32WB5x/ 下

该开发板已测试过扩展 HCI 二进制文件：stm32wb5x_BLE_HCILayer_extended_fw.bin

有关这些二进制文件各版本的兼容性信息，请查看 hal_stm32:lib/stm32wb/README.rst。

烧录无线协处理器二进制文件

烧录 Cortex-M0+ 无线协处理器二进制文件 需要外部调试探针 和 STM32CubeProgrammer，M0+ 协处理器无法使用 DFU 模式。将外部调试探针（ST-LINK/V2 或 J-Link）连接到 4 针 SWD 排针（P3），然后使用 STM32CubeProgrammer 将二进制文件编程到相应的内存地址。

STM32WB5xxG（1M 型号）的安装地址因二进制文件类型而异（v1.23.0）：

  • BLE_HCILayer_extended: 0x080DB000

  • BLE_HCILayer: 0x080E1000

FUS（固件升级服务）安装地址（v2.1.0）：

  • FUS v2.1.0: 0x080EE000

完整的地址信息请参阅 STM32 Wireless Coprocessor Binary Table。

连接与 IO

Zephyr 默认外设映射：

  • UART_1 TX/RX : PA9/PA10

  • LPUART_1 TX/RX：PA2/PA3（带 CTS：PA6，RTS：PB1）

  • I2C_1_SCL : PB8

  • I2C_1_SDA : PB9

  • SPI_1_NSS : PA4

  • SPI_1_SCK : PA5

  • SPI_1_MISO : PB4

  • SPI_1_MOSI : PB5

  • PWM_1_CH1 : PA8

  • PWM_2_CH1 : PA15

  • ADC_1_IN5 : PA0

  • ADC_1_IN6 : PA1

  • USER_LED（蓝色）：PB2

  • BOOT_BUTTON : PE4

  • USB_DP : PA12

  • USB_DM : PA11

系统时钟

WeAct STM32WB55 核心板的系统时钟由 32 MHz HSE 晶体振荡器驱动。默认情况下，系统时钟配置为以 HSE 为源、通过 PLL 运行在 64 MHz。

电源

该开发板带有一个 ME6231A33M3G 3.3V LDO 稳压器，输入电压范围为 3.3V 至 5.5V。可以通过以下方式供电：

  • USB Type-C 连接器（5V）

  • P1 排针上的 VDD5V 引脚

  • P2 排针上的 VDD33 引脚（3.3V 稳压电源）

串口

该开发板有 1 个 USART 和 1 个 LPUART。Zephyr 控制台输出分配给 USART1（PA9/PA10），默认设置为 115200 8N1。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

WeAct STM32WB55 核心板不带板载调试器。Cortex-M4 无需外部调试探针即可通过 DFU 模式烧录，但 Cortex-M0+ 协处理器需要将外部调试探针（ST-LINK/V2 或 J-Link）连接到 4 针 SWD 排针（P3）。

烧录

安装 dfu-util

建议使用 v0.8 或更高版本的 dfu-util。debian/ubuntu 中提供的软件包可能相当旧，因此可能需要从源码构建 dfu-util。也有可用的 Windows 版本，但可能需要借助 Zadig 等工具安装正确的 USB 驱动。

烧录应用程序

连接 USB Type-C 线缆后，开发板应会上电。按住 BOOT 按键，同时按下并松开 RESET 按键，即可强制开发板进入 DFU 模式。

本开发板支持 dfu-util 运行器，因此可以方便地构建和测试示例。

# From the root of the zephyr repository
west build -b weact_stm32wb55_core samples/basic/blinky
west flash

# From the root of the zephyr repository
west build -b weact_stm32wb55_core samples/hello_world
west flash

另外，如果已将外部调试探针（ST-LINK/V2 或 J-Link）连接到 SWD 排针（P3），也可以通过 --runner（或 -r）选项使用 STM32CubeProgrammer 烧录 Cortex-M4 应用程序：

$ west flash --runner stm32cubeprogrammer

调试

要在该开发板上调试应用程序，需要将外部调试器连接到 SWD 排针（P3），然后即可按常规方式调试应用程序。以下是 Blinky 应用程序的示例。

# From the root of the zephyr repository
west build -b weact_stm32wb55_core samples/basic/blinky
west debug
