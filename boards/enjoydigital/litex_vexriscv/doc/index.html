LiteX VexRiscv

Board Overview

Name:
litex_vexriscv
Vendor:

EnjoyDigital

Status:

Not actively maintained

Architecture:

riscv

SoC:

litex_vexriscv

Browse board sources

LiteX VexRiscv 是一个片上系统（SoC）示例，由 VexRiscv 处理器 和附加外设组成。该设计可以使用 Zephyr on LiteX VexRiscv（参考平台） 或 LiteX SoC Builder 生成，并可用于各种 FPGA 芯片。比特流（FPGA 配置文件）既可以使用厂商专用工具获得，也可以使用开源工具获得，包括 F4PGA 工具链。

Zephyr 中的 litex_vexriscv 开发板配置适用于为 Digilent Arty A7-35T 或 A7-100T 开发板 或 SDI-MIPI 视频转换器 生成的 LiteX VexRiscv SoC 实现。

LiteX 基于 Migen/MiSoC SoC builder，提供总线、数据流、互连、通用内核和 CPU 封装等现成的系统组件，便于轻松构建 SoC。该工具包含用于集成、仿真和构建面向不同厂商多种芯片的各类设计的机制。有关 LiteX 项目的更多信息，请访问 LiteX 网站。

VexRiscv 是用 SpinalHDL 编写的 32 位 RISC-V CPU 架构实现。该处理器支持 M、C 和 A 三种 RISC-V 指令集扩展，并包含多级流水线和数据缓存等多项优化。该项目提供许多可选扩展，可用于定制设计（JTAG、MMU、MUL/DIV 扩展）。该实现针对 FPGA 芯片进行了优化。有关该项目的更多信息，请访问 VexRiscv 网站。

要在 VexRiscv CPU 上运行 Zephyr OS，需要为 Digilent Arty A7-35 开发板或 SDI-MIPI 视频转换器上的 FPGA 准备比特流。这可以使用 Zephyr on LiteX VexRiscv 参考平台完成，也可以使用官方 LiteX SoC Builder。

生成比特流

Zephyr on LiteX VexRiscv

使用该平台可确保所有寄存器地址都位于正确的位置。所有驱动都已使用该平台测试过。要生成比特流，请按以下说明操作：

  1. 克隆仓库并更新所有子模块：

    git clone https://github.com/litex-hub/zephyr-on-litex-vexriscv.git
cd zephyr-on-litex-vexriscv
git submodule update --init --recursive

    为 Digilent Arty A7-35 开发板生成比特流需要安装 F4PGA 工具链，可以按照 该教程 中的说明完成安装。

    要为 SDI-MIPI 视频转换器生成比特流，请按照 这些说明 安装 oxide（yosys+nextpnr）工具链。

  2. 接下来，获取所有必需的软件包并运行安装脚本：

    apt-get install build-essential bzip2 python3 python3-dev python3-pip
./install.sh

  3. 将 LiteX 添加到路径中：

    source ./init

  4. 设置 F4PGA 环境（用于 Digilent Arty A7-35 开发板）：

    export F4PGA_INSTALL_DIR=~/opt/f4pga
export FPGA_FAM="xc7"
export PATH="$F4PGA_INSTALL_DIR/$FPGA_FAM/install/bin:$PATH";
source "$F4PGA_INSTALL_DIR/$FPGA_FAM/conda/etc/profile.d/conda.sh"
conda activate $FPGA_FAM

  5. 为 Arty 35T 生成比特流：

    ./make.py --board=arty --variant=a7-35 --build --toolchain=symbiflow

  6. 为 Arty 100T 生成比特流：

    ./make.py --board=arty --variant=a7-100 --build --toolchain=symbiflow

  7. 为 SDI-MIPI 视频转换器生成比特流：

    ./make.py --board=sdi_mipi_bridge --build --toolchain=oxide

官方 LiteX SoC Builder

也可以使用 官方 LiteX 仓库 生成比特流。这种情况下还必须生成 dts 覆盖文件。

  1. 安装 Migen/LiteX 和 LiteX 的内核：

    wget https://raw.githubusercontent.com/enjoy-digital/litex/master/litex_setup.py
chmod +x litex_setup.py
./litex_setup.py --init --install --user (--user to install to user directory) --config=(minimal, standard, full)

  2. 安装 RISC-V 工具链：

    pip3 install meson ninja
./litex_setup.py --gcc=riscv

  3. 构建目标：

    ./litex-boards/litex_boards/targets/digilent_arty.py --build --timer-uptime --csr-json csr.json

  4. 生成 dts 和配置覆盖文件：

    ./litex/litex/tools/litex_json2dts_zephyr.py --dts overlay.dts --config overlay.config csr.json

编程与启动

构建

litex_vexriscv 开发板配置的应用程序可以按常规方式构建（参见 构建应用程序）。要为 litex_vexriscv 构建应用程序，请将 BOARD 变量设置为 litex_vexriscv。

如果使用官方 LiteX SoC Builder 生成比特流，则需要传入一个额外的参数：

west build -b litex_vexriscv path/to/app -DDTC_OVERLAY_FILE=path/to/overlay.dts

启动

要将比特流上传到 Digilent Arty A7-35，可以使用 xc3sprog 或 openFPGALoader：

xc3sprog -c nexys4 digilent_arty.bit

openFPGALoader -b arty_a7_100t digilent_arty.bit

使用 ecpprog 将比特流上传到 SDI-MIPI 视频转换器：

ecpprog -S antmicro_sdi_mipi_video_converter.bit

可以使用 litex_term 从串口启动（将 ttyUSBX 替换为你的设备），例如：

litex_term /dev/ttyUSBX --speed 115200 --kernel zephyr.bin
