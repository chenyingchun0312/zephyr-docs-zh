LiteX VexiiRiscv

Board Overview

Name:
litex_vexiiriscv
Vendor:

EnjoyDigital

Status:

Not actively maintained

Architecture:

riscv

SoC:

litex_vexiiriscv

Browse board sources

警告

该开发板并非固定的硬件，而是由 LiteX SoC Builder 生成的 软 SoC，可能随时发生变化。内存映射、外设集合及其基地址和配置都在生成比特流时确定，因此用不同 LiteX 版本或不同配置构建的 SoC 很可能与该开发板自带的设备树不一致。

因此，树内的开发板定义只是某一特定配置的快照。只要你的 SoC 与其不完全一致，就应使用 litex_json2dts_zephyr.py 为构建生成设备树和 Kconfig 覆盖文件（参见 Bitstream generation），而不要依赖树内文件；并且树内文件可能随时更改，不提供任何向后兼容保证。

LiteX VexiiRiscv 是一个片上系统（SoC）示例，由 VexiiRiscv 处理器 和附加外设组成。该设计可以使用 LiteX SoC Builder 生成，并可用于各种 FPGA 芯片。比特流（FPGA 配置文件）既可以使用厂商专用工具获得，也可以使用开源工具获得。

Zephyr 中的 litex_vexiiriscv 开发板配置适用于为 Efinix Titanium Ti375 C529 开发套件 生成的 LiteX VexiiRiscv SoC 实现。

LiteX 基于 Migen/MiSoC SoC builder，提供总线、数据流、互连、通用内核和 CPU 封装等现成的系统组件，便于轻松构建 SoC。该工具包含用于集成、仿真和构建面向不同厂商多种芯片的各类设计的机制。有关 LiteX 项目的更多信息，请访问 LiteX 网站。

VexiiRiscv 是用 SpinalHDL 编写的 RISC-V CPU 架构实现，针对 FPGA 芯片进行了优化。有关该项目的更多信息，请访问 VexiiRiscv 网站。

要在 VexiiRiscv CPU 上运行 Zephyr OS，需要为 Efinix Titanium Ti375 C529 开发套件上的 FPGA 准备比特流。

生成比特流

比特流使用 官方 LiteX 仓库 生成。由于生成的 SoC 不一定与该开发板自带的设备树一致，应始终同时生成设备树和 Kconfig 覆盖文件。

  1. 创建并激活虚拟环境：

    python3 -m venv .venv
source .venv/bin/activate

  2. 安装 Migen/LiteX 和 LiteX 的内核：

    wget https://raw.githubusercontent.com/enjoy-digital/litex/master/litex_setup.py
chmod +x litex_setup.py
./litex_setup.py --init --install --user (--user to install to user directory) --config=(minimal, standard, full)

  3. 安装 RISC-V 工具链：

    pip3 install meson ninja
./litex_setup.py --gcc=riscv

  4. 构建目标：

    ./litex-boards/litex_boards/targets/efinix_ti375_c529_dev_kit.py --cpu-type=vexiiriscv --build

  5. 生成 dts 和配置覆盖文件：

    ./litex/litex/tools/litex_json2dts_zephyr.py --dts overlay.dts --config overlay.config csr.json

编程与启动

构建

litex_vexiiriscv 开发板配置的应用程序可以按常规方式构建（参见 构建应用程序），只需将 BOARD 变量设置为 litex_vexiiriscv，并传入为你的 SoC 生成的覆盖文件：

west build -b litex_vexiiriscv path/to/app -DDTC_OVERLAY_FILE=path/to/overlay.dts

启动

要将比特流上传到 FPGA，可以使用 --load 选项，也可以使用 --flash 选项烧写 SPI Flash。

可以使用 litex_term 从串口启动（将 ttyUSBX 替换为你的设备），例如：

litex_term /dev/ttyUSBX --speed 115200 --kernel zephyr.bin
