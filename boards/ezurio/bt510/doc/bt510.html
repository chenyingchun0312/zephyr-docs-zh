Sentrius BT510 Sensor

Board Overview

Name:
bt510
Vendor:

Ezurio

Status:

Not actively maintained

Architecture:

arm

SoC:

nrf52840

Browse board sources

概述

Sentrius™ BT510 传感器是一款电池供电、支持 Bluetooth v5 长距离的集成传感器，采用 Nordic Semiconductor nRF52840 ARM Cortex-M4F CPU。

该传感器具有以下特性：

  • ADC

  • CLOCK

  • FLASH

  • GPIO

  • I2C

  • MPU

  • NVIC

  • PWM

  • RADIO（低功耗蓝牙和 802.15.4）

  • RTC

  • Segger RTT（RTT 控制台）

  • UART

  • WDT

有关该开发板的更多信息，请访问 Sentrius BT510 website [1]。

连接与 IO

LED

透过 BT510 外壳盖可以看到两个 LED。

  • LED_1A（绿色）= P0.22

  • LED_1B（红色）= P0.20

按键

BT510 外壳盖同时用作按键。

  • BUTTON_1 = SW1 = P1.10

磁阻传感器

BT510 集成了 Honeywell SM351LT 磁阻传感器。更多详细信息请参阅 Honeywell SM351LT datasheet [7]。

  • MAG = P1.14

加速度计

BT510 集成了 I2C 接口的意法半导体 LIS2DH 加速度计。更多详细信息请参阅 ST Microelectronics LIS2DH datasheet [6]。

  • SDA = P0.26

  • SCL = P0.27

  • INT_1 = P1.05

  • INT_2 = P1.12

温度传感器

BT510 集成了 I2C 接口的 Silabs SI7055 温度传感器。更多详细信息请参阅 Silabs 7055 datasheet [5]。

  • SDA = P0.26

  • SCL = P0.27

bt510 开发板配置的应用程序可以按常规方式构建、烧录和调试。有关构建和运行的更多详细信息，请参阅 构建应用程序 和 运行应用程序。

BT510 带有一个 TagConnect 10 路插座，用于连接编程器/调试器。合适的 TagConnect 线缆详见 TagConnect TC2050 product page [2]。

烧录

要使用 USB-SWD 编程板连接 BT510 开发板进行编程或调试，请在编程板上将 SW6 设置到供电输出位置、SW5 设置到 3V3 位置，确保 J35 上装有跳线帽且 SW1 处于调试位置，然后通过 J3 使用 Tag-Connect 线缆将 BT510 连接到编程板：

然后按常规方式构建和烧录应用程序（详见 构建应用程序 和 运行应用程序）。例如，烧录：

$ west flash

以下以 Hello World 应用程序为例。

首先，运行你常用的终端程序以监听输出。

注意：BT510 上的 UART 线为 TTL 电平，必须经过适当的线路驱动电路转换为 RS232 电平。合适的驱动 IC 请参阅 MAX3232 datasheet [4]。USB-SWD 编程板内置一个连接到 BT510 的 UART，用作 USB CDC 端口。在 Linux 和 Windows 10 上，该驱动应会自动安装；在 Windows 7 上，需要 MBED 驱动才能使用该串口，有关详细信息和驱动安装方法，请参阅 MBED Serial Driver [8] 链接。

$ minicom -D <tty_device> -b 115200

将 <tty_device> 替换为 bt510 所在的端口。例如，在 Linux 下为 /dev/ttyACM0。

然后按常规方式构建并烧录应用程序。

# From the root of the zephyr repository
west build -b bt510 samples/hello_world
west flash

注意，烧录应用程序需要外部调试器。

调试

bt510 开发板不像某些 nRF5x 开发板那样带有板载 J-Link 调试 IC，不过 Nordic nRF5x Segger J-Link 页面中的说明同样适用于该开发板，只需额外连接一个外部调试器。USB-SWD 编程板提供兼容 CMSIS 调试器的接口，可以使用 pyocd、openocd 或任何其他支持 CMSIS 接口的应用程序进行调试。
