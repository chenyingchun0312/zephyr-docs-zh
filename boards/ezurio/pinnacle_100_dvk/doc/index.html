Pinnacle 100 DVK

Board Overview

Name:
pinnacle_100_dvk
Vendor:

Ezurio

Status:

Not actively maintained

Architecture:

arm

SoC:

nrf52840

Browse board sources

概述

Pinnacle™ 100 蜂窝调制解调器无缝集成了性能强大的 Cortex M4F 控制器、完整的 Bluetooth 5 和 LTE-M/NB-IoT 能力，并已获得全部法规认证和 LTE 运营商认可。Pinnacle 100 还提供完全灵活的天线选择，可选用预集成的内置或外置天线，例如 Revie Flex 系列 LTE 和 NB-IoT 内置天线。

使用 Zephyr RTOS 直接在 M4F 控制器上开发应用程序，以降低 BOM 成本和功耗。可以借助 Zephyr 社区、Ezurio 的示例代码（蜂窝、Bluetooth）和硬件接口，也可以使用我们的托管模式 AT 命令集固件。

Pinnacle 100 对功耗要求极为严格，非常适合运行在物联网边缘的电池供电设备，可将蜂窝 WAN 无缝桥接到 BLE。通过低功耗 LTE 连接将无线 Bluetooth 5 传感器数据桥接到 AWS IoT 等云服务，从未如此简单。

有关该开发板的更多信息，请访问 Pinnacle 100 website [1]。

Pinnacle 100 开发套件（453-00010-K1 或 453-00011-K1）硬件支持 Nordic Semiconductor nRF52840 ARM Cortex-M4F CPU、Sierra Wireless HL7800 [2]（Altair ALT1250）以及以下设备：

  • ADC

  • CLOCK

  • FLASH

  • GPIO

  • I2C

  • MPU

  • NVIC

  • PWM

  • RADIO（低功耗蓝牙和 802.15.4）

  • RTC

  • Segger RTT（RTT 控制台）

  • SPI

  • UART

  • USB

  • WDT

  • QSPI

  • BME680

  • HL7800

LED

  • LED1（蓝色）= P1.4

  • LED2（绿色）= P1.5

  • LED4（绿色）= P1.7

按键

  • BUTTON2 = SW2 = P0.3

  • BUTTON3 = SW3 = P0.4

  • BUTTON4 = SW4 = P0.2

  • NRF RESET = SW5 = 复位

首先，运行你常用的终端程序以监听输出。

备注

在 Pinnacle 100 开发板上，应使用 FTDI USB 访问 UART 控制台。

$ minicom -D <tty_device> -b 115200

将 <tty_device> 替换为 Pinnacle 100 DVK 开发板所在的端口。例如，在 Linux 下为 /dev/ttyUSB0。

然后按常规方式构建并烧录应用程序。

# From the root of the zephyr repository
west build -b pinnacle_100_dvk samples/hello_world
west flash

调试

请参阅 Nordic nRF5x Segger J-Link 页面，了解如何使用 Segger IC 调试 Nordic 开发板。
