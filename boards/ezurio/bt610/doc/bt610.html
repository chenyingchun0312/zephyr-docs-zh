Sentrius BT610 Sensor

Board Overview

Name:
bt610
Vendor:

Ezurio

Status:

Not actively maintained

Architecture:

arm

SoC:

nrf52840

Browse board sources

概述

Sentrius™ BT610 传感器是一款电池供电、支持 Bluetooth v5 长距离的集成传感器平台，采用 Nordic Semiconductor nRF52840 ARM Cortex-M4F CPU。

该传感器具有以下特性：

  • ADC

  • CLOCK

  • FLASH

  • GPIO

  • I2C

  • MPU

  • NVIC

  • PWM

  • QSPI

  • RADIO（低功耗蓝牙和 802.15.4）

  • RTC

  • Segger RTT（RTT 控制台）

  • SPI

  • UART

  • WDT

有关该开发板的更多信息，请访问 Sentrius BT610 website [1]。

连接与 IO

LED

透过 BT610 外壳盖可以看到两个 LED。注意，这些 LED 既可以直接驱动，也可以通过 PWM 驱动。需要尽量降低电流消耗时应使用 PWM。

  • LED_1（红色）= LED0 = P1.07（红色 LED 1）

  • LED_2（绿色）= LED1 = P1.03（绿色 LED 2）

  • LED_PWM_1（红色）= LED0PWM = P1.07（红色 PWM LED 1）

  • LED_PWM_2（绿色）= LED1PWM = P1.03（绿色 PWM LED 2）

按键

BT610 集成三个机械按键。注意，只有在拆下外壳盖后才能触及这些按键。

其中两个按键可通过开发板 DTS 文件使用，如下所示。

  • BUTTON_1 = SW0 = P0.24（Boot 按键 SW1）

  • BUTTON_2 = SW1 = P1.01（防拆开关 SW2）

第三个机械按键用于复位板载微控制器。

磁阻传感器

BT610 集成了 Honeywell SM351LT 磁阻传感器。更多详细信息请参阅 Honeywell SM351LT datasheet [2]。

  • MAG_1 = SW2 = P1.15 (SM3531LT_0)

外部 Flash

板上提供一颗 64Mbit 外部 Flash 存储器，用于存储应用程序镜像和数据。更多详细信息请参阅 Macronix MX25R6435FZNIL0 datasheet [6]。

该 Flash 连接到板载 QSPI 设备控制器。

  • MX25R64 = QSPI

电压基准

V_REF 输入端提供一个精密 2.5V 电压基准，供 AD 测量时使用。

它可提供最高 50mA 的峰值电流和 20mA 的持续电流。

外部电源

可以通过 B+ OUT 端子为外部传感器供电，设置 BATTERY_OUTPUT_ENABLE GPIO 线即可启用。此外，设置 HIGH_SUPPLY_ENABLE GPIO 线可将外部电源升压到 5V。未选择 5V 时，外部电源跟随电池电压。

外部电源可提供最高 50mA 的峰值电流和 20mA 的持续电流。

烧录

按照 Nordic nRF5x Segger J-Link 页面中的说明安装并配置所有必需的软件。更多信息见 烧录。然后按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

以下以 Hello World 应用程序为例。

首先，运行你常用的终端程序以监听输出。

注意：BT610 上的 UART 线为 TTL 电平，必须经过适当的线路驱动电路转换为 RS232 电平。合适的驱动 IC 请参阅 MAX3232 datasheet [3]。

$ minicom -D <tty_device> -b 115200

将 <tty_device> 替换为 BT610 所在的端口。例如，在 Linux 下为 /dev/ttyUSB0。

然后按常规方式构建并烧录应用程序。

# From the root of the zephyr repository
west build -b bt610 samples/hello_world
west flash

注意，烧录应用程序需要外部调试器。

调试

bt610 开发板不像某些 nRF5x 开发板那样带有板载 J-Link 调试 IC，不过 Nordic nRF5x Segger J-Link 页面中的说明同样适用于该开发板，只需额外连接一个外部调试器。
