PSOC 63 BLE Pioneer Kit

Board Overview

Name:
cy8ckit_062_ble
Vendor:

Cypress Semiconductor Corporation

Status:

Not actively maintained

Architecture:

arm

SoC:

cy8c6347

Browse board sources

概述

PSOC 6 BLE Pioneer Kit（CY8CKIT-062-BLE）是一个可用于设计和调试 Cypress PSOC 63 BLE MCU 的硬件平台。

PSOC 6 BLE Pioneer Kit 搭载 PSOC 63 MCU：这是一款双核 MCU，以 150-MHz Arm Cortex-M4 作为主应用处理器，以支持低功耗运行的 100-MHz Arm Cortex-M0+ 作为辅助处理器，具有 1MB Flash、288KB SRAM、集成 BLE 4.2 射频、78 个 GPIO、7 个可编程模拟模块、12 个可编程数字模块，以及基于 CapSense 的电容感应功能。

PSOC 6 BLE Pioneer 开发板兼容 Arduino 扩展板，配有 512-Mb NOR Flash、板载编程器/调试器（KitProg2）、USB Type-C 电力传输系统（EZ-PD™ CCG3）、5 段 CapSense 滑条、两个 CapSense 按键、一个 CapSense 接近感应排针、一个 RGB LED、两个用户 LED 和一个按键。

CY8CKIT-062-BLE 套件包含一块 CY8CKIT-028-EPD 电子墨水显示扩展板，其上有一块 2.7 英寸电子墨水显示屏、一个运动传感器、一个热敏电阻和一个 PDM 麦克风。套件还包含一个 CY5677 CySmart BLE 4.2 USB 适配器，出厂时已编程为模拟 BLE GAP 中心设备，可以在计算机上模拟 BLE 主机。

Cortex-M0+ 是开发板 SoC 上的主核。它首先启动，并启用 CM4 内核。

系统时钟

PSOC 63 BLE MCU SoC 配置为使用内部 IMO+FLL 作为系统时钟源。CM0+ 工作在 50MHz，CM4 工作在 100MHz。根据系统需求，SoC 中还提供了其他系统时钟源。

串口

PSOC 63 BLE MCU SoC 有 8 个 SCB 模块，每个都可以配置为 UART/SPI/I2C 接口用于串行通信。目前配置了 SCB5 上的 UART5 和 SCB6 上的 UART6。SCB5 连接到板载 KitProg2 的 USB-UART 桥，用作串口控制台接口。SCB6 连接到兼容 Arduino Uno R3 的 PSOC 6 I/O 排针 J3 上的 P13_0、P13_1 引脚，供通用用途使用。

安装 OpenOCD

要获取 OpenOCD 软件包，需要

  1. 下载 ModusToolbox 3.1 软件。https://softwaretools.infineon.com/tools/com.ifx.tb.tool.modustoolbox

  2. 下载后，添加路径以访问 ModusToolbox 提供的 Scripts 文件夹 export PATH=$PATH:/path/to/ModusToolbox/tools_3.1/openocd/scripts

  3. 将 OpenOCD 可执行文件的路径添加到 west flash/debug。

  4. 烧录：west flash --openocd path/to/infineon/openocd/bin/openocd

  5. 调试：west debug --openocd path/to/infineon/openocd/bin/openocd

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

CY8CKIT-062-BLE 带有板载编程器/调试器（KitProg2），支持大容量存储编程，可通过 USB 提供调试、Flash 编程和串行通信。还有 PSOC 6 编程和调试排针 J11 和 J12，可配合 Segger J-Link 使用 [默认]。看门狗定时器默认启用。要禁用它，请调用 Cy_WDT_Unlock() 和 Cy_WDT_Disable()。

  1. 构建 Zephyr 内核和 Hello World 示例应用程序：

    west build -b cy8ckit_062_ble/cy8c6347/m0 samples/hello_world

  2. 运行你常用的终端程序以监听输出。在 Linux 下，终端应为 /dev/ttyACM0。例如：

    $ minicom -D /dev/ttyACM0 -o

    -o 选项让 minicom 不发送调制解调器初始化字符串。连接应按如下方式配置：

    • 波特率：115200

    • 数据位：8 位

    • 校验位：无

    • 停止位：1

  3. 烧录镜像：

    west build -b cy8ckit_062_ble/cy8c6347/m0 samples/hello_world
west flash

    终端中应显示 "Hello World! cy8ckit_062_ble"。

在双核上运行

  1. 构建 Zephyr 内核和 Button 示例应用程序：

    west build -b cy8ckit_062_ble/cy8c6347/m4 samples/basic/button

  2. 如果有 USB 转串口适配器，可以连接 Arduino 排针上的 SBC[UART]-6。连接方式请查看原理图。再次运行你常用的终端程序，查看另一路输出。在 Linux 下终端设备应为 /dev/ttyUSB0。例如：

    $ minicom -D /dev/ttyUSB0 -o

    -o 选项让 minicom 不发送调制解调器初始化字符串。连接应按如下方式配置：

    • 波特率：115200

    • 数据位：8 位

    • 校验位：无

    • 停止位：1

  3. 烧录镜像：

    west build -b cy8ckit_062_ble/cy8c6347/m4 samples/basic/button
west flash

  4. 配置 Cortex-M0+ 以启用 Cortex-M4：

    最后一步将 M4 镜像烧录到 Flash 中。但 Cortex-M0 默认不会启动 M4，因此不会有任何反应。要启用 Cortex-M4 CPU，请重复编程和调试步骤，并在构建时添加以下参数。

    west build -b cy8ckit_062_ble/cy8c6347/m0 samples/hello_world -- -DCONFIG_SOC_PSOC6_M0_ENABLES_M4=y
west flash

    现在可以按下按键 SW-2，看到 LED-9 闪烁，同时终端中显示 "Hello World! cy8ckit_062_ble"。

开发板版本

CY8CKIT-062-BLE 的 KitProg2 与 Arduino-R3 排针共用部分连接，这些连接可能导致扩展板无法正常使用。默认开发板版本（0.0.0）使用默认连接。只有在对开发板进行改装并使用版本 1.0.0 之后，才能使用 Arduino 排针。

  1. 为开发板版本 1.0.0 构建 Zephyr 内核和 Hello World 示例应用程序：

    west build -b cy8ckit_062_ble@1.0.0/cy8c6347/m0 samples/hello_world

  2. 版本 0.0.0 与 1.0.0 的区别：

1.0.0

CDC-COM RX

P5_0

P9_0

CDC-COM TX

P9 引脚位于 J2。这些信号应引到 J6。

J2-2 to J6-14 J2-4 to J6-13

最复杂的部分是将 U13 的引脚 14 和 15 短接，从而将 KitProg2 的 UART_RTS 与 UART_CTS 连接起来。
