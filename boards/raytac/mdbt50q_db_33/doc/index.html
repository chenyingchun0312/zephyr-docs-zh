MDBT50Q-DB-33

Board Overview

Name:
raytac_mdbt50q_db_33
Vendor:

Raytac Corporation

Status:

Not actively maintained

Architecture:

arm

SoC:

nrf52833

Browse board sources

概述

Raytac MDBT50Q-DB-33 硬件支持 Nordic Semiconductor nRF52833 ARM Cortex-M4F CPU 以及以下设备：

  • ADC

  • CLOCK

  • FLASH

  • GPIO

  • I2C

  • MPU

  • NVIC

  • PWM

  • RADIO（低功耗蓝牙和 802.15.4）

  • RTC

  • Segger RTT（RTT 控制台）

  • SPI

  • UART

  • USB

  • WDT

有关该开发板的更多信息，参见 MDBT50Q-DB-33 website [1]。MDBT50Q-DB-33 Specification [2] 包含演示板的数据手册，MDBT50Q-DB-33 Schematic [3] 包含演示板的原理图。

硬件

  • 基于 MDBT50Q-512K 的模块演示板

  • Nordic nRF52833 SoC 方案

  • Nordic Semiconductor 推荐的第三方模组。

  • 通过 BT5.2、BT5.1、BT5 蓝牙规范认证

  • 支持蓝牙 5 远距离（Long Range）特性

  • 认证：FCC、IC、CE、Telec(MIC)、KC、SRRC、NCC、RCM、WPC

  • 32 位 ARM® Cortex® M4F CPU

  • 512kB Flash 存储器/128kB RAM

  • 符合 RoHs 和 Reach。

  • 42 GPIO

  • 片式天线

  • 接口：SPI、UART、I2C、I2S、PWM、ADC、NFC 和 USB

  • 高度灵活的多协议 SoC，非常适合低功耗蓝牙（Bluetooth® Low Energy）、ANT+、Zigbee、Thread（802.15.4）等超低功耗无线应用。

  • 3 个用户 LED

  • 4 个用户按键

  • 1 个用于供电和 USB 通信的 Mini USB 连接器

  • 用于固件烧写的 SWD 连接器

  • 用于固件烧写的 J-Link 接口

  • 用于 UART 通信的 UART 接口

连接与 IO

LED

  • LED1（绿色）= P0.13

  • LED2（红色）= P0.14

  • LED3（蓝色）= P0.15

按键

  • BUTTON1 = SW1 = P0.11

  • BUTTON2 = SW2 = P0.12

  • BUTTON3 = SW3 = P0.24

  • BUTTON4 = SW4 = P0.25

UART

  • RXD = P0.08

  • TXD = P0.06

  • RTS = P0.05

  • CTS = P0.07

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

raytac_mdbt50q_db_33/nrf52833 开发板配置的应用程序可以按常规方式构建、烧录和调试。有关构建和运行的更多信息，参见 构建应用程序 和 运行应用程序。

备注

将 Zephyr 烧录到 raytac_mdbt50q_db_33/nrf52833 开发板并进行调试需要外部 J-Link 编程器。编程器连接到 J1 或 J9 SWD 连接器。

烧录

按照 Nordic nRF5x Segger J-Link 页面中的说明安装并配置所有必需的软件。更多信息见 烧录。然后按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

以下以 Hello World 应用程序为例。

使用 USB 转 TTL 转换器连接计算机和 raytac_mdbt50q_db_33/nrf52833 的 J10 连接器。然后运行你常用的终端程序查看输出。

$ minicom -D <tty_device> -b 115200

将 <tty_device> 替换为 USB 转 TTL 转换器所在的端口。例如，在 Linux 下为 /dev/ttyUSB0。

然后按常规方式构建并烧录应用程序。

# From the root of the zephyr repository
west build -b raytac_mdbt50q_db_33/nrf52833 samples/hello_world
west flash

调试

raytac_mdbt50q_db_33/nrf52833 开发板没有板载 J-Link 调试芯片，但 Nordic nRF5x Segger J-Link 页面中的说明同样适用于该开发板。使用 nRF52x DK 的 Debug out 连接器连接 J1 连接器，并使用 SEGGER J-Link OB IF 进行调试。

测试 Raytac MDBT50Q-DB-33 上的 LED 和按键

有 2 个示例可用于测试开发板上的按键（开关）和 LED 能否在 Zephyr 下正常工作：

samples/basic/blinky
samples/basic/button

可以构建并烧录示例，确认 Zephyr 在开发板上正常运行。按键和 LED 的定义位于 boards/raytac/mdbt50q_db_33/raytac_mdbt50q_db_33_nrf52833.dts。

选择引脚

引脚可以在开发板的 pinctrl 文件中配置。要查看可用的映射，请打开 MDBT50Q-DB-33 Specification [2] 第 2.5 章 “Pin Assignment”，选择标为 “General-purpose I/O” 的引脚。注意，标为 “low-frequency I/O only” 的引脚只能用于 10KHz 以下的应用，不适用于 SPI、I2C、UART 和 PWM。
