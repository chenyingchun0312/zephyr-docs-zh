AN54LV-DB-15

Board Overview

Name:
raytac_an54lv_db_15
Vendor:

Raytac Corporation

Status:

Not actively maintained

Architecture:

riscv, arm

SoC:

nrf54l15

Browse board sources

概述

Raytac AN54LV-DB-15 演示板是一款基于 Raytac AN54LV-15 模块的开发板，采用 Nordic Semiconductor nRF54L15 SoC 方案。其设计思路是把模块的所有引脚都引到 2.54mm 排针上，便于验证模块功能，以及连接其他外设和传感器引脚，是早期软件开发的实用工具。

备注

有关 nRF54L15 SoC 的更多信息，请访问 nRF54L15 website [1]。nRF54L15 的技术文档和其他资源（例如 SoC 数据手册）请参阅 nRF54L15 documentation [2] 页面。

硬件

Raytac AN54LV-DB-15 有两个晶体振荡器：

  • 高频 32 MHz 晶体振荡器（HFXO）

  • 低频 32.768 kHz 晶体振荡器（LFXO）

晶体振荡器可配置为使用内部电容或外部电容。

  • 基于 AN54LV-15 的模块演示板

  • Nordic nRF54L15 SoC 方案

  • Nordic Semiconductor 推荐的第三方模组。

  • 面向蓝牙规范 BT6

  • 面向 FCC、IC、CE、Telec（MIC）、KC、SRRC、NCC、RCM、WPC 认证

  • 带 TrustZone® 技术的 128 MHz ARM® Cortex®-M33 处理器

  • 带 TrustZone® 技术的 128 MHz RISC-V 协处理器

  • 1.5MB Flash 存储器 / 256KB RAM

  • 符合 RoHS 和 Reach。

  • 32 GPIO

  • 片式天线

  • 接口：SPI、UART、I2C、I2S、PDM、PWM、ADC 和 NFC

  • 高度灵活的多协议 SoC，非常适合 Bluetooth® Low Energy、ANT+、Zigbee、Thread（802.15.4）和 Matter 超低功耗无线应用。

  • BUTTON2 = SW1 = P1.09

  • BUTTON3 = SW2 = P1.08

  • BUTTON4 = SW3 = P0.04

UART

  • RX = P1.05

  • TX = P1.04

  • RTS = P1.06

  • CTS = P1.07

raytac_an54lv_db_15/nrf54l15/cpuapp 开发板的应用程序可以按常规方式构建、烧录和调试。有关构建和运行的更多信息，参见 构建应用程序 和 运行应用程序。

烧录

本节以 Hello World 应用程序为例，介绍如何构建和烧录。

警告

烧写设备时，可能会出现类似以下信息的错误:

ERROR: The operation attempted is unavailable due to readback protection in
ERROR: your device. Please use --recover to unlock the device.

启用了回读保护时会出现此错误。要禁用回读保护，必须对设备执行 恢复（recover）操作。

输入以下命令恢复该内核:

west flash --recover

--recover 命令会擦除 Flash，然后向恢复后的 Flash 写入一个小型二进制文件。该二进制文件可防止回读保护在引脚复位或重新上电后再次自行启用。

按照 Nordic nRF5x Segger J-Link 页面中的说明安装并配置所有必需的软件。更多信息见 烧录。

要构建示例并将其烧录到 Raytac AN54LV-DB-15，请完成以下步骤：

首先，使用 USB 转 TTL 转换器将 Raytac AN54LV-DB-15 的 J10 连接器连接到计算机。然后运行你常用的终端程序查看输出。

$ minicom -D <tty_device> -b 115200

将 <tty_device> 替换为 USB 转 TTL 转换器所在的端口。例如，在 Linux 下为 /dev/ttyUSB0。

接下来，运行以下命令构建示例：

# From the root of the zephyr repository
west build -b raytac_an54lv_db_15/nrf54l15/cpuapp samples/hello_world
west flash
