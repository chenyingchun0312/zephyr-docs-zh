KV260 Development Board RPU Cortex-R5

Board Overview

Name:
kv260_r5
Vendor:

Advanced Micro Devices (AMD), Inc.

Status:

Not actively maintained

Architecture:

arm

SoC:

zynqmp_rpu

Browse board sources

概述

此配置为 Xilinx KV260 开发板上的 RPU（实时处理单元）提供支持，它可以按以下方式工作：

  • 两个独立的 R5 内核，各自带有 TCM（紧耦合存储器）

  • 或者作为单个双核锁步单元工作，TCM 容量加倍。

该处理单元基于 ARM Cortex-R5 CPU，还启用了以下设备：

  • ARM PL-390 通用中断控制器

  • Xilinx Zynq TTC (Cadence TTC)

  • Xilinx Zynq UART

kv260_r5 开发板支持下列硬件功能。

设备

系统定时器

本开发板配置使用 1000 Hz 的系统定时器节拍频率。

串口

此开发板配置使用片上 UART1 作为单一串行通信通道。

存储器

虽然 DTS 文件中定义了 Flash、DDR 和 OCM 存储区域，但应用程序的全部代码和数据都会加载到指向 DDR 内存的 sram0 区域中。ocm0 存储区域目前可供使用，但默认情况下不会在其中放置任何内容。

已知问题或限制

以下平台功能暂不支持：

  • 尚不支持双冗余内核锁步（DCLS）执行。

  • 仅支持 R5 子系统的第一个内核。

  • Xilinx Zynq TTC 驱动不支持无节拍（tickless）模式。

  • Cortex-R5 和 Cortex-A53 共用同一个 UART 控制器，详见下文。

目前运行此示例的最佳方式是在运行 Linux 的 APU 上通过 remoteproc 将其加载到 RPU，前提是目标开发板具有兼容的 Linux 内核。用户可以使用 Xilinx 预构建的 Petalinux 参考镜像作为起点来启用 remoteproc 支持，该镜像基于 Xilinx 维护的 5.15 内核，如下所述：

https://xilinx-wiki.atlassian.net/wiki/spaces/A/pages/1641152513/Kria+K26+SOM#PetaLinux

另一种选择是使用 openAMP 项目的参考镜像，下面的链接指向其中适用于 kv260 目标的选项：

https://github.com/OpenAMP/openamp-ci-builds/releases/tag/v2022.12

选择 xilinx-kv260.tar.gz 选项，然后将其解压到用户 SD 卡的目标 rootfs 分区中即可：

$ sudo mount /dev/<user-sd> /media/rootfs
$ sudo tar -C /media/rootfs -xzf xilinx-kv260.tar.gz
$ sudo umount /media/rootfs

SD 卡此时应已可以使用，只需将其插入开发板上的卡槽即可。

Linux 镜像在目标开发板上运行后，构建一个 Zephyr 应用程序，例如下面所示的 hello world 示例：

# From the root of the zephyr repository
west build -b kv260_r5 samples/hello_world

由于硬件限制，Linux 和 Zephyr 共用同一个 UART 控制器，这意味着 Zephyr 应用程序启动后会从 Linux 接管控制台。

为了在访问 Linux shell 时避开这一限制，最好的方法是通过网络使用 ssh 连接开发板（不使用开发板上的 FTDI USB 接口），并让开发板和主机连接到同一网络。

假设使用 Xilinx 参考镜像中的默认 petalinux 用户，在主机上打开一个终端，使用开发板的 IP 地址（通过 ifconfig 查得）通过 ssh 登录开发板：

$ ssh petalinux@<board-ip-address>

初始密码应为 petalinux。在另一个终端中使用 scp 或 rsync 等工具部署 Zephyr 应用程序的 .elf 文件，例如：

$ scp /path/to/zephyr_app_elf_file  petalinux@<board-ip-address>:/home/petalinux

然后将文件移到 /lib/firmware 目录，即可通过 remoteproc 在所需的 RPU 上启动固件：

$ sudo -i # You need to operate the remoteproc as root
$ echo zephyr.elf > /sys/class/remoteproc/remoteproc0/firmware
$ echo start > /sys/class/remoteproc/remoteproc0/state

在主机上用另一个终端连接到 UART1（通过板载 FTDI 芯片提供的某个 tty 端口访问），应能看到 Zephyr 应用程序正在运行：

*** Booting Zephyr OS build v3.4.0  ***
Hello World kv260_r5!
