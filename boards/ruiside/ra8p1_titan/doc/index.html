RA8P1 Titan

Board Overview

Name:
ra8p1_titan
Vendor:

Shanghai Ruiside Electronic Technology Co., Ltd.

Status:

Not actively maintained

Architecture:

arm

SoC:

r7ka8p1kflcac

Browse board sources

概述

RA8P1 Titan Board 是 RT-Thread 推出的一款开发板，基于 Renesas R7KA8P1 芯片，采用 Cortex-M85 与 Cortex-M33 双核架构。它为工程师提供灵活而全面的开发平台，帮助开发者在嵌入式物联网领域获得更深入的认识和体验。

RA8P1 MCU 集成了主频最高 1 GHz 的高性能 Arm® Cortex®-M85 内核和主频最高 250 MHz 的 Arm® Cortex®-M33 内核，具有以下特性：

  • 最多 1 MB MRAM

  • 2 MB SRAM（256 KB CM85 TCM RAM、128 KB CM33 TCM RAM、1664 KB 用户 SRAM）

  • Arm® Ethos™-U55 NPU

  • 八线串行外设接口（OSPI）

  • 三层以太网交换模块（ESWM）、USBFS、USBHS、SD/MMC 主机接口

  • 图形 LCD 控制器（GLCDC）

  • 2D 绘图引擎（DRW）

  • MIPI DSI/CSI 接口

  • 模拟外设

  • 安全和功能安全特性

主要特性

  • Renesas RA8P1 MCU，带 1 GHz Arm Cortex-M85、250 MHz Arm Cortex-M33、Arm Ethos-U55 NPU 和 1 MB MRAM

  • 64 MB NorFlash 和 32 MB HyperRAM 存储扩展

  • 2 个千兆以太网接口

  • Octal SPI、Wi-Fi、CAN FD、USBFS/HS 和 SDHI

  • 板载 IMU 和磁力计

有关该开发板的更多信息，请参阅 RA8P1 Titan Board GitHub [1] 仓库和 RT-Thread RA8P1 Titan Board introduction [2]。

开发板硬件

RA8P1 Titan Board 围绕 Renesas R7KA8P1 MCU 设计，通过存储、网络、存储卡、无线、传感器和扩展接口提供 RA8P1 器件的各项功能。

MCU 与存储器

  • Renesas R7KA8P1 MCU

  • Arm Cortex-M85 核，运行频率最高 1 GHz

  • Arm Cortex-M33 核，运行频率最高 250 MHz

  • 用于 AI 加速的 Arm Ethos-U55 NPU

  • 1 MB 片上 MRAM

  • 2 MB 片上 SRAM，包括 CM85 TCM、CM33 TCM 和用户 SRAM

  • 64 MB 外部 NorFlash

  • 32 MB 外部 HyperRAM

连接与存储

  • 两个千兆以太网接口

  • Wi-Fi 模块

  • CAN FD 接口

  • USB 全速和 USB 高速接口

  • SDHI 接口

  • Octal SPI 接口

传感器与扩展

  • 板载 IMU

  • 板载磁力计

  • 用于网络、存储、无线和扩展的板上接口

双核运行

RA8P1 Titan Board 支持 Cortex-M85（CPU0）和 Cortex-M33（CPU1）双核运行。默认情况下，CM85 内核为启动内核，负责初始化系统并启动 CM33 内核。

存储器使用

默认情况下，MRAM（Flash）和 SRAM 在两个核之间平均分配。用户可以通过以下节点手动更改 MRAM（Flash）和 SRAM 的地址和大小：

  • CPU0: &code_mram_cm85, &sram0

  • CPU1: &code_mram_cm33, &sram1

备注

  • MRAM 可用范围：0x0200_0000 ... 0x0210_0000（1 MB）

  • SRAM 可用范围：0x2200_0000 ... 0x221A_0000（1664 KB）

双核烧录

烧录或调试双核示例时，必须为 CM85 镜像选择 CONFIG_SOC_RA_ENABLE_START_SECOND_CORE。CM85 核负责在 soc_late_init_hook 中启动 CM33 核。

ra8p1_titan 开发板配置的应用程序可以按常规方式构建、烧录和调试。有关构建和运行的更多细节，请参阅 构建应用程序 和 运行应用程序。

串口控制台

CM85 开发板目标使用 UART5 作为 Zephyr 控制台和 shell，CM33 开发板目标使用 UART6。这些控制台 UART 引出在外部 UART 接口引脚上，没有连接到板载 DAP-Link 虚拟串口。

在这块开发板上，DAP-Link 虚拟串口连接的是另一个 UART。该 UART 同时被 Wi-Fi/Bluetooth 模块的 UART HCI 接口使用，因此它不是任何一个内核的默认 Zephyr 日志控制台。读取 Zephyr 日志时，请使用连接到 UART5 或 UART6 引脚的外部 USB 转 UART 适配器。

以下是在 CM85 核上运行 Hello World 应用程序的示例。

# From the root of the zephyr repository
west build -b ra8p1_titan/r7ka8p1kflcac/cm85 samples/hello_world
west flash

打开串口终端，复位开发板，终端中应显示以下信息：

***** Booting Zephyr OS v4.2.0-xxx-xxxxxxxxxxxxx *****
Hello World! ra8p1_titan/r7ka8p1kflcac/cm85

对于 CM33 核，使用 --sysbuild 流程构建一个最小的第一核启动器镜像，由它启动 CM33 核。

# From the root of the zephyr repository
west build -b ra8p1_titan/r7ka8p1kflcac/cm33 --sysbuild samples/hello_world
west flash

烧录

可以使用已配置的 Zephyr 运行器（runner）将程序烧录到 RA8P1 Titan Board。

将程序烧录到开发板：

  1. 将开发板的调试端口连接到主机 PC。

  2. 执行 west 命令：

    west flash

MCUboot 引导加载程序

Sysbuild 可以构建并烧录引导开发板所需的全部镜像。

使用 sysbuild 构建示例应用程序：

# From the root of the zephyr repository
west build -b ra8p1_titan/r7ka8p1kflcac/cm85 --sysbuild samples/hello_world -- -DSB_CONFIG_BOOTLOADER_MCUBOOT=y
west flash

默认情况下，sysbuild 会生成 MCUboot 镜像和用户应用程序镜像。

sysbuild 创建的构建目录结构与传统 Zephyr 构建不同，输出按域（domain）子目录组织：

build/
|-- hello_world
|   `-- zephyr
|       |-- zephyr.elf
|       |-- zephyr.hex
|       |-- zephyr.bin
|       |-- zephyr.signed.bin
|       `-- zephyr.signed.hex
|-- mcuboot
|   `-- zephyr
|       |-- zephyr.elf
|       |-- zephyr.hex
|       `-- zephyr.bin
`-- domains.yaml

备注

使用 --sysbuild 选项时，每次进行全新（pristine）构建都会重新构建并重新烧录 MCUboot。

在后续构建中仅烧录用户应用程序，使用：

west flash --domain hello_world

有关系统构建的更多信息，请参阅 Sysbuild（系统构建） 文档。
