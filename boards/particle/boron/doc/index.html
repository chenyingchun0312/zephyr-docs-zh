Boron

Board Overview

Name:
particle_boron
Vendor:

Particle.io

Status:

Not actively maintained

Architecture:

arm

SoC:

nrf52840

Browse board sources

概述

Particle Boron 是一款支持蜂窝网络的开发板，配有用于 mesh 支持的 Nordic Semiconductor nRF52840 和一个 LTE 或 2G/3G 调制解调器。该开发板由 Particle Industries 开发，板上带有用于编程的 SWD 连接器。

开发板带有板载锂电池电路，符合 Adafruit Feather 外形规格。

Particle Boron 开发板支持 Nordic Semiconductor nRF52840 ARM® Cortex®-M4F SoC，该 SoC 集成了支持低功耗蓝牙（Bluetooth® Low Energy）和 IEEE® 802.15.4 的 2.4 GHz 收发器。

有关 Particle Boron 开发板的更多信息：

  • Boron Datasheet

  • Boron Hardware Files

硬件

开发板正面有 RGB-LED、LED 和锂电池电路。RGB-LED 由 nRF52840 通过 GPIO 引脚控制。

电源

本开发板针对低功耗应用进行了优化，支持两种供电配置：电池和 micro USB 连接器。

开发板带有锂电池电路，可通过 USB 端口充电。

连接与 IO

排针引脚分配请参阅 Boron Datasheet，所有兼容 Feather 的 Particle 开发板的引脚分配都相同。部分外设可以通过 DTS 覆盖文件的 include 指令提供给应用程序使用：

  • mesh_feather_spi_spi3.dtsi 将 SPI3 引出到标注为 Feather SPI 的引脚

  • mesh_feather_spi1_spi3.dtsi 将 SPI3 引出到标注为 Feather SPI1 的引脚

  • mesh_feather_uart1_rtscts.dtsi 为标注为 Feather UART 的引脚添加硬件流控

LED

  • LED0（蓝色）

  • LED1（红色）

  • LED2（绿色）

  • LED3（蓝色）

按键

  • SW0 对应 MODE

  • SW1 对应 RESET

I2C

  • TWI0 已在标注的排针（SDA/SCL）上启用

  • TWI1 已启用，用于板内电源管理 IC

SPI

  • SPI0 因与 TWI0 冲突而禁用

  • SPI1 因与 TWI1 冲突而禁用

  • SPI2 在内部连接到 32 Mb CFI Flash 芯片

  • SPI3 可通过覆盖文件选择（SPI 或 SPI1）

UART

  • UARTE0 已在标注的排针（UART1）上启用 RX/TX；可通过覆盖文件添加 RTS/CTS

  • UARTE1 在板内连接到 u-blox 蜂窝调制解调器

编程与调试

说明

particle_boron 开发板配置的应用程序可以按常规方式构建和烧录（详见 构建应用程序 和 运行应用程序）。

烧录

按常规方式构建和烧录应用程序，例如：

# From the root of the zephyr repository
west build -b particle_boron samples/basic/blinky
west flash

调试

可以按常规方式调试应用程序。以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b particle_boron samples/hello_world
west debug
