概述

Arduino™ Opta® 是一款具备工业物联网（IoT）能力的安全微型可编程逻辑控制器（PLC）。

该设备与 Finder® 合作开发，同时支持 Arduino 编程语言和标准 IEC-61131-3 PLC 编程语言，例如梯形图（LD）、顺序功能图（SFC）、功能块图（FBD）、结构化文本（ST）和指令表（IL），是自动化工程师的理想设备。

Zephyr RTOS 支持两个内核。也可以只在 M4 上运行 Zephyr，由 M7 运行 PLC 任务，而运行 Zephyr 的 M4 内核作为协处理器。

此外，该设备还具有：

  • 符合 IEEE802.3-2002 标准的以太网

  • 16MB QSPI Flash 存储器

  • 4 个绿色状态 LED

  • 复位按键上方的 1 个绿色或红色 LED

  • 用户按键上方的 1 个蓝色 LED（仅 Opta Advanced）

  • 1 个用户按键

  • 1 个可通过针孔按压的复位按键

  • 8 路模拟输入

  • 4 路隔离继电器输出

有关此开发板的更多信息，请访问 ARDUINO-OPTA website。有关 STM32H747XIH6 的更多信息，请参阅：

  • STM32H747XI on www.st.com

  • STM32H747xx reference manual

  • STM32H747xx datasheet

引脚映射

M7 和 M4 内核都可以访问 9 个 GPIO 控制器。这些控制器负责引脚复用、输入/输出、上拉等功能。

更多细节请参阅 ARDUINO-OPTA website。

Zephyr 默认外设映射

  • 状态 LED1：PI0

  • 状态 LED2：PI1

  • 状态 LED3：PI3

  • 状态 LED4：PH15

  • 绿色 "reset" LED：PH12

  • 红色 "reset" LED：PH11

  • 蓝色 LED：PE5

  • 用户按键：PE4

  • 输入 1：PA0

  • 输入 2：PC2

  • 输入 3：PF12

  • 输入 4：PB0

  • 输入 5：PF10

  • 输入 6：PF8

  • 输入 7：PF6

  • 输入 8：PF4

  • 继电器 1：PI6

  • 继电器 2：PI5

  • 继电器 3：PI7

  • 继电器 4：PI4

系统时钟

STM32H747I 系统时钟可由内部或外部振荡器驱动，也可由主 PLL 时钟驱动。默认情况下，CPU2（Cortex-M4）系统时钟运行在 240MHz。PLL 时钟由 25MHz 高速外部时钟提供。M7 时钟运行在 400MHz。

外部 Flash

可以通过 CONFIG_FLASH 选项启用对外部 Flash（QSPI 上的 16MB）的访问。默认分区表与最新 Arduino IoT Cloud 库所用的分区表保持一致。如果遇到问题，请重新运行 QSPIFormat.ino 草图（sketch）更新 Flash 内容。

资源共享

STM32H747 SoC 为双核架构，两个内核之间需要共享硬件资源。共享通过以下 3 种方式实现：

  • 编译：只有 M7 内核可以访问时钟配置。M4 内核只能激活和停用总线时钟。

  • 编译前静态分配：UART 等外设在编译前通过设备树分配。用户必须确保同一外设不会同时分配给两个内核。

  • 运行时保护：两个内核在运行时都可以访问中断控制器和 GPIO 配置。这些访问由硬件信号量保护，以避免潜在的并发访问问题。

编程与调试

arduino_opta 的应用程序使用常规的 Zephyr 构建命令。有关应用程序构建的更多信息，请参阅 构建应用程序。

烧录

烧录操作取决于要烧录的目标和 SoC 选项字节配置。OPTA 带有支持 DFU 的引导加载程序：将设备连接到 USB，然后快速按两次 RESET 按键即可进入。板上的 RESET-LED 呈渐变闪烁，表示开发板处于引导加载程序模式。

默认情况下：

  • CPU1（Cortex-M7）启动地址设置为 0x08040000

  • CPU2（Cortex-M4）启动地址设置为 0x08180000

Zephyr 的 Flash 配置已设置为与 Arduino IDE 中的 "Flash split: 1.5MB M7 + 0.5MB M4" 选项兼容。Flash 分区如下：

  • 0x08000000-0x0803FFFF（256k）基于 Arduino MCUboot 的引导加载程序

  • 0x08040000-0x080FFFFF（768k）M7 应用程序

  • 0x08180000-0x081FFFFF（512k）M4 应用程序

将应用程序烧录到 ARDUINO OPTA M7

首先，使用 USB 端口将设备连接到主机，为烧录做好准备。然后构建并烧录应用程序。

以下是在 M7 内核上运行 Blinky 应用程序的示例。

# From the root of the zephyr repository
west build -b arduino_opta/stm32h747xx/m7 samples/basic/blinky
west flash

将应用程序烧录到 ARDUINO OPTA M4

首先，使用 USB 端口将设备连接到主机，为烧录做好准备。然后构建并烧录应用程序。

以下以 M4 内核上的 Blinky 应用程序为例。

# From the root of the zephyr repository
west build -b arduino_opta/stm32h747xx/m4 samples/basic/blinky
west flash

在 ARDUINO OPTA M4 上启动应用程序

如果同时向 M7 烧录了应用程序，M4 处理器会在启动时启动。否则，需要通过 Arduino 草图启动该处理器。

确保选项字节已设置为阻止 M4 自动启动，并且 M7 一侧会从正确的 Flash 地址启动 M4。

可以在 Arduino IDE 的 "Tools" / "Flash Split" 菜单中选择 "1.5MB M7 + 0.5MB M4" 选项，并加载一个至少包含以下代码的草图来实现：

#include <RPC.h>

void setup() {
    RPC.begin();
}

void loop() { }

调试

调试端口不便于访问，但可以打开外壳，在开发板上焊接一个标准 10 针 SWD 连接器。之后即可通过 ST-LINK 进行烧录和调试（仅限 M7 内核）。
