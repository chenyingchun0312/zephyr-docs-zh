Hexiwear

概述

Hexiwear 由基于 ARM Cortex-M4 内核的 Kinetis K64 微控制器驱动。另一颗 Kinetis 无线 MCU KW40Z 提供低功耗蓝牙连接。Hexiwear 还集成了多种传感器，以及由 1.1" 96px x 96px 全彩 OLED 显示屏和六个带触觉反馈的电容按键组成的用户界面。

  • 醒目的智能手表外形，配备性能强大的低功耗 Kinetis K6x MCU 和 6 个板载传感器。

  • 专为可穿戴应用设计，板载可充电电池、OLED 屏幕以及光学心率、加速度计、磁力计和陀螺仪等传感器。

  • 专为物联网终端节点应用设计，板载温度、气压、湿度和环境光等传感器。

  • 可通过 click 板灵活添加近 200 种额外传感器，按需选择。

硬件

  • 主 MCU：NXP Kinetis K64x（ARM Cortex-M4，120 MHz，1M Flash，256K SRAM）

  • 无线 MCU：NXP Kinetis KW4x（ARM Cortex-M0+，低功耗蓝牙和 802.15.4 射频）

  • 6 轴加速度计与磁力计组合传感器 NXP FXOS8700

  • 3 轴陀螺仪：NXP FXAS21002

  • 绝对压力传感器 NXP MPL3115

  • 锂离子/锂聚合物电池充电器 NXP MC34671

  • 光学心率传感器 Maxim MAX30101

  • 环境光传感器、湿度和温度传感器

  • 1.1" 全彩 OLED 显示屏

  • 触觉反馈引擎

  • 190 mAh 2C 锂聚合物电池

  • 电容式触摸界面

  • RGB LED

备注

要启用电池检测，需要在设备树中启用 en_bat_sens 稳压器。同样，要启用连接到 1V8 或 3V3 电源轨的设备（传感器），需要在设备树中启用 en_ldo 和 en_3v3b 稳压器。

系统时钟

K64F SoC 配置为使用开发板上的 12 MHz 外部振荡器，并通过片上 PLL 生成 120 MHz 系统时钟。

串口

K64F SoC 有六个 UART。一个配置为控制台，另一个用于 BT HCI，其余未使用。

编程与调试

按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

配置调试探针

烧录和调试开发板都需要使用调试探针。该开发板默认配置为使用 OpenSDA DAPLink 板载调试探针，但由于 KW40Z 上的控制台需要 Segger RTT，建议将开发板重新配置为使用 OpenSDA J-Link 板载调试探针。

备注

OpenSDA 通过开关在 K64 和 KW40Z 之间共享，因此同一时间只能对一个 SoC 进行烧录、调试或打开控制台。

选项 1：OpenSDA J-Link 板载调试探针 （推荐）

安装 J-Link 调试主机工具，并确保它们位于搜索路径中。

按照 OpenSDA J-Link 板载调试探针 中的说明烧写 OpenSDA J-Link Generic Firmware for V2.1 Bootloader。确认开关 SW1 和 SW2 处于 on 位置，SW3 和 SW4 处于 off 位置，以确保 K64F 的 SWD 信号连接到 OpenSDA 微控制器。

选项 2：OpenSDA DAPLink 板载调试探针

安装 pyOCD 调试主机工具，并确保它们位于搜索路径中。

按照 OpenSDA DAPLink 板载调试探针 中的说明烧写 OpenSDA DAPLink Hexiwear Firmware。确认开关 SW1 和 SW2 处于 on 位置，SW3 和 SW4 处于 off 位置，以确保 K64F 的 SWD 信号连接到 OpenSDA 微控制器。

调用 west build 时添加参数 -DBOARD_FLASH_RUNNER=pyocd 和 -DBOARD_DEBUG_RUNNER=pyocd，将默认运行器从 J-Link 改为 pyOCD：

# From the root of the zephyr repository
west build -b hexiwear/mk64f12 samples/hello_world -- -DBOARD_FLASH_RUNNER=pyocd -DBOARD_DEBUG_RUNNER=pyocd

配置控制台

无论选择哪种调试探针，我们都将 OpenSDA 微控制器用作 USB 转串口适配器，为串口控制台提供连接。

用 USB 线将 PC 连接到 CN1。

在你选用的串口终端（minicom、putty 等）中使用以下设置：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

烧录

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b hexiwear/mk64f12 samples/hello_world
west flash

打开串口终端，复位开发板（按下 T4 按键），终端中应显示以下信息：

***** Booting Zephyr OS v1.14.0-rc1 *****
Hello World! hexiwear

调试

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b hexiwear/mk64f12 samples/hello_world
west debug

打开串口终端，在调试器中单步执行应用程序，终端中应显示以下信息：

***** Booting Zephyr OS v1.14.0-rc1 *****
Hello World! hexiwear

使用蓝牙

将 KW40Z 配置为蓝牙控制器

将 KW40Z 配置为蓝牙控制器后，K64 即可运行 Zephyr 蓝牙主机应用程序。

  1. 下载并安装 KW40Z Connectivity Software。该软件包中包含适用于 KW40Z 的蓝牙控制器应用程序。

  2. 将文件 tools/binaries/BLE_HCI_Modem.bin 烧录到 KW40Z。

现在可以在 K64 上构建并运行 Zephyr 蓝牙主机示例应用程序。以后每次向 K64 烧录新的蓝牙主机应用程序时，无需重复此步骤。

外设心率传感器

进入 Zephyr 的 samples/bluetooth/peripheral_hr 示例应用程序，构建并将其烧录到 Hexiwear K64。确保扩展坞上的 OpenSDA 开关已设置为连接 K64。

# From the root of the zephyr repository
west build -b hexiwear/mk64f12 samples/bluetooth/peripheral_hr
west flash

使用扩展坞上的按键复位 KW40Z 和 K64。

在智能手机上安装 Kinetis BLE Toolbox：

  • Kinetis BLE Toolbox for iOS

  • Kinetis BLE Toolbox for Android

打开应用，点击 Heart Rate 功能，应能看到一个 Zephyr Heartrate Sensor 设备。点击 Zephyr Heartrate Sensor 设备，即可看到每秒更新一次的心率数据曲线图。

Hexiwear KW40Z

概述

KW40Z 是开发板上的第二颗 SoC，通过多模 BLE 和 802.15.4 射频提供无线连接。

有关 KW40Z SoC 的更多信息：

  • KW40Z Datasheet

  • KW40Z Reference Manual

hexiwear 开发板支持下列硬件功能。

KW40Z SoC 有三组 pinmux/gpio 控制器，但目前 hexiwear/mkw40z4 开发板只启用了其中一组（PORTC/GPIOC）。

KW40Z SoC 只有一个 UART，用于蓝牙 HCI，没有可用于控制台的 UART。

编程与调试

按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

配置调试探针

配置控制台

控制台可通过 Segger RTT 使用。

用 USB 线将 PC 连接到 CN1。

启动调试会话后，运行 telnet：

$ telnet localhost 19021
Trying 127.0.0.1...

Escape character is '^]'.

烧录

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b hexiwear/mkw40z4 samples/hello_world

# From the root of the zephyr repository
west build -b hexiwear/mkw40z4 samples/hello_world
west attach

按前述方法运行 telnet，终端中应显示以下信息：
