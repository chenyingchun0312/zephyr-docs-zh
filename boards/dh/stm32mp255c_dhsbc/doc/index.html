DHSBC STM32MP255C

Board Overview

Name:
stm32mp255c_dhsbc
Vendor:

DH electronics GmbH

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32mp255cxx

Browse board sources

概述

DHSBC STM32MP255C 是一款工业级、开箱即用的单板计算机，专为物联网和人机界面（HMI）应用开发。它基于可焊接、引脚兼容的 DHCOS STM32MP2 系统模块（System on Module），可实现模块化、可扩展的系统架构。该平台专为高性能、超过十年的长期供货以及在严苛工业环境中使用而设计。

DHSBC STM32MP255C 全面支持主线 Linux（包括 Vivante GPU），为开发图形用户界面和复杂应用程序提供了面向未来的软件基础。安全启动（Secure Boot）和安全存储（Secure Storage）等集成安全功能确保敏感数据受到保护，并支持实现“设计即安全”（Security by Design）方法。连接选项从千兆以太网、WiFi 和 Bluetooth，到 3D GPU、显示、摄像头和视频支持等高级多媒体功能。得益于集成的 STPMIC25 电源管理芯片，DHSBC STM32MP255C 也适用于对能效和低功耗模式要求较高的应用。

Zephyr OS 被移植到 Cortex®-M33 内核上运行，作为 Cortex®-A35 内核的协处理器，从而在应用内核进行基于 Linux 的高性能处理的同时，实现实时和低功耗应用。

功能：

  • STM32MP255CAK3 微处理器，采用 VFBGA424 封装，集成双核 Arm® Cortex®-A35、一个 Cortex®-M33 和一个 Cortex®-M0+

  • ST 电源管理芯片 STPMIC25DPQR

  • 4 GB DRAM（LPDDR4-2400 32 位）

  • 16 GB eMMC Flash 存储器

  • 4 MB SPI NOR Flash 存储器

  • 4 kB EEPROM

  • 两个 1 Gbit/s 以太网（RGMII）

  • 高速 USB 主机集线器

  • 高速 USB Type-C 3.2 Gen 1x1，支持 DisplayPort 替代模式

  • Bluetooth® v5.4 BR/EDR/LE

  • WiFi（三频 2.4 GHz、5 GHz 和 6 GHz，支持 IEEE802.11a/b/g/n/ac/ax）

  • 电源和复位按键

  • 四个启动引脚开关

  • 开发板连接器：

    • 两个以太网 RJ45 接口

    • 一个 USB 主机 Type-A 接口

    • USB Type-C®（数据）

    • USB Type-C®（供电）

    • microSD™ 卡座

    • 双通道 MIPI CSI-2® 摄像头模组扩展连接器

    • LVDS

    • 三针 UART 连接器（串口控制台）

    • Raspberry Pi 40 针扩展连接器

    • 用于 RTC 和备份 SRAM 的 VBAT

    • JTAG

  • Linux® Yocto 项目 BSP

有关该开发板和 SoC 的更多信息，请参阅 STM32MP255C-DHSBC website [1]、STM32MP255C website [5] 和 STM32MP255C reference manual [6]

硬件

内核：

  • 64 位双核 Arm® Cortex®-A35，最高频率 1.2 GHz

    • 每个 Cortex®-A35 内核配有 32 KB 指令 + 32 KB 数据一级缓存

    • 512 KB 统一二级缓存

    • Arm® NEON™ 和 Arm® TrustZone®

  • 32 位 Arm® Cortex®-M33，带 FPU/MPU 和 Arm® TrustZone®，最高频率 400 MHz

    • Cortex®-M33 的 L1 16 KB ICache / 16 KB DCache

  • SmartRun 域中的 32 位 Arm® Cortex®-M0+，最高频率 200 MHz（自主模式下最高 16 MHz）

存储器：

  • 外部 DDR 内存 4 GB（LPDDR4-2400 32 位）

  • 808 KB 内部 SRAM：256 KB AXI SYSRAM、128 KB AXI 视频 RAM 或 SYSRAM 扩展、256 KB AHB SRAM、备份域中 128 KB 带 ECC 的 AHB SRAM、备份域中 8 KB 带 ECC 的 SRAM、SmartRun 域中 32 KB

  • 两个 Octo-SPI 存储器接口

  • 灵活的外部存储器控制器，数据总线最宽 16 位：用于连接外部 IC 的并行接口，以及支持最高 8 位 ECC 的 SLC NAND 存储器

Power

  • 用于电压调节的 STPMIC25（多路 buck/LDO 稳压器）

  • USB-C 电源输入

  • VBAT 备用电池连接器（RTC、备份 SRAM）

时钟管理

  • 外部振荡器：

    • 32.768 kHz LSE 晶体

    • 40 MHz HSE 晶体

  • 内部振荡器：

    • 64 MHz HSI 振荡器

    • 4 MHz CSI 振荡器

    • 32 kHz LSI 振荡器

    • 五个独立的 PLL，支持整数和小数模式

Security/Safety

  • 安全启动、TrustZone® 外设、主动防篡改、环境监测、显示安全层、硬件加速器

  • 完整的资源隔离框架

连接

  • 2 个千兆以太网（RGMII）

  • USB 2.0 高速主机

  • USB Type-C®

  • Raspberry Pi 40 针扩展连接器

显示与摄像头

  • LVDS 接口（1 个双链路，2 个 4 通道 LVDS 连接器）

  • 1 个 2 通道 MIPI-CSI2 连接器

前提条件

在 DHSBC STM32MP255C 上运行 Zephyr 之前，需要先在 Cortex®-A35 内核上搭建 Linux® 环境。Cortex®-M33 内核作为协处理器运行 Zephyr，需要由 Cortex®-A35 通过 remoteproc 加载并启动固件。

搭建 Linux 环境的一种方法是使用 DH electronics 的 KAS/Yocto 仓库构建 Linux 镜像：STM32MP255C-DHSBC kas yocto [3]。也有预构建的镜像：STM32MP255C-DHSBC prebuild images [4]。

另一种方法是按照 Starter Package 5 使用 OpenSTLinux 发行版（有关该流程的更多信息，请参阅 STM32MPU Wiki [8]）。

加载固件

在开发板上安装 Linux 发行版后，由 Cortex®-A35 负责将 Zephyr 固件镜像加载到 DDR 和/或 SRAM 中，并启动 Cortex®-M33 内核。应用程序可以使用 west 构建，以 Hello World 为例。

# From the root of the zephyr repository
west build -b stm32mp255c_dhsbc/stm32mp255cxx/m33 samples/hello_world

可以将固件复制到开发板的文件系统中，并通过 Linux remoteproc 框架启动。

启动固件：

$ cp zephyr.elf /lib/firmware/
$ echo -n zephyr.elf > /sys/class/remoteproc/remoteproc0/firmware
$ echo start > /sys/class/remoteproc/remoteproc0/state

停止固件：

$ echo stop > /sys/class/remoteproc/remoteproc0/state

有关该流程的更多信息，请参阅 ST Wiki 页面 STM32MP257F boot Cortex-M33 firmware [7]。

调试

可以使用 J-Link 配合 J-Link Software Pack，或使用 ST-Link 配合 OpenOCD 调试应用程序。默认使用 J-Link。

使用 ST-Link 时必须使用 ST 提供的最新版 OpenOCD，相关文件可在 device-stm-openocd [9] 获取。要使用该版本，请在 west attach 中使用 --openocd 和 --openocd-search 参数。

固件必须先由 Cortex®-A35 启动，然后才能将调试器连接到正在运行的 Zephyr 固件。

  • 构建示例

# From the root of the zephyr repository
west build -b stm32mp255c_dhsbc/stm32mp255cxx/m33 samples/drivers/uart/echo_bot

  • 将固件复制到开发板，并通过 remoteproc 加载并启动它（STM32MP257F boot Cortex-M33 firmware [7]）。它会回显 raspberry_pi_serial 上收到的所有字节。

  • 使用 J-Link 连接到目标：

$ west attach

  • 或者使用 ST-Link 和 OpenOCD 连接到目标（假设 ST 的 OpenOCD 已下载到 /opt/device-stm-openocd）：

$ west attach --runner openocd \
  --openocd "/opt/device-stm-openocd/prebuilt/openocd" \
  --openocd-search "/opt/device-stm-openocd/prebuilt/scripts/"
