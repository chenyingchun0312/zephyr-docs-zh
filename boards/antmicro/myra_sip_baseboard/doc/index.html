Myra SiP Baseboard

Board Overview

Name:
myra_sip_baseboard
Vendor:

Antmicro

Status:

Not actively maintained

Architecture:

arm

SoC:

myra

Browse board sources

概述

Myra SiP 底板搭载 Antmicro 的 Myra SiP，其中集成了 STM32G491REI6 MCU、128kB FRAM 和 FTDI FT231XQ USB 转 UART 转换器。该板配备温度、湿度和气压传感器，用于帮助监测机房环境状况。

传感器位于一块可从主 PCB 上拆下的独立小板上，可以直接安装到所需位置。该板提供用于数据记录的本地存储，以及防止数据丢失的备用电池。它可以作为环境参数监测 PoC 方案的基础组件。

主要特性包括：

  • STM32G491REI6 MCU（Cortex-M4，170 MHz）

  • 128 KB 富士通（Fujitsu）FRAM

  • FTDI FT231XQ USB 转 UART 转换器

  • 50 mm x 26.5 mm PCB

  • 用于数据和供电的 USB-C 连接器

  • SHT45 温湿度传感器

  • BME280 温度、湿度和气压传感器

  • 用于外设扩展的 QWIIC 连接器

  • 带备用电池的 RTC

有关此开发板的更多信息，请访问 Antmicro 开放硬件门户。

硬件

Myra SiP 提供以下硬件：

  • STM32G491REI6 MCU:

    • 带 FPU 的 ARM Cortex-M4 CPU，主频最高 170 MHz

    • 时钟源：

      • 4 至 48 MHz 外部晶体振荡器（HSE）

      • 用于 RTC 的 32 kHz 晶体振荡器（LSE）

      • 内部 16 MHz RC 振荡器（±1%）

      • 内部低功耗 32 kHz RC 振荡器（±5%）

      • 2 个 PLL，用于系统时钟、USB、音频和 ADC

    • RTC：带硬件日历、闹钟和校准功能的实时时钟

    • 定时器：

      • 1 个 32 位定时器和 2 个 16 位定时器，每个最多提供 4 路 IC/OC/PWM 或脉冲计数器，以及正交（增量）编码器输入

      • 3 个 16 位高级电机控制定时器，每个最多 8 路 PWM 通道，支持死区时间生成和紧急停止

      • 1 个 16 位定时器，带 2 路 IC/OC、1 路 OCN/PWM，支持死区时间生成和紧急停止

      • 2 个看门狗定时器（独立看门狗、窗口看门狗）

      • 2 个 16 位基本定时器

      • SysTick 定时器

      • 1 个低功耗定时器

    • I/O：最多 86 个快速 I/O，大多数可耐受 5V

    • 存储器：

      • 512 KB Flash 存储器，带 ECC 和 PCROP 保护

      • 96 KB SRAM，其中 32 KB 带硬件奇偶校验

    • 模拟外设：

      • 3 个 16 位 ADC，最多 36 个通道，支持硬件过采样，分辨率最高 16 位

      • 4 个 12 位 DAC 通道

      • 4 个超快速轨到轨模拟比较器

      • 4 个内置 PGA 的运算放大器

      • 内部温度传感器和电压基准，支持三种输出电压（2.048 V、2.5 V、2.9 V）

    • 通信接口：

      • 2 个支持灵活数据速率的 FDCAN 控制器

      • 3 个 I2C 超快速模式（Fast Mode Plus，1 Mbit/s）接口，支持 20 mA 灌电流和 SMBus/PMBus

      • 5 个 USART/UART（ISO 7816、LIN、IrDA、调制解调器控制）

      • 1x LPUART

      • 3 个 SPI 接口（其中 2 个复用半双工 I²S）

      • 1 个 SAI（串行音频接口）

      • USB 2.0 全速接口，支持 LPM 和 BCD

      • IRTIM（红外接口）

      • USB Type-C™ / USB 电力传输（UCPD）

    • 其他外设：

      • 16 通道 DMA 控制器

      • 真随机数发生器（RNG）

      • CRC 计算单元，96 位唯一 ID

      • 开发支持：SWD、JTAG、嵌入式跟踪宏单元（Embedded Trace Macrocell™）

      • 符合 ECOPACK2® 标准的封装

  • 128 KB 富士通 MB85RS1MT FRAM：用于数据记录的本地存储，提供非易失性存储。

  • FTDI FT231XQ USB 转 UART 转换器：提供可靠的 USB 转 UART 接口。

有关 STM32G491RE 的更多信息参见：

  • STM32G491RE on www.st.com

开发板的其他外设：

  • USB-C 连接器：用于数据传输和供电。

  • SHT45 传感器：

    • 相对湿度精度：±1.0% RH

    • 工作湿度范围：0-100% RH

    • 温度精度：±0.1 °C

    • 工作温度范围：-40 °C 至 125 °C

  • BME280 传感器：

    • 相对湿度精度：±3% RH

    • 温度精度：±1 C

    • 气压精度：±1 hPa

    • 工作温度范围：-40 °C 至 85 °C

    • 气压范围：300-1100 hPa

  • QWIIC 连接器：便于扩展外设。

  • SPI_CS2 : PB2

  • SPI_CS3 : PA7

  • SPI_2_SCK : PB13

  • SPI_2_MISO : PB14

  • SPI_2_MOSI : PB15

  • PWM_2_CH1 : PA5

  • USER_PB : PC13

  • LD2 : PA5

  • ADC1_IN1 : PA0

  • DAC1_OUT1 : PA4

  • USB_MCU_N : PA11

  • USB_MCU_P : PA12

  • SWDIO-JMTS : PA13

  • SWCLK-JTCK : PA14

  • JTDI : PA15

  • JTDO : PB3

  • JTRST : PB4

  • FRAM_WP (ACTIVE LOW) : PB11

  • FRAM_CS (ACTIVE LOW) : PB12

  • GPIO_PC10 : PC10

  • GPIO_PC11 : PC11

  • GPIO_PC12 : PC12

  • PF0_OSC : PF0

系统时钟

系统时钟可由内部或外部振荡器驱动，也可由主 PLL 时钟驱动。默认情况下，系统时钟由 170MHz 的 PLL 时钟驱动（选择了 boost 模式），而 PLL 时钟由 8MHz 高速外部振荡器（HSE）驱动。HSE 振荡器默认可工作在最高 48 MHz 的频率，但在此配置中专门设置为 8 MHz。

串口

Myra SiP 底板有 5 个 U(S)ART。Zephyr 控制台输出分配到 LPUART1，默认设置为 115200 8N1。

编程与调试

说明

可以按常规方式为 myra_sip_baseboard 开发板目标构建和烧录应用程序（详见 构建应用程序 和 运行应用程序）。

烧录

本开发板带有 USB-JTAG 接口，可与 OpenOCD 配合使用。

使用 USB 端口将 Myra SiP 底板连接到主机，然后构建并烧录应用程序。以下是 Hello World 的示例。

# From the root of the zephyr repository
west build -b myra_sip_baseboard samples/hello_world
west flash

然后运行串口主机程序（例如 picocom）连接 Myra SiP 底板：

$ picocom /dev/ttyUSB0 -b 115200

警告

本开发板只有一个端口，同时用于编程和控制台。因此建议将 CONFIG_BOOT_DELAY 设置为任意值。在设备上运行 twister 测试时，这一点尤为重要。此时还应使用 --flash-before 和 --device-flash-timeout=120 选项：

$ scripts/twister --device-testing --device-serial /dev/ttyUSB0 --device-serial-baud 115200 -p myra_sip_baseboard --flash-before --device-flash-timeout=120 -v

调试

可以按常规方式调试应用程序。以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b myra_sip_baseboard samples/hello_world
west debug
