EFR32xG27 Dev Kit (xG27-DK2602A)

Board Overview

Name:
xg27_dk2602a
Vendor:

Silicon Laboratories

Status:

Not actively maintained

Architecture:

arm

SoC:

efr32bg27c140f768im40

Browse board sources

Silicon Labs xG27-DK2602A 是一款使用 EFR32BG27 SoC 的开发套件。该套件包含 EFR32BG27 +8 dBm 开发套件板（BRD2602A）。

硬件

  • EFR32BG27 Blue Gecko 无线 SoC，工作频率最高 76.8 MHz

  • ARM® Cortex®-M33 内核，64 kB RAM 和 768 kB Flash

  • Macronix 超低功耗 8 Mbit SPI Flash（MX25R8035F）

  • 用于无线传输的 2.4 GHz 陶瓷天线

  • Silicon Labs Si7021 相对湿度和温度传感器

  • Vishay VEML6035 低功耗、高灵敏度环境光传感器

  • Silicon Labs Si7210 霍尔效应传感器

  • TDK InvenSense ICM-20689 6 轴惯性传感器

  • 一对 PDM 麦克风

  • 一个 LED 和一个按键

  • 用于超低功耗运行的电源使能信号和隔离开关

  • 板载 SEGGER J-Link 调试器，便于编程和调试，包含 USB 虚拟 COM 端口和数据包跟踪接口（PTI）

  • Mini Simplicity 连接器，用于能耗分析和高级无线网络调试

  • 用于访问 GPIO 和连接外部硬件的引出焊盘

  • 复位按键

  • CR2032 纽扣电池座和外部电池连接器

更多信息请参阅以下文档：

  • xG27 Dev Kit User's Guide

烧录

xG27 开发套件内置一个基于 EFM32GG12 微控制器的 J-Link 适配器（用户不可编程）。该适配器提供：

  • 连接 EFR32BG27 的 SWD 接口，用于烧录和调试。

  • 连接 EFR32BG27 的 SWO 跟踪接口，用于跟踪。

  • 连接 EFR32BG27 的 UART 接口，用于访问控制台。

  • 与主机的 USB 连接，提供用于访问控制台 UART 接口的 CDC-ACM 串口端点，以及用于访问 SWD 和 SWO 接口的专有 J-Link 端点。

适配器的 UART 功能可通过大多数桌面操作系统自带的标准 CDC-ACM USB 驱动和任意标准串口终端程序（例如 picocom）访问。

SWD 和 SWO 功能可通过 Simplicity Commander 访问。

烧录开发板最简单的方法是使用 West，它会以无人值守模式运行 Simplicity Commander，并向其传递所有必要的参数。

  • 如果系统中已安装 Simplicity Commander，并且 commander 可执行文件所在目录已加入 PATH 环境变量：

    west flash

  • 否则，需要指定 commander 可执行文件的完整路径：

    west flash --commander <path_to_commander_directory>/commander

  • 如果连接了多个 J-Link 适配器，必须指定用于烧录的适配器序列号：

    west flash --dev-id <J-Link serial number>

编程与调试

说明

本例使用示例应用程序 Hello World。构建 Zephyr 内核和应用程序：

# From the root of the zephyr repository
west build -b xg27_dk2602a samples/hello_world

使用 USB 端口将设备连接到主机，应该能看到一个 USB 连接。使用 west 的 flash 命令

使用以下设置打开串口终端（minicom、putty 等）：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

复位开发板，应能在对应的串口上看到以下信息：

Hello World! xg27_dk2602a
