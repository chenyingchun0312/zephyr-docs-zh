SiWx917 Wi-Fi 功能（Alpha）

概述

本文档概述 917 Wi-Fi 模块的能力和功能，重点介绍其 STA 和 Soft-AP 模式。

STA 模式功能

917 Wi-Fi 模块的 STA（Station）模式提供完善的功能，可作为客户端连接无线网络。主要功能如下：

扫描

STA 模式支持网络扫描，以识别可用的接入点：

  • 主动扫描：主动探测附近的网络。

  • 被动扫描：监听信标帧来发现网络。

  • 后台（BG）扫描：支持后台扫描，可在不中断当前连接的情况下寻找更好的接入点。

该模块一次最多支持 11 个扫描结果，可高效发现附近的接入点。

该模块只支持指定一个 SSID 用于 SSID 过滤。

设备未处于关联状态时执行主动扫描和被动扫描。

设备处于关联状态时执行 BG 扫描。

如果未提供信道，设备将扫描所有有效信道。

默认主动驻留时间为 100 ms。

默认被动驻留时间为 400 ms。

Security（安全）

该模块采用先进的安全措施，确保连接安全可靠。它支持以下安全模式：

  • Open：无加密，适用于不安全的网络。

  • WPA（Wi-Fi Protected Access）：安全性比 WEP 更高。

  • WPA2（Wi-Fi Protected Access II）：大多数网络使用的行业标准加密。

  • WPA3（Wi-Fi Protected Access III）：增强的加密，可防御现代威胁。

  • WPA2-SHA256：使用 SHA256 增强 WPA2 安全性，提高加密强度。

  • WPA3 过渡模式（WPA2+WPA3）：确保与同时使用 WPA2 和 WPA3 安全标准的网络兼容。

这些模式确保模块能够安全地连接到各种网络，同时保持强有力的数据保护。

链路模式

为了兼容各种网络，该模块支持多种 Wi-Fi 链路模式：

  • 802.11b（Wi-Fi 0 和 Wi-Fi 1）：传统模式，速率最高 11 Mbps。

  • 802.11g（Wi-Fi 3）：性能提升，速率最高 54 Mbps。

  • 802.11n（Wi-Fi 4）：借助 MIMO 技术实现高吞吐量。

  • 802.11ax（Wi-Fi 6）：新一代的效率、容量和性能。

省电

该模块实现了省电机制，以优化能耗。

它支持以下传统省电模式：

  • 基于 DTIM（Delivery Traffic Indication Message）：利用 DTIM 间隔，仅在接入点有缓存数据时唤醒，从而降低功耗。

  • 基于监听间隔：允许模块根据设定的监听间隔周期性唤醒，检查是否有数据。监听间隔以信标间隔为单位。

设备支持的（省电）监听间隔范围为 100 ms - 1000 ms。因此，监听间隔需要以信标间隔为单位进行配置。如果配置的监听间隔超过 1000 ms，则按 1000 ms 处理。基于监听间隔的唤醒在设备进入已连接状态后生效。如果监听间隔设为零，驱动会自动切换为 DTIM 唤醒。如果固件禁用了省电，则重新启用时驱动将使用之前配置的监听间隔。

此（省电）监听间隔应小于（重新）关联请求帧中通告的监听间隔。

它还支持以下模式来获取缓存的数据包：

  • PS-Poll（省电轮询）：使设备在进入省电模式后能够从接入点获取缓存的数据包。

  • QoS Null Data：允许设备发送 QoS Null 帧，以节能的方式从接入点获取缓存的数据包。

为提升性能，设备默认启用其专有的 Enhanced Max PSP 功能来获取缓存的数据包。

如果通过关闭配置标志 CONFIG_WIFI_SILABS_SIWX91X_ENHANCED_MAX_PSP 禁用此功能，则会启用 QoS Null 帧。QoS Null 帧和 Enhanced Max PSP 互斥。

断开连接后，PS 会被禁用，因此如有需要，必须为新连接重新启用 PS。

监视间隔（Monitor Interval）定义为距最后一次收到数据包（ACK 除外）的时间。如果在此间隔内没有收到数据包，设备将进入睡眠。如果配置为 0，监视间隔的默认值为 50 ms。该参数用于 QoS Null Data 或 Enhanced Max PSP。设备支持的监视间隔最大值为 1000 ms。

目前设备不支持 timeout_ms。

管理帧保护

对 802.11w 的支持可以保护管理帧，防御以下攻击：

  • 解除认证（Deauthentication）攻击。

  • 解除关联（Disassociation）攻击。

802.11w 默认启用。

BG 扫描和漫游

漫游使 Wi-Fi STA（Station）能够在同一网络内从一个接入点（AP）无缝切换到另一个接入点而不断开连接。这样，STA 在不同 AP 覆盖区域之间移动时可以保持连接不中断。

设备支持 传统漫游，包括以下过程：

  1. Background (BG) Scan:

    • 在 STA 保持连接到网络的情况下执行的标准扫描过程。

    • 当接收信号强度指示（RSSI）低于预定义阈值时触发。

  2. Roaming:

    • 当 RSSI 越过阈值且满足漫游迟滞条件时启动。

    • 漫游过程可以使用 NDP（Null Data Packet） 或 解除认证帧 完成。默认配置为使用 NDP。可以通过 Kconfig CONFIG_WIFI_SILABS_SIWX91X_ROAMING_USE_DEAUTH 更改配置，改用解除认证帧进行漫游。

Challenges:

  • Zephyr API 目前没有为传统漫游提供 API。虽然定义了 802.11r 漫游 的 API，但它们不适用于传统漫游。

Current Design:

  • BG 扫描：使用扫描 API 执行。BG 扫描期间会忽略扫描 API 中的信道参数。BG 扫描使用的信道来自第一次前台扫描。

  • 漫游配置：在第一次 BG 扫描期间配置。漫游参数通过 Kconfig 选项管理。

漫游默认启用，但需要执行 BG 扫描来启动并配置漫游参数。可以通过关闭配置标志 WIFI_SILABS_SIWX91X_ENABLE_ROAMING 禁用漫游。

STA 断开连接时 BG 扫描会停止。需要再次下发 BG 扫描命令才能启用 BG 扫描和漫游。

设备在 BG 扫描中支持多探测（multi-probe），也可以扫描 SSID 不同的 AP。可以使用 Kconfig 禁用此配置。

目标唤醒时间（TWT）

该模块支持符合 Wi-Fi 6 标准的 单独目标唤醒时间（Individual TWT）：

  • 单独 TWT：允许模块与接入点协商唤醒时间，优化设备功耗。仅支持作为请求方。

  • 不支持广播 TWT。

此功能非常适合需要以最低能耗周期性联网的 IoT 设备。

设备不支持显式 TWT（Explicit TWT），也不支持 TWT 信息元素。

设备不支持 TWT 快速设置，也不支持配置 TWT 间隔、TWT 提前唤醒时长和对话令牌等参数。

缺陷与限制

  • 对于 WPA3（SAE），设备的密码长度限制为 64 个字符。

  • 不支持 EAP 安全模式。

  • 设备仅支持 20 MHz 带宽和 1 个空间流。

  • 不支持 802.11r。

  • 不支持 WMM 省电模式。

  • 对于 Wi-Fi 状态（wifi_iface_status），即使 AP 不支持 TWT，twt_capable 字段也可能被设为 true。当连接处于 802.11ax 模式但 AP 禁用了 TWT 时，就会出现这种情况。

Soft-AP 模式功能

在 Soft-AP（软件接入点）模式下，917 Wi-Fi 模块可以充当接入点，允许其他设备连接。主要功能如下：

Security（安全）

该模块为连接到 Soft-AP 的设备提供安全连接。它支持以下安全模式：

  • Open：无加密，适用于不安全的网络。

  • WPA（Wi-Fi Protected Access）：安全性比 WEP 更高。

  • WPA2（Wi-Fi Protected Access II）：大多数网络使用的行业标准加密。

  • 混合模式（WPA+WPA2）：确保与同时使用 WPA 和 WPA2 安全标准的网络兼容。

这些模式为连接到 Soft-AP 的设备提供了灵活的配置。

链路模式

Soft-AP 模式支持以下链路模式：

  • 802.11b（Wi-Fi 0 和 Wi-Fi 1）：用于基本连接的传统模式。

  • 802.11g（Wi-Fi 3）：为现代设备提供更高速率。

  • 802.11n（Wi-Fi 4）：为高要求应用提供高速连接。

隐藏 SSID

允许不广播网络名称（SSID）。这可以防止未授权用户看到 SSID，从而增强隐私。

缺陷与限制

  • 设备仅支持 20 MHz 带宽和 1 个空间流。

  • 虽然 STA 和 BLE 可以同时共存，但 AP 和 BLE 不能同时工作。

通用功能

监管域

SiWx91x 驱动支持监管域配置，在 STA 和 Soft-AP 模式下强制执行特定地区的信道和发射功率限制。

  • 国家代码值遵循 ISO/IEC 3166-1 alpha-2（例如 US、IN、FR）。

  • 驱动将支持的国家代码映射为 SiWx91x 固件的地区标识符。

  • 支持的地区包括：EU、CN、KR、JP 和 US。

  • 驱动默认使用 US 监管域。

备注

必须在激活设备（扫描、连接或启动 Soft-AP）之前 配置监管域。这样可以确保只使用允许的信道和发射功率等级。

如果请求的国家代码不受支持，驱动会回退到默认监管域（US）。

最大发射功率

驱动支持在 STA 和 Soft-AP 模式下配置最大发射（TX）功率。该设置定义射频输出功率的上限，同时受硬件和法规限制约束。

  • 通过设备树属性进行配置。

  • 如果未指定，默认最大 TX 功率为 31 dBm。

设备树属性

  • wifi-max-tx-pwr-scan Wi-Fi 扫描期间使用的最大 TX 功率（单位 dBm）。仅适用于 STA 模式。

  • wifi-max-tx-pwr-join 加入 Wi-Fi 网络时使用的最大 TX 功率（单位 dBm）。

备注

SiWx91x 固件不支持按速率控制 TX 功率。

RTS 阈值

驱动支持配置 RTS（Request to Send）阈值，帧长度超过该阈值时启用 RTS/CTS 握手。

  • 有效范围：0 到 2347 字节。

  • 值为 0 表示每个发送的帧之前都会先发送一个 RTS 帧。

  • 默认 RTS 阈值为 2346 字节。
