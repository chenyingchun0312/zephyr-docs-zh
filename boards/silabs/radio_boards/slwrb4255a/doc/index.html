EFR32FG13 2400/915 MHz 19 dBm Dual Band (SLWRB4255A)

Board Overview

Name:
slwrb4255a
Vendor:

Silicon Laboratories

Status:

Not actively maintained

Architecture:

arm

SoC:

efr32fg13p233f512gm48

Browse board sources

概述

EFR32FG13P Flex Gecko 2.4 GHz 和 915 MHz 无线电板作为 standalone Proprietary Wireless radio board 提供。它搭载一颗 EFR32FG13P 无线 SoC，基于 ARM Cortex®-M4F 处理器，具有出色的低功耗性能。

BRD4255A（又称 SLWRB4255A）无线电板插在 Wireless Starter Kit 主板 BRD4001A 上使用，作为 无线电板（Radio Board） 之一受到支持。

硬件

  • EFR32FG13P233F512GM48 Flex Gecko SoC

  • CPU 内核：带 FPU 的 ARM Cortex®-M4

  • Flash 存储器：512 kB

  • RAM: 64 kB

  • 发射功率：最高 19 dBm

  • 工作频率：2.4 GHz、915 MHz

  • 用于 LFXO（32.768 kHz）和 HFXO（38.4 MHz）的晶体。

有关 EFR32FG13 SoC 和 BRD4255A 开发板的更多信息，请参阅以下文档：

  • EFR32FG13 Website

  • EFR32FG13 Datasheet

  • EFR32xG13 Reference Manual

  • BRD4255A Reference Manual

系统时钟

EFR32FG13P SoC 配置为使用板上的 38.4 MHz 外部振荡器。

串口

EFR32FG13P SoC 有三个 USART 和一个低功耗 UART（LEUART）。USART0 连接到板载控制器，用作控制台。

烧录

使用 USB 端口将装有 BRD4255A 无线模块的 BRD4001A 板连接到主机。

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b slwrb4255a samples/hello_world
west flash

使用以下设置打开串口终端（minicom、putty 等）：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

复位开发板，终端中应显示以下信息：

Hello World! slwrb4255a
