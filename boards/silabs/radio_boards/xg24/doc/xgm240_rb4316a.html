xGM240P 10 dBm Module Radio Board (xGM240-RB4316A)

Board Overview

Name:
xgm240_rb4316a
Vendor:

Silicon Laboratories

Status:

Not actively maintained

Architecture:

arm

SoC:

mgm240pb22vna

Browse board sources

概述

适用于 xGM240P 模块的 xGM240P +10 dBm Module Radio Board 搭载一颗 EFR32MG24 系列无线片上系统，基于 ARM Cortex®-M33 处理器，具有出色的低功耗性能。

该射频板插在 Wireless Pro Kit Mainboard BRD4002A 上使用，在 Zephyr 中作为 无线电板（Radio Board） 之一获得支持。

硬件

  • 基于 EFR32MG24 的 MGM240PB32VNA 模组

  • CPU 内核：带 FPU 的 ARM Cortex®-M33

  • Flash 存储器：1536 kB

  • RAM: 256 kB

  • 发射功率：最高 +10 dBm

  • 工作频率：2.4 GHz

  • 开发板上的 LFXO 晶振（32.768 kHz）和模组内的 HFXO 晶振（39 MHz）。

有关 MGM240P 模块、EFR32MG24 SoC 和 BRD4316A 开发板的更多信息，请参阅以下文档：

  • MGM240 Modules Website

  • MGM240P Datasheet

  • EFR32xG24 Reference Manual

  • BRD4316A User Guide

系统时钟

MGM240P 模组配置为使用 78 MHz 的 HFRCODPLL 振荡器作为系统时钟，并锁定到开发板上的 39 MHz 外部晶体振荡器。

串口

MGM240P 模组有一个 USART 和两个 EUSART。USART0 连接到板载控制器，用作控制台。

按键和 LED

本开发板有两个按键和两个 LED，它们共用 GPIO 引脚。如果应用程序要同时使用编号相同的按键和 LED（例如按键 0 和 LED 0），需要对这两种功能进行分时复用。

烧录

通过 USB 端口将装有 BRD4186C 射频板的 BRD4002A 开发板连接到主机。

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b xgm240_rb4316a samples/hello_world
west flash

使用以下设置打开串口终端（minicom、putty 等）：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

复位开发板，终端中应显示以下信息：

Hello World! xgm240_rb4316a

蓝牙

要使用蓝牙功能，请运行以下命令，从 Silicon Labs HAL 仓库获取所需的二进制 blob。

west blobs fetch hal_silabs

然后使用以下命令构建 Zephyr 内核和一个蓝牙示例。本例使用 Observer 示例应用程序。

# From the root of the zephyr repository
west build -b xgm240_rb4316a samples/bluetooth/observer
