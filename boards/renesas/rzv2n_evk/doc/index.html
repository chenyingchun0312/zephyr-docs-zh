RZ/V2N Evaluation Board Kit

Board Overview

Name:
rzv2n_evk
Vendor:

Renesas Electronics Corporation

Status:

Not actively maintained

Architecture:

arm

SoC:

r9a09g056n48gbg

Browse board sources

概述

RZ/V2N 是一款视觉 AI 微处理器（MPU），搭载 Renesas 专有的 AI 加速器（DRP-AI3），AI 性能最高可达 15TOPS。其 CPU 为四核 Arm Cortex-A55（1.8GHz）和 Arm Cortex-M33（200MHz）。RZ/V2N 配备 ISP（图像信号处理器）和双通道 MIPI CSI-2 摄像头接口，支持双摄像头信号处理，这对实现视觉系统至关重要。它还配备 PCIe 和 USB 3.2 等高速接口，便于扩展外部设备。RZ/V2N 非常适合同时需要低功耗和高级 AI 推理的应用，例如 DMS（驾驶员监控系统）、监控摄像头、移动机器人等。

  • RZ/V2N 评估板（CPU 板）：

    • CPU: RZ/V2N

    • PMIC: RAA215300

    • 时钟发生器：5L35023B

    • 主存储器：LPDDR4X 8GB x1

    • xSPI Flash 存储器：64MB

    • 外部存储器：microSD x1

    • 用于子板的板对板连接器

    • 高速接口： * 千兆以太网 x2 端口 * USB 3.2 Gen2 x1 通道（仅 Host） * USB 2.0 x1 通道（OTG） * PCIe Gen3 x1 通道（最多 2 lane） * MIPI CSI-2 x2 通道 * MIPI DSI x 1 通道 * GPIO：86 个引脚

  • RZ/V2H-EVK 扩展板（EXP 板）：与 RZ/V2H 共用

    • HDMI Tx x1ch

    • 音频辅助输入接口 x1 通道

    • 音频麦克风输入接口 x1 通道

    • 音频耳机输出接口 x1 通道

    • Pmod 接口 x4

连接与 IO

默认情况下，本开发板配置为配合以下设备使用：

SCI_UART

  • SCI_UART0:

    • TX = Pmod 3A 引脚 2

    • RX = Pmod 3A 引脚 3

LED

  • LED5（黄色）= P0_0

  • LED6（黄色）= P0_1

编程与调试（M33）

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

rzv2n_evk 开发板的应用程序可以按照 构建应用程序 中描述的常规方式构建。

Console

将 Pmod USBUART 连接到 PMOD Type 3A 的上排，即可访问 Cortex-M33 系统内核的 UART 端口。

调试

可以使用 JLink 调试器（J-Link 调试主机工具），在本开发板的 Cortex-M33 系统内核上从内部 SRAM 加载并执行 Zephyr 应用程序二进制文件。

以下以 Hello World 应用程序为例，演示构建和调试。

# From the root of the zephyr repository
west build -b rzv2n_evk/r9a09g056n48gbg/cm33 samples/hello_world
west debug

烧录

RZ/V2N-EVK 设计为在不同内核上启动不同的系统。它使用 Yocto 作为构建系统来构建 Linux 系统和引导加载程序，并通过 u-boot 在 Cortex-M33 上运行 Zephyr。最少步骤如下。

  1. 从 RZ/V2N Group Handbook [1] 下载 Multi-OS Package

  2. 解压 Multi-OS Package，然后打开“r01qs0078ej****-rzv2n-multi-os-pkg”PDF 文件。

  3. 按照“3.2 Integration of OpenAMP related stuff”构建 RZ/V2N AI SDK 源代码。在 meta-rz-features/meta-rz-multi-os/meta-rzv2n/conf/layer.conf 中取消注释以下几行。

#MACHINE_FEATURES_append = " RZV2N_CM33_BOOT"
MACHINE_FEATURES_append = " SRAM_REGION_ACCESS"
#MACHINE_FEATURES_append = " CM33_FIRMWARE_LOAD"
#MACHINE_FEATURES_append = " CA55_CPU_CLOCKUP"

以下必需的产物将位于 build/tmp/deploy/image 中

构建产物

引导加载程序

bl2_bp_spi-rzv2n-evk.srec

fip-rzv2n-evk.srec

SD 卡镜像

  1. 执行 Step 7 Deploy AI Application [2] 中“1-B Write the Linux files to SD card”的第 1-9 步，准备 SD 卡。

  2. 运行以下命令将 zephyr.bin 写入 SD 卡。

$ sudo mkdir /mnt/sd -p
$ sudo mount /dev/sdb2 /mnt/sd
$ sudo cp /path/to/zephyr.bin /mnt/sd/boot
$ sync
$ sudo umount /mnt/sd

警告

将 /dev/sdb 改为你的 microSD 卡设备名。可使用 dh -h 查看。

  1. 将 SD 卡插入 RZ/V2N EVK 的 SD1，并将开发板设为 eSD 模式（DSW1[4:5] = ON, OFF）。

  2. 小心地给开发板上电，参见 Getting Started with Flexible Software Package [3] 中的“3.3.2.4 Power Supply”。随后，在与 RZ/V2N EVK 的 CN12 相连的控制台上应能看到以下信息。

U-Boot 2021.10 (Sep 19 2024 - 10:13:55 +0000)

DRAM:  7.9 GiB
MMC:   mmc@15c00000: 0, mmc@15c10000: 1
Loading Environment from SPIFlash...

OK

  1. 在 3 秒内按任意键以停止自动启动。

  2. 按如下方式设置 u-boot 以启动 CM33 内核。

=> setenv cm33start 'dcache off
=> mw.l 0x10420D2C 0x02000000
=> mw.l 0x1043080c 0x08003000
=> mw.l 0x10430810 0x18003000
=> mw.l 0x10420604 0x00040004
=> mw.l 0x10420C1C 0x00003100
=> mw.l 0x10420C0C 0x00000001
=> mw.l 0x10420904 0x00380008
=> mw.l 0x10420904 0x00380038
=> ext4load mmc 0:2 0x08003000 boot/zephyr.bin
=> mw.l 0x10420C0C 0x00000000
=> dcache on'
=> saveenv
=> run cm33start
