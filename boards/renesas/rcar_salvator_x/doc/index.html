R-Car Salvator-X

Board Overview

Name:
rcar_salvator_x
Vendor:

Renesas Electronics Corporation

Status:

Not actively maintained

Architecture:

arm

SoC:

r8a77951

Browse board sources

概述

  • H3 Salvator-X 开发板用于评估 Renesas Electronics R-CAR H3 器件的功能和性能，也用于为 R-CAR H3 开发和评估应用软件。

  • H3 Salvator-X 基于 R-CAR H3 SIP，配备 4GB LPDDR4（2 通道，每通道 64 位宽）和 64MB Hyperflash、CSI2 接口以及 USB、以太网、HDMI 等多种通信接口。它可以独立工作，也可以通过底部的 440 针连接器与其他开发板配合使用。

有关 H3 SoC 的更多信息，参见 Renesas R-Car H3 chip

硬件

H3 Salvator-X 的硬件功能参见 eLinux H3 Salvator-X page。

备注

Zephyr 将在专供 RTOS 使用的 CR7 处理器上启动。

有关该开发板的更多信息，参见 Renesas R-Car Development Support website。

连接与 IO

GPIO

在 H3 Salvator-X 上运行 Zephyr 时，软件可读按键 “SW20”、“SW21”、“SW22” 可用作输入，软件可控 LED “LED4”、“LED5”、“LED6” 可用作输出。

UART

Salvator-X 开发板提供两个串口：

  • 一个供 A53/A57 处理器使用

  • 另一个供 CR7 使用

两个串口都通过 CP2102 转换器转为 USB，引出方式如下：

处理器

A53/A57

CN26

CR7

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

支持的调试探针

"Olimex ARM-USB-OCD-H" 探针是唯一官方支持的探针。Zephyr SDK 附带的 OpenOCD 支持该探针。

"Olimex ARM-USB-OCD-H" 调试探针需要连接到 Salvator-X 上的 CN1。

配置控制台

用 USB 线将 PC 连接到 CN25 和/或 CN26，然后在你选用的串口终端（minicom、putty 等）中使用以下设置：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

烧录

首先，打开串口终端。

rcar_salvator_x 开发板配置的应用程序可以按常规方式构建（详见 构建应用程序）。

# From the root of the zephyr repository
west build -b rcar_salvator_x samples/hello_world
west flash

终端中应显示以下信息：

*** Booting Zephyr OS build v2.6.0-rc1 ***
Hello World! rcar_salvator_x

调试

首先，打开串口终端。

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b rcar_salvator_x samples/hello_world
west debug

随后即可进入 GDB 会话进行调试。

继续运行应用程序后，终端中应显示以下消息：

*** Booting Zephyr OS build v2.6.0-rc1 ***
Hello World! rcar_salvator_x
