R-Car H3ULCB

Board Overview

Name:
rcar_h3ulcb
Vendor:

Renesas Electronics Corporation

Status:

Not actively maintained

Architecture:

arm, arm64

SoC:

r8a77951

Browse board sources

概述

R-Car H3ULCB 入门套件开发板基于 R-Car H3 SoC，具备新一代车载导航系统的基本功能。该 SoC 由四核 Cortex®-A57 集群、四核 Cortex®-A53 集群和双核锁步 Cortex®-R7 组成。

Cortex®-A 内核和 Cortex®-R7 内核均支持 Zephyr OS。

有关 H3 SoC 的更多信息，参见 Renesas R-Car H3 chip。

硬件

  • H3ULCB 特性：

    • 存储：

      • 384KB 系统 RAM

      • 4/8 GB LPDDR4

      • 64 MB HYPER FLASH (512 MBITS, 160 MHZ, 320 MBYTES/S)

      • 16MB QSPI FLASH (128 MBITS,80 MHZ,80 MBYTES/S)1 HEADER QSPI MODULE

      • 8/32/64/128 GB EMMC (HS400 240 MBYTES/S)

      • MICROSD-CARD SLOT (SDR104 100 MBYTES/S)

    • 连接器

      • CN1 COM Express 型连接器，440 针

      • CN2 QSPI Flash 模块

      • CN3 DEBUG JTAG

      • CN4 HDMI (HDMI-0)

      • CN5 USB 2.0 (USB2.0-1)

      • CN6 推推式 microSD 卡座（SDHI-0）

      • CN7 以太网连接器，RJ45

      • CN8 LINE Out

      • CN9 麦克风输入

      • CN10 调试串口（未焊接）

      • CN11 CPLD 编程 JTAG

      • CN12 调试串口（串行）

      • CN13 主电源输入（5VDC）

      • CN14 CPU Fan

    • 输入

      • SW1 Hyper Flash 开关

      • SW2 软件可读 DIP 开关（4 个）

      • SW3 软件可读按键

      • SW4 软件可读按键

      • SW5 软件可读按键

      • SW6 模式设置

      • SW7 CPLD 复位

      • SW8 电源

      • SW9 复位

    • 输出

      • LED1 HDMI / 热插拔同步检测

      • LED4 软件可控 LED

      • LED5 软件可控 LED

      • LED6 软件可控 LED

      • LED9 5V 主电源

      • LED14 备用 LED

      • LED15 系统复位

H3ULCB 开发板的完整功能列表参见该开发板的 eLinux H3SK page。

有关该开发板的更多信息，参见 Renesas R-Car Starter Kit website。

GPIO

在 H3ULCB 上运行 Zephyr 时，软件可读按键 “SW3” 可用作输入，软件可控 LED “LED5” 可用作输出。

I2C

H3ULCB 开发板提供两条 I2C 总线。遗憾的是，无法通过连接器直接访问这些总线。

I2C 主要用于管理 H3ULCB 和 Kingfisher 子板上的多个板载芯片并为其上电。

目前尚不支持板载 I2C 器件和 I/O 扩展器。因此，当前的 I2C 支持暂时无法向用户提供任何器件。

PWM

ULCB 开发板提供一个 PWM 控制器，最多 7 个通道 [0..6]。H3ULCB 只通过测试引脚 CP8 提供 pwm0。

插接到 Kingfisher 子板上时，CN7 LVDS 连接器上可以使用 pwm4 通道。

烧录

编程与调试（R7）

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

支持的调试探针

"Olimex ARM-USB-OCD-H" 探针是唯一官方支持的探针。Zephyr SDK 附带的 OpenOCD 支持该探针。

"Olimex ARM-USB-OCD-H" 调试探针需要通过 SICA20I2P 适配器连接到 H3ULCB 上的 CN3。

备注

如果 JTAG 遇到问题，请参见 eLinux Kingfisher page 中的 "Known issues" 一节。

配置控制台

用 USB 线将 PC 连接到 Kingfisher 子板的 CN04。

在你选用的串口终端（minicom、putty 等）中使用以下设置：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

烧录

首先，打开串口终端。

rcar_h3ulcb/r8a77951/r7 开发板配置的应用程序可以按常规方式构建（详见 构建应用程序）。

# From the root of the zephyr repository
west build -b rcar_h3ulcb/r8a77951/r7 samples/hello_world
west flash

终端中应显示以下信息：

*** Booting Zephyr OS build v2.6.0-rc1 ***
Hello World! rcar_h3ulcb

调试

首先，打开串口终端。

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b rcar_h3ulcb/r8a77951/r7 samples/hello_world
west debug

随后即可进入 GDB 会话进行调试。

继续运行应用程序后，终端中应显示以下消息：

*** Booting Zephyr OS build v2.6.0-rc1 ***
Hello World! rcar_h3ulcb
