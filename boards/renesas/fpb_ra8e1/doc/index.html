Fast Prototyping Board for RA8E1 MCU Group

Board Overview

Name:
fpb_ra8e1
Vendor:

Renesas Electronics Corporation

Status:

Not actively maintained

Architecture:

arm

SoC:

r7fa8e1afdcfb

Browse board sources

概述

FPB-RA8E1 是 RA8E1 MCU 组的快速原型开发板。用户可以借助它全面评估 RA8E1 MCU 组的各项特性，并使用 Flexible Software Package（FSP）和 e2 studio IDE 开发嵌入式系统应用。用户可以结合板载功能，以及自行选择的主流生态系统扩展组件，将创意变为现实。

该系列 MCU 采用带 HeliumTM 的高性能 Arm® Cortex®-M85 内核，主频最高 360 MHz，具有以下特性：

  • 1 MB 代码 Flash 存储器

  • 544 KB SRAM（32 KB TCM RAM，512 KB 用户 SRAM）

  • 八线串行外设接口（OSPI）

  • 以太网 MAC 控制器（ETHERC）、USBFS

  • 模拟外设

  • 安全和功能安全特性

FPB-RA8E1 包装盒内包括以下组件：

  • FPB-RA8E1 v1 开发板

  • FPB-RA8E1 v1 快速入门指南

CPU 板的规格如下：

MCU specifications

  • 基于 360 MHz Arm® Cortex®-M85 内核的 RA8E1 MCU，144 引脚，LQFP 封装

  • ROM/SRAM 容量：1MB/512KB

  • MCU 输入时钟：20MHz（由外部晶体振荡器产生）

  • 电源：DC 5V，自动从以下方式中选择一种：

    • 由调试 USB 连接器（J10）供电

    • 由外部 5V 输入（J60 或经 TP7/TP9）供电

Connector

  • 两个 Digilent Pmod™ 连接器（Pmod 1 为 SPI、I2C 和 UART，Pmod 2 为 SPI/UART）

  • Arduino™（UNO R3）连接器

  • JTAG/SWD 连接器

  • 调试用 USB-C 连接器

  • 外部 +5 V 电源连接器（J60）

  • 实时时钟备用电池连接器

  • 20 针摄像头接口连接器

Onboard debugger

本产品带有板载调试电路 J-Link On-Board（以下简称“J-Link-OB”）。写入程序时，用 USB 线将 CPU 板连接到 PC。J-Link-OB 作为与 J-Link 等效的调试器工作。如果从 Flash 编程工具（例如 SEGGER 的 J-Flash Lite）连接，请将调试器（工具）类型设为“JLink”

硬件

RA8E1 MCU 组的详细硬件特性参见：

  • RA8E1 MCU 组：RA8E1 Group User's Manual Hardware

  • FPB-RA8E1 开发板：FPB-RA8E1 - User's Manual

编程与调试

说明

fpb_ra8e1 开发板的应用程序可以按常规方式构建、烧录和调试。有关构建和运行的更多信息，参见 构建应用程序 和 运行应用程序。

配置调试探针

FPB-RA8E1 开发板带有板载 SEGGER J-Link 调试器。SEGGER J-Link 驱动可从 https://www.segger.com/downloads/jlink 下载

要使用板载 J-Link 调试器，请确保：

  1. J-Link OB 通过 USB 端口（J10）连接到主机 PC。

  2. J-Link OB 跳线采用 FPB-RA8E1 - User's Manual 中所述的默认配置。

配置控制台

用 USB 线将 PC 连接到板载虚拟 COM 端口（J10），然后使用任意串口终端（minicom、PuTTY 等），设置如下：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

烧录

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b fpb_ra8e1 samples/hello_world
west flash

打开串口终端，复位开发板（按下复位开关 S2），终端中应显示以下信息：

***** Booting Zephyr OS v4.3.0-xxx-xxxxxxxxxxxxx *****
Hello World! fpb_ra8e1

调试

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b fpb_ra8e1 samples/hello_world
west debug

打开串口终端，在调试器中单步执行应用程序，终端中应显示以下信息：

***** Booting Zephyr OS v4.3.0-xxx-xxxxxxxxxxxxx *****
Hello World! fpb_ra8e1
