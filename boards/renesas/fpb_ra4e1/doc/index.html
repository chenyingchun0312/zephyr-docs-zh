RA4E1 Fast Prototyping Board

Board Overview

Name:
fpb_ra4e1
Vendor:

Renesas Electronics Corporation

Status:

Not actively maintained

Architecture:

arm

SoC:

r7fa4e10d2cfm

Browse board sources

概述

Renesas RA4E1 组使用 Arm® Cortex®-M33 内核，CPU 性能最高 100 MHz，具有 512 KB 代码 Flash 存储器、8 KB 数据 Flash 存储器和 128 KB SRAM。RA4E1 MCU 性能领先。RA4E1 组提供丰富的外设，包括 USB 2.0 全速、Quad SPI 和高级模拟功能。

该系列 MCU 集成了主频最高 100 MHz 的高性能 Arm Cortex®-M33 内核，具有以下特性：

MCU Native Pin Access

  • R7FA4E10D2CFM MCU（下文称 RA MCU）

  • 100 MHz Arm® Cortex®-M33 内核

  • 512 KB 代码 Flash、8 KB 数据 Flash、128 KB SRAM

  • 64 引脚，LQFP 封装

  • 通过 2 个 50 针公头排针直接访问引脚（未安装）

  • MCU 电流测量点，用于精确测量电流消耗

  • 多个时钟源：RA MCU 内部提供低精度（约 1%）时钟。另外还提供 RA MCU 振荡器和副时钟振荡器晶振，提供精确的 24.000 MHz（未焊接）和 32,768 Hz 参考时钟

System Control and Ecosystem Access

  • 两种 5 V 输入电源

    • USB（调试，全速）

    • 外部电源（使用 2 针排针）（未安装）

  • 内置 SEGGER J-Link Emulator On-Board 编程器/调试器（SWD）

  • 用户 LED 和按键

    • 两个用户 LED（绿色）

    • 电源 LED（绿色，未焊接），指示稳压电源是否可用

    • 调试/电源 LED（黄色），指示电源和调试连接状态

    • 一个用户按键

    • 一个复位按键

  • 两种流行的生态系统扩展接口

    • 两个 Digilent PmodTM（SPI、UART）连接器（未焊接）

    • ArduinoTM（Uno R3）连接器

  • MCU 启动配置跳线（未安装）

说明

fpb_ra4e1 开发板的应用程序可以按常规方式构建、烧录和调试。有关构建和运行的更多信息，参见 构建应用程序 和 运行应用程序。

烧录

可以通过板载 SEGGER J-Link 调试器将程序烧录到 FPB-RA4E1。SEGGER J-Link 驱动可从 https://www.segger.com/downloads/jlink/ 下载

将程序烧录到开发板

  1. 通过 USB 端口将 J-Link OB 连接到主机 PC

  2. 确保 J-Link OB 跳线采用 FPB-RA4E1 - User's Manual 中所述的默认配置

  3. 执行 west 命令

    west flash -r jlink

调试

可以使用 Segger Ozone（Segger Ozone Download）作为可视化调试界面

下载并安装后，打开 Segger Ozone，按如下方式配置调试工程：

  • 目标器件：R7FA4E10D

  • Target Interface（目标接口）：SWD

  • Target Interface Speed（目标接口速度）：4 MHz

  • Host Interface（主机接口）：USB

  • 程序文件：<path/to/your/build/zephyr.elf>

注意： 已验证可在 Segger Ozone v3.30d 上正常调试，请使用该版本或更高版本的 Segger Ozone
