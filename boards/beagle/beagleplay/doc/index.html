BeaglePlay

Board Overview

Name:
beagleplay
Vendor:

BeagleBoard.org Foundation

Status:

Not actively maintained

Architecture:

arm

SoC:

am6254, cc1352p7

Browse board sources

概述

BeagleBoard.org BeaglePlay 是一款开源硬件单板计算机，基于 TI Sitara AM6254 四核 ARM Cortex-A53 SoC，并配有一颗外部 TI SimpleLink 多标准 CC1352P7 无线 MCU，提供远距离、低功耗的连接能力。

硬件

  • 处理器

    • TI Sitara AM6254 SoC

      • 4 个 ARM Cortex-A53

      • ARM Cortex-R5

      • ARM Cortex-M4

      • 双核 32 位 RISC 可编程实时单元（PRU）

    • TI SimpleLink CC1352P7 无线 MCU

      • ARM Cortex-M4F 可编程 MCU

      • ARM Cortex-M0+ 软件定义无线电处理器

  • 内存

    • 2GB DDR4

    • 16GB eMMC Flash 存储器

    • I2C EEPROM

  • 有线连接

    • 千兆以太网（RJ45）

    • 单对以太网，带 5V/250mA PoDL 输出（RJ11）

    • HDMI

    • USB Type-A 接口（主机）

    • USB Type-C 接口（设备/供电）

  • 无线连接

    • TI WL1807 2.4GHz/5GHz WiFi

    • 通过 CC1352P7 提供 BLE/SubG

  • 扩展

    • mikroBUS

    • Grove

    • QWIIC

BeaglePlay 的 ARM Cortex-A53 CPU 通常运行 Linux，而 CC1352P7 Cortex-M4 通常运行 Zephyr。

说明

烧录

CC1352P7

烧录时，先禁用占用串口的现有驱动，然后使用定制的 BSL Python 脚本。

  1. 确保 bcfserial 或 gb-beagleplay 驱动没有占用串口。可以加载 :file: /overlays/k3-am625-beagleplay-bcfserial-no-firmware.dtbo，或选择禁用 bcfserial/gb-beagleplay 的 uboot 启动项来实现。

  2. 现在重启开发板。

    sudo shutdown -r now

  3. 如果尚未安装 CC1352-flasher，请先安装

    if ! command -v cc1352_flasher &> /dev/null; then pip install cc1352-flasher; fi

  4. 烧录 CC1352P7

    west flash

M4F 内核

本开发板通过 OpenAMP 资源表支持 remoteproc。

测试时需要将二进制文件复制到 SD 卡，以便 A53 内核在启动时通过 remoteproc 加载它。

要测试 M4F 内核，可使用以下命令构建 Hello World 示例。

# From the root of the zephyr repository
west build -b beagleplay/am6254/m4 samples/hello_world

该命令会构建程序，生成的二进制文件位于 build/zephyr 目录下，名为 zephyr.elf。

现在将该二进制文件复制到 SD 卡的 /lib/firmware 目录中，并命名为 am62-mcu-m4f0_0-fw。

# Mount the SD card at sdcard for example
sudo mount /dev/sdX sdcard
# copy the elf to the /lib/firmware directory
sudo cp --remove-destination zephyr.elf sdcard/lib/firmware/am62-mcu-m4f0_0-fw

现在可以使用该 SD 卡进行引导。启动时，二进制文件将被加载到 M4F 内核上。

该二进制文件运行后会向 MCU_UART0 端口打印 Hello world。

调试

CC1352P7

调试时可以使用串口或 JTAG。可以通过开发板上的 Tag-Connect 排针使用 OpenOCD。

  • Tagconnect JTAG

M4F 内核

本开发板支持从运行 Linux 的 A53 内核调试 M4 内核。由于目标需要超级用户权限，目前需要单独启动 OpenOCD：

sudo openocd -f board/ti_am625_swd_native.cfg

开始调试

west build -b beagleplay/am6254/m4
west debug
