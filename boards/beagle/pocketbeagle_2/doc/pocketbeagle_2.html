PocketBeagle 2

Board Overview

Name:
pocketbeagle_2
Vendor:

BeagleBoard.org Foundation

Status:

Not actively maintained

Architecture:

arm, arm64

SoC:

am6232, am6254, mspm0l1105

Browse board sources

概述

PocketBeagle 2 是一个由 TI AM6254 SoC 驱动的计算平台。

（注意：Rev A0 使用 TI AM6232 SoC，现已停产。Rev A1 使用 TI AM6254 SoC。）

详情请参阅 PocketBeagle 2 Product Page。

硬件

PocketBeagle 2 搭载 TI AM62x SoC，该 SoC 以 Arm Cortex-A53 多核集群为核心，配有 Arm Cortex-M4F 微控制器、Imagination Technologies AXE-1-16 图形处理器，以及 TI 可编程实时单元子系统微控制器集群协处理器。

此外，PocketBeagle 2 还包含一颗 MSPM0L1105 SoC，用作 EEPROM 和 ADC。

Zephyr 可以运行在：

  • AM62x 上的 Arm Cortex-A53 内核，

  • AM62x 上的 Arm Cortex-M4F 内核，以及

  • MSPM0L1105 上的 Arm Cortex-M0+ 内核。

目前支持的 PocketBeagle 2 版本：

  • A0：搭载 SoC AM6232，已停产。

  • A1：搭载 SoC AM6254

支持的功能

pocketbeagle_2 开发板支持下列硬件功能。

说明

The list of supported hardware features was not generated. Run a full documentation build for the required metadata to be available.

设备

系统时钟

本开发板配置使用 400 MHz 的系统时钟频率。

DDR RAM

此开发板有 512MB DDR RAM 可用。此开发板配置为 Zephyr 分配 4kB RAM（仅用于资源表：0x9CC00000 至 0x9CC00400）。

串口

A53 内核

本开发板配置使用 MAIN 域 UART（MAIN_UART6，即调试端口）作为唯一的串行通信通道。

M4F 内核

本开发板配置使用 MCU 域 UART（MCU_UART0，即 P2.05 作为 RX、P2.07 作为 TX）作为唯一的串行通信通道。

SD 卡

A53 内核

下载 BeagleBoard.org 官方的 BeagleBoard Imaging Utility，用 Zephyr 镜像制作可启动 SD 卡。也可以从 bb-zephyr-images 下载 Zephyr SD 卡镜像。

M4F 内核

下载 BeagleBoard.org 官方的 BeagleBoard Imaging Utility，用 Linux 发行版镜像制作可启动 SD 卡。这会在 A53 应用核上启动 Linux，然后由这些内核使用 remoteproc 将 Zephyr 二进制文件加载到 M4 内核上。

MSPM0L1105

下载 BeagleBoard.org 官方的 BeagleBoard Imaging Utility，用 Linux 发行版镜像制作可启动 SD 卡。这会在 A53 应用核上启动 Linux，然后即可在 Linux 中通过 I2C 使用 BSL 烧录 MSPM0L1105 固件。BeagleBoard.org 发行版镜像自带一个驱动，支持 MSPM0L1105 的 Firmware Upload API。

烧录

A53 内核

测试需要将二进制文件复制到 SD 卡的 BOOT 分区。

要测试 A53 内核，使用以下命令构建 Hello World 示例。

# From the root of the zephyr repository
west build -b pocketbeagle_2/am6254/a53 samples/hello_world

然后将该二进制文件复制到 SD 卡的 /boot/ 目录，并命名为 zephyr.bin。

# Mount the SD card at sdcard for example
sudo mount /dev/sdX sdcard
# copy the bin to the /boot/
sudo cp --remove-destination zephyr.bin sdcard/boot/zephyr.bin

现在即可使用该 SD 卡启动。

该二进制文件运行后会向调试端口打印 Hello world。

M4F 内核

本开发板通过 OpenAMP 资源表支持 remoteproc。

测试时需要将二进制文件复制到 SD 卡，以便 A53 内核在启动时通过 remoteproc 加载它。

要测试 M4F 内核，可使用以下命令构建 Hello World 示例。

# From the root of the zephyr repository
west build -b pocketbeagle_2/am6254/m4 samples/hello_world

该命令会构建程序，生成的二进制文件位于 build/zephyr 目录下，名为 zephyr.elf。

现在将该二进制文件复制到 SD 卡的 /lib/firmware 目录中，并命名为 am62-mcu-m4f0_0-fw。

# Mount the SD card at sdcard for example
sudo mount /dev/sdX sdcard
# copy the elf to the /lib/firmware directory
sudo cp --remove-destination zephyr.elf sdcard/lib/firmware/am62-mcu-m4f0_0-fw

现在可以使用该 SD 卡进行引导。启动时，二进制文件将被加载到 M4F 内核上。

该二进制文件运行后会向 MCU_UART0 端口打印 Hello world。

MSPM0L1105

备注

在 PocketBeagle 2 上，MSPM0L1105 用作 EEPROM 和 ADC。因此烧录任何自定义固件都会破坏这些功能。

备注

烧录新固件还会清除 EEPROM 内容。因此在尝试向 MSPM0L1105 烧录固件之前，请先备份 EEPROM 数据。

备注

Zephyr 默认分别使用 P1.19 和 P1.21 作为 UART RX 和 TX。

要测试 MSPM0L1105，使用以下命令构建 Minimal footprint 示例。

# From the root of the zephyr repository
west build -b pocketbeagle_2/mspm0l1105 samples/basic/minimal

该命令会构建程序，生成的二进制文件位于 build/zephyr 目录下，名为 zephyr.bin。

然后使用 FW Upload API 烧录该二进制文件。

echo 1 > /sys/class/firmware/mspm0l1105/loading
dd if=zephyr.bin of=/sys/class/firmware/mspm0l1105/data
echo 0 > /sys/class/firmware/mspm0l1105/loading

调试

M4F 内核

本开发板支持从运行 Linux 的 A53 内核调试 M4 内核。由于目标需要超级用户权限，目前需要单独启动 OpenOCD：

sudo openocd -f board/ti_am625_swd_native.cfg

开始调试

west build -b pocketbeagle_2/am6254/m4
west debug

MSPM0L1105

开始调试之前，需要应用设备树覆盖文件 k3-am62-pocketbeagle2-mspm0swd.dtbo 以启用 SWD 引脚。可以在 /boot/firmware/extlinux/extlinux.conf 中添加以下条目：

label msmp0
    kernel /Image.gz
    append console=ttyS2,115200n8 earlycon=ns16550a,mmio32,0x02860000 root=/dev/mmcblk1p3 ro rootfstype=ext4 fsck.repair=yes resume=/dev/mmcblk1p2 rootwait net.ifnames=0
    fdtdir /
    fdtoverlays /overlays/k3-am62-pocketbeagle2-mspm0swd.dtbo

保存对 /boot/firmware/extlinux/extlinux.conf 的修改后，可以通过以下任一方式选择该启动条目：

  • 在 /boot/firmware/extlinux/extlinux.conf 中将其设为默认条目。

  • 通过 UART 在启动菜单中选择该条目。

本开发板支持从运行 Linux 的 A53 内核调试 MSPM0L1105。由于 Zephyr 附带的 OpenOCD 不支持 sysfsgpio 驱动，目前需要单独启动 OpenOCD：

openocd -f board/beagle/pocketbeagle_2/support/mspm0l1105.cfg

开始调试

west build -b pocketbeagle_2/mspm0l1105
west debug

备注

默认附带的 MSPM0 ADC EEPROM 固件禁用了 SWD 调试。因此要使上述说明生效，需要烧录一个启用 SWD 调试的固件。可以使用 Linux 在 /sys/class/firmware/mspm0l1105 提供的 FW UPLOAD API 完成。

也可以对 MSPM0l1105 进行上电复位，达到同样的效果。
