MEC17xxEVB ASSY6941

Board Overview

Name:
mec_assy6941
Vendor:

Microchip Technology Inc.

Status:

Not actively maintained

Architecture:

arm

SoC:

mec1743_qsz, mec1653b_nsz, mec1753_qsz, mec1753_qlj, mec1743_qlj

Browse board sources

概述

MEC5 Assembly 6941 EVB 套件是用于评估 Microchip MEC174x 和 MEC175x 系列微控制器的开发平台。该开发板需要搭配 CPU 子卡：DC 176WFBGA DC ASSY 6949 适用于 MEC1743-QLJ 或 MEC1753-QLJ（176 引脚封装），DC 176WFBGA DC ASSY 6946 适用于 MEC1743-QSZ、MEC1753-QSZ 或 MEC1653B-NSZ（144 引脚封装）

硬件

  • MEC174x-QLJ/QSZ 或 MEC175x-QLJ/QSZ ARM Cortex-M4F 处理器

  • 共 480 KB SRAM（416 KB 代码，64 KB 数据）和 128 KB 引导 ROM

  • MEC1653B-NSZ ARM Cortex-M4 处理器（无 FPU）

  • 共 416 KB SRAM（352 KB 代码，64 KB 数据）和带 PQC 的 128 KB 引导 ROM。

  • 键盘接口

  • ADC 和 GPIO 排针

  • 四个 DB9 UART 接口

  • FAN0、FAN1、FAN2 排针

  • 风扇 PWM 接口

  • JTAG/SWD、ETM 和 MCHP 跟踪端口

  • PECI 3.0 接口

  • I2C 电平转换器

  • 10 个 SMBUS 排针

  • VCI 接口

  • 两个硬件驱动的 PS/2 端口

  • eSPI 排针

  • 2 个 SPI NOR 芯片插座

  • 复位按键和 VCC_PWRDGD 按键各一个

  • 一个外部 PCA9555 I/O 端口，I2C 地址可通过跳线选择。

  • 一个外部 LTC2489 delta-sigma ADC，I2C 地址可通过跳线选择。

  • 开发板电源可通过跳线选择由 +5V 2.1mm/5.5mm 圆形电源插座或 USB Micro A 连接器供电。

  • MEC175x/MEC165xB 各有一个 I3C 主控制器和一个 I3C 从控制器，每个控制器都有多个端口。

有关 MEC174x 的更多信息，请参阅 MEC174x Data Brief [1]。有关 MEC175x 的更多信息，请参阅 MEC175x Data Brief [2]。有关 MEC165xB 的更多信息，请参阅 MEC165xB Data Brief [3]

支持的功能

mec_assy6941 开发板支持下列硬件功能。

说明

The list of supported hardware features was not generated. Run a full documentation build for the required metadata to be available.

连接与 IO

该评估板套件由以下硬件模块组成：

  • MEC174x EVB ASSY 6941 Rev B

  • 搭载 MEC1743Q-LJ 或 MEC1753Q-LJ 芯片的 MEC174x 176WFBGA SOLDER DC ASSY 6942

  • SPI DONGLE ASSY 6791

系统时钟

MEC174x/MEC175x MCU 配置为使用 96Mhz 内部振荡器，并通过片上 PLL 生成 96 MHz 的 EC 时钟频率。请参阅本文档末尾参考资料中数据手册第 4 章 "4.0 POWER, CLOCKS, and RESETS" 中的处理器时钟控制寄存器。

串口

UART1 配置用于输出串口日志。

跳线设置

请按照以下跳线设置来正确演示本开发板。高级用户可以不按此建议设置。

EVB Assy 6941 Rev B 的跳线设置

电源相关跳线

如果要使用 +5V 电源适配器供电，请连接到圆形电源插座 P1 （外径 5.5mm，内径 2.1mm），并设置跳线 J1 5-6。

如果要通过 Host USB micro-USB A/B 型接口 J62 供电，请将跳线移到 J1 9-10、J59 1-2 和 J61 1-2。

备注

J1 上只需要一个跳线帽。

需要安装的电源跳线：

  • JP42 1-2, JP43 1-2, JP45 1-2, JP47 1-2, JP48 1-2

  • JP50 1-2, JP53 1-2, JP56 1-2, JP58 1-2, JP60 1-2

  • JP62 1-2, JP65 1-2, JP66 1-2, JP68 1-2

为以下电源轨选择开发板 +3.3V_STBY：

  • JP161 1-2 VBAT_CHIP 电源轨

  • J67 1-2 VCHIP_VTR_REG 电源轨

  • JP157 1-2 VCHIP_VTR_PLL 电源轨

  • JP158 1-2 VCHIP_VTR_ANALOG 电源轨

  • JP159 1-2 VCHIP_VTR1 电源轨

VCHIP_VTR2 电源轨可以是 +3.3V 或 +1.8V，会影响 VTR2 上的引脚。注意：QSPI 共享端口引脚位于 VTR2 电源轨上。只能选择其中一项：

  • J68 1-2 VTR2 连接到 +3.3V_STBY

  • J68 3-4 VTR2 连接到 +1.8V_STBY

正常工作时，VCHIP_VTR3 电源轨连接到 +1.8V。

  • JP160 1-2 VTR3 连接到 +1.8V_STBY

VCC_PWRGD 的跳线选择：VCC_PWRGD 通过 4.75K 上拉电阻连接到 VTR1，开关 S1 可将其接地，并连接复位发生器 U2。

  • JP17 3x7 19-20

  • JP19 3x6 8-9

  • JP36 1-2

  • JP34 1-2

nRESET_IN 的跳线选择：nRESET_IN 通过 4.75K 上拉电阻连接到 VTR1，开关 S2 可将其接地，并连接复位发生器 U3。

  • JP37 1-2

  • JP35 1-2

Boot-ROM 配置引脚（strap）

这些跳线用于配置 MEC174x/MEC175x Boot-ROM 启动配置引脚（strap）。

  • JP1 1-2 UART_BSTRAP 正常启动

  • JP2 1-2 CR_STRAP 正常启动

  • JP3 2-3 JTAG_STRAP：JTAG/SWD 接口不保持在复位状态

  • JP4 2-3 CMP_STRAP：GPIO207 可用作 GPIO

  • JP5 1-2 PWRGD_STRAP

  • JP7 1-2 BSS_STRAP：如果 OTP 中已启用，则选择 eSPI CAF 或 G3

  • JP8 1-2 BSS_STRAP：默认 BSS_STRAP，选择从共享 SPI 加载

  • JP6 1-2 VTR2_STRAP

  • JP9 1-2 CRISIS_RECOVERY_STRAP

外设路由跳线

UART0 连接到 P19A DB9（上方）

  • JP89 No jumper （不安装跳线）：RS-232 收发器 U8 不处于复位状态。

  • JP21 2-3, 8-9 从 GPIO 中选择 UART0_TX 和 UART0_RX。

  • JP22 1-2, 4-5 将 UART0_TX 和 UART0_RX 连接到 U8。

UART1 连接到 P19B DB9（下方）

  • JP90 No jumper （不安装跳线）：RS-232 收发器 U9 不处于复位状态。

  • JP91 1-2, 4-5 将 UART1_TX 和 UART1_RX 连接到 U9。

  • JP24 2-3, 5-6 从 GPIO 中选择 UART1_TX 和 UART1_RX。

J18 2x10 排针上的共享 SPI。

  • JP18 14-15 选择 SHD_nCS0。

  • JP18 17-18 选择 SHD_CLK。

  • JP18 2-3 选择 SHD_IO0。

  • JP18 5-6 选择 SHD_IO1。

  • JP18 8-9 选择 SHD_IO2（nWP）。

  • JP18 11-12 选择 SHD_IO3（nHOLD）。

用于访问 SPI 转接板 Flash U7 的第二个片选。

  • JP18 20-12 选择 SHD_nCS1。

JTAG/SWD ARM JTAG 2x10 J29.

  • JP80 1-2 不安装跳线。该跳线会使 JTAG/SWD 接口保持在复位状态。

  • JP12 2-3 选择 JTAG_TDO 或 SWO。

  • JP12 5-6 选择 JTAG_TDI，ARM SWD 不需要。

  • JP12 8-9 选择 JTAG_TMS 或 SWDIO。

  • JP12 11-12 选择 JTAG_CLK 或 SWCLK。

注意：ARM SWD 是一种两线接口，使用 JTAG_TMS 作为双向 I/O 引脚，另一根为 JTAG_CLK。ARM 串行线输出跟踪（SWO）功能位于第三个引脚 JTAG_TDO 上。配置选项如下：

  1. 4 线 JTAG 或 SWD 加 SWO。连接上面列出的全部四个 JP12 跳线。

  2. 2 线 SWD 加 SWO。连接 JTAG_TDO、JTAG_TMS 和 JTAG_CLK 的 JP12 跳线。JTAG_TDI 可用作 GPIO145。

  3. 仅 2 线 SWD。连接 JTAG_TMS 和 JTAG_CLK 的 JP12 跳线。JTAG_TDI 和 JTAG_TDO 分别可用作 GPIO145 和 GPIO146

用户按键和 LED

Button 示例使用 GPIO106 作为用户按键，使用 GPIO156 驱动 LED。请配置以下跳线来连接这些信号：

  • JP19 1-2 将 GPIO106 复用到 JP71.3 （按键输入）。

  • JP149 1-2 将 GPIO156 连接到 LED7 （LED 输出）。

MEC174x/MEC175x 176WFBGA Socket DC Assy 6942 Rev A0p1 的跳线设置

上面说明的跳线配置针对底板。ASSY 6942 MEC174x/MEC175x CPU 板支持可选的外部 32KHz 时钟源。该卡带有一个 32KHz 晶体振荡器，也可以配置为在 XTAL2/32KHZ_IN 引脚上使用外部 50% 占空比的 32KHz 时钟源。注意，固件必须设置 MEC174x/MEC175x 时钟使能寄存器，选择与跳线设置相符的外部时钟源。如果使用 MEC174x/MEC175x 内部硅振荡器，则 32K 跳线如何设置都无关紧要。子卡上的 JP1 用于用示波器观察测试时钟输出。请参阅下文参考资料部分中的原理图。

并联 32KHz 晶体配置

JP1 1x2 ON JP2 1x3 2-3

外部 32KHz 50% 占空比配置

JP1 1x2 NC JP2 1x3 1-2

注意：EVB 上的 JP117 3-4 将 32KHz 振荡器 U15 的输出连接到子卡。

构建

  1. 按常规方式构建 :zephyr:code-sample:'hello_world` 应用程序。

  2. 如果构建系统能找到镜像生成工具，就会生成 spi_image.bin 文件。该二进制镜像可用于烧写 SPI 芯片。

编程与调试

设置

  1. 在 Assy6791 SPI 转接板上烧录 SPI Flash 的示例。

  2. 这里使用一款基于 FTDI FT232H 器件的低成本 USB 转 GPIO 设备。

    这里使用的 FT232H 设备是 AdaFruit FT232H [6]。AdaFruit FT232H 同时支持 5V 和 3.3V 器件。

    linux flashrom 工具支持将 FT232H USB 转 GPIO 设备用作 SPI 编程器。

    $ sudo /usr/sbin/flashrom -V -p ft2232_spi:type=232H,divisor=30 -w spi_image.bin

  3. 克隆 MEC174x SPI Image Gen [4] 或 MEC175x SPI Image Gen [5] 仓库，或下载该目录中的文件。

  4. 让 Zephyr 能够使用镜像生成工具：可以将该工具加入搜索路径，也可以设置环境变量 MEC5_SPI_GEN，例如：

    export MEC5_SPI_GEN=<path to tool>/mec174x_spi_gen_linux_x86_64
or
export MEC5_SPI_GEN=<path to tool>/mec175x_spi_gen_linux_x86_64

  5. 默认配置文件是位于 ${BOARD_DIR}/support 中的 mec174x_spi_cfg.txt 或 mec175x_spi_cfg.txt。如有需要，可以指定自定义的 SPI 镜像配置文件来覆盖默认文件。

    export MEC5_SPI_CFG=custom_spi_cfg.txt

接线

  1. 将 SPI Dongle ASSY 6791 连接到 EVB 上的 J18。

  2. 重要：暂时拔掉 JP87 上的跳线，将 SPI 转接板的电源与 EVB 电源轨隔离，以防 SPI 编程器向 EVB 反向灌电。

  3. 将编程器连接到 Assy6791 板上的排针 J6，它会烧录 SPI NOR 芯片 U3。

    备注

    AdaFruit FT232H 开发板支持 +5V 或 +3.3V 的 SPI Flash 器件，它有独立的 +3V 和 +5V 引脚。应将相应的电源轨连接到 Assy6791 Flash 转接板的 J6-1 电源引脚。建议烧录时将 Assy6791 转接板从 EVB 上取下。如果转接板连接在未上电的 EVB 上，SPI 编程器会向所有元件反向灌电。拔掉 EVB 上 JP87 的跳线，断开 VTR1/VTR2 与 2x10 排针 J18 的连接，即可避免反向灌电。

  4. AdaFruit FT232H 带有 USB Type-C 接口。用合适的 USB 线将其连接到开发主机，FT232H 开发板和 Assy6791 转接板随即上电。

烧录

  1. 运行你常用的终端程序

  2. 烧录 zephyr 构建过程中由 Microchip SPI 镜像生成器创建的 SPI 镜像。flashrom 传给 linux FT232 驱动的 divisor 选项用于对 60 MHz SPI 时钟分频。将 '-w' 选项改为 '-r' 即可读取当前的 SPI 镜像。

    $ sudo /usr/sbin/flashrom -V -p ft2232_spi:type=232H,divisor=30 -w spi_image.bin

  3. flashrom 完成后，拔下 USB 线，断开 AdaFruit FT232H 编程器的电源。断开 FT232H 与 Assy6791 转接板的连接，然后重新装回 EVB 上 JP87 的跳线。

# 给 EVB 上电。

  1. 应该会在第一个终端窗口中看到 "Hello World! <board name>"。如果没有看到这条消息，请按复位按键，消息就会出现。

调试

本开发板带有 Cortex ETM 端口，只需一个物理连接即可进行跟踪和调试。此外，它还带有仅用于 JTAG 会话的插座。

故障排除

  1. 如果应用程序没有运行，请确认 LED1 和 LED2 已点亮。如果其中任一熄灭，请重新检查与电源相关的跳线。

  2. 如果怀疑 SPI 镜像没有烧录成功，请将 SPI 转接板从 EVB 上取下，然后重新烧录。
