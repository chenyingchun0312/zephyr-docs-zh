使用 Microchip MPLAB VS Code 调试

可以使用 MPLAB® Extension for Visual Studio Code 在 Visual Studio Code 中调试 Microchip 器件。该扩展集成了 Microchip 调试工具，可以直接在 VS Code 中启动和调试应用程序。

本节介绍如何使用 MPLAB 调试器扩展和 launch.json 配置，为 Microchip 目标配置 VS Code 调试。

通常支持的调试工具包括：

  • MPLAB PICkit™ debuggers/programmers

  • MPLAB SNAP 调试器

  • MPLAB ICD 调试器

  • 部分 Microchip 开发板上提供的板载调试器

支持的器件和工具的具体列表取决于所安装的 MPLAB 扩展、Microchip 工具包和器件系列包。

要求

开始调试会话之前，请安装并配置以下工具：

  • Visual Studio Code

  • MPLAB® Extension for Visual Studio Code

  • 所需的 Microchip 器件包

  • 受支持的 Microchip 调试探针或板载调试器

  • 启用了调试信息构建的固件镜像

构建系统生成的 ELF 文件用于源码级调试。

build/zephyr/zephyr.elf

安装 MPLAB 扩展

安装 MPLAB 扩展的步骤如下：

  1. 打开 Visual Studio Code。

  2. 打开扩展视图。

  3. 搜索 MPLAB。

  4. 安装官方的 Microchip MPLAB 扩展。

  5. 如有需要，重启 VS Code。

安装完成后，确认该扩展能够检测到所需的 Microchip 调试工具和器件支持包。

构建 Zephyr 应用程序

开始调试会话之前先构建 Zephyr 应用程序。

示例：

# From the root of the zephyr repository
west build -b <board> samples/basic/blinky

构建成功后，Zephyr ELF 文件位于：

build/zephyr/zephyr.elf

应在 .vscode/launch.json 的 program 字段中引用该 ELF 文件。

VS Code 调试配置

VS Code 调试配置保存在以下文件中：

.vscode/launch.json

MPLAB 扩展使用 mplab-core-da 调试适配器类型。

以下 launch.json 配置仅作为示例，具体配置可能因开发板而异。要为特定开发板使用正确的 launch.json，请参阅该开发板的文档页面。

{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "MPLAB Debug Zephyr : pic32cm_jh01_cpro",
      "type": "mplab-core-da",
      "request": "launch",
      "program": "${workspaceFolder}/zephyr/build/zephyr/zephyr.elf",
      "tool": "${command:pickTool}",
      "stopOnEntry": true,
      "device": "PIC32CM5164JH01100"
    }
  ]
}

tool 字段使用以下命令：

"tool": "${command:pickTool}"

这样，MPLAB 扩展会在调试会话开始时提示选择所连接的调试工具。

使用特定序列号的调试工具

如果连接了多个兼容的调试工具，可以在配置中添加 serial 字段来选择特定的探针。

示例：

{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "MPLAB Debug Zephyr : pic32cm_jh01_cpro",
      "type": "mplab-core-da",
      "request": "launch",
      "program": "${workspaceFolder}/zephyr/build/zephyr/zephyr.elf",
      "tool": "${command:pickTool}",
      "stopOnEntry": true,
      "device": "PIC32CM5164JH01100",
      "serial": "020107402RYN000062"
    }
  ]
}

备注

serial 的值必须与所连接 Microchip 调试探针的序列号一致。如果只连接了一个调试工具，通常不需要该字段。在 VS Code 命令面板中输入命令 MPLAB: List connected tools 即可查到序列号。

配置字段

调试配置中的主要字段如下：

name

在 VS Code “运行和调试”视图中显示的名称。

type

MPLAB 扩展使用的调试适配器类型。对于 MPLAB 内核调试，使用 mplab-core-da。

request

调试请求类型。使用 launch 启动新的调试会话。

program

要调试的 ELF 文件的路径，通常为 ${workspaceFolder}/zephyr/build/zephyr/zephyr.elf，也可以替换为绝对路径。

device

目标 Microchip 器件名称，例如 PIC32CM5164JH01100。

tool

调试工具选择。${command:pickTool} 会让 MPLAB 扩展提示选择所连接的调试工具。

stopOnEntry

如果设为 true，调试会话开始时程序会停在入口点。

serial

可选的调试工具序列号。连接了多个调试探针时很有用。

启动调试会话

开始调试的步骤如下：

  1. 将 Microchip 调试探针连接到目标开发板。

  2. 给目标开发板上电。

  3. 在 VS Code 中打开 Zephyr 工作区。

  4. 构建应用程序。

  5. 确认 ELF 文件存在。

  6. 要开始调试，请在菜单栏中选择 Run -> Start Debugging (F5)

  7. 后续调试时，可根据需要使用调试工具栏执行继续（Continue）、单步跳过（Step Over）、单步进入（Step Into）等操作。

备注

如果 launch.json 中定义了多个调试配置，可以在 VS Code 侧边工具栏“运行和调试”视图的下拉菜单中选择所需的配置。

会话开始时，MPLAB 扩展会提示用户选择一个已连接的调试工具。选择工具后，扩展会连接该工具、加载 ELF 文件并启动调试器。

调试期间，可以使用 VS Code：

  • 设置和清除断点

  • 单步执行源代码

  • 继续和暂停执行

  • 查看局部变量和全局变量

  • 查看调用栈

  • 监视表达式

  • 查看寄存器（取决于扩展的支持情况）

故障排除

检测不到调试工具

如果检测不到调试工具：

  • 检查 USB 连接。

  • 确保 MPLAB 扩展支持该调试探针。

  • 确认探针固件是最新版本。

  • 断开并重新连接调试探针。

  • 重启 VS Code。

  • 确保没有其他应用程序正在使用该调试工具。

无法识别设备

如果无法识别器件：

  • 确认 device 字段与 Microchip 器件的确切名称一致。

  • 安装或更新所需的 Microchip 器件包。

  • 确认目标开发板已上电。

  • 检查调试接口和接线。

  • 确认所选探针支持目标器件。

找不到 ELF 文件

如果调试会话找不到程序文件：

  • 确认 Zephyr 应用程序已成功构建。

  • 检查 build/zephyr/zephyr.elf 是否存在。

  • 更新 launch.json 中的 program 路径。

  • 对于需要可移植的项目，建议使用 ${workspaceFolder}/zephyrproject/zephyr/build/zephyr/zephyr.elf。

断点未命中

如果断点未命中：

  • 确保应用程序构建时带有调试符号。

  • 修改源文件后重新构建应用程序。

  • 确保源码树与正在调试的 ELF 文件一致。

  • 如果源码级调试不可靠，请降低编译器优化级别。

  • 确认目标已烧录预期的固件镜像。

调试器模式

Microchip 调试工具（包括所支持开发板上的板载调试器，以及 MPLAB SNAP 和 MPLAB ICD 等外部调试探针）出厂时默认处于 MPLAB 模式。如果已使用 pycmsisdapswitcher 工具将调试器切换到 CMSIS-DAP v2 模式，MPLAB 调试适配器将无法检测到该工具。请将调试器恢复为 MPLAB 模式，然后重新连接该工具。
