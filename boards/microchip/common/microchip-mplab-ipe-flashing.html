使用 Microchip MPLAB IPE 烧录

Microchip 器件可以使用 MPLAB 集成编程环境（IPE） 进行编程（烧录）。MPLAB IPE 是一款独立的编程工具，支持 Microchip 调试探针和板载调试器。它可以通过 ipecmd 工具在命令行中使用，该工具通过 MPLAB IPE 运行器与 Zephyr 的 west flash 命令集成。

本节介绍如何安装和配置 MPLAB IPE，以便将 Zephyr 应用程序烧录到 Microchip 目标开发板上。

概述

MPLAB IPE 为 Microchip 微控制器提供了可用于量产的编程接口。与 Zephyr 配合使用时，west flash 命令会调用 ipecmd 命令行工具，用构建好的固件镜像对目标器件进行编程。

烧录过程使用 Zephyr 构建系统生成的 Intel HEX 文件：

build/zephyr/zephyr.hex

支持的调试工具

MPLAB IPE 支持以下调试/编程工具：

  • MPLAB PICkit™ debuggers/programmers

  • MPLAB SNAP debuggers/programmers

  • MPLAB ICD 调试器

  • Microchip 开发板上提供的板载调试器（PKoB、PKoB4、EDBG）

支持的工具的具体列表取决于所安装的 MPLAB IPE 版本和目标器件系列。

要求

使用 MPLAB IPE 烧录之前，请安装并配置以下内容：

  • MPLAB X IDE （包含 MPLAB IPE）

  • 所需的 Microchip 器件包（自动安装，或通过 MPLAB IPE Pack Manager 安装）

  • 受支持的 Microchip 调试探针或板载调试器

  • 为目标开发板构建的 Zephyr 固件镜像

安装 MPLAB IPE

MPLAB IPE 包含在 MPLAB X IDE 安装程序中。安装步骤如下：

  1. 从 Microchip Technology 网站下载 MPLAB X IDE 安装程序。

  2. 解压下载的软件包并运行安装程序。

    在 Linux 上：

    chmod +x MPLABX-vX.XX-linux-installer.sh
sudo ./MPLABX-vX.XX-linux-installer.sh

    在 Windows 上，运行 .exe 安装程序。

  3. 安装过程中，请确保在可用组件中选中 MPLAB IPE。

  4. 安装完成后，确认可以访问 ipecmd 可执行文件。

    在 Linux 上，ipecmd 通常位于：

    /opt/microchip/mplabx/vX.XX/mplab_platform/bin/ipecmd.sh

    在 Windows 上：

    C:\Program Files\Microchip\MPLABX\vX.XX\mplab_platform\bin\ipecmd.exe

  5. 将包含 ipecmd 的目录添加到系统 PATH 中。

验证安装

运行以下命令验证 MPLAB IPE 是否正确安装。屏幕上会显示帮助菜单。

在 Linux 上：

ipecmd.sh -?

在 Windows 上：

ipecmd.exe -?

构建 Zephyr 应用程序

烧录之前先构建 Zephyr 应用程序。例如，构建 Blinky 示例：

# From the root of the zephyr repository
west build -b <board> samples/basic/blinky

构建成功后，HEX 文件位于：

build/zephyr/zephyr.hex

连接开发板

将目标开发板上的调试/编程接口连接到主机：

  1. 用 USB 线将开发板的 调试 USB 端口 连接到主机。

  2. 该连接通常为开发板供电，并提供对板载调试器（例如 PKoB 或 PKoB4）的访问。

  3. 如果使用外部调试探针（例如 PICkit、SNAP、ICD），请将探针连接到开发板的调试排针，并通过 USB 将探针连接到主机。

  4. 确保开发板已上电。有些开发板除调试 USB 外还需要单独供电。

备注

具体的调试 USB 端口和接口名称因开发板而异。确切的连接详情请参阅开发板的文档页面。

使用 west flash 烧录

构建好应用程序并连接好开发板后，使用以下命令烧录设备：

west flash

Zephyr 构建系统会使用适合目标器件和所连接工具的参数调用 ipecmd。

如果需要显式指定运行器：

west flash -r mplab_ipe

故障排除

找不到 ipecmd

如果 west flash 报告找不到 ipecmd：

  • 确认已安装 MPLAB X IDE / MPLAB IPE。

  • 确保包含 ipecmd 的目录位于系统 PATH 中。

检测不到工具

如果检测不到编程工具：

  • 检查探针/开发板与主机之间的 USB 连接。

  • 确保没有其他应用程序（例如 MPLAB X IDE、MPLAB IPE 图形界面）正在使用该调试工具。

  • 确认探针固件是最新版本。如有需要，使用 MPLAB IPE 图形界面更新固件。

  • 断开并重新连接调试探针。

  • 在 Linux 上，确保已为 Microchip 工具安装了合适的 udev 规则。

无法识别设备

如果无法识别目标器件：

  • 确认 MPLAB IPE 中已安装正确的器件包。

  • 打开 MPLAB IPE 图形界面，使用 Pack Manager 安装或更新器件包。

  • 确保目标开发板已上电，且调试连接牢靠。

  • 确认目标器件与 Zephyr 开发板定义中配置的器件一致。
