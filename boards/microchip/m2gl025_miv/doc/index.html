M2GL025 Mi-V

Board Overview

Name:
m2gl025_miv
Vendor:

Microchip Technology Inc.

Status:

Not actively maintained

Architecture:

riscv

SoC:

miv

Browse board sources

概述

Microchip M2GL025 开发板是一款基于 IGLOO2 FPGA 的开发板，可以在 MGL025 开发板上部署 Mi-V RISC-V 软核 CPU。更多信息请访问 Microchip 网站。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

构建

m2gl025_miv 开发板配置的应用程序可以按常规方式构建（参见 构建应用程序）：

west build -b m2gl025_miv

烧录

要将应用程序上传到设备，需要支持 RISC-V 的 OpenOCD 和 GDB。它们包含在 SoftConsole SDK 中。下载和安装说明请参阅 Microchip SoftConsole 网站。

安装好必要的工具后，可以使用 OpenOCD 连接开发板。运行以下命令建立 OpenOCD 连接：

sudo LD_LIBRARY_PATH=<softconsole_path>/openocd/bin \
<softconsole_path>/openocd/bin/openocd  --file \
<softconsole_path>/openocd/share/openocd/scripts/board/microsemi-riscv.cfg

保持其运行，然后在另一个终端中使用 GDB 将二进制文件上传到开发板。可以使用 SoftConsole SDK 附带工具链中的 RISC-V GDB。

以下是在 GDB 终端中连接设备并加载二进制文件的命令：

<softconsole_path>/riscv-unknown-elf-gcc/bin/riscv64-unknown-elf-gdb \
-ex "target extended-remote localhost:3333" \
-ex "set mem inaccessible-by-default off" \
-ex "set arch riscv:rv32" \
-ex "set riscv use_compressed_breakpoints no" \
-ex "load" <path_to_executable>
