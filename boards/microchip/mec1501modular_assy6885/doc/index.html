MEC1501 Modular card ASSY6885

Board Overview

Name:
mec1501modular_assy6885
Vendor:

Microchip Technology Inc.

Status:

Not actively maintained

Architecture:

arm

SoC:

mec1501_hsz

Browse board sources

概述

MEC1501 Modular card ASSY6885 是一款用于评估 Microchip MEC152X 系列微控制器的开发板。该开发板可以独立工作，也可以与任何符合 MECC 规范的平台配合使用。

硬件

  • MEC1521HA0SZ ARM Cortex-M4 处理器

  • 256 KB RAM 和 64 KB 启动 ROM

  • GPIO 排针

  • 通过 microUSB 引出的 UART1

  • PECI 3.0 接口

  • 10 个 SMBUS 实例

  • FAN、PWM 和 TACHO 引脚

  • VCI 接口

  • 独立的硬件驱动 PS/2 端口

与 MEC15xx 评估板不同，模块化的 MEC1521 以两种不同方式引出引脚：

  1. 通过排针使用的独立模式

    • GPIO

    • PWM5

    • JTAG/SWD、ETM 和 MCHP 跟踪端口

    • eSPI 总线

    • SMB0

  2. 与另一个带高密度 MECC 连接器的平台配合使用的配接模式。

    • FAN0, PWM0, SMB0, SMB1, SMB4 and SMB5

    • eSPI 总线

    • Breathing/Blinking LEDs

该开发板通过 +5V USB Micro A 接口或 MECC 连接器供电。

有关该 SoC 的更多信息，请参阅 MEC152x Reference Manual [1]

系统时钟

MEC1501 MCU 配置为使用 48Mhz 内部振荡器，并通过片上 PLL 生成 12 MHz 的 EC 时钟频率。请参阅本文档末尾参考资料中数据手册第 4 章 "4.0 POWER, CLOCKS, and RESETS" 中的处理器时钟控制寄存器。

串口

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

设置

  1. 克隆 MEC152x SPI Image Gen [3] 仓库，或下载该目录中的文件。对于预量产的 MEC150x，请使用 MEC150x SPI Image Gen [4] 仓库。

  2. 让 Zephyr 能够使用该镜像生成工具：将工具加入路径以便查找，或设置环境变量 EVERGLADES_SPI_GEN，例如：

    export EVERGLADES_SPI_GEN=<path to tool>/everglades_spi_gen_RomE

    注意，Linux 和 Windows 版本的工具文件名不同。对于预量产版 MEC1501 SOC，请使用 everglades_spi_gen_lin64。

  3. 如有需要，可以指定自定义的 SPI 镜像配置文件来覆盖默认配置文件。

    export EVERGLADES_SPI_CFG=custom_spi_cfg.txt

构建

  1. 按常规方式构建 Hello World 应用程序。

  2. 得到 zephyr.bin 后，使用 Microchip 工具 MEC152x SPI Image Gen [3] 生成最终的二进制文件。需要将该工具的输出烧录到 SHD SPI 存储器中。

烧录

  1. 将 Dediprog 连接到排针 J2。

  2. 使用 Dediprog SF100 或类似的 SPI 芯片烧录工具，在偏移量 0x0 处烧录 SPI NOR U3。

  3. 运行你常用的终端程序以监听输出。在 Linux 下，终端应为 /dev/ttyACM0。例如：

    $ minicom -D /dev/ttyACM0 -o

    -o 选项让 minicom 不发送调制解调器初始化字符串。连接应按如下方式配置：

    • 波特率：115200

    • 数据位：8 位

    • 校验位：无

    • 停止位：1

  4. 通过 UART1 端口将 MEC1501MODULAR_ASSY6885 开发板连接到主机并上电。

    应该会在终端中看到 "Hello World! mec1501modular_assy6885"。

调试

本开发板带有 Cortex ETM 端口，只需一个物理连接即可进行跟踪和调试。此外，它还带有仅用于 JTAG 会话的插座。

硬件问题

如果没有看到应用程序运行，请确认 LED1 已点亮。如果它不亮，请再次检查与电源相关的跳线。
