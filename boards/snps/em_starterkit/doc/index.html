ARC EM Starter Kit

Board Overview

Name:
em_starterkit
Vendor:

Synopsys, Inc.

Status:

Not actively maintained

Architecture:

arc

SoC:

emsk_em7d, emsk_em9d, emsk_em11d

Browse board sources

概述

DesignWare(R) ARC(R) EM Starter Kit 是一款低成本、多用途的解决方案，可用于 ARC EM 系列处理器的快速软件开发、软件调试和性能分析。EM 系列包括 EM4、EM6、EM5D、EM7D、EM9D 和 EM11D 内核。Zephyr RTOS 可以在 EM Starter Kit 上使用。

ARC EM Starter Kit 由一个硬件平台组成，其中预装了多种带外设的 ARC EM 处理器配置的 FPGA 镜像。该开发板的文档可在 embARC website [1] 上找到。

该开发板的详细信息另请参见以下网址：Designware ARC EM Starter Kit website [2] 。

EM Starter Kit 的最新版本是 2.3，开发者可以使用最新固件从 2.0/2.1/2.2 升级到 2.3。EM Starter Kit 开发板的默认配置位于 boards/snps/em_starterkit/。

Zephyr 为该开发板支持的默认 SoC 是 EM9D。此配置采用哈佛架构，指令总线和数据总线相互独立。指令存储器称为 ICCM，数据存储器称为 DCCM。EM9D 的配置文件位于 soc/snps/emsk/Kconfig.defconfig.em9d。

如果程序较大，可以选择 EM7D 或 EM11D，它们可以访问 128KB DRAM，并带有指令缓存和数据缓存。EM7D 的配置文件位于 soc/snps/emsk/Kconfig.defconfig.em7d，EM11D 的配置文件位于 soc/snps/emsk/Kconfig.defconfig.em11d。

硬件

开发板布局

ARC EM Starter Kit 主板有 6 个 Pmod 连接器，可以配置为连接 GPIO、I2C、UART 或 SPI 设备。

开发板还带有 16MB SPI-FLASH 和一个 SD 卡用于存储。另有 9 个 LED、3 个按键和 4 个拨码开关，可通过 GPIO 使用。

Xilinx Spartan(R)-6 LX150 FPGA 可以自动加载 3 个 FPGA SoC 比特文件之一，分别包含 EM7D、EM9D 或 EM11D SoC。

该开发板的文档和基本信息可在 embARC website [1] 上找到，该网站还提供了一些免费的示例软件。

支持的固件版本

EM Starter Kit 有多个版本，例如 1.0、1.1、2.0、2.1、2.2 和 2.3。Zephyr 仅支持固件版本 2.2 和 2.3。

所需硬件和软件

要在 EM Starter Kit 开发板上使用 Zephyr RTOS 应用程序，还需要一些额外的硬件。

  • USB 线缆（随 ARC EM Starter Kit 一同提供）

  • USB 线缆可以为开发板供电；不过，如果开发板需要独立运行，可以使用包装中附带的通用开关电源适配器（110-240V AC 转 5V DC）为开发板供电。

  • The Zephyr SDK

  • 用于 USB-UART 的终端仿真软件。建议使用：Putty Website [4]。

  • （可选）一组 Pmod 模块。参见 Digilent Pmod Modules [3]，或自行开发定制接口连接到 Pmod 连接器。

设置 ARC EM Starter Kit

要在 EM Starter Kit 的正确 ARC 内核上运行 Zephyr 应用程序，需要正确设置开发板。

  • 用 Digilent USB 线将主机连接到开发板。

  • 将 5V DC 电源连接到开发板。

  • 通过正确设置拨码开关 SW1 选择开发板的内核配置，然后按下位于开发板上 ARC 标志字母“C”上方的 FPGA 配置按键。

  • 随后开发板将以所选内核配置重新配置，此时即可下载并调试 Zephyr 应用程序。

  • 如需进一步了解该开发板的使用方法，可以参阅 ARC EM Starter Kit User Guide [2]。

设置 Zephyr 软件

由于 EM Starter Kit 有不同的固件版本，需要选择 Zephyr 支持的正确固件版本。

该开发板有三种不同的配置：

  • EM7D: em_starterkit_em7d_defconfig

  • EM9D: em_starterkit_defconfig

  • EM11D: em_starterkit_em11d_defconfig

构建示例应用程序

可以尝试许多示例应用程序或测试，这里以 Hello World 为例。它位于 samples/hello_world。

配置

如果示例中没有 prj_arc.conf 文件，可能需要自行编写一个。接下来，可以使用 menuconfig 规则配置目标。将开发板配置指定为 em_starterkit，即可为 Zephyr 选择 ARC EM Starter Kit 开发板支持。

# From the root of the zephyr repository
west build -b em_starterkit samples/hello_world
west build -t menuconfig

在该开发板上还需要考虑“ARC SoC Selection”，将其设置为 EM9D 或 EM11D。要在开发板上启动 EM9D，除开关 1 外，所有拨码开关都应拨到 UP。其他配置项按常规方式选择。要在开发板上启动 EM11D，除开关 2 外，所有拨码开关都应拨到 UP。然后按下丝印“ARC”标志中字母 C 上方的按键。

构建

可以按常规方式构建应用程序，详情请参阅 构建应用程序。下面以 Hello World 为例。

# From the root of the zephyr repository
west build -b em_starterkit samples/hello_world

连接串口输出

在默认配置中，Zephyr 的 EM Starter Kit 镜像支持通过开发板上的 UART1 进行串口输出。要启用串口输出：

在开发环境中，需要：

  • 打开串口仿真程序（例如 Linux 上的 minicom、putty、screen 等）

  • 指定 tty 驱动名称，例如在 Linux 上可能是 /dev/ttyUSB1

  • 将通信参数设置为：

调试

使用最新版本的 Zephyr SDK（>=0.9），可以直接调试和烧录 EM Starterkit。

一种方式是使用常规的 Zephyr 构建系统命令构建和调试应用程序。

west build -b em_starterkit <my app>
west debug

此时即可进行常规调试会话。设置断点，然后输入“c”继续运行程序。

另一种方式是启动调试服务器，如下所示。

west build -b em_starterkit <my app>
west debugserver

然后在第二个控制台中，从包含输出文件 zephyr.elf 的构建目录连接到 EM Starter Kit 的调试服务器。

$ cd <my app>
$ $ZEPHYR_SDK_INSTALL_DIR/arc-zephyr-elf/bin/arc-zephyr-elf-gdb zephyr.elf
(gdb) target remote localhost:3333
(gdb) load
(gdb) b main
(gdb) c

烧录

如果只想将应用程序下载到 EM Starter Kit 的 CCM 或 DDR 中运行，可以按常规方式进行。

west build -b em_starterkit
west flash

该命令仍然使用 openocd 和 gdb 将应用程序 elf 文件加载到 EM Starter Kit，但会在加载应用程序后立即运行。如果断电，应用程序也会随之丢失。

大多数情况下，你不会烧录程序，而是使用 openocd 和 gdb 进行调试。程序可以通过 USB 线下载到代码存储器和数据存储器中。

当准备好部署程序，使其在复位或上电时自动启动时，可以按照以下步骤将程序放到 SPI-FLASH 上。

关于如何将程序写入 SPI-FLASH，请参阅 embARC website [1] 上 ARC EM Starter Kit 的文档，其中说明了如何以引导加载程序能够识别的方式将可执行镜像放到 SPI-FLASH 上。
