ARC HS4x/HS4xD Development Kit

Board Overview

Name:
hsdk4xd
Vendor:

Synopsys, Inc.

Status:

Not actively maintained

Architecture:

arc

SoC:

arc_hsdk4xd

Browse board sources

概述

ARC HS4x/HS4xD Development Kit 是 Synopsys HSDK 开发板 的下一代版本。它搭载一颗基于 ARC HS4xD 的多核芯片，集成了以太网、HDMI、WiFi、Bluetooth、USB、SDIO、I2C、SPI、UART、I2S、ADC、PWM 和 GPIO 等丰富接口，以及一个 Think Silicon GPU。

该开发板的详细信息请参见：ARC HS4x/HS4xD Development Kit (HSDK4xD)

硬件

ARC HSDK4xD 有 24 个通用 GPIO，分为 8 组，命名为 GPIO_SEL_0 到 GPIO_SEL_7。每组可以配置为不同的功能，例如 GPIO、UART、SPI、I2C 和 PWM。可以通过编程 CREG_GPIO_MUX 寄存器来配置每一组。下表列出了 CREG_GPIO_MUX 寄存器的位定义以及每个引脚的详细配置。

所需硬件和软件

要在 HS4x/HS4xD Development Kit 开发板上使用 Zephyr RTOS 应用程序，还需要一些额外的硬件。

  • 一根 micro USB 线为开发板提供 USB-JTAG 调试和 USB-UART 通信

  • 包装内附带的通用开关电源适配器（110-240V AC 转 12V DC）为开发板供电。

  • The Zephyr SDK

  • 用于 USB-UART 的终端仿真软件。建议使用：Putty Website [2]。

  • （可选）一组 Pmod、Arduino 模块或 Mikro 模块。请参阅 Digilent Pmod Modules [1]，或自行开发连接到 Pmod 连接器的自定义接口。

设置 ARC HS4x/HS4xD Development Kit

要在 ARC HS4x/HS4xD Development Kit 上运行 Zephyr 应用程序，需要正确设置开发板。

  • 用 digilent USB 线将主机连接到开发板。

  • 将 12V 直流电源连接到开发板

配置

如果示例中没有 prj.conf 文件，可能需要自行编写一个。接下来，可以使用 menuconfig 规则配置目标。将开发板配置指定为 hsdk4xd，即可为 Zephyr 选择 ARC HS4x/HS4xD Development Kit 开发板支持。

# From the root of the zephyr repository
west build -b hsdk4xd samples/hello_world
west build -t menuconfig

构建

可以按常规方式构建应用程序。详情参见 构建应用程序。以下以 Hello World 为例。

# From the root of the zephyr repository
west build -b hsdk4xd samples/hello_world

调试

使用最新版本的 Zephyr SDK（>=0.15.2），可以直接调试和烧录（运行）HS4x/HS4xD Development Kit。

一种方式是使用常规的 Zephyr 构建系统命令构建和调试应用程序。

west build -b hsdk4xd <my app>
west debug

此时可以进行常规的调试会话。设置断点，然后按 c 继续运行程序。

另一种方式是启动调试服务器，如下所示。

west build -b hsdk4xd <my app>
west debugserver

然后在第二个控制台中，从包含输出文件 zephyr.elf 的构建目录连接到 HS4x/HS4xD Development Kit 的调试服务器。

$ cd <my app>
$ $ZEPHYR_SDK_INSTALL_DIR/arc-zephyr-elf/arc-zephyr-elf-gdb zephyr.elf
(gdb) target remote localhost:3333
(gdb) load
(gdb) b main
(gdb) c

烧录

如果只想将应用程序下载到 HS4x/HS4xD Development Kit 的 DDR 中运行，可以按常规方式进行。

west build -b hsdk4xd <my app>
west flash

该命令仍然使用 openocd 和 gdb 将应用程序 elf 文件加载到 HS4x/HS4xD Development Kit，但会在加载应用程序后立即运行。如果断电，应用程序将会丢失，因为它没有写入 Flash。

大多数情况下，你不会烧录程序，而是使用 openocd 和 gdb 进行调试。程序可以通过 USB 线下载到代码存储器和数据存储器中。

HS4x/HS4xD Development Kit 还支持使用 U-Boot 引导加载程序烧录 Zephyr 应用程序。U-Boot 是一个强大而灵活的工具，可以从不同来源加载可执行文件并在目标平台上运行。

HS4x/HS4xD Development Kit 的 U-Boot 实现还进一步扩展了额外功能，使用户能够更好地管理 HS4x/HS4xD Development Kit 丰富的可配置项

准备部署程序，使其在复位或上电时自动启动时，可以按照步骤将程序放到 SD 卡上。

详情请参见：Uboot-HS4x/HS4xD-Command-Reference
