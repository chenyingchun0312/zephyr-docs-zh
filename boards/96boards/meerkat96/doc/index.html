96Boards Meerkat96

概述

96Boards Meerkat96 开发板基于 NXP i.MX7 混合多核处理器，由双核 Cortex®-A7 和单核 Cortex®-M4 组成。Zephyr OS 已移植为在 Cortex®-M4 核上运行。

  • 开发板特性：

    • RAM：512 MB

    • 存储：

      • microSD 卡座

    • 无线：

      • WiFi: 2.4GHz IEEE 802.11b/g/n

      • 蓝牙：v4.1（BR/EDR）

    • USB:

      • 主机：2 个 type A

      • OTG：1 个 type micro-B

    • HDMI

    • 连接器：

      • 40 针低速排针

      • 60 针高速排针

    • LEDs:

      • 4 个绿色用户 LED

      • 1 个蓝色蓝牙 LED

      • 1 个黄色 WiFi LED

有关该开发板的更多信息，参见 96Boards website。

硬件

i.MX7 SoC 提供以下硬件功能：

  • 双核 Cortex A7（800MHz/1.0GHz）和单核 Cortex M4（200MHz）

  • 内存

    • 外部 DDR 存储器，最大 1 GB

    • 内部 RAM -> A7：256KB SRAM

    • 内部 RAM -> M4：3 个 32KB（TCML、TCMU、OCRAM_S）、1 个 128KB（OCRAM）和 1 个 256MB（DDR）

  • 显示

    • RGB 1920x1080x24bpp

    • 四线电阻式触摸

  • 多媒体

    • 1 个摄像头并行接口

    • 1 个模拟音频线路输入（立体声）

    • 1 个模拟音频麦克风输入（单声道）

    • 1 个模拟音频耳机输出（立体声）

  • 连接

    • USB 2.0 OTG（高速）

    • USB 2.0 主机（高速）

    • 10/100 Mbit/s 以太网 PHY

    • 4x I2C

    • 4x SPI

    • 7x UART

    • 1x IrDA

    • 20x PWM

    • 最多 125 个 GPIO

    • 4 个模拟输入（12 位）

    • 2x SDIO/SD/MMC (8 Bit)

    • 2x CAN

有关 i.MX7 SoC 的更多信息，请参阅：

  • i.MX 7 Series Website

  • i.MX 7 Dual Datasheet

  • i.MX 7 Dual Reference Manual

编程与调试

96Boards Meerkat96 开发板没有供 M4 使用的 QSPI Flash，需要由 A7 核启动它。A7 核负责将 M4 二进制应用程序加载到 RAM 中，使 M4 进入复位，设置 M4 的程序计数器和栈指针，然后使 M4 退出复位。A7 可以在引导加载程序阶段或 Linux 系统启动后执行这些步骤。

编译时必须选择要使用的 RAM。该配置在文件 boards/96boards/meerkat96/96b_meerkat96_mcimx7d_m4.dts 中通过 "zephyr,flash"（当 CONFIG_XIP=y 时）和 "zephyr,sram" 属性完成。可用的配置如下：

"zephyr,flash"
- &ddr_code
- &tcml_code
- &ocram_code
- &ocram_s_code
- &ocram_pxp_code
- &ocram_epdc_code

"zephyr,sram"
- &ddr_sys
- &tcmu_sys
- &ocram_sys
- &ocram_s_sys
- &ocram_pxp_sys
- &ocram_epdc_sys

下面介绍如何在 A7 上使用 u-boot 将 Zephyr 加载到 M4 并运行。

将编译好的 zephyr.bin 复制到 SD 卡的第一个 FAT 分区，再将 SD 卡插入开发板。给开发板上电并停止 u-boot 的执行。设置 u-boot 环境变量，然后从 Zephyr 编译时配置的相应存储器中运行 zephyr.bin：

setenv bootm4 'fatload mmc 0:1 $m4addr $m4fw && dcache flush && bootaux $m4addr'
# TCML
setenv m4tcml 'setenv m4fw zephyr.bin; setenv m4addr 0x007F8000'
setenv bootm4tcml 'run m4tcml && run bootm4'
run bootm4tcml
# TCMU
setenv m4tcmu 'setenv m4fw zephyr.bin; setenv m4addr 0x00800000'
setenv bootm4tcmu 'run m4tcmu && run bootm4'
run bootm4tcmu
# OCRAM
setenv m4ocram 'setenv m4fw zephyr.bin; setenv m4addr 0x00900000'
setenv bootm4ocram 'run m4ocram && run bootm4'
run bootm4ocram
# OCRAM_S
setenv m4ocrams 'setenv m4fw zephyr.bin; setenv m4addr 0x00180000'
setenv bootm4ocrams 'run m4ocrams && run bootm4'
run bootm4ocrams
# DDR
setenv m4ddr 'setenv m4fw zephyr.bin; setenv m4addr 0x80000000'
setenv bootm4ddr 'run m4ddr && run bootm4'
run bootm4ddr

调试

可以将外部 JLink JTAG 调试器连接到 J4 调试连接器来调试 96Boards Meerkat96 开发板。然后下载并安装 J-Link Tools 和 NXP iMX7D Connect CortexM4.JLinkScript。

要使用 J-Link 运行 Zephyr 二进制文件，请创建以下脚本，从 zephyr.bin 中获取程序计数器和栈指针。

get-pc-sp.sh: .. code-block:: console

#!/bin/sh

firmware=$1

pc=$(od -An -N 8 -t x4 $firmware | awk '{print $2;}') sp=$(od -An -N 8 -t x4 $firmware | awk '{print $1;}')

echo pc=$pc echo sp=$sp

从固件二进制文件获取 SP 和 PC：./get-pc-sp.sh zephyr.bin .. code-block:: console

pc=00900f01 sp=00905020

将 J-Link 连接到开发板和 PC，然后运行 J-Link 命令行工具：

/usr/bin/JLinkExe -device Cortex-M4 -if JTAG -speed 4000 -autoconnect 1 -jtagconf -1,-1 -jlinkscriptfile iMX7D_Connect_CortexM4.JLinkScript

运行 zephyr.bin 需要以下步骤：

  1. 使 M4 内核进入复位状态

  2. 将二进制文件加载到相应地址（TMCL、TCMU、OCRAM、OCRAM_S 或 DDR）

  3. 设置 PC（程序计数器）

  4. 设置 SP（栈指针）

  5. 使 M4 内核退出复位状态

在 J-Link Commander 中执行以下命令：

w4 0x3039000C 0xAC
loadfile zephyr.bin,0x00900000
w4 0x00180000 00900f01
w4 0x00180004 00905020
w4 0x3039000C 0xAA

借助这些机制，即可照常构建和调试 96b_meerkat96 开发板配置的应用程序（详见 构建应用程序 和 运行应用程序）。
