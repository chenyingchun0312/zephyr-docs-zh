96Boards WisTrio

概述

96Boards WisTrio LoRa Tracker 开发板基于 RAK Wireless RAK5205 芯片组，集成了 SX1276 LoRaWAN 调制解调器、STM32L151CB-A MCU 和 GPS 模块。Zephyr 应用程序使用 96b_wistrio 配置在这些开发板上运行。

该开发板是提供 LoRa 连接的 96Boards IoT Edition [5] 平台之一。

硬件

96Boards WisTrio 提供以下硬件组件：

  • RAK5205 芯片组

  • 3.3V 工作电压

  • 128 KB Flash

  • 16 KB SRAM

  • 板载传感器：

    • 加速度计：STMicro LIS3DH

    • 集成环境传感器：Bosch BME680

  • 2 个用户 LED

  • 支持外部中断的 GPIO

  • UART (2)

  • I2C (1)

  • GPS 模块

  • GPS 天线

  • LoRa 天线

支持的功能

96b_wistrio 开发板支持下列硬件功能。

说明

The list of supported hardware features was not generated. Run a full documentation build for the required metadata to be available.

连接与 IO

LED

  • LED1 / User1 LED = PA12

  • LED2 / User2 LED = PB4

按键

  • BUTTON = RST (BT1)

串口

96Boards WisTrio 开发板有 2 个 UART。Zephyr 控制台输出分配给 USART1，默认设置为 115200 8N1；USART3 用于 GPS 模块。

I2C

96Boards WisTrio 开发板有 1 个 I2C，连接到板载传感器。默认的 I2C 映射如下：

  • I2C1_SCL : PB8

  • I2C1_SDA : PB9

I2C1 还连接到 J22 连接器，可用于连接外部传感器。

SPI

96Boards WisTrio 开发板有 1 个 SPI，连接到片上 LoRa 无线电。默认的 SPI 映射如下：

  • SPI1_SCLK : PA5

  • SPI1_MISO : PA6

  • SPI1_MOSI : PA7

  • SPI1_NSS : PB0

编程与调试

烧录

96Boards WisTrio 有两种烧录方法：一种使用 ROM 引导加载程序，另一种使用 SWD 调试端口（需要额外的硬件）。

使用 ROM 引导加载程序烧录需要特殊的激活方式，可通过 BOOT0 引脚触发。ROM 引导加载程序支持通过 UART 和 I2C 烧录，但本文档只介绍 UART 方式。有关如何启用和使用 ROM 引导加载程序的更多信息，请参阅应用笔记 AN2606 [1]。

使用 ROM 引导加载程序：

  1. 使用 USB Micro 转 USB-A 线缆将 96Boards WisTrio 连接到 Linux PC。

  2. 可以通过以下方式触发 ROM 引导加载程序：

    • 将 BOOT0 连接到 VDD（短接 J12 的引脚 1 和 2）

    • 按下并松开 RST 按键

有关激活 ROM 引导加载程序的更多详细信息，请参阅应用笔记 AN2606 [1] 第 29 章。ROM 引导加载程序支持通过 UART 和 I2C 协议烧录。

以下示例演示如何使用 stm32flash [2] 命令行工具构建并烧录 Hello World 应用程序：

# From the root of the zephyr repository
west build -b 96b_wistrio samples/hello_world
west flash
使用 SWD 调试器：

使用 Black Magic Debug Probe [3] 作为 SWD 编程器，通过其飞线和 20 针 JTAG 转接板套件连接到 J22 排针上引出的 SWD 引脚。插入主机 PC 后，Black Magic Debug Probe 会枚举为 USB 串口设备，详见其 Getting started page [4]。

它还使用 Zephyr SDK 提供的 GDB 二进制文件 arm-zephyr-eabi-gdb。也可以使用其他 GDB 二进制文件，例如 GCC ARM Embedded 中的 GDB。

$ arm-zephyr-eabi-gdb -q zephyr.elf
(gdb) target extended-remote /dev/ttyACM0
Remote debugging using /dev/ttyACM0
(gdb) monitor swdp_scan
Target voltage: 3.3V
Available Targets:
No. Att Driver

调试

烧录 96Boards WisTrio 后，可以使用同一个 GDB 实例对其进行调试。要重新连接，只需按照上述相同步骤执行到 "attach 1" 为止。之后即可照常使用 GDB 调试。特别地，在 GDB 提示符下输入 "run" 可重新启动已烧录的程序。
