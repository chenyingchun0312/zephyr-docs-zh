SK-AM62 Evaluation board

Board Overview

Name:
sk_am62
Vendor:

Texas Instruments

Status:

Not actively maintained

Architecture:

arm, arm64

SoC:

am6254

Browse board sources

概述

SK-AM62 开发板配置供运行在 TI AM62x 平台上的 Zephyr 应用程序使用。该配置支持两种开发板变体：

  • SK-AM62（基础变体）

  • SK-AM62B-P1（集成 PMIC 的变体）

两种变体都使用 AM6254 SoC。该开发板配置支持：

  • ARM Cortex-M4F MCU 核及以下特性：

    • 嵌套向量中断控制器（NVIC）

    • 系统节拍时钟（SYSTICK）

  • ARM Cortex-A53 核及以下特性：

    • 通用中断控制器（GIC）

    • ARM 通用定时器（arch_timer）

    • 片上 SRAM（oc_sram）

    • UART 接口（uart0 至 uart6）

    • 邮箱接口（mbox0）

本开发板配置还启用了对半主机（semihosting）调试控制台的支持。

详情请参阅 TI AM62X Product Page。

硬件

SK-AM62 EVM 搭载 AM6254 SoC，该 SoC 由一个四核 Cortex-A53 集群和 MCU 域中的一个 Cortex-M4 内核组成。Zephyr 已移植到 M4F 和 A53 内核上运行。使用了以下硬件规格：

  • 高性能 ARM Cortex-A53

  • 低功耗 ARM Cortex-M4F

  • 内存

    • 256KB of SRAM

    • 2GB of DDR4

  • 调试

    • 基于 XDS110 的 JTAG

设备

系统时钟

本开发板配置使用 400 MHz 的系统时钟频率。

DDR RAM

本开发板有 2GB DDR RAM 可用。该开发板配置为 Zephyr 分配 4kB RAM（仅用于资源表：0x9CC00000 至 0x9CC00400）。

串口

本开发板配置使用 MCU 域的 UART（MCU_UART0）作为唯一的串行通信通道。

SD 卡

下载 TI 官方的 WIC，并使用镜像烧写软件将 WIC 文件写入 SD 卡。这样 EVM 的 A53 应用内核会启动 Linux。为 M4 内核编程时，A53 内核会通过 remoteproc 将 zephyr 二进制文件加载到 M4 内核上。

为 M4F 内核编程

该开发板可以使用 remoteproc，并借助 OpenAMP 资源表实现这一点。

测试时需要将二进制文件复制到 SD 卡，以便 A53 内核在启动时通过 remoteproc 加载它。

要测试 M4F 内核，可使用以下命令构建 Hello World 示例。

# From the root of the Zephyr repository
west build -p -b sk_am62/am6254/m4 samples/hello_world

该命令会构建程序，生成的二进制文件位于 build/zephyr 目录下，名为 zephyr.elf。

现在将该二进制文件复制到 SD 卡的 /lib/firmware 目录中，并命名为 am62-mcu-m4f0_0-fw。

# Mount the SD card at sdcard for example
sudo mount /dev/sdX sdcard
# copy the elf to the /lib/firmware directory
sudo cp --remove-destination zephyr.elf sdcard/lib/firmware/am62-mcu-m4f0_0-fw

现在可以使用该 SD 卡进行引导。启动时，二进制文件将被加载到 M4F 内核上。

要让开发板从 SD 卡启动，请将启动引脚设置为 SD 卡启动模式。参见 EVM Setup Page。

更改启动模式后，开发板上电时应完成启动流程。二进制文件随后运行，并向 MCU_UART0 端口打印 Hello world。

为 A53 内核编程

将编译生成的 zephyr.bin 复制到 SD 卡的第一个 FAT 分区，然后将 SD 卡插入开发板。给开发板上电，并在提示符处中止 u-boot 的执行。

使用 U-Boot 加载并启动 zephyr.bin：

fatload mmc 1:1 0x82000000 zephyr.bin; go 0x82000000

Zephyr 应用程序应当开始在 A53 内核上运行。运行 hello_world 示例时，应能看到类似如下的输出：

*** Booting Zephyr OS build v4.3.0-4646-g13fc152f3546 ***
Secondary CPU core 1 (MPID:0x1) is up
Secondary CPU core 2 (MPID:0x2) is up
Secondary CPU core 3 (MPID:0x3) is up
Hello World! sk_am62/am6254/a53

这表明全部四个 A53 内核均已成功启动。

调试

本开发板配备 XDS110 JTAG 调试器。要调试二进制文件，请使用 debug 构建目标：

  • M4F 内核

west build -b sk_am62/am6254/m4 <my_app>
west debug

  • A53 内核

west build -b sk_am62/am6254/a53 <my_app>
west debug

提示

要使用此功能，需要 OpenOCD 0.12 或更高版本。由于软件包源中可能提供的是旧版本，建议从源码构建 OpenOCD（参见 build OpenOCD from source）。
