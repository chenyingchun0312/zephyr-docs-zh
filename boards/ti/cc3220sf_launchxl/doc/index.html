CC3220SF LaunchXL

Board Overview

Name:
cc3220sf_launchxl
Vendor:

Texas Instruments

Status:

Not actively maintained

Architecture:

arm

SoC:

cc3220sf

Browse board sources

概述

SimpleLink Wi-Fi CC3220SF LaunchPad 开发套件（CC3220SF-LAUNCHXL）以 CC3220SF 为核心。CC3220SF 是一款单芯片无线微控制器（MCU），具有 1MB 内部 Flash、4MB 外部串行 Flash、256KB RAM 以及增强的安全功能。

详情请参阅 TI CC3220 Product Page。

功能：

  • 两个独立的执行环境：一个专用于用户应用程序的 ARM Cortex-M4 MCU，以及一个运行所有 Wi-Fi 和互联网逻辑层的网络处理器 MCU

  • 40 针 LaunchPad 标准，可利用 BoosterPack 生态系统

  • 板载加速度计和温度传感器

  • 两个按键和三个 LED，用于用户交互

  • 通过 USB 连接 PC 的 UART

  • BoosterPack 插件模块，可添加图形显示屏、音频编解码器、天线选择、环境传感等功能

  • 通过 USB 为 LaunchPad 和可选的外部 BoosterPack 供电

  • 基于 XDS110 的 JTAG 仿真，带用于 Flash 编程的串口

CC3220SF LaunchXL 开发板的详细信息请参阅 CC3220SF LaunchPad Dev Kit Hardware User's Guide。

硬件

CC3220SF SoC 包含两个 MCU：

  1. 应用 MCU：80 MHz ARM® Cortex®-M4 核，带 256Kb RAM，可访问外部 4MB 串行 Flash，ROM 中包含引导加载程序和外设驱动。

  2. 网络协处理器（NWP）：专用的 ARM MCU，可完全分担应用 MCU 的 Wi-Fi 和互联网协议处理。

CC3220SF SoC 的完整详细信息请参阅 CC3220 TRM。

备注

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

TI 官方支持在 Windows 和 Linux 上使用 TI CC3220 SDK 及 TI 工具在 CC3220SF 上进行开发：使用 Code Composer Studio 调试，使用 UniFlash 烧录。

Windows 开发者请参阅 CC3220 Getting Started Guide，了解工具的安装方法以及如何使用 UniFlash 烧录开发板。

注意，Zephyr SDK 生成的 zephyr.bin 可能无法通过 UniFlash 工具加载。如果遇到问题，请改用 zephyr.elf 文件和 openocd（见下文）。

以下说明面向更喜欢命令行工具而不是 IDE 的 Linux 开发者。

在烧录和调试开发板之前，需要完成一些一次性的开发板设置步骤。

前提条件：

  1. 下载并安装最新版本的 UniFlash。

  2. 将跳线 SOP[2..0]（J15）设为 [010]，然后将 USB 线连接到 PC。

    此时 /dev/ttyACM1 和 /dev/ttyACM0 处应出现一个新设备 "Texas Instruments XDS110 Embed with CMSIS-DAP"。

  3. 更新服务包（service pack），并将开发板置于 "Development Mode"（开发模式）。

    设置 "Development Mode" 会启用 JTAG 接口，后续使用 OpenOCD 和更新 XDS110 固件都需要该接口。

    按照 CC3220 Getting Started Guide 中第 2.4 节“Download the Application”的说明操作，但跳过第 2.4.1 节中用于选择 MCU 镜像的第 5 步和第 6 步。

  4. 确保 XDS-110 仿真固件已更新。

    下载并安装最新的 XDS-110 emulation package。

    按照 xds110 固件更新说明 操作

    注意，安装仿真软件包后，xdsdfu 工具可能位于 <install_dir>/ccs_base/common/uscif/xds110/。

  5. 将跳线 SOP[2..0]（J15）改回 [001]。

    更换跳线前，请先断开开发板电源（拔下 USB 线）。

  6. 安装 OpenOCD

    可以按照 安装最新 Zephyr SDK 的说明 获取 OpenOCD。

    安装完成后，将包含 OpenOCD 可执行文件的目录添加到环境变量 PATH 中。例如，在 Linux 中使用以下命令：

    export PATH=$ZEPHYR_SDK_INSTALL_DIR/sysroots/x86_64-pokysdk-linux/usr/bin/openocd:$PATH

    如果之前安装过 TI OpenOCD，可以直接改用 Zephyr SDK 中的 OpenOCD。如果出于某些原因希望继续使用已安装的 TI OpenOCD，可以在包含通用的 openocd.board.cmake 文件之前，在 boards/ti/cc3220sf_launchxl/board.cmake 中设置 OPENOCD 和 OPENOCD_DEFAULT_PATH 变量，使构建指向 OpenOCD 二进制文件及其脚本的路径：

    set(OPENOCD "/usr/local/bin/openocd" CACHE FILEPATH "" FORCE)
set(OPENOCD_DEFAULT_PATH /usr/local/share/openocd/scripts)
include(${ZEPHYR_BASE}/boards/common/openocd.board.cmake)

  7. 确保设置了 CONFIG_XIP=y（默认）。

    这会将程序放入 Flash，并设置 CONFIG_CC3220SF_DEBUG=y。该选项会在镜像前添加一个调试头，使 Flash 中的程序在后续重启后依然保留，从而绕过引导加载程序的 Flash 签名验证。

    有关安全 Flash 启动过程的详细信息，请参阅 CC3220 TRM 第 21.10 节“Debugging Flash User Application Using JTAG”。

满足上述前提条件后，即可按照 Zephyr 应用程序开发入门（见 构建应用程序 和 运行应用程序），使用 openocd 和 gdb 构建、烧录和调试 _cc3220sf_launchxl 开发板的应用程序。

烧录

要构建并烧录应用程序，请针对 <my_app> 执行以下命令：

west build -b cc3220sf_launchxl <my_app>
west flash

这会将镜像加载到 Flash。

要查看 UART0 的程序输出，请连接一个单独的终端窗口：

% screen /dev/ttyACM0 115200 8N1

然后按下开发板上的复位按键（SW1）运行程序。

使用 Zephyr SDK 中的 OpenOCD 烧录设备时，如果程序使用了网络处理器，可能会发现程序在启动设备上的网络处理器时卡住。这是该版本 OpenOCD 复位网络处理器的方式存在的已知问题。烧录后需要手动按下开发板上的复位按键，才能正确复位设备。

调试

要调试之前烧录的镜像，在复位开发板后使用 'debug' 构建目标：

west build -b cc3220sf_launchxl <my_app>
west debug

Wi-Fi 支持

从 SimpleLink SDK 引入的 SimpleLink Host Driver 已移植到 Zephyr，通过专用 SPI 与网络协处理器通信。它以 Zephyr Wi-Fi 设备驱动的形式提供，位于 drivers/wifi/simplelink。

用法：

将 CONFIG_WIFI_SIMPLELINK 和 CONFIG_WIFI 设置为 y 以启用 Wi-Fi。参见 samples/net/wifi/shell/boards/cc3220sf_launchxl.conf。

配网：

SimpleLink 提供了几种相当复杂的 Wi-Fi 配网方法。为了简化 Zephyr 开发和演示，这里启用了 SimpleLink 的“Fast Connect”策略，并采用单次扫描。这样 cc3220sf_launchxl 可以自动重新连接到上一次连接成功的接入点（AP），无需重新扫描，也无需重新指定 SSID 和密码。

要连接到 AP，请先运行 Zephyr Wi-Fi shell 示例应用程序，使用 SSID 和密码连接到一个已知 AP。

See Wi-Fi shell

连接成功后，网络协处理器会将该 AP 的身份信息保存在其持久性存储器中。此后新加载的 Wi-Fi 应用程序无需再显式执行任何 Wi-Fi 扫描或连接操作，直到需要更换为新的 AP 为止。

安全套接字卸载

SimpleLink Wi-Fi 驱动向 Zephyr 套接字卸载点提供套接字操作。将 CONFIG_NET_SOCKETS_OFFLOAD 设置为 y 后，Zephyr BSD 套接字 API 调用会被转交给 SimpleLink Wi-Fi 驱动。

安全套接字（TLS）通信作为套接字 API 的一部分处理，通过以下方式启用：

  • 将 CONFIG_NET_SOCKETS_SOCKOPT_TLS 和 CONFIG_TLS_CREDENTIAL_FILENAMES 都设置为 y；

  • 使用 TI Uniflash 工具将所需的证书和密钥编程到安全 Flash 文件系统中，并启用 TI 受信任根证书目录（Trusted Root-Certificate Catalog）。

示例请参阅 HTTP GET using plain sockets 和 samples/net/sockets/http_get/boards/cc3220sf_launchxl.conf。

有关使用 TI UniFlash 工具编程证书的详细信息，请参阅文档 Simplelink Wi-Fi Certificates Handling。
