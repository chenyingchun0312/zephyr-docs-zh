FlySky FS-i6S

Board Overview

Name:
fs_i6s
Vendor:

FlySky

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32f072xb

Browse board sources

概述

FlySky FS-i6s 是一款 10 通道 2.4GHz 遥控发射机，常用于遥控多旋翼和固定翼飞行器。其内部硬件由意法半导体 STM32F072VB 微控制器驱动，配有电容触摸屏、实体摇杆、开关、按键和集成射频模块。

硬件

  • STM32F072VB，采用 LQFP100 封装

  • ARM® 32 位 Cortex®-M0 CPU

  • CPU 最高频率 48 MHz

  • VDD 范围 2.0 V 至 3.6 V

  • 128 KB Flash

  • 16 KB SRAM

  • 支持外部中断的 GPIO

  • 39 通道 12 位 ADC

  • 12 位 D/A 转换器

  • RTC

  • 通用定时器（12 个）

  • USART/UART (4)

  • I2C (2)

  • SPI (2)

  • CAN

  • USB 2.0 全速接口

  • DMA 控制器

支持的功能

fs_i6s 开发板支持下列硬件功能。

Zephyr 默认外设映射：

LED 和音频

  • LCD 背光： PF3（屏幕背光控制）

  • 左电源 LED： PD10（左电源按键下方的蓝色 LED）

  • 右电源 LED： PD11（右电源按键下方的蓝色 LED）

  • 蜂鸣器： PA8（压电蜂鸣器，可由 TIM1_CH1 驱动）

按键与电源管理

备注

两个实体电源按键必须同时按下才会触发相关的 GPIO，无法单独读取单个按键的按下状态。

  • 电源按键： PB14（两个电源按键同时按下）

  • 背面左按键： PA9（背面的轻触按键）

  • 背面右按键： PA10（背面的轻触按键）

  • 关机触发： PB15（用于触发系统关机）

模拟输入（ADC）

所有摇杆、电位器和拨动开关都通过 STM32 的 ADC 多路复用器读取。

  • 右摇杆左/右： PA0、ADC_CH0（右摇杆水平轴）

  • 右摇杆上/下： PA1、ADC_CH1（右摇杆垂直轴）

  • 左摇杆上/下： PA2、ADC_CH2（左摇杆垂直轴，油门）

  • 左摇杆左/右： PA3、ADC_CH3（左摇杆水平轴）

  • 开关 A（左）： PA4、ADC_CH4（两档拨动开关）

  • 开关 B（左）： PA5、ADC_CH5（三档拨动开关）

  • 左拨轮： PA6、ADC_CH6（左侧比例肩部拨轮）

  • 右拨轮： PA7、ADC_CH7（右侧比例肩部拨轮）

  • 开关 C（右）： PB0、ADC_CH8（三档拨动开关）

  • 开关 D（右）： PB1、ADC_CH9（两档拨动开关）

  • 电池电压： PC0、ADC_CH10（需要换算，分压电阻：R9=10kΩ，R10=5.1kΩ 接 GND）

显示屏（Sitronix ST7567）

LCD 使用 Sitronix ST7567 控制器，通过 8 位并行接口连接到 MCU。

  • LCD_D0 - D7： PE0 - PE7（8 位数据总线）

  • LCD_RS： PB3（寄存器选择 / 数据命令）

  • LCD_RST： PB4（硬件复位）

  • LCD_RW: PB5 (Read/Write)

  • LCD_RD： PD7（读使能）

  • LCD_CS： PD2（片选）

触摸控制器（Focaltech FT6236）

电容触摸层由 FT6236 驱动，通过 I2C1 通信。

  • TOUCH_SCL： PB8（I2C1 时钟）

  • TOUCH_SDA： PB9（I2C1 数据）

  • TOUCH_INT： PC12（FT6236 中断输出）

  • TOUCH_RST： PA15（硬件复位）

USART

  • UART_1_TX: PB6

  • UART_1_RX: PB7

射频模块（仅供参考，未使用）

内部射频模块标记为 FS-HS060，包含一颗 XL7105 收发器以及 PA/LNA 芯片。

  • SPI Lines: PE15 (SDIO), PE13 (SCK), PE12 (SCS)

  • Control Lines: PE11 (RF1), PE10 (RF0), PE8 (RX-W), PE9 (TX-W)

  • Interrupts: PB2 (GIO2), PE14 (GIO1)

SWD 接口

PCB 上有标注好的串行线调试（SWD）接口测试点，便于焊接排针以连接 ST-Link 或 J-Link 编程器。也可以通过板上的小型 J4 连接器访问这些信号：

  • SWDIO

  • SWCLK

  • NRST

  • GND

DFU 引导加载程序

由于 STM32F072 内置 USB DFU 引导加载程序，无需专用 SWD 编程器即可烧录 Zephyr。视具体设备而定，可能需要先使用 ST-Link SWD 关闭内部 Flash 的写保护位。

进入 DFU 模式：

  1. 找到电阻 R59 和 R60（连接到 BOOT1 引脚）。

  2. 短接 R60。

  3. 连接电池（或 USB）。

  4. 同时按下两个电源按键。

  5. 设备应在 PC 上枚举为 "STM32 BOOTLOADER" 设备，此时可以使用 dfu-util 烧录 Zephyr 的 .bin 文件。

烧录应用程序

本开发板支持 dfu-util 运行器，因此可以方便地构建和测试示例。

# From the root of the zephyr repository
west build -b fs_i6s samples/basic/blinky
west flash
