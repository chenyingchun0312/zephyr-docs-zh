MIMXRT1060-EVK

Board Overview

Name:
mimxrt1060_evk
Vendor:

NXP Semiconductors

Status:

Not actively maintained

Architecture:

arm

SoC:

mimxrt1062

Browse board sources

概述

i.MX RT1060 加入了业界首个跨界处理器系列，并将 i.MX RT 系列扩展为三个可扩展的产品系列。

i.MX RT1060 将片上 SRAM 翻倍至 1MB，同时与 i.MX RT1050 保持引脚兼容。该系列引入了非常适合实时应用的附加功能，例如高速 GPIO、CAN FD 以及同步并行 NAND/NOR/PSRAM 控制器。i.MX RT1060 运行在最高 600 MHz 的 Arm® Cortex-M7® 内核上。

硬件

  • MIMXRT1062DVL6A MCU（600 MHz，1024 KB 片上存储器）

  • 内存

    • 256 Mbit SDRAM

    • 64 Mbit QSPI Flash

    • 512 Mbit Hyper Flash

    • 用于 SD 卡的 TF 卡座

  • 显示

    • LCD 连接器

  • 以太网

    • 10/100 Mbit/s 以太网 PHY

  • USB

    • USB 2.0 OTG 连接器

    • USB 2.0 主机连接器

  • 音频

    • 3.5 mm 立体声耳机插孔

    • 板载麦克风

    • 左、右扬声器输出连接器

  • Power

    • 5 V 直流电源插孔

  • 调试

    • 20 针 JTAG 连接器

    • 带 DAPLink 的 OpenSDA

  • 传感器

    • FXOS8700CQ 6 轴电子罗盘

    • CMOS 摄像头传感器接口

  • 扩展端口

    • Arduino 接口

  • CAN 总线连接器

系统时钟

MIMXRT1060 SoC 配置为使用 SysTick 作为系统时钟源，运行频率为 600MHz。

启用电源管理后，开发板上的 32 KHz 低频振荡器将用作 GPT 定时器的时钟源来产生系统时钟。该时钟可支持更低功耗的状态，代价是分辨率降低

串口

MIMXRT1060 SoC 有八个 UART。LPUART1 配置为控制台，LPUART3 用于 Bluetooth 主机控制器接口（BT HCI），其余未使用。

开发板版本与构建目标

该开发板有三个版本。

Rev A:

  • 初始版本

Rev B:

  • 增加了用于 Wi-Fi/BLE 的 M.2 连接器

  • 增加了音频扩展连接器 J23

  • USER LED1 改为 GPIO1 引脚 8

Rev C:

  • 音频编解码器由 WM8960（已停产）更换为 WM8962

  • 32.768 KHz 振荡器由 ASH7K-32.768KHz-T（已停产）更换为 ASH7KW-32.768KHZ-L-T

  • 运动传感器由 FXOS8700CQ（已停产）更换为 FXLS8974CFR3

  • Bluetooth 音频 PCM 重新分配到专用的 I2S2

  • Bluetooth 接口的 UART_CTS、UART_RTS 重新分配到硬件引脚

根据将哪个 Flash 设置为 zephyr,flash，本开发板有两个可选的变体：

  • mimxrt1060_evk/mimxrt1062/qspi 是默认变体，对应开发板使用 qspi Flash 的出厂配置。

  • mimxrt1060_evk/mimxrt1062/hyperflash 适用于经过改装、使用 hyperflash 代替 qspi Flash 的开发板。

  • 该开发板还有两个版本：EVKA 和 EVKB。EVKA 是该开发板的默认目标。若要以 EVKB 为目标，开发板目标字符串应改为例如 mimxrt1060_evk@B//qspi。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

该开发板支持 4 种调试主机工具。请安装你偏好的主机工具，然后按照 Configuring a Debug Probe 中的说明对开发板进行相应配置。

  • J-Link 调试主机工具（NXP 提供支持）

  • LinkServer 调试主机工具 （NXP 支持）

  • IAR EW 与 C-Spy 主机工具（NXP 不支持）

  • pyOCD 调试主机工具（NXP 不支持）

配置好主机工具和开发板后，按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

配置调试探针

RT1060 EVK 共有三个版本。对于所有版本，要更换调试固件，请短接 DFU 跳线，使板载调试器启动进入 ISP 模式。

  • RT1060 EVK（版本 A）

    • SWD 隔离跳线：J47/48

    • 20 针 JTAG/SWD 排针：J21

    • DFU 模式跳线：J42

  • RT1060 EVKB

    • SWD 隔离跳线：J9/10

    • 20 针 JTAG/SWD 排针：J2

    • DFU 模式跳线：J12

  • RT1060 EVKC

    • 调试器选择跳线：JP5

    • DFU 模式跳线：JP3

调试探针既用于烧录也用于调试开发板。本开发板带有 LPC-LINK2 板载调试探针，该探针中的默认固件为 LPC-Link2 DAPLink 板载调试探针。

根据所安装的主机工具，按以下说明设置调试探针：

  • J-Link 调试主机工具: Using J-Link with LPC-Link2 Probe

  • LinkServer 调试主机工具: Using CMSIS-DAP with LPC-Link2 Probe

  • pyOCD 调试主机工具: Using CMSIS-DAP with LPC-Link2 Probe

通过 LPC-Link2 探针使用 CMSIS-DAP

  1. 按照 LPC-LINK2 CMSIS DAP 板载调试探针 中的说明，重新烧写本开发板上默认的调试探针固件。

  2. 确保已安装 SWD 隔离跳线

通过 LPC-Link2 探针使用 J-Link

有两种方式：将板载调试电路更新为 Segger J-Link 固件，或者将 J-Link 外部调试探针 连接到 EVK。

要更新板载调试电路，请执行以下操作：

  1. 将 EVK 的电源切换为调试 USB 以外的其他电源，因为 J-Link 固件不会通过调试 USB 为 EVK 供电。

  2. 按照 LPC-Link2 J-Link 板载调试探针 中的说明，重新烧写本开发板上默认的调试探针固件。

  3. 确保已安装 SWD 隔离跳线。

要连接外部 J-Link 探针，请确保已移除 SWD 隔离跳线，然后将探针连接到外部 JTAG/SWD 排针

更多详细信息，请参阅 Using J-Link with MIMXRT1060-EVK or MIMXRT1064-EVK 或 Using J-Link with MIMXRT1060-EVKB。

配置控制台

无论选择哪种调试探针，串口控制台都使用 OpenSDA 微控制器作为 USB 转串口适配器。请检查跳线 J45 和 J46 是否处于 接通 状态（开发板出厂时默认接通），以便将 UART 信号连接到 OpenSDA 微控制器。

使用 USB 线将 PC 连接到 J41。

在你选用的串口终端（minicom、putty 等）中使用以下设置：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

使用 SWO

设置 CONFIG_LOG_BACKEND_SWO=y 即可将 SWO 用作日志后端。SWO 查看器应配置为 CPU 频率 132MHz、SWO 频率 7500KHz。

故障排除

如果调试探针连接失败并出现以下错误，可能是 QSPI Flash 中的启动头无效或已损坏。启动头由 CONFIG_NXP_IMXRT_BOOT_HEADER 配置。

Remote debugging using :2331
Remote communication error.  Target disconnected.: Connection reset by peer.
"monitor" command not supported by this target.
"monitor" command not supported by this target.
You can't do that when your target is `exec'
(gdb) Could not connect to target.
Please check power, connection and settings.

可以按以下步骤擦除并重新编程 QSPI Flash 来解决该问题：

  1. 将 SW7 拨码开关设为 ON-OFF-ON-OFF，以防止从 QSPI Flash 启动。

  2. 按下 SW9 复位

  3. 使用一个确认可正常工作的 Zephyr 应用程序再次运行 west debug 或 west flash。

  4. 将 SW7 拨码开关设为 OFF-OFF-ON-OFF，以从 QSPI Flash 启动。

  5. 按下 SW9 复位

如果 west flash 或 debug 命令失败，且命令在执行 runners.jlink 时卡住，请确认 J-Link 调试探针已正确配置、上电并连接到 EVK。
