MIMXRT1170-EVK

Board Overview

Name:
mimxrt1170_evk
Vendor:

NXP Semiconductors

Status:

Not actively maintained

Architecture:

arm

SoC:

mimxrt1176

Browse board sources

概述

双核 i.MX RT1170 的 Cortex-M7 内核运行在 1 GHz，Cortex-M4 内核运行在 400 MHz。i.MX RT1170 MCU 支持宽温度范围，并通过了消费、工业和汽车市场的认证。Zephyr 支持该 EVK 的初始版本以及 EVKB 版本。

硬件

  • MIMXRT1176DVMAA MCU

    • 1GHz Cortex-M7 和 400Mhz Cortex-M4

    • 2MB SRAM，其中 Cortex-M7 有 512KB TCM，Cortex-M4 有 256KB TCM

  • 内存

    • 512 Mbit SDRAM

    • 128 Mbit QSPI Flash

    • 512 Mbit 八线 Flash

    • 2 Gbit 裸 NAND Flash

    • 64 Mbit LPSPI Flash 存储器

    • 用于 SD 卡的 TF 卡座

  • 显示

    • MIPI LCD 连接器

  • 以太网

    • 10/100 Mbit/s 以太网 PHY

    • 10/100/1000 Mbit/s 以太网 PHY

  • USB

    • USB 2.0 OTG 连接器

    • USB 2.0 主机连接器

  • 音频

    • 3.5 mm 立体声耳机插孔

    • 板载麦克风

    • 左、右扬声器输出连接器

  • Power

    • 5 V 直流电源插孔

  • 调试

    • 20 针 JTAG 连接器

    • 板载调试器

  • 传感器

    • FXOS8700CQ 6 轴电子罗盘

    • MIPI 摄像头传感器连接器

  • 扩展端口

    • Arduino 接口

    • M.2 WIFI/BT 接口

  • CAN 总线连接器

用于支持功能的扩展板

上表中的部分功能使用 Zephyr 扩展板（shield）进行了测试。以下扩展板已在本开发板上测试过：

  • NXP RK055HDMIPI4M MIPI 显示屏、NXP RK055HDMIPI4MA0 MIPI 显示屏 和 NXP G1120B0MIPI MIPI 显示屏 - 支持 MIPI-DSI 显示接口。

  • NXP BTB-44 OV5640 摄像头模块：支持 MIPI-CSI 视频/摄像头接口。

  • NXP M.2 Wi-Fi 和 BT 扩展板：EVK RevB 版本已使用该扩展板测试过，可连接任何带 BT HCI UART 接口和 Wi-Fi SDIO 接口的 M.2 模块。该扩展板会绑定所需的 NXP HCI 驱动或 SDIO 驱动，为 NXP SoC IW416/IW612/IW610 执行固件加载和其他设置配置。

系统时钟

MIMXRT1170 SoC 配置为使用 SysTick 作为系统时钟源，运行频率为 996MHz。以 M4 核为目标时同样使用 SysTick，运行频率为 400MHz

启用电源管理后，开发板上的 32 KHz 低频振荡器将用作 GPT 定时器的时钟源来产生系统时钟。该时钟可支持更低功耗的状态，代价是分辨率降低

串口

MIMXRT1170 SoC 有 12 个 UART。LPUART1 配置为控制台，LPUART2 用于 Bluetooth 主机控制器接口（BT HCI），其余未使用。

获取二进制 blob

开发板的蓝牙/WiFi 模块需要获取一些二进制 blob 文件，为此请运行以下命令：

west blobs fetch hal_nxp

备注

目前仅支持蓝牙功能。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

构建双核镜像

双核示例会将 M4 核镜像从 Flash 加载到共享的 ocram 区域，然后由 M7 核将 M4 的启动地址设置为该区域。目前唯一支持双核构建的示例是 openamp 示例。烧录双核示例时，必须先烧录 M4 镜像，使其写入 Flash，然后再烧录 M7 镜像。openamp sysbuild 示例通过设置镜像顺序自动完成这一过程。

在单核构建（目标为 mimxrt1170_evk/mimxrt1176/cm4）中，可以正常调试从内核。在双核构建中，应先让从内核进入循环，然后再连接调试器（详见 AN13264 第 4.2.3 节）

启动以 M4 核为目标的镜像

如果以 M4 核为目标进行构建，M7 核必须先运行代码来启动 M4 镜像：将镜像复制到 ocram 区域，然后启动 M4 核。使用 sysbuild 以 M4 核为目标构建时，会构建一个最小的“启动器（launcher）”镜像并烧录到 M7 核，由它加载并启动 M4 核。因此，开发打算在 M4 核上独立运行的应用程序时，建议使用 sysbuild 构建，如下所示：

# From the root of the zephyr repository
west build -b mimxrt1170_evk/mimxrt1176/cm4 --sysbuild samples/hello_world
west flash

如有需要，可以在构建时使用 -DSB_CONFIG_SECOND_CORE_MCUX_LAUNCHER=n 禁用此行为

配置调试探针

烧录和调试开发板都使用调试探针。下面列出的板载调试器默认与 LinkServer 运行器配合使用，也可以重新烧写为 JLink 固件。

  • MIMXRT1170-EVKB: MCU-Link CMSIS-DAP 板载调试探针

  • MIMXRT1170-EVK: OpenSDA DAPLink 板载调试探针

使用 LinkServer

安装 LinkServer 调试主机工具，并确保它们位于搜索路径中。LinkServer 可与板载调试器中自带的默认 CMSIS-DAP 固件配合使用。

使用 J-Link

安装 J-Link 调试主机工具，并确保它们位于搜索路径中。

有两种方式：将板载调试电路更新为 Segger J-Link 固件，或者将 J-Link 外部调试探针 连接到 EVK。更多详细信息，请参阅 Using J-Link with MIMXRT1170-EVKB 或 Using J-Link with MIMXRT1160-EVK or MIMXRT1170-EVK。

在 West 中使用 -r jlink 选项以使用 jlink 运行器（runner）。

west flash -r jlink

也可以在 west 中使用 -r pyocd 选项，用 pyOCD 烧录和调试开发板。完成入门指南中的 获取 Zephyr 并安装 Python 依赖项 步骤时会安装 pyOCD。NXP 支持的运行器为 LinkServer 和 JLink。pyOCD 也是一种可选方式，但 NXP 不测试也不支持 pyOCD 运行器。

配置控制台

使用板载调试器微控制器作为串口控制台的 USB 转串口适配器。以下跳线设置是这些开发板的默认设置，也是将 UART 信号连接到 USB 桥接电路所必需的：

  • MIMXRT1170-EVKB：JP2 断开（默认）

  • MIMXRT1170-EVK：J31 和 J32 短接（默认）

用 USB 线将 PC 连接到板载调试器的 USB 端口：

  • MIMXRT1170-EVKB: J86

  • MIMXRT1170-EVK: J11

在你选用的串口终端（minicom、putty 等）中使用以下设置：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

烧录

以下以 Hello World 应用程序为例。

开发板上电前，请确保 SW1 设置为 0001b

# From the root of the zephyr repository
west build -b mimxrt1170_evk/mimxrt1176/cm7 samples/hello_world
west flash

关闭开发板电源，将 SW1 改为 0010b。然后给开发板上电并打开串口终端，复位开发板（按下 SW4 按键），终端中应显示以下信息：

***** Booting Zephyr OS v3.4.0-xxxx-xxxxxxxxxxxxx *****
Hello World! mimxrt1170_evk

调试

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b mimxrt1170_evk/mimxrt1176/cm7 samples/hello_world
west debug

打开串口终端，在调试器中单步执行应用程序，终端中应显示以下信息：

***** Booting Zephyr OS v3.4.0-xxxx-xxxxxxxxxxxxx *****
Hello World! mimxrt1170_evk

ENET1G 驱动

以太网驱动当前默认使用 100M 以太网实例 ENET。要改用 1G 以太网实例 ENET1G，请在 west build 中通过选项 -DEXTRA_DTC_OVERLAY_FILE=nxp,enet1g.overlay 加入该覆盖文件。
