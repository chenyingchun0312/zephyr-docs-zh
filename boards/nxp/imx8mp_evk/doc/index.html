i.MX8MP EVK

Board Overview

Name:
imx8mp_evk
Vendor:

NXP Semiconductors

Status:

Not actively maintained

Architecture:

xtensa, arm, arm64

SoC:

mimx8ml8

Browse board sources

概述

i.MX8M Plus LPDDR4 EVK 开发板基于 NXP i.MX8M Plus 应用处理器，该处理器由一个四核 Cortex®-A53 集群和一个 Cortex®-M7 内核组成。Zephyr OS 已移植到 Cortex®-A53 内核上运行。

  • 开发板特性：

    • RAM: 2GB LPDDR4

    • 存储：

      • SanDisk 16GB eMMC5.1

      • Micron 32MB QSPI NOR

      • microSD 卡座

    • 无线：

      • WiFi: 2.4/5GHz IEEE 802.11b/g/n

      • 蓝牙：v4.1

    • USB:

      • OTG - 2 个 Type-C

    • 以太网

    • PCI-E M.2

    • 连接器：

      • 40 针双排排针

    • LEDs:

      • 1 个电源状态 LED

      • 1x UART LED

    • 调试

      • 20 针 JTAG 连接器

      • 用于 UART 调试的 MicroUSB，提供分别用于 A53 和 M4 的两个 COM 端口

有关该开发板的更多信息，请访问 NXP website。

设备

系统时钟

本开发板配置使用 8 MHz 的系统时钟频率。

M7 核配置为以 800 MHz 时钟频率运行。

串口

编程与调试（A53）

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

在 A53 内核上编程和调试 Zephyr 有多种方法：

选项 1：使用 JLink 运行器引导 Zephyr

本开发板的默认运行器为 JLink。使用 J-Link 调试器将 EVK 开发板的 JTAG 连接器连接到主机，给开发板上电，并让开发板停在 U-Boot 命令行。

然后使用 "west flash" 或 "west debug" 命令从主机加载 zephyr.bin 镜像，并在 A53 core0 上启动 Zephyr 应用程序。

烧录并运行

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b imx8mp_evk/mimx8ml8/a53 samples/hello_world
west flash

然后可以在 UART4 控制台上看到以下日志：

*** Booting Zephyr OS build v4.1.0-3063-g38519ca2c028 ***
Hello World! imx8mp_evk/mimx8ml8/a53

调试

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b imx8mp_evk/mimx8ml8/a53 samples/hello_world
west debug

选项 2：使用 U-Boot 命令引导 Zephyr

使用 U-Boot "cpu" 命令将 Zephyr 加载到 Cortex-A 从核并启动。目前 Real-Time Edge U-Boot 支持该命令（使用 "uboot_vxxxx.xx-y.y.y" 分支，其中 xxxx.xx 是 U-Boot 版本，y.y.y 是 Real-Time Edge Software 版本，例如 "uboot_v2023.04-2.9.0" 分支是 Real-Time Edge Software v2.9.0 版本所用的 U-Boot v2023.04），预编译镜像和用户指南可在 Real-Time Edge Software 获取。

步骤 1：将 Zephyr 镜像下载到 DDR 内存

首先需要将 Zephyr 二进制镜像下载到 DDR 内存中，可以使用 tftp：

tftp 0xc0000000 zephyr.bin

也可以将 Zephyr 镜像 zephyr.bin 复制到 SD 卡，再将卡插入开发板。例如，如果复制到 SD 卡的 FAT 分区，可使用以下 U-Boot 命令将镜像加载到 DDR 内存中（假设 SD 卡为 dev 1，FAT 分区 ID 为 1，可根据实际情况修改）：

fatload mmc 1:1 0xc0000000 zephyr.bin;

步骤 2：引导 Zephyr

然后使用以下命令在 core0 上引导 Zephyr：

dcache off; icache flush; go 0xc0000000;

也可以使用 "cpu" 命令从副核引导，例如 Core1：

dcache flush; icache flush; cpu 1 release 0xc0000000

选项 3：在 Linux 下使用 Remoteproc 引导 Zephyr

在 A53 核上运行 Linux 时，可以使用 remoteproc 框架加载并启动 Zephyr，详情请参阅 Real-Time Edge 用户指南。预构建镜像和用户指南可在 Real-Time Edge Software 获取。

使用此配置运行基本的 Zephyr 应用程序和内核测试，例如 Basic Synchronization 示例：

# From the root of the zephyr repository
west build -b imx8mp_evk/mimx8ml8/a53 samples/synchronization

这将构建一个包含 synchronization 示例应用程序的镜像，启动该镜像，并显示以下控制台输出：

*** Booting Zephyr OS build v4.1.0-3063-g38519ca2c028 ***
thread_a: Hello World from cpu 0 on mimx8mp_evk!
thread_b: Hello World from cpu 0 on mimx8mp_evk!
thread_a: Hello World from cpu 0 on mimx8mp_evk!
thread_b: Hello World from cpu 0 on mimx8mp_evk!
thread_a: Hello World from cpu 0 on mimx8mp_evk!

CAN 总线（FlexCAN）（A53）

FlexCAN 控制器是 CAN 2.0B 控制器，同时支持标准帧和扩展帧。FlexCAN 控制器有两个独立的 FlexCAN 模块：FlexCAN1 和 FlexCAN2。默认情况下，设备树中启用了 FlexCAN1。要启用 FlexCAN2，需要将以下覆盖文件添加到设备树中：boards/nxp/imx8mp_evk/dts/flexcan2.overlay。

例如，要构建启用 CAN shell 和 CAN 统计信息、并使用 FlexCAN1 控制器的 Hello World 示例，可以使用以下配置：

# From the root of the zephyr repository
west build -b imx8mp_evk/mimx8ml8/a53 samples/hello_world -- -DCONFIG_SHELL=y -DCONFIG_CAN=y -DCONFIG_CAN_SHELL=y -DCONFIG_STATS=y -DCONFIG_CAN_STATS=y

编程与调试（M7）

MIMX8MP EVK 开发板没有供 M7 使用的 QSPI Flash，M7 需要由 A53 内核启动。A53 内核负责将 M7 二进制应用程序加载到 RAM 中，使 M7 复位，设置 M7 的程序计数器和栈指针，然后使 M7 退出复位。A53 可以在引导加载程序阶段或 Linux 系统启动后执行这些步骤。

M7 最多可以使用 3 种不同的 RAM（目前只支持两种配置：ITCM 和 DDR）。A53 和 M7 的存储器映射如下：

编译时必须选择要使用的 RAM。该配置根据开发板名称完成（imx8mp_evk/mimx8ml8/m7 对应 ITCM，imx8mp_evk/mimx8ml8/m7/ddr 对应 DDR）。

加载 M7 内核镜像有两种方法：U-Boot 命令和 Linux remoteproc。

从 U-Boot 加载并运行 M7 Zephyr 镜像

要通过 u-boot 从 A53 在 M7 上加载并运行 Zephyr，请将编译好的 zephyr.bin 复制到 SD 卡的第一个 FAT 分区，再将 SD 卡插入开发板。给开发板上电，并在提示符处停止 u-boot 的执行。

将 M7 二进制文件加载到所需的存储器中，并使用以下命令开始执行：

ITCM

fatload mmc 0:1 0x48000000 zephyr.bin
cp.b 0x48000000 0x7e0000 20000
bootaux 0x7e0000

DDR

fatload mmc 0:1 0x80000000 zephyr.bin
dcache flush
bootaux 0x80000000

使用 Linux remoteproc 加载并运行 M7 Zephyr 镜像

准备设备树：

设备树必须包含兼容字符串为 "fsl,imx8mn-cm7" 的 CM7 dts 节点；如果代码和系统地址使用 DDR，还需要预留 M4 DDR 内存，并将 "m4_reserved" 放入 cm7 节点的 memory-region 属性列表中。

reserved-memory {
         #address-cells = <2>;
         #size-cells = <2>;
         ranges;

         m7_reserved: m4@80000000 {
               no-map;
               reg = <0 0x80000000 0 0x1000000>;
         };
         ...
}


imx8mp-cm7 {
         compatible = "fsl,imx8mn-cm7";
         rsc-da = <0x55000000>;
         clocks = <&clk IMX8MP_CLK_M7_DIV>,
                  <&audio_blk_ctrl IMX8MP_CLK_AUDIO_BLK_CTRL_AUDPLL_ROOT>;
         clock-names = "core", "audio";
         mbox-names = "tx", "rx", "rxdb";
         mboxes = <&mu 0 1
                  &mu 1 1
                  &mu 3 1>;
         memory-region = <&vdevbuffer>, <&vdev0vring0>, <&vdev0vring1>, <&rsc_table>, <&m7_reserved>;
         status = "okay";
         fsl,startup-delay-ms = <500>;
};

DDR 镜像所需的额外 Zephyr 内核配置项：

如果使用 remoteproc 启动 DDR 开发板（imx8mp_evk/mimx8ml8/m7/ddr），还需要启用 "CONFIG_ROMSTART_RELOCATION_ROM"，将 romstart 内存段放入 ITCM，因为 M7 内核会从 ITCM 的零地址获取第一条指令。但 romstart 重定位会使 zephyr.bin 的存储体积过大，因此开发板 defconfig 中默认不启用它。

diff --git a/boards/nxp/imx8mp_evk/imx8mp_evk_mimx8ml8_m7_ddr_defconfig b/boards/nxp/imx8mp_evk/imx8mp_evk_mimx8ml8_m7_ddr_defconfig
index 17542cb4eec..8c30c5b6fa3 100644
--- a/boards/nxp/imx8mp_evk/imx8mp_evk_mimx8ml8_m7_ddr_defconfig
+++ b/boards/nxp/imx8mp_evk/imx8mp_evk_mimx8ml8_m7_ddr_defconfig
@@ -12,3 +12,4 @@ CONFIG_CONSOLE=y
CONFIG_XIP=y
CONFIG_CODE_DDR=y
+CONFIG_ROMSTART_RELOCATION_ROM=y

然后按以下步骤启动 Zephyr 内核：

  1. 在 U-Boot 命令行中执行准备脚本：

u-boot=> run prepare_mcore

  1. 使用指定的 dtb 启动 Linux 内核，然后通过 remoteproc 启动 Zephyr：

root@imx8mp-lpddr4-evk:~# echo zephyr.elf > /sys/devices/platform/imx8mp-cm7/remoteproc/remoteproc0/firmware
root@imx8mp-lpddr4-evk:~# echo start  > /sys/devices/platform/imx8mp-cm7/remoteproc/remoteproc0/state
[   39.195651] remoteproc remoteproc0: powering up imx-rproc
[   39.203345] remoteproc remoteproc0: Booting fw image zephyr.elf, size 503992
[   39.203388] remoteproc remoteproc0: No resource table in elf
root@imx8mp-lpddr4-evk:~# [   39.711380] remoteproc remoteproc0: remote processor imx-rproc is now up

root@imx8mp-lpddr4-evk:~#

调试

可以将外部 JLink JTAG 调试器连接到 J24 调试连接器和 PC 来调试 MIMX8MP EVK 开发板，然后按常规方式调试应用程序。

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b imx8mp_evk/mimx8ml8/m7 samples/hello_world
west debug

打开串口终端，在调试器中单步执行应用程序，终端中应显示以下信息：

*** Booting Zephyr OS build v2.7.99-1310-g2801bf644a91  ***
Hello World! imx8mp_evk
