MCXW23-EVK

Board Overview

Name:
mcxw23_evk
Vendor:

NXP Semiconductors

Status:

Not actively maintained

Architecture:

arm

SoC:

mcxw236

Browse board sources

概述

MCXW23 EVK 底板与 MCXW23 无线子模块（RDM）组合，构成支持 NXP MCXW23 无线处理器的评估环境。该 EVK 支持物联网应用，适用于原型开发、演示、软件开发和测量（功耗和射频）。MCXW23 EVK 提供多种调试机制，便于应用程序开发。

硬件

  • MCXW23 Arm® Cortex®-M33 微控制器，运行频率最高 32 MHz

  • 片上 1 MB Flash 和 128 KB SRAM

  • 40HVQFN 封装

  • 板载 MCU-Link 调试器，支持 CMSIS-DAP

  • LED

  • 复位、ISP、唤醒和用户按键，便于测试软件功能

  • NXP FXLS8974CF 加速度计

  • NXP FXPQ3115BVT1 压力传感器

  • TMP117 温度传感器

  • Arduino 排针、mikroBUS

系统时钟

MCXW23 SoC 配置为使用运行在 32 MHz 的 FRO 作为系统时钟源。

串口

MCXW23 SoC 有 3 个用于串行通信的 FLEXCOMM 接口。其中一个配置为 USART，用作控制台，一个配置为 I2C，另一个未使用。

获取二进制 blob

要支持 Bluetooth，mcxw23_evk 需要获取控制器库二进制文件（blob），可通过运行以下命令完成：

west blobs fetch hal_nxp -l "mcxw23"

备注

-l 选项接受一个 Python 正则表达式，用于匹配每个 blob 的路径。传入 "mcxw23" 可将下载限制为本开发板所需的 blob，而不是获取所有 NXP blob。省略该选项（west blobs fetch hal_nxp）则获取所有 NXP blob。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

配置调试探针

调试探针既用于烧录也用于调试开发板。本开发板默认配置为使用 MCU-Link CMSIS-DAP 板载调试探针。

使用 LinkServer

Linkserver 是该开发板的默认运行器（runner），支持出厂默认的 MCU-Link 固件。按照 MCU-Link CMSIS-DAP 板载调试探针 中的说明重新烧写默认的 MCU-Link 固件。只有在板载调试电路的默认固件被更改过时才需要这样做。要让开发板进入 DFU mode 以烧写固件，请短接跳线 J32。

使用 J-Link

有两种方式。第一种是按照 MCU-Link JLink 板载调试探针 中的说明，将板载调试电路更新为 Segger J-Link 固件。为了烧写固件，需要短接跳线 J32，使开发板进入 DFU mode。第二种是将 J-Link 外部调试探针 连接到开发板的 10 针 SWD 连接器（J11）。此外，必须短接跳线 JP30。两种方式都需要在 west 中使用 -r jlink 选项来使用 jlink 运行器。

west flash -r jlink

配置控制台

用 USB 线将 PC 连接到 J33，并使用任意串口终端（minicom、putty 等），设置如下：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

烧录

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b mcxw23_evk samples/hello_world
west flash

打开串口终端，复位开发板（按下 RESET 按键），终端中应显示以下信息：

*** Booting Zephyr OS build v4.2.0-2105-g9da1d56da9e7 ***
Hello World! mcxw23_evk/mcxw236

调试

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b mcxw23_evk samples/hello_world
west debug

打开串口终端，在调试器中单步执行应用程序，终端中应显示以下信息：

*** Booting Zephyr OS build v4.2.0-2105-g9da1d56da9e7 ***
Hello World! mcxw23_evk/mcxw236

电源管理

启用电源管理 CONFIG_PM 时，OSTIMER 用作操作系统节拍定时器。

限制：在 Standby 模式下，唤醒引脚不能用作唤醒源。

蓝牙

动态 BLE 发射功率配置

MCXW23 支持动态配置 BLE 发射功率。但存在一个已知限制：更改发射功率等级后，必须重新启动广播，新的功率设置才能生效。
