VMU RT1170

Board Overview

Name:
vmu_rt1170
Vendor:

NXP Semiconductors

Status:

Not actively maintained

Architecture:

arm

SoC:

mimxrt1176

Browse board sources

概述

VMU RT1170 采用 i.MX RT1176 双核 MCU，其 Cortex-M7 内核运行在 1 GHz，Cortex-M4 内核运行在 400 MHz。i.MX RT1176 MCU 支持宽温度范围，并通过了消费、工业和汽车市场的认证。VMU RT1170 是 CogniPilot Cerebri 的默认 VMU，Cerebri 是基于 Zephyr RTOS 的自动驾驶仪。

硬件

  • MIMXRT1176DVMAA MCU

    • 1GHz Cortex-M7 和 400Mhz Cortex-M4

    • 2MB SRAM，其中 Cortex-M7 有 512KB TCM，Cortex-M4 有 256KB TCM

  • 内存

    • 512 Mbit 八线 Flash

    • 用于 SD 卡的 TF 卡座

  • 以太网

    • 双线 100BASE-T1

  • USB

    • USB 2.0 连接器

  • Power

    • 冗余双 picoflex 电源端口

  • 调试

    • 10 针调试和 shell 转接板，转接到 20 针 JTAG 调试器和 USB-C shell

  • 传感器

    • BMI088 六轴 IMU

    • BMM150 磁力计

    • 双 BMP388 气压计

    • 双 ICM-42688 六轴 IMU

    • IST8310 三轴磁力计

    • U-blox NEO-M8N GNSS 模块

  • UART JST-GH 连接器

  • I2C JST-GH 连接器

  • CAN 总线 JST-GH 连接器

  • RC IN

    • 用于兼容 SBUS 的遥控接收机的 RC 输入连接器

有关 MIMXRT1176 SoC 和 VMU RT1170 开发板的更多信息，请参阅以下参考资料：

  • VMU RT1170 Schematics

  • i.MX RT1170 Datasheet

  • i.MX RT1170 Reference Manual

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

配置调试探针

烧录和调试开发板都使用调试探针。

使用 J-Link

安装 J-Link 调试主机工具，并确保它们位于搜索路径中。

通过调试转接板连接 J-Link 调试器。

配置控制台

使用调试转接板上的 USB-C 访问控制台，在任意串口终端（screen、minicom、putty 等）中使用以下设置：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

烧录

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b vmu_rt1170 samples/hello_world
west flash

终端中应显示以下信息：

***** Booting Zephyr OS v3.4.0-xxxx-xxxxxxxxxxxxx *****
Hello World! vmu_rt1170

调试

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b vmu_rt1170 samples/hello_world
west debug

打开串口终端，在调试器中单步执行应用程序，终端中应显示以下信息：

***** Booting Zephyr OS v3.4.0-xxxx-xxxxxxxxxxxxx *****
Hello World! vmu_rt1170
