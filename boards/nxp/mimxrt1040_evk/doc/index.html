MIMXRT1040-EVK

Board Overview

Name:
mimxrt1040_evk
Vendor:

NXP Semiconductors

Status:

Not actively maintained

Architecture:

arm

SoC:

mimxrt1042

Browse board sources

概述

i.MX RT1040 跨界 MCU 提供新的封装和最高 125° C 的扩展温度范围，带来更大的灵活性。i.MX RT1040 MCU 有紧凑的 9x9 mm 封装，也有支持双层 PCB 设计的 11x11 mm 封装。i.MX RT1040 MCU 运行在 600 MHz 的 Arm® Cortex®-M7 内核上。

硬件

  • MIMXRT1042XJM5B MCU (600 MHz, 512 KB TCM)

  • 内存

    • 256 MBit SDRAM 内存（Winbond W9825G6KH）

    • 64 Mbit QSPI Flash 存储器（Winbond W25Q64JVSSIQ）

  • 显示

    • LCD 连接器

    • 触摸连接器

  • 以太网

    • 10/100 Mbit/s 以太网 PHY

  • USB

    • USB 2.0 OTG 连接器

  • 音频

    • 3.5 mm 立体声耳机插孔

    • 板载麦克风

  • Power

    • 5 V 直流电源插孔

  • 调试

    • 20 针 JTAG 连接器

    • 带 DAPLink 的 OpenSDA

  • 扩展端口

    • Arduino 接口

  • CAN 总线连接器

备注

对于尚未支持的其他功能，也请参阅 MIMXRT1064-EVK，它是 NXP i.MX RT10xx 系列中的超集开发板。NXP 优先在超集开发板上实现 NXP 对 Zephyr 的全平台支持。因此，mimxrt1064_evk 开发板可能已经支持更多功能，这些功能也可以在这块 mimxrt1040_evk 开发板上复用。

用于支持功能的扩展板

上表中的部分功能使用 Zephyr 扩展板（shield）进行了测试。以下扩展板已在本开发板上测试过：

  • NXP RK043FN02H-CT 并行显示屏 和 NXP RK043FN66HS-CTG 并行显示屏 - 支持显示接口。

  • NXP M.2 Wi-Fi 和 BT 扩展板：Rev C 版本已与该扩展板（shield）一起测试，可连接任何带 BT HCI UART 接口和 Wi-Fi SDIO 接口的 M.2 模组。该扩展板会绑定所需的 NXP HCI 驱动或 SDIO 驱动，为 NXP SoC IW416/IW612/IW610 执行固件加载和其他设置配置。

使用 NXP M.2 Wi-Fi 和 BT 扩展板 扩展板时，需要进行以下硬件改装：

  • 在 R96 和 R93 处焊接 0 欧姆电阻。

  • 拆除 R497、R498、R456 和 R457 处的电阻。

此外，由于引脚冲突，无法支持 Bluetooth 模块的 PCM 接口。

系统时钟

MIMXRT1040 SoC 配置为使用 SysTick 作为系统时钟源，运行频率为 600MHz。

启用电源管理后，开发板上的 32 KHz 低频振荡器将用作 GPT 定时器的时钟源来产生系统时钟。该时钟可支持更低功耗的状态，代价是分辨率降低

串口

MIMXRT1040 SoC 有八个 UART。LPUART1 配置为控制台，LPUART3 用于 Bluetooth 主机控制器接口（BT HCI），其余 UART 未使用。

获取二进制 blob

开发板的蓝牙/WiFi 模块需要获取一些二进制 blob 文件，为此请运行以下命令：

west blobs fetch hal_nxp

备注

目前仅支持蓝牙功能。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

本开发板支持 3 种调试主机工具。请安装你偏好的主机工具，然后按照 Configuring a Debug Probe 中的说明对开发板进行相应配置。

  • J-Link 调试主机工具（默认，NXP 支持）

  • LinkServer 调试主机工具 （NXP 支持）

  • pyOCD 调试主机工具（NXP 不提供支持）

配置好主机工具和开发板后，按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

配置调试探针

对于 RT1040，J9/J10 是 SWD 隔离跳线，J12 是 DFU 模式跳线，J2 是 20 针 JTAG/SWD 排针。

调试探针既用于烧录也用于调试开发板。本开发板带有 LPC-LINK2 板载调试探针，该探针中的默认固件为 LPC-Link2 DAPLink 板载调试探针。

根据所安装的主机工具，按以下说明设置调试探针：

  • J-Link 调试主机工具: Using J-Link with LPC-Link2 Probe

  • LinkServer 调试主机工具: Using CMSIS-DAP with LPC-Link2 Probe

  • pyOCD 调试主机工具: Using CMSIS-DAP with LPC-Link2 Probe

通过 LPC-Link2 探针使用 CMSIS-DAP

  1. 按照 LPC-LINK2 CMSIS DAP 板载调试探针 中的说明，重新烧写本开发板上默认的调试探针固件。

  2. 确保已安装 SWD 隔离跳线

通过 LPC-Link2 探针使用 J-Link

有两种方式：将板载调试电路更新为 Segger J-Link 固件，或者将 J-Link 外部调试探针 连接到 EVK。

要更新板载调试电路，请执行以下操作：

  1. 将 EVK 的电源切换为调试 USB 以外的其他电源，因为 J-Link 固件不会通过调试 USB 为 EVK 供电。

  2. 按照 LPC-Link2 J-Link 板载调试探针 中的说明，重新烧写本开发板上默认的调试探针固件。

  3. 确保已安装 SWD 隔离跳线。

要连接外部 J-Link 探针，请确保已移除 SWD 隔离跳线，然后将探针连接到外部 JTAG/SWD 排针

配置控制台

无论选择哪种调试探针，都使用 OpenSDA 微控制器作为串口控制台的 USB 转串口适配器。请确认跳线 J11 和 J13 处于 接通 状态（开发板出厂时默认接通），以便将 UART 信号连接到 OpenSDA 微控制器。

用 USB 线将 PC 连接到 J1。

在你选用的串口终端（minicom、putty 等）中使用以下设置：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

烧录

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b mimxrt1040_evk samples/hello_world
west flash

打开串口终端，复位开发板（按下 SW1 按键），终端中应显示以下信息：

***** Booting Zephyr OS Booting Zephyr OS build v3.3.0-rc3-66 *****
Hello World! mimxrt1040_evk

以下以 Hello World 应用程序为例。

***** Booting Zephyr OS Booting Zephyr OS build v3.3.0-rc3-66 *****
Hello World! mimxrt1040_evk

故障排除

USER_LED D8

MIMXRT1040-EVK 开发板出厂时 M.2 连接器上装有无线模块，并且跳线 J80 处于短接状态。这会与 USER_LED D8 冲突，导致该 LED 无法熄灭。使用 USER_LED D8 的示例和应用程序（例如 blinky）需要拆除跳线 J80。

启动头

如果调试探针连接失败并报告以下错误，可能是 QSPI 中的启动头无效或已损坏。启动头由 CONFIG_NXP_IMXRT_BOOT_HEADER 配置。

Remote debugging using :2331
Remote communication error.  Target disconnected.: Connection reset by peer.
"monitor" command not supported by this target.
"monitor" command not supported by this target.
You can't do that when your target is `exec'
(gdb) Could not connect to target.
Please check power, connection and settings.

可以按照以下步骤擦除并重新烧写 QSPI 来修复：

  1. 将 SW4 拨码开关设置为 OFF-OFF-OFF-ON，从 ROM 引导加载程序启动。

  2. 按 SW1 复位

  3. 使用一个确认可正常工作的 Zephyr 应用程序再次运行 west debug 或 west flash。

  4. 将 SW4 拨码开关设置为 OFF-OFF-ON-OFF，从 QSPI 启动。

  5. 按 SW1 复位

Bluetooth 模块

如果调试器连接失败并报告以下错误，请参阅下一节。

WiFi 模块

如果调试器连接失败并报告以下错误，可能是 M.2 WiFi 模块干扰了调试信号

Remote debugging using :2331
Remote communication error.  Target disconnected.: Connection reset by peer.
"monitor" command not supported by this target.
"monitor" command not supported by this target.
You can't do that when your target is `exec'
(gdb) Could not connect to target.
Please check power, connection and settings.

要解决此问题，可以在烧录或调试时从开发板上取下 M.2 WiFi 模块，或者拆除跳线 J80。
