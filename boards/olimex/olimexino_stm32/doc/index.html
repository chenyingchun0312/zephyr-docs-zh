OLIMEXINO-STM32

Board Overview

Name:
olimexino_stm32
Vendor:

OLIMEX Ltd.

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32f103xb

Browse board sources

概述

OLIMEXINO-STM32 开发板基于 STMicroelectronics STM32F103RB ARM Cortex-M3 CPU。

有关该开发板的更多信息，请访问 OLIMEXINO-STM32 website 并参阅 OLIMEXINO-STM32 user manual。ST STM32F103xB Datasheet 包含处理器的相关信息和数据手册。

系统时钟

OLIMEXINO-STM32 有两个外部振荡器。低速时钟频率为 32.768 kHz，主时钟频率为 8 MHz。处理器可以设置 HSE 驱动主时钟，主时钟最高可设为 72 MHz。

串口

OLIMEXINO-STM32 开发板最多有 3 个 U(S)ART。Zephyr 控制台输出分配给 USART1。默认设置为 115200 8N1。

SPI

OLIMEXINO-STM32 开发板最多有 2 个 SPI。Zephyr 默认的 SPI 映射如下：

  • SPI1_NSS : PA4

  • SPI1_SCK : PA5

  • SPI1_MISO : PA6

  • SPI1_MOSI : PA7

I2C

OLIMEXINO-STM32 开发板支持两个 I2C 设备。Zephyr 默认的 I2C 映射如下：

  • I2C1_SCL : PB6

  • I2C1_SDA : PB7

  • I2C2_SCL : PB10

  • I2C2_SDA : PB11

USB

OLIMEXINO-STM32 开发板通过 mini USB 连接器提供 USB 2.0 全速设备接口。

  • USB_DM : PA11

  • USB_DP : PA12

CAN

OLIMEXINO-STM32 开发板有一个 CAN 接口，板载收发器。CAN 通过螺丝端子引出。

  • CAN_RX : PB8

  • CAN_TX : PB9

跳线

Zephyr 内核使用 OLIMEXINO-STM32 的默认跳线设置。注意，开发板上的所有跳线都是 SMD 类型，需要焊接、拆焊或割断才能重新配置。

将 Zephyr 烧录到 OLIMEXINO-STM32

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

将 Zephyr 内核烧录到 OLIMEXINO-STM32 需要使用 stm32flash tool。

构建 stm32flash 命令行工具

按照以下步骤构建 stm32flash 工具：

  1. 从仓库检出 stm32flash 工具的代码。

$ git clone http://git.code.sf.net/p/stm32flash/code stm32flash
$ cd stm32flash

  1. 构建 stm32flash 工具。

$ make

  1. 生成的二进制文件为 stm32flash。

将应用程序烧录到 OLIMEXINO-STM32

向 OLIMEXINO-STM32 开发板上传应用程序需要一个 TTL（3.3V）串口适配器。本教程使用 Button 示例应用程序。

  1. 将串口线连接到 UART 接口的 UEXT 线（引脚 #3=TX，引脚 #4=RX）。

  2. 通过 mini USB 为 OLIMEXINO-STM32 供电。

  3. 按住按键（BUT）的同时复位开发板。

  4. 要构建并烧录应用程序，请输入：

    # From the root of the zephyr repository
west build -b olimexino_stm32 samples/basic/button
west flash

  5. 运行你常用的终端程序以监听输出。

    $ minicom -D /dev/ttyUSB0 -b 115200

    -b 选项用于设置波特率，忽略配置中的值。

  6. 按下复位按键，终端中应显示 button 应用程序的输出。程序会监视 BUT 按键的 GPIO 线状态并打印到串口控制台。按下输入按键时，中断处理程序会打印该事件的信息及其时间戳。

备注

烧录二进制镜像前请确保已关闭终端程序，否则它会干扰烧录过程。
