PSOC™ Control C3M5 Connectivity Card 2

kit_psc3m5_cc2
Vendor:

Infineon Technologies

Status:

Not actively maintained

Architecture:

arm

SoC:

psc3m5fds2afq1

Browse board sources

概述

KIT_PSC3M5_CC2 是 KIT_PSC3M5_MC1 电机控制套件附带的连接卡。它基于 PSOC™ Control C3 系列，搭载采用 Arm® Cortex®-M33 内核的 PSOC™ Control C3M5（PSC3M5FDS2AFQ1）微控制器。该卡承载套件的控制和通信接口，配套的功率板承载逆变级。

主要特性包括 256 KB Flash、64 KB SRAM、隔离 CAN FD 接口、具备高分辨率能力的高级定时器，以及高性能可编程模拟子系统。

该开发板支持 mikroBUS 扩展插座，并带有板载隔离 SEGGER J-Link LITE 编程器/调试器。

硬件

  • SoC： PSOC™ Control C3M5（PSC3M5FDS2AFQ1，PG-E-LQFP-80）

  • CPU： Arm® Cortex®-M33，配置为 180 MHz

  • Flash: 256 KB

  • SRAM: 64 KB

  • 连接： 隔离 CAN FD、SCB（UART/SPI/I2C）

  • 外设： TCPWM 定时器、可编程模拟（HPPASS）

  • Security: Arm® TrustZone®-M

  • 调试： 板载隔离 SEGGER J-Link LITE（SWD + UART 桥接）

  • 扩展： mikroBUS 插座、100 针功率板连接器

  • 用户 I/O： 两个用户 LED、一个用户按键、两个电位器

有关 PSOC™ Control C3 和 KIT_PSC3M5_CC2 的更多信息：

系统时钟

PSOC™ Control C3M5 由内部振荡器驱动。配置的时钟路径如下：

  • FLL: 96 MHz

  • DPLL-LP0: 180 MHz

  • DPLL-LP1: 240 MHz

  • CLK_HF0：180 MHz（系统时钟）

  • CLK_HF2：80 MHz（外设组 4：UART、CAN FD、SPI）

  • CLK_HF3: 240 MHz

CLK_HF2 被分频到 80 MHz，以使 CAN FD 位时序符合 CiA 601-3。

P1.0 和 P1.1 上安装了一个 16 MHz 晶体。由于 Zephyr 目前没有为 PSOC™ Control C3 提供外部晶体振荡器时钟节点，该晶体未被使用。板上没有安装 32.768 kHz 手表晶体，因此开发板设备树中禁用了手表晶体振荡器，P0.0 和 P0.1 改为引至 mikroBUS 插座。

串口

PSOC™ Control C3M5 有六个 SCB（串行通信块）接口，可配置为 UART、SPI 或 I2C。Zephyr 控制台输出分配给 SCB1（uart1），经由板载 J-Link LITE USB-UART 桥接器引出。该开发板未引出硬件流控信号。

默认通信设置为 115200 8N1。

CAN FD

CAN 接口采用电气隔离。控制器信号通过一个 2DIB1400F 双通道数字隔离器连接到 Infineon TLE9371VSJ 收发器:

P6.3 CAN1_TX --> INA  ==||== OUTA --> TXD --+ TLE9371VSJ +-- CANH
P6.2 CAN1_RX <-- OUTB ==||== INB  <-- RXD --+  STB = GND +-- CANL
                  2DIB1400F

收发器的待机引脚连接到隔离地。待机为高电平有效，因此收发器始终处于正常模式，无需软件控制。因此开发板设备树中不包含 can-transceiver-gpio 节点，can1 也没有 phys 属性。CAN 应用程序无需覆盖文件即可在该开发板上运行。

mikroBUS 插座

开发板提供 mikrobus_header GPIO nexus 和 mikrobus_spi 总线标签，因此 boards/shields 下的 SPI 和 GPIO 扩展板可以直接针对该开发板构建：

west build -b kit_psc3m5_cc2 --shield mikroe_adc_click samples/basic/blinky

I2C 不可用

插座的 SCL 和 SDA 引脚未连接到微控制器。原本用于将它们连接到 SCB3 数据线的 0 欧姆连接未焊接，因此这些引脚终止于插座。

因此未声明 mikrobus_i2c，nexus 索引 10 和 11 保持未映射，这样 I2C 扩展板会在构建时失败，而不是在硬件上运行失败。

PFC 检测

只有通道 12 和 16 是用户输入。其余通道承载电机驱动和 PFC 检测信号，这些信号通过功率板连接器到达微控制器。

电位器 POT1 与 mikroBUS 的 AN 引脚共用同一网络，因此驱动 AN 引脚的 Click 板也会影响 POT1 的读数。POT2 与该插座无关。

功率板连接器

上表未列出的引脚是两路电机的逆变器栅极驱动信号和功率级使能信号，连接到功率板连接器。开发板设备树没有启用其中任何输出；需要使用某个信号的应用程序应在自己的覆盖文件中启用它。

警告

连接功率板时，不要运行驱动这些引脚的应用程序。同时驱动高侧信号及其对应的低侧信号会导致半桥直通。

构建

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b kit_psc3m5_cc2 samples/hello_world

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

KIT_PSC3M5_CC2 带有一个板载隔离式 SEGGER J-Link LITE 编程器/调试器，可用于对 PSOC™ Control C3M5 Cortex®-M33 内核进行编程和调试。主机上必须安装 SEGGER J-Link Software 软件包。

配置控制台

用 USB 线将 PC 连接到 KIT_PSC3M5_CC2 上的调试 USB 接口。使用任意串口终端（minicom、PuTTY 等），设置如下：

  • Speed: 115200

  • 数据位： 8 位

  • 校验位： 无

  • Stop bits: 1

烧录

构建并烧录应用程序：

west build -b kit_psc3m5_cc2 -p always samples/hello_world
west flash

控制台上应显示以下信息：

*** Booting Zephyr OS build vX.Y.Z ***
Hello World! kit_psc3m5_cc2

调试

# From the root of the zephyr repository
west build -b kit_psc3m5_cc2 samples/hello_world
west debug

GDB 控制台启动后，即可设置断点，并在 PSOC™ Control C3M5 Cortex®-M33 内核上进行标准的 GDB 调试。
