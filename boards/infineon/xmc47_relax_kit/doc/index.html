arm

xmc4700

Browse board sources

概述

KIT_XMC47_RELAX_V1 是基于 XMC™ 4700 系列的评估套件，搭载一颗 XMC4700 微控制器，其 Arm® Cortex®-M4 内核主频最高 144 MHz。该套件面向工业和通用嵌入式应用。

主要特性包括 2048 KB Flash、352 KB SRAM、以太网、CAN、32 Mb QSPI Flash、一个 microSD 卡槽，以及兼容 Arduino 的排针（3.3V）。

该开发板带有一个可拆卸的 SEGGER J-Link 调试器（带 UART VCOM）。

硬件

  • SoC: XMC 4700

  • CPU： Arm® Cortex®-M4，144 MHz

  • Package: LQFP144

  • Flash: 2048 KB

  • SRAM: 352 KB

  • 连接： 以太网、CAN

  • 外设： 32 Mb QSPI Flash、microSD、12 MHz + 32.768 kHz 晶振

  • 调试： 可拆卸的 J-Link 调试器（SWD + SWO + UART VCOM）

  • 电源： USB 供电（3.3V 工作电压）

  • 连接器： 用于调试和供电的 Micro-USB

  • 扩展： 兼容 Arduino 的排针（3.3V）、两个 80 针排针（x1、x2）

  • 用户 I/O： 两个用户 LED、两个用户按键

串口

XMC 4700 Relax Kit 使用 USIC0CH0 接口输出 Zephyr 控制台。该 UART 经由 J-Link VCOM 接口输出。

默认通信设置为 115200 8N1 （FIFO：TX/RX 各 16 字节）。

构建

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b xmc47_relax_kit samples/hello_world

编程与调试

说明

KIT_XMC47_RELAX_V1 带有一个可拆卸的 SEGGER J-Link 调试器，通过 USB 提供编程、调试和 UART VCOM 串口通信功能。

安装 SEGGER J-Link

本开发板需要在主机上安装 SEGGER J-Link 软件。请从 SEGGER J-Link 网站下载并安装适用于你的操作系统的 J-Link Software and Documentation Pack。

配置控制台

用 USB 线将 PC 连接到 KIT_XMC47_RELAX_V1 上的板载 USB 调试器接口（X101）。使用任意串口终端（minicom、PuTTY 等），设置如下：

  • Speed: 115200

  • 数据位： 8 位

  • 校验位： 无

  • Stop bits: 1

烧录

使用 west flash 构建和烧录应用程序，默认使用 J-Link 运行器：

west build -b xmc47_relax_kit -p always samples/hello_world
west flash

控制台上应显示以下信息：

*** Booting Zephyr OS build vX.Y.Z ***
Hello World! xmc47_relax_kit

调试

# From the root of the zephyr repository
west build -b xmc47_relax_kit samples/hello_world
west debug

GDB 控制台启动后，即可设置断点，并在 XMC 4700 Cortex-M4 内核上进行标准的 GDB 调试。
