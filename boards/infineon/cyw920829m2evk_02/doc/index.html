Browse board sources

概述

CYW920829M2EVK-02 是 AIROC™ CYW20829 Bluetooth® LE MCU 的评估套件，采用运行于 96 MHz 的 Arm® Cortex®-M33 内核。它专为 Bluetooth® 低功耗应用设计，包括工业物联网、智能家居、资产跟踪、信标、传感器和医疗设备。

主要特性包括 2048 KB Flash、1024 KB SRAM、发射输出功率 10 dBm 的 Bluetooth® LE（无需外部 PA），以及一整套板载传感器和外设。

该开发板支持 Arduino Uno R3 排针，并带有 micro-B USB 接口的板载 KitProg3 编程器/调试器。

硬件

  • SoC： AIROC CYW20829 Bluetooth® LE MCU（56 引脚 QFN）

  • CPU： Arm® Cortex®-M33，96 MHz

  • Flash: 2048 KB

  • SRAM: 1024 KB

  • 无线： Bluetooth® LE（10 dBm 发射功率，无需外部 PA）

  • 传感器： 六轴 IMU、热敏电阻、模拟麦克风、数字麦克风

  • USB： Micro-B（供电、编程、USB-UART 桥接）

  • 扩展： 兼容 Arduino Uno R3 的排针

  • 用户 I/O： RGB LED、两个用户 LED、两个用户开关

  • 调试： 板载 KitProg3（SWD + USB-UART）

  • 电源： USB 供电（3.3V 工作电压）

系统时钟

AIROC CYW20829 使用内部高频振荡器（IHO）作为时钟源。时钟路径如下：

  • FLL: IHO → 96 MHz

  • CLK_HF0：96 MHz（系统时钟）

串口

AIROC CYW20829 有多个 SCB（串行通信块）接口。Zephyr 控制台输出分配给 SCB2（uart2），经由带硬件流控的 KitProg3 USB-UART 桥接器引出。

默认通信设置为 115200 8N1。

前提条件

构建之前，CYW920829M2EVK-02 需要先获取二进制 blob（例如 Bluetooth 控制器固件）：

west blobs fetch hal_infineon

备注

在该开发板上进行 MCUboot 镜像签名需要 cysecuretools（Edge Protect Tools）。安装命令：pip install cysecuretools

构建

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b cyw920829m2evk_02/cyw20829b0lkml samples/hello_world

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

CYW920829M2EVK-02 包含一个板载编程器/调试器（KitProg3），可用于对 AIROC CYW20829 Cortex-M33 内核进行编程和调试。

CYW920829M2EVK-02 还支持通过 SEGGER J-Link 设备使用 RTT，目标名称为 cyw20829_tm。可以使用 rtt-console 代码片段构建，或设置以下 Kconfig 值来启用：CONFIG_UART_CONSOLE=n、CONFIG_RTT_CONSOLE=y 和 CONFIG_USE_SEGGER_RTT=y。

west build -p always -b cyw920829m2evk_02/cyw20829b0lkml samples/basic/blinky -S rtt-console

备注

对于 RTT 控制块，不要使用 "Auto Detection"，而应将搜索范围设置为：RAM RangeStart 为 0x20000000，RAM RangeSize 为 0x3d000。

安装 Infineon OpenOCD

ModusToolbox™ Programming Tools 软件包中包含 Infineon OpenOCD。也可以单独安装：下载适用于你的系统的 Infineon OpenOCD 发布版本，并将文件解压到你选择的位置。

备注

在 Linux 上，需要为 KitProg3 设置设备访问权限。安装 ModusToolbox™ Programming Tools 时会自动完成此设置。如果单独安装 OpenOCD，可以手动执行脚本 openocd/udev_rules/install_rules.sh 完成设置。

配置控制台

使用 USB 线缆将 PC 连接到 CYW920829M2EVK-02 上的 KitProg3 micro-B USB 连接器（J5）。使用你选择的串口终端（minicom、PuTTY 等），并采用以下设置：

  • Speed: 115200

  • 数据位： 8 位

  • 校验位： 无

  • Stop bits: 1

west build -b cyw920829m2evk_02/cyw20829b0lkml -p always samples/hello_world

在 SECURE 生命周期阶段运行

器件生命周期阶段（LCS）是 AIROC CYW20829 Bluetooth® MCU 安全性的关键方面。生命周期阶段按照 eFuse 位的编程（将值从 "0" 改为 "1"）严格、不可逆地推进。该机制用于按照用户要求的级别保护器件的数据和代码。SECURE 是已加密保护器件的生命周期阶段。

按照 AN239590 Provision CYW20829 to SECURE LCS 中的说明将器件转换到 SECURE LCS。在 SECURE LCS 阶段，保护状态被设置为安全。已加密保护的器件只有在 Flash 内容认证成功后才会启动。

以下配置选项可用于为已配置到 SECURE LCS 并使用加密 Flash 接口的器件构建：

  • CONFIG_INFINEON_SECURE_LCS：目标器件处于 SECURE LCS 时启用

  • CONFIG_INFINEON_SECURE_POLICY：策略 JSON 文件的路径，该文件是在将器件配置到 SECURE LCS 时创建的（参见 AN239590 Provision CYW20829 to SECURE LCS 第 3.2 节 "Key creation"）

  • CONFIG_INFINEON_SMIF_ENCRYPTION：配置到 SECURE LCS 后，启用此选项以使用加密 Flash 接口

以下示例为 SECURE LCS 构建 Blinky 示例应用程序：

# From the root of the zephyr repository
west build -b cyw920829m2evk_02/cyw20829b0lkml -p always samples/basic/blinky -- -DCONFIG_INFINEON_SECURE_LCS=y -DCONFIG_INFINEON_SECURE_POLICY=\"policy/policy_secure.json\"

使用 MCUboot

CYW20829 器件受 Cypress branch of MCUboot 中的 Cypress MCU 引导加载程序（MCUBootApp）支持。

构建 Cypress MCU 引导加载程序 MCUBootApp

请参阅 CYW20829 platform description 并按照其中的说明，了解针对普通/安全芯片的 MCUBootApp 构建流程，以及它作为引导加载程序的总体用法。将密钥和策略相关文件夹放在 cypress 目录 mcuboot/boot/cypress/ 中。

确保默认内存映射与 Zephyr 应用程序的内存映射一致（参见 boards/infineon/cyw920829m2evk_02/cyw920829m2evk_02-memory_map.dtsi 中 flash0 的分区）。

可以使用 west flash 烧录 MCUBootApp：

# Flash MCUBootApp.hex
west flash --no-rebuild --hex-file /path/to/cypress/mcuboot/boot/cypress/MCUBootApp/out/CYW20829/Debug/MCUBootApp.hex

备注

west flash 需要一个现有的 Zephyr 构建目录，可以先为目标开发板构建任意 Zephyr 应用程序来创建该目录。

使用 MCUboot 构建 Zephyr 应用程序

以下示例为 MCUboot 构建并烧录 Blinky 示例应用程序：

# From the root of the zephyr repository
west build -b cyw920829m2evk_02/cyw20829b0lkml -p always samples/basic/blinky -- -DCONFIG_BOOTLOADER_MCUBOOT=y -DCONFIG_MCUBOOT_SIGNATURE_KEY_FILE=\"/path/to/cypress/mcuboot/boot/cypress/keys/cypress-test-ec-p256.pem\"
west flash

如果使用 CONFIG_MCUBOOT_ENCRYPTION_KEY_FILE 生成加密镜像，最终的 hex 文件为 zephyr.signed.encrypted.hex，对应的 bin 文件为 zephyr.signed.encrypted.bin。前者用于烧录，后者用于 OTA 上传。

例如，为 MCUboot 构建并烧录加密的 Blinky 示例应用程序镜像：

# From the root of the zephyr repository
west build -b cyw920829m2evk_02/cyw20829b0lkml -p always samples/basic/blinky -- -DCONFIG_BOOTLOADER_MCUBOOT=y -DCONFIG_MCUBOOT_SIGNATURE_KEY_FILE=\"/path/to/cypress/mcuboot/boot/cypress/keys/cypress-test-ec-p256.pem\" -DCONFIG_MCUBOOT_ENCRYPTION_KEY_FILE=\"/path/to/cypress/mcuboot/enc-ec256-pub.pem\"
west flash --hex-file build/zephyr/zephyr.signed.encrypted.hex
