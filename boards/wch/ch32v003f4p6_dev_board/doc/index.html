WCH CH32V003F4P6 Development Board

Board Overview

Name:
ch32v003f4p6_dev_board
Vendor:

WinChipHead

Status:

Not actively maintained

Architecture:

riscv

SoC:

ch32v003

Browse board sources

概述

WCH [1] CH32V003F4P6 开发板硬件支持 QingKe V2A 32 位 RISC-V 处理器以及以下器件：

  • CLOCK

  • GPIO

  • NVIC

该开发板配有一个 LED，连接到 PD1 和 SWIO 引脚。WCH webpage on CH32V003 [2] 提供了该处理器的信息和数据手册。

硬件

WCH CH32V003F4P6_DEV_BOARD 的 QingKe V2A 32 位 RISC-V 处理器由内部 RC 振荡器提供时钟，运行在 24 MHz。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

ch32v003f4p6_dev_board 开发板目标的应用程序可以按常规方式构建和烧录（详见 构建应用程序 和 运行应用程序），但由于开发板没有内置调试支持，需要使用外部编程器。

外部编程器的以下引脚必须连接到 PCB 上的以下引脚（见图）：

  • VCC = VCC（不要同时通过 USB 端口为开发板供电）

  • GND = GND

  • SWIO = PD1

烧录

SWIO 引脚连接到 PD1，同时也连接到开发板上的 LED。PD1 默认功能为 SWD。为了使用板上的 LED，如果 PD1 没有接地，PD1 的功能会被切换为 GPIO（参见 boards/wch/ch32v003f4p6_dev_board/board.c）。如果 Flash 中已经加载了 Zephyr 应用程序，要重新烧录开发板，请在 PD1 接地的情况下给开发板上电，使 PD1 保持为 SWIO。之后，将外部调试器的 SWDIO 引脚重新连接到 PD1/SWIO，即可使用外部调试器烧录开发板。

可以使用 minichlink 烧录开发板。设置好 minichlink 后，按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

以下以 Blinky 应用程序为例。

# From the root of the zephyr repository
west build -b ch32v003f4p6_dev_board samples/basic/blinky
west flash

调试

可以通过 OpenOCD 或 minichlink 调试本开发板。

测试 WCH CH32V003F4P6_DEV_BOARD 上的 LED

有 1 个示例程序可用于测试开发板上的 LED 能否在 Zephyr 下正常工作：

samples/basic/blinky

可以构建并烧录示例，以确认 Zephyr 在开发板上正常运行。按键和 LED 的定义位于 boards/wch/ch32v003f4p6_dev_board/ch32v003f4p6_dev_board.dts。
