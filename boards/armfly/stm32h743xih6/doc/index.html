Armfly STM32H743XIH6

Board Overview

armfly_stm32h743xih6
Vendor:

Armfly

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32h743xx

Browse board sources

概述

Armfly STM32H743XIH6 开发板是一款基于 TFBGA240 封装的 STMicroelectronics STM32H743XIH6 微控制器的开发板。它将 STM32H743 MCU 与外部 SDRAM、显示和触摸硬件、多种存储设备、双以太网接口、音频、传感器以及大量板级扩展接口结合在一起。

当前的 Zephyr 开发板移植为该开发板提供了初步支持。目前的上游描述主要涵盖基础 MCU、外部 SDRAM、USART1 控制台、LTDC 显示通路、GT911 触摸控制器、SPI NOR Flash、MicroSD 插槽、以太网 MAC 和 PHY 通路、RTC、按键，以及用于板载 LED 的可选板级私有 FMC 锁存器 GPIO 输出。

有关该 SoC 的更多信息，请参阅：

  • STM32H743 product page

  • STM32H743 reference manual

硬件

完整的 Armfly STM32H743XIH6 开发板包含以下硬件：

  • TFBGA240 封装的 STM32H743XIH6 MCU

  • 带 FPU 的 ARM Cortex-M7 内核

  • CPU 频率最高 480 MHz

  • 2 MB 内部 Flash

  • 1 MB 内部 SRAM

  • 通过 32 位 FMC 总线连接的 32 MB SDRAM

  • 支持 XIP 的 32 MB QSPI Flash

  • 通过 8 位 FMC 总线连接的 128 MB NAND Flash

  • 16 KB 串行 EEPROM

  • 8 MB SPI NOR Flash 存储器

  • RGB888 LCD 接口，带 I2C 触摸和可调背光

  • 双以太网接口：

    • 一个接口使用 STM32 内部 MAC 和 DM9162 PHY

    • 一个连接在 16 位 FMC 总线上的 DM9000AEP 控制器

  • 一个 USB 全速主机端口

  • 一个 USB 全速设备端口

  • 一个 RS-485 接口

  • 一个 RS-232 接口，可通过 DB9 和 TTL UART 排针接入

  • 两个 CAN 接口

  • 一个 MicroSD 卡插槽

  • 一个带两个 TTL 串口的 SDIO 扩展连接器

  • WM8978 全双工 I2S 音频编解码器

  • 板载扬声器和麦克风

  • Si4704 FM 收音机接收器

  • 一个 PS/2 键盘或鼠标连接器

  • 红外接收和发射硬件

  • 一个与红外发射功能共用的蜂鸣器

  • MPU6050 运动传感器

  • BH1750 环境光传感器

  • BMP180 气压传感器

  • 三个用户按键和一个五向摇杆

  • 一个摄像头连接器

  • ADC 和 DAC 扩展接口

  • 用于 SPI、TTL UART 和 I2C 模块的扩展排针，兼容 Armfly V5 和 V6 扩展生态，支持以下模块：

    • AD7705 或 TM7705 双通道 16 位 ADC 模块

    • VS1053B 音频模块

    • GPS 和 GPRS 模块

    • ESP8266 UART Wi-Fi 模块

    • 8 位并行接口的 OLED 模块

    • AD7606 16 位 8 通道 ADC 模块

    • ADS1256 8 通道 24 位 ADC 模块

    • DAC8501 双通道 DAC 模块

    • DAC8563 双通道 DAC 模块

    • AD9833 DDS 波形发生器模块

  • 通过连接在 FMC 上的快速 32 位锁存器接口实现的额外 5 V 和 3.3 V 扩展输出

Zephyr 开发板移植目前只提供初步支持。完整开发板上的许多外设尚未在上游开发板描述中建模或验证。

支持的功能

armfly_stm32h743xih6 开发板支持下列硬件功能。

说明

The list of supported hardware features was not generated. Run a full documentation build for the required metadata to be available.

当前的开发板定义启用或描述了以下硬件模块：

  • STM32H743XIH6 SoC 内核支持

  • 内部 Flash 和 SRAM

  • FMC 上的外部 SDRAM

  • USART1 控制台

  • GPIO 按键

  • 用于板载 LED 的可选板级私有 FMC 锁存器 GPIO 控制器

  • I2C1，连接 GT911 触摸控制器、MPU6050 运动传感器、BH1750 环境光传感器、BMP180 气压传感器和 AT24C128 EEPROM

  • SPI3，连接 SPI NOR Flash

  • QUADSPI，连接 QSPI NOR Flash

  • 用于 MicroSD 插槽的 SDMMC1

  • 使用外部 SDRAM 的 LTDC 显示控制器

  • 基于 PWM 的 LCD 背光控制

  • 使用低速时钟源的 RTC

  • 带 MDIO 和外部 PHY 的以太网 MAC

备注

板载 LED 通过 FMC Bank1 上的外部锁存器连接。它们默认处于禁用状态，因为应用程序必须先启用 FMC 控制器才能访问该锁存器。使用这些 LED 的应用程序必须在应用程序覆盖文件中启用 MEMC 支持并启用锁存器 GPIO 节点。

引脚映射

Zephyr 默认外设映射：

  • USART1 TX/RX: PA9 / PA10

  • I2C1 SCL/SDA: PB6 / PB9

  • GT911 INT: PH7

  • QUADSPI CLK/NCS/IO0/IO1/IO2/IO3: PF10 / PG6 / PF8 / PF9 / PF7 / PF6

  • SPI3 SCK/MISO/MOSI: PB3 / PB4 / PB5

  • SPI3 CS: PD13

  • SDMMC1 D0-D3/CK/CMD: PC8 / PC9 / PC10 / PC11 / PC12 / PD2

  • SDMMC1 卡检测：PG12

  • PWM 背光控制：PA8 上的 TIM1 CH1

  • 以太网 RMII REF_CLK/CRS_DV/TX_EN/TXD0/TXD1/RXD0/RXD1：PA1 / PA7 / PG11 / PG13 / PB13 / PC4 / PC5

  • 以太网 MDC/MDIO：PC1 / PA2

系统时钟

开发板配有一个 25 MHz 高速外部振荡器和一个用于 RTC 的 32.768 kHz 低速外部晶体。当前的 Zephyr 开发板移植使用设备树中描述的 RCC 和 PLL 配置来提供系统时钟和外设时钟。

显示与触摸

开发板 DTS 为 RGB 显示通路启用了 STM32 LTDC 控制器，并将外部 SDRAM1 存储区域分配为帧缓冲区的后备存储。GT911 触摸控制器连接在 I2C1 上，并通过 zephyr,touch 选为开发板的触摸设备。

LVGL 指针伪设备有意不包含在基础开发板 DTS 中。使用 LVGL 的应用程序可以在需要时通过覆盖文件提供它。

I2C 设备

开发板 DTS 描述了连接到 I2C1 的板载 I2C 设备：

  • 地址为 0x5d 的 GT911 触摸控制器

  • 地址为 0x68 的 MPU6050 运动传感器

  • 地址为 0x23 的 BH1750 环境光传感器

  • 地址为 0x77 的 BMP180 气压传感器

  • 地址为 0x50 的 AT24C128 EEPROM

串口

Zephyr 默认控制台分配到 USART1，设置为 115200 8N1。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

可以按常规方式为 armfly_stm32h743xih6 开发板构建和烧录应用程序。开发板定义提供了对 STM32CubeProgrammer、OpenOCD、J-Link 和 pyOCD 运行器的支持。

烧录

默认运行器是 STM32CubeProgrammer。也可以显式选择 OpenOCD、J-Link 和 pyOCD：

$ west flash --runner openocd
$ west flash --runner jlink
$ west flash --runner pyocd

Hello World 应用程序的构建和烧录命令示例：

# From the root of the zephyr repository
west build -b armfly_stm32h743xih6 samples/hello_world
west flash

调试

可以按常规方式开始调试：

# From the root of the zephyr repository
west build -b armfly_stm32h743xih6 samples/hello_world
west debug
