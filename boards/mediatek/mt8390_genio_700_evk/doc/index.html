Genio 700 EVK

Board Overview

Name:
mt8390_genio_700_evk
Vendor:

MediaTek Inc.

Status:

Not actively maintained

Architecture:

arm64

SoC:

mt8188

Browse board sources

概述

MediaTek Genio 700 EVK 是 Genio 700（MT8390）应用处理器的评估板，面向边缘 AI 和物联网应用。

MT8390 是 Genio 700 平台所用的 SoC。SoC 的 IP 基于 MT8188 的驱动和设备树，MT8390 只出现在开发板名称中。

MT8390 是一款 6 nm 芯片，集成了两个 2.2 GHz 的 Cortex-A78 内核、六个 2.0 GHz 的 Cortex-A55 内核、一个 Arm Mali-G57 MC3 GPU、一个 4.0 TOPS 的 NPU 和一个 Tensilica HiFi 5 音频 DSP。

Zephyr 作为 Jailhouse inmate 与 Linux 一同运行在本开发板的 一个 Cortex-A55 核 上。参见 Programming and Debugging。

硬件

  • MediaTek Genio 700 EVK

  • 8 GB LPDDR4X DRAM

  • 64 GB eMMC 5.1 和一个 microSD 卡槽

  • AzureWave AW-XB468NF Wi-Fi 模组（MT7921）

  • 10/100/1000M 以太网

  • 一个 USB Type-C 主机端口和一个 micro USB 设备端口

  • 两个 M.2 插槽（PCIe/USB 和 SDIO）

  • 两个 4 通道 MIPI CSI 摄像头接口

  • 40 针 2.54 mm 扩展排针，引脚定义与 Raspberry Pi 兼容

  • 三个 micro USB 连接器，通过 USB 转 UART 桥接芯片输出 UART 跟踪日志

  • 2.0 mm 插孔 12 V 直流输入

连接与 IO

串口

Zephyr 控制台位于 UART1，参数为 115200 8N1，复用到引脚 33（UTXD1）和 34（URXD1）。

开发板引出三个 UART，每个 UART 都通过 USB 转 UART 桥接芯片连接到各自的 micro USB 连接器：

UART

连接器

UART0

CN3200

UART1

CN3201

UART2

CN3202

UART0 是 Linux 控制台，归 root cell 所有，因此 Zephyr 使用 CN3201 上的 UART1。

编程与调试

Zephyr 借助 Jailhouse hypervisor 在本开发板上运行，该 hypervisor 从 Linux 中划出一个 Cortex-A55 核交给 Zephyr。

这里涉及三个 Jailhouse 概念：

  • cell 是分配给一个操作系统的一组硬件资源。

  • root cell 是 Linux 所运行的 cell。它持有 Linux 使用的全部资源，分配给 inmate 的资源也从中划出。

  • inmate 是与 Linux 一同运行的其他任何操作系统。这里 Zephyr 就是一个 inmate。

Linux 和 Zephyr 都感知不到对方。各自只能看到其 cell 所描述的核和内存，hypervisor 通过第二阶段地址转换强制实施这一点。如果 inmate 访问了其 cell 配置中不存在的资源，就会触发异常。

Zephyr 获得一个 Cortex-A55 核和一段 8 MB 的 DRAM 窗口，cell 将其放在 inmate 自身地址空间的 0x8000 处。其他核和其余所有外设仍归 Linux 所有。

前提条件

目标设备上运行 IoT Yocto 镜像。Jailhouse、其内核模块以及本开发板的 cell 配置都已包含在该镜像中，无需单独构建。

以下步骤已在 IoT Yocto 26.0-release 上验证，其中 Jailhouse 0.12 运行于 6.6 内核。

构建

# From the root of the zephyr repository
west build -b mt8390_genio_700_evk/mt8188/a55 samples/hello_world

需要加载的产物是原始二进制文件 build/zephyr/zephyr.bin，而不是 ELF 文件。将其复制到目标设备，例如使用 scp。

加载

在目标设备上，将 Zephyr 二进制文件放在当前目录后执行：

modprobe jailhouse
jailhouse enable      /usr/share/jailhouse/cells/genio-700-evk.cell
jailhouse cell create /usr/share/jailhouse/cells/genio-700-evk-zephyr.cell
jailhouse cell load   zephyr zephyr.bin -a 0x8000
jailhouse cell start  zephyr

镜像本身不会启动 hypervisor，因此目标设备每次启动后，在创建任何 inmate 之前都需要执行一次 jailhouse enable。之后再次运行只需执行最后三条命令。

重要

传给 jailhouse cell load 的加载地址必须是 0x8000。它必须同时与 hypervisor 配置的 inmate 基地址以及开发板设备树中的 memory@8000 节点一致。如果不一致，镜像会被放到 Zephyr 链接地址之外的位置，而构建过程无法发现这一问题。

输出显示在 Connections and IOs 中所述的控制台上：

*** Booting Zephyr OS build v4.4.0 ***
Hello World! mt8390_genio_700_evk/mt8188/a55

停止并卸载 inmate：

jailhouse cell shutdown zephyr
jailhouse cell destroy  zephyr

调试

本开发板不提供 Zephyr 烧录或调试运行器（runner）：镜像由 hypervisor 从 Linux 中加载，而不是由主机端工具加载，因此 west flash 和 west debug 不适用于本开发板。
