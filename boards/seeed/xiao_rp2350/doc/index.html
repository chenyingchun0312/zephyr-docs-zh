XIAO RP2350

Board Overview

Name:
xiao_rp2350
Vendor:

Seeed Technology Co., Ltd

Status:

Not actively maintained

Architecture:

riscv, arm

SoC:

rp2350a

Browse board sources

概述

XIAO RP2350 是 Seeed Studio 推出的一款物联网迷你开发板。它搭载 RP2350A SoC、一个板载 WS2812 可寻址 LED 和 USB 接口。借助 USB 引导加载程序，无需任何适配器，通过拖放即可烧录。

更多细节请参阅 Seeed Studio XIAO RP2350 [1] wiki 页面。

硬件

Seeed Studio XIAO RP2350 是一款低功耗微控制器板，搭载强大的双核 RP2350A 处理器，时钟灵活可调，最高可达 133 MHz。此外还有 264KB SRAM 和 2MB 板载 Flash 存储器。

Seeed Studio XIAO RP2350 上有 14 个 GPIO 引脚，其中包括 11 个数字引脚、3 个模拟引脚、11 个 PWM 引脚、1 个 I2C 接口、1 个 UART 接口、1 个 SPI 接口和 1 个 SWD 焊盘接口。PCB 底面还有 8 个作为测试焊盘的 GPIO 引脚，额外提供 8 个用于次级接口的数字引脚，包括 1 个 I2C、1 个 UART 和 1 个 SPI。

引脚映射

RP2350A SoC 的外设可以路由到开发板上的不同引脚。这些路由配置可以通过 DTS 修改。各外设可用的路由方式请参阅数据手册。

Zephyr 默认外设映射：

主接口和次级接口

  • UART0_TX : P0

  • UART0_RX : P1

  • I2C1_SDA : P6

  • I2C1_SCL : P7

  • SPI0_CS : P5 (GPIO)

  • SPI0_RX : P4

  • SPI0_TX : P3

  • SPI0_SCK : P2

  • UART1_TX : P20

  • UART1_RX : P21

  • I2C0_SDA : P16

  • I2C0_SCL : P17

  • SPI1_CS : P9 (GPIO)

  • SPI1_SCK : P10

  • SPI1_RX : P11

  • SPI1_TX : P12

连接与 IO

该开发板在边缘连接器上采用标准 XIAO 引脚定义，并在 PCB 底面提供额外的 XIAO 测试焊盘。Seeed Studio XIAO RP2350 [1] wiki 提供了该开发板的详细信息，包括 pinouts [2] 和 schematic [3]。

烧录

使用 UF2

可以使用 UF2 文件烧录 Xiao RP2350。默认情况下，为该开发板构建应用程序时会生成 build/zephyr/zephyr.uf2 文件。如果按住 BOOTSEL 按键给 Xiao RP2350 上电，它会在主机上显示为大容量存储设备。将 UF2 文件复制到该设备，即可烧录 Xiao RP2350。
