STM32L562E-DK Discovery

Board Overview

Name:
stm32l562e_dk
Vendor:

STMicroelectronics

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32l562xx

Browse board sources

概述

STM32L562E-DK Discovery 套件是面向 STMicroelectronics 基于 Arm® Cortex®-M33 内核、带 TrustZone® 的 STM32L562QEI6QU 微控制器的完整演示和开发平台。STM32L562E-DK Discovery 开发板的主要特点如下：

  • STM32L562QEI6QU 微控制器，配备 512 KB Flash 和 256 KB SRAM，BGA132 封装

  • 1.54 英寸 240 x 240 像素、262K 色 TFT LCD 模块，带并行接口和触控面板

  • USB Type-C® 受电（Sink）全速设备

  • 板载电能计：测量范围 300 nA 至 150 mA，带专用 USB 接口

  • SAI 音频编解码器

  • MEMS 数字麦克风

  • 512 Mbit 容量的 Octal-SPI Flash

  • Bluetooth® V4.1 低功耗模块

  • iNEMO 三轴加速度计和三轴陀螺仪

  • 开发板连接器

    • STMod+ 扩展连接器，配有扇出扩展板，提供 Wi‑Fi®、Grove 和 mikroBUS™ 兼容连接器

    • Pmod™ 扩展连接器

    • 音频 MEMS 子板扩展连接器

    • ARDUINO® Uno V3 扩展连接器

  • 灵活的供电选项

    • ST-LINK

    • USB VBUS

    • 外部电源

  • 板载 STLINK-V3E 调试器/编程器，支持 USB 重新枚举：

    • 大容量存储

    • 虚拟 COM 端口

    • 调试端口

  • 2 个用户 LED

  • 用户按键和复位按键

有关该开发板的更多信息，请访问 STM32L562E-DK Discovery website。

硬件

STM32L562xx 器件是基于高性能 Arm® Cortex®-M33 32 位 RISC 内核的超低功耗微控制器系列（STM32L5 系列），工作频率最高可达 110 MHz。

  • 超低功耗，支持 FlexPowerControl（Standby 模式低至 108 nA，Run 模式 62 uA/MHz）

  • 内核：带 TrustZone® 和 FPU 的 ARM® 32 位 Cortex®-M33 CPU。

  • 性能基准：

    • 1.5 DMPIS/MHz（Drystone 2.1）

    • 442 CoreMark® (4.02 CoreMark® /MHZ)

  • Security（安全）

    • Arm® TrustZone® 以及可设为安全的 I/O、存储器和外设

    • 灵活的生命周期方案，支持 RDP（读出保护）

    • 通过唯一启动入口和隐藏保护区（HDP）建立信任根

    • 借助内置的 Root Secure Services 实现安全固件安装

    • 支持基于 TF-M 的安全固件更新

    • AES 协处理器

    • 公钥加速器

    • Octo-SPI 外部存储器的实时解密

    • HASH 硬件加速器

    • 主动防篡改，防护温度、电压和频率攻击

    • 真随机数发生器，符合 NIST SP800-90B

    • 96 位唯一 ID

    • 512 字节一次性可编程（OTP）用户数据区

  • 时钟管理：

    • 4 至 48 MHz 晶体振荡器

    • 用于 RTC 的 32 kHz 晶体振荡器（LSE）

    • 内部 16 MHz 出厂校准 RC 振荡器（±1%）

    • 内部低功耗 32 kHz RC 振荡器（±5%）

    • 内部多速振荡器，100 kHz 至 48 MHz，由 LSE 自动校准（精度优于 ±0.25%）

    • 3 个 PLL，分别用于系统时钟、USB、音频和 ADC

  • 电源管理

    • 内置稳压器（LDO），具有三档可配置输出范围，为数字电路供电

    • 内置 SMPS 降压转换器

    • 支持外部 SMPS

  • 带硬件日历、闹钟和校准功能的 RTC

  • 最多 114 个快速 I/O，大多数可耐受 5 V，最多 14 个 I/O 可独立供电，电压低至 1.08 V

  • 最多 22 个电容感应通道：支持触摸按键、线性和旋转触摸传感器

  • 最多 16 个定时器和 2 个看门狗

    • 2 个 16 位高级电机控制定时器

    • 2 个 32 位和 5 个 16 位通用定时器

    • 2 个 16 位基本型

    • 3 个低功耗 16 位定时器（在 Stop 模式下可用）

    • 2 个看门狗

    • 2 个 SysTick 定时器

  • 存储器

    • 最多 512 MB Flash，2 个 bank，支持边读边写

    • 512 KB SRAM，其中 64 KB 带硬件奇偶校验

    • 用于静态存储器的外部存储器接口，支持 SRAM、PSRAM、NOR、NAND 和 FRAM 存储器

    • OCTOSPI 存储器接口

  • 丰富的模拟外设（独立供电）

    • 3 个 12 位 ADC，5 MSPS，通过硬件过采样最高可达 16 位，200 uA/MSPS

    • 2 个 12 位 DAC，支持低功耗采样保持

    • 2 个内置 PGA 的运算放大器

    • 2 个超低功耗比较器

    • 4 个用于 Σ-Δ 调制器的数字滤波器

  • 19 个通信接口

    • USB Type-C / USB 供电（PD）控制器

    • 2.0 全速无晶振方案，支持 LPM 和 BCD

    • 2 个 SAI（串行音频接口）

    • 4x I2C FM+(1 Mbit/s), SMBus/PMBus

    • 6 个 USART（ISO 7816、LIN、IrDA、调制解调器）

    • 3 个 SPI（USART 和 OCTOSPI 工作在 SPI 模式时共 7 个 SPI）

    • 1xFDCAN

    • 1 个 SDMMC 接口

    • 2 个 14 通道 DMA 控制器

  • CRC 计算单元

  • 开发支持：串行线调试（SWD）、JTAG、嵌入式跟踪宏单元（Embedded Trace Macrocell™）

有关 STM32L562QE 的更多信息，请参阅：

  • STM32L562QE on www.st.com

  • STM32L562 reference manual

Zephyr 开发板选项

STM32L562e 是一款 Cortex-M33 架构的 SoC。Zephyr 支持构建安全固件和非安全固件。

BOARD 选项汇总如下：

BOARD

说明

stm32l562e_dk

用于构建禁用 TrustZone 的固件

stm32l562e_dk/stm32l562xx/ns

用于构建非安全固件

以下是使用 TF-M IPC 示例构建非安全配置 Zephyr 的说明：

$ west build -b stm32l562e_dk/stm32l562xx/ns samples/tfm_integration/tfm_ipc/

完成后，在烧录之前，需要先运行一个生成的脚本，用于设置平台选项字节配置并擦除平台（其中会设置选项位 TZEN）。

$ ./build/tfm/api_ns/regression.sh
$ west flash

注意，在开发板上运行 TFM 示例后，需要再次运行 ./build/tfm/api_ns/regression.sh，清除开发板上的安全选项，使平台恢复到“正常”状态，才能运行普通的非 TFM 二进制文件。另外，即使这样 TZEN 仍会保持置位，如有需要，必须使用 STM32CubeProgrammer 将其完全禁用。

连接与 IO

STM32L562E-DK Discovery 开发板有 8 个 GPIO 控制器。这些控制器负责引脚复用、输入/输出、上拉等功能。

更多详细信息，请参阅 STM32L562E-DK Discovery board User Manual。

Zephyr 默认外设映射：

  • USART_1 TX/RX : PA9/PA10

  • USART_3 TX/RX : PC10/PC11

  • I2C_1 SCL/SDA : PB6/PB7

  • SPI_1 SCK/MISO/MOSI : PG2/PG3/PG4（蓝牙 SPI 总线）

  • SPI_3 NSS/SCK/MISO/MOSI : PE0/PG9/PB4/PB5（Arduino SPI 接口）

  • USER_PB : PC13

  • LD10 : PG12

  • PWM_2_CH1 : PA0

  • DAC1 : PA4

  • ADC1 : PC4

系统时钟

STM32L562E-DK 的系统时钟可以由内部或外部振荡器驱动，也可以由主 PLL 时钟驱动。默认情况下，系统时钟由 110MHz 的 PLL 时钟驱动，PLL 由 4MHz 中速内部振荡器驱动。

串口

STM32L562E-DK Discovery 开发板有 6 个 U(S)ART。Zephyr 控制台输出分配到 USART1。默认设置为 115200 8N1。

TFT LCD 屏幕和触摸面板

STM32L562E-DK Discovery 开发板支持 TFT LCD 屏和触摸面板，可以使用 LVGL basic sample 示例进行测试：

# From the root of the zephyr repository
west build -b stm32l562e_dk samples/subsys/display/lvgl

编程与调试

说明

STM32L562E-DK Discovery 开发板集成了 ST-LINK/V3E 嵌入式调试工具接口。

stm32l562e_dk 开发板配置的应用程序可以按常规方式构建和烧录（详见 构建应用程序 和 运行应用程序）。

烧录

本开发板配置为使用 west 的 STM32CubeProgrammer 运行器（runner）进行烧录，因此需要先完成其 安装。

也可以通过 --runner（或 -r）选项使用 OpenOCD 烧录开发板：

$ west flash --runner openocd

也可以通过以下 pyOCD 命令添加“pack”支持，从而启用 pyOCD 支持：

$ pyocd pack --update
$ pyocd pack --install stm32l562qe

将应用程序烧录到 STM32L562E-DK Discovery

使用 USB 端口将 STM32L562E-DK Discovery 连接到主机，然后构建并烧录应用程序。下面以 Hello World 应用程序为例。

运行串口主机程序以连接 Nucleo 开发板：

$ minicom -D /dev/ttyACM0

然后构建并烧录应用程序。

# From the root of the zephyr repository
west build -b stm32l562e_dk samples/hello_world
west flash

控制台上应显示以下信息：

Hello World! stm32l562e_dk

调试

可以按常规方式调试应用程序。以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b stm32l562e_dk samples/hello_world
west debug
