Nucleo N657X0-Q

Board Overview

Name:
nucleo_n657x0_q
Vendor:

STMicroelectronics

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32n657xx

Browse board sources

概述

NUCLEO-N657X0-Q 开发板为用户提供了一种经济、灵活的方式，可以在 STM32 微控制器提供的多种性能和功耗特性组合中进行选择，尝试新概念并构建原型。对于兼容的开发板，内部或外部 SMPS 可以显著降低运行模式下的功耗。

ST Zio 连接器扩展了 ARDUINO® Uno V3 连接，配合 ST morpho 排针，可以借助种类丰富的专用扩展板方便地扩展 Nucleo 开放开发平台的功能。

NUCLEO-N657X0-Q 开发板集成了 ST-LINK 调试器/编程器，无需单独的调试探针。

STM32 Nucleo-144 开发板附带 STM32Cube MCU 软件包中提供的完整的 STM32 免费软件库和示例。

硬件

  • 共同特性：

    • STM32 微控制器，采用 LQFP144、TFBGA225 或 VFBGA264 封装

    • 3 个用户 LED

    • 1 个用户按键和 1 个复位按键

    • 32.768 kHz 晶体振荡器

    • 开发板连接器：

      • SWD

      • ST morpho 扩展连接器

    • 灵活的供电选项：ST-LINK USB VBUS、USB 连接器或外部电源

  • 部分开发板特有的功能（详情请参阅数据简介中的订购信息一节）；

    • 外部或内部 SMPS，用于产生 Vcore 逻辑电源

    • 符合 IEEE-802.3-2002 的以太网

    • 仅 USB 设备、USB OTG 全速，或 SNK/UFP（全速或高速模式）

    • 开发板连接器：

      • ARDUINO® Uno V3 连接器，或包含 ARDUINO® Uno V3 的 ST Zio 扩展连接器

      • 摄像头模块 FPC

      • 带跟踪信号的 MIPI20 兼容连接器

      • Micro-AB 或 USB Type-C® USB 接口

      • 以太网 RJ45

    • 板载 ST-LINK（STLINK/V2-1、STLINK-V3E 或 STLINK-V3EC）调试器/编程器，支持 USB 重新枚举：大容量存储、虚拟 COM 端口和调试端口

更多详细信息请参阅：

  • NUCLEO-N657X0-Q website

  • STM32N657X0 on www.st.com

  • STM32N657 reference manual

支持的功能

nucleo_n657x0_q 开发板支持下列硬件功能。

说明

以太网

NUCLEO-N657X0-Q 带有一个以太网接口，通过 RMII 连接到外部 PHY。

片上 OTP（一次性可编程）存储器中有一个区域专门用于保存以太网 MAC 地址。该区域在生产时未编程，读出值全为零；必须在现场使用 STM32CubeProgrammer 编程。

要在应用程序中使用 OTP MAC 地址 MAC_ADDR1，请添加以下覆盖文件：

&mac {
    nvmem-cells = <&mac_address0>;
    nvmem-cell-names = "mac-address";
};

警告

如果片上 OTP 尚未编程，使用此覆盖文件时以太网将无法工作，因为此时会读到未编程的 OTP 值（全为零）并将其用作 MAC 地址，而 00:00:00:00:00:00 不是有效的 MAC 地址。

不过，为了能在不对设备进行不可逆编程的情况下运行 Zephyr 网络相关示例，STM32 以太网驱动默认会根据设备唯一 ID 生成一个本地管理的 MAC 地址。

USB

STM32N657XX 微控制器上的 USB 引脚分配是固定的。也就是说，指定用于 USB 功能的引脚不能更改，也不能重新分配给其他功能，从而确保 USB 通信一致可靠。

连接与 IO

NUCLEO-N657X0-Q 开发板有 12 个 GPIO 控制器。这些控制器负责引脚复用、输入/输出、上拉等功能。

系统时钟

NUCLEO-N657X0-Q 的系统时钟可以由内部或外部振荡器驱动，也可以由主 PLL 时钟驱动。默认情况下，系统时钟由 400MHz 的 PLL 时钟驱动，PLL 由 64MHz 高速内部振荡器驱动。

串口

NUCLEO-N657X0-Q 开发板有 10 个 U(S)ART。Zephyr 控制台输出分配到 USART1，默认设置为 115200 8N1。

STM32 OEMuROT 集成

STM32CubeN6 提供了一个名为 STM32 OEMuROT 的外部安全引导加载程序，它利用了 STM32N657X0 微控制器的安全特性。关于该引导加载程序的详细信息，请参阅 OEMuRoT for STM32N6 wiki article。

该引导加载程序在 Zephyr 构建环境中的集成由外部的 STM32 OEMxROT module 提供。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

NUCLEO-N657X0-Q 开发板带有 ST-LINK/V3 嵌入式调试工具接口。通过该调试探针可以使用多种工具烧录和调试开发板。

烧录或加载

本开发板配置为使用 west STM32CubeProgrammer 运行器（runner）进行编程，因此需要 安装 该工具。要求 STM32CubeProgrammer 版本为 2.18.0 或更高。

备注

固件以安全执行模式运行，因此需要签名。构建完成后，构建系统会自动使用 STM32CubeProgrammer 的工具 STM32_SigningTool_CLI 生成二进制文件的签名版本。该工具随 STM32CubeProgrammer 一同安装，但请确保它位于 PATH 变量中。

编程开发板有两种方式：

  • 将固件编程到外部 Flash 中。启动时，固件会被加载到 RAM 并在 RAM 中执行。

  • 也可以选择利用启动 ROM 提供的串行启动接口。此时固件直接加载到 RAM 并在 RAM 中执行，不会保留在持久性存储器中。

将应用程序烧写到 NUCLEO-N657X0-Q

以下是构建并运行 Hello World 应用程序的示例。

首先使用 ST-Link USB 端口将 NUCLEO-N657X0-Q 连接到主机。

使用 nucleo_n657x0_q 目标构建并烧录应用程序。

# From the root of the zephyr repository
west build -b nucleo_n657x0_q samples/hello_world
west flash

备注

烧录时，在给开发板上电之前，按以下配置设置启动引脚：

  • BOOT0：0（跳线 JP1 位于位置 1，PCB 上有印刷标注）

  • BOOT1：1（跳线 JP2 位于位置 2，PCB 上无印刷标注）

烧录完成后，要运行应用程序，请按以下配置设置启动引脚：

  • BOOT0：0（跳线 JP1 位于位置 1，PCB 上有印刷标注）

  • BOOT1：0（跳线 JP2 位于位置 1，PCB 上有印刷标注）

将开发板断电后重新上电。

除 USB/ST-Link 外，还需使用 USB 端口（USB/CN8）将 NUCLEO-N657X0-Q 连接到主机。

在此配置下，ST-Link（USB 连接器 CN10）用于为开发板供电并通过虚拟 COM 端口进行串行通信，而 USB/CN8 用于将 Zephyr 镜像发送给 Boot ROM，由其加载到 RAM 中并执行。

备注

在给开发板上电之前，按以下配置设置启动引脚：

  • BOOT0：1（跳线 JP1 位于位置 2，PCB 上无印刷标注）

  • BOOT1：0（跳线 JP2 位于位置 1，PCB 上有印刷标注）

使用 nucleo_n657x0_q/stm32n657xx/sb 目标（也可以使用简写形式 nucleo_n657x0_q//sb）构建并加载应用程序

# From the root of the zephyr repository
west build -b nucleo_n657x0_q//sb samples/hello_world
west flash

运行串口终端程序连接开发板：

$ minicom -D /dev/ttyACM0

控制台上应显示以下信息：

Hello World! nucleo_n657x0_q/stm32n657xx

调试

可以使用 ST-LINK GDB 服务器 按常规方式调试应用程序。下面以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b nucleo_n657x0_q samples/hello_world
west debug

备注

要启用调试，请在给开发板上电之前，按以下配置设置启动引脚：

  • BOOT0: 0

  • BOOT1: 1

另一种调试方法是使用 STM32CubeIDE：

  • 依次选择 File ‣ Import，然后选择 C/C++ ‣ STM32 Cortex-M Executable。

  • 在 Executable 字段中，浏览选择 <ZEPHYR_PATH>/build/zephyr/zephyr.elf。

  • 在 MCU 字段中，选择 STM32N657X0HxQ。

  • 点击 Finish。

  • 最后，点击 Debug 开始调试会话。

使用 twister 运行测试

由于使用 nucleo_n657x0_q 开发板目标烧录时需要操作 BOOT 开关，因此只能在 nucleo_n657x0_q/stm32n657xx/sb 开发板目标上运行 twister 测试，该目标加载和执行二进制文件时无需改变 BOOT 引脚。为此，建议使用 Twister 的硬件映射功能，并采用以下设置：

- platform: nucleo_n657x0_q/stm32n657xx/sb
  product: BOOT-SERIAL
  pre_script: <path_to_zephyr>/boards/st/common/scripts/board_power_reset.sh
  runner: stm32cubeprogrammer
