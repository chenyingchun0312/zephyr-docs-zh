Nucleo C5A3ZG

Board Overview

Name:
nucleo_c5a3zg
Vendor:

STMicroelectronics

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32c5a3xx

Browse board sources

概述

STM32 Nucleo-144 开发板为用户提供了一种经济、灵活的方式，可以从 STM32 微控制器提供的各种性能和功耗特性组合中进行选择，尝试新概念并构建原型。对于兼容的开发板，内部或外部 SMPS 可显著降低运行模式下的功耗。

STM32 Nucleo-144 开发板通过多个扩展连接器，可以方便地借助种类丰富的专用扩展板来扩展 Nucleo 开放开发平台的功能：

  • ARDUINO® Uno V3 连接器，在部分开发板上作为 ST Zio 扩展连接器的一部分进行了扩展

  • ST morpho 排针，可访问微控制器的 I/O 引脚

STM32 Nucleo-144 开发板集成了 ST-LINK 调试器/编程器，无需单独的调试探针。

关于该开发板的更多信息，请参见 Nucleo C5A3ZG website [1]。

硬件

  • STM32C5A3ZGT6 微控制器，基于 Arm® Cortex®-M33 内核，采用 LQFP144 封装

  • 32.768 kHz LSE 晶体振荡器

  • 48 MHz HSE 晶体振荡器

  • 三个用户 LED

  • 三个按键：用户、复位和启动

  • USB Type-C® FS 受电（Sink）设备

  • 符合 IEEE-802.3-2002 的以太网

  • 开发板连接器：

    • USB Type-C® 连接器

    • 通过 ST B-M2MEM-PACK1 M.2 串行存储器套件 扩展板支持 M.2 Key A 串行存储器连接器。

    • 用于调试的 MIPI20 连接器（SWD、JTAG、4 位 Trace）

    • 10/100 Mbit/s 以太网连接器

    • ARDUINO® Uno V3 连接器

    • ST morpho 扩展连接器，可完全访问大部分 STM32 I/O

  • 灵活的供电选项：ST-LINK USB VBUS、USB 连接器或外部电源

  • 板载 STLINK-V3EC 调试器/编程器，支持 USB 重新枚举：大容量存储、虚拟串口和调试端口

关于 STM32C5A3ZG 的更多信息请参见：STM32C5 reference manual [2]

连接与 IO

每个 GPIO 引脚都可以通过软件配置为输出（推挽或开漏）、输入（带或不带上拉/下拉）或外设复用功能。大多数 GPIO 引脚与数字或模拟复用功能共用。除模拟输入外，所有 GPIO 都支持大电流。

默认配置下，PA5（ARDUINO® D13）引脚可能存在冲突，它同时连接到绿色 LED（LD1）和 SPI1 SCK（ARDUINO® SPI）。不建议同时使用这两种功能。

也可以改为焊接 SB7 而非 SB8，用第二个 GPIO PG0 驱动 LD1。这样 ARDUINO® D13 功能可以与绿色 LED 功能同时使用。在此配置下，STM32 I/O 为高电平时用户 LED 熄灭，为低电平时点亮。

详情请参阅 STM32 Nucleo-144 board User Manual [3]。

USB

警告

默认情况下，连接器上没有死电池下拉电阻（自供电模式）。因此不能使用 USB-C 转 USB-C 线缆通过用户 USB-C 连接器为开发板供电，但传统的 USB-C 转 USB-A 线缆仍可使用。另一种方法是同时连接用户 USB 和 ST-Link USB。也可以修改开发板以支持总线供电模式。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

Nucleo C5A3ZG 开发板带有 STLINK-V3EC 嵌入式调试工具接口。

nucleo_c5a3zg 开发板的应用程序可以按常规方式构建和烧录（详情请参见 构建应用程序 和 运行应用程序）。

烧录

本开发板配置为使用 west 的 STM32CubeProgrammer [4] 运行器（runner）进行烧录，因此需要先完成其 安装。

也可以通过 --runner 选项使用外部 JLink（Software and Documentation Package 版本 >= v8.12e）烧录开发板：

$ west flash --runner jlink

将应用程序烧录到 Nucleo C5A3ZG

以下以 Blinky 应用程序为例。

# From the root of the zephyr repository
west build -b nucleo_c5a3zg samples/basic/blinky
west flash

可以看到 LED 每秒闪烁一次。

调试

可以按常规方式使用 ST-LINK GDB Server 调试应用程序。以下以 Blinky 应用程序为例。

# From the root of the zephyr repository
west build -b nucleo_c5a3zg samples/basic/blinky
west debug
