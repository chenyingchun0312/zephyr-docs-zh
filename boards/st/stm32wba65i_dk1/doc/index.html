STM32WBA65I Discovery kit

Board Overview

Name:
stm32wba65i_dk1
Vendor:

STMicroelectronics

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32wba65xx

Browse board sources

概述

STM32WBA65I-DK1 是一款支持 Bluetooth® Low Energy、802.15.4 和 Zigbee® 的无线超低功耗开发板，内置一个性能强大的超低功耗射频模块，符合 Bluetooth® Low Energy SIG 规范 v5.4 以及 IEEE 802.15.4-2015 和 Zigbee® 规范。

借助 ARDUINO® Uno V3 连接支持和 ST morpho 排针，可以使用种类繁多的专用扩展板（shield）轻松扩展 STM32 Discovery 套件开放开发平台的功能。

  • 超低功耗无线 STM32WBA65RI 微控制器，基于带 TrustZone®、MPU、DSP 和 FPU 的 Arm® Cortex® ‑M33 核，工作频率最高 100 MHz，具有 2 MB Flash 存储器和 512 KB SRAM，采用 VFQFPN68 封装

  • MCU 射频板（MB2130）：

    • 2.4 GHz RF 收发器，支持 Bluetooth® v5.4 规范

    • Arm® Cortex® M33 CPU，带 TrustZone®、MPU、DSP 和 FPU

    • 集成 PCB 天线

  • 3 个用户 LED（其中 1 个默认未连接）

  • 1 个复位按键

  • 1 个摇杆

  • 开发板连接器：

    • 2 个 USB Type-C

    • ARDUINO® Uno V3 扩展连接器

    • ST morpho 排针，可访问 STM32 的全部 I/O

  • 灵活的供电选项：ST-LINK USB VBUS 或外部电源

  • 板载 STLINK-V3MODS 调试器/编程器，支持 USB 重新枚举：大容量存储、虚拟 COM 端口和调试端口

硬件

STM32WBA65xx 多协议无线超低功耗器件内置一个强大的超低功耗射频，符合 Bluetooth® SIG Low Energy 5.4 规范。

  • 包含 ST 最先进的专利技术

  • 超低功耗射频：

    • 2.4 GHz 射频

    • RF 收发器，支持 Bluetooth® Low Energy 5.4 规范以及 IEEE 802.15.4-2015 PHY 和 MAC，支持 Thread、Matter 和 Zigbee®

    • 专有协议

    • 接收灵敏度：-96 dBm（Bluetooth® Low Energy，1 Mbps）和 -100 dBm（IEEE 802.15.4，250 kbps）

    • 可编程输出功率最高 +10 dBm，步进 1 dB

    • 支持外部 PA

    • 集成巴伦（balun），减少 BOM

    • 适用于需要符合 ETSI EN 300 328、EN 300 440、FCC CFR47 Part 15 和 ARIB STD-T66 射频法规的系统

  • 基于 FlexPowerControl 的超低功耗平台：

    • 1.71 至 3.6 V 电源

      • 40 °C 至 85 °C 温度范围

    • 带 DMA 的自主外设，可在低至 Stop 1 模式下工作

    • Standby 模式 120 nA（16 个唤醒引脚）

    • 保留 64 KB SRAM 并带 RTC 的 Standby 模式 1.68 µA

    • 保留 64 KB SRAM 并带 RTC 的 Stop 2 模式 5.58 µA

    • 3.3 V 下 Run 模式 28.75 µA/MHz

    • 射频：Rx 4.26 mA / Tx（0 dBm）5.94 mA

  • ART Accelerator™：8 KB 指令缓存，支持从 Flash 零等待执行（频率最高 100 MHz，150 DMIPS）

  • 电源管理：内置稳压器 LDO 和 SMPS 降压转换器

  • 支持动态切换和电压调节

  • 基准测试：

    • 1.5 DMIPS/MHz（Drystone 2.1）

    • 410 CoreMark® (4.10 CoreMark/MHz)

  • 时钟源：

    • 32 MHz 晶体振荡器

    • 32 kHz 晶体振荡器（LSE）

    • 内部低功耗 32 kHz RC 振荡器（±5%）

    • 内部 16 MHz 出厂校准 RC 振荡器（±1%）

    • 用于系统时钟和 ADC 的 PLL

  • 存储器：

    • 2 MB 带 ECC 的 Flash 存储器，其中 256 KB 支持 100 次擦写周期

    • 512 KB SRAM，其中 64 KB 带奇偶校验

    • 512 字节（32 行）OTP

  • 丰富的模拟外设（独立供电）：

    • 12 位 ADC，2.5 Msps，支持硬件过采样

  • 通信外设：

    • 四个 UART（ISO 7816、IrDA、调制解调器）

    • 三个 SPI

    • 四个 I2C Fm+（1 Mbit/s），SMBus/PMBus®

  • 系统外设：

    • 触摸感应控制器，最多 24 个传感器，支持触摸按键、线性、

      旋转式触摸传感器

    • 一个 16 位高级电机控制定时器

    • 三个 16 位定时器

    • 两个 32 位定时器

    • 两个低功耗 16 位定时器（在 Stop 模式下可用）

    • 两个 Systick 定时器

    • 带硬件日历和校准功能的 RTC

    • 两个看门狗

    • 8 通道 DMA 控制器，可在 Stop 模式下工作

  • 安全与加密：

    • Arm® TrustZone® 以及可设为安全的 I/O、存储器和外设

    • 灵活的生命周期管理方案，支持 RDP 和密码保护调试

    • 基于唯一启动入口和安全隐藏保护区（HDP）的信任根

    • 借助嵌入式 RSS（根安全服务）实现 SFI（安全固件安装）

    • 使用根硬件唯一密钥（RHUK）的安全数据存储

    • 支持基于 TF-M 的安全固件升级

    • 两个 AES 协处理器，其中一个具有抗 DPA 能力

    • 公钥加速器，抗 DPA 攻击

    • HASH 硬件加速器

    • 真随机数发生器，符合 NIST SP800-90B

    • 96 位唯一 ID

    • 主动防篡改

    • CRC 计算单元

  • 最多 86 个 I/O（大部分可耐受 5 V），支持中断

  • 开发支持：

    • 串行线调试（SWD）、JTAG、Embedded Trace Macrocell™

  • 符合 ECOPACK2 的封装

有关 STM32WBA 系列的更多信息，请参阅：

  • STM32WBA Series on www.st.com

Bluetooth 和 IEEE 802.15.4 支持

stm32wba65i_dk1 已启用 BLE 和 IEEE 802.15.4 支持。要使用该开发板构建 Zephyr 示例，首先需要安装 Zephyr 中以二进制 blob 形式提供的 Bluetooth 和/或 IEEE 802.15.4 控制器库。

获取二进制 BLOB：

west blobs fetch hal_stm32

Zephyr 开发板选项

Zephyr 支持为 STM32WBA65I-DK1 开发板同时构建安全固件和非安全固件，其中 TF-M 作为嵌入式安全固件，Zephyr 作为非安全固件。

BOARD 选项汇总如下：

BOARD

说明

stm32wba65i_dk1

用于构建禁用 TrustZone 的固件

stm32wba65i_dk1/stm32wba65xx/ns

用于构建非安全固件

以下是使用 TF-M IPC 示例构建非安全配置 Zephyr 的说明：

# From the root of the zephyr repository
west build -b stm32wba65i_dk1/stm32wba65xx/ns samples/tfm_integration/tfm_ipc

完成后，在烧录之前，需要先运行一个生成的脚本，用于设置平台选项字节配置并擦除内部 Flash（其中会设置选项位 TZEN）。

$ ./build/tfm/api_ns/regression.sh
$ west flash

请注意，为启用 TrustZone 的系统编程开发板之后（例如使用 ./build/tfm/api_ns/regression.sh），SoC 的 TZEN 选项字节会被启用。要让开发板恢复正常状态，以便启动禁用 TrustZone 的系统（例如不支持 TF-M），需要执行特定的操作序列来禁用该 TZEN 选项字节配置。可以使用 STM32CubeProgrammer 禁用 SoC TZEN 选项字节配置。请参阅 How to disable STM32WBA65 TZEN Option Byte。

安全引导加载程序

STM32 OEMiROT 集成

STM32CubeWBA 提供了名为 STM32 OEMiROT 的外部安全引导加载程序，它利用了 STM32WBA65RI 微控制器的安全特性。有关该引导加载程序的详细信息，请参阅 OEMiRoT/OEMuRoT for STM32WBA wiki article。

该引导加载程序在 Zephyr 构建环境中的集成由外部的 STM32 OEMxROT module 提供。

STM32 器件支持使用基于 MCUboot 的默认工作流在 Zephyr 中实现安全启动。SMP server 应用程序就是可配合 MCUboot 镜像管理工作流使用的示例之一。

使用支持 MCUmgr 的客户端（工具和库）。以下步骤使用 newtmgr。

根据开发板的能力，可以使用 smp_svr 应用程序通过串行 UART 连接更新镜像。

使用 MCUboot 和串口 MCUmgr 传输构建该示例：

west build -b stm32wba65i_dk1 --sysbuild samples/subsys/mgmt/mcumgr/smp_svr -- \
  -DEXTRA_CONF_FILE=serial.conf

UART MCUmgr 需要 zephyr,uart-mcumgr chosen 节点。如果开发板未定义该节点，请在 samples/subsys/mgmt/mcumgr/smp_svr/boards/ 下添加应用程序的开发板覆盖文件。例如：

/ {
  chosen {
    zephyr,uart-mcumgr = &usart1;
  };
};

将 &usart1 替换为连接到开发板串口接口的 UART。

烧录 smp_svr 后，即可通过串口使用 newtmgr。以下示例假设串口设备为 /dev/ttyACM0：

# Create the serial connection for your board, here on /dev/ttyACM0
newtmgr conn add serial type=serial connstring="dev=/dev/ttyACM0,baud=115200"
# Upload a new signed image to the download slot
newtmgr -c serial image upload build/smp_svr/zephyr/zephyr.signed.bin
# List the images and retrieve the hash of the image the download slot
newtmgr -c serial image list
# Mark this image as a test image
newtmgr -c serial image test <new_image_hash>
# Reset the device for the bootloader to install the image into the primary slot
newtmgr -c serial reset
# Once the image is validated, confirm it to make it permanent (skip this step and reset to revert)
newtmgr -c serial image confirm <new_image_hash>

STM32WBA65I-DK1 开发板还支持使用 SMP server 应用程序，通过 BLE 在 Zephyr 中进行安全 FOTA。

烧录 smp_svr 后，即可使用 newtmgr 通过 BLE 进行 FOTA。以下示例假定 HCI 接口为 hci0。注意，内部 HCI 设备有时可能不太可靠。

# Upload a new signed image to the download slot
newtmgr -i 0 --conntype ble --connstring peer_name=Zephyr image upload build/smp_svr/zephyr/zephyr.signed.bin
# List the images and retrieve the hash of the image in the download slot
newtmgr -i 0 --conntype ble --connstring peer_name=Zephyr image list
# Mark this image as a test image
newtmgr -i 0 --conntype ble --connstring peer_name=Zephyr image test <new_image_hash>
# Reset the device for the bootloader to install the image into the primary slot
newtmgr -i 0 --conntype ble --connstring peer_name=Zephyr reset
# Once the image is validated, confirm it to make it permanent (skip this step and reset to revert)
newtmgr -i 0 --conntype ble --connstring peer_name=Zephyr image confirm <new_image_hash>

低功耗

STM32WBA65I-DK1 支持 Zephyr 电源管理，可在应用程序空闲时进入低功耗状态。

为实现最低功耗，Zephyr 的 suspend-to-ram 在本平台上使用 STM32 的 Standby 模式。

必须在应用程序中启用 CONFIG_PM 以开启电源管理：

CONFIG_PM=y

对于 STM32WBA 上的 suspend-to-ram，参考实现是 Heart-rate Monitor (Peripheral)，需配合 samples/bluetooth/peripheral_hr/boards/stm32wba_pwr_optim.overlay 使用。

在该覆盖文件中，可以将 sram0 缩减到最小可用大小以降低功耗，而 pm_s2ram 应保持位于可用 RAM 的末尾。

构建命令示例：

west build -b stm32wba65i_dk1 samples/bluetooth/peripheral_hr -- \
  -DDTC_OVERLAY_FILE=boards/stm32wba_pwr_optim.overlay \
  -DCONFIG_PM=y

连接与 IO

STM32WBA65I-DK1 开发板有 4 个 GPIO 控制器。这些控制器负责引脚复用、输入/输出、上拉等功能。

Zephyr 默认外设映射：

  • USART_1 TX/RX : PB12/PA8

  • I2C_1_SCL : PB2

  • I2C_1_SDA : PB1

  • LD6 : PD8

  • SPI_1_NSS : PA12 (arduino_spi)

  • SPI_1_SCK : PB4 (arduino_spi)

  • SPI_1_MISO : PB3 (arduino_spi)

  • SPI_1_MOSI : PA15 (arduino_spi)

系统时钟

STM32WBA65I-DK1 的系统时钟可以由内部或外部振荡器驱动，也可以由主 PLL 时钟驱动。默认情况下，系统时钟由 100MHz 的 HSE+PLL 时钟驱动。

串口

STM32WBA65I-DK1 开发板有 3 个 U(S)ART。Zephyr 控制台输出分配到 USART1。默认设置为 115200 8N1。

烧录

本开发板配置为使用 west 的 STM32CubeProgrammer 运行器（runner）进行烧录，因此需要先完成其 安装。

将应用程序烧录到 STM32WBA65I-DK1

以下以 Blinky 应用程序为例。

# From the root of the zephyr repository
west build -b stm32wba65i_dk1 samples/basic/blinky
west flash

可以看到 LED 每秒闪烁一次。

调试

使用 OpenOCD 调试

OpenOCD 于 2026 年 1 月（在 v0.12.0 发布标签之后）添加了对 STM32WB65x 的完整支持（OpenOCD WBA6xx commit）。借助 OpenOCD 对 STM32WBA5x 的支持（于 2023 年 9 月合并，在 v0.12.0 发布标签之后，见 OpenOCD WBA5xx commit）可以获得基本支持。Zephyr SDK 派生的 OpenOCD 目前只包含 STM32WBA5x 支持。

如果所用的 OpenOCD 工具（本地安装或来自 Zephyr SDK）至少支持 STM32WBA5x，即可照常使用 OpenOCD 调试应用程序。以下是 Blinky 应用程序的示例。

# From the root of the zephyr repository
west build -b stm32wba65i_dk1 samples/basic/blinky
west debug
