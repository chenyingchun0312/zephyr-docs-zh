B-U585I-IOT02A Discovery kit

Board Overview

Name:
b_u585i_iot02a
Vendor:

STMicroelectronics

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32u585xx

Browse board sources

概述

B_U585I_IOT02A Discovery 套件搭载基于 ARM Cortex-M33 的 STM32U585AI MCU，支持多种连接方式和配置。以下是 B_U585I_IOT02A Discovery 套件的一些亮点：

  • STM32U585AII6Q 微控制器，具有 2 MB Flash 存储器和 786 KB RAM，采用 UFBGA169 封装

  • 512 Mbit 八线 SPI Flash 存储器、64 Mbit 八线 SPI PSRAM、256 Kbit I2C EEPROM

  • USB FS，支持受电（Sink）和供电（Source），供电能力 2.5 W

  • MXCHIP 的符合 802.11 b/g/n 的 Wi-Fi® 模块

  • STMicroelectronics 的低功耗蓝牙（Bluetooth® Low Energy）

  • STMicroelectronics 的 MEMS 传感器

    • 2 个数字麦克风

    • 相对湿度和温度传感器

    • 3 轴磁力计

    • 3D 加速度计和 3D 陀螺仪

    • 压力传感器，260-1260 hPa 绝对数字输出气压计

    • 飞行时间（ToF）和手势检测传感器

    • 环境光传感器

  • 2 个按键（用户按键和复位按键）

  • 2 个用户 LED

  • 灵活的供电选项

    • ST-LINK/V3

    • USB Vbus

    • 外部电源

关于该开发板的更多信息，请参见 B U585I IOT02A Discovery kit website。

硬件

STM32U585xx 器件是基于高性能 Arm® Cortex®-M33 32 位 RISC 内核的超低功耗微控制器系列（STM32U5 系列），工作频率最高 160 MHz。

  • 基于 FlexPowerControl 的超低功耗（Standby 模式低至 300 nA，运行模式 19.5 uA/MHz）

  • 内核：带 TrustZone® 和 FPU 的 ARM® 32 位 Cortex®-M33 CPU。

  • 性能基准：

    • 1.5 DMPIS/MHz（Drystone 2.1）

    • 651 CoreMark® (4.07 CoreMark® /MHZ)

  • 安全与加密

    • Arm® TrustZone® 以及可设为安全的 I/O、存储器和外设

    • 灵活的生命周期管理方案，支持 RDP（读出保护）和密码保护调试

    • 基于唯一启动入口和安全隐藏保护区（HDP）的信任根

    • 借助内置的 Root Secure Services 实现安全固件安装

    • 使用硬件唯一密钥（HUK）的安全数据存储

    • 支持基于 TF-M 的安全固件更新

    • 2 个 AES 协处理器，其中一个抗 DPA 攻击

    • 公钥加速器，抗 DPA 攻击

    • Octo-SPI 外部存储器的实时解密

    • HASH 硬件加速器

    • 主动防篡改

    • 真随机数发生器，符合 NIST SP800-90B

    • 96 位唯一 ID

    • 512 字节一次性可编程（OTP）用户数据区

    • 主动防篡改

  • 时钟管理：

    • 4 至 50 MHz 晶体振荡器

    • 用于 RTC 的 32 kHz 晶体振荡器（LSE）

    • 内部 16 MHz 出厂校准 RC 振荡器（±1%）

    • 内部低功耗 32 kHz RC 振荡器（±5%）

    • 2 个内部多速振荡器，100 kHz 至 48 MHz，其中一个由 LSE 自动校准（精度优于 ±0.25%）

    • 3 个 PLL，分别用于系统时钟、USB、音频和 ADC

    • 内部 48 MHz 振荡器，带时钟恢复

  • 电源管理

    • 内置稳压器（LDO）

    • 内置 SMPS 降压转换器，支持动态切换和电压调节

  • 带硬件日历和校准功能的 RTC

  • 最多 136 个快速 I/O，大多数可耐受 5 V，最多 14 个 I/O 可独立供电，电压低至 1.08 V

  • 最多 24 个电容感应通道：支持触摸按键、线性和旋转触摸传感器

  • 最多 17 个定时器和 2 个看门狗

    • 2 个 16 位高级电机控制定时器

    • 2 个 32 位和 5 个 16 位通用定时器

    • 4 个低功耗 16 位定时器（在 Stop 模式下可用）

    • 2 个看门狗

    • 2 个 SysTick 定时器

  • ART 加速器

    • 8 KB 指令缓存，可从 Flash 和外部存储器零等待执行：最高 160 MHz，带 MPU，240 DMIPS 和 DSP

    • 用于外部存储器的 4 KB 数据缓存

  • 存储器

    • 2 MB 带 ECC 的 Flash 存储器，2 个 bank 支持边读边写，其中 512 KB 可擦写 100 k 次

    • 关闭 ECC 时 786 KB SRAM，或开启 ECC 时 722 KB SRAM（其中最多 322 KB 带 ECC）

    • 外部存储器接口，支持 SRAM、PSRAM、NOR、NAND 和 FRAM 存储器

    • 2 个 Octo-SPI 存储器接口

  • 丰富的模拟外设（独立供电）

    • 14 位 ADC，2.5 Msps，通过硬件过采样分辨率最高可达 16 位

    • 12 位 ADC，2.5 Msps，支持硬件过采样，可在 Stop 2 模式下自主运行

    • 12 位 DAC，低功耗采样保持

    • 2 个内置 PGA 的运算放大器

    • 2 个超低功耗比较器

  • 最多 22 个通信接口

    • USB Type-C / USB 供电（PD）控制器

    • USB OTG 2.0 全速控制器

    • 2 个 SAI（串行音频接口）

    • 4x I2C FM+(1 Mbit/s), SMBus/PMBus

    • 6 个 USART（ISO 7816、LIN、IrDA、调制解调器）

    • 3 个 SPI（双 OCTOSPI 工作于 SPI 模式时共 5 个 SPI）

    • 1x FDCAN

    • 2 个 SDMMC 接口

    • 16 通道和 4 通道 DMA 控制器，可在 Stop 模式下工作

    • 1 个多功能数字滤波器（6 个滤波器）+ 1 个带声音活动检测的音频数字滤波器

  • CRC 计算单元

  • 开发支持：串行线调试（SWD）、JTAG、嵌入式跟踪宏单元（Embedded Trace Macrocell™）

  • 真随机数发生器（RNG）

  • 图形功能

    • Chrom-ART 加速器（DMA2D），增强图形内容生成能力

    • 1 个数字摄像头接口

  • 数学协处理器

  • CORDIC，用于加速三角函数运算

  • FMAC（滤波器数学加速器）

有关 STM32U585AI 的更多信息参见：

  • STM32U585 on www.st.com

  • STM32U585 reference manual

Zephyr 开发板选项

STM32U585i 是一款采用 Cortex-M33 架构的 SoC。Zephyr 支持构建安全固件和非安全固件。

BOARD 选项汇总如下：

BOARD

说明

b_u585i_iot02a

用于构建禁用 TrustZone 的固件

b_u585i_iot02a/stm32u585xx/ns

用于构建非安全固件

以下是使用 TF-M IPC 示例构建非安全配置 Zephyr 的说明：

$ west build -b b_u585i_iot02a/stm32u585xx/ns samples/tfm_integration/tfm_ipc/

完成后，在烧录之前，需要先运行一个生成的脚本，用于设置平台选项字节配置并擦除平台（其中会设置选项位 TZEN）。

$ ./build/tfm/api_ns/regression.sh
$ west flash

注意，在开发板上运行 TFM 示例后，需要再次运行 ./build/tfm/api_ns/regression.sh，清除开发板上的安全选项，使平台恢复到“正常”状态，才能运行普通的非 TFM 二进制文件。另外，即使这样 TZEN 仍会保持置位，如有需要，必须使用 STM32CubeProgrammer 将其完全禁用。

连接与 IO

B_U585I_IOT02A Discovery 套件有 9 个 GPIO 控制器（从 A 到 I）。这些控制器负责引脚复用、输入/输出、上拉等功能。

更多详情请参阅 B U585I IOT02A board User Manual。

Zephyr 默认外设映射：

  • UART_1 TX/RX：PA9/PA10（ST-Link 虚拟 COM 端口）

  • LD1 : PH7

  • LD2 : PH6

  • 用户按键 : PC13

  • SPI1 NSS/SCK/MISO/MOSI : PE12/P13/P14/P15 (Arduino SPI)

  • I2C_1 SDA/SDL：PB9/PB8（Arduino I2C）

  • I2C_2 SDA/SDL : PH5/PH4

  • DAC1 CH1 : PA4 (STMOD+1)

  • ADC1_IN15 : PB0

  • USB OTG : PA11/PA12

  • PWM4 : CN14 PB6

  • PWM3 : CN4 PE4

系统时钟

B_U585I_IOT02A Discovery 的系统时钟可以由内部或外部振荡器驱动，也可以由主 PLL 时钟驱动。默认情况下，系统时钟由 80MHz 的 PLL 时钟驱动，PLL 由 16MHz 高速内部振荡器驱动。

串口

B_U585I_IOT02A Discovery 套件有 4 个 U(S)ART。Zephyr 控制台输出分配到 UART1，默认设置为 115200 8N1。

备份 SRAM

如需测试备份 SRAM，可能需要断开 VBAT 与 VDD 的连接，方法是移除开发板背面的 SB6 跳线。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

B_U585I_IOT02A Discovery 套件带有 ST-LINK/V3 嵌入式调试工具接口。通过该调试探针可以使用多种工具烧录开发板。

烧录

本开发板配置为使用 west 的 STM32CubeProgrammer 运行器（runner）进行烧录，因此需要先完成其 安装。

也可以通过 --runner（或 -r）选项使用 OpenOCD 或 JLink 烧录开发板：

$ west flash --runner openocd
$ west flash --runner jlink

使用 USB 端口将 B_U585I_IOT02A Discovery 套件连接到主机，然后运行串口终端程序连接 Discovery 开发板。例如：

$ minicom -D /dev/ttyACM0

然后按常规方式构建并烧录。以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b b_u585i_iot02a samples/hello_world
west flash

控制台上应显示以下信息：

Hello World! arm

调试

该开发板的默认烧录工具是 OpenOCD，可以按常规方式使用。下面以 Blinky 应用程序为例。

# From the root of the zephyr repository
west build -b b_u585i_iot02a samples/basic/blinky
west debug

在开发板上禁用 TrustZone®

如果之前向开发板烧录过启用 TrustZone 的示例，则需要先禁用 TrustZone，才能在开发板上烧录并运行新的非 TrustZone 示例。

要禁用 TrustZone，必须同时修改 TZEN 和 RDP 位：TZEN 需要从 1 改为 0，RDP 需要从 DC 改为 AA（见下面的第 3 步）。

这在 AN5347, in section 9 的“TrustZone deactivation”中有说明。

不过，RDP 位可能尚未设置为 DC，此时需要先将其设置为 DC（第 2 步）。

最后需要正确设置“Write Protection 1 & 2”字节，否则部分存储区域将无法擦除，整片擦除也会失败（第 4 步）。

以下命令序列将完全禁用 TZ：

第 1 步：

确保 U23 BOOT0 开关设置为 1（假设从左到右读丝印标签“BOOT0”，开关拨到左侧）。切换开关后需要按下“Reset”（B2 RST 开关）才能使更改生效。

第 2 步：

$ STM32_Programmer_CLI -c port=/dev/ttyACM0 -ob rdp=0xDC

第 3 步：

$ STM32_Programmer_CLI -c port=/dev/ttyACM0 -tzenreg
