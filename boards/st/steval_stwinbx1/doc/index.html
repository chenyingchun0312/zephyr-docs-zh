STEVAL STWINBX1 Development kit

Board Overview

Name:
steval_stwinbx1
Vendor:

STMicroelectronics

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32u585xx

Browse board sources

概述

STWIN.box（STEVAL-STWINBX1）是一款开发套件，搭载基于 Arm® Cortex®-M33 的 STM32U585AI MCU。它是一个参考设计，可简化物联网场景（如状态监测和预测性维护）中高级工业传感应用的原型设计和测试。

STEVAL-STWINBX1 套件包括 STWIN.box 核心系统、一块 480mAh 锂聚合物电池、一个 ST-LINK 调试器适配器、一个塑料外壳、一块 DIL 24 传感器转接板和一根柔性排线。

有关该开发板的更多信息，请访问 STEVAL-STWINBX1 Development kit website。

支持的功能

STEVAL-STWINBX1 通过内置 RS485 收发器、BLE、Wi-Fi、NFC 或 USB 协议，将运动、环境和音频传感器数据提供给运行在智能手机/PC 上的主机应用，以实现如下应用：

  • 用于振动监测和超声波检测的多传感无线平台

  • 结合云端 AI 学习的婴儿哭声检测

  • 气压计 / 环境监测

  • 车辆 / 货物跟踪

  • 振动监测

  • 指南针和倾角仪

  • 传感器数据记录器

（板载传感器的完整列表参见 Sensing 一节）

硬件

STM32U585xx 器件是基于高性能 Arm® Cortex®-M33 32 位 RISC 内核的超低功耗微控制器系列（STM32U5 系列），工作频率最高 160 MHz。

  • 基于 FlexPowerControl 的超低功耗（Standby 模式低至 300 nA，运行模式 19.5 uA/MHz）

  • 内核：带 TrustZone® 和 FPU 的 ARM® 32 位 Cortex®-M33 CPU。

  • 性能基准：

    • 1.5 DMPIS/MHz（Drystone 2.1）

    • 651 CoreMark® (4.07 CoreMark® /MHZ)

  • 安全与加密

    • Arm® TrustZone® 以及可设为安全的 I/O、存储器和外设

    • 灵活的生命周期管理方案，支持 RDP（读出保护）和密码保护调试

    • 基于唯一启动入口和安全隐藏保护区（HDP）的信任根

    • 借助内置的 Root Secure Services 实现安全固件安装

    • 使用硬件唯一密钥（HUK）的安全数据存储

    • 支持基于 TF-M 的安全固件更新

    • 2 个 AES 协处理器，其中一个抗 DPA 攻击

    • 公钥加速器，抗 DPA 攻击

    • Octo-SPI 外部存储器的实时解密

    • HASH 硬件加速器

    • 主动防篡改

    • 真随机数发生器，符合 NIST SP800-90B

    • 96 位唯一 ID

    • 512 字节一次性可编程（OTP）用户数据区

    • 主动防篡改

  • 时钟管理：

    • 4 至 50 MHz 晶体振荡器

    • 用于 RTC 的 32 kHz 晶体振荡器（LSE）

    • 内部 16 MHz 出厂校准 RC 振荡器（±1%）

    • 内部低功耗 32 kHz RC 振荡器（±5%）

    • 2 个内部多速振荡器，100 kHz 至 48 MHz，其中一个由 LSE 自动校准（精度优于 ±0.25%）

    • 3 个 PLL，分别用于系统时钟、USB、音频和 ADC

    • 内部 48 MHz 振荡器，带时钟恢复

  • 电源管理

    • 内置稳压器（LDO）

    • 内置 SMPS 降压转换器，支持动态切换和电压调节

  • 带硬件日历和校准功能的 RTC

  • 最多 136 个快速 I/O，大多数可耐受 5 V，最多 14 个 I/O 可独立供电，电压低至 1.08 V

  • 最多 24 个电容感应通道：支持触摸按键、线性和旋转触摸传感器

  • 最多 17 个定时器和 2 个看门狗

    • 2 个 16 位高级电机控制定时器

    • 2 个 32 位和 5 个 16 位通用定时器

    • 4 个低功耗 16 位定时器（在 Stop 模式下可用）

    • 2 个看门狗

    • 2 个 SysTick 定时器

  • ART 加速器

    • 8 KB 指令缓存，可从 Flash 和外部存储器零等待执行：最高 160 MHz，带 MPU，240 DMIPS 和 DSP

    • 用于外部存储器的 4 KB 数据缓存

  • 存储器

    • 2 MB 带 ECC 的 Flash 存储器，2 个 bank 支持边读边写，其中 512 KB 可擦写 100 k 次

    • 关闭 ECC 时 786 KB SRAM，或开启 ECC 时 722 KB SRAM（其中最多 322 KB 带 ECC）

    • 外部存储器接口，支持 SRAM、PSRAM、NOR、NAND 和 FRAM 存储器

    • 2 个 Octo-SPI 存储器接口

  • 丰富的模拟外设（独立供电）

    • 14 位 ADC，2.5 Msps，通过硬件过采样分辨率最高可达 16 位

    • 12 位 ADC，2.5 Msps，支持硬件过采样，可在 Stop 2 模式下自主运行

    • 12 位 DAC，低功耗采样保持

    • 2 个内置 PGA 的运算放大器

    • 2 个超低功耗比较器

  • 最多 22 个通信接口

    • USB Type-C / USB 供电（PD）控制器

    • USB OTG 2.0 全速控制器

    • 2 个 SAI（串行音频接口）

    • 4x I2C FM+(1 Mbit/s), SMBus/PMBus

    • 6 个 USART（ISO 7816、LIN、IrDA、调制解调器）

    • 3 个 SPI（双 OCTOSPI 工作于 SPI 模式时共 5 个 SPI）

    • 1x FDCAN

    • 2 个 SDMMC 接口

    • 16 通道和 4 通道 DMA 控制器，可在 Stop 模式下工作

    • 1 个多功能数字滤波器（6 个滤波器）+ 1 个带声音活动检测的音频数字滤波器

  • CRC 计算单元

  • 开发支持：串行线调试（SWD）、JTAG、嵌入式跟踪宏单元（Embedded Trace Macrocell™）

  • 真随机数发生器（RNG）

  • 图形功能

    • Chrom-ART 加速器（DMA2D），增强图形内容生成能力

    • 1 个数字摄像头接口

  • 数学协处理器

  • CORDIC，用于加速三角函数运算

  • FMAC（滤波器数学加速器）

连接与 IO

  • 2 个用户 LED

    • led0（绿色）

    • led1（橙色）

  • 4x buttons/switch

    • User / boot0 按键，可供用户应用程序使用；若硬件复位后检测到该按键被按下，SensorTile.box PRO 会进入 DFU 模式（参见 rst 按键和 Programming and Debugging 一节）

    • PWR 按键，用于开关开发板电源

更多详细信息，请参阅 STEVAL-STWINBX1 board User Manual。

系统时钟

STEVAL-STWINBX1 的系统时钟可以由内部或外部振荡器驱动，也可以由主 PLL 时钟驱动。默认情况下，系统时钟由 160MHz 的 PLL 时钟驱动，PLL 由 16MHz 高速外部振荡器驱动。内部 AHB/APB1/APB2/APB3 AMBA 总线的时钟均为 160MHz。

串口

USART2 连接到 JTAG/SWD 连接器，可用作控制台。

USB 接口

STEVAL-STWINBX1 可以通过其 USB-C 连接器作为 USB 设备连接到 PC 主机。最终应用可以借此将 STEVAL-STWINBX1 声明为某个标准类或厂商类的设备，例如 CDC、大容量存储设备，或同时具备这两种功能的复合设备。

Console

Zephyr 控制台输出有两种可选方式：

  • 通过适用于所有开发板的通用 CDC ACM UART 后端配置

  • 通过 SWD 连接器（CN4）上的 USART2。此时可以用 JTAG 适配器连接 STEVAL-STWINBX1，同时使用 SWD 和控制台线路。

    通过 UART 启用控制台和 shell：

    • 在 prj.conf 中设置 CONFIG_BOARD_SERIAL_BACKEND_CDC_ACM=n，覆盖开发板的默认配置

    • 添加名为 <board>.overlay 的覆盖文件：

/ {
    chosen {
       zephyr,console = &usart2;
       zephyr,shell-uart = &usart2;
     };
  };

控制台默认设置为 115200 8N1。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

ST Sensortile.box Pro 开发板有两种可选的烧录方式：

  1. 使用 DFU 软件工具

    此方法需要在按住 USER（BOOT0）按键的同时给开发板上电（或复位），使其进入 STM32U585 ROM 引导加载程序的 DFU 模式。除一根 USB-C 线外无需其他硬件。烧录与调试主机工具 完全支持此方法。有关如何启用和使用 ROM 引导加载程序的更多信息，请参阅应用笔记 AN2606（STM32U585xx 章节）。

  2. 使用 SWD 硬件工具

    STEVAL-STWINBX1 不带板载调试探针，需要将额外的硬件（例如 ST-LINK/V3 嵌入式调试工具）连接到开发板上标有 MCU-/SWD 的 STDC14 连接器（CN4）。

安装 dfu-util

备注

仅在使用 dfu-util 运行器时需要。

建议使用 v0.9 或更高版本的 dfu-util。Debian 和 Ubuntu 中提供的软件包可能相当陈旧，因此可能需要从源代码构建 dfu-util。有关获取源代码和构建方法的信息，请参阅 DFU-UTIL website

安装 STM32CubeProgrammer

备注

通过 DFU（默认）或 SWD 编程时需要。

建议使用最新版本的 STM32CubeProgrammer

将应用程序烧录到 STEVAL-STWINBX1

有两种方法进入 DFU 模式：

  1. 未连接 USB-C 线时

    按住 USER 按键，同时用 USB-C 线连接 STEVAL-STWINBX1 的 USB OTG 端口和计算机。

  2. 已连接 USB-C 线时

    按住 USER 按键，同时按下 RESET 按键后松开。

无论使用哪种方法，开发板都会被强制进入 DFU 模式。

检查开发板是否确实处于 DFU 模式：
