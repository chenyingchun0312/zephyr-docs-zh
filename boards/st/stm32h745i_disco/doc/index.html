STM32H745I Discovery

Board Overview

Name:
stm32h745i_disco
Vendor:

STMicroelectronics

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32h745xx

Browse board sources

概述

STM32H745I-DISCO Discovery 套件是面向 STMicroelectronics 基于 Arm® Cortex®‑M7 和 Cortex®‑M4 内核的 STM32H745XI 微控制器的完整演示和开发平台。

开发板上丰富的硬件功能可让用户评估几乎所有外设（如 USB OTG FS、10/100Mb/s 以太网、eMMC、USART、带音频插孔输入输出的 SAI 立体声音频 DAC、MEMS 数字麦克风、SDRAM、Quad-SPI Flash，以及带电容式多点触摸面板的 RGB 接口 LCD），从而加快应用开发。ARDUINO® Uno V3 连接器便于为特定应用连接扩展板（shield）或子板。

开发板集成了 STLINK-V3E，作为 STM32 MCU 的嵌入式在线调试器和编程器以及 USB 虚拟串口桥

主要特性

  • 基于 Arm® Cortex® 内核的微控制器，配备 2 MB Flash 和 1 MB RAM，TFBGA240+25 封装

  • 4.3 英寸 RGB 接口 LCD，带触摸面板连接器

  • 符合 IEEE-802.3-2002 的以太网，支持 PoE

  • USB OTG FS

  • SAI 音频编解码器

  • 1 个 ST-MEMS 数字麦克风

  • 2 个 512 Mbit Quad-SPI NOR Flash

  • 128-Mbit SDRAM

  • 4 GB 板载 eMMC

  • 1 个用户按键和 1 个复位按键

  • 扇出子板

  • 2× CAN FDs

  • 开发板连接器：

  • USB FS Micro-AB 连接器

  • ST-LINK Micro-B USB 连接器

  • USB 电源 Micro-B 连接器

  • 以太网 RJ45

  • 立体声耳机插孔，含模拟麦克风输入

  • 用于外接扬声器的音频排针

  • Tag‑Connect™（TAG）10 针焊盘

  • STDC14 焊盘上的 Arm® Cortex® 10 针 1.27 mm 间距调试连接器

  • ARDUINO® Uno V3 扩展连接器

  • STMod+

  • 灵活的供电选项：

  • STLINK-V3E USB 连接器、USB FS 连接器

  • 通过 RJ45 提供 5 V（以太网供电）

  • 通过 ARDUINO® 或外部连接器提供 5 V

  • USB 充电器

  • USB 供电

有关该开发板的更多信息，请访问 STM32H745I-DISCO website。有关 STM32H747XIH6 的更多信息，请参阅：

  • STM32H745XI on www.st.com

  • STM32H745xx reference manual

  • STM32H745xx datasheet

支持的功能

stm32h745i_disco 开发板支持下列硬件功能。

说明

The list of supported hardware features was not generated. Run a full documentation build for the required metadata to be available.

更多详细信息，请参阅 STM32H745-Disco User Manual。

Zephyr 默认外设映射：

  • USART_3 TX/RX : PB10/PB11（ST-Link 虚拟串口）

  • USART_1 TX/RX : PB6/PB7（Arduino 串口）

  • SPI_2 NSS/SCK/MISO/MOSI : PB4/PD3/PI2/PB15（Arduino SPI 接口）

  • I2C_4 SCL/SDA: PD12, PD13（Arduino I2C 接口，板载 FT5336 触摸控制器）

  • LTDC : 4.3 英寸 480x272 RGB888 面板（DISP_ON = PD7）

  • USER_PB : PC13

  • LD1 : PI13

  • LD2 : PJ2

  • LD3 : PD3

系统时钟

STM32H745I-DISCO 的系统时钟可以由内部或外部振荡器驱动，也可以由主 PLL 时钟驱动。默认情况下，系统时钟由 480MHz 的 PLL 时钟驱动，PLL 由 25MHz 高速外部时钟驱动。

串口

STM32H745I-DISCO 开发板有 4 个 UART 和 4 个 USART。Zephyr 控制台输出分配到 UART3。默认设置为 115200 8N1。

资源共享

STM32H745 SoC 的双核特性要求两个核共享硬件资源。共享方式有 3 种：

  • 编译：只有 M7 内核可以访问时钟配置。M4 内核只能激活和停用总线时钟。

  • 编译前静态分配：UART 等外设在编译前通过设备树分配。用户必须确保同一外设不会同时分配给两个内核。

  • 运行时保护：两个内核在运行时都可以访问中断控制器和 GPIO 配置。这些访问由硬件信号量保护，以避免潜在的并发访问问题。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

STM32H745I-DISCO 开发板集成了 ST-LINK/V3 嵌入式调试工具接口。

stm32h745i_disco 开发板的应用程序应按内核目标分别构建，目标为 stm32h745i_disco/stm32h745xx/m7 或 stm32h745i_disco/stm32h745xx/m4（详见 构建应用程序 和 运行应用程序）。

备注

检查板载 ST-LINK V3 是否为最新固件版本。可以使用 STM32CubeIDE 或 STM32CubeProgrammer 进行检查

烧录

开发板配置为使用 west 的 STM32CubeProgrammer 运行器烧录，因此需要先 安装 该工具。目标内核会被自动检测。

也可以通过 --runner（或 -r）选项使用 OpenOCD 或 JLink 烧录开发板：

$ west flash --runner openocd
$ west flash --runner jlink

将应用程序烧录到 STM32H745I-DISCO

烧录操作取决于目标以及 SoC 选项字节的配置。

默认情况下：

  • CPU0（Cortex-M7）启动地址设置为 0x80000000（OB：BOOT_CM7_ADD0）

  • CPU1（Cortex-M4）启动地址设置为 0x81000000（OB：BOOT_CM4_ADD0）

此外，开发板出厂默认配置在上电时同时启动 CM7 和 CM4（选项字节 BCM7 和 BCM4 均已勾选）。在这种配置下，应选择 Kconfig 启动选项 STM32H7_BOOT_CM4_CM7。Zephyr 的 Flash 配置已按这些默认设置进行设定。

将应用程序烧录到 STM32H745XI M7 内核

首先，使用 USB 端口将 STM32H745I-DISCO 连接到主机，为烧录做好准备。然后构建并烧录应用程序。

以下以 Hello World 应用程序为例。

运行串口终端程序连接 STM32H745I-DISCO 开发板。

$ minicom -b 115200 -D /dev/ttyACM0

或者使用 screen：

$ screen /dev/ttyACM0 115200

构建并烧录应用程序：

# From the root of the zephyr repository
west build -b stm32h745i_disco/stm32h745xx/m7 samples/hello_world
west flash

控制台上应显示以下信息：

$ Hello World! stm32h745i_disco

备注

有时烧录无法正常工作，需要先擦除 Flash（例如使用 STM32CubeProgrammer）才能恢复正常。

同样，也可以在 M4 目标上构建和烧录示例。为此，请注意资源共享问题（例如用作控制台的 UART 端口）。

以下以 M4 内核上的 Blinky 应用程序为例。

# From the root of the zephyr repository
west build -b stm32h745i_disco/stm32h745xx/m4 samples/basic/blinky
west flash

备注

烧录 M4 和 M7 后按下开发板上的 RESTART 按键，LD1 和 LD2 会同时闪烁。

调试

可以按常规方式调试应用程序。以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b stm32h745i_disco/stm32h745xx/m7 samples/hello_world
west debug

目前无法用 west 在 Cortex M4 侧调试。要在 Cortex M4 侧调试 Zephyr 应用程序，可以使用 STM32CubeIDE。
