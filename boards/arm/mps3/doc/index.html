MPS3 FPGA/Corstone FVP

Board Overview

Name:
mps3
Vendor:

ARM Ltd.

Status:

Not actively maintained

Architecture:

arm

SoC:

corstone300, an536, corstone310

Browse board sources

概述

mps3 开发板配置用于在 MPS3 开发板上运行的 Zephyr 应用程序。它支持多种 Arm FPGA 镜像和仿真模型：

  • AN536 支持 Arm Cortex-R52 CPU

  • AN547 和 AN552 支持 Arm Cortex-M55 CPU

  • AN555 支持 Arm Cortex-M85 CPU

  • 部分 Cortex-M 配置支持 Corstone-300 和 Corstone-310 FVP

根据所选的开发板目标，支持以下设备：

  • 嵌套向量中断控制器（NVIC）

  • 系统节拍时钟（SYSTICK）

  • 通用中断控制器 v3（GICv3）

  • Arm 架构定时器

  • Cortex-M System Design Kit GPIO

  • Cortex-M System Design Kit UART

  • Ethos-U55 NPU

Corstone-300 FVP/Corstone-310 FVP（固定虚拟平台）是对 Arm 系统（包括处理器、内存和外设）的完整仿真，可在 Linux 和 Windows 系统上免费使用。选择 FVP 进行仿真，是因为它们提供了对 Ethos-U55 NPU 的访问，而 QEMU 或其他仿真平台不提供该 NPU。

AN536 Cortex-R52x2 子系统可通过 QEMU 的 mps3-an536 机器运行。

开发板限定符必须包含上述完整的开发板名称。不带完整开发板限定符的 mps3/corstone300、mps3/corstone310 或 mps3/an536 无效。

硬件

ARM MPS3 提供以下硬件组件：

  • CPU

    • AN547 和 AN552 支持 Arm Cortex-M55 CPU 以及 SSE-300 子系统的软宏模型（SMM）实现

    • AN555 支持 Arm Cortex-M85 CPU 以及 SSE-310 子系统的软宏模型（SMM）实现

    • AN536 支持 Arm Cortex-R52 CPU 以及一个 Cortex-R52x2 示例子系统

  • 内存

    • 8MB BRAM

    • 4GB DDR4 SODIMM（默认，可升级到 8GB）

    • 16GB eMMC

    • 8MB QSPI Flash

  • 调试

    • P‐JTAG、F-JTAG、SWD、4 位跟踪、16 位跟踪

    • 四个基于 USB 的串口

  • 接口

    • AHB GPIO

    • UART

    • SPI

    • I2C

    • I2S

    • 彩色 LCD 串行接口

    • 以太网

    • VGA

  • 板载外设

    • 彩色 LCD

    • 10 LEDs

    • 8 个开关

    • 2 个用户按键

串口

MPS3 有六个 UART。Zephyr 控制台输出默认使用 UART0，它通过调试 USB 接口（J8）引出。

调试 USB 接口上的串口 0 是 MCC 开发板控制台。

调试 USB 接口上的串口 1 连接到 UART 0。

调试 USB 接口上的串口 2 连接到 UART 1。

调试 USB 接口上的串口 3 连接到 UART 2。

对于 AN536，Cortex-R52x2 子系统提供 LLPP UART0 和 LLPP UART1 作为 CPU 私有 UART，此外还有共享的 CMSDK UART。mps3/an536/cpu0 目标使用 LLPP UART0 作为 Zephyr 控制台。

编程与调试

烧录

MPS3 提供：

  • 一个连接到主机的 USB 接口，呈现为大容量存储设备、CMSIS-DAP 和串口。

使用 AN547 构建应用程序

可以按常规方式构建应用程序。以下是在 AN547 上运行 Hello World 应用程序的示例。

# From the root of the zephyr repository
west build -b mps3/corstone300/an547 samples/hello_world

使用以下设置打开串口终端（minicom、putty 等）：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

复位开发板，应能在对应串口上看到以下消息：

Hello World! mps3

将应用程序上传到 MPS3 AN547

应用程序可以是 elf、hex 或 bin 格式。开发板启动时，使用存储在板载 Micro SD 卡上的文件烧录二进制文件。主板配置控制器（MCC）负责加载 FPGA 镜像和二进制文件。

使用 USB 端口将 MPS3 连接到主机。应能看到一个呈现为大容量存储设备的 USB 连接（默认为 V2M-MPS3）。

更新需要 3 个步骤：

  1. 将应用程序文件复制到 <MPS3 device name>/SOFTWARE/。

  2. 打开 <MPS3 device name>/MB/HBI0309C/AN547/images.txt。

  3. 按如下方式更新 images.txt 文件：

TITLE: Versatile Express Images Configuration File

[IMAGES]
TOTALIMAGES: 1 ;Number of Images (Max: 32)

IMAGE0ADDRESS: 0x01000000 ;Please select the required executable program

IMAGE0FILE: \SOFTWARE\zephyr.elf

复位开发板，应能在对应串口上看到以下消息：

Hello World! mps3

使用 AN536 构建并运行应用程序

可以按常规方式构建应用程序。以下是在 AN536 上运行 Hello World 应用程序的示例。

# From the root of the zephyr repository
west build -b mps3/an536/cpu0 samples/hello_world

使用 QEMU 运行应用程序：

# From the root of the zephyr repository
west build -b mps3/an536/cpu0 samples/hello_world
west build -t run

应能看到以下消息：

Hello World! mps3/an536/cpu0
