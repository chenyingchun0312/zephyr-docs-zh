MPS4 Corstone FVP

Board Overview

Name:
mps4
Vendor:

ARM Ltd.

Status:

Not actively maintained

Architecture:

arm

SoC:

corstone315, corstone320

Browse board sources

概述

MPS4 开发板配置用于在 MPS4 开发板上运行的 Zephyr 应用程序。

Corstone-315 FVP/Corstone-320 FVP 是 Arm 面向安全片上系统的参考子系统，包含 Armv8.1-M Cortex-M85 处理器以及 LCM、KMU 和 SAM IP。Corstone-320 FVP 带有 Ethos-U85，而 Corstone-315 FVP 带有 Ethos-U65 神经网络处理器。它们可在 Linux 和 Windows 系统上免费使用。选择 FVP 进行仿真，是因为它们提供了对 Ethos-U65/Ethos-U85 NPU 的访问，而 QEMU 或其他仿真平台不提供这些 NPU。

Zephyr 开发板选项

MPS4 FVP 是采用 Cortex-M85 架构的 SoC。Zephyr 支持构建安全和非安全固件。

BOARD 选项汇总如下：

BOARD

说明

mps4/corstone315/fvp

用于构建安全（或纯安全）固件

mps4/corstone315/fvp/ns

用于构建非安全固件
FPGA 用法：

  • N/A.

FVP 用法：

  • 要使用 FVP 运行，首先设置环境变量 ARMFVP_BIN_PATH，然后即可用 west build -t run 运行。

export ARMFVP_BIN_PATH=/path/to/fvp/directory
west build -b {BOARD qualifier from table above} samples/hello_world -t run

要运行固定虚拟平台仿真工具，必须从 Arm 下载 "FVP model for the Corstone-315 MPS4" 并安装到主机 PC 上。

QEMU 用法：

  • N/A.

备注

  • 开发板限定符必须包含上述变体名称。不带变体名称的 mps4/corstone315/ mps4/corstone320 不是有效的限定符。

  • mps4/corstone315/fvp/ns/ mps4/corstone320/fvp/ns 变体需要最新的上游 TF-M 版本，因为 Zephyr 当前的 TF-M 尚不支持 Corstone-315 FVP。

串口

MPS4 有六个 UART。Zephyr 控制台输出默认使用 UART0。

调试 USB 接口上的串口 0 是 MCC 开发板控制台。

调试 USB 接口上的串口 1 连接到 UART 0。

调试 USB 接口上的串口 2 连接到 UART 1。

调试 USB 接口上的串口 3 连接到 UART 2。

使用 Corstone-315 构建应用程序

可以按常规方式构建应用程序。以下是在 Corstone-315 上运行 Hello World 应用程序的示例。

# From the root of the zephyr repository
west build -b mps4/corstone315/fvp samples/hello_world
west build -t run

使用 FVP 运行，应能看到以下信息：

Hello World! mps4

使用 Corstone-320 构建应用程序

可以按常规方式构建应用程序。以下是在 Corstone-320 上运行 Hello World 应用程序的示例。

# From the root of the zephyr repository
west build -b mps4/corstone320/fvp samples/hello_world
west build -t run
