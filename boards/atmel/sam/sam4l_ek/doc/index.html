SAM4L-EK

Board Overview

Name:
sam4l_ek
Vendor:

Atmel Corporation

Status:

Not actively maintained

Architecture:

arm

SoC:

sam4lc4c

Browse board sources

概述

SAM4L 系列内置 picoPower 技术，可实现超低功耗。通过多种组合的电源控制技术，活动电流消耗可降至 90μA/MHz。该器件支持多种配置，用户可以在尽可能低的功耗与应用所选的功能集之间取得平衡。WAIT 和 RETENTION 模式可完整保持逻辑和 RAM 状态，具备快速唤醒能力（<1.5μs），功耗分别仅为 3 μA 和 1.5 μA。此外，WAIT 模式支持 SleepWalking 功能。在 BACKUP 模式下，CPU、外设和 RAM 均断电，功耗低于 0.9μA，并支持外部中断唤醒。

SAM4L-EK 是一款功能齐全的设计，用于 Atmel SAM4L SoC 系列的开发。该套件配备了丰富的外设，使 ATSAM4L-EK 成为理想的评估平台。更多细节请下载 SAM4L-EK Online User Guide [1]。

硬件

  • ATSAM4LC4C ARM Cortex-M4 处理器

  • 12 MHz 晶体振荡器

  • 32.768 kHz 晶体振荡器

  • 1 个 Micro-AB USB OTG 主机/设备接口

  • 1 个 AT86RF2xx IEEE 802.15.4 收发器连接器

  • 1 个 RS-485 全双工接口

  • 1 个 Sensor Xplained 板连接器

  • 1 个 3.5mm 音频插孔

  • 1 个专用的板载监控 MCU

    • 功率测量（VDDIN、VDDIO、VDDANA）

    • 1 个 OLED 显示屏（128x64）

    • 5 LEDs

    • 1 个摇杆

    • 1 USART

    • 1 TWI

  • 1 个 40x4 段式 LCD 显示屏

  • 1 个用户触摸按键和一个用户按键

  • 1 个用户 LED

  • 1 个 QTouch 滑条

  • 1 个 QTouch 按键

  • 1 个 TEMT6000 光传感器

  • 1 个 AT25DF641A 串行 NOR Flash

连接与 IO

SAM4L-EK Design Documentation [2] 提供了有关开发板连接的详细信息。更多细节请下载 SAM4L-EK Design Documentation [2]。

系统时钟

SAM4L MCU 配置为使用开发板上的 12 MHz 内部振荡器，由片上 PLL 生成 48 MHz 系统时钟。

串口

ATSAM4LC4C MCU 有 4 个 USART。其中一个 USART（USART2）连接到嵌入式调试单元，可用作控制台。USART0 由其他所有排针和 RS-485 端口共用。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

SAM4L-EK 开发板带有 Segger 嵌入式调试单元 J-Link OB，为 SAM4LC4C 芯片提供调试接口。可以使用 Ozone 或 JLink 与 SAM4LC4C 通信。

烧录

  1. 从 Segger JLink Downloads Page [3] 下载 JLink。进入“J-Link Software and Documentation Pack”部分，安装“J-Link Software and Documentation pack for Linux”。JLinkExe 程序需要能通过 PATH 访问。

  2. 运行你常用的终端程序监听输出。在 Linux 下终端设备应为 /dev/ttyACM0。例如：

    $ minicom -D /dev/ttyACM0 -o

    -o 选项让 minicom 不发送调制解调器初始化字符串。连接应按如下方式配置：

    • 波特率：115200

    • 数据位：8 位

    • 校验位：无

    • 停止位：1

  3. 使用 USB 调试端口将 SAM4L-EK 开发板连接到主机。然后构建并烧录 Hello World 应用程序。

    # From the root of the zephyr repository
west build -b sam4l_ek samples/hello_world
west flash

    终端中应显示 "Hello World! sam4l_ek"。

调试

可以按常规方式调试应用程序。以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b sam4l_ek samples/hello_world
west debug
