MAX78002EVKIT

Board Overview

Name:
max78002evkit
Vendor:

Analog Devices, Inc.

Status:

Not actively maintained

Architecture:

riscv, arm

SoC:

max78002

Browse board sources

概述

MAX78002 评估套件（EV kit）提供了一个平台和一套工具，可利用该器件的能力构建新一代人工智能（AI）产品。

该套件采用模块化外设架构，具有极佳的通用性，各种输入和输出设备可以放置在远端。它支持 DVP 和 CSI 摄像头、I2S 音频外设、数字麦克风和模拟传感器，一对业界标准的 QWIIC 连接器还支持大量且不断增加的第三方开发板。板载立体声音频编解码器提供线路电平音频输入和输出，一块 2.4in 触控 TFT 显示屏提供触摸输入。MAX78002 的能耗由功率累加器跟踪，四个通道的格式化结果显示在辅助 TFT 显示屏上。器件的所有 GPIO 都可以通过 0.1in 排针访问。标准同轴电源插座作为电源输入，使用随附的 5V、3A 壁挂式电源适配器。两个 USB 连接器提供对 MAX78002 的串口访问，一个直接连接，另一个经由 USB 转 UART 桥接器。第三个 USB 连接器用于访问 MAX78002 的能耗数据。此外，microSD 连接器提供了低成本、高密度的便携式数据存储能力。

Zephyr 移植运行在 MAX78002 MCU 上。

硬件

  • MAX78002 MCU:

    • 双核低功耗微控制器

      • 带 FPU 的 Arm Cortex-M4 处理器，主频最高 120MHz

      • 2.5MB Flash、64KB ROM 和 384KB SRAM

      • 16KB 指令缓存优化性能

      • SRAM 可选纠错码（ECC SEC-DED）

      • 最高 60MHz 的 32 位 RISC-V 协处理器

      • 最多 60 个通用 I/O 引脚

      • MIPI 摄像头串行接口 2（MIPI CSI-2）控制器 V2.1

      • 支持两条数据通道

      • 12 位并行摄像头接口

      • 用于数字音频接口的 I2S 控制器/目标设备

      • 安全数字接口，支持 SD 3.0/SDIO 3.0/eMMC 4.51

    • 卷积神经网络（CNN）加速器

      • 针对深度 CNN 高度优化

      • 200 万个 8 位权重容量，支持 1、2、4 和 8 位权重

      • 1.3MB CNN 数据存储器

      • 可编程输入图像尺寸，最大 2048 x 2048 像素

      • 可编程网络深度，最多 128 层

      • 每层网络通道宽度可编程，最多 1024 个通道

      • 一维和二维卷积处理

      • 能够以 30fps 处理 VGA 图像

    • 延长电池寿命的电源管理

      • 集成单电感多输出（SIMO）开关电源（SMPS）

      • 2.85V 至 3.6V 电源电压范围

      • 支持可选的外部辅助 CNN 电源

      • 动态电压调节，最大程度降低内核工作功耗

      • 3.3V 下从缓存执行 while 循环时为 23.9μA/MHz（仅 CM4）

      • 在启用实时时钟（RTC）的低功耗模式下可选择保留 SRAM 内容

    • 安全性与完整性

      • 支持安全启动

      • AES 128/192/256 硬件加速引擎

      • 真随机数发生器（TRNG）种子发生器

  • 连接到 MAX78002 EVKIT 的外部设备：

    • 彩色 TFT 显示屏

    • 立体声音频编解码器接口

    • 数字麦克风

    • 一个 8Mb QSPI RAM

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

烧录

可以将外部调试探针连接到 SWD 端口来烧录 MAX78002 MCU。SWD 调试通过 Cortex 10 针连接器 JH8 进行。逻辑电平固定为 VDDIO（1.8V）。

调试探针连接到主机后，只需运行 west flash 命令即可将固件镜像写入 Flash。如需全片擦除，请在执行 west flash 时加上 --erase 选项。

备注

该开发板默认使用 OpenOCD 作为调试接口。也可以通过覆盖运行器（runner），在 west 命令后追加 --runner jlink，配合 Segger 原生工具使用 Segger J-Link。J-Link 应通过合适的转接板和线缆连接到标准 2*5 针调试连接器（JH8）。

调试

请参阅 Flashing 一节，并将 west flash 命令替换为 west debug。
