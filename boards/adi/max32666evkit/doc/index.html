MAX32666EVKIT

Board Overview

Name:
max32666evkit
Vendor:

Analog Devices, Inc.

Status:

Not actively maintained

Architecture:

arm

SoC:

max32666

Browse board sources

概述

MAX32666EVKIT 提供了一个平台，用于评估 MAX32665 和 MAX32666 高能效 Arm® 微控制器及音频 DSP 的各项能力，适用于可穿戴和可听戴设备应用。

Zephyr 移植运行在 MAX32666 MCU 上。

硬件

  • MAX32666 MCU:

    • 面向可穿戴和可听戴设备的高能效微控制器和音频 DSP

      • 带 FPU 的 Arm Cortex-M4，最高 96MHz

      • 可选的第二个带 FPU 的 Arm Cortex-M4，针对数据处理优化

      • 可选低功耗 7.3728MHz 系统时钟

      • 1MB Flash，分为两个 512KB bank

      • 560KB（448KB ECC）SRAM；3 x 16KB 缓存

      • 缓存、SRAM 和内部 Flash 可选纠错码（ECC-SEC-DED）

    • Bluetooth 5 低功耗射频

      • 1Mbps 和 2Mbps 数据吞吐率

      • 远距离模式（125kbps 和 500kbps）

      • 广播扩展

      • 接收灵敏度：-95dbm；发射功率最高 +4.5dbm

      • 片上匹配，单端天线端口

    • 电源管理可最大程度延长电池供电应用的工作时间

      • 集成 SIMO SMPS，支持纽扣电池供电

      • 动态电压调节，最大程度降低内核工作功耗

      • 3.3V 下从缓存执行时 27.3μA/MHz

      • 在启用 RTC 的低功耗模式下可选择保留 SRAM 内容

    • 用于系统控制的多种外设

      • 三个 QSPI 主/从接口，每个带三个片选

      • 三个四线 UART

      • 三个 I2C 主/从接口

      • 最多 50 个 GPIO

      • 支持 Flash 实时解密的 QSPI（SPIXF）

      • QSPI（SPIXR）RAM 接口，用于扩展 SRAM

      • 8 输入 10 位 Delta-Sigma ADC，7.8ksps

      • 带内部收发器的 USB 2.0 HS 引擎

      • PDM 接口，支持两个数字麦克风

      • 支持 TDM 的 I2S

      • 六个 32 位定时器

      • 两个高速定时器

      • 1-Wire 主机

      • 十六路脉冲序列（PWM）

      • 安全数字接口，支持 SD3.0/SDIO3.0/eMMC4.51

    • 通过硬件安全保护有价值的 IP/数据

      • 信任保护单元（TPU），其 MAA 支持快速 ECDSA 和模运算

      • AES128/192/256、DES、3DES 硬件加速器

      • TRNG 种子发生器

      • SHA-2 加速器•安全引导加载程序

  • MAX32666EVKIT 的优势和特性：

    • Bluetooth SMA 连接器，配 2.4GHz 铰链式鞭状天线

    • 1.28in 128 x 128 单色 TFT 显示屏

    • 64MB XIP Flash

    • 1MB XIP RAM

    • 立体声音频编解码器，带 3.5mm 线路输入和线路输出插孔

    • 数字音频麦克风

    • USB 2.0 Micro B 接口

    • USB 2.0 Micro B 转串行 UART

    • Micro SD 卡接口

    • 通过 0.1in 排针引出部分 GPIO

    • 通过 0.1in 排针引出 8 路模拟输入

    • Arm® 或 SWD JTAG 20 针排针

    • 1-Wire RJ11 端口

    • 可完全由纽扣电池供电

    • 开发板可由任一 USB 端口供电

    • 可通过跳线对所有 IC 电源轨分别进行功耗测量

    • 板载 1.8V 和 3.3V 稳压器

    • 两个通用 LED 和两个通用按键开关

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

烧录

可以将外部调试探针连接到 SWD 端口来烧录 MAX32666 MCU。SWD 调试通过 Cortex 10 针连接器 J6 进行。逻辑电平固定为 VDDIOH（1.8V 或 3.3V）。

调试探针连接到主机后，只需运行 west flash 命令即可将固件镜像写入 Flash。如需全片擦除，请在执行 west flash 时加上 --erase 选项。

备注

该开发板默认使用 OpenOCD 作为调试接口。也可以通过覆盖运行器（runner），在 west 命令后追加 --runner jlink，配合 Segger 原生工具使用 Segger J-Link。J-Link 应连接到标准 20 针连接器（J7）或 Cortex® 10 针连接器（J6）。

调试

请参阅 Flashing 一节，并将 west flash 命令替换为 west debug。
