MAX32675EVKIT

Board Overview

Name:
max32675evkit
Vendor:

Analog Devices, Inc.

Status:

Not actively maintained

Architecture:

arm

SoC:

max32675

Browse board sources

概述

MAX32675 评估套件（EV kit）提供了一个平台，用于评估 MAX32675 微控制器的各项能力。MAX32675 是一款高集成度、混合信号、超低功耗微控制器，专为工业和医疗传感器设计。它集成了低功耗 HART 调制解调器，可以通过电流环与工业传感器双向传输数字数据，用于配置和诊断。

Zephyr 移植运行在 MAX32675 MCU 上。

硬件

  • MAX32675 MCU:

    • 面向工业应用的低功耗、高性能

      • 100MHz 带 FPU 的 Arm Cortex-M4

      • 384KB 内部 Flash

      • 160KB SRAM

      • 128kB，启用 ECC

      • ACTIVE 模式下 0.9V、最高 12MHz 时为 44.1μA/MHz（Coremark®）

      • ACTIVE 模式下 1.1V、最高 100MHz 时为 64.5μA/MHz（Coremark）

      • VDDIO = 3.3V 时，BACKUP 模式下保持全部存储器的电流为 2.84μA

      • 超低功耗模拟外设

    • 优化的外设组合，提供平台可扩展性

      • 两个 Sigma-Delta ADC

      • 12 个通道，可分配给任一 ADC

      • 分辨率和采样率可灵活配置（0.4ksps 时 24 位，4ksps 时 16 位）

      • 12-Bit DAC

      • 片上温度传感器

      • SPI (M/S)

      • 最多两个 I2C

      • 最多两个 UART

      • 最多 23 个 GPIO

      • 最多五个 32 位定时器

      • 两个窗口看门狗定时器

      • 8 通道标准 DMA 控制器

      • 一个用于数字音频接口的 I2S 从接口

    • 可靠的安全性和可靠性

      • 符合 SP800-90B 的 TRNG

      • 安全非易失性密钥存储和 AES-128/192/256

      • 用于保护 IP/固件的安全引导加载程序

      • -40 °C 至 +105 °C 宽工作温度范围

  • MAX32675EVKIT 的优势和特性：

    • 兼容 HART 的副主站，能够连接现有 4-20mA 电流环并与支持 HART 的设备通信

    • USB 2.0 Micro B 转串口 UART

    • 两个板载高精度参考电压

    • 所有 GPIO 信号均通过 0.1 英寸排针引出

    • 通过 SMA 连接器引出 4 路差分配置的模拟输入

    • 通过 0.1in 排针引出 8 路单端配置的模拟输入

    • 通过 SMA 连接器或测试点引出 DAC 输出

    • 10 针 SWD 连接器

    • 开发板由 USB 端口供电

    • 板载 1.0V、1.8V 和 3.3V LDO 稳压器

    • 可通过跳线对所有 IC 电源轨分别进行功耗测量

    • 两个通用 LED 和两个通用按键开关

硬件详细说明

HART 接口

HART 电路作为副主站，能够连接到现有的 4mA–20mA 电流环，并与支持 HART 的设备通信。通过 JH8 连接电容耦合环路，通过 JH9 连接变压器环路。与 MAX32675 的 HART 通信通过 USB 连接器 CN1 进行。

USB 转 HART 接口

EV kit 提供了一个 USB 转 HART 桥接芯片 FTDI FT231，因此无需物理 RS-232 COM 端口，而是通过 Micro-USB Type-B 连接器 CN1 访问 IC 的 HART 功能。虚拟 COM 端口驱动以及 Windows® 驱动安装指南可从 FTDI 芯片网站获取。

电源

EV kit 由 +5V 供电，该电源来自 Micro-USB Type-B 连接器 CN1 上的 VBUS。开发板通电时蓝色 LED（D5）点亮。3V3、1V8 和 1V0 LDO 通电时，绿色 LED（D6）、（D7）和（D8）分别点亮。

电流监测

两针排针为 VDDIO EN（JP21）、VDDA EN（JP22）、VDD18 EN（JP23）和 VCORE（JP24）提供了方便的电流监测点。要准确测得低功耗电流值，EV kit 的配置必须确保没有外部因素（例如上拉电阻、外部时钟、调试器连接器等）在 GPIO 上引起拉电流或灌电流。

时钟

MAX32675 的时钟由外部 16MHz 晶振（Y1）提供。

参考电压

差分参考输入 REF0 和 REF1 可以由内部参考（INT_VREF）或更高精度的外部参考源 MAX6071 提供，通过跳线 JP25 和 JP26 选择。

UART 接口

评估套件提供一个 USB 转 UART 桥接芯片（FTDI FT230XS-R），因此不需要物理 RS-232 串口，IC 的 UART 通过 Micro USB type-B 连接器（CN1）访问。可通过跳线 JP10（RX0）和 JP11（TX0）将 USB 转 UART 桥连接到 IC 的 UART0 或 LPUART0。虚拟串口驱动以及 Windows® 驱动安装指南可在 FTDI Chip 网站获取。

引导加载程序

引导加载由引导加载使能拨动开关 SW5 激活。

GPIO 和复用功能排针

MAX32675 的 GPIO 和复用功能信号可以通过 0.1in 间距的排针 JH1、JH2、JH3 和 JH4 访问。

模拟输入访问

模拟输入（AIN0–AIN3）可以通过 SMA 连接器 J2 和 J3 以差分方式访问，也可以分别通过 TP10、TP12、TP15 和 TP16 单独访问。模拟输入（AIN4–AIN11）可以通过 0.1in 间距的排针 JH5 和 JH6 访问。

I2C 上拉电阻

I2C 端口可以分别通过 JP3（I2C_SCL）和 JP4（I2C_SDA）独立上拉到 3V3。

复位按键

可以通过按键 SW3 复位该 IC。

指示 LED

通用指示灯 LED D1（红色）连接到 GPIO P1.9，LED D2（绿色）连接到 GPIO P1.10。

GPIO 按键开关

两个通用按键（SW1 和 SW2）分别连接到 GPIO P1.11 和 P1.12。按下按键时，相应的端口引脚会被拉低。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

烧录

SWD 调试可通过 Arm Cortex 10 针连接器（J5）进行。逻辑电平默认设置为 3V3，如果从外部向 TP5（VDD_VDDA_EXT）供电，也可设置为 1.8V。如果从外部提供 VDD 和 VDDA，务必取下跳线 JP15（LDO_DUT_EN），断开 3.3V LDO。

调试探针连接到主机后，只需运行 west flash 命令即可将固件镜像写入 Flash。如需全片擦除，请在执行 west flash 时加上 --erase 选项。

备注

本开发板默认使用 OpenOCD 作为调试接口。也可以覆盖运行器（runner），在 west 命令后追加 --runner jlink，使用 Segger J-Link 及 Segger 原生工具。J-Link 应通过合适的转接板和线缆连接到标准 2*5 针调试连接器（JH2）。

调试

请参阅 Flashing 一节，并将 west flash 命令替换为 west debug。
