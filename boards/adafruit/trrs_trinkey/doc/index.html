TRRS Trinkey

Board Overview

Name:
adafruit_trrs_trinkey
Vendor:

Adafruit Industries, LLC

Status:

Not actively maintained

Architecture:

arm

SoC:

samd21e18a

Browse board sources

概述

Adafruit TRRS Trinkey 是一款小型 ARM 开发板，带有板载 TRRS 插孔、RGB LED、USB 端口和 STEMMA QT 端口。

硬件

  • ATSAMD21E18A ARM Cortex-M0+ 处理器，主频 48 MHz

  • 256 KiB Flash 和 32 KiB RAM

  • 内部校准的 8 MHz 振荡器

  • TRRS 插孔

  • STEMMA QT I2C 端口

  • An RGB NeoPixel LED

  • 原生 USB 端口

  • 一个复位按键

连接与 IO

Adafruit TRRS Trinkey Learn site [1] 提供了该开发板的详细信息，包括 pinouts [2] 和 schematic [3]。

系统时钟

SAMD21 MCU 配置为使用 8 MHz 内部振荡器，由片上 PLL 产生 48 MHz 系统时钟。内部 APB 和 GCLK 单元的设置方式与上游 Arduino 库相同。

TRRS 插孔

TRRS 插孔连接到 SAMD21 MCU 的以下引脚：

Pin

函数

PA02 (AIN0)

Tip

PA03 (AIN1)

Tip 开关

PA04 (AIN4)

Ring 2（第二环）

PA05 (AIN5)

Sleeve（套筒）

PA06 (AIN6)

Ring 1（第一环）

PA07 (AIN7)

Ring 开关

USB 串口

由于 TRRS Trinkey 带有原生 USB 端口，且没有专用 UART 引脚，因此使用 USB CDC ACM 串口作为控制台 I/O。

STEMMA QT I2C 端口

SAMD21E MCU 有 5 个基于 SERCOM 的 I2C 外设。在 TRRS Trinkey 上，SERCOM2 用于驱动 STEMMA QT I2C 端口。

RGB NeoPixel LED

该开发板有一个连接到引脚 PA01 的 NeoPixel WS2812B RGB LED。遗憾的是，Zephyr 目前没有适用于这种 MCU 和引脚组合的驱动。

USB 设备端口

SAMD21 MCU 有一个 USB 设备端口，可用于与主机 PC 通信。更多信息请参阅 USB 示例应用程序。由于 TRRS Trinkey 没有 UART 引脚，默认启用 USB CDC ACM 串口作为控制台 I/O。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

TRRS Trinkey 出厂预装兼容 BOSSA 的 UF2 引导加载程序。快速连按两次复位按键即可进入引导加载程序。

烧录

  1. 构建 Zephyr 内核和 Hello World 示例应用程序：

    west build -b adafruit_trrs_trinkey samples/hello_world

  2. 使用 USB 将 TRRS Trinkey 连接到主机

  3. 运行你常用的终端程序以监听输出。在 Linux 下，终端应为 /dev/ttyACM0。例如：

    $ minicom -D /dev/ttyACM0 -o

    -o 选项让 minicom 不发送调制解调器初始化字符串。连接应按如下方式配置：

    • 波特率：115200

    • 数据位：8 位

    • 校验位：无

    • 停止位：1

  4. 快速连按两次复位按键进入引导加载程序模式

  5. 烧录镜像：

    west build -b adafruit_trrs_trinkey samples/hello_world
west flash

    终端中应显示 "Hello World! adafruit_trrs_trinkey/samd21e18a"。
