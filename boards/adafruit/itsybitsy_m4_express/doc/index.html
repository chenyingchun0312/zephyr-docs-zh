ItsyBitsy M4 Express

Board Overview

Name:
adafruit_itsybitsy_m4_express
Vendor:

Adafruit Industries, LLC

Status:

Not actively maintained

Architecture:

arm

SoC:

samd51g19a

Browse board sources

概述

Adafruit ItsyBitsy M4 Express 是一款小巧（36 mm x 18 mm）的 ARM 开发板，带有板载 RGB LED、USB 端口、2 MiB SPI Flash，并通过 23 个 GPIO 引脚引出多种 I/O。

硬件

  • ATSAMD51G19A ARM Cortex-M4 处理器，主频 120 MHz

  • 512 KiB Flash 和 192 KiB RAM

  • 2 MiB 的 SPI Flash

  • 内部校准的 8 MHz 振荡器

  • 一个用户 LED

  • An RGB DotStar LED

  • 原生 USB 端口

  • 一个复位按键

支持的功能

adafruit_itsybitsy_m4_express 开发板支持下列硬件功能。

说明

The list of supported hardware features was not generated. Run a full documentation build for the required metadata to be available.

Zephyr 可以使用默认的 Cortex-M SYSTICK 定时器或 SAM0 专用的 RTC。要使用 RTC，请设置 CONFIG_CORTEX_M_SYSTICK=n，并将 CONFIG_SYS_CLOCK_TICKS_PER_SEC 设置为不超过 32 kHZ 除以 7，即不超过 4500。

连接与 IO

Adafruit Learning System [1] 提供了该开发板的详细信息，包括 pinouts [2] 和 schematic [3]。

系统时钟

SAMD51 MCU 配置为使用 32 kHz 内部振荡器，由片上 PLL 生成 120 MHz 系统时钟。

串口

SAMD51 MCU 有 6 个基于 SERCOM 的 USART。在 ItsyBitsy 上，SERCOM3 用作 Zephyr 控制台，位于引脚 0（RX）和 1（TX）。

SPI 端口

SAMD51 MCU 有 6 个基于 SERCOM 的 SPI。在 ItsyBitsy 上，可以将 SERCOM1 设置为 SPI 模式，通过 SCK（SCLK）、MO（MOSI）和 MI（MISO）引脚连接设备。

PWM

SAMD51 有三个 PWM 发生器，每个最多六个通道。TCC_0 的分辨率为 24 位，其他发生器均为 16 位。TCC_1 的引脚 2 映射到 PA18（D7），引脚 3 映射到 PA19（D9）。

USB 设备端口

SAMD51 MCU 带有一个 USB 设备端口，可用于与主机 PC 通信。更多内容请参阅 USB 示例应用程序，例如 USB CDC ACM UART sample 示例，它会建立一个虚拟串口，将字符回显给主机 PC。

编程与调试

说明

The list of supported runners was not generated. Run a full documentation build for the required metadata to be available.

ItsyBitsy 出厂时带有兼容 BOSSA 的 UF2 引导加载程序。快速按两下复位按键即可进入引导加载程序。

此外，如果启用了 CONFIG_USB_CDC_ACM，运行 west flash 时会自动进入引导加载程序。

烧录

  1. 构建 Zephyr 内核和 Hello World 示例应用程序：

    west build -b adafruit_itsybitsy_m4_express samples/hello_world

  2. 用 USB 将 ItsyBitsy 连接到主机

  3. 将 3.3 V USB 转串口适配器连接到开发板和主机。开发板的引脚连接见上文 Serial Port 一节。

  4. 运行你常用的终端程序以监听输出。在 Linux 下，终端应为 /dev/ttyUSB0。例如：

    $ minicom -D /dev/ttyUSB0 -o

    -o 选项让 minicom 不发送调制解调器初始化字符串。连接应按如下方式配置：

    • 波特率：115200

    • 数据位：8 位

    • 校验位：无

    • 停止位：1

  5. 快速连按两次复位按键进入引导加载程序模式

  6. 烧录镜像：

    west build -b adafruit_itsybitsy_m4_express samples/hello_world
west flash

    终端中应显示 "Hello World! adafruit_itsybitsy_m4_express"。

调试

除内置引导加载程序外，还可以使用 Segger J-Link 等 SWD 调试探针烧录和调试 ItsyBitsy。

  1. 将 ItsyBitsy 上的 SWCLK、SWDIO、RESET、GND 和 3V3 引脚分别连接到 J-Link [4] 上的 SWCLK、SWDIO、RESET、GND 和 VTref 引脚，从而将开发板连接到调试探针。

  2. 烧录镜像：

    west build -b adafruit_itsybitsy_m4_express samples/hello_world
west flash -r openocd

  3. 开始调试：

    west build -b adafruit_itsybitsy_m4_express samples/hello_world
west debug
