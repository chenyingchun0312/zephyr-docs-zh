VAR-SOM-MX93

Board Overview

Name:
imx93_var_som
Vendor:

Variscite Ltd.

Status:

Not actively maintained

Architecture:

arm, arm64

SoC:

mimx9352

Browse board sources

概述

VAR-SOM-MX93 是一款低功耗系统模块，提供高性能的处理能力。该产品基于 i.MX 93 系列，这是 NXP 最新的功耗优化处理器，面向智能家居、楼宇控制、非接触式 HMI、物联网边缘和工业应用。

i.MX 93 集成了两个强大的 Arm® Cortex®-A55 处理器，速度最高 1.7 GHz，并集成可加速机器学习推理的 NPU。一个通用 Arm® Cortex®-M33 运行频率最高 250 MHz，用于实时和低功耗处理。通过 CAN-FD 接口可以构建可靠的控制网络。此外，两个 1 Gbps 以太网控制器（其中一个支持时间敏感网络 TSN）可以低延迟地驱动网关应用。

Zephyr OS 已移植为可在 Cortex®-A55 或 Cortex®-M33 上运行。

规格摘要

  • CPU

    • NXP i.MX 93:

    • 2 个 Cortex®-A55 @ 1.7GHz

    • 1 个 Cortex®-M33 @ 250 MHz

    • 1 个 Ethos-U65 microNPU，0.5 TOPS

  • 内存

    • 最高 2GB LPDDR4 RAM

  • GPU

    • PXP 2D 像素加速引擎

  • NPU（神经网络处理单元）

    • 神经网络性能（256 个 MAC，工作频率最高 1.0 GHz，每个 MAC 2 OPS）

    • NPU 面向 8 位和 16 位整数 RNN

    • 支持 8 位权重

  • 显示

    • LVDS，最高 1366x768p60 或 1280x800p60

    • 并行 RGB，最高 1366x768p60 或 1280x800p60

    • 1 个 MIPI DSI，最高 1920x1200p60 24 位

  • 网络

    • 2 个 10/100/1000 Mbit/s 以太网接口

    • 经认证的 Wi-Fi 802.11ax/ac/a/b/g/n

    • Bluetooth/BLE 5.4

  • 摄像头

    • 一个 2 lane MIPI CSI-2 摄像头输入

  • 音频

    • 耳机

    • 麦克风：数字、模拟（立体声）

    • 3x I2S(SAI), S/PDIF, PDM 4CH

  • USB

    • 2x USB 2.0 OTG

  • 串行接口

    • SPI: x7

    • I2C: x7

    • UART：7 个，最高 5 Mbps

    • CAN: x2

  • 温度范围

    • -40 °C to 85 °C

有关该 SoM 的更多信息，请参阅 Variscite Wiki 和 Variscite website。

备注

建议在 Linux 主机上禁用 M33 核所使用的外设。

设备

系统时钟

本开发板配置使用 24 MHz 的系统时钟频率。Cortex-A55 内核最高运行在 1.7 GHz。Cortex-M33 内核最高运行在 200MHz，SYSTICK 运行在相同频率。

串口

该开发板配置为 A55 核和 M33 核共用 CPU 的 UART7 这一个串行通信通道。

编程与调试（A55）

将编译生成的 zephyr.bin 复制到 SD 卡的 boot 目录，然后将 SD 卡插入开发板。给开发板上电，并在提示符处中止 U-Boot 的执行。

使用 U-Boot 在 Cortex-A55 上加载并运行 zephyr.bin：

load mmc $mmcdev:$mmcpart $loadaddr /boot/zephyr.bin
dcache off; icache flush; go $loadaddr

使用此配置运行基本的 Zephyr 应用程序和内核测试，例如 Hello World 示例：

# From the root of the zephyr repository
west build -b imx93_var_som/mimx9352/a55 samples/hello_world

这将构建一个包含 hello_world 示例应用程序的镜像。加载并执行后，将显示以下 RAM 控制台输出：

*** Booting Zephyr OS build v4.0.0-45-gf012a8b9f506 ***
Hello World! imx93_var_som/mimx9352/a55

编程与调试（M33）

说明

加载 M33 核镜像有两种方法：U-Boot 命令和 Linux remoteproc。

从 U-Boot 加载并运行 M33 Zephyr 镜像

要通过 U-Boot 从 A55 在 M33 上加载并运行 Zephyr，请将编译好的 zephyr.bin 复制到 SD 卡的 boot 目录，再将 SD 卡插入开发板。给开发板上电，并在提示符处停止 U-Boot 的执行。

将 M33 二进制文件加载到所需的存储器中，并使用以下命令开始执行：

load mmc $mmcdev:$mmcpart 0x80000000 /boot/zephyr.bin
cp.b 0x80000000 0x201e0000 0x30000
bootaux 0x1ffe0000 0

使用 Linux remoteproc 加载并运行 M33 Zephyr 镜像

使用 scp 或通过 U 盘，将构建出的二进制文件 zephyr.bin 和 zephyr.elf 分别传送到 SoM 的 /boot 和 /lib/firmware。

从 Linux 运行 Cortex-M33 二进制文件之前，需要启用专用于 Cortex-M33 应用程序的设备树：

root@imx93-var-som:~# fw_setenv fdt_file imx93-var-som-symphony-m33.dtb
root@imx93-var-som:~# reboot

可以使用 Variscite 为 MCUXpresso 二进制文件编写的 remoteproc 脚本来执行 Zephyr 二进制文件：

root@imx93-var-som:~# /etc/remoteproc/variscite-rproc-linux -f /lib/firmware/zephyr.elf
[   44.366948] remoteproc remoteproc0: powering up imx-rproc
[   44.374250] remoteproc remoteproc0: Booting fw image zephyr.elf, size 469352
[   44.383338] remoteproc remoteproc0: No resource table in elf
[   44.904615] remoteproc remoteproc0: remote processor imx-rproc is now up

UART7 串口控制台上应显示以下结果：

*** Booting Zephyr OS build v4.0.0-44-g93cbaccbbc41 ***
Hello World! imx93_var_som/mimx9352/m33

也可以配置 U-Boot 在启动时加载固件：

root@imx93-var-som:~# /etc/remoteproc/variscite-rproc-u-boot -f /boot/zephyr.bin
Configuring for TCM memory
+ fw_setenv m33_addr 0x201E0000
+ fw_setenv fdt_file imx93-var-som-symphony-m33.dtb
+ fw_setenv use_m33 yes
+ fw_setenv m33_bin zephyr.bin

Finished: Please reboot, the m33 firmware will run during U-Boot

有关 Variscite remoteproc 脚本和 Cortex-M33 通用支持的更多信息，请访问 Variscite Wiki。
