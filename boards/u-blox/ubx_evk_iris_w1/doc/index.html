EVK-IRIS-W106-RW612

Board Overview

Name:
ubx_evk_iris_w1
Vendor:

u-blox

Status:

Not actively maintained

Architecture:

arm

SoC:

rw612

Browse board sources

概述

EVK-IRIS-W10x 评估套件可单独使用 IRIS-W10 系列模块。本指南详细介绍 EVK-IRIS-W10 开发板的硬件功能，并给出开始开发所需的设置说明。

IRIS-W10 系列模块支持的所有引脚和接口都可以方便地从评估板上引出。简单的 USB 连接即可作为供电、编程 COM 端口、调试以及 USB 外设连接器的物理接口。此外，该开发板还提供以太网 RJ45 和 SDIO 排针等其他接口。EVK-IRIS-W10 开发板配有一个复位按键、一个启动（Boot）按键和两个用户可配置按键，并集成了电流检测电阻，可精确测量模块内的电流。

为便于灵活使用，GPIO 信号可通过排针引出，另有四个 mikroBUS™ 标准插槽，方便使用 Click boards™。每块 Click 板都可以直接插入空闲的 mikroBUS™ 插槽，从而借助各种标准化的小型附加板轻松扩展硬件。Click 板涵盖各种电子模块，包括传感器、收发器、显示屏、编码器、电机驱动器、连接端口等。有关 Click 板的更多信息，请访问 MIKROE 网站。

硬件

  • 260 MHz ARM Cortex-M33，以及用于 Wi-Fi 6 + BLE 5.3 + 802.15.4 的三射频核

  • 1.2 MB 片上 SRAM

  • 带 IRIS-W101 模块的 EVK-IRIS-W101 评估板。配有用于 WLAN 的双频 PCB 天线，带 100 mm 同轴线缆和 U.FL 连接器

  • 带 IRIS-W106 模块的 EVK-IRIS-W106 评估板。集成双频 PCB 走线天线（不提供外部天线）

为特定 Flash 版本构建：

west build -b ubx_evk_iris_w1@fidelix/rw612 samples/hello_world
west build -b ubx_evk_iris_w1@fidelix_16mb/rw612 samples/hello_world
west build -b ubx_evk_iris_w1@macronix/rw612 samples/hello_world
west build -b ubx_evk_iris_w1@macronix_16mb/rw612 samples/hello_world

如果未指定版本，默认使用 fidelix（8MB）。

每个版本都使用专用的 DTS 覆盖文件，其中定义了该 Flash 型号特有的 Flash 节点和分区布局。

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

无线连接支持

获取二进制 blob

要支持 Bluetooth 或 Wi-Fi，ubx_evk_iris_w1 需要获取二进制 blob。可以运行以下命令来获取：

west blobs fetch hal_nxp

蓝牙

BLE 功能需要获取二进制 blob，因此请务必先按照“Fetch Binary Blobs”一节操作。

所需的二进制 blob <zephyr workspace>/modules/hal/nxp/zephyr/blobs/rw61x_sb_ble_a2.bin 会直接与应用程序镜像链接，形成单个整体镜像。

Wi-Fi

Wi-Fi 功能同样需要获取二进制 blob，因此请务必先按照“Fetch Binary Blobs”一节操作。

所需的二进制 blob <zephyr workspace>/modules/hal/nxp/zephyr/blobs/rw61x_sb_wifi_a2.bin 会直接与应用程序镜像链接，形成单个整体镜像。

开发板变体

以太网

EVK-IRIS-W1 开发板带有一个以太网 RJ45 连接器，可与 ethernet 开发板变体配合使用。要使用以太网功能，请针对开发板目标 ubx_evk_iris_w1//ethernet 构建。

west build -b ubx_evk_iris_w1@fidelix/rw612/ethernet
west build -b ubx_evk_iris_w1@fidelix_16mb/rw612/ethernet
west build -b ubx_evk_iris_w1@macronix/rw612/ethernet
west build -b ubx_evk_iris_w1@macronix_16mb/rw612/ethernet

备注

以太网 PHY 与外部振荡器之间存在引脚冲突，需要对开发板进行硬件改动。所需的硬件改动请参阅以下文档：

  • EVK-IRIS-W1 User Guide

  • IRIS-W10 SIM
