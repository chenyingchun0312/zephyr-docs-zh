u-blox EVK-BMD-34/48: BMD-380-EVAL

概述

BMD-380-EVAL 硬件为 u-blox BMD-380 Bluetooth 5.0 模块提供支持，该模块基于 Nordic Semiconductor nRF52840 ARM Cortex-M4F CPU，并包含以下器件：

  • ADC

  • CLOCK

  • FLASH

  • GPIO

  • I2C

  • MPU

  • NVIC

  • PWM

  • RADIO（低功耗蓝牙和 802.15.4）

  • RTC

  • Segger RTT（RTT 控制台）

  • SPI

  • UART

  • USB

  • WDT

备注

BMD-380-EVAL 的排针及引脚分配与 BMD-340-EVAL 相同，但有四处例外。此处展示的是 BMD-340-EVAL。例外情况请参见下面的引脚表。

有关 BMD-340-EVAL 和 BMD-340 模块的更多信息，请访问 u-blox website [1]。Nordic Semiconductor 为 nRF52840 DK（nrf52840dk_nrf52840）提供的所有示例都可以不加修改地使用。

硬件

BMD-380-EVAL 上的 BMD-380 内部有一个 32MHz 高频振荡器，另外还有一个 32.768kHz 低频（慢速）振荡器。BMD-380 本身不包含慢速晶振，但 BMD-380-EVAL 上带有该晶振。

备注

如果目标是没有低速晶体的自定义设计，请务必修改代码，使用内部 RC 振荡器作为低速时钟。

编程与调试

BMD-380-EVAL 开发板配置的应用程序可以按常规方式构建和烧录（详见 构建应用程序 和 运行应用程序），但目前无法使用标准的调试目标。

烧录

按照 Nordic nRF5x Segger J-Link 页面中的说明安装并配置所有必需的软件。更多信息见 烧录。然后按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

以下以 Hello World 应用程序为例。

首先，运行你常用的终端程序以监听输出。

$ minicom -D <tty_device> -b 115200

将 <tty_device> 替换为 BMD-380-EVAL 所在的端口，例如在 Linux 下为 /dev/ttyACM0。

然后按常规方式构建并烧录应用程序。

# From the root of the zephyr repository
west build -b ubx_bmd380eval/nrf52840 samples/hello_world
west flash

调试

请参阅 Nordic nRF5x Segger J-Link 页面，了解如何使用 Segger J-LINK-OB IC 调试 u-blox 开发板。

测试 BMD-380-EVAL 上的 LED 和按键

有 2 个示例可用于测试开发板上的按键（开关）和 LED 能否在 Zephyr 下正常工作：

samples/basic/blinky
samples/basic/button

可以构建并烧录这些示例，以确认 Zephyr 在开发板上正常运行。按键和 LED 的定义位于 boards/u-blox/ubx_bmd340eval/ubx_bmd340eval_nrf52840.dts。

使用 UART1

当应用程序需要使用多个 UART 连接外设时，可以采用以下方法：

  1. 将设备树覆盖文件添加到应用程序的主目录：

    &pinctrl {
   uart1_default: uart1_default {
      group1 {
         psels = <NRF_PSEL(UART_TX, 0, 14)>,
                 <NRF_PSEL(UART_RX, 0, 16)>;
      };
   };
   /* required if CONFIG_PM_DEVICE=y */
   uart1_sleep: uart1_sleep {
      group1 {
         psels = <NRF_PSEL(UART_TX, 0, 14)>,
                 <NRF_PSEL(UART_RX, 0, 16)>;
         low-power-enable;
      };
   };
};

&uart1 {
  compatible = "nordic,nrf-uarte";
  current-speed = <115200>;
  status = "okay";
  pinctrl-0 = <&uart1_default>;
  pinctrl-1 = <&uart1_sleep>;
  pinctrl-names = "default", "sleep";
};

    在上面的覆盖文件中，引脚 P0.16 用作 RX，P0.14 用作 TX

  2. 以 DEVICE_DT_GET(DT_NODELABEL(uart1)) 方式使用 UART1

覆盖文件命名

该文件必须命名为 <board>.overlay 并放在应用程序主目录中，才能被设备树编译器自动识别。

选择引脚

引脚可以在开发板的 pinctrl 文件中配置。要查看可用的映射，请打开 u-blox website [1] 上 BMD-380 数据手册的第 2 节“Pin definition”，在表 3 中选择标记为“GPIO”的引脚。注意，标记为“Standard drive, low frequency I/O only (<10 kH”的引脚只能用于 10KHz 以下的应用，不适合用作 115200 速率的 UART。
