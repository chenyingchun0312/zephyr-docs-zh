Digilent Arty

概述

Digilent Arty 是面向创客和爱好者的一系列基于 FPGA 的开发板。Arty 有多种配置，每种配置使用不同的 Xilinx FPGA（Spartan-7、Artix-7 或 Zynq-7000 系列）。

每块开发板都配有用于 FPGA 编程和调试的板载 JTAG、LED、开关、按键、DDR3 RAM，以及用于存储 FPGA 比特流的 QSPI Flash。

基于 Spartan-7 和 Artix-7 的 Arty 开发板不包含 CPU，需要在 FPGA 中例化一个所谓的软核处理器才能运行 Zephyr。Zephyr 尚不支持基于 Zynq-7000 的 Arty 开发板。

ARM Cortex-M1/M3 DesignStart FPGA

在 Arty 上例化软核处理器的一种方法是使用 ARM 提供的 ARM DesignStart FPGA Xilinx 版参考设计。Zephyr 同时支持 Cortex-M1 和 Cortex-M3 参考设计。Cortex-M1 设计面向基于 Spartan-7 或 Artix-7 的 Arty 开发板，而 Cortex-M3 设计仅面向基于 Artix-7 的开发板。目前 Zephyr 只支持面向 Artix-7 的设计。

有关 ARM Cortex-M1/M3 DesignStart FPGA 的更多信息，请参阅以下网站：

  • Technical Resources for DesignStart FPGA

  • Technical Resources for DesignStart FPGA on Xilinx

  • ARM DesignStart FPGA Xilinx FAQs

支持的功能

arty_a7 开发板支持下列硬件功能。

说明

The list of supported hardware features was not generated. Run a full documentation build for the required metadata to be available.

系统时钟

Cortex-M1 参考设计配置为使用板上的 100 MHz 外部振荡器作为 CPU 系统时钟，而 Cortex-M3 参考设计配置为 50MHz 的 CPU 系统时钟。

串口

参考设计包含一个 Xilinx UART Lite。该 UART 被配置为控制台，可通过板载 JTAG 适配器经由 USB 连接器 J10 访问。

连接调试探针

对开发板编程需要两种不同的调试探针：连接到 FPGA 的板载 Digilent JTAG，以及连接到 ARM Cortex-M1 CPU、支持串行线调试（SWD）的外部调试探针。

板载 JTAG 用于配置和调试 Xilinx FPGA 本身，位于 USB 连接器 J10。

外部 SWD 调试探针可以连接到连接器 J4（nSRST 在 IO39，SWDIO 在 IO40，SWCLK 在 IO41）。另一种选择是使用专用的 适用于 DesignStart FPGA 的 ARM V2C-DAPLink。

编程与调试

首先，按照 ARM Cortex-M1/Cortex-M3 DesignStart FPGA Xilinx 版用户指南（随参考设计一同从 Technical Resources for DesignStart FPGA on Xilinx 下载）中的说明，使用 Xilinx Vivado 将所选参考设计的 FPGA 比特流配置到 FPGA 中。

用参考设计比特流配置 FPGA 的另一种方法是使用 OpenOCD 调试主机工具：

openocd -f board/arty_s7.cfg -c "init;\
     pld load 0 m1_for_arty_a7_reference.bit;\
     shutdown"

或者：

openocd -f board/arty_s7.cfg -c "init;\
     pld load 0 m3_for_arty_a7_reference.bit;\
     shutdown"

备注

预构建的 FPGA 比特流仅适用于配备 Artix-35T FPGA 的 Arty 开发板。对于其他 Arty 型号（例如 Arty A7-100），必须重新构建比特流。

然后按常规方式构建和烧录应用程序（详情参见 构建应用程序 和 运行应用程序）。

配置控制台

UART 控制台可通过 USB 连接器 J10 上的板载 JTAG 访问。板载 JTAG 会枚举为两个 USB 串口，UART 通常位于第二个串口。

在你选用的串口终端（minicom、putty 等）中使用以下设置：

  • 波特率：115200

  • 数据位：8 位

  • 校验位：无

  • 停止位：1

烧录

以下示例为 Cortex-M1 参考设计构建并烧录 Hello World 应用程序：

# From the root of the zephyr repository
west build -b arty_a7/designstart_fpga_cortex_m1 samples/hello_world
west flash

烧录后，终端中应显示类似以下的信息：

*** Booting Zephyr OS build zephyr-v2.3.99  ***
Hello World! arty_a7

Cortex-M3 参考设计也可以使用相同的步骤。

但请注意，上述步骤并未将应用程序持久保存到 Flash 中，只是将其写入了 FPGA 的内部块 RAM。下次配置 FPGA 时，它将恢复为 FPGA 比特流中块 RAM 存储的应用程序。

ARM Cortex-M1/M3 DesignStart FPGA Xilinx 版用户指南介绍了将应用程序固化到 FPGA 比特流中的步骤。如果启用了 CONFIG_BUILD_OUTPUT_VERILOG，构建系统会自动生成 Verilog 内存十六进制转储文件 zephyr.mem，可用于通过 Xilinx Vivado 初始化块 RAM。

调试

以下以 Hello World 应用程序为例。

# From the root of the zephyr repository
west build -b arty_a7/designstart_fpga_cortex_m1 samples/hello_world
west debug

在调试器中单步执行应用程序，终端中应显示类似以下的消息：

*** Booting Zephyr OS build zephyr-v2.3.99  ***
Hello World! arty_a7
