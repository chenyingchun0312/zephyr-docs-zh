WaRP7 - Next Generation IoT and Wearable Development Platform

Board Overview

Name:
warp7
Vendor:

Element14 (A Premier Farnell Company)

Status:

Not actively maintained

Architecture:

arm

SoC:

mcimx7d

Browse board sources

概述

i.MX7S SoC 是一款混合多核处理器，由单个 Cortex A7 内核和单个 Cortex M4 内核组成。Zephyr 被移植到 M4 内核上运行。在以后的版本中，它还将通过 RPmsg 与（运行 Linux 的）A7 内核通信。

硬件

WaRP7 平台由 CPU 板和 IO 板组成。

WaRP7 IO 板

  • 6 轴加速度计/磁力计：NXP FXOS8700CQ（I2C4 接口）

  • 3 轴陀螺仪：NXP FXAS21002C（I2C4 接口）

  • 高度计：NXP MPL3115A2（I2C4 接口）

  • NXP NTAG NT3H1101（I2C2 接口）

  • 音频编解码器：NXP SGTL5000（I2C4 和 SAI1 接口）

  • S1 - 复位按键（POR_B 信号）

  • S2 - 用户自定义按键（ENET1_RD1/GPIO7_IO1 信号）

  • S3 - 开/关（MX7_ONOFF 信号）

  • 板对板连接器（34 个可配置引脚）

  • mikroBUS 扩展连接器

  • 10 针针式 JTAG 连接器

  • 调试 USB，引出两个 UART（UART1 用于 A7，UART2 用于 M4）

  • MIPI DSI 单通道连接器

  • LCD 触摸连接器（I2C2 接口）

  • 音频插孔：麦克风和立体声耳机

WaRP7 CPU 板

  • CPU：i.MX7 Solo，带单个 Cortex A7（800MHz）内核和单个 Cortex M4（200MHz）内核

  • 内存

    • RAM -> A7：4GB（Kingston 08EMCP04）

    • RAM -> M4：3x32KB（TCML、TCMU、OCRAM_S）、1x128KB（OCRAM）和 1x256MB（DDR）

    • Flash -> A7：8GB eMMC（Kingston 08EMCP04）

  • 多媒体

    • MIPI CSI 单通道连接器，配 5MP OV5640 摄像头模块（I2C2 接口）

  • 连接

    • 板对板连接器（34 个可配置引脚）

    • Micro USB 2.0 OTG 连接器（USB_OTG1 接口）

    • Murata Type 1DX Wi-Fi IEEE 802.11b/g/n 和 Bluetooth 4.1 + EDR（SD1、UART3、SAI2 接口）

  • 锂离子/锂聚合物电池充电器：NXP BC3770（I2C1 接口）

  • 电源管理集成电路（PMIC）：NXP PF3000（I2C1 接口）

WaRP7 没有供 M4 使用的 QSPI Flash，M4 需要由 A7 内核启动。A7 内核负责将 M4 二进制应用程序加载到 RAM 中、将 M4 置于复位状态、设置 M4 的程序计数器和栈指针，然后让 M4 退出复位。A7 可以在引导加载程序阶段或 Linux 系统启动后执行这些步骤。

下面介绍如何在 A7 上使用 u-boot 将 Zephyr 加载到 M4 并运行。

将两个 micro USB 接口都连接到 PC。其中一个 USB 接口会提供 2 个 USB 串口，第一个是 A7 控制台，第二个是 Zephyr 使用的 M4 控制台，两者都配置为 115200 8N1。另一个 USB 接口用于为 CPU 板和 IO 板供电，并连接到 i.MX7S 的 USB OTG 接口。

平台上电后，在 A7 内核上中止 u-boot 的执行，并在 u-boot 提示符下使用以下命令将 eMMC 作为大容量存储设备暴露：ums 0 mmc 0。将编译好的 zephyr.bin 复制到第一个 FAT 分区，然后在 u-boot 提示符下按“Ctrl+C”移除 PC 上挂载的设备。设置 u-boot 环境变量，并从 Zephyr 编译时配置的相应内存中运行 zephyr.bin：

setenv bootm4 'fatload mmc 0:1 $m4addr $m4fw && dcache flush && bootaux $m4addr'
# TCML
setenv m4tcml 'setenv m4fw zephyr.bin; setenv m4addr 0x007F8000'
setenv bootm4tcml 'run m4tcml && run bootm4'
run bootm4tcml
# TCMU
setenv m4tcmu 'setenv m4fw zephyr.bin; setenv m4addr 0x00800000'
setenv bootm4tcmu 'run m4tcmu && run bootm4'
run bootm4tcmu
# OCRAM
setenv m4ocram 'setenv m4fw zephyr.bin; setenv m4addr 0x00900000'
setenv bootm4ocram 'run m4ocram && run bootm4'
run bootm4ocram
# OCRAM_S
setenv m4ocrams 'setenv m4fw zephyr.bin; setenv m4addr 0x00180000'
setenv bootm4ocrams 'run m4ocrams && run bootm4'
run bootm4ocrams
# DDR
setenv m4ddr 'setenv m4fw zephyr.bin; setenv m4addr 0x80000000'
setenv bootm4ddr 'run m4ddr && run bootm4'
run bootm4ddr

调试

下载并安装 J-Link Tools 和 NXP iMX7D Connect CortexM4.JLinkScript。

要使用 J-Link 运行 Zephyr 二进制文件，请创建以下脚本，从 zephyr.bin 中获取程序计数器和栈指针。

get-pc-sp.sh: .. code-block:: console

#!/bin/sh

firmware=$1

pc=$(od -An -N 8 -t x4 $firmware | awk '{print $2;}') sp=$(od -An -N 8 -t x4 $firmware | awk '{print $1;}')

echo pc=$pc echo sp=$sp

从固件二进制文件获取 SP 和 PC：./get-pc-sp.sh zephyr.bin .. code-block:: console

pc=00900f01 sp=00905020

将 J-Link 连接到开发板和 PC，然后运行 J-Link 命令行工具：

/usr/bin/JLinkExe -device Cortex-M4 -if JTAG \
   -speed 4000 -autoconnect 1 -jtagconf -1,-1 \
   -jlinkscriptfile iMX7D_Connect_CortexM4.JLinkScript

运行 zephyr.bin 需要以下步骤：

  1. 使 M4 内核进入复位状态

  2. 将二进制文件加载到相应地址（TMCL、TCMU、OCRAM、OCRAM_S 或 DDR）

  3. 设置 PC（程序计数器）

  4. 设置 SP（栈指针）

  5. 使 M4 内核退出复位状态

在 J-Link Commander 中执行以下命令：

w4 0x3039000C 0xAC
loadfile zephyr.bin,0x00900000
w4 0x00180000 00900f01
w4 0x00180004 00905020
w4 0x3039000C 0xAA

借助这些机制，warp7 开发板配置的应用程序可以按常规方式构建和调试（详见 构建应用程序 和 运行应用程序）。
