AZ3166 MXChip IoT DevKit

Board Overview

Name:
az3166_iotdevkit
Vendor:

Shanghai MXCHIP Information Technology Co., Ltd.

Status:

Not actively maintained

Architecture:

arm

SoC:

stm32f412rx

Browse board sources

概述

MXChip 的 AZ3166 IoT DevKit 是一款专为物联网（IoT）项目设计的开发板。它是一款由 Arm Cortex-M4 处理器驱动的一体化开发板。板载外设包括 OLED 屏幕、耳机输出、立体声麦克风，以及湿度和温度、气压、运动（加速度计和陀螺仪）、磁力计等丰富的传感器。

有关该开发板的更多信息，请访问 MXChip AZ3166 website [1]。

硬件

MXChip AZ3166 IoT DevKit 具有以下硬件特性：

  • 96 MHz 的 STM32F412 Arm Cortex M4F 处理器

  • 工作电压：3.3v 或 USB 供电

  • 支持 3.3V DC-DC，最大电流 1.5A

  • OLED 显示屏，128x64 像素

  • 2 个可编程按键

  • 1 RGB LED

  • 3 个状态指示 LED（"Wi-Fi"、"Azure"、"User"）

  • 安全加密芯片

  • 用于红外遥控或交互的红外发射器

  • 运动传感器（LSM6DSL）

  • 磁力计传感器（LIS3MDL）

  • 大气压力传感器（LPS22HB）

  • 温湿度传感器（HTS221）

  • EMW3166 Wi-Fi 模块，带 256K SRAM 和 1M+2M 字节 SPI Flash

烧录

按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

以下以 Hello World 应用程序为例。

首先，运行你常用的终端程序以监听输出。

$ minicom -D <tty_device> -b 115200

将 <tty_device> 替换为 micro:bit 开发板所在的端口。例如在 Linux 下为 /dev/ttyACM0。

然后按常规方式构建并烧录应用程序。

# From the root of the zephyr repository
west build -b az3166_iotdevkit samples/hello_world
west flash
