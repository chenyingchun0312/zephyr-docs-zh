SC-OBC Module V1

scobc_v1

Space Cubics Inc.

Status:

Not actively maintained

Architecture:

riscv, arm

SoC:

versal_rpu, miv

Browse board sources

概述

Space Cubics [1] OBC Module V1（SC-OBC Module V1）是一款星载计算机，面向需要可靠实时控制和边缘处理的太空任务。它基于 AMD Versal 自适应 SoC 和 Microchip IGLOO2 FPGA 构建，专为地球轨道和月球任务等严酷环境而设计。

在 Versal 一侧，SC-OBC V1 利用该器件结合通用处理器、可编程逻辑和矢量处理器的异构架构，运行目标检测、图像压缩/分割和高速信号处理等在轨工作负载，同时让飞行关键任务处于 Zephyr RTOS 可预测的调度模型之下。

在 IGLOO2 一侧，SC-OBC V1 将该器件用作开发板的安全处理器，负责监管主系统，提供独立的看门狗和故障管理通路，并协调安全模式切换，以提高容错能力。

系统时钟

该开发板提供一个 50 MHz 参考振荡器用于时钟生成。在这块开发板上，RPU（Cortex-R5F）默认以 600 MHz 运行。

在 Zephyr 中，“系统时钟”是内核的节拍基准。默认情况下，周期节拍构建为 100 Hz，无节拍（tickless）构建为 10 kHz（10000 Hz）。详情请参阅 CONFIG_SYS_CLOCK_TICKS_PER_SEC。

串口

SC-OBC Module V1 有多个 UART 端口。主要端口连接到评估板上的 FT4232H，因此用 USB Type-C 线缆将开发板连接到 PC 后，开发主机会枚举出这些端口。

  • 端口 A 用于 JTAG。

  • 端口 B 通过 Bank 502 上的 LPD MIO 引脚 0（RXD）和引脚 1（TXD）连接到 UART0。

  • 端口 C 通过 Bank 502 上的 LPD MIO 引脚 4（TXD）和引脚 5（RXD）连接到 UART1。对于 Versal RPU 上的 Zephyr，scobc_v1_versal_rpu.dts 中选择 UART1 作为默认控制台。在 Linux 主机上，该控制台通常显示为类似 /dev/ttyUSB2 的设备（设备编号可能不同）。

  • 端口 D 连接到 IGLOO2。

烧录

以下是为本开发板构建并烧录 Hello World 应用程序的示例：

# From the root of the zephyr repository
west build -b scobc_v1/versal_rpu samples/hello_world
west flash --pdi /path/to/your.pdi

烧录后，终端中应显示类似以下的信息：

*** Booting Zephyr OS build v4.2.0 ***
Hello World! scobc_v1/versal_rpu
