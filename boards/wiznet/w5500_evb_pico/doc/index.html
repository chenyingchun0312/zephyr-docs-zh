W5500-EVB-Pico

Board Overview

Name:
w5500_evb_pico
Vendor:

WIZnet Co., Ltd.

Status:

Not actively maintained

Architecture:

arm

SoC:

rp2040

Browse board sources

概述

W5500-EVB-Pico 是一款微控制器评估板，基于 Raspberry Pi RP2040 和全硬件 TCP/IP 控制器 W5500，其工作方式与 Raspberry Pi Pico 开发板基本相同，只是通过 W5500 增加了以太网功能。借助 USB 引导加载程序，无需任何适配器即可通过拖放方式烧录。也可以使用外部适配器，通过开发板的 SWD 接口进行烧录和调试。

硬件

  • 双核 Arm Cortex-M0+ 处理器，主频最高 133MHz

  • 264KB 片上 SRAM

  • 2MB 板载 QSPI Flash，支持 XIP

  • 26 个 GPIO 引脚

  • 3 个模拟输入

  • 2 个 UART 外设

  • 2 个 SPI 控制器

  • 2 个 I2C 控制器

  • 16 个 PWM 通道

  • USB 1.1 控制器（主机/设备）

  • 2 个可编程 IO（PIO）模块，共 8 个状态机

  • 板载 LED

  • 1 个看门狗定时器外设

  • Wiznet W5500 以太网 MAC/PHY

引脚映射

RP2040 SoC 的外设可以路由到开发板上的不同引脚。这些路由配置可以通过 DTS 修改。各外设可用的路由方式请参阅数据手册。

W5500_EVB_PICO 的外部引脚映射与 Raspberry Pi Pico 相同。与 Raspberry Pi Pico 类似，GPIO 25 连接到板载 LED，因此 blinky 示例可以正常运行。GPIO 29（ADC_CH3）在内部连接，用于测量 VSYS/3。W5500 连接到 SPI0（P16-P19），W5500 的复位信号和中断信号分别连接到 P20 和 P21。这些引脚都与开发板的板边连接器共用。

开发板原理图及其他认证信息请参阅 W5500 Evaluation Board Documentation [1]。

Zephyr 默认外设映射：

  • UART0_TX : P0

  • UART0_RX : P1

  • I2C0_SDA : P4

  • I2C0_SCL : P5

  • I2C1_SDA : P14

  • I2C1_SCL : P15

  • SPI0_RX : P16

  • SPI0_CSN : P17

  • SPI0_SCK : P18

  • SPI0_TX : P19

  • W5500 复位 : P20

  • W5500 中断 : P21

  • ADC_CH0 : P26

  • ADC_CH1 : P27

  • ADC_CH2 : P28

  • ADC_CH3 : P29

# From the root of the zephyr repository
west build -b w5500_evb_pico samples/basic/blinky
west flash --openocd /usr/local/bin/openocd
