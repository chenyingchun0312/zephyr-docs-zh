Waveshare Core2350B

Board Overview

Name:
core2350b
Vendor:

Waveshare Electronics

Status:

Not actively maintained

Architecture:

riscv, arm

SoC:

rp2350b

Browse board sources

概述

Waveshare Core2350B 是一款基于 Raspberry Pi RP2350B 微控制器的紧凑型核心板。它通过 2.54 mm 间距的排针引出 48 个 GPIO，便于集成到载板中。USB 通过一个 6 针 FPC 连接器提供，可借助可选的转接板连接到 USB Type-C 端口。

该开发板有三种型号，区别仅在于焊接的 PSRAM：

  • Core2350B0: no PSRAM

  • Core2350B1: 2 MB PSRAM

  • Core2350B2: 8 MB PSRAM

RP2350B SoC 有两个 Cortex-M33 内核和两个 Hazard3（RISC-V）内核。Zephyr 支持针对任一 CPU 架构进行构建，但目前仅在一个内核上运行，不支持在第二个内核上运行代码。

硬件

  • RP2350B 微控制器，带双核 Cortex-M33 或双核 Hazard3 处理器，最高 150 MHz

  • 520 KB SRAM 和 16 MB QSPI Flash（W25Q128JVSIQ）

  • 可选 2 MB 或 8 MB QSPI PSRAM，取决于型号

  • 12 MHz 晶体振荡器

  • 6 针 0.5 mm 间距 FPC 连接器，引出 VBUS、USB D+/D-、BOOTSEL 和 RUN

  • ME6217C33M5G 3.3 V LDO 稳压器（800 mA），使能信号可从排针引出

  • 四组 2x8、2.54 mm 间距排针，共 64 个引脚

  • USB 1.1，支持设备和主机模式

  • 低功耗睡眠和休眠（dormant）模式

  • 通过 USB 大容量存储进行拖放式烧写

  • 48 个多功能 GPIO 引脚，其中 8 个可用作 ADC 输入

  • 2 个 SPI、2 个 I2C、2 个 UART、8 个 12 位 ADC 通道、24 个可控 PWM 通道

  • 温度传感器

  • 3 个可编程 I/O（PIO）块，共 12 个状态机

  • 排针上的 SWD 调试端口

  • GPIO39 上的用户 LED（红色）

连接与 IO

该开发板自身没有按键，也没有 USB 连接器。BOOTSEL 和 RUN 信号、USB 数据线以及 VBUS 同时引到 FPC 连接器和 P2 排针上。通过 FPC 线缆连接的 USB Type-C 转接板提供 BOOT 和 RESET 按键。

排针

  • P1: GPIO0 to GPIO14

  • P3: GPIO15 to GPIO29

  • P4: GPIO30 to GPIO44

  • P2：GPIO45 至 GPIO47、SWCLK、SWD、BOOTSEL、RUN、USBD_P、USBD_N、ADC_VREF、3V3_EN、VBUS 和 3V3

该开发板通过 FPC 连接器或 P2 排针由 VBUS（5 V）供电。将 3V3_EN 拉低会禁用 3.3 V 稳压器。

Zephyr 默认外设映射

  • UART0_TX : GPIO0

  • UART0_RX : GPIO1

  • I2C0_SDA : GPIO4

  • I2C0_SCL : GPIO5

  • I2C1_SDA : GPIO6

  • I2C1_SCL : GPIO7

  • SPI0_RX : GPIO16

  • SPI0_CSN : GPIO17

  • SPI0_SCK : GPIO18

  • SPI0_TX : GPIO19

  • LED0 / PWM_11B : GPIO39

  • ADC_CH0 : GPIO40

  • ADC_CH1 : GPIO41

  • ADC_CH2 : GPIO42

  • ADC_CH3 : GPIO43

  • ADC_CH4 : GPIO44

  • ADC_CH5 : GPIO45

  • ADC_CH6 : GPIO46

Zephyr 控制台和 shell 默认使用 USB CDC ACM。

GPIO47（ADC 通道 7）是 PSRAM 的片选信号，同时还经过一个 0 欧姆电阻（R11）引到 P2 排针。在 Core2350B1 和 Core2350B2 型号上，请勿将其用作通用引脚。Zephyr 目前不支持 PSRAM。

使用 UF2 烧录

连接 USB Type-C 转接板时，要进入 UF2 引导加载程序，请按住 BOOT 按键，按下并松开 RESET，然后松开 BOOT。不使用转接板时，请在 P2 排针上将 BOOTSEL 拉到地，同时给 RUN 一个低电平脉冲。之后开发板会在主机上显示为大容量存储设备。

以下以 Blinky 应用程序为例，演示构建和烧录。

# From the root of the zephyr repository
west build -b core2350b/rp2350b/m33_0 samples/basic/blinky
west flash -r uf2

如果要以 Hazard3（RISC-V）内核为目标，请使用 core2350b/rp2350b/hazard3_0 作为开发板。
