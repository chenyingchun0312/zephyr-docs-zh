nRF52840 Dongle

Board Overview

Name:
nrf52840dongle
Vendor:

Nordic Semiconductor

Status:

Not actively maintained

Architecture:

arm

SoC:

nrf52840

Browse board sources

概述

nRF52840 Dongle（PCA10059）硬件支持 Nordic Semiconductor nRF52840 ARM Cortex-M4F CPU。

有关该开发板的更多信息，请访问 nRF52840 Dongle website [1]。nRF52840 Dongle guide [2] 中包含处理器的信息和数据手册。

硬件

nrf52840dongle/nrf52840 有两个外部振荡器。低速时钟频率为 32.768 kHz，主时钟频率为 32 MHz。

nRF52840 Dongle 开发板的完整硬件功能列表请参阅 nRF52840 Dongle website [1] 和 nRF52840 Dongle Hardware description [3]。

连接与 IO

LED

  • LED0（绿色）= P0.6

  • LED1（红色）= P0.8

  • LED1（绿色）= P1.9

  • LED1（蓝色）= P0.12

按键

  • BUTTON1 = SW1 = P1.6

  • RESET = SW2 = P0.18

nrf52840dongle/nrf52840 开发板配置的应用程序可以按常规方式构建（详见 构建应用程序）。

烧录

本开发板支持以下烧写方式：

  1. 仅使用内置引导加载程序

  2. 在串口恢复模式下使用 MCUboot

  3. 使用外部 调试探针

以下说明使用 west 工具，并假定你位于 west installation 的根目录。

方式 1：仅使用内置引导加载程序

开发板出厂时已烧录 Nordic nRF5 SDK 中的 Nordic 引导加载程序。使用此方式时，需要使用 Nordic 的 nrfutil [5] 程序创建该引导加载程序支持的固件包，并将其烧录到设备。继续之前请确保：

  • nrfutil is installed.

  • 已在 nrfutil 中安装 nrf5sdk-tools 命令。

  1. 按下 RESET 按键，使开发板复位进入 Nordic 引导加载程序。

    该按键位于开发板上远离 USB 连接器的一侧。注意，按键并非朝上，需要从外侧向内、朝 USB 连接器方向按下：

    红色 LED 应开始呈现渐变效果，表示引导加载程序正在运行。

  2. 编译一个 Zephyr 应用程序；这里使用 Blinky。

    west build -b nrf52840dongle/nrf52840 zephyr/samples/basic/blinky

  3. 使用 nrfutil 为引导加载程序打包应用程序：

    nrfutil nrf5sdk-tools pkg generate \
         --hw-version 52 \
         --sd-req=0x00 \
         --application build/zephyr/zephyr.hex \
         --application-version 1 \
         blinky.zip

  4. 将其烧录到开发板。注意 /dev/ttyACM0 适用于 Linux；在 Windows 上类似 COMx，在 macOS 上则是其他名称。

    nrfutil nrf5sdk-tools dfu usb-serial -pkg blinky.zip -p /dev/ttyACM0

    该命令退出后，可以看到开发板上的绿色 LED 闪烁，而不是引导加载程序使用的红色 LED。

更多信息参见 Nordic Semiconductor USB DFU [4]。

方式 2：在串口恢复模式下使用 MCUboot

也可以在本开发板上使用 MCUboot 引导加载程序来烧录 Zephyr 应用程序。需要先进行一次性设置，在开发板上构建并烧录 MCUboot。此后即可使用 MCUboot 的串口恢复模式构建和烧录其他 Zephyr 应用程序。该过程不会覆盖内置的 Nordic 引导加载程序，因此以后随时可以改回使用方式 1。

先安装 nrfutil [5] 和 mcumgr [7]，并确保 MCUboot 的 imgtool 可用，以便按照 签名二进制文件 中的说明为 MCUboot 签名二进制文件。

接下来，进行 一次性设置 以烧录 MCUboot。这里假设已将 MCUboot [6] 仓库克隆到 mcuboot 目录中，并且该目录在计算机上与 zephyr 仓库相邻。

  1. 按上述方法将开发板复位进入 Nordic 引导加载程序。

  2. 将 MCUboot 作为 Zephyr 应用程序编译。

    west build -b nrf52840dongle/nrf52840 -d build/mcuboot mcuboot/boot/zephyr

  3. 使用 nrfutil 为引导加载程序打包应用程序：

    nrfutil nrf5sdk-tools pkg generate \
         --hw-version 52 \
         --sd-req=0x00 \
         --application build/mcuboot/zephyr/zephyr.hex \
         --application-version 1 \
         mcuboot.zip

  4. 将其烧录到开发板。注意 /dev/ttyACM0 适用于 Linux；在 Windows 上类似 COMx，在 macOS 上则是其他名称。

    nrfutil nrf5sdk-tools dfu usb-serial -pkg mcuboot.zip -p /dev/ttyACM0

现在可以使用 MCUboot 的串口恢复模式将 Zephyr 应用程序烧录到开发板。这里使用 SMP server 示例，因为它已可直接编译为由 MCUboot 链式加载（并且它本身支持通过蓝牙更新固件）。

  1. 按住 SW1 按键的同时插入开发板，即可启动进入 MCUboot 串口恢复模式。SW1 的位置见上图。

    不要按 RESET；那样会运行 Nordic 引导加载程序，它与 MCUboot 不同。

    开发板会枚举出一个串口。在 Windows 上，设备管理器的“其他设备”下应出现 "MCUBOOT"（此外还有常见的 COMx 设备）。在 Linux 上，应创建类似 /dev/serial/by-id/usb-ZEPHYR_MCUBOOT_0.01-if00 的设备。

    如果没有出现串口，请确保按住 SW1 后重新插入开发板。如果仍未出现，请重新执行 MCUboot 一次性设置。

  2. 编译 smp_svr。

    west build -b nrf52840dongle/nrf52840 -d build/smp_svr zephyr/samples/subsys/mgmt/mcumgr/smp_svr

  3. 为 smp_svr 签名，以便由 MCUboot 链式加载。

    west sign -t imgtool --bin --no-hex -d build/smp_svr \
          -B smp_svr.signed.bin -- --key mcuboot/root-rsa-2048.pem

  4. 使用 mcumgr 将应用程序烧录到 MCUboot 串口：

    mcumgr --conntype=serial --connstring='dev=/dev/ttyACM0,baud=115200' \
       image upload -e smp_svr.signed.bin

  5. 复位设备：

    mcumgr --conntype=serial --connstring='dev=/dev/ttyACM0,baud=115200' reset

现在应能使用智能手机或计算机扫描到蓝牙设备。刚烧录的设备会以名称中带有 Zephyr 的形式列出。

备注

本开发板也支持以这种方式构建其他 Zephyr 应用程序并通过 MCUboot 烧录。只需确保构建应用程序时设置了 CONFIG_BOOTLOADER_MCUBOOT。例如，要编译供 MCUboot 加载的 blinky，使用：

west build -b nrf52840dongle/nrf52840 -d build/blinky zephyr/samples/basic/blinky -- -DCONFIG_BOOTLOADER_MCUBOOT=y

然后按上述步骤签名并烧录。

方式 3：使用外部调试探针

如果有外部 调试探针，也可以用它来烧录和调试 Zephyr 应用程序，但需要在开发板背面焊接 SWD 排针。

对于 Segger J-Link 调试探针，请按照 Nordic nRF5x Segger J-Link 页面中的说明安装并配置所有必需的软件。更多信息见 烧录。

使用 nrf52840dongle/nrf52840/bare 开发板变体构建应用程序。该变体使用修改过的分区表，不为板载 USB 引导加载程序预留空间。

然后按常规方式构建并烧录应用程序（详见 构建应用程序 和 运行应用程序）。

以下以 Blinky 应用程序为例。

# From the root of the zephyr repository
west build -b nrf52840dongle/nrf52840/bare samples/basic/blinky
west flash

观察开发板上的 LED 闪烁。

调试

nrf52840dongle/nrf52840 开发板不像某些 nRF5x 开发板那样带有板载 J-Link 调试 IC，但 Nordic nRF5x Segger J-Link 页面中的说明同样适用于该开发板，只是需要额外连接一个外部调试器。
