Xen Dom0：适用于 Xen 控制域的通用代码片段

概述

此代码片段允许用户将 Zephyr 构建为 Xen 初始域（Dom0）。该功能以配置代码片段的形式实现，以便支持任何兼容的平台。

如何添加对新开发板的支持

  • 为此代码片段添加删除 UART 节点的开发板设备树覆盖文件。

  • 在应用程序设备树覆盖文件中，根据你的环境中 Xen 为 Domain-0 选择的区域，添加正确的 memory 和 hypervisor 节点。

编程

调用 west build 时必须指定正确的 Xen 代码片段名称。例如：

west build -b qemu_cortex_a53 -S xen-dom0 samples/synchronization

使用 Xen 的 QEMU 示例

此代码片段 snippets/xen-dom0/boards/ 目录中提供的 qemu_cortex_a53 开发板覆盖文件，是一个 QEMU Xen 控制域示例。

要运行该环境，需要：

  • 获取并构建适用于 arm64 平台的 Xen（例如 RELEASE-4.17.0）

  • 获取并编译 example/ 目录中的示例设备树

  • 使用 xen-dom0 代码片段构建你的 Zephyr 示例或应用程序，并将其作为 Xen 控制域启动

关于设备树的重要说明

Xen 会动态分配 Dom0 镜像以及授权表（grant table）/扩展区域所使用的地址，因此这些地址在不同环境中可能不同（取决于内存 bank 的位置和大小、应用程序镜像大小、引导加载程序使用的 hypervisor 加载地址等）。由于 Zephyr 不在运行时解析设备树，也不是位置无关的可执行文件，因此需要在构建时知道确切的值。为此，需要先构建最终的二进制文件，尝试通过 Xen 启动它，然后分析 hypervisor 的输出，得到你的环境中的确切地址。输出如下所示：

授权表区域（hypervisor 节点中的第一个 reg）：

(XEN) Grant table range: 0x00000088080000-0x000000880c0000

扩展区域（hypervisor 节点中的第二个及之后的 reg）：

(XEN) [    0.928173] d0: extended region 2: 0x40000000->0x47e00000

Zephyr Dom0 内存：

(XEN) Allocating 1:1 mappings for dom0:
(XEN) BANK[0] 0x00000060000000-0x00000070000000 (256MB)

对于所提供的示例（基于带扩展区域的 R-Car H3ULCB），应用程序覆盖文件应添加的设备树节点：

hypervisor: hypervisor@88080000 {
    compatible = "xen,xen";
    reg = <0x0 0x88080000 0x0 0x40000 0x0 0x40000000 0x0 0x7e00000>;
    interrupts = <GIC_PPI 0x0 IRQ_TYPE_EDGE IRQ_DEFAULT_PRIORITY>;
    interrupt-parent = <&gic>;
    status = "okay";
};

ram: memory@60000000 {
    device_type = "mmio-sram";
    reg = <0x00 0x60000000 0x00 DT_SIZE_M(256)>;
};

关于 Xen 扩展区域的说明

默认情况下，对 Xen 扩展区域的支持处于禁用状态。因此，在设备树的 hypervisor 节点中指定扩展区域后，还需要在应用程序覆盖文件中将 XEN_REGIONS 配置设为“yes”。

启动示例

启动时可以使用 Zephyr SDK 中的 QEMU，命令如下：

<path to Zephyr SDK>/sysroots/x86_64-pokysdk-linux/usr/bin/qemu-system-aarch64 -cpu cortex-a53 \
-m 6G -nographic -machine virt,gic-version=3,virtualization=true -chardev stdio,id=con,mux=on \
-serial chardev:con -mon chardev=con,mode=readline -pidfile qemu.pid \
-device loader,file=<path to Zephyr app build>/zephyr.bin,addr=0x40600000 \
-dtb <path to DTB>/xen.dtb -kernel <path to Xen build>/xen

这会启动 Xen hypervisor，并将你的应用程序作为 Xen 控制域运行。为使其真正可用，可以在项目中添加 Xen-troops 提供的 zephyr-xenlib 库。该库提供基本的域管理功能，包括域的创建和配置。
