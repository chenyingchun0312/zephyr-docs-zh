Wi-Fi IPv4 代码片段（wifi-ipv4）

west build -S wifi-ipv4 [...]

概述

此代码片段启用 IPv4 Wi-Fi 支持。

使用 Wi-Fi shell 连接 Wi-Fi 网络：

wifi connect -s <SSID> -k <key_management> -p <passphrase>

要求

需要以下硬件支持：

  • CONFIG_WIFI

  • CONFIG_WIFI_USE_NATIVE_NETWORKING
