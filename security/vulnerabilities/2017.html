CVE-2017

CVE 2017-14199

getaddrinfo() 中存在缓冲区溢出。

  • Zephyr project bug tracker ZEPSEC-12

  • PR6158 fix for 1.11.0

CVE 2017-14201

由于误用栈变量，shell 的 DNS 命令可能导致不可预测的结果。

Zephyr shell 中的释放后使用（Use After Free）漏洞允许通过串口或 telnet 连接的用户造成拒绝服务，并可能导致远程代码执行。

此问题已在 v1.14.0 版本中修复。

  • Zephyr project bug tracker ZEPSEC-17

  • PR13260 fix for v1.14.0

CVE 2017-14202

shell 的实现未防范缓冲区溢出，会导致不可预测的行为。

Zephyr shell 组件中存在内存缓冲区边界内操作限制不当（Improper Restriction of Operations within the Bounds of a Memory Buffer）漏洞，允许通过串口或 telnet 连接的用户造成崩溃，并可能执行任意代码。

此问题已在 v1.14.0 版本中修复。

  • Zephyr project bug tracker ZEPSEC-18

  • PR13048 fix for v1.14.0
