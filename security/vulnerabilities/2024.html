CVE 2024-3077

Bluetooth：gatt_find_info_rsp 中的整数下溢。恶意的 Bluetooth LE 设备可以通过发送格式错误的 GATT 数据包使作为受害者的 Bluetooth LE 设备崩溃。

  • Zephyr project bug tracker GHSA-gmfv-4vfh-2mh8

此问题已在 main 分支中修复，将包含在 v3.7.0 中

  • PR 69396 fix for main

  • Zephyr project bug tracker GHSA-jmr9-xw2v-5vf4

此问题已在 main 分支中修复，将包含在 v3.7.0 中

  • PR 71030 fix for main

CVE 2024-10395

net：lib：http_server：缓冲区下溢读（Buffer Under-read）

http_server_get_content_type_from_extension 未对用户输入的长度进行正确校验，可能导致读取缓冲区边界之外的内存，从而引发段错误或崩溃。

  • Zephyr project bug tracker GHSA-hfww-j92m-x8fv

此问题已在 main 分支中修复，将包含在 v4.0.0 中

  • PR 80396 fix for main

CVE 2024-11263

arch：riscv：userspace：CONFIG_RISCV_GP=y 时存在潜在安全风险

恶意线程可以破坏 gp 寄存器，轻则导致整个系统发生硬故障（hard fault），重则可能诱使系统访问另一组随机的全局符号。

  • Zephyr project bug tracker GHSA-jjf3-7x72-pqm9

此问题已在 main 分支中修复，将包含在 v4.0.0 中

  • PR 81155 fix for main

  • PR 81370 fix for 3.7
