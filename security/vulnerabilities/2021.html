CVE 2021-3436

Bluetooth：在已知绑定的身份地址时，可在密钥分发阶段覆盖已有绑定

在分发身份地址信息时，没有检查是否已存在具有相同身份地址的绑定。这意味着会在 RAM 中创建一个重复条目，而最新的条目会覆盖持久存储中已有的条目。

此问题已在 main 分支中修复，将包含在 v2.6.0 中

  • Zephyr project bug tracker GHSA-j76f-35mc-4h63

  • PR 33266 fix for main

  • PR 33432 fix for 2.5

  • PR 33433 fix for 2.4

  • PR 33718 fix for 1.14.2

CVE 2021-3454

截断的 L2CAP K 帧导致断言失败

例如，在以前的 Zephyr 版本中，发送 SDU 长度字段被截断为仅一个字节的 L2CAP K 帧会导致断言失败。此问题已在 master 分支中由提交 0ba9437 修复，但尚未向后移植到较早的发布分支。

此问题已在 main 分支中修复，将包含在 v2.6.0 中

  • Zephyr project bug tracker GHSA-fx88-6c29-vrp3

  • PR 32588 fix for main

  • PR 33513 fix for 2.5

  • PR 33514 fix for 2.4

CVE 2021-3455

在无效的 ATT 请求之后立即断开 L2CAP 信道会导致卡死

当 Central 设备连接到外设并为 Enhanced ATT 创建 L2CAP 连接后，发送某些无效的 ATT 请求并立即断开连接会导致卡死。

此问题已在 main 分支中修复，将包含在 v2.6.0 中

  • Zephyr project bug tracker GHSA-7g38-3x9v-v7vp

  • PR 35597 fix for main

  • PR 36104 fix for 2.5

  • PR 36105 fix for 2.4

CVE 2021-3510

Zephyr JSON 解码器错误地解码数组的数组

使用 JSON_OBJ_DESCR_ARRAY_ARRAY 时，子数组的 token 类型为 JSON_TOK_LIST_START，但随后被赋值给联合体的对象部分。arr_parse 接着取数组对象的偏移量（它与列表毫无关系），将其视为相对于父对象的偏移量，并把子数组的长度存储在该位置。

此问题已在 main 分支中修复，将包含在 v2.7.0 中

  • Zephyr project bug tracker GHSA-289f-7mw3-2qf4

  • PR 36340 fix for main

  • PR 37816 fix for 2.6

CVE 2021-3581

HCI 数据未经正确检查，导致 Bluetooth 协议栈中的内存溢出

在通过 HCI 命令设置 SCAN_RSP 的过程中，Zephyr Bluetooth 协议栈没有有效检查传入的 HCI 数据的长度。这会导致内存溢出，进而覆盖内存中的数据，甚至可能导致任意代码执行。

此问题已在 main 分支中修复，将包含在 v2.6.0 中

  • Zephyr project bug tracker GHSA-8q65-5gqf-fmw5

  • PR 35935 fix for main

  • PR 35984 fix for 2.5

  • PR 35985 fix for 2.4

  • PR 35985 fix for 1.14
