CVE-2025

CVE 2025-1673

在 dns_validate_msg 中调用 crc16_ansi 和 strlen 时发生越界读

不带载荷的恶意或格式错误的 DNS 数据包可能导致越界读，从而引起崩溃（拒绝服务）或计算错误。

  • Zephyr project bug tracker GHSA-jjhx-rrh4-j8mx

此问题已在 main 分支中修复，将包含在 v4.1.0 中

  • PR 82072 fix for main

  • PR 82289 fix for 4.0

  • PR 82288 fix for 3.7

CVE 2025-1674

解包 DNS 应答时发生越界读

由于缺少输入校验，恶意或格式错误的数据包可导致越界读。

  • Zephyr project bug tracker GHSA-x975-8pgf-qh66

此问题已在 main 分支中修复，将包含在 v4.1.0 中

  • PR 82072 fix for main

  • PR 82289 fix for 4.0

  • PR 82288 fix for 3.7

CVE 2025-1675

dns_copy_qname 中的越界读

dns_pack.c 中的 dns_copy_qname 函数使用一个不可信的字段执行 memcpy 操作，且未检查源缓冲区是否足以容纳要复制的数据。

  • Zephyr project bug tracker GHSA-2m84-5hfw-m8v4

此问题已在 main 分支中修复，将包含在 v4.1.0 中

  • PR 82072 fix for main

  • PR 82289 fix for 4.0

  • PR 82288 fix for 3.7

CVE 2025-2962

dns_copy_qname 中的无限循环

DNS 实现中的一个拒绝服务问题可能导致无限循环。

  • Zephyr project bug tracker GHSA-2qp5-c2vq-g2ww

此问题已在 main 分支中修复，将包含在 v4.2.0 中

  • PR 87753 fix for main

  • PR 87925 fix for 4.1

  • PR 87949 fix for 3.7

CVE 2025-7403

Bluetooth：bt_conn_tx_processor 中的不安全处理

bt_conn_tx_processor 中的不安全处理会导致释放后使用（use-after-free），进而导致对零地址之前内存的写入（write-before-zero）。写入的 4 个字节由攻击者控制，可实现精确的内存破坏。

  • Zephyr project bug tracker GHSA-9r46-cqqw-6j2j

此问题已在 main 分支中修复，将包含在 v4.2.0 中

  • PR 90975 fix for main

CVE 2025-10456

Bluetooth：可半任意地使 BLE 目标设备发送断开连接请求

在处理 Bluetooth Low Energy（BLE）固定信道（例如 SMP 或 ATT）时发现了一个漏洞。具体来说，攻击者可以利用一个缺陷，使 BLE 目标设备（即受攻击的设备）尝试断开固定信道，而 Bluetooth 规范不允许这样做。这会导致未定义行为，包括可能的断言失败、崩溃或内存损坏。

  • Zephyr project bug tracker GHSA-hcc8-3qr7-c9m8

此问题已在 main 分支中修复，将包含在 v4.2.0 中

  • PR 93576 fix for main

  • PR 100474 fix for 3.7

CVE 2025-10457

Bluetooth：在非预期上下文中处理 le_conn_rsp

负责处理 BLE 连接响应的函数不会验证该响应是否在预期之中，即设备是否发起过连接请求，而是仅依赖标识符匹配。

  • Zephyr project bug tracker GHSA-xqj6-vh76-2vv8

此问题已在 main 分支中修复，将包含在 v4.2.0 中

  • PR 94080 fix for main

CVE 2025-10458

Bluetooth：le_conn_rsp 未对 CID、MTU、MPS 值进行合法性检查

这些参数未经校验或清理，随后被用于各种内部操作。

  • Zephyr project bug tracker GHSA-vmww-237q-2fwp

此问题已在 main 分支中修复，将包含在 v4.2.0 中

  • PR 93174 fix for main

CVE 2025-9408

Cortex M 上的用户空间权限提升漏洞

Cortex M 上的系统调用入口（R 和 A 系列可能也受影响，但报告者认为不受影响）存在竞争条件，恶意用户空间进程可借此以非常实际可行的方式提升权限。

  • Zephyr project bug tracker GHSA-3r6j-5mp3-75wr

此问题已在 main 分支中修复，将包含在 v4.3.0 中

  • PR 95101 fix for main

  • PR 96850 fix for main

  • PR 96014 fix for 4.2

  • PR 97306 fix for 4.2

  • PR 96015 fix for 4.1

  • PR 97305 fix for 4.1

  • PR 96030 fix for 3.7

  • PR 97313 fix for 3.7

CVE 2025-9557

Bluetooth：Mesh：gen_prov_cont 中的越界写

越界写可能导致任意代码执行。即使在具有某种形式内存保护的设备上，它仍可能导致崩溃，进而造成拒绝服务。

  • Zephyr project bug tracker GHSA-r3j3-c5v7-2ppf

此问题已在 main 分支中修复，将包含在 v4.3.0 中

  • PR 95061 fix for main

  • PR 97518 fix for 4.2

  • PR 97517 fix for 4.1

CVE 2025-9558

Bluetooth：Mesh：gen_prov_start 中的越界写

pb_adv.c 的 gen_prov_start 函数中存在潜在的越界写漏洞。接收到的数据被完整复制到接收缓冲区 link.rx.buf 中，而未对数据大小做任何校验。

  • Zephyr project bug tracker GHSA-8wvr-688x-68vr

此问题已在 main 分支中修复，将包含在 v4.3.0 中

  • PR 95064 fix for main

  • PR 97520 fix for 4.2

  • PR 97519 fix for 4.1

CVE 2025-12035

Bluetooth：Bluetooth Classic（BR/EDR）L2CAP 中的整数溢出

Bluetooth Host 协议栈的 bt_br_acl_recv 例程中存在整数溢出问题，该例程是处理传入 BR/EDR L2CAP 流量的关键路径。

  • Zephyr project bug tracker GHSA-p793-3456-h7w3

此问题已在 main 分支中修复，将包含在 v4.3.0 中

  • PR 97370 fix for main

CVE 2025-12890

Bluetooth：peripheral：对格式错误的连接请求处理不当

对格式错误的连接请求处理不当：当连接请求的间隔被设置为 1（本应属于非法值）且 chM 为 0x7CFFFFFFFF 时，会触发崩溃。此后该外设将无法再被连接。

  • Zephyr project bug tracker GHSA-8hrf-pfww-83v9

此问题已在 main 分支中修复，将包含在 v4.2.0 中

  • PR 89955 fix for main

CVE 2025-12899

net：icmp：越界内存读

Zephyr 网络协议栈中的一个缺陷会导致包含 ICMP 类型 128 的 IPv4 数据包被错误地归类为 ICMPv6 Echo Request。这会导致越界内存读，并在网络子系统中造成潜在的信息泄露漏洞。

  • Zephyr project bug tracker GHSA-c2vg-hj83-c2vg

此问题已在 main 分支中修复，将包含在 v4.3.0 中

  • PR 98780 fix for main

  • PR 98983 fix for 4.2

  • PR 98984 fix for 4.1

  • PR 98985 fix for 3.7
