ETSI 303-645

ETSI EN 303 645，又称“Cyber Security for Consumer Internet of Things: Baseline Requirements”（《消费类物联网网络安全：基线要求》），是由欧洲电信标准协会（ETSI）制定的一项标准。

该标准包含关于安全软件更新、数据保护、安全通信以及尽量减少暴露的攻击面等方面的条款。它是应对物联网设备相关挑战和风险的更广泛工作的一部分。

该标准的完整版本见 此处。

术语

ETSI 303645 术语

管理员（administrator）

在设备用户中拥有最高可能权限级别的用户，这可能意味着其能够更改与预期功能相关的任何配置。

关联服务（associated services）

与设备一起构成整个消费类物联网产品的一部分、并且通常是提供产品预期功能所必需的数字服务。

认证机制（authentication mechanism）

用于证明实体真实性的方法。

认证值（authentication value）

认证机制所使用的某一属性的具体值。

最佳实践密码学（best practice cryptography）

适用于相应用例、并且没有迹象表明可以用当前容易获得的技术对其发起可行攻击的密码学。

受限设备（constrained device）

由于其预期用途带来的限制，在处理数据、传输数据、存储数据或与用户交互的能力方面存在物理限制的设备。

消费者（consumer）

出于其贸易、商业、手艺或职业以外的目的而行事的自然人。

消费类物联网设备（consumer IoT device）

与关联服务存在联系、通常由消费者在家中使用或作为电子可穿戴设备使用的联网（及可联网）设备。

关键信息安全参数（critical security parameter）

一旦泄露或被修改就可能危及安全模块信息安全的、与信息安全相关的机密信息。

调试接口（debug interface）

制造商在开发期间用于与设备通信或对设备问题进行分诊的物理接口，不作为面向消费者功能的一部分使用

规定的支持期（defined support period）

制造商提供信息安全更新的最短时长，以时间段或截止日期表示。

设备制造商（device manufacturer）

制造组装好的最终消费类物联网产品的实体，该产品可能包含许多其他供应商的产品和组件。

出厂默认状态（factory default）

设备在恢复出厂设置后或最终生产/组装完成后的状态。

初始化（initialization）

激活设备的网络连接以投入运行，并可选择为用户或网络访问设置认证功能的过程。

已初始化状态（initialized state）

设备在初始化之后的状态。

物联网产品（IoT product）

消费类物联网设备及其关联服务。

可隔离的（isolable）

能够从其所连接的网络中移除，并且由此造成的任何功能损失仅与该连接有关，而与其主要功能无关；或者，当且仅当能够确保某一独立环境中各设备的完整性时，能够与其他设备一起置于该独立环境中

逻辑接口（logical interface）

利用网络接口，通过信道或端口在网络上进行通信的软件实现。

制造商（manufacturer）

供应链中相关的经济经营者（包括设备制造商）。

网络接口（network interface）

可用于通过网络访问消费类物联网功能的物理接口。

所有者（owner）

拥有或购买该设备的用户。

个人数据（personal data）

与已识别或可识别的自然人相关的任何信息。

物理接口（physical interface）

用于在物理层与设备通信的物理端口或空中接口（例如无线电、音频或光学接口）。

公开信息安全参数（public security parameter）

一旦被修改就可能危及安全模块信息安全的、与信息安全相关的公开信息。

可远程访问（remotely accessible）

旨在可以从本地网络以外进行访问。

安全模块（security module）

实现信息安全功能的硬件、软件和/或固件的集合。

信息安全更新（security update）

针对由制造商发现或向制造商报告的信息安全漏洞的软件更新。

敏感信息安全参数（sensitive security parameters）

关键信息安全参数和公开信息安全参数。

软件服务（software service）

设备中用于支持功能的软件组件。

遥测（telemetry）

来自设备的数据，可以提供有助于制造商识别问题的信息或与设备使用相关的信息。

每台设备唯一（unique per device）

对于给定产品类别或类型中的每一台设备都是唯一的。

用户（user）

自然人或组织。
