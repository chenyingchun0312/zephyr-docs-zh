CPU 负载

CPU 负载模块跟踪 CPU 在空闲状态之外所花费时间的比例。有两种测量后端可用，通过 CPU_LOAD_BACKEND Kconfig 选项选择：

调度器运行时统计

CONFIG_CPU_LOAD_BACKEND_RUNTIME_STATS 根据调度器的每 CPU 运行时统计推算负载。它可在各种架构之间移植，并支持多个 CPU。

架构空闲钩子

CONFIG_CPU_LOAD_BACKEND_IDLE_HOOK 使用架构空闲钩子测量负载，这些钩子在 CPU 进入空闲前后被调用。它的开销低于运行时统计后端，并且可以使用 计数器 设备获得更高的精度（计数器路径仅支持单 CPU）。它适用于任何会调用空闲钩子的架构（CONFIG_ARCH_HAS_CPU_IDLE_HOOKS）。与 线程分析器 相比，它更准确，因为它也考虑了在中断上下文中花费的时间。该后端不依赖跟踪子系统。

使用 cpu_load_get() 获取当前 CPU 的负载，或使用 cpu_load_get_cpu() 获取指定 CPU 的负载。二者都以千分比（0...1000）返回负载，并且可以重置测量窗口。使用 CPU_LOAD_PERMILLE_TO_PERCENT 可将该值转换为整数百分比。

也可以使用日志消息定期报告负载。报告周期通过 CONFIG_CPU_LOAD_LOG_PERIODICALLY 配置。

示例请参阅 On-demand CPU frequency scaling 示例。

使用计数器设备

空闲钩子后端默认使用 k_cycle_get_32()。需要更高精度时，可以启用 CONFIG_CPU_LOAD_USE_COUNTER 并在设备树中设置 chosen 节点，以使用 计数器 设备。

chosen {
  zephyr,cpu-load-counter = &counter_device;
};
