USB 设备协议栈 API（已弃用）

API 参考

传输数据有两种方式：使用“低层”读/写 API，或使用“高层”传输 API。

低层 API

要向主机发送数据，类驱动应调用 usb_write()。完成后，已注册的端点回调会被调用。在发送下一个数据包之前，类驱动应等待上一次写操作完成。接收到数据时，已注册的端点回调会被调用，此时应使用 usb_read() 读取接收到的数据。对于 CDC ACM 示例驱动，这一过程通过端点数组（cdc_acm_ep_data）中列出的 OUT 批量端点处理函数（cdc_acm_bulk_out）完成。

高层 API

usb_transfer 方法可用于与主机之间双向传输数据。传输 API 会根据端点的最大包长，自动将数据传输拆分为一个或多个 USB 事务。类驱动无需实现端点回调，而应将该回调设置为通用的 usb_transfer_ep_callback。
