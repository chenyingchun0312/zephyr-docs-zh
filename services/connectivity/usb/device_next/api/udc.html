USB 设备控制器（UDC）驱动 API

USB 设备控制器驱动 API 在 include/zephyr/drivers/usb/udc.h 中描述，称为 UDC driver API。

UDC 驱动 API 尚不稳定，可能随时变更，恕不另行通知。它用于取代 USB 设备控制器驱动 API（已弃用）。如果要将现有驱动移植到 UDC 驱动 API，或添加新驱动，请以 drivers/usb/udc/udc_skeleton.c 为起点。
