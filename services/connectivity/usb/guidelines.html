USB 测试和示例的通用准则

概述

总体而言，所有 USB 示例和测试都与平台无关，不应需要平台专用的覆盖文件。尽管代码树中可能已经存在例外，但目标是避免使用平台专用的覆盖文件。USB 示例或 USB 测试没有义务支持某个特定平台。

开发板配置

默认 USB 设备控制器和主机控制器

USB 支持使用 zephyr_udc0 节点标签指定默认 USB 设备控制器，使用 zephyr_uhc0 节点标签指定默认 USB 主机控制器。开发板必须根据自身支持的功能分配这些节点标签，才能运行代码树中的示例和测试。

开发板元数据中支持的特性

开发板元数据文件中只有两个受支持的特性，供 Twister 用来选择示例或测试。对于 USB 控制器支持设备模式的开发板，特性为 usbd；对于 USB 控制器支持主机模式的开发板，特性为 usbh。

更多详情请参阅 开发板配置。

已弃用的特性

不应再使用 usb_device 特性。该特性属于旧版 USB 设备协议栈，后者已弃用并将被移除。

测试的 Twister 配置

USB 测试可能需要额外的硬件或软件环境。这些测试应使用下表所列的 fixture。

Fixture

用例

usb_host_connected

测试实现 USB 设备功能，需要将 USB 主机连接到被测开发板。

usb_device_connected

测试实现 USB 主机功能，需要将 USB 设备连接到被测开发板。
