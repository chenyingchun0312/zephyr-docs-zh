Bluetooth Shell 的设置与使用

首先需要构建 Bluetooth Shell 并将其烧录到开发板上。具体方法请参阅 入门指南。Bluetooth Shell 本身位于 tests/bluetooth/shell/。

完成后，使用你常用的串口终端应用程序连接到命令行界面（CLI）。你应该会看到以下提示符：

uart:~$

有关 Shell 一般用法的更多细节，请参阅 Shell。

第一步是启用 Bluetooth。为此，请使用 bt init 命令。系统会打印以下消息，确认 Bluetooth 已初始化。

日志

你可以在运行时为每个模块配置日志级别，可配置的范围取决于编译进来的最大日志级别。配置时使用 log 命令。以下是一些示例：

  • 列出可用模块及其当前日志级别

uart:~$ log status

  • 禁用 bt_hci_core 的日志

uart:~$ log disable bt_hci_core

  • 为 bt_att 和 bt_smp 启用错误日志

uart:~$ log enable err bt_att bt_smp

  • 禁用所有模块的日志

uart:~$ log disable

  • 为所有模块启用警告日志

uart:~$ log enable wrn
