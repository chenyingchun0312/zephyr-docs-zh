健康服务器

健康服务器（Health Server）模型为 健康客户端 模型提供注意（attention）回调和节点诊断功能。它主要用于报告 Mesh 节点中的故障，以及将 Mesh 节点与其物理位置对应起来。

如果存在，健康服务器模型必须在主元素上实例化。

故障

健康服务器模型可以报告设备生命周期内发生过的故障列表。通常，故障是指可能改变节点行为的事件或状况，例如断电或外设故障。故障分为警告和错误。警告表示状况已接近节点设计所能承受的极限，但不一定会损坏设备。错误表示状况已超出节点的设计极限，可能已导致异常行为或对设备造成永久性损坏。

故障值 0x01 到 0x7f 保留给 Bluetooth Mesh 规范使用，规范定义的完整故障列表见 健康故障。故障值 0x80 到 0xff 由厂商自定义。故障列表在报告时总会附带公司 ID，以便解读厂商自定义的故障。

注意状态

注意状态用于让设备通过某种物理行为（例如闪烁、播放声音或振动）引起用户注意。注意状态可以在配网期间使用，让用户知道正在为哪台设备配网，也可以在运行时通过健康模型使用。

注意状态在启用时总会被分配一个 1 到 255 秒范围内的超时时间。健康服务器 API 为应用程序提供了两个回调来执行引起注意的行为：在注意期开始时调用 bt_mesh_health_srv_cb.attn_on，在结束时调用 bt_mesh_health_srv_cb.attn_off。

注意期的剩余时间可以通过 bt_mesh_health_srv.attn_timer 查询。
