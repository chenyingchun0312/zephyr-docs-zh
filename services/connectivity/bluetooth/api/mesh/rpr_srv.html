远程配网服务器

远程配网服务器（Remote Provisioning Server）模型是 Bluetooth Mesh 规范定义的一个基础模型。它通过 CONFIG_BT_MESH_RPR_SRV 选项启用。

远程配网服务器模型是在 Bluetooth Mesh 协议规范 1.1 版中引入的，用于支持将设备远程配网到 Mesh 网络中的功能。

远程配网服务器本身没有 API，而是依靠 远程配网客户端 对其进行控制。远程配网服务器模型只接受使用节点设备密钥（DevKey）加密的消息。

如果存在，远程配网服务器模型必须在主元素上实例化。

注意，通过节点配网协议接口（Node Provisioning Protocol Interface，NPPI）过程刷新设备密钥、节点地址或组成数据（Composition Data）之后，会触发 bt_mesh_prov.reprovisioned 回调。更多细节请参阅 远程配网客户端 一节。

如何将该模型集成到应用程序中

要在应用程序中添加远程配网服务器模型，请执行以下操作：

  1. 在项目配置中启用 Kconfig：

    CONFIG_BT_MESH_RPR_SRV=y

  2. 使用 BT_MESH_MODEL_RPR_SRV 宏将模型实例添加到主元素的模型列表 bt_mesh_elem.models 中，例如：

    static const struct bt_mesh_model models[] = {
        BT_MESH_MODEL_CFG_SRV,
        BT_MESH_MODEL_HEALTH_SRV(&health_srv, &health_pub),
        BT_MESH_MODEL_RPR_SRV,
        /* ... */
};

static const struct bt_mesh_elem elements[] = {
        BT_MESH_ELEM(0, models, BT_MESH_MODEL_NONE),
};

  3. 调用 bt_mesh_prov_enable() 并传入 BT_MESH_PROV_REMOTE，以启用 PB-Remote：

    err = bt_mesh_prov_enable(BT_MESH_PROV_REMOTE);
if (err) {
        printk("PB-Remote enable failed (err %d)\n", err);
}

限制

远程配网服务器模型存在以下限制：

  • 不支持使用 PB-GATT 为未配网设备配网。

  • 支持所有节点配网协议接口（NPPI）过程。但是，如果设备的组成数据在设备固件更新后发生变化（参见 固件影响），设备将无法保持已配网状态。如果预计设备的组成数据会发生变化，应当将设备取消配网。
