Bluetooth：经典 Bluetooth：AVRCP Shell

本文档介绍如何通过 Shell 命令使用经典 Bluetooth 的 AVRCP（音频/视频远程控制规范，Audio/Video Remote Control Profile）功能。avrcp 命令同时提供控制器（Controller，CT）和目标（Target，TG）两种角色，用于试用 AVRCP 的控制和浏览功能。

有两个子命令：avrcp ct 和 avrcp tg。avrcp ct 子命令提供 控制器（CT） 功能，avrcp tg 子命令提供 目标（TG） 功能。

前提条件

运行 avrcp Shell 之前，请确保构建时启用了经典 Bluetooth 和 Shell。在创建 AVRCP 控制或浏览连接之前，必须先与对端设备建立 ACL BR/EDR 连接（通常通过通用的 bt Shell 命令）。

命令

除 avrcp ct register_cb 和 avrcp tg register_cb 外，所有命令都只能在建立 ACL 连接后使用。

avrcp 命令：

uart:~$ avrcp

  tg                     : AVRCP TG shell commands

基本 AVRCP 操作

演示基本 AVRCP 操作的流程：

  • 双方分别使用 avrcp ct register_cb 和 avrcp tg register_cb 注册 AVRCP 回调。

  • 使用 avrcp connect 创建 AVRCP 连接。

  • CT 使用 avrcp ct get_caps events 从 TG 获取能力。

  • CT 使用 avrcp ct register_notification 0x01 注册通知。

  • CT 使用 avrcp ct play 请求播放控制。

  • CT 使用 avrcp ct get_play_status 获取当前播放状态。

  • CT 使用 avrcp ct get_element_attrs 获取元素属性（元数据）。

  • CT 使用 avrcp ct set_absolute_volume 50 设置音量。

  • CT 使用 avrcp ct pause 暂停播放。

备注

CT（控制器）发送命令，TG（目标）进行响应。对于支持通知的事件，TG 通常会在注册后立即发送 INTERIM 响应以指示当前值，之后在值实际发生变化时发送 CHANGED 响应。

AVRCP 连接

AVRCP 规范同时支持控制连接和浏览连接。控制连接用于基本的远程控制功能，浏览连接则允许浏览媒体内容。

控制连接

建立 AVRCP 控制连接：

  1. 注册回调（CT 端）：

uart:~$ avrcp ct register_cb
AVRCP CT callbacks registered

  1. 注册回调（TG 端）：

uart:~$ avrcp tg register_cb
AVRCP TG callbacks registered

  1. 连接 AVRCP：

uart:~$ avrcp connect
AVRCP CT connected
AVRCP TG connected

  1. 断开 AVRCP：

uart:~$ avrcp disconnect
AVRCP CT disconnected
AVRCP TG disconnected

浏览连接

建立控制连接后，可以发起浏览连接：

  1. 连接浏览：

uart:~$ avrcp browsing_connect
AVRCP browsing connect request sent
AVRCP CT browsing connected
AVRCP TG browsing connected

  1. 断开浏览：

uart:~$ avrcp browsing_disconnect
AVRCP browsing disconnect request sent
AVRCP CT browsing disconnected
AVRCP TG browsing disconnected
