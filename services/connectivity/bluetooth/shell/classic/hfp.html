Bluetooth：经典 Bluetooth：HFP Shell

本文档介绍如何运行经典 Bluetooth 的 HFP 功能。hfp 命令提供了经典 Bluetooth HFP 的 Shell 命令。

有两个子命令：hfp hf 和 hfp ag。

hfp hf 用于免提（Hands-Free，HF）功能，hfp ag 用于音频网关（Audio Gateway，AG）功能。

命令

除 hfp hf reg 和 hfp ag reg 外，所有命令都只能在建立 ACL 连接后使用。

hfp 命令：

uart:~$ hfp
hfp - Bluetooth HFP shell commands
Subcommands:
  hf  : HFP HF shell commands
  ag  : HFP AG shell commands

HFP AG SLC

hfp ag 子命令提供经典 Bluetooth 中 HFP AG 的功能。

  1. 注册 HFP AG：

uart:~$ hfp ag reg

  1. 连接到 HFP HF：

uart:~$ hfp ag connect 1

  1. 与 HF 设备建立连接：

Security changed: XX:XX:XX:XX:XX:XX level 2
AG received codec id bit map 2
AG connected
AG received vgm 0
AG received vgs 0

  1. 断开与 HFP HF 的连接：

uart:~$ hfp ag disconnect

  1. 连接已断开：

AG disconnected

HFP HF SLC

hfp hf 子命令提供经典 Bluetooth 中 HFP HF 的功能。

  1. 注册 HFP HF：

uart:~$ hfp hf reg

  1. 连接到 HFP AG：

uart:~$ hfp hf connect 2

  1. 与 AG 设备建立连接：

Security changed: XX:XX:XX:XX:XX:XX level 2
HF service 0
HF signal 0
HF roam 0
HF battery 0
HF ring: in-band
HF connected

  1. 断开与 HFP HF 的连接：

uart:~$ hfp hf disconnect

  1. 连接已断开：

HF disconnected

结束通话

通话（呼出或来电）被接听后，可以从 AG（音频网关）或 HF（免提）任意一端结束通话。

从 AG 结束通话过程：

uart:~$ hfp ag terminate 0
AG call 0x20007690 terminate
AG SCO disconnected 0x20005248 (reason 22)

HF call 0x20007408 terminated
HF SCO disconnected 0x20005248 (reason 22)

从 HF 结束通话过程：

AG call 0x20007690 terminate
AG SCO disconnected 0x20005248 (reason 22)

uart:~$ hfp hf terminate 0
HF call 0x20007408 terminated
HF SCO disconnected 0x20005248 (reason 22)

由远端结束通话过程：

uart:~$ hfp ag remote_terminate 0
AG call 0x20007690 terminate
AG SCO disconnected 0x20005248 (reason 22)

HF call 0x20007408 terminated
HF SCO disconnected 0x20005248 (reason 22)
