Bluetooth：电话承载服务（Telephone Bearer Service）Shell

本文档介绍如何以客户端和（电话承载服务（TBS））服务器两种身份运行呼叫控制功能。注意，为了缩短篇幅并提供更好的概览，以下示例中删除了部分调试输出行。

电话承载服务客户端

电话承载服务客户端通常位于资源受限的设备上，例如耳机，但也可能位于手机或笔记本电脑等设备上。因此，呼叫控制客户端通常也是广播者。客户端可以使用呼叫控制点（call control point）控制服务器上通话的状态。

要以交互方式使用客户端，必须启用 CONFIG_BT_TBS_CLIENT_LOG_LEVEL_DBG。

使用电话承载服务客户端

初始化 Bluetooth 协议栈（bt init）并连接设备后，电话承载服务客户端可以调用 tbs_client discover 在已连接设备上发现 TBS，该命令会开始发现 TBS UUID 并保存句柄，还可选择订阅所有通知（默认订阅全部）。

由于服务器可能有多个 TBS 实例，大多数 tbs_client 命令都以索引（从 0 开始）作为输入。合并通话至少需要 2 个通话 ID，并且所有通话索引必须位于同一个 TBS 实例上。

服务器还会有一个 GTBS 实例，它是服务器上所有电话承载的抽象层。如果服务器同时具有 GTBS 和 TBS，并且启用了 BT_TBS_CLIENT_GTBS，客户端在发送请求时可以订阅并使用其中任意一个。

在以下示例中，除非另有说明，否则忽略来自 GTBS 的通知。

使用示例

设置

uart:~$ bt init
uart:~$ bt advertise on
Advertising started

连接后

拨打电话：

<dbg> bt_tbs_client.notify_handler: Index 0

<dbg> bt_tbs_client.notify_handler: Index 0
<dbg> bt_tbs_client.current_calls_notify_handler: Call 0x01 is in the active state with URI tel:123

在 GTBS 上拨打电话：

uart:~$ tbs_client originate 0 tel:123
<dbg> bt_tbs_client.notify_handler: Index 0
<dbg> bt_tbs_client.current_calls_notify_handler: Call 0x01 is in the dialing state with URI tel:123

电话承载服务（TBS）

电话承载服务通常位于能够拨打电话（包括 Skype 等应用发起的通话）的设备上，例如（智能）手机和 PC。

要以交互方式使用 TBS 服务器，必须启用 CONFIG_BT_TBS_LOG_LEVEL_DBG。

使用电话承载服务

TBS 可以在本地控制，也可以由远端设备控制（通话期间）。例如，远端设备可以向具有 TBS 服务器的设备发起呼叫，TBS 服务器也可以在没有 TBS_CLIENT 客户端的情况下向远端设备发起呼叫。TBS 实现能够完全控制任何通话。对于可以提供 <instance_index> 的命令，省略索引时默认使用 GTBS 承载。

tbs --help

   print_calls                 :Output all calls in the debug log

使用示例

设置

uart:~$ bt init
uart:~$ bt connect P:xx:xx:xx:xx:xx:xx

连接后

为对端设备接听由客户端发起的呼叫：

<dbg> bt_tbs.write_call_cp: Index 0: Processing the originate opcode
<dbg> bt_tbs.originate_call: New call with call index 1
<dbg> bt_tbs.write_call_cp: Index 0: Processed the originate opcode with status success for call index 1
uart:~$ tbs remote_answer 1
TBS succeeded for call_id: 1

来自对端设备的来电，由客户端接听：

uart:~$ tbs incoming 0 tel:123 tel:456 Peter
TBS succeeded for call_id: 4
<dbg> bt_tbs.bt_tbs_remote_incoming: New call with call index 4
<dbg> bt_tbs.write_call_cp: Index 0: Processed the accept opcode with status success for call index 4
