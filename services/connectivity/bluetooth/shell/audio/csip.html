Bluetooth：协调集识别规范（Coordinated Set Identification Profile）Shell

本文档介绍如何以客户端和服务器两种身份运行协调集识别功能。注意，为了缩短篇幅并提供更好的概览，以下示例中删除了部分调试输出行。

集合协调者（Set Coordinator，客户端）

客户端通常是资源丰富的设备，例如智能手机或笔记本电脑。客户端能够锁定和释放协调集的成员。协调集被锁定期间，其他客户端无法锁定该集合。

要锁定一个集合，客户端必须连接到它要锁定的每个集合成员。本实现总是尝试同时连接集合的所有成员。因此，如果集合大小为 3，则 BT_MAX_CONN 必须至少为 3。

如果希望集合成员上的锁在断开连接后仍然保持，则需要与集合成员绑定。如果需要与多个集合成员绑定，请确保 BT_MAX_PAIRED 配置正确。

使用集合协调者

初始化 Bluetooth 协议栈（bt init）并连接集合成员设备后，可以调用 csip_set_coordinator init 初始化呼叫控制客户端，该命令会开始发现 TBS UUID 并保存句柄，还可选择订阅所有通知（默认订阅全部）。

客户端连接并发现句柄后，就可以读取识别其他集合成员所需的集合信息。然后客户端可以扫描并连接其余的集合成员，所有成员都连接后，即可锁定和释放该集合。

要正确使用集合协调者，需要启用 CONFIG_BT_CSIP_SET_COORDINATOR_LOG_LEVEL_DBG。

csip_set_coordinator --help
csip_set_coordinator - Bluetooth CSIP_SET_COORDINATOR shell commands
Subcommands:
   init              :Initialize CSIP_SET_COORDINATOR
   discover          :Run discover for CSIS on peer device [member_index]

协调集成员（Coordinated Set Member，服务器）

服务器位于属于某个集合（至少由两个设备组成，例如一对入耳式耳机）的设备上。

使用集合成员

csip_set_member --help
csip_set_member - Bluetooth CSIP set member shell commands
   Subcommands:
   register           : Initialize the service and register callbacks [size
                        <int>] [rank <int>] [not-lockable] [sirk <data>]
   lock               : Lock the set
   release            : Release the set [force]
   sirk               : Set the currently used SIRK <sirk>
   set_size_and_rank  : Set the currently used size and rank <size> <rank>
   get_info           : Get service info
   sirk_rsp           : Set the response used in SIRK requests <accept,
                        accept_enc, reject, oob>

使用示例

设置

uart:~$ bt init
uart:~$ csip_set_member register

设置新的 SIRK

该命令可以修改当前使用的 SIRK。要在空中广播新的 RSI，必须再次调用 bt adv-data 或 bt advertise 来设置新的广播数据。如果启用了 CONFIG_BT_CSIP_SET_MEMBER_SIRK_NOTIFIABLE，还会通知已连接的客户端。

uart:~$ csip_set_member sirk 00112233445566778899aabbccddeeff
SIRK updated

设置新的集合大小和等级（rank）

该命令可以修改服务实例的集合大小和等级。必须同时对集合中的所有设备执行该操作，且所有设备的集合大小必须相同。如果集合不可锁定，则忽略等级；否则等级必须小于或等于集合大小，并且在集合中对该设备唯一。

uart:~$ csip_set_member set_size_and_rank 1 1
Set size and rank updated to 1 and 1

获取当前信息

该命令可以获取当前使用的集合信息。

uart:~$ csip_set_member get_info
Info for 0x2003b0c8
        SIRK
00000000: 20 37 0a 00 95 c4 04 20  00 00 00 00 f1 79 09 00 | 7.....  .....y..|
        Set size: 2
        Rank: 1
        Lockable: true
        Locked: false
