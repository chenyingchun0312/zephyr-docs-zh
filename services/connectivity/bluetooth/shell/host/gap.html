Bluetooth：GAP Shell 命令

GAP Shell 是 Bluetooth 的“主” Shell，负责连接管理、扫描、广播等。

身份（Identity）

身份是 Zephyr 主机的一个概念，它允许单个物理设备表现为多个逻辑 Bluetooth 设备。

Shell 允许创建多个身份，最大数量由 Kconfig 符号 CONFIG_BT_ID_MAX 设置。要创建新身份，请使用 bt id-create 命令。然后可以通过其 ID 使用 bt id-select <id> 选择并使用它。最后，可以使用 id-show 列出所有可用的身份。

扫描设备

使用 bt scan on 命令开始扫描。根据所处环境的不同，Shell 上可能会打印大量的行。要停止扫描，请运行 bt scan off，滚动输出随即停止。

下面是一个可能的输出示例：

uart:~$ bt scan on

[DEVICE]: R:CB:01:1A:2D:6E:AE, AD evt type 0, RSSI -78  C:1 S:1 D:0 SR:0 E:0 Prim: LE 1M, Secn: No packets, Interval: 0x0000 (0 us), SID: 0xff
[DEVICE]: R:20:C2:EE:59:85:5B, AD evt type 3, RSSI -62  C:0 S:0 D:0 SR:0 E:0 Prim: LE 1M, Secn: No packets, Interval: 0x0000 (0 us), SID: 0xff
[DEVICE]: R:E3:72:76:87:2F:E8, AD evt type 3, RSSI -74  C:0 S:0 D:0 SR:0 E:0 Prim: LE 1M, Secn: No packets, Interval: 0x0000 (0 us), SID: 0xff
[DEVICE]: R:1E:19:25:8A:CB:84, AD evt type 3, RSSI -67  C:0 S:0 D:0 SR:0 E:0 Prim: LE 1M, Secn: No packets, Interval: 0x0000 (0 us), SID: 0xff
[DEVICE]: R:26:42:F3:D5:A0:86, AD evt type 3, RSSI -73  C:0 S:0 D:0 SR:0 E:0 Prim: LE 1M, Secn: No packets, Interval: 0x0000 (0 us), SID: 0xff
[DEVICE]: R:0C:61:D1:B9:5D:9E, AD evt type 3, RSSI -87  C:0 S:0 D:0 SR:0 E:0 Prim: LE 1M, Secn: No packets, Interval: 0x0000 (0 us), SID: 0xff
[DEVICE]: R:20:C2:EE:59:85:5B, AD evt type 3, RSSI -66  C:0 S:0 D:0 SR:0 E:0 Prim: LE 1M, Secn: No packets, Interval: 0x0000 (0 us), SID: 0xff
[DEVICE]: R:25:3F:7A:EE:0F:55, AD evt type 3, RSSI -83  C:0 S:0 D:0 SR:0 E:0 Prim: LE 1M, Secn: No packets, Interval: 0x0000 (0 us), SID: 0xff
uart:~$ bt scan off
Scan successfully stopped

可以看到，这可能会产生大量结果。为了减少结果数量并方便地找到特定设备，可以启用扫描过滤器。过滤器有四种类型：按名称、按 RSSI、按地址和按周期性广播间隔。要应用过滤器，请使用 bt scan-set-filter 命令，后跟过滤器类型。再次使用这些命令即可添加多个过滤器。

例如，如果只想查找名称为 test shell 的设备：

uart:~$ bt scan-filter-set name "test shell"

或者，如果要查找距离非常近的设备：

uart:~$ bt scan-filter-set rssi -40
RSSI cutoff set at -40 dB

最后，如果要移除所有过滤器：

uart:~$ bt scan-filter-clear all

可以使用命令 bt scan on 创建 主动 扫描器，即扫描器会通过发送 扫描请求（scan request） 数据包向广播者请求更多信息。也可以使用 bt scan passive 命令创建 被动扫描器，此时扫描器不会向广播者请求更多信息。

启用 CONFIG_BT_SCAN_EXT_FILTER_POLICY 后，bt scan --ext-filter-policy on 命令会使用扩展扫描器过滤策略启动扫描器。这样控制器还会上报目标地址为其无法解析的可解析私有地址的定向广播。定向广播的目标地址会单独打印一行。这需要控制器支持扩展扫描器过滤策略（Extended Scanner Filter Policies），否则该命令会失败。

连接设备

要连接设备，需要知道它的地址和地址类型，并以地址和类型作为参数使用 bt connect 命令。

下面是一个示例：

uart:~$ bt connect R:52:84:F6:BD:CE:48
Connection pending
Connected: R:52:84:F6:BD:CE:48
Remote LMP version 5.3 (0x0c) subversion 0xffff manufacturer 0x05f1
LE Features: 0x000000000001412f
LE PHY updated: TX PHY LE 2M, RX PHY LE 2M
LE conn  param req: int (0x0018, 0x0028) lat 0 to 42
LE conn param updated: int 0x0028 lat 0 to 42

可以使用 bt connections 命令列出 Shell 的活动连接。Shell 的最大连接数由 CONFIG_BT_MAX_CONN 定义。可以使用 bt disconnect <address: P:XX:XX:XX:XX:XX:XX or R:XX:XX:XX:XX:XX:XX> 命令断开连接。

备注

如果刚刚进行过扫描，只需运行 bt connect 命令即可连接到最后扫描到的设备。

也可以使用 bt connect-name <name> 命令，自动启用带名称过滤器的扫描并连接到第一个匹配的设备。

广播

使用 bt advertise on 命令开始广播。这将使用默认参数，并以可解析私有地址和设备名称进行广播。也可以运行 bt advertise on identity 命令改用身份地址。要停止广播，请使用 bt advertise off 命令。

要启用更高级的广播功能，应使用 bt adv-create 命令创建广播者（advertiser）。广播者的参数可以在创建时传入，也可以使用 bt adv-param 命令设置。要使用新创建的广播者开始广播，请使用 bt adv-start 命令，然后使用 bt adv-stop 命令停止广播。

使用自定义广播者时，可以选择它是否可连接、是否可扫描，由此产生四个选项：conn-scan、conn-nscan、nconn-scan 和 nconn-nscan。创建广播者或更新其参数时，这些参数是必需的。

例如，要创建一个可连接且可扫描的广播者并启动它：

uart:~$ bt adv-create conn-scan
Created adv id: 0, adv: 0x200022f0
uart:~$ bt adv-start
Advertiser[0] 0x200022f0 set started

你可能会注意到，这样创建的自定义广播者不会广播设备名称，需要另行添加。接着上一个示例：

uart:~$ bt adv-stop
Advertiser set stopped
uart:~$ bt adv-data dev-name
uart:~$ bt adv-start
Advertiser[0] 0x200022f0 set started

现在应该可以在广播数据中看到设备名称。也可以使用 name <custom name> 代替 dev-name 来设置自定义名称。还可以使用 bt adv-data 命令手动设置广播数据。下面的示例展示了如何用它通过原始广播数据设置广播者名称：

uart:~$ bt adv-create conn-scan
Created adv id: 0, adv: 0x20002348
uart:~$ bt adv-data 1009426C7565746F6F74682D5368656C6C
uart:~$ bt adv-start
Advertiser[0] 0x20002348 set started

数据必须按照 Bluetooth 核心规范（参见 5.3 版第 3 卷 C 部分第 11 节）进行格式化。在本例中，第一个八位组是数据的大小（数据本身加上一个表示数据类型的八位组），第二个是数据类型，0x09 表示完整本地名称（Complete Local Name），其余数据是 ASCII 格式的名称。因此，在另一台设备上应该能看到名称 Bluetooth-Shell。

广播时，如果其他设备使用 主动 扫描器，你可能会收到 扫描请求 数据包。要显示这些数据包，可以在广播者参数中添加 scan-reports。

定向广播

如果要重新连接某个设备，可以在 Shell 中使用定向广播。下面的示例演示如何创建定向广播者，地址紧跟在参数 directed 之后指定。low 参数表示使用低占空比模式；如果远端设备启用了隐私功能并支持解析定向广播中的目标地址，则必须使用 dir-rpa 参数。

uart:~$ bt adv-create conn-scan directed R:D7:54:03:CE:F3:B4 low dir-rpa
Created adv id: 0, adv: 0x20002348

之后启动广播者，目标设备即可重新连接。

扩展广播

下面来看一些扩展广播功能。要启用扩展广播，请使用 ext-adv 参数。

uart:~$ bt adv-create conn-nscan ext-adv
Created adv id: 0, adv: 0x200022f0
uart:~$ bt adv-start
Advertiser[0] 0x200022f0 set started

这将创建一个可连接且不可扫描的扩展广播者。

加密广播数据

Zephyr 支持加密广播数据（Encrypted Advertising Data）功能。bt encrypted-ad 子命令用于管理给定广播者的广播数据。

要加密广播数据，需要提供密钥材料，可以通过 bt encrypted-ad set-keys <session key> <init vector> 完成。会话密钥长 16 字节，初始化向量长 8 字节。

可以使用 bt encrypted-ad add-ad 和 bt encrypted-ad add-ead 添加广播数据。前者添加一个广播数据结构（按核心规范定义），后者读取给定数据、将其加密，然后添加生成的加密广播数据结构。加密数据和非加密数据可以混合使用。添加完广播数据后，可以使用 bt encrypted-ad commit-ad 将对数据的更改应用到所选的广播者。之后就可以按前述方法启动广播者。可以使用 bt encrypted-ad clear-ad 清除广播数据。

在中心设备端，可以按前述方法设置正确的密钥材料，然后使用 bt encrypted-ad decrypt-scan on 启用数据解密，从而解密收到的加密广播数据。

备注

要在扫描报告中查看广播数据，需要启用 bt scan-verbose-output。

备注

可以通过增大 CONFIG_BT_CTLR_ADV_DATA_LEN_MAX 和 CONFIG_BT_CTLR_SCAN_DATA_LEN_MAX 的值来增加广播数据的长度。

过滤器接受列表（Filter Accept List）

可以创建一个允许地址列表，用于自动连接这些地址。方法如下：

uart:~$ bt fal-add R:47:38:76:EA:29:36
uart:~$ bt fal-add R:66:C8:80:2A:05:73
uart:~$ bt fal-connect on

Shell 随后会连接到第一个可用的设备。在本例中，如果两个设备同时在广播，将连接到最先加入列表的地址。

通过选项 fal，过滤器接受列表也可用于扫描或广播。例如，如果要扫描一组选定的地址，可以设置过滤器接受列表：

uart:~$ bt fal-add R:65:4B:9E:83:AF:73
uart:~$ bt fal-add R:73:72:82:B4:8F:B9
uart:~$ bt fal-add R:5D:85:50:1C:72:64
uart:~$ bt scan on fal

扫描器应该只会上报这三个地址。

启用安全

连接设备后，可以启用多种安全级别。以下是 Bluetooth LE 的安全级别列表：

  • 1 无加密，无认证；

  • 2 加密，无认证；

  • 3 加密并认证；

  • 4 Bluetooth LE 安全连接。

要启用安全，请使用 bt security <level> 命令。对于需要认证的级别（3 级及以上），必须先设置认证方法，可以使用 bt auth all 命令完成。之后设置安全级别时，会要求在两个设备上确认配对码。在 Shell 端，使用命令 bt auth-passkey-confirm 进行确认。

配对

启用认证要求设备处于可绑定状态。Shell 默认是可绑定的。可以使用 bt bondable off 使 Shell 不可绑定。可以使用命令 bt bonds 列出所有已配对的设备。

已配对设备的最大数量由 CONFIG_BT_MAX_PAIRED 设置。可以使用 bt clear <address: P:XX:XX:XX:XX:XX:XX or R:XX:XX:XX:XX:XX:XX> 移除一个已配对设备，或使用命令 bt clear all 移除所有已配对设备。
