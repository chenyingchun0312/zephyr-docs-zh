ISO-TP 传输协议

  • 概述

  • API 参考

概述

ISO-TP 是 ISO 标准 ISO15765-2《Road vehicles - Diagnostic communication over Controller Area Network (DoCAN). Part2: Transport protocol and network layer services》（道路车辆——基于控制器局域网的诊断通信（DoCAN），第 2 部分：传输协议和网络层服务）中定义的一种传输协议。顾名思义，它最初是为基于控制器局域网的道路车辆诊断而设计的，并且至今仍用于该领域。不过，它并不局限于道路车辆或汽车领域的应用。

该传输协议将经典 CAN（8 字节）和 CAN FD（64 字节）有限的有效载荷数据长度扩展到理论上的 4 GB。此外，它还增加了一种流控制机制，用于影响发送方的行为。ISO-TP 根据 CAN 帧的有效载荷大小将数据包分割成小的分段。这些分段的头部称为协议控制信息（Protocol Control Information，PCI）。

在经典 CAN 上，小于或等于 7 字节的数据包称为单帧（single-frame，SF）。单帧无需分段，也没有任何流控制。

大于该长度的数据包会被分割成一个首帧（first-frame，FF）和所需数量的连续帧（consecutive-frame，CF）。首帧包含整个有效载荷数据的长度信息，以及有效载荷数据的前几个字节。接收端会回送一个流控制帧（flow-control-frame，FC），以拒绝、推迟或接受随后的连续帧。流控制帧还规定了发送条件，即块大小（block-size，BS）和帧之间的最小间隔时间（STmin）。块大小规定了发送方在必须等待下一个流控制帧之前允许发送的连续帧数量。
