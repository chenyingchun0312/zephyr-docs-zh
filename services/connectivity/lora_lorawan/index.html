LoRa 和 LoRaWAN

概述

LoRa（Long Range 的缩写）是由 Semtech Corporation 开发的一种专有低功耗无线通信协议。

LoRa 作为物理层（PHY），基于线性调频扩频（chirp spread spectrum，CSS）调制技术。

LoRaWAN（Long Range Wide Area Network，远距离广域网）在 LoRa PHY 之上定义了网络层。

Zephyr 既为 LoRa 提供了直接通过无线接口发送原始数据包的 API，也为 LoRaWAN 提供了通过网关将终端设备连接到互联网的 API。

Zephyr 提供两种 LoRaWAN 后端实现：

  • LoRaMac-node（默认）：基于 Semtech 的 LoRaMac-node library，作为 Zephyr 模块引入。支持 LoRaWAN 规范定义的所有地区。通过 CONFIG_LORA_MODULE_BACKEND_LORAMAC_NODE 选择。

  • Native：一种符合 Zephyr 惯用风格的 LoRaWAN 1.0.x Class A 实现，直接与 LoRa 无线电驱动交互，没有外部依赖。目前支持 EU868 地区。通过 CONFIG_LORA_MODULE_BACKEND_NATIVE 选择。

备注

Semtech 已弃用 LoRaMac-node，转而推荐 LoRa Basics Modem。将 Zephyr API 移植为使用 LoRa Basics Modem 作为后端的工作正在进行中。

目前，通过 CONFIG_LORA_MODULE_BACKEND_LORA_BASICS_MODEM，仅为 SX1261、SX1262、SX1272 和 SX1276 芯片组支持基础 LoRa API。

LoRaWAN 规范由 LoRa Alliance 发布。

配置选项

LoRa PHY

相关配置选项位于 drivers/lora/Kconfig 中。

  • CONFIG_LORA

  • CONFIG_LORA_SHELL

  • CONFIG_LORA_INIT_PRIORITY

LoRaWAN

相关配置选项位于 subsys/lorawan/Kconfig 中。

  • CONFIG_LORAWAN

  • CONFIG_LORAWAN_SYSTEM_MAX_RX_ERROR

  • CONFIG_LORAWAN_REGION_AS923

  • CONFIG_LORAWAN_REGION_AU915

  • CONFIG_LORAWAN_REGION_CN470

  • CONFIG_LORAWAN_REGION_CN779

  • CONFIG_LORAWAN_REGION_EU433

  • CONFIG_LORAWAN_REGION_EU868

  • CONFIG_LORAWAN_REGION_KR920

  • CONFIG_LORAWAN_REGION_IN865

  • CONFIG_LORAWAN_REGION_US915

  • CONFIG_LORAWAN_REGION_RU864

Native 后端

Native 后端通过 CONFIG_LORA_MODULE_BACKEND_NATIVE 选择，其额外选项位于 subsys/lorawan/native/Kconfig 中：

  • CONFIG_LORAWAN_NATIVE_ENGINE_STACK_SIZE

  • CONFIG_LORAWAN_NATIVE_ENGINE_PRIORITY

  • CONFIG_LORAWAN_NATIVE_PUBLIC_NETWORK

  • CONFIG_LORAWAN_NATIVE_DUTY_CYCLE
