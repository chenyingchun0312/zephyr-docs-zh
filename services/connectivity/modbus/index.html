Modbus

Modbus 是一种工业消息传递协议。该协议针对不同类型的网络或总线制定了规范。Zephyr OS 的实现支持通过串行线路进行通信，并可配合不同的物理接口使用，例如 RS485 或 RS232。TCP 支持并未直接实现，但提供了一些辅助函数，可根据应用程序的需要实现 TCP 支持。

Modbus 通信基于客户端/服务器模型。总线上只能有一个客户端。客户端可以与多个服务器设备通信。服务器设备本身是被动的，不得发送请求或主动发送响应。客户端请求的服务由功能码（FCxx）指定，可以在规范或下文的 API 文档中找到。

Zephyr RTOS 的实现同时支持客户端和服务器两种角色。

有关 Modbus 和 Modbus RTU 的更多信息，请访问网站 MODBUS Protocol Specifications。

示例

  • 借助 Modbus RTU server 和 Modbus RTU client 示例，可以在评估板上试用 RTU 服务器和 RTU 客户端的实现。

  • Modbus TCP server 示例是一个简单的 Modbus TCP 服务器。

  • Modbus TCP-to-serial gateway 示例展示了如何使用 Zephyr OS 构建 TCP 到串行线路的网关。
