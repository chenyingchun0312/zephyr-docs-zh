使用 QEMU 和 IEEE 802.15.4 联网

  • 基本设置

    • 第 1 步 - 编译并启动 echo-server

    • 第 2 步 - 编译并启动 echo-client

本页介绍如何在两个 QEMU 之间建立虚拟网络，两者通过 UART 相连，并在彼此之间运行 IEEE 802.15.4 链路层。注意，这只适用于 Linux 主机。

基本设置

执行以下步骤需要两个终端窗口：

  • 终端 #1 用于运行 Zephyr 示例应用程序 echo-server。

  • 终端 #2 用于运行 Zephyr 示例应用程序 echo-client。

如果要捕获传输的网络数据，必须编译 tools/net-tools 目录下的 monitor_15_4 程序。

打开一个终端窗口并输入：

cd $ZEPHYR_BASE/../tools/net-tools
make monitor_15_4

第 1 步 - 编译并启动 echo-server

在终端 #1 中输入：

west build -b qemu_x86 -d build/server samples/net/sockets/echo_server -- -DEXTRA_CONF_FILE=overlay-qemu_802154.conf
west build -t server -d build/server

如果要捕获两个 QEMU 之间的网络流量，请输入：

west build -b qemu_x86 -d build/server samples/net/sockets/echo_server -- -G'Unix Makefiles' -DEXTRA_CONF_FILE=overlay-qemu_802154.conf -DPCAP=capture.pcap
west build -t server -d build/server

注意，如果在命令行中设置了数据包捕获选项，则必须对 server 目标使用 make。build/server/capture.pcap 文件将包含传输的数据。

第 2 步 - 编译并启动 echo-client

在终端 #2 中输入：

west build -b qemu_x86 -d build/client samples/net/sockets/echo_client -- -DEXTRA_CONF_FILE=overlay-qemu_802154.conf
west build -t client -d build/client

你应该能看到数据在两个 QEMU 之间传递。按 CTRL+A x 退出 QEMU。
