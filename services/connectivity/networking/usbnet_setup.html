USB 设备联网

  • 基本设置

    • 选择 IP 地址

    • 设置 IPv4 地址和路由

    • 设置 IPv6 地址和路由

  • 测试连接

本页介绍如何在 Linux 主机与运行在支持 USB 的设备上的 Zephyr 应用程序之间建立网络连接。

开发板通过 USB 线缆连接到 Linux 主机，并向主机提供一个以太网接口。在受支持的开发板上运行 Zephyr 源码中的 Echo server (advanced) 应用程序。开发板通过 USB 线缆连接到 Linux 主机，向主机提供以太网接口。

基本设置

要通过新建的以太网接口与 Zephyr 应用程序通信，需要为 Linux 主机分配 IP 地址并设置路由表。将开发板通过 USB 线缆插入 Linux 主机后，cdc_ether 驱动会以给定的 MAC 地址注册一个新的以太网设备。

可以在 Linux 主机上运行 dmesg，检查网络设备是否已创建以及 MAC 地址是否已分配。

cdc_ether 1-2.7:1.0 eth0: register 'cdc_ether' at usb-0000:00:01.2-2.7, CDC Ethernet Device, 00:00:5e:00:53:01

接下来需要按下一节的说明启用该接口并分配 IP 地址。

选择 IP 地址

要与开发板建立网络连接，需要为 Linux 主机上的接口选择 IP 地址。

合理的做法是选择与 Zephyr 应用程序相同子网的地址。IP 地址通常在项目配置文件中设置，也可以在 shell 中用以下命令查看。将串口控制台程序（例如 puTTY）连接到开发板，在 Zephyr shell 中输入以下命令：

shell> net iface

Interface 0xa800e580 (Ethernet)
===============================
Link addr : 00:00:5E:00:53:00
MTU       : 1500
IPv6 unicast addresses (max 2):
        fe80::200:5eff:fe00:5300 autoconf preferred infinite
        2001:db8::1 manual preferred infinite
...
IPv4 unicast addresses (max 1):
        192.0.2.1 manual preferred infinite

该命令显示开发板已分配一个 IPv4 地址和两个 IPv6 地址。根据开发板的网络配置，可以使用 IPv4 或 IPv6 进行网络连接。

下一步是为 Linux 主机上的新接口分配 IP 地址。在以下步骤中，enx00005e005301 是作者 Linux 系统上的接口名称。

设置 IPv4 地址和路由

# ip address add dev enx00005e005301 192.0.2.2
# ip link set enx00005e005301 up
# ip route add 192.0.2.0/24 dev enx00005e005301

设置 IPv6 地址和路由

# ip address add dev enx00005e005301 2001:db8::2
# ip link set enx00005e005301 up
# ip -6 route add 2001:db8::/64 dev enx00005e005301

测试连接

可以在主机上 ping 开发板的 Zephyr IP 地址来测试连接：

$ ping 192.0.2.1
PING 192.0.2.1 (192.0.2.1) 56(84) bytes of data.
64 bytes from 192.0.2.1: icmp_seq=1 ttl=64 time=2.30 ms
64 bytes from 192.0.2.1: icmp_seq=2 ttl=64 time=1.43 ms
64 bytes from 192.0.2.1: icmp_seq=3 ttl=64 time=2.45 ms
...
