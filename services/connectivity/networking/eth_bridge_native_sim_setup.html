native_sim 开发板上的以太网桥

本文介绍如何在（Linux）主机与运行在 native_sim 开发板上的 Zephyr 应用程序之间建立桥接以太网网络。

该设置可用于测试以太网桥接功能，该功能通过 Kconfig 选项 CONFIG_NET_ETHERNET_BRIDGE 启用。在此设置中，net-tools 配置会创建两个主机网络接口 zeth0 和 zeth1，并将它们连接到 Zephyr 的 native_sim 应用程序。

首先创建主机接口。本例创建两个接口。

cd $ZEPHYR_BASE/../tools/net-tools
./net-setup.sh -c zeth-multiface.conf -i zeth0 -t 2

-c 指定要使用的配置文件，其中 zeth-multiface.conf 专门用于在主机上生成多个网络接口。-i 选项指定第一个主机接口的名称。-t 指定要创建的网络接口数量。

然后创建一个示例并启用以太网桥接支持。本例创建 Echo server (advanced) 示例应用程序。

桥接需要第二个 TAP 接口。创建一个设备树覆盖文件 second-iface.overlay，添加第二个 zephyr,native-tap 接口：

/ {
    zeth1: zeth1 {
        compatible = "zephyr,native-tap";
        status = "okay";
        zephyr,random-mac-address;
        host-interface = "zeth1";
    };
};

然后指定该覆盖文件，构建并运行应用程序：

west build -p -b native_sim -d ../build/echo-server \
   samples/net/sockets/echo_server -- \
   -DCONFIG_UART_NATIVE_PTY_AUTOATTACH_DEFAULT_CMD="\"gnome-terminal -- screen %s\"" \
   -DCONFIG_NET_ETHERNET_BRIDGE=y \
   -DCONFIG_NET_ETHERNET_BRIDGE_SHELL=y \
   -DEXTRA_DTC_OVERLAY_FILE=second-iface.overlay \
   -DCONFIG_NET_IF_MAX_IPV6_COUNT=2 \
   -DCONFIG_NET_IF_MAX_IPV4_COUNT=2
../build/echo-server/zephyr/zephyr.exe -attach_uart

这会创建并运行已启用桥接但尚未配置桥接的 Echo server (advanced)。要配置桥接，可以使用 bridge shell，也可以在应用程序中直接调用桥接 API。下面使用 bridge shell 设置桥接：

net bridge addif 1 3 2
net iface up 1

在上例中，网桥接口的索引为 1，接口 2 和 3 是以太网接口，分别与主机侧的 zeth0 和 zeth1 接口相连。

net bridge 命令会显示桥接的当前状态：

net bridge
Bridge Status   Config   Interfaces
1      up       ok       2 3

addif 命令将以太网接口 2 和 3 添加到网桥接口 1。执行 addif 命令后，桥接仍处于禁用状态，因为网桥接口默认未启用（up）。net iface up 命令会开启桥接。

如果在主机侧运行 wireshark 并监视 zeth0 和 zeth1，应该能在两个主机接口上看到相同的网络流量。

注意，接口索引号不是固定的，在你的环境中，网桥和以太网接口的索引值可能不同。

关闭网桥接口即可禁用桥接，使用 delif 命令可以将以太网接口从网桥中移除。

net iface down 1
net bridge delif 1 2 3
