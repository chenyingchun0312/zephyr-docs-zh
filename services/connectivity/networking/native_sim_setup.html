使用虚拟/TAP 以太网驱动

本节介绍如何在（Linux）主机与运行在 native_sim 开发板上的 Zephyr 应用程序之间建立虚拟网络。

本例在 native_sim 开发板上运行 Zephyr 源码中的 Echo server (advanced) 示例应用程序。Zephyr native_sim 开发板实例通过 tuntap 设备连接到 Linux 主机，该设备在 Linux 中表现为一个以太网网络接口。

前提条件

在 Linux 主机上找到 Zephyr net-tools 项目。它位于 Zephyr 标准安装的 tools/net-tools 目录下，也可以从其独立的 git 仓库单独安装：

git clone https://github.com/zephyrproject-rtos/net-tools

基本设置

执行以下步骤需要三个终端窗口：

  • 终端 #1 的当前目录为 net-tools（cd net-tools）

  • 终端 #2 是常用的 Zephyr 开发终端，已初始化 Zephyr 环境。

  • 终端 #3 是正在运行的 Zephyr native_sim 实例的控制台（可选）。

第 1 步 - 创建以太网接口

在启动带网络模拟的 native_sim 之前，应先创建网络接口。

在终端 #1 中输入：

./net-setup.sh

可以调整 net-setup.sh 脚本的行为。按如下方式运行 net-setup.sh 可查看各种选项：

./net-setup.sh --help

第 2 步 - 在 native_sim 开发板中启动应用程序

构建并启动 echo_server 示例应用程序。

在终端 #2 中输入：

west build -b native_sim samples/net/sockets/echo_server
west build -t run

第 3 步 - 连接控制台（可选）

启动 Zephyr 实例时，控制台窗口应会自动打开；如果没有出现，可以手动连接控制台。native_sim 开发板启动时会打印类似下面的字符串：

UART connected to pseudotty: /dev/pts/5

可以按如下方式手动连接：

screen /dev/pts/5

使用卸载式套接字

与 Using virtual/TAP Ethernet driver 相比，其主要优点是无需在主机上设置虚拟网络接口。这意味着不需要提升的（root）权限。

第 1 步 - 在 native_sim 开发板中启动应用程序

构建并启动 echo_server 示例应用程序：

west build -b native_sim samples/net/sockets/echo_server -- -DEXTRA_CONF_FILE=overlay-nsos.conf
west build -t run

第 2 步 - 运行 net-tools 中的 echo-client

在 Linux 主机上找到 Zephyr net-tools 项目。它位于 Zephyr 标准安装的 tools/net-tools 目录下，也可以从其独立的 git 仓库单独安装：

git clone https://github.com/zephyrproject-rtos/net-tools

备注

使用卸载式套接字网络驱动的 Native Simulator 与任何其他使用 BSD 套接字 API 的（Linux）应用程序使用相同的网络接口/命名空间。这意味着 Echo server (advanced) 和 echo-client 应用程序将通过 localhost/环回接口（地址 127.0.0.1）通信。

运行 UDP 测试，请输入：

./echo-client 127.0.0.1

运行 TCP 测试，请输入：

./echo-client -t 127.0.0.1

从命令行设置接口名称和 IPv4 参数

默认情况下，native_sim 使用的以太网接口名称由 zephyr,native-tap 设备树节点的 host-interface 属性决定，但也可以在命令行中使用 --eth-if=<interface_name> 设置。

IPv4 地址、网关和子网掩码同样如此，可以在命令行中分别使用 --ipv4-addr=<ip_address>、--ipv4-gw=<gateway> 和 --ipv4-nm=<netmask> 设置。

这些选项作用于第一个接口。定义了多个 zephyr,native-tap 接口时，每个额外接口都有各自的接口选项，以设备树节点名称为前缀，例如 --<node>_eth-if 和 --<node>_ipv4-addr。

注意，配置选项 CONFIG_NET_CONFIG_MY_IPV4_ADDR 与命令行参数会同时生效。这意味着如果两者都设置了，接口最终可能会有两个 IP 地址。大多数情况下，同一时间只使用其中一种才合理。

如果应用程序需要运行多个实例，而为每个实例重新编译又很麻烦，这种方式会很有用。

./zephyr.exe --eth-if=zeth2 --ipv4-addr=192.0.2.2 --ipv4-gw=192.0.0.1
--ipv4-nm=255.255.0.0

备注

也可以在构建时通过 CONFIG_NATIVE_EXTRA_CMDLINE_ARGS 配置选项提供这些命令行选项。
