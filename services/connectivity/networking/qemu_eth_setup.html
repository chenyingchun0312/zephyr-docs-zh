使用 QEMU 以太网联网

  • 前提条件

  • 基本设置

    • 第 1 步 - 创建以太网接口

    • 第 2 步 - 在 QEMU 开发板中启动应用程序

本页介绍如何在（Linux）主机与运行在 QEMU 中的 Zephyr 应用程序之间建立虚拟网络。

本例在 QEMU 中运行 Zephyr 源码中的 Echo server (advanced) 示例应用程序。Zephyr 实例通过 tuntap 设备连接到 Linux 主机，该设备在 Linux 中表现为一个以太网网络接口。

前提条件

在 Linux 主机上找到 Zephyr net-tools 项目。它位于 Zephyr 标准安装的 tools/net-tools 目录下，也可以从其独立的 git 仓库单独安装：

git clone https://github.com/zephyrproject-rtos/net-tools

基本设置

执行以下步骤需要两个终端窗口：

  • 终端 #1 的当前目录为 net-tools（cd net-tools）

  • 终端 #2 是常用的 Zephyr 开发终端，已初始化 Zephyr 环境。

配置 Zephyr 实例时，必须为 QEMU 连接选择正确的以太网驱动：

  • 对于 qemu_x86，选择 Intel(R) PRO/1000 Gigabit Ethernet driver 以太网驱动。该驱动在 Zephyr 源码树中名为 e1000。

  • 对于 qemu_cortex_m3，选择 TI Stellaris MCU family ethernet driver 以太网驱动。该驱动在 Zephyr 源码树中名为 stellaris。

  • 对于 mps2_an385，选择 SMSC911x/9220 Ethernet driver 以太网驱动。该驱动在 Zephyr 源码树中名为 smsc911x。

  • 对于 qemu_cortex_a53，默认选择 Intel(R) PRO/1000 Gigabit Ethernet driver 以太网驱动。

  • 此外，Echo server (advanced) 示例还包含用于 qemu_x86_64 上 VIRTIO 网络设备的覆盖文件。

第 1 步 - 创建以太网接口

在启动带网络连接的 QEMU 之前，应先在主机系统中创建网络接口。

在终端 #1 中输入：

./net-setup.sh

可以调整 net-setup.sh 脚本的行为。按如下方式运行 net-setup.sh 可查看各种选项：

./net-setup.sh --help

第 2 步 - 在 QEMU 开发板中启动应用程序

构建并启动 Echo server (advanced) 示例应用程序。本例使用 qemu_x86 开发板。

在终端 #2 中输入：

west build -b qemu_x86 samples/net/sockets/echo_server -- -DEXTRA_CONF_FILE=overlay-e1000.conf
west build -t run

如果决定在 qemu_x86_64 上使用 VIRTIO 网络设备，则输入：

west build -b qemu_x86_64 samples/net/sockets/echo_server -- -DDTC_OVERLAY_FILE=virtnet.overlay -DEXTRA_CONF_FILE=overlay-virtnet.conf
west build -t run

按 CTRL+A x 退出 QEMU。
