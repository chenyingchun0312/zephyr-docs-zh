网络跟踪

用户可以启用对网络核心协议栈和套接字 API 调用的跟踪。

CONFIG_TRACING_NET_CORE 选项控制网络核心协议栈的跟踪。启用跟踪和网络功能后，该选项默认启用。系统会开始收集接收和发送调用的结果，即网络数据包是否成功发送或接收。系统还会收集数据包发送或接收的耗时，即递交网络数据包所用的时间，以及所用的网络接口、优先级和流量类别。

CONFIG_TRACING_NET_SOCKETS 选项可用于跟踪系统中 BSD 套接字调用的使用情况。启用跟踪和 BSD 套接字 API 支持后，该选项即被启用。系统会开始收集调用了哪些 BSD 套接字 API，以及这些 API 调用使用的参数和返回值。

关于如何使用跟踪服务，请参阅 跟踪文档。
