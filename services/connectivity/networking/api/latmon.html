Latmon 网络服务

概述

提供基于网络的延迟监测所需的功能，包括套接字管理、客户端-服务器通信，以及与运行在被测系统（SUT）上的 Latmus 服务交换数据。

Latmon 网络服务负责在 Latmon 应用程序（运行在基于 Zephyr 的开发板上）与 Latmus 服务（运行在 SUT 上）之间建立和管理网络通信。

它使用 TCP 套接字进行可靠通信，并使用 UDP 套接字广播 Latmon 设备的 IP 地址。

API 参考

latmon

Related code samples

  • Latmon ClientMeasures delta time between GPIO events and reports the latency metrics via latmon to the latmus service executing on the SUT.

特性

  • 套接字管理：创建并管理用于通信的 TCP 和 UDP 套接字。

  • 客户端-服务器通信：处理来自 Latmus 服务的传入连接。

  • 数据交换：向 Latmus 服务发送延迟指标和直方图数据。

  • IP 地址广播：广播 Latmon 设备的 IP 地址，便于 Latmus 服务发现。

  • 线程安全设计：使用 Zephyr 的内核原语（例如消息队列和信号量）进行同步。

工作流程

创建套接字

调用 net_latmon_get_socket() 函数创建并配置一个用于与 Latmus 服务通信的 TCP 套接字。可以通过参数指定连接地址，把套接字绑定到特定的接口和端口。

连接处理

net_latmon_connect() 函数等待来自 Latmus 服务的连接。如果在超时时间内没有收到连接，该服务会使用 UDP 广播其 IP 地址并返回 -EAGAIN。如果无法发送广播请求，该函数返回 -1，客户端应退出。

启动监测

连接建立后，调用 net_latmon_start() 函数启动监测过程。该函数使用回调计算延迟差值，并把数据发送给 Latmus 服务。

监测状态

可以使用 net_latmon_running() 函数检查监测过程是否处于活动状态。

线程管理

该服务使用 Zephyr 线程处理传入连接并管理监测过程。

启用 Latmon 服务

必须在 prj.conf 文件中启用以下配置选项。

  • CONFIG_NET_LATMON

可以配置以下选项来定制 Latmon 服务：

  • CONFIG_NET_LATMON_PORT：Latmon 服务的端口号。

  • CONFIG_NET_LATMON_XFER_THREAD_STACK_SIZE

  • CONFIG_NET_LATMON_XFER_THREAD_PRIORITY

  • CONFIG_NET_LATMON_THREAD_STACK_SIZE

  • CONFIG_NET_LATMON_THREAD_PRIORITY

  • CONFIG_NET_LATMON_MONITOR_THREAD_STACK_SIZE

  • CONFIG_NET_LATMON_MONITOR_THREAD_PRIORITY

使用示例

#include <zephyr/net/latmon.h>
#include <zephyr/net/socket.h>

void main(void)
{
    struct in_addr ip;
    int server_socket, client_socket;

    /* Create and configure the server socket */
    server_socket = net_latmon_get_socket(NULL);

    while (1) {
        /* Wait for a connection from the Latmus service */
        client_socket = net_latmon_connect(server_socket, &ip);
        if (client_socket < 0) {
            if (client_socket == -EAGAIN) {
                continue;
            }
            goto out;
        }

        /* Start the latency monitoring process */
        net_latmon_start(client_socket, measure_latency_cycles);
    }
out:
    close(server_socket);
}
