网络配置库

  • SNTP 时钟初始化

  • 使用示例

  • API 参考

概述

网络配置库根据用户提供的 Kconfig 选项，在系统启动期间以半自动的方式设置网络设备。

以下 Kconfig 选项会影响配置库设置系统的方式：

网络配置库的 Kconfig 选项

选项名称

说明

CONFIG_NET_CONFIG_SETTINGS

该选项控制是否对网络系统进行配置或初始化。如果未设置，则不使用配置库进行初始化，应用程序需要自行完成所有网络相关配置。如果设置了该选项，用户可以选择配置静态 IP 地址，并将其设置到系统中的第一个网络接口上。通常，设置静态 IP 地址只适用于测试，不应在生产代码中使用。设置静态 IP 地址的具体选项请参见配置库的 Kconfig 文件 subsys/net/lib/config/Kconfig。

CONFIG_NET_CONFIG_AUTO_INIT

设备启动时自动配置网络系统。

CONFIG_NET_CONFIG_INIT_TIMEOUT

该选项指定等待网络就绪可用的时长。例如，如果在此时限内没有从 DHCPv4 获得 IPv4 地址，那么在设备启动期间调用 net_config_init() 会返回错误。

CONFIG_NET_CONFIG_NEED_IPV4

网络应用程序需要 IPv4 支持才能正常工作。该选项确保网络应用程序被正确初始化以使用 IPv4。如果未启用 CONFIG_NET_IPV4，设置该选项会自动启用 IPv4。

CONFIG_NET_CONFIG_NEED_IPV6

网络应用程序需要 IPv6 支持才能正常工作。该选项确保网络应用程序被正确初始化以使用 IPv6。如果未启用 CONFIG_NET_IPV6，设置该选项会自动启用 IPv6。

CONFIG_NET_CONFIG_NEED_IPV6_ROUTER

如果启用了 IPv6，该选项表示网络应用程序需要先存在 IPv6 路由器才能继续。实际上，这意味着应用程序要等到收到 IPv6 路由器通告消息后才继续。

CONFIG_NET_CONFIG_MY_IPV6_ADDR

分配给默认网络接口的本地静态 IPv6 地址。

CONFIG_NET_CONFIG_PEER_IPV6_ADDR

对端静态 IPv6 地址。主要用于测试环境，使应用程序可以连接到预定义的主机。

CONFIG_NET_CONFIG_MY_IPV4_ADDR

分配给默认网络接口的本地静态 IPv4 地址。

CONFIG_NET_CONFIG_MY_IPV4_NETMASK

分配给该 IPv4 地址的静态 IPv4 子网掩码。

CONFIG_NET_CONFIG_MY_IPV4_GW

分配给默认网络接口的静态 IPv4 网关地址。

CONFIG_NET_CONFIG_PEER_IPV4_ADDR

对端静态 IPv4 地址。主要用于测试环境，使应用程序可以连接到预定义的主机。

SNTP 时钟初始化

如果设置了 CONFIG_NET_CONFIG_CLOCK_SNTP_INIT，该库还会根据 SNTP 服务器初始化系统时钟，并可通过 CONFIG_NET_CONFIG_SNTP_INIT_RESYNC 选择保持时钟同步。

要查询的服务器按以下顺序确定：

  1. 运行时通过 net_config_sntp_set_server() 设置的服务器。这需要 CONFIG_NET_CONFIG_SNTP_INIT_SERVER_RUNTIME，适用于只有在运行期间（例如完成配置下发后）才知道要使用哪个时间服务器的应用程序。

  2. 如果设置了 CONFIG_NET_CONFIG_SNTP_INIT_SERVER_USE_DHCPV4_OPTION，则使用通过 DHCPv4 NTP 服务器选项获得的服务器。

  3. CONFIG_NET_CONFIG_SNTP_INIT_SERVER。如果设置了 CONFIG_NET_CONFIG_CLOCK_SNTP_INIT，但既没有启用 CONFIG_NET_CONFIG_SNTP_INIT_SERVER_RUNTIME，也没有启用 CONFIG_NET_CONFIG_SNTP_INIT_SERVER_USE_DHCPV4_OPTION，则必须设置该选项。

使用示例

如果设置了 CONFIG_NET_CONFIG_AUTO_INIT，配置库会自动启用，并在设备启动期间运行。这种情况下，该库会自动调用 net_config_init()，应用程序不需要进行任何网络配置。

如果想使用网络配置库但不使用自动初始化，可以手动调用 net_config_init()。flags 参数可用于向该库提示应用程序在真正启动之前希望具备哪些功能。
