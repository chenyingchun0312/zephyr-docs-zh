虚拟局域网（VLAN）支持

  • 概述

  • API 参考

概述

虚拟局域网 （VLAN）是在数据链路层（OSI 第 2 层）上划分并隔离的计算机网络。对于以太网，它指的是 IEEE 802.1Q

在 Zephyr 中，每个 VLAN 都被建模为一个虚拟网络接口。也就是说，系统中有一个对应于真实物理以太网端口的以太网网络接口，每个 VLAN 都会创建一个虚拟网络接口，该虚拟网络接口连接到真实的网络接口。这与 Linux 实现 VLAN 的方式类似。eth0 是真实的网络接口，vlan0 是运行在 eth0 之上的虚拟网络接口。

必须在编译时通过设置 CONFIG_NET_VLAN 选项启用 VLAN 支持，并设置 CONFIG_NET_VLAN_COUNT 以反映系统中将有多少个网络接口。例如，如果有一个不支持 VLAN 的网络接口和两个支持 VLAN 的网络接口，则 CONFIG_NET_VLAN_COUNT 选项应设置为 3。

即使在 prj.conf 文件中启用了 VLAN，应用程序仍需要在运行时激活 VLAN。VLAN API 为此提供了 net_eth_vlan_enable() 函数，应用程序需要将网络接口和所需的 VLAN 标签作为参数传给该函数。可以使用 net_eth_vlan_disable() 函数禁用指定网络接口的 VLAN 标记。应用程序需要自行配置 VLAN 网络接口，例如设置 IP 地址等。

API 用法示例另请参见 VLAN 示例应用程序。该示例应用程序的源代码位于 samples/net/ethernet/vlan。

net-shell 模块包含 net vlan add 和 net vlan del 命令，可用于为指定网络接口启用或禁用 VLAN 标签。

关于以太网 VLAN 的更多信息，请参见 IEEE 802.1Q spec。
