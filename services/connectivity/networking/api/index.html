网络 API

Zephyr 支持标准 BSD 套接字 API（定义于 include/zephyr/net/socket.h），供应用程序使用。详情请参见 BSD 套接字 API。

除标准 API 外，Zephyr 还提供了一组自定义的网络 API 和库供应用程序使用。详情请参见下面的列表。

备注

应用程序不应使用 include/zephyr/net/net_context.h 中的旧版连接 API。
