Wi-Fi 功能与加密的对应关系

本页列出 Zephyr 中（通过基于 hostap 的 wpa_supplicant）支持的 Wi-Fi 功能与底层 MbedTLS 加密原语之间的对应关系。借助本页可以了解哪些功能需要大数运算（bignum）、ECDH、TLS 等，以及在启用 CONFIG_WIFI_NM_WPA_SUPPLICANT_CRYPTO_MBEDTLS_PSA 时，哪些代码路径使用 传统加密 （MbedTLS 传统 API），哪些使用 PSA 加密 （平台安全架构 API）。

相关实现位于 hostap 模块中：crypto_mbedtls_alt.c （通用加密）和 tls_mbedtls_alt.c （TLS/EAP）。这里只考虑 MbedTLS 后端。

功能集（来自 hostap Kconfig）

各项功能由 Kconfig 控制。相关选项包括：

  • CONFIG_WIFI_NM_WPA_SUPPLICANT_WEP — WEP（传统）

  • CONFIG_WIFI_NM_WPA_SUPPLICANT_WPA3_COMMON — 选择 Internal 或 External 时的 WPA3-SAE（WIFI_NM_WPA_SUPPLICANT_WPA3_IMPLEMENTATION；默认为 Internal）。CONFIG_WIFI_NM_WPA_SUPPLICANT_WPA3 没有提示项，在选择 Internal 时会启用内部的大数运算 SAE 路径（请在 prj.conf 中设置实现方式的选择，而不是设置此符号）。

  • CONFIG_WIFI_NM_WPA_SUPPLICANT_DPP — Wi-Fi 简易连接（Easy Connect，DPP）

  • CONFIG_WIFI_NM_WPA_SUPPLICANT_WPS — Wi-Fi 保护设置（WPS）

  • CONFIG_WIFI_NM_WPA_SUPPLICANT_P2P — P2P / Wi-Fi Direct（隐含启用 WPS）

  • CONFIG_WIFI_NM_WPA_SUPPLICANT_CRYPTO_ENTERPRISE — EAP（EAP-TLS、EAP-TTLS-MSCHAPV2、EAP-PEAP-MSCHAPV2、EAP-PEAP-GTC、EAP-PEAP-TLS）

只要加密未设置为 CRYPTO_NONE，WPA2-PSK 和 WPA2-PSK-256 就可用。

  • ECDH（P-256、P-384、P-521）

WPA2-PSK / WPA2-PSK-256

  • PBKDF2-SHA1（-256 使用 SHA256）

  • HMAC

  • AES（CCMP）

  • OMAC1-AES（密钥封装）

启用 PSA 时，PBKDF2、HMAC、AES、OMAC1 通过 PSA 实现。

WEP

  • RC4/ARC4（流密码）

  • 某些封装可选用 AES。已弃用。

不适用（WEP 未迁移到 PSA）。

WPS

  • DH（有限域）

  • 大数

  • 哈希、HMAC、AES、TLS-PRF。注册器（Registrar）使用 TLS。

  • DH（mbedtls_dhm）、大数（mbedtls_mpi）

  • tls_mbedtls_alt 中的 TLS

  • 通过 PSA 实现的哈希、HMAC、AES、PBKDF2

  • DH/大数和 TLS 为传统实现

EAP-TLS / EAP-TTLS / EAP-PEAP

  • TLS 1.2（可选 1.3）

  • RSA

  • X.509 解析/验证

  • 哈希、HMAC、AES（密码套件）

  • 完整的 TLS 协议栈（mbedtls_ssl_*、mbedtls_x509_*）

  • RSA

  • tls_mbedtls_alt 中未使用 PSA

  • TLS 层仍为传统实现

  • 底层的哈希/HMAC/AES 可在 crypto_mbedtls_alt 中使用 PSA

EAP-PWD

  • TLS-PRF

  • 大数

  • DH（有限域）

  • EC（可选）

  • 哈希、HMAC

大数、DH、EC（如使用）通过传统 MbedTLS 实现。

  • 通过 PSA 实现的哈希/HMAC

  • 大数/DH/EC 为传统实现

EAP-IKEV2

  • 密码（AES）、大数、DH

  • TLS-PRF 类操作

传统的密码、大数、DH。

  • 通过 PSA 实现的 AES/哈希/HMAC

  • 大数/DH 为传统实现

无认证/加密。

不适用

不适用

备注

WEP 必须通过 CONFIG_WIFI_NM_WPA_SUPPLICANT_WEP 显式启用。WEP 已弃用且不安全，仅可用于传统网络。

总结：传统实现与 PSA（MbedTLS 后端）

启用 CONFIG_WIFI_NM_WPA_SUPPLICANT_CRYPTO_MBEDTLS_PSA 后，crypto_mbedtls_alt.c （以及 supp_psa_api.h / supp_psa_api.c）中的实现划分如下。可通过此表了解哪些操作使用 PSA，哪些使用 传统 MbedTLS。
