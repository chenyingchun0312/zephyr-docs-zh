网络 Shell

网络 shell 及其配套 shell 提供了一些辅助功能，用于了解网络状态、启用/禁用功能，以及执行 ping 或 DNS 解析等命令。注意，net-shell 会占用额外内存，因此可能不应在生产代码中使用。详细的 shell 信息另请参见 通用 shell。

注意，默认情况下，无论 net-shell 命令是否已启用，用户都可以看到它们。这有助于用户了解有哪些命令可用以及如何启用它们。禁用 CONFIG_NET_SHELL_SHOW_DISABLED_COMMANDS 选项可以关闭这一额外帮助。

已实现以下 net-shell 命令：

net-shell 命令

命令

说明

net allocs

打印网络内存分配情况。仅在设置了 CONFIG_NET_DEBUG_NET_PKT_ALLOC 时可用。

net arp

打印 IPv4 ARP 缓存的信息。仅在启用了 IPv4 的网络中设置了 CONFIG_NET_ARP 时可用。

net bridge

打印以太网网桥的信息并对其进行操作。仅在设置了 CONFIG_NET_ETHERNET_BRIDGE_SHELL 时可用。

net capture

监控网络流量。详细信息请参见 监视网络流量。

net cm

连接管理器 shell。仅在设置了 CONFIG_NET_CONNECTION_MANAGER 时可用。

net conn

打印网络连接的信息。

net dhcpv4

启用/禁用 DHCPv4 客户端或服务器支持。仅在设置了 CONFIG_NET_DHCPV4_SERVER 或 CONFIG_NET_DHCPV4 时可用。

net dhcpv6

启用/禁用 DHCPv6 客户端支持。仅在设置了 CONFIG_NET_DHCPV6 时可用。

net dns

显示 DNS 的配置情况。该命令也可用于解析 DNS 名称。仅在设置了 CONFIG_DNS_RESOLVER 时可用。

net events

启用网络事件监控。仅在设置了 CONFIG_NET_MGMT_EVENT_MONITOR 时可用。

net filter

查看网络数据包过滤规则。仅在设置了 CONFIG_NET_PKT_FILTER 时可用。

net ftp

连接 FTP 服务器以传输文件。仅在设置了 CONFIG_FTP_CLIENT 时可用。

net gptp

打印 gPTP 支持的信息。仅在设置了 CONFIG_NET_GPTP 时可用。

net http

显示 HTTP 服务器信息，或发送 HTTP GET/POST/PUT/DELETE 请求。仅在设置了 CONFIG_HTTP_SERVER 或 CONFIG_HTTP_CLIENT 时可用。

net iface

打印网络接口的信息。

net ipv4

打印 IPv4 特定的信息和配置。仅在设置了 CONFIG_NET_IPV4 时可用。

net ipv6

打印 IPv6 特定的信息和配置。仅在设置了 CONFIG_NET_IPV6 时可用。

net mem

打印网络内存使用情况的信息。如果设置了 CONFIG_NET_BUF_POOL_USAGE，该命令会打印更多信息。

net nbr

打印邻居信息。仅在设置了 CONFIG_NET_IPV6 时可用。

net ping

ping 一台网络主机。

net pkt

打印底层网络数据包信息，用于调试。

net pmtu

打印路径 MTU 发现信息。仅在设置了 CONFIG_NET_IPV6_PMTU 或 CONFIG_NET_IPV4_PMTU 时可用。

net ppp

打印点对点协议信息。仅在同时设置了 CONFIG_NET_L2_PPP 和 CONFIG_NET_PPP 时可用。

net ptp

打印 PTP 支持的信息。使用 net ptp <port> 可查看每个端口的详细信息。仅在设置了 CONFIG_PTP 时可用。

net qbv

显示和配置 IEEE 802.1Qbv 时间感知整形器（TAS）信息。仅在设置了 CONFIG_NET_QBV 时可用。

net quic

显示和配置 QUIC 传输。仅在设置了 CONFIG_QUIC 时可用。

net resume

如果启用了网络电源管理，恢复网络接口。

net route

显示 IPv6 或 IPv4 网络路由。仅在设置了 CONFIG_NET_IPV6_ROUTING 或 CONFIG_NET_IPV4_ROUTING 时可用。

net sockets

显示网络套接字信息和统计数据。仅在同时设置了 CONFIG_NET_SOCKETS_OBJ_CORE 和 CONFIG_OBJ_CORE 时可用。

net ssh

SSH 客户端支持。仅在设置了 CONFIG_SSH_CLIENT 时可用。

net sshd

SSH 服务器支持。仅在设置了 CONFIG_SSH_SERVER 时可用。

net ssh_key

支持 SSH 密钥的生成/删除/保存/加载。仅在设置了 CONFIG_SSH_CLIENT 或 CONFIG_SSH_SERVER 时可用。

net stats

显示网络统计信息。

net suspend

如果启用了网络电源管理，挂起网络接口。

net tcp

建立 TCP 连接、发送数据、关闭 TCP 连接。仅在设置了 CONFIG_NET_TCP 时可用。

net udp

直接从 shell 发送 UDP 数据。仅在设置了 CONFIG_NET_UDP 时可用。

net virtual

显示和操作网络虚拟接口。仅在设置了 CONFIG_NET_L2_VIRTUAL 时可用。

net vlan

显示以太网虚拟局域网信息。仅在设置了 CONFIG_NET_VLAN 时可用。

net websocket

打印 websocket 信息。仅在设置了 CONFIG_WEBSOCKET_CLIENT 时可用。

net wg

显示 WireGuard VPN 信息并设置 VPN。仅在设置了 CONFIG_WIREGUARD 时可用。

Wi-Fi shell 提供了扫描、连接、断开和配置 Wi-Fi 网络的命令。已实现以下 Wi-Fi shell 命令：

wifi-shell 命令

命令

说明

wifi <cmd>

用于 Wi-Fi 网络连接、断开、扫描和配置的多个命令。仅在设置了 CONFIG_NET_L2_WIFI_SHELL 时可用。

wifi cred

显示/添加/删除 Wi-Fi 网络凭据。仅在设置了 CONFIG_WIFI_CREDENTIALS_SHELL 时可用。详细信息请参见 Wi-Fi 凭据库。

TLS 凭据 shell 提供了从易失性或受保护的后端存储中列出、添加、删除和获取 TLS 凭据信息的命令。已实现以下 TLS 凭据 shell 命令。这些命令仅在设置了 CONFIG_TLS_CREDENTIALS_SHELL 时可用。详细信息请参见 TLS 凭据 Shell。

tls-credentials-shell 命令

命令

说明

cred buf

缓冲凭据数据，以便随后添加。

cred add

添加一个 TLS 凭据。

cred del

删除一个 TLS 凭据。

cred get

获取一个 TLS 凭据的内容。

cred list

列出已存储的 TLS 凭据。
