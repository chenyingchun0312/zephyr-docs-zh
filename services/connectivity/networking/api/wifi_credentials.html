Wi-Fi 凭据库

Wi-Fi 凭据库提供了加载和存储 Wi-Fi® 网络凭据的方法。

概述

该库使用 Zephyr 的 settings 子系统或平台安全架构（PSA）内部可信存储（ITS）来存储凭据。它还在 RAM 中保存一份 SSID 列表，以 SSID 为键提供类似字典的访问方式。

配置

要使用 Wi-Fi 凭据库，请启用 CONFIG_WIFI_CREDENTIALS Kconfig 选项。

可以使用以下选项选择后端：

  • CONFIG_WIFI_CREDENTIALS_BACKEND_PSA - 包含 TF-M 分区（非 minimal 类型的 TF-M 配置文件）的非安全目标的默认选项。

  • CONFIG_WIFI_CREDENTIALS_BACKEND_SETTINGS - 安全目标的默认选项。

要配置网络的最大数量，请使用 CONFIG_WIFI_CREDENTIALS_MAX_ENTRIES Kconfig 选项。

IEEE 802.11 标准没有规定 SAE 密码的最大长度。要更改默认值，请使用 CONFIG_WIFI_CREDENTIALS_SAE_PASSWORD_LENGTH Kconfig 选项。

添加凭据

可以使用 wifi_credentials_set_personal() 和 wifi_credentials_set_personal_struct() 函数添加凭据。前者根据给定的字段构建内部使用的结构体，后者则直接接受该结构体。如果两次添加相同 SSID 的凭据，较旧的条目将被覆盖。

查询凭据

已知 SSID 时，可以使用 wifi_credentials_get_by_ssid_personal() 和 wifi_credentials_get_by_ssid_personal_struct() 函数查询凭据。

可以使用 wifi_credentials_for_each_ssid() 函数遍历所有已存储的凭据。遍历期间允许删除或覆盖凭据，因为这些操作不会改变内部索引。

删除凭据

可以使用 wifi_credentials_delete_by_ssid() 函数删除凭据。

限制

该库存在以下限制：

  • 尽管 IEEE 802.11 标准允许，但该库不支持零长度的 SSID。

  • Wi-Fi 保护访问（WPA）企业版凭据仅得到部分支持。

  • 可存储的网络数量在编译时固定。
