概述

Thread 是一种低功耗网状（mesh）网络技术，专为家庭自动化应用而设计。它是一种基于 IPv6 的标准，在 IEEE 802.15.4 协议之上使用 6LoWPAN 技术。借助 IP 连接，可以通过 Thread 边界路由器轻松地将 Thread 网状网络接入互联网。

Thread 规范提供了很高的网络安全性。使用 Thread 构建的网状网络是安全的：只有经过认证的设备才能加入网络，并且网状网络内的所有通信都经过加密。关于 Thread 协议的更多信息，请访问 Thread Group 网站。

Zephyr 集成了一个名为 OpenThread 的开源 Thread 协议实现，其文档见 OpenThread 网站。

互联网连接

要将网状网络接入互联网，需要一个 Thread 边界路由器。OpenThread 社区提供了 Thread 边界路由器的开源实现。关于如何搭建边界路由器，请参见 OpenThread 边界路由器指南。

示例用法

可以尝试将 OpenThread 与 Zephyr 的 Echo 服务器和 Echo 客户端示例一起使用，这些示例提供了开箱即用的 OpenThread 配置。要在这些示例中启用 OpenThread 支持，请使用 overlay-ot.conf 覆盖配置文件构建它们。详细信息请参见 Echo server (advanced) 和 Echo client (advanced) 示例。

Zephyr 还提供了 OpenThread shell，可用于测试和调试 Thread 及其底层的 IEEE 802.15.4 驱动。

Thread 相关 API

OpenThread 驱动 API

OpenThread L2 在内部使用 Zephyr 与协议无关的 IEEE 802.15.4 驱动 API。希望支持 OpenThread 的 驱动开发者 会关注此 API。

该驱动 API 属于 IEEE 802.15.4 驱动 API 子系统，并在其中有相应文档。

OpenThread L2 适配层 API

Zephyr 的 OpenThread L2 平台适配层将外部 OpenThread 协议栈与 Zephyr 与协议无关的 IEEE 802.15.4 驱动 API 粘合在一起。此 API 仅供 OpenThread L2 子系统贡献者 关注。

OpenThread 平台 API

OpenThread 平台 API 由 OpenThread 协议栈定义，并在 Zephyr 中作为 OpenThread 模块实现。应用程序可以直接使用该实现，也可以通过 OpenThread L2 适配层访问它。

使用 OpenThread L2 适配层 API

要通过 OpenThread L2 适配层使用 OpenThread 平台 API，请将 CONFIG_NET_L2_OPENTHREAD 和 CONFIG_NETWORKING 两个 Kconfig 选项都设置为 y。适配层将使用 modules/openthread/platform/radio.c 中的 OpenThread 射频 API 实现。在这种设置下，OpenThread 协议栈由适配层初始化和管理。

直接使用 OpenThread 平台 API

也可以绕过 OpenThread L2 适配层，直接使用 OpenThread 平台 API。不过，这种方式需要自行提供与所用射频驱动兼容的 OpenThread 射频 API 实现。

要直接使用 OpenThread 平台 API，请将 CONFIG_OPENTHREAD Kconfig 选项设置为 y，并且 不要 设置 CONFIG_NET_L2_OPENTHREAD。在这种情况下，必须使用自己的射频驱动实现 OpenThread 射频 API 中的以下函数：

  • otPlatRadioGetPromiscuous

  • otPlatRadioGetCcaEnergyDetectThreshold

  • otPlatRadioGetTransmitPower

  • otPlatRadioGetIeeeEui64

  • otPlatRadioSetPromiscuous

  • otPlatRadioGetCaps

  • otPlatRadioGetTransmitBuffer

  • otPlatRadioSetPanId

  • otPlatRadioEnable

  • otPlatRadioDisable

  • otPlatRadioReceive

  • otPlatRadioGetRssi

  • otPlatRadioGetReceiveSensitivity

  • otPlatRadioEnergyScan

  • otPlatRadioSetExtendedAddress

  • otPlatRadioSetShortAddress

  • otPlatRadioAddSrcMatchExtEntry

  • otPlatRadioTransmit

  • otPlatRadioClearSrcMatchShortEntries

  • otPlatRadioClearSrcMatchExtEntries

  • otPlatRadioEnableSrcMatch

  • otPlatRadioAddSrcMatchShortEntry

  • otPlatRadioClearSrcMatchShortEntry

  • otPlatRadioClearSrcMatchExtEntry

此外，还必须实现 OpenThread 射频 API 中的以下函数（参见 include/zephyr/net/openthread.h），用于处理射频初始化和事件处理：

  • platformRadioInit()

  • platformRadioProcess()

在这种方式下，要初始化 OpenThread 协议栈，可以在应用程序中调用 ot_platform_init() 函数，或者启用 CONFIG_OPENTHREAD_SYS_INIT Kconfig 选项，在系统启动期间自动初始化 OpenThread。初始化优先级可以通过 CONFIG_OPENTHREAD_SYS_INIT_PRIORITY Kconfig 选项设置。
