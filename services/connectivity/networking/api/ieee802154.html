简介

IEEE 802.15.4 是一项技术标准，定义了低速率无线个域网（LR-WPAN）的运行方式。关于该标准更详细的介绍，请参见 IEEE 802.15.4 维基百科文章。

该标准的最新版本可以通过 IEEE GET Program 获取。需要先创建一个免费的 IEEE 账户，然后即可下载。

我们目前遵循 IEEE 802.15.4-2020 规范。该版本向后兼容 IEEE 802.15.4-2015，后者的部分内容包含在 Thread 协议栈中。2020 版还纳入了先前被标准接受的扩展，即与工业物联网和自动化相关的 IEEE 802.15.4g（SUN FSK）和 IEEE 802.15.4e（TSCH）。关于 UWB 测距技术的最新进展，请参见 IEEE 802.15.4z，它尚未并入标准主线。

除非另有说明，文档中引用的标准章节均指 IEEE 802.15.4-2020 的章节、表格和图编号。

Zephyr 同时支持原生 IEEE 802.15.4 和 Thread，并支持 6LoWPAN。Zephyr 的 Thread 协议 实现基于 OpenThread。原生 IEEE 802.15.4 使用 6LoWPAN 中的 IPv6 头部压缩。

IEEE 802.15.4 管理 API

这是 IEEE 802.15.4 应用程序开发者 最关注的子系统专用 API，可用于在运行时配置 IEEE 802.15.4 子系统。对应用程序开发者而言，其他相关接口是常规的 shell、套接字、Kconfig 和设备树 API，可以在 Zephyr 通用的、与子系统无关的文档中查阅。请留意其中带有 IEEE802154/ieee802154 前缀的内容。

ieee802154_mgmt

IEEE 802.15.4 驱动 API

这是 IEEE 802.15.4 驱动开发者 最关注的 API。

ieee802154_driver

IEEE 802.15.4 L2 / 原生协议栈 API

本部分记录 IEEE 802.15.4 L2 原生协议栈，应用程序和驱动都不会直接访问它。它由 Zephyr 的上层网络层（L3 及以上）及其套接字和网络上下文抽象在内部调用。因此，该 API 只有 IEEE 802.15.4 子系统贡献者 才会关注。

ieee802154_l2

OpenThread L2 适配层 API

Zephyr 的 OpenThread L2 平台适配层把外部 OpenThread 协议栈与 Zephyr 中与协议无关的 IEEE 802.15.4 驱动 API 粘合在一起。该 API 只有 OpenThread L2 子系统贡献者 才会关注。

OpenThread API 属于 Thread 协议 子系统，并在该处有文档说明。
