数字信号处理（DSP）

  • 使用 zDSP

  • 针对特定架构进行优化

  • API 参考

DSP API 提供了一种与架构无关的信号处理方式。目前该 API 可在任何架构上运行，但很可能未经优化。各架构的状态如下：

架构

状态

ARC

已优化

ARM

已优化

ARM64

已优化

MIPS

未优化

POSIX

未优化

RISCV

未优化

RISCV64

未优化

SPARC

未优化

X86

未优化

XTENSA

未优化

使用 zDSP

zDSP 提供多种后端选项，会为应用程序自动选择。默认情况下，包含 CMSIS 模块即可让所有架构使用 zDSP API。可通过如下设置实现:

CONFIG_CMSIS_DSP=y

如果应用程序需要更多定制，可以启用 CONFIG_DSP_BACKEND_CUSTOM，这意味着由应用程序负责提供 zDSP 库的实现。

针对特定架构进行优化

如果某个架构显示为 Unoptimized，可以为其添加新的 zDSP 后端以提供更好的支持。为此，应在 subsys/dsp/Kconfig 中添加一个新的 Kconfig 选项及其所需依赖，并为 Kconfig choice DSP_BACKEND 设置 default。

接下来，应在 subsys/dsp/<backend>/ 下添加实现，并在 subsys/dsp/CMakeLists.txt 中链接。要添加架构特定的属性，应在 subsys/dsp/Kconfig 中添加对应的 Kconfig 选项，并用它们更新 include/zephyr/dsp/dsp.h 中的 DSP_DATA 和 DSP_STATIC_DATA。
