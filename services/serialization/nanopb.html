Nanopb

Nanopb 是 Google Protocol Buffers 的 C 语言实现。

前提条件

Nanopb 使用 protocol buffer 编译器生成源文件和头文件，请确保已安装 protoc 可执行文件且可以调用。

使用 apt 安装依赖：

sudo apt install protobuf-compiler

使用 brew 安装依赖：

brew install protobuf

使用 choco 安装依赖：

choco install protoc

配置

请按如下方式在 CMakeLists.txt 文件中包含 nanopb：

list(APPEND CMAKE_MODULE_PATH ${ZEPHYR_BASE}/modules/nanopb)
include(nanopb)

可以使用 CMake 函数 zephyr_nanopb_sources() 添加 proto 文件，该函数确保在构建指定目标之前生成相应的头文件和源文件。

Nanopb 提供了 生成器选项，可用于配置消息或字段，例如设置固定大小或完全跳过某些字段。

内部的 CMake 生成器带有一个扩展，可以使用 CMake 变量自动配置 *.options.in 文件。

用法示例请参见 samples/modules/nanopb/src/simple.options.in 和 samples/modules/nanopb/CMakeLists.txt。
