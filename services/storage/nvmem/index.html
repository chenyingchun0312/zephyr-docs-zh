非易失性存储器（NVMEM）

NVMEM 子系统为访问非易失性存储设备提供了通用接口。它对底层硬件进行抽象，并提供用于读写数据的统一 API。

关键概念

NVMEM 提供者

NVMEM 提供者（provider）是暴露 NVMEM 单元的驱动。例如，EEPROM 驱动就可以是 NVMEM 提供者。NVMEM 提供者负责向底层硬件读写数据。

NVMEM 单元

NVMEM 单元（cell）是一段非易失性存储区域。它在设备树中定义，具有偏移量、大小和只读状态等属性。

NVMEM 使用者

NVMEM 使用者（consumer）是使用 NVMEM 单元来存储或读取数据的驱动或应用程序。

配置

  • CONFIG_NVMEM：启用 NVMEM 子系统。

  • CONFIG_NVMEM_BBRAM：启用对电池供电 RAM（BBRAM）的 NVMEM 支持。

  • CONFIG_NVMEM_EEPROM：启用对 EEPROM 设备的 NVMEM 支持。

  • CONFIG_NVMEM_FLASH.*：配置对 Flash 设备的 NVMEM 支持。

  • CONFIG_NVMEM_OTP.*：配置对 OTP 设备的 NVMEM 支持。

设备树绑定

NVMEM 子系统依赖设备树绑定来定义 NVMEM 单元。下面的示例展示了如何在设备树中定义 NVMEM 提供者和单元：

&eeprom0 {
	nvmem-layout {
		compatible = "fixed-layout";
		#address-cells = <1>;
		#size-cells = <1>;

		mac_address: mac_address@0 {
			reg = <0x0 6>;
			#nvmem-cell-cells = <0>;
			read-only;
		};

		calibration_data: calibration_data@6 {
			reg = <0x6 100>;
			#nvmem-cell-cells = <0>;
		};
	};
};

reg 属性是一个数组，包含：

  • 要创建单元的存储器中的偏移量；

  • 单元的大小，以字节为单位。

#nvmem-cell-cells 描述 phandle 中属性项的数量，参见 说明符单元名称（*-cells），通常设为零。

随后，使用者可以像下面这样引用 NVMEM 单元：

my_consumer: my-consumer {
	compatible = "my,consumer";
	nvmem-cells = <&mac_address>, <&calibration_data>;
	nvmem-cell-names = "mac-address", "calibration-data";
};

用法示例

下面的示例展示了如何使用 NVMEM API 从 NVMEM 单元读取数据：

#include <zephyr/nvmem.h>

static const struct nvmem_cell mac_address =
	NVMEM_CELL_GET_BY_NAME(DT_NODELABEL(my_consumer), mac_address);

int main(void)
{
	uint8_t mac[6];
	int ret;

	if (!nvmem_cell_is_ready(&mac_address)) {
		printk("NVMEM cell is not ready\n");
		return -ENODEV;
	}

	ret = nvmem_cell_read(&mac_address, mac, 0, sizeof(mac));
	if (ret < 0) {
		printk("Failed to read MAC address: %d\n", ret);
		return ret;
	}

	/* ... */
}
