线程分析器

线程分析器模块会启用跟踪线程信息所需的全部 Zephyr 选项，例如线程栈大小使用情况和其他线程运行时统计信息。

分析按需进行，即在应用程序调用 thread_analyzer_run() 或 thread_analyzer_print() 时执行。

例如，要在启用线程分析器的情况下构建 synchronization 示例，请执行以下操作：

# From the root of the zephyr repository
west build -b qemu_x86 samples/synchronization/ -- -DCONFIG_QEMU_ICOUNT=n -DCONFIG_THREAD_ANALYZER=y \
-DCONFIG_THREAD_ANALYZER_USE_PRINTK=y -DCONFIG_THREAD_ANALYZER_AUTO=y \
-DCONFIG_THREAD_ANALYZER_AUTO_INTERVAL=5

配置

使用以下选项配置该模块。

CONFIG_THREAD_ANALYZER

启用该模块。

CONFIG_THREAD_ANALYZER_USE_PRINTK

使用 printk 输出线程统计信息。

CONFIG_THREAD_ANALYZER_USE_LOG

使用日志系统输出线程统计信息。

CONFIG_THREAD_ANALYZER_AUTO

自动运行线程分析器。使用此选项时，无需在应用程序中添加任何代码。

CONFIG_THREAD_ANALYZER_AUTO_INTERVAL

在自动模式下，模块在两次打印线程分析结果之间的睡眠时间。

CONFIG_THREAD_ANALYZER_AUTO_STACK_SIZE

线程分析器自动线程的栈大小。

CONFIG_THREAD_NAME

打印线程名称而不是线程 ID。

CONFIG_THREAD_RUNTIME_STATS

打印线程运行时数据，例如利用率。此选项由 CONFIG_THREAD_ANALYZER 自动选择。

CONFIG_THREAD_ANALYZER_LONG_FRAME_PER_INTERVAL

打印后重置最长帧（Longest Frame）统计值。使用 SCHED_THREAD_USAGE_ANALYSIS 获取线程的平均帧和最长帧统计信息时，每次打印线程统计信息后都将最长帧的值重置为零。这样可以观察最近一个间隔内的最长帧，而不是自启动以来的最长帧。

CONFIG_THREAD_ANALYZER_PRINT_THREAD_PRIORITY

打印每个线程的优先级。
