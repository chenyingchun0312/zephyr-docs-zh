Shell 管理

Shell 管理用于通过 SMP 协议向 shell 子系统传递命令。

Shell 管理组定义了以下命令：

Command ID

命令描述

0

执行 shell 命令行

执行 shell 命令行

该命令以类似于在 shell 中键入命令行的方式执行命令行，但请求和响应都通过 SMP 传输。

执行 shell 命令行请求

执行命令请求头部：

OP

Group ID

Command ID

2

9

0

请求的 CBOR 数据：

{
    (str)"argv"     : [
        (str)<cmd>
        (str,opt)<arg>
        ...
    ]
}

其中：

"argv"

由表示命令及其参数的字符串组成的数组。

<cmd>

要执行的命令。

<arg>

命令的可选参数。

执行 shell 命令行响应

执行命令行响应头部字段：

OP

Group ID

Command ID

3

9

0

成功响应的 CBOR 数据：

{
    (str)"o"            : (str)
    (str)"ret"          : (int)
}

出错时，CBOR 数据采用以下形式：

{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}

{
    (str)"rc"       : (int)
}

其中：

"o"

命令输出。

"ret"

shell 命令执行的返回码。

"err" -> "group"

基于组的错误码所属的 mcumgr_group_t 组。仅在使用 SMP 版本 2 且返回错误时出现。

"err" -> "rc"

包含基于组的错误码的索引。仅在使用 SMP 版本 2 且该值非零（出错）时出现。

"rc"

mcumgr_err_t，仅在使用 SMP 版本 1 且该值非零（出错）时，或在使用 SMP 版本 2 时出现 SMP 错误的情况下出现。

备注

在较旧版本的 Zephyr 中，"rc" 既用作 mcumgr 状态码，也用作 shell 命令执行的返回码；可以通过启用 CONFIG_MCUMGR_GRP_SHELL_LEGACY_RC_RETURN_CODE 恢复这一旧行为
