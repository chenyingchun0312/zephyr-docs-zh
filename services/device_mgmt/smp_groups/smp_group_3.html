设置（配置）管理组

设置管理组（在原始 MCUmgr 仓库中称为配置管理器）定义了以下命令：

Command ID

命令描述

0

读/写设置

1

删除设置

2

提交设置

3

加载/保存设置

注意，Zephyr 版本增加了原始上游版本不支持的额外命令和功能，不过原始客户端的读/写功能应当仍然可用。

读/写设置命令

读/写设置命令用于更新设备上的设置条目，或者从设备获取某个设置的当前值。

读取设置请求

读取设置请求头部字段：

OP

Group ID

Command ID

0

3

0

请求的 CBOR 数据：

{
    (str)"name"         : (str)
    (str,opt)"max_size" : (uint)
}

其中：

"name"

要获取的设置的名称字符串

"max_size"

可选，要返回数据的最大大小

读取设置响应

读取设置响应头部字段：

OP

Group ID

Command ID

1

3

0

成功响应的 CBOR 数据：

{
    (str)"val"          : (bstr)
    (str,opt)"max_size" : (uint)
}

出错时，CBOR 数据采用以下形式：

{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}

{
    (str)"rc"       : (int)
}

其中：

"val"

返回数据的二进制字符串。注意，无法通过它指定底层数据类型，客户端必须事先知道。

"max_size"

当支持的最大数据大小小于请求的最大数据大小时设置该字段，其中包含设备支持的最大数据大小，相当于 kconfig:option:CONFIG_MCUMGR_GRP_SETTINGS_NAME_LEN。

"err" -> "group"

基于组的错误码所属的 mcumgr_group_t 组。仅在使用 SMP 版本 2 且返回错误时出现。

"err" -> "rc"

包含基于组的错误码的索引。仅在使用 SMP 版本 2 且该值非零（出错）时出现。

"rc"

mcumgr_err_t，仅在使用 SMP 版本 1 且该值非零（出错）时，或在使用 SMP 版本 2 时出现 SMP 错误的情况下出现。

设置访问回调

MCUmgr 提供了一个设置访问回调（有关回调的详细信息，请参阅 MCUmgr 回调），使应用程序/模块能够知道何时使用了设置管理命令，并可选择阻止访问（例如通过某种安全机制）。可以通过 CONFIG_MCUMGR_GRP_SETTINGS_ACCESS_HOOK 启用该回调，并使用事件 MGMT_EVT_OP_SETTINGS_MGMT_ACCESS 注册，提供的回调数据为 settings_mgmt_access。
