统计信息管理

统计信息管理用于获取由 Zephyr 统计子系统收集的数据，该子系统通过 CONFIG_STATS 启用。

统计信息管理组定义了以下命令：

Command ID

命令描述

0

组数据

1

列出组

统计信息：组数据

该命令用于获取由名称指定的组的数据。该名称是收集统计信息的模块中通过 STATS_INIT_AND_REG 宏或 stats_init_and_reg() 函数调用注册的组名之一。

统计信息：组数据请求

统计信息组数据请求头部：

OP

Group ID

Command ID

0

2

0

请求的 CBOR 数据：

{
    (str)"name" :  (str)
}

其中：

"name"

组名。

统计信息：组数据响应

统计信息组数据响应头部：

OP

Group ID

Command ID

1

2

0

成功响应的 CBOR 数据：

{
    (str)"name"     : (str)
    (str)"fields"   : {
        (str)<entry_name> : (uint)
        ...
    }
}

出错时，CBOR 数据采用以下形式：

{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}

{
    (str)"rc"       : (int)
}

其中：

"name"

响应中所含数据对应的组名。

"fields"

组内条目的映射，由若干对组成，每对将条目名称映射到它在统计信息中所代表的值。

<entry_name>

单个条目到值的映射；值被硬编码为 CBOR 意义上的无符号整数类型。

"err" -> "group"

基于组的错误码所属的 mcumgr_group_t 组。仅在使用 SMP 版本 2 且返回错误时出现。

"err" -> "rc"

包含基于组的错误码的索引。仅在使用 SMP 版本 2 且该值非零（出错）时出现。

"rc"

mcumgr_err_t，仅在使用 SMP 版本 1 且该值非零（出错）时，或在使用 SMP 版本 2 时出现 SMP 错误的情况下出现。

统计信息：组列表

该命令用于获取设备上收集的统计信息组的列表。该列表由收集统计信息的模块中通过 STATS_INIT_AND_REG 宏或 stats_init_and_reg() 函数调用为各组指定的名称组成；这意味着该命令可视为可选的，因为构建中会包含哪些组在编译时就已知道，发出查询之前无需列出它们。

统计信息：组列表请求

统计信息组列表请求头部：

OP

Group ID

Command ID

0

2

1

该命令发送一个空的 CBOR 映射作为数据。

统计信息：组列表响应

统计信息组列表请求头部：

OP

Group ID

Command ID

1

2

1

成功响应的 CBOR 数据：

{
    (str)"stat_list" :  [
        (str)<stat_group_name>, ...
    ]
}

出错时，CBOR 数据采用以下形式：

{
    (str)"err" : {
        (str)"group"    : (uint)
        (str)"rc"       : (uint)
    }
}

{
    (str)"rc"       : (int)
}

其中：

"stat_list"

表示组名的字符串数组；如果没有任何组，该数组可以为空。

"err" -> "group"

基于组的错误码所属的 mcumgr_group_t 组。仅在使用 SMP 版本 2 且返回错误时出现。

"err" -> "rc"

包含基于组的错误码的索引。仅在使用 SMP 版本 2 且该值非零（出错）时出现。

"rc"

mcumgr_err_t，仅在使用 SMP 版本 1 且该值非零（出错）时，或在使用 SMP 版本 2 时出现 SMP 错误的情况下出现。
