测试套件

TF-M 包含两组测试套件：

  • tf-m-tests：标准的 TF-M 专用回归测试

  • psa-arch-tests：针对特定 PSA API（安全存储等）的测试套件

这些测试套件可以通过 samples/tfm_integration 文件夹中相应的示例应用程序在 Zephyr 中运行。

TF-M 回归测试

回归测试套件可以通过 tests/modules/tf-m/regression 测试运行。

它通过 PSA API 测试跨越 NS/S 边界的各种服务和通信机制，可作为一项有用的完整性检查，确认 NS RTOS（这里是 Zephyr）与安全应用程序（TF-M）是否正确集成。

PSA 架构测试

PSA 架构测试套件可通过 TF-M 平台安全架构测试示例 获取，其中包含多个测试套件，可用于验证安全应用程序是否遵循 PSA API 规范；TF-M 就是平台安全架构（PSA）的一种实现。

每次只能运行其中一个套件，可用的测试套件由 CONFIG_TFM_PSA_TEST_* Kconfig 标志描述：

用途

要为特定的开发板、RTOS（这里是 Zephyr）和 PSA 实现（这里是 TF-M）获得 PSA 认证，需要这些测试套件的输出结果。

对于对 TF-M 做出实质性修改的 PR，例如启用新的 TF-M 开发板目标或修改核心 TF-M 模块，这些测试套件也是很有用的验证用例。在发布新的 PR（例如新的开发板支持）之前，一般都应运行它们作为一致性检查。
