TF-M 要求

以下是部分可与 TF-M 配合使用的开发板：

开发板

NSPE 开发板名称

ARM MPS2+ AN521

mps2/an521/cpu0/ns （支持 qemu）

MPS3 FPGA/Corstone FVP

  • mps3/corstone300/fvp/ns （支持 armfvp）

  • mps3/corstone310/fvp/ns （支持 armfvp）

MPS4 Corstone FVP

  • mps4/corstone315/fvp/ns （支持 armfvp）

  • mps4/corstone320/fvp/ns （支持 armfvp）

BL5340 DVK

bl5340_dvk/nrf5340/cpuapp/ns

LPCXPRESSO55S69

lpcxpresso55s69_ns

nrf9160dk_nrf9160

nrf9160dk/nrf9160/ns

nRF5340 DK

nrf5340dk/nrf5340/cpuapp/ns

B-U585I-IOT02A Discovery kit

b_u585i_iot02a/stm32u585xx/ns

Nucleo L552ZE Q

nucleo_l552ze_q/stm32l552xx/ns

STM32L562E-DK Discovery

stm32l562e_dk/stm32l562xx/ns

V2M Musca B1

v2m_musca_b1/musca_b1/ns

要确认某块开发板在其输出中支持 TF-M，请检查该开发板的默认配置中 CONFIG_TRUSTED_EXECUTION_NONSECURE 是否设置为 y。

软件要求

构建 TF-M 二进制文件所需的 Python 模块列在 TF-M 仓库的 tools/requirements.txt 中。

可以通过以下命令安装：

$ pip3 install -r "$(west list trusted-firmware-m -f '{abspath}')/tools/requirements.txt"

TF-M 的签名工具使用这些模块来准备固件镜像，以供引导加载程序验证。

在某些平台上，为 QEMU 生成二进制文件以及合并已签名的安全和非安全二进制文件的过程中，还需要用到 srec_cat 工具。

在 Linux 上可以通过以下命令安装：

$ sudo apt-get install srecord

在 OS X 上可以通过以下命令安装：

$ brew install srecord

对于基于 Windows 的系统，请确保系统路径中有该工具的副本。例如，请参阅：SRecord for Windows
