输入

输入子系统提供了一套 API，用于将输入设备产生的输入事件分发给应用程序。

输入事件

该子系统围绕 input_event 结构体构建。一个输入事件表示单个事件实体的变化，例如单个按键的状态，或单个轴上的移动。

input_event 结构体描述具体的事件，并包含一个同步位，用于表示设备已达到稳定状态，例如多轴设备的多个轴对应的事件均已上报时。

输入设备

输入设备可以使用 input_report() 或任何相关函数直接上报输入事件；例如按键或其他开关类输入实体会使用 input_report_key()。

复杂设备可能组合使用多个事件，并在输出稳定后设置 sync 位。

input_report* 系列函数接受一个 device 指针，用于指明是哪个设备上报了事件，订阅者可借此只接收来自特定设备的事件。如果事件没有实际关联的设备，可以将其设为 NULL，此时只有未设置设备过滤器的订阅者才会收到该事件。

应用程序 API

应用程序可以使用 INPUT_CALLBACK_DEFINE 宏注册回调。如果指定了设备节点，则只有来自该设备的事件才会调用回调，否则回调会收到系统中的所有事件。这是唯一支持的过滤方式，任何更复杂的过滤逻辑都必须在回调内部实现。

根据 CONFIG_INPUT_MODE 选项，该子系统可以同步运行，也可以使用事件队列。如果使用输入线程，所有事件都会被加入队列，并在公共的 input 线程中执行。如果不使用该线程，回调会直接在输入驱动的上下文中调用。

同步模式可用于简单的应用程序以保持最小的资源占用，也可用于已有事件模型的复杂应用程序，此时回调只是一个包装，把事件转发到更复杂的、应用程序特定的事件系统中。

HID 码映射

输入设备的一个常见用途是生成 HID 报告。为此，可以使用 input_to_hid_code() 和 input_to_hid_modifier() 函数将输入码映射为 HID 码和修饰键。

通用驱动

  • adc-keys：用于连接到电阻梯的按键。

  • analog-axis：用于连接到 ADC 输入的绝对位置设备（摇杆、滑块等）。

  • gpio-kbd-matrix：用于通过 GPIO 连接的键盘矩阵。

  • gpio-keys：用于直接连接到 GPIO 的开关，实现了按键消抖。

  • gpio-qdec：用于通过 GPIO 连接的正交编码器。

  • input-keymap：将键盘矩阵的行/列/触摸事件映射为按键事件。

  • zephyr,input-longpress：监听按键事件，针对短按和长按发出事件。

  • zephyr,input-double-tap：监听按键事件，针对双击发出事件，并可选地针对单击发出事件

  • zephyr,lvgl-button-input zephyr,lvgl-encoder-input zephyr,lvgl-keypad-input zephyr,lvgl-pointer-input：监听输入事件，并将其转换为各种类型的 LVGL 输入设备。
