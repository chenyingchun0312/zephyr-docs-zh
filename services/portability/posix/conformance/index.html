备注

有些功能超出了 Zephyr 当前设计和能力的范围，因此可能表现出未定义的行为。例如，多进程、临时内存映射、多用户或正则表达式等功能，在资源占用小的嵌入式系统中并不常见。这类未定义行为用 †（剑号）标记。更多细节见 此处。

备注

各种 POSIX 选项或选项组中列出的功能，可以全部或部分由符合标准的 C 库实现提供。这包括（但不限于）POSIX 对 ISO C 标准的扩展（CX）。
