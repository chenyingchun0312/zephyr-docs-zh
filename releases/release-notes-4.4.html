Zephyr 4.4.0

我们很高兴地宣布 Zephyr 4.4.0 版本正式发布。

本版本的主要改进包括：

OpenRISC 支持

Zephyr 现已支持 OpenRISC architecture。

工具链更新：Zephyr SDK 1.0 与 C17

Zephyr 4.4 是首个支持 Zephyr SDK 1.0 的版本，该 SDK 提供升级后的 GNU 工具链、实验性的 Clang/LLVM 支持，以及多平台的 QEMU 和 OpenOCD 主机工具。

Zephyr 现在默认以 C17 作为最低要求的 C 标准版本。

网络改进

Wi-Fi 管理协议栈现已支持 Wi-Fi P2P（Wi-Fi Direct），设备无需传统接入点即可相互发现并直接连接。

网络协议栈还新增了对 WireGuard VPN 的支持，可实现安全、低开销的隧道传输。

USB 主机

实验性的 USB 主机支持得到大幅扩展，新增了主机类驱动框架，并支持在作为 USB 主机的 Zephyr 设备上使用 UVC 摄像头。

新的驱动类别

Zephyr 4.4 新增了多个驱动 API，包括：

  • 一次性可编程（OTP）存储设备，用于写入和读取永久性的设备数据；

  • 生物识别 API，用于集成指纹扫描器、人脸识别系统等生物识别传感器；以及

  • 唤醒控制器（WUC）API，用于管理可使系统退出低功耗状态的唤醒源。

Zbus 异步监听器与代理（proxy agent）

Zbus 异步监听器通过工作队列实现非阻塞的观察者回调。

Zbus 代理 通过 IPC 将发布-订阅消息机制扩展到 CPU 与域的边界之外。

基于负载压力的 CPU 频率调节

实验性的 CPU 频率调节 子系统现已包含 基于压力的策略，可根据调度器负载调整 CPU 频率。

ARM Cortex-M 上下文切换性能改进

ARM Cortex-M 新增了一种上下文切换实现，可通过 CONFIG_USE_SWITCH 启用，性能提升明显。

NAND Flash 支持

新增的闪存转换层（FTL）磁盘驱动（zephyr,ftl-dhara）提供磨损均衡和坏块管理，使 NAND Flash 存储器可以作为标准磁盘设备使用。

开发者体验改进

本版本为开发和测试流程新增了多项工具和改进：

  • 新增的 仪表板 将 RAM 和 ROM 占用、设备树配置、子系统初始化级别等构建信息汇总到一份报告中。

  • 新增了一个用于 QEMU 目标的显示驱动，便于在无法使用原生模拟器的环境中开发基于显示的应用程序。

  • 新增的堆加固机制（CONFIG_SYS_HEAP_HARDENING）提供多个级别的运行时保护，防止堆损坏。

  • 新增的 基于作用域的清理辅助工具 在 C 语言中提供 RAII/defer 风格的离开作用域时自动清理功能。

  • 新增的 ztest 基准测试框架 提供了一种标准化方式来创建精确到周期的基准测试，支持自动数据采集、开销补偿和统计报告。

Bluetooth LE 主机认证

本版本包含已成功通过认证的蓝牙低功耗（LE）主机协议栈，与 Bluetooth 核心规范 6.2 保持一致。认证范围涵盖核心组件（GAP、ATT、GATT、L2CAP、SM）以及设备信息服务（DIS）。认证列表及对应的设计编号（DN）见：https://qualification.bluetooth.com/ListingDetails/332380

扩展的开发板支持

本版本新增了对 121 款 新开发板 和 31 款 新扩展板 的支持。

将应用程序从 Zephyr v4.3.0 迁移到 Zephyr v4.4.0 时所需或建议的修改概览，请参阅单独的 迁移指南。

    • 已移除 CONFIG_LINKER_USE_PINNED_SECTION 和 CONFIG_LINKER_GENERIC_SECTIONS_PRESENT_AT_BOOT。它们启用的选择性内核固定（pinning）模型在任何按需分页换出算法下都不安全：CPU 异常分派可能访问线程特权栈中不属于显式 __pinned_* 集合的页面，如果该页面已被换出，在 x86 上会升级为 #DF，在 ARM64 上会导致嵌套中止（GitHub #108773）。现在 Zephyr 内核镜像始终驻留在物理内存中；按需分页仅适用于匿名映射（k_mem_map()）和显式的 __ondemand_* 链接器段。

    • 已移除 __pinned_func、__pinned_data、__pinned_rodata、__pinned_bss 和 __pinned_noinit 属性宏，以及它们的汇编别名 PINNED_TEXT、PINNED_RODATA、PINNED_DATA、PINNED_BSS 和 PINNED_NOINIT。
