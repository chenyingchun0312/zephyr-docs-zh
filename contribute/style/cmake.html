CMake 风格指南

这些指南中的一部分由 CI 中的 CMakeStyle 合规性检查强制执行。可以使用 scripts/cmake/cmake_style.py 在本地运行相同的检查（对于目录，会递归查找其中的 CMakeLists.txt 和 *.cmake 文件）：

pip install tree-sitter tree-sitter-cmake
./scripts/cmake/cmake_style.py path/to/CMakeLists.txt
./scripts/cmake/cmake_style.py drivers/

通用格式

  • 缩进：使用 2 个空格 缩进。避免使用制表符，以确保在不同环境中保持一致。

  • 行长度：尽可能将行长度限制在 100 列 以内。

  • 空行：使用空行分隔 CMake 文件中逻辑上不同的部分。

  • 左括号前不加空格：不要在命令和左圆括号之间添加空格。应使用 if(...) 而不是 if (...)。

    # Good:
if(ENABLE_TESTS)
  add_subdirectory(tests)
endif()

# Bad:
if (ENABLE_TESTS)
  add_subdirectory(tests)
endif()

命令和语法

  • 命令使用小写：始终使用 小写 的 CMake 命令（例如 add_executable、find_package）。这样可以提高可读性和一致性。

    # Good:
add_library(my_lib STATIC src/my_lib.cpp)

# Bad:
ADD_LIBRARY(my_lib STATIC src/my_lib.cpp)

    由 CMake 模块定义的命令，以及扩展现有大小写混合命令的 Zephyr 或 sysbuild 扩展命令属于例外：它们遵循大小写混合的 Module_Action 命名约定，必须使用其规范的大小写拼写（例如 CMake 的 ExternalProject_Add 由 Zephyr 的 ExternalZephyrProject_Add 扩展）。CMakeStyle 检查对这些命令豁免小写规则。对小写命令的扩展仍保持小写（例如 add_dependencies 由 sysbuild 的 sysbuild_add_dependencies 扩展）。

  • 每行一个文件参数：将文件参数拆分到多行，以便于浏览和识别每个源文件或条目。

    # Good:
target_sources(my_target PRIVATE
  src/file1.cpp
  src/file2.cpp
)

 # Bad:
target_sources(my_target PRIVATE src/file1.cpp src/file2.cpp)

变量命名

  • 缓存变量或在多个 CMake 文件之间共享的变量使用大写：使用 option 或 set(... CACHE ...) 定义缓存变量时，使用 大写名称。

    option(ENABLE_TESTS "Enable test suite" ON)
set(CMAKE_CXX_STANDARD 17 CACHE STRING "C++ standard version")

  • 局部变量使用小写：CMake 文件内的局部变量使用 小写 或 snake_case。

    set(output_dir "${CMAKE_BINARY_DIR}/output")

  • 前缀保持一致：为变量使用一致的前缀以避免名称冲突，在大型项目中尤其如此。

    set(MYPROJECT_SRC_DIR "${CMAKE_SOURCE_DIR}/src")

引号

  • 为字符串和变量加引号：始终为字符串字面量和变量加引号，以防止意外行为，在处理可能包含空格的路径或参数时尤其如此。

    # Good:
set(my_path "${CMAKE_SOURCE_DIR}/include")

# Bad:
set(my_path ${CMAKE_SOURCE_DIR}/include)

  • 布尔值不加引号：对于布尔值（ON、OFF、TRUE、FALSE），不要加引号。

    option(BUILD_SHARED_LIBS "Build shared libraries" OFF)

避免硬编码路径

  • 使用 CMake 变量（CMAKE_SOURCE_DIR、CMAKE_BINARY_DIR、CMAKE_CURRENT_SOURCE_DIR）代替硬编码路径。

    set(output_dir "${CMAKE_BINARY_DIR}/bin")

条件逻辑

  • 使用 if、elseif 和 else 并正确缩进，最后用 endif() 结束。

    if(ENABLE_TESTS)
  add_subdirectory(tests)
endif()

文档

  • 使用注释说明 CMake 文件中的复杂逻辑。

    # Find LlvmLld components required for building with llvm
find_package(LlvmLld 14.0.0 REQUIRED)
