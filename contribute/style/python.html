Python 风格指南

Python 代码应按照符合 PEP 8 的方式进行格式化。Zephyr 使用 ruff formatter 来实现这一点。这个带有明确主张的格式化工具旨在实现一致性、通用性和可读性，并减少 git diff。

要应用该格式化工具，请运行：

ruff check --select I --fix <file> # Sort imports
ruff format <file>

Ruff 配置

在默认设置之上应用了少量选项：

  • 行长度不超过 100 列。

  • 单引号 ' 和双引号 " 两种风格均可使用。

  • 行尾会被转换为 \n，即 Unix 上的默认行尾。

排除的文件

CI 会强制执行该格式化工具，但仅针对新添加的 Python 文件，因为引入该工具时项目已有大量 Python 代码。.ruff-excludes.toml 文件中有一个 [format] 节，列出了当前所有被排除的文件。鼓励贡献者在修改被排除的文件时，将其从列表中移除，并在单独的提交中对其进行格式化。
