Visual Studio Code

Visual Studio Code（简称 VS Code）是一款流行的跨平台 IDE，支持 C 项目，并拥有丰富的扩展。

本指南介绍如何在 VS Code 中为 Zephyr 的 Blinky 示例设置 VS Code。

这些说明已在 Linux 上测试过，但 macOS 和 Windows 上的步骤应当相同，只需根据需要调整路径即可。

获取 VS Code

Download VS Code 并安装。

通过左侧面板中的 Extensions 市场安装所需的扩展。搜索 C/C++ Extension Pack 并安装。

初始化新的工作区

本指南详细介绍如何配置 Blinky 示例应用程序，但对于任何 Zephyr 项目和 工作区布局，步骤都是类似的。

开始之前，请按照 入门指南 中的说明，确保已有可用的 Zephyr 开发环境。

在 VS Code 中打开项目

  1. 在 VS Code 中，从主菜单选择 File ‣ Open Folder。

  2. 导航到你的 Zephyr 工作区并选择它（如果按照入门指南操作，即主目录下的 zephyrproject 文件夹）。

  3. 如有提示，启用工作区信任。

生成编译命令

为了支持代码导航和代码检查（linting）功能，必须先编译一次项目，生成 compile_commands.json 文件，为 C/C++ 扩展提供所需信息（例如包含路径）。可以在 VS Code 的内置终端中完成：从顶部菜单或命令面板（Ctrl+Shift+P）选择 Terminal ‣ New Terminal，然后输入：

$ cd zephyr
$ west build -p always -b native_sim/native/64 samples/basic/blinky

配置 C/C++ 扩展

现在需要指向生成的 compile_commands.json 文件，以便在 VS Code 中启用代码检查和代码导航。

  1. 在 VS Code 顶部菜单中进入 File ‣ Preferences ‣ Settings。

  2. 搜索参数 C_Cpp > Default: Compile Commands，并将其值设置为 zephyr/build/compile_commands.json。

    代码中的检查错误此时应已消除，并且应该可以在代码中导航了。
