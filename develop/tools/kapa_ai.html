Kapa.ai 文档助手

Zephyr 文档网站集成了一个由 Kapa.ai 驱动的 AI 助手。该助手基于 Zephyr 自身的文档、源代码和 GitHub 活动进行训练（见下文 Data sources），可以用自然语言回答自由提出的问题，并注明构建每个答案时所用的文档页面和资源。

同一知识库还通过一个 Model Context Protocol（MCP）服务器对外提供，外部 AI 助手和 IDE 可以直接查询 Zephyr 知识（见 Using the MCP server）。

备注

答案由 AI 生成，可能存在不准确之处。重要信息请务必对照官方文档核实，并将该助手视为起点，而非权威来源。

使用聊天机器人

文档的每个页面上都可以使用聊天机器人：

  • 点击页面底部显示的聊天机器人按钮，或者

  • 在任意位置按 Ctrl+K（macOS 上为 Cmd+K）打开它。

助手会在侧边栏中打开，你可以用平实的语言提问，例如 “如何在设备树中配置 UART 设备？” 或 “工作队列和线程有什么区别？”。答案中包含指向相关文档页面、GitHub issue 或源文件的链接，方便你深入了解。

首次使用该助手时，会显示一次性的同意界面，说明该功能的工作方式以及收集哪些数据。请参阅下文的 Privacy 一节。

小技巧

你不必用英语提问。助手会检测你使用的语言并以同一种语言回答，因此你可以用自己偏好的语言（英语、中文、西班牙语、日语、法语、德语等）与它交流。

AI 驱动的搜索

除聊天机器人外，Kapa.ai 还可以驱动文档搜索框：

  1. 点击搜索框旁边的齿轮（Search settings）图标。

  2. 从菜单中选择 Kapa AI search。

  3. 输入查询内容并按 Enter。

此时你的查询将由 AI 助手回答，而不是使用内置的关键字搜索。你的选择会被记住，之后的搜索会一直使用你选择的引擎，直到你改回去为止。

使用 MCP 服务器

Kapa.ai 还将 Zephyr 知识库以 MCP 服务器的形式对外提供。MCP 是一项开放标准，可让 AI 助手和支持 AI 的 IDE 连接外部工具和知识来源。将 Zephyr MCP 服务器添加到你的助手后，它就能代表你查询最新的 Zephyr 文档、源代码和 GitHub 活动。

该服务器位于以下端点，使用可流式传输的 HTTP 传输方式：

https://zephyrproject.mcp.kapa.ai

具体的配置步骤取决于你使用的 MCP 客户端。大多数客户端会读取一个 JSON 配置文件，其中包含类似下面的 mcpServers 部分：

{
  "mcpServers": {
    "zephyr-docs": {
      "url": "https://zephyrproject.mcp.kapa.ai"
    }
  }
}

有些客户端则要求通过本地 stdio 桥接程序（例如 mcp-remote）启动服务器：

{
  "mcpServers": {
    "zephyr-docs": {
      "command": "npx", "args": ["-y", "mcp-remote", "https://zephyrproject.mcp.kapa.ai"]
    }
  }
}

关于配置文件的确切位置和语法，请参阅你所用 MCP 客户端（AI 编程助手、IDE 扩展等）的文档。

小技巧

将 MCP 服务器连接到 AI 编程助手后，它就能回答 Zephyr 相关问题，并以项目的实际文档和源代码为依据给出代码建议，而不是只依赖其训练数据。

隐私

该助手会根据 Zephyr 文档、源代码以及 GitHub issue 和 PR，利用你的问题提供答案。问题和交互可能会被匿名收集和分析，以找出需要澄清的地方，从而帮助改进文档。不会收集任何个人身份信息。
