macOS 替代安装说明

关于 Gatekeeper 的重要说明

从 macOS 10.15 Catalina 开始，从 macOS 终端应用程序（或其他任何终端模拟器）启动的应用程序，与从 Dock 启动的应用程序一样，受相同的系统安全策略约束。这意味着如果使用 Web 浏览器下载可执行二进制文件，macOS 默认不允许在终端中运行它们。要解决这个问题，可以采用以下两种方法之一：

  • 运行 xattr -r -d com.apple.quarantine /path/to/folder，其中 path/to/folder 是要运行的可执行文件所在文件夹的路径。

  • 打开 System Preferences ‣ Security and Privacy ‣ Privacy，然后向下滚动到“Developer Tools”（开发者工具）。接着解锁以便进行更改，并勾选所用终端模拟器对应的复选框。此设置将应用于从该终端程序启动的所有可执行文件。

注意，本节 不 适用于通过 Homebrew 安装的可执行文件，因为 brew 本身会自动解除它们的隔离。不过，本节内容适用于大多数 工具链。

MacPorts 用户的补充说明

虽然本指南没有正式支持 MacPorts，但可以在 macOS 上使用 MacPorts 代替 Homebrew 来获取所有必需的依赖项。另请注意，可能需要安装 rust 和 cargo，才能正确安装 Python 依赖项。
