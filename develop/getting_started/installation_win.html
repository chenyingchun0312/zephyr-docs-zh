Windows 替代安装说明

Windows 10 WSL（适用于 Linux 的 Windows 子系统）

如果运行的是较新版本的 Windows 10，可以利用其内置功能，在标准命令提示符中直接原生运行 Ubuntu 二进制文件。这样无需搭建虚拟机即可使用 Zephyr SDK 等软件。

警告

Windows 10 1803 版本存在一个会导致 CMake 无法正常工作的问题，该问题已在 1809 版本（及更高版本）中修复。更多信息请参见 Zephyr Issue 10420。

  1. Install the Windows Subsystem for Linux (WSL)。

    备注

    Zephyr SDK 要正常工作，需要 Windows 10 build 15002 或更高版本。可以在系统设置的“关于你的电脑”（About your PC）部分查看当前运行的 Windows 10 build。如果运行的是较旧的 Windows 10 build，可能需要安装创意者更新（Creator's Update）。

  2. 按照 安装 Linux 主机依赖项 文档中的 Ubuntu 说明操作。
