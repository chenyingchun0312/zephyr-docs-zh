West 故障排除

本页介绍 west 的常见问题及其解决方法。

west update 获取失败

排查获取问题的一个好方法是以详细模式运行 west update，例如：

west -v update

输出中包含 west 运行的 Git 命令及其输出。请查找类似下面的内容：

=== updating your_project (path/to/your/project):
west.manifest: your_project: checking if cloned
[...other west.manifest logs...]
--- your_project: fetching, need revision SOME_SHA
west.manifest: running 'git fetch ... https://github.com/your-username/your_project ...' in /some/directory

上面最后一行中的 git fetch 命令示例就是需要成功执行的命令。

一种办法是进入 /path/to/your/project，复制粘贴并运行完整的 git fetch 命令，然后参考你所用凭据存储助手的文档从那里开始调试。

如果你处在公司防火墙之后，可能存在代理或其他问题，此时 curl -v FETCH_URL （用于 HTTPS URL）或 ssh -v FETCH_URL （用于 SSH URL）可能会有帮助。

如果直接运行 git fetch 命令时能够成功执行且不提示输入密码，那么在同一个 shell 中运行 west update 时也无需输入密码。

"'west' is not recognized as an internal or external command, operable program or batch file.'

在 Windows 上，这意味着要么没有安装 west，要么 PATH 环境变量中不包含 pip 安装 west.exe 的目录。

首先，确保已经安装了 west；请参阅 安装 west。然后尝试在新的 cmd.exe 窗口中运行 west。如果仍然不行，请继续阅读。

你需要找到包含 west.exe 的目录，然后将其添加到 PATH 中。（安装 Python 和 pip 时应该已经为你完成了对 PATH 的这一修改，因此通常不需要执行这些步骤。）

在 cmd.exe 中运行以下命令：

pip3 show west

然后：

  1. 在输出中查找类似 Location: C:\foo\python\python38\lib\site-packages 的一行。你计算机上的具体位置会有所不同。

  2. 在 scripts 目录 C:\foo\python\python38\scripts 中查找名为 west.exe 的文件。

    重要

    注意，pip3 show 输出中的 lib\site-packages 被换成了 scripts！

  3. 如果在 scripts 目录中看到了 west.exe，请使用类似下面的命令将 scripts 的完整路径添加到 PATH 中：

    setx PATH "%PATH%;C:\foo\python\python38\scripts"

    不要直接复制粘贴此命令。在你的系统上，scripts 目录的位置会有所不同。

  4. 关闭 cmd.exe 窗口并打开一个新窗口。现在应该可以运行 west 了。

"invalid choice: 'build'"（或 'flash' 等）

如果在尝试运行 Zephyr 扩展命令（例如 west flash、west build 等）时看到类似下面的意外错误：

$ west build [...]
west: error: argument <command>: invalid choice: 'build' (choose from 'init', [...])

$ west flash [...]
west: error: argument <command>: invalid choice: 'flash' (choose from 'init', [...])

最可能的原因是你在 west 工作区 之外运行了该命令。West 需要知道工作区的位置才能找到 扩展。

要解决此问题，有两种选择：

  1. 在工作区内运行该命令（例如在 入门 时创建的 zephyrproject 目录中）。

    例如，在工作区内创建构建目录，或者在工作区内运行 west flash --build-dir YOUR_BUILD_DIR。

  2. 设置 ZEPHYR_BASE 环境变量，然后重新运行 west 扩展命令。如果设置了该变量，west 会使用 ZEPHYR_BASE 查找你的工作区。

如果不确定某个命令是内置命令还是扩展，请在工作区内运行 west help。输出会单独列出扩展命令，对于主线 Zephyr，输出如下所示：

$ west help

built-in commands for managing git repositories:
  init:                 create a west workspace
  [...]

other built-in commands:
  help:                 get help for west or a command
  [...]

extension commands from project manifest (path: zephyr):
  build:                compile a Zephyr application
  flash:                flash and run a binary on a board
  [...]

"invalid choice: 'post-init'"

如果在运行 west init 时看到此错误：

west: error: argument <command>: invalid choice: 'post-init'
(choose from 'init', 'update', 'list', 'manifest', 'diff',
'status', 'forall', 'config', 'selfupdate', 'help')

说明你安装的 west 版本较旧，而你正试图在一个需要更新版本的工作区中使用它。

解决此问题最简单的方法是升级 west，然后按如下步骤重试：

  1. 按照 安装 west 中所示，使用 pip3 install 的 -U 选项安装最新版本的 west。

  2. 备份 zephyrproject/.west/config 中你想保留的内容。（如果没有设置任何配置选项，可以放心跳过此步骤。）

  3. 完全删除 zephyrproject/.west 目录（否则会出现下文所述的“already in a workspace”错误消息）。

  4. 再次运行 west init。
