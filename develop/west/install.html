安装 west

West 使用 Python 3 编写，通过 PyPI 分发。请使用 pip3 安装或升级 west：

在 Linux 上：

pip3 install --user -U west

在 Windows 和 macOS 上：

pip3 install -U west

备注

有关使用 --user 开关的更多说明，请参阅 Python 和 pip。

安装完成后，可以运行 pip3 show -f west 查看 west 可执行文件及相关文件的安装位置。

安装 west 后，就可以用它来 克隆 Zephyr 仓库。

结构

West 的代码以名为 west 的 Python 包的形式通过 PyPI 分发。该发行包中包含一个启动器可执行文件，其名称也是 west （在 Windows 上为 west.exe）。

安装 west 时，pip3 会将启动器放在用户文件系统中的某个位置（具体位置取决于操作系统，但应当位于 PATH 环境变量 中）。该启动器是运行 west init、west update 等内置命令以及工作区中发现的任何扩展的命令行入口。

除了命令行接口，也可以直接使用 west 的 Python API。详情请参阅 West 的 API。

启用 shell 补全

West 目前支持在以下 shell 中进行 shell 补全：

  • bash

  • zsh

  • fish

  • powershell（仅限开发板限定符）

要启用 shell 补全，需要获取相应的补全脚本并加载（source）它。使用补全脚本：

一次性设置：

source <(west completion bash)

永久设置：

west completion bash > ~/west-completion.bash; printf '\n%s\n' "source ~/west-completion.bash" >> ~/.bashrc

一次性设置：

source <(west completion zsh)

永久设置：

west completion zsh > "${fpath[1]}/_west"

一次性设置：

west completion fish | source

永久设置：

west completion fish > $HOME/.config/fish/completions/west.fish

一次性设置：

west completion powershell | Out-String | Invoke-Expression

永久设置：

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
New-item -type file -force $PROFILE
west completion powershell > $HOME/west-completion.ps1
(Add-Content -Path $PROFILE -Value ". '{$HOME/west-completion.ps1}'")
