不使用 west 使用 Zephyr

本页介绍如何在不使用 west 的情况下使用 Zephyr。由于需要额外的工作量，不建议初学者这样做。具体来说，你需要“手动”完成以下工作来替代这些功能：

  • 除主 zephyr 仓库之外，克隆 Zephyr 使用的其他源代码仓库，并使其保持最新

  • 向 Zephyr 构建系统指定这些仓库的位置

  • 在不了解相关主机工具详细用法的情况下进行烧录和调试

备注

如果之前安装过 west 并且想停止使用它，请先将其卸载：

pip3 uninstall west

否则，Zephyr 的构建系统会找到它并可能尝试使用它。

获取源代码

除了下载 zephyr 源代码仓库本身之外，还需要手动克隆该仓库中 west manifest 文件所列出的其他项目。

mkdir zephyrproject
cd zephyrproject
git clone https://github.com/zephyrproject-rtos/zephyr
# clone additional repositories listed in zephyr/west.yml,
# and check out the specified revisions as well.

从 zephyr 仓库拉取更改时，还需要维护这些额外的仓库：必要时添加新仓库，并使已有仓库保持在最新修订版本。

构建应用程序

如果手动指定所有模块，就可以在不安装 west 的情况下直接使用 CMake 和 Ninja（或 make）构建 Zephyr 应用程序。

cmake -Bbuild -GNinja -DZEPHYR_MODULES=module1;module2;... samples/hello_world
ninja -Cbuild

安装了 west 时，Zephyr 构建系统会使用它来设置 ZEPHYR_MODULES。

如果没有安装 west，且应用程序不需要这些仓库中的任何一个，构建仍然可以正常进行。

如果没有安装 west，而应用程序 确实 需要这些仓库中的某一个，则必须如上所示自行设置 ZEPHYR_MODULES。

更多细节请参阅 模块（外部项目）。

类似地，如果应用程序需要二进制 blob，而你又不使用 west，就需要自行下载这些 blob 并放到正确的位置，而不是使用 west blobs。更多细节请参阅 二进制 blob。

烧录和调试

烧录和调试通过 west flash、west debug、west debugserver、west attach 和 west rtt 命令完成，这些命令在 构建、烧录和调试 中有介绍。这些命令需要 west，因此如果不使用 west，就无法使用它们。

没有 west 时，仍然可以使用适用于你的开发板的任何 烧录与调试主机工具 （也就是这些 west 命令所包装的工具）进行烧录和调试，但需要自行调用它们，并为你的开发板和应用程序提供正确的选项。
