West 别名

West 允许在本地、全局或系统配置文件中添加别名命令。这些别名可以方便地为常用命令或难以记忆的命令添加快捷方式，便于开发。

与 git 别名的工作方式类似，别名命令会被替换为别名的完整文本，并解析为新的 shell 参数列表（内部使用 Python 函数 shlex.split() 拆分该值）。这样就可以像向原始命令传递参数那样添加参数。空格被视为参数分隔符；如果参数不应被拆分，请正确转义。

要添加新的别名，只需调用 west config 命令：

west config alias.mylist "list -f '{name} {revision}'"

要列出别名，请使用 west help some_alias。

别名允许递归，因为一个别名命令可以包含其他别名，从而构建出更复杂但易于记忆的命令。

可以覆盖已有的命令，例如用来传递默认参数：

west config alias.update "update -o=--depth=1 -n"

警告

覆盖或遮蔽其他命令或内置命令属于高级用法，可能导致奇怪的副作用，应当非常谨慎。

示例

在全局配置中添加 west run 和 west menuconfig 快捷方式，以使用对应的 CMake 目标调用 west build：

west config --global alias.run "build --pristine=never --target run"
west config --global alias.menuconfig "build --pristine=never --target menuconfig"

为正在开发的示例创建一个带有附加选项的别名：

west config alias.sample "build -b native_sim samples/hello_world -t run -- -DCONFIG_ASSERT=y"

覆盖 west update，使其检查本地缓存：

west config alias.update "update --path-cache $HOME/.cache/zephyrproject"

通过 west 运行 Twister 时，自动排除 32 位原生模拟器目标。这在没有 32 位主机 C 库的主机系统（例如 Linux/AArch64）上运行时特别有用：

west config alias.twister "twister --exclude-platform native_sim/native"
