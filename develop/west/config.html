配置

本页介绍 west 的配置文件体系、west config 命令以及内置命令所使用的配置选项。有关 west.configuration 模块的 API 文档，请参阅 west.configuration。

West 配置文件

West 的配置文件语法类似 INI；下面是一个示例文件：

[manifest]
path = zephyr

[zephyr]
base = zephyr

上例中，manifest 节的 path 选项被设置为 zephyr。换一种说法，在该文件中 manifest.path 为 zephyr。

配置文件有三种类型：

  1. 系统：此文件中的设置会影响登录到该计算机的每个用户的 west 行为。其位置取决于平台：

    • Linux：/etc/westconfig

    • macOS：/usr/local/etc/westconfig

    • Windows：%PROGRAMDATA%\west\config

  2. 全局 （按用户）：此文件中的设置会影响计算机上某个特定用户运行 west 时的行为。

    • 所有平台：默认是用户主目录下的 .westconfig。

    • Linux 注意事项：如果设置了环境变量 XDG_CONFIG_HOME，则使用 $XDG_CONFIG_HOME/west/config。

    • Windows 注意事项：查找主目录时会依次检查以下环境变量：%HOME%，然后是 %USERPROFILE%，最后是 %HOMEDRIVE% 和 %HOMEPATH% 的组合。

  3. 本地：此文件中的设置会影响 west 在当前 west workspace 中的行为。该文件是相对于工作区根目录的 .west/config。

在此列表中位置靠后的文件中的设置会覆盖靠前的设置。例如，如果 color.ui 在系统配置文件中为 true，而在工作区配置文件中为 false，则最终值为 false。类似地，用户配置文件中的设置会覆盖系统设置，依此类推。

west config

内置的 config 命令可用于获取和设置配置值。可以向 west config 传递 --system、--global 或 --local 选项来指定使用哪个配置文件。一次只能使用其中一个。如果都没有给出，则写操作默认使用 --local，读操作显示应用覆盖之后的最终值。

下面是一些常见用法的示例；运行 west config -h 可获得详细帮助，有关内置选项的更多细节请参阅 内置配置选项。

将 manifest.path 设置为 some-other-manifest：

west config manifest.path some-other-manifest

这样做意味着 west update 等命令将在 some-other-manifest 目录（相对于工作区根目录）中查找 west manifest，而不是在提供给 west init 的目录中查找，所以请小心！

读取 zephyr.base。如果调用环境中未设置 ZEPHYR_BASE，就会使用该值（同样相对于工作区根目录）：

west config zephyr.base

可以使用以下命令切换到另一个 zephyr 仓库，而无需更改 manifest.path （因而也不会改变 west update 等命令的行为）：

west config zephyr.base some-other-zephyr

如果你使用 git worktree 等命令创建了自己的 zephyr 目录，并希望 west build 等命令使用这些目录而不是清单中指定的 zephyr 仓库，这会很有用。（运行 west config zephyr.base zephyr 即可恢复使用上游清单中的目录。）

在全局（用户范围）配置文件中将 color.ui 设置为 false，这样该用户在任何工作区中运行 west 时都不再打印彩色输出：

west config --global color.ui false

撤销上述更改：

west config --global color.ui true

内置配置选项

下表列出了 west 内置命令支持的配置选项。Zephyr 扩展命令支持的配置选项记录在这些命令各自的页面中。

选项

说明

alias.ALIAS

字符串。如果非空，<ALIAS> 可以作为 west 命令使用。请参阅 West 别名。

color.ui

布尔值。如果为 true （默认值），则当 stdout 是终端时，west 的输出会带颜色。

commands.allow_extensions

布尔值，默认为 true；如果为 false，则禁用 扩展

grep.color

字符串，默认为空。将其设置为 never 可禁用 west grep 的彩色输出。如果设置了该值，west grep 会将其传递给 grep 工具的 --color 选项。

grep.tool

字符串，取值为 "git-grep" （默认）、"ripgrep" 或 "grep" 之一。指定 west grep 应使用的 grep 工具。

grep.<TOOL>-args

字符串，默认为空。<TOOL> 部分是一个模式，可以是任意 grep.tool 取值，因此 grep.ripgrep-args 就是一个配置选项示例。如果设置了该值，它就是 west grep 应传递给相应 grep 工具的参数。详情请运行 west help grep。

grep.<TOOL>-path

字符串，默认为空。<TOOL> 部分是一个模式，可以是任意 grep.tool 取值，因此 grep.ripgrep-path 就是一个配置选项示例。它是 west grep 应使用的相应工具的路径，设置后将不再搜索该命令。详情请运行 west help grep。

manifest.file

字符串，默认为 west.yml。从清单仓库根目录到清单文件的相对路径，west init 以及其他解析清单的命令会使用该清单文件。

manifest.group-filter

字符串，默认为空。以逗号分隔的列表，指定在工作区中要启用和禁用的项目组。启用的组以 + 为前缀，禁用的组以 - 为前缀。例如，值 "+foo,-bar" 会启用组 foo 并禁用 bar。请参阅 项目组。

manifest.path

字符串，从 west workspace 根目录到清单仓库的相对路径，west update 以及其他解析清单的命令会使用该清单仓库。由 west init 在本地设置。

manifest.project-filter

以逗号分隔的字符串列表。

该选项的值是一个以逗号分隔的正则表达式列表，每个正则表达式都以 + 或 - 为前缀，例如：

+re1,-re2,-re3

项目名称会按顺序与列表中的每个正则表达式（re1、re2、re3 ……）进行匹配。如果整个项目名称与某个正则表达式匹配，则该列表元素会停用或激活该项目。如果元素以 - 开头，则停用该项目；如果元素以 + 开头，则激活该项目。（使用此选项时，项目名称不能包含 ,，因此正则表达式无需包含字面的 , 字符。）

如果项目名称与列表中的多个正则表达式匹配，则以最后一个正则表达式的结果为准。例如，如果 manifest.project-filter 为：

-hal_.*,+hal_foo

那么名为 hal_bar 的项目处于非活动状态，而名为 hal_foo 的项目处于活动状态。

如果项目被某个列表元素设为非活动或活动，那么无论其部分或全部组是否被禁用，该项目都相应地处于非活动或活动状态。（这是目前使没有任何组的项目变为非活动状态的唯一方法。）

否则，即如果项目不与列表中的任何正则表达式匹配，则按照与其组相关的常规规则确定其是否处于活动状态（这种情况下的示例请参阅 项目组示例）。

在 manifest.project-filter 列表的元素中，前导和尾随空白会被忽略。这意味着以下示例值是等价的：

+foo,-bar
+foo , -bar

空元素会被忽略。这意味着以下示例值是等价的：

+foo,,-bar
+foo,-bar

update.auto-cache

字符串。如果非空，且命令行中未给出 --auto-cache 选项，west update 会将该值用作该选项的值。

update.fetch

字符串，取值为 "smart" （从 v0.6.1 开始的默认行为）或 "always" （之前的行为）之一。如果设置为 "smart"，当清单文件中项目的修订版本是本地已有的 SHA 或标签时，west update 命令将跳过从这些项目的远程仓库获取。"always" 行为则是无条件地从远程获取。

update.name-cache

字符串。如果非空，且命令行中未给出 --name-cache 选项，west update 会将该值用作该选项的值。

update.narrow

布尔值。如果为 true，west update 的行为就如同在命令行中给出了 --narrow。默认值为 false。

update.path-cache

字符串。如果非空，且命令行中未给出 --path-cache 选项，west update 会将该值用作该选项的值。

update.sync-submodules

布尔值。如果为 true （默认值），west update 会在更新 Git 子模块之前先同步它们。

zephyr.base

字符串，west 命令运行期间为 ZEPHYR_BASE 环境变量设置的默认值。默认情况下，west init 期间会将其设置为路径为 zephyr 的清单项目（如果存在）的路径。如果该环境变量已经设置，则忽略此设置，除非 zephyr.base-prefer 为 "configfile"。

zephyr.base-prefer

字符串，取值为 "env" 和 "configfile" 之一。如果设置为 "env" （默认值），则在调用环境中设置的 ZEPHYR_BASE 会覆盖 zephyr.base 配置选项的值。如果设置为 "configfile"，则以配置选项为准。
