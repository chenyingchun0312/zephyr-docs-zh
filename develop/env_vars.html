环境变量

本文档的许多页面都提到要设置 Zephyr 特定的环境变量。本页介绍如何设置。

设置变量

方式 1：仅设置一次

要在当前终端窗口的生命周期内将环境变量 MY_VARIABLE 设置为 foo：

export MY_VARIABLE=foo

set MY_VARIABLE=foo

警告

这种方式最适合用于试验。如果关闭终端窗口、使用其他终端窗口或标签页、重启计算机等，此设置将永久丢失。

如果希望持续使用该设置，建议使用方式 2 或方式 3。

方式 2：在所有终端中生效

将 export MY_VARIABLE=foo 这一行添加到主目录中 shell 的启动脚本中。对于 Bash，在 Linux 上通常是 ~/.bashrc，在 macOS 上通常是 ~/.bash_profile。对这些启动脚本的更改不会影响已经启动的 shell 实例；请打开新的终端窗口以获取新设置。

可以在 cmd.exe 中使用 setx 程序，或使用第三方程序 RapidEE。

要使用 setx，请输入以下命令，然后关闭终端窗口。之后新打开的所有 cmd.exe 窗口中，MY_VARIABLE 都会被设置为 foo。

setx MY_VARIABLE foo

RapidEE 是一款免费的图形化环境变量编辑器。要安装它，请在管理员命令提示符中 using Chocolatey：

choco install rapidee

之后可以在终端中运行 rapidee 启动该程序并设置环境变量。请确保使用“User”（用户）环境变量区域，否则必须以管理员身份运行 RapidEE。另外，退出前请务必点击左上角的 Save 按钮保存更改。在 RapidEE 中所做的设置会在每次打开新的终端窗口时生效。

方式 3：使用 zephyrrc 文件

如果不希望变量设置在所有终端中都生效，但仍希望保存该值，以便在使用 Zephyr 时加载到环境中，请选择此方式。

Zephyr 支持将 zephyrrc 文件放在多个位置，并尽可能遵循 XDG 基础目录规范（XDG Base Directory Specification）。在以下任一位置创建 zephyrrc 文件（将按顺序检查这些位置）：

  1. $XDG_CONFIG_HOME/zephyr/zephyrrc

  2. $HOME/.config/zephyr/zephyrrc

  3. $HOME/.zephyrrc

在所选位置的文件中添加这一行：

export MY_VARIABLE=foo

要将此值加载回当前终端环境，必须在 zephyr 主仓库中 运行 source zephyr-env.sh。该脚本会执行多项操作，其中包括加载（source）zephyrrc （即在上述位置列表中找到的第一个文件）。

如果关闭窗口等，该值将会丢失；再次运行 source zephyr-env.sh 即可恢复。

使用记事本等文本编辑器，将 set MY_VARIABLE=foo 这一行添加到文件 %userprofile%\zephyrrc.cmd 中以保存该值。

要将此值加载回当前终端环境，必须 在 cmd.exe 窗口中切换到 zephyr 主仓库目录后 运行 zephyr-env.cmd。该脚本会执行多项操作，其中包括运行 %userprofile%\zephyrrc.cmd。

如果关闭窗口等，该值将会丢失；再次运行 zephyr-env.cmd 即可恢复。

这些脚本会：

  • 将 ZEPHYR_BASE 设置为 zephyr 仓库的位置

  • 将一些 Zephyr 特定的位置（例如 zephyr 的 scripts 目录）添加到 PATH 环境变量中

  • 加载上文 方式 3：使用 zephyrrc 文件 中所述 zephyrrc 文件中的所有设置。

因此，每当需要这些设置时，都可以使用这些脚本。

Zephyr 环境脚本

可以使用 zephyr 仓库中的脚本 zephyr-env.sh （适用于 macOS 和 Linux）和 zephyr-env.cmd （适用于 Windows），将 Zephyr 特定的设置加载到当前终端的环境中。为此，请在 zephyr 仓库中运行以下命令：

source zephyr-env.sh

zephyr-env.cmd

这些脚本会：

  • 将 ZEPHYR_BASE 设置为 zephyr 仓库的位置

  • 将一些 Zephyr 特定的位置（例如 zephyr 的 scripts 目录）添加到 PATH 环境变量中

  • 加载上文 方式 3：使用 zephyrrc 文件 中所述 zephyrrc 文件中的所有设置。

因此，每当需要这些设置时，都可以使用这些脚本。

重要的环境变量

部分 重要的构建系统变量 也可以在环境中设置。下面介绍其中一些重要的环境变量。此列表并不完整。

BOARD

请参见 重要的构建系统变量。

CONF_FILE

请参见 重要的构建系统变量。

SHIELD

请参见 扩展板（shield）。

ZEPHYR_BASE

请参见 重要的构建系统变量。

EXTRA_ZEPHYR_MODULES

请参见 重要的构建系统变量。

ZEPHYR_MODULES

请参见 重要的构建系统变量。

ZEPHYR_BOARD_ALIASES

请参见 开发板别名

配置用于构建 Zephyr 应用程序的 工具链 时，以下附加环境变量也很重要。

ZEPHYR_SDK_INSTALL_DIR

Zephyr SDK 的安装路径。

ZEPHYR_TOOLCHAIN_VARIANT

要使用的工具链的名称。

{TOOLCHAIN}_TOOLCHAIN_PATH

ZEPHYR_TOOLCHAIN_VARIANT 所指定工具链的路径。例如，如果 ZEPHYR_TOOLCHAIN_VARIANT=host/llvm，则使用 LLVM_TOOLCHAIN_PATH。（注意构成环境变量名称时的大小写。）

在 更新 Zephyr SDK 工具链 时，可能需要更新其中一些变量。

仿真器和开发板可能还依赖其他程序。构建系统会尝试自动找到这些程序，但可能需要借助其他 CMake 变量或环境变量。更多信息请查阅仿真器或开发板的文档。在这种情况下，以下环境变量可能有用：

PATH

PATH 是类 Unix 或 Microsoft Windows 操作系统上使用的一个环境变量，用于指定可执行程序所在的一组目录。
