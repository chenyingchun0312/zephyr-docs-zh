West 项目索引

本页是与 West 元工具兼容的项目（模块）索引。

它主要列出 Zephyr 默认 manifest file 中声明的组件。关于这些导入组件的贡献和评审流程，详见 贡献外部组件。

它还维护一份 外部项目 登记表，这些项目在 Zephyr 项目之外维护，可以轻松集成到 Zephyr 工作区中。

活动项目/模块

下列项目默认启用，调用 west update 时会被下载。下面列出的许多项目或模块是构建通用 Zephyr 应用程序所必需的，其中包括对 Zephyr 中许多可用平台的硬件支持。

要禁用任何活动模块（例如某个特定的 HAL），请使用以下命令:

west config manifest.project-filter -- -hal_FOO
west update
