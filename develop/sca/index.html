静态代码分析（SCA）

Zephyr 通过 CMake 支持静态代码分析工具。

构建设置 ZEPHYR_SCA_VARIANT 可用于指定要使用的 SCA 工具。也支持将 ZEPHYR_SCA_VARIANT 作为 环境变量 使用。

使用 -DZEPHYR_SCA_VARIANT=<tool>，例如用 -DZEPHYR_SCA_VARIANT=sparse 启用静态分析工具 sparse。

SCA 工具基础设施

对某个 SCA 工具的支持在 sca.cmake 文件中实现。sca.cmake 必须放在 SCA_ROOT/cmake/sca/tool/sca.cmake 下。Zephyr 本身总是会被添加为一个 SCA_ROOT，但构建系统允许向 SCA_ROOT 设置中添加更多文件夹。

可以通过创建以下结构，为源码树之外的 SCA 工具提供支持：

<sca_root>/                 # Custom SCA root
└── cmake/
    └── sca/
        └── <tool>/         # Name of SCA tool, this is the value given to ZEPHYR_SCA_VARIANT
            └── sca.cmake   # CMake code that configures the tool to be used with Zephyr

要在 /path/to/my_tools/cmake/sca 下添加 foo，请创建以下结构：

/path/to/my_tools
         └── cmake/
             └── sca/
                 └── foo/
                     └── sca.cmake

然后，要将 foo 用作 SCA 工具，必须指定 -DZEPHYR_SCA_VARIANT=foo。

记得将 /path/to/my_tools 添加到 SCA_ROOT 中。

SCA_TOOL 可以像普通 CMake 设置一样通过 -DSCA_ROOT=<sca_root> 设置，也可以由 Zephyr 模块在其 module.yml 文件中添加，参见 Zephyr 模块 - 构建设置

编译器与链接器启动器

需要观察或包装编译和链接命令的 SCA 工具，通过在其 sca.cmake 中设置 CMAKE_<LANG>_COMPILER_LAUNCHER 和 CMAKE_<LANG>_LINKER_LAUNCHER 变量来实现。它们必须设置为普通变量，而不是缓存条目。

以这种方式设置的启动器会替换任何已配置的启动器，包括 ccache。透明包装工具（即原样运行所给命令的工具）可以通过追加的方式保留之前的启动器：

set(CMAKE_C_COMPILER_LAUNCHER ${my_wrapper} ${CMAKE_C_COMPILER_LAUNCHER})

原生 SCA 工具支持

以下是 Zephyr 构建系统原生支持的 SCA 工具列表。

  • Clang 静态分析器支持
  • CodeChecker 支持
  • Coverity
  • Parasoft C/C++test 支持
  • 设备树诊断（dtdoctor）
  • ECLAIR 支持
  • GCC 静态分析支持
  • IAR C-STAT 支持
  • include-what-you-use（IWYU）支持
  • Polyspace 支持
  • Sparse 支持
