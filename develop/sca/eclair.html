ECLAIR 支持

Bugseng ECLAIR 是一款经过认证的静态分析工具和软件验证平台。其应用范围包括：编码规则验证（尤其侧重 MISRA 和 BARR-C 编码标准）、软件度量计算、软件组件之间独立性与免干扰性检查，以及对重要类别软件错误的自动检测。

前提条件

必须安装 ECLAIR 工具，并将其加入操作系统的 PATH 变量中。

要验证安装，可以运行：

eclair -version

使用 ECLAIR 需要有效的许可证或试用许可证。要申请试用许可证，请访问 此页面。

运行 ECLAIR

要运行 ECLAIR，应在调用 west build 时传入 -DZEPHYR_SCA_VARIANT=eclair 参数。

west build -b mimxrt1064_evk samples/basic/blinky -- -DZEPHYR_SCA_VARIANT=eclair

备注

这只会使用预定义规则集 first_analysis 调用 ECLAIR 分析。如果要使用其他规则集，需要提供配置文件。更多信息请参阅下一节。

配置

ECLAIR SCA 环境既可以通过 CMake 选项文件配置，也可以通过命令行参数传入调整后的选项来配置。

要在 ECLAIR 调用中使用 CMake 选项文件，可以定义 ECLAIR_OPTIONS_FILE 变量，例如：

west build -b mimxrt1064_evk samples/basic/blinky -- -DZEPHYR_SCA_VARIANT=eclair -DECLAIR_OPTIONS_FILE=my_options.cmake

默认配置（未给出配置文件时）始终是 first_analysis，它只包含一小部分规则，用于验证一切工作正常。

如果希望通过命令行而不是选项文件覆盖默认配置，可以传入参数 -DOption=ON|OFF。

例如：

west build -b mimxrt1064_evk samples/basic/blinky -- -DZEPHYR_SCA_VARIANT=eclair -DECLAIR_REPORTS_SARIF=ON

Zephyr 是一个庞大而复杂的项目，因此配置集将 Zephyr 的准则选择（取自 https://docs.zephyrproject.org/latest/contribute/coding_guidelines/index.html）分成五组，以便在个人机器上更容易使用：

  • first_analysis（默认）：项目编码准则中的一小部分，用于验证一切工作正常。

  • STU：项目编码准则中可以通过独立分析单个翻译单元来验证的部分。

  • STU_heavy：项目编码准则中需要大量时间、较为复杂的 STU 部分。

  • WP：项目编码准则中所有针对整个程序的部分（MISRA 术语中称为“system”）。

  • std_lib：项目编码准则中关于 C 标准库的部分。

此外，zephyr_guidelines 规则集包含 编码准则 中列出的所有主要规则。

相关的 CMake 选项：

  • ECLAIR_RULESET_FIRST_ANALYSIS

  • ECLAIR_RULESET_STU

  • ECLAIR_RULESET_STU_HEAVY

  • ECLAIR_RULESET_WP

  • ECLAIR_RULESET_STD_LIB

  • ECLAIR_RULESET_ZEPHYR_GUIDELINES

用户自定义规则集

如果要使用自己定义的规则集，而不是预定义的 Zephyr 编码准则规则集，可以设置 ECLAIR_RULESET_USER=ON。按照 analysis_<RULESET>.ecl 的命名格式为 ECLAIR 创建自己的规则集文件。创建文件后，通过 CMake 变量 ECLAIR_USER_RULESET_NAME 为 ECLAIR 定义规则集名称。如果规则集文件不在应用程序源码目录中，可以通过 CMake 变量 ECLAIR_USER_RULESET_PATH 定义规则集文件的路径。该配置接受相对路径和绝对路径。

相关的 CMake 选项和变量：

  • ECLAIR_RULESET_USER

  • ECLAIR_USER_RULESET_NAME

  • ECLAIR_USER_RULESET_PATH

生成其他报告格式

除默认的 ecd 文件外，ECLAIR 还可以生成其他报告格式（例如 DOC、ODT、XLSX）以及不同变体的报告。可以生成以下附加报告和报告格式：

  • 电子表格格式的度量数据。

  • 电子表格格式的发现结果。

  • SARIF 格式的发现结果。

  • 纯文本格式的摘要报告。

  • DOC 格式的摘要报告。

  • ODT 格式的摘要报告。

  • HTML 格式的摘要报告。

  • txt 格式的详细报告。

  • DOC 格式的详细报告。

  • ODT 格式的详细报告。

  • HTML 格式的详细报告。

相关的 CMake 选项：

  • ECLAIR_METRICS_TAB

  • ECLAIR_REPORTS_TAB

  • ECLAIR_REPORTS_SARIF

  • ECLAIR_SUMMARY_TXT

  • ECLAIR_SUMMARY_DOC

  • ECLAIR_SUMMARY_ODT

  • ECLAIR_SUMMARY_HTML

  • ECLAIR_FULL_TXT

  • ECLAIR_FULL_DOC

  • ECLAIR_FULL_ODT

  • ECLAIR_FULL_HTML

完整报告的详细程度

txt 和 doc 完整报告的详细程度也可以通过配置调整。此时可以使用以下配置：

  • 显示所有区域

  • 只显示第一个区域

相关的 CMake 选项：

  • ECLAIR_FULL_DOC_ALL_AREAS

  • ECLAIR_FULL_DOC_FIRST_AREA

  • ECLAIR_FULL_TXT_ALL_AREAS

  • ECLAIR_FULL_TXT_FIRST_AREA
