IAR C-STAT 支持

IAR C-STAT 是一款面向 C/C++ 源代码的综合性静态分析工具。它可以发现错误和漏洞，支持多种编码标准，例如 MISRA C、MISRA C++、CERT C/C++ 和 CWE。

安装 IAR C-STAT

IAR C-STAT 预装在 IAR Build Tools 和 IAR Embedded Workbench 中。详情请参阅相应产品的文档。

使用 IAR C-STAT 构建

运行 IAR C-STAT 需要 CMake 4.1.0 或更高版本。使用 west build 构建时，追加额外参数 -DZEPHYR_SCA_VARIANT=iar_c_stat 以选择 IAR C-STAT，例如：

west build -b stm32f429ii_aca samples/basic/blinky -- -DZEPHYR_SCA_VARIANT=iar_c_stat

配置 IAR C-STAT

IAR C-STAT 接受用于定制分析的参数。下表列出了支持的选项。

参数

说明

CSTAT_RULESET

要使用的预定义规则集。（默认值：stdchecks，可接受的值：all,cert,misrac2004,misrac2012,misrac++2008,stdchecks,security）

CSTAT_ANALYZE_THREADS

分析时使用的线程数。（默认值：<CPU 数量>）

CSTAT_ANALYZE_OPTS

直接传递给 analyze 命令的参数。（例如 --timeout=900;--deterministic;--fpe）

CSTAT_DB

覆盖 C-STAT SQLite 数据库的默认位置。（例如 /home/user/cstat.db）

CSTAT_CLEANUP

清理 C-STAT SQLite 数据库。（例如 true）

这些参数可以在命令行中传入，也可以设置为环境变量。下面的示例展示了如何按需启用并组合非标准规则集：

# From the root of the zephyr repository
west build -b stm32f429ii_aca samples/basic/blinky -- -DZEPHYR_SCA_VARIANT=iar_c_stat -DCSTAT_RULESET=misrac2012,cert
