GCC 静态分析支持

静态分析功能在 GCC 10 中引入，通过选项 -fanalyzer 启用。该选项对代码执行的分析比传统警告开销大得多，也彻底得多。

运行 GCC 静态分析

要运行 GCC 静态分析，应在调用 west build 时传入 -DZEPHYR_SCA_VARIANT=gcc 参数，例如：

west build -b qemu_x86 samples/userspace/hello_world_user -- -DZEPHYR_SCA_VARIANT=gcc

配置 GCC 静态分析器

可以通过特定选项控制 GCC 静态分析器。

  • 控制分析器的选项

  • 控制诊断消息格式的选项

参数

说明

GCC_SCA_OPTS

以分号分隔的 GCC 分析器选项列表。

这些参数可以在命令行中传入，也可以设置为环境变量。

west build -b stm32h573i_dk samples/hello_world -- -DZEPHYR_SCA_VARIANT=gcc -DGCC_SCA_OPTS="-fdiagnostics-format=json;-fanalyzer-verbosity=3"

备注

GCC 静态分析器正处于积极开发中，每个新版本都会带来新选项。这个 页面 概述了分析器每个新版本引入的选项和修复。

最新版本的分析器

由于 Zephyr 工具链可能不包含最新版本的 GCC 静态分析器，可以使用更新的 GNU Arm embedded 工具链 运行 GCC 静态分析，以利用最新版本的分析器。

west build -b stm32h573i_dk samples/hello_world -- -DZEPHYR_SCA_VARIANT=gcc -DZEPHYR_TOOLCHAIN_VARIANT=gnuarmemb -DGNUARMEMB_TOOLCHAIN_PATH=...
