Polyspace 支持

Polyspace® 是 MathWorks 推出的商业静态代码分析工具，经认证可用于最高安全等级的场景。它可以检查对 MISRA C 和 CERT C 等编码准则的合规性、发现 CWE、检测缺陷并计算代码复杂度指标。它还可以选择运行形式化证明，验证不存在数组越界访问、溢出、竞态条件等运行时错误，从而帮助实现内存安全。

安装

必须安装 Polyspace 工具，并将其加入操作系统或容器的 PATH 变量中。具体而言，路径 <polyspace_root>/polyspace/bin 必须在该列表中。

安装说明请参阅 此处。要使用形式化验证（证明 不存在 缺陷），还需要安装 此组件。

安装文件夹中必须有许可证文件。要申请试用许可证，请访问 此页面。

运行

可以通过 west 命令触发代码分析，只需在构建时追加选项 -DZEPHYR_SCA_VARIANT=polyspace，例如：

west build -b qemu_x86 samples/hello_world -- -DZEPHYR_SCA_VARIANT=polyspace

查看结果

发现的问题会在构建结束时汇总并打印在控制台窗口中，同时给出包含详细结果的文件夹路径。

为了高效地审查，应在 Polyspace 用户界面 中打开该文件夹，或将其 上传到 Web 界面 后在那里审查。

为了便于以编程方式访问结果（例如在 CI 流水线中），结果文件夹中的 CSV 文件也描述了各个问题。

配置

默认情况下，Polyspace 会扫描所有 C 和 C++ 源文件中的典型编程缺陷。可以使用以下选项定制默认行为：

选项

作用

示例

POLYSPACE_ONLY_APP

设置后，只分析用户代码，忽略 Zephyr 源代码。

-DPOLYSPACE_ONLY_APP=1

POLYSPACE_OPTIONS

提供额外的命令行标志，例如用于选择编码规则。选项及其值之间用分号分隔。选项列表请参阅 此处。

-DPOLYSPACE_OPTIONS="-misra3;mandatory-required;-checkers;all"

POLYSPACE_OPTIONS_FILE

命令行标志也可以逐行写在文本文件中提供。请提供该文件的绝对路径。

-DPOLYSPACE_OPTIONS_FILE=/workdir/zephyr/myoptions.txt

POLYSPACE_MODE

在缺陷查找模式和证明模式之间切换。默认为缺陷查找模式。详见 此处。

-DPOLYSPACE_MODE=prove

POLYSPACE_PROG_NAME

覆盖被分析应用程序的名称。默认为开发板名称和应用程序名称。

-DPOLYSPACE_PROG_NAME=myapp

POLYSPACE_PROG_VERSION

覆盖被分析应用程序的版本。默认取自 git-describe。

-DPOLYSPACE_PROG_VERSION=v1.0b-28f023
