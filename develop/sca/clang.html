Clang 静态分析器支持

Clang 静态分析器（Clang Static Analyzer）构建在 Clang 和 LLVM 之上。严格来说，该分析器是 Clang 的一部分，因为 Clang 由一组可复用的 C++ 库组成，用于构建强大的源码级工具。Clang 静态分析器所用的静态分析引擎是一个 Clang 库，可以在不同的场景中被不同的客户端复用。

LLVM 提供了多种在代码库上运行该分析器的方法：可以通过一组专用工具（scan-build 和 analyze-build），也可以在运行 clang 时通过命令行参数（'--analyze'）。

  • 对于使用简单 $CC makefile 变量的项目，'scan-build' 实用程序是最方便的方式，因为它会包装并替换编译器调用来执行分析。

  • 'analyze-build' 实用程序是 'scan-build' 的一个子工具，它只依赖 'compile_commands.json' 数据库来执行分析。

  • clang 选项 '--analyze' 会在构建的同时运行分析器，但不会生成目标文件，因此无法进行任何链接阶段。在我们的场景中，第一个链接阶段就会失败并终止分析。

由于 Zephyr 的构建基础设施较为复杂，使用 'analyze-build' 调用 clang 分析器是分析 Zephyr 项目最简单的方式。

Clang 静态分析器文档

安装 clang 分析器

'scan-build' 及其子工具 'analyze-build' 作为 llvm 二进制文件的一部分原生提供。确保二进制文件目录可以通过 PATH 访问。

'scan-build' 也以独立 Python 软件包的形式发布在 pypi 上。

pip install scan-build

运行 clang 静态分析器

备注

该分析器要求项目使用 LLVM 工具链构建，并生成 'compile_commands.json' 数据库。

要运行 clang 静态分析器，应在调用 west build 时传入 -DZEPHYR_SCA_VARIANT=clang 参数以及 llvm 工具链参数，例如：

west build -b qemu_x86 samples/userspace/hello_world_user -- -DZEPHYR_TOOLCHAIN_VARIANT=host/llvm -DLLVM_TOOLCHAIN_PATH=... -DZEPHYR_SCA_VARIANT=clang

备注

默认情况下，clang 静态分析器生成 html 报告，但可以通过选项选择其他多种输出格式（sarif、plist、html）

配置 clang 静态分析器

可以通过特定选项控制 clang 静态分析器。要获取完整的可用选项列表，请参阅 'analyze-build' 和 'scan-build' 的帮助信息。

analyze-build --help

默认已启用的选项：

  • --analyze-headers : 同时分析通过 #include 包含的文件中的函数。

参数

说明

CLANG_SCA_OPTS

以分号分隔的 'analyze-build' 选项列表。

这些参数可以在命令行中传入，也可以设置为环境变量。

west build -b stm32h573i_dk samples/hello_world -- -DZEPHYR_TOOLCHAIN_VARIANT=host/llvm -DLLVM_TOOLCHAIN_PATH=... -DZEPHYR_SCA_VARIANT=clang -DCLANG_SCA_OPTS="--sarif;--verbose"
