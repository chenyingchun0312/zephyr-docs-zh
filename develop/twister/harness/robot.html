Robot

Zephyr 支持将 Robot Framework 作为自动化测试方案之一。

Robot 文件允许你以人类可读的文本格式描述交互式测试场景，并在仿真环境中或在硬件上执行这些场景。目前，Zephyr 的集成支持在 Renode 仿真框架、QEMU 和 Native Simulator 中运行 Robot 测试。

要使用 twister 执行 Robot 测试套件，请运行以下命令：

$ west twister --platform hifive1 --test samples/subsys/shell/shell_module/sample.shell.shell_module.robot

编写 Robot 测试

Robot Framework 自身提供的关键字列表请参阅 Robot 官方文档。

有关在 Renode 中编写和运行 Robot Framework 测试的信息，请参阅 Renode 文档的 测试章节。其中列出了最常用的关键字，并附有指向定义这些关键字的源代码的链接。

可以通过添加新关键字来扩展该框架：直接在 Robot 测试套件文件中编写，作为外部 Python 库提供，或者像 Renode 那样通过 XML-RPC 动态提供。详情请参阅 Robot 官方文档中的 扩展 Robot Framework 一节。

运行单个测试套件

要运行单个测试套件而不是整组测试，可以运行：

$ west twister -p qemu_riscv32 -s arch.shared_interrupt

robot harness 用于在仿真目标（Qemu、Native Simulator、Renode）中执行 Robot Framework 测试套件。

robot_testsuite: <robot 文件路径>（默认为空）

指定一个或多个包含要运行的 Robot Framework 测试套件的文件路径。

robot_option: <robot 选项>（默认为空）

要传递给 robotframework 的一个或多个选项。
