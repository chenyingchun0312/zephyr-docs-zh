Zephyr SDK

Zephyr 软件开发工具包（SDK）包含适用于 Zephyr 所支持的每种架构的 GNU 和 LLVM 工具链。它还包含其他主机工具，例如定制的 QEMU 和 OpenOCD。

强烈建议使用 Zephyr SDK，在某些情况下甚至必须使用（例如在 QEMU 中运行某些架构的测试）。

支持的架构

Zephyr SDK 支持以下目标架构：

  • ARC（32 位和 64 位；ARCv1、ARCv2、ARCv3）

  • ARM（32 位和 64 位；ARMv6、ARMv7、ARMv8；A/R/M Profile）

  • Microblaze（32 位）

  • MIPS（32 位和 64 位）

  • RISC-V（32 位和 64 位；RV32I、RV32E、RV64I）

  • RX

  • SPARC（32 位和 64 位；SPARC V8、SPARC V9）

  • x86（32 位和 64 位）

  • Xtensa

安装包与变量

Zephyr SDK 安装包支持所有主流操作系统（Linux、macOS 和 Windows），以压缩文件的形式提供。

为便于分发，SDK 预先打包为三种不同的变体供下载：

安装过程包括解压下载的安装包文件并运行其中附带的安装脚本。

无论下载哪个安装包，安装过程中都会提示你选择要安装的工具链；如果在执行安装脚本的本地目录中找不到所选工具链，安装过程中会下载它。也可以将 GNU 和 LLVM 两个 SDK 安装包都下载并解压到同一目录树中，这样无需在运行安装脚本时下载任何一个即可同时安装两者。

下文各节介绍了特定于操作系统的其他说明。

如果未选择工具链，构建系统会查找 Zephyr SDK 并使用其中的工具链。也可以将环境变量 ZEPHYR_TOOLCHAIN_VARIANT 设置为 zephyr 来强制这样做。

如果你将 Zephyr SDK 安装在任何默认位置（见下文特定于操作系统的说明）之外，又希望自动发现 Zephyr SDK，就必须运行安装脚本，将 Zephyr SDK 注册到 CMake 软件包注册表中。如果决定不在 CMake 注册表中注册 Zephyr SDK，可以用 ZEPHYR_SDK_INSTALL_DIR 指向 Zephyr SDK 的安装目录。

也可以将 ZEPHYR_SDK_INSTALL_DIR 设置为包含多个 Zephyr SDK 的目录，以便自动选择工具链。例如，可以将 ZEPHYR_SDK_INSTALL_DIR 设置为 /company/tools，其中 company/tools 文件夹包含以下子文件夹：

  • /company/tools/zephyr-sdk-0.13.2

  • /company/tools/zephyr-sdk-a.b.c

  • /company/tools/zephyr-sdk-x.y.z

这样 Zephyr 构建系统就能选择正确版本的 SDK，同时允许将多个 Zephyr SDK 集中存放在特定路径下。

Zephyr SDK 版本兼容性

一般而言，本页引用的 Zephyr SDK 版本应视为对应 Zephyr 版本的推荐版本。

关于相互兼容的 Zephyr 与 Zephyr SDK 版本的完整列表，请参阅 Zephyr SDK Version Compatibility Matrix。

安装 Zephyr SDK

备注

如有需要，可以在下面的说明中将 1.0.1 改为其他版本；Zephyr SDK Releases 页面列出了所有可用的 SDK 发布版本。

备注

下面的说明适用于使用 Zephyr GNU SDK 安装包进行安装，该安装包包含适用于所有支持架构的 GNU 工具链和主机工具。若要使用 Zephyr LLVM SDK 安装包进行安装，请将 SDK 安装包文件名中的 _gnu 后缀替换为 _llvm。

备注

如果要卸载 SDK，只需删除其安装目录即可。

  1. 下载并校验 Zephyr SDK bundle：

    cd ~
wget https://github.com/zephyrproject-rtos/sdk-ng/releases/download/v1.0.1/zephyr-sdk-1.0.1_linux-x86_64_gnu.tar.xz
wget -O - https://github.com/zephyrproject-rtos/sdk-ng/releases/download/v1.0.1/sha256.sum | shasum --check --ignore-missing

    如果你的主机架构是 64 位 ARM（例如 Raspberry Pi），请将 x86_64 替换为 aarch64，以下载 64 位 ARM Linux 版 SDK。

  2. 解压 Zephyr SDK 安装包压缩文件：

    tar xvf zephyr-sdk-1.0.1_linux-x86_64_gnu.tar.xz

    备注

    建议将 Zephyr SDK 安装包解压到以下位置之一：

    • $HOME

    • $HOME/.local

    • $HOME/.local/opt

    • $HOME/bin

    • /opt

    • /usr/local

    Zephyr SDK 安装包压缩文件中包含 zephyr-sdk-<version> 目录；解压到 $HOME 下时，最终的安装路径为 $HOME/zephyr-sdk-<version>。

  3. 运行 Zephyr SDK 安装包的安装脚本：

    cd zephyr-sdk-1.0.1
./setup.sh

    备注

    解压 Zephyr SDK 安装包后，只需运行一次安装脚本。

    如果在初次设置后移动了 Zephyr SDK 安装包目录，必须重新运行安装脚本。

  4. 安装 udev 规则，这样就能以普通用户身份烧录大多数 Zephyr 开发板：

    sudo cp ~/zephyr-sdk-1.0.1/hosttools/sysroots/x86_64-pokysdk-linux/usr/share/openocd/contrib/60-openocd.rules /etc/udev/rules.d
sudo udevadm control --reload

  2. 下载 Zephyr SDK bundle：

    cd %HOMEPATH%
wget https://github.com/zephyrproject-rtos/sdk-ng/releases/download/v1.0.1/zephyr-sdk-1.0.1_windows-x86_64_gnu.7z

  3. 解压 Zephyr SDK 安装包压缩文件：

    7z x zephyr-sdk-1.0.1_windows-x86_64_gnu.7z

    备注

    建议将 Zephyr SDK 安装包解压到以下位置之一：

    • %HOMEPATH%

    • %PROGRAMFILES%

    Zephyr SDK 安装包压缩文件中包含 zephyr-sdk-<version> 目录；解压到 %HOMEPATH% 下时，最终的安装路径为 %HOMEPATH%\zephyr-sdk-<version>。

  4. 运行 Zephyr SDK 安装包的安装脚本：

    cd zephyr-sdk-1.0.1
setup.cmd

    备注

    解压 Zephyr SDK 安装包后，只需运行一次安装脚本。
