DesignWare ARC MetaWare Development Toolkit (MWDT)

  1. 你需要在主机上安装 ARC MWDT。

  2. 你需要在主机上安装 Zephyr SDK。

    备注

    Zephyr SDK 用于提供设备树编译器（DTC）、QEMU 等工具。即使使用 ARC MWDT 工具链构建 Zephyr RTOS，某些步骤（如设备树预处理和 .bin 文件生成）仍可能用到 GNU 预处理器和 GNU objcopy。我们同样使用 Zephyr SDK 来提供这些 ARC GNU 工具。要设置 ARC GNU 工具链，请使用 SDK Bundle（完整版或精简版），而不要手动安装单独的压缩包。它会在系统中安装并注册工具链和主机工具，从而避免构建 Zephyr 时出现与工具链相关的问题。

  3. 设置以下环境变量：

    • 将 ZEPHYR_TOOLCHAIN_VARIANT 设置为 arcmwdt。

    • 将 ARCMWDT_TOOLCHAIN_PATH 设置为工具链的安装目录。MWDT 安装会提供 METAWARE_ROOT，因此只需将 ARCMWDT_TOOLCHAIN_PATH 设置为 $METAWARE_ROOT/../（Linux）或 %METAWARE_ROOT%\..\（Windows）。

    小技巧

    如果你的机器上只安装了一个版本的 ARC MWDT 工具链，可以不设置 ARCMWDT_TOOLCHAIN_PATH，它会被自动检测到。

  4. 要检查当前环境中这些变量是否设置正确，请参照以下 shell 会话示例（你系统上的 ARCMWDT_TOOLCHAIN_PATH 值可能不同）：

    # Linux:
$ echo $ZEPHYR_TOOLCHAIN_VARIANT
arcmwdt
$ echo $ARCMWDT_TOOLCHAIN_PATH
/home/you/ARC/MWDT_2023.03/

# Windows:
> echo %ZEPHYR_TOOLCHAIN_VARIANT%
arcmwdt
> echo %ARCMWDT_TOOLCHAIN_PATH%
C:\ARC\MWDT_2023.03\
