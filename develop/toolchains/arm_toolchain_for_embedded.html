Arm Toolchain for Embedded (ATfE)

Arm Toolchain for Embedded（ATfE）是 Arm 推出的 C 和 C++ 工具链，

它基于自由开源的 LLVM 编译器基础设施和 Picolib C 库，面向裸机目标。

ATfE 经过专门调优，尤其注重以下较新

Arm 产品（2024 年以后）的性能，例如 64 位 Arm 架构（AArch64）或 M-Profile 向量扩展（MVE，一种 32 位 Armv8.1-M 扩展）。

安装

  1. 下载并安装适用于你的操作系统的 Arm toolchain for embedded 构建版本，并将其解压到文件系统中。

  2. 设置以下环境变量：

    • 将 ZEPHYR_TOOLCHAIN_VARIANT 设置为 host/llvm。

    • 将 LLVM_TOOLCHAIN_PATH 设置为工具链的安装目录。

  3. 要检查当前环境中这些变量是否设置正确，请参照以下 shell 会话示例（你系统上的 LLVM_TOOLCHAIN_PATH 值可能不同）：

    echo $ZEPHYR_TOOLCHAIN_VARIANT
host/llvm
echo $LLVM_TOOLCHAIN_PATH
/home/you/Downloads/ATfE

    echo $ZEPHYR_TOOLCHAIN_VARIANT
host/llvm
echo $LLVM_TOOLCHAIN_PATH
/home/you/Downloads/ATfE

    > echo %ZEPHYR_TOOLCHAIN_VARIANT%
host/llvm
> echo %LLVM_TOOLCHAIN_PATH%
C:\ATfE

  4. 在为 Zephyr 应用程序生成构建系统时，也可以将 ZEPHYR_TOOLCHAIN_VARIANT 和 LLVM_TOOLCHAIN_PATH 设置为 CMake 变量，如下所示：

    west build ... -- -DZEPHYR_TOOLCHAIN_VARIANT=host/llvm -DLLVM_TOOLCHAIN_PATH=...

工具链设置

由于 LLVM 与 GNU 工具高度兼容，使用任何 LLVM 工具链进行构建时，都必须指定一些设置，让编译器知道要使用哪些工具：

链接器

  • 设置 CONFIG_LLVM_USE_LLD=y 以使用 LLVM 链接器。

  • 设置 CONFIG_LLVM_USE_LD=y 以使用 GNU LD 链接器。

运行时库

  • 设置 CONFIG_COMPILER_RT_RTLIB=y 以使用 LLVM 运行时库。

  • 设置 CONFIG_LIBGCC_RTLIB=y 以使用 LibGCC 运行时库。

west build ... -- -DZEPHYR_TOOLCHAIN_VARIANT=host/llvm -DLLVM_TOOLCHAIN_PATH=... -DCONFIG_LLVM_USE_LLD=y -DCONFIG_COMPILER_RT_RTLIB=y
