MPLAB XC32

  1. 下载并安装适用于你的操作系统的 MPLAB XC32 Compiler。

  2. 设置以下环境变量：

    • 将 ZEPHYR_TOOLCHAIN_VARIANT 设置为 xc32。

    • 将 XC32_TOOLCHAIN_PATH 设置为工具链的安装目录。

  3. 要检查当前环境中这些变量是否设置正确，请参照以下 shell 会话示例（你系统上的 XC32_TOOLCHAIN_PATH 值可能不同）：

    # Linux, macOS:
$ echo $ZEPHYR_TOOLCHAIN_VARIANT
xc32
$ echo $XC32_TOOLCHAIN_PATH
/opt/microchip/xc32/v5.00

# Windows:
> echo %ZEPHYR_TOOLCHAIN_VARIANT%
xc32
> echo %XC32_TOOLCHAIN_PATH%
C:\Microchip\xc32\v5.00

  4. 对于 Microchip SoC，将 XC_PACK_DIR 设置为已安装的 Microchip 器件系列包（DFP）所在的根目录。

    备注

    Zephyr 使用 XC_PACK_DIR 查找与所选 SoC 匹配的 DFP，并向 XC32 工具链传递所需的 -mdfp 和 -mprocessor 标志。

    例如：

    # Linux, macOS:
$ export XC_PACK_DIR=/home/path/.packs/microchip

# Windows:
> set XC_PACK_DIR=C:\Users\path\.mchp_packs\Microchip
