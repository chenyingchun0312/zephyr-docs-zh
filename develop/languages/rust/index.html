Rust 语言支持

Rust 是一种现代系统编程语言，旨在提供内存安全、并发和高性能，同时不牺牲底层控制能力。它通过独特的所有权模型实现这一点，在编译时就消除了空指针解引用和数据竞争等常见缺陷。

Rust 对安全性和正确性的重视，使其特别适合嵌入式系统以及对可靠性要求极高的环境。此外，Rust 在没有运行时或垃圾回收器的情况下提供强大的抽象，让开发者既能编写高层代码，也能自信、高效地编写底层硬件交互代码。

这些特性使 Rust 成为 Zephyr 项目的有力选择，因为在这类项目中，资源限制和系统稳定性至关重要。

启用 Rust 支持

要在 Zephyr 应用程序中启用 Rust 支持，需要完成以下几件事：

  1. 由于 Rust 目前是一个可选模块，需要先启用该模块。最简单的方法是使用 west：

    west config manifest.project-filter +zephyr-lang-rust
west update

    这样，Rust 语言支持应会被放到 Zephyr 工作区的 modules/lang/rust 中。

  2. 通过 prj.conf 中的 CONFIG_RUST 启用 Rust 支持。最简单的做法（对下一步的 CMake 设置同样适用）是从 modules/lang/rust/samples 中的某个示例开始。

  3. 配置应用程序的 CMakeLists.txt 文件以支持 Rust。同样，最简单的方法是从示例中复制，内容大致如下：

    cmake_minimum_required(VERSION 3.28.0)

find_package(Zephyr REQUIRED HINTS $ENV{ZEPHYR_BASE})

project(my_app)
rust_cargo_application()

  4. 创建一个 Cargo.toml，描述如何构建 Rust 应用程序。以 Hello World 示例为例：

    [package]
# This must be rustapp for now.
name = "rustapp"
version = "0.1.0"
edition = "2021"
description = "The description of my app"
license = "Apache-2.0 or MIT"

[lib]
crate-type = ["staticlib"]

[dependencies]
zephyr = "0.1.0"
log = "0.4.22"

    唯一必需的依赖是 zephyr，它提供用于与 Zephyr 交互的 zephyr crate。

  5. 像构建任何其他 Zephyr 应用程序一样进行构建。目前只有少数目标支持 Rust（可在 modules/lang/rust/etc/platforms.txt 文件中查看）。

API 文档

该模块最新版本的 API Documentation 托管在 gh-pages 上。

这份文档是针对通用目标、启用全部特性生成的。当你有一个可以构建的应用程序后，可以专门为你的目标生成文档：

west build -t rustdoc

...

Generated /my/path/app/zephyr/build/doc/rust/target/riscv32i-unknown-none-elf/doc/rustapp/index.html

最后打印出的路径可以在浏览器中打开。顶层文档对应你的应用程序本身。在左侧边栏中找到 'zephyr' crate，即可进入 Zephyr 的文档。该页面还会为应用程序直接或间接使用的所有依赖生成本地文档。
