Minimal libc

最基础的 C 库名为“minimal libc”，它是 Zephyr 代码库的一部分，提供满足 Zephyr 及其子系统需求所需的标准 C 库最小子集，主要涉及字符串操作和显示方面。

它的资源占用非常小，适合不依赖 ISO C 标准库中较少使用部分的项目。它还可以与多种不同的工具链配合使用。

minimal libc 的实现位于 Zephyr 主源码树的 lib/libc/minimal 中。

函数

minimal libc 实现了满足 Zephyr 内核需求所需的 ISO/IEC 9899:2011 标准 C 库函数的最小子集，具体由 编码准则规则 A.4 定义。

格式化输出

minimal libc 没有实现自己的格式化输出处理器，而是将 printf 和 sprintf 等 C 标准格式化输出函数映射到 cbprintf() 函数，后者是 Zephyr 自己的、与 C99 兼容的格式化输出实现。

更多详细信息，请参阅 格式化输出 操作系统服务文档。

动态内存管理

minimal libc 使用 通用 C 库 提供的 malloc 系列 API 实现，而后者本身构建在 内核内存堆 API 之上。

错误号

Zephyr API 中广泛使用错误号，作为函数返回值来表示错误情况。它们通常以本节所定义整数字面量的负值形式返回，并定义在 errno.h 头文件中。

minimal libc 中加入了 POSIX errno.h specification 及其他事实标准来源中定义的部分错误号。

Zephyr 有意使 minimal libc 错误号的取值与 Zephyr 支持的各种 C 标准库实现保持一致。minimal libc 的 errno.h 会与 Newlib 的进行比对，以确保错误号保持一致。
