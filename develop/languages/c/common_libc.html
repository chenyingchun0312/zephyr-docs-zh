通用 C 库代码

Zephyr 提供了一些 C 库函数，设计为可与多种 C 库配合使用。这些函数要么提供多种 C 库中都没有的功能，要么用于以更适合 Zephyr 环境的代码替换 C 库中的相应功能

时间函数

这里提供了标准 C 函数 time() 的一个实现，它依赖于 Zephyr 函数 sys_clock_gettime()。可以通过选中 COMMON_LIBC_TIME 启用该函数。

动态内存管理

可以在应用程序配置文件中选中 CONFIG_COMMON_LIBC_MALLOC，启用通用动态内存管理实现。

通用 C 库在内部使用 内核内存堆 API 管理内存堆，供 malloc() 和 free() 等标准动态内存管理接口函数使用。

内部内存堆通常位于 .bss 段中。但启用用户空间时，它会被放在一个名为 z_malloc_partition 的专用内存分区中，用户模式线程可以访问该分区。内部内存堆的大小由 CONFIG_COMMON_LIBC_MALLOC_ARENA_SIZE 指定。

对于使用通用 C 库的应用程序，默认堆大小为零（没有堆）。对于其他 C 库的使用者，如果存在 MMU，默认堆大小为 16kB；否则，堆会使用所有可用内存。

另外还有单独的选项用于选择 calloc()（COMMON_LIBC_CALLOC）和 reallocarray()（COMMON_LIBC_REALLOCARRAY）。这两个选项默认都是启用的，因为它们不会影响未使用这些函数的应用程序的内存用量。

通用 C 库实现的标准动态内存管理接口函数是线程安全的，可以被多个线程同时调用。这些函数实现于 lib/libc/common/source/stdlib/malloc.c。
