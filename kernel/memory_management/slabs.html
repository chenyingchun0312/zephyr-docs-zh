内存块（slab）

memory slab 是一种内核对象，允许从指定的内存区域中动态分配内存块。内存块（slab）中的所有内存块大小固定且相同，因此可以高效地分配和释放，也避免了内存碎片问题。

概念

可以定义任意数量的内存块（slab）（仅受可用 RAM 限制）。每个内存块（slab）通过其内存地址引用。

内存块（slab）具有以下关键属性：

  • 每个块的 块大小，以字节为单位。在 32 位平台上必须至少为 4N 字节，在 64 位平台上必须至少为 8N 字节，其中 N 大于 0。

  • 可供分配的 块数量。必须大于零。

  • 为内存块（slab）的各个块提供内存的 缓冲区。其长度必须至少为“块大小”乘以“块数量”字节。

内存块（slab）的缓冲区必须按 N 字节边界对齐，其中 N 是 2 的幂。在 32 位平台上 N 必须至少为 4，在 64 位平台上必须至少为 8。为确保缓冲区中的所有内存块都同样按该边界对齐，块大小也必须是 N 的整数倍。

内存块（slab）在使用前必须先初始化。初始化会将其所有块标记为未使用。

需要使用内存块的线程只需从内存块（slab）中分配一个即可。线程用完内存块后，必须将其释放回内存块（slab），以便重复使用。

如果所有块当前都在使用中，线程可以选择等待某个块变为可用。任意数量的线程可以同时在空的内存块（slab）上等待；当有内存块可用时，它会被分配给等待时间最长的最高优先级线程。

如有需要，可以定义多个内存块（slab）。这样就可以有一个块较小的内存块（slab），以及其他块较大的内存块（slab）。也可以改用内存池对象。

内部运作

内存块（slab）的缓冲区是一个由固定大小的块组成的数组，块与块之间没有浪费的空间。

内存块（slab）使用链表跟踪未分配的块。32 位平台使用每个未使用块的前 4 个字节提供所需的链接，64 位平台则使用每个未使用块的前 8 个字节。

实现

定义内存块（slab）

内存块（slab）使用 k_mem_slab 类型的变量定义，然后必须调用 k_mem_slab_init() 对其进行初始化。

以下代码定义并初始化一个内存块（slab），它包含 6 个长度为 400 字节的块，每个块都按 8 字节边界对齐。

struct k_mem_slab my_slab;
char __aligned(8) my_slab_buffer[6 * 400];

k_mem_slab_init(&my_slab, my_slab_buffer, 400, 6);

也可以调用 K_MEM_SLAB_DEFINE，在编译时定义并初始化内存块（slab）。

以下代码与上面的代码段效果相同。注意，该宏同时定义了内存块（slab）及其缓冲区。

K_MEM_SLAB_DEFINE(my_slab, 400, 6, 8);

类似地，也可以在私有作用域中定义内存块（slab）：

K_MEM_SLAB_DEFINE_STATIC(my_slab, 400, 6, 8);

分配内存块

调用 k_mem_slab_alloc() 分配内存块。

以下代码基于上面的示例，最多等待 100 毫秒以获得可用的内存块，然后将其填充为零。如果没有获得合适的块，则打印警告。

char *block_ptr;

if (k_mem_slab_alloc(&my_slab, (void **)&block_ptr, K_MSEC(100)) == 0) {
    memset(block_ptr, 0, 400);
    ...
} else {
    printf("Memory allocation time-out");
}

释放内存块

调用 k_mem_slab_free() 释放内存块。

以下代码基于上面的示例，分配一个内存块，然后在不再需要时将其释放。

char *block_ptr;

k_mem_slab_alloc(&my_slab, (void **)&block_ptr, K_FOREVER);
... /* use memory block pointed at by block_ptr */
k_mem_slab_free(&my_slab, (void *)block_ptr);

查询使用情况

可以在运行时查询内存块（slab）当前的使用情况。k_mem_slab_num_used_get() 返回当前已分配的块数，k_mem_slab_num_free_get() 返回仍然可用的块数。启用 CONFIG_MEM_SLAB_TRACE_MAX_UTILIZATION 后，k_mem_slab_max_used_get() 报告同时分配的块数峰值，而 k_mem_slab_runtime_stats_get() 会把这些数据一并放在一个 sys_memory_stats 结构体中返回。

建议用法

使用内存块（slab）以固定大小的块为单位分配和释放内存。

从一个线程向另一个线程发送大量数据时，使用内存块（slab）中的块，以避免不必要的数据复制。
