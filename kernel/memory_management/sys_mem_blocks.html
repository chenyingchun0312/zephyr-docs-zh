内存块分配器

内存块分配器允许从指定的内存区域动态分配内存块，其特点是：

  • 所有内存块大小固定且相同。

  • 可以一次分配或释放多个块。

  • 一起分配的一组块可能不连续。这对分散-聚集（scatter-gather）DMA 传输等操作很有用。

  • 已分配块的簿记在相关缓冲区之外进行（与内存块（slab）不同）。这使得缓冲区可以位于能够断电以节省能耗的内存区域中。

概念

可以定义任意数量的内存块分配器（仅受可用 RAM 限制）。每个分配器通过其内存地址引用。

内存块分配器具有以下关键属性：

  • 每个块的 块大小，以字节为单位。必须至少为 4N 字节，其中 N 大于 0。

  • 可供分配的 块数量。必须大于零。

  • 一个 缓冲区，作为内存块分配器分配块时所用的后备存储。其长度必须至少为“块大小”乘以“块数量”字节。

  • 一个 块位图，用于跟踪哪些块已被分配。

缓冲区必须按 N 字节边界对齐，其中 N 是大于 2 的 2 的幂（即 4、8、16……）。为确保缓冲区中的所有内存块都同样按该边界对齐，块大小也必须是 N 的整数倍。

由于需要使用并创建内部簿记结构，每个内存块分配器都必须在编译时声明和定义。

内部运作

与分配器关联的每个缓冲区都是一个由固定大小的块组成的数组，块与块之间没有浪费的空间。

内存块分配器使用位图跟踪未分配的块。

内存块分配器

在内部，内存块分配器使用位图跟踪哪些块已被分配。每个分配器借助 sys_bitarray 接口，从后备缓冲区中逐个获取内存块，直到达到所请求的块数。分配器的所有元数据都存储在后备缓冲区之外。由于分配器代码从不接触缓冲区的内容，后备缓冲区所在的内存区域可以断电以节省能耗。

多内存块分配器组

多内存块分配器组的工具函数用于方便地管理一组分配器。可以编写自定义函数，选择使用该组管理的哪个分配器来分配块。

分配器组应在运行时通过 sys_multi_mem_blocks_init() 初始化，之后可以通过 sys_multi_mem_blocks_add_allocator() 添加各个分配器。

要从分配器组中分配内存块，需要调用 sys_multi_mem_blocks_alloc() 并传入一个不透明的“配置”参数。该参数会直接传给分配器选择函数，以便选出合适的分配器。选定分配器后，通过 sys_mem_blocks_alloc() 分配内存块。

已分配的内存块可以通过 sys_multi_mem_blocks_free() 释放。调用者不需要传入配置参数。分配器代码会根据传入的内存地址匹配找到正确的分配器，然后通过 sys_mem_blocks_free() 释放内存块。

用法

定义内存块分配器

内存块分配器使用 sys_mem_blocks_t 类型的变量定义。它需要在编译时通过调用 SYS_MEM_BLOCKS_DEFINE 进行定义和初始化。

以下代码定义并初始化一个内存块分配器，它包含 4 个长度为 64 字节的块，每个块都按 4 字节边界对齐：

SYS_MEM_BLOCKS_DEFINE(allocator, 64, 4, 4);

类似地，也可以在私有作用域中定义内存块分配器：

SYS_MEM_BLOCKS_DEFINE_STATIC(static_allocator, 64, 4, 4);

也可以为分配器提供一个预先定义的缓冲区，这样缓冲区可以单独放置。注意，定义该缓冲区时 必须 指定其对齐方式。

uint8_t __aligned(4) backing_buffer[64 * 4];
SYS_MEM_BLOCKS_DEFINE_WITH_EXT_BUF(allocator, 64, 4, backing_buffer);

分配内存块

调用 sys_mem_blocks_alloc() 分配内存块。

int ret;
uintptr_t blocks[2];

ret = sys_mem_blocks_alloc(allocator, 2, blocks);

如果 ret == 0，数组 blocks 中将包含指向已分配块的内存地址。

释放内存块

调用 sys_mem_blocks_free() 释放内存块。

以下代码基于上面的示例，分配 2 个内存块，然后在不再需要时将其释放。

int ret;
uintptr_t blocks[2];

ret = sys_mem_blocks_alloc(allocator, 2, blocks);
... /* perform some operations on the allocated memory blocks */
ret = sys_mem_blocks_free(allocator, 2, blocks);

使用多内存块分配器组

以下代码演示如何初始化分配器组：

sys_mem_blocks_t *choice_fn(struct sys_multi_mem_blocks *group, void *cfg)
{
    ... /* choose which allocator in the group to use based on cfg */
}

SYS_MEM_BLOCKS_DEFINE(allocator0, 64, 4, 4);
SYS_MEM_BLOCKS_DEFINE(allocator1, 64, 4, 4);

static sys_multi_mem_blocks_t alloc_group;

sys_multi_mem_blocks_init(&alloc_group, choice_fn);
sys_multi_mem_blocks_add_allocator(&alloc_group, &allocator0);
sys_multi_mem_blocks_add_allocator(&alloc_group, &allocator1);

从分配器组中分配和释放内存块：

int ret;
uintptr_t blocks[1];
size_t blk_size;

ret = sys_multi_mem_blocks_alloc(&alloc_group, UINT_TO_POINTER(0),
                                 1, blocks, &blk_size);

ret = sys_multi_mem_blocks_free(&alloc_group, 1, blocks);
