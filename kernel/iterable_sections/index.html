可迭代段

本页包含可迭代段 API 的参考文档。这些 API 可用于定义由相同大小的数据结构组成的可迭代区域，并可使用 STRUCT_SECTION_FOREACH 对其进行迭代。

概述

可迭代段是一组静态定义的同一结构体的实例，链接器会将它们放入一个连续的输出段中。这样运行时无需维护显式列表，就可以遍历所有实例。

Zephyr 目前支持两种链接脚本流程：一种基于模板，使用通过 zephyr_linker_sources() 注册的 .ld 脚本；另一种由 CMake 生成，使用 zephyr_iterable_section() 调用。为了在所有受支持的工具链上工作，目前新的可迭代段必须在两处都进行声明。

当 CONFIG_CMAKE_LINKER_GENERATOR=y 时，可迭代段的输出段由 zephyr_iterable_section() 调用生成，通过 zephyr_linker_sources() 注册的 .ld 片段中的任何 ITERABLE_SECTION_RAM/ROM 定义都会被忽略。当 CONFIG_CMAKE_LINKER_GENERATOR=n 时则正好相反：zephyr_iterable_section() 调用不会被使用，段定义由 .ld 脚本提供。

由于上游 Zephyr 必须在这两种配置下都能构建，新的可迭代段必须在这两个地方都进行声明。

创建一个可迭代段需要三个部分，它们在结构体名称以及放置在 RAM 还是 ROM 上必须保持一致：

  1. C 代码：定义结构体，并使用 STRUCT_SECTION_ITERABLE（或用于 ROM 的 const 变体）实例化条目。

  2. 链接器放置：通过以下两种方式之一声明（上游要求两种都提供）：

    • CMake：zephyr_iterable_section()，由 CMake 生成的流程使用。

    • 链接脚本：通过 zephyr_linker_sources() 注册的 ITERABLE_SECTION_RAM/ROM，由基于模板的流程使用。

第 1 步：在 C 中定义数据

在公共头文件中定义结构体，并提供一个使用 STRUCT_SECTION_ITERABLE 实例化条目的辅助宏：

struct my_data {
         int a, b;
};

#define DEFINE_DATA(name, _a, _b) \
         STRUCT_SECTION_ITERABLE(my_data, name) = { \
                 .a = _a, \
                 .b = _b, \
         }

...

DEFINE_DATA(d1, 1, 2);
DEFINE_DATA(d2, 3, 4);
DEFINE_DATA(d3, 5, 6);

对于驻留在 ROM 中的可迭代段，实例必须声明为 const，以便编译器将它们输出到只读输入段中。C 声明与 CMake 放置（参见第 2 步）在放置于 RAM 还是 ROM 上必须保持一致。

第 2 步：在 CMake 中声明段

zephyr_iterable_section() 的 NAME 参数必须与传给 STRUCT_SECTION_ITERABLE 的结构体名称一致。GROUP 参数用于选择生成的输出段所在的链接器分组。

驻留在 RAM 中的示例：

# CMakeLists.txt
zephyr_iterable_section(NAME my_data GROUP DATA_REGION ${XIP_ALIGN_WITH_INPUT})

驻留在 ROM 中的示例（实例在 C 中声明为 const）：

# CMakeLists.txt
zephyr_iterable_section(NAME my_data GROUP RODATA_REGION)

完整的参数列表以及可用 GROUP 选项的更详细说明，请参阅 cmake/modules/extensions.cmake 中的 zephyr_iterable_section()。

第 3 步：提供链接脚本

链接脚本使用 ITERABLE_SECTION_RAM 或 ITERABLE_SECTION_ROM 生成实际的段。

驻留在 RAM 中：

/* sections-ram.ld */
#include <zephyr/linker/iterable_sections.h>

ITERABLE_SECTION_RAM(my_data, Z_LINK_ITERABLE_SUBALIGN)

驻留在 ROM 中：

/* sections-rom.ld */
#include <zephyr/linker/iterable_sections.h>

ITERABLE_SECTION_ROM(my_data, Z_LINK_ITERABLE_SUBALIGN)

在 CMakeLists.txt 中注册链接脚本：

zephyr_linker_sources(<location> <path-to-ld-file>)

完整的参数列表以及可用 <location> 选项的更详细说明，请参阅 cmake/modules/extensions.cmake 中的 zephyr_linker_sources()。

遍历条目

段就位后，使用 STRUCT_SECTION_FOREACH 遍历其中的条目：

STRUCT_SECTION_FOREACH(my_data, data) {
        printk("%p: a: %d, b: %d\n", data, data->a, data->b);
}

备注

链接器会按名称对条目排序后放置，因此无论这些条目在代码中以何种方式定义，上面的示例都会依次访问 d1、d2 和 d3。
