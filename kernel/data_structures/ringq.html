sys_ringq 数据结构

  • 概述

    • 并发

  • 实例化与使用

  • API 参考

概述

环形队列（或循环缓冲区）是一种数据结构，它使用单个固定大小的缓冲区，并将其视为首尾相连。这种结构特别适合按顺序缓冲数据项。

当需要将固定大小离散数据的生产者和消费者解耦，又不想处理部分读取或可变长度负载的问题时，就可以使用 ringq。这一点使它有别于 ring_buffer 数据结构，后者是面向字节的流式数据结构。

并发

sys_ringq API 不提供任何并发控制。根据使用方式，当从多个线程访问 sys_ringq 结构体时，应用程序应使用适当的同步机制（例如互斥量、信号量）加以保护，以确保线程安全。

实例化与使用

可以使用 SYS_RINGQ_DEFINE(name, item_size, item_capacity) 宏声明 sys_ringq，也可以在运行时使用 sys_ringq_init(struct sys_ringq *ringq, uint8_t *data, size_t data_size, size_t item_size); 函数创建。

SYS_RINGQ_DEFINE(my_ringq, item_size, item_capacity);
/* equivalent to */

static struct sys_ringq my_ringq;
static uint8_t buffer[item_size * item_capacity];
void init_fn (void) {
   sys_ringq_init(&my_ringq, buffer, sizeof(buffer), item_size);
   ....
}

sys_ringq 初始化完成后，可以使用 sys_ringq_put() 函数向 ringq 添加数据项，并使用 sys_ringq_get() 函数取出数据项。ringq 会保持数据项的顺序，并确保对底层数据缓冲区进行正确的边界检查。

struct my_item item_to_add = { ... };
struct my_item item_removed;

/* Add an item to the queue */
if (sys_ringq_put(&my_ringq, &item_to_add) == 0) {
    // Item added successfully
} else {
    // ringq is full
}

/* Remove an item from the queue */
if (sys_ringq_get(&my_ringq, &item_removed) == 0) {
    // Item removed successfully
} else {
    // ringq is empty
}

除了标准的数据操作（sys_ringq_put() 和 sys_ringq_get()）之外，sys_ringq API 还提供了一组实用函数，用于管理和检查数据结构的状态。

  • sys_ringq_capacity() – 返回 sys_ringq 的总容量，即它可以容纳的数据项数量。

  • sys_ringq_empty() – 如果 sys_ringq 不包含任何数据项，则返回 true。

  • sys_ringq_full() – 如果 sys_ringq 无法再接受更多数据项，则返回 true。

  • sys_ringq_space() – 返回剩余的空闲槽位数量。

  • sys_ringq_size() – 返回当前存储的数据项数量。

  • sys_ringq_reset() – 将 sys_ringq 重置为空状态。
