计时函数

计时函数可用于获取一段代码的执行时间，以辅助分析和优化。

请注意，计时函数使用的定时器可能与默认的内核定时器不同，具体使用哪个定时器由架构、SoC 或开发板配置指定。

配置

要使用计时函数，需要启用 CONFIG_TIMING_FUNCTIONS。

用法

收集计时信息的步骤如下：

  1. 调用 timing_init() 初始化定时器。

  2. 调用 timing_start() 表示开始收集计时信息。这通常会启动定时器。

  3. 调用 timing_counter_get() 标记代码执行的开始。

  4. 调用 timing_counter_get() 标记代码执行的结束。

  5. 调用 timing_cycles_get() 获取代码执行开始到结束之间的定时器周期数。

  6. 使用总周期数调用 timing_cycles_to_ns()，将周期数转换为纳秒。

  7. 从第 3 步开始重复，以收集其他代码块的计时信息。

  8. 调用 timing_stop() 表示结束收集计时信息。这通常会停止定时器。

示例

以下示例展示了如何使用计时函数：

#include <zephyr/timing/timing.h>

void gather_timing(void)
{
    timing_t start_time, end_time;
    uint64_t total_cycles;
    uint64_t total_ns;

    timing_init();
    timing_start();

    start_time = timing_counter_get();

    code_execution_to_be_measured();

    end_time = timing_counter_get();

    total_cycles = timing_cycles_get(&start_time, &end_time);
    total_ns = timing_cycles_to_ns(total_cycles);

    timing_stop();
}
