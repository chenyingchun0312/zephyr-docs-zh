信号量

semaphore （信号量）是实现传统计数信号量的内核对象。

概念

可以定义任意数量的信号量（仅受可用 RAM 限制）。每个信号量通过其内存地址引用。

信号量具有以下关键属性：

  • 计数，表示信号量还可以被获取的次数。计数为零表示信号量不可用。

  • 上限，表示信号量计数所能达到的最大值。

信号量必须先初始化才能使用。其计数必须设置为小于或等于上限的非负值。

线程或 ISR 都可以 释放 （give）信号量。释放信号量会使其计数加一，除非计数已经等于上限。

线程可以 获取 （take）信号量。获取信号量会使其计数减一，除非信号量不可用（即计数为零）。当信号量不可用时，线程可以选择等待信号量被释放。任意数量的线程可以同时在一个不可用的信号量上等待。信号量被释放后，将由等待时间最长的最高优先级线程获取。

备注

可以将信号量初始化为“满”状态（计数等于上限），以限制能同时执行临界区的线程数量。也可以将信号量初始化为空（计数为 0，上限大于 0），从而形成一道闸门，在信号量计数增加之前，任何等待中的线程都无法通过。普通信号量的所有标准用法都受支持。

备注

内核允许 ISR 获取信号量，但如果信号量不可用，ISR 不得尝试等待。

实现

定义信号量

信号量使用 k_sem 类型的变量定义，然后必须调用 k_sem_init() 进行初始化。

以下代码定义了一个信号量，并将其计数设为 0、上限设为 1，从而将其配置为二值信号量。

struct k_sem my_sem;

k_sem_init(&my_sem, 0, 1);

也可以调用 K_SEM_DEFINE 在编译时定义并初始化信号量。

以下代码与上面的代码段效果相同。

K_SEM_DEFINE(my_sem, 0, 1);

释放信号量

调用 k_sem_give() 释放信号量。

以下代码基于上面的示例，释放信号量，表示有一个数据单元可供消费者线程处理。

void input_data_interrupt_handler(void *arg)
{
    /* notify thread that data is available */
    k_sem_give(&my_sem);

    ...
}

获取信号量

调用 k_sem_take() 获取信号量。

以下代码基于上面的示例，最多等待 50 毫秒，直到信号量被释放。如果未能及时获得信号量，则发出警告。

void consumer_thread(void)
{
    ...

    if (k_sem_take(&my_sem, K_MSEC(50)) != 0) {
        printk("Input data not available!");
    } else {
        /* fetch available data */
        ...
    }
    ...
}

建议用法

使用信号量控制多个线程对一组资源的访问。

使用信号量在生产者与消费者线程或 ISR 之间同步处理。
