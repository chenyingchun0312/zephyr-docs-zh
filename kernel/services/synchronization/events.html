事件

event object （事件对象）是实现传统事件机制的内核对象。

概念

可以定义任意数量的事件对象（仅受可用 RAM 限制）。每个事件对象通过其内存地址引用。一个或多个线程可以在事件对象上等待，直到所需的事件集合被投递到该事件对象。当有新事件投递到事件对象时，所有等待条件已满足的线程会同时变为就绪状态。

事件对象具有以下关键属性：

  • 一个 32 位值，用于记录哪些事件已投递给它。

事件对象必须先初始化才能使用。

事件可以由线程或 ISR 投递。投递事件时，既可以覆盖现有的事件集合，也可以按位追加到现有集合中。覆盖现有事件集合称为设置（setting），按位追加称为发布（posting）。发布和设置事件都可能满足多个在该事件对象上等待的线程的匹配条件。所有匹配条件已满足的线程会同时被激活。

线程可以等待一个或多个事件，既可以等待所有请求的事件，也可以等待其中任意一个。此外，发起等待请求的线程还可以选择在等待之前重置事件对象当前记录的事件集合。当多个线程在同一事件对象上等待时，使用此选项要格外小心。

备注

内核允许 ISR 查询事件对象，但 ISR 不得尝试等待事件。

实现

定义事件对象

事件对象使用 k_event 类型的变量定义，然后必须调用 k_event_init() 进行初始化。

以下代码定义了一个事件对象。

struct k_event my_event;

k_event_init(&my_event);

也可以调用 K_EVENT_DEFINE 在编译时定义并初始化事件对象。

以下代码与上面的代码段效果相同。

K_EVENT_DEFINE(my_event);

设置事件

调用 k_event_set() 设置事件对象中的事件。

以下代码基于上面的示例，将事件对象记录的事件设置为 0x001。

void input_available_interrupt_handler(void *arg)
{
    /* notify threads that data is available */

    k_event_set(&my_event, 0x001);

    ...
}

发布事件

调用 k_event_post() 向事件对象发布事件。

以下代码基于上面的示例，向事件对象发布一组事件。

void input_available_interrupt_handler(void *arg)
{
    ...

    /* notify threads that more data is available */

    k_event_post(&my_event, 0x120);

    ...
}

等待事件（不清除）

线程调用 k_event_wait() 等待事件。

以下代码基于上面的示例，最多等待 50 毫秒，直到指定事件中的任意一个被发布。如果没有事件及时发布，则发出警告。

void consumer_thread(void)
{
    uint32_t  events;

    events = k_event_wait(&my_event, 0xFFF, false, K_MSEC(50));
    if (events == 0) {
        printk("No input devices are available!");
    } else {
        /* Access the desired input device(s) */
        ...
    }
    ...
}

另外，消费者线程也可以使用 k_event_wait_all() 等待所有事件都发生后再继续执行。

void consumer_thread(void)
{
    uint32_t  events;

    events = k_event_wait_all(&my_event, 0x121, false, K_MSEC(50));
    if (events == 0) {
        printk("At least one input device is not available!");
    } else {
        /* Access the desired input devices */
        ...
    }
    ...
}

等待事件（清除）

线程调用 k_event_wait_safe() 等待事件（收到后以原子方式清除）。

以下代码基于上面的示例，最多等待 50 毫秒，直到指定事件中的任意一个被发布。如果没有事件及时发布，则发出警告。

如果及时收到事件，这些事件将不再存在于事件对象中，直到下一次被设置或发布。

void consumer_thread(void)
{
    uint32_t  events;

    events = k_event_wait_safe(&my_event, 0xFFF, false, K_MSEC(50));
    if (events == 0) {
        printk("No input devices are available!");
    } else {
        /* Access the desired input device(s) */
        ...
    }
    ...
}

另外，消费者线程也可以使用 k_event_wait_all_safe() 等待所有事件都发生（收到后以原子方式清除）后再继续执行。

如果及时收到所有事件，这些事件将不再存在于事件对象中，直到下一次被设置或发布。

void consumer_thread(void)
{
    uint32_t  events;

    events = k_event_wait_all_safe(&my_event, 0x121, false, K_MSEC(50));
    if (events == 0) {
        printk("At least one input device is not available!");
    } else {
        /* Access the desired input devices */
        ...
    }
    ...
}

建议用法

使用事件表示一组条件已经发生。

使用事件一次向多个线程传递少量数据。
