条件变量

condition variable 是一种同步原语，使线程能够等待某个特定条件发生。

概念

可以定义任意数量的条件变量（仅受可用 RAM 限制）。每个条件变量通过其内存地址引用。

线程可以利用条件变量来等待某个条件变为真。

条件变量本质上是一个线程队列：当某种执行状态（即某个条件）不符合预期时，线程可以把自己放入该队列（即在条件上等待）。函数 k_condvar_wait() 以原子方式执行以下步骤：

  1. 释放最后获取的互斥量。

  2. 将当前线程放入条件变量队列。

其他线程在改变上述状态后，可以通过 k_condvar_signal() 或 k_condvar_broadcast() 在该条件上发出信号，唤醒一个（或多个）等待中的线程，使其继续执行。被唤醒的线程随后：

  1. 重新获取之前释放的互斥量。

  2. 从 k_condvar_wait() 返回。

无论等待因何结束（线程收到信号、指定的超时到期，或者以不阻塞的方式请求等待），k_condvar_wait() 返回时，调用线程总是已重新锁定关联的互斥量。

条件变量必须先初始化才能使用。

实现

定义条件变量

条件变量使用 k_condvar 类型的变量定义，然后必须调用 k_condvar_init() 进行初始化。

以下代码定义了一个条件变量：

struct k_condvar my_condvar;

k_condvar_init(&my_condvar);

也可以调用 K_CONDVAR_DEFINE 在编译时定义并初始化条件变量。

以下代码与上面的代码段效果相同。

K_CONDVAR_DEFINE(my_condvar);

在条件变量上等待

线程可以调用 k_condvar_wait() 在某个条件上等待。

以下代码在条件变量上等待。

K_MUTEX_DEFINE(mutex);
K_CONDVAR_DEFINE(condvar)

int main(void)
{
    k_mutex_lock(&mutex, K_FOREVER);

    /* block this thread until another thread signals cond. While
     * blocked, the mutex is released, then re-acquired before this
     * thread is woken up and the call returns.
     */
    k_condvar_wait(&condvar, &mutex, K_FOREVER);
    ...
    k_mutex_unlock(&mutex);
}

向条件变量发送信号

调用 k_condvar_signal() 可向一个线程发送条件变量信号，调用 k_condvar_broadcast() 可向多个线程发送信号。

以下代码基于上面的示例。

void worker_thread(void)
{
    k_mutex_lock(&mutex, K_FOREVER);

    /*
     * Do some work and fulfill the condition
     */
    ...
    ...
    k_condvar_signal(&condvar);
    k_mutex_unlock(&mutex);
}

建议用法

将条件变量与互斥量配合使用，以便从一个线程向另一个线程通知状态（条件）的变化。条件变量本身并不是条件，也不是事件。条件包含在外围的程序逻辑中。

单独的互斥量并非为用作通知/同步机制而设计，它只用于提供对共享资源的互斥访问。
