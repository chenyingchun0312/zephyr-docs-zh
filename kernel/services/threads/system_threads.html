系统线程

  • 实现

    • 编写 main() 函数

  • 建议用法

系统线程（system thread）是内核在系统初始化期间自动创建的线程。

内核会创建以下系统线程：

主线程

该线程执行内核初始化，然后调用应用程序的 main() 函数（如果已定义）。

默认情况下，主线程使用所配置的最高可抢占线程优先级（即 0）。如果内核未配置为支持可抢占线程，主线程使用所配置的最低协作式线程优先级（即 -1）。

主线程在执行内核初始化或执行应用程序的 main() 函数期间是关键线程（essential thread），这意味着如果该线程中止，就会引发致命系统错误。如果未定义 main()，或者它执行后正常返回，主线程会正常终止，不会引发错误。

空闲线程

当系统没有其他工作要做时，该线程才会执行。如果可能，空闲线程会启用开发板的电源管理支持以节省功耗；否则，空闲线程只是执行一个“什么也不做”的循环。只要系统在运行，空闲线程就一直存在，永不终止。

空闲线程始终使用所配置的最低线程优先级。

空闲线程是关键线程，这意味着如果该线程中止，就会引发致命系统错误。

根据应用程序指定的内核和开发板配置选项，还可能创建其他系统线程。例如，启用系统工作队列会创建一个系统线程，用于处理提交给它的工作项。（参见 工作队列线程。）

实现

编写 main() 函数

内核初始化完成后，应用程序提供的 main() 函数开始执行。内核不会向该函数传递任何参数，除非选择了 CONFIG_BOOTARGS。在这种情况下，内核会向它传递参数，可以使用 main(int, char **)。

以下代码概述了一个简单的 main(void) 函数。实际应用程序中使用的函数可以根据需要任意复杂。

int main(void)
{
    /* initialize a semaphore */
    ...

    /* register an ISR that gives the semaphore */
    ...

    /* monitor the semaphore forever */
    while (1) {
        /* wait for the semaphore to be given by the ISR */
        ...
        /* do whatever processing is now needed */
        ...
    }
}

建议用法

对于只需要单个线程的应用程序，使用主线程执行基于线程的处理，而不是另外定义一个应用程序专用线程。
