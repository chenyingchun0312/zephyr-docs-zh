原子服务

atomic variable （原子变量）是可以由线程和 ISR 以不可中断的方式读取和修改的变量。在 32 位机器上它是 32 位变量，在 64 位机器上它是 64 位变量。

概念

可以定义任意数量的原子变量（仅受可用 RAM 限制）。

使用内核的原子 API 操作原子变量，可以保证所需的操作正确完成，即使更高优先级的上下文也在操作同一个变量。

内核还支持对原子变量数组中的单个比特进行原子操作。

实现

定义原子变量

原子变量使用 atomic_t 类型的变量定义。

默认情况下，原子变量被初始化为零。不过，也可以使用 ATOMIC_INIT 为其指定其他值：

atomic_t flags = ATOMIC_INIT(0xFF);

操作原子变量

使用本节末尾列出的 API 操作原子变量。

以下代码展示了如何使用原子变量来记录某个函数被调用的次数。由于计数是以原子方式递增的，即使调用该函数的线程被同样调用该例程的更高优先级上下文中断，计数也不会在递增过程中被破坏。

atomic_t call_count;

int call_counting_routine(void)
{
    /* increment invocation counter */
    atomic_inc(&call_count);

    /* do rest of routine's processing */
    ...
}

操作原子变量数组

可以按常规方式定义 32 位原子变量的数组。此外，也可以使用 ATOMIC_DEFINE 定义一个 N 位的原子变量数组。

可以使用本节末尾列出的、名称以 _bit() 结尾的 API 操作原子变量数组中的单个比特。

以下代码展示了如何使用原子变量数组实现一组 200 个标志位。

#define NUM_FLAG_BITS 200

ATOMIC_DEFINE(flag_bits, NUM_FLAG_BITS);

/* set specified flag bit & return its previous value */
int set_flag_bit(int bit_position)
{
    return (int)atomic_set_bit(flag_bits, bit_position);
}

内存序

为了保证一致性和正确性，所有 Zephyr 原子 API 都应在硬件需要时包含完整的内存屏障（例如 x86 上的“串行化”指令、ARM 上的 "DMB"，或 C++ 内存模型所定义的“顺序一致”操作），以确保各个上下文看到可靠的一致视图。任何架构特定的实现都有责任确保这一行为。

建议用法

使用原子变量实现只需操作单个 32 位值的临界区处理。

使用多个原子变量，对长度超过 32 位的比特数组中的一组标志位实现临界区处理。

备注

与使用互斥量或锁中断等其他实现临界区的技术相比，使用原子变量通常要高效得多。

配置选项

相关配置选项：

  • CONFIG_ATOMIC_OPERATIONS_BUILTIN

  • CONFIG_ATOMIC_OPERATIONS_ARCH

  • CONFIG_ATOMIC_OPERATIONS_C
