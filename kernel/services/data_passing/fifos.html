FIFO

FIFO 是实现传统先进先出（FIFO）队列的内核对象，允许线程和 ISR 添加和移除任意大小的数据项。

概念

可以定义任意数量的 FIFO（仅受可用 RAM 限制）。每个 FIFO 通过其内存地址引用。

FIFO 具有以下关键属性：

  • 队列，包含已添加但尚未移除的数据项。该队列以简单链表实现。

FIFO 必须先初始化才能使用，初始化会将其队列置为空。

FIFO 数据项必须按指针的要求对齐，因为内核会保留数据项中第一个指针大小的字段，用作指向队列中下一个数据项的指针。因此，一个包含 N 字节应用程序数据的数据项需要 N+4（或 N+8）字节内存。如果使用 k_fifo_alloc_put() 添加数据项，则对数据项没有对齐或预留空间的要求，而是从调用线程的资源池中临时分配额外的内存。

备注

在所有 FIFO 数据队列中，一个 FIFO 数据项同一时刻只能有一个活动实例。如果在数据项从之前加入的队列中移除之前，就尝试将其再次加入某个队列，将导致未定义行为。

线程或 ISR 都可以向 FIFO 添加 数据项。如果有线程正在等待，数据项会直接交给该线程；否则数据项会被加入 FIFO 的队列。可排队的数据项数量没有限制。

线程可以从 FIFO 中 移除 数据项。如果 FIFO 的队列为空，线程可以选择等待数据项到来。任意数量的线程可以同时在一个空 FIFO 上等待。添加数据项时，它会交给等待时间最长的最高优先级线程。

备注

内核允许 ISR 从 FIFO 中移除数据项，但如果 FIFO 为空，ISR 不得尝试等待。

如有需要，可以将 多个数据项 串成单链表，在一次操作中添加到 FIFO。当多个写入者向 FIFO 添加多组相关数据项时，这一功能很有用，因为它能确保每组中的数据项不会与其他数据项交错。一次添加多个数据项也比逐个添加更高效，并且可以保证任何移除了某组中第一个数据项的线程都能无需等待地移除其余数据项。

实现

定义 FIFO

FIFO 使用 k_fifo 类型的变量定义，然后必须调用 k_fifo_init() 进行初始化。

以下代码定义并初始化了一个空 FIFO。

struct k_fifo my_fifo;

k_fifo_init(&my_fifo);

也可以调用 K_FIFO_DEFINE 在编译时定义并初始化一个空 FIFO。

以下代码与上面的代码段效果相同。

K_FIFO_DEFINE(my_fifo);

写入 FIFO

调用 k_fifo_put() 向 FIFO 添加数据项。

以下代码基于上面的示例，使用 FIFO 向一个或多个消费者线程发送数据。

struct data_item_t {
    void *fifo_reserved;   /* 1st word reserved for use by FIFO */
    ...
};

struct data_item_t tx_data;

void producer_thread(int unused1, int unused2, int unused3)
{
    while (1) {
        /* create data item to send */
        tx_data = ...

        /* send data to consumers */
        k_fifo_put(&my_fifo, &tx_data);

        ...
    }
}

此外，可以调用 k_fifo_put_list() 或 k_fifo_put_slist() 将数据项单链表添加到 FIFO。

最后，还可以使用 k_fifo_alloc_put() 向 FIFO 添加数据项。使用此 API 时，无需在数据项中为内核预留空间，而是从调用线程的资源池中分配额外的内存，直到该数据项被读取。

从 FIFO 读取

调用 k_fifo_get() 从 FIFO 中移除数据项。

以下代码基于上面的示例，使用 FIFO 从生产者线程获取数据项，然后以某种方式处理这些数据项。

void consumer_thread(int unused1, int unused2, int unused3)
{
    struct data_item_t  *rx_data;

    while (1) {
        rx_data = k_fifo_get(&my_fifo, K_FOREVER);

        /* process FIFO data item */
        ...
    }
}

建议用法

使用 FIFO 以“先进先出”的方式异步传递任意大小的数据项。
