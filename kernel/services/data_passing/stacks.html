栈

stack （栈）是实现传统后进先出（LIFO）队列的内核对象，允许线程和 ISR 添加和移除有限数量的整数数据值。

概念

可以定义任意数量的栈（仅受可用 RAM 限制）。每个栈通过其内存地址引用。

栈具有以下关键属性：

  • 队列，包含已添加但尚未移除的整数数据值。该队列使用 stack_data_t 类型的数组实现，并且必须按本机字长边界对齐。stack_data_t 类型对应本机字长，即 32 位或 64 位，具体取决于 CPU 架构和编译模式。

  • 最大数量，即数组中可排队的数据值的最大个数。

栈必须先初始化才能使用，初始化会将其队列置为空。

线程或 ISR 都可以向栈 添加 数据值。如果有线程正在等待，数据值会直接交给该线程；否则数据值会被加入 LIFO 的队列。

备注

如果启用了 CONFIG_NO_RUNTIME_CHECKS，内核将 不会 检测和阻止向已达到最大排队数量的栈添加数据值。向已满的栈添加数据值会导致数组溢出，进而引发不可预测的行为。

线程可以从栈中 移除 数据值。如果栈的队列为空，线程可以选择等待数据值到来。任意数量的线程可以同时在一个空栈上等待。添加数据项时，它会交给等待时间最长的最高优先级线程。

备注

内核允许 ISR 从栈中移除数据项，但如果栈为空，ISR 不得尝试等待。

实现

定义栈

栈使用 k_stack 类型的变量定义，然后必须调用 k_stack_init() 或 k_stack_alloc_init() 进行初始化。使用后者时无需提供缓冲区，而是从调用线程的资源池中分配。

以下代码定义并初始化了一个空栈，最多可容纳十个字长大小的数据值。

#define MAX_ITEMS 10

stack_data_t my_stack_array[MAX_ITEMS];
struct k_stack my_stack;

k_stack_init(&my_stack, my_stack_array, MAX_ITEMS);

也可以调用 K_STACK_DEFINE 在编译时定义并初始化栈。

以下代码与上面的代码段效果相同。注意，该宏同时定义了栈及其数据值数组。

K_STACK_DEFINE(my_stack, MAX_ITEMS);

压栈

调用 k_stack_push() 向栈添加数据项。

以下代码基于上面的示例，展示了线程如何通过将一组数据结构的内存地址保存在栈中来创建数据结构池。

/* define array of data structures */
struct my_buffer_type {
    int field1;
    ...
    };
struct my_buffer_type my_buffers[MAX_ITEMS];

/* save address of each data structure in a stack */
for (int i = 0; i < MAX_ITEMS; i++) {
    k_stack_push(&my_stack, (stack_data_t)&my_buffers[i]);
}

出栈

调用 k_stack_pop() 从栈中取出数据项。

以下代码基于上面的示例，展示了线程如何动态分配一个未使用的数据结构。当不再需要该数据结构时，线程必须将其地址压回栈中，以便该数据结构可以被重用。

struct my_buffer_type *new_buffer;

建议用法

当已知所存数据项的最大数量时，使用栈以“后进先出”的方式存储和取回整数数据值。
