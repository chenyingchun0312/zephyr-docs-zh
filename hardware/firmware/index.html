固件

概述

这一类驱动用于与各种提供服务（例如时钟管理、电源管理、引脚控制等）的固件进行交互。Zephyr 目前支持的固件汇总如下：

API 参考

通常，固件驱动旨在为其他类别的驱动提供功能。此外，不同固件的用途和功能可能各不相同。因此，这一类驱动并不实现供最终用户使用的标准 API。
