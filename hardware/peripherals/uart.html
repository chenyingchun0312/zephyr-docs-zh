通用异步收发器（UART）

概述

Zephyr 提供三种不同的方式访问 UART 外设。根据所用方式的不同，使用的 API 函数也不同，详见以下各节：

  1. 轮询 API

  2. 中断驱动 API

  3. 使用 直接存储器访问（DMA） 的 异步 API

轮询是访问 UART 外设最基本的方式。读取函数 uart_poll_in() 是非阻塞函数，返回一个字符；没有有效数据时返回 -1。写入函数 uart_poll_out() 是阻塞函数，线程会一直等待，直到给定字符发送完毕。

使用中断驱动 API 时，可能较慢的通信可以在后台进行，线程则继续执行其他任务。可以使用内核的 数据传递 功能在线程与 UART 驱动之间通信。

异步 API 允许使用 DMA 在后台读写数据，完全不打断 MCU。不过，其设置比其他方式更复杂。

警告

不应（NOT）对同一个硬件外设同时使用中断驱动 API 和异步 API，因为这两种 API 都需要硬件中断才能正常工作。同时使用两种 API 的回调会导致相互干扰。CONFIG_UART_EXCLUSIVE_API_CALLBACKS 默认启用，因此同一时间只有与一种 API 相关联的回调处于活动状态。

配置选项

最重要的是，Kconfig 选项决定了可以使用轮询 API（默认）、中断驱动 API 还是异步 API。为了尽量减小内存占用，只启用所需的功能。

相关配置选项：

  • CONFIG_SERIAL

  • CONFIG_UART_INTERRUPT_DRIVEN

  • CONFIG_UART_ASYNC_API

  • CONFIG_UART_WIDE_DATA

  • CONFIG_UART_USE_RUNTIME_CONFIGURE

  • CONFIG_UART_LINE_CTRL

  • CONFIG_UART_DRV_CMD
