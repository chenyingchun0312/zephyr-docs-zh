发光二极管（LED）

概述

LED API 用于访问发光二极管，包括单个 LED 和灯带形式。它将简单的 GPIO 驱动 LED、可 PWM 调光的 LED、专用 LED 控制器 IC 以及可寻址 LED 灯带之间的差异，抽象为一小组通用操作。

提供两个相关的子系统：

  • LED：通用 API，用于控制分立 LED 或由控制器驱动的 LED（开/关、亮度、颜色、闪烁）

  • LED Strip：专为 WS2812、APA102 等可寻址 LED 灯串设计的 API，其中每个像素都有各自的颜色值

LED 操作

驱动实现以下操作中的一部分。如果底层驱动未提供某个可选操作，调用该操作会返回 -ENOSYS。

必需操作（至少实现其中之一）：

  • led_on() / led_off()：将 LED 完全打开或关闭

  • led_set_brightness()：在 0 到 LED_BRIGHTNESS_MAX（100）范围内设置亮度；如果实现了该操作，led_on() 和 led_off() 也会自动使用它

可选操作：

  • led_blink()：以给定的亮/灭时长使 LED 开始闪烁

  • led_set_color()：设置多色 LED 各通道的颜色值

  • led_get_info()：获取描述特定 LED 的 led_info（标签、索引、颜色映射）

  • led_write_channels()：写入一段原始通道值，供将 LED 作为通道数组提供的驱动使用

LED 索引

驱动控制的每个 LED 都通过从零开始的 led 索引寻址。多色 LED 只占用一个索引，其各颜色通道一起提交给 led_set_color()。

多色 LED 的颜色通道顺序由 led_info 的 color_mapping 字段描述。每个条目都是 include/zephyr/dt-bindings/led/led.h 中定义的某个 LED_COLOR_ID_* 值：

  • LED_COLOR_ID_WHITE

  • LED_COLOR_ID_RED

  • LED_COLOR_ID_GREEN

  • LED_COLOR_ID_BLUE

  • LED_COLOR_ID_AMBER

  • LED_COLOR_ID_VIOLET

  • LED_COLOR_ID_YELLOW

  • LED_COLOR_ID_IR

设备树配置

简单 LED 通常描述为 LED 控制器的子节点，并通过设备树别名引用：

/ {
    aliases {
        led0 = &status_led;
    };

    leds {
        compatible = "gpio-leds";
        status_led: led_0 {
            gpios = <&gpio0 13 GPIO_ACTIVE_HIGH>;
            label = "Status LED";
        };
    };
};

对于多色 LED，颜色信息通过 color-mapping 属性编码，使用 include/zephyr/dt-bindings/led/led.h 中的 LED_COLOR_ID_* 值。

用法示例

使用设备树别名进行基本的开/关控制：

#include <zephyr/drivers/led.h>
#include <zephyr/devicetree.h>

#define LED_NODE DT_ALIAS(led0)
static const struct device *led_dev = DEVICE_DT_GET(DT_PARENT(LED_NODE));
static const uint32_t led_idx = DT_NODE_CHILD_IDX(LED_NODE);

int turn_on_status_led(void)
{
    if (!device_is_ready(led_dev)) {
        return -ENODEV;
    }
    return led_on(led_dev, led_idx);
}

设置亮度（0 到 100）：

/* Dim the LED to 25% brightness */
led_set_brightness(led_dev, led_idx, 25);

以亮 500 ms、灭 500 ms 的模式闪烁：

int err = led_blink(led_dev, led_idx, 500, 500);

if (err == -ENOSYS) {
    /* Driver does not implement blink natively */
}

设置多色（RGB）LED 的颜色：

/* Order of the values must match the color_mapping reported by
 * led_get_info(); for a standard RGB mapping the order is R, G, B.
 */
const uint8_t purple[] = { 0x80, 0x00, 0x80 };

led_set_color(led_dev, led_idx, ARRAY_SIZE(purple), purple);

配置选项

相关配置选项：

  • CONFIG_LED

  • CONFIG_LED_STRIP

  • CONFIG_LED_SHELL

  • CONFIG_LED_INIT_PRIORITY
