安全数字（SD 卡）接口

Zephyr 可以通过系统原生的 SD 卡接口或通过 SPI（串行外设接口）与连接的 SD 卡通信。有些设备还可以与 MMC（多媒体卡，MultiMediaCard）设备通信。

应用程序可以使用 Zephyr 的 磁盘访问 API 将 SD 卡用作存储设备，也可以使用 Zephyr 的 SD 卡子系统直接读写卡。

SD 主机控制器（SDHC）

SD 主机控制器（SDHC）是能够向 SD 卡发送命令的设备。这些命令可以通过系统原生的 SD 卡接口发送，也可以通过 SPI 发送。

应用程序一般不应直接使用 SD 主机控制器 API，而应使用 Zephyr 的 SD 卡子系统。

请求

SD 主机控制器（SDHC）API 的核心是 sdhc_request() API。请求包含一个 sdhc_command 命令结构体和一个可选的 sdhc_data 数据结构体。调用者可以检查返回码或 SD 命令结构体的 response 字段，以判断 SDHC 请求是否成功。通过数据结构体，调用者可以指定要传输的块数，以及读写这些块所用的缓冲区位置。所提供的缓冲区用于发送数据还是读取数据，取决于所提供的命令操作码。

主机控制器 I/O

通过 sdhc_set_io() API，用户可以修改 SD 主机控制器的 I/O 设置，例如时钟频率、I/O 电压和卡电源。并非所有控制器都支持应用全部 I/O 设置。例如，SPI 模式的控制器通常无法切换 SD 卡的电源。

相关配置选项：

  • CONFIG_SDHC
