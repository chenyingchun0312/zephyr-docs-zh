步进电机

步进驱动子系统由两套设备驱动 API 组成：

步进 API

步进驱动 API 为步进驱动器提供通用接口。

  • 使用 stepper_set_micro_step_res() 和 stepper_get_micro_step_res() 配置 微步分辨率。

  • 使用 stepper_enable() 使能 步进驱动器。

  • 使用 stepper_disable() 禁止 步进驱动器。

  • 使用 stepper_set_event_cb() 注册 事件回调。

步进运动控制器 API

步进运动控制器 API 为步进运动控制器提供通用接口。

  • 使用 stepper_ctrl_set_reference_position() 和 stepper_ctrl_get_actual_position() 配置以微步为单位的 参考位置。

  • 使用 stepper_ctrl_set_microstep_interval() 设置相邻两步之间以纳秒为单位的 步间隔

  • 使用 stepper_ctrl_move_by() 移动 正负若干微步，即 相对运动。

  • 使用 stepper_ctrl_move_to() 移动到 特定位置，即 绝对运动。

  • 使用 stepper_ctrl_run() 以 恒定步间隔 朝特定方向连续运行，直到检测到停止。

  • 使用 stepper_ctrl_stop() 停止 步进电机。

  • 使用 stepper_ctrl_is_moving() 检查步进电机是否正在 运动。

  • 使用 stepper_ctrl_set_event_cb() 注册 事件回调。

设备树

对于步进运动控制器，设备树按设备逐个提供步进驱动器的初始硬件配置。在 Zephyr 中，每个设备都必须指定一个设备树绑定，最好还提供一组硬件配置选项，例如电流设置、加减速曲线参数等。之后即可在开发板设备树中使用这些选项，将步进驱动器配置到其初始状态。

步进运动控制器 API 测试套件

步进运动控制器 API 测试套件提供一组测试，可用于验证步进运动控制器的功能。

# From the root of the zephyr repository
west build -b <board> --extra-dtc-overlay <path/to/board.overlay> tests/drivers/stepper/stepper_ctrl
west flash
