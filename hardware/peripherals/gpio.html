通用输入/输出（GPIO）

概述

通用输入/输出（GPIO）是一种数字信号引脚，它没有特定功能，但可以由软件控制，用作输入或输出。

GPIO API 提供了与通用输入/输出（GPIO）引脚交互的通用方法。应用程序可以用它将引脚配置为输入或输出、读写引脚状态以及管理中断。主要功能包括：

引脚配置

将引脚配置为输入、输出或断开连接。支持配置内部上拉/下拉电阻和驱动强度。

数据访问

读取输入值和写入输出值。

中断

配置引脚状态变化（上升沿、下降沿、低电平、高电平）时触发的中断，并注册回调来处理这些中断。

设备树集成

GPIO 通常在设备树中定义，驱动和应用程序可以通过 gpio_dt_spec 以与硬件无关的方式引用它们。

设备树配置

GPIO 控制器在设备树中定义为带有 gpio-controller 属性的节点。#gpio-cells 属性通常指定用 2 个单元来描述一个 GPIO：引脚号和标志。

GPIO 控制器定义示例：

gpio0: gpio@40022000 {
    compatible = "ti,cc13xx-cc26xx-gpio";
    reg = <0x40022000 0x400>;
    interrupts = <0 0>;
    gpio-controller;
    #gpio-cells = <2>;
};

引用 GPIO 的示例：

leds {
    compatible = "gpio-leds";
    led0: led_0 {
        gpios = <&gpio0 25 GPIO_ACTIVE_HIGH>;
        label = "Green LED";
    };
};

基本操作

GPIO 操作通常基于 gpio_dt_spec 结构体进行，该结构体用于存放设备树中指定的 GPIO 引脚信息。

该结构体通常使用 GPIO_DT_SPEC_GET 宏（或其任一变体）填充。

为定义为别名 led0 的 GPIO 引脚填充 gpio_dt_spec 结构体
#define LED0_NODE DT_ALIAS(led0)
static const struct gpio_dt_spec led = GPIO_DT_SPEC_GET(LED0_NODE, gpios);

之后即可使用 gpio_dt_spec 结构体执行 GPIO 操作。

将一个 GPIO 引脚（上一代码片段中的 led）配置为输出且初始为无效状态，然后将其设置为有效电平。
int ret;

ret = gpio_pin_configure_dt(&led, GPIO_OUTPUT_INACTIVE);
if (ret < 0) {
    return ret;
}

ret = gpio_pin_set_dt(&led, 1);
if (ret < 0) {
    return ret;
}

使用 gpio_dt_spec 结构体进行 GPIO 基本操作的完整示例，请参阅 Blinky。

也可以直接在 GPIO 控制器设备上执行 GPIO 操作，此时需使用以设备指针为参数的 GPIO API 函数，例如使用 gpio_pin_configure() 而不是 gpio_pin_configure_dt()。

GPIO Hog 引脚

GPIO hog 提供了一种在系统初始化期间自动配置 GPIO 引脚的机制。对于需要设置为特定状态（例如复位线、电源使能）且不需要应用程序在运行时控制的引脚，这一机制很有用。

Hog 在设备树中定义为 GPIO 控制器节点的子节点。

  • gpio-hog 属性将该节点标记为 hog。

  • gpios 属性指定引脚及其有效状态。

  • input、output-low 或 output-high 属性中的一个用于指定配置。

设备树覆盖文件示例：

&gpio0 {
    hog1 {
        gpio-hog;
        gpios = <1 GPIO_ACTIVE_LOW>;
        output-high;
    };

    hog2 {
        gpio-hog;
        gpios = <2 GPIO_ACTIVE_HIGH>;
        output-low;
    };
};

如果对于配置为 hog 的引脚，除了在系统初始化期间自动设置初始状态之外，还需要在运行时控制它，可以考虑改用 稳压器，并配合 regulator-fixed 设备树节点。

配置选项

主要配置选项：

  • CONFIG_GPIO

  • CONFIG_GPIO_SHELL

  • CONFIG_GPIO_GET_DIRECTION

  • CONFIG_GPIO_GET_CONFIG

  • CONFIG_GPIO_HOGS

  • CONFIG_GPIO_ENABLE_DISABLE_INTERRUPT
