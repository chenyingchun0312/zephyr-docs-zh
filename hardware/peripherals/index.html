外设

Zephyr 通过一组设备驱动 API 支持多种硬件外设。这些外设分为以下几个类别；每张卡片列出该类别中的外设，也可以点击类别标题查看更多详情。

模拟

  • 模拟
    • 模数转换器（ADC）
    • 数模转换器（DAC）
    • 比较器
    • 运算放大器（OPAMP）
音频

  • 音频
    • 音频编解码器
    • 数字麦克风（DMIC）
    • Inter-IC Sound（I2S）总线
    • 数字音频接口（DAI）
通信

  • 通信
    • 控制器局域网（CAN）
    • Inter-Integrated Circuit（I2C）总线
    • 改进型 Inter-Integrated Circuit（I3C）总线
    • 串行外设接口（SPI）总线
    • 高速外设组件互连总线（PCIe）
    • 通用异步收发器（UART）
    • 增强型串行外设接口（eSPI）总线
    • 管理数据输入/输出（MDIO）
    • 多位 SPI 总线
    • 系统管理总线（SMBus）
    • 处理器间邮箱（IPM）
    • 局部互联网络（LIN）
    • 多通道处理器间邮箱（MBOX）
    • 1-Wire 总线
    • 脉冲 IO
显示

  • 显示
    • 显示
    • 辅助显示器（auxdisplay）
    • 视频
    • 发光二极管（LED）
    • DALI
GPIO 与输入

  • GPIO 与输入
    • 通用输入/输出（GPIO）
    • PS/2
    • 时间感知通用输入/输出（TGPIO）
存储器与存储

  • 存储器与存储
    • Flash
    • 电可擦除可编程只读存储器（EEPROM）
    • 安全数字（SD 卡）接口
    • 电池备份 RAM（BBRAM）
    • 保持存储器
    • I2C EEPROM 目标设备
    • 存储器控制器（MEMC）
    • 一次性可编程（OTP）存储器设备
电源

  • 电源
    • BC1.2 设备（实验性）
    • 充电器
    • 电量计
    • 稳压器
    • 复位控制器
    • USB Type-C 端口控制器（TCPC）
    • USB-C VBUS
    • 唤醒控制器（WUC）
传感器

  • 传感器
    • 传感器
    • GNSS（全球导航卫星系统）
    • 外设传感器接口（PSI5）
    • 单边沿半字节传输（SENT）
    • 生物识别
运动与执行

  • 运动与执行
    • 触觉反馈
    • 脉冲宽度调制（PWM）
    • 步进电机
    • 蜂鸣器
系统与诊断

  • 系统与诊断
    • 硬件信息
    • 硬件自旋锁（HWSPINLOCK）
    • 熵
    • 错误检测与纠正（EDAC）
    • 核心转储设备
    • 循环冗余校验（CRC）
    • 平台环境控制接口（PECI）
    • 直接存储器访问（DMA）
    • 多路复用器（MUX）
定时

  • 定时
    • 时钟控制
    • 时钟监视器
    • 计数器
    • 实时时钟（RTC）
    • 看门狗
