EEPROM Shell

  • 概述

  • EEPROM 大小

  • 写入数据

  • 读取数据

概述

EEPROM shell 为 shell 模块提供一个带有一组子命令的 eeprom 命令。借助它，无需编写专门的应用程序，即可通过交互式界面测试和探索 EEPROM 驱动 API。也可以在现有应用程序中启用 EEPROM shell，以便交互式地调试 EEPROM 问题。

要启用 EEPROM shell，必须启用以下 Kconfig 选项：

  • CONFIG_SHELL

  • CONFIG_EEPROM

  • CONFIG_EEPROM_SHELL

例如，为 Native simulator - native_sim 构建启用了 EEPROM shell 的 Hello World 示例：

# From the root of the zephyr repository
west build -b native_sim samples/hello_world -- -DCONFIG_SHELL=y -DCONFIG_EEPROM=y -DCONFIG_EEPROM_SHELL=y

关于如何连接 shell 并与之交互的一般说明，请参阅 shell 文档。EEPROM shell 自带内置帮助（除非禁用了 CONFIG_SHELL_HELP）。向 eeprom 命令或其任一子命令传入 -h 或 --help 即可打印内置帮助信息。所有子命令的参数都支持 Tab 补全。

小技巧

所有 EEPROM shell 子命令的第一个参数都是 EEPROM 外设的名称，该参数同样支持 Tab 补全。启用 CONFIG_DEVICE_SHELL 后，可以使用 device list shell 命令获取所有可用设备的列表。下面的示例均使用设备名 eeprom@0。

EEPROM 大小

可以使用 eeprom size 子命令查看 EEPROM 的大小，如下所示：

uart:~$ eeprom size eeprom@0
32768 bytes

写入数据

可以使用 eeprom write 子命令向 EEPROM 写入数据。该子命令至少需要三个参数：EEPROM 设备名称、开始写入的偏移量，以及至少一个数据字节。在下面的示例中，十六进制字节序列 0x0d 0x0e 0x0a 0x0d 0x0b 0x0e 0x0e 0x0f 被写入偏移量 0x0 处：

uart:~$ eeprom write eeprom@0 0x0 0x0d 0x0e 0x0a 0x0d 0x0b 0x0e 0x0e 0x0f
Writing 8 bytes to EEPROM...
Verifying...
Verify OK

还可以使用 eeprom fill 子命令以相同的模式填充 EEPROM 的一部分。在下面的示例中，从偏移量 0x8 开始的 16 个字节被写入模式 0xaa：

uart:~$ eeprom fill eeprom@0 0x8 16 0xaa
Writing 16 bytes of 0xaa to EEPROM...
Verifying...
Verify OK

读取数据

可以使用 eeprom read 子命令从 EEPROM 读取数据。该子命令需要三个参数：EEPROM 设备名称、开始读取的偏移量，以及要读取的字节数：

uart:~$ eeprom read eeprom@0 0x0 8
Reading 8 bytes from EEPROM, offset 0...
00000000: 0d 0e 0a 0d 0b 0e 0e 0f                          |........         |
