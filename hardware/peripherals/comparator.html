比较器

概述

模拟比较器比较连接到其负输入端和正输入端的两路模拟信号的电压。如果正输入端的电压高于负输入端，比较器输出高电平，否则输出低电平。

比较器通常可以设置一个在输出变化时触发的触发器。该触发器既可以调用回调，也可以通过轮询获取其状态。

相关配置选项：

  • CONFIG_COMPARATOR

配置

嵌入式比较器通常可以在运行时配置。启用后，必须通过设备树提供初始配置。在运行时，可以使用设备驱动特定的 API 更新比较器的配置。新配置会在比较器恢复（resume）时生效。

电源管理

比较器通过电源管理来启用。恢复后，比较器会主动比较其输入，产生输出并检测边沿。挂起时，比较器处于非活动状态。

比较器 shell

比较器 shell 为 shell 模块提供带有一组子命令的 comp 命令。

comp shell 命令提供以下子命令：

  • get_output：参见 comparator_get_output()

  • set_trigger：参见 comparator_set_trigger()

  • await_trigger：按以下流程等待触发：

    • 使用 comparator_set_trigger_callback() 设置触发回调

    • 等待回调，或在默认超时（或可选指定的超时）后超时返回

    • 使用 comparator_set_trigger_callback() 清除触发回调

  • trigger_is_pending：参见 comparator_trigger_is_pending()

相关配置选项：

  • CONFIG_SHELL

  • CONFIG_COMPARATOR_SHELL

  • CONFIG_COMPARATOR_SHELL_AWAIT_TRIGGER_DEFAULT_TIMEOUT

  • CONFIG_COMPARATOR_SHELL_AWAIT_TRIGGER_MAX_TIMEOUT

备注

还可以选择与比较器 shell 一起启用电源管理 shell。

相关配置选项：

  • CONFIG_PM_DEVICE

  • CONFIG_PM_DEVICE_SHELL
