系统管理总线（SMBus）

  • 概述

  • SMBus 控制器 API

  • 配置选项

  • API 参考

概述

系统管理总线（SMBus）由 I2C 衍生而来，用于与主板上的设备通信。系统可以使用 SMBus 与主板上的外设通信，而无需专用的控制线。SMBus 外设可以提供各种制造商信息、报告错误、接受控制参数等。

总线上的设备可以担任三种角色：发起事务并控制时钟的控制器（Controller）、响应事务命令的外设（Peripheral），或主机（Host）。主机是一种特殊的控制器，提供与系统 CPU 之间的主要接口。Zephyr 提供了控制器角色的 API。

SMBus 外设可以通过两种方式发起与控制器的通信：

  • 主机通知（Host Notify）协议：支持主机通知协议的外设会以控制器身份执行通知。它向特殊地址 “SMBus Host（0x08）” 写入一条三字节消息，内容为自身地址和两字节的相关数据。

  • SMBALERT# 信号：外设使用特殊信号 SMBALERT# 请求控制器关注。控制器需要从特殊地址 “SMBus 警报响应地址（ARA，Alert Response Address）（0x0c）” 读取一个字节，外设则以包含自身地址的数据字节进行响应。

目前该 API 基于 SMBus Specification 2.0 版

备注

关于此 API 所用术语的信息，请参阅 规则 A.2：包容性语言。

SMBus 控制器 API

当 SMBus 设备控制总线（尤其是起始条件、停止条件和时钟）时，使用 Zephyr 的 SMBus 控制器 API。这是与 SMBus 外设交互最常用的模式。
