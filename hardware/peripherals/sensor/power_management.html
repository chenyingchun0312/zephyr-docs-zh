电源管理

传感器的电源管理往往并不简单，因为传感器的各个通道可能有多种电源状态。有些传感器允许通道进入低噪声、低功耗或挂起状态，这可能以牺牲噪声或采样速度性能为代价，节省相当多的功耗。在极低功耗状态下，传感器可能会丢失其状态，甚至关闭设备的数字逻辑部分。

总之，传感器的电源管理通常是应用程序特定的！通道状态通常可以通过 传感器属性 修改。如果设备实现了必要的功能，则可以使用电源管理的引用计数 API 来挂起和恢复整个设备。

对于完全挂起/恢复的电源状态，传感器最可能使用的 API 是 设备运行时电源管理，由应用程序层显式调用 pm_device_runtime_get() 和 pm_device_runtime_put()。

将来，借助 读取与解码（Read and Decode），在流式场景下有可能实现设备电源的自动管理，因为应用程序始终会通过针对特定事件的读取请求，告知驱动当前的使用情况。
