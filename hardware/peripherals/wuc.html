唤醒控制器（WUC）

概述

唤醒控制器（WUC）API 为使能和管理唤醒源提供通用接口，这些唤醒源可以使系统退出低功耗状态。WUC 设备通常在设备树中描述，客户端通过 wuc_dt_spec 引用它们。

设备树配置

客户端节点通过 wakeup-ctrls 属性引用唤醒控制器。该属性编码了指向 WUC 设备的 phandle 以及唤醒源的标识符。

设备树片段示例：

wuc0: wakeup-controller@40000000 {
    compatible = "nxp,mcx-wuc";
    reg = <0x40000000 0x1000>;
    #wakeup-ctrl-cells = <1>;
};

button0: button@0 {
    wakeup-ctrls = <&wuc0 10>;
};

基本操作

应用程序通常使用 WUC_DT_SPEC_GET 获取 wuc_dt_spec，然后根据需要使能或禁止唤醒源。

根据设备树使能唤醒源
#define BUTTON0_NODE DT_NODELABEL(button0)

static const struct wuc_dt_spec button_wuc =
    WUC_DT_SPEC_GET(BUTTON0_NODE);

if (!device_is_ready(button_wuc.dev)) {
    return -ENODEV;
}

return wuc_enable_wakeup_source_dt(&button_wuc);

如果驱动支持，应用程序可以检查并清除唤醒源的已触发状态。未实现时，这些 API 返回 -ENOSYS。

检查并清除唤醒源
int ret;

ret = wuc_check_wakeup_source_triggered_dt(&button_wuc);
if (ret > 0) {
    (void)wuc_clear_wakeup_source_triggered_dt(&button_wuc);
}
