视频

视频驱动 API 为视频设备提供通用接口。

基本操作

视频设备

视频设备是对硬件或软件视频功能的抽象，可以生成、处理、消费或转换视频数据。视频 API 旨在提供灵活的方式来创建、处理和组合各种视频设备。

端点

每个视频设备可以有一个或多个端点。输出端点配置视频输出功能并生成数据；输入端点配置视频输入功能并消费数据。

视频缓冲区

视频缓冲区提供数据的传输机制。对其内容没有特别要求，内容要求由端点格式定义。视频缓冲区可以加入设备端点的队列，以进行填充（输入端点）或消费（输出端点）操作；操作完成后，可以将缓冲区出队，以进行后处理、释放或重用。

控制项

视频控制项通过 CID（控制标识符，control identifier）访问和标识，表示一项视频控制属性。不同设备提供的控制项各不相同，可以是通用的、与设备类别相关的，或厂商特定的。设置/获取控制项的函数提供了通用且可扩展的接口，用于处理和创建控制项。
