显示

Zephyr 的显示子系统提供统一的方式与各种显示设备交互。显示 API 与传输方式无关：它描述的是希望显示器做什么，而不暴露数据在线路上如何传输。

MIPI 显示总线接口（DBI）

MIPI DBI 规范定义了多种用于连接主机与显示控制器的并行和串行总线。在 Zephyr 中，DBI 支持提供总线级原语，包括命令写入、读取、像素传输、复位及相关操作，供驱动在内部实现通用 API 时使用。

应用程序不直接使用 DBI 函数，而是调用通用的显示 API（例如写入像素），由显示驱动在底层处理 DBI 协议。

MIPI-DBI 定义了 3 种接口类型：

  • A 型：Motorola 6800 并行总线

  • B 型：Intel 8080 并行总线

  • C 型：SPI 类串行总线，有 3 种选项：

    1. 每字节 9 个写时钟，最后一位是命令/数据选择位

    2. 同上，但每字节 16 个写时钟

    3. 每字节 8 个写时钟，通过 GPIO 引脚选择命令/数据

目前该 API 不支持使用 16 个写时钟的 C 型控制器（选项 2）。

MIPI 显示串行接口（DSI）

MIPI DSI 标准是为现代彩色 TFT 面板设计的高速差分串行总线。Zephyr 的 DSI 支持提供驱动所需的原语，用于在 DSI 链路之上实现通用显示 API。

与 DBI 一样，应用程序从不直接调用 DSI 函数。应用程序通过使用通用显示 API 保持可移植性，而由驱动在内部处理 DSI 事务。
