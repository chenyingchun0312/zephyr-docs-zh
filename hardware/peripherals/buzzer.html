蜂鸣器

蜂鸣器子系统提供一套 API，以统一的方式驱动蜂鸣器硬件，无论底层器件是由 PWM 通道驱动的无源压电蜂鸣器，还是由单根 GPIO 线控制的有源蜂鸣器。

基本操作

应用程序通过设备树获取蜂鸣器设备，并使用 include/zephyr/drivers/buzzer.h 中的函数驱动它：

蜂鸣器 API 调用不会等待所请求的发声时长结束。时长表示硬件应持续发声多久，而不是调用线程应休眠多久；使用 BUZZER_DURATION_FOREVER 可一直发声，直到显式停止。

  • buzzer_tone() 以指定频率发声指定时长。硬件在所请求的时长内持续发声，之后由驱动自动静音。

  • buzzer_beep() 以蜂鸣器的固有工作频率发声，该频率由开发板文件写在 pwms 设备树属性的周期单元中（通常是压电片的机械谐振频率，即该器件能发出的最响亮的音调）。对于有源蜂鸣器，该调用等同于将 GPIO 线驱动为有效，因为实际音高由硬件振荡器决定。

  • buzzer_set_volume() 调节感知响度。零值会立即静音；非零值会被保存，并在下一次发声时生效。有源蜂鸣器没有模拟音量控制，零值对应静音，任何非零值都对应其唯一的可听音量。

  • buzzer_stop() 立即取消正在进行的发声。

后端

提供两种可通过设备树发现的后端：

  • pwm-buzzer 用于由 PWM 通道驱动的无源压电蜂鸣器。PWM 通道的周期决定音频频率，占空比决定感知音量；驱动根据应用程序的音调和音量请求推导出这两个值。

  • gpio-buzzer 用于通过单根 GPIO 驱动的有源蜂鸣器。对于任何非零频率，驱动将该线置为有效；对于 BUZZER_FREQ_REST，则将其置为无效。
