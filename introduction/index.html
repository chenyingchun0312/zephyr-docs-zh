简介

Zephyr 操作系统基于一个小体积内核，专为资源受限的嵌入式系统设计，适用范围从简单的嵌入式环境传感器、LED 可穿戴设备，到复杂的嵌入式控制器、智能手表和 IoT 无线应用。

Zephyr 内核支持多种架构，包括：

  • ARCv2（EM 和 HS）以及 ARCv3（HS6X）

  • ARMv6-M、ARMv7-M 和 ARMv8-M（Cortex-M）

  • ARMv7-A 和 ARMv8-A（Cortex-A，32 位和 64 位）

  • ARMv7-R、ARMv8-R（Cortex-R，32 位和 64 位）

  • Qualcomm Hexagon

  • Intel x86（32 位和 64 位）

  • MIPS（MIPS32 Release 1 规范）

  • OpenRISC（32 位）

  • Renesas RX

  • RISC-V（32 位和 64 位）

  • SPARC V8

  • Tensilica Xtensa

  • TriCore（TC1.6.2 和 TC1.8）

基于这些架构的完整开发板支持列表见 此处 。

在 Zephyr 操作系统中，子系统 指操作系统中逻辑上独立的一部分，负责特定功能或提供特定服务。子系统包括网络、文件系统、设备驱动类别、电源管理和通信协议等组件。每个子系统都采用模块化设计，可以通过配置、定制和扩展来满足不同嵌入式应用的需求。

许可证

Zephyr 采用宽松的 Apache 2.0 license 许可证（见项目 GitHub repo 中的 LICENSE 文件）。Zephyr 项目中有一些引入或复用的组件使用其他许可证，详见 Zephyr 项目组件的许可 。

主要特性

Zephyr 提供大量且不断增加的功能，包括：

丰富的内核服务

Zephyr 为开发提供了许多常见的服务：

  • 多线程服务：支持协作式、基于优先级的非抢占式以及抢占式线程，可选时间片轮转。包含兼容 POSIX pthreads 的 API。

  • 中断服务：在编译期注册中断处理函数。

  • 内存分配服务：动态分配和释放固定大小或可变大小的内存块。

  • 线程间同步服务：二值信号量、计数信号量和互斥信号量。

  • 线程间数据传递服务：基本消息队列、增强型消息队列和字节流。

  • 电源管理服务：包括由应用或策略定义的全局系统电源管理，以及由驱动定义的细粒度设备电源管理。

多种调度算法

Zephyr 提供了全面的线程调度选项：

  • 协作式调度与抢占式调度

  • 最早截止时间优先（EDF）

  • Meta IRQ 调度，实现“中断下半部”或“tasklet”行为

  • 时间片：在同优先级的可抢占线程之间进行时间片轮转

  • 多种就绪队列策略：

    • 简单链表就绪队列

    • 红黑树就绪队列

    • 传统多队列就绪队列

高度可配置、模块化、灵活

应用程序可以按需 只 引入所需的功能，并指定其数量和大小。

跨架构

支持多种不同 CPU 架构和开发工具的 开发板 。社区贡献不断增加对更多 SoC、平台和驱动的支持。

内存保护

实现可配置的、与架构相关的栈溢出保护，内核对象和设备驱动的权限跟踪，以及在 x86、ARC 和 ARM 架构上基于线程级内存保护的线程隔离、用户空间和内存域。

对于没有 MMU/MPU 的平台和内存受限的设备，支持将应用相关的代码与定制内核组合成一个单体镜像，加载到系统硬件上执行。应用代码和内核代码在同一个共享地址空间中运行。

编译期资源定义

允许在编译期定义系统资源，从而为资源受限的系统减小代码体积、提高性能。

优化的设备驱动模型

为平台/系统中的驱动提供一致的配置模型，以及一致的初始化模型来初始化系统中配置的所有驱动，并允许在具有相同设备/IP 模块的平台之间复用驱动。

设备树支持

使用 设备树 描述硬件。设备树中的信息用于生成应用镜像。

支持多种协议的原生网络协议栈

网络支持功能完整且经过优化，包括 LwM2M 和兼容 BSD socket 的接口。还提供 OpenThread 支持（在 Nordic 芯片上），这是一种为在家庭环境中安全可靠地连接数百个产品而设计的 Mesh 网络。

支持低功耗蓝牙 5.0

符合蓝牙 5.0 规范（ESR10），并支持低功耗蓝牙控制器（LE 链路层）。包括 Bluetooth Mesh，以及可用于蓝牙认证的蓝牙控制器。

  • 支持所有 LE 角色的通用访问规范（GAP）

  • 通用属性规范（GATT）

  • 配对支持，包括蓝牙 4.2 中的安全连接（Secure Connections）功能

  • 清晰的 HCI 驱动抽象

  • Raw HCI 接口，可将 Zephyr 作为控制器运行，而不是完整的主机协议栈

  • 已在多种常见控制器上验证

  • 高度可配置

Mesh 支持：

  • 中继（Relay）、好友节点（Friend Node）、低功耗节点（LPN）和 GATT 代理功能

  • 支持两种配网承载（PB-ADV 和 PB-GATT）

  • 高度可配置，可运行在至少 16k RAM 的设备上

支持在 Linux、macOS 和 Windows 上原生开发

基于命令行的 CMake 构建环境可在常见的开发者操作系统上运行。原生移植（native_sim）允许在 Linux 上将 Zephyr 作为原生应用构建和运行，便于开发和测试。

支持 ext2、FatFs 和 LittleFS 的虚拟文件系统接口

支持 ext2、LittleFS 和 FatFS；为内存受限的应用提供 FCB（Flash 循环缓冲区）。

强大的多后端日志框架

支持日志过滤、对象转储、panic 模式、多种后端（内存、网络、文件系统、控制台等），并与 shell 子系统集成。

易用且功能完整的 Shell 接口

多实例 shell 子系统，提供自动补全、通配符、颜色、功能键（方向键、退格、ctrl+u 等）和历史记录等易用功能。支持静态命令和动态子命令。

基于非易失性存储的设置

设置（settings）子系统让模块可以保存每台设备的持久化配置和运行时状态。设置项以键值对字符串的形式存储。

非易失性存储（NVS）

NVS 可存储二进制数据块、字符串、整数、长整数以及它们的任意组合。

原生移植

Native sim 允许将 Zephyr 作为 Linux 应用程序运行，并支持多种子系统和网络。
