BUILD_VERSION

此变量在所有上下文中用作 Zephyr 内核的构建版本。

默认情况下，如果 Zephyr 项目位于 Git 仓库中且 git 工具可用，其内容由在 Zephyr 目录中运行 git describe --abbrev=12 --always 命令的输出生成。生成的字符串包含最近的标签、自该标签以来的提交数，以及缩写的提交哈希。

也可以将 CMake 变量 BUILD_VERSION 设为所需的字符串值，以覆盖此默认行为。可以在 CMakeLists.txt 文件中设置，也可以在调用 CMake 时通过命令行设置，例如 cmake -DBUILD_VERSION="v3.3.0-18-g2c85d92" ..。

version 的输入

本次构建使用的自定义 Zephyr 构建版本（如果由外部设置）。

version 的输出

Zephyr 项目构建版本的最终值：如果已设置 BUILD_VERSION，则为其值，否则为从 Git 仓库生成的值。

另请参见 APP_BUILD_VERSION。
