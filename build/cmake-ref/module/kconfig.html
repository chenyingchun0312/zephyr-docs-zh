kconfig

此模块包含 Kconfig 配置逻辑。

它提供以下目标：

  • menuconfig：运行 Kconfig menuconfig 工具。

  • guiconfig：运行 Kconfig guiconfig 工具。

  • hardenconfig：运行 Kconfig hardenconfig 工具。

  • traceconfig：运行 Kconfig traceconfig 工具。

变量

加载此模块后，将定义以下全局变量：

KCONFIG_ROOT

Kconfig 根文件的路径。默认值：${ZEPHYR_BASE}/Kconfig。

AUTOCONF_H

生成的 autoconf 头文件的路径。默认值：${PROJECT_BINARY_DIR}/include/generated/zephyr/autoconf.h。

DOTCONFIG

生成的 .config 文件的路径。默认值：${PROJECT_BINARY_DIR}/.config。

EXTRA_KCONFIG_TARGETS

要添加的额外 Kconfig 目标列表。

EXTRA_KCONFIG_TARGET_COMMAND_FOR_<target>

为额外 Kconfig 目标运行的命令。

此模块读取的 Kconfig 片段由 CONF_FILE 和 EXTRA_CONF_FILE 选定，这两个变量由 configuration_files 模块解析。
