boards

校验开发板并设置 boards 目标。

此 CMake 模块会校验 BOARD 参数，并将其拆分为 <BOARD> 和 <BOARD_REVISION>。

如果找不到指定开发板的实现，将报错并打印有效开发板列表。

如果用户提供的开发板是开发板别名，则会将其调整为实际的开发板名称。

如果开发板名称已弃用，则会将其调整为新的开发板名称，并向用户打印弃用警告。

必需变量

  • BOARD

可选变量

  • BOARD_ROOT

  • ARCH_ROOT

变量

此 CMake 模块执行完毕后将定义以下变量：

  • BOARD

  • BOARD_REVISION

  • BOARD_QUALIFIERS

  • NORMALIZED_BOARD_QUALIFIERS

  • NORMALIZED_BOARD_TARGET

  • BOARD_DIR

  • ARCH_DIR

  • BOARD_ROOT

目标

此 CMake 模块执行完毕后将定义以下目标：

  • boards

    调用时将打印有效开发板列表。

可选环境变量

ZEPHYR_BOARD_ALIASES

指向包含开发板别名的 CMake 文件的环境变量设置。

用法示例

# BOARD is normally given on the command line, for example:
#   west build -b nrf52840dk/nrf52840
include(boards)

message(STATUS "Building for ${BOARD} (${NORMALIZED_BOARD_TARGET})")
message(STATUS "Board files are in ${BOARD_DIR}")
