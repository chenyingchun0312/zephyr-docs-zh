yaml

为 Zephyr 构建系统提供 YAML 文件处理功能。

此模块支持在 Zephyr 构建系统中读取、写入和操作 YAML 文件，支持基本键值对、嵌套对象、列表以及映射列表。

支持的 YAML 特性

此模块支持以下 YAML 结构：

基本键值对
foo: bar
嵌套对象
foo:
  bar: baz
简单列表
foos:
  - foo1
  - foo2
  - foo3
映射列表
foo:
  - bar: val1
    baz: val1
  - bar: val2
    baz: val2

用法示例

include(yaml)

# Create a new YAML context
yaml_create(NAME my_yaml FILE my_file.yaml)

# Set some values
yaml_set(NAME my_yaml KEY foo VALUE bar)
yaml_set(NAME my_yaml KEY list LIST item1 item2 item3)

# Append a map to a list
yaml_set(NAME my_yaml KEY list APPEND LIST MAP "name: test, value: 42")

# Save the context to file
yaml_save(NAME my_yaml)

# my_file.yaml now contains:
#
# foo: bar
# list:
#   - item1
#   - item2
#   - item3
#   - name: test
#     value: 42

命令

yaml_context

查询 YAML 上下文的状态。

yaml_context(EXISTS NAME <name> <result>)
EXISTS

检查当前作用域中是否存在该 YAML 上下文。如果存在，则在 <result> 中返回 TRUE。

NAME <name>

YAML 上下文的名称。

<result>

用于存放查询结果的变量。

yaml_create

创建新的空 YAML 上下文。

yaml_create(NAME <name> [FILE <file>])
NAME <name>

YAML 上下文的名称。

FILE <file>

与此 YAML 上下文一起使用的文件路径。调用 yaml_save() 时将使用此文件。

yaml_load

将现有 YAML 文件加载到 YAML 上下文中。

yaml_load(FILE <file> NAME <name>)
FILE <file>

要加载的文件路径。

NAME <name>

YAML 上下文的名称。

yaml_get

从 YAML 上下文中获取某个键的值。

yaml_get(<out-var> NAME <name> KEY <key>...)
NAME <name>

YAML 上下文的名称。

KEY <key>...

要获取的键名。可指定多个键以访问嵌套内容。

<out-var>

用于存放所获取值的变量。

如果该键表示列表，则返回该列表。如果该键指向复杂对象，则行为未定义。

yaml_length

获取由某个键定义的数组的长度。

yaml_length(<out-var> NAME <name> KEY <key>...)
NAME <name>

YAML 上下文的名称。

KEY <key>...

定义该列表的键名。

<out-var>

用于存放长度的变量。

如果该键定义的不是数组，则返回 -1。

yaml_set

在 YAML 上下文中设置一个值或值列表。

yaml_set(NAME <name> KEY <key>... [GENEX] VALUE <value>)
yaml_set(NAME <name> KEY <key>... [APPEND] [GENEX] LIST <value>...)
yaml_set(NAME <name> KEY <key>... [APPEND] LIST MAP <map1> MAP <map2> MAP ...)
NAME <name>

YAML 上下文的名称。

KEY <key>...

要设置的键名。

VALUE <value>

该键的新值。

LIST <values>

该键的新值列表。

APPEND

将值列表追加到现有列表中。

GENEX

值中包含生成器表达式。

MAP <map>

由键值对组成的映射，键值对之间用 ',' 分隔，键与值之间用 ':' 分隔。格式："<key1>: <value1>, <key2>: <value2>, ..."。向列表添加内容时，可给出多个 MAP 参数来区分不同的映射。不能与 GENEX 一起使用。

注意：如果映射的值中包含逗号，则该值必须用单引号括起来，且逗号必须进行双重转义：'A \\,string'

yaml_remove

从 YAML 上下文中移除一个键。

yaml_remove(NAME <name> KEY <key>...)
NAME <name>

YAML 上下文的名称。

KEY <key>...

要移除的键名。可指定多个键以访问嵌套内容。

yaml_save

将 YAML 上下文写入文件。

yaml_save(NAME <name> [FILE <file>])
NAME <name>

YAML 上下文的名称。

FILE <file>

写入上下文的文件路径。如果未给出，则使用该 YAML 上下文的 FILE 属性。

如果上下文使用了生成器表达式，包含生成器表达式的键起初会以注释形式写入，完整内容在构建时才可用。依赖于该文件完整内容的构建步骤必须依赖 name_yaml_saved 目标。
