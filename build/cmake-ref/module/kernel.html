kernel

Zephyr 内核主 CMake 模块。

此模块负责创建 Zephyr 库和 Zephyr 可执行文件。它会创建名为 Zephyr-Kernel 的 CMake 项目，并定义配置待构建库时所用的属性。

变量

加载此模块后，将定义以下全局变量：

ZEPHYR_LIBS

需要链接的所有 Zephyr CMake 库的全局列表。zephyr_library() 会向此列表追加库。

ZEPHYR_INTERFACE_LIBS

需要链接的所有 Zephyr 接口库的全局列表。zephyr_interface_library_named() 会向此列表追加库。

GENERATED_APP_SOURCE_FILES

Zephyr 完成首次链接后生成的源文件，可能包括 dev_handles.c 等。

GENERATED_KERNEL_OBJECT_FILES

符号地址固定后生成的目标文件，可能包括 MMU 页表等。

GENERATED_KERNEL_SOURCE_FILES

符号地址固定后生成的源文件，可能包括 isr_tables.c 等。

目标

code_data_relocation_target

用于代码和数据重定位的自定义目标。

app

包含全部应用程序代码的 CMake 库。由入口文件 ${APPLICATION_SOURCE_DIR}/CMakeLists.txt 修改。

用法

此模块不应直接加载，而应通过 find_package(Zephyr) 加载。它自身不会加载任何 Zephyr CMake 模块。
