git

为 Zephyr 构建系统提供 Git 相关功能。

此模块提供在 Zephyr 构建系统中与 Git 仓库交互的函数。

命令

git_describe

获取与某个目录或文件关联的简短 Git 描述。

git_describe(<file|dir> OUTPUT)

此函数在提供的目录上运行 git describe --abbrev=12 --always；如果提供的是文件，则在该文件所在的目录上运行。两种情况下，结果都会存入提供的输出变量。

file|dir

要运行 git 命令的目录或文件。

OUTPUT

用于存放 git 描述的变量名。如果 git 命令失败或找不到 Git，则不会设置此变量。

在以下情况下，该函数会输出状态消息：

  • git 命令失败（错误消息）

  • git 命令产生警告（警告消息）

用法示例

include(git)

git_describe(${CMAKE_CURRENT_SOURCE_DIR} GIT_DESCRIPTION)
if(DEFINED GIT_DESCRIPTION)
  message(STATUS "Git description: ${GIT_DESCRIPTION}")
endif()
