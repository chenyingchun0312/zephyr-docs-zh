设计目标

Zephyr 对设备树的使用方式随着时间推移发生了很大变化，预计还会有进一步的变化。以下是总体设计目标，以及这些目标如何影响 Zephyr 源代码的具体示例，和仍有待完成的工作。

硬件信息的单一来源

Zephyr 的内置设备驱动和示例应用程序应从设备树获取可配置的硬件描述。

示例

  • 新的设备驱动应使用设备树 API 来确定要 创建哪些设备。

  • 树内示例应用程序应使用 别名 来确定当前构建中使用给定类型的多个可能通用设备中的哪一个。例如，Blinky 示例使用别名来确定要闪烁的 LED。

  • 新 SoC 的启动时引脚复用和引脚控制应通过基于设备树的 pinctrl 驱动实现

尚待完成的工作示例

  • Zephyr 的 测试运行器（Twister） 目前使用 board.yaml 文件来确定开发板支持的硬件。这应改为从设备树获取。

  • 旧式设备驱动目前使用 Kconfig 来确定启用某个 compatible 的哪些实例。这可以而且应该改用设备树覆盖文件来完成。

  • 开发板级文档中仍包含手工生成和维护的硬件支持表格。这些信息可以而且应该改为从开发板级设备树获取。

  • 运行时 struct device 关系的确定（例如用于设备电源管理）应使用从设备树获取的信息来完成。

与其他操作系统的源码兼容性

Zephyr 的设备树工具基于一个通用层，该层可与 Linux 内核等其他设备树使用者互操作。

Zephyr 绑定语言的 语义 可以支持 Zephyr 特有的属性，但不应表达 Zephyr 特有的关系。

示例

  • Zephyr 的设备树源码解析器 dtlib.py 与 dtc 等其他工具双向源码兼容：dtlib.py 可以解析 dtc 的输出，dtc 也可以解析 dtlib.py 的输出。

  • Zephyr 的“扩展 dtlib”库 edtlib.py 不应包含 Zephyr 特有的功能。它的用途是针对中断和总线等常见元素提供更高层次的设备树视图。

    只有构建在 edtlib.py 之上的高层脚本 gen_defines.py 包含 Zephyr 特有的知识和功能。

尚待完成的工作示例

  • Zephyr 有一套自定义的 设备树绑定 语言 语法。虽然 Linux 的 dtschema 尚不能满足 Zephyr 的需求，但我们应尽量在 Zephyr 自己的绑定中遵循它能够表示的内容。

  • 由于绑定语言不够灵活，Zephyr 无法支持 Linux 所支持的全部绑定。

  • Zephyr 与 Linux 之间不共享设备树源文件。

对通过多个 Zephyr API 使用的硬件进行建模

当一个硬件模块可以通过不同的 Zephyr API 使用时，设备树应将硬件标识与软件驱动和子系统使用各个硬件实例的方式分开。

准则

  • 让 compatible 属性专注于设备的编程模型。避免仅为了选择软件 API 而更改它。当硬件接口在架构上不同时（例如使用不同的寄存器块），使用不同的 compatible 才是合适的。

  • 使用 /chosen 进行系统范围内的单例选择。如果系统必须为某个全局功能（例如系统定时器、控制台或熵源）选择恰好一个实例，应使用与平台无关的 chosen 属性表示该选择，即使其他相同的硬件实例被其他 API 使用。另请参见 Zephyr 特有的 chosen 节点。

  • 在合适的集成层级进行选择。如果它是芯片级的固定属性，应在 SoC .dtsi 中描述；如果它随开发板、产品或应用程序而变化，应在开发板 .dts 或覆盖文件中描述。

如果硬件设备的不同用途需要不同的属性、子节点或总线语义，则它们不必共享同一个绑定模式。这种情况下，应使用不同的 compatible 值，或者将该设备建模为多功能设备。

示例

使用 /chosen 进行单例选择

系统定时器是一个单例功能。zephyr,system-timer chosen 属性选择由哪个硬件定时器实例提供该功能，其他相同的实例仍可供其他 API 使用。

例如，两个相同的 LPTMR 定时器实例可以在硬件描述中共享同一个 compatible：

lptmr1: timer@44300000 {
    compatible = "nxp,lptmr";
    reg = <0x44300000 0x1000>;
    /* ... */
};

lptmr2: timer@424d0000 {
    compatible = "nxp,lptmr";
    reg = <0x424d0000 0x1000>;
    /* ... */
};

然后，集成层可以选择由哪一个实例提供单例的系统定时器功能：

/ {
    chosen {
        zephyr,system-timer = &lptmr1;
    };
};

系统定时器驱动绑定到 /chosen 节点。计数器驱动跳过该实例，使用剩下的那个实例。
