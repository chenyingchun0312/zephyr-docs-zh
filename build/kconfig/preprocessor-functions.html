自定义 Kconfig 预处理器函数

Kconfiglib 支持用 Python 编写的自定义 Kconfig 预处理器函数。这些函数定义在 scripts/kconfig/kconfigfunctions.py 中。

备注

官方 Kconfig 预处理器文档请见 此处。

详细文档请参阅 scripts/kconfig/kconfigfunctions.py 中的 Python 文档字符串。大多数自定义预处理器函数用于将设备树信息导入 Kconfig。例如，Kconfig 符号的默认值可以从设备树的 reg 属性中获取。

整数函数

下面列出的函数可用于对整数变量进行加法、减法等算术运算。名称带 _hex 后缀和不带该后缀的函数分别返回十六进制值和十进制值。

$(add,<value>[,value]...)
$(add_hex,<value>[,value]...)
$(dec,<value>[,value]...)
$(dec_hex,<value>[,value]...)
$(div,<value>[,value]...)
$(div_hex,<value>[,value]...)
$(inc,<value>[,value]...)
$(inc_hex,<value>[,value]...)
$(max,<value>[,value]...)
$(max_hex,<value>[,value]...)
$(min,<value>[,value]...)
$(min_hex,<value>[,value]...)
$(mod,<value>[,value]...)
$(mod_hex,<value>[,value]...)
$(mul,<value>[,value]...)
$(mul_hex,<value>[,value]...)
$(sub,<value>[,value]...)
$(sub_hex,<value>[,value]...)

字符串函数

下面列出的函数可用于修改字符串变量。

$(normalize_upper,<string>)
$(substring,<string>,<start>[,<stop>])

其他函数

用于执行特定操作的函数，目前只有一个检查是否指定了某个扩展板名称的函数。

$(shields_list_contains,<shield name>)

扩展板名称不能包含空白字符。逗号后的空格（如 $(shields_list_contains, foo) 中所示）会被去除并打印一条警告，因此仍能匹配到 foo。

用法示例

假设某开发板的设备树如下：

{
     soc {
             #address-cells = <1>;
             #size-cells = <1>;

             spi0: spi@10014000 {
                     compatible = "sifive,spi0";
                     reg = <0x10014000 0x1000 0x20010000 0x3c0900>;
                     reg-names = "control", "mem";
                     ...
             };
};

spi@1001400 中 reg 的第二项（<0x20010000 0x3c0900>）对应 mem，其地址为 0x20010000。可以按如下方式将该地址插入 Kconfig：

config FLASH_BASE_ADDRESS
     default $(dt_node_reg_addr_hex,/soc/spi@1001400,1)

经过预处理器展开后，它会变成如下定义：

config FLASH_BASE_ADDRESS
     default 0x20010000
