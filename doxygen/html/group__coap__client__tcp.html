◆ coap_client_tcp_payload_cb_t

typedef int(*) coap_client_tcp_payload_cb_t(size_t offset, const uint8_t **payload, size_t *len, bool *last_block, void *user_data)

#include <zephyr/net/coap_client_tcp.h>

为 CoAP TCP 请求提供有效载荷的回调。

参数
offset有效载荷相对于块传输起始位置的偏移。
payload指向包含有效载荷块的缓冲区的指针。
len输入时为请求的（最大）块大小，输出时为实际有效载荷长度。
last_block指向表示是否预期还有更多有效载荷块的标志的指针。
user_data用户提供的上下文。
返回
成功时为零，返回负的错误码以中止上传。

◆ coap_client_tcp_connect()

int coap_client_tcp_connect ( struct coap_client_tcp * client,
const struct net_sockaddr * addr,
net_socklen_t addrlen,
int proto )

#include <zephyr/net/coap_client_tcp.h>

将 CoAP TCP 客户端连接到服务器。

与 UDP 客户端不同，TCP 客户端在内部管理套接字。此函数创建 TCP 套接字、连接到服务器，并按 RFC 8323 自动发送 CSM（能力与设置消息）以协商能力。

参数
client客户端实例。
addr服务器的目的地址。
addrlen地址结构的长度。
proto要使用的协议（IPPROTO_TCP 或 IPPROTO_TLS_1_2）。
返回
成功时为 0，否则为负的错误码。

◆ coap_client_tcp_csm_req()

int coap_client_tcp_csm_req ( struct coap_client_tcp * client,
uint32_t max_block_size,
coap_client_tcp_response_cb_t cb,
void * user_data )

#include <zephyr/net/coap_client_tcp.h>

通过 TCP 发送 CSM（能力与设置消息）

按 RFC 8323，在建立 CoAP-over-TCP 连接时应交换 CSM。这会协商最大消息大小和 BERT 等能力。

参数
client客户端实例（必须已通过 coap_client_tcp_connect 连接）。
max_block_size要通告的最大块大小。
cb响应回调（可以为 NULL，因为服务器可能不响应）。
user_data用于回调的用户数据。
返回
成功时返回 0，未连接时返回 -ENOTCONN，否则返回负的错误码。

#include <zephyr/net/coap_client_tcp.h>

向服务器发送 Release 信号（RFC 8323）

这表示优雅地终止连接。服务器应在关闭前完成待处理的请求。

参数

hold_off_sec等待时间（秒，没有时为 0）。
返回
成功时为 0，否则为负的错误码。
