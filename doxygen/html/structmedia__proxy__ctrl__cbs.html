◆ search_recv

void(*) media_proxy_ctrl_cbs::search_recv(struct media_player *player, int err, uint8_t result_code)

搜索结果码接收回调

收到搜索结果码时调用。另见 media_proxy_ctrl_send_search()

搜索结果码表示搜索是否成功。对于成功的搜索，可以使用搜索结果对象 ID 访问搜索的实际结果（即搜索得到的结果）。搜索结果对象 ID 有单独的回调——search_results_id_recv()。

参数
player媒体播放器实例指针
err错误值。成功时为 0，正值时为 GATT 错误，负值时为 errno。
result_code搜索结果码
