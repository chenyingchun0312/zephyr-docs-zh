◆ gcov_coverage_dump()

void gcov_coverage_dump ( void )

转储所有已收集的 gcov 覆盖率数据。

获取每个已注册对象的 gcov 覆盖率数据，并通过覆盖率转储方法所选的传输方式发送（控制台为 CONFIG_COVERAGE_DUMP）。 CONFIG_COVERAGE_SEMIHOST for the host filesystem). This is the untagged form and is equivalent to gcov_coverage_dump_tagged() with a NULL tag.

◆ gcov_coverage_dump_tagged()

void gcov_coverage_dump_tagged ( const char * tag)

转储带有标签的 gcov 覆盖率数据。

获取 gcov 覆盖率数据并通过配置的传输方式发出，将转储与 tag 关联，以便消费者将其归属于单一生产者（例如单个测试用例）。

根据所选的转储方法，标签的承载方式不同：

  • 控制台（ CONFIG_COVERAGE_DUMP）：tag 会被追加。 GCOV_COVERAGE_DUMP_START marker that frames the data.
  • 半主机（ CONFIG_COVERAGE_SEMIHOST）：每个 .gcda 会写入由文件名追加 @@ 和标签构成的路径（例如 foo.gcda@@suite.test），而不是其规范路径，这样多个隔离的转储可以与对应的 .gcno 共存而不会互相覆盖。

当 tag 不是 NULL 时，会跳过未记录任何覆盖率的对象，使带标签（按生产者）的转储保持较小。传入 NULL 则重现历史上的无标签行为，转储所有对象。

参数
tag用于归属转储的标签，无标签转储时为 NULL。

◆ gcov_coverage_semihost()

void gcov_coverage_semihost ( void )

通过半主机转储所有已收集的 gcov 覆盖率数据。

使用半主机将所有已注册对象的 gcov 覆盖率数据写入主机文件系统。仅在选择了半主机转储方法（ CONFIG_COVERAGE_SEMIHOST）时可用。这是无标签形式。

◆ gcov_static_init()

void gcov_static_init ( void )

初始化 gcov 运行时。

调用 gcov 构造函数，使每个插桩对象完成注册。 gcov_info with the runtime. Must run before any coverage data is dumped.
