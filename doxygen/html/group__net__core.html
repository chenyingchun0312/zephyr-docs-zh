当收到网络数据包时，由下层网络协议栈或网络设备驱动调用。该函数会将数据包向上推送到网络协议栈以进一步处理。

参数

返回
成功时为 0，出错时 <0。

◆ net_send_data()

int net_send_data ( struct net_pkt * pkt)
inlinestatic

#include <zephyr/net/net_core.h>

向网络发送数据。

向网络发送数据。应用程序通常不应使用此函数，因为它要求网络数据包已正确构造。等价于使用无限超时的 net_try_send_data。

参数
pkt网络数据包。
返回
如果正常则为 0，如果出错则小于 0。如果返回小于 0，则调用方需要对 pkt 进行 unref 以避免内存泄漏。
