#include <zephyr/bluetooth/mesh/access.h>

让一个模型与另一个模型对应。

Mesh 模型可以相互对应，这意味着如果其中一个存在，另一个也必须存在。一个 Mesh 模型可以与任意元素中任意数量的模型对应。通过对应关系连接在一起的所有模型构成一个对应组（Correspondence Group），该组具有唯一的对应 ID。对应关系信息用于构建组合数据第 1 页。

必须在已初始化的 base_mod 上调用此函数。因为此函数设计为在 corresponding_mod 的初始化器中被调用，这意味着 base_mod 必须先于 corresponding_mod 初始化。

base_mod被对应的模型。
返回值
0成功将对应关系保存到 base_mod 模型。
-ENOMEM没有更多空间保存此关系。
-ENOTSUP不支持组合数据第 1 页。

◆ bt_mesh_model_extend()

int bt_mesh_model_extend ( const struct bt_mesh_model * extending_mod,
const struct bt_mesh_model * base_mod )

#include <zephyr/bluetooth/mesh/access.h>

让一个模型扩展另一个模型。

可以扩展 Mesh 模型以复用其功能，从而构成更复杂的模型。一个 Mesh 模型可以扩展任意元素中任意数量的模型。扩展也可以嵌套，即扩展了其他模型的模型本身也可以被扩展。

相互扩展的一组模型构成一个模型扩展列表。

扩展列表中的所有模型在每个元素上共享一个订阅列表。访问层将使用扩展列表和元素中所有模型的合并订阅列表，从而为这些模型提供扩展的订阅列表容量。

如果启用了 CONFIG_BT_MESH_COMP_PAGE_1，则在两个模型的 bt_mesh_model_cb::init 回调被调用之前不得调用此函数，除非该调用是作为最终回调的一部分进行的。

参数
extending_mod正在扩展基础模型的 Mesh 模型。
base_mod被扩展的模型。
返回值
0成功扩展了 base_mod 模型。
