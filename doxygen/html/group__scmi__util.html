定义 SCMI 传输驱动

这只是对 DEVICE_DT_INST_DEFINE() 的封装，但必须如此，因为传输层驱动不允许把自己的 init() 函数放入初始化段。传输层驱动改为把 scmi_core_transport_init() 函数放入初始化段，再由该函数调用传输层驱动 init() function. This is required because the SCMI core needs to perform channel binding and setup during the transport layer driver's initialization.

定义 SCMI 协议

此宏执行三项重要功能：

  1. 它定义 struct scmi_protocol，所有协议驱动都需要它才能使用 SCMI API。
  2. 它声明绑定到该协议的静态通道。仅在传输层驱动支持静态通道时适用。
  3. 它创建 struct device，并将 data 字段设为新定义的 struct scmi_protocol。这是必需的，因为协议驱动既需要使用 SCMI API，**同时** 也需要使用子系统 API。
参数
node_id协议节点标识符
init_fn指向协议初始化函数的指针
api指向协议子系统 API 的指针
pm指向协议电源管理资源的指针
data指向协议私有数据的指针
config指向协议私有常量数据的指针
level协议初始化级别
prio协议在其初始化级别内的优先级
version_val驱动所支持的协议版本

检查节点是否为 SCMI 基础传输节点。

此宏通过检查给定 node_id 节点的兼容字符串是否匹配当前传输的定义（DT_SCMI_TRANSPORT_COMPATIBLE），判断该节点是否对应主 SCMI 传输层（基础节点）。

参数
node_id协议节点标识符
返回
如果该节点是基础传输节点则为 1，否则为 0。
