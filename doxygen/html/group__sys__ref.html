增加对象的引用。

仅在调用方已持有有效引用时才可安全调用，因为有效引用使对象保持存活且计数器不为零。它不能用于取得第一个引用（参见 sys_ref_init()），也不能用于复活引用可能已降为零的对象。

◆ sys_ref_put()

bool sys_ref_put ( struct sys_ref *const ref,
const sys_ref_release_t release )
inlinestatic

#include <zephyr/sys/ref.h>

减少对象的引用。

递减引用，并在最后一个引用被丢弃后调用 release。此调用之后，调用方不得再访问该对象，因为它可能已被释放。

释放处理程序使用 CONTAINER_OF 恢复外层对象并释放其持有的资源：

struct my_obj {
struct sys_ref ref;
...
};
static void my_obj_release(struct sys_ref *const ref)
{
struct my_obj *obj = CONTAINER_OF(ref, struct my_obj, ref);
k_free(obj);
}
sys_ref_put(&obj->ref, my_obj_release);
