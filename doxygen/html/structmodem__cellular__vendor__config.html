详细描述

厂商特定的蜂窝调制解调器配置。

为每个调制解调器变体定义一个常量对象。所引用的脚本和非请求匹配数组必须在使用此配置的每个设备实例的整个生命周期内保持有效。

◆ chat_filter

const char* modem_cellular_vendor_config::chat_filter

从调制解调器响应中过滤掉的字符，为以 NULL 结尾的字符串。

可以为 NULL 以禁用过滤。非 NULL 字符串必须在设备生命周期内保持有效。
