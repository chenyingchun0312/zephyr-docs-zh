nRF GPIO 驱动标志

nRF GPIO 驱动标志

标准（S）或高（H）驱动模式可应用于两种引脚电平，0 或

  1. 高驱动模式会提高引脚的电流能力（参见各 SoC 参考手册）。

当引脚配置为开漏模式（线与）运行时，驱动模式只能为 0 电平选择（1 为断开）。类似地，当引脚配置为开源模式（线或）运行时，驱动模式只能为 1 电平设置（0 为断开）。

这些驱动标志编码在 gpio_dt_flags_t 的高 8 位中，具体如下：

  • 第 8 位：'0' 的驱动模式（0=标准，1=高）
  • 第 9 位：'1' 的驱动模式（0=标准，1=高）
#define NRF_GPIO_DRIVE_S0   (0U << 8U)
 '0' 的标准驱动（默认，与 GPIO_OPEN_DRAIN 配合使用）
#define NRF_GPIO_DRIVE_H0   (1U << 8U)
 '0' 的高驱动（与 GPIO_OPEN_DRAIN 配合使用）
#define NRF_GPIO_DRIVE_S1   (0U << 9U)
 '1' 的标准驱动（默认，与 GPIO_OPEN_SOURCE 配合使用）
#define NRF_GPIO_DRIVE_H1   (1U << 9U)
 '1' 的高驱动（与 GPIO_OPEN_SOURCE 配合使用）
#define NRF_GPIO_DRIVE_S0S1   (NRF_GPIO_DRIVE_S0 | NRF_GPIO_DRIVE_S1)
 '0' 和 '1' 均为标准驱动（默认）
#define NRF_GPIO_DRIVE_S0H1   (NRF_GPIO_DRIVE_S0 | NRF_GPIO_DRIVE_H1)
 '0' 为标准驱动，'1' 为高驱动
#define NRF_GPIO_DRIVE_H0S1   (NRF_GPIO_DRIVE_H0 | NRF_GPIO_DRIVE_S1)
 '0' 为高驱动，'1' 为标准驱动
#define NRF_GPIO_DRIVE_H0H1   (NRF_GPIO_DRIVE_H0 | NRF_GPIO_DRIVE_H1)
 '0' 和 '1' 均为高驱动
