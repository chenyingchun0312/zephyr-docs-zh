◆ uart_poll_in()

int uart_poll_in ( const struct device * dev,
unsigned char * p_char )

从设备读取一个字符作为输入。

此例程检查接收器是否有有效数据。当接收器有有效数据时，它从设备读取一个字符，存储到 p_char 指向的位置，并向调用线程返回 0。否则返回 -1。此函数是非阻塞调用。

参数
devUART 设备实例。
p_char指向字符的指针。
返回值
0有一个字符到达。
-1没有可读取的字符（即 UART 输入缓冲区为空）。
-ENOSYS该操作未实现。
-EBUSY已使用 uart_rx_enable 启用异步接收。

◆ uart_poll_out()

void uart_poll_out ( const struct device * dev,
unsigned char out_char )

向设备写入一个字符作为输出。

此例程检查发送器是否已满。当发送器未满时，它向数据寄存器写入一个字符。否则等待并阻塞调用线程。此函数是阻塞调用。它会阻塞调用线程直到该字符被发送。

在启用硬件流控时发送字符，必须使握手信号 CTS 有效。

参数
devUART 设备实例。
out_char要发送的字符。
