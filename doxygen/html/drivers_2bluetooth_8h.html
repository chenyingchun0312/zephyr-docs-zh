◆ bt_hci_cmd_complete_create()

struct net_buf * bt_hci_cmd_complete_create ( uint16_t op,
uint8_t plen )

分配 HCI Command Complete 事件缓冲区。

该函数为 HCI Command Complete 事件分配新缓冲区。传入 OpCode（例如用 BT_OP 宏编码）和参数总长度。成功返回后，缓冲区即可用于编码参数。

参数
opHCI 命令操作码。
plen命令参数的长度。
返回
新分配的缓冲区。

H4 驱动中包含该函数的弱定义版本，因此每个开发板可选择是否定义它。
