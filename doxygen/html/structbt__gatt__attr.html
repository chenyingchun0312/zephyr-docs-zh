详细描述

GATT 属性

此类型主要表示可能是本地 ATT 数据库中条目的 ATT 属性。此类型的对象必须是构成 GATT 服务的数组的一部分。

当所构成的 GATT 服务在本地 GATT 服务器中注册后，指向此类型的指针通常可以传给 GATT 服务器 API，例如 bt_gatt_notify()。

◆ uuid

const struct bt_uuid* bt_gatt_attr::uuid

属性类型

属性类型是一个 UUID，它决定了 read() 和 write() 方法可提供的接口以及可能的权限配置。

例如，类型为 BT_UUID_GATT_CPF 的属性将充当 Core Specification 3.G.3.3.3.5 中规定的 GATT 特征表示格式描述符。

可以为应用程序的特定用途生成新的 UUID，从而定义新的属性类型。
