定义新的仿真器

这会将一个新的 struct emul 添加到仿真的链接器列表中。通常用于仿真器的 DT_INST_FOREACH_STATUS_OKAY() 子句。

参数
node_id要仿真的驱动的节点 ID（例如 DT_DRV_INST(n)）；node_id 必须 有对应的 DEVICE_DT_DEFINE()。
init_fn用于初始化仿真器的函数（参见 emul_init 类型定义）
data_ptr仿真器特定的数据
cfg_ptr仿真器特定的配置数据
bus_api仿真器特定的总线 API
_backend_api仿真器特定的后端 API

值:
(&EMUL_DT_NAME_GET(node_id))

从设备树节点标识符获取 const struct emul*

如果任何设备已由某个仿真器实现分配，则返回指向从该设备树节点创建的仿真器对象的指针。

如果未分配这样的设备，链接时会失败。如果看到类似 undefined reference to __device_dts_ord_<N> 的错误，就是这种情况。请检查你的仿真器实现是否被编译，通常需要使能它所需的 Kconfig 选项。

参数
node_id设备树节点标识符
返回
指向为该节点创建的 emul 对象的指针

◆ emul_get_binding()

const struct emul * emul_get_binding ( const char * name)

#include <zephyr/drivers/emul.h>

按名称获取仿真器的 emul 结构体

仿真器对象通过 EMUL_DT_DEFINE() 宏创建，并由链接器放入内存。若自定义 API 调用需要该仿真器结构体，可通过仿真器向系统暴露的名称获取（默认为设备树节点的标签）。

参数
name要搜索的仿真器名称。空指针或指向空字符串的指针会导致返回 NULL。
返回
指向仿真器结构体的指针；未找到或不可用时为 NULL。
