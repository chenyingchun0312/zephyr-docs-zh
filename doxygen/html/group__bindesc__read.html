int bindesc_foreach ( struct bindesc_handle * handle,

#include <zephyr/bindesc.h>

遍历二进制描述符并对每个描述符运行用户定义的回调

注解
如果回调返回非零值，遍历即停止。

user_data要传给回调的用户定义数据
返回
如果遍历被回调提前结束，则返回回调的返回值，否则返回零

获取映像二进制描述符的大小

遍历二进制描述符结构以计算该结构的总字节大小。例如，当需要将整个结构复制到 RAM 时，这很有用。

返回
成功时为 0，否则为负的 errno

◆ bindesc_open_flash()

int bindesc_open_flash ( struct bindesc_handle * handle,
size_t offset,
const struct device * flash_device )

#include <zephyr/bindesc.h>

从 Flash 打开映像的二进制描述符以供读取

为后续的 bindesc API 调用初始化一个 bindesc 句柄。与从 RAM 或内存映射 Flash 读取 bindesc 不同，此后端需要使用 Flash API 将数据从 Flash 读入内部缓冲区。

参数
[out]handle要传给后续调用的 bindesc 句柄
offset从 Flash 起始处算起、可找到 bindesc 魔数的偏移
flash_device要从中读取描述符的 Flash 设备
注意
Available only when the following Kconfig option is enabled: CONFIG_BINDESC_READ_FLASH.
返回值
0成功时
-ENOENT在给定偏移处未找到 bindesc 魔数时

◆ bindesc_open_ram()

int bindesc_open_ram ( struct bindesc_handle * handle,
const uint8_t * address,
size_t max_size )

#include <zephyr/bindesc.h>

从 RAM 打开映像的二进制描述符以供读取

为后续的 bindesc API 调用初始化一个 bindesc 句柄。假定整个 bindesc 上下文在调用此函数之前已由用户或引导加载程序复制到 RAM。

注解
给定地址必须按 BINDESC_ALIGNMENT 对齐
参数
[out]handle要传给后续调用的 bindesc 句柄
address可找到 bindesc 魔数的地址
max_size给定缓冲区的最大大小
返回值
0成功时
-ENOENT在给定地址处未找到 bindesc 魔数时
-EINVAL给定地址未对齐时
