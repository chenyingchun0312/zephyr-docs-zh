◆ mem_attr_check_buf()

int mem_attr_check_buf ( void * addr,
size_t size,
uint32_t attr )

#include <zephyr/mem_mgmt/mem_attr.h>

检查缓冲区的大小和属性是否正确。

该函数用于检查具有给定属性集的缓冲区是否在大小和属性上与某个内存区域完全匹配。

通常用于验证缓冲区具有预期的属性（例如缓冲区可缓存 / 不可缓存，或属于 RAM / FLASH 等）并且已正确分配。

缓冲区的预期属性集会与其所属内存区域的完整属性集（位掩码）进行与匹配。因此，只要该属性集对内存区域有效，就认为缓冲区匹配（但该区域还可以标记参数所传入属性之外的其他属性）。

参数
addr用户缓冲区的虚拟地址。
size用户缓冲区的大小。
attr缓冲区期望 / 所需的属性。
返回值
0缓冲区的大小和属性正确。
-ENOSYS如果该操作不受支持（例如启用了 MMU）。
-ENOTSUP如果传入了错误的参数。
-EINVAL如果缓冲区的属性集不正确。
-ENOSPC如果缓冲区对于其所属区域而言过大。
-ENOBUFS如果缓冲区完全分配在内存区域之外。
