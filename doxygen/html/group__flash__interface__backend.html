typedef int(*) flash_api_erase(const struct device *dev, off_t offset, size_t size)

#include <zephyr/drivers/flash.h>

Flash 擦除实现处理函数类型

注解
任何必要的擦除保护管理都必须由驱动执行，驱动负责确保操作完成（无论成功与否）后的 "erase-protect" 状态与操作开始时的擦除保护状态一致。

对于设计上无需擦除的 RAM 非易失设备，此回调是可选的；但如果它能提高设备效率，或设备支持驱动所用擦除的内部填充操作，也可以提供。

◆ flash_api_pages_layout

typedef void(*) flash_api_pages_layout(const struct device *dev, const struct flash_pages_layout **layout, size_t *layout_size)

#include <zephyr/drivers/flash.h>

获取 Flash 设备的布局。

Flash 设备布局是对设备上各页的游程编码描述。（此处“页”指 Flash 设备上最小的可擦除区域。）

对于页大小均匀的 Flash 存储器，此例程返回长度为 1 的数组，其中指定页大小和存储器中的页数。

页大小不均匀的 Flash 存储器的布局将以多元素数组返回，每个元素描述一组大小相同的页。此时，数组元素的顺序指定这些组在设备上出现的顺序。

参数
dev要获取布局的 Flash 设备。
layoutFlash 布局将在此参数中返回。
layout_size返回的布局中的元素数量。
