提供可配置定界符的 COBS 编码/解码功能。实现同时支持标准的零定界 COBS 和自定义定界符变体。

默认 COBS 定界符值

标准 COBS 定界符为零（0x00）。这是未指定 COBS_FLAG_CUSTOM_DELIMITER 时使用的定界符值。

在标志中设置自定义定界符的宏

"flags" 的 8 个最低位用于定界符值。配置自定义定界符时，实现会在编码后、解码前对编码数据与定界符值执行 XOR 运算。这使 COBS 可用于零以外的定界符。

参数
x自定义定界符值（0-255）
返回
掩码到 8 位的定界符值

用法示例：

cobs_encode(src_buf, dst_buf, COBS_FLAG_TRAILING_DELIMITER | COBS_FLAG_CUSTOM_DELIMITER(0x7F));

类型定义说明

◆ cobs_stream_cb

typedef int(*) cobs_stream_cb(const uint8_t *buf, size_t len, void *user_data)

#include <zephyr/data/cobs.h>

流式 COBS 编码器/解码器的回调函数类型

此回调由流式编码器/解码器调用，用于输出已处理的数据块。允许尾部定界符的解码器遇到定界符时，会以 NULL 指针和零长度调用此回调，表示一帧已结束。不结束帧的定界符（如连续的定界符）会被忽略。

当此回调函数返回负的错误值时，编码器或解码器流将中止，该错误会被传播。

当此回调函数对已完成的帧返回正值时，解码器在帧的定界符之后停止，参见 cobs_decoder_write()。对数据块返回的正值或编码器回调返回的正值会被忽略。

buf is only valid for the duration of the call.

参数
buf包含已处理数据的缓冲区
len缓冲区中数据的长度
user_data用户提供的上下文指针
返回
成功时为 0，正值表示在帧结束时停止解码，失败时为负的 errno 错误码

COBS 解码

从源缓冲区向目标缓冲区解码单个 COBS 帧。成功时该帧从源缓冲区取出，出错时两个缓冲区都不会被修改。

使用 COBS_FLAG_TRAILING_DELIMITER 时，解码在结束第一帧的定界符处停止，其后的数据保留在源缓冲区中。帧之前的定界符会随帧一起取出。

参数
src要解码的源缓冲区
dst用于解码数据的目标缓冲区
flags解码标志 COBS_FLAGS
返回值
0成功
-EAGAIN源缓冲区中没有完整帧，仅在带有尾部定界符时 COBS_FLAG_TRAILING_DELIMITER
-ENOMEM目标空间不足
-EINVAL无效的 COBS 结构或参数
注意
Available only when the following Kconfig option is enabled: CONFIG_NET_BUF.

◆ cobs_decoder_close()

int cobs_decoder_close ( struct cobs_decoder * dec)

#include <zephyr/data/cobs.h>

结束 COBS 流式解码器

完成解码过程并验证流是否正确结束。应在所有数据写入解码器之后调用。

未使用 COBS_FLAG_TRAILING_DELIMITER 时，流中必须恰好包含一个完整帧。使用 COBS_FLAG_TRAILING_DELIMITER 时，流必须以定界符结尾，或完全不包含帧。

解码器状态将被重置。

参数
dec指向解码器结构体的指针
返回值
0成功
-EINVAL帧缺失、不完整或未终止

向 COBS 流式解码器写入数据

解码所提供的编码数据，并通过已注册的回调函数输出解码后的数据块。此函数可多次调用以增量解码数据。

若返回错误，解码器状态将被重置。

注解
若遇到定界符且设置了 COBS_FLAG_TRAILING_DELIMITER 标志，将以 NULL 指针调用已注册的回调函数，表示帧结束。在帧的第一个码字节之前收到的定界符会被忽略。若回调返回正值，解码在定界符之后停止，buf 中剩余的数据不会被使用。
参数
dec指向解码器结构体的指针
buf包含编码数据的缓冲区
len缓冲区中数据的长度
返回
成功时为从 buf 使用的字节数（除非回调在帧结束时停止，否则即为 len）；遇到意外定界符时为 -EINVAL；或为回调返回的负 errno 错误码
