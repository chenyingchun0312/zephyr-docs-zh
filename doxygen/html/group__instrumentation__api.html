enum instr_event_types

#include <zephyr/instrumentation/instrumentation.h>

插桩事件记录类型。

枚举值
INSTR_EVENT_ENTRY 

被调用者进入事件记录，后跟 instr_event。

INSTR_EVENT_EXIT 

被调用者退出事件记录，后跟 instr_event。

INSTR_EVENT_PROFILE 

性能分析事件

INSTR_EVENT_SCHED_IN 

调度器中线程切入事件

INSTR_EVENT_SCHED_OUT 

调度器中线程切出事件

INSTR_EVENT_NUM 

在此之上添加更多事件

INSTR_EVENT_INVALID 

提升后的事件无效或未生成
