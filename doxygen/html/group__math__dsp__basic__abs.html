详细描述

逐元素计算向量的绝对值。 

 dst[n] = abs(src[n]), 0 <= n < block_size.

这些函数支持原地计算，允许源指针和目标指针引用同一内存缓冲区。浮点、Q7、Q15 和 Q31 数据类型各有独立的函数。
