const struct arch_esf * esf )

#include <zephyr/fatal.h>

致命错误策略处理程序

此函数不由应用程序代码调用，但被声明为弱符号，以便应用程序可以引入自己的策略。

此函数的默认实现会无条件停止系统。取决于架构支持，这可能是一个简单的无限循环、关闭硬件电源，或退出仿真器。

如果此函数返回，则当前正在执行的线程将被终止。

自定义实现的几点说明：

  • 如果判定该错误不可恢复，应调用 LOG_PANIC() 以刷新任何待处理的日志缓冲区。
  • K_ERR_KERNEL_PANIC 表示内核自身发生的严重不可恢复错误，不应视为可恢复。z_fatal_error() 中有断言来强制这一点。
  • 即使不是内核 panic，除非故障发生在用户模式，内核自身也可能处于不一致状态，对内核对象的 API 调用可能表现出未定义行为或触发另一次异常。
参数
reason致命错误的原因
esf异常上下文，包含错误发生时的详细信息以及部分或全部寄存器状态。某些情况下可能为 NULL。
