void(*) input_kbd_matrix_api::drive_column(const struct device *dev, int col)

请求驱动特定列。

请求驱动特定矩阵列、不驱动任何列或驱动所有列。

参数
dev指向键盘矩阵设备的指针。
col要驱动的列，或 INPUT_KBD_MATRIX_COLUMN_DRIVE_NONE or INPUT_KBD_MATRIX_COLUMN_DRIVE_ALL.

◆ set_detect_mode

void(*) input_kbd_matrix_api::set_detect_mode(const struct device *dev, bool enabled)

请求将矩阵置于检测模式。

请求将驱动程序置于检测模式，这在请求驱动所有列之后调用，通常涉及重新启用行引脚变化的相应中断。

参数
dev指向键盘矩阵设备的指针。
enabled检测模式是否应被启用或禁用。
