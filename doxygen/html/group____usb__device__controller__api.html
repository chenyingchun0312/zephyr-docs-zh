◆ usb_dc_ep_read()

int usb_dc_ep_read ( const uint8_t ep,
uint8_t *const data,
const uint32_t max_data_len,
uint32_t *const read_bytes )

#include <zephyr/drivers/usb/usb_dc.h>

从指定端点读取数据

弃用
请改用 USB 设备控制器

当该端点收到 OUT 中断后，由端点处理函数调用此函数。应用程序只能通过提供的 usb_ep_callback 函数调用它。如果端点 FIFO 中的数据已全部读取，此函数会清除端点 NAK，以便接受主机发来的更多数据。

参数
[in]ep与设备配置表中列出的端点相对应的端点地址
[in]data指向要写入的数据缓冲区的指针
[in]max_data_len要读取的数据的最大长度
[out]read_bytes读取的字节数。若 data 为 NULL 且 max_data_len 为 0，则应返回可读取的字节数。
返回
成功时为 0，失败时为负的 errno 错误码。

int usb_dc_ep_read_continue ( uint8_t ep)

#include <zephyr/drivers/usb/usb_dc.h>

继续从端点读取数据

清除端点 NAK 并使端点能够接受主机发来的更多数据。通常在使用者可以接受更多数据时、于 usb_dc_ep_read_wait() 之后调用。因此这些调用共同构成了流控机制。

参数
[in]ep与设备配置表中列出的端点相对应的端点地址
返回
成功时为 0，失败时为负的 errno 错误码。

#include <zephyr/drivers/usb/usb_dc.h>

从指定端点读取数据
