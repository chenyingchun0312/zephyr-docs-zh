◆ dmop_create_ioreq_server()

int dmop_create_ioreq_server ( domid_t domid,
uint8_t handle_bufioreq,
ioservid_t * id )

#include <zephyr/xen/dmop.h>

在给定的 Xen 域中创建 I/O 请求服务器。

该函数发出 XEN_DMOP_create_ioreq_server 超级调用，以创建一个代表客户域处理 I/O 请求的服务器。

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_DMOP.
参数
domid创建服务器的 Xen 域标识符。
handle_bufioreq指示是否应处理缓冲 I/O 请求的标志。设为非零以启用缓冲处理。
[out]id用于接收新创建的服务器 ID 的输出指针。
返回
成功时为 0，失败时为负的 errno 值。

id由 dmop_create_ioreq_server() 返回的 I/O 请求服务器 ID。

ioservid_t id,
uint32_t type,
uint64_t start,
uint64_t end )

#include <zephyr/xen/dmop.h>

将指定的 I/O 地址范围映射到现有 I/O 请求服务器。

该函数发出 XEN_DMOP_map_io_range_to_ioreq_server 超级调用，以授予指定服务器访问给定 I/O 地址范围的权限。

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_DMOP.
参数
domid应用映射所在的 Xen 域标识符。
id由 dmop_create_ioreq_server() 返回的 I/O 请求服务器 ID。
typeI/O 范围的类型标识符（例如 MMIO、端口 I/O）。
startI/O 范围的起始物理地址。
endI/O 范围的结束物理地址（含端点）。
返回
成功时为 0，失败时为负的 errno 值。

int dmop_set_irq_level ( domid_t domid,
uint32_t irq,
uint8_t level )

#include <zephyr/xen/dmop.h>

设置 Xen 域中特定 IRQ 的中断电平。

该函数发出 XEN_DMOP_set_irq_level 超级调用，以调整给定 IRQ 线路的信号电平（置位或撤销置位）。

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_DMOP.
参数
domidXen 域标识符。
irq要设置电平的 IRQ 编号。
level非零表示置位（拉高）该 IRQ，零表示撤销置位（拉低）。
返回
成功时为 0，失败时为负的 errno 值。
