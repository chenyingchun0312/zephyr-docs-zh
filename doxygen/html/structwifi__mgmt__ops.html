◆ get_iface_caps

uint32_t(*) wifi_mgmt_ops::get_iface_caps(const struct device *dev, struct net_if *iface)

获取接口支持的角色（驱动静态能力）。由请求方在添加接口时读取一次，并被视为每接口的静态属性。驱动不能用它在运行时通告角色变化。

iface要查询的网络接口。
返回
受支持角色的 BIT(enum wifi_nm_iface_type)。返回 0 表示让调用方使用默认值。

◆ get_rts_threshold

int(*) wifi_mgmt_ops::get_rts_threshold(const struct device *dev, struct net_if *iface, unsigned int *rts_threshold)

设置 Wi-Fi 企业版模式的 CA/客户端证书和密钥

creds 引用的缓冲区仅在调用期间有效。驱动必须保留自己后续连接所需的凭据副本，且不得释放仍被活动连接使用的副本。所有缓冲区均为 NULL 的请求会释放已保存的副本。

参数
dev指向该驱动实例设备结构的指针。
iface用于企业级凭据操作的网络接口
creds指向 CA/客户端证书和密钥的指针。
返回
成功时为 0，出错时 < 0 获取 RTS 阈值
参数
dev指向该驱动实例设备结构的指针。
iface用于 RTS 阈值操作的网络接口
rts_threshold指向 RTS 阈值的指针。
返回
成功时为 0，出错时 < 0
