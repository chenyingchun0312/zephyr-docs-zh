详细描述

仿真 GPIO 后端 API

仿真 GPIO 的行为由应用定义。因此，每个应用可以

  • 定义一个设备树覆盖文件，以指明 GPIO 控制器的数量以及每个控制器的引脚数量
  • 使用以下方式向 GPIO 控制器注册回调 gpio_add_callback to emulate "wiring"
  • 异步调用 gpio_emul_input_set 和/或 gpio_emul_input_set_masked in order to emulate GPIO events

一个合适的设备树覆盖文件示例位于 tests/drivers/gpio/gpio_basic_api/boards/native_sim.overlay。

注册回调以仿真“接线”以及调用 gpio_emul_input_set 的示例位于文件 tests/drivers/gpio/gpio_basic_api/src/main.c 中。
