对设备树 "/cpus" 节点中 device_type 为 "cpu" 的每个子节点调用 fn

宏 fn 必须接受一个参数，即 device_type = "cpu" 的 "/cpus" 子节点的节点标识符。device_type 不是 "cpu" 的 "/cpus" 子节点会被跳过。

设备树片段示例：

cpus {
cpu0: cpu@0 {
device_type = "cpu";
reg = <0>;
};
cpu1: cpu@1 {
device_type = "cpu";
reg = <1>;
};
power-states {
idle: idle { ... };
};
};

Example usage:

#define REG_AND_COMMA(node_id) DT_REG_ADDR(node_id),
const uint32_t cpu_regs[] = {
DT_FOREACH_CPU(REG_AND_COMMA)
};

对设备树 "/cpus" 节点中 device_type 为 "cpu" 的每个子节点调用 fn，并带分隔符

宏 fn 必须接受一个参数，即 device_type = "cpu" 的 "/cpus" 子节点的节点标识符。device_type 不是 "cpu" 的 "/cpus" 子节点会被跳过。

sep is placed after each invocation of fn, not between invocations. This means the expansion has a trailing sep, which is convenient for initializers since a trailing comma is legal.

用法示例：

const uint32_t cpu_regs[] = {
DT_FOREACH_CPU_SEP(DT_REG_ADDR, (,))
};
