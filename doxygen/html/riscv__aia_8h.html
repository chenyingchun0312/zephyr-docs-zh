详细描述

RISC-V AIA（高级中断架构）统一协调器 API。

提供单一 API 封装 APLIC 和 IMSIC，用于 Zephyr 的中断管理。该协调器以类似 PLIC 的二级中断控制器形式暴露给 Zephyr；APLIC 和 IMSIC 仍为实现细节。

设置某个 AIA 中断源的优先级。

APLIC-MSI 模式没有按源设置的优先级寄存器。优先级通过 IMSIC EITHRESHOLD 或隐式的 EIID 顺序处理。
