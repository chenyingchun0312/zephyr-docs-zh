详细描述

Infineon AURIX 中断路由器（IR）的公共 API。

AURIX 中断子系统由两个协同工作的模块组成：

  • 中断路由器（IR），在各 CPU 与 DMA 之间仲裁待处理的服务请求，并驱动每个源的优先级比较器。
  • 服务请求控制（SRC）寄存器，每个中断源一个，携带该源的使能、优先级、路由和挂起位。

此头文件提供 Zephyr TriCore IRQ 胶合层用于配置、启用、查询和触发各个中断源的小型底层辅助函数。

◆ intc_aurix_ir_irq_clear_pending()

void intc_aurix_ir_irq_clear_pending ( unsigned int irq)

清除 AURIX 中断源上的挂起请求。

写入对应 SRC 寄存器中的 CLRR 位，从而在不影响其他字段的情况下清除 SRR。

配置一个 AURIX 中断源。

用给定优先级和 SoC 支持的任何标志（例如服务类型/路由）写入该源的 SRC 寄存器。

◆ intc_aurix_ir_irq_disable()

void intc_aurix_ir_irq_disable ( unsigned int irq)

禁用一个 AURIX 中断源。

void intc_aurix_ir_src_raise ( uintptr_t src)

按 SRC 寄存器地址触发一个 AURIX 中断源。

intc_aurix_ir_irq_raise 的变体，按源的绝对 SRC 寄存器地址而非 IRQ 编号来指定源。适用于已持有 SRC 指针的调用点（例如驱动内部的软件事件）。
