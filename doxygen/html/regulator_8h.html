◆ regulator_disable()

int regulator_disable ( const struct device * dev)

禁用稳压器。

在此前 regulator_enable() 成功完成后释放稳压器。始终开启、或在设备树中配置了 regulator-always-on 的稳压器会始终保持启用，因此该函数总是成功。

对每次成功的 regulator_enable()，最多只能调用一次。

参数
dev稳压器设备实例。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENOTSUP无法控制稳压器的禁用。

◆ regulator_enable()

int regulator_enable ( const struct device * dev)

启用稳压器。

以引用计数方式请求开启稳压器。当稳压器达到稳定/可用状态时即被视为“开启”。始终开启、或在设备树中配置了 regulator-always-on 的稳压器会始终保持启用，因此该函数总是成功。

参数
dev稳压器设备实例
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENOTSUP无法控制稳压器的启用。

int regulator_set_mode ( const struct device * dev,

Set mode.

稳压器可支持多种模式，以便允许不同的电压配置或更好的节能效果。该 API 会为稳压器施加一种模式。可用设备树属性 regulator-allowed-modes 限制允许的模式。

参数
dev稳压器设备实例。
mode为该稳压器选择的模式。
返回
成功时为 0，失败时为负的 errno 值。
返回值
