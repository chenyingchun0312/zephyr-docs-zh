#include <zephyr/drivers/emul_sensor.h>

获取关于某属性的元数据。

此函数提供的信息包括属性的最小值/最大值以及增量（每 LSB 的值），可用作比较结果时的 epsilon。

参数
[in]target指向要操作的仿真器实例的指针
[in]ch要请求信息的通道。若 ch 不受支持，返回 '-ENOTSUP'
[in]attribute要请求信息的属性。若 attribute 不受支持，返回 '-ENOTSUP'
[out]min该属性可设置的最小值
[out]max该属性可设置的最大值
[out]increment该属性每 LSB 增加的值
[out]shiftmin、max 和 increment 的移位
返回
成功时为 0
出错时 < 0

#include <zephyr/drivers/emul_sensor.h>

查询仿真器某通道支持的采样值范围和容差

参数
target指向要操作的仿真器实例的指针
ch要请求信息的通道。若 ch 不受支持，返回 -ENOTSUP
[out]lower支持的采样值最小值，SI 单位、定点格式
[out]upper支持的采样值最大值，SI 单位、定点格式
[out]epsilon比较预期值与实际值时使用的容差，用于补偿舍入和传感器精度问题。通常可设为最小采样值步长。使用 SI 单位和定点格式。
[out]shift与 lower、upper 及 epsilon.
返回
成功时为 0
若无后端 API 或仿真器不支持该通道则返回 -ENOTSUP

为给定传感器仿真器上的给定通道设置预期值

参数
target指向要操作的仿真器实例的指针
ch要设置预期值的传感器通道
value使用传感器类型标准 SI 单位的定点格式预期值
shift应用于 value 的移位值（缩放因子）
返回
成功时为 0
若无后端 API 或仿真器不支持该通道则返回 -ENOTSUP
若提供的值不在传感器支持的范围内则返回 -ERANGE
