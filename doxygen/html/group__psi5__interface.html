◆ psi5_send()

int psi5_send ( const struct device * dev,
uint8_t channel,
const uint64_t data,
k_timeout_t timeout,
psi5_tx_callback_t callback,
void * user_data )

#include <zephyr/drivers/psi5/psi5.h>

在指定通道上传输 PSI5 数据

该通道必须配置为同步模式，且只能在同步脉冲发生器启动后开始传输。

参数
dev指向该驱动实例设备结构的指针。
channel驱动实例的硬件通道。
data要传输的 PSI5 数据。
timeout等待可发送新数据的超时。
callback帧已发送或发生传输错误时的可选回调。如果为 NULL，该函数会一直阻塞直到帧被发送。
user_data传递给回调函数的用户数据。
返回值
0成功。
-EINVAL无效通道。
-ENOTSUP向函数传入了不支持的参数。
-ENETDOWN已停止状态。
-EIO发生一般传输错误。
-EAGAINtimeout.
