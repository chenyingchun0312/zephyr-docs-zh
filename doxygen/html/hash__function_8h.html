◆ sys_hash_func32_t

typedef uint32_t(*) sys_hash_func32_t(const void *str, size_t n)

32 位哈希函数接口

哈希函数用于把任意大空间中的数据映射到（通常更小的）固定大小空间。对于给定输入，哈希函数会一致地生成相同的、半唯一的数值。即使数据仅有微小差异，好的哈希函数在与有限大小数值域上的取模运算结合时，也会把熵几乎均匀地分布到哈希值的所有位上。

参数
str输入数据字符串
nstr 中的字节数
返回
与 str 关联的数值哈希

朴素的恒等哈希函数

此哈希函数要求 n 等于某个基本类型的大小，例如 [u]int8_t、[u]int16_t、[u]int32_t、[u]int64_t、float、double 或 void *，并且 str 的对齐方式与相应原生类型一致。

注解
恒等哈希函数用于测试 sys_hashmap。
