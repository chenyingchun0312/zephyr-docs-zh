int hl78xx_enter_gnss_mode ( const struct device * dev)

#include <zephyr/drivers/modem/hl78xx_apis.h>

进入 GNSS 模式

将调制解调器从 LTE 模式切换到 GNSS 模式。具体切换过程取决于调制解调器当前的电源状态：

Without low-power mode (default / airplane mode path):

  1. 关闭载波（通知应用、关闭套接字）
  2. 将调制解调器置于飞行模式（AT+CFUN=4）
  3. 初始化 GNSS 引擎
  4. 完成时触发 HL78XX_GNSS_ENGINE_READY 事件

  1. 将 GNSS 标记为待处理
  2. 等待调制解调器进入 PSM 睡眠（PSMEV:1）
  3. 唤醒调制解调器（仅 UART —— LTE 保持休眠）
  4. 初始化 GNSS 引擎（无需 CFUN=4，射频路径已空闲）
  5. 完成时触发 HL78XX_GNSS_ENGINE_READY 事件

按照 HL78xx GNSS 应用笔记 5.3：“GNSS 可在 PSM 模式下使用”，因为 LTE 调制解调器不可用，共享的射频接收路径空闲。

进入 GNSS 模式后，调用 hl78xx_queue_gnss_search() 开始定位获取。

int hl78xx_wakeup_modem ( const struct device * dev)

#include <zephyr/drivers/modem/hl78xx_apis.h>

将调制解调器从 PSM 睡眠中唤醒

向调制解调器发送唤醒信号，触发驱动状态机中的 RESUME 事件。调制解调器将重新打开 UART 总线，并继续执行 GNSS（如果在 PSM 后模式中有待处理的 GNSS 请求）或 LTE 注册（AWAIT_REGISTERED）。

这是面向用户的 POST-PSM GNSS 工作流 API：

  1. hl78xx_enter_gnss_mode() — 排队 GNSS，调制解调器进入 PSM
  2. （调制解调器睡眠，等待用户触发）
  3. hl78xx_wakeup_modem() — 唤醒调制解调器，GNSS 在 LTE 之前运行
  4. GNSS 完成，调制解调器返回 LTE 注册

也可以独立于 GNSS 使用，以便为任何目的唤醒调制解调器（例如在下一个 PSM 周期之前发送数据）。

注意
Available only when the following Kconfig option is enabled: CONFIG_MODEM_HL78XX_LOW_POWER_MODE.
参数
dev指向调制解调器设备的指针
返回
成功时为 0
调制解调器不处于睡眠状态时返回 -EALREADY
dev 无效时返回 -EINVAL
