◆ stm32_ex_ops

enum stm32_ex_ops

#include <zephyr/drivers/flash/stm32_flash_api_extensions.h>

STM32 Flash 扩展操作的枚举。

枚举值
FLASH_STM32_EX_OP_SECTOR_WP 

STM32 扇区写保护控制。

注意
Available only when the following Kconfig option is enabled: CONFIG_FLASH_STM32_WRITE_PROTECT.

作为输入，该操作接收带有两个扇区掩码的 flash_stm32_ex_op_sector_wp_in：第一个掩码用于在扇区上启用保护，第二个掩码则做相反的操作。若两个掩码都为 0，则保护保持不变。若同一扇区在两个掩码中都被置位，则启用保护。

作为输出，返回已启用保护的扇区掩码。若只想获取受保护的扇区，输入可以为 NULL。若不需要，输出可以为 NULL。

FLASH_STM32_EX_OP_RDP 

STM32 扇区读出保护控制。

注意
Available only when the following Kconfig option is enabled: CONFIG_FLASH_STM32_READOUT_PROTECTION.

作为输入，该操作接收带有目标 RDP 状态信息的 flash_stm32_ex_op_rdp。作为输出，返回应用更改后的状态。

FLASH_STM32_EX_OP_BLOCK_OPTION_REG 

锁定 STM32 选项寄存器。

该操作使选项寄存器保持锁定，直到下次启动。调用之后无法再更改选项字节（WP、RDP、用户字节）。

FLASH_STM32_EX_OP_BLOCK_CONTROL_REG 

锁定 STM32 控制寄存器。

该操作使控制寄存器保持锁定，直到下次启动。调用之后无法执行擦除或写入等基本操作。

FLASH_STM32_EX_OP_OPTB_READ 

读取 STM32 选项字节。

读取选项字节内容，out 接收 *uint32_t，in 未使用。

FLASH_STM32_EX_OP_OPTB_WRITE 

写入 STM32 选项字节。

写入选项字节内容，in 接收新值，out 未使用。注意，新值只有在设备重启后才会生效。
