int vtd_allocate_entries ( const struct device * dev,
uint8_t n_entries )
inlinestatic

分配连续的 IRTE

参数
dev驱动实例的设备结构体指针
n_entries要分配多少个 IRTE

注意：会尝试全部分配，否则失败。

返回
第一个已分配的 IRTE 索引，失败时为 -EBUSY
