详细描述

并查集实现

这实现了一种并查集（union-find），对所有操作保证 O(alpha(n)) 的运行时间。算法和命名沿用现有学术与教学实现中的惯例，参见：

https://en.wikipedia.org/wiki/Disjoint-set_data_structure

void sys_set_union ( struct sys_set_node * node1,
struct sys_set_node * node2 )

#include <zephyr/sys/set.h>

将两个节点合并到同一个并查集中。

此函数将秩较小的节点挂到秩较大的节点上。也就是说，若 node1 的秩小于 node2，则它将被链接到 node2。

参数
node1指向 sys_set_node 结构体的指针。
node2指向 sys_set_node 结构体的指针。
