#include <zephyr/sys/bitarray.h>

在位数组中分配位

此函数在先前未分配的连续区域中查找一定数量的位（num_bits）。若存在这样的区域，则把这些位标记为已分配，并通过 offset 返回该区域起始处的偏移量。

参数
[in]bitarray位数组结构
[in]num_bits要分配的位数
[out]offset成功时返回所分配区域起始处的偏移量
返回值
0分配成功
-EINVAL参数无效（例如要分配的位多于位数组拥有的位数、尝试分配 0 位等）
-ENOSPC没有足够大的连续区域可容纳该分配

查找区域中第 n 个被设置的位

此函数搜索区域（offset、num_bits），若第 n 个被设置的位存在，则返回其索引（found_at），同时返回值为零。

若不存在，则不更新 found_at，并返回 1。

参数
[in]bitarray位数组结构
[in]n要查找的第 n 个被设置的位
[in]num_bits要检查的位数，必须大于 0
[in]offset起始位位置
[out]found_at若找到，第 n 个被设置的位的索引
返回值
0操作成功
1在区域中未找到第 n 个被设置的位
-EINVAL参数无效（例如越界访问、尝试统计 0 位等）

◆ sys_bitarray_test_and_set_region()

int sys_bitarray_test_and_set_region ( sys_bitarray_t * bitarray,
size_t num_bits,
size_t offset,
bool to_set )

#include <zephyr/sys/bitarray.h>

以单个原子操作测试区域内所有位是否已清除/设置，并设置/清除它们

此函数检查从 offset 开始的区域内所有位（num_bits）是否处于所需状态。若即使只有一位不满足，则返回 -EEXIST。若整个区域已设置/清除，则把它设为相反状态。检查与设置作为单个原子操作完成。

参数
bitarray位数组结构
num_bits要测试并设置的位数
offset要测试并设置的起始位位置
to_set若为 true，则在所有位都已清除时设置该区域；若为 false，则在所有位都已设置时清除该区域
返回值
0操作成功
-EINVAL参数无效（例如要设置的位超出位数组的位数等）
-EEXIST区域内至少有一位已设置/清除，操作被取消
