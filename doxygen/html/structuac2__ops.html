void(*) uac2_ops::buf_release_cb(const struct device *dev, uint8_t terminal, void *buf, void *user_data)

发送缓冲区释放回调

此函数释放通过 usbd_uac2_send 提供的缓冲区，此时该类不再需要它。如果调用 usbd_uac2_send，则必须注册此回调。

参数
devUSB 音频 2 设备
terminal链接到 AudioStreaming 接口的输出终端 ID
buf先前通过 usbd_uac2_send 提供的缓冲区
user_data不透明的用户数据指针

已接收的数据

此函数释放通过 get_recv_buf 获取的缓冲区，此时 USB 已向该缓冲区写入数据并/或不再需要它。从 USB 主机接收 USB 音频的设备必须注册此回调。

参数
devUSB 音频 2 设备
terminal链接到 AudioStreaming 接口的输入终端 ID
buf先前通过 get_recv_buf 获取的缓冲区
size写入缓冲区的字节数
user_data不透明的用户数据指针

◆ feedback_cb

uint32_t(*) uac2_ops::feedback_cb(const struct device *dev, uint8_t terminal, void *user_data)

获取显式反馈值

显式反馈值的格式取决于终端连接速度。如果设备支持高速，则当且仅当调用 terminal_update_cb 时 microframes 参数为 true 的情况下必须使用 Q16.16 格式。对于仅支持全速的设备，或支持高速的设备工作在全速下（microframes 为 false），格式为 Q10.14，存储在 24 个最低有效位中（即 8 个最高有效位被忽略）。如果存在链接到输入终端的、由异步时钟（即不带 sof-synchronized; 的时钟源）提供时钟的 USB 音频流接口，且该接口上没有 implicit-feedback;，则必须注册此回调。

参数
devUSB 音频 2 设备
terminal应返回其反馈的输入终端 ID
user_data不透明的用户数据指针

◆ get_recv_buf

void *(*) uac2_ops::get_recv_buf(const struct device *dev, uint8_t terminal, uint16_t size, void *user_data)

获取接收缓冲区地址

USB 栈调用此函数以获取 AudioStreaming 接口的接收缓冲区地址。该缓冲区归 USB 栈所有，直到 data_recv_cb callback is called. The buffer must be sufficiently aligned and otherwise suitable for use by UDC driver. This callback is mandatory to register for devices receiving USB audio from the USB host.

参数
devUSB 音频 2 设备
terminal链接到 AudioStreaming 接口的输入终端 ID
sizeUSB 栈将写入缓冲区的最大字节数。
user_data不透明的用户数据指针

◆ get_sample_rate

uint32_t(*) uac2_ops::get_sample_rate(const struct device *dev, uint8_t clock_id, void *user_data)

获取活动采样率

如果时钟源实体支持多于一个采样率，USB 栈会在主机询问活动采样率时调用此函数。如果所有时钟源实体仅支持一个采样率，则永远不会调用此函数（应为 NULL）。

参数
devUSB 音频 2 设备
clock_id应返回其采样率的时钟源 ID
user_data不透明的用户数据指针
返回
以 Hz 为单位的活动采样率

◆ set_sample_rate

int(*) uac2_ops::set_sample_rate(const struct device *dev, uint8_t clock_id, uint32_t rate, void *user_data)

设置活动采样率

当主机设置活动采样率时，USB 栈会调用此函数。如果所有时钟源实体只有一个采样率，此回调可为 NULL。USB 栈会将采样率修正为给定时钟源实体最接近的有效速率。

参数
devUSB 音频 2 设备
clock_id应设置其采样率的时钟源 ID
rate以 Hz 为单位的采样率
user_data不透明的用户数据指针
返回
成功时为 0，出错时为负值
