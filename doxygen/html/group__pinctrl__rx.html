用于配置 Renesas RX SoC 引脚控制的宏

引脚通过多功能引脚控制器（MPC）配置。每个引脚配置由 RX_PSEL() 宏构建，该宏组合了外设功能选择器、端口号以及该端口内的引脚号。

提供两种选择器。通用选择器名为 RX_PSEL_<PERIPHERAL> carry a function code shared by every pin of a peripheral, where <PERIPHERAL> is one of RSCI, SCI_1, SCI_5, SCI_6, SCI_12, TMR, POE, ADC or LVD.

按引脚的选择器名为 RX_PSEL_P<PORT>nPFS_<SIGNAL>（例如 RX_PSEL_P1nPFS_RXD1) give the exact code for one pin, where <PORT> is the port letter/number and <SIGNAL> is the peripheral signal routed to the pin. Signals are grouped by peripheral:

  • 多功能定时器（MTU）：MTIOC0A ... MTIOC5W、MTCLKA ... MTCLKD
  • 8 位定时器（TMR）：TMO0 ... TMO3、TMCI0 ... TMCI3、TMRI0 ... TMRI3
  • 串行（SCI）：RXD0 ... RXD12、TXD0 ... TXD12、SCK0 ... SCK12， CTS, RTS, SS
  • SPI（RSPI，或简易 SPI 模式下的 SCI）：RSPCKA、MOSIA、MISOA， SSLA0 ... SSLA3, SMOSI, SMISO
  • I2C（RIIC，或简易 I2C 模式下的 SCI）：SCL、SDA、SSCL、SSDA 电容式触摸（CTSU）：TS0 ... TS35、TSCAP 比较器：CMPOB0、CMPOB1 其他：POE0 ... POE8、ADTRG0、RTCOUT、CLKOUT、CACREF @code {.dts} #include <zephyr/dt-bindings/pinctrl/renesas/pinctrl-rx.h>

&pinctrl { sci1_default: sci1_default { group1 { psels = <RX_PSEL(RX_PSEL_SCI_1, 2, 6)>; }; group2 { psels = <RX_PSEL(RX_PSEL_SCI_1, 3, 0)>; }; }; };

用于编码 Renesas RX SoC 引脚配置的宏。

该宏把模式、外设选择（PSEL）、端口号和引脚号编码为单个 32 位值，适用于设备树 pinctrl 配置。

参数

pin_num端口内的引脚号。
