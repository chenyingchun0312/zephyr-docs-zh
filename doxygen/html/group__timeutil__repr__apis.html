将内核超时转换为 timespec

此函数将以 Zephyr k_timeout_t 对象表示的时长转换为 struct timespec 对象。

注解
若启用了断言且 timeout 不是相对值（即使用了由 K_TIMEOUT_ABS_TICKS 或类似方式生成的超时），此函数将触发断言。
参数
timeout要转换的内核超时
[out]ts用于存储结果的 timespec

◆ timespec_to_timeout()

k_timeout_t timespec_to_timeout ( const struct timespec * req,
struct timespec * rem )
inlinestatic

#include <zephyr/sys/timeutil.h>

将 timespec 转换为内核超时

此函数将以 timespec 对象表示的时长 req 转换为 Zephyr k_timeout_t object.

若 req 包含负时长，或 tv_sec 和 tv_nsec 两个字段均为零，则此函数返回 K_NO_WAIT。

若 req 包含可表示的最大 timespec，即 {max(time_t), 999999999}，则此函数返回 K_FOREVER。

若 req 包含大于最大等效 tick 时长的值，则此函数返回可表示的最大 tick 时长（即 req 将被向下舍入）。

否则，此函数返回向上舍入到 tick 边界的 k_timeout_t。

若 rem 不为 NULL，则它将被设为转换的余数，即所请求时长与所转换时长之差（以 timespec 对象表示），大致如下所示。

rem = requested_duration - converted_duration
参数
req要转换的所请求 timespec
[out]rem指向用于存储余数的 timespec 的可选指针
返回
对应的内核超时
