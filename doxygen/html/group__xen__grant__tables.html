◆ gnttab_alloc_and_grant()

int32_t gnttab_alloc_and_grant ( void ** map,
bool readonly )

#include <zephyr/xen/gnttab.h>

分配一个页并立即授予对其的访问权限。

调用者在不再需要 map 中返回的缓冲区后，必须释放授权，然后对其调用 k_free()。

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_GRANT_TABLE.
参数
[out]map接收页基地址的缓冲区。
readonly设为 true 以授予只读访问权限。
返回
成功时为授权引用，失败时为负的 errno 值。
返回值
-ENOMEM页分配失败。

返回值

void * gnttab_get_pages ( unsigned int npages)

参数

返回
所分配范围的基地址，失败时为 NULL。

◆ gnttab_map_refs()

int gnttab_map_refs ( struct gnttab_map_grant_ref * map_ops,
unsigned int count )

#include <zephyr/xen/gnttab.h>

映射一个或多个外部授权引用。

map_ops 所引用的 host_addr 页必须按 4K 对齐，并应通过 gnttab_get_pages() 获取。

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_GRANT_TABLE.
参数
[in,out]map_ops已准备好的映射操作数组。
countmap_ops 中的条目数量。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-EFAULTXen 扩展区域已启用，而某个主机地址位于这些区域之外。

Xen 还会在每个 map_ops[i].status 字段中存储逐条目的状态码。
