详细描述

仿真计数器后端 API

仿真计数器捕获的行为由应用程序定义。测试通过用 counter_capture_emul_input_set 设置捕获通道上的仿真输入电平来驱动捕获事件。当电平跳变与通道配置的边缘匹配时（通过 counter_capture_configure) and the channel is enabled, the registered capture callback is invoked synchronously, much like gpio_emul_input_set fires GPIO interrupt callbacks.

仿真计数器支持的边缘在设备树中通过计数器节点上的 rising-edge 和 falling-edge 布尔属性声明。

在 chan_id 的仿真捕获输入上驱动 level。若得到的边缘与通道配置的捕获标志匹配且该通道已使能，则同步地以当前计数器值调用捕获回调。
