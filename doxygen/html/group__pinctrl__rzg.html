详细描述

用于配置 Renesas RZ/G SoC 引脚控制的宏

通用引脚由 RZG_PINMUX() 宏配置，该宏接受三个字段：

  • port —— 端口标识，取 PORT_* 之一。
  • pin —— 该端口内的引脚号。
  • func —— 备用功能编号，用于选择路由到该引脚的外设信号，取值来自 SoC 的引脚功能控制器表；它没有符号宏，以普通整数传入。

位于通用端口矩阵之外的专用功能引脚直接通过其 BSP_IO_* 标识引用，涵盖调试（BSP_IO_NMI、BSP_IO_TMS_SWDIO、BSP_IO_TDO）、音频时钟、XSPI Flash、I3C、SD/MMC 以及看门狗溢出。

可用 RZG_FILTER_SET() 为引脚组施加可选的数字噪声滤波器，该宏由级数（RZG_FILNUM_*）和采样时钟分频（RZG_FILCLKSEL_*）构建。 预定义的端口/引脚组合因 RZ/G 型号而异，由各型号专用的头文件提供：

  • pinctrl-rzg-common.h — RZ/G3S
  • pinctrl-rzg2-common.h — RZ/G2L, RZ/G2LC, RZ/G2UL
  • pinctrl-rzg3e.h — RZ/G3E
#include <zephyr/dt-bindings/pinctrl/renesas/pinctrl-rzg-common.h>
&pinctrl {
scif0_default: scif0_default {
device-pinmux {
pinmux = <RZG_PINMUX(PORT_08, 1, 5)>,
<RZG_PINMUX(PORT_08, 2, 5)>;
bias-pull-up;
renesas,filter =
RZG_FILTER_SET(RZG_FILNUM_8_STAGE, RZG_FILCLKSEL_DIV_18000);
};
};
};

#define RZG_FILTER_SET ( filnum,
filclksel )

#include <zephyr/dt-bindings/pinctrl/renesas/pinctrl-rzg-common.h>

值:
(((filnum) & 0x3) << 0x2) | (filclksel & 0x3)

把滤波器级数和时钟选择编码为一个配置值。

编码方式：

  • bits [3:2] = FILNUM（掩码为 2 位）
  • bits [1:0] = FILCLKSEL（掩码为 2 位）
参数
filnum滤波器级数选择（RZG_FILNUM_*）。
filclksel滤波器时钟选择（RZG_FILCLKSEL_*）。
返回
编码后的滤波器配置值。
