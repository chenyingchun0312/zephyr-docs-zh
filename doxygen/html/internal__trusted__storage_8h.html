◆ psa_its_get()

psa_status_t psa_its_get ( psa_storage_uid_t uid,
size_t data_offset,
size_t data_size,
void * p_data,
size_t * p_data_length )

检索与所提供 uid 关联的数据。

参数
[in]uid数据的标识符。
[in]data_offset开始读取数据的偏移（字节）。
[in]data_size要读取的字节数。
[out]p_data成功时存放数据的缓冲区。长度必须至少为 data_size 字节。
[out]p_data_length成功时，放入 p_data 的字节数。
返回值
PSA_SUCCESS操作成功完成。
PSA_ERROR_GENERIC_ERROR发生了未指明的内部故障。
PSA_ERROR_INVALID_ARGUMENT一个或多个参数无效。当 data_offset 大于与 uid 关联的数据大小时也会发生此错误。
PSA_ERROR_DOES_NOT_EXIST在存储中未找到所提供的 uid。
PSA_ERROR_STORAGE_FAILURE物理存储发生故障（致命错误）。
PSA_ERROR_INVALID_SIGNATURE与 uid 关联的数据未通过认证。
PSA_ERROR_DATA_CORRUPT与 uid 关联的数据已损坏。

◆ psa_its_remove()

psa_status_t psa_its_remove ( psa_storage_uid_t uid)

删除所提供的 uid 及其关联数据。

从内部存储中删除与该条目关联的所有数据。

参数
uid要删除的条目标识符。
返回值
PSA_SUCCESS操作成功完成。
PSA_ERROR_NOT_PERMITTED该条目是以 PSA_STORAGE_FLAG_WRITE_ONCE 创建的。
PSA_ERROR_INVALID_ARGUMENTuid is invalid.
PSA_ERROR_DOES_NOT_EXIST在存储中未找到所提供的 uid。
PSA_ERROR_STORAGE_FAILURE物理存储发生故障（致命错误）。

◆ psa_its_set()

psa_status_t psa_its_set ( psa_storage_uid_t uid,
size_t data_length,
const void * p_data,
psa_storage_create_flags_t create_flags )

创建新条目或修改现有条目。

将数据存储在内部存储中。

参数
uid数据的标识符。必须非零。
data_lengthp_data 中要存储的数据大小（字节）。
p_data包含要存储数据的缓冲区。
create_flags指示条目属性的标志。
返回值
PSA_SUCCESS操作成功完成。
PSA_ERROR_GENERIC_ERROR发生了未指明的内部故障。
PSA_ERROR_NOT_PERMITTED与所提供的 uid 关联的条目已存在，并且是以 PSA_STORAGE_FLAG_WRITE_ONCE 创建的。
PSA_ERROR_NOT_SUPPORTEDcreate_flags 中提供的一个或多个标志不受支持或无效。
PSA_ERROR_INVALID_ARGUMENTcreate_flags 以外的一个或多个参数无效。
PSA_ERROR_INSUFFICIENT_STORAGE存储介质上的空间不足。
PSA_ERROR_STORAGE_FAILURE物理存储发生故障（致命错误）。
