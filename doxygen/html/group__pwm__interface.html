 PWM 引脚捕获捕获周期。
#define PWM_CAPTURE_TYPE_PULSE   (2U << PWM_CAPTURE_TYPE_SHIFT)
 PWM 引脚捕获捕获脉宽。
#define PWM_CAPTURE_TYPE_BOTH
 PWM 引脚捕获同时捕获周期和脉宽。
#define PWM_CAPTURE_MODE_SINGLE   (0U << PWM_CAPTURE_MODE_SHIFT)
 PWM 引脚捕获捕获单个周期/脉宽。
#define PWM_CAPTURE_MODE_CONTINUOUS   (1U << PWM_CAPTURE_MODE_SHIFT)
 PWM 引脚捕获持续捕获周期/脉宽。

PWM 事件类型

#define PWM_EVENT_TYPE_SHIFT   0U
#define PWM_EVENT_TYPE_PERIOD   (1U << PWM_EVENT_TYPE_SHIFT)
 配置为在每个 PWM 周期结束时触发事件
#define PWM_EVENT_TYPE_FAULT   (2U << PWM_EVENT_TYPE_SHIFT)
 配置为在故障时触发事件。可用于对导致 PWM 外设行为改变（通常是禁用输出）的错误事件作出反应。这些错误事件的来源可以是内部的（例如振荡器故障）或外部的（例如 pio）
#define PWM_EVENT_TYPE_COMPARE_CAPTURE   (4U << PWM_EVENT_TYPE_SHIFT)
 配置为在比较/捕获匹配时触发事件。当计数器达到比较值（输出比较模式）或捕获到外部边沿（输入捕获模式）时触发。

PWM 周期设置辅助宏。PWM 说明符中的 period 单元需以纳秒为单位给出。但在某些应用中，使用其他量级更为方便。@{

#define PWM_NSEC(x)
 以纳秒为单位指定 PWM 周期
#define PWM_USEC(x)
 以微秒为单位指定 PWM 周期
#define PWM_MSEC(x)
 以毫秒为单位指定 PWM 周期
#define PWM_SEC(x)
 以秒为单位指定 PWM 周期
#define PWM_HZ(x)
 以赫兹为单位指定 PWM 频率
#define PWM_KHZ(x)
 以千赫兹为单位指定 PWM 频率

PWM 极性标志。<tt>PWM_POLARITY_*</tt> 标志与 pwm_set_cycles()、pwm_set() 或 pwm_configure_capture() 配合使用，用于指定 PWM 通道的极性。

这些标志位于 pwm_flags_t 的低 8 位

#define PWM_POLARITY_NORMAL   (0 << 0)
 PWM 引脚正常极性（高电平有效脉冲）。
#define PWM_POLARITY_INVERTED   (1 << 0)
 PWM 引脚反相极性（低电平有效脉冲）。

◆ pwm_set_cycles()

int pwm_set_cycles ( const struct device * dev,
uint32_t channel,
uint32_t period,
uint32_t pulse,
pwm_flags_t flags )

#include <zephyr/drivers/pwm.h>

为单个 PWM 输出设置周期和脉宽。

PWM 周期和脉宽会被同步设置为新值，且 PWM 信号中不会出现毛刺，但该调用不会阻塞等待变更生效。

注解
并非所有 PWM 控制器都支持同步、无毛刺地更新 PWM 周期和脉宽。视硬件而定，改变 PWM 周期和/或脉宽可能会在所生成的 PWM 信号中产生毛刺。
某些多通道 PWM 控制器的所有通道共享 PWM 周期。视硬件而定，改变一个通道的 PWM 周期可能会影响同一 PWM 控制器其他通道的 PWM 周期。

将 pulse 传为 0 会使引脚被驱动到恒定的非活动电平。将非零的 pulse 传为等于 period 的值会使引脚被驱动到恒定的活动电平。

参数
[in]devPWM 设备实例。
channelPWM channel.
period设置给 PWM 的周期（以时钟周期计）。与硬件相关。
pulse设置给 PWM 的脉宽（以时钟周期计）。与硬件相关。
flags引脚配置标志。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-EINVAL脉宽超过周期。
