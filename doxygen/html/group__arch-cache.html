◆ arch_dcache_flush_and_invd_range()

int arch_dcache_flush_and_invd_range ( void * addr,
size_t size )

#include <zephyr/arch/cache.h>

刷新并使 d-cache 中的地址范围失效

刷新并使数据缓存中指定的地址范围失效。

注解
缓存操作以缓存行为单位。当多个数据结构共享正在被刷新的同一条缓存行时，共享该行的数据结构的所有部分都会在失效之前被刷新。这通常不是问题，因为回写是非破坏性过程，硬件可能在任何时候触发它，因此对齐的 addr 或补齐的 size 并非严格必要。
参数
addr要刷新并使之失效的起始地址。
size范围大小。
返回值
0If succeeded.
-ENOTSUP不受支持时。
-errno其他失败时为负的 errno。

使 d-cache 中的地址范围失效

使数据缓存中指定的地址范围失效。

注解
缓存操作以缓存行为单位。当多个数据结构共享正在失效的同一条缓存行时，共享该行的非只读数据结构的所有部分也会失效。这是破坏性过程，可能导致数据丢失和/或被破坏。当 addr 未按缓存行对齐和/或 size 不是缓存行大小的整数倍时，行为未定义。
参数
addr要使之失效的起始地址。
size范围大小。
返回值
0If succeeded.
-ENOTSUP不受支持时。
