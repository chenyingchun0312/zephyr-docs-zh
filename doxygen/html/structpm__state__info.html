◆ min_residency_us

uint32_t pm_state_info::min_residency_us

注解

◆ pm_device_disabled

bool pm_state_info::pm_device_disabled

此状态是否触发设备电源管理。

当此属性为 false 时，电源管理子系统将在进入此状态之前挂起设备，并在离开时正确地恢复它们。

◆ substate_id

uint8_t pm_state_info::substate_id

某些平台有多个状态映射到同一个 Zephyr 电源状态。此属性允许平台区分它们。例如：

power-states {
state0: state0 {
compatible = "zephyr,power-state";
power-state-name = "suspend-to-idle";
substate-id = <1>;
min-residency-us = <10000>;
exit-latency-us = <100>;
};
state1: state1 {
compatible = "zephyr,power-state";
power-state-name = "suspend-to-idle";
substate-id = <2>;
min-residency-us = <20000>;
exit-latency-us = <200>;
zephyr,pm-device-disabled;
};
};
