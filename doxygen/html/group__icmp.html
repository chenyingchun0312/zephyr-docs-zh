◆ net_icmp_handler_t

typedef enum net_verdict(*) net_icmp_handler_t(struct net_icmp_ctx *ctx, struct net_pkt *pkt, struct net_icmp_ip_hdr *ip_hdr, struct net_icmp_hdr *icmp_hdr, void *user_data)

#include <zephyr/net/icmp.h>

收到 ICMP 响应时调用的处理函数。

参数
ctx要使用的 ICMP 上下文。
pkt收到的 ICMP 响应网络报文。
ip_hdr该报文的 IP 头部。
icmp_hdr该报文的 ICMP 头部。
user_data指向用户数据的有效指针，或 NULL
返回值
NET_OK报文已被成功处理，不会再调用其他处理程序。
NET_CONTINUE该报文未被此处理程序处理，应传递给下一个处理程序。
NET_DROP应丢弃该报文，且不会再调用其他处理程序。

◆ net_icmp_offload_ping_handler_t

typedef int(*) net_icmp_offload_ping_handler_t(struct net_icmp_ctx *ctx, struct net_if *iface, struct net_sockaddr *dst, struct net_icmp_ping_params *params, void *user_data)

#include <zephyr/net/icmp.h>

当有回显请求发送到卸载设备时调用的处理函数。此处理程序通常由设备驱动设置，以便捕获 ping 请求并将其发送给卸载设备。

参数
ctx此请求中使用的 ICMP 上下文。
iface网络接口，可设为 NULL，此时将根据目的地址选择接口。
dst目标主机的 IP 地址。
params回显请求专用参数。可以为 NULL，此时使用合适的默认参数。
user_data传给处理程序的用户提供的不透明数据。可以为 NULL。

#include <zephyr/net/icmp.h>

发送 ICMP 回显请求消息，且发送过程中不等待。

此函数可用于从系统工作队列的处理程序中发送 ICMP 回显请求，该处理程序不应有任何睡眠或等待。此变体使用 K_NO_WAIT 进行 net_buf 分配。这样可以避免日志中关于超时的警告消息。

参数
ctx此请求中使用的 ICMP 上下文。
iface网络接口，可设为 NULL，此时将根据目的地址选择接口。
dst目标主机的 IP 地址。
params回显请求专用参数。可以为 NULL，此时使用合适的默认参数。
user_data传给处理程序的用户提供的不透明数据。可以为 NULL。
返回
发送成功时返回 0，否则 <0。
