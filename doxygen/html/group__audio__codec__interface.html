◆ audio_codec_register_done_callback()

int audio_codec_register_done_callback ( const struct device * dev,
audio_codec_tx_done_callback_t tx_cb,
void * tx_cb_user_data,
audio_codec_rx_done_callback_t rx_cb,
void * rx_cb_user_data )
inlinestatic

#include <zephyr/audio/codec.h>

注册编解码器一帧数据发送/接收完成时的回调函数。

该回调将从 DMA ISR（中断）上下文中调用。因此回调必须：

  • 非常短小，并避免深调用栈或大量栈分配，因为 ISR 栈是有限的。
  • 不得睡眠或阻塞（不得等待信号量、互斥量、队列等）。
  • 只调用明确记录为 IRQ/ISR 安全的 API。
  • 避免繁重的处理或大量日志输出；应将此类工作推迟到线程或工作队列上下文中（例如提交工作项）。
参数
dev指向音频编解码器设备的指针
tx_cbDMA 帧发送完成时应调用的函数
tx_cb_user_data将传给 tx_cb 的用户数据
rx_cbDMA 帧接收完成时应调用的函数
rx_cb_user_data将传给 rx_cb 的用户数据
返回
如果成功则为 0，失败时为负的 errno 码。

◆ audio_codec_write()

int audio_codec_write ( const struct device * dev,
uint8_t * data,
size_t data_size )
inlinestatic

#include <zephyr/audio/codec.h>

为音频播放写入一个块大小的数据。

将音频数据写入设备以供播放，不等待数据被发送。这是一个非阻塞 API：驱动接受（或拒绝）缓冲区后函数即返回，而不是在音频数据实际播放完毕后才返回。

参数
dev指向编解码器驱动实例的设备结构的指针。
data指向数据的指针。
data_size数据大小，以字节为单位。
返回
如果成功则为 0，失败时为负的 errno 码。
