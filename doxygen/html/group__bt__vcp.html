◆ bt_vcp_vol_ctlr_discover()

int bt_vcp_vol_ctlr_discover ( struct bt_conn * conn,
struct bt_vcp_vol_ctlr ** vol_ctlr )

#include <zephyr/bluetooth/audio/vcp.h>

发现音量控制服务及其包含的服务。

这会启动 GATT 发现并设置句柄和订阅。应在对对端设备执行任何其他操作之前调用一次，并且 bt_vcp_vol_ctlr_cb::discover callback will notify when it is possible to start remote operations.

此操作只能作为客户端执行，

参数
conn要为其发现音量控制服务的连接。
[out]vol_ctlr成功时为有效的远端实例对象。
返回
成功时为 0，失败时为 errno。

int bt_vcp_vol_ctlr_included_get ( struct bt_vcp_vol_ctlr * vol_ctlr,

获取音量控制服务所包含的服务。

返回指向某个结构体的指针，该结构体包含音量控制服务所包含服务实例的信息，例如指向音量偏移控制服务（Volume Offset Control Service）或音频输入控制服务（AICS）实例的指针。

要求启用 CONFIG_BT_VCP_VOL_CTLR_VOCS 或 CONFIG_BT_VCP_VOL_CTLR_AICS。

参数
vol_ctlr音量控制器实例指针。
[out]included用于存放结果的指针。
返回
成功时为 0，失败时为 errno。
