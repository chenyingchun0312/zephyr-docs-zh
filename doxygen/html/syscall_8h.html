◆ k_is_user_context()

bool k_is_user_context ( void )
inlinestatic

指示 CPU 当前是否处于用户模式

返回
如果 CPU 当前以用户权限运行则为 true

注意！如果你根据 k_is_user_context() 进行分支，然后执行仅限内核的操作，则必须在特权操作之前插入内存屏障。编译器和 CPU 都可能在分支前后重排内存操作。没有屏障时，与特权路径相关的内存访问可能会被移到上下文检查之前或被推测执行。
