详细描述

保存工作队列可选配置项的结构。

此结构及其引用的值不会被 k_work_queue_start() 保留。

结构体成员变量说明

◆ essential

bool k_work_queue_config::essential

控制是否将工作队列线程标记为必需线程。

◆ name

const char* k_work_queue_config::name

要赋予工作队列线程的名称。

如果留为 null，该线程将没有名称。

◆ no_yield

bool k_work_queue_config::no_yield

控制工作队列线程是否应在各项之间让出 CPU。

在各项之间让出 CPU 有助于保证工作队列线程不会饿死其他线程，包括由工作项释放的协作式线程。这是默认行为。

将此值设为 true 可防止工作队列线程在各项之间让出 CPU。当一系列项应在不让出控制权的情况下连续完成时，这可能适用。

◆ work_timeout_ms

uint32_t k_work_queue_config::work_timeout_ms

控制工作队列是否监视工作超时。

如果非零且启用了 CONFIG_WORKQUEUE_WORK_TIMEOUT，工作队列将监视每个工作项的持续时间。如果工作项处理函数的执行时间超过指定时间，工作队列线程将被中止，并且如果启用了 CONFIG_LOG 将记录错误。
