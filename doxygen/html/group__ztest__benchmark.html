定义手动采样的基准测试

框架每次迭代运行一次主体，与 ZTEST_BENCHMARK() 完全一样，但由主体决定测量自身的哪一部分，即用 ztest_benchmark_start() 和 ztest_benchmark_end() 将其括出：

ZTEST_BENCHMARK_MANUAL(my_suite, my_benchmark, 1000, NULL, NULL)
{
prepare();
ztest_benchmark_start();
operation_under_test();
ztest_benchmark_end();
}

结束手动基准测试迭代的测量区间

That covers a span the framework cannot time by itself because it does not start and end where the body does. Both hooks are safe to call from an ISR, so a span need not even begin and end in the same execution context: for the latency from an interrupt to the thread it wakes, the ISR calls ztest_benchmark_start() and the woken thread calls ztest_benchmark_end().

A body that records no span contributes no sample for that iteration.

void ztest_benchmark_end ( void )

#include <subsys/testsuite/ztest/include/zephyr/benchmark.h>

结束手动基准测试迭代的测量区间

记录当前时间戳。若之前没有 ztest_benchmark_start()，则不存在区间，该调用被忽略。

可从 ISR 安全调用，原因与 ztest_benchmark_start() 相同：区间在主体返回线程上下文后才交给统计。

◆ ztest_benchmark_start()

void ztest_benchmark_start ( void )

#include <subsys/testsuite/ztest/include/zephyr/benchmark.h>

开始手动基准测试迭代的测量区间

记录当前时间戳。主体在本次调用之前所做的任何工作都不计入测量。

可从 ISR 安全调用：它只获取时间戳，因此起始时间属于中断上下文的区间可直接在那里标记。样本本身在主体返回后才计算。

在 ZTEST_BENCHMARK_MANUAL() 主体之外进行的调用会被忽略。
