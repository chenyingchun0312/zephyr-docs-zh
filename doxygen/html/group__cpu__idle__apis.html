◆ k_cpu_atomic_idle()

void k_cpu_atomic_idle ( unsigned int key)
inlinestatic

#include <zephyr/kernel.h>

以原子方式使 CPU 空闲。

与 k_cpu_idle() 类似，但必须在中断锁定的情况下调用。

使能中断并进入低功耗模式将是原子操作，即不存在处理器进入低功耗模式之前中断被使能的时间段。

从低功耗模式唤醒后，中断锁定状态将如同通过 irq_unlock(key) 一样被恢复。

参数
key从 irq_lock() 获得的中断锁定键。

◆ k_cpu_idle()

void k_cpu_idle ( void )
inlinestatic

#include <zephyr/kernel.h>

使 CPU 空闲。

此函数使 CPU 空闲，直到有事件将其唤醒。

在常规系统中，空闲线程应是唯一负责使 CPU 空闲并触发任何类型电源管理的线程。然而在一些受限系统中（例如单线程系统），如有需要，唯一的一个线程将负责此工作。

注解
在某些架构上，此函数在返回前会无条件解除中断屏蔽。
