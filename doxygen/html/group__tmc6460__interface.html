◆ tmc6460_disable()

int tmc6460_disable ( const struct device * dev)

#include <zephyr/drivers/misc/tmc6460/tmc6460.h>

禁用 TMC6460 栅极驱动。

清除 MCC_CONFIG_GDRV 寄存器中的 DRV_EN 位，禁用栅极驱动输出级。这是读-改-写操作，因此寄存器中的其他位保持不变。

参数
dev指向 TMC6460 设备的指针。
返回值
0成功时。
-EIO总线失败时。

◆ tmc6460_poll_flag()

int tmc6460_poll_flag ( const struct device * dev,
uint16_t reg_addr,
uint32_t flag_mask,
uint32_t poll_interval_ms,
uint32_t timeout_ms )

#include <zephyr/drivers/misc/tmc6460/tmc6460.h>

轮询寄存器，直到给定的标志位全部置位或超时。

反复读取 reg_addr，并检查其中的所有位是否 flag_mask are set, sleeping poll_interval_ms between reads. This is a reusable helper for the common "wait for a ready/lock status bit" pattern (e.g. PLL lock, ADC ready).

参数
dev指向 TMC6460 设备的指针。
reg_addr要轮询的 16 位状态寄存器地址。
flag_mask必须全部置位才算成功的位掩码。
poll_interval_ms两次读取之间的延迟，单位为毫秒（0 表示紧凑循环）。
timeout_ms最长等待时间，单位为毫秒。
返回值
0如果标志位已置位。
-ETIMEDOUT如果先超时。
-EIO总线失败时。

向 RTMI 流式寄存器槽写入值（仅 UART）。

使用发后不管的流式写入协议（同步字节 0x41）。此函数仅在使能 CONFIG_TMC6460_UART 时可用。

-errno失败时。
