void(*) bt_hfp_hf_cb::call_waiting(struct bt_hfp_hf_call *call, const char *number, uint8_t type)

向应用程序通知 HF 呼叫等待的回调

如果提供了此回调，则每当出现非请求结果码 +CCWA 时都会调用它。可通过调用函数 bt_hfp_hf_call_waiting_notify 启用或禁用此通知。如果未启用 CONFIG_BT_HFP_HF_3WAY_CALL，则非请求结果码 +CCWA 将被忽略，且不会通知该回调。

参数
callHFP HF 呼叫对象。
number通知的电话号码。
type指定电话号码的格式。

◆ subscriber_number

void(*) bt_hfp_hf_cb::subscriber_number(struct bt_hfp_hf *hf, const char *number, uint8_t type, uint8_t service)

查询用户号码回调

如果提供了此回调，则每当从 AG 收到结果码 +CUNM: [<alpha>],<number>, <type>,[<speed> ,<service>] 时都会调用它。<alpha>：不支持此可选字段，应留空。<number>：带引号的字符串，包含以 <type> 指定格式的电话号码。<type> 字段指定所提供电话号码的格式，可取以下值之一：

  • 值 128-143：电话号码格式可以是国内或国际格式，可包含前缀和/或转义数字。号码呈现方式无需更改。
  • 值 144-159：电话号码格式为国际号码，包含国家代码前缀。如果号码中未包含加号（“+”），则应由 AG 按需添加。
  • 值 160-175：国内号码。不包含前缀或转义数字。<speed>：不支持此可选字段，应留空。<service>：指示此电话号码与哪项服务相关。应为 4（语音）或 5（传真）。
参数
hfHFP HF object.
number不带引号的 <number> 的值。
type<type> 的值。
service<service> 的值。

◆ textual_representation

void(*) bt_hfp_hf_cb::textual_representation(struct bt_hfp_hf *hf, char *id, uint8_t type, uint8_t operation, const char *text)

文本表示回调

如果提供了此回调，则每当从 AG 收到非请求结果码 +BVRA: 1,<vrecstate>, <textualRepresentation> 时都会调用它。<textualRepresentation>: <textID>,<textType>,<textOperation>, <string>。<textID>：当前文本的唯一 ID，为十六进制字符串（最长 4 个字符，少于 4 个字符也有效）。<textType>：来自以下列表的 textType ID：0 - AG 从 HF 提供的音频输入中识别出的文本；1 - AG 的音频输出文本；2 - AG 的音频输出文本，其中包含一个问题；3 - AG 的音频输出文本，其中包含错误描述。<textOperation>：文本操作的 ID：1 - NewText：表示开始一个新文本，应在 <textID> 变化时使用；2 - Replace：替换任何具有相同 <textID> 和相同 <textType> 的现有文本；3 - Append：在现有文本后附加新文本，并保持相同的 <textID> 和 <textType>。<string>：<string> 参数应为 UTF-8 文本字符串，且必须始终包含在双引号内。如果未启用 CONFIG_BT_HFP_HF_VOICE_RECG_TEXT，则非请求结果码 +BVRA 将被忽略，且不会通知该回调。

参数
hfHFP HF object.
id<textID> 的值。
type<textType> 的值。
operation<textOperation> 的值。
text<string> 的值。

◆ vre_state

void(*) bt_hfp_hf_cb::vre_state(struct bt_hfp_hf *hf, uint8_t state)

语音识别引擎状态回调

如果提供了此回调，则每当从 AG 收到非请求结果码 +BVRA: 1,<vrecstate> 时都会调用它。<vrecstate>：反映 AG 上语音识别引擎当前状态的位掩码。位 0 - 若为 1，表示 AG 已准备好接受音频输入；位 1 - 若为 1，表示 AG 正在向 HF 发送音频；位 2 - 若为 1，表示 AG 正在处理音频输入。如果未启用 CONFIG_BT_HFP_HF_ENH_VOICE_RECG，则非请求结果码 +BVRA 将被忽略，且不会通知该回调。

参数
hfHFP HF object.
state<vrecstate> 的值。
