◆ k_condvar_wait()

int k_condvar_wait ( struct k_condvar * condvar,
struct k_mutex * mutex,
k_timeout_t timeout )

#include <zephyr/kernel.h>

在条件变量上等待并释放互斥量锁

原子地释放当前拥有的互斥量，阻塞当前线程以等待 condvar 指定的条件变量，最后重新获取该互斥量。

只有在另一个线程对同一条件变量调用 k_condvar_signal 或 k_condvar_broadcast 后，等待的线程才会解除阻塞。

参数
condvark_condvar 结构的指针
mutex互斥量的地址。
timeout条件变量的等待时间，或特殊值 K_NO_WAIT 和 K_FOREVER 之一。
返回值
0成功时
-EAGAIN等待时间超时。
