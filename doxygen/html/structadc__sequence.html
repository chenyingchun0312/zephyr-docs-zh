void* adc_sequence::buffer

指向用于写入采样数据的缓冲区的指针。后续采样的采样值会依次写入该缓冲区。每次采样写入的采样值数量由 "channels" 字段中选中的通道数决定。写入缓冲区的值表示来自每个选中通道的采样，从 ID 最小的通道开始。缓冲区必须具有合适的大小，需考虑选中的通道数、所用的 ADC 分辨率以及序列中包含的采样次数。

bool adc_sequence::calibrate

若请求，则在读取之前执行校准。

通道配置对校准过程的影响取决于具体硬件。不支持校准的 ADC 实现应忽略该标志。

◆ oversampling

uint8_t adc_sequence::oversampling

过采样设置。每个采样值由 2^oversampling 个转换结果平均得到。给定 ADC 硬件可能不支持该功能，或在特定模式下不支持（例如采样多个通道时）。

◆ priority

uint32_t adc_sequence::priority

用于仲裁的通道优先级。0 表示默认/最低优先级；数值越大表示优先级越高；相等表示无偏好。不保证类似内核的语义（如抢占/完全阻塞），仅作为硬件/驱动仲裁的提示。可能的优先级数量取决于硬件。

注意
Available only when the following Kconfig option is enabled: CONFIG_ADC_SEQUENCE_PRIORITY.
