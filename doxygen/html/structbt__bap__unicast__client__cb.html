◆ discover

void(*) bt_bap_unicast_client_cb::discover(struct bt_conn *conn, int err, enum bt_audio_dir dir)

BAP 发现回调函数。

如果发现过程已完成，ep 设为 NULL 且 err 为 0。

参数
conn到远程单播服务器的连接。
err错误值。成功时为 0，正值时为 GATT 错误，负值时为 errno。
dir所发现的远程端点与能力的类型。

如果发现过程已完成，codec 和 ep 都将设为 NULL。

void(*) bt_bap_unicast_client_cb::pac_record(struct bt_conn *conn, enum bt_audio_dir dir, const struct bt_audio_codec_cap *codec_cap)

发现远程已发布音频能力（PAC）记录

当在发现过程中发现 PAC 记录时调用。

codec 仅在回调期间有效，因此如需后续使用，接收方必须保存其值。

参数
conn到远程单播服务器的连接。
dir所发现的远程端点与能力的类型。
codec_cap远程能力。

如果发现过程已完成，codec 和 ep 都将设为 NULL。
