定义 bytes 类型的二进制描述符。

定义一个注册到二进制描述符头部的 uint8_t 数组。所定义的数组可通过 BINDESC_GET_BYTES 访问。该值应以数组字面量的形式给出，并用括号包裹，例如： 

BINDESC_BYTES_DEFINE(name, id, ({1, 2, 3, 4}));
注解
所定义的数组不是 static 的，因此其名称不得与可执行文件中的任何其他符号冲突。
参数
name描述符的名称
id描述符的唯一 ID
value作为描述符数据的 uint8_t 数组

获取 bytes 二进制描述符的值

获取先前由 BINDESC_BYTES_DEFINE 定义的字符串二进制描述符的值。返回值可作为数组访问： 

for (size_t i = 0; i < BINDESC_GET_SIZE(name); i++)
    BINDESC_GET_BYTES(name)[i];
