◆ cb

void(*) lorawan_downlink_cb::cb(uint8_t port, uint8_t flags, int16_t rssi, int8_t snr, uint8_t len, const uint8_t *data)

对下行数据运行的回调函数

注解
回调在系统工作队列上运行，因此应尽可能短小。
参数
port消息发送所用的端口
flags下行数据标志（参见 lorawan_dl_flags）
rssi接收信号强度，单位 dBm
snr信噪比，单位 dBm
len收到的数据长度，对于 ACK 将为 0
data收到的数据，对于 ACK 将为 NULL

◆ port

uint16_t lorawan_downlink_cb::port

要为其处理消息的端口。

  • 端口 0：TX 数据包确认
  • 端口 1-255：标准下行端口
  • LW_RECV_PORT_ANY：所有下行
