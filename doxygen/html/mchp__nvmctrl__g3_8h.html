详细描述

支持 Microchip flash-controller G3 驱动 ex_op 的头文件

该头文件提供 Microchip NVMCTRL G3 Flash 控制器专用的附加 Flash 存储器操作定义。它通过启用区域锁定/解锁、清除页缓冲区等高级操作来扩展标准 Flash API 能力，

注解
该 API 扩展只应在面向带有 NVMCTRL G3 Flash 控制器的设备时使用。
