◆ BC12_CHARGER_MIN_CURR_UA

#define BC12_CHARGER_MIN_CURR_UA   2500

#include <zephyr/drivers/usb/usb_bc12.h>

BC1.2 USB 充电器最小电流。设为与 Isusp 2.5 mA 参数匹配。当 BC1.2 检测失败或连接的伙伴为 SDP（标准下行端口）时，驱动返回该值。

应用程序可在确定 USB 设备处于挂起/未配置/已配置状态后提高取用电流。挂起：2.5 mA；未配置：100 mA；已配置：500 mA（USB 2.0）

typedef void(*) bc12_callback_t(const struct device *dev, struct bc12_partner_state *state, void *user_data)

用于充电器配置的 BC1.2 回调

参数
dev通知新充电器状态的 BC1.2 设备。
stateBC1.2 客户端的当前状态，包括检测到的 BC1.2 类型、电压和电流限制。如果为 NULL，则伙伴充电器已断开或 BC1.2 设备工作在主机模式。
user_data请求方提供的数据，会一并传给回调。
