#include <zephyr/bluetooth/mesh/dfu_cli.h>

DFU 映像回调。

调用 bt_mesh_dfu_cli_imgs_get 时，会为目标节点上的每个 DFU 映像调用映像回调。

参数

img给定映像索引的映像信息。
cb_data回调数据。

◆ bt_mesh_dfu_cli_confirm()

int bt_mesh_dfu_cli_confirm ( struct bt_mesh_dfu_cli * cli)

#include <zephyr/bluetooth/mesh/dfu_cli.h>

确认活动传输已在目标节点上应用。

只有在传输已应用之后才能确认它。确认过程结束时将调用固件更新客户端的 confirmed 回调。

已报告效果为 BT_MESH_DFU_EFFECT_UNPROV 的目标节点预计不会响应该查询，如果它们响应则会失败。

参数
cli固件更新客户端模型实例。
返回
成功时返回 0，否则返回（负的）错误码。

◆ bt_mesh_dfu_cli_imgs_get()

int bt_mesh_dfu_cli_imgs_get ( struct bt_mesh_dfu_cli * cli,
struct bt_mesh_msg_ctx * ctx,
bt_mesh_dfu_img_cb_t cb,
void * cb_data,
uint8_t max_count )

#include <zephyr/bluetooth/mesh/dfu_cli.h>

执行 DFU 映像列表请求。

请求目标节点上完整的 DFU 映像列表，并遍历它们，为每个映像调用 cb。

DFU 映像列表请求可用于确定目标节点将其各个固件存放在哪个映像索引中。

等待响应，直到过程超时。

参数
cli固件更新客户端模型实例。
ctx消息上下文。
cb要为每个映像索引调用的回调。
cb_data要传给 cb 的回调数据。
max_count要返回的最大映像数量。
返回
成功时返回 0，否则返回（负的）错误码。

#include <zephyr/bluetooth/mesh/dfu_cli.h>

开始分发 DFU。

开始将给定槽位中的固件分发到 ctx 中的 DFU 目标节点列表。传输在后台运行，其结束通过 bt_mesh_dfu_cli_cb::ended 回调指示。

注解
BLOB 传输客户端的传输输入 targets 列表必须指向 bt_mesh_dfu_target 节点列表。
参数
cli固件更新客户端模型实例。
inputsBLOB 传输客户端传输输入。
io要从中读取 BLOB 的 BLOB 流。
xfer固件更新客户端传输参数。
返回
成功时返回 0，否则返回（负的）错误码。
