◆ bt_ccp_call_control_client_discover()

int bt_ccp_call_control_client_discover ( struct bt_conn * conn,
struct bt_ccp_call_control_client ** out_client )

#include <zephyr/bluetooth/audio/ccp.h>

发现远端设备上的电话承载服务（TBS）支持。

这会在远端设备上发现电话承载服务（TBS）和通用电话承载服务（GTBS）。

注意
Available only when the following Kconfig option is enabled: CONFIG_BT_CCP_CALL_CONTROL_CLIENT..
参数
conn与远端服务器的连接。
out_client成功时为指向客户端实例的指针
返回值
0成功
-EINVALconn 或 out_client 为 NULL
-ENOTCONNconn 未连接
-ENOMEM无法为请求分配内存
-EBUSY已在为 conn 执行发现
-ENOEXEC底层 TBS 客户端返回了意外错误
