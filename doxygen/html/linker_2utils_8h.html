bool linker_is_in_rodata ( const void * addr)
inlinestatic

检查地址是否位于只读段中。

检查默认的 .rodata 区域以及任何迁移的 rodata 段（CCM_RODATA、SMEM_RODATA），这些段的链接器符号通过弱引用暴露。这可确保由 zephyr_code_relocate(LOCATION ..._RODATA) 放入自定义 rodata 段的字符串字面量仍被 cbprintf 识别为只读，从而防止延迟日志打包器将其指针置为 NULL 并附加副本，而这些副本下游 IPC 日志传输可能无法正确重建。

参数
addrAddress.
返回
如果地址位于任何只读段内则为真。
