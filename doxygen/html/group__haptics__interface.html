◆ haptics_error_type

enum haptics_error_type

#include <zephyr/drivers/haptics.h>

触觉错误类型

大多数触觉驱动都提供保护特性以防止运行中损坏。应用程序可注册回调函数（参见 ）来处理错误状态或从中恢复。以下错误类型用于构造在运行时提供给应用层的位掩码（参见 haptics_error_callback_t）。

注意
设备特定的错误码必须是独立位标志，并从 HAPTICS_ERROR_PRIV_START 继续，例如 BIT(5)、BIT(6) 等。
枚举值
HAPTICS_ERROR_OVERCURRENT 

输出过流错误

HAPTICS_ERROR_OVERTEMPERATURE 

设备过温错误

HAPTICS_ERROR_UNDERVOLTAGE 

电源欠压错误

HAPTICS_ERROR_OVERVOLTAGE 

电源过压错误

HAPTICS_ERROR_DC 

输出直流错误

◆ haptics_trigger()

const enum haptics_trigger_type type )

#include <zephyr/drivers/haptics.h>

触发触觉效果

执行产生指定触觉效果所需的动作。例如，若使用 haptics_set_trigger() 设置了上升沿效果，而调用此函数时 type 设为 HAPTICS_TRIGGER_RISING, then a device driver may drive the specified pin high. Refer to device drivers for implementation details.

注意
应用程序负责管理物理线电平。例如，当物理电平已为高时，以 type 设为 HAPTICS_TRIGGER_RISING 调用此函数可能不会产生任何效果。
参数

[in]type触发类型（类型为 haptics_trigger_type）
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENOSYS若未实现
