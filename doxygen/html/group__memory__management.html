◆ sys_mm_is_phys_addr_in_range()

bool sys_mm_is_phys_addr_in_range ( uintptr_t phys)

#include <zephyr/sys/mem_manage.h>

检查物理地址是否在物理内存范围内。

此函数检查物理地址（phys）是否在允许范围内，例如介于 :c:macro:DT_CHOSEN_SRAM_ADDR 和（:c:macro:DT_CHOSEN_SRAM_ADDR + :c:macro:DT_CHOSEN_SRAM_SIZE）之间。

注解
仅在启用 :kconfig:option:CONFIG_KERNEL_VM_USE_CUSTOM_MEM_RANGE_CHECK 时使用。
参数
phys要检查的物理地址。
返回
若物理地址在范围内则为真，否则为假。

bool sys_mm_is_virt_addr_in_range ( void * virt)

#include <zephyr/sys/mem_manage.h>

检查虚拟地址是否在虚拟内存范围内。

此函数检查虚拟地址（virt）是否在允许范围内，例如介于 :kconfig:option:CONFIG_KERNEL_VM_BASE 和（:kconfig:option:CONFIG_KERNEL_VM_BASE + :kconfig:option:CONFIG_KERNEL_VM_SIZE）之间。

注解
仅在启用 :kconfig:option:CONFIG_KERNEL_VM_USE_CUSTOM_MEM_RANGE_CHECK 时使用。
参数
virt要检查的虚拟地址。
返回
若虚拟地址在范围内则为真，否则为假。
