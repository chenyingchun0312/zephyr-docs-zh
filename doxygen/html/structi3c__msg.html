详细描述

One I3C Message.

定义一个要在 I3C 总线上处理（transact）的 I3C 消息。

注解
此 API 支持的某些配置可能不被特定的 SoC I3C 硬件实现支持，尤其是与在单个事务中读写不同缓冲区的总线事务相关的特性。遇到不支持的配置时，i3c_transfer() 的调用可能不会指示错误。在某些情况下，驱动会为每个消息片段生成单独的事务，无论 flags 中是否存在 #I3C_MSG_RESTART。
