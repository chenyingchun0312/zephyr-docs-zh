定义 wuc.h:49

wuc_dt_spec 的静态初始化器

给定设备树节点标识符、指定唤醒控制器的属性和索引，此宏返回 wuc_dt_spec 结构体的静态初始化器。

设备树片段示例： 

 n: node {
    wakeup-ctrls = <&wuc 10>;
 }

用法示例： 

 const struct wuc_dt_spec spec = WUC_DT_SPEC_GET_BY_IDX(DT_NODELABEL(n), 0); 会将 'spec' 初始化为：{ .dev = DEVICE_DT_GET(DT_NODELABEL(wuc)), .id = 10 }

仍必须检查 'dev' 字段是否就绪，例如使用 device_is_ready()。除非节点存在、具有给定属性，且该属性如上所示指定了唤醒控制器的唤醒源 ID，否则使用此宏是错误的。

参数
node_id设备树节点标识符
idx"wakeup-ctrls" 中的逻辑索引
返回
该属性对应的 struct wuc_dt_spec 的静态初始化器

类似 WUC_DT_SPEC_GET_BY_IDX()，但可回退到默认值

如果设备树节点标识符 'node_id' 指向的节点具有 'wakeup-ctrls' 属性，则此宏展开为 WUC_DT_SPEC_GET_BY_IDX(node_id, idx)。此时不会展开 default_value 参数。

否则，展开为 default_value。

参数

idx'wakeup-ctrls' 属性中的逻辑索引
default_value要展开为的回退值
返回
该属性对应的 struct wuc_dt_spec 的静态初始化器；如果节点或属性不存在，则为 default_value
