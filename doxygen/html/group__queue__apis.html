#include <zephyr/kernel.h>

原子地将元素列表追加到队列。

此例程在一次操作中将数据项列表添加到 queue。这些数据项必须位于单向链表中，每个数据项的第一个指针大小的字段指向下一个数据项；该链表必须以 NULL 结尾。

参数
queue队列的地址。
head指向单向链表中第一个节点的指针。
tail指向单向链表中最后一个节点的指针。
返回值
0成功时
-EINVAL所提供的数据无效时

◆ k_queue_cancel_wait()

void k_queue_cancel_wait ( struct k_queue * queue)
isr-ok

#include <zephyr/kernel.h>

取消对队列的等待。

此例程使第一个挂起在 queue 上的线程（如果有）以 NULL 值从 k_queue_get() 调用返回（如同超时到期）。如果该队列正被 k_poll() 等待，则其将以 -EINTR 和 K_POLL_STATE_CANCELLED 状态返回（并且如上所述，后续的 k_queue_get() 将返回 NULL）。

参数
queue队列的地址。

原子地将元素列表添加到队列。

此例程在一次操作中将数据项列表添加到 queue。这些数据项必须位于使用 sys_slist_t 对象实现的单向链表中。完成后，原链表为空。调用者负责确保 list 不被其他线程或 ISR 并发访问。

参数
queue队列的地址。

返回值
0成功时
-EINVAL数据无效时
