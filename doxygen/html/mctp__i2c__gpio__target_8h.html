为带 GPIO 的 I2C 目标定义 MCTP 总线绑定

与 MCTP 标准所期望的模式切换不同，这是一种自定义绑定。在目标侧，当有待处理的写入时，会将某个 gpio 引脚置为有效（可以是低电平有效或高电平有效）。预期控制器会在之后某个时刻读取该 I2C 目标设备。读取可在任意时刻被接受，并预期包含完整的 mctp 数据包。

实际上，每个设备都有一对伪寄存器，用于以数据包 FIFO 方式读取或写入。

因此，I2C 目标发送消息的步骤为……

  1. 设置长度值和消息值（伪寄存器）。
  2. 通过设置 GPIO 电平向控制器发出信号
  3. 随后控制器应读取长度（写地址 0 + 读 1 字节）
  4. 随后控制器应读取消息（写地址 1 + 读 N 字节）
  5. 目标清除引脚置位
  6. 控制器向 MCTP 报告收到消息
参数
_name总线绑定变量的符号名
_node_id包含此 MCTP 绑定配置的设备树节点
