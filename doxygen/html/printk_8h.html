◆ printk()

void printk ( const char * fmt,
... )

打印内核调试消息。

此例程将内核调试消息打印到系统控制台。输出会立即发送，不经任何互斥保护或缓冲。

支持一组基本的转换说明符字符：

  • 有符号十进制：%d、%i
  • 无符号十进制：%u
  • 无符号十六进制：%x（%X 按 %x 处理）
  • 指针：%p
  • 字符串：%s
  • 字符：%c
  • 百分号：%%

支持字段宽度（带前导零或不带）。支持长度属性 h、hh、l、ll 和 z。不过，使用 lld 和 lli 的整数值只有在能放入 long 时才会打印，否则打印 'ERR'。完整的 64 位值可用 llx 打印。不支持标志和精度属性。

◆ printk_panic()

void printk_panic ( void )

让 printk() 停止获取其锁，用于崩溃报告

此后 printk() 的行为就如同每个调用方都使用了 printk_unlocked()。一旦开始处理致命错误，锁便不再可信：出错的上下文可能已持锁死亡，或者某个再也不会运行的 CPU 可能持有它，此后任何 printk() 都会永远阻塞。各个调用点无法解决该问题，因为在故障之后执行到的代码并不知道自己处于崩溃之中。

由致命错误路径调用。单向生效，直至系统生命期结束。

◆ printk_unlocked()

void printk_unlocked ( const char * fmt,
... )

不获取 printk 锁地输出字符串

输出与 printk() 相同，但绝不获取自旋锁，并且同时绕过日志子系统和用户模式缓冲区：文本直接送往平台的字符输出钩子。

适用于无法获取锁的调用方：锁持有者已死亡的崩溃、从 printk() 自身内部重入的输出，或自旋锁所需原子操作尚不可用的早期启动阶段。输出可能与并发的 printk() 交织，但这总比挂起或丢失输出强。

注解
仅限内核上下文，且仅与输出钩子同样地无锁。

将内核调试消息打印到缓冲区。

格式化方式与 printk() 相同，但写入 str 而非控制台。若输出放不下则被截断；只要 size 不为零，输出就以 NUL 结尾。
