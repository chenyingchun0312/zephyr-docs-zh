◆ mspi_config()

int mspi_config ( const struct mspi_dt_spec * spec)

#include <zephyr/drivers/mspi.h>

配置 MSPI 控制器。

该例程提供通用接口，用于覆盖 MSPI 控制器的能力。

在控制器驱动中，可以实现该 API 来初始化或重新初始化其控制器硬件。可将 struct mspi_cfg 中未包含的其他 SoC 平台专用设置添加到自己的绑定（xxx,mspi-controller.yaml）中，以便从 DTS 推导这些设置并在该 API 中配置。一般而言，这些设置在运行期间不应改变。

参见
mspi_cfg 的绑定可在 mspi-controller.yaml 中找到。
参数
spec指向 MSPI DT 信息的指针。
返回值
0If successful.
-EIO通用输入/输出错误，配置设备失败。
-EINVAL能力无效，配置设备失败。
-ENOTSUPMSPI 外设不支持该能力。

#include <zephyr/drivers/mspi.h>

用设备专用参数配置 MSPI 控制器。

该例程提供通用接口，用于覆盖应从设备数据手册推导的 MSPI 控制器设备专用设置。

以设备树中的设备索引和 CE GPIO 定义的

参见
mspi_dev_id 为标识，该 API 支持在同一控制器实例上挂载多个设备。是否支持设备切换（通过软件、硬件或完全不支持）由控制器驱动实现决定。若通过软件实现，切换应在本 API 的实现中完成。实现也可以支持由
mspi_dev_cfg_mask 指定的单项参数配置。一旦设备初始化后确定了工作模式，
mspi_dev_cfg 中的设置通常不再改变。
mspi_dev_cfg 的绑定可在 mspi-device.yaml 中找到。
参数
controller指向该驱动实例设备结构的指针。
dev_id指向设备 ID 结构体的指针。
param_mask宏定义，说明要在 cfg 中配置什么。
cfgMSPI 控制器的设备运行时配置。
返回值
0If successful.
-EIO通用输入/输出错误，配置设备失败。
-EINVAL能力无效，配置设备失败。
-ENOTSUPMSPI 外设不支持该能力。
