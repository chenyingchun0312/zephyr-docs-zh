计时测量 API

自从
2.4
版本
1.0.0

计时测量 API 可用于获取某段代码的执行时间，以辅助分析和优化。

请注意，计时函数使用的定时器可能与默认的内核定时器不同，具体使用哪个定时器由架构、SoC 或开发板配置指定。

◆ timing_ns_get()

uint64_t timing_ns_get ( void )

#include <zephyr/timing/timing.h>

返回单调递增的纳秒时间戳。

与 timing_counter_get() 不同（其底层计数器可能窄于 64 位并会回绕），此函数返回一个 64 位纳秒值，在计数器回绕时仍单调递增。它面向需要绝对时间参考（例如跟踪事件时间戳）而不需要两次显式读数之间时长的使用方。

该值始终单调递增。只要至少在每个底层计数器回绕周期内调用一次该函数，它也是准确的；若调用间隔更远，该值仍然只是递增，但可能低估真实经过的时间。

返回
单调递增的纳秒时间戳。
