详细描述

用于 NXP FREQME 参考源 / 目标源路由的 INPUTMUX 连接 cookie。

这些数值与各器件 MCUX HAL 头文件 fsl_inputmux_connections.h 中的 inputmux_connection_t 枚举一致：

cookie = selector + (destination_register << PMUX_SHIFT)，即选择器值加上左移 PMUX_SHIFT 位的目标寄存器。

在所有支持 FREQME 的 SoC 上 PMUX_SHIFT 均为 20。目标寄存器与各源的选择器编号取决于 SoC 系列，因此下面按系列对 cookie 分组，并在每组中列出其适用的器件。设备树和驱动只需附加该 cookie，硬件会将其路由到所编码的寄存器。

◆ NXP_FREQME_SOURCE_UNCHANGED

#define NXP_FREQME_SOURCE_UNCHANGED   0U

set_source() 的哨兵值：保持该轴（参考源或目标源）不变。

真实的 INPUTMUX connection cookie 始终非零：其高位总带有目标寄存器字段（MCX 上为 0x180/0x184，RT7xx 上为 0x700/0x704），因此 0 可以表示 NXP FREQME clock_monitor_set_source() 后端的 "无更改"。公共 clock_monitor API 未定义通用的哨兵值；该常量是 FREQME 私有的。
