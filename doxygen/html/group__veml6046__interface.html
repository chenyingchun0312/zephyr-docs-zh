enum sensor_attribute_veml6046

#include <zephyr/drivers/sensor/veml6046.h>

VEML6046 专用传感器属性。

高低阈值窗口设置（G_THDH_L、G_THDH_H、G_THDL_L 和 G_THDL_H）请使用通用属性 SENSOR_ATTR_UPPER_THRESH 和 SENSOR_ATTR_LOWER_THRESH with 16-bit unsigned integer values. Both threshold settings are in lux and converted by the driver to a value compatible with the sensor. This conversion depends on the current gain, integration time and effective photodiode size settings. So a change in gain, integration time or effective photodiode size usually requires an update of threshold window settings. To get the correct threshold values into the sensor update the thresholds -after- a change of gain or integration time.

当传感器饱和时返回 -E2BIG。这发生在原始 ALS 值为最大值 0xFFFF 时。此时需要用户减小以下一个或多个属性，以回到传感器的最佳测量范围： SENSOR_ATTR_VEML6046_GAIN (gain) SENSOR_ATTR_VEML6046_IT (integration time) SENSOR_ATTR_VEML6046_PDD (effective photodiode size)

枚举值

enum sensor_channel_veml6046

#include <zephyr/drivers/sensor/veml6046.h>

VEML6046 专用传感器通道。

枚举值
SENSOR_CHAN_VEML6046_RED_RAW_COUNTS 

用于原始红色传感器值的通道。

该通道表示传感器寄存器提供的原始测量计数值。它可用于在 fetch 和 get 模式下估算积分时间、有效光电二极管尺寸与增益属性的合适取值。

对于将来带触发器的实现，它还可用于估算传感器中断处理的阈值窗口属性。

它不能被直接读取。该通道的值改为通过 SENSOR_CHAN_RED 隐式读取。以此枚举作为参数调用 sensor_channel_fetch_chan 将返回 -ENOTSUP。

SENSOR_CHAN_VEML6046_GREEN_RAW_COUNTS 

用于绿色传感器值的通道。

该通道是传感器输出的原始绿色通道计数值。读取方式同前述说明。 SENSOR_CHAN_VEML6046_RED_RAW_COUNTS applies.

SENSOR_CHAN_VEML6046_BLUE_RAW_COUNTS 

用于蓝色传感器值的通道。

该通道是传感器输出的原始蓝色通道计数值。读取方式同前述说明。 SENSOR_CHAN_VEML6046_RED_RAW_COUNTS applies.

SENSOR_CHAN_VEML6046_IR_RAW_COUNTS 

用于 IR 传感器值的通道。

该通道是传感器输出的原始 IR 通道计数值。读取方式同前述说明。 SENSOR_CHAN_VEML6046_RED_RAW_COUNTS applies.
