int log_backend_mqtt_client_set ( struct mqtt_client * client)

#include <zephyr/logging/log_backend_mqtt.h>

设置 MQTT 客户端实例，以便将应用程序的日志消息发布到代理。

此函数允许应用程序向日志后端提供自己已初始化的 MQTT 客户端。后端将专门使用此客户端通过 mqtt_publish() 发布日志消息。

参数
client指向已初始化并已连接的 MQTT 客户端的指针。该客户端在日志后端使用期间必须保持有效。传入 NULL 以禁用 MQTT 日志记录。
返回
成功时为 0，失败时为负的错误码。
注解
调用此函数之前，MQTT 客户端必须已连接。
后端不会管理客户端连接——这是应用程序的责任。
后端仅使用 mqtt_publish()，不会对客户端执行任何其他操作。

◆ log_backend_mqtt_topic_set()

int log_backend_mqtt_topic_set ( const char * topic)

#include <zephyr/logging/log_backend_mqtt.h>

设置日志消息要发布到的 MQTT 主题。

允许应用程序指定日志后端发布日志消息所用的 MQTT 主题。

参数
topic指向包含 MQTT 主题的以 null 结尾的字符串的指针。该主题在日志后端使用期间必须保持有效。
返回
成功时为 0，失败时为负的错误码。
注解
主题必须是有效的 UTF-8 字符串、以 null 结尾，且不应超过 MQTT 代理支持的最大长度。
