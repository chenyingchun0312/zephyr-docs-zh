平衡红黑树实现

这实现了一种侵入式平衡树，对所有操作保证 O(log2(N)) 的运行时间，并对整棵树的创建和销毁具有摊还 O(1) 行为。算法和命名沿用现有学术与教学实现中的惯例，参见：

https://en.wikipedia.org/wiki/Red%E2%80%93black_tree

该实现针对尺寸进行了优化，以优先考虑运行时内存占用。数据结构是侵入式的，也就是说 rbnode 句柄应放在单独的结构体中，与其他此类结构（例如 Zephyr 的 parent 指针，树的上层结构在递归时通过栈动态生成。因此节点的总体内存开销只有两个指针，与双向链表相同。

不递归地按序遍历树

虽然 rb_walk() 非常简单，但在某些用途上及某些架构上，在 C 栈上递归可能很笨拙，并会在栈帧中浪费大量内存。此宏实现了一个非递归的“foreach”循环，可直接在树上迭代，代价是适度增加代码尺寸。

注意所产生的循环对树的修改不安全。循环期间对树结构的更改会产生错误结果，因为节点可能被跳过或重复。与链表不同，不存在 _SAFE 变体。

另请注意该宏会多次展开其参数，因此它们不应该是带副作用的表达式。

参数
tree指向要遍历的 struct rbtree 的指针
node用作迭代器的局部 struct rbnode* 变量的符号名

红黑树比较谓词

比较两个节点，若按树的排序准则节点 A 严格小于 B 则返回 true，否则返回 false。

注意，在插入过程中，被插入的新节点始终是 "A"，而 "B" 是树中与之比较的现有节点。利用这一特性（需谨慎！）可以在原本比较相等的节点之间实现“最近/最久添加”语义。
