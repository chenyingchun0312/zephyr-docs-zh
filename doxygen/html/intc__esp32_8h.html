◆ esp_intr_alloc()

int esp_intr_alloc ( int source,
int flags,
intr_handler_t handler,
void * arg,
intr_handle_t * ret_handle )

按给定参数分配一个中断。

此函数查找一个满足 flags 参数中给定限制的中断，将给定的中断源映射到该中断，并挂接给定的中断处理程序（可带可选参数）。如有需要，还可返回该中断的句柄。

中断将始终在运行此函数的内核上分配。

若使用了 ESP_INTR_FLAG_IRAM 标志，而处理程序地址不在 IRAM 或 RTC_FAST_MEM 中，则返回 ESP_ERR_INVALID_ARG。

参数
source中断源。为 esp-xtensa-intmux.h 中定义的某个 INTR_SOURCE 中断复用源，或本头文件中定义的某个内部 ETS_INTERNAL_INTR_SOURCE 源。
flagsESP_INTR_FLAG_* 定义的按位或掩码。这些会限制此例程可从中选择的中断。若该值为 0，则默认分配级别 1、2 或 3 的非共享中断。若为 ESP_INTR_FLAG_SHARED，则分配级别 1 的共享中断。设置 ESP_INTR_FLAG_INTRDISABLED 将使本函数返回时中断处于禁用状态。
handler中断处理程序。请求级别 >3 的中断时必须为 NULL，因为这类中断不能从 C 调用。
arg传递给中断处理程序的可选参数
ret_handle指向 intr_handle_t 指针的指针，用于存储句柄，之后可用它查询详情或释放中断。若不需要句柄则可为 NULL。
返回
若参数组合无效则返回 -EINVAL。-ENODEV 表示未找到符合指定标志的空闲中断。否则返回 0。

◆ esp_intr_alloc_intrstatus()

int esp_intr_alloc_intrstatus ( int source,
int flags,
uint32_t intrstatusreg,
uint32_t intrstatusmask,
intr_handler_t handler,
void * arg,
intr_handle_t * ret_handle )

按给定参数分配一个中断。

这基本上与 esp_intr_alloc 相同，但允许指定寄存器和掩码的组合。对于共享中断，只有当从指定寄存器读取的值与掩码相与后非零时才会调用处理程序。通过传入中断状态寄存器地址和合适的掩码，可在触发共享中断时加速中断处理；先检查中断状态，代码即可判断哪些 ISR 可以跳过

参数
source中断源。为 esp-xtensa-intmux.h 中定义的某个 INTR_SOURCE 中断复用源，或本头文件中定义的某个内部 ETS_INTERNAL_INTR_SOURCE 源。
flagsESP_INTR_FLAG_* 定义的按位或掩码。这些会限制此例程可从中选择的中断。若该值为 0，则默认分配级别 1、2 或 3 的非共享中断。若为 ESP_INTR_FLAG_SHARED，则分配级别 1 的共享中断。设置 ESP_INTR_FLAG_INTRDISABLED 将使本函数返回时中断处于禁用状态。
intrstatusreg中断状态寄存器的地址
intrstatusmask掩码。若读取地址 intrstatusreg 得到的值中有任何与掩码中为 1 的位对应的位置位，则调用 ISR；否则跳过。
handler中断处理程序。请求级别 >3 的中断时必须为 NULL，因为这类中断不能从 C 调用。
arg传递给中断处理程序的可选参数
ret_handle指向 intr_handle_t 指针的指针，用于存储句柄，之后可用它查询详情或释放中断。若不需要句柄则可为 NULL。
返回
若参数组合无效则返回 -EINVAL。-ENODEV 表示未找到符合指定标志的空闲中断。否则返回 0。

◆ esp_intr_disable()

int esp_intr_disable ( intr_handle_t handle)

禁用与句柄关联的中断

注解
  1. 对于本地中断（ESP_INTERNAL_* 源），必须在分配该中断的 CPU 上调用此函数。其他中断没有此限制。
  2. 当多个处理程序共享同一中断源时，在禁用某个处理程序前应先屏蔽该处理程序负责的中断状态位，或在其他已启用的中断中正确处理。缺少中断状态处理将导致无限次中断调用，最终使系统崩溃。
参数
handle句柄，由 esp_intr_alloc 或 esp_intr_alloc_intrstatus 获得
返回
若参数组合无效则返回 -EINVAL，否则返回 0

◆ esp_intr_free()

int esp_intr_free ( intr_handle_t handle)

禁用并释放一个中断。

使用中断句柄禁用中断并释放与之关联的资源。若当前内核不是注册该中断的内核，此例程将被分配到分配该中断的内核上执行，并阻塞等待资源成功释放。

注解
当处理程序与其他处理程序共享中断源时，在释放它之前应正确管理其负责的中断状态位。详见 esp_intr_disable。请勿在 esp_ipc_call_blocking 中调用此函数。
参数
handle句柄，由 esp_intr_alloc 或 esp_intr_alloc_intrstatus 获得
返回
若句柄为 NULL 则返回 -EINVAL，否则返回 0
