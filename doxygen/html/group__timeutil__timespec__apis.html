规范化 timespec，使 tv_nsec 字段位于有效范围内。

通过调整 tv_sec 和 tv_nsec 字段使 tv_nsec 字段位于 [0, NSEC_PER_SEC-1] 范围内，从而规范化 timespec。这通过将纳秒换算为秒并累加秒来实现：当 tv_nsec > NSEC_PER_SEC 时向正方向累加，当 tv_nsec < 0 时向负方向累加。

用伪代码表示，规范化可如下进行：python if ts.tv_nsec >= NSEC_PER_SEC: sec = ts.tv_nsec / NSEC_PER_SEC ts.tv_sec += sec ts.tv_nsec -= sec * NSEC_PER_SEC elif ts.tv_nsec < 0: @section autotoc_md4 div_round_up(abs(ts->tv_nsec), NSEC_PER_SEC) sec = (NSEC_PER_SEC - ts.tv_nsec - 1) / NSEC_PER_SEC ts.tv_sec -= sec; ts.tv_nsec += sec * NSEC_PER_SEC;

注解
有两种情况规范化可能导致整数溢出。可以将它们外推为不只是使 tv_sec 字段溢出一个秒，而是溢出任何可实现的 NSEC_PER_SEC 倍数。
  1. 当 tv_nsec 为负且 tv_sec 已是最负值时。
  2. 当 tv_nsec 大于或等于 NSEC_PER_SEC 且 tv_sec 已是最正值时。

若该操作将导致整数溢出，则返回值为 false。
