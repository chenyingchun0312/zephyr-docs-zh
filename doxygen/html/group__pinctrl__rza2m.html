详细描述

用于配置 Renesas RZ/A2M SoC 引脚控制的宏

每个引脚配置由 RZA2M_PINMUX() 宏构建，该宏接受端口、该端口内的引脚号以及备用功能编号。端口按硬件手册中的方式命名：PORT_00 ... PORT_09， PORT_A ... PORT_M, plus PORT_CKIO and PORT_PPOC.

RZ/A2M 使用比其他 RZ/A SoC 更旧的引脚复用方案：备用功能索引编码在高位中，取自 SoC 的引脚功能表（没有对应的符号宏）。

#include <zephyr/dt-bindings/pinctrl/renesas/pinctrl-rza2m.h>
&pinctrl {
scifa4_default: scifa4_default {
device-pinmux {
pinmux = <RZA2M_PINMUX(PORT_09, 0, 4)>,
<RZA2M_PINMUX(PORT_09, 1, 4)>;
};
};
};
