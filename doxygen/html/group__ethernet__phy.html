◆ phy_link_callback_set()

int phy_link_callback_set ( const struct device * dev,
phy_callback_t callback,
void * user_data )
inlinestatic

#include <zephyr/net/phy.h>

设置链路状态变化回调

设置一个在链路状态变化时调用的回调。这是以太网驱动获知 PHY 链路状态变化的首选方法。设置后回调会被调用一次，即使链路状态尚未变化。同一时间只能设置并激活一个回调函数。此函数主要供以太网驱动注册回调以获知链路状态变化，因此不应由应用程序使用。

参数
[in]devPHY 设备结构体
callback回调处理程序
user_data指向用户指定的数据的指针。
返回值
0If successful.
-ENOTSUP不受支持时。
