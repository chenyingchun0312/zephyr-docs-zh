注解
这些回调在线程上下文中调用，绝不会在 ISR 中调用。回调是由协议栈内部上下文调用，还是由触发它的 API 调用同步调用，以及来自哪个上下文，不属于 API 的一部分，且可能随版本变化。参见 Callback execution contexts for the hazards of blocking in a callback and their mitigations.

◆ addr_res_support_read

void(*) bt_conn_auth_info_cb::addr_res_support_read(struct bt_conn *conn, enum bt_le_addr_res_support support)

已读取对端对地址解析的支持情况。

此回调通知应用程序：在启用 CONFIG_BT_GATT_AUTO_READ_CENTRAL_ADDR_RES 后对已绑定对端的中央地址解析特性的自动读取已完成。该结果也可通过 bt_le_bond_addr_res_support() 获取；读取失败时仍为未知。

参数
conn读取该特性所在的连接。
support对端对地址解析的支持情况。
