#include <zephyr/bluetooth/mesh/main.h>

复位本地 Mesh 节点的状态。

复位节点状态，这意味着需要重新配网才能再次成为 Mesh 网络中的活动节点。

调用此 API 后，节点不会自动以未配网状态广播，而是需要调用 bt_mesh_prov_enable() API 在一个或多个配网承载上启用未配网广播。

void bt_mesh_rpl_pending_store ( uint16_t addr)

#include <zephyr/bluetooth/mesh/main.h>

将挂起的 RPL 条目存储到持久化存储中。

此 API 允许用户在不等待超时的情况下将挂起的 RPL 条目存储到持久化存储中。

注解
当使用 Flash 作为持久化存储时，过于频繁地调用此 API 可能使其磨损。
参数
addr需存储 RPL 条目的节点地址，或 BT_MESH_ADDR_ALL_NODES to store all pending RPL entries.

◆ bt_mesh_suspend()

int bt_mesh_suspend ( void )

#include <zephyr/bluetooth/mesh/main.h>

暂时挂起 Mesh 网络。

此 API 可用于省电，但用户应注意，使本地节点长时间处于挂起状态可能导致其永久断开与 Mesh 网络的连接。如果可能，应改用 Friendship 功能，将节点变为低功耗节点。

注解
配网过程未设计为可挂起。如果在配网进行期间调用此 API，则无法挂起，函数将返回错误。
返回值
0Success.
-EBUSY配网处于活动状态。
Other失败时为负的 errno 错误码。

◆ bt_mesh_va_uuid_get()

const uint8_t * bt_mesh_va_uuid_get ( uint16_t addr,
const uint8_t * uuid,
uint16_t * retaddr )

#include <zephyr/bluetooth/mesh/main.h>

遍历已存储的标签 UUID。

当 addr 为 BT_MESH_ADDR_UNASSIGNED 时，此函数从 uuid 开始遍历所有可用地址。此时请使用 retaddr 获取所返回标签 UUID 的虚拟地址表示。当 addr 为虚拟地址时，此函数返回与该 addr 对应的下一个标签 UUID。当 uuid 为 NULL 时，此函数返回第一个可用的 UUID。如果 uuid 是先前返回的 uuid，此函数返回其后的 uuid。

参数
addr要搜索的虚拟地址，或 BT_MESH_ADDR_UNASSIGNED。
uuid指向先前返回的标签 UUID 的指针，或 NULL。
retaddr指向用于存放所返回 UUID 虚拟地址表示的内存指针。
返回
指向标签 UUID 的指针，如果没有更多条目则为 NULL。
