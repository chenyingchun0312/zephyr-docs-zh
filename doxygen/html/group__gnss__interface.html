◆ gnss_start()

int gnss_start ( const struct device * dev,
enum gnss_start_mode mode )

#include <zephyr/drivers/gnss.h>

启动 GNSS 接收机引擎。

启动（或恢复）GNSS 接收机引擎。mode 控制重启时保留哪些导航数据，在首次定位时间与最初几次定位的精度之间权衡。

参数
dev设备实例
mode启动模式：GNSS_HOT_START、GNSS_WARM_START 或 GNSS_COLD_START
返回值
0成功
-ENOSYS驱动不支持此函数
-ENODEV设备尚未启动（电源管理未恢复）
-EINVAL模式无效
-errno其他驱动特定错误
