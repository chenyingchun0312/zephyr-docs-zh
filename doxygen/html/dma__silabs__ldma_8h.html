int silabs_ldma_append_block ( const struct device * dev,
uint32_t channel,
struct dma_config * config )

向当前通道追加新块

该函数允许向当前 DMA 传输追加一个块。它允许用户或驱动在传输进行期间注册下一次 DMA 传输，而无需停止或重启 DMA 引擎。它非常适合 Zephyr UART API，因为用户在该 API 中会在 DMA 引擎运行期间提供缓冲区。由于该函数动态更改 DMA 引擎将作为下一次传输加载的块的链接，因此它只适用于没有链接块列表的通道。

若 DMA 引擎因前一次传输完成而自然停止，该函数会用给定的块直接重启 DMA 引擎。若 DMA 引擎在重新配置下一次传输时停止，DMA 引擎也会重启。
