◆ bt_att_err_to_str()

const char * bt_att_err_to_str ( uint8_t att_err)
inlinestatic

#include <zephyr/bluetooth/att.h>

将 ATT 错误转换为字符串。

错误码在 Bluetooth 核心规范第 3 卷第 F 部分第 3.4.1.1 节以及《Bluetooth 核心规范补充文件》（CSS）v11 第 B 部分第 1.2 节中描述。

第 4 卷第 F 部分和第 G 部分中的 ATT 和 GATT 文档说明了各错误码的使用场合。

另请参见已定义的 BT_ATT_ERR_* 宏。

返回
ATT 错误码的字符串表示。若未启用 CONFIG_BT_ATT_ERR_TO_STR，则仅返回空字符串。

◆ bt_att_get_max_indicate_size()

int bt_att_get_max_indicate_size ( struct bt_conn * conn,
enum bt_att_chan_opt chan_opt )
inlinestatic

#include <zephyr/bluetooth/att.h>

获取连接的最大指示值大小

ATT_HANDLE_VALUE_IND PDU 的值受限于 ATT_MTU - 3，其中 3 个字节为操作码和属性句柄，如 Bluetooth 核心规范 6.1 版第 3 卷第 F 部分第 3.4.7.2 节所定义。该限制与通知相同。

大于该值的取值需由发送方截断，或由客户端通过读取请求读取。

注解
ATT_MTU 可能在连接存活期间发生变化，因此不应缓存本函数的返回值。
参数
conn要获取其最大指示值大小的 LE ACL 连接。
chan_opt要获取其最大指示值大小的承载。应为 BT_ATT_CHAN_OPT_NONE、 BT_ATT_CHAN_OPT_UNENHANCED_ONLY 或 BT_ATT_CHAN_OPT_ENHANCED_ONLY（仅在启用 CONFIG_BT_EATT 时） BT_ATT_CHAN_OPT_NONE will get the value for any bearer.
返回
成功时为最大指示值大小（字节）。
返回值
-EINVALconn 为 NULL、不是 ACL 连接，或 chan_opt 无效。
-ENOTCONNconn 未连接。

◆ bt_eatt_connect()

int bt_eatt_connect ( struct bt_conn * conn,
size_t num_channels )

#include <zephyr/bluetooth/att.h>

连接增强 ATT 通道

发送一系列基于信用的连接请求，以连接 num_channels 个增强 ATT 通道。对端资源可能有限，因此创建的通道数可能更少。

注意
Available only when the following Kconfig option is enabled: CONFIG_BT_EATT.
参数
conn要在其上发送请求的连接
num_channels要请求的增强 ATT 承载数量。必须在 1 到 CONFIG_BT_EATT_MAX 的闭区间内。
返回
成功时为 0，出错时为负值。
返回值
-EINVAL当 num_channels 不在允许范围内或 conn 为 NULL 时。
-ENOMEM若分配的通道少于 num_channels 个。
0成功时
