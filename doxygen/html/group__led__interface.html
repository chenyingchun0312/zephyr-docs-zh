设置 LED 亮度

该可选例程将 LED 的亮度设为给定值。在 led_blink() 之后调用此函数不会影响闪烁。

只能点亮或熄灭的 LED 无需提供此函数。这类 LED 应在 value 非零时自动通过开关 API 点亮，在 value 为零时自动熄灭。

参数
devLED 设备
ledLED 编号
value要设置的亮度百分比值
返回
成功时为 0，出错时为负值

写入/更新一段 LED 通道

该可选例程将一段 LED 通道写入给定的电平数组，因此可用于同时配置多个 LED。

在 led_blink() 之后调用此函数不会影响闪烁。

参数
devLED 设备
start_channel要更新的第一个通道的绝对编号（即不相对于某个 LED）。
num_channels要写入/更新的通道数量。
buf用于配置这些通道的值数组。必须提供 num_channels 个条目。
返回
成功时为 0，出错时为负值
