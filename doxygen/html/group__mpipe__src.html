详细描述

产生缓冲区并驱动协商的元素。

source 有一个 source pad 而没有 sink pad：它是数据进入图的地方，数据可以来自设备、文件，或者什么也不来自。它拥有其推送的缓冲区所在的缓冲区池。

source 还承担其他基类没有的第二项职责。因为它位于图的头部，所以在 READY 到 PAUSED 的转换中由 source **驱动协商**。它会逐个向下游提供自己支持的能力，保留整条链接受的第一个，将其归约为单一格式并作为事件通告；随后执行缓冲区池查询，配置并启动自己的池。派生的 source 提供各个部分——它支持什么、选定格式后做什么、它需要什么缓冲区——由基类执行遍历。

num_buffers 属性限定 source 在声明流结束之前产生多少个缓冲区；0 表示一直运行直到被停止。
