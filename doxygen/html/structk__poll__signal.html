轮询信号对象

轮询信号是一个内核对象，可以通过 k_poll_signal_raise() 从线程或 ISR 中触发，并通过 k_poll() 使用 K_POLL_TYPE_SIGNAL.

unsigned int k_poll_signal::signaled

如果事件已被发送信号则为 1，否则为 0。在用户将其重置为 0 之前一直保持为 1。
