可选的统计名称

这些宏定义在……时使用的可选条目名称映射 CONFIG_STATS_NAMES is enabled.

详细描述

跟踪并报告子系统事件计数器。

统计信息是用于故障排查、维护和使用情况监控的按模块事件计数器。统计信息组织为命名的“组”，每组由一组“条目”构成。一个条目对应一个单独的计数器。每个条目在……时可选择性地命名。 CONFIG_STATS_NAMES setting is enabled. Statistics can be retrieved with the 统计管理 subsystem.

统计信息适用于统计运行时事件，例如传输尝试、已处理字节数、可恢复错误、阈值命中，或其他有助于诊断行为而无需添加自定义管理命令的值。

这里有两大段基本重复的统计信息部分，用以提供可选的统计命名能力。

STATS_SECT_START and STATS_SECT_END actually declare the statistics structure definition, STATS_SECT_DECL creates the structure declaration so you can declare these statistics as a global structure, and STATS_NAME_START and STATS_NAME_END are how you name the statistics themselves.

统计条目可以声明为若干整数类型中的任意一种。但给定结构中的所有统计信息必须大小相同，且全部为无符号类型。

  • STATS_SECT_ENTRY()：默认统计条目，32 位。
  • STATS_SECT_ENTRY16()：16 位。若需要符合特定的 RAM 或代码大小数值，可使用更小的统计信息。
  • STATS_SECT_ENTRY32(): 32-bits.
  • STATS_SECT_ENTRY64()：64 位。适合存储成块的数据。

静态条目声明之后是统计名称声明。当 CONFIG_STATS_NAMES 设置未定义时，这部分不会编译进去。

当定义了 CONFIG_STATS_NAMES 时，统计名称会被存储并返回给管理 API。当该设置未定义时，会按需按以下格式生成临时名称： 

s<stat-idx>（统计条目下标）

E.g., "s0", "s1", etc.

示例：

STATS_SECT_START(my_driver_stats)
STATS_SECT_ENTRY(rx_packets)
STATS_SECT_ENTRY(rx_bytes)
STATS_SECT_ENTRY(errors)
STATS_SECT_END;
STATS_NAME_START(my_driver_stats)
STATS_NAME(my_driver_stats, rx_packets)
STATS_NAME(my_driver_stats, rx_bytes)
STATS_NAME(my_driver_stats, errors)
STATS_NAME_END(my_driver_stats);
static STATS_SECT_DECL(my_driver_stats) stats;
static int my_driver_init(void)
{
int rc;
rc = STATS_INIT_AND_REG(stats, STATS_SIZE_32, "my_driver");
if (rc != 0) {
return rc;
}
return 0;
}
static void my_driver_rx_complete(size_t len)
{
STATS_INC(stats, rx_packets);
STATS_INCN(stats, rx_bytes, len);
}
static void my_driver_error(void)
{
STATS_INC(stats, errors);
}
