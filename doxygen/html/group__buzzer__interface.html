面向简单蜂鸣器及类似单音声源的音频输出抽象。

蜂鸣器 API 调用不会等待所请求的音调持续时长：时长描述硬件应持续发出音调多久，而不是调用线程应休眠多久。

◆ buzzer_beep()

int buzzer_beep ( const struct device * dev,
uint32_t duration_ms )
inlinestatic

#include <zephyr/drivers/buzzer.h>

播放蜂鸣器的默认音调，持续 duration_ms。

该调用在硬件配置完成后返回；它不会等待 duration_ms 过去。对于 PWM 驱动的无源压电蜂鸣器，默认音调由设备 pwms 设备树属性的 period 单元推导得出。对于 GPIO 驱动的有源蜂鸣器，实际音高由硬件振荡器决定。

参数
dev蜂鸣器设备。
duration_ms蜂鸣器应持续发出该音调的时长。使用 BUZZER_DURATION_FOREVER 可一直播放，直到显式调用 buzzer_stop() 或另一个发声调用。
返回值
0音调已成功调度。
-errno失败时为负的 errno 错误码。

◆ buzzer_set_volume()

int buzzer_set_volume ( const struct device * dev,
uint8_t percent )
inlinestatic

#include <zephyr/drivers/buzzer.h>

设置蜂鸣器音量。

音量以 0 到最大值之间的百分比表示 BUZZER_VOLUME_MAX, where 0 is silent and BUZZER_VOLUME_MAX is the loudest level the hardware can produce. The volume control affects subsequent tones until changed. Setting the volume to 0 also silences the buzzer immediately.

没有可编程音量控制的后端会将任何非零值映射到其唯一的可听级别，并将零映射到静音。

参数
dev蜂鸣器设备。
percent期望的音量，范围为 0 到 BUZZER_VOLUME_MAX（含）。
返回值
0音量已成功更新。
-EINVALpercent 超出范围。
-errno失败时为负的 errno 错误码。

◆ buzzer_tone()

int buzzer_tone ( const struct device * dev,
uint32_t freq_hz,
uint32_t duration_ms )
inlinestatic

#include <zephyr/drivers/buzzer.h>

在 freq_hz 频率下播放单个音调，持续 duration_ms。

该调用在硬件配置完成后返回；它不会等待 duration_ms 过去。蜂鸣器会持续发出该音调 duration_ms，之后驱动自动将其静音。若上一个音调仍在播放时再次调用 buzzer_tone()，会抢占它。

传入 BUZZER_FREQ_REST 会立即让蜂鸣器静音。

无法精确实现所请求频率的后端会播放其最接近的支持音调，或者，若请求为静音，则停止。

参数
dev蜂鸣器设备。
freq_hz音调频率，单位 Hz。
duration_ms蜂鸣器应持续发出该音调的时长。使用 BUZZER_DURATION_FOREVER 可一直播放，直到显式调用 buzzer_stop() 或另一个发声调用。
返回值
0音调已成功调度。
-errno失败时为负的 errno 错误码。
