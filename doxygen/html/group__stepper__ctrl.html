◆ stepper_ctrl_set_microstep_interval()

int stepper_ctrl_set_microstep_interval ( const struct device * dev,
const uint64_t microstep_interval_ns )

#include <zephyr/drivers/stepper/stepper_ctrl.h>

以纳秒为单位设置步与步之间的时间间隔，立即生效。

注解
设置步进间隔不会使步进电机运动，需要结合 set_microstep_interval 与 move 才能使步进电机运动。
参数
dev指向该驱动实例设备结构的指针。
microstep_interval_ns步与步之间的时间间隔，单位为纳秒
返回值
-EIO一般输入/输出错误
-EINVAL所请求的步进间隔不受支持
-ENOSYS设备驱动未实现时
0成功
