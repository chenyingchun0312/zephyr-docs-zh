◆ dma_callback_t

typedef void(*) dma_callback_t(const struct device *dev, void *user_data, uint32_t channel, int status)

#include <zephyr/drivers/dma.h>

DMA 传输完成回调函数

启用后，回调函数将在传输或块完成时、或发生错误时被调用。在循环模式下，status 表示 DMA 设备已到达缓冲区末尾（DMA_STATUS_COMPLETE）或某个水位标记（DMA_STATUS_BLOCK）。

参数
dev指向调用回调的 DMA 设备的指针。
user_data指向某些用户数据的指针，或 NULL
channel通道号
status传输状态
  • DMA_STATUS_COMPLETE 缓冲区已完全消费
  • DMA_STATUS_BLOCK 缓冲区消费达到配置的块或水位标记
  • 否则为负的 errno
