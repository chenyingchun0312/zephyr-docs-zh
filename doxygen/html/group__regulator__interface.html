◆ regulator_parent_dvs_state_set()

int regulator_parent_dvs_state_set ( const struct device * dev,
regulator_dvs_state_t state )
inlinestatic

#include <zephyr/drivers/regulator.h>

Set a DVS state.

某些 PMIC 具备 DVS（动态电压调节）功能，可为多个状态编程电压档位。这些状态可由硬件通过 GPIO 引脚自动切换。某些 MCU 甚至允许在进入低功耗模式时自动配置特定输出引脚，从而无需软件干预即可改变 PMIC 状态。当需要由软件更改状态时，可以使用该 API。

参数
dev父稳压器设备实例。
stateDVS 状态（厂商专用标识符）。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENOTSUP不支持给定状态。
-EPERM状态无法由软件更改。
-ENOSYS该函数未实现。

◆ regulator_parent_ship_mode()

int regulator_parent_ship_mode ( const struct device * dev)
inlinestatic

#include <zephyr/drivers/regulator.h>

进入 ship 模式。

某些 PMIC 具备 ship 模式，可让系统省电。通常通过引脚电平变化退出低功耗。

当需要进入 ship 模式时，可以使用该 API。

参数
dev父稳压器设备实例。
返回
成功时为 0，失败时为负的 errno 值。
