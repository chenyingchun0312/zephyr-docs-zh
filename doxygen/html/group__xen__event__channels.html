typedef void(*) evtchn_cb_t(void *priv)

#include <zephyr/xen/events.h>

事件通道回调签名。

该回调从 Xen 事件中断处理程序中运行。

◆ evtchn_status()

int evtchn_status ( evtchn_status_t * status)

#include <zephyr/xen/events.h>

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_EVENTS.

返回
成功时为 0，失败时为负的 errno 值。

◆ unbind_event_channel()

int unbind_event_channel ( evtchn_port_t port)

#include <zephyr/xen/events.h>

移除绑定到事件通道的回调。

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_EVENTS.

通道仍保持分配状态，但后续通知会作为未处理事件被记录，直到注册另一个回调。

参数
port本地事件通道端口号。
返回值
0成功时。

◆ xen_events_init()

int xen_events_init ( void )

#include <zephyr/xen/events.h>

为当前客户机初始化 Xen 事件处理。

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_EVENTS.

该函数准备每个端口的回调表，并将 Zephyr ISR 连接到设备树所描述的 Xen 事件中断。

成功时为 0，失败时为负的 errno 值。
