宏定义

#define STM32_RESET(bus, bit)
 为 st,stm32-rcc-rctl 绑定编码外设复位单元值。

详细描述

用于编码 STM32 外设复位单元的宏。

用于编码 STM32 设备上外设复位单元的设备树宏，用于 st,stm32-rcc-rctl 兼容的复位控制器。

每个 SoC 系列头文件（例如 stm32h5_reset.h）以 STM32_RESET_BUS_<bus> 常量的形式定义该系列的 RCC 总线复位寄存器偏移。然后用 STM32_RESET() 将总线常量与该外设复位线在对应总线复位寄存器中的位位置组合，来编码外设复位单元。

注解
STM32MP1 和 STM32MP13 用分开的 SET/CLEAR 偏移重新定义了 STM32_RESET()。STM32MP2 使用每外设独立的寄存器。
#include <zephyr/dt-bindings/reset/stm32h5_reset.h>
&usart1 {
resets = <&rctl STM32_RESET(APB2, 14)>;
};

值:
(((STM32_RESET_BUS_##bus) << 5U) | (bit))

为 st,stm32-rcc-rctl 绑定编码外设复位单元值。

将 RCC 总线寄存器偏移与位位置打包为一个 32 位复位单元值。

位 [4:0] 保存复位位在 32 位 RCC 总线寄存器中的位置；位 [16:5] 保存相对于 RCC 基址的 RCC 寄存器字节偏移。

参数
busRCC 总线名称。
bit外设复位线在总线复位寄存器中的位位置
