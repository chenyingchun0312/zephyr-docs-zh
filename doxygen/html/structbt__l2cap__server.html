◆ accept

int(*) bt_l2cap_server::accept(struct bt_conn *conn, struct bt_l2cap_server *server, struct bt_l2cap_chan **chan)

服务器接受回调

当新的传入连接需要授权时调用此回调。若接受该连接，回调应为零初始化的信道对象分配内存，并更新信道引用 chan 使其指向该对象的公共成员：对于使用 bt_l2cap_server_register() 注册的服务器，该对象必须是以下类型 bt_l2cap_le_chan and chan set to its bt_l2cap_le_chan::chan member, and for a server registered with bt_l2cap_br_server_register() the object must be of type bt_l2cap_br_chan and chan set to its bt_l2cap_br_chan::chan member.

警告
尽管通过 chan 传回的引用是一个 bt_l2cap_chan, it must be a member of a bt_l2cap_le_chan or bt_l2cap_br_chan object as described above. The stack uses the containing object, so returning a bare bt_l2cap_chan would result in out-of-bounds access. It is the responsibility of this callback to zero out the containing object.
参数
conn请求授权的连接
server指向此回调所关联的服务器结构的指针
chan用于接收所分配信道的指针
返回
成功时为 0，出错时为负值。
若没有可用于新信道的空间，则为 -ENOMEM。
若应用程序未授权该连接，则为 -EACCES。
若加密密钥长度过短，则为 -EPERM。

◆ psm

uint16_t bt_l2cap_server::psm

服务器 PSM。

对于 LE，可能的取值：0 表示在调用 bt_l2cap_server_register() 时自动分配动态值。

0x0001-0x007f 为标准值，即 Bluetooth SIG 分配的固定值。

0x0080-0x00ff 为动态分配。可由应用程序在注册服务器之前预先设置（但不推荐），或在应用程序给出 0 时由协议栈自动分配。

对于 BR，可能的取值：

PSM 字段长度至少为两个字节。所有 PSM 值中，最高有效字节的最低有效位应等于 0，其他所有字节的最低有效位应等于 1。

0 表示在调用 bt_l2cap_br_server_register() 时自动分配动态值。

0x0001-0x0eff 为标准值，即 Bluetooth SIG 分配的固定值。

0x1000 为动态分配。可由应用程序在注册服务器之前预先设置（但不推荐），或在应用程序给出 0 时由协议栈自动分配。
