ESP32 引脚配置位域布局 @{

ESP32 引脚配置位域。

该字段编码 ESP32 引脚控制驱动所使用的引脚配置选项。

字段：

  • 偏置 [ 0 : 1 ]
  • 驱动强度 [ 2 : 3 ]
  • 输出电平 [ 4 : 5 ]
  • 输入/输出使能覆盖 [ 6 : 7 ]
  • 休眠保持 [ 8 ]

这些值合并为单个整数，随后由驱动转换为 GPIO 配置标志。

以太网 RMII 引脚编码。

RMII 焊盘使用专用的 EMAC IOMUX 功能而非 GPIO 矩阵，因此不能使用 ESP32_PINMUX() 编码。RMII 单元仅承载信号槽与 GPIO 编号；以太网驱动负责解析并应用 IOMUX 功能。ESP32_RMII_MARKER 位用于将这些单元与 ESP32_PINMUX() 单元区分开。 RMII 信号槽字段的移位
