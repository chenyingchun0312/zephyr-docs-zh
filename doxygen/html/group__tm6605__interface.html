详细描述

用于 LRA 的 TM6605 触觉驱动

Titan Micro Electronics 的 TM6605 是一款 I2C 控制的 LRA 触觉驱动。它提供 44 个可通过 ID 选择的预编程效果，通过写入两个寄存器（效果选择和播放控制）进行控制。I2C 接口为只写。

选择并启动此“效果”会使 TM6605 进入休眠模式。SCL 上的下降沿（即下一次 I2C 事务）会唤醒器件，但唤醒后的第一条命令可能被芯片丢弃。

◆ tm6605_select_effect()

int tm6605_select_effect ( const struct device * dev,
enum tm6605_effect effect )

#include <zephyr/drivers/haptics/tm6605.h>

选择下一次 start_output 调用要播放的触觉效果。

TM6605 效果选择寄存器被加载，但不启动播放。之后调用 haptics_start_output() 以触发该效果。

参数
devTM6605 设备实例。
effect效果 ID（参见 tm6605_effect）。
返回值
0成功时。
-EINVAL若 effect 不是有效效果 ID。
-errno失败时来自底层 I2C 控制器。
