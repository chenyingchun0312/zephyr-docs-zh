◆ phy_supported_channel_pages

uint32_t ieee802154_attr_value::[union].__unnamed0__ phy_supported_channel_pages

表示支持的信道页的位字段，参见 ieee802154_phy_channel_page。

注解
为按标准要求保持 API 可扩展，支持的信道页被建模为位图，以支持在多个信道页之间进行运行时切换的驱动。
目前 Zephyr 驱动中没有任何一个在运行时实现多个信道页，因此只会设置一个位，当前信道页（参见 PHY PIB 属性 phyCurrentPage，第 11.3 节、表 11-2）被视为只读、固定，并可通过受支持信道页属性 "已知"。

◆ phy_supported_channels

const struct ieee802154_phy_supported_channels* ieee802154_attr_value::[union].__unnamed0__ phy_supported_channels

指向表示所选信道页上当前可用信道范围的结构体的指针。

警告
该指针在接口整个生命周期内必须有效且保持不变。

所选信道页对应于 phyCurrentPage PHY PIB 属性，参见上文 phy_supported_channel_pages 的说明。目前可通过 IEEE802154_ATTR_PHY_SUPPORTED_CHANNEL_PAGES 属性获取它。

大多数驱动只提供一个信道页，其中包含单个固定的信道范围（通常从零开始）。

一些值得注意的例外：

  • 传统信道页（零）在不同频段甚至不同 PHY 中提供范围，而这些通常不是由单个驱动实现的。
  • SUN 和 LECIM PHY 在单个页上规定大量频段和工作模式，且每个频段都有相互重叠的信道范围。其中有些范围不从零开始，或包含 "空洞"。这就解释了为什么可能需要多个范围来表示所有可用信道。
  • UWB PHY 常在同一信道页上根据所支持的频段支持部分信道范围。

在这些情况下，驱动可提供自定义配置属性（Kconfig、设备树、运行时等），以允许在同一信道页内的子范围之间切换（例如在信道页零的 SubG 和 2.4G 频段之间切换，或在 SUN 或 LECIM PHY 中的多个工作模式之间切换。
