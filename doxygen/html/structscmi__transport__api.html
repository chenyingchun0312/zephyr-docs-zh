◆ channel_is_free

bool(*) scmi_transport_api::channel_is_free(const struct device *transport, struct scmi_channel *chan)

检查 TX 通道是否空闲

用于检查 TX 通道是否允许向平台发送数据。如果先前已向平台发送过消息，则认为此函数会指示该消息回复是否可用。

参数
transportDevice（设备）
chan要查询的 TX 通道
返回
成功时为 0，失败时为负的 errno 值。

◆ request_channel

struct scmi_channel *(*) scmi_transport_api::request_channel(const struct device *transport, uint32_t proto, bool tx)

动态请求通道

如果使能了 CONFIG_ARM_SCMI_TRANSPORT_HAS_STATIC_CHANNELS，则使用此操作动态请求通道并将其绑定到给定协议。否则可以不实现此操作。

注解
此操作是可选的
参数
transport传输设备
proto请求通道所属协议的 ID
tx如果通道为 TX 则为 true，如果通道为 RX 则为 false
返回值
pointer成功时返回绑定到给定协议的通道
NULL如果失败

◆ send_message

int(*) scmi_transport_api::send_message(const struct device *transport, struct scmi_channel *chan, struct scmi_message *msg, bool use_polling)

向平台发送消息

用于通过给定 TX 通道向平台发送消息。

注解
传输驱动不得以任何方式覆盖 use_polling 参数的值，并且必须遵循该参数。
参数
transport传输设备
chan用于发送消息的通道
msg要发送的消息
use_polling如果应使能轮询则为 true，否则为 false
返回
成功时为 0，失败时为负的 errno 值。
