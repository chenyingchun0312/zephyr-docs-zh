◆ timeutil_sync_estimate_skew()

float timeutil_sync_estimate_skew ( const struct timeutil_sync_state * tsp)

#include <zephyr/sys/timeutil.h>

基于当前状态估计偏移。

使用状态中的基准和最新同步点，确定本地时钟相对于参考时钟的偏移。参见 timeutil_sync_state::skew。

参数
tsp指向时间同步状态的指针。基准和最新同步点必须存在，且最新同步点在本地时间刻度中必须晚于基准点。
返回
所估计的偏移，若无法估计则为零。

◆ timeutil_sync_skew_to_ppb()

int32_t timeutil_sync_skew_to_ppb ( float skew)

#include <zephyr/sys/timeutil.h>

将偏移转换为以 ppb（十亿分之一）为单位的误差。

偏移为 1.0 时误差为零。偏移小于 1 时误差为正（时钟比应有的快）。偏移大于 1 时误差为负（时钟比应有的慢）。

注意，由于 float 相比 double 精度有限，可表示的最小误差约为 120 ppb。“精确”的时间源误差可能在 2000 ppb 量级。

大于 3.14748 的偏移可能使 32 位表示下溢；这表示时钟以低于其标称频率 1/3 的速率运行。

返回
以 ppb 表示的偏移误差，若该偏移无法用返回类型表示则为 INT32_MIN。

◆ timeutil_sync_state_set_skew()

int timeutil_sync_state_set_skew ( struct timeutil_sync_state * tsp,
float skew,
const struct timeutil_sync_instant * base )

#include <zephyr/sys/timeutil.h>

用新的偏移以及可能的基准值更新状态。

设置偏移，取值可来自持久化存储，或基于近期偏移估计（包括来自 timeutil_sync_estimate_skew()）计算得出。

可选地更新基准时间戳。若替换了基准，则最新瞬间将被清除，直到调用 timeutil_sync_state_update()。

参数
tsp指向时间同步状态的指针。
skew要使用的偏移。该值必须为正，且不应偏离 1 太远。
base可选要设置的新基准。若提供，则它成为基准时间戳，将与偏移一起用于在参考时间刻度与本地时间刻度的瞬间之间转换。设置基准会清除已捕获的最新值。
返回
若偏移已更新则为 0
若偏移无效则为 -EINVAL

◆ timeutil_sync_state_update()

int timeutil_sync_state_update ( struct timeutil_sync_state * tsp,
const struct timeutil_sync_instant * inst )

#include <zephyr/sys/timeutil.h>

在时间同步状态中记录一个新的瞬间。

注意，这只更新最新的持久化瞬间。偏移不会自动调整。

参数
tsp指向 timeutil_sync_state 对象的指针。
inst要记录的新瞬间。若尚无基准瞬间，则将作为基准瞬间，否则该值在参考时间刻度和本地时间刻度中都必须严格晚于基准瞬间。
返回值
0若安装成功提供了新的基准
1若安装提供了新的最新瞬间
-EINVAL若新瞬间与基准瞬间不兼容
