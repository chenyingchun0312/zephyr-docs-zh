#include <zephyr/usb/usb_device.h>

类特定请求的回调函数签名

处理与设备描述符表中指定接口编号对应的类特定请求的函数。对于主机到设备方向，'len' 和 'payload_data' 分别包含所接收数据的长度和指向所接收数据的指针。对于设备到主机的类请求，回调函数应分别用要发送的数据缓冲区的长度和地址来设置 'len' 和 'payload_data'。

清除端点的 NAK，使端点能够接受来自主机的更多数据。通常在消费者可以接受更多数据时于 usb_ep_read_wait() 之后调用。因此这些调用共同构成流控机制。

uint8_t * data,
uint32_t max_data_len,
uint32_t * read_bytes )

#include <zephyr/usb/usb_device.h>

从指定端点读取数据

弃用
请改用 USB 设备核心 API

这与 usb_ep_read 类似，区别在于它不会清除端点的 NAK，从而使消费者不会因后续的上行调用而受阻，直到它处理完数据。调用者应通过调用 usb_ep_read_continue() 来重新激活 EP。

参数
[in]ep与设备配置表中列出的端点相对应的端点地址
[in]data指向要写入的数据缓冲区的指针
[in]max_data_len要读取的数据的最大长度
[out]read_bytes读取的字节数。若 data 为 NULL 且 max_data_len 为 0，则应返回可读取的字节数。
返回
成功时为 0，失败时为负的 errno 错误码。

启动一次与数据缓冲区之间的 USB 传输。该函数是异步的，可以在 IRQ 上下文中执行。所提供的回调将在传输完成（或出错）时在线程上下文中调用。

[in]flags传输标志（USB_TRANS_READ、USB_TRANS_WRITE……）
[in]cb在传输完成/失败时调用的函数
[in]priv传回传输完成回调的数据
返回
成功时为 0，失败时为负的 errno 错误码。
