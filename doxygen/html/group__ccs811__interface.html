函数说明

◆ ccs811_baseline_fetch()

int ccs811_baseline_fetch ( const struct device * dev)

#include <zephyr/drivers/sensor/ccs811.h>

获取 BASELINE 寄存器的当前值。

BASELINE 寄存器编码了用于根据单个设备配置及其随时间的变化来校正传感器读数的数据。

有关 BASELINE 寄存器的正确管理，请参见 AN000370 “Baseline Save and Restore on CCS811”。

参数
dev指向传感器设备的指针
返回
非负的 16 位寄存器值，失败时为负的 errno 码。

◆ ccs811_envdata_update()

int ccs811_envdata_update ( const struct device * dev,
const struct sensor_value * temperature,
const struct sensor_value * humidity )

#include <zephyr/drivers/sensor/ccs811.h>

更新 ENV_DATA 寄存器。

准确计算气体水平需要准确的环境数据。测量仅准确到 0.5 摄氏度和 0.5 RH。

参数
dev指向传感器设备的指针
temperature传感器处的当前温度
humidity传感器处的当前湿度
返回
如果成功则为 0，失败时为负的 errno 码。
