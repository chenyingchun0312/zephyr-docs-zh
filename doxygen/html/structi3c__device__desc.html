详细描述

描述 I3C 目标设备的结构体。

其实例会传给 I3C 控制器设备 API，例如：

  • i3c_device_register() 用于向控制器告知目标设备。
  • i3c_transfers() 用于在控制器与目标设备之间发起数据传输。

在将对象引用传给 I3C 控制器设备 API 之前，实现目标设备行为的模块必须初始化 #bus、#pid 和 static_addr 字段。如果目标设备没有静态地址，#static_addr 可以为零。

内部字段 node 不应手动初始化或修改。

◆ dynamic_addr

uint8_t i3c_device_desc::dynamic_addr

该目标设备用于通信的动态地址。

由控制器驱动在以下情形之一设置：

  • 动态地址分配期间（ENTDAA 期间）
  • 重置动态地址分配（RSTDAA）
  • 将所有地址设为静态地址（SETAASA）
  • 设置新的动态地址（SETNEWDA）
  • 由静态地址设置动态地址（SETDASA）

尚未分配地址时为 0。

◆ static_addr

uint8_t i3c_device_desc::static_addr

该目标设备的静态地址。

未使用静态地址而仅使用动态地址时为 0。这意味着目标设备必须先经过 ENTDAA（动态地址分配）获得动态地址，才能与控制器通信。这也意味着不能使用 SETAASA 和 SETDASA CCC 为目标设备设置动态地址（因为二者都是让目标设备把静态地址用作动态地址）。
