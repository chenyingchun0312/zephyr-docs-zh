音频流控制服务（ASCS）

自从
4.5
版本
0.1.0

音频流控制服务（ASCS）提供音频流端点（ASE），使客户端能够控制这些 ASE 及其关联的单播音频流。

◆ bt_ascs_register()

int bt_ascs_register ( const struct bt_ascs_register_param * param)

#include <zephyr/bluetooth/audio/ascs.h>

注册音频流控制服务（ASCS）

这将初始化该服务并将其暴露在 GATT 数据库中，同时注册所提供数量的接收端和发送端 ASE 特征。

参数
param服务的参数
返回值
0Success.
-EINVALparam 为 NULL 或包含无效值，或者 bt_gatt_service_register() 失败。
-EALREADYASCS 已注册。
-EADDRINUSEISO 服务器已通过 bt_iso_server_register() 注册。
-ENOTSUP控制器不支持 ISO。

#include <zephyr/bluetooth/audio/ascs.h>
