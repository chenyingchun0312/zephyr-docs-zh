解码 base64 格式的缓冲区

参数
dst目标缓冲区（可为 NULL，用于检查大小）
dlen目标缓冲区的大小
olen已写入的字节数
src源缓冲区
slen要解码的数据量
返回
成功时为 0；若输入数据不正确则为 -ENOMEM 或 -EINVAL。*olen 始终会被更新，以反映已写入（或本应写入）的数据量。
注解
以 *dst = NULL 或 dlen = 0 调用此函数，可在 *olen 中获取所需的缓冲区大小

#include <zephyr/sys/base64.h>

把缓冲区编码为 base64 格式

参数
dst目标缓冲区
dlen目标缓冲区的大小
olen已写入的字节数
src源缓冲区
slen要编码的数据量
返回
成功时为 0，若缓冲区太小则为 -ENOMEM。*olen 始终会被更新，以反映已写入（或本应写入）的数据量。若该长度无法表示，则不向缓冲区写入任何数据，并把 *olen 设为 size_t 能表示的最大长度。
注解
以 dlen = 0 调用此函数，可在 *olen 中获取所需的缓冲区大小
