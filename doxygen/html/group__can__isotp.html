◆ isotp_bind()

int isotp_bind ( struct isotp_recv_ctx * rctx,
const struct device * can_dev,
const struct isotp_msg_id * rx_addr,
const struct isotp_msg_id * tx_addr,
const struct isotp_fc_opts * opts,
k_timeout_t timeout )

#include <zephyr/canbus/isotp.h>

将地址绑定到接收上下文。

此函数将接收和发送地址组合绑定到一个接收上下文。当数据从指定地址到达时，它会被缓冲，可通过调用 isotp_recv 读取。调用此例程时，会在 CAN 设备中应用一个过滤器，并初始化上下文。上下文在调用 unbind 之前必须保持有效。

参数
rctx用于存储内部状态的上下文。
can_dev用于发送和接收的 CAN 设备。
rx_addr接收数据的标识符。
tx_addrFC 帧的标识符。
opts流控制选项。
timeoutFF SF 缓冲区分配超时。
返回值
ISOTP_N_OK成功时
ISOTP_NO_FREE_FILTER若 CAN 设备没有剩余过滤器。

uint8_t * data,
size_t len,

#include <zephyr/canbus/isotp.h>

从 FIFO 读取接收到的数据。

此函数从上下文的接收 FIFO 读取数据。若 FIFO 为空则阻塞。若发生错误，函数返回负数，数据缓冲区保持不变。

参数
rctx已绑定的上下文。
data指向复制数据的缓冲区的指针。
len缓冲区的大小。
timeout接收数据的超时时间。
返回
成功时复制的字节数
返回值
ISOTP_RECV_TIMEOUT当 "timeout" 超时时
ISOTP_N_*出错时

◆ isotp_recv_net()

int isotp_recv_net ( struct isotp_recv_ctx * rctx,
struct net_buf ** buffer,
k_timeout_t timeout )

#include <zephyr/canbus/isotp.h>

在数据接收时获取网络缓冲区

此函数将接收到的数据读入网络缓冲区。它会阻塞，直到收到完整数据包、达到 BS 或发生错误。若 BS 为零，数据位于单个 net_buf 中；否则数据按 BS 大小分片。这些网络缓冲区已被引用，数据处理完毕后必须用 net_buf_unref 释放。

参数
rctx已绑定的上下文。
buffer写入 net_buf 指针的地址。
timeout接收数据的超时时间。
返回
本次传输的剩余数据长度（若 BS > 0），BS = 0 时为 0
返回值
ISOTP_RECV_TIMEOUT当 "timeout" 超时时
ISOTP_N_*出错时

complete_cb完成时调用的函数，或 NULL。
cb_arg传递给完成回调的参数。
返回值
ISOTP_N_OK成功时
ISOTP_N_*出错时

◆ isotp_unbind()

void isotp_unbind ( struct isotp_recv_ctx * rctx)

#include <zephyr/canbus/isotp.h>

从接口解绑上下文

此函数解除由 isotp_bind 建立的绑定。过滤器会从 CAN 设备上移除，若正在传输，则释放缓冲区。调用此函数后可安全丢弃上下文。

参数
rctx应被解绑的上下文。
