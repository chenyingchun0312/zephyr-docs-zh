◆ bt_mesh_gatt_proxy_set()

int bt_mesh_gatt_proxy_set ( enum bt_mesh_feat_state gatt_proxy)

#include <zephyr/bluetooth/mesh/cfg.h>

启用或禁用 GATT 代理功能。

必须通过以下方式启用对 GATT 代理功能的支持 CONFIG_BT_MESH_GATT_PROXY configuration option.

注解
GATT 代理功能只控制代理节点向 Mesh 网络转发消息的能力。支持 GATT 代理的节点即使该功能被禁用，仍会广播可连接的代理信标。只有在编译时配置中才能完全禁用代理功能。
参数
gatt_proxy新的 GATT 代理状态。必须是以下值之一 BT_MESH_FEATURE_ENABLED and BT_MESH_FEATURE_DISABLED.
返回值
0已成功更改 GATT 代理功能状态。
-ENOTSUP不支持 GATT 代理功能。
-EINVAL参数无效。
-EALREADY已处于给定状态。

◆ bt_mesh_subnet_add()

uint8_t bt_mesh_subnet_add ( uint16_t net_idx,
const uint8_t key[16] )

#include <zephyr/bluetooth/mesh/cfg.h>

Add a Subnet.

将具有给定网络索引和网络密钥的子网添加到已知子网列表中。在该子网上发送的所有消息都将由本节点处理，本节点可以在该子网上发送和接收网络信标。

参数
net_idx网络索引。
key子网的根网络密钥。所有其他密钥都由它派生。
返回值
STATUS_SUCCESS子网已成功添加。
STATUS_INSUFF_RESOURCES没有空间容纳该子网。
STATUS_UNSPECIFIED由于某种原因无法创建该子网。

◆ bt_mesh_subnet_del()

uint8_t bt_mesh_subnet_del ( uint16_t net_idx)

#include <zephyr/bluetooth/mesh/cfg.h>

删除子网。

从节点中删除具有给定网络索引的子网。节点将停止使用该子网发送网络信标，并且不再能在该子网上处理消息。

绑定到该子网的所有应用程序也会被删除。

#include <zephyr/bluetooth/mesh/cfg.h>

更新给定子网。

通过添加第二组加密密钥为该子网启动密钥刷新过程。子网将继续使用旧密钥发送（但会使用两组密钥接收消息），直到该子网进入密钥刷新阶段 2。

这样网络配置器可以为整个网络替换旧的网络密钥和应用程序密钥，从而有效移除所有未获得新密钥的节点的访问权限。

参数
net_idx网络索引。
key子网的新根网络密钥。
返回值
STATUS_SUCCESS子网已用第二组密钥更新。
STATUS_INVALID_NETKEYNetIdx 未知。
STATUS_IDX_ALREADY_STOREDkey 的值与当前密钥相同。
STATUS_CANNOT_UPDATE由于某种原因，该子网无法更新。
