SWD 包请求位

SWD 包请求字段的位定义。这些位用于构造 SWD 事务期间发送的 8 位请求包头。

#define SWDP_REQUEST_APnDP   BIT(0)
 访问端口（AP）或调试端口（DP）。1 = AP，0 = DP
#define SWDP_REQUEST_RnW   BIT(1)
 读（1）或写（0）操作
#define SWDP_REQUEST_A2   BIT(2)
 用于寄存器选择的地址位 2
#define SWDP_REQUEST_A3   BIT(3)
 用于寄存器选择的地址位 3

SWD 确认（ACK）响应位

SWD 确认响应字段的位定义。这些位用于指示 SWD 事务的结果。

#define SWDP_ACK_OK   BIT(0)
 事务成功完成
#define SWDP_ACK_WAIT   BIT(1)
 目标请求稍后重试该事务
#define SWDP_ACK_FAULT   BIT(2)
 目标检测到故障状态

SWDP 接口引脚定义

SWDP 接口控制的引脚标识符。这些常量定义 SWDP 接口中用于控制各个引脚的位位置。

#define SWDP_SWCLK_PIN   0U
 串行线时钟（SWCLK）引脚标识符
#define SWDP_SWDIO_PIN   1U
 串行线数据输入/输出（SWDIO）引脚标识符
#define SWDP_nRESET_PIN   7U
 低有效复位（nRESET）引脚标识符

◆ swdp_transfer()

int swdp_transfer ( const struct device * dev,
const uint8_t request,
uint32_t *const data,
const uint8_t idle_cycles,
uint8_t *const response )

#include <zephyr/drivers/swdp.h>

执行 SWDP 传输并存储响应

请求必须采用 APnDP | RnW | A[2:3] 的形式，不包含起始位、停止位或奇偶校验位。当 SWDCLK 始终有时钟输出时，驱动程序可能忽略 idle_cycles。

参数
devSWDP 设备
requestSWDP 请求位
data随请求一起传输的数据
idle_cycles请求与响应之间的空闲周期数
response用于存储响应（ACK/WAIT/FAULT）的缓冲区
返回
成功时为 0，否则为错误码
