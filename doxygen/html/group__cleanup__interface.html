定义带条件（可能失败）的作用域保护类型

此宏定义一个锁获取可能失败的保护，供以下情况使用： scoped_cond_guard. Unlike SCOPE_GUARD_DEFINE, the acquire expression is evaluated for success: when it evaluates truthy the guard stores _type _T and the release expression runs on scope exit; when it evaluates falsy the guard stores NULL and nothing is released.

定义作用域变量类型

此宏定义一个新的清理辅助程序，可与 __cleanup 属性一起使用，在变量离开作用域时自动执行清理代码。

参数
_name清理辅助程序的名称
_type要清理的变量的类型
_exit_fn变量离开作用域时要执行的清理代码（可引用 _T）
_init_fn变量的初始化表达式
...初始化参数（可变参数）

此宏会创建：

  • 一个执行清理代码的退出函数 cleanup_<name>_exit
  • 一个初始化变量的初始化函数 cleanup_<name>_init
  • 该类型的一个 typedef cleanup_<name>_t
注意
Available only when the following Kconfig option is enabled: CONFIG_SCOPE_CLEANUP_HELPERS.

用法：

struct foo {
int value;
};
static inline struct foo *foo_constructor(int value)
{
struct foo *ptr = k_malloc(sizeof(struct foo));
if (ptr != NULL) {
ptr->value = value;
}
return ptr;
}
static inline void foo_destructor(struct foo *ptr)
{
k_free(ptr);
}
// Define the cleanup helper
SCOPE_VAR_DEFINE(foo, struct foo *, foo_destructor(_T), foo_constructor(val), int val);
static int some_function(void)
{
// The scope_var macro declares 'f' with automatic cleanup
scope_var(foo, f)(42);
if (f == NULL) {
return -ENOMEM;
}
// Use f normally - it points to an allocated and initialized struct foo
printk("Value: %d\n", f->value);
// No need to manually free - foo_destructor is called automatically
// when 'f' goes out of scope
}

有条件地在后续代码块的存续期间持有保护

此宏尝试获取带条件（可能失败）的作用域保护，并在成功时于紧随其后的花括号代码块的持续时间内持有它，一旦离开该块就立即释放。如果无法获取锁，则执行 _fail 并跳过该块。

成功时该代码块恰好运行一次，锁在从该块以任何方式退出时释放，包括 break、return 和 goto（continue 的行为与 break 相同）。

在后续代码块的存续期间持有保护

此宏获取一个作用域保护的锁，并在紧随其后的花括号代码块的持续时间内持有它，一旦离开该块就立即释放。与 scope_guard, whose guard lives until the end of the enclosing scope, the guard created here is bound to its own block.

该代码块恰好运行一次。锁在从该块以任何方式退出时释放，包括 break、return 和 goto。请注意，由于该块是用隐藏循环实现的，break 和 continue 会离开受保护的块，而不会影响外层循环。

此宏也接受用 SCOPE_COND_GUARD_DEFINE 定义的保护。在这种情况下，如果无法获取锁，则跳过该块（并且不持有任何东西）；请使用 scoped_cond_guard when you need to run a statement on acquisition failure.

参数
_name保护类型的名称（由 SCOPE_GUARD_DEFINE 或 SCOPE_COND_GUARD_DEFINE)
...获取保护的参数（例如锁对象）
注意
Available only when the following Kconfig option is enabled: CONFIG_SCOPE_CLEANUP_HELPERS.

用法：

scoped_guard(k_mutex, &my_mutex) {
// lock held only inside these braces
}
