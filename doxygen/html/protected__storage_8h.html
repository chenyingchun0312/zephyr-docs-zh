◆ psa_ps_create()

psa_status_t psa_ps_create ( psa_storage_uid_t uid,
size_t capacity,
psa_storage_create_flags_t create_flags )

为所提供的 uid 预留存储空间。

成功后，uid 的存储容量将为 capacity，大小为 0。只需为将要使用以下方式写入的数据调用此函数 psa_ps_set_extended() function. If only the psa_ps_set() function is used, calls to this function are redundant. This function cannot be used to replace or resize an existing entry.

参数
uid要为其预留存储的条目标识符。
capacity要分配的容量（字节）。
create_flags指示条目属性的标志。
返回值
PSA_SUCCESS操作成功完成。
PSA_ERROR_GENERIC_ERROR发生了未指明的内部故障。
PSA_ERROR_NOT_SUPPORTED该实现不支持此函数，或 create_flags 中提供的一个或多个标志不受支持或无效。
PSA_ERROR_INVALID_ARGUMENTuid is invalid.
PSA_ERROR_ALREADY_EXISTS具有所提供 uid 的条目已存在。
PSA_ERROR_INSUFFICIENT_STORAGE存储介质上的空间不足。
PSA_ERROR_STORAGE_FAILURE物理存储发生故障（致命错误）。

◆ psa_ps_get()

psa_status_t psa_ps_get ( psa_storage_uid_t uid,
size_t data_offset,
size_t data_size,
void * p_data,
size_t * p_data_length )

检索与所提供 uid 关联的数据。

参数
[in]uid数据的标识符。
[in]data_offset开始读取数据的偏移（字节）。
[in]data_size要读取的字节数。
[out]p_data成功时存放数据的缓冲区。长度必须至少为 data_size 字节。
[out]p_data_length成功时，放入 p_data 的字节数。
返回值
PSA_SUCCESS操作成功完成。
PSA_ERROR_GENERIC_ERROR发生了未指明的内部故障。
PSA_ERROR_INVALID_ARGUMENT一个或多个参数无效。当 data_offset 大于与 uid 关联的数据大小时也会发生此错误。
PSA_ERROR_DOES_NOT_EXIST在存储中未找到所提供的 uid。
PSA_ERROR_STORAGE_FAILURE物理存储发生故障（致命错误）。
PSA_ERROR_INVALID_SIGNATURE与 uid 关联的数据未通过认证。
PSA_ERROR_DATA_CORRUPT与 uid 关联的数据已损坏。

◆ psa_ps_set_extended()

psa_status_t psa_ps_set_extended ( psa_storage_uid_t uid,
size_t data_offset,
size_t data_length,
const void * p_data )

写入与所提供 uid 关联的部分数据。

在调用此函数之前，必须已通过调用以下函数预留存储 psa_ps_create(). This function can also be used to overwrite data that was written with psa_ps_set(). This function can overwrite existing data and/or extend it up to the capacity of the entry specified in psa_ps_create(), but cannot create gaps.

参数
uid要写入的条目标识符。
data_offset开始写入数据的偏移（字节）。至多为数据的当前大小。
data_lengthp_data 中要写入的数据大小（字节）。data_offset
  • data_length 至多为该条目的容量。
p_data包含要写入数据的缓冲区。
返回值
PSA_SUCCESS操作成功完成。
PSA_ERROR_GENERIC_ERROR发生了未指明的内部故障。
PSA_ERROR_NOT_PERMITTED该条目是以 PSA_STORAGE_FLAG_WRITE_ONCE 创建的。
PSA_ERROR_NOT_SUPPORTED该实现不支持此函数。
PSA_ERROR_INVALID_ARGUMENT一个或多个参数无效。
PSA_ERROR_DOES_NOT_EXIST在存储中未找到所提供的 uid。
PSA_ERROR_STORAGE_FAILURE物理存储发生故障（致命错误）。
PSA_ERROR_INVALID_SIGNATURE与 uid 关联的数据未通过认证。
PSA_ERROR_DATA_CORRUPT与 uid 关联的数据已损坏。
