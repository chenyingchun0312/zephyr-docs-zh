typedef int(*) net_latmon_measure_t(uint32_t *delta)

#include <zephyr/net/latmon.h>

用于获取延迟差值的回调函数类型。

参数
delta指向用于存放所计算延迟差值（以周期为单位）的指针。
返回
成功时为 0，失败时为负的 errno 码。

◆ net_latmon_connect()

int net_latmon_connect ( int socket,
struct net_in_addr * ip )

#include <zephyr/net/latmon.h>

等待来自 Latmus 服务的连接。

此函数会阻塞，直到 Latmus 服务连接到指定的套接字。一旦连接成功，Latmus 服务的 IP 地址会存入所提供的 ip 结构体。

参数
socket用于侦听的有效套接字描述符。
ip客户端的 IP 地址。
返回
成功时为连接到 latmus 的有效客户端套接字描述符，失败时为负的 errno 错误码。

◆ net_latmon_get_socket()

int net_latmon_get_socket ( struct net_sockaddr * bind_addr)

#include <zephyr/net/latmon.h>

获取用于 Latmus 服务的套接字。

此函数创建并返回一个用于等待 Latmus 连接的套接字

参数
bind_addr要将套接字绑定到的地址。若为 NULL，则套接字将使用构建时配置的 latmus 端口绑定到第一个可用地址。
返回
成功时为有效套接字描述符，失败时为负的 errno 错误码。

◆ net_latmon_running()

bool net_latmon_running ( void )

#include <zephyr/net/latmon.h>

检查延迟监控是否正在运行。

此函数检查延迟监控当前是否处于活动运行状态。

返回
若延迟监控正在运行则为 True，若正在等待 Latmus 连接则为 false

◆ net_latmon_start()

void net_latmon_start ( int latmus,
net_latmon_measure_t measure_func )

#include <zephyr/net/latmon.h>

启动延迟监控。

此函数启动延迟监控，它使用所提供的回调函数计算差值来测量延迟。采样数据会发送到已连接的 Latmus 服务。

参数
latmus连接到 latmus 的有效套接字描述符
measure_func用于执行差值计算的回调函数。
