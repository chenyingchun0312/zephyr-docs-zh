GPIO 中断配置标志 <tt>GPIO_INT_*</tt> 标志用于指定输入 GPIO 引脚如何触发中断。中断可以对引脚的物理电平或逻辑电平敏感。对引脚逻辑电平敏感的中断会考虑 GPIO_ACTIVE_LOW 标志。如果引脚被配置为低有效，则物理低电平将被视为逻辑电平 1（有效状态），物理高电平将被视为逻辑电平 0（无效状态）。在配置中断触发属性时，GPIO 控制器应复位中断状态，例如清除挂起位等。应用程序应使用 <tt>GPIO_INT_MODE_ENABLE_ONLY</tt> 和 <tt>GPIO_INT_MODE_DISABLE_ONLY</tt> 标志在不改变任何 GPIO 设置的情况下使能和禁用引脚上的中断。@{

根据设备树 "gpio-reserved-ranges" 属性和 "ngpios" 参数生成保留 GPIO 的位掩码

此宏以 "gpio-reserved-ranges" 属性的位掩码形式返回值。该属性定义 0...ngpios-1 范围内被禁用（或“保留”）的 GPIO，并以定义保留范围起始偏移和大小的值对数组形式给出。

例如，设置 "gpio-reserved-ranges = <3 2>, <10 1>;" 表示即使 ngpios = <18>，GPIO 偏移 3、4 和 10 也不能使用。

实现约束继承自通用设备树限制：最多可使用 64 对（结果受限于 gpio_port_pins_t 类型的位数）。

注意：由于 C 宏的特性，某些不正确的元组定义（例如重叠或越界）会产生未定义的结果。

另请注意，如果 ngpios 小于 32（设备树 int 类型的位数），则 ngpios 定义范围之外所有未使用的高位也会被标记为保留。

ngpios = <32>;
gpio-reserved-ranges = <0 4>, <5 3>, <9 5>, <11 2>, <15 2>,
<18 2>, <21 1>, <23 1>, <25 4>, <30 2>;
};
b {
compatible = "some,gpio-controller";
ngpios = <18>;
gpio-reserved-ranges = <3 2>, <10 1>;
};

此类型的值通常与 gpio_port_pins_t 值配合使用，后者指定哪些编码的引脚值对该操作有效。

设置输出引脚的逻辑电平，并考虑 GPIO_ACTIVE_LOW 标志。值 0 将引脚设为逻辑 0 / 无效状态。值 1 将引脚设为逻辑 1 / 有效状态。若引脚配置为高有效（默认），将其设为无效状态会强制引脚为低物理电平。若引脚配置为低有效，将其设为无效状态会强制引脚为高物理电平。

索引为 n 的引脚由 mask 和 value 参数中的第 n 位表示。

参数
port指向该驱动实例设备结构的指针。
mask指示要修改哪些引脚的掩码。
value赋给输出引脚的值。
返回值
0If successful.
-EIO访问外部 GPIO 芯片时发生 I/O 错误。
-EWOULDBLOCK若操作会阻塞。

警告
在回调处理程序内明确允许移除正在运行的回调（即 callback）的注册。尝试移除同一设备上的其他注册可能导致未定义行为，包括未能调用仍注册的回调以及意外调用已移除的回调。
