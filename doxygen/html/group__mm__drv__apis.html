将一组物理页面映射到虚拟地址空间

此函数将一组物理页面映射到连续的虚拟地址空间。提供未对齐地址时的行为未定义，此处假定为页对齐。

此操作不会访问这些物理内存页面。

此 API 必须可在 ISR 或异常处理程序中安全调用。对此 API 的调用假定已串行化。

参数
virt要映射的目标虚拟地址，需页对齐
phys要映射的页对齐源物理地址数组
cnt物理页面数组中的元素数量
flags缓存、访问和控制标志，参见 SYS_MM_MEM_* 宏
返回值
0成功时
-EINVAL如果提供了无效参数
-EFAULT如果任一虚拟地址已被映射

◆ sys_mm_drv_move_array()

int sys_mm_drv_move_array ( void * virt_old,
size_t size,
void * virt_new,
uintptr_t * phys_new,
size_t phys_cnt )

#include <zephyr/drivers/mm/system_mm.h>

以拷贝方式物理搬移内存

此函数将一段物理内存区域映射到新的虚拟地址空间（virt_new），并从旧虚拟地址空间（virt_old）拷贝大小为 size 的区域。新的虚拟内存区域映射自一个物理页面数组。

提供未对齐地址/大小时的行为未定义，此处假定为页对齐。

注意，旧地址和新地址处的虚拟内存都必须在任何可运行的 Zephyr 线程的内存域中取消映射，因为此函数不处理内存域。

注意，较简单的实现通常不支持新旧虚拟内存区域重叠。请参考具体驱动以确认是否允许重叠。

参数
virt_old现有内存的页对齐基虚拟地址
size所映射内存区域的大小，单位为字节，需页对齐
virt_new要将新物理页面映射到的页对齐基虚拟地址
phys_new用于容纳所搬移内存的页对齐物理地址数组
phys_cnt物理页面数组中的元素数量
返回值
0成功时
-EINVAL如果提供了无效参数
-EFAULT如果旧虚拟地址未全部映射，或新虚拟地址未全部取消映射

◆ sys_mm_drv_remap_region()

int sys_mm_drv_remap_region ( void * virt_old,
size_t size,
void * virt_new )

#include <zephyr/drivers/mm/system_mm.h>

将虚拟页面重新映射到新地址

此函数将以 virt_old 起始、大小为 size 的虚拟内存区域重新映射到起始于 virt_new. In other words, physical memory at virt_old is remapped to appear at virt_new. Both addresses must be page aligned and valid.

注意，旧地址和新地址处的虚拟内存都必须在任何可运行的 Zephyr 线程的内存域中取消映射，因为此函数不处理内存域。

注意，较简单的实现通常不支持新旧虚拟内存区域重叠。请参考具体驱动以确认是否允许重叠。

参数
virt_old现有内存的页对齐基虚拟地址
size所映射内存区域的大小，单位为字节，需页对齐
virt_new要将内存重新映射到的页对齐基虚拟地址
返回值
0成功时
-EINVAL如果提供了无效参数
-EFAULT如果旧虚拟地址未全部映射，或新虚拟地址未全部取消映射
