 架构专用内存属性。它们必须位于以下部分 zephyr,memory-attr value corresponding to DT_MEM_ARCH_ATTR_MASK.

 软件专用内存属性。它们必须位于 zephyr,memory-attr 值中对应 DT_MEM_ARCH_ATTR_MASK 的部分。

详细描述

内存属性的设备树宏。

内存属性是描述性属性，可通过 zephyr,memory-attr 属性分配给设备树中的内存区域，用于描述其能力或特性（例如可缓存性、非易失性、乱序访问、DMA 能力等）。
