◆ pm_system_resume()

void pm_system_resume ( void )

#include <zephyr/pm/pm.h>

通知内核休眠已退出。

如果相应的 pm_system_suspend() 通知已被处理且未返回 PM_STATE_ACTIVE，此函数将通知内核空闲已退出。

此函数应从导致内核退出空闲的事件的 ISR 上下文中调用。

对于进入低功耗状态时需要使能中断的 CPU 电源状态（例如 x86 中的 C1），这是必需的。在这些情况下，ISR 会在事件唤醒 CPU 后立即被调用，而跟随在 CPU 等待之后的代码还来不及执行。如果在唤醒事件通知时无需做任何操作，可以忽略此函数。
