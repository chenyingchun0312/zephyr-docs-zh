获取设备的命名 MMIO 地址

此宏从设备对象链接数据结构中的适当位置返回命名区域的 MMIO 基址。

它适用于有多个 MMIO 区域的驱动。

此宏要求本地定义了宏 DEV_DATA 和 DEV_CFG，且它们返回指向此驱动特定 dev_data 和 config 结构的类型正确的指针。

为命名 MMIO 区域设置内存

这会执行所需的 PCI 探测和/或 MMU 虚拟内存映射，使 DEVICE_MMIO_GET(name) 能返回该 MMIO 区域合适的线性内存地址。

若目标硬件不需要此类操作，它展开为空。

应在驱动的初始化函数中调用它，每个需要映射的 MMIO 区域调用一次。

此宏要求本地定义了宏 DEV_DATA 和 DEV_CFG，且它们返回指向此驱动特定 dev_data 和 config 结构的类型正确的指针。

flags 参数目前用于缓存模式，应为 DEVICE_CACHE_* 宏之一。未使用的位保留以备将来扩展。

在设备的 config 结构中声明 MMIO 数据的存储位置。

它由 DEVICE_MMIO_NAMED_MAP() 和 DEVICE_MMIO_NAMED_GET() 宏访问。

此处存储的内容因配置不同而差别很大。可以声明多个命名区域。dev_data 结构中必须有对应的条目。

若设备是 PCIe，则不使用此存储，可以省略。

若使用它，则必须在构建时使用来自 DTS 的信息通过 DEVICE_MMIO_NAMED_ROM_INIT() 初始化

可以用 DEVICE_MMIO_NAMED_ROM_PTR() 获取指向此内存的指针。

名为 "foo" 的驱动的示例：

struct foo_config {
int bar;
DEVICE_MMIO_NAMED_ROM(corge);
DEVICE_MMIO_NAMED_ROM(grault);
int baz;
...
}
