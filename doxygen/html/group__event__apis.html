向事件对象投递一个或多个事件

此例程向事件对象投递一个或多个事件。所有等待在事件对象 event 上的任务，若其等待条件因本次投递而得到满足，则立即解除挂起。

投递与设置的不同之处在于，投递的事件会与事件对象当前跟踪的事件集合合并。

参数
event事件对象的地址
events要投递到 event 的事件集合
返回
正在投递的事件的先前值，即 events 中在本次调用之前已在 event 中置位的那些位

◆ k_event_wait()

uint32_t k_event_wait ( struct k_event * event,
uint32_t events,
bool reset,
k_timeout_t timeout )

#include <zephyr/kernel.h>

等待指定的任一事件

此例程等待事件对象 event，直到指定的任一事件已投递给该事件对象，或达到最长等待时间 timeout has expired. A thread may wait on up to 32 distinctly numbered events that are expressed as bits in a single 32-bit word.

注解
如果有多个线程正在等待事件对象 event，调用者在重置时须谨慎。
仅当 timeout 设置为 K_NO_WAIT 时，才可在 ISR 上下文中调用此函数。
参数
event事件对象的地址
events要等待的期望事件集合
reset如果为 true，则在等待之前清除事件对象跟踪的事件集合。如果为 false，则不清除这些事件。
timeout等待期望事件集合的时段，或特殊值 K_NO_WAIT 和 K_FOREVER 之一。
注解
如果 events 为零，此函数立即返回 0。如果 reset 为 true，则事件对象当前跟踪的事件会在返回之前被重置。
返回值
non-zero成功时为匹配的事件集合
0如果在指定时间内未收到匹配的事件

等待指定的所有事件（安全版本）

此调用与 k_event_wait_all 几乎相同，主要区别在于安全版本会原子地从事件对象中清除已接收的事件。这减少了对以下调用的需要： k_event_clear, or passing a "reset" argument, since doing so may result in lost event information.

参数
event事件对象的地址
events要等待的期望事件集合
reset如果为 true，则在等待之前清除事件对象跟踪的事件集合。如果为 false，则不清除这些事件。
timeout等待期望事件集合的时段，或特殊值 K_NO_WAIT 和 K_FOREVER 之一。
注解
如果 events 为零，此函数立即返回 0。如果 reset 为 true，则事件对象当前跟踪的事件会在返回之前被重置。
返回值
non-zero成功时为匹配的事件集合
0如果在指定时间内未收到所有匹配的事件
