详细描述

描述 MQTT-SN 传输的结构体。

MQTT-SN 不要求传输可靠或保持连接。传输只需基于帧，因此只要使用某种帧定界协议，你可以使用 UDP、ZigBee，甚至简单的 UART。

◆ poll

int(*) mqtt_sn_transport::poll(struct mqtt_sn_transport *transport)

检查是否有传入数据可用。

如果 poll() 返回正数，则 recv 不能阻塞。

可以为 NULL，但此时 recv 也不应阻塞。

返回
有数据可用时为正数，没有数据时为零。负值表示错误。

◆ sendto

int(*) mqtt_sn_transport::sendto(struct mqtt_sn_transport *transport, void *buf, size_t sz, const void *dest_addr, size_t addrlen)

当库要发送消息时会被调用。

实现应遵循 sendto 约定并带有例外。当 dest_addr == NULL 时，消息应以广播方式发送，addrlen 为广播半径。当地址变化时，这还应处理按需建立或销毁连接。

返回
连接和传输成功时为 ENOERR，负值表示错误。
