◆ auxdisplay_custom_character_set()

int auxdisplay_custom_character_set ( const struct device * dev,
struct auxdisplay_character * character )

#include <zephyr/drivers/auxdisplay.h>

在显示器上设置自定义字符。

自定义字符结构体必须包含要添加的自定义字符的像素数据以及有效的自定义字符索引。若成功，结构体中的 character_code 变量将被设为可与 auxdisplay_write() 函数一起使用以显示该字符的字符编码。 

            对于由 uint8 数组（大小为字符宽度乘以字符高度）构成的显示器，字符必须合法，像素关闭的值为 @c 0x00、像素开启的值为 @c 0xff；若显示器支持灰度，则可使用 @c 0x00 到 @c 0xff 之间的值（取决于显示器驱动）。
参数
dev辅助显示设备实例
character自定义字符结构体的指针
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENOSYS若不支持/未实现。
-EINVAL若提供的参数无效。
