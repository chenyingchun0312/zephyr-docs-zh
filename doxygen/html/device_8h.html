定义 util.h:237

声明 API 类别 _child 是设备 API 类别 _parent 的扩展。

这会注册父子关系，使得对于 API 属于 _child 类别的设备，DEVICE_API_IS(_parent, dev) 返回 true。父 API 结构体必须是子 API 结构体的第一个成员。

参数
_child子（扩展）API 类别的名称。
_parent父（基础）API 类别的名称。
_member_child API 类别结构体第一个成员的名称。该成员的类型必须与 _parent API 类别结构体相同。
