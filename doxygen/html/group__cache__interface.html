◆ sys_cache_cached_ptr_get()

ALWAYS_INLINE void * sys_cache_cached_ptr_get ( void * ptr)
static

#include <zephyr/cache.h>

返回指向 RAM 地址的可缓存指针

此函数接受一个指向任意可寻址对象（无论该对象是否位于可缓存内存中）的指针，并返回一个可通过 L1 数据缓存引用同一内存的指针。通过所得指针读取的数据将反映当前 CPU 上本地缓存的值（若存在），写入则先进入缓存，稍后再回写。

注解
如果未启用 CONFIG_CACHE_HAS_MIRRORED_MEMORY_REGIONS，此 API 返回相同的指针。
参见
arch_uncached_ptr()
参数
ptr指向有效 C 对象的指针
返回
通过 L1 dcache 指向同一对象的指针

◆ sys_cache_data_flush_and_invd_range()

int sys_cache_data_flush_and_invd_range ( void * addr,
size_t size )

#include <zephyr/cache.h>

刷新并使 d-cache 中的地址范围失效

刷新并使数据缓存中指定的地址范围失效。

注解
缓存操作以缓存行为单位。当多个数据结构共享正在被刷新的同一条缓存行时，共享该行的数据结构的所有部分都会在失效之前被刷新。这通常不是问题，因为回写是非破坏性过程，硬件可能在任何时候触发它，因此对齐的 addr 或补齐的 size 并非严格必要。
参数
addr要刷新并使之失效的起始地址。
size范围大小。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENOTSUP不受支持时。

static

#include <zephyr/cache.h>

获取 d-cache 行大小。

提供此 API 是为了获取数据缓存行。

缓存行大小按以下优先级顺序获取：

  • 设置 CONFIG_DCACHE_LINE_SIZE_DETECT 时在运行时获取。

  • 若 DCache 被禁用则为 0

0d-cache 未启用时。

◆ sys_cache_is_mem_coherent()

ALWAYS_INLINE bool sys_cache_is_mem_coherent ( void * ptr)
static

#include <zephyr/cache.h>

检测内存一致性类型

如果所指字节位于 "coherence regions"（通常以不可缓存内存实现）内，且可在多处理器代码中安全使用而无需显式刷新或失效操作，则此函数返回 true。

注解
结果仅针对指定地址处的单个字节，此 API 不需要检查区域边界，也不要求指针对齐。其预期是上述代码已查询了相应的地址。
参数
ptr要检查的指针。
返回
如果指针位于任何一致性区域内则为 true，否则为 false。

◆ sys_cache_is_ptr_cached()

ALWAYS_INLINE bool sys_cache_is_ptr_cached ( void * ptr)
static

#include <zephyr/cache.h>

测试指针是否位于可缓存区域。

某些硬件可能将同一物理内存映射两次，使其既出现在（非一致的）可缓存映射中，也出现在一致的 "shared" 区域中。此函数测试特定指针是否位于可缓存的一致区域内。

参数
ptr指针
返回值
True如果指针位于可缓存区域。
False如果指针不在可缓存区域。
