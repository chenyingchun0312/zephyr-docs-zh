◆ fcb_walk_cb

typedef int(*) fcb_walk_cb(struct fcb_entry_ctx *loc_ctx, void *arg)

#include <zephyr/fs/fcb.h>

FCB 遍历回调函数类型。

在通过 fcb_walk 调用遍历 fcb 表项时预期被调用的函数类型。

表项数据可使用 flash_area_read() 读取，以 loc_ctx 字段作为参数。如果回调希望停止遍历，应返回非零值。

参数
[in]loc_ctx表项位置信息（完整上下文）
[in,out]arg回调上下文，由 fcb_walk 传入。
返回
0 表示继续遍历，非零表示停止遍历。

◆ fcb_getnext()

int fcb_getnext ( struct fcb * fcbp,
struct fcb_entry * loc )

#include <zephyr/fs/fcb.h>

获取下一个 fcb 表项位置。

用于获取相对于

loc 所指向表项的 fcb 表项位置的函数。如果设置了 loc->fe_sector 且 loc->fe_elem_off 不为 0，函数会获取下一个 fcb 表项位置。如果 loc->fe_sector 为 NULL，函数会获取 FCB 存储中最旧的表项位置。如果设置了 loc->fe_sector 且 loc->fe_elem_off 为 0，函数会获取 fcb 扇区中的第一个表项位置。

参数
[in]fcbpFCB 实例结构体。
[in,out]loc表项位置信息
返回
成功时为 0，失败时为非零。
