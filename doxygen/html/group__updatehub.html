◆ updatehub_response

enum updatehub_response

#include <zephyr/mgmt/updatehub.h>

来自 UpdateHub 的响应消息。

这些消息用于向服务器和用户告知 UpdateHub 的处理状态，也用于统一可能发生的错误。

◆ updatehub_autohandler()

void updatehub_autohandler ( void )

#include <zephyr/mgmt/updatehub.h>

自动运行 UpdateHub 探测和 UpdateHub 更新。

updatehub_autohandler 按预定的时间间隔处理整个过程。

◆ updatehub_confirm()

int updatehub_confirm ( void )

#include <zephyr/mgmt/updatehub.h>

确认映像按预期运行。

必须在 UpdateHub 探测之前使用。它应当成为重启后的首批操作之一。

返回
成功时返回 0，否则返回负的 'errno' 值。

◆ updatehub_probe()

enum updatehub_response updatehub_probe ( void )

#include <zephyr/mgmt/updatehub.h>

UpdateHub 探测会验证是否有需要执行的更新。

返回
UPDATEHUB_HAS_UPDATE 有可用更新。
UPDATEHUB_NO_UPDATE 没有可用更新。
UPDATEHUB_NETWORKING_ERROR 无法连接到 UpdateHub 服务器。
UPDATEHUB_INCOMPATIBLE_HARDWARE 如果硬件不兼容。
UPDATEHUB_METADATA_ERROR 解析或编码元数据失败。

◆ updatehub_reboot()

int updatehub_reboot ( void )

#include <zephyr/mgmt/updatehub.h>

请求系统重启。

返回
成功时返回 0，否则返回负的 'errno' 值。

◆ updatehub_report_error()

int updatehub_report_error ( void )

#include <zephyr/mgmt/updatehub.h>

向 UpdateHub 服务器报告更新失败。

这会为最后一个包发送 ERROR 状态（UPDATEHUB_STATE_ERROR）。

返回
成功时为 0，失败时为负的 errno。

◆ updatehub_update()

enum updatehub_response updatehub_update ( void )

#include <zephyr/mgmt/updatehub.h>

应用更新包。

必须在 UpdateHub 探测之后使用；若有待执行的更新，将执行新映像的安装并重启硬件。

返回
成功时返回 UPDATEHUB_OK
UPDATEHUB_NETWORKING_ERROR 如果无法连接到服务器。
UPDATEHUB_DOWNLOAD_ERROR 下载更新包时失败。
UPDATEHUB_INSTALL_ERROR 安装更新包时失败。
UPDATEHUB_FLASH_INIT_ERROR 初始化 flash 失败。
