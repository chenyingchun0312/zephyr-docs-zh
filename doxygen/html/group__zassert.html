模块感知的断言。

由本文件中 ZASSERT_MODULE() 给出的级别控制。在 ZASSERT_LEVEL_TERSE 下仅报告固定的 "ASSERTION FAIL" 横幅。在 ZASSERT_LEVEL_NORMAL 下会加上失败位置。在 ZASSERT_LEVEL_VERBOSE 下还会编译进并打印字符串化的条件以及可选消息及其参数。

参数
_test要检查的条件。若为假则产生致命错误。
...可选的消息格式字符串，后跟其参数。当检查本身已说明问题时可以省略。

◆ ZASSERT_MODULE

#define ZASSERT_MODULE ( ...)

#include <zephyr/sys/zassert.h>

值:
ZASSERT_IMPL_MODULE(__VA_ARGS__)

选择本文件中 ZASSERT() 所使用的、由 Kconfig 定义的断言模块。

必须放在文件作用域，且位于本翻译单元中任何 ZASSERT() 使用之前。每个使用 ZASSERT() 的文件都必须选择一个模块。

参数
...断言模块名称（一个大写标识符），后跟可选的显式级别。模块的默认级别取自 Kconfig 符号 CONFIG_ASSERT_MODULE_<module>_LEVEL，该符号必须存在（名称按原样拼接，因此必须匹配）。可选的第二个参数（ZASSERT_LEVEL_OFF、ZASSERT_LEVEL_TERSE、ZASSERT_LEVEL_NORMAL 或 ZASSERT_LEVEL_VERBOSE）将覆盖本文件的模块默认值。
注解
CONFIG_ASSERT 是总开关：当它被禁用时，所有模块都被强制为 ZASSERT_LEVEL_OFF，无论模块默认值或显式级别如何。

FUNC_NORETURN void zassert_fail ( const char * cond,
const char * file,
unsigned int line,
const char * fmt,

#include <zephyr/sys/zassert.h>

报告断言失败并执行终止操作。弱符号，可覆盖。

将整个断言冷路径合并为一次非内联调用：默认实现打印位置（并在 fmt 非 NULL 时打印用户消息），然后调用 zassert_post_action()。覆盖此函数即可在单一位置捕获或重定向整个断言输出。

参数
cond字符串化的失败条件。
file失败断言所在的源文件。
line失败断言所在的源代码行。
fmt可选的用户消息格式字符串，若没有则为 NULL。
...fmt 的参数。
