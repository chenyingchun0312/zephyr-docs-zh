◆ conn_mgr_all_if_connect()

int conn_mgr_all_if_connect ( bool skip_ignored)

#include <zephyr/net/conn_mgr_connectivity.h>

将所有可用接口置为 admin-up 状态，并连接支持连通性的那些接口的便捷函数。

本质上是 net_if_up 和 conn_mgr_if_connect 的包装。

参数
skip_ignored- 若为 true，则只影响未被 conn_mgr 忽略的接口。否则影响所有接口。
返回
若所有 net_if_up 和 conn_mgr_if_connect 调用都返回 0 则为 0，否则为 net_if_up 或 conn_mgr_if_connect 返回的第一个非零值。
