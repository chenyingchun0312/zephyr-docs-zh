◆ gdb_bin2hex()

size_t gdb_bin2hex ( const uint8_t * buf,
size_t buflen,
char * hex,
size_t hexlen )

将二进制数组转换为字符串表示。

注意，这与 bin2hex() 类似，但不会在十六进制输出缓冲区末尾强制添加空字符。

参数
buf要转换的二进制数组
buflen要转换的二进制数组长度
hex存储字符串表示的地址。
hexlen用于字符串表示的存储区大小。
返回
转换后字符串的长度，若出错则为 0。

◆ gdb_mem_region_array

const struct gdb_mem_region gdb_mem_region_array[]
extern

用于 GDB 内存访问的内存区域描述。

此数组指定 GDB 可以读/写属性访问的内存区域。它用于将 GDB stub 的内存读写限制在可合法访问而不会引发内存错误的范围内。
