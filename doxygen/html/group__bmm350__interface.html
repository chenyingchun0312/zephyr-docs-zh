◆ bmm350_magnetic_reset()

int bmm350_magnetic_reset ( const struct device * dev)

#include <zephyr/drivers/sensor/bmm350.h>

执行磁性复位。

BMM350 具有从过强磁场中恢复的措施。设备会在复位后自行触发磁性复位，但如果在挂起模式下发生了过强磁场暴露，传感器无法检测到该事件。如果较大的偏移或灵敏度漂移表明发生了此类事件，则应用程序可以调用该函数。

较晚的 BMM350 版本所支持的“增强型”磁性复位尚未实现。

参数
dev指向传感器设备的指针
返回
如果成功则为 0，失败时为负的 errno 码。

◆ bmm350_self_test()

int bmm350_self_test ( const struct device * dev,
struct bmm350_self_test_result * result )

#include <zephyr/drivers/sensor/bmm350.h>

运行 BMM350 内置的用户自检。

重新初始化 TMR 传感器，并按 Bosch SensorAPI 的流程测量 X 轴和 Y 轴上对正、负激励的响应。返回时会恢复调用前的设备配置。

调用方负责根据设备的自检限值判断结果（参见 BMM350 数据手册）；该函数只报告测得的响应。

不得在传感器处于数据流模式时调用。

参数
dev指向传感器设备的指针。
result输出：每轴自检响应与差值。
返回
成功时为 0，失败时为负的 errno 码。
