◆ sys_csrand_get()

int sys_csrand_get ( void * dst,
size_t len )

#include <zephyr/random/random.h>

用密码学安全的随机数据值填充目标缓冲区。

注解
如果所请求的随机值不需要密码学安全，请改用 sys_rand_get()。
参数
[out]dst要填充的目标缓冲区。
len目标缓冲区的大小。
返回
成功时为 0，熵重播种出错时为 -EIO
