◆ smp_transport_get_mtu_fn

typedef uint16_t(*) smp_transport_get_mtu_fn(const struct net_buf *nb)

#include <zephyr/mgmt/mcumgr/transport/smp.h>

传输的 SMP MTU 查询回调

弃用
SMP 层不会调用此函数。传输会在其 smp_transport_out_fn 中对发出的数据包进行分片。

所提供的 net_buf 应包含从正在查询其 MTU 的对端收到的请求。此函数接收 net_buf 参数，是因为某些传输会把连接特定信息存放在 net_buf 用户头部中（例如，Bluetooth 传输存放对端地址）。

参数
nb包含来自相关对端的请求。
返回
该传输的 MTU；当前无法发送时为 0。

◆ smp_transport_out_fn

typedef int(*) smp_transport_out_fn(struct net_buf *nb)

#include <zephyr/mgmt/mcumgr/transport/smp.h>

传输的 SMP 发送回调

所提供的 net_buf 存放一个完整的 SMP 数据包，最大为 CONFIG_MCUMGR_TRANSPORT_NETBUF_SIZE bytes. If the packet does not fit in a single frame of the underlying link, the transport is responsible for fragmenting it. Likewise, on reception the transport must pass only complete SMP packets to the SMP layer, see CONFIG_MCUMGR_TRANSPORT_REASSEMBLY for a common reassembly helper.

无论返回码如何，所提供的 net_buf 总会被消耗。

参数
nb要发送的 net_buf。
返回
成功时为 0，失败时为 mcumgr_err_t 错误码。

typedef bool(*) smp_transport_query_valid_check_fn(struct net_buf *nb, void *arg)

#include <zephyr/mgmt/mcumgr/transport/smp.h>

用于检查已排队数据是否仍然有效的函数。

此函数用于检查已排队的 SMP 数据是否仍然有效，例如在远程设备断开连接时；调用 smp_rx_remove_invalid() 时即会触发。

参数
nb包含已排队请求的 net buf。
arg调用 smp_rx_remove_invalid() 函数时提供的参数。
返回
如果数据不再有效/应被释放则为 false，否则为 true。
