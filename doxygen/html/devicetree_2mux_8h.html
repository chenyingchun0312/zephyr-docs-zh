详细描述

MUX 设备树宏公共 API 头文件。

MUX 子系统的纯设备树辅助工具：这些宏解析为预处理器词法单元（标识符、单元值、节点标识符，以及通过 DEVICE_DT_GET 得到的 device 结构体指针）。

生成 struct mux_control 或 struct mux_state 初始化器的辅助功能位于 <zephyr/drivers/mux.h>，因为它们在展开处需要完整的结构体定义。
