void uart_bridge_settings_update ( const struct device * dev,
const struct device * bridge_dev )

更新 UART 桥上的硬件端口设置

如果 dev 是 bridge_dev 的一部分，则 dev 的 UART 配置会被应用到 UART 桥中的另一设备。这样可以把设置从 USB CDC-ACM 端口传播到硬件 UART。

如果 dev 不属于 bridge_dev，则该函数为空操作。
