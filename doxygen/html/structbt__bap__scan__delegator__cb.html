可通过 bt_bap_scan_delegator_register() 注册这些回调以供使用。

◆ add_source

int(*) bt_bap_scan_delegator_cb::add_source(struct bt_conn *conn, const struct bt_bap_scan_delegator_recv_state *recv_state)

添加源操作回调

当收到添加源的请求时，这些回调会通知应用程序。应用程序可返回 0 接受请求，或返回其他值拒绝请求。

参数
conn指向发起请求的连接的指针；若由本地触发则为 NULL。
recv_state指向待添加的所请求接收状态的指针。
返回
接受时为 0，拒绝时为其他值。

◆ bis_sync_req

int(*) bt_bap_scan_delegator_cb::bis_sync_req(struct bt_conn *conn, const struct bt_bap_scan_delegator_recv_state *recv_state, const uint32_t bis_sync_req[COND_CODE_1(CONFIG_BT_AUDIO,(CONFIG_BT_BAP_BASS_MAX_SUBGROUPS),(0))])

广播同步流同步请求

广播助理设备请求修改广播同步流状态。该请求应在合理时间内按 bis_sync_req 完成。广播助理也可以请求同步更少或不请求任何索引。当任何 bis_sync_req 值为 BT_BAP_BIS_SYNC_NO_PREF 时，总会调用此回调。

参数
[in]conn指向请求同步的广播助理的连接的指针。
[in]recv_state指向为其请求同步的接收状态的指针。
[in]bis_sync_req由广播助理为每个子组请求同步的 BIS 索引位字段数组。值为 0 表示请求终止 BIG 同步。
返回
接受时为 0，拒绝时为其他值。

周期广播同步请求
