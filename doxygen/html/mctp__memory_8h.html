◆ mctp_heap_alloc()

void * mctp_heap_alloc ( size_t bytes)

从 MCTP 堆分配内存。

此函数从 MCTP 堆分配内存。返回的内存适合传递给接管该内存所有权的 libmctp 函数。不再需要时，应使用 mctp_heap_free() 释放所分配的内存。

参数
bytes要分配的字节数。
返回
指向所分配内存的指针，分配失败时为 NULL。

◆ mctp_heap_free()

void mctp_heap_free ( void * ptr)

释放从 MCTP 堆分配的内存。

此函数释放先前通过 mctp_heap_alloc() 从 MCTP 堆分配的内存。传给此函数的指针必须由 mctp_heap_alloc() 返回，且尚未被释放。

参数
ptr指向要释放内存的指针。
