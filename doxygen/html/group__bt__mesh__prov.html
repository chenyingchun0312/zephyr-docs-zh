◆ bt_mesh_auth_method_set_input()

int bt_mesh_auth_method_set_input ( bt_mesh_input_action_t action,
uint8_t size )

#include <zephyr/bluetooth/mesh/main.h>

使用输入 OOB 认证。

仅配网器使用。

指示未配网设备使用指定的输入 OOB 认证动作。当使用 BT_MESH_PUSH、 BT_MESH_TWIST 或 BT_MESH_ENTER_NUMBER, the bt_mesh_prov::output_numeric callback is called with a random number that has to be entered on the unprovisioned device.

使用 BT_MESH_ENTER_STRING 时，将以随机字符串调用 bt_mesh_prov::output_string 回调，该字符串需要在未配网设备上输入。

参数
action未配网设备使用的认证动作。
size认证大小。
返回
成功时为零，否则为（负的）错误码。

◆ bt_mesh_auth_method_set_none()

int bt_mesh_auth_method_set_none ( void )

#include <zephyr/bluetooth/mesh/main.h>

不使用 OOB 认证。

仅配网器使用。

配网新设备时不使用任何认证。这是默认行为。

警告
不使用任何认证会使 mesh 网络面临假冒攻击，攻击者可以伪装成未配网设备以获取网络访问权限。强烈建议使用认证。
返回
成功时为零，否则为（负的）错误码。

int bt_mesh_auth_method_set_output ( bt_mesh_output_action_t action,
uint8_t size )

#include <zephyr/bluetooth/mesh/main.h>

使用输出 OOB 认证。

仅配网器使用。

指示未配网设备使用指定的输出 OOB 认证动作。将调用 bt_mesh_prov::input 回调。

使用 BT_MESH_BLINK、 BT_MESH_BEEP、BT_MESH_VIBRATE 或 BT_MESH_DISPLAY_NUMBER 时，应用程序必须调用 bt_mesh_input_numeric with the random number indicated by the unprovisioned device.

使用 BT_MESH_DISPLAY_STRING 时，应用程序必须调用 bt_mesh_input_string with the random string displayed by the unprovisioned device.

参数
action未配网设备使用的认证动作。
size认证大小。
返回
成功时为零，否则为（负的）错误码。

#include <zephyr/bluetooth/mesh/main.h>

使用 PB-Remote 对 Mesh 节点重新配网

重新配网可用于更改另一设备的设备密钥、单播地址和组成数据。重新配网过程使用与普通配网相同的协议，并具有同等的安全性。

重新配网分为三个层级：

  1. 刷新设备密钥
  2. 刷新设备密钥和节点地址。组成数据可能变化，包括元素数量。
  3. 刷新设备密钥和组成数据，适用于目标节点的组成数据因固件更新或类似过程而发生变化的情况。

目标节点通过实例化其组成数据页 128 来表示其组成数据已变化。如果元素数量发生变化，可能还需要移动目标节点的单播地址，以避免地址重叠。

注解
更改目标节点的单播地址需要修改所有直接向目标节点任一模型发布的节点。
参数
cli用于执行配网的远程配网客户端模型
srv用于重新配网的远程配网服务器
addr要分配给远程设备的地址。如果 addr 为 0，将选择最低的可用地址。
comp_change目标节点已表示其组成数据发生变化。注意，如果情况并非如此，目标节点将拒绝该更新。
返回
成功时为零，否则为（负的）错误码。
