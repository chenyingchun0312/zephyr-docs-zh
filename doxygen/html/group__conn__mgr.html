◆ conn_mgr_ignore_iface()

void conn_mgr_ignore_iface ( struct net_if * iface)

#include <zephyr/net/conn_mgr_monitor.h>

将某个 iface 标记为被 conn_mgr 忽略。

忽略某个 iface 会强制 conn_mgr 将其视为未就绪/已断开。

这意味着与该 iface 连接/断开相关的事件不会被触发；若该 iface 在被忽略前已连接，则会按此刻断开触发事件。

参数
iface要被忽略的 iface。

◆ conn_mgr_watch_iface()

void conn_mgr_watch_iface ( struct net_if * iface)

#include <zephyr/net/conn_mgr_monitor.h>

监视（停止忽略）某个 iface。

conn_mgr 将不再被迫将该 iface 视为未就绪/已断开。

与该 iface 连接/断开相关的事件不再被阻塞；若该 iface 在被监视前已连接，则会按此刻连接触发事件。

启动时所有 iface 默认处于被监视状态。

参数
iface不再忽略的 iface。
