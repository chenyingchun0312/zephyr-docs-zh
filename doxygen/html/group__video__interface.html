◆ VIDEO_MIPI_CSI2_DT_USER

#define VIDEO_MIPI_CSI2_DT_USER ( n)

#include <zephyr/drivers/video.h>

值:
(0x30 + (n))

用户定义数据类型生成宏

为自定义或专有格式生成用户定义的数据类型标识符。MIPI CSI-2 规范将数据类型 0x30 到 0x37 保留给用户特定实现。

注解
参数 n 必须在 0-7 范围内才能生成有效的用户定义数据类型
参数
n用户定义类型索引（0-7）
返回
用户定义范围内的数据类型值（0x30-0x37）

设置视频选择区域（裁剪/合成）。

配置视频设备的可选裁剪与合成功能。裁剪首先应用于输入帧，裁剪的结果再应用于合成。合成结果（宽/高）等于传给 video_set_format 函数的格式宽度/高度。

uint8_t video_mipi_data_type ( uint32_t pixfmt)
inlinestatic

#include <zephyr/drivers/video.h>

将像素格式映射为对应的 MIPI 数据类型

只有完全匹配的格式才会映射为对应的 MIPI 数据类型。驱动程序可能希望在调用此函数之前先处理非标准类型。

请注意，虽然大多数接收器将 VIDEO_MIPI_CSI2_DT_YUV422_8 存储为 YUYV，但通过 MIPI 通道发送的实际上是 UYVY 格式。

参数
pixfmt要转换的像素格式
返回值
the如果找到，则为匹配的 MIPI 数据类型
VIDEO_MIPI_CSI2_DT_NULL当该格式没有已知的对应 MIPI 数据类型时
