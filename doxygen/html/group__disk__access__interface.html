◆ disk_access_init()

int disk_access_init ( const char * pdrv)

#include <zephyr/storage/disk_access.h>

执行任何初始化

此调用由使用方在任何 IO 调用之前发起，以便磁盘或后端设备进行初始化。虽然为兼容旧代码仍然支持，但用户应改为调用 disk_access_ioctl with the IOCTL DISK_IOCTL_CTRL_INIT.

磁盘初始化是引用计数的，因此只有第一次成功初始化未初始化（或先前已反初始化）的磁盘时才会真正初始化该磁盘

参数
[in]pdrv磁盘名称
返回
成功时为 0，失败时为负的 errno 错误码

从磁盘读取数据

用于从磁盘读取数据到内存缓冲区的函数。

注意：若磁盘是 NVMe 类型，用户需要确保 data_buf 指针是 4 字节对齐的。

[in]data_buf指向用于存放数据的内存缓冲区的指针。
[in]start_sector读取的起始磁盘扇区
[in]num_sector要读取的磁盘扇区数
