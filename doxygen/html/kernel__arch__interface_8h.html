宏定义

#define ARCH_DATA_PAGE_ACCESSED
 指示自上次清除该值以来该数据页是否被访问过的位。
#define ARCH_DATA_PAGE_DIRTY
 指示该数据页在被淘汰后需要换出的位。
#define ARCH_DATA_PAGE_LOADED
 指示该数据页已加载到物理页帧中的位。
#define ARCH_DATA_PAGE_NOT_MAPPED
 若未设置 ARCH_DATA_PAGE_LOADED，则表示该页完全没有映射。若设置了 ARCH_DATA_PAGE_LOADED，则该位未定义。

详细描述

在架构层实现的内核内部 API。

并非所有架构特定的定义都在这里，公共函数和宏所使用的 API 定义在 include/zephyr/arch/arch_interface.h 中。

对于此处声明原型的所有内联函数，其实现应由 arch/ARCH/include/kernel_arch_func.h 提供。
