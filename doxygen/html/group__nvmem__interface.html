按索引获取 struct nvmem_cell 的静态初始化器。

此宏在给定设备树节点标识符和索引的情况下返回 struct nvmem_cell 的静态初始化器。

设备树片段示例：

mac_eeprom: mac_eeprom@2 {
nvmem-layout {
compatible = "fixed-layout";
#address-cells = <1>;
#size-cells = <1>;
mac_address: mac_address@fa {
reg = <0xfa 0x06>;
#nvmem-cell-cells = <0>;
};
};
};
eth: ethernet {
nvmem-cells = <&mac_address>;
nvmem-cell-names = "mac-address";
};

Example usage:

const struct nvmem_cell cell =
NVMEM_CELL_GET_BY_IDX(DT_NODELABEL(eth), 0);
// Initializes 'cell' to:
// {
// .dev = DEVICE_DT_GET(DT_NODELABEL(mac_eeprom)),
// .offset = 0xfa,
// .size = 6,
// .read_only = false,
// }

int nvmem_cell_read ( const struct nvmem_cell * cell,
void * data,
off_t off,
size_t len )

#include <zephyr/nvmem.h>

从 NVMEM 单元读取数据。

参数
cell要读取的 NVMEM 单元。
[out]data用于存放读取数据的缓冲区。必须至少为 len 字节。
off在单元内开始读取的偏移，以字节为单位。必须小于单元大小。
len要读取的字节数。 off + len must not exceed the cell size.
注意
Available only when the following Kconfig option is enabled: CONFIG_NVMEM.
返回值
-EINVAL偏移或长度参数无效。
-ENODEV控制器设备未就绪。
-ENXIO没有可用的运行时设备 API。
返回
底层设备 API 调用的结果。
