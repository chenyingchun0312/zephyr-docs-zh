◆ spsc_pbuf_alloc()

int spsc_pbuf_alloc ( struct spsc_pbuf * pb,
uint16_t len,
char ** buf )

在包缓冲区中分配空间。

此函数尝试在包缓冲区中分配 len 字节的连续内存。若分配期间发生回绕，则在缓冲区末尾添加内部填充。除填充外，分配不改变缓冲区的状态，因此若分配后不再需要该包，则无需提交。

所分配的缓冲区必须提交（spsc_pbuf_commit）才能使包可供读取。

包缓冲区确保所分配的缓冲区按 32 位字对齐。

注解
若使用数据缓存，则用户有责任写回新数据。
参数
[in]pb要写入的缓冲区。
[in]len分配长度。必须为正。若小于 SPSC_PBUF_MAX_LEN，则在无法分配所请求长度时会尝试分配尽可能大的空间（其中可能包含添加回绕填充）。若使用 SPSC_PBUF_MAX_LEN，则在尝试分配最大缓冲区时不应用回绕填充。
[out]buf分配成功时写入缓冲区地址的位置。
返回
成功分配的空间量，非负。可以等于或小于 p len。
返回值
-EINVAL若 len 不被允许。

◆ spsc_pbuf_claim()

uint16_t spsc_pbuf_claim ( struct spsc_pbuf * pb,
char ** buf )

从缓冲区取用包。

它按 spsc_pbuf_commit 函数提交的顺序从缓冲区取用单个包。最先提交的包将最先被取用。返回的缓冲区按 32 位字对齐并指向连续内存。取用的包必须使用 spsc_pbuf_free 函数释放。

注解
若使用数据缓存，则对该包执行缓存无效化。
参数
[in]pb要从中取用包的缓冲区。
[in,out]buf写入所取用包地址的位置。地址按 32 位字对齐并指向连续内存。
返回值
0缓冲区中没有包。
返回
正的包长度。

初始化包缓冲区。

此函数在专用内存区域之上初始化包缓冲区。

参数
buf指向用于创建缓冲区的内存区域的指针。使用缓存时，它必须按 Z_SPSC_PBUF_DCACHE_LINE 对齐，否则必须按 32 位字对齐。
blen缓冲区的长度。必须足够大以容纳内部结构和至少两个字节的数据（其中一个保留给已写入消息的长度）。
flags选项标志。参见 SPSC_PBUF_FLAGS。
返回
struct spsc_pbuf* 指向所创建缓冲区的指针。该指针指向与 buf 相同的地址。
返回值
NULL缓冲区对齐无效。

◆ spsc_pbuf_read()

int spsc_pbuf_read ( struct spsc_pbuf * pb,
char * buf,
uint16_t len )

从数据包缓冲区读取指定数量的数据。

单次读取可读取由单次写入发送的消息。提供的 p buf 必须足够大，以存储整条消息。

它将 spsc_pbuf_claim 和 spsc_pbuf_free 合并为一次调用。

参数
pb要从中读取数据的缓冲区。
buf指向读取数据要写入的位置的数据指针。如果为 NULL，则返回所存储消息的长度。
len要从缓冲区读取的字节数。
返回值
int已读取的字节数，失败时为负的错误码。若 buf == NULL，则为要读取的字节数。若消息无法放入所提供的 buf 则为 -ENOMEM。若整个消息尚未就绪则为 -EAGAIN。

将指定数量的数据写入数据包缓冲区。

它将 spsc_pbuf_alloc 和 spsc_pbuf_commit 合并为一次调用。

参数
pb要写入的缓冲区。
buf指向要写入缓冲区的数据的指针。
len要写入缓冲区的字节数。必须为正，且小于 SPSC_PBUF_MAX_LEN。
返回值
int已写入的字节数，失败时为负的错误码。若 len == 0 则为 -EINVAL。若 len 大于缓冲区可容纳的量则为 -ENOMEM。
