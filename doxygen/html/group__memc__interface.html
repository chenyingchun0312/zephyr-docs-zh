◆ memc_get_mem_base()

void * memc_get_mem_base ( const struct device * dev)
inlinestatic

#include <zephyr/drivers/memc.h>

获取 MEMC 设备的内存映射基地址。

注解
该函数仅在内核模式下可用（不是系统调用）。返回的指针是内核空间地址，不能直接用于用户空间。可移植访问请使用 memc_read() / memc_write()。
参数
devMEMC device.
返回
指向映射基地址的指针；若未做内存映射或设备未实现 memc API 则为 NULL

◆ memc_read_id()

int memc_read_id ( const struct device * dev,
uint8_t * id,
size_t len )

#include <zephyr/drivers/memc.h>

读取外部内存的 ID。

参数
devMEMC device.
id用于存放 ID 的缓冲区（大小取决于设备，通常为 2-4 字节）。
len要读取的字节数。若设备 ID 更短，驱动返回的字节数可能少于请求的字节数。
返回
成功时为 0，失败时为负的 errno 码。
返回值
-ENOTSUP设备未实现 memc API 或未实现该可选回调时返回。
