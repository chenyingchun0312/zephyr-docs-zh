◆ conn_mgr_if_flag

enum conn_mgr_if_flag

#include <zephyr/net/conn_mgr_connectivity.h>

按接口的连通性标志

枚举值
CONN_MGR_IF_PERSISTENT 

持久

置位时表示绑定到该接口的连通性实现应通过在连接丢失后自动重连来尝试保持连通。

CONN_MGR_IF_NO_AUTO_CONNECT 

不自动连接

置位时，conn_mgr 不会在该接口达到 admin-up 时自动尝试连接它。

CONN_MGR_IF_NO_AUTO_DOWN 

不自动下线

置位时，即使启用了 CONFIG_NET_CONNECTION_MANAGER_AUTO_IF_DOWN，conn_mgr 也不会在该接口停止尝试连接时自动将其置为 admin-down。

函数说明

◆ conn_mgr_if_connect()

int conn_mgr_if_connect ( struct net_if * iface)

#include <zephyr/net/conn_mgr_connectivity.h>

连接接口

若所提供的接口已绑定到某个连通性实现，则发起网络连接/关联。

若接口尚未处于 admin-up，会自动将其置为 admin-up（通过调用 net_if_up）。

Non-Blocking.

参数
iface指向网络接口的指针
返回值
0成功时。
-ESHUTDOWN若接口未处于 admin-up。
-ENOTSUP若接口没有连通性实现。
-EAGAIN若接口没有用于连接的配置信息
返回
否则为实现特定的状态码。

◆ conn_mgr_if_disconnect()

int conn_mgr_if_disconnect ( struct net_if * iface)

#include <zephyr/net/conn_mgr_connectivity.h>

断开接口

若所提供的接口已绑定到某个连通性实现，则将其从网络断开/解除关联，并取消任何待处理的连接/关联尝试。

若接口当前处于 admin-down，则不做任何操作。

参数
iface指向网络接口的指针
返回值
0成功时。
-ENOTSUP若接口没有连通性实现。
返回
否则为实现特定的状态码。

◆ conn_mgr_if_get_opt()

int conn_mgr_if_get_opt ( struct net_if * iface,
int optname,
void * optval,
size_t * optlen )

#include <zephyr/net/conn_mgr_connectivity.h>

获取实现特定的连通性选项。

若所提供的接口已绑定到支持该操作的连通性实现，则获取与该接口相关的实现特定连通性选项。

参数
iface指向网络接口的指针。
optname表示要设置选项的整数值。各值的含义由 conn_mgr_conn_api 的实现决定。某些设置可能由多个接口共享。
optval指向存放所获取值的位置的指针。
optlen指向可用于存放所获取值的目标缓冲区长度的指针（字节）。若可用空间小于所需，则返回 -ENOBUFS。若可用空间无效，则返回 -EINVAL。 
     无论是否返回错误，即使写入了零字节，optlen 也总会被设为写入的总字节数。
返回值
0If successful.
-ENOTSUP若该接口未实现 conn_mgr_if_get_opt。
-ENOBUFS若获取缓冲区过小。
-EINVAL若提供了无效的获取缓冲区长度，或提供了 NULL 的 optval 或 optlen 指针。
-ENOPROTOOPT若 optname 无法识别。
返回
否则为实现特定的错误码。
