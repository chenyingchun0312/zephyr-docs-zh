◆ ssh_client_register_transport_callback()

int ssh_client_register_transport_callback ( struct ssh_transport_conf * conf)

#include <zephyr/net/ssh/client.h>

注册用于获取与服务器连接关联的传输的回调函数。

所注册的回调会针对客户端侧的传输事件被调用。在客户端角色下只会发出以下事件类型：

  • 当服务器接受了所请求的 SSH 服务时，发出 SSH_TRANSPORT_EVENT_SERVICE_ACCEPTED。
  • 当一次认证尝试完成时，发出 SSH_TRANSPORT_EVENT_AUTHENTICATE_RESULT。
  • 当传输被拆除时，发出 SSH_TRANSPORT_EVENT_CLOSED。

回调的返回值被忽略；该回调只是观察者，无法影响传输流程。

参数
conf传输回调的配置数据。该结构在注销之前必须保持有效。
返回
成功时为 0，失败时为负的错误码。

◆ ssh_transport_get_client()

struct ssh_client * ssh_transport_get_client ( struct ssh_transport * transport)

#include <zephyr/net/ssh/client.h>

获取拥有给定传输的 SSH 客户端实例。

在已注册的传输回调内部，这很有用：该回调会针对所有客户端实例的事件全局调用，因此需要确定某个传输属于哪个客户端实例。它只能对从客户端传输回调获得的传输调用。

参数
transport要获取其所属客户端的传输。
返回
指向所属 SSH 客户端实例的指针，如果该传输为 NULL 则为 NULL。
