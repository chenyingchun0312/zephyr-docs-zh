详细描述

BLOB 传输客户端模型的事件处理回调。

所有处理函数都是可选的。

结构体成员变量说明

◆ caps

void(*) bt_mesh_blob_cli_cb::caps(struct bt_mesh_blob_cli *cli, const struct bt_mesh_blob_cli_caps *caps)

能力获取完成回调。

在能力获取过程完成时调用，表示已为给定的目标节点列表确定了一组共同可接受的传输参数。所有兼容的目标节点状态码均为 BT_MESH_BLOB_SUCCESS。

参数
cliBLOB 传输客户端实例。
caps如果至少一个目标节点的传输能力满足了客户端，则为安全的传输能力，否则为 NULL。

◆ end

void(*) bt_mesh_blob_cli_cb::end(struct bt_mesh_blob_cli *cli, const struct bt_mesh_blob_xfer *xfer, bool success)

传输结束回调。

在传输结束时调用。

参数
cliBLOB 传输客户端实例。
xfer已完成的传输。
success传输的状态。如果至少一个目标节点接收到了完整的传输，则为 true。

◆ lost_target

void(*) bt_mesh_blob_cli_cb::lost_target(struct bt_mesh_blob_cli *cli, struct bt_mesh_blob_target *target, enum bt_mesh_blob_status reason)

目标节点丢失回调。

当某个目标节点因传输中的某种错误而丢失时调用。在所有目标节点都丢失之前，丢失目标节点对客户端而言不算致命错误。

参数
cliBLOB 传输客户端实例。
target丢失的目标节点。
reason目标节点丢失的原因。

◆ suspended

void(*) bt_mesh_blob_cli_cb::suspended(struct bt_mesh_blob_cli *cli)

传输已挂起。

当因所有目标节点响应超时而使传输挂起时调用。

参数
cliBLOB 传输客户端实例。
