定时器到期函数类型。

定时器的到期函数在每次定时器到期时由系统时钟中断处理程序执行。到期函数是可选的，仅当初始化定时器时提供了该函数才会被调用。

◆ k_timer_stop_t

typedef void(*) k_timer_stop_t(struct k_timer *timer)

#include <zephyr/kernel.h>

定时器停止函数类型。

如果定时器被提前停止，则执行其停止函数。该函数在停止定时器的调用上下文中运行。由于 k_timer_stop() 可以从 ISR 调用，停止函数必须可从中断上下文调用（isr-ok）。

停止函数是可选的，仅当初始化定时器时提供了该函数才会被调用。

参数
timer定时器的地址。

◆ k_timer_cleanup()

int k_timer_cleanup ( struct k_timer * timer)

#include <zephyr/kernel.h>

在释放动态分配的定时器之前对其进行清理。

如果 k_timer 对象是动态分配的，则必须先取消其超时，并等待任何正在执行的到期处理程序完成，才能释放其存储空间——否则该处理程序会解引用已释放的内存。此函数两者都做：它把定时器从超时队列中移除，并等待其他 CPU 上正在执行的处理程序结束。

与 k_timer_stop() 不同，此函数不调用用户的 stop_fn 回调，也不触碰等待队列：如果该函数返回 0，则调用者承担对该存储空间的责任，且该定时器已无其他使用者。

参数
timer定时器的地址。
返回值
0成功时。
-EAGAIN当仍有线程挂起在定时器的等待队列上时（例如通过 k_timer_status_sync()）。

◆ k_timer_start()

void k_timer_start ( struct k_timer * timer,
k_timeout_t duration,
k_timeout_t period )

#include <zephyr/kernel.h>

启动定时器。

此例程启动定时器，并将其状态重置为零。定时器开始按指定的时长和周期值倒计时。

允许尝试启动已在运行的定时器。定时器状态被重置为零，并按新的时长和周期值开始倒计时。

如果 duration 为 K_FOREVER，此例程既不更新指定定时器，也不对其产生其他影响。

参数
timer定时器的地址。
duration定时器的初始时长。
period定时器周期。

◆ k_timer_status_sync()

uint32_t k_timer_status_sync ( struct k_timer * timer)

#include <zephyr/kernel.h>

使线程与定时器到期同步。

此例程阻塞调用线程，直到定时器状态非零（表示自上次检查以来已至少到期一次），或定时器被停止。如果定时器状态已非零，或定时器已停止，调用者不用等待即继续执行。

调用此例程会将定时器状态重置为零。

中断处理程序不得使用此例程，因为不允许它们阻塞。

参数
timer定时器的地址。
返回
定时器状态。

◆ k_timer_stop()

void k_timer_stop ( struct k_timer * timer)
isr-ok

#include <zephyr/kernel.h>

停止定时器。

此例程提前停止正在运行的定时器。定时器的停止函数（如果存在）由调用者调用。

允许尝试停止未在运行的定时器，但对该定时器没有影响。

注解
如果要在 ISR 中调用 k_timer_stop，则停止处理程序必须可从 ISR 调用。
参数
timer定时器的地址。
