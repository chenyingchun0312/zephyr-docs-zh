定义 reset.h:49

reset_dt_spec 的静态初始化器

给定设备树节点标识符、指定复位控制器的属性以及索引，返回 reset_dt_spec 结构体的静态初始化器。

设备树片段示例： 

 n: node {
    resets = <&reset 10>;
 }

用法示例： 

 const struct reset_dt_spec spec = RESET_DT_SPEC_GET_BY_IDX(DT_NODELABEL(n), 0); // 将 'spec' 初始化为： // { // .dev = DEVICE_DT_GET(DT_NODELABEL(reset)), // .id = 10 // }

'reset' 字段仍需检查是否就绪，例如使用 device_is_ready()。除非节点存在、具有给定属性，且该属性如上所示指定了复位控制器的复位线 ID，否则使用该宏是错误的。

参数
node_id设备树节点标识符
idx"resets" 中的逻辑索引
返回
struct reset_dt_spec 的静态初始化器，用于该属性
