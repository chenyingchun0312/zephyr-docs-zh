网络数据包缓冲区描述符 API

注解
该结构体不是线程安全的。在任一时刻，给定的 net_pkt 实例应只由单个线程访问（独占所有权模型）。

网络数据通过 net_buf 结构体在协议栈的不同部分之间传递。
