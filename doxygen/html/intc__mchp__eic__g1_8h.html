◆ eic_mchp_config_interrupt()

int eic_mchp_config_interrupt ( struct eic_config_params * eic_pin_config)

为给定引脚配置并启用 EIC 中断。

此函数为指定引脚配置 EIC 中断，包括设置触发类型、使能输入、按需配置去抖，并更新内部数据结构以反映引脚到 eic 线路的新分配。

参数
eic_pin_config指向 EIC 引脚配置结构的指针。
返回
成功时为 0，失败时为负的错误码：
  • 若该引脚没有可用的 EIC 线路则为 -ENOTSUP。
  • 若该 EIC 线路已被占用则为 -EBUSY。

◆ eic_mchp_disable_interrupt()

int eic_mchp_disable_interrupt ( struct eic_config_params * eic_pin_config)

为给定引脚配置禁用 EIC 中断。

此函数禁用与指定引脚配置关联的 EIC 中断。它会检查该引脚当前是否分配到 EIC 线路，若是则禁用该中断线路，并更新内部数据结构将该线路标记为空闲。

参数
eic_pin_config指向 EIC 引脚配置结构的指针。
返回
成功时为 0，失败时为负的错误码。

◆ eic_mchp_interrupt_pending()

uint32_t eic_mchp_interrupt_pending ( uint8_t port_id)

获取给定端口的挂起 EIC 中断。

此函数检查指定端口中哪些引脚有挂起的 EIC 中断。它返回一个位掩码，每个置位对应一个有挂起中断的引脚。

参数
port_id要检查挂起中断的端口标识符。
返回
表示端口内哪些引脚有挂起中断的位掩码。返回值中每个置位的位对应该引脚编号有挂起中断。
