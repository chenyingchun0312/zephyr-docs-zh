◆ w1_configure()

int w1_configure ( const struct device * dev,
enum w1_settings_type type,
uint32_t value )

#include <zephyr/drivers/w1.h>

配置 1-Wire 主机的参数。

允许的配置参数在 enum w1_settings_type 中定义，但主机设备可能不支持所有类型。

参数
[in]dev指向该驱动实例设备结构的指针。
type指定设置类型的枚举。
value所传设置类型的新值。
返回值
0成功时。
-ENOTSUP主机不支持所提供类型的配置。
-EIO一般输入/输出错误，配置主机设备失败。

◆ w1_reset_bus()

int w1_reset_bus ( const struct device * dev)

#include <zephyr/drivers/w1.h>

复位 1-Wire 总线以让从设备准备好通信。

此例程复位所有 1-Wire 总线从设备，使它们准备好接收命令。连接的从设备在准备好接收数据时会以存在脉冲应答。

如果驱动程序同时支持标准速度和超速，复位例程会根据当前状态发送短复位脉冲或长复位脉冲。速度可通过以下方式更改 w1_configure().

参数
[in]dev指向该驱动实例设备结构的指针。
返回值
0没有从设备以存在脉冲应答。
1至少有一个从设备以存在脉冲应答。
返回
失败时为负的 errno 值。
