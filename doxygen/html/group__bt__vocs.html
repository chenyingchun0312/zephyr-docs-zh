详细描述

音量偏移控制服务（VOCS）

自从
2.6
版本
0.8.0

音量偏移控制服务是辅助服务，因此不应单独使用，而应在其他（主要）服务的上下文中使用。

此 API 同时实现服务器和客户端功能。注意，该 API 抽象掉了音量偏移控制状态中的变更计数器，并会自动处理其任何变化。若已过期，客户端实现会在执行写入请求时自主读取变更计数器值。
