详细描述

适用于不使用 Zephyr 驱动模型、且不把 struct device 与驱动实例关联的驱动。此时改用顶层存储，可为全局或静态作用域。

这通常对中断控制器和定时器驱动很有用。

目前这组宏对 PCIe 设备的支持并不好。对此类设备要么使用 Zephyr 的驱动模型，要么通过调用 device_map() 手动管理内存。

声明 MMIO 信息的顶层存储，全局作用域

它面向不使用 Zephyr 那种把 config/dev_data 链接到 struct device 的驱动模型的驱动。

取而代之，这是驱动 C 文件的顶层声明。此声明的作用域为全局，其他 C 文件可用 DEVICE_MMIO_TOPLEVEL_DECLARE 引用它。

为驱动的 MMIO 区域设置内存

这会执行所需的 MMU 虚拟内存映射，使 DEVICE_MMIO_GET() 能返回该 MMIO 区域合适的线性内存地址。

若目标硬件不需要此类操作，它展开为空。

应在驱动的初始化函数中调用一次。

flags 参数目前用于缓存模式，应为 DEVICE_CACHE_* 宏之一。未使用的位保留以备将来扩展。

参数
name顶层 MMIO 区域的名称
flagsDEVICE_CACHE_* 缓存模式之一
