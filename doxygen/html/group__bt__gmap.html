◆ bt_gmap_discover()

int bt_gmap_discover ( struct bt_conn * conn)

#include <zephyr/bluetooth/audio/gmap.h>

发现远端设备上的游戏服务。

在由 conn 标识的服务器上查找游戏服务的过程。发现过程完成或失败时调用 bt_gmap_cb::discover 回调。发现成功时该回调包含远端设备的信息。

参数
connBluetooth 连接对象。
返回值
-EINVAL若 conn 为 NULL
-EBUSY若已在为 conn 执行发现
-ENOTCONN若 conn 未连接
-ENOEXEC若发现无法发起
0成功时

◆ bt_gmap_set_role()

int bt_gmap_set_role ( enum bt_gmap_role role,
struct bt_gmap_feat features )

#include <zephyr/bluetooth/audio/gmap.h>

动态设置一个或多个游戏音频配置文件角色和特性。

先前注册的值将被覆盖。若角色发生变化，将触发游戏音频服务（GMAS）的服务变更。若仅特性变化，则不会发生服务变更。

参数
role游戏音频配置文件角色。
features各角色的特性。若某个角色不在 role 参数中，则该角色的特性值将被直接忽略。
返回值
-ENOEXEC若服务尚未注册
-EINVAL参数无效时
-EALREADY若 role 和 features 与现有值相同
-ENOENT服务注销失败时
-ECANCELED服务重新注册失败时
0成功时
