详细描述

无连接数据通道回调结构。

此结构用于跟踪无连接数据通道帧。它通过 bt_l2cap_br_connless_register() API 注册。允许注册多个此 bt_l2cap_br_connless_cb 类型的实例，以便应用程序的不同模块都可跟踪无连接数据通道帧。

结构体成员变量说明

◆ psm

uint16_t bt_l2cap_br_connless_cb::psm

注册 PSM。

对于 BR，可能的取值：

PSM 字段长度至少为两个字节。所有 PSM 值中，最高有效字节的最低有效位应等于 0，其他所有字节的最低有效位应等于 1。

0 将通知任何无连接数据通道帧。

0x0001-0x0eff 为标准值，即 Bluetooth SIG 分配的固定值。

0x1000 为动态分配。可由应用程序在注册服务器之前预先设置（但不推荐），或在应用程序给出 0 时由协议栈自动分配。
