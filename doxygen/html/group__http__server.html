◆ http_resource_dynamic_cb_t

typedef int(*) http_resource_dynamic_cb_t(struct http_client_ctx *client, enum http_transaction_status status, const struct http_request_ctx *request_ctx, struct http_response_ctx *response_ctx, void *user_data)

#include <zephyr/net/http/server.h>

接收数据时使用的回调。可在此指定要发送给客户端的数据。

参数
client此客户端连接的 HTTP 上下文信息。
statusHTTP 事务状态，HTTP_SERVER_REQUEST_DATA_MORE 和 HTTP_SERVER_REQUEST_DATA_FINAL 描述请求体的交付进度。HTTP_SERVER_TRANSACTION_ABORTED 和 HTTP_SERVER_TRANSACTION_COMPLETE 是终止通知。
request_ctx请求上下文结构体，包含已接收的 HTTP 请求数据。已捕获的请求头（如果 CONFIG_HTTP_SERVER_CAPTURE_HEADERS is enabled) are only available in the first callback of a request; see http_request_ctx.
response_ctx供应用程序填充响应数据的响应上下文结构体。
user_data用户指定的数据。
返回
0 表示成功，服务器可发送 response_ctx 中提供的任意响应数据。<0 表示出错，关闭连接。

◆ http_resource_websocket_cb_t

typedef int(*) http_resource_websocket_cb_t(int ws_socket, struct http_request_ctx *request_ctx, void *user_data)

#include <zephyr/net/http/server.h>

建立 Websocket 连接时使用的回调。应用程序需要处理与该连接相关的全部功能，例如读写 websocket 数据和关闭连接。

参数
ws_socket用于 Websocket 数据的套接字。
request_ctx与 HTTP 升级请求关联的请求上下文结构体
user_data用户指定的数据。
返回
0 表示接受该连接，HTTP 服务器库将不再处理该套接字上的数据，应用程序需自行负责通过所提供的套接字收发数据。<0 表示出错，关闭连接。

◆ http_server_start()

int http_server_start ( void )

#include <zephyr/net/http/server.h>

启动 HTTP2 服务器。

服务器在后台线程中运行。启动后，服务器将为系统中注册的所有 HTTP 服务创建服务器套接字，并接受客户端连接（参见 HTTP_SERVICE_DEFINE）。

◆ http_server_stop()

int http_server_stop ( void )

#include <zephyr/net/http/server.h>

停止 HTTP2 服务器。

所有服务器套接字都被关闭，服务器线程被挂起。
