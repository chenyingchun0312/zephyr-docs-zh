详细描述

低层 sys_trace_* 钩子层的默认实现。

除 sys_port_trace_* 宏钩子（参见 tracing_hooks.h）之外，内核还调用一小组较低层的 sys_trace_* 钩子，用于调度器/ISR、空闲、系统初始化和用户命名事件。不插桩这些钩子的跟踪格式可以包含此头文件以获得安全的默认实现：

  • sys_trace_isr_* / sys_trace_idle* 解析为 tracing_none.c 中的弱空操作（或 CPU 负载统计）实现，某种格式可用真实定义覆盖它。
  • sys_trace_named_event 和 sys_trace_sys_init_* 成为空操作宏，并由 #ifndef 保护，因此定义了自身实现的格式将胜出。

树内格式（CTF、SystemView 等）自行提供该层，不包含此头文件；它面向通过以下方式选择的树外格式 CONFIG_TRACING_FORMAT_HEADER or CONFIG_TRACING_CUSTOM.
