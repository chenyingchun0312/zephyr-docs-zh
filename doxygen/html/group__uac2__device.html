◆ usbd_uac2_send()

int usbd_uac2_send ( const struct device * dev,
uint8_t terminal,
void * data,
uint16_t size )

#include <zephyr/usb/class/usbd_uac2.h>

向输出终端发送音频数据

数据缓冲区必须充分对齐，并在其他方面适合 UDC 驱动使用。

注解
成功时缓冲区的所有权转移给协议栈；出错时调用方保留缓冲区的所有权。
参数
devUSB 音频 2 设备
terminal链接到 AudioStreaming 接口的输出终端 ID
data包含待发送数据的缓冲区
size要发送的字节数
返回
成功时为 0，出错时为负值
