void fwargs_handler_hook ( const uintptr_t * args,
size_t argc )

处理由架构保存的固件参数。

此钩子由理解该架构固件参数约定的平台相关代码实现。它接收架构在初始化期间保存的固件参数。

此钩子在 BSS 和数据初始化之后、正常内核初始化之前，于主 CPU 上运行。实现不得假定内存转换、设备、分配或调度服务可用。

参数数组仅在调用期间有效。请复制后续需要的任何值。这些值所引用内存的生命周期取决于平台的启动协议。
