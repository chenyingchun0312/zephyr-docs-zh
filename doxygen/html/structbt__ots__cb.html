◆ obj_cal_checksum

int(*) bt_ots_cb::obj_cal_checksum(struct bt_ots *ots, struct bt_conn *conn, uint64_t id, off_t offset, size_t len, void **data)

对象计算校验和回调

在执行 OACP 计算校验和过程时调用此回调。由于对象数据对 OTS 不透明，只有应用程序知道数据所在位置，应返回实际对象数据的指针。

参数
[in]otsOTS instance.
[in]conn写入对象的连接。
[in]id对象 ID。
[in]offset需要计算的对象内容的起始八位组。
[in]len对象名称的八位组长度。
[out]data实际对象数据的指针。
返回
0 表示接受，任何负值表示拒绝。

◆ obj_created

int(*) bt_ots_cb::obj_created(struct bt_ots *ots, struct bt_conn *conn, uint64_t id, const struct bt_ots_obj_add_param *add_param, struct bt_ots_obj_created_desc *created_desc)

对象已创建回调

每当创建新对象时调用此回调。当应用程序没有保存此新对象所需的资源时，可以通过返回错误来拒绝该请求。当服务器使用 bt_ots_obj_add() API 创建新对象时也会触发此回调。

参数
otsOTS instance.
conn请求创建对象的连接；如果对象由 bt_ots_obj_add() 创建则为 NULL。
id对象 ID。
add_param对象创建请求的参数。
created_desc已创建对象的描述符，应由此回调的接收者填充。
返回
成功时为 0，出错时为负值。
如果对象类型不受支持则为 -ENOTSUP
-ENOMEM 如果没有可用空间容纳新对象。
如果提供了无效参数则为 -EINVAL
其他负值被视为一般操作失败

◆ obj_deleted

int(*) bt_ots_cb::obj_deleted(struct bt_ots *ots, struct bt_conn *conn, uint64_t id)

对象已删除回调

每当对象被删除时调用此回调。当服务器使用 bt_ots_obj_delete() API 删除对象时也会触发。

参数
otsOTS instance.
conn删除该对象的连接；如果此请求来自服务器则为 NULL。
id对象 ID。
返回值
When使用负值表示错误，此时对象删除过程被中止，并向客户端返回相应的失败状态。
返回
成功时为 0。
如果对象被锁定则为 -EBUSY。这通常不应由应用程序返回，因为 OTS 层会跟踪对象访问。会向客户端返回对象锁定状态。
出错时为其他负值。会向客户端返回一般操作失败状态。

◆ obj_read

ssize_t(*) bt_ots_cb::obj_read(struct bt_ots *ots, struct bt_conn *conn, uint64_t id, void **data, size_t len, off_t offset)

对象读回调

在对象读操作期间会多次调用此回调。OTS 模块将持续向应用程序请求后续对象片段，直到读操作完成。读操作结束由 data 参数为 NULL 表示。

参数
otsOTS instance.
conn读取对象的连接。
id对象 ID。
data输入：读操作完成后为 NULL。输出：要发送的下一块数据。
len客户端请求的剩余长度。
offset对象数据偏移。
返回
要通过 data 参数发送的数据长度。此值应小于或等于 len 参数。
出错时为负值。

◆ obj_write

ssize_t(*) bt_ots_cb::obj_write(struct bt_ots *ots, struct bt_conn *conn, uint64_t id, const void *data, size_t len, off_t offset, size_t rem)

对象写回调

在对象写操作期间会多次调用此回调。OTS 模块将持续向应用程序提供后续对象片段，直到写操作完成。OTS 模块会校验每个写片段的偏移和长度处于对象的已分配大小范围内。remaining length 表示剩余待写入的数据长度，并在每次写入迭代中递减，直到最后一个写片段时变为 0。

参数
otsOTS instance.
conn写入对象的连接。
id对象 ID。
data要写入的下一块数据。
len缓冲区中当前数据块的长度。
offset对象数据偏移。
rem写操作中的剩余长度。
返回
成功时返回已写入的字节数；如果已写入字节数与 len 不一致，则向 L2CAP 层返回 -EIO。
出错时为负值。
-EINPROGRESS 具有特殊含义，目前不受支持。不应返回它。
