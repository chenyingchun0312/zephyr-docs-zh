int mfd_npm2100_hibernate ( const struct device * dev,
uint32_t time_ms,
bool pass_through )

#include <zephyr/drivers/mfd/npm2100.h>

npm2100 休眠

进入低功耗状态，并在指定时间或 "shphld" 引脚信号后唤醒。当电池电压足够高、可直接为 PMIC 供电而无需升压时，可使用直通模式。这会降低休眠模式激活时 PMIC 的功耗。

参数
devnpm2100 mfd 设备
time_ms定时器值，单位为 ms。设为 0 可禁用定时器。
pass_through设为使用直通休眠模式。
返回
成功时返回 0，失败时返回负 errno 值（参见 i2c_write_dt()）。
返回值
-EINVAL时间值过大。
-EBUSY定时器已在使用中。
