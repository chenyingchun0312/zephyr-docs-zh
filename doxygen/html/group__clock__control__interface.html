#include <zephyr/drivers/clock_control.h>

请求启动时钟，并在时钟启动后通知。

该函数是非阻塞的，可从任何上下文调用。时钟启动时会调用用户回调。

参数
devDevice.
sys指向表示该子系统的抽象数据的指针。
cbCallback.
user_data传递给回调的用户上下文。
返回值
0若启动已成功发起。
-EALREADY若时钟已启动并正在启动或运行。
-ENOTSUP若请求的操作模式不受支持。
-ENOSYS若该接口未实现。
<0厂商特定错误时为其他负的 errno。

◆ clock_control_configure()

int clock_control_configure ( const struct device * dev,
clock_control_subsys_t sys,
void * data )
inlinestatic

#include <zephyr/drivers/clock_control.h>

配置源时钟

该函数是非阻塞的，可从任何上下文调用。成功时，所选时钟会按调用方的请求进行配置。

调用方有责任确保后续对该 API 的调用提供正确的信息，以便 clock_control 驱动执行正确的操作（例如在 clock_control_get_rate 调用中使用正确的时钟源）。

data is implementation specific and could be used to convey supplementary information required for expected clock configuration.

参数
dev其驱动控制该时钟的设备结构体
sys表示该时钟的抽象数据
data为时钟配置提供附加输入的抽象数据
返回值
0成功时
-ENOSYS若设备驱动未实现该调用
-errno失败时为其他负的 errno。
