◆ transport_descriptor_cb

typedef int(*) transport_descriptor_cb(uint32_t descriptor)

#include <zephyr/lorawan/lorawan.h>

定义用户描述符回调处理函数签名。

此回调的使用是可选的。启用分片数据块传输时，应用程序将通过 FragSessionSetupReq 命令中携带的 descriptor 字段获得通知。

参数
descriptorFragSessionSetupReq 命令中给出的描述符值。

描述符的含义取决于应用。当使用二进制映像执行 FUOTA 时，它可能表示所传输固件的版本。

返回
成功时为 0。在描述符为固件版本的情况下，这表示终端设备能够接收二进制固件。否则为负的错误码（errno.h），表示失败原因。任何负的错误码都会导致向网络服务器发送 FragSessionSetupAns 时设置 Wrong Descriptor 状态位掩码。

◆ lorawan_clock_sync_get()

int lorawan_clock_sync_get ( uint32_t * gps_time)

#include <zephyr/lorawan/lorawan.h>

获取当前已同步的时间

此函数使用 GPS 纪元格式，这与所有 LoRaWAN 服务中使用的格式相同。

GPS 纪元从 1980-01-06T00:00:00Z 开始，但此后与 UTC 产生了偏差，因为它不考虑闰秒之类的修正。

注意
Available only when the following Kconfig option is enabled: CONFIG_LORAWAN_APP_CLOCK_SYNC.
参数
gps_time以 GPS 纪元格式表示并截断为 32 位的同步时间。
返回
成功时返回 0，时钟尚未同步时返回 -EAGAIN。

◆ lorawan_clock_sync_run()

int lorawan_clock_sync_run ( void )

#include <zephyr/lorawan/lorawan.h>

运行应用层时钟同步服务

该服务按固定间隔（可通过 Kconfig 配置，使用 CONFIG_LORAWAN_APP_CLOCK_SYNC_PERIODICITY）发出当前时间，并在时钟偏差被认为过大时从应用服务器接收校正偏移量。

时钟同步是组播会话固件升级所必需的，但也可以独立于 FUOTA 过程使用。

注意
Available only when the following Kconfig option is enabled: CONFIG_LORAWAN_APP_CLOCK_SYNC.
返回
成功时返回 0，否则返回负的 errno。

◆ lorawan_enable_adr()

void lorawan_enable_adr ( bool enable)

#include <zephyr/lorawan/lorawan.h>

启用自适应数据速率（ADR）

控制是否启用自适应数据速率（ADR）。启用 ADR 时，数据速率被视为默认数据速率，在 ADR 算法尚未确定数据速率时会使用它。通常只应为射频条件稳定的设备（例如位于基本静止位置的设备）启用 ADR。

启用 ADR 不会重置当前数据速率；先前通过 lorawan_set_datarate() 设置的值会继续使用，直到网络通过 LinkADRReq 对其进行调整。

此函数必须在 lorawan_start() 之后调用。在启动之前调用将被忽略。

参数
enable启用或禁用自适应数据速率。

◆ lorawan_set_channels_mask()

int lorawan_set_channels_mask ( uint16_t * channels_mask,
size_t channels_mask_size )

#include <zephyr/lorawan/lorawan.h>

设置信道掩码。

更改默认信道掩码。如果掩码未更改，则所有信道都可用于数据传输。某些网络服务器并不使用所有信道，在这种情况下必须提供信道掩码。

此函数必须在 lorawan_start() 之后、区域信道计划初始化完成后调用。如果在 lorawan_join() 之前调用，该掩码将用于入网信道选择。Join-Accept 的 CFList 处理或之后的 LinkADRReq 命令可能会在入网后更新信道状态。

参数
channels_mask包含要使用的信道掩码的缓冲区。
channels_mask_size信道掩码缓冲区的大小。
返回值
0成功
-EPERMLoRaWAN 协议栈尚未启动
-EINVAL信道掩码或信道掩码大小错误
