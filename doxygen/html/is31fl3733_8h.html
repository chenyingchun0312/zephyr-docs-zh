熄灭 IS31FL3733 LED 显示。

设置 blank_en 后，LED 显示将被禁用。可用于无闪烁的显示更新或省电。

参数
devLED 设备结构
blank_en是否应启用熄灭
返回
成功时为 0，出错时为负值。

int is31fl3733_current_limit ( const struct device * dev,
uint8_t limit )

设置 LED 电流限制

设置 LED 驱动的电流限制。该值与单个 LED 的亮度是分开的，适用于所有 LED。此值按以下公式设置输出电流限制：(840/R_ISET) * (limit/256) 更多细节参见数据手册的表 14。

参数
devLED 设备结构
limit要应用的电流限制
返回
成功时为 0，出错时为负值。
