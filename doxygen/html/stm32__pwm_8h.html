stm32_pwm.h 文件参考

宏定义

输出引脚的自定义 PWM 互补标志。该标志可与任意 <tt>pwm_pin_set_*</tt> API 调用配合使用，以表明 PWM 信号需路由到互补输出通道。该特性仅在部分 SoC 系列上可用，详情请参阅对应绑定的文档。自定义标志位于 pwm_flags_t 的高 8 位 @{
#define STM32_PWM_COMPLEMENTARY   (1U << 8)
 PWM 互补输出引脚已启用
输入捕获预分频器的自定义 PWM 标志。这些标志可与 <tt>pwm_configure_capture</tt> API 调用配合使用，以设置输入捕获预分频器（TIMx_CCMRx 中的 ICxPSC）。大于 1 的预分频器只能与 PWM_CAPTURE_TYPE_PERIOD 一起使用。@{
#define STM32_PWM_CAPTURE_PSC_1   (0U << STM32_PWM_CAPTURE_PSC_POS)

 PWM 输入捕获预分频器设为 2
#define STM32_PWM_CAPTURE_PSC_4   (2U << STM32_PWM_CAPTURE_PSC_POS)
 PWM 输入捕获预分频器设为 4
