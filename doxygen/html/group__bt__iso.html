(BIT((x) - 1))
BIT
#define BIT(n)
置位了位位置 n 的无符号整数（在汇编语言中为有符号）。
定义 util_macro.h:40

将 BIS 索引转换为位

BIS 索引从 0x01 开始，因此允许的最低位为 BIT(0)，它表示索引 0x01。例如要同步到 BIS 索引 0x01 和 0x02，位字段值应为 BIT(0) | BIT(1)。一般地，要同步到 BIS 索引 N 应使用 BIT(N - 1)。

◆ bt_iso_remove_data_path()

int bt_iso_remove_data_path ( const struct bt_iso_chan * chan,
uint8_t dir )

#include <zephyr/bluetooth/iso.h>

移除 ISO 信道的 ISO 数据路径

移除由 bt_iso_setup_data_path() 为提供的 dir 配置的 ISO 数据路径。

根据 Bluetooth Core specification 6.0, Vol 4, Part E, Section 7.7.5，外设的 CIS 数据路径由控制器删除，因此外设的 CIS 断开后无需（也无法）移除其数据路径。中心设备的 CIS 数据路径在断开后仍然有效，因此中心设备若不再想使用该 CIS，应在断开时调用 bt_iso_remove_data_path()。使用 bt_iso_cig_terminate() 移除 CIG 时，中心设备创建的所有数据路径都会被移除。

根据 Bluetooth Core specification 6.0, Vol 4, Part E, Section 7.7.65.30，与 ISO 同步接收者 BIG 关联的所有数据路径在 BIG 同步丢失或终止时由控制器移除，因此对于同步接收者，无需（也无法）移除与 BIG 关联的 ISO 信道的数据路径。

根据 Bluetooth Core specification 6.0, Vol 4, Part E, Section 7.8.105，与 ISO 广播者 BIG 关联的所有数据路径在通过 bt_iso_big_terminate() 终止 BIG 时被移除，因此对于广播者，无需（也无法）移除与 BIG 关联的 ISO 信道的数据路径。

参数
chan要为其设置 ISO 数据路径的信道
dir要设置的方向，为 BT_HCI_DATAPATH_DIR_CTLR_TO_HOST 或 BT_HCI_DATAPATH_DIR_HOST_TO_CTLR. For ISO broadcast channels this can only be BT_HCI_DATAPATH_DIR_HOST_TO_CTLR, and for ISO sync receiver channels this can only be BT_HCI_DATAPATH_DIR_CTLR_TO_HOST.
返回值
0成功
-EINVAL参数无效
-ENOBUFS无法分配 HCI 命令缓冲区
-EIO控制器拒绝了该请求，或响应中包含无效数据
