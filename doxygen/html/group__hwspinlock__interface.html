k_spinlock_key_t hw_spin_lock ( const struct device * dev,
uint32_t id )
inlinestatic

#include <zephyr/drivers/hwspinlock.h>

锁定硬件自旋锁

此函数用于锁定硬件自旋锁。若该自旋锁已被另一方锁定，则等待其释放。这在保护多个簇之间共享的资源时很有用。

注解
其目的不是取代常规自旋锁，而是在簇之间保护共享资源。不过，由于我们不想让另一个线程两次获取同一个硬件自旋锁，该锁定机制同时也起到常规自旋锁的作用。

由于它把 Zephyr 常规自旋锁与硬件自旋锁结合使用，因此适用同样的规则。不同的硬件自旋锁可以嵌套。持有锁时锁定另一个（未锁定的）硬件自旋锁是合法的。但是，尝试获取 CPU 已持有的硬件自旋锁会死锁。

释放锁时必须传给 hw_spin_unlock() 的键值。

尝试锁定硬件自旋锁

此函数用于尝试锁定硬件自旋锁。若该自旋锁已被另一个簇锁定，则以 -EBUSY 退出。
