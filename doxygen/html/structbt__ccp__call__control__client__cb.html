用于保存电话承载服务客户端回调的结构体

可通过 bt_tbs_client_register_cb() 注册后使用。

◆ bearer_provider_name

void(*) bt_ccp_call_control_client_cb::bearer_provider_name(struct bt_ccp_call_control_client_bearer *bearer, int err, const char *name, void *user_data)

bt_ccp_call_control_client_read_bearer_provider_name() 的回调函数。

读取承载提供方名称的过程完成后调用此回调。

参数
bearer呼叫控制客户端承载指针。
err错误值。成功时为 0，正值时为 GATT 错误，负值时为 errno。
name承载提供方名称。若 err 不为 0 则为 NULL。若在返回后使用，必须复制该值。
user_data存放在回调结构体中的用户数据。以下情况下始终为 NULL CONFIG_BT_CCP_CALL_CONTROL_CLIENT_CB_USER_DATA is not enabled.
