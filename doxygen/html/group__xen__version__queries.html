◆ xen_version()

int xen_version ( void )

#include <zephyr/xen/version.h>

获取以主版本号和次版本号编码的 Xen 版本。

返回的整数使用 XENVER_version 所定义的 Xen major:minor 编码。

返回
成功时为编码后的 Xen 版本，失败时为负的 errno 值。
