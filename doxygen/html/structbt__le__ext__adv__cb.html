详细描述

用于通知广播者活动的回调结构体。

bt_le_ext_adv_cb 结构体包含的回调函数会在与广播集相关的各类事件发生时被调用。这些事件包括：

  • 广播数据传输完成
  • 接受新连接
  • 扫描响应数据的发送
  • 若启用了隐私功能：
    • 广播集有效期到期
  • 若启用了 PAwR（带响应的周期性广播）：
    • 已准备好发送一个或多个 PAwR 子事件，即 LE 周期性广播子事件数据请求事件
    • 已收到已同步设备对周期性广播子事件指示的响应，即 LE 周期性广播响应报告事件
注解
在广播集的存活期内必须指向有效内存。
用于 bt_le_ext_adv_create。
这些回调在线程上下文中调用，绝不会在 ISR 中调用。回调是由协议栈内部上下文调用，还是由触发它的 API 调用同步调用，以及来自哪个上下文，不属于 API 的一部分，且可能随版本变化。参见 Callback execution contexts for the hazards of blocking in a callback and their mitigations.

◆ pawr_response

void(*) bt_le_ext_adv_cb::pawr_response(struct bt_le_ext_adv *adv, struct bt_le_per_adv_response_info *info, struct net_buf_simple *buf)

控制器指示一个或多个已同步设备已对周期性广播子事件指示作出响应。

响应可能分散在多个控制器报告中。当 CONFIG_BT_PER_ADV_RSP_REASSEMBLY is enabled, the host reassembles the fragments and delivers the complete response in a single callback. If it is disabled, partial reports are discarded and only reports already marked as "complete" by the controller are forwarded to the application.

参数
adv广播集对象。
info有关所收到响应的信息。
buf收到的数据。若控制器报告未收到任何响应，则为 NULL。
注意
Available only when the following Kconfig option is enabled: CONFIG_BT_PER_ADV_RSP.

◆ rpa_expired

bool(*) bt_le_ext_adv_cb::rpa_expired(struct bt_le_ext_adv *adv)

广播集的 RPA 有效期已过。

此回调通知应用程序广播集的 RPA 有效期已过。用户可利用此回调将广播负载更新与 RPA 轮换同步，例如在回调中调用 bt_le_ext_adv_set_data。

若启用了 RPA 共享（参见 CONFIG_BT_RPA_SHARING），且同一广播 ID 的任一广播集的此 RPA 到期回调返回 false，则这些广播集将在整个 RPA 轮换期间继续使用旧的 RPA。

参数
adv广播集对象。
返回
为 true 时轮换当前 RPA，为 false 时在下一个轮换周期继续使用它。
