◆ arch_printk_char_out()

int arch_printk_char_out ( int c)

#include <kernel/include/kernel_arch_interface.h>

早期启动控制台输出钩子

此函数的定义是可选的。若实现，则任何 printk() 调用（或使用 CONFIG_LOG_MODE_MINIMAL 且由 printk 支撑的日志调用）默认都会将字符发送给此函数。在主串口或控制台驱动启动之前，它可用于早期启动调试。

这可以在运行时通过 __printk_hook_install() 覆盖。

此函数的默认 __weak 实现什么也不做。
