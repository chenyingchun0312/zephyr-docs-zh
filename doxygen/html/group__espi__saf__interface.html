◆ espi_saf_config()

int espi_saf_config ( const struct device * dev,
const struct espi_saf_cfg * cfg )

#include <zephyr/drivers/espi_saf.h>

配置 eSPI 控制器的操作。

此例程提供覆盖 eSPI 控制器能力的通用接口。

如果此 eSPI 控制器作为从设备，则此处设置的值会在初始化期间通过 eSPI 主设备发出的 GET_CONFIGURATION 命令被发现。

如果此 eSPI 控制器作为主设备，则此处设置的值将由 eSPI 主设备用于确定与 eSPI 从设备的最小公共能力，然后通过 SET_CONFIGURATION 命令发送。

◆ espi_saf_remove_callback()

int espi_saf_remove_callback ( const struct device * dev,
struct espi_callback * callback )
inlinestatic

#include <zephyr/drivers/espi_saf.h>

移除应用回调。

参数
dev指向该驱动实例设备结构的指针。
callback有效的应用回调结构体指针。
返回
成功时为 0，失败时为负的 errno 码。
警告
在回调处理程序内明确允许移除正在运行的回调（即 callback）的注册。尝试移除同一设备上的其他注册可能导致未定义行为，包括未能调用仍注册的回调以及意外调用已移除的回调。

注意：可移除通过 espi_add_callback() 添加的任意多个回调。
