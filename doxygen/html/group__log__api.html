限速日志

限速变体会丢弃重复消息，使频繁命中的调用点不会淹没日志。每个调用点使用原子操作独立限速以保证线程安全，并在恢复日志输出时发出被跳过消息的摘要。普通变体使用默认间隔 LOG_RATELIMIT_INTERVAL_MS; the _RATE variants take an explicit interval.

用于声明日志模块（不注册它）的宏。

被拆分到多个文件的模块必须恰好有一个文件使用 LOG_MODULE_REGISTER() 来创建模块特定状态并向日志记录器核心注册模块。

模块中的其他文件应改用此宏来声明同一状态。（否则，LOG_INF() 等将无法引用模块特定的状态变量。）

该宏接受一个或两个参数：

  • 模块名称
  • 可选的日志级别。如果未提供，则文件中使用默认日志级别。

用法示例：

  • LOG_MODULE_DECLARE(foo, CONFIG_FOO_LOG_LEVEL)
  • LOG_MODULE_DECLARE(foo)
注解
仅当当前源文件的 LOG_LEVEL 非零，或者未定义它且 CONFIG_LOG_DEFAULT_LEVEL 非零时，才会声明模块状态。在其他情况下，此宏不起作用。
