uint16_t w1_crc16 ( const uint16_t seed,
const uint8_t * src,
const size_t len )
inlinestatic

#include <zephyr/drivers/w1.h>

计算 CRC 16 的 1-Wire 变体

16 位 1-Wire CRC 变体使用反射多项式函数 X^16 + X^15 * + X^2 + 1，初始值设为 0x0000。另请参见应用笔记 27：“UNDERSTANDING AND USING CYCLIC REDUNDANCY CHECKS WITH MAXIM 1-WIRE AND IBUTTON PRODUCTS” https://www.analog.com/en/resources/technical-articles/understanding-and-using-cyclic-redundancy-checks-with-maxim-1wire-and-ibutton-products.html

参数
seedCRC 的初始值，通常设为 0x0000。
[in]src用于计算的输入字节。
len输入的长度（字节）。
返回
计算得到的 CRC16 值。

◆ w1_match_rom()

int w1_match_rom ( const struct device * dev,
const struct w1_slave_config * config )

#include <zephyr/drivers/w1.h>

通过广播选定的 ROM 来选择特定从设备。

此例程允许 1-Wire 总线主机选择由其唯一 ROM 标识的从设备，使下一条命令只针对这个被选中的从设备。

此命令仅在多点环境中才需要，否则可以发出 Skip ROM 命令。一旦选定了某个从设备，为减少通信开销，可改用 resume 命令而不是此命令来与该选定的从设备通信。

参数
[in]dev指向该驱动实例设备结构的指针。
[in]config指向从设备专用 1-Wire 配置的指针。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENODEV没有从设备响应复位。

◆ w1_search_bus()

int w1_search_bus ( const struct device * dev,
uint8_t command,
uint8_t family,
w1_search_callback_t callback,
void * user_data )

#include <zephyr/drivers/w1.h>

搜索总线上的 1-wire 从设备。

此函数搜索 1-wire 总线上的从设备，可以搜索所有从设备，也可以只搜索处于活动警报状态的从设备。如果传入了回调，则每个找到的从设备都会调用该回调。

该算法主要遵循 https://www.analog.com/en/resources/app-notes/1wire-search-algorithm.html 的建议

注意：不支持按家族过滤。

参数
[in]dev指向该驱动实例设备结构的指针。
command可以是 W1_CMD_SEARCH_ALARM 或 W1_CMD_SEARCH_ROM。
familyW1_SEARCH_ALL_FAMILIES 会搜索所有家族，尚不支持按特定家族过滤。
callback为每个找到的从设备调用的应用回调处理函数。
[in]user_data要传给应用回调处理函数的用户数据。
返回
找到的从设备数量，失败时为负的 errno 值。
