详细描述

从工具发送的消息（响应/通知）

此结构用于将工具执行结果提交回 MCP 服务器。

注解
对于工具响应（MCP_USR_TOOL_RESPONSE）：
  • data 应指向包含工具结果的纯文本字符串。服务器会自动将其包装为单个 MCP TextContent 项。
  • 最大长度为 CONFIG_MCP_TOOL_RESULT_MAX_LEN。
  • 如果工具执行失败，is_error 应设为 true。
  • 示例：.data = "Tool execution result"
