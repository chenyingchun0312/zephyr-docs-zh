◆ hid_int_ep_read()

int hid_int_ep_read ( const struct device * dev,
uint8_t * data,
uint32_t max_data_len,
uint32_t * ret_bytes )

#include <zephyr/usb/class/usb_hid.h>

从 USB HID 中断端点缓冲区读取

弃用
Use USBD HID 设备 API instead.
参数
[in]dev指向 USB HID 设备的指针
[in]data指向数据缓冲区的指针
[in]max_data_len要复制的最大数据长度
[out]ret_bytes要复制的字节数。如果 data 为 NULL 且 max_data_len 为 0，则返回缓冲区中可用的字节数。
返回
成功时为 0，失败时为负的 errno 错误码。
