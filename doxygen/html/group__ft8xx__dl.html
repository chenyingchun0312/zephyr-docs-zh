◆ FT8XX_BEGIN

#define FT8XX_BEGIN ( prim)

#include <zephyr/drivers/misc/ft8xx/ft8xx_dl.h>

值:
(0x1f000000 | ((prim) & 0x0f))

开始绘制图形图元

有效的图元定义如下：

  • FT8XX_BITMAPS
  • FT8XX_POINTS
  • FT8XX_LINES
  • FT8XX_LINE_STRIP
  • FT8XX_EDGE_STRIP_R
  • FT8XX_EDGE_STRIP_L
  • FT8XX_EDGE_STRIP_A
  • FT8XX_EDGE_STRIP_B
  • FT8XX_RECTS

要绘制的图元由 FT8XX_BEGIN 命令选择。图元一经选定，就一直有效，直到 FT8XX_BEGIN 命令选择了新的图元。

注解
图元绘制操作在满足以下条件之前不会执行 FT8XX_VERTEX2II or FT8XX_VERTEX2F is executed.
参数
prim图形图元

◆ FT8XX_CLEAR

值:
(0x26000000 | \
((c) ? 0x04 : 0) | ((s) ? 0x02 : 0) | ((t) ? 0x01 : 0))

将缓冲区清除为预设值

将 c 置为 true 会把 FT8xx 的颜色缓冲区清除为预设值。将该位设为 false 则保持 FT8xx 颜色缓冲区的值不变。预设值由命令 FT8XX_CLEAR_COLOR_RGB for RGB channel and FT8XX_CLEAR_COLOR_A for alpha channel.

将 s 置为 true 会把 FT8xx 的模板缓冲区清除为预设值。将该位设为 false 则保持 FT8xx 模板缓冲区的值不变。预设值由命令 FT8XX_CLEAR_STENCIL 定义。

将 t 置为 true 会把 FT8xx 的标签缓冲区清除为预设值。将该位设为 false 则保持 FT8xx 标签缓冲区的值不变。预设值由命令 FT8XX_CLEAR_TAG 定义。

参数
c清除颜色缓冲区
s清除模板缓冲区
t清除标签缓冲区

◆ FT8XX_LINE_WIDTH

#define FT8XX_LINE_WIDTH ( width)

#include <zephyr/drivers/misc/ft8xx/ft8xx_dl.h>

值:
(0x0e000000 | ((uint32_t)(width) & 0xfff))

指定使用图元 FT8XX_LINES 绘制的线条宽度

设置所绘制线条的宽度。宽度是指从线条中心到最外侧绘制像素的距离，单位为 1/16 像素。以 1/16 像素为单位时，有效范围是 16 到 4095。

注解
FT8XX_LINE_WIDTH 命令会影响 FT8XX_LINES， FT8XX_LINE_STRIP, FT8XX_RECTS, FT8XX_EDGE_STRIP_A /B/R/L primitives.
参数
width线宽，单位为 1/16 像素

为后续的图形对象附加标签值。

FT8xx 标签缓冲区的初始值由命令 FT8XX_CLEAR_TAG 指定，并由命令 FT8XX_CLEAR 生效。FT8XX_TAG 命令可指定在图形对象绘制到屏幕时应用于这些对象的 FT8xx 标签缓冲区值。除非使用 FT8XX_TAG_MASK 命令禁用，否则该标签值会赋给之后的所有对象。后续图形对象一旦绘制完成，就成功附上了该标签值。当附有该标签值的图形对象被触摸时，寄存器 FT800_REG_TOUCH_TAG or FT810_REG_TOUCH_TAG will be updated with the tag value of the graphics object being touched. If there is no FT8XX_TAG commands in one display list, all the graphics objects rendered by the display list will report tag value as 255 in FT800_REG_TOUCH_TAG or FT810_REG_TOUCH_TAG when they were touched.

参数
s标签值 1-255

在指定坐标处开始图形图元的操作

坐标范围以 1/16 像素为单位，从 -16384 到 +16383。负的 x 坐标值表示 (0, 0) 左侧虚拟屏幕中的坐标，负的 y 坐标值表示 (0, 0) 上方虚拟屏幕中的坐标。在负坐标位置绘制时，绘制操作不可见。

参数
x以 1/16 像素精度表示的有符号 x 坐标
y以 1/16 像素精度表示的有符号 y 坐标

在指定坐标处开始图形图元的操作

handle 的有效范围是 0 到 31。16 到 31 的位图句柄专用于 FT8xx 内置字体。

单元格编号是位图布局和格式相同的位图索引。例如，对于句柄 31，单元格 65 表示最大内置字体中的字符 "A"。

参数
x以像素为单位的 x 坐标，从 0 到 511
y以像素为单位的 y 坐标，从 0 到 511
handle位图句柄
cell单元格编号
