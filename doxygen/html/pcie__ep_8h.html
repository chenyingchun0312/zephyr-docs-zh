◆ pcie_ep_dma_xfer()

int pcie_ep_dma_xfer ( const struct device * dev,
uint64_t mapped_addr,
uintptr_t local_addr,
uint32_t size,
const enum xfer_direction dir )
inlinestatic

在映射的 Host 内存与设备内存之间使用“系统 DMA”进行数据传输。使用“系统 DMA”一词是为了说明这里不是专用的“PCIe DMA”，而是不能直接理解 PCIe 地址、使用映射的 Host 内存的 DMA。

如果 EP 设备中有可用的 DMA 控制器，可使用此 API 在映射的 Host 内存（即出站内存）与 EP 设备本地内存之间以 DMA 完成数据传输。

参数
dev驱动实例的设备结构体指针
mapped_addr映射的 Host 内存地址
local_addr设备内存地址
sizeDMA 传输长度（字节）
dirDMA 传输方向
返回
如果成功则为 0，失败时为负的 errno 码。

◆ pcie_ep_map_addr()

int pcie_ep_map_addr ( const struct device * dev,
uint64_t pcie_addr,
uint64_t * mapped_addr,
uint32_t size,
enum pcie_ob_mem_type ob_mem_type )
inlinestatic

将 Host 内存缓冲区映射到 PCIe 出站区域

此 API 将 Host 内存缓冲区映射到 PCIe 出站区域。若 SoC 支持，由 EP 驱动通过多个 PCIe 出站区域管理多重映射。

参数
dev驱动实例的设备结构体指针
pcie_addr要映射的 Host 内存缓冲区地址
mapped_addr映射的 PCIe 出站区域地址
sizeHost 内存缓冲区大小（字节）
ob_mem_type提示是否必须使用 lowmem/highmem 出站区域；当总线主控无法生成超过 32 位的地址时很有用，此时必须使用 lowmem 出站区域。
返回
映射大小：如果映射大小小于请求大小，则请求方在数据传输完成后需再次调用同一 API 来映射尚未映射的 Host 缓冲区。这种情况可能因映射对齐要求而出现。
失败时为负的 errno 错误码。

local_addr本地内存缓冲区地址
size数据传输大小（字节）
ob_mem_type提示是否必须使用 lowmem/highmem 出站区域（PCIE_OB_LOWMEM / PCIE_OB_HIGHMEM / PCIE_OB_ANYMEM）
dir数据传输方向（HOST_TO_DEVICE / DEVICE_TO_HOST）
返回
如果成功则为 0，失败时为负的 errno 码。
