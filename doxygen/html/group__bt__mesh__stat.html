◆ bt_mesh_stat_lpn_timing_get()

int bt_mesh_stat_lpn_timing_get ( struct bt_mesh_lpn_timing * timing)

#include <zephyr/bluetooth/mesh/statistic.h>

获取测得的 LPN Friendship 轮询时序。

返回根据时间戳得出的实际 ReceiveDelay 和 ReceiveWindow 的空中测量值。时间戳在轮询发送完成、启用扫描器和收到响应时使用 k_uptime_get() 捕获。

参数
timing指向要填充的结构体的指针。
返回值
0Success.
-ENOTSUP未启用 LPN 或统计功能。
-EINVALNULL pointer.
