◆ flash_img_buffered_write()

int flash_img_buffered_write ( struct flash_img_context * ctx,
const uint8_t * data,
size_t len,
bool flush )

#include <zephyr/dfu/flash_img.h>

处理要写入镜像 slot 1 Flash 存储器的输入缓冲区，以单个块为单位。剩余的字节会在多次调用之间保留。

以 flush 设为 true 最后一次调用该函数时，会将剩余的块缓冲区写入 Flash。由于 Flash 以块为单位写入，从最后写入的字节到 CONFIG_IMG_BLOCK_BUF_SIZE 的下一个整数倍之间的 Flash 内容会用 0xff 填充。

参数
ctx上下文
data要写入的数据
len要写入的字节数
flush为 true 时强制将所有缓冲的数据写入 Flash
返回
成功时为 0，失败时为负的 errno 错误码

int flash_img_check ( struct flash_img_context * ctx,

#include <zephyr/dfu/flash_img.h>

校验 Flash 区域中 length 字节的 Flash 存储器完整性。起始点由 offset 值指示。

该函数通过 CONFIG_IMG_ENABLE_IMAGE_CHECK Kconfig 选项启用。

参数

[in]ficFlash 镜像校验数据。
[in]area_id应校验镜像的分区的 Flash 区域 ID。
返回
成功时为 0，失败时为负的 errno 错误码
