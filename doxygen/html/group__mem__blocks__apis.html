◆ sys_multi_mem_blocks_choice_fn_t

typedef sys_mem_blocks_t *(*) sys_multi_mem_blocks_choice_fn_t(struct sys_multi_mem_blocks *group, void *cfg)

#include <zephyr/sys/mem_blocks.h>

多内存块分配器的选择函数

这是用户提供的函数，其职责是根据不透明的 cfg 值选择特定的内存块分配器，该值由用户作为 sys_multi_mem_blocks_alloc() 的参数指定。回调返回指向所选分配器的指针，分配将在其中执行。

可能返回 NULL，此时分配将失败并向调用代码报告 -EINVAL。

参数
group多内存块分配器结构。
cfg用户提供的不透明值。应用程序可以任意方式解释它。
返回
指向所选分配器的指针，若未选择则为 NULL。

int sys_multi_mem_blocks_alloc ( sys_multi_mem_blocks_t * group,
void * cfg,
size_t count,
void ** out_blocks,
size_t * blk_size )

#include <zephyr/sys/mem_blocks.h>

从多内存块分配器组分配内存

与 sys_mem_blocks_alloc() 一样，分配多个内存块。它接收传给选择函数的不透明配置指针，集成代码用它来选择分配器。

参数
[in]group多内存块分配器结构。
[in]cfg不透明配置参数，与 sys_multi_mem_blocks_choice_fn_t 相同
[in]count要分配的块数量
[out]out_blocks由内存块指针填充的输出数组。它必须至少有 count elements.
[out]blk_size若不为 NULL，则输出所选分配器的块大小。
返回值
0成功
-EINVAL提供的参数无效，或未选择分配器。
-ENOMEM没有足够的块可供分配。
