◆ bt_ccm_decrypt()

int bt_ccm_decrypt ( const uint8_t key[16],
uint8_t nonce[13],
const uint8_t * enc_data,
size_t len,
const uint8_t * aad,
size_t aad_len,
uint8_t * plaintext,
size_t mic_size )

#include <zephyr/bluetooth/crypto.h>

使用 AES-CCM 解密大端数据。

按 https://tools.ietf.org/html/rfc3610 的描述，使用 AES-CCM 对 enc_data 进行解密和认证。

假定 MIC 紧跟在加密数据之后。

参数
key128 位 MS byte first 密钥
nonce13 字节 MS byte first 的 nonce
enc_data加密数据
len加密数据的长度
aad附加认证数据
aad_len附加认证数据的长度
plaintext用于存放结果的明文缓冲区
mic_size尾部 MIC 的大小（字节）
返回值
0已成功解密数据。
-EINVAL参数无效。
-EBADMSG认证失败。

#include <zephyr/bluetooth/crypto.h>

使用 AES-CCM 加密大端数据。

按 https://tools.ietf.org/html/rfc3610 的描述，使用 AES-CCM 对 plaintext 进行加密并生成 MIC。

将 MIC 紧接在加密数据之后放置。

参数
key128 位 MS byte first 密钥
nonce13 字节 MS byte first 的 nonce
plaintext要加密的明文缓冲区
len加密数据的长度
aad附加认证数据
aad_len附加认证数据的长度
enc_data用于存放加密数据的缓冲区
mic_size尾部 MIC 的大小（字节）
返回值
0已成功加密数据。
-EINVAL参数无效。

uint8_t enc_data[16] )

#include <zephyr/bluetooth/crypto.h>

对大端数据执行 AES 加密。

AES 加密辅助函数，请求 Bluetooth 控制器自身的硬件使用密钥对明文加密并返回加密后的数据。

参数
key用于加密明文的 128 位 MS byte first 密钥
plaintext要加密的 128 位 MS byte first 明文数据块
enc_data128 位 MS byte first 加密数据块
返回
成功时为零，否则为错误码。
