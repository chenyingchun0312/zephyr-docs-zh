用于配置 Renesas RA0 SoC 引脚控制的宏

每个引脚配置由 RA_PSEL() 宏构建，该宏组合了按端口的外设功能选择器、端口号以及该端口内的引脚号。

选择器遵循 RA_PSEL_P<PORT>nPFS_<SIGNAL> 的命名约定，其中 <PORT> 是端口号，<SIGNAL> 是路由到该引脚的外设信号（例如 RA_PSEL_P1nPFS_TXDA0C 在端口 1 上选择 TXDA0C 信号）。信号按外设分组：

  • 定时器阵列单元（TAU）：定时器输入 TI 和输出 TO
  • 串行阵列单元（SAU）在 SPI 模式下：SCK、SI、SO、SSI；在 UART 模式下：TXD、RXD；在简易 I2C 模式下：SCL、SDA IICA: SCLA0, SDAA0, SCLA1, SDAA1
  • UARTA: TXDA0, RXDA0, TXDA1, RXDA1
  • RTC: RTCOUT, RTCOUNTC
  • 时钟输出（CGC）：PCLBUZ0、PCLBUZ1 电容式触摸（CTSU）：TS0 ... TS12、TSCAP JTAG/SWD: SWDIO, SWCLK
#include <zephyr/dt-bindings/pinctrl/renesas/pinctrl-ra0.h>
&pinctrl {
uarta0_default: uarta0_default {
group1 {
psels = <RA_PSEL(RA_PSEL_P1nPFS_TXDA0C, 1, 5)>,
<RA_PSEL(RA_PSEL_P1nPFS_RXDA0C, 1, 6)>;
};
};
};
