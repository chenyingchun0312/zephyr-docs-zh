◆ bt_ead_decrypt()

int bt_ead_decrypt ( const uint8_t session_key[16],
const uint8_t iv[8],
const uint8_t * encrypted_payload,
size_t encrypted_payload_size,
uint8_t * payload )

#include <zephyr/bluetooth/ead.h>

对给定加密广播数据进行解密和认证。

注解
术语 advertising structure 用于描述带有广播类型的广播数据以及两者的长度。
参数
[in]session_key用于加密的 16 字节密钥。
[in]iv用于生成 nonce 的初始化向量。
[in]encrypted_payload收到的加密广播数据。其中应只包含来自所接收广播结构的广播数据，不含长度和类型。
[in]encrypted_payload_size收到的广播数据的大小，单位为字节。应等于所接收广播结构的长度字段减去类型大小（1 字节）。
[out]payload解密后的广播载荷。使用 BT_EAD_DECRYPTED_PAYLOAD_SIZE 获取正确大小。
返回值
0数据已正确解密并认证。
-EIO解密或认证过程中发生错误。
-EINVAL其中一个参数为 NULL 指针，或 encrypted_payload_size 小于 BT_EAD_RANDOMIZER_SIZE + BT_EAD_MIC_SIZE。

◆ bt_ead_encrypt()

int bt_ead_encrypt ( const uint8_t session_key[16],
const uint8_t iv[8],
const uint8_t * payload,
size_t payload_size,
uint8_t * encrypted_payload )

#include <zephyr/bluetooth/ead.h>

对给定广播数据进行加密和认证。

encrypted_payload 中的结果数据形如：

  • 随机化器添加在起始的 BT_EAD_RANDOMIZER_SIZE 个字节中；
  • 添加加密载荷（payload_size 个字节）；
  • MIC 添加在末尾的 BT_EAD_MIC_SIZE 个字节中。
注意
每次 RPA 更新或数据被修改时都必须调用该函数。
注解
术语 advertising structure 用于描述带有广播类型的广播数据以及两者的长度。
参数
[in]session_key用于加密的 BT_EAD_KEY_SIZE 字节密钥。
[in]iv用于生成 nonce 的初始化向量。每次会话密钥变化时都必须更改。
[in]payload要加密的广播数据。可以是多个拼接在一起的广播结构。
[in]payload_size要加密的广播数据的大小。
[out]encrypted_payload包含随机化器和 MIC 的加密广播数据。大小必须至少为 BT_EAD_RANDOMIZER_SIZE + payload_size + BT_EAD_MIC_SIZE。使用 BT_EAD_ENCRYPTED_PAYLOAD_SIZE 获取正确大小。
返回值
0数据已正确加密并认证。
-EIO加密或认证过程中发生错误。
-EINVAL其中一个参数为 NULL 指针。
-ECANCELED随机数生成过程中发生错误。
