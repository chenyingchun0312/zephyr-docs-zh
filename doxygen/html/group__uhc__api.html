◆ uhc_bus_resume()

int uhc_bus_resume ( const struct device * dev)
inlinestatic

#include <zephyr/drivers/usb/uhc.h>

恢复 USB 总线

发出至少 20ms 的恢复信号，并在 USB 总线恢复信号结束时发出 UHC_EVT_RESUMED。此后 SoF 发生器应在 3ms 内启动。

参数
[in]dev指向驱动实例 device 结构体的指针
返回
成功时为 0，所有其他值都应视为错误。
返回值
-EBUSY控制器已在执行总线操作时
