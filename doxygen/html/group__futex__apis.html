int k_futex_wait ( struct k_futex * futex,
int expected,
k_timeout_t timeout )

#include <zephyr/kernel.h>

使当前线程挂起在 futex 上

测试所提供 futex 是否包含期望值，如果是则休眠，直到其他线程对其调用 k_futex_wake()。

参数
futexfutex 的地址。
expectedfutex 的期望值；如果不同，调用者将不会在其上等待。
timeout在 futex 上的等待时段，或特殊值 K_NO_WAIT 或 K_FOREVER 之一。
返回值
-EACCES调用者对 futex 地址没有写权限。
-EAGAIN如果 futex 值与期望参数不匹配。
-ETIMEDOUT线程因超时而非 futex 唤醒而醒来。
0如果调用者曾进入休眠并被唤醒。调用者应在唤醒时检查 futex 的值，以确定是否需要再次阻塞。

◆ k_futex_wake()

int k_futex_wake ( struct k_futex * futex,
bool wake_all )

#include <zephyr/kernel.h>

唤醒挂起在 futex 上的一个/所有线程

唤醒挂起在所提供 futex 上的最高优先级线程，或唤醒挂起在该 futex 上的所有线程，具体行为取决于 wake_all。

参数
futex用于唤醒挂起线程的 futex。
wake_all如果为 true，则唤醒所有挂起线程；如果为 false，则唤醒最高优先级的线程。
返回值
-EACCES调用者无法访问该 futex 地址。
>=0被唤醒的线程数量。
