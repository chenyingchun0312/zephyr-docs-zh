向给定目的地址发送子网桥接 Get 消息

此函数向给定目的地址发送子网桥接 Get 消息，以查询某个子网的子网桥接状态值。子网桥接状态指示子网桥接功能是否已启用。该函数期望从目的节点收到子网桥接 Status 消息作为响应。

将 status 设为 NULL 可以异步方式使用此方法。这样该方法将不等待响应，并在发送命令后立即返回。

参数
net_idx用于为消息加密的网络索引。
addr目标节点地址。
status状态响应参数，返回以下值之一 BT_MESH_BRG_CFG_DISABLED or BT_MESH_BRG_CFG_ENABLED on success.
返回
成功时返回 0，失败时返回（负的）错误码。

用给定参数向给定目的地址发送已桥接子网 Get 消息

此函数用给定参数向给定目的地址发送已桥接子网 Get 消息，以获取该节点所桥接的子网列表。该函数期望从目的节点收到已桥接子网 List 消息作为响应。

将 rsp 设为 NULL 可以异步方式使用此方法。这样该方法将不等待响应，并在发送命令后立即返回。

设置 rsp 时，用户负责为以下内容中的 N 对 NetKey 索引的过滤集合提供缓冲区 bt_mesh_brg_cfg_subnets_list::list. If a buffer is not provided, the bridged subnets won't be copied.

参数
net_idx用于为消息加密的网络索引。
addr目标节点地址。
filter_net_idx过滤条件以及用于过滤的 NetKey 索引
start_idx起始读取偏移，以桥接表状态条目为单位
rsp指向用于存储从服务器收到的响应的结构的指针，为 NULL 表示不等待响应。
返回
成功时返回 0，失败时返回（负的）错误码。

用给定参数向给定目的地址发送桥接表 Get 消息

此函数用给定参数向给定目的地址发送桥接表 Get 消息，以获取桥接表的内容。桥接表包含该节点允许桥接的地址。该函数期望从目的节点收到桥接表 List 消息作为响应。

将 rsp 设为 NULL 可以异步方式使用此方法。这样该方法将不等待响应，并在发送命令后立即返回。

设置 rsp 时，用户负责为以下内容中的 N 对 NetKey 索引的过滤集合提供缓冲区 bt_mesh_brg_cfg_table_list::list. If a buffer is not provided, the bridged addresses won't be copied. If a buffer size is shorter than received list, only those many entries that fit in the buffer will be copied from the list, and rest will be discarded.

参数
net_idx用于为消息加密的网络索引。
addr目标节点地址。
net_idx1第一个子网的 NetKey 索引。
net_idx2第二个子网的 NetKey 索引。
start_idx起始读取偏移，以桥接表状态条目为单位。
rsp指向用于存储从服务器收到的响应的结构的指针，为 NULL 表示不等待响应。
返回
成功时返回 0，失败时返回（负的）错误码。
