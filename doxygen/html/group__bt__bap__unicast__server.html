◆ bt_bap_unicast_server_unregister()

int bt_bap_unicast_server_unregister ( void )

#include <zephyr/bluetooth/audio/bap.h>

注销单播服务器。

注销单播服务器。这将从 GATT 数据库中注销 ASCS。调用此函数前，通过 bt_bap_unicast_server_register_cb() 注册的所有回调都需要用 bt_bap_unicast_server_unregister_cb() 注销。

调用此函数将对任何处于非空闲状态的 ASE 发起释放操作。

返回
成功时为 0，否则为负的错误码。
