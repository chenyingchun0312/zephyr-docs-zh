向已订阅的客户端发送指示。

向所有已订阅客户端发送包含更新后已用时间的指示。当时间因自然推移之外的原因发生变化时（例如手动调整、外部时间同步、DST 变更、时区变更），应调用此函数。

参数

返回值
0成功时。
-ENOTCONN如果没有客户端连接或订阅。
-errno失败时为其他负的 errno。

◆ bt_ets_time_from_unix_ms()

int bt_ets_time_from_unix_ms ( struct bt_ets_elapsed_time * et_time,
int64_t unix_ms,
uint8_t time_src,
int8_t tz_dst_offset )

#include <zephyr/bluetooth/services/ets.h>

将 Unix 毫秒数编码为 ETS 格式的时间。

将 Unix 时间戳（1970-01-01 00:00:00 UTC）转换为 ETS 时间格式。处理 epoch 转换（从 Unix 1970-01-01 到 ETS 2000-01-01）、分辨率缩放，以及基于编译时配置的时区转换。

输入的 unix_ms 始终为 UTC。tz_dst_offset 参数的行为：

  • CONFIG_BT_ETS_SUPPORT_UTC：时间保持为 UTC，不做转换。如果启用了 CONFIG_BT_ETS_SUPPORT_TZ_DST，则存储偏移供客户端使用。
  • CONFIG_BT_ETS_SUPPORT_LOCAL_TIME 与 CONFIG_BT_ETS_SUPPORT_TZ_DST：应用偏移将 UTC 转换为本地时间并存入输出。公式：本地时间 = UTC 时间 + TZ/DST 偏移 × 15 分钟 BT_ETS_FLAG_TZ_DST_USED flag is set in output.

输出 et_time 的标志根据编译时配置设置：

  • 时间模式： CONFIG_BT_ETS_SUPPORT_UTC 或 CONFIG_BT_ETS_SUPPORT_LOCAL_TIME
  • 分辨率：CONFIG_BT_ETS_RESOLUTION_*（1_SEC、100_MS、1_MS 或 100_US）
  • BT_ETS_FLAG_CURRENT_TIMELINE 始终被设置
注意
Available only when the following Kconfig option is enabled: CONFIG_BT_ETS_HELPER_API.
注解
这需要 CONFIG_BT_ETS_SUPPORT_UTC 或 CONFIG_BT_ETS_SUPPORT_TZ_DST to be enabled.
参数
et_time指向要填充的 ETS 时间结构体的指针。
unix_ms自 Unix epoch（1970-01-01 00:00:00 UTC）起的毫秒数，始终为 UTC。
time_src时间同步源类型。（参见 BT_ETS_TIME_SOURCE）
tz_dst_offset相对 UTC 的 TZ/DST 偏移，以 15 分钟为单位（有符号）。如果处于 LOCAL_TIME 模式，则用于 UTC 到本地时间的转换。
返回值
0成功时。
-EINVAL如果 et_time 为 NULL，或转换后的时间早于 ETS epoch（2000-01-01）。
-EOVERFLOW如果转换后的时间值超出 48 位范围。

◆ bt_ets_time_to_unix_ms()

int bt_ets_time_to_unix_ms ( const struct bt_ets_elapsed_time * et_time,
int64_t * unix_ms )

#include <zephyr/bluetooth/services/ets.h>

将 ETS 格式的时间解码为自 Unix epoch 起的毫秒数。

将 ETS 时间格式转换为以 Unix epoch（1970-01-01 00:00:00 UTC）为基准的毫秒数。处理 epoch 转换（ETS 使用 2000-01-01，而 Unix 使用 1970-01-01）、分辨率缩放，以及根据 et_time 中的标志字段进行的时区转换。

输出 unix_ms 始终为 UTC。时区处理取决于标志：

  • CONFIG_BT_ETS_SUPPORT_UTC：时间已是 UTC，无需转换。如果设置了 BT_ETS_FLAG_TZ_DST_USED，该偏移仅供参考。
  • CONFIG_BT_ETS_SUPPORT_LOCAL_TIME 与 CONFIG_BT_ETS_SUPPORT_TZ_DST：如果在 et_time 中设置了 BT_ETS_FLAG_TZ_DST_USED，则通过减去偏移将本地时间转换为 UTC：UTC = 本地时间 - TZ/DST 偏移 × 15 分钟
注意
Available only when the following Kconfig option is enabled: CONFIG_BT_ETS_HELPER_API.
注解
这需要 CONFIG_BT_ETS_SUPPORT_UTC 或 CONFIG_BT_ETS_SUPPORT_TZ_DST to be enabled (proper UTC conversion needs either UTC mode or timezone offset information).
参数
et_time要解码的 ETS 时间格式结构体。
unix_ms指向用于存放自 Unix epoch（1970-01-01 00:00:00 UTC）起毫秒数的指针。
返回值
0成功时。
-EINVAL如果 et_time 或 unix_ms 为 NULL。
-EOVERFLOW如果转换后的时间值在转换期间溢出。
