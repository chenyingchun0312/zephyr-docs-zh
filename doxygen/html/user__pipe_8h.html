◆ modem_at_user_pipe_claim()

int modem_at_user_pipe_claim ( struct modem_chat * chat,
k_timeout_t timeout )

占用 AT 命令用户管道以运行命令

注解
如果底层管道未打开，此函数不会阻塞
在附加聊天实例之前，管道中所有待处理数据都会被排空
参数
chat将与用户管道一起使用的聊天实例
timeout等待其他用户释放管道的最大时长
返回值
0成功时
-EPERM调制解调器未就绪
-EBUSY用户管道已被占用

◆ modem_at_user_pipe_release()

void modem_at_user_pipe_release ( void )

将 AT 命令用户管道释放给其他用户

必须在管道不再使用后、于 modem_at_user_pipe_claim 之后调用。
