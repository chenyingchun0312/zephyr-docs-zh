◆ zms_iter_init_with_config()

int zms_iter_init_with_config ( const struct zms_fs * fs,
struct zms_iter * iter,
const struct zms_iter_config * config )

#include <zephyr/kvss/zms.h>

使用过滤配置初始化 ZMS 迭代器。

将文件系统的当前写入位置捕获为迭代边界。在此调用之后写入或删除的条目不会出现在后续对 zms_iter_next 的调用中。

当 config->use_mask 为真时，仅当 (id & config->mask_id) == id 时才返回条目。当 config->use_range 为真时，仅当条目的 ID 位于闭区间 [config->min_id, config->max_id] 内时才返回条目。当 config->use_predicate 为真时，仅当 config->predicate_func(id) 返回真时才返回条目。

如果任一过滤器被禁用，迭代器会回退到默认值： ZMS_ITER_MASK_ALL for the mask and the full [ZMS_ITER_ID_MIN, ZMS_ITER_ID_MAX] range. Predicate filtering is disabled by default.

注解
在 zms_iter_init_with_config() 与最后一次 zms_iter_next() 调用之间，调用方不得向 fs 写入或从中删除。
参数
fs已挂载的文件系统实例。
iter要初始化的迭代器状态。
config由调用方提供的迭代器配置。
返回值
0Success.
-EINVAL如果 fs、iter 或 config 为 NULL，fs 未挂载， config->predicate_func is NULL while use_predicate is enabled, or the configured range is invalid.

◆ zms_iter_next()

int zms_iter_next ( struct zms_fs * fs,
struct zms_iter * iter,
zms_id_t * id,
size_t * len,
void * data,
size_t data_len )

#include <zephyr/kvss/zms.h>

推进迭代器到下一个有效条目。

从最新到最旧遍历 ATE 环。对每个 ID，只返回最近写入的、未被删除（len > 0）的条目；更旧的历史版本和删除标记会被透明地跳过。

注解
当返回的 len（ATE 中存储的数据长度）不超过 ZMS_DATA_IN_ATE_SIZE 时，条目的数据保存在 ATE 自身内。在这种情况下，且仅在提供了 data 缓冲区时，数据会直接复制到其中（无需额外读取 flash）。最多 data_len bytes are copied, so provide a buffer with data_len greater than or equal to len to receive the complete data. Entries whose len exceeds ZMS_DATA_IN_ATE_SIZE are not copied and must be read with zms_read.
参数
fs已挂载的文件系统实例。
iter迭代器状态（必须使用 zms_iter_init 或 zms_iter_init_with_config).
id成功时（返回值 1）：填充为条目 ID。
len成功时（返回值 1）：填充为所存储数据的长度（字节）。
data可选的调用方分配缓冲区。当非 NULL 且条目的数据直接存储在 ATE 内（其长度不超过 ZMS_DATA_IN_ATE_SIZE）时，该数据会复制到这里（最多 data_len 字节）。未存储在 ATE 内的数据（较大的条目）不会被复制；请使用 zms_read 获取。传入 NULL 以跳过复制。
data_lendata 所指向缓冲区的大小（字节）。当 data 为 NULL 时忽略。
返回值
1找到条目；id 和 len 有效。
0没有更多条目；遍历完成。
-EINVAL如果 fs、iter、id 或 len 为 NULL，或 fs 未挂载。
-EIOFlash 读取错误。
-ENXIO设备错误。

◆ zms_iter_next_all()

int zms_iter_next_all ( struct zms_fs * fs,
struct zms_iter * iter,
zms_id_t * id,
size_t * len,
void * data,
size_t data_len )

#include <zephyr/kvss/zms.h>

推进迭代器到下一个匹配的 ATE。

从最新到最旧遍历 ATE 环，返回所有匹配的 ATE，包括删除标记（len == 0）和更旧的历史版本。

此函数不执行 ID 唯一性过滤。因此，遍历期间同一 ID 可能出现多次。

注解
当返回的 len（ATE 中存储的数据长度）不超过 ZMS_DATA_IN_ATE_SIZE 时，条目的数据保存在 ATE 自身内。在这种情况下，且仅在提供了 data 缓冲区时，数据会直接复制到其中（无需额外读取 flash）。最多 data_len bytes are copied, so provide a buffer with data_len greater than or equal to len to receive the complete data. Entries whose len exceeds ZMS_DATA_IN_ATE_SIZE, and delete markers (len == 0), are not copied; use zms_read for the latest value or zms_read_hist to retrieve older revisions.
参数
fs已挂载的文件系统实例。
iter迭代器状态（必须使用 zms_iter_init 或 zms_iter_init_with_config).
id成功时（返回值 1）：填充为条目 ID。
len成功时（返回值 1）：填充为所存储数据的长度（字节）（0 表示删除标记）。
data可选的调用方分配缓冲区。当非 NULL 且条目的数据直接存储在 ATE 内（其长度不超过 ZMS_DATA_IN_ATE_SIZE）时，该数据会复制到这里（最多 data_len 字节）。未存储在 ATE 内的数据（较大的条目）和删除标记（len == 0）不会被复制；请使用 zms_read 获取所存储的数据。传入 NULL 以跳过复制。
data_lendata 所指向缓冲区的大小（字节）。当 data 为 NULL 时忽略。
返回值
1找到条目；id 和 len 有效。
0没有更多条目；遍历完成。
-EINVAL如果 fs、iter、id 或 len 为 NULL，或 fs 未挂载。
-EIOFlash 读取错误。
-ENXIO设备错误。
