函数说明

◆ nunchuk_read()

int nunchuk_read ( const struct device * dev)

#include <zephyr/input/input_nunchuk.h>

开始从 Nunchuk 读取当前按键状态、操纵杆位置，以及可选的加速度（如果启用了 CONFIG_INPUT_NUNCHUK_ACCELERATION）。

仅当 Nunchuk 输入驱动程序的 DTS 定义中属性 'polling-interval-ms' 设为 0（即禁用后台轮询）时，此函数才有效。

注意，该函数会立即返回，数据在后台从 Nunchuk 读取并通过标准输入事件接口报告。

参数
dev指向 Nunchuk 设备的指针
返回值
SUCCESS如果数据读取过程能够启动。
-errno出现任何错误时。
