◆ setup_cb

void(*) ztest_param_values::setup_cb(void)

可选的单次设置，在分发循环之前调用。

非 NULL 时，在产生第一个值之前，每个参数化测试的分发过程中恰好调用一次。适用于为 PRNG 播种、重置有状态的生成器，或进行其他每次测试运行的初始化。可为 NULL。

使用 ZTEST_DEFINE_PARAM_GENERATOR_WITH_SETUP() 设置此字段。

◆ value_at_cb

void(*) ztest_param_values::value_at_cb(size_t index, void *out)

可选的值生成器，用于范围参数或运行时参数。

非 NULL 时，每次调用都会以从 0 开始的索引和指向至少 elem_size 字节的对齐暂存缓冲区的指针调用一次。回调必须精确写入 elem_size 字节 out. values must be NULL when this callback is provided.

请改用 ZTEST_DEFINE_PARAM_RANGE() 或 ZTEST_DEFINE_PARAM_GENERATOR()，不要直接设置此项。
