详细描述

防火墙所有者变更的请求和响应

参数
fwl_id所涉及的防火墙 ID
region要设置配置信息的区域或通道编号。对于简单防火墙，此字段不使用，必须初始化为零。对于基于区域的防火墙，此字段表示所涉及的区域（索引从 0 开始）。对于基于通道的防火墙，此字段表示所涉及的通道（索引从 0 开始）
n_permission_regs权限寄存器数量 <= 3
control该区域的控制寄存器值
owner_index要更改到的新所有者索引。所有者索引在 DMSC 固件启动配置数据中设置
owner_privid新的所有者 priv-id；如果不知道 owner_index，则用它查找，否则必须设为零
owner_permission_bits新的所有者权限位
