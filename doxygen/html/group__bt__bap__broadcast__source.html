◆ bt_bap_broadcast_source_create()

int bt_bap_broadcast_source_create ( struct bt_bap_broadcast_source_param * param,
struct bt_bap_broadcast_source ** source )

#include <zephyr/bluetooth/audio/bap.h>

创建音频广播源。

创建一个包含一个或多个音频流的音频广播源。

调用后，广播源将对扫描器可见，设备将广播音频通告。

在调用 bt_bap_broadcast_source_start() 之前无法发送音频数据，扫描器也将看不到任何音频信息（BIGInfo）（参见 bt_le_per_adv_sync_cb）。

参数
[in]param指向用于创建广播源的参数的指针。
[out]source指向所创建广播源的指针
返回
成功时为零，否则为（负的）错误码。

◆ bt_bap_broadcast_source_get_base()

int bt_bap_broadcast_source_get_base ( struct bt_bap_broadcast_source * source,
struct net_buf_simple * base_buf )

#include <zephyr/bluetooth/audio/bap.h>

获取广播源的广播音频流端点

这会将广播源的 BASE 编码到缓冲区中，可用于广播。编码后的 BASE 采用小端序。BASE 应放入周期广播数据中（参见 bt_le_per_adv_set_data()）。

结构参见 Basic Audio Profile v1.0.1 中的表 3.15。

参数
source指向广播源的指针。
base_buf指向将插入 BASE 的缓冲区的指针。
返回
成功时为零，否则为（负的）错误码。

◆ bt_bap_broadcast_source_reconfig()

int bt_bap_broadcast_source_reconfig ( struct bt_bap_broadcast_source * source,
struct bt_bap_broadcast_source_param * param )

#include <zephyr/bluetooth/audio/bap.h>

重配置音频广播源。

使用新的编解码器及编解码器服务质量参数重配置音频广播源。只能在广播源停止时执行。

由于这可能修改广播音频源端点（BASE），之后应调用 bt_bap_broadcast_source_get_base() 以获取新的 BASE 信息。

如果 param.params_count 小于广播源中已创建的子组数量，则只更新前 param.params_count 个子组。如果某个子组中存在不属于 param 的流，则该流保持原样（即不会被移除；从广播源移除流的唯一方式是重新创建广播源）。

参数
source指向广播源的指针
param指向用于重配置广播源的参数的指针。
返回
成功时为零，否则为（负的）错误码。
