获取设备的 MMIO 地址

对于大多数微控制器，MMIO 地址可以是构建时已知的固定值，我们可以把它存放在位于 ROM 的 device->config 中。

但有些设备只能在运行时才知道其 MMIO 地址，因为它们需要被内存映射到地址空间、从 PCI 枚举，或两者兼有。

此宏返回驱动 MMIO 区域的线性地址。它适用于只有一个 MMIO 区域的驱动。必须在驱动初始化函数中调用过 device_map()。

它不适用于 PCIe 设备；这类设备必须在运行时探测，你会希望直接调用 device_map()，并使用 DEVICE_MMIO_RAM_PTR() 作为目标虚拟地址位置。

◆ DEVICE_MMIO_RAM

#define DEVICE_MMIO_RAM   mm_reg_t _mmio

#include <zephyr/sys/device_mmio.h>

在设备的 dev_data 结构中声明 MMIO 信息的存储位置。

它由 DEVICE_MMIO_MAP() 和 DEVICE_MMIO_GET() 宏访问。

取决于配置，可能完全不保留内存。它必须是数据结构的第一个成员。

若物理地址在构建时已知，则 config_info 中必须有对应的 DEVICE_MMIO_ROM；若未知（例如 PCIe）则可省略

名为 "foo" 的驱动的示例：

struct foo_driver_data {
DEVICE_MMIO_RAM;
int wibble;
...

◆ DEVICE_MMIO_ROM

#define DEVICE_MMIO_ROM   struct z_device_mmio_rom _mmio

#include <zephyr/sys/device_mmio.h>

在设备的 config 结构中声明 MMIO 数据的存储位置

它由 DEVICE_MMIO_MAP() 和 DEVICE_MMIO_GET() 宏访问。

此处存储的内容因配置不同而差别很大。它必须是 config 结构的第一个成员。data 中必须有对应的 DEVICE_MMIO_RAM。

若设备是 PCIe，则不使用此存储，可以省略。

应在构建时使用来自 DTS 的信息通过 DEVICE_MMIO_ROM_INIT() 初始化它。

可以用 DEVICE_MMIO_ROM_PTR() 获取指向此内存的指针。

名为 "foo" 的驱动的示例：

struct foo_config {
DEVICE_MMIO_ROM;
int baz;
...
