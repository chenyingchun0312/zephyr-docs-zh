◆ cache_data_flush_and_invd_range()

int cache_data_flush_and_invd_range ( void * addr,
size_t size )

#include <zephyr/drivers/cache.h>

刷新并使 d-cache 中的地址范围失效

刷新并使数据缓存中指定的地址范围失效。

注意
Available only when the following Kconfig option is enabled: CONFIG_DCACHE.
注解
缓存操作以缓存行为单位。当多个数据结构共享正在被刷新的同一条缓存行时，共享该行的数据结构的所有部分都会在失效之前被刷新。这通常不是问题，因为回写是非破坏性过程，硬件可能在任何时候触发它，因此对齐的 addr 或补齐的 size 并非严格必要。
参数
addr要刷新并使之失效的起始地址。
size范围大小。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENOTSUPNot supported.

◆ cache_data_invd_range()

int cache_data_invd_range ( void * addr,
size_t size )

#include <zephyr/drivers/cache.h>

使 d-cache 中的地址范围失效

使数据缓存中指定的地址范围失效。

注意
Available only when the following Kconfig option is enabled: CONFIG_DCACHE.
注解
缓存操作以缓存行为单位。当多个数据结构共享正在失效的同一条缓存行时，共享该行的非只读数据结构的所有部分也会失效。这是破坏性过程，可能导致数据丢失和/或被破坏。当 addr 未按缓存行对齐和/或 size 不是缓存行大小的整数倍时，行为未定义。
参数
addr要使之失效的起始地址。
size范围大小。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENOTSUPNot supported.

◆ cache_data_line_size_get()

size_t cache_data_line_size_get ( void )

#include <zephyr/drivers/cache.h>

获取 d-cache 行大小。

此 API 用于在运行时动态检测数据缓存行大小。

仅当定义了 CONFIG_DCACHE_LINE_SIZE_DETECT_SUPPORT 时才必须实现此函数。

注意
Available only when the following Kconfig option is enabled: CONFIG_DCACHE_LINE_SIZE_DETECT_SUPPORT.
返回值
sized-cache 行的大小。
0d-cache 未启用。
