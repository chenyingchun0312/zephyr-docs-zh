◆ log_frontend_stmesp_etr_ready()

int log_frontend_stmesp_etr_ready ( void )

#include <zephyr/logging/log_frontend_stmesp.h>

通知前端 ETR/STM 已就绪。

日志前端可选地转储缓冲的数据，并开始写入 STM 激励端口。

注解
此函数仅适用于执行初始 ETR/STM 设置的域。
返回值
0成功时。
-EIO如果出现内部故障。
