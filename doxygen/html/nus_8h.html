NUS 服务器实例回调注册

此函数注册在与 NUS 相关的特定事件中被调用的回调。

参数
inst指向 NUS 服务实例的指针。如果使用默认实例则为 NULL。
cb指向回调结构体的指针。必须在应用程序的整个生命周期内有效。
ctx通过回调提供的用户上下文。
返回
成功时为 0
如果 cb 为 NULL 则为 -EINVAL

int bt_nus_inst_send ( struct bt_conn * conn,
struct bt_nus_inst * inst,
const void * data,
uint16_t len )

向 NUS 实例发送数据

注解
此 API 将数据发送到指定对端。
参数
conn要向其发送数据的连接对象。如果通知所有对端则为 NULL。
inst指向 NUS 服务实例的指针。如果使用默认实例则为 NULL。
data指向包含要发送字节的缓冲区的指针。
len要发送数据的长度（字节）。
返回
成功时为 0，失败时为负的错误码。
Bluetooth 协议栈尚未启用时为 -EAGAIN。
未建立连接或没有对端订阅时为 -ENOTCONN。
