为给定节点标识符定义所有引脚控制信息。

该工具宏应与设备定义一同调用。它为 node_id 所表示的设备定义并初始化引脚控制配置。每个引脚控制状态（pinctrl-0、...、pinctrl-N）也会被定义并初始化。注意，标记为跳过的状态不会被定义（详见 Z_PINCTRL_SKIP_STATE）。

使用动态引脚控制定义存放在设备树中的替代状态配置时，该宏应与 PINCTRL_DT_STATE_PINS_DEFINE 配合使用。

注意
Available only when the following Kconfig option is enabled: CONFIG_PINCTRL_DYNAMIC.

// board.dts

// uart0_alt_default node contains alternative pin config

// application

static const struct pinctrl_state uart0_alt[] = {
PINCTRL_DT_STATE_INIT(uart0_alt_default, PINCTRL_STATE_DEFAULT)

◆ pinctrl_update_states()

int pinctrl_update_states ( struct pinctrl_dev_config * config,
const struct pinctrl_state * states,
uint8_t state_cnt )

#include <zephyr/drivers/pinctrl.h>

用新的一组状态更新状态。

注解
为保证设备驱动正常工作，必须提供相同的状态。例如，若当前状态列表中有 default 和 sleep，则新的状态数组也应同时包含二者。
注意
Available only when the following Kconfig option is enabled: CONFIG_PINCTRL_DYNAMIC.
参数
config引脚控制配置。
states要设置的新状态。
state_cnt要设置的新状态数量。
返回值
-EINVAL新配置与当前活动配置的状态不一致时返回。
-ENOSYS该功能不可用时返回。
0成功时。
