◆ cp_event_callback_t

typedef int(*) cp_event_callback_t(void *arg, int pd, struct osdp_event *ev)

CP 事件通知的回调。在通过 osdp_cp_set_event_callback 注册后，当 CP 收到来自 PD 的事件时会调用该方法。

参数
arg应用程序在注册回调时提供的不透明指针。
pd此 PD 在 kconfig OSDP_PD_ADDRESS_LIST 中的偏移（从 0 开始计数）
ev指向 osdp_event 结构体的指针（由 libosdp 填充）。
返回值
0成功处理该事件时。
-veon errors.

◆ pd_command_callback_t

typedef int(*) pd_command_callback_t(void *arg, struct osdp_cmd *cmd)

PD 命令通知的回调。在通过 osdp_pd_set_command_callback 注册后，当 PD 收到来自 CP 的命令时会调用该方法。

参数
arg将传给 osdp_pd_set_command_callback 的 arg 参数的指针。
cmd指向所收到命令的指针。
返回值
0如果 LibOSDP 必须发送 osdp_ACK 响应
-ve如果 LibOSDP 必须发送 osdp_NAK 响应
+ve并在 LibOSDP 必须发送特定响应时修改传入的 struct osdp_cmd *cmd。这适用于发送厂商特定的回复 osdp_MFGREP。
