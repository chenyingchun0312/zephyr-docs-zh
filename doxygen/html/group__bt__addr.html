◆ bt_addr_le_rpa_resolve()

int bt_addr_le_rpa_resolve ( uint8_t id,
const bt_addr_le_t * addr,
bt_addr_le_t * resolved_addr )

#include <zephyr/bluetooth/addr.h>

将 Bluetooth LE 可解析私有地址（RPA）解析为其身份地址。

此函数尝试使用主机身份解析密钥（IRK）数据库，将 RPA 解析为对应的身份地址（公共地址或随机静态地址）。

注意
Available only when the following Kconfig option is enabled: CONFIG_BT_PRIVACY.
参数
[in]id使用其 IRK 数据库的本地身份。必须小于 CONFIG_BT_ID_MAX。
[in]addrThe RPA to resolve.
[out]resolved_addr成功时包含解析出的身份地址。该地址将是公共地址（BT_ADDR_LE_PUBLIC）或随机静态地址（ BT_ADDR_LE_RANDOM）。
返回值
0成功。地址已解析。 resolved_addr contains the identity address.
-ENOENTaddr 是一个 RPA，但在数据库中未找到匹配的 IRK。该地址无法解析。
-EINVAL参数无效：addr 或 resolved_addr 为 NULL， id is invalid, or addr is not an RPA.

◆ bt_addr_le_to_str()

int bt_addr_le_to_str ( const bt_addr_le_t * addr,
char * str,
size_t len )
inlinestatic

#include <zephyr/bluetooth/addr.h>

将二进制 LE Bluetooth 地址转换为字符串。

将 LE Bluetooth 地址转换为以下格式的字符串表示：

  • 公共地址为“P:XX:XX:XX:XX:XX:XX”
  • 随机地址为“R:XX:XX:XX:XX:XX:XX”

携带额外 HCI 级信息的地址类型值，例如 BT_ADDR_LE_PUBLIC_ID and BT_ADDR_LE_RANDOM_ID, are formatted according to their base type (public or random). The HCI sentinels for an unresolved RPA (BT_ADDR_LE_UNRESOLVED) and an anonymous advertiser (BT_ADDR_LE_ANONYMOUS) are formatted as random addresses. The additional information is not part of the string and has to be conveyed separately by the caller.

参数
addr包含二进制 LE Bluetooth 地址的缓冲区地址。
str有足够空间的用户缓冲区地址，用于存储包含二进制 LE 地址的格式化字符串。
len要复制到用户字符串缓冲区的数据长度。推荐值请参阅 BT_ADDR_LE_STR_LEN。
返回
从二进制地址成功格式化的字节数。
