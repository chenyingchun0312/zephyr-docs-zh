◆ gnss_publish_data()

void gnss_publish_data ( const struct device * dev,
const struct gnss_data * data )

#include <zephyr/drivers/gnss/gnss_publish.h>

将 GNSS 数据发布给已注册的回调。

调用通过 GNSS_DATA_CALLBACK_DEFINE() 和 GNSS_DT_DATA_CALLBACK_DEFINE() 注册的、与 dev 匹配的所有回调。

每当接收机有新的导航数据可用时，GNSS 驱动应调用该函数。

参数
dev发布数据的 GNSS 设备实例。
data要发布的导航数据、定位信息和 UTC 时间。
参见
GNSS_DATA_CALLBACK_DEFINE()
GNSS_DT_DATA_CALLBACK_DEFINE()

◆ gnss_publish_satellites()

void gnss_publish_satellites ( const struct device * dev,
const struct gnss_satellite * satellites,
uint16_t size )

#include <zephyr/drivers/gnss/gnss_publish.h>

将 GNSS 卫星信息发布给已注册的回调。

调用通过 GNSS_SATELLITES_CALLBACK_DEFINE() 和 GNSS_DT_SATELLITES_CALLBACK_DEFINE() 注册的、与 dev 匹配的所有回调。

每当接收机有更新的卫星跟踪信息可用时，GNSS 驱动应调用该函数。

注意
Available only when the following Kconfig option is enabled: CONFIG_GNSS_SATELLITES.
参数
dev发布卫星数据的 GNSS 设备实例。
satellites卫星跟踪数据的数组。
sizesatellites 中的元素数量。
参见
GNSS_SATELLITES_CALLBACK_DEFINE()
GNSS_DT_SATELLITES_CALLBACK_DEFINE()
