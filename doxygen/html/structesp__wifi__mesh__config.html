char ssid [33]
 路由器 SSID：根节点为访问外部网络而关联的上游 Wi-Fi 网络。留空则形成无路由器的固定根 mesh（参见 esp_wifi_mesh_start()）。以 NUL 结尾，最长 32 个字符。
char password [64]
 路由器密码。以 NUL 结尾，最长 63 个字符；开放路由器时留空。
char mesh_password [64]
 保护节点间 mesh 链路的 mesh softAP 密码。必须为空（对应 WIFI_SECURITY_TYPE_NONE）或 8..63 个字符，且在 mesh 中每个节点上相同。
uint8_t channel
 mesh 信道：0 表示由 mesh 通过扫描选择（路由器信道未知时必须这样）；1-13 指定固定信道，此时每个节点必须一致。
uint8_t mesh_id [6]
 6 字节的 mesh 网络标识符。节点只会加入广播相同 ID 的 mesh，因此同一网络中的每个节点都必须使用相同的值。
enum wifi_security_type authmode
 mesh softAP 认证模式。
uint8_t num_layers
 此 mesh 使用的树深度（层数）。必须至少为 1，且不大于编译期配置的 CONFIG_WIFI_ESP32_MESH_MAX_LAYER，后者在构建时决定路由表缓冲区大小。
uint8_t max_connections
 此 mesh 使用的每节点直接子节点扇出数。必须至少为 1，且不大于编译期配置的 CONFIG_WIFI_ESP32_MESH_MAX_CONNECTIONS，后者在构建时决定路由表缓冲区大小。

详细描述

可在运行时配置的 mesh 凭据与树限制。

由 esp_wifi_mesh_start() 读取，用以替代驱动的 Kconfig 默认值。请在调用 esp_wifi_mesh_start() 之前设置；mesh 栈不支持运行时重新配置或拆除，因此启动后的修改不会生效。
