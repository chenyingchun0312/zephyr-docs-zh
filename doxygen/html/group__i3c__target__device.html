◆ i3c_target_register()

int i3c_target_register ( const struct device * dev,
struct i3c_target_config * cfg )
inlinestatic

#include <zephyr/drivers/i3c/target_device.h>

将提供的配置注册为控制器的目标设备。

使用提供的配置结构体（cfg）为 dev I3C 总线驱动启用 I3C 目标模式，该结构体包含发送总线事件所需的函数和参数。与目标模式相关的任何 I3C 总线事件都将通过 'callbacks' 结构体成员中提供的一组回调函数传递给 I3C 目标设备驱动。

大多数现有硬件支持同时使用主机模式和目标模式，但这并非所有硬件都能保证。

参数
dev指向以目标模式配置的 I3C 控制器驱动的设备结构的指针。
cfg包含 I3C 目标驱动用于发送总线事件的函数和参数的配置结构体
返回值
0是否成功
-EINVAL参数无效时
-EIO通用输入/输出错误。
-ENOSYS未实现目标模式时

inlinestatic

#include <zephyr/drivers/i3c/target_device.h>

写入目标的 TX FIFO

使用提供的缓冲区和长度，向 dev I3C 总线驱动的 TX FIFO 写入数据。某些 I3C 目标在数据写入 TX FIFO 之前会对读请求返回 NACK。此函数会尽可能多地向 FIFO 写入数据，并返回写入的总字节数。剩余数据需由应用程序利用目标回调写入。返回负值表示错误。

大多数现有硬件支持同时使用主机模式和目标模式，但这并非所有硬件都能保证。

参数
dev指向以目标模式配置的 I3C 控制器驱动的设备结构的指针。
buf指向缓冲区的指针
len缓冲区长度
hdr_modeHDR 模式，参见 I3C_MSG_HDR_MODE*
返回值
Total已写入的字节数
-ENOTSUP不处于目标模式，或 HDR 模式不受支持
-ENOSPCTx FIFO 中没有空间
-ENOSYS未实现目标模式时
