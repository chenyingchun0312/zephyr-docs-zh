◆ duration

net_time_t ieee802154_config::[struct].__unnamed0__.rx_slot duration

以纳秒为分辨率的 RX 窗口时长，相对于上述 RX 窗口起始时间，在此期间接收机预期处于侦听状态（即不包含任何关闭时间）。仅允许大于或等于零的正值。

无论 start 参数为何，将 duration 设为零都会禁用接收机。

◆ start

net_time_t ieee802154_config::[struct].__unnamed0__.rx_slot start

以纳秒为分辨率的时间戳，相对于网络子系统的本地时钟，定义接收机预期处于侦听状态的 RX 窗口起始（即不包含任何驱动启动时间）。

将 rx_slot 的 start 属性设为 -1 进行配置，将取消并删除任何先前活动的 rx 时隙。
