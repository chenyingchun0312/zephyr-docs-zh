◆ arch_cpu_atomic_idle()

void arch_cpu_atomic_idle ( unsigned int key)

#include <zephyr/arch/arch_interface.h>

以原子方式重新使能中断并进入低功耗模式

arch_cpu_atomic_idle() 的要求如下：

  1. 使能中断与进入低功耗模式必须是原子操作，即在处理器进入低功耗模式之前，不应存在中断被使能的时间段。例如，请参阅 k_lifo_get() 中关于不满足该要求时会出现的竞态条件的注释。
  2. 从低功耗模式唤醒后，必须按 'key' 输入参数所指示的那样恢复中断锁定状态。
参见
k_cpu_atomic_idle()
参数
key先前调用 arch_irq_lock() 返回的锁定键

◆ arch_cpu_idle()

void arch_cpu_idle ( void )

#include <zephyr/arch/arch_interface.h>

省电空闲例程

当 '_pm_save_flag' 变量非零时，内核空闲循环或内核中 z_pm_save_idle 的某个实现会调用此函数。

未实现电源管理指令的架构可以直接返回，否则应发出省电指令以等待中断。

注解
该函数预期在使 CPU 退出省电模式的中断被处理完毕后返回，尽管这并不是硬性要求。
参见
k_cpu_idle()

◆ arch_pm_state_set_finish()

void arch_pm_state_set_finish ( unsigned int key)

#include <zephyr/arch/arch_interface.h>

在离开系统电源管理状态之后恢复中断状态

此钩子将 arch_pm_state_set_prepare() 准备的中断状态恢复为 PM 核心所期望的锁定状态。原始的空闲线程中断键仍由空闲路径持有，并在 PM 恢复簿记完成后恢复。

参数
keyarch_pm_state_set_prepare() 返回的架构特定键。

◆ arch_pm_state_set_prepare()

unsigned int arch_pm_state_set_prepare ( void )

#include <zephyr/arch/arch_interface.h>

在进入系统电源管理状态之前准备中断状态

SoC 电源管理实现在系统 PM 恢复期间保持 IRQ 分发被阻塞，并在中断锁定状态下调用此钩子。它应在低功耗指令之前立即调用。架构可利用它，使待处理的唤醒事件能够让 CPU 退出低功耗指令，同时不允许常规中断处理程序在 PM 恢复簿记之前运行。

尽管名称如此，这并不是 pm_state_set() 的边界钩子。SoC 代码应在低功耗指令（通常是 WFI）前后立即调用它，以尽量缩小限制性中断屏蔽的窗口。

返回
要传给 arch_pm_state_set_finish() 的架构特定键。
