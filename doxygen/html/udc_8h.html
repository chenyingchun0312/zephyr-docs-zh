◆ udc_event_cb_t

typedef int(*) udc_event_cb_t(const struct device *dev, const struct udc_event *const event)

向上层提交 UDC 事件的回调。

在上层，事件将被插入消息队列。（待定）也许更好的做法是提供初始化期间传入的 k_msgq 指针。

参数
[in]dev指向驱动实例 device 结构体的指针
[in]event指向事件结构体
返回
成功时为 0，所有其他值都应视为错误。

枚举值
UDC_EVT_VBUS_READY 

VBUS 就绪事件。表示 VBUS 处于稳定状态。

UDC_EVT_VBUS_REMOVED 

VBUS 移除事件。表示 VBUS 低于有效范围。

UDC_EVT_RESUME 

设备恢复事件

UDC_EVT_SUSPEND 

设备挂起事件

UDC_EVT_RESET 

检测到端口复位

UDC_EVT_SOF 

帧起始事件

UDC_EVT_EP_REQUEST 

端点请求结果事件

UDC_EVT_ERROR 

不可纠正错误事件，需要上层或应用程序处理。
