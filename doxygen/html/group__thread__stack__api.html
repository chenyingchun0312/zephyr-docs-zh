定义顶层内核栈内存区域

这定义一块内存区域，用作仅在内核管理员模式下运行的线程的线程栈。这也适合为中断或异常处理声明专用栈。

使用此宏定义的栈不能承载用户模式线程。

在此定义前加 'static' 关键字是合法的。

取 sizeof(sym) 并传给 k_thread_create() 的 stackSize 参数是不合法的，它可能与 'size' 参数不同。请改用 K_KERNEL_STACK_SIZEOF()。

分配的总内存量可能会增加，以容纳固定大小的栈溢出保护。

参数
sym线程栈符号名称
size栈内存区域的大小

定义顶层线程栈内存区域

这定义一块适合用作线程栈的内存区域。

这是通用的传统定义。对齐到 Z_THREAD_STACK_OBJ_ALIGN，并放入 'noinit' 段，使其在启动时不被清零

所定义的符号始终是 k_thread_stack_t，可以传给 k_thread_create()，但除此之外不应操作它。如果需要检查内部的缓冲区，请检查关联线程对象的 thread->stack_info 以获取边界。

在此定义前加 'static' 关键字是合法的。

取 sizeof(sym) 并传给 k_thread_create() 的 stackSize 参数是不合法的，它可能与 'size' 参数不同。请改用 K_THREAD_STACK_SIZEOF()。

某些架构可能会向上取整可用栈区域的大小以满足对齐约束。K_THREAD_STACK_SIZEOF() 将返回对齐后的大小。

参数
sym线程栈符号名称
size栈内存区域的大小

计算栈数组中各栈要分配的大小

此宏计算栈数组中各栈要分配的大小。它接受指定的 "size" 作为参数，并在需要时填充一些额外字节（例如用于 MPU 场景）。请参阅 K_THREAD_STACK_ARRAY_DEFINE 的定义了解其使用方式。返回的大小确保每个数组成员都按所需的栈基对齐对齐。

参数

数组成员的合适大小

返回栈内存区域的字节大小

便于将所需的栈大小传给 k_thread_create() 的便捷宏，因为底层实现实际创建的可能会更大（例如保护区域）。

此处返回的值不保证与传给 K_THREAD_STACK_DEFINE 的 'size' 参数一致，可能更大，但对于关联的栈对象，传给 k_thread_create() 总是安全的。
