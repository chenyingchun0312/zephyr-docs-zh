详细描述

一个带类型的标量或范围，是能力的最小组成单元。

值容器 是 能力结构 的字段所持有的内容：一个布尔值、一个有符号或无符号整数，或其中之一的一个 {min, max, step} 范围。范围是设备表示它接受一个区间而不是单个设定的方式——从 16 到 1280、步长为 2 的每个宽度——后续的固定会从中挑出一个值。

它是一个带标签的联合体，任何分支中都不含指针，因此在每个目标上大小相同，复制它就是普通赋值，也没有需要释放的东西。这正是能力可以按值传递并放入 .rodata 的原因。

类型集合刻意只有这两种形态，因为它们在相交下封闭：两个值相交绝不会产生比其输入更大的东西，因此结果总能放进调用方已有的存储中。备选集合类型会破坏这一点并迫使分配重新出现，这正是备选存在于枚举索引上而不是这里的原因——参见 Pad.

传给此 API 的指针不得为 NULL，除非该参数另有文档说明。
