RISC-V APLIC（高级平台级中断控制器）驱动 API

此头文件提供 RISC-V 高级平台级中断控制器（APLIC）的 API 和寄存器定义。APLIC 是 RISC-V 高级中断架构（AIA）的一部分，同时支持 MSI 和直接投递模式。
