void(*) bt_has_client_cb::preset_read_rsp(struct bt_has *has, int err, const struct bt_has_preset_record *record, bool is_last)

预设读取操作的回调函数。

远端服务器发送预设读取响应时调用该回调。记录对象及其成员都是临时的，必须复制后才能缓存其信息。

参数
has指向听力辅助服务对象的指针。
err成功时为 0，否则为 ATT 错误或负的 errno。
record预设记录，出错时为 NULL。
is_last若读取预设操作可视为已完成则为 true。

◆ preset_switch

void(*) bt_has_client_cb::preset_switch(struct bt_has *has, int err, uint8_t index)

听力辅助服务活动预设变更的回调函数。

可选回调，当远端服务器更改活动预设且预设切换过程完成时调用。必须设置该回调才能接收活动预设变更并启用预设切换支持。若未设置该回调，则不会发现活动索引和控制点特征 bt_has_client_discover.

参数
has指向听力辅助服务对象的指针。
err成功时为 0，否则为 ATT 错误或负的 errno。
index活动预设索引。

void(*) bt_has_client_cb::preset_update(struct bt_has *has, uint8_t index_prev, const struct bt_has_preset_record *record, bool is_last)

预设更新通知的回调函数。

远端服务器通知预设记录更新时调用该回调。记录对象及其对象都是临时的，必须复制后才能缓存其信息。

index_prev列表中前一个预设的索引。
record预设记录。
