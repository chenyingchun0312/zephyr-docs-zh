定义 devicetree.h:82

创建一个虚拟网络接口。与另一个接口的绑定在运行时通过调用 net_virtual_interface_attach() 完成。当 IP 隧道驱动中设置了对端 IP 地址、建立隧道时，会自动完成挂接。

参数
dev_id网络设备 id。
name该驱动实例向系统公开的名称。
init_fn驱动初始化函数的地址。
pm对与设备关联的 struct pm_device 的引用。（可选）。
data设备私有数据的指针。
config包含该驱动实例配置信息的结构体的地址。
prio进行配置的初始化级别。
api提供驱动所用 API 函数结构体的初始指针。可以为 NULL。
mtu此网络接口的最大传输单元（字节）。这是默认值，其值可在运行时调整。
