◆ bt_l2cap_br_connless_register()

int bt_l2cap_br_connless_register ( struct bt_l2cap_br_connless_cb * cb)

#include <zephyr/bluetooth/classic/l2cap_br.h>

注册无连接数据通道回调。

注册回调以监视并接收无连接数据通道帧。这使应用程序无需建立连接即可接收发往特定 PSM 的数据。

参数
cb回调结构体。必须指向保持有效的内存。PSM 字段必须设置为所需的协议或服务多路复用器值，或设为 0 以接收所有无连接数据帧。
返回值
0Success.
-EINVAL如果 cb 为 NULL、PSM 值无效、recv 回调无效或安全级别无效。
-EEXIST如果已注册具有相同 PSM 的回调。

◆ bt_l2cap_br_connless_send()

int bt_l2cap_br_connless_send ( struct bt_conn * conn,
uint16_t psm,
struct net_buf * buf )

#include <zephyr/bluetooth/classic/l2cap_br.h>

通过无连接数据通道发送数据

通过无连接数据通道发送数据。此函数允许在未建立 L2CAP 通道连接的情况下向特定 PSM 发送数据。

应用程序需要在发送前在缓冲区中预留 BT_L2CAP_CONNLESS_RESERVE 字节。出错时，应用程序仍拥有 buf，并会原样取回。

参数
conn连接对象。
psm标识目标服务的协议或服务多路复用器。
buf包含要发送数据的缓冲区。应用程序需要在缓冲区中为 L2CAP 报头预留足够的头部空间。
返回值
0Success.
-EINVAL如果 conn 或 buf 为 NULL、psm 无效、buf 的引用计数 != 1、buf 的头部空间小于 BT_L2CAP_CONNLESS_RESERVE，或 buf->user_data_size 小于 struct closure 的大小。
返回
-ENOTSUP 如果远端不支持无连接接收特性。
-ENOTCONN 如果未找到具有无连接通道的 L2CAP 通道。
-EMSGSIZE 如果数据大小超过对端无连接通道 MTU。
返回值
-ESHUTDOWN如果低层中具有无连接通道的 L2CAP 通道为 NULL。

◆ bt_l2cap_br_echo_req()

int bt_l2cap_br_echo_req ( struct bt_conn * conn,
struct net_buf * buf )

#include <zephyr/bluetooth/classic/l2cap_br.h>

通过 ECHO 请求发送 ECHO 数据

通过 ECHO 请求发送 ECHO 数据。应用程序需要已预留 BT_L2CAP_BR_ECHO_REQ_RESERVE bytes in the buffer before sending. On error, the application still owns buf and gets it back unchanged.

参数
connACL 连接对象。
buf发送 ECHO 数据。
返回
成功时为 0，出错时为负值。
