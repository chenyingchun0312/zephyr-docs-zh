按名称获取 MBOX 通道值

设备树片段示例： 

mbox1: mbox@... {
        #mbox-cells = <1>;
};

n: node {
    mboxes = <&mbox1 1>,
             <&mbox1 6>;
    mbox-names = "tx", "rx";
};

mbox 兼容的绑定片段： 

mbox-cells:
  - channel

用法示例： 

DT_MBOX_CHANNEL_BY_NAME(DT_NODELABEL(n), tx) // 1
DT_MBOX_CHANNEL_BY_NAME(DT_NODELABEL(n), rx) // 6
参数
node_id带 mboxes 属性的节点的节点标识符
name由节点 mbox-names 属性定义的 mboxes 元素的小写加下划线名称
返回
命名元素处说明符中的通道值；若不支持任何通道则为 0
参见
DT_PHA_BY_NAME_OR()
