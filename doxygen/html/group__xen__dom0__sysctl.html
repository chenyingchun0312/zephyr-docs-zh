uint16_t first,
uint16_t num )

#include <zephyr/xen/dom0/sysctl.h>

获取 Xen 域的信息。

参数
[out]domaininfo指向 xen_domctl_getdomaininfo 结构的指针，用于存储获取到的域信息。
first要获取其信息的第一个域 ID。
num要获取信息的最大域数量。
注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_DOM0.
返回
成功时返回写入 domaininfo 的条目数，失败时返回负的 errno 值。
返回值
-EINVALdomaininfo 为 NULL 或 num 为零。
