结构体成员变量说明

◆ connect

int(*) conn_mgr_conn_api::connect(struct conn_mgr_conn_binding *const binding)

被调用时，连通性实现应开始为 if_conn->iface 所指向的绑定接口尝试建立连通性（与网络关联）。

必须是非阻塞的。

由 conn_mgr_if_connect 调用。

◆ disconnect

int(*) conn_mgr_conn_api::disconnect(struct conn_mgr_conn_binding *const binding)

被调用时，连通性实现应断开（解除关联），或停止任何正在进行的与网络关联的尝试，目标为 if_conn->iface 所指向的绑定接口。

由 conn_mgr_if_disconnect 调用。

◆ get_opt

int(*) conn_mgr_conn_api::get_opt(struct conn_mgr_conn_binding *const binding, int optname, void *optval, size_t *optlen)

conn_mgr_if_get_opt 的实现回调。

用于获取实现特定的连接设置。

对某个 iface 调用 conn_mgr_if_get_opt 时，会以绑定到该 iface 的 conn_mgr_conn_binding 结构体调用此回调。

optname 的解释由连接实现负责。选项既可以专属于绑定的 iface（由 if_conn->iface 指向），也可以作用于整个连接实现。

更多细节参见 conn_mgr_if_get_opt 的说明。get_opt 的实现应遵循该说明。

◆ has_connection_config

bool(*) conn_mgr_conn_api::has_connection_config(struct conn_mgr_conn_binding *const binding)

被调用时，连通性实现应返回它是否具备尝试连接所需的配置。

若此检查在非持久连接上失败，则该接口永远不会被启用，且 connect 永远不会被调用。

此检查的一个例子是 WiFi 连通性绑定是否已配置了要连接的 SSID。

必须是非阻塞的。

由 conn_mgr_if_connect 调用。

◆ init

void(*) conn_mgr_conn_api::init(struct conn_mgr_conn_binding *const binding)

对每个使用此 API 绑定到连通性实现的接口各调用一次。

连通性实现应使用此回调来执行所需的按绑定接口初始化。

若认为合适，实现可以选择以部分写入的方式来优雅地处理无效的缓冲区长度，而不是报错。

◆ set_opt

int(*) conn_mgr_conn_api::set_opt(struct conn_mgr_conn_binding *const binding, int optname, const void *optval, size_t optlen)

conn_mgr_if_set_opt 的实现回调。

用于设置实现特定的连通性设置。

对某个接口调用 conn_mgr_if_set_opt 会以绑定到该接口的 conn_mgr_conn_binding 结构调用此回调。

optname 的解释由连接实现负责。选项既可以专属于绑定的 iface（由 if_conn->iface 指向），也可以作用于整个连接实现。

更多细节参见 conn_mgr_if_set_opt 的说明。set_opt 的实现应遵循该说明。

如认为合适，实现可以选择以部分读取的方式妥善处理无效的缓冲区长度，而不是报错。
