取消已提交的 P4 工作项

取消先前提交的工作项并将其从队列中移除。若该项在队列中被找到并移除，则返回 true。若函数返回 false，则该项可能从未提交、已被执行，或仍在运行。

返回
若该项被成功移除则为 true，否则为 false

◆ k_p4wq_submit()

void k_p4wq_submit ( struct k_p4wq * queue,
struct k_p4wq_work * item )

向 P4 队列提交工作项

将指定的工作项提交到队列。调用方必须已初始化该结构体的相关字段。队列将在有 CPU 时间可用且没有更高优先级工作项可用时执行处理程序。处理程序可在任意 CPU 上被调用。

该结构体存放在队列中时，调用方不得修改它。在调用 k_p4wq_cancel() 之前、或进入处理程序函数之前，该内存应保持不变。

注解
此调用是一个调度点，因此若所提交的项（或任何其他就绪线程）的优先级高于当前线程，且当前线程具有可抢占优先级，则调用方将让出 CPU。
参数
queue要提交到的 P4 队列
item要提交的 P4 工作项
