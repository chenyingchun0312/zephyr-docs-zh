获取 GPIO 说明符在给定索引处的 flags 单元

此宏要求 GPIO 说明符具有名为 flags 的单元。若 GPIO 说明符中没有 flags 单元，则返回零。如有必要，请参考节点绑定以确认说明符单元名称。

设备树片段示例： 

gpio1: gpio@... {
        compatible = "vnd,gpio";
        #gpio-cells = <2>;
};

gpio2: gpio@... {
        compatible = "vnd,gpio";
        #gpio-cells = <2>;
};

n: node {
        gpios = <&gpio1 10 GPIO_ACTIVE_LOW>,
                <&gpio2 30 GPIO_ACTIVE_HIGH>;
};

vnd,gpio 兼容的绑定片段： 

gpio-cells:
  - pin
  - flags

用法示例： 

DT_GPIO_FLAGS_BY_IDX(DT_NODELABEL(n), gpios, 0) // GPIO_ACTIVE_LOW
DT_GPIO_FLAGS_BY_IDX(DT_NODELABEL(n), gpios, 1) // GPIO_ACTIVE_HIGH
参数
node_id节点标识符
gpio_pha小写加下划线形式的、类型为 "phandle-array" 的 GPIO 属性
idxgpio_pha 中的逻辑索引
返回
索引 idx 处的 flags 单元值，若无则为零

获取 GPIO hog 说明符在给定索引处的 flags 单元

此宏要求 GPIO 说明符具有名为 flags 的单元。若 GPIO 说明符中没有 flags 单元，则返回零。如有必要，请参考节点绑定以确认说明符单元名称。

设备树片段示例： 

gpio1: gpio@... {
  compatible = "vnd,gpio";
  #gpio-cells = <2>;

  n1: node-1 {
          gpio-hog;
          gpios = <0 GPIO_ACTIVE_HIGH>, <1 GPIO_ACTIVE_LOW>;
          output-high;
  };

  n2: node-2 {
          gpio-hog;
          gpios = <3 GPIO_ACTIVE_HIGH>;
          output-low;
  };
};

vnd,gpio 兼容的绑定片段： 

gpio-cells:
  - pin
  - flags

用法示例： 

DT_GPIO_HOG_FLAGS_BY_IDX(DT_NODELABEL(n1), 0) // GPIO_ACTIVE_HIGH
DT_GPIO_HOG_FLAGS_BY_IDX(DT_NODELABEL(n1), 1) // GPIO_ACTIVE_LOW
DT_GPIO_HOG_FLAGS_BY_IDX(DT_NODELABEL(n2), 0) // GPIO_ACTIVE_HIGH
参数
node_id节点标识符
idxgpios 属性中的逻辑索引
返回
索引 idx 处的 flags 单元值，若无则为零

展开为被 hog 占用的 GPIO 数量，若没有则为零。

设备树片段示例： 

gpio1: gpio@... {
  compatible = "vnd,gpio";
  #gpio-cells = <2>;

  n1: node-1 {
          gpio-hog;
          gpios = <0 GPIO_ACTIVE_HIGH>, <1 GPIO_ACTIVE_LOW>;
          output-high;
  };

  n2: node-2 {
          gpio-hog;
          gpios = <3 GPIO_ACTIVE_HIGH>;
          output-low;
  };
};

vnd,gpio 兼容的绑定片段： 

gpio-cells:
  - pin
  - flags

用法示例： 

DT_NUM_GPIO_HOGS(DT_NODELABEL(n1)) // 2
DT_NUM_GPIO_HOGS(DT_NODELABEL(n2)) // 1
参数
node_id节点标识符；可以是也可以不是 GPIO hog 节点。
返回
节点中被 hog 占用的 GPIO 数量
