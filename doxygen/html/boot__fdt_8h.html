校验并复制引导固件设备树二进制对象。

注意
Available only when the following Kconfig option is enabled: CONFIG_BOOT_FDT.

此辅助函数校验 FDT 头部的魔数和 total-size 字段，检查该二进制对象能否装入调用方提供的存储空间，并把该二进制对象复制到该存储空间中。调用方拥有目标缓冲区，并决定复制的二进制对象可用多久。

参数
dst用于存放所复制 FDT 的目标缓冲区。
dst_size目标缓冲区大小（字节）。
src源 FDT 指针。
fdt_size输出 FDT 的大小（字节）。成功时以及返回 -ENOSPC 时设置。
返回值
0若该 FDT 已通过校验并被复制。
-EINVAL若某个参数无效，或 src 不是有效的 FDT。
-ENOSPC若 dst 对于该 FDT 来说太小。
