◆ TC_PRINT_RUNID

#define TC_PRINT_RUNID   do {} while (false)

报告 Run ID

当定义了 CPP 符号 TC_RUNID 时（例如来自编译环境），调用时打印所定义的字符串 RunID: <TC_RUNID>\ （TC_END_REPORT() 也会调用它）。

这主要用于自动化执行和运行多个测试用例时，验证正在执行的是预期镜像（因为有时目标板烧录或复位不成功）。

TC_RUNID 为任意字符串，会被转换为字符串字面量。

◆ TC_PRINT_RUNID_START

#define TC_PRINT_RUNID_START   do {} while (false)

在测试镜像开始执行时报告 Run ID

与运行开始时发出的 TC_PRINT_RUNID 相对应，因此一次运行的输出被两个 Run ID 标记包围。若在先前运行的输出仍待处理时观察到起始标记，日志解析器即可据此得知设备已重启、待处理的输出已过期，而无需依赖可选的启动横幅。

当定义了 TC_RUNID 时打印 RunID started: <TC_RUNID>，否则不打印任何内容。
