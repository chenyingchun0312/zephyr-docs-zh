详细描述

Raspberry Pi BCM283x 电源域标识符。

电源域 ID 与 Raspberry Pi 固件邮箱属性接口中的电源设备 ID 相对应。

参见
https://github.com/raspberrypi/firmware/wiki/Mailbox-property-interface#power
