◆ i3c_addr_slots_init()

int i3c_addr_slots_init ( const struct device * dev)

#include <zephyr/drivers/i3c/addresses.h>

初始化 I3C 地址槽结构体。

这会清除已分配地址位，并根据 I3C 规范设置保留地址位。

参数
dev指向控制器设备驱动实例的指针。
返回值
0If successful.
-EINVAL若有重复地址。
