◆ DT_PINCTRL_IDX_TO_NAME_TOKEN

#define DT_PINCTRL_IDX_TO_NAME_TOKEN ( node_id,
pc_idx )

#include <zephyr/devicetree/pinctrl.h>

值:
DT_CAT4(node_id, _PINCTRL_IDX_, pc_idx, _TOKEN)

将 pinctrl 属性索引转换为其名称词法单元

这样你就可以获取 pinctrl 属性的名称，并从中 "去掉引号"。

DT_PINCTRL_IDX_TO_NAME_TOKEN() 只能在该节点具有 pinctrl-'pc_idx' 属性且 pinctrl-names 属性中存在该索引对应元素时使用。在其他情况下使用它是错误的。

设备树片段示例： 

n: node {
        pinctrl-0 = <...>;
        pinctrl-1 = <...>;
        pinctrl-names = "default", "f.o.o2";
};

用法示例： 

DT_PINCTRL_IDX_TO_NAME_TOKEN(DT_NODELABEL(n), 0) // default
DT_PINCTRL_IDX_TO_NAME_TOKEN(DT_NODELABEL(n), 1) // f_o_o2

适用于 DT_STRING_TOKEN() 返回值的相同注意事项和限制在此同样适用。

参数
node_id节点标识符
pc_idx该节点中 pinctrl 属性的索引
返回
pinctrl 属性的名称，以词法单元形式给出，不带任何引号，且非字母数字字符会转换为下划线

这与 DT_PINCTRL_IDX_TO_NAME_TOKEN(node_id, pc_idx) 执行类似的转换。唯一区别是结果中的字母字符会被转换为大写。

设备树片段示例： 

n: node {
        pinctrl-0 = <...>;
        pinctrl-1 = <...>;
        pinctrl-names = "default", "f.o.o2";
};

用法示例： 

DT_PINCTRL_IDX_TO_NAME_TOKEN(DT_NODELABEL(n), 0) // default DT_PINCTRL_IDX_TO_NAME_TOKEN(DT_NODELABEL(n), 1) // f_o_o2

适用于 DT_STRING_UPPER_TOKEN() 返回值的相同注意事项和限制在此同样适用。

将 pinctrl 名称转换为其对应的索引

设备树片段示例： 

n: node {
        pinctrl-0 = <&foo &bar>;
        pinctrl-1 = <&baz &blub>;
        pinctrl-names = "default", "sleep";
};

用法示例： 

DT_PINCTRL_NAME_TO_IDX(DT_NODELABEL(n), default) // 0
DT_PINCTRL_NAME_TO_IDX(DT_NODELABEL(n), sleep)   // 1
