获取 DMA 说明符在给定索引处的单元值

设备树片段示例： 

dma1: dma@... {
        compatible = "vnd,dma";
        #dma-cells = <2>;
};

dma2: dma@... {
        compatible = "vnd,dma";
        #dma-cells = <2>;
};

n: node {
    dmas = <&dma1 1 0x400>,
           <&dma2 6 0x404>;
};

vnd,dma 兼容的绑定片段： 

dma-cells:
  - channel
  - config

用法示例： 

DT_DMAS_CELL_BY_IDX(DT_NODELABEL(n), 0, channel) // 1
DT_DMAS_CELL_BY_IDX(DT_NODELABEL(n), 1, channel) // 6
DT_DMAS_CELL_BY_IDX(DT_NODELABEL(n), 0, config) // 0x400
DT_DMAS_CELL_BY_IDX(DT_NODELABEL(n), 1, config) // 0x404
参数
node_id带 dmas 属性的节点的节点标识符
idxdmas 属性中的逻辑索引
cell小写加下划线形式的单元名
返回
索引 idx 处的单元值
