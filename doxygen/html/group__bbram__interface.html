◆ bbram_check_invalid()

int bbram_check_invalid ( const struct device * dev)

#include <zephyr/drivers/bbram.h>

检查 BBRAM 是否无效

检查是否置位了“无效电池后备 RAM”状态，然后复位该状态位。这可能由 VBAT 引脚上的低电压引起。

参数
[in]devBBRAM 设备指针。
返回
若电池后备 RAM 数据有效则为 0，否则为 -EFAULT。

◆ bbram_check_power()

int bbram_check_power ( const struct device * dev)

#include <zephyr/drivers/bbram.h>

检查 V CC1 电源故障。

若 V CC1 电源域在关闭后又被开启，则返回错误并复位该状态位。

参数
[in]devBBRAM 设备指针。
返回
若 V CC1 电源域正常工作则为 0，否则为 -EFAULT。
