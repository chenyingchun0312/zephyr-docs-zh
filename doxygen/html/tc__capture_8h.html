详细描述

测试输出捕获辅助工具。

将测试期间产生的文本诊断输出捕获到内存缓冲区，以便对其断言，而无需每个测试自行接入日志后端或 printk 钩子。两条输出路径都会被透明处理：

  • printk() 输出（以及 CONFIG_LOG_MODE_MINIMAL 下经 printk 路由的日志记录）通过包装 printk 字符输出钩子来捕获。
  • 完整日志输出（ CONFIG_LOG 配合真实后端模式）通过专用日志后端捕获。

典型用法：

tc_capture_start();
do_something_that_prints();
tc_capture_stop();
zassert_true(tc_capture_contains("expected text"));

注解
When capturing logging output, the message must reach the backend before tc_capture_stop() is called. Use CONFIG_LOG_MODE_IMMEDIATE (or otherwise flush the logs) so deferred messages are not missed.

◆ tc_capture_start()

void tc_capture_start ( void )

开始捕获测试输出。

清除之前捕获的数据，并开始将 printk 和日志输出记录到内部捕获缓冲区。捕获会持续到调用 tc_capture_stop()。输出仍会转发到普通控制台，因此常规测试日志不受影响。

◆ tc_capture_stop()

void tc_capture_stop ( void )

停止捕获测试输出。

恢复正常输出路径。捕获的数据可继续用 tc_capture_contains() 和 tc_capture_get() 检查，直到下一次调用 tc_capture_start() 或 tc_capture_clear()。
