Zephyr 提供了一套基础设施，用于在 main 之前调用初始化代码。此类初始化调用可通过 SYS_INIT() 或 SYS_INIT_NAMED() 宏注册。通过组合初始化级别和优先级，可按需调整初始化顺序。可用的初始化级别按顺序描述如下：

  • EARLY：在引导过程的极早期使用，紧接着进入 C 域之后（z_cstart()）。可用于扩展或实现架构代码、并使用必须在任何架构特定初始化代码被内核调用之前完成初始化的驱动或系统服务的架构和 SoC 中。
  • PRE_KERNEL_1：在内核的初始化上下文中执行，使用中断栈。此时内核服务尚不可用。
  • PRE_KERNEL_2：与 PRE_KERNEL_1 相同。
  • POST_KERNEL：在内核已运行后执行。从此以后可以使用内核原语。
  • APPLICATION：在应用程序代码（main）之前执行。
  • SMP：仅在启用 CONFIG_SMP 时可用，专用于 SMP。

初始化优先级取值范围为 0 到 999。

注解
设备也使用同一套基础设施。
