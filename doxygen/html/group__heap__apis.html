定义静态 k_heap

此宏定义并初始化指定大小的静态内存区域和 k_heap。内核启动后，可以像已调用 k_heap_init() 那样使用 &name。

注意，此宏对内存区域强制执行最小大小，以满足元数据需求。非常小的堆将被填充以适应。

参数
namestruct k_heap 对象的符号名
bytes内存区域的大小，以字节为单位

void * k_aligned_alloc ( size_t align,
size_t size )

#include <zephyr/kernel.h>

从堆分配具有指定对齐的内存。

此例程提供与 aligned_alloc() 类似的语义；内存从堆中按指定对齐分配。不过有一处细微差别：k_aligned_alloc() 接受任何非零的 size，而 aligned_alloc() 只接受为 align 整数倍的 size。

上文中，aligned_alloc() 指的是：C11 标准（ISO/IEC 9899:2011）：7.22.3.1 The aligned_alloc function（p: 347-348）

参数
align请求的内存对齐（以字节为单位）。
size请求的内存数量（以字节为单位）。
返回
成功时为所分配内存的地址；否则为 NULL。

从 k_heap 分配内存

从堆所拥有的内存区域中分配并返回一个内存缓冲区。如果没有立即可用的内存，调用将按指定的超时（通过标准超时 API 构造，或 K_NO_WAIT 或 K_FOREVER）阻塞，等待内存被释放。如果在超时到期时仍无法执行分配，则返回 NULL。分配的内存按指针大小的整数倍对齐。

注解
如果从 ISR 调用，timeout 必须设置为 K_NO_WAIT。
当 CONFIG_MULTITHREADING=n 时，任何 timeout 都被视为 K_NO_WAIT。
参数
h要从中分配的堆
bytes要分配的块的期望大小
timeout等待多长时间，或 K_NO_WAIT
返回
指向有效堆内存的指针，或 NULL

从 k_heap 为对象数组分配并初始化内存

为 num 个大小为 size 的对象组成的数组分配内存，并将已分配存储中的所有字节初始化为零。如果没有立即可用的内存，调用将按指定的超时（通过标准超时 API 构造，或 K_NO_WAIT 或 K_FOREVER）阻塞，等待内存被释放。如果在超时到期时仍无法执行分配，则返回 NULL。分配的内存按指针大小的整数倍对齐。

注解
如果从 ISR 调用，timeout 必须设置为 K_NO_WAIT。
当 CONFIG_MULTITHREADING=n 时，任何 timeout 都被视为 K_NO_WAIT。
参数
h要从中分配的堆
num要分配的对象数量
size要分配的每个对象的期望大小
timeout等待多长时间，或 K_NO_WAIT
返回
指向有效堆内存的指针，或 NULL

◆ k_realloc()

void * k_realloc ( void * ptr,
size_t size )

#include <zephyr/kernel.h>

扩大现有分配的大小

返回指向具有相同内容但分配大小不同的新内存区域的指针。如果新分配可以就地扩展，返回的指针将相同。否则，数据将被复制到新块，旧块将按 sys_heap_free() 释放。如果指定的大小小于原始大小，则该块将被就地截断，剩余内存归还给堆。如果新块的分配失败，则返回 NULL，旧块不会被释放或修改。

参数
ptr先前分配返回的原始指针
size请求的内存数量（以字节为单位）。
返回
指向调用者现在可以使用的内存的指针，或 NULL。
