在更改资源缓冲区的数据后，LwM2M 引擎可利用此回调将数据传回客户端或 LwM2M 对象。

在块式传输中，处理程序会被多次调用，每次携带数据块和递增的偏移。最后一块的 last_block 标志设为 true。块传输开始时偏移设为 0。

[in]data指向数据的指针。
[in]data_len数据的长度。
