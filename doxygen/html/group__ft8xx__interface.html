void ft8xx_calibrate ( const struct device * dev,
struct ft8xx_touch_transform * data )

#include <zephyr/drivers/misc/ft8xx/ft8xx.h>

校准触摸屏

运行触摸屏校准程序，采集触摸屏上的三次触摸。计算所得的校准结果会自动应用到触摸屏处理中，并通过 data 返回。

data 的内容可以保存下来，并在复位后用于 ft8xx_touch_transform_set()，以避免每次设备复位后都重新校准触摸屏。

参数
dev驱动实例的设备结构体指针
data指向要填充的触摸屏变换结构体的指针

◆ ft8xx_get_tracker_value()

uint32_t ft8xx_get_tracker_value ( const struct device * dev)

#include <zephyr/drivers/misc/ft8xx/ft8xx.h>

获取被跟踪对象的标签和跟踪值。

报告的标签和跟踪值适用于协处理器通过 ft8xx_copro_cmd_track() 函数跟踪的对象。

参数
dev驱动实例的设备结构体指针
返回
跟踪寄存器内容，其中 2 个最高字节（掩码 0xffff0000）表示跟踪值，2 个最低字节（掩码 0x0000ffff）表示标签。

◆ ft8xx_register_int()

void ft8xx_register_int ( const struct device * dev,
ft8xx_int_callback callback,
void * user_data )

#include <zephyr/drivers/misc/ft8xx/ft8xx.h>

设置 FT8xx 触发中断时执行的回调

此函数配置 FT8xx 在触摸事件改变标签值时触发中断。

当触摸事件改变标签值时，FT8xx 激活 INT 线。该线保持激活，直到调用 ft8xx_get_touch_tag()。因此在调用 ft8xx_get_touch_tag() 之前，callback 只会执行一次。

参数
dev驱动实例的设备结构体指针
callback指向 FT8xx 触发中断时调用的函数的指针
user_data要传给 callback 的用户数据指针
