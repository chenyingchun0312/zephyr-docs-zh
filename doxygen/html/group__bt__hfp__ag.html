◆ bt_hfp_ag_query_subscriber_func_t

typedef int(*) bt_hfp_ag_query_subscriber_func_t(struct bt_hfp_ag *ag, char *number, uint8_t type, uint8_t service)

#include <zephyr/bluetooth/classic/hfp_ag.h>

查询用户号码回调函数

当 AG 想要发送用户号码信息时，所有信息都将通过该回调传递，并在该函数中发送用户号码信息。

参数
agHFP AG object.
number用户号码。
type用户号码的类型指定所提供电话号码的格式，可取以下值之一：
  • 值 128-143：电话号码格式可以是国内或国际格式，可包含前缀和/或转义数字。号码呈现方式无需更改。
  • 值 144-159：电话号码格式为国际号码，包含国家代码前缀。如果号码中未包含加号（“+”），则应由 AG 按需添加。
  • 值 160-175：国内号码。不包含前缀或转义数字。
service用户号码的服务指示此电话号码与哪项服务相关。应为 4（语音）或 5（传真）。
返回
0 表示应继续处理下一个用户号码信息。
负值表示停止。

◆ bt_hfp_ag_audio_connect()

int bt_hfp_ag_audio_connect ( struct bt_hfp_ag * ag,
uint8_t id )

#include <zephyr/bluetooth/classic/hfp_ag.h>

创建音频连接

由 HFP AG 创建音频连接。其中包含两种建立过程：编解码器连接和音频连接。如果双方都支持编解码器协商，将首先建立编解码器连接。如果传入的编解码器 ID 与上一次编解码器连接不同，将触发编解码器连接过程。编解码器连接建立后，将启动音频连接。传入的编解码器 ID 可以是 BT_HFP_AG_CODEC_XXX 之一。如果双方都支持编解码器协商特性，编解码器 ID 可以是回调 codec 通知的 ids 位图中的一位。否则，id 应为 BT_HFP_AG_CODEC_CVSD。

参数
agHFP AG object.
id编解码器 ID。
返回
成功时为 0，出错时为负值。

◆ bt_hfp_ag_hf_indicator()

int bt_hfp_ag_hf_indicator ( struct bt_hfp_ag * ag,
enum hfp_ag_hf_indicators indicator,
bool enable )

#include <zephyr/bluetooth/classic/hfp_ag.h>

激活或停用 HF 指示器

它允许 HF 发出 +BIND 非请求结果码，以激活或停用 AG 支持的 HF 指示器。可激活或停用的受支持指示器在 enum hfp_ag_hf_indicators 中定义。BT_HFP_AG_HF_INDICATOR_ENH_SAFETY 用于支持 Enhanced Safety。只有启用相应配置后，indicator 才能取 HFP_AG_ENHANCED_SAFETY_IND。BT_HFP_AG_HF_INDICATOR_BATTERY 用于支持 Remaining level of Battery。只有启用相应配置后，indicator 才能取 HFP_AG_BATTERY_LEVEL_IND。如果未启用 CONFIG_BT_HFP_HF_HF_INDICATORS，调用该函数时将返回错误 -ENOTSUP。

参数
agHFP AG object.
indicatorAG 支持的 HF 指示器。
enable启用或禁用特定 HF 指示器。
返回
成功时为 0，出错时为负值。

设置语音识别引擎状态

用于设置语音识别引擎状态。将发送非请求结果码 +BVRA: 1,<vrecstate>。<vrecstate>：反映 AG 上语音识别引擎当前状态的位掩码。位 0 - 若为 1，表示 AG 已准备好接受音频输入；位 1 - 若为 1，表示 AG 正在向 HF 发送音频；位 2 - 若为 1，表示 AG 正在处理音频输入。如果未启用 CONFIG_BT_HFP_AG_ENH_VOICE_RECG，调用该函数时将返回错误 -ENOTSUP。

参数
agHFP AG object.
state<vrecstate> 的值。
返回
成功时为 0，出错时为负值。

设置语音识别引擎状态及文本表示

用于设置语音识别引擎状态及其文本表示。将发送非请求结果码 +BVRA: 1,<vrecstate>, <textualRepresentation>。<vrecstate> 与函数 bt_hfp_ag_vre_state 的参数 state 相同。<textualRepresentation>: <textID>,<textType>,<textOperation>, <string>。<textID>：当前文本的唯一 ID，为十六进制字符串（最长 4 个字符，少于 4 个字符也有效）。<textType>：来自以下列表的 textType ID：0 - AG 从 HF 提供的音频输入中识别出的文本；1 - AG 的音频输出文本；2 - AG 的音频输出文本，其中包含一个问题；3 - AG 的音频输出文本，其中包含错误描述。<textOperation>：文本操作的 ID：1 - NewText：表示开始一个新文本，应在 <textID> 变化时使用；2 - Replace：替换任何具有相同 <textID> 和相同 <textType> 的现有文本；3 - Append：在现有文本后附加新文本，并保持相同的 <textID> 和 <textType>。<string>：<string> 参数应为 UTF-8 文本字符串，且必须始终包含在双引号内。如果未启用 CONFIG_BT_HFP_AG_VOICE_RECG_TEXT，调用该函数时将返回错误 -ENOTSUP。

参数
agHFP AG object.
state<vrecstate> 的值。
id<textID> 的值。
type<textType> 的值。
operation<textOperation> 的值。
text<string> 的值。
返回
成功时为 0，出错时为负值。
