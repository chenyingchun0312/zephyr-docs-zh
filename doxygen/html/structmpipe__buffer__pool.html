struct mpipe_buffer_pool_config mpipe_buffer_pool::req_config

◆ set_config

int(*) mpipe_buffer_pool::set_config(struct mpipe_buffer_pool *pool, const struct mpipe_buffer_pool_config *cfg)

应用协商得到的池配置。实现会根据池所能提供的内容校验 cfg，并将接受的值写入 mpipe_buffer_pool::config itself, and returns a negative errno to refuse (e.g.

-ENOTSUP for an alignment the backing allocator cannot honor, -ENOSPC for a buffer count beyond the pool capacity).
