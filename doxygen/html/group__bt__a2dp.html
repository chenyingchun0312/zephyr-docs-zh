◆ bt_a2dp_discover_ep_cb

typedef uint8_t(*) bt_a2dp_discover_ep_cb(struct bt_a2dp *a2dp, struct bt_a2dp_ep_info *info, struct bt_a2dp_ep **ep)

#include <zephyr/bluetooth/classic/a2dp.h>

发现流端点时调用。

该类型的函数由用户提供给 bt_a2dp_discover_param 对象。每完成一个有效流端点的发现就会调用一次。没有更多端点时会向用户传入 NULL。否则用户可从参数 info 获取有效端点信息，并可设置参数 ep 以在回调返回后获取该端点。返回的函数值让用户可以控制是否继续检索后续端点。若当前找到的端点已满足需求、用户不想再读取更多端点，应返回 BT_A2DP_DISCOVER_EP_STOP。否则返回的值表示允许继续更多子调用迭代。

参数
a2dpa2dp 连接对象，标识与被查询远端的 a2dp 连接。
info指向所回调端点信息的对象。
ep若用户想使用找到的端点，可为其设置值，以获得可在其他 A2DP API 中进一步使用的端点。若 info 为 NULL（未找到更多端点），则该值为 NULL。
返回
若无需继续发现下一个端点则为 BT_A2DP_DISCOVER_EP_STOP。通过返回 BT_A2DP_DISCOVER_EP_STOP，用户允许继续该发现。

◆ bt_a2dp_connect()

struct bt_a2dp * bt_a2dp_connect ( struct bt_conn * conn)

#include <zephyr/bluetooth/classic/a2dp.h>

A2DP Connect.

此函数应在通过执行 GAP 过程获得 conn 参数之后调用。该 API 用于在设备之间建立 A2DP 连接。此函数只建立 AVDTP L2CAP 信令连接。连接成功后，会调用由 bt_a2dp_register_connect_callback 注册的回调。

参数
conn指向 bt_conn 结构体的指针。
返回
成功时为指向 struct bt_a2dp 的指针，出错时为 NULL。
