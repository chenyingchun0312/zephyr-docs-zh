枚举类型说明

◆ mdm_hl7800_event

enum mdm_hl7800_event

#include <zephyr/drivers/modem/hl7800.h>

报告给 mdm_hl7800_event_callback_t 的事件类型。

每个事件的文档说明了以该事件调用回调时，回调的 event_data 参数所指向的类型。

枚举值
HL7800_EVENT_RESERVED 

保留，不会产生

HL7800_EVENT_NETWORK_STATE_CHANGE 

网络注册状态变化。

事件数据指向一个 struct mdm_hl7800_compound_event，其中含有 enum mdm_hl7800_network_state 代码。

HL7800_EVENT_APN_UPDATE 

接入点名称变化。

事件数据指向一个 struct mdm_hl7800_apn。

HL7800_EVENT_RSSI 

参考信号接收功率变化。

事件数据指向一个 int，其中存放以 dBm 为单位的 RSRP。

HL7800_EVENT_SINR 

信号与干扰加噪声比变化。

事件数据指向一个 int，其中存放以 dB 为单位的 SINR。

HL7800_EVENT_STARTUP_STATE_CHANGE 

调制解调器启动状态变化。

事件数据指向一个 struct mdm_hl7800_compound_event，其中含有 enum mdm_hl7800_startup_state 代码。

HL7800_EVENT_SLEEP_STATE_CHANGE 

睡眠状态变化。

事件数据指向一个 struct mdm_hl7800_compound_event，其中含有 enum mdm_hl7800_sleep 代码。

HL7800_EVENT_RAT 

无线接入技术变化。

事件数据指向一个 enum mdm_hl7800_radio_mode 值。

HL7800_EVENT_BANDS 

已配置的 LTE 频段发生变化。

事件数据指向一个以 NUL 结尾的频段配置字符串。

HL7800_EVENT_ACTIVE_BANDS 

活动 LTE 频段发生变化。

事件数据指向一个以 NUL 结尾的频段配置字符串。

HL7800_EVENT_FOTA_STATE

固件更新进度。

固件版本变化。

HL7800_EVENT_GPS

定位状态变化。

HL7800_EVENT_POLTE_REGISTRATION 

PoLTE 注册结果。

HL7800_EVENT_POLTE_LOCATE_STATUS 

发出 PoLTE 定位命令的结果。

事件数据指向一个 struct mdm_hl7800_polte_location_data，其中只有状态字段有效。

HL7800_EVENT_POLTE 

PoLTE 位置响应。

事件数据指向一个 struct mdm_hl7800_polte_location_data。

HL7800_EVENT_SITE_SURVEY 

站点调查响应。

事件数据指向一个 struct mdm_hl7800_site_survey。每收到一次来自调制解调器的响应就会生成一次该事件。

HL7800_EVENT_STATE 

驱动状态变化。

事件数据指向一个 struct mdm_hl7800_compound_event，其中含有 enum mdm_hl7800_state 代码。
