 设置当前计数器值

详细描述

基于 MCUX IMX SNVS 计数器 API 的实时时钟控制。

Zephyr 对该设备的核心 API 是以计数器方式使用。

用户应考虑的其他实现细节：

  • 可通过配置选项启用可选的 SRTC（默认启用）
  • 高功耗通道（id 0）始终可用，低功耗通道（id 1）可选
  • 低功耗闹钟可用于触发唤醒
  • 计数器周期固定为 1Hz
