对 struct sys_heap 启用 KASAN 影子跟踪。

放在 sys_heap 声明之后的文件作用域中。它分配静态影子缓冲区，并以 PRE_KERNEL_1 优先级 0 把它注册到该堆。之后必须调用 sys_heap_init()。

参数
_heap_namesys_heap 变量名。
_heap_sz堆缓冲区大小（字节，编译期常量）。

示例用法：

static char heap_buf[4096];
static struct sys_heap my_heap;
SYS_HEAP_KASAN_ENABLE(my_heap, sizeof(heap_buf));
// call sys_heap_init(&my_heap, heap_buf, sizeof(heap_buf)) at runtime

void heap_kasan_register ( struct sys_heap * heap,
sys_bitarray_t * ba )

#include <zephyr/sys/heap_kasan.h>

为 KASAN 跟踪把影子位数组与堆关联。

对未在构建时通过 SYS_HEAP_KASAN_ENABLE() 或 K_HEAP_KASAN_ENABLE() 注册的堆启用 KASAN 影子跟踪。适用于动态创建的堆。

警告
必须在 sys_heap_init() 之前调用。在 sys_heap_init() 之后调用不会生效，该堆也不会被跟踪。
参数
heapsys_heap to track.
ba影子位数组；它必须有至少 SYS_HEAP_KASAN_SHADOW_BITS(heap_size) 个位，由 SYS_HEAP_KASAN_SHADOW_BUNDLES(heap_size) 个 uint32_t 束支撑。
