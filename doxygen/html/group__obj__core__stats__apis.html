将内核对象核心注销统计收集后，它将不再收集任何统计数据。这应在内核对象生命周期的末尾调用。

int k_obj_core_stats_query ( struct k_obj_core * obj_core,
void * stats,
size_t stats_len )

#include <zephyr/kernel/obj_core.h>

获取与内核对象关联的统计数据

此函数将 obj_core 指定的内核对象核心关联的统计数据复制到缓冲区 stats 中。与原始统计数据不同，这里可能报告平均值等计算值。请注意，缓冲区大小（stats_len）必须与内核对象类型的统计描述符所指定的大小一致。

参数
obj_core指向内核对象核心的指针
stats指向用于复制所查询统计数据的内存缓冲区的指针
stats_len内存缓冲区的长度
返回值
0成功时
-errno失败时

注册内核对象以收集统计数据

内核对象在收集统计数据之前，必须先注册才能执行此操作。注册还会自动使内核对象能够收集其统计数据。

参数

stats指向原始内核统计数据的指针
stats_len原始内核统计缓冲区的大小
返回值
0成功时
