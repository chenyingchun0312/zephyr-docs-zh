◆ bt_mesh_health_srv_fault_update()

int bt_mesh_health_srv_fault_update ( const struct bt_mesh_elem * elem)

#include <zephyr/bluetooth/mesh/health_srv.h>

通知协议栈给定元素的故障数组状态已改变。

这会促使该元素上的健康服务器在禁用周期性发布时发布当前故障数组。

参数
elem要更新其故障状态的元素。
返回
成功时返回 0，否则返回（负的）错误码。
