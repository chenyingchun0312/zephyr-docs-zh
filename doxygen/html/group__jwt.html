int jwt_add_payload ( struct jwt_builder * builder,
int32_t exp,
int32_t iat,
const char * aud )

#include <zephyr/data/jwt.h>

Add JWT payload.

向先前初始化的构建器添加具有以下字段的 JWT 有效载荷：

  • 过期时间
  • 签发时间
  • 受众

有关这些字段的更多信息，参见 RFC 7519 第 4.1 节。

参数
builder先前已初始化的构建器。
exp过期时间（epoch 格式）。
iat签发时间（epoch 格式）。
audAudience.
返回值
0Success.
<0Failure.

◆ jwt_init_builder()

int jwt_init_builder ( struct jwt_builder * builder,
char * buffer,
size_t buffer_size )

#include <zephyr/data/jwt.h>

初始化 JWT 构建器。

为创建新令牌而初始化给定的 JWT 构建器。缓冲区大小应足够容纳整个令牌。

参数
builder要初始化的构建器。
buffer要写入令牌的缓冲区。
buffer_size此缓冲区的大小。令牌将以 NULL 结尾，需在此大小中留出空间。
返回值
0Success.
-ENOSPC缓冲区不足以完成初始化。
