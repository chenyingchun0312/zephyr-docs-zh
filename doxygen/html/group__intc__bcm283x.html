#define BCM2836_L1_IRQ_GPU_BIT   8U

#include <zephyr/drivers/interrupt_controller/intc_bcm283x.h>

GPU 级联在 L1 IRQ_SOURCE 中的位位置。

同时用作该级联条目的 Zephyr IRQ 编号。ISR 从不在该索引处注册；当 L1 intc 报告该编号时，SoC 分派器会透明地向下进入 ARMC 控制器以查找真正的外设 IRQ。

◆ bcm2835_armctrl_ic_init()

void bcm2835_armctrl_ic_init ( void )

#include <zephyr/drivers/interrupt_controller/intc_bcm283x.h>

初始化 BCM2835 ARMC 外设中断控制器。

通过 device_map() 映射 MMIO 区段，并禁用所有 bank-0、PEND1 和 PEND2 源。由 SoC 的 z_soc_irq_init() 在架构启动期间、任何 SYS_INIT 优先级之前调用。

◆ bcm2835_armctrl_ic_irq_get_active()

unsigned int bcm2835_armctrl_ic_irq_get_active ( void )

#include <zephyr/drivers/interrupt_controller/intc_bcm283x.h>

解析触发中的 ARMC 外设 IRQ。

封装 bank-0 快捷位解析（BCM2835 ARM 外设数据手册第 7 章中的 Quirk 1），仅在没有任何快捷位被置位时才转入 PEND1 / PEND2 遍历。

返回
触发外设的 Zephyr IRQ 编号，或 CONFIG_NUM_IRQS if no ARMC source is asserted.

◆ bcm2836_l1_intc_init()

void bcm2836_l1_intc_init ( void )

#include <zephyr/drivers/interrupt_controller/intc_bcm283x.h>

初始化 BCM2836 ARM 本地中断控制器。

通过 device_map() 映射 MMIO 区段，并屏蔽内核 0 的所有本地路由源。由 SoC 的 z_soc_irq_init() 在架构启动期间、任何 SYS_INIT 优先级之前调用。
