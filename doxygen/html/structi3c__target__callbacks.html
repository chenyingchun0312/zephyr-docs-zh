◆ buf_read_requested_cb

int(*) i3c_target_callbacks::buf_read_requested_cb(struct i3c_target_config *config, uint8_t **ptr, uint32_t *len, uint8_t *hdr_mode)

从设备发起读操作时调用的函数。

当总线准备好通过缓冲区为从该设备地址的读操作提供更多数据时，控制器调用此函数。

**ptr 和 *len 中返回的值将被发送。返回成功将使控制器响应后续的读操作。返回错误将使控制器忽略总线操作，直到收到新的起始条件。

注意
Available only when the following Kconfig option is enabled: CONFIG_I3C_TARGET_BUFFER_MODE.
参数
config与该操作的目标设备关联的配置结构体。
ptr指向存储单元的指针，用于存放读请求要返回的数据缓冲区地址。
len指向存储单元的指针，用于存放读请求要传输的数据长度。
hdr_modeHDR 模式
返回
若已提供数据则为 0，否则为负的错误码。

len要传输的数据长度。

当活动控制器将控制器角色移交给此目标时调用的函数。

当活动控制器将控制器角色移交给此目标时，由活动控制器调用此函数。无论是目标主动请求，还是活动控制器选择移交给支持控制器功能的目标，都可能发生此调用。

参数

int(*) i3c_target_callbacks::write_received_cb(struct i3c_target_config *config, uint8_t val)

向设备的写操作被继续时调用的函数。

当控制器在对设备的进行中的写操作中完成一个数据字节的接收时，调用此函数。

返回成功将使控制器对接收到的下一个字节回 ACK。返回错误将使控制器对接收到的下一个字节回 NACK。

参数
config与该操作所寻址的设备相关联的配置结构。
val控制器接收到的字节。
返回
若还可接受更多数据则为 0，否则为负的错误码。
