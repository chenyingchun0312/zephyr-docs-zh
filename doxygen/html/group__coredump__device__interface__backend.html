详细描述

This group contains the API type definitions, callback signatures, and other helpers required to implement a Coredump pseudo-device driver.

◆ coredump_device_dump_t

typedef void(*) coredump_device_dump_t(const struct device *dev)

#include <zephyr/drivers/coredump.h>

将设备的数据加入正在生成的核心转储。

由核心转储子系统在转储时调用，以便设备可以将已注册的内存区域和回调数据复制到核心转储中。
