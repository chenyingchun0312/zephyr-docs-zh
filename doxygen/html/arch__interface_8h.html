static uint32_t arch_k_cycle_get_32 (void)
 获取当前周期计数，单位由 CONFIG_SYS_CLOCK_HW_CYCLES_PER_SEC 指定。虽然传统上它被指定为架构 API 的一部分，但实际上几乎所有平台都将其转发到定时器驱动提供的 sys_clock_cycle_get_32() API。

◆ k_thread_entry_t

typedef void(*) k_thread_entry_t(void *p1, void *p2, void *p3)

线程入口点函数类型。

线程入口点函数在线程开始执行时被调用。最多可以向该函数传递 3 个参数值。

如果入口点函数返回，线程将永久终止执行。线程有责任在返回之前释放其可能拥有的任何共享资源（例如互斥量和动态分配的内存）。

参数
p1第一个参数。
p2第二个参数。
p3第三个参数。

◆ arch_spin_relax()

void arch_spin_relax ( void )

在自旋循环内执行架构特定的处理

这会在中断禁用时的忙等循环（例如竞争自旋锁的循环）中被调用。默认实现是一个调用 arch_nop() 的弱函数。架构可以实现此函数，以在需要时执行额外检查或电源管理技巧。
