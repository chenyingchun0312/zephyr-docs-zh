◆ cellular_configure_networks()

int cellular_configure_networks ( const struct device * dev,
const struct cellular_network * networks,
uint8_t size )
inlinestatic

#include <zephyr/drivers/cellular.h>

为设备配置蜂窝网络

蜂窝网络设备至少支持一种蜂窝接入技术。每种蜂窝接入技术定义一组频段，蜂窝设备将支持其中的全部或一个子集。

蜂窝设备一次只能使用一种蜂窝网络技术。它必须仅使用所提供的蜂窝网络配置，并在有多个配置时按提供顺序确定优先级（第一个蜂窝网络配置优先级最高）。

参数
dev蜂窝网络设备实例。
networks要应用的蜂窝网络配置列表。
size蜂窝网络配置列表的大小。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-EINVAL所提供的任一蜂窝网络配置无效或不受支持。
-ENOTSUP蜂窝网络设备不支持该 API。

◆ cellular_modem_pause_periodic_script()

int cellular_modem_pause_periodic_script ( const struct device * dev)

#include <zephyr/drivers/modem/modem_cellular.h>

暂停 cellular_modem 驱动的周期性 chat 脚本。

在调用 cellular_modem_resume_periodic_script() 之前，已安排的周期脚本运行会被抑制。本次调用时正在执行的脚本调用允许完成；抑制从下一次计划运行起生效。

参数
dev用 MODEM_CELLULAR_DEFINE_INSTANCE() 创建的蜂窝设备。不得为 NULL。
返回值
0Success.
-ENOTSUP设备未配置周期性 chat 脚本。
-EINVAL周期脚本已处于暂停状态。
参见
cellular_modem_resume_periodic_script

◆ cellular_modem_resume_periodic_script()

int cellular_modem_resume_periodic_script ( const struct device * dev)

#include <zephyr/drivers/modem/modem_cellular.h>

恢复 cellular_modem 驱动的周期性 chat 脚本。

重新启用周期脚本。如果暂停期间至少跳过了一次计划运行，脚本会立即触发；否则周期定时器按配置的间隔重新开始。

参数

返回值
0Success.
-ENOTSUP设备未配置周期性 chat 脚本。
-EINVAL周期脚本当前未处于暂停状态。
参见
cellular_modem_pause_periodic_script
