LwM2M 资源项结构体

值类型必须与目标资源匹配，因为不会进行类型转换，值只是被内存复制。

以下 C 类型用于资源类型：

  • BOOL is uint8_t
  • U8 is uint8_t
  • S8 is int8_t
  • U16 is uint16_t
  • S16 is int16_t
  • U32 is uint32_t
  • S32 is int32_t
  • S64 is int64_t
  • TIME is time_t
  • FLOAT 即 double
  • OBJLNK 即 struct lwm2m_objlnk
  • STRING 即 char * 类型，且大小中应包含结尾的 null 终止符。
  • OPAQUE 即任意二进制数据。当向 OPAQUE 资源写入以 null 结尾的字符串时，大小中不应包含终止符。
