◆ flexram_set_dtcm_magic_addr()

int flexram_set_dtcm_magic_addr ( uint32_t dtcm_addr)

为 DTCM 设置魔数地址

魔数地址使 FlexRAM 在该地址被访问时向内核产生中断。

注意
Available only when the following Kconfig option is enabled: CONFIG_NXP_FLEXRAM_MAGIC_ADDR_API.
参数
dtcm_addrDTCM 中要启用魔数功能的地址。
返回值
0成功时
-EINVALdtcm_addr 不在 DTCM 中时
-ENODEVflexram 中没有 DTCM 分配时
