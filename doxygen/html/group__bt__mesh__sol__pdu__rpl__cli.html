◆ bt_mesh_sol_pdu_rpl_clear()

int bt_mesh_sol_pdu_rpl_clear ( struct bt_mesh_msg_ctx * ctx,
uint16_t range_start,
uint8_t range_len,
uint16_t * start_rsp,
uint8_t * len_rsp )

#include <zephyr/bluetooth/mesh/sol_pdu_rpl_cli.h>

从 Solicitation PDU RPL 中移除给定范围内地址的条目。

通过将 start_rsp 或 len_rsp as NULL. This way the method will not wait for response and will return immediately after sending the command.

要处理异步方法的响应参数，请在 bt_mesh_sol_pdu_rpl_cli 结构体中注册 srpl_status 回调。

参数
ctx该消息的消息上下文。
range_start单播地址范围的起始。
range_len单播地址范围的长度。有效值为 0x00 以及 0x02 到 0xff。
start_rsp范围起始响应缓冲区。
len_rsp范围长度响应缓冲区。
返回
成功时返回 0，否则返回（负的）错误码。
