◆ eth_adin2111_broadcast_filter()

int eth_adin2111_broadcast_filter ( const struct device * dev,
bool enable )

启用或禁用广播帧的转发（到主机）。DA 不匹配的帧会被丢弃。

注解
调用方负责设备锁。不得从 ISR 调用。
参数
[in]devADIN2111 device.
enable设为 0 表示禁用，设为非零表示启用。
返回
成功时为 0，失败时为负的 errno 值。
