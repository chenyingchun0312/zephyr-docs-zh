详细描述

ARM SiP 服务的公共 API

ARM SiP 服务提供了从运行于 EL1 的内核向运行于 EL2/EL3 的虚拟机监视器/安全监视器固件发送 SMC/HVC 调用的能力。

每个系统只允许一个 SMC 和一个 HVC。

该服务支持多个客户端。

客户端在发送任何请求之前必须打开通道，并在完成后立即关闭通道。该服务一次只允许一个通道。

该服务将通过回调函数把 SMC/HVC 返回值返回给客户端。

客户端状态机

  • INVALID：注册之前的无效状态。
  • IDLE ：初始状态。
  • OPEN ：客户端成功打开通道后会从 IDLE 切换到 OPEN。反之，成功关闭通道后会从 OPEN 切换到 IDLE 状态。
  • ABORT ：客户端已关闭通道，但仍遗留有未完成的事务。只有所有事务完成后，服务才会把客户端移回 IDLE 状态。处于 ABORT 状态时不允许客户端重新打开通道/

◆ sip_svc_open()

int sip_svc_open ( void * ctrl,
uint32_t c_token,
k_timeout_t k_timeout )

客户端请求在 ARM SiP 服务上打开通道。

客户端在通过 SMC/HVC 向运行于 EL2/EL3 的虚拟机监视器/安全监视器固件发送任何请求之前，必须先打开通道。

该服务一次只允许一个已打开的通道，并由互斥量保护。

参数
ctrl指向提供 ARM SiP 服务的控制器实例的指针。
c_token客户端的令牌
k_timeout互斥量已被锁定时需要等待的时间。当互斥量已被锁定时：
  • 若值为 K_NO_WAIT，则立即返回非零错误码
  • 若值为 K_FOREVER，则永久等待
  • 否则等待给定时长
返回值
0成功时。
-EINVAL参数无效。
-ETIMEDOUT超时到期。
-EALREADY客户端状态已处于打开状态。

◆ sip_svc_register()

uint32_t sip_svc_register ( void * ctrl,
void * priv_data )

在 ARM SiP 服务上注册客户端

成功时，客户端在服务中处于 IDLE 状态，服务会向客户端返回一个令牌。客户端随后可用该令牌在服务上打开通道，并与运行于 EL2/EL3 的虚拟机监视器/安全监视器固件通信。

参数
ctrl指向控制器实例的指针，该实例的服务提供 ARM SMC/HVC SiP 服务。
priv_data指向客户端私有数据的指针。
返回值
token_id成功时。
SIP_SVC_ID_INVALID参数无效、无法分配客户端 id，以及无法获取锁。

◆ sip_svc_send()

int sip_svc_send ( void * ctrl,
uint32_t c_token,
struct sip_svc_request * req,
sip_svc_cb_fn cb )

客户端请求向 EL3/EL2 发送 SMC/HVC 调用

客户端在使用此函数前必须先在该设备上打开通道。此函数是非阻塞的，可以从任何上下文调用。若请求被接受，服务会向客户端返回一个事务 ID。事务完成时会调用客户端回调。

参数
ctrl指向提供 ARM SiP 服务的控制器实例的指针。
c_token客户端的令牌
req指向采用 struct sip_svc_request 格式的用户输入的地址。
cb回调。SMC/SVC 返回值会通过回调中以 struct sip_svc_response 格式给出的上下文传给客户端。
返回
成功时为事务 ID。
返回值
-EINVAL参数无效。
-EOPNOTSUPP命令 id 或功能 id 无效。
-ESRCH客户端状态无效。
-ENOMEM分配内存失败。
-ENOMSG插入数据库失败。
-ENOBUF插入 msgq 失败。
-ENOLCK获取锁失败。
-EHOSTDOWNsip_svc 线程不存在。
-ENOTSUP检查不受支持的条件。
