◆ uuid_generate_v5()

int uuid_generate_v5 ( const struct uuid * ns,
const void * data,
size_t data_size,
struct uuid * out )

#include <zephyr/sys/uuid.h>

生成 UUIDv5。

此函数从一个命名空间 UUID 和二进制数据出发计算出一个确定性的 UUID。

注意
Available only when the following Kconfig option is enabled: CONFIG_UUID_V5.
参数
ns指向用作命名空间的 UUID 的指针。
data指向将被哈希以生成 UUID 的数据的指针。
data_size数据缓冲区的大小。
out将写入结果的 UUID。
返回值
0UUID 已正确生成并存入 out
-EINVALout 为 NULL
-ENOMEM内存分配失败
-ENOTSUPPSA Crypto 提供程序不支持所需的加密算法（SHA-1）
-EIO通用错误

◆ uuid_is_nil()

bool uuid_is_nil ( const struct uuid * data)

#include <zephyr/sys/uuid.h>

检查 UUID 是否为 Nil UUID。

Nil UUID 是 RFC9562 第 5.9 节定义的特殊形式，其中全部 128 位均为零。

参数
dataUUID to test.
返回值
truedata 是 Nil UUID。
falsedata 是其他任意值。
