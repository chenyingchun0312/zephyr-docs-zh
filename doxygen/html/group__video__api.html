#include <zephyr/video/video.h>

从视频设备获取视频缓冲区。

在驱动的端点出队中取出一个空（输出）或已填充（采集）的视频缓冲区。

参数
dev指向该驱动实例设备结构的指针。
vbuf从视频设备返回的缓冲区。
timeout超时时长或 K_NO_WAIT
返回值
0是否成功。
-EINVAL若参数无效。
-EIO通用输入/输出错误。

◆ video_set_signal()

int video_set_signal ( const struct device * dev,
struct k_poll_signal * sig )

#include <zephyr/video/video.h>

为视频端点注册/注销 k_poll 信号。

向端点注册轮询信号，该信号将在帧完成（完成、中止、出错）时被通知。注册 NULL 轮询信号会注销任何先前注册的信号。

参数
dev指向该驱动实例设备结构的指针。
sig指向 k_poll_signal 的指针
返回值
0若成功，否则为 -ERRNO 代码。

#include <zephyr/video/video.h>

在两个视频设备之间传输缓冲区

辅助函数，从源设备出队一个缓冲区并入队到宿设备，并在两者之间改变其缓冲区类型。

参数
src缓冲区从其出队的视频设备（源）
sink缓冲区入队到的视频设备（宿）
src_type源设备上的视频缓冲区类型
sink_type宿设备上的视频缓冲区类型
timeout出队时应用的超时
返回
成功时为 0，否则为负的 errno 代码
