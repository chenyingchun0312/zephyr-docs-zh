获取映射分区的绝对地址

设备树片段示例： 

 flash@1000000 {
    compatible = "soc-nv-flash";
    reg = <0x1000000 0x30000>;
    ranges = <0x0 0x1000000 0x30000>;

    partitions {
            ranges;

            storage_partition: partition@3a000 {
                    compatible = "zephyr,mapped-partition";
                    label = "storage";
                    reg = <0x3a000 0x8000>;
            };
    };
 };

此处 "storage" 分区被认为属于起始地址为 0x1000000 的 Flash 存储器。该分区的地址 0x3a000 表示该 Flash 存储器内部的偏移。

用法示例： 

DT_MAPPED_PARTITION_ADDR(DT_NODELABEL(storage_partition)) // 0x103a000

此宏只能用于 CPU 可寻址的内部存储器分区。否则可能产生编译时错误，例如：'__REG_IDX_0_VAL_ADDRESS' undeclared。

参数
node_idzephyr,mapped-partition 节点的节点标识符
返回
分区的单元地址。

 flash@... {
    reg = <0x0 0x40000>;
    ranges = <0x0 0x0 0x40000>;

    partitions {
            ranges;

                    compatible = "zephyr,mapped-partition";
                    reg = <0x0 0xc000>;
                    label = "mcuboot";
            };

            slot0_partition: partition@c000 {
                    compatible = "zephyr,mapped-partition";
                    reg = <0xc000 0x18000>;
                    label = "image-0";
            };

            ...
    };
 };

用法示例： 

 DT_NODE_BY_MAPPED_PARTITION_LABEL(mcuboot) // Node identifier for boot_partition
 DT_NODE_BY_MAPPED_PARTITION_LABEL(image_0) // Node identifier for slot0_partition
