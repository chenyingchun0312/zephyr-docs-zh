◆ sys_bitfield_test_and_clear_bit()

ALWAYS_INLINE int sys_bitfield_test_and_clear_bit ( mem_addr_t addr,
unsigned int bit )
static

#include <zephyr/sys/sys_io.h>

测试该位并清除它

此函数取从 addr 开始的指定位，测试其当前设置并将其清零。它将返回先前的设置。

参数
addr要从中查找该位的内存地址
bit要测试并清除的指定位（任意）
返回
目标位清零之前 addr 内容与 (1 << bit) 按位与的结果。仅当该位曾清零时结果为 0，否则结果为非 0 值。
