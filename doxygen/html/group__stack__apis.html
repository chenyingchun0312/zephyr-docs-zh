◆ k_stack_alloc_init()

int32_t k_stack_alloc_init ( struct k_stack * stack,
uint32_t num_entries )

#include <zephyr/kernel.h>

初始化栈。

此例程在首次使用前初始化栈对象。内部缓冲区将从调用线程的资源池中分配。如果调用 k_stack_cleanup()，或在启用用户模式且栈对象失去所有引用时，该内存将被释放。

参数
stack栈的地址。
num_entries可入栈的最大值数量。
返回值
0成功时
-ENOMEM如果内存无法分配

◆ k_stack_cleanup()

int k_stack_cleanup ( struct k_stack * stack)

#include <zephyr/kernel.h>

释放栈已分配的缓冲区

如果栈对象通过 k_stack_alloc_init() 获得了动态分配的缓冲区，此函数将释放它。如果缓冲区不是动态分配的，此函数不做任何操作。

参数
stack栈的地址。
返回值
0成功时
-EAGAIN对象仍在使用时

◆ k_stack_pop()

int k_stack_pop ( struct k_stack * stack,
stack_data_t * data,
k_timeout_t timeout )
isr-ok

#include <zephyr/kernel.h>

从栈弹出元素。

此例程以“后进先出”方式从 stack 移除 stack_data_t 值，并将该值存入 data。

注解
如果从 ISR 调用，timeout 必须设置为 K_NO_WAIT。
参数
stack栈的地址。
data用于存放从栈弹出值的区域的地址。
timeout获取值的等待时间，或特殊值 K_NO_WAIT 和 K_FOREVER 之一。
返回值
0从栈弹出的元素。
-EBUSY未等待即返回。
-EAGAIN等待时间超时。
