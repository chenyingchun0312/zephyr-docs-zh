◆ bt_mesh_health_cli_period_get()

int bt_mesh_health_cli_period_get ( struct bt_mesh_health_cli * cli,
struct bt_mesh_msg_ctx * ctx,
uint8_t * divisor )

#include <zephyr/bluetooth/mesh/health_cli.h>

获取目标节点的健康快速周期除数。

健康周期除数用于在注册故障时提高发布速率。正常情况下，健康服务器按已配置的发布参数中的周期发布。当注册了故障时，发布周期会除以 (1 << divisor)。例如，如果目标节点的健康服务器配置为以 16 秒的周期发布，而健康快速周期除数为 5，则注册故障时健康服务器将以 500 ms 的间隔发布。

将 divisor 设为 NULL 可以异步方式使用此方法。这样该方法将不等待响应，并在发送命令后立即返回。

要处理异步方法的响应参数，请在 bt_mesh_health_cli 结构中注册 period_status 回调。

参数
cli用于发送的客户端模型。
ctx消息上下文，为 NULL 表示使用已配置的发布参数。
divisor健康周期除数响应缓冲区。
返回
成功时返回 0，失败时返回（负的）错误码。
