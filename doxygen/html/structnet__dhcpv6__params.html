◆ downstream_ifaces

int net_dhcpv6_params::downstream_ifaces[NET_DHCPV6_MAX_DOWNSTREAM]

可选的下游接口索引。当委派前缀时（request_prefix），每个列出的接口都会成为请求路由器（RFC 8415）的下游链路：它会被分配一个从委派前缀中划分出的独立 /64（第 N 个条目获得第 N 个 /64），并通过路由器通告（RA）发布。需要 CONFIG_NET_IPV6_ND_RA_TX.

A downstream_count of 0 means the delegated prefix is only installed on iface.

注意，委派前缀必须足够短，以便为每个列出的接口容纳一个独立的 /64，即长度为 L 的委派最多可服务 2^(64 - L) 个下游接口。无法分配独立 /64 的接口会被跳过。
