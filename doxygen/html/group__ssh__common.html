◆ ssh_transport_traverse_callbacks()

int ssh_transport_traverse_callbacks ( bool is_server,
struct ssh_transport * transport,
const struct ssh_transport_event * event )

#include <zephyr/net/ssh/common.h>

对给定传输调用用户配置的回调。

此函数用于对给定传输调用用户配置的回调。SSH 传输用它来向用户通知认证结果、通道打开请求、通道数据等事件。该函数会遍历已配置的回调列表，并用所提供的传输和事件信息依次调用每个回调。注意，回调不得调用传输的注册或注销 API，否则可能导致死锁。

参数
is_server如果设为 true，则遍历已配置的服务器回调；如果设为 false，则遍历已配置的客户端回调。
transport要传给用户指定回调的传输。
event要传给用户回调的事件信息。
返回
成功时为 0；如果传输角色与分发角色不匹配（服务器与客户端），则为 -EINVAL。
