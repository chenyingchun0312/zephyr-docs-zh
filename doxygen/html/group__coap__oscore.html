◆ coap_oscore_context_add()

int coap_oscore_context_add ( const struct coap_oscore_init_params * params,
struct coap_oscore_context ** ctx )

#include <zephyr/net/coap_oscore.h>

添加一个 OSCORE 安全上下文。

从 params 派生公共、发送方和接收方上下文（RFC 8613, section-3.2），并将它们添加到可供 CoAP 服务器使用的上下文池中。上下文从固定大小的池中分配，该池的大小由以下配置决定 CONFIG_COAP_OSCORE_MAX_CONTEXTS and released with coap_oscore_context_remove(). Each context corresponds to one client identity (Recipient ID); add one context per client to serve multiple clients concurrently.

注意
Available only when the following Kconfig option is enabled: CONFIG_COAP_OSCORE.
参数
params派生参数。
ctx成功时被设为新建的上下文句柄。
返回值
0成功时。
-EINVAL当 params 为 NULL、缺少必需参数或其大小无效，或无法派生上下文时。
-ENOTSUP当 fresh_master_secret_salt 为 false 且出现以下情况时 CONFIG_COAP_OSCORE_CONTEXT_REUSE is disabled.
-ENOMEM没有空闲的上下文槽位时。

◆ coap_oscore_context_remove()

int coap_oscore_context_remove ( struct coap_oscore_context * ctx)

#include <zephyr/net/coap_oscore.h>

移除一个 OSCORE 安全上下文。

从可供 CoAP 服务器使用的上下文池中移除该上下文。上下文是带引用计数的：若有在途请求、活动交换或观察者仍引用它，则保留该上下文并返回 -EAGAIN。请在这些引用释放后重试。传入 NULL 会返回 -EINVAL。

注意
Available only when the following Kconfig option is enabled: CONFIG_COAP_OSCORE.
参数
ctx要移除的上下文句柄。
返回值
0成功时。
-EAGAIN上下文正在使用且无法移除时。
-EINVALctx 为 NULL 或不是有效的上下文句柄时。
