为 PCIe 端点 IRQ 初始化中断处理函数

该例程仅用于使用 PCIe 总线且具有固定或基于 MSI 的 IRQ（即不进行 IRQ 运行时检测）的驱动。如需运行时检测，请参见 pcie_connect_dynamic_irq()

参数
bdf_pPCIe 端点 BDF
irq_pIRQ 线号。
priority_p中断优先级。
isr_p中断服务例程的地址。
isr_param_p传给中断服务例程的参数。
flags_p架构特定的 IRQ 配置标志。

◆ pcie_alloc_irq()

unsigned int pcie_alloc_irq ( pcie_bdf_t bdf)
extern

#include <zephyr/drivers/pcie/pcie.h>

为端点分配 IRQ。

该函数首先检查 IRQ 寄存器，如果其中包含有效值则返回该值。如果寄存器中没有有效值，则尝试分配新的 IRQ。仅当未设置 CONFIG_PCIE_CONTROLLER 时才提供该函数。因此它适用于架构相关地为 PCIe 设备动态分配 IRQ 有意义的情形。

参数
bdfPCI(e) 端点
返回
IRQ 号，分配失败时为 PCIE_CONF_INTR_IRQ_NONE。

◆ pcie_probe_iobar()

bool pcie_probe_iobar ( pcie_bdf_t bdf,
unsigned int index,
struct pcie_bar * iobar )
extern

#include <zephyr/drivers/pcie/pcie.h>

探测分配给端点的第 n 个 I/O BAR 地址。

参数
bdfPCI(e) 端点
index（从 0 开始的）索引
iobar指向 struct pcie_bar 的指针
返回
找到该 I/O BAR 且有效时为 true，否则为 false

PCI(e) 端点有 0 个或多个 I/O 区域。该函数允许调用方以 index=0..n 调用它们来枚举。n 的值必须小于 6，因为最多有 6 个 BAR。索引相对于端点 BAR 保持顺序：例如索引 0 返回端点编号最小的 I/O BAR。
