宏定义

GPIO 驱动强度标志

驱动强度标志是 Linux GPIO 绑定所规定标准 GPIO 标志的 Zephyr 专用扩展。仅适用于 Espressif ESP32 SoC。

该接口支持两种不同的驱动强度：DFLT 表示硬件支持的最高驱动强度，ALT 表示硬件支持的最低驱动强度

#define ESP32_GPIO_DS_DFLT   (0x0U << ESP32_GPIO_DS_POS)
 默认驱动强度。
#define ESP32_GPIO_DS_ALT   (0x3U << ESP32_GPIO_DS_POS)
 替代驱动强度。
GPIO 引脚输入/输出使能标志

这些标志允许将引脚配置为输入或输出，同时不改动其互补配置。例如，若将某个 GPIO 引脚配置为输入并传入 ESP32_GPIO_PIN_OUT_EN 标志，驱动不会禁用该引脚的输出缓冲器。此功能可用于诊断或测试目的，使引脚同时作为输入和输出。

#define ESP32_GPIO_PIN_OUT_EN   (1 << 12)
 保持 GPIO 引脚作为输出使能
#define ESP32_GPIO_PIN_IN_EN   (1 << 13)
 保持 GPIO 引脚作为输入使能
GPIO 睡眠保持标志

在系统睡眠期间为引脚启用 ESP GPIO 焊盘保持功能。

启用后，引脚状态会在系统进入低功耗模式前被锁存，并在系统睡眠期间保持不变。即使控制该引脚的外设已断电或其寄存器状态丢失，也能确保 GPIO 电平得以保持。

该功能在输入和输出模式下均有效，且仅适用于支持输出的 GPIO。

注意：对于深度睡眠周期，自动保持功能可能无法覆盖从进入睡眠到应用程序恢复执行的整个时段。深度睡眠期间寄存器状态会因复位而丢失，保持配置会在驱动初始化阶段被释放。对于维持稳定电平至关重要的输出（例如边沿敏感信号），应用程序可能需要在请求断电前调用 gpio_hold_en() 显式启用保持功能。这样可确保引脚状态在整个深度睡眠期间一直保持，直到应用程序重新运行。

#define ESP32_GPIO_SLEEP_HOLD_EN   (1 << 14)
 在睡眠期间启用 GPIO 状态保持
