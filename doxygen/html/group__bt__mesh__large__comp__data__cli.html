#include <zephyr/bluetooth/mesh/large_comp_data_cli.h>

发送 Large Composition Data Get 消息。

此 API 用于读取 Composition Data 页的一部分。

通过将 rsp 设为 NULL，可异步使用此 API。这样该方法不会等待响应，发送命令后立即返回。

设置 rsp 时，用户负责在 bt_mesh_large_comp_data_rsp::data 中为 Composition Data 提供缓冲区。如果未提供缓冲区，则不会复制元数据。

参数
net_idx加密时使用的网络索引。
addr目标节点元素地址。
page要读取的 Composition Data 页。
offsetComposition Data 页内的偏移。
rsp指向用于存储从服务器收到的响应的结构的指针，为 NULL 表示不等待响应。
返回
成功时返回 0，失败时返回（负的）错误码。
