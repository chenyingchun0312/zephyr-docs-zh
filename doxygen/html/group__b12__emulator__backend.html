int bc12_emul_set_charging_partner ( const struct emul * target,
enum bc12_type partner_type )
inlinestatic

#include <zephyr/drivers/usb/emul_bc12.h>

设置连接到 BC1.2 设备的充电伙伴类型。

相应的 BC1.2 仿真器会更新厂商专用寄存器，以模拟连接指定的充电伙伴类型。如果支持，仿真器还会生成中断供真实驱动处理。

参数
target指向 BC1.2 仿真器实例的仿真器结构体的指针。
partner_type模拟的伙伴类型。设为 BC12_TYPE_NONE 以断开充电伙伴。
返回值
0If successful.
-EINVAL伙伴类型不受支持时。

◆ bc12_emul_set_pd_partner()

int bc12_emul_set_pd_partner ( const struct emul * target,
bool connected )
inlinestatic

#include <zephyr/drivers/usb/emul_bc12.h>

设置便携设备伙伴状态。

相应的 BC1.2 仿真器会更新厂商专用寄存器，以模拟连接或断开便携设备伙伴。如果支持，仿真器还会生成中断供真实驱动处理。

参数
target指向 BC1.2 仿真器实例的仿真器结构体的指针。
connected为 true 时模拟连接便携设备伙伴；为 false 时模拟断开事件。
返回值
0If successful.
-EINVAL不支持 PD 伙伴的连接/断开时。
