◆ dns_resolve_cb_t

typedef void(*) dns_resolve_cb_t(enum dns_resolve_status status, struct dns_addrinfo *info, void *user_data)

#include <zephyr/net/dns_resolve.h>

DNS 解析回调

DNS 解析回调在 DNS 解析成功后调用。解析器可能多次调用此回调，每个解析出的地址调用一次。

参数
status查询状态：每个解析出的地址返回 DNS_EAI_INPROGRESS；DNS_EAI_ALLDONE 表示解析结束，此时 info 被设为 NULL；若查询被手动取消或发生超时则为 DNS_EAI_CANCELED；若服务器无法解析该名称则为 DNS_EAI_FAIL；若不存在该名称则为 DNS_EAI_NODATA；其他值表示发生了错误。
info查询结果存放在此。
user_data在调用 dns_resolve_name() 时传入的用户数据。

#include <zephyr/net/dns_resolve.h>

从 DNS 获取 IP 地址信息。

此函数可用于解析例如 IPv4 或 IPv6 地址。注意这是异步调用，函数会立即返回，系统将在解析完成或超时后调用回调。解析器可能会查询多个已配置的服务器。视配置而定，它要么并行地向所有服务器发送请求，要么逐个推进直到有一个成功。只有第一个成功的响应会报告给调用方。此变体使用系统范围的 DNS 服务器。

参数
query调用方想要解析的内容。
type调用方想要获取的数据类型。
dns_idDNS id 会返回给调用方。若希望取消查询则需要该值。若无需取消查询，可设为 NULL。
cb在解析完成或发生超时后调用的回调。
user_data用户数据。
timeout连接的超时值。可能的取值：SYS_FOREVER_MS：查询将一直重试，若耗时过长用户需手动取消；>0：启动查询并让系统在指定的毫秒数后使其超时
返回
若解析已成功启动则为 0，否则 < 0

◆ dns_resolve_init()

int dns_resolve_init ( struct dns_resolve_context * ctx,
const char * dns_servers_str[],
const struct net_sockaddr * dns_servers_sa[] )

#include <zephyr/net/dns_resolve.h>

初始化 DNS 解析上下文。

此函数设置 DNS 服务器地址，并初始化实际解析器所使用的 DNS 上下文。DNS 服务器地址可以用文本形式指定，也可以用 struct net_sockaddr 指定（或两者兼用）。注意，解析 DNS 名称的推荐方式是使用 dns_get_addr_info() API。在这种情况下，由于系统已设置好 DNS 服务器，用户无需调用 dns_resolve_init()。

参数
ctxDNS 上下文。若该上下文变量是从栈上分配的，则该变量在整个解析期间必须保持有效。调用方无需事先填充该变量，也无需在之后修改该上下文。
dns_servers_str使用文本字符串表示的 DNS 服务器地址。该数组以 NULL 结尾。端口号可以在字符串中给出。服务器地址带或不带端口号的语法：IPv4 : 10.0.9.1 IPv4 + 端口 : 10.0.9.1:5353 IPv6 : 2001:db8::22:42 IPv6 + 端口 : [2001:db8::22:42]:5353
dns_servers_sa以 struct net_sockaddr 表示的 DNS 服务器地址。该数组以 NULL 结尾。struct net_sockaddr 中的端口号是可选的，设为 0 时使用默认值。
返回
成功时为 0，出错时 <0。

◆ dns_resolve_is_active()

bool dns_resolve_is_active ( struct dns_resolve_context * ctx)

#include <zephyr/net/dns_resolve.h>

检查 DNS 解析上下文是否处于活动状态。

当上下文使用至少一个 DNS 服务器初始化后即处于活动状态，关闭后则处于非活动状态。该状态不说明服务器本身的情况，例如它们是否可达。

参数
ctx已调用过 dns_resolve_init() 的 DNS 上下文，或 NULL。
返回值
true上下文处于活动状态。
false上下文不处于活动状态，或 ctx 为 NULL。

用新的服务器列表重新配置 DNS 解析上下文，并允许将服务器指定给特定的网络接口。

参数
ctxDNS 上下文
servers_str使用文本字符串表示的 DNS 服务器地址。该数组以 NULL 结尾。端口号可以在字符串中给出。服务器地址带或不带端口号的语法：IPv4 : 10.0.9.1 IPv4 + 端口 : 10.0.9.1:5353 IPv6 : 2001:db8::22:42 IPv6 + 端口 : [2001:db8::22:42]:5353
servers_sa以 struct net_sockaddr 表示的 DNS 服务器地址。该数组以 NULL 结尾。struct net_sockaddr 中的端口号是可选的，设为 0 时使用默认值。
interfacesDNS 服务器所绑定到的网络接口。这是网络接口索引数组。该数组的长度必须与 servers_str 和 servers_sa 数组相同。
sourceDNS 服务器的来源，例如手动、DHCPv4/6 等。
返回
成功时为 0，出错时 <0。

#include <zephyr/net/dns_resolve.h>

解析 DNS 服务。

此函数可用于解析 DNS-SD 服务发现所需的服务记录。注意这是异步调用，函数会立即返回，系统将在解析完成或发生超时后调用回调。每收到一个响应就调用一次回调。该查询需要手动取消，或由超时取消。

参数
ctxDNS 上下文
query调用方想要解析的内容。
dns_idDNS id 会返回给调用方。若希望取消查询则需要该值。若无需取消查询，可设为 NULL。
cb在解析完成或发生超时后调用的回调。
user_data用户数据。
timeout查询的超时值。可能的取值：SYS_FOREVER_MS：查询将一直重试，若耗时过长用户需手动取消；>0：启动查询并让系统在指定的毫秒数后使其超时
返回
若解析已成功启动则为 0，否则 < 0
