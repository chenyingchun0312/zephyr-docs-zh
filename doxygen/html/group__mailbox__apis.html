◆ k_mbox_async_put()

void k_mbox_async_put ( struct k_mbox * mbox,
struct k_mbox_msg * tx_msg,
struct k_sem * sem )

#include <zephyr/kernel.h>

以异步方式发送邮箱消息。

此例程向 mbox 发送消息，不等待接收者处理它。消息数据可以位于缓冲区中，也可以不存在（即空消息）。可选地，当消息被接收者接收并完全处理后，将释放信号量 sem。

参数
mbox邮箱的地址。
tx_msg发送消息描述符的地址。
sem信号量的地址，如果不需要则为 NULL。

◆ k_mbox_data_get()

void k_mbox_data_get ( struct k_mbox_msg * rx_msg,
void * buffer )

#include <zephyr/kernel.h>

将邮箱消息数据取入缓冲区。

此例程通过将所接收消息的数据取入缓冲区，然后处置该消息，来完成对该消息的处理。

或者，此函数可用于在不取出数据的情况下处置所接收的消息。

参数
rx_msg接收消息描述符的地址。
buffer用于接收数据的缓冲区的地址；如果丢弃数据则为 NULL。

#include <zephyr/kernel.h>

接收邮箱消息。

此例程从 mbox 接收消息，然后可选择取出其数据并处置该消息。

参数
mbox邮箱的地址。
rx_msg接收消息描述符的地址。
buffer用于接收数据的缓冲区的地址；如果希望稍后再取出数据并处置消息，则为 NULL。
timeout等待消息被接收的时间，或特殊值 K_NO_WAIT 和 K_FOREVER 之一。
返回值
0已接收消息。
-ENOMSG未等待即返回。
-EAGAIN等待时间超时。

◆ k_mbox_put()

int k_mbox_put ( struct k_mbox * mbox,
struct k_mbox_msg * tx_msg,
k_timeout_t timeout )

#include <zephyr/kernel.h>

以同步方式发送邮箱消息。

此例程向 mbox 发送消息，并等待接收者接收并处理该消息。消息数据可以位于缓冲区中，也可以不存在（即空消息）。

参数
mbox邮箱的地址。
tx_msg发送消息描述符的地址。
timeout等待消息被接收的时间，或特殊值 K_NO_WAIT 和 K_FOREVER 之一。一旦消息被接收，此例程将按需要等待任意长时间，直到消息被完全处理。
返回值
0已发送消息。
-ENOMSG未等待即返回。
-EAGAIN等待时间超时。
