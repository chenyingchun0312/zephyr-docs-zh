定义 USB 设备配置

USB 设备对每种支持的速度至少需要一个配置实例。 attrib is a combination of USB_SCD_SELF_POWERED or USB_SCD_REMOTE_WAKEUP, depending on which characteristic the USB device should have in this configuration.

参数
name配置名称
attrib配置特性。属性也可以通过 usbd_config_attrib_rwup() 和 usbd_config_attrib_self() 更新
power以 2 mA 为单位的 bMaxPower 值。该值也可以通过 usbd_config_maxpower() 设置
desc_nd用于描述该配置的字符串描述符节点的地址，参见 USBD_DESC_CONFIG_DEFINE()。字符串描述符是可选的，该参数可以为 NULL。
