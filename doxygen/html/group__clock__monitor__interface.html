◆ clock_monitor_mode

enum clock_monitor_mode

#include <zephyr/drivers/clock_monitor.h>

时钟监视器实例的运行模式。

值 0 故意未命名：零初始化的配置会被 clock_monitor_configure 以 -ENOTSUP 拒绝。

枚举值
CLOCK_MONITOR_MODE_WINDOW 

连续高/低阈值窗口检查：将被监视时钟的频率持续与可编程的上下限比较，当频率超出窗口时产生事件。

CLOCK_MONITOR_MODE_MEASURE 

每次 clock_monitor_start 进行一次频率测量，通过配置时回调以 Hz 报告。在完成回调运行之前，设备会自动返回配置的（停止）状态；正常路径下无需调用 clock_monitor_stop。若要重复测量，请调用 clock_monitor_start again from the callback.

必须在监视器停止时调用。将 cfg->callback\ （可为 NULL）与其余配置一起原子地安装。重新配置的方法是使用新的模式/参数集再次调用该函数；没有单独的拆除操作。

◆ clock_monitor_get_rate()

int clock_monitor_get_rate ( const struct device * dev,
uint32_t * rate_hz )

#include <zephyr/drivers/clock_monitor.h>

轮询最近完成的测量。

返回自上次 clock_monitor_configure 以来最近完成测量的结果。该值会被保留：读取不会清除它，读取也没有硬件副作用。这是配置时回调的轮询替代方案，并且可在无法安装回调的用户模式下工作。

参数
dev在 MEASURE 模式下配置的设备。
[out]rate_hz测得的频率，单位 Hz。仅在成功时写入。
返回值
0*rate_hz 保存最近测得的值
-EAGAIN测量正在进行，或尚无完成的测量
-EIO自 configure() 以来被监视时钟丢失（卡住）
-ENOSYS后端没有测量硬件

在运行时切换参考/目标时钟输入。

reference 和 target 参数是抽象的后端 cookie。每个后端通过 dt-bindings 头文件（例如 <zephyr/dt-bindings/clock_monitor/<vendor>-<ip>.h>）公开其接受的编码，以便设备树属性和运行时调用共享同一组常量。

◆ clock_monitor_start()

int clock_monitor_start ( const struct device * dev)

#include <zephyr/drivers/clock_monitor.h>

启动已配置模式的操作。

设备必须已通过 clock_monitor_configure 配置。其行为遵循已安装的模式：

  • CLOCK_MONITOR_MODE_WINDOW 开始连续阈值检查。阈值跨越会通过配置时回调传递，直到 clock_monitor_stop。
  • CLOCK_MONITOR_MODE_MEASURE 开始一次测量。完成时会以如下内容调用配置时回调 CLOCK_MONITOR_EVT_MEASURE_DONE and the measured value in evt->measured_hz (or CLOCK_MONITOR_EVT_CLOCK_LOST with 0 if the monitored clock is stuck). The device automatically returns to the configured (stopped) state before the callback runs.

该函数是 ISR 安全的，且可从事件回调中调用：通过在回调中再次调用它即可实现重复采样（与从回调重新装设计数器报警的惯用法相同）。

该 API 不为测量提供阻塞等待或超时：请以应用程序选择的超时等待回调（例如在其给出的信号量上），并在超时路径上调用 clock_monitor_stop 中止正在进行的测量。或者轮询 clock_monitor_get_rate.

参数
dev时钟监视器设备。
返回值
0成功
-EINVAL设备未配置
-EBUSY已在运行

◆ clock_monitor_stop()

int clock_monitor_stop ( const struct device * dev)

#include <zephyr/drivers/clock_monitor.h>

停止监视器。

使设备返回配置的（停止）状态，并中止任何正在进行的测量。幂等：停止已停止的设备会返回 0。

该函数是 ISR 安全的，且可从事件回调中调用（在 MEASURE 模式下，由于自动解除已在其中停止了设备，此处为无害的空操作）。

参数
dev时钟监视器设备。
返回值
0成功
