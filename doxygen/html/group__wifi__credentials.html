int wifi_credentials_set_personal ( const char * ssid,

const char * password,
size_t password_len,
uint32_t flags,
uint8_t channel,
uint32_t timeout )

#include <zephyr/net/wifi_credentials.h>

设置给定 SSID 的凭据。

注解
为已存储的 SSID 再次存储凭据会覆盖现有条目，而不会新增第二条。只有不同的 SSID 才占用存储槽位。
参数
[in]ssid要查找的 SSID
[in]ssid_lenSSID 的长度
[in]typeWi-Fi 安全类型
[in]bssidBSSID（可为 NULL）
[in]bssid_lenBSSID 缓冲区的长度（0 或 WIFI_MAC_ADDR_LEN）
[in]password口令
[in]password_len口令的长度
[in]flagsflags
[in]channelchannel
[in]timeout超时
返回
0 成功。凭据已存储到持久化存储中。
-EINVAL 必需的缓冲区为 NULL，或安全类型不受支持。
-ENOTSUP 安全类型不受支持。
-ENOBUFS 所有槽位均已被占用。
