ssize_t nvs_calc_free_space ( struct nvs_fs * fs)

#include <zephyr/kvss/nvs.h>

计算文件系统中的可用空闲空间。

参数
fs指向文件系统的指针
返回
空闲的字节数。成功时，它将等于仍可写入文件系统的字节数。计算空闲空间是一项耗时的操作，尤其是在 spi flash 上。出错时，返回 errno.h 定义的错误码的负值。

从文件系统读取条目。

参数

data指向数据缓冲区的指针
len要读取的字节数
返回
读取的字节数。成功时，它将等于请求读取的字节数。当返回值大于请求读取的字节数时，表明并非所有字节都被读取，还有更多数据可用。出错时，返回 errno.h 定义的错误码的负值。

◆ nvs_sector_use_next()

int nvs_sector_use_next ( struct nvs_fs * fs)

#include <zephyr/kvss/nvs.h>

关闭当前活动扇区并切换到下一个。

注解
会在新扇区上调用垃圾收集器。
警告
此例程为特定用例提供。它违背了 NVS 避免任何不必要 flash 擦除的目标。大量使用此例程可能导致 flash 设备过早失效。
参数
fs指向文件系统的指针。
返回
成功时为 0。出错时，返回 errno.h 定义的错误码的负值。

◆ nvs_write()

ssize_t nvs_write ( struct nvs_fs * fs,
uint16_t id,
const void * data,
size_t len )

#include <zephyr/kvss/nvs.h>

向文件系统写入一个条目。

注解
当 len 参数等于 0 时，条目实际上被移除（等同于调用 nvs_delete）。任何对数据长度为以下值的条目的 nvs_read 调用 0 will return error.
It is not possible to distinguish between deleted entry and entry with data of length 0.
参数
fs指向文件系统的指针
id要写入的条目的 id
data指向要写入数据的指针
len要写入的字节数
返回
写入的字节数。成功时，它将等于请求写入的字节数。当尝试重写已存储的相同数据时，不会向 flash 写入任何内容，因此返回 0。出错时，返回 errno.h 定义的错误码的负值。
