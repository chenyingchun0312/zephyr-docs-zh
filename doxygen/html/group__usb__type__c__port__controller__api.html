enum tcpc_alert

TCPC 告警位

枚举值
TCPC_ALERT_CC_STATUS 

CC 状态已变化

TCPC_ALERT_POWER_STATUS 

电源状态已变化

TCPC_ALERT_MSG_STATUS 

接收缓冲区寄存器已变化

TCPC_ALERT_HARD_RESET_RECEIVED 

收到硬复位消息

TCPC_ALERT_TRANSMIT_MSG_FAILED 

SOP* 消息发送失败

TCPC_ALERT_TRANSMIT_MSG_DISCARDED 

由于有传入的接收消息，复位或 SOP* 消息未发送

TCPC_ALERT_TRANSMIT_MSG_SUCCESS 

复位或 SOP* 消息发送成功

TCPC_ALERT_VBUS_ALARM_HI 

发生了高压告警

TCPC_ALERT_VBUS_ALARM_LO 

发生了低压告警

TCPC_ALERT_FAULT_STATUS 

发生了故障。请读取 FAULT_STATUS 寄存器

TCPC_ALERT_RX_BUFFER_OVERFLOW 

TCPC RX 缓冲区已溢出

TCPC_ALERT_VBUS_SNK_DISCONNECT 

处于 Attached.SNK 状态的 TCPC 检测到 Sink 断开

TCPC_ALERT_BEGINNING_MSG_STATUS 

接收缓冲区寄存器已变化

TCPC_ALERT_EXTENDED_STATUS 

扩展状态已变化

TCPC_ALERT_EXTENDED 

发生了扩展中断事件。请读取 alert_extended 寄存器

TCPC_ALERT_VENDOR_DEFINED 

检测到厂商自定义告警

◆ tcpc_get_rx_pending_msg()

int tcpc_get_rx_pending_msg ( const struct device * dev,
struct pd_msg * buf )
inlinestatic

#include <zephyr/drivers/usb_c/usbc_tcpc.h>

从 TCPC 获取 Power Delivery 消息。如果 buf 为 NULL，则只返回状态，其中 0 表示有消息待处理，-ENODATA 表示没有待处理消息。

参数
dev运行时设备结构体
buf写入 pd_buf 指针的位置；若只检查状态则为 NULL
返回值
Greater如果提供了 buf 参数，则为收到的字节数（大于或等于 0）
0有消息待处理且 buf 参数为 NULL 时
-EIO失败时
-ENODATA没有待处理消息时
