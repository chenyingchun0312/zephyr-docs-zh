void stm32_sdmmc_get_card_cid ( const struct device * dev,
uint32_t cid[4] )

#include <zephyr/drivers/disk/sdmmc_stm32.h>

从 SD/MMC 卡获取 CID（卡标识）信息。

该函数从设备初始化期间填充的内部 HAL SD/MMC 结构体复制卡标识数据（CID）。它不检查卡当前是否存在或其状态。若卡在初始化后被移除（或初始化失败），返回的 CID 可能已失效或全为零。

调用方有责任在调用此函数之前确认卡已存在并已初始化（例如调用 disk_access_status）。

参数
dev指向表示 SD/MMC 卡的设备结构体的指针。
cid指向用于存放 CID 数据的数组的指针。
