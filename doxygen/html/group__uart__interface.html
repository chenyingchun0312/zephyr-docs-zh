◆ uart_rx_stop_reason

enum uart_rx_stop_reason

#include <zephyr/drivers/uart.h>

接收停止原因。

与导致停止接收的事件或错误对应的值。

枚举值
UART_ERROR_OVERRUN 

溢出错误

UART_ERROR_PARITY 

奇偶校验错误

UART_ERROR_FRAMING 

帧错误

UART_BREAK 

中断（break）中断

收到了 break 中断。当串行输入在逻辑 '0' 状态保持的时间超过起始时间 + 数据位 + 奇偶校验 + 停止位之和时，就会发生这种情况。

UART_ERROR_COLLISION 

冲突错误

当发送的数据与接收的数据不匹配时会引发此错误。通常这在 TX 和 RX 线可能连在一起的场景中很有用，例如 RS-485 半双工。此错误仅在支持冲突检测的 UART 上有效。

UART_ERROR_NOISE 

噪声错误
