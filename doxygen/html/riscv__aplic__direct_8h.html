RISC-V APLIC 直接投递模式驱动 API

此头文件提供工作于直接投递模式的 RISC-V 高级平台级中断控制器（APLIC）的 API。在直接模式下，中断直接投递到 hart 的 MEXT 中断线路，而不经过 MSI。
