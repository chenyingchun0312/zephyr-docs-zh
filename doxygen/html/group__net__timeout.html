宏定义说明

◆ NET_TIMEOUT_MAX_VALUE

#define NET_TIMEOUT_MAX_VALUE   ((uint32_t)INT32_MAX)

#include <zephyr/net/net_timeout.h>

用于支持毫秒分辨率超时的除数。

由于延迟在工作队列中处理，而工作队列不会随时钟变化同步调用，因此我们需要能够在超时发生后检测到它，这就要求把“截止时间”（deadline）与“当前时间”（now）相比较，并留出足够的“余量”（slop），以应对“当前时间”越过“截止时间”所带来的任何可观测延迟。

最简单的方案是利用把定义良好的 32 位无符号差值原生转换为 32 位有符号差值这一做法，它将最大延迟限制为 INT32_MAX。这与检测未溢出其表示的截止时间是否到达的标准机制兼容。

◆ net_timeout_evaluate()

uint32_t net_timeout_evaluate ( struct net_timeout * timeout,
uint32_t now )

#include <zephyr/net/net_timeout.h>

更新状态以反映经过的时间，并获取新的延迟。

此函数必须定期调用，以便（1）对超出最大可表示延迟的那部分总延迟施加已过时间的影响，以及（2）判断超时已完成，或者基础设施必须等待一段时间后再检查是否完成。

参数
timeout指向超时状态的指针
now用于计算剩余时间估计值的参照时间。这应是最近捕获的 k_uptime_get_32() 值。
返回值
0超时是否已完成
>0重新评估该超时状态之前的最长延迟，单位为毫秒。

◆ net_timeout_remaining()

uint32_t net_timeout_remaining ( const struct net_timeout * timeout,
uint32_t now )

#include <zephyr/net/net_timeout.h>

以整秒计算到超时的剩余时间。

注解
此函数对剩余时间向下取整，即如果超时将在 3500 毫秒后发生，则返回 3。
要保证行为正确，需按规定间隔调用 net_timeout_evaluate()。
参数
timeout指向超时状态的指针
now用于计算剩余时间估计值的参照时间。这应是最近捕获的 k_uptime_get_32() 值。
返回值
0超时是否已完成。
>0超时的剩余持续时间，单位为秒。
