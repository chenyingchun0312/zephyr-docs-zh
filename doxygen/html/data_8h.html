◆ BT_DATA_SERIALIZED_SIZE

#define BT_DATA_SERIALIZED_SIZE ( data_len)
值:
((data_len) + 2)

给定数据长度，获取序列化 bt_data 的大小。

'AD Structure'->'Length' 字段的大小，等于 1。'AD Structure'->'Data'->'AD Type' 字段的大小，等于 1。'AD Structure'->'Data'->'AD Data' 字段的大小，等于 data_len。

参见 Core Specification Version 5.4 第 3 卷第 C 部分第 11 章图 11.1。

获取给定 bt_data 结构集合的总大小（字节）。

总大小包括每个元素的长度（1 字节）和类型（1 字节）字段，以及各自的数据长度。

参数

[in]data_countdata 中 bt_data 结构的数量。

◆ bt_data_serialize()

size_t bt_data_serialize ( const struct bt_data * input,
uint8_t * output )

将 bt_data 结构序列化为广播结构（扁平数组）。

数据按 Bluetooth Core Specification v. 5.4 第 3 卷第 C 部分第 11 章格式化。

参数
[in]input要读取的单个 bt_data 结构。
[out]output足以存放广播结构的缓冲区 input. The size of it must be at least the size of the input->data_len + 2 (for the type and the length).
返回
写入 output 的字节数。
