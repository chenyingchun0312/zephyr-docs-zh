◆ console_getchar()

int console_getchar ( void )

#include <zephyr/console/console.h>

从控制台输入缓冲区获取下一个字符。

从控制台返回下一个输入字符。若无可用字符，此函数将阻塞。此函数类似 ANSI C 的 getchar() 函数，旨在便于移植现有软件。使用此函数前应先调用一次 console_init()。此函数与 Zephyr 原生基于回调的控制台输入处理、Shell 子系统以及 console_getline() 不兼容。

返回
0-255：读取到的字符，包括控制字符。<0：发生错误。

◆ console_getline()

char * console_getline ( void )

#include <zephyr/console/console.h>

从控制台输入缓冲区获取下一行。

从控制台返回下一行输入。在完整行可用之前，此函数将阻塞。此函数类似 ANSI C 的 gets() 函数（区别在于行返回在系统拥有的缓冲区中，由系统负责缓冲区溢出检查），旨在便于移植现有软件。使用此函数前应先调用一次 console_getline_init()。此函数与 Zephyr 原生基于回调的控制台输入处理、Shell 子系统以及 console_getchar() 不兼容。

返回
指向所读取行的指针，不包含行尾字符。行位于系统拥有的缓冲区中，因此应用程序应在调用 console_getline() 后立即完成对该行的处理，否则缓冲区可能被重用。

◆ console_getline_init()

void console_getline_init ( void )

#include <zephyr/console/console.h>

初始化 console_getline() 调用。

此函数应调用一次，以初始化通过 console_getline() 函数进行的拉取式控制台访问。此函数取代回调（推式）控制台处理方式（通过 console_input_fn 回调等），并与之不兼容。

◆ console_init()

int console_init ( void )

#include <zephyr/console/console.h>

初始化控制台设备。

此函数应调用一次，以初始化通过 console_getchar() 函数进行的拉取式控制台访问，以及通过 console_putchar() 函数进行的缓冲输出。此函数取代回调（推式）控制台处理方式（通过 console_input_fn 回调等），并与之不兼容。

返回
成功时为 0，否则为错误码（<0）

◆ console_putchar()

int console_putchar ( char c)

#include <zephyr/console/console.h>

向控制台输出一个字符（缓冲）。

将一个字符放入控制台输出缓冲区。它会被异步发送到控制台，例如通过 IRQ 处理函数。

返回
出错时 <0，否则为 0。

void * buf,
size_t size )

#include <zephyr/console/console.h>

从控制台读取数据。

参数
dummy忽略，仅为与 read() 原型保持一致
buf用于读取数据的缓冲区
size最多读取的字节数
返回
>0，实际读取的字节数（可能小于 size 参数）；=0，遇到 EOF；<0，出错（例如超时到期时为 -EAGAIN）。同时会设置 errno 变量。

◆ console_set_rx_timeout()

void console_set_rx_timeout ( k_timeout_t timeout)

#include <zephyr/console/console.h>

设置控制台操作的接收超时。

设置 console_getchar() 和 console_read() 操作的超时。初始化后的默认超时为 K_FOREVER。

参数
timeout读取时等待的最长时间。

#include <zephyr/console/console.h>

设置控制台操作的发送超时。

设置 console_putchar() 和 console_write() 操作的超时，用于输出缓冲区已满的情况。初始化后的默认超时为 K_FOREVER。
