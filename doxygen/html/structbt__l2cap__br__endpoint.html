uint8_t fcs
 端点 FCS 类型。该值定义为 BT_L2CAP_BR_FCS_*。默认设置应为 BT_L2CAP_BR_FCS_16BIT。对于 FC 和 RET，FCS 类型应为 BT_L2CAP_BR_FCS_16BIT。对于 ERET 和 STREAM，FCS 类型是可选的。若该字段不是默认值，且双方都支持 FCS Option，则本地端将在配置请求数据包中包含 FCS 选项。
bool extended_control
 端点扩展控制。若该字段为 true，且双方都支持 Extended Window size feature，则本地端将在配置请求数据包中包含 extended window size 选项。
