bool shell_mqtt_get_devid ( char * id,
int id_max_len )

#include <zephyr/shell/shell_mqtt.h>

用于定义设备 ID（devid）的函数，shell mqtt 后端在连接 broker 时会把它用作客户端 ID。它会把自己的输出发布到 devid_tx，并订阅 devid_rx 以接收输入。

注解
这是一个弱链接函数，如有需要可以覆盖。
参数
id指向 devid 缓冲区的指针
id_max_lendevid 缓冲区的最大大小，由 DEVICE_ID_HEX_MAX_SIZE 定义
返回
若 devid 长度 > 0 则为 true
