◆ addr

const bt_addr_le_t* bt_le_scan_recv_info::addr

广播者的 LE 地址和类型。

若广播者是匿名的，则该地址为 BT_ADDR_LE_ANY.

◆ adv_props

uint16_t bt_le_scan_recv_info::adv_props

广播包属性位域。

使用 bt_gap_adv_prop 取值。若该值包含以下标志，则表示这是一个扫描响应： BT_GAP_ADV_PROP_SCAN_RESPONSE bit.

◆ adv_type

uint8_t bt_le_scan_recv_info::adv_type

广播包类型。

使用 bt_gap_adv_type 取值。

若类型为以下值，则表示这是一个扫描响应： BT_GAP_ADV_TYPE_SCAN_RSP.

◆ direct_addr

const bt_addr_le_t* bt_le_scan_recv_info::direct_addr

定向广播的目标地址。

NULL if the report carries no target address. Whether the advertisement was directed is given by BT_GAP_ADV_PROP_DIRECTED in bt_le_scan_recv_info::adv_props.

LE 扩展广播报告始终携带定向广播的目标地址，无论控制器是否已解析它。LE 广播报告没有目标地址字段，因此对于控制器在使用传统扫描命令扫描时已解析的定向广播，该值为 NULL。

若控制器无法解析，则地址类型为 BT_ADDR_LE_UNRESOLVED。

◆ interval

uint16_t bt_le_scan_recv_info::interval

周期性广播间隔（N * 1.25 ms）。

若为 0，则没有周期性广播。
