bool input_kbd_matrix_active ( const struct device * dev)

如果矩阵被视为活动则返回 true。

如果矩阵被视为活动则返回 true，即某个按键被按下，或正在等待去抖/释放。

参数

false矩阵空闲，所有按键都已释放。

◆ input_kbd_matrix_actual_key_mask_set()

int input_kbd_matrix_actual_key_mask_set ( const struct device * dev,
uint8_t row,
uint8_t col,
bool enabled )

#include <zephyr/input/input_kbd_matrix.h>

在实际按键掩码中启用或禁用特定的行、列组合。

这允许在运行时启用或禁用实际按键掩码中特定的行、列组合。当某些按键在特定配置中不存在，且该特定配置在运行时确定时，这会很有用。需要启用 CONFIG_INPUT_KBD_ACTUAL_KEY_MASK_DYNAMIC。

参数
dev指向键盘矩阵设备的指针。
row要启用或禁用的矩阵行。
col要启用或禁用的矩阵列。
enabled指定的行、列是否应被启用或禁用。
返回值
0如果更改成功。
-errno如果行或列超出设备的范围，则为负的 errno。

◆ input_kbd_matrix_update_state()

void input_kbd_matrix_update_state ( const struct device * dev)

#include <zephyr/input/input_kbd_matrix.h>

更新键盘矩阵状态并应用去抖。

驱动程序必须首先填充 input_kbd_matrix_common_config 和 input_kbd_matrix_common_data for the kbd matrix. This function then updates the stable and unstable states, performs per-key debouncing, and reports key events to the input subsystem.

参数
dev键盘矩阵设备实例。
