◆ rtc_alarm_set_callback()

int rtc_alarm_set_callback ( const struct device * dev,
uint16_t id,
rtc_alarm_callback callback,
void * user_data )
inlinestatic

#include <zephyr/drivers/rtc.h>

设置闹钟回调的 API。

为闹钟设置回调即启用该闹钟的回调。闹钟回调启用后，闹钟触发事件会调用该回调，随后闹钟的挂起状态会被自动清除。闹钟将保持启用，直到使用以下方式手动禁用它 rtc_alarm_set_time().

要禁用某个闹钟的回调，需将 callback 和 user_data parameters must be set to NULL. When the alarm callback for an alarm is disabled, the alarm triggered event will set the alarm status to "pending". To check if the alarm status is "pending", use rtc_alarm_is_pending().

参数
dev设备实例
id要为其设置回调的闹钟 ID
callback闹钟发生时调用的回调
user_data传给回调的可选用户数据
返回
成功时为 0
id 超出范围时为 -EINVAL
硬件不支持该 API 时为 -ENOTSUP
失败时为 -errno 错误码

#include <zephyr/drivers/rtc.h>

设置 RTC 闹钟时间的 API。

要启用 RTC 闹钟，必须启用 RTC 闹钟时间的一个或多个字段。掩码指定要启用闹钟时间的哪些字段。若 mask 参数为 0，闹钟将被禁用。当闹钟时间中所有已启用的字段都与 RTC 时间匹配时，RTC 闹钟会触发。

参数
dev设备实例
id闹钟的 ID
mask闹钟时间中要启用的字段掩码
timeptr要设置的闹钟时间
注解
若 mask 参数为 0，则 timeptr 参数可以为 NULL
只需配置 timeptr 参数中已启用的字段
mask 参数中的各个位在此定义 RTC_ALARM_TIME_MASK
返回
成功时为 0
id 超出范围或时间无效时为 -EINVAL
硬件不支持该 API 时为 -ENOTSUP
失败时为 -errno 错误码

◆ rtc_update_set_callback()

int rtc_update_set_callback ( const struct device * dev,
rtc_update_callback callback,
void * user_data )
inlinestatic

#include <zephyr/drivers/rtc.h>

设置更新回调的 API。

设置更新回调即启用该更新回调。RTC 时钟每推进 1 秒就会调用一次更新回调。它可用于将 RTC 时钟与其他时钟源同步。

要禁用 RTC 时钟的更新回调，需将 callback and user_data parameters must be set to NULL.

参数
dev设备实例
callback更新发生时调用的回调
user_data传给回调的可选用户数据
返回
成功时为 0
硬件不支持该 API 时为 -ENOTSUP
失败时为 -errno 错误码
