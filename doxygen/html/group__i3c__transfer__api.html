◆ i3c_transfer()

int i3c_transfer ( struct i3c_device_desc * target,
struct i3c_msg * msgs,
uint8_t num_msgs )

#include <zephyr/drivers/i3c.h>

执行从控制器到 I3C 目标设备的数据传输。

该例程提供通用接口，以同步方式向目标设备执行数据传输。简单的读写请使用 i3c_read()/i3c_write()。

消息数组 msgs 不能为 NULL。消息数量 num_msgs 可以为零，此时不发生传输。

注意
Available only when the following Kconfig option is enabled: CONFIG_I3C_CONTROLLER.
注解
并非所有驱动都支持全部分散/聚集（scatter/gather）事务。例如，聚集写（多个连续的 i3c_msg 缓冲区都配置为 #I3C_MSG_WRITE）可能被某些驱动打包成单个事务，而其他驱动可能将每个片段作为独立的写事务发出，从而产生不同的行为。有关多消息总线事务支持的限制，请参阅 i3c_msg 的文档。
参数
targetI3C 目标设备描述符。
msgs要传输的消息数组。
num_msgs要传输的消息数量。
返回值
0成功时。
-EBUSY总线忙。
-EIO通用输入/输出错误。
-ENODATA若消息设置了 I3C_MSG_NOACK_EXPECTED 标志且目标对传输回复 NACK。

带回调执行从控制器到 I3C 目标设备的异步数据传输。

该例程提供通用接口，以异步方式向目标设备执行数据传输。

消息数组 msgs 不能为 NULL。消息数量 num_msgs 可以为零，此时不发生传输。

注意
Available only when the following Kconfig options are enabled: CONFIG_I3C_CONTROLLER, CONFIG_I3C_CALLBACK.
注解
并非所有驱动都支持全部分散/聚集（scatter/gather）事务。例如，聚集写（多个连续的 i3c_msg 缓冲区都配置为 #I3C_MSG_WRITE）可能被某些驱动打包成单个事务，而其他驱动可能将每个片段作为独立的写事务发出，从而产生不同的行为。有关多消息总线事务支持的限制，请参阅 i3c_msg 的文档。
参数
targetI3C 目标设备描述符。
msgs要传输的消息数组。
num_msgs要传输的消息数量。
cb完成回调的函数指针。
userdata传给回调的用户数据。
返回值
0If successful.
-EBUSY总线忙。
-EIO通用输入/输出错误。
