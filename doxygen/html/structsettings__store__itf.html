◆ csi_load

int(*) settings_store_itf::csi_load(struct settings_store *cs, const struct settings_load_arg *arg)

从存储中加载值，范围限定为由 subtree 定义的子树。

参数
[in]cs对应的后端处理函数节点，
[in]arg用于保存数据加载附加数据的结构体。
注解
后端不应提供重复实体。这意味着如果后端没有任何真正删除旧键的功能，它必须过滤掉旧实体，并只对最终实体调用加载回调。
返回
成功时为与 name 对应的值的实际大小，失败时为负值。
