#define GROUP_LINK_IN ( where)

将内存路由到指定的内存区域

GROUP_LINK_IN() 宏位于段描述的末尾，告诉链接器该段位于 'where' 参数指定的内存区域中。

对于 CONFIG_MMU 系统，当 CONFIG_KERNEL_VM_BASE 与 DT_CHOSEN_SRAM_ADDR 不同时，此宏被有意定义为未定义，因为所有段的 LMA 和 VMA 目标都必须已知，这对应于物理位置与虚拟位置。

参数
where目标内存区域

◆ GROUP_ROM_LINK_IN

#define GROUP_ROM_LINK_IN ( vregion,
lregion )
值:
> lregion

为只读段路由内存

GROUP_ROM_LINK_IN() 宏位于段描述的末尾，告诉链接器这是一个只读段，其物理位置在 lregion 参数处。

如果 CONFIG_XIP 处于活动状态，则 lregion 区域是 flash 存储器。

如果 CONFIG_MMU 处于活动状态，将使用 vregion 参数确定它在虚拟内存映射中的位置，否则该参数被忽略。

参数
vregion输出 VMA（仅在 LMA != VMA 的 CONFIG_MMU 情况下使用）
lregion输出 LMA

SECTION_PROLOGUE() 宏用于定义段的起始部分。
定义 linker-tool-gcc.h:170

与 SECTION_PROLOGUE() 相同，但此宏必须用于在 XIP 平台上虚拟地址与加载地址不同的数据段（即它们会在程序启动时被复制到 RAM 中）。这样的段还必须使用 GROUP_DATA_LINK_IN 指定正确的输出加载地址。

在非 XIP 系统上，这等同于 SECTION_PROLOGUE()。在 XIP 系统上，会隐含指定 ALIGN_WITH_INPUT。

参数
name输出段的名称
options段选项，或留空
align对齐指示，例如 SUBALIGN()。不允许使用 ALIGN() 本身。可以留空。
