◆ modbus_custom_cb_t

typedef bool(*) modbus_custom_cb_t(const int iface, const struct modbus_adu *const rx_adu, struct modbus_adu *const tx_adu, uint8_t *const excep_code, void *const user_data)

#include <zephyr/modbus/modbus.h>

自定义功能码处理函数签名。

Modbus 允许使用用户定义的功能码来扩展基础协议。这些回调还可用于实现 Zephyr 的 Modbus 子系统目前不支持的功能码。

如果在处理请求期间发生错误，处理函数应将 excep_code 设为某个 modbus 异常码以示明。

用户数据指针可用于在处理函数的后续调用之间传递状态。

参数
ifaceModbus 接口索引
rx_adu指向所接收 ADU 结构体的指针
tx_adu指向要发出的 ADU 结构体的指针
excep_code指向可能的异常码的指针
user_data指向用户数据的指针
返回
如果应发送响应则为 true，否则为 false
