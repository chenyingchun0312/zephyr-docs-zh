◆ explicit_call_transfer

void(*) bt_hfp_ag_cb::explicit_call_transfer(struct bt_hfp_ag *ag)

HF 显式呼叫转移回调

如果提供了此回调，则每当从 HF 发送 AT+CHLD=4 时都会调用它。通知回调时，应用程序应连接这两路呼叫，并断开用户与这两路呼叫的连接（显式呼叫转移）。回调返回后，呼叫对象将失效。如果该回调为 NULL，则 AT 命令的响应结果码将为 AT ERROR。如果未启用 CONFIG_BT_HFP_AG_3WAY_CALL，则不会通知该回调。

参数
agHFP AG object.

◆ get_indicator_value

int(*) bt_hfp_ag_cb::get_indicator_value(struct bt_hfp_ag *ag, uint8_t *service, uint8_t *strength, uint8_t *roam, uint8_t *battery)

获取指示器值回调

如果提供了此回调，则每当 AG 需要向 HF 提供当前指示器值时都会调用它。这通常发生在 HF 发送 AT+CIND? 命令查询 AG 指示器当前状态时。

应用程序应通过所提供的指针填充指示器值。所有指示器值都应根据 AG 的当前状态设置。

参数
agHFP AG object.
service用于存放服务可用性指示器值的指针。0 = 服务不可用，1 = 服务可用。
strength用于存放信号强度指示器值的指针。范围：0-5（0 = 无信号，5 = 信号最强）。
roam用于存放漫游状态指示器值的指针。0 = 未漫游，1 = 漫游。
battery用于存放电池电量指示器值的指针。范围：0-5（0 = 电量耗尽，5 = 电量充满）。
注解
AG 处于 SLC 建立阶段。此时不会通知 AG 回调 connected()。
如果应用程序未提供该回调或返回的错误不为零，则所有这些指示器的值都将默认设为 0。具体值可通过调用专用函数设置并通知。例如，service availability indicator value 可通过调用函数 bt_hfp_ag_service_availability() 设置；signal strength value 可通过调用 bt_hfp_ag_signal_strength() 设置，依此类推。
返回
成功时为 0，出错时为负值。

◆ get_ongoing_call

int(*) bt_hfp_ag_cb::get_ongoing_call(struct bt_hfp_ag *ag)

获取正在进行的呼叫信息的回调

如果提供了此回调，则每当收到来自 HF 的 AT+CIND? 命令时都会调用它。在回调通知后，应在超时时间内通过函数 bt_hfp_ag_ongoing_calls() 设置正在进行的呼叫 CONFIG_BT_HFP_AG_GET_ONGOING_CALL_TIMEOUT.

参数
agHFP AG object.
注解
AG 处于 SLC 建立阶段。此时不会通知 AG 回调 connected()。
返回
成功时为 0。响应 +CIND 将在调用函数 bt_hfp_ag_ongoing_calls() 之后或超过时间之后发送 CONFIG_BT_HFP_AG_GET_ONGOING_CALL_TIMEOUT. Or negative value in case of error. The response +CIND will be replied immediately.

◆ ready_to_accept_audio

void(*) bt_hfp_ag_cb::ready_to_accept_audio(struct bt_hfp_ag *ag)

已准备好接受音频的回调

如果提供了此回调，则每当 HF 准备好接受音频时都会调用它。如果 HF 支持 Enhanced Voice Recognition Status 特性，则在收到 AT 命令 AT+BVRA=2 时会通知该回调。HF 可在正在进行的 VR（语音识别）会话期间发送此值，以终止 AG 的音频输出（如有）并为新的音频输入做准备。或者，在语音识别激活后也会通知该回调。如果未启用 CONFIG_BT_HFP_AG_ENH_VOICE_RECG，则不会通知该回调。

参数
agHFP AG object.

◆ redial

int(*) bt_hfp_ag_cb::redial(struct bt_hfp_ag *ag, char number[CONFIG_BT_HFP_AG_PHONE_NUMBER_MAX_LEN+1])

HF 末位号码重拨请求回调

如果提供了此回调，则每当通过 AT+BLDN 命令收到来自 HF 的末位号码重拨请求时都会调用它。触发回调时，应用程序需要提供最后拨出的电话号码。如果该回调无效，则无法支持从 HF 末位号码重拨。

应用程序应：

  1. 从其呼叫历史记录中获取最后拨出的电话号码
  2. 将电话号码复制到所提供的缓冲区
参数
agHFP AG object.
number用于存放最后拨出电话号码的缓冲区。缓冲区大小为 CONFIG_BT_HFP_AG_PHONE_NUMBER_MAX_LEN + 1，且应以 NUL 结尾。
返回
成功时为 0，出错时为负值。如果成功，AG 将继续进行呼叫建立过程。如果出错，将向 HF 发送 ERROR 响应。
