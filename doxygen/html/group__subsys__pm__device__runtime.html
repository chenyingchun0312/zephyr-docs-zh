◆ pm_device_runtime_get()

int pm_device_runtime_get ( const struct device * dev)
pre-kernel-ok

#include <zephyr/pm/device_runtime.h>

基于使用计数恢复设备。

如果设备已挂起（使用计数等于 0），此函数将恢复该设备。若恢复失败，使用计数和设备状态将保持不变。在其他所有情况下，使用计数将递增。

如果由于调用 pm_device_runtime_put_async() 而设备仍在挂起过程中，此函数将等待该操作完成后再恢复设备。

注解
只要设备 PM 实现不会阻塞，就可以在不允许阻塞的上下文（例如 ISR）中安全使用此函数。
参数
dev设备实例。
返回
成功时为 0（包括运行时 PM 未启用或不可用的情况），失败时为负的 errno 值。
返回值
-EWOULDBLOCK调用将阻塞，但当前不允许阻塞（例如在 ISR 中）。

◆ pm_device_runtime_put()

int pm_device_runtime_put ( const struct device * dev)
pre-kernel-ok

#include <zephyr/pm/device_runtime.h>

基于使用计数挂起设备。

如果设备不再被需要（使用计数等于 0），此函数将挂起该设备。若挂起失败，使用计数和设备状态将保持不变。在其他所有情况下，使用计数将递减（直至 0）。

参数
dev设备实例。
返回
成功时为 0（包括运行时 PM 未启用或不可用的情况），失败时为负的 errno 值。
返回值
-EALREADY设备已处于挂起状态（只可能发生在 get/put 调用不配对时）。
参见
pm_device_runtime_put_async()

◆ pm_device_runtime_put_async()

int pm_device_runtime_put_async ( const struct device * dev,
k_timeout_t delay )
pre-kernel-okasyncisr-ok

#include <zephyr/pm/device_runtime.h>

基于使用计数异步挂起设备。

如果设备不再被需要（使用计数等于 0），此函数将排定挂起该设备。在其他所有情况下，使用计数将递减（直至 0）。

注解
内核启动前模式下不支持异步操作。此时该函数将阻塞（等同于 pm_device_runtime_put()）。
参数
dev设备实例。
delay触发该动作之前的最短时间。
返回
成功时为 0（包括运行时 PM 未启用或不可用的情况），失败时为负的 errno 值。
返回值
-EBUSY设备忙碌。
-EALREADY设备已处于挂起状态（只可能发生在 get/put 调用不配对时）。
参见
pm_device_runtime_put()
