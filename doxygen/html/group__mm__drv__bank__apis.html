内存块驱动 API

包含供系统级内存管理驱动使用的 API，用于跟踪内存块内的页面使用情况。

注解
这些函数的调用方需要确保进行适当的加锁以保护数据。

#include <zephyr/drivers/mm/mm_drv_bank.h>

初始化内存块的数据结构

驱动可能希望跟踪其使用的内存块的各种信息。此例程将初始化一个包含这些信息的通用结构体。由于上电时所有内存块都处于开启状态，因此将从所有页面均已映射的状态开始。在驱动初始化的下一阶段，未使用的页面将被取消映射。

参数
[in,out]bank指向用于跟踪的内存块结构体的指针
[in]bank_pages内存块中的页面数量
