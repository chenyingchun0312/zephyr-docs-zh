◆ tty_init()

int tty_init ( struct tty_serial * tty,
const struct device * uart_dev )

初始化串口对象（传统上称为 tty）。

"tty" 设备支持对底层 UART 设备进行带缓冲、中断驱动、超时可控的访问。为完整起见，它也支持非中断驱动的忙轮询访问模式。初始化后，tty 处于“最保守的”无缓冲模式，超时为无限（这可保证在任何硬件上工作）。用户应使用 tty_set_rx_buf()、tty_set_tx_buf()、tty_set_rx_timeout()、tty_set_tx_timeout() 按需配置缓冲区和超时。

参数
tty要初始化的 tty 设备结构体
uart_dev要使用的底层 UART 设备（应支持中断驱动操作）
返回
成功时为 0，否则为错误码（<0）

参数

返回
>0，实际读取的字节数（可能小于 size 参数）；=0，类似 EOF 的情况（例如收到 break 信号）；<0，出错（例如超时到期时为 -EAGAIN）。同时会设置 errno 变量。
