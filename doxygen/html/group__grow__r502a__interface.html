◆ sensor_attribute_grow_r502a

enum sensor_attribute_grow_r502a

#include <zephyr/drivers/sensor/grow_r502a.h>

Grow R502A 的自定义传感器属性

枚举值
SENSOR_ATTR_R502A_CAPTURE 

采集手指并作为特征文件存入 RAM 缓冲区 char_buf_1 和 char_buf_2。

SENSOR_ATTR_R502A_TEMPLATE_CREATE 

从 RAM 缓冲区 char_buf_1 和 char_buf_2 中的特征文件创建模板，并将模板数据存回这两个 RAM 缓冲区。

SENSOR_ATTR_R502A_RECORD_ADD 

将模板添加到传感器记录存储中

sensor_value.val1 为要存入传感器设备 Flash 的模板记录索引

SENSOR_ATTR_R502A_RECORD_FIND 

在记录存储中查找请求的数据

sensor_value.val1 为匹配的记录索引。sensor_value.val2 为匹配得分。

SENSOR_ATTR_R502A_RECORD_DEL 

从记录存储中删除指定数据

sensor_value.val1 为要删除的记录起始索引。sensor_value.val2 为要删除的记录数量。

SENSOR_ATTR_R502A_RECORD_FREE_IDX 

获取记录存储中可用于存放数据的空闲位置

SENSOR_ATTR_R502A_RECORD_EMPTY 

清空存储记录

SENSOR_ATTR_R502A_RECORD_LOAD 

将模板从存储加载到传感器的 RAM 缓冲区

sensor_value.val1 为要加载到设备内部 RAM 缓冲区的记录起始索引。

SENSOR_ATTR_R502A_COMPARE 

存放在传感器 RAM 缓冲区中的模板数据

sensor_value.val1 为匹配结果（R502A_FINGER_MATCH_FOUND 或 R502A_FINGER_MATCH_NOT_FOUND），sensor_value.val2 为匹配得分。

SENSOR_ATTR_R502A_SYS_PARAM 

设置设备的系统参数

sensor_value.val1 为 enum r502a_sys_param_set 中的参数编号。sensor_value.val2 为相应参数要写入的内容。
