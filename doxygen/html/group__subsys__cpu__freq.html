函数说明

◆ cpu_freq_pstate_set()

int cpu_freq_pstate_set ( const struct pstate * state)

#include <zephyr/cpu_freq/cpu_freq.h>

请求处理器设置给定的性能状态。

由 SoC 实现。此 API 抽象了更改当前 CPU 性能状态所需的硬件和 SoC 特定调用。调用者必须确保当前 CPU 不发生变更。若从 ISR 或单 CPU 系统调用，该限制自动满足。若在 SMP 系统的线程中调用，则必须禁用中断或调度器，以确保当前 CPU 不发生变更。

注解
并不保证性能状态会立即设置，甚至不保证会被设置。
参数
state指向性能状态的指针。
返回
成功接收请求时为 0，失败时为 -errno。
