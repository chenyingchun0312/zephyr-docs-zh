◆ mcp_tool_callback_t

typedef int(*) mcp_tool_callback_t(enum mcp_tool_event_type event, const char *arguments, const char *execution_token)

#include <zephyr/net/mcp/mcp_server.h>

工具回调函数

参数
event工具事件的类型（调用或取消请求）
arguments含工具参数的 JSON 字符串
execution_token唯一执行标识符（UUID 字符串）
注解
此回调在 MCP 请求工作线程的上下文中执行。默认工作线程栈大小为 CONFIG_MCP_REQUEST_WORKER_STACK_SIZE。如果工具回调需要更多栈空间，请增大该值。 
  对大型缓冲区考虑使用堆分配，以尽量减少栈占用。

  此回调会阻塞 MCP 服务器工作线程。对于长时间运行的操作，建议使用自己的线程池异步执行工作，并尽快从此回调返回，以避免阻塞 MCP 服务器工作线程并可能导致服务器响应能力下降。

     是否允许同一工具并发执行，由用户应用程序自行决定。
返回
成功时为 0，失败时为负的 errno

用于检查工具执行状态的辅助函数

注解
检查取消的另一种方式。主要检查应通过工具调用事件（struct mcp_tool_event_type）进行。此检查函数需要使用互斥量和线性查找来定位所需的执行上下文。
