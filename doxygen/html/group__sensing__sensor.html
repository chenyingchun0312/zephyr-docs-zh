类似 SENSOR_DEVICE_DT_DEFINE()，但带有 sensing 特定内容。

定义一个实现传感器 API 的传感器。可能会在用于枚举所有 sensing 传感器的 sensing 传感器可迭代段中定义一个元素。

参数
node设备树节点标识符。
reg_ptr指向设备 sensing_sensor_register_info 的指针。
cb_list_ptr指向 sensing 回调列表的指针。
init_fn驱动初始化函数的名称。
pm_devicePM 设备资源引用（若设备不使用 PM 则为 NULL）。
data_ptr设备私有数据的指针。
cfg_ptr包含该驱动实例配置信息的结构体的地址。
level初始化级别。详情参见 SYS_INIT()。
prio所选初始化级别内的优先级。详情参见 SYS_INIT()。
api_ptr提供驱动所用 API 函数结构体的初始指针。可以为 NULL。

#include <zephyr/sensing/sensing_sensor.h>

按传感器类型获取给定传感器实例的报告者句柄。

参数
dev传感器实例的设备结构体。
type给定类型，使用 SENSING_SENSOR_TYPE_ALL 可获取所有类型的报告者。
max_handles输入的 reporter_handles 数组的最大数量。可通过 sensing_sensor_get_reporters_count 获取实际数量。
reporter_handles用于接收找到的报告者传感器实例的输入句柄数组
返回
找到的报告者数量，未找到时返回 0。
