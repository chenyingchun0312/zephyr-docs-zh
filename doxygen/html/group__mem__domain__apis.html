◆ k_mem_domain_add_partition()

int k_mem_domain_add_partition ( struct k_mem_domain * domain,
struct k_mem_partition * part )

#include <zephyr/app_memory/mem_domain.h>

将内存分区添加到内存域中。

将内存分区添加到内存域中。分区必须符合以下约束：

  • 同一内存域中的分区不得相互重叠。
  • 不得定义暴露私有内核数据结构或内核对象的分区。
  • 起始地址的对齐和分区大小必须符合底层内存管理硬件的约束，这些约束因架构而异。
  • 内存域分区仅用于控制用户模式线程对内存的访问。
  • 如果启用了 CONFIG_EXECUTE_XOR_WRITE，则分区不得同时允许写入和执行。

违反这些约束可能导致 CPU 异常或未定义行为。

参数
domain要添加内存分区的内存域。
part要添加的内存分区
返回值
0成功时
-EINVAL如果提供的参数无效
-ENOSPC如果没有空闲的分区槽位可用

◆ k_mem_domain_init()

int k_mem_domain_init ( struct k_mem_domain * domain,
uint8_t num_parts,
struct k_mem_partition * parts[] )

#include <zephyr/app_memory/mem_domain.h>

初始化内存域。

用给定的名称和内存分区初始化内存域。

有关分区约束的详细信息，请参阅 k_mem_domain_add_partition() 的文档。

不要对同一个内存域多次调用 k_mem_domain_init()，这样做会导致未定义行为。

参数
domain要初始化的内存域。
num_parts“parts”参数的数组项数。
parts指向内存分区的指针数组。如果 num_parts 为零，则可以为 NULL。
返回值
0成功时
-EINVAL如果提供的参数无效
-ENOMEM如果内存不足

◆ k_mem_domain_default

struct k_mem_domain k_mem_domain_default
extern

#include <zephyr/app_memory/mem_domain.h>

默认内存域

所有线程都是某个内存域的成员，即使运行在超级用户模式下也是如此。如果线程未被添加到其他域或从其他域继承成员关系，则它属于此默认内存域。

如果 C 库的 z_libc_partition 分区存在，此内存域会将其加入。
