◆ net_config_init_clock_via_sntp()

int net_config_init_clock_via_sntp ( void )
inlinestatic

#include <zephyr/net/net_config.h>

使用 SNTP 初始化系统时钟。

查询配置的 SNTP 服务器，并根据响应设置系统实时时钟（可选地还设置 RTC 设备，参见 CONFIG_NET_CONFIG_CLOCK_SNTP_SET_RTC）。该调用最多阻塞 CONFIG_NET_CONFIG_SNTP_INIT_TIMEOUT 毫秒。

要查询的服务器按优先级依次为：

  1. 通过 net_config_sntp_set_server() 设置的那个（如果满足条件） CONFIG_NET_CONFIG_SNTP_INIT_SERVER_RUNTIME is enabled,
  2. 通过 DHCPv4 NTP 服务器选项收到的那个（如果满足条件） CONFIG_NET_CONFIG_SNTP_INIT_SERVER_USE_DHCPV4_OPTION is enabled,
  3. 在 CONFIG_NET_CONFIG_SNTP_INIT_SERVER 中设置的那个。

此函数由 net_config_init_app 调用，除非使用连接管理器来驱动 SNTP 客户端（参见 CONFIG_NET_CONFIG_SNTP_INIT_USE_CONNECTION_MANAGER）。

返回
如果时钟已设置则为 0，出错时小于 0。

inlinestatic

在设备上初始化 SSH 服务器。

参数
iface用于 SSH 服务器的网络接口。如果为 NULL，SSH 服务器将绑定到通配地址，并可通过所有网络接口访问。
priv_key_configSSH 服务器的私钥配置。
pub_key_configSSH 服务器的公钥配置。
password_auth_configSSH 服务器的密码认证配置。如果使用公钥认证，则此项可以保留为 NULL，或用户名和密码均为 NULL。公钥认证的优先级高于密码认证，因此如果两者都配置，则只有公钥认证失败时才会使用密码认证。如果你想为公钥认证指定用户名，则应在 password_auth_config 结构体中设置用户名，即使不使用密码认证。这是因为 SSH 服务器需要知道用户名才能将其与公钥关联。
sshd_instanceSSH 服务器实例编号。它用于标识 SSH 服务器实例，如果定义了多个实例则必须唯一。
返回
如果 SSH 服务器初始化成功则为 0，如果出错则小于 0。

#include <zephyr/net/net_config.h>

设置用于初始化系统时钟的 SNTP 服务器。

通过此函数设置的服务器优先于通过 DHCP 获得的服务器（如果满足条件） CONFIG_NET_CONFIG_SNTP_INIT_SERVER_USE_DHCPV4_OPTION is enabled, and over the server set in CONFIG_NET_CONFIG_SNTP_INIT_SERVER.

参数
server要使用的服务器的主机名或 IP 地址。NULL 或空字符串会取消先前设置的服务器。
返回
如果 SNTP 服务器设置成功则为 0，如果出错则小于 0。
