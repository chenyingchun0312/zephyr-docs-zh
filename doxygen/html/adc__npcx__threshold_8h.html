int adc_npcx_threshold_ctrl_enable ( const struct device * dev,
uint8_t th_sel,
const bool enable )

启用/禁用 ADC 阈值中断。

注解
仅当选中 CONFIG_ADC_CMP_NPCX 时此函数才可用。
参数
dev指向该驱动实例设备结构的指针。
th_sel选定的阈值。
enable启用或禁用阈值中断。
返回
成功时为 0，否则为负的错误码。启用阈值中断前必须配置好所有参数，否则将返回错误。
