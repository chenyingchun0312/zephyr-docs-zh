◆ log_backend_init()

void log_backend_init ( const struct log_backend *const backend)
inlinestatic

#include <zephyr/logging/log_backend.h>

初始化或启动日志后端。

如果后端初始化耗时较长，且后端是自动启动的，可能会阻塞日志线程。这是因为所有后端都在日志线程的上下文中初始化。在这种情况下，后端应提供用于轮询就绪状态的函数（log_backend_is_ready）。

参数
[in]backend指向后端实例的指针。
