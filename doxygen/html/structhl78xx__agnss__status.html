A-GNSS 辅助数据状态结构体

包含 AT+GNSSAD? 命令的解析结果。当 mode 为 VALID 时，到期字段表示剩余时间。

注意
Available only when the following Kconfig option is enabled: CONFIG_HL78XX_GNSS_SUPPORT_ASSISTED_MODE.
