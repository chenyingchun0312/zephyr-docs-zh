◆ ticks

uint32_t counter_alarm_cfg::ticks

触发闹钟的定时计数。

它可以是相对值（相对于当前）或绝对值（参见 COUNTER_ALARM_CFG_ABSOLUTE）。相对值和绝对闹钟值都可以是零到当前顶部值之间的任何值（参见 counter_get_top_value). When setting an absolute alarm value close to the current counter value there is a risk that the counter will have counted past the given absolute value before the driver manages to activate the alarm. Therefore a guard period can be defined that lets the driver decide unambiguously whether it is late or not (see counter_set_guard_period). If the counter is clock driven then ticks can be converted to microseconds (see counter_ticks_to_us). Alternatively, the counter implementation may count asynchronous events.
