◆ input_queue_empty()

bool input_queue_empty ( void )

#include <zephyr/input/input.h>

如果输入队列为空则返回 true。

可用于批量处理输入事件，直到整个队列被清空。如果启用了 CONFIG_INPUT_MODE_SYNCHRONOUS，则始终返回 true。

◆ input_report()

int input_report ( const struct device * dev,
uint8_t type,
uint16_t code,
int32_t value,
bool sync,
k_timeout_t timeout )

#include <zephyr/input/input.h>

报告一个新的输入事件。

这会导致对指定设备的所有回调被执行，可以同步执行，也可以通过输入线程执行（如果使用了线程）。

参数
dev生成该事件的设备，或 NULL。
type事件类型（参见 INPUT_EV_CODES）。
code事件代码（参见 INPUT_KEY_CODES、 INPUT_BTN_CODES、 INPUT_ABS_CODES, INPUT_REL_CODES, INPUT_MSC_CODES).
value事件值。
sync设置该事件的同步位。
timeout报告事件的超时时间，若满足以下条件则忽略 CONFIG_INPUT_MODE_SYNCHRONOUS is used.
返回值
0如果消息已处理。
<0如果启用了 CONFIG_INPUT_MODE_THREAD 且消息入队失败，则为负值。

◆ input_to_hid_code()

int16_t input_to_hid_code ( uint16_t input_code)

#include <zephyr/input/input_hid.h>

将输入代码转换为 HID 代码。

接受输入代码作为输入，返回对应的 HID 代码作为输出。如果未找到该代码，返回值为 -1；如果找到，可以安全地将其转换为 uint8_t 类型。

参数
input_code事件代码（参见 INPUT_KEY_CODES）。
返回
与输入代码对应的 HID 代码。
返回值
-1如果指定的输入代码没有对应的 HID 代码。
