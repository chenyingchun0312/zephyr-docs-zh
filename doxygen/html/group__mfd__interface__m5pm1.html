详细描述

M5Stack M5PM1 电源管理协处理器 MCU 接口。

自从
4.5
版本
0.1.0

M5PM1 是 M5Stack 开发板上使用的小型协处理器 MCU，用于提供电源管理（电池充电、可切换电源轨）、少量 GPIO 以及片上 ADC。此 MFD 驱动负责 I2C 传输并串行化寄存器访问；与之并列的 GPIO、ADC 和稳压器驱动在这些原语之上实现各自领域的功能。

◆ m5pm1_pin_func

enum m5pm1_pin_func

#include <zephyr/drivers/mfd/m5pm1.h>

M5PM1 复用引脚的语义功能。

每个引脚通过 GPIO_FUNC0/GPIO_FUNC1 中的 2 位字段选择其功能。标准 GPIO 和 IRQ 功能存在于所有引脚上，但“特殊”功能（寄存器值 0b11）在每个引脚上对应不同的外设，因此有效性需逐引脚检查（参见 mfd_m5pm1_pin_request()）：

  • IO0: M5PM1_PIN_FUNC_NEOPIXEL
  • IO1, IO2: M5PM1_PIN_FUNC_ADC
  • IO3, IO4: M5PM1_PIN_FUNC_PWM
枚举值
M5PM1_PIN_FUNC_GPIO 

标准 GPIO（FUNC 字段 0b00）。

M5PM1_PIN_FUNC_IRQ 

IRQ 输入（FUNC 字段 0b01）。

M5PM1_PIN_FUNC_ADC 

ADC 输入（FUNC 字段 0b11，仅 IO1/IO2）。

M5PM1_PIN_FUNC_PWM 

PWM 输出（FUNC 字段 0b11，仅 IO3/IO4）。

M5PM1_PIN_FUNC_NEOPIXEL 

NeoPixel 输出（FUNC 字段 0b11，仅 IO0）。

int mfd_m5pm1_burst_read ( const struct device * dev,
uint8_t reg,
uint8_t * buf,
size_t len )

#include <zephyr/drivers/mfd/m5pm1.h>

在单次 I2C 事务中读取多个连续的 M5PM1 寄存器。

使用单次重复起始的 I2C 传输，使设备将该读取视为原子操作，这对在读取低字节时锁存的寄存器对（例如 ADC 采样寄存器）很重要。

重要事项
The M5PM1 only allows continuous reads of certain register ranges, please refer to the datasheet for more details.
参数
devM5PM1 MFD device.
reg要读取的第一个寄存器地址。
[out]buf接收 len 个连续寄存器值的缓冲区。
len要读取的字节数。
返回值
0Success.
-errnoI2C 传输错误（参见 i2c_burst_read_dt()）。

◆ mfd_m5pm1_pin_request()

int mfd_m5pm1_pin_request ( const struct device * dev,
const struct device * client,
uint8_t pin,
enum m5pm1_pin_func func )

#include <zephyr/drivers/mfd/m5pm1.h>

代表并列驱动为给定功能占用某个引脚。

M5PM1 的引脚在多个外设（GPIO、ADC、PWM、NeoPixel）之间复用，其并列驱动都共享 GPIO_FUNC0/GPIO_FUNC1 选择寄存器。此例程集中处理该复用：它验证 func 在 pin 上是否可用，写入该引脚的功能字段，并记录 client 为引脚所有者。一个引脚只能由一个客户端拥有；这可避免开发板误将同一引脚接到两个不兼容的使用方。

对于当前所有者，请求是幂等的：同一个 client 可以再次调用（例如更改其自身的功能）而不会出错。

参数
devM5PM1 MFD device.
client请求该引脚的设备（用作所有权令牌）。
pin引脚索引（0..M5PM1_GPIO_COUNT-1）。
func要配置的功能（参见 m5pm1_pin_func）。
返回值
0Success.
-EINVALpin 超出范围。
-ENOTSUPfunc 在 pin 上不可用。
-EBUSYpin 已被其他客户端拥有。
-errnoI2C 传输错误。

对 reg 执行原子（受互斥量保护）的读-改-写，反转由 mask. Holding the lock across the read and write makes the toggle atomic with respect to the other mfd_m5pm1_*() accessors.
