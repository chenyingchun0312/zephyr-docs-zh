具有公开作用域的内部内核 API

任何以实现为内联函数形式提供、且需要调用架构特定 API 的公开内核 API，其架构特定 API 的原型都放在此处。不以这种方式使用的架构 API 放在 kernel/include/kernel_arch_interface.h 中。

公开宏和公开头文件中的内联函数在内部使用的架构特定 API 集合，也在此处指定并记录。

对于此处描述的所有宏和内联函数原型，<arch/cpu.h> 最终必须引入它们的完整定义（实际的宏定义和内联函数体）

include/zephyr/kernel.h 及其他公开头文件依赖此头文件中的定义。
