详细描述

用于编码 CH32 外设复位单元的宏。

用于在 CH32 器件上编码外设复位的设备树宏，配合 wch,ch32-rcc-rctl 兼容的复位控制器使用。

每个 SoC 系列的头文件（例如 ch32v20x_30x-reset.h）以 CH32_RESET_BUS_<bus> 常量的形式定义该系列的 RCC 总线复位寄存器偏移。外设复位单元由 CH32_RESET() 编码，方法是将总线常量与该外设复位线在该总线复位寄存器中的位位置组合起来。

#include <zephyr/dt-bindings/reset/ch32v20x_30x-reset.h>
&usart1 {
resets = <&rctl CH32_RESET(APB2, 14)>;
}

为 wch,ch32-rcc-rctl 绑定编码外设复位单元的值。

将 RCC 总线寄存器偏移与位位置打包为一个 32 位复位单元值。

位 [4:0] 保存复位位在 32 位 RCC 总线寄存器中的位置；位 [16:5] 保存相对于 RCC 基址的 RCC 寄存器字节偏移。
