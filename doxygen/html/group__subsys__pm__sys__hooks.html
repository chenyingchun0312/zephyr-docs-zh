void pm_state_exit_post_ops ( enum pm_state state,
uint8_t substate_id )

#include <zephyr/pm/pm.h>

在休眠状态退出后执行任何 SoC 或架构特定的后续操作。

此函数是一个占位符，用于执行休眠状态退出后可能需要的任何操作。默认情况下，它在系统管理的设备已恢复之后、PM 退出通知和系统时钟空闲退出核算之前、且中断仍处于锁定状态时被调用。

启用 CONFIG_PM_EARLY_SYSTEM_TIMER_RESUME 时，此钩子在系统时钟空闲退出核算和系统管理设备恢复之前运行。启用此实验性顺序的平台必须确保此钩子不依赖于设备已被恢复，例如在释放 I/O 保持或隔离时。

未选择 CONFIG_PM_STATE_SET_IRQ_UNLOCKED 的实现只能将此钩子用于硬件恢复操作。它们不得从此钩子解除中断屏蔽或以其他方式分发挂起的唤醒源 ISR；内核空闲路径会在 PM 恢复清理完成后恢复原始中断状态。

注解
在这两种顺序中，此钩子运行时系统定时器都尚未重启。如果低功耗状态停止了该定时器，则等待该定时器的代码（例如基于定时器的 k_busy_wait()）可能永远不会返回。
与 pm_state_set 一样，当系统 PM 在恢复期间保持中断锁定状态时，此顺序只涵盖 arch_irq_lock() 能够屏蔽的中断。零延迟中断（IRQ_ZERO_LATENCY）可能在此钩子完成之前的恢复窗口内运行，并且必须对 PM 唤醒安全（参见 pm_state_set）。
参数
state电源状态。
substate_id电源子状态 ID。

◆ pm_state_set()

void pm_state_set ( enum pm_state state,
uint8_t substate_id )

#include <zephyr/pm/pm.h>

将处理器置于某个电源状态。

此函数实现将处理器置于可用电源状态所需的 SoC 特定细节。选择 CONFIG_PM_STATE_SET_IRQ_UNLOCKED 的实现仍可沿用在此钩子中解除中断屏蔽的旧行为。其他实现不得从此钩子解除中断屏蔽或以其他方式分发挂起的唤醒源 ISR。架构辅助函数可以在低功耗指令前后立即调整中断状态，但内核空闲路径会在 PM 恢复清理完成后恢复原始中断状态。

注解
当系统 PM 在恢复期间保持中断锁定状态时，锁定恢复的顺序保证只涵盖 arch_irq_lock() 能够屏蔽的中断。零延迟中断（IRQ_ZERO_LATENCY）不在此顺序保证之内，它必须对 PM 唤醒安全，或者在系统状态不允许执行其 ISR 期间屏蔽或禁用其中断源。
参数
state电源状态。
substate_id电源子状态 ID。
