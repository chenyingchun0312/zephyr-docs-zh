◆ enable

int(*) shell_transport_api::enable(const struct shell_transport *transport, bool blocking_tx)

用于以给定 TX 模式启用传输层的函数。

可用该函数重新配置 TX 以在阻塞模式下工作。

参数
transport指向传输实例的指针。
blocking_tx若为 true，则以阻塞模式启用传输层 TX。
返回
成功时为 0，失败时为负的 errno 码（包括该操作不受支持时）。
