在公开（非静态）作用域中静态定义并初始化内存块。

内存块的缓冲区包含 slab_num_blocks 个长度为 slab_block_size 字节的内存块。该缓冲区对齐到 slab_align -byte boundary. To ensure that each memory block is similarly aligned to this boundary, slab_block_size must also be a multiple of slab_align.

内存块可在定义它的模块之外通过以下方式访问：

extern struct k_mem_slab <name>;
注解
This macro cannot be used together with a static keyword. If such a use-case is desired, use K_MEM_SLAB_DEFINE_STATIC instead.
参数
nameName of the memory slab.
slab_block_sizeSize of each memory block (in bytes).
slab_num_blocksNumber memory blocks.
slab_alignAlignment of the memory slab's buffer (power of 2).

◆ k_mem_slab_alloc()

int k_mem_slab_alloc ( struct k_mem_slab * slab,
void ** mem,
k_timeout_t timeout )
isr-ok

#include <zephyr/kernel.h>

从内存块分配内存。

此例程从内存块（slab）中分配一个内存块。

注解
如果从 ISR 调用，timeout 必须设置为 K_NO_WAIT。
当 CONFIG_MULTITHREADING=n 时，任何 timeout 都被视为 K_NO_WAIT。
参数
slab内存块的地址。
mem指向块地址区域的指针。
timeout等待操作完成的等待时间。使用 K_NO_WAIT 表示不等待直接返回，或使用 K_FOREVER 表示按需要等待任意长时间。
返回值
0已分配内存。mem 所指向的块地址区域被设为该内存块的起始地址。
-ENOMEM未等待即返回。
-EAGAIN等待时间超时。

◆ k_mem_slab_init()

int k_mem_slab_init ( struct k_mem_slab * slab,
void * buffer,
size_t block_size,
uint32_t num_blocks )

#include <zephyr/kernel.h>

初始化内存块。

在首次使用前初始化内存块。

内存块的缓冲区包含 slab_num_blocks 个长度为 slab_block_size 字节的内存块。缓冲区必须对齐到与字边界匹配的 N 字节边界，其中 N 是 2 的幂（即 32 位系统上为 4，也可为 8、16 等）。为确保每个内存块也同样对齐到该边界， slab_block_size must also be a multiple of N.

参数
slab内存块的地址。
buffer指向用于内存块的缓冲区的指针。
block_size每个内存块的大小（以字节为单位）。
num_blocks内存块数量。
返回值
0成功时
-EINVAL提供的数据无效
