typedef void(*) usb_audio_data_completion_cb_t(const struct device *dev, struct net_buf *buffer, size_t size)

用于通知应用程序数据已成功发送/接收的回调类型。

参数
dev调用该回调所针对的设备。
buffer指向已成功发送/接收的 net_buf 数据块的指针。如果应用程序使用 data_written_cb 和/或 data_received_cb 回调，则需自行负责释放该缓冲区。
size成功发送/接收的数据量。

◆ usb_audio_data_request_cb_t

typedef void(*) usb_audio_data_request_cb_t(const struct device *dev)

用于通知应用程序主机已请求设备数据、且这些数据可以发送给主机的回调类型。发送数据应使用 usb_audio_send() API 函数。

注解
用户可以不使用此回调，改为尝试在 1 ms 任务中发送。如果主机并未请求数据，每 1 ms 发送一次可能不成功，并可能返回 -EAGAIN。
参数
dev主机向其请求数据的设备。

◆ usb_audio_feature_updated_cb_t

typedef void(*) usb_audio_feature_updated_cb_t(const struct device *dev, const struct usb_audio_fu_evt *evt)

用于通知应用程序主机已更改针对该设备配置的某个特性的回调类型。适用于所有设备。

警告
主机可能不会使用所有已配置的特性。
参数
devUSB 音频设备
evt指向要由应用程序解析的事件的指针。该结构体指针是临时的，仅在此回调执行期间有效。

◆ usb_audio_get_in_frame_size()

size_t usb_audio_get_in_frame_size ( const struct device * dev)

获取主机所接受的帧大小。

弃用
Use USB 音频类 2 设备 API instead.

此函数返回主机对输入设备所期望的帧大小。返回值取决于输入设备配置：

  • 信道数量
  • 采样频率
  • 采样分辨率：设备配置通过设备树覆盖文件完成。
参数
dev被询问帧大小的输入设备。
警告
不要用于仅输出设备（头戴式耳机）。对于仅输出设备，此函数应返回 0。

◆ usb_audio_send()

int usb_audio_send ( const struct device * dev,
struct net_buf * buffer,
size_t len )

使用 USB 音频设备发送数据

弃用
Use USB 音频类 2 设备 API instead.
参数
dev通过其 ISO IN 端点发送数据的 USB 音频设备
buffer指向待发送缓冲区的指针。对于输入设备，用户负责管理该缓冲区。如果发送出错，用户必须决定是丢弃还是重传该缓冲区。缓冲区成功发送后，如果应用程序使用了 data_written_cb 回调，则会传给该回调，否则会自动释放。用户必须提供合适的 net_buf 数据块，尤其是在其大小方面。该信息可通过 usb_audio_get_in_frame_size() API 函数获取。
len要发送数据的长度
返回
成功时为 0，失败时为负的错误码
