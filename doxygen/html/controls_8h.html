摄像头类控制 ID @{

#define VIDEO_CID_CAMERA_CLASS_BASE   0x009a0900
#define VIDEO_CID_EXPOSURE_AUTO   (VIDEO_CID_CAMERA_CLASS_BASE + 1)
 使能对曝光时间和/或光圈孔径的自动调整。当该控制不为 VIDEO_EXPOSURE_MANUAL 时手动修改曝光或光圈是未定义行为。驱动应忽略此类请求。
#define VIDEO_CID_EXPOSURE_ABSOLUTE   (VIDEO_CID_CAMERA_CLASS_BASE + 2)
 确定摄像头传感器的曝光时间。曝光时间受帧间隔限制。驱动应将这些值解释为 100 µs 单位，其中值 1 表示 1/10000 秒，10000 表示 1 秒，100000 表示 10 秒。
#define VIDEO_CID_EXPOSURE_AUTO_PRIORITY   (VIDEO_CID_CAMERA_CLASS_BASE + 3)
 设备是否可以在自动曝光作用下动态改变帧率。适用于 VIDEO_CID_EXPOSURE_AUTO 被设为 VIDEO_EXPOSURE_AUTO 或的情况 VIDEO_EXPOSURE_APERTURE_PRIORITY.
#define VIDEO_CID_PAN_RELATIVE   (VIDEO_CID_CAMERA_CLASS_BASE + 4)
 该只写控制按指定量水平转动摄像头。单位未定义。正值使摄像头向右移动（从上方看为顺时针），负值向左。值为零不产生运动。
#define VIDEO_CID_TILT_RELATIVE   (VIDEO_CID_CAMERA_CLASS_BASE + 5)
 该只写控制按指定量垂直转动摄像头。单位未定义。正值使摄像头向上移动，负值向下。值为零不产生运动。
#define VIDEO_CID_PAN_ABSOLUTE   (VIDEO_CID_CAMERA_CLASS_BASE + 8)
 该控制将摄像头水平转动到指定位置。正值使摄像头向右移动（从上方看为顺时针），负值向左。驱动应将这些值解释为角秒，有效值范围为 -180 * 3600 到 +180 * 3600（含端点）。
#define VIDEO_CID_TILT_ABSOLUTE   (VIDEO_CID_CAMERA_CLASS_BASE + 9)
 该控制将摄像头垂直转动到指定位置。正值使摄像头向上移动，负值向下。驱动应将这些值解释为角秒，有效值范围为 -180 * 3600 到 +180 * 3600（含端点）。
#define VIDEO_CID_FOCUS_ABSOLUTE   (VIDEO_CID_CAMERA_CLASS_BASE + 10)
 该控制将摄像头的焦点设置到指定位置。单位未定义。正值将焦点设得更靠近摄像头，负值则趋向无穷远。
#define VIDEO_CID_FOCUS_RELATIVE   (VIDEO_CID_CAMERA_CLASS_BASE + 11)
 该只写控制按指定量移动摄像头的焦点。单位未定义。正值使焦点更靠近摄像头，负值则趋向无穷远。
#define VIDEO_CID_FOCUS_AUTO   (VIDEO_CID_CAMERA_CLASS_BASE + 12)
 使能连续的自动对焦调整。在该控制开启（设为 1）时手动调整对焦是未定义行为。驱动应忽略此类请求。
#define VIDEO_CID_ZOOM_ABSOLUTE   (VIDEO_CID_CAMERA_CLASS_BASE + 13)
 以绝对值指定物镜焦距。变焦单位由驱动定义，其值应为正整数。
#define VIDEO_CID_ZOOM_RELATIVE   (VIDEO_CID_CAMERA_CLASS_BASE + 14)
 该只写控制相对于当前值设置物镜焦距。正值使变焦镜组向长焦方向移动，负值向广角方向移动。变焦单位由驱动定义。
#define VIDEO_CID_ZOOM_CONTINUOUS   (VIDEO_CID_CAMERA_CLASS_BASE + 15)
 开始连续变焦运动。以指定速度移动物镜镜组，直到达到设备的物理极限或收到明确的停止请求。正值使变焦镜组向长焦方向移动。值为零停止变焦镜组运动。负值使变焦镜组向广角方向移动。变焦速度单位由驱动定义。
#define VIDEO_CID_IRIS_ABSOLUTE   (VIDEO_CID_CAMERA_CLASS_BASE + 17)
 该控制将摄像头的光圈设置到指定值。单位未定义。值越大光圈开得越大，值越小光圈收得越小。
#define VIDEO_CID_IRIS_RELATIVE   (VIDEO_CID_CAMERA_CLASS_BASE + 18)
 该只写控制按指定量修改摄像头的光圈。单位未定义。正值使光圈再开大一档，负值使其再收小一档。
#define VIDEO_CID_AUTO_EXPOSURE_BIAS   (VIDEO_CID_CAMERA_CLASS_BASE + 19)
 自动曝光补偿。
#define VIDEO_CID_WIDE_DYNAMIC_RANGE   (VIDEO_CID_CAMERA_CLASS_BASE + 21)
 使能或禁用摄像头的宽动态范围功能。该功能可在整个场景中光照强度变化显著的条件下获得清晰图像，即同时存在很暗和很亮的区域。在摄像头中，最常见的实现方式是将两帧不同曝光时间的图像合并。
#define VIDEO_CID_PAN_SPEED   (VIDEO_CID_CAMERA_CLASS_BASE + 32)
 该控制以特定速度水平转动摄像头。单位未定义。正值使摄像头向右移动（从上方看为顺时针），负值向左。值为零会在运动进行时停止运动，其他情况无效果。
#define VIDEO_CID_TILT_SPEED   (VIDEO_CID_CAMERA_CLASS_BASE + 33)
 该控制以指定速度垂直转动摄像头。单位未定义。正值使摄像头向上移动，负值向下。值为零会在运动进行时停止运动，其他情况无效果。
#define VIDEO_CID_CAMERA_ORIENTATION   (VIDEO_CID_CAMERA_CLASS_BASE + 34)
 该只读控制描述摄像头在设备上的位置，它报告摄像头的安装位置，即其在设备上的安装位置。该控制对具有明确定义朝向的设备（如手机、笔记本电脑和便携设备）特别有意义，因为该控制是以相对于设备预期使用方向的位置来表示的。，或，被称为具有 VIDEO_CAMERA_ORIENTATION_EXTERNAL orientation.
#define VIDEO_CID_CAMERA_SENSOR_ROTATION   (VIDEO_CID_CAMERA_CLASS_BASE + 35)
 该只读控制描述传感器在设备中的朝向。该值为逆时针方向的旋转校正角度，在图像采集到内存后应用，以补偿摄像头传感器的安装旋转。
