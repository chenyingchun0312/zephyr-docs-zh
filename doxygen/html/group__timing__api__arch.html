架构特定的计时测量 API

实现必要内容，以支持使用架构特定的计时测量机制进行计时测量。

◆ arch_timing_counter_get()

timing_t arch_timing_counter_get ( void )

#include <zephyr/arch/arch_interface.h>

返回计时计数器。

注解
对 arch_timing_counter_get() 的任何调用都必须在 arch_timing_start() 与 arch_timing_stop() 调用之间、并在同一 CPU 核上完成。

注解
并非所有架构都有 64 位精度的计时计数器。由于内部回绕，可能看到该值“倒退”。计时代码必须准备好处理回绕（使用与平台相关的代码，例如在相减之前转换为 uint32_t），或使用 arch_timing_cycles_get()，该函数必须理解这种区别。
返回
计时计数器。

timing_counter_get()

◆ arch_timing_cycles_get()

uint64_t arch_timing_cycles_get ( volatile timing_t *const start,
volatile timing_t *const end )

#include <zephyr/arch/arch_interface.h>

获取 start 与 end 之间的周期数。

注解
对于某些架构，来自计数器的原始数值需要缩放才能得到实际周期数，或者可能在内部回绕。此函数计算两个返回的周期值之间的正定区间。
参数
start指向被测执行开始时计数器的指针。
end指向被测执行停止时计数器的指针。
返回
开始与结束之间的周期数。
参见
timing_cycles_get()
