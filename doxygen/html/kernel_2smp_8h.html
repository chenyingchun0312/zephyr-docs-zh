恢复先前暂停的 CPU。

此函数的工作方式与 k_smp_cpu_start 类似，但不会重新初始化内核为目标 CPU 维护的内部跟踪数据。因此，先前必须已为目标 CPU 调用过 k_smp_cpu_start，并且它必须已可验证地进入空闲/关闭状态（其检测必须由平台层提供）。在平台层有要求（例如要求保留中断栈或空闲栈上的数据）的情况下可以使用它。

注解
此函数不得用于当前正在运行的 CPU。目标 CPU 必须处于暂停状态，或处于允许 CPU 执行恢复过程的某些架构状态。此类状态的检测必须由平台层提供。

启动 CPU。

此例程用于手动启动 id 指定的 CPU。可以在重启曾停止或下电的 CPU 以及其他某些场景下调用它。CPU 完成初始化后，将准备好参与线程调度和执行。

注解
此函数不得用于当前正在运行的 CPU。目标 CPU 必须处于关闭状态，或处于允许 CPU 执行上电过程的某些架构状态。此类状态的检测必须由平台层提供。
这会初始化每个 CPU 的内核结构体，并初始化 MP 操作所需的定时器。如果不需要这些，请使用 k_smp_cpu_resume。
