analog_axis_raw_data_t cb )

#include <zephyr/input/input_analog_axis.h>

设置原始数据回调。

设置一个回调以接收指定模拟轴设备的原始数据。这旨在供应用程序获取用于校准的数据。将 cb 设为 NULL 可禁用该回调。

参数
dev模拟轴设备。
cb要使用的 analog_axis_raw_data_t 回调，NULL 表示禁用。
