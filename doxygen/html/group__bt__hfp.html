◆ bt_hfp_hf_connect()

int bt_hfp_hf_connect ( struct bt_conn * conn,
struct bt_hfp_hf ** hf,
uint8_t channel )

#include <zephyr/bluetooth/classic/hfp_hf.h>

启动服务级连接建立过程

在参数 conn 指定的 ACL 连接上，使用函数 bt_br_discovery_start 发现的特定 RFCOMM 通道，启动服务级连接建立过程。

参数 hf 是输出参数。当服务级连接建立过程无错误地启动时，将分配 HFP HF 对象，如果参数 hf 不是 NULL 指针，则该对象将通过参数 hf 返回。

当服务级连接建立后，将触发注册的回调 connected，通知应用程序服务级连接建立过程已完成。此时 HFP HF 对象是有效的。这意味着该函数无错误调用后，HFP HF 提供的所有接口都只能在注册的回调 connected 触发后才能调用。

参数
connACL 连接对象。
hf已创建的 HFP HF 对象。
channel要连接的对端 rfcomm 通道。
返回
成功时为 0，出错时为负值。

◆ bt_hfp_hf_disconnect()

int bt_hfp_hf_disconnect ( struct bt_hfp_hf * hf)

#include <zephyr/bluetooth/classic/hfp_hf.h>

释放服务级连接

释放与对端设备的服务级连接。

该函数只能在注册的回调 connected 触发后调用。

如果该函数无错误地调用，则此时 HFP HF 对象已失效。不应再调用 HFP HF 提供的任何接口。

如果服务级连接被释放，将触发注册的回调 disconnected，通知应用程序服务级连接释放过程已完成。并且在注册的回调 disconnected 返回后，HFP HF 对象将被释放。

参数
hfHFP HF object.
返回
成功时为 0，出错时为负值。

免提 HF 设置 AG 指示器的激活或停用状态

如果 HF 需要更改 AG 中指示器的激活或停用状态，它允许 HF 发出 AT+BIA 命令。可激活或停用的所有指示器的索引在 enum hfp_hf_ag_indicators 中定义。参数 status 的每一位表示与该索引对应的指示器状态。例如，status 的值 0b111110 表示 AG 指示器 service 需要被停用，其他则需被激活。

hfHFP HF object.

免提 HF 上报麦克风增益（VGM）

上报麦克风增益（VGM）。将向 AG 发送 AT 命令 AT+VGM=<gain>，向 AG 上报其当前麦克风增益级别设置。<gain> 是十进制数值常量，与 HF 控制的特定（取决于实现的）音量级别相关。此命令不会改变 AG 的麦克风增益，只是指示 HF 中麦克风增益的当前值。如果未启用 CONFIG_BT_HFP_HF_VOLUME，调用该函数时将返回错误 -ENOTSUP。对于音量级别同步（Volume Level Synchronization），HF 应用程序可在 HF 连接回调函数中调用该函数设置 VGM 增益值。之后在 HF 连接回调返回后，VGM 增益将发送给 HFP AG。

参数
hfHFP HF object.
gain麦克风增益。
返回
成功时为 0，出错时为负值。
