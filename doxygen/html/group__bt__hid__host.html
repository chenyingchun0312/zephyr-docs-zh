◆ bt_hid_host_connect()

int bt_hid_host_connect ( struct bt_conn * conn,
struct bt_hid_host ** hid )

#include <zephyr/bluetooth/classic/hid_host.h>

向远程 HID 设备发起 HID 连接。

打开 L2CAP 控制通道，并在其建立后打开中断通道。

此处不读取 HID 服务记录。需要报告描述符或设备属性的应用程序自行通过 SDP 发现它们，这样它们也可以自由决定是否在每次连接时都进行发现。

参数
conn到远程设备的 ACL 连接。
hid成功时用于存放 HID 主机实例的指针。
返回
成功时为 0，如果未调用 bt_hid_host_register() 则为 -ENOTSUP，其他失败时为负 errno。

◆ bt_hid_host_create_pdu()

struct net_buf * bt_hid_host_create_pdu ( struct net_buf_pool * pool)

#include <zephyr/bluetooth/classic/hid_host.h>

为 HID 主机传输分配 PDU 缓冲区。

返回的缓冲区已为 HID 报头预留头部空间，因此配置可直接前置而无需复制。调用方只需用 net_buf_add_*() 追加报告载荷，不得自行消耗头部空间。

参数
pool用于分配的缓冲区池，或 NULL 表示默认池。
返回
成功时为 net_buf，失败时为 NULL。

◆ bt_hid_host_get_report()

int bt_hid_host_get_report ( struct bt_hid_host * hid,
uint8_t type,
uint8_t report_id,
uint16_t buffer_size )

#include <zephyr/bluetooth/classic/hid_host.h>

向 HID 设备发送 GET_REPORT 请求。

响应通过 get_report 回调异步到达；如果设备始终不应答，则关联会被拆除。

一旦报告描述符声明了 Report ID，ReportID 字段就是必需的；在引导协议模式下它始终是必需的（HID 规范 v1.1.2 第 3.1.2.3 节和第 3.3.1 节）。只有应用程序了解描述符，因此由它决定是否发送该字段。

参数
hidHID 主机实例。
type报告类型（BT_HID_REPORT_TYPE_INPUT/OUTPUT/FEATURE）。
report_id要请求的报告 ID，或 0 表示省略该字段。USB HID 规范保留了报告 ID 0，因此它无法标识报告。
buffer_size最大响应载荷大小（0 = 无限制）。不得超过控制通道可接收的大小。
返回
成功时为 0，失败时为负的 errno。

◆ bt_hid_host_output_report()

int bt_hid_host_output_report ( struct bt_hid_host * hid,
struct net_buf * buf )

#include <zephyr/bluetooth/classic/hid_host.h>

在中断通道上发送输出报告。

这是无确认的异步传输：HID 规范 v1.1.2 第 3.1.2.9 节规定中断通道传输无需应答。当报告描述符声明了 Report ID 或设备处于引导协议模式时，缓冲区必须以 Report ID 开头。

参数
hidHID 主机实例。
buf包含输出报告的缓冲区，用 bt_hid_host_create_pdu() 分配，以便容纳 HIDP 报头（成功时被消耗）。
返回
成功时为 0，失败时为负的 errno。

int bt_hid_host_register ( const struct bt_hid_host_cb * cb)

#include <zephyr/bluetooth/classic/hid_host.h>

注册 HID 主机回调。

注册应用程序回调，并设置 L2CAP 服务端，以在 PSM 0x0011/0x0013 上接受设备发起的呼入重连。

参数

返回
成功时为 0，失败时为负的 errno。

◆ bt_hid_host_unregister()

int bt_hid_host_unregister ( void )

#include <zephyr/bluetooth/classic/hid_host.h>

注销 HID 主机回调。

注销 L2CAP 服务端，从而不再接受设备发起的呼入重连。必须先断开所有 HID 关联。

返回
成功时为 0，其他失败时为负 errno。
返回值
-EBUSY如果 HID 关联仍处于活动状态。
-EALREADY如果未注册 HID 主机回调。

◆ bt_hid_host_virtual_cable_unplug()

int bt_hid_host_virtual_cable_unplug ( struct bt_hid_host * hid)

#include <zephyr/bluetooth/classic/hid_host.h>

向 HID 设备发送虚拟线缆拔出。

发送 VCU 控制消息，并按 HID 规范 v1.1.2 第 3.1.2.2.3 节等待 HID 设备通过断开关联予以确认。如果对端未断开，主机将在事务超时后启动后备拆除。销毁绑定留给应用程序处理，参见 vc_unplug 回调。

参数
hidHID 主机实例。
返回
成功时为 0，失败时为负的 errno。
