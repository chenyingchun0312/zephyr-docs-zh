注册 mspi 回调函数。

该例程提供注册 mspi 回调函数的通用接口。通常应在 mspi_transceive 之前调用。

参数
controller指向该驱动实例设备结构的指针。
dev_id指向设备 ID 结构体的指针。
evt_type与该回调关联的事件类型。
cb指向用户实现的回调函数的指针。
ctx指向回调上下文的指针。

0If successful.
