◆ websocket_connect()

int websocket_connect ( int http_sock,
struct websocket_request * req,
int32_t timeout,
void * user_data )

#include <zephyr/net/websocket.h>

连接到提供 Websocket 服务的服务器。连接建立后调用回调。返回值是一个新的套接字描述符，可用于通过 BSD 套接字 API 收发数据。

参数
http_sock到服务器的套接字 id。注意，此套接字用于进行 HTTP 握手等操作。实际的 Websocket 连接通过返回的 websocket id 完成。注意，此函数返回后不得关闭 http_sock，因为它用于把 Websocket 数据包投递给 Websocket 服务器。
reqWebsocket 请求。用户应分配并填充请求数据。
timeout等待连接的最大超时。超时值单位为毫秒。值 SYS_FOREVER_MS 表示永远等待。
user_data传给回调的用户指定数据。
返回
收发 Websocket 数据时要使用的 Websocket id。

int websocket_recv_msg ( int ws_sock,

#include <zephyr/net/websocket.h>

从对端接收 websocket 消息。

该函数会自动从消息中移除 websocket 头部。

参数

buf读取 websocket 数据的缓冲区。
buf_len数据缓冲区的长度。
message_type消息类型。
remaining本次读取后消息中还剩余多少数据。
timeout尝试接收该消息的时长。值单位为毫秒。值 SYS_FOREVER_MS 表示永远等待。
返回值
>=0已接收的字节数。
-EAGAINon timeout.
-ENOTCONN套接字关闭时。
-errno失败时的其他负 errno 值。

◆ websocket_register()

int websocket_register ( int http_sock,
uint8_t * recv_buf,
size_t recv_buf_len )

#include <zephyr/net/websocket.h>

将一个套接字注册为 websocket。当连接被升级为 websocket 连接时由 HTTP 服务器调用。

参数
http_sock底层的套接字连接套接字。
recv_buf用于 websocket 解析的临时接收缓冲区。必须指向在整个 websocket 会话期间都有效的内存区域。
recv_buf_len临时接收缓冲区的长度。
返回
出错时 <0，否则为应用程序实际要使用的 websocket，>=0

◆ websocket_send_msg()

int websocket_send_msg ( int ws_sock,
const uint8_t * payload,
size_t payload_len,
enum websocket_opcode opcode,
bool mask,
bool final,
int32_t timeout )

#include <zephyr/net/websocket.h>

向对端发送 websocket 消息。

该函数会自动为消息添加 websocket 头部。

参数
ws_sockwebsocket_connect() 返回的 Websocket id。
payload要发送的 Websocket 数据。
payload_len要发送的数据长度。
opcode操作码（文本、二进制、ping、pong、关闭）
mask对数据做掩码处理，详情参见 RFC 6455
final是否为本消息发送的最终消息。若 final == false，则第一条消息必须有有效的操作码，后续消息的操作码必须为 WEBSOCKET_OPCODE_CONTINUE。若 final == true 且这是唯一一条消息，则操作码应设置为合适的操作码（text 或 binary）。
timeout尝试发送该消息的时长。值单位为毫秒。值 SYS_FOREVER_MS 表示永远等待。
返回
出错时 <0，否则为已发送字节数，>=0
