◆ get_tx_buffer

int(*) ipc_service_backend::get_tx_buffer(const struct device *instance, void *token, void **data, uint32_t *len, k_timeout_t wait)

指向将返回空 TX 缓冲区的函数的指针。

参数
[in]instance实例指针。
[in]token后端特定的令牌。
[out]data指向该空 TX 缓冲区的指针。
[in,out]len用于存储 TX 缓冲区大小的指针。
[in]wait等待可用 TX 缓冲区超时。
返回值
-EINVAL当实例无效时。
-ENOENT当端点未注册到该实例时。
-ENOTSUP当不支持该操作或超时时。
-ENOBUFS当没有可用的 TX 缓冲区时。
-EALREADY当已有缓冲区被占用且尚未释放时。
-ENOMEM当请求的大小过大时（此时 size 参数包含允许的最大大小）。
0成功时
other取决于后端实现的 errno 错误码。

◆ send_critical

int(*) ipc_service_backend::send_critical(const struct device *instance, void *token, const void *data, size_t len)

指向绕过流控发送关键消息的函数的指针。

此函数直接发送高优先级消息，绕过繁忙检查和正常的排队机制。它只应用于崩溃报告或致命错误等关键系统通知。

参数
[in]instance实例指针。
[in]token后端特定的令牌。
[in]data指向要发送的缓冲区的指针。
[in]len要发送的字节数。
返回值
-EINVAL当实例无效时。
-ENOENT当端点未注册到该实例时。
-EBADMSG当消息无效时。
-ENOTSUP当不支持关键发送时。
-ENOMEM当连关键缓冲区也不可用时。
bytes已发送的字节数。
other取决于后端实现的 errno 错误码。
