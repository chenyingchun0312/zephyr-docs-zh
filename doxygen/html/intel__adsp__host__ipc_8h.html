typedef bool(*) intel_adsp_ipc_done_t(const struct device *dev, void *arg)

Intel ADSP IPC 消息完成回调。

该函数一旦通过 intel_adsp_ipc_set_done_handler() 注册，就会在从连接对端收到 "DONE" 返回中断（表示先前发送的消息已完成处理）时在中断上下文中被调用。

注解
在 Intel ADSP 硬件上，DONE 中断的发送与远程设备上的中断清除是同步的，无法延迟处理。该回调仍会出现，但依赖异步命令处理通知的协议需要修改。
参数
devIPC device.
arg来自 intel_adsp_ipc_set_done_handler() 的已注册参数。
返回
如果 IPC 完成将由外部完成则为 true，否则为 false。
注解
返回 true 会使该 API 跳过写 IPC 寄存器以通知 IPC 消息完成，这些操作应由外部代码手动完成。若处理程序返回 false，该 API 会正常写入 IPC 寄存器以通知消息完成。
