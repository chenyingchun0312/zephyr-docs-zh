◆ count

uint8_t bt_mesh_cfg_cli_hb_pub::count

心跳次数的对数值。如果 count 在 1 到 0x11 之间，解码为 (1 << (count - 1))；如果 count 为 0 则为 0；如果 count 为 0xff 则为 "无限期"。

在心跳发布设置中使用时，此参数表示要发送的心跳消息数量。

从心跳发布获取返回时，此参数表示剩余待发送的心跳消息数量。
