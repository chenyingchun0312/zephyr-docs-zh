共享多堆（SMH）接口

共享多堆管理器使用多堆分配器来管理一组具有不同能力 / 属性（可缓存、不可缓存等）的内存区域。

所有不同的区域都可以在运行时加入共享多堆池，同时提供一个不透明的“属性”值（整数或枚举值），驱动或应用程序可以用它来请求具有特定能力的内存。

该框架的常见用法如下：

  • 启动时，一些平台代码使用 shared_multi_heap_pool_init 初始化共享多堆框架，并用 shared_multi_heap_add 把内存区域添加到池中，区域所需的信息可能来自 DT。
  • 每个内存区域编码在一个 shared_multi_heap_region 结构中。该结构还携带一个不透明的、用户定义的整数值，用于定义区域的能力（例如：可缓存性、CPU 亲和性等）。
  • 当驱动或应用程序需要具有某种能力的动态内存时，可以使用 shared_multi_heap_alloc（或对齐版本），通过不透明参数为所需内存选择正确的属性集合来请求内存。框架会根据不透明参数和各堆的运行时状态（可用内存、堆状态等）负责选择合适的堆（即内存区域）来切分内存。

此接口的分配函数可从任何线程和 ISR 中安全调用。区域在初始化时从单一上下文中添加。

◆ shared_multi_heap_realloc()

void * shared_multi_heap_realloc ( enum shared_multi_heap_attr attr,
void * ptr,
size_t bytes )

#include <zephyr/multi_heap/shared_multi_heap.h>

从共享多堆内存池重新分配内存

返回指向具有相同内容但分配大小不同的新内存区域的指针。若新分配可以就地扩展，返回的指针将相同。否则数据会被复制到新块，并按 sys_heap_free() 的约定释放旧块。若指定大小小于原大小，则块会就地截断，剩余内存归还给堆。若新块的分配失败，则返回 NULL，且旧块不会被释放或修改。后端使用不透明属性参数在需要时选择从中分配内存的正确堆。

参数
attr为内存块请求的能力 / 属性。
ptr指向要重新分配的内存块的指针
bytes请求的分配大小（字节）。
返回值
newptr指向大小为 size 字节的新堆内存块的有效指针。
err没有可用内存时为 NULL。
