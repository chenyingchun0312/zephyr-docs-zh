详细描述

音频输入控制服务（AICS）

自从
2.6
版本
0.8.0

音频输入控制服务是次要服务，因此不应单独使用，而应在另一个（主要）服务的上下文中使用。

此 API 同时实现服务端和客户端功能。请注意，该 API 抽象掉了音频输入控制状态中的变更计数器，并会自动处理对该计数器的任何更改。如果信息已过期，客户端实现会在执行写入请求时自主读取变更计数器的值。
