◆ emul_fuel_gauge_set_battery_charging()

int emul_fuel_gauge_set_battery_charging ( const struct emul * target,
uint32_t uV,
int uA )

#include <zephyr/drivers/emul_fuel_gauge.h>

设置电量计所关联电池的充电状态。

设置电量计 IC 所关联电池的充电或放电量。其中电压始终为正，正电流或负电流分别表示充电或放电。

参数
target指向电量计仿真器实例的仿真器结构体的指针。
uV描述电池电压的微伏值。
uA描述电池电流的微安值，负值表示放电。
返回值
0If successful.
-EINVAL若 uV 或 uA 为 0。
