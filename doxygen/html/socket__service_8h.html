结构体

struct  net_socket_service_event
 该结构体包含是哪个套接字触发了回调函数调用的信息。 更多...
struct  net_socket_service_desc
 保存套接字服务配置信息的主结构体。创建 k_work 项，以便当这些 fd 有数据到来时调用 k_work 回调。工作队列可设为 NULL，此时使用系统工作队列。服务描述符应在构建时创建，然后作为参数用于注册要监控的套接字。用户应创建所需的套接字，然后设置 poll 结构体，并在运行时注册要监控的套接字。 更多...

宏定义

#define NET_SOCKET_SERVICE_SYNC_DEFINE(name, cb, count)
 静态定义一个网络套接字服务。该服务的用户回调以同步方式调用，即服务 API 会等待用户回调返回后才继续处理下一个套接字服务。
#define NET_SOCKET_SERVICE_SYNC_DEFINE_STATIC(name, cb, count)
 在私有（静态）作用域内静态定义一个网络套接字服务。该服务的用户回调以同步方式调用，即服务 API 会等待用户回调返回后才继续处理下一个套接字服务。
