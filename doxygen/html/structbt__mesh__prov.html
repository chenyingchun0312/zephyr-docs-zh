◆ capabilities

void(*) bt_mesh_prov::capabilities(const struct bt_mesh_dev_capabilities *cap)

配网能力。

此回调通知应用程序已收到未配网设备的配网能力。

因此应用程序可以调用 bt_mesh_auth_method_set_<*> 来选择合适的配网 OOB 认证方法。

此回调返回后，配网器将使用所选方法开始认证。

参数
cap设备支持的能力。

◆ input

int(*) bt_mesh_prov::input(bt_mesh_input_action_t act, uint8_t size)

请求输入。

此回调通知应用程序应使用给定动作向用户请求输入。所请求的输入将是字符串或数字，应用程序在从用户处获取数据后需要相应地调用 bt_mesh_input_string() 或 bt_mesh_input_numeric() 函数。

参数
act用于输入数据的动作。
size输入数据的最大大小。
返回
成功时为零，否则为负的错误码

◆ reset

void(*) bt_mesh_prov::reset(void)

节点已被复位。

此回调通知应用程序本地节点已被复位，需要重新配网。节点不会自动以未配网状态广播，而是需要调用 bt_mesh_prov_enable() API 在一个或多个配网承载上启用未配网广播。
