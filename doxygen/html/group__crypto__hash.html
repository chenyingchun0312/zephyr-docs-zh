建立哈希会话

初始化一次性参数，例如算法，它在会话的所有操作中可能保持不变。状态可缓存在硬件和/或驱动的数据状态变量中。

参数
dev指向该驱动实例设备结构的指针。
ctx指向上下文结构体的指针。会话能力和算法等各种一次性参数通过此结构体提供。结构体文档说明了哪些字段须由应用程序在调用前填充。
algo此会话中要使用的哈希算法，例如 sha256
返回
成功时为 0，失败时为负的 errno 错误码。

◆ hash_callback_set()

int hash_callback_set ( const struct device * dev,
hash_completion_cb cb )
inlinestatic

#include <zephyr/crypto/crypto.h>

向驱动注册异步哈希完成回调

应用程序可注册异步哈希完成回调处理函数，由驱动在先前通过 hash_compute() 提交的请求完成时调用。根据加密设备硬件的语义，该回调很可能在 ISR 上下文中调用。

参数
dev指向该驱动实例设备结构的指针。
cb指向要由驱动调用的应用程序回调的指针。
返回
成功时为 0，若驱动不支持异步操作则为 -ENOTSUP，其他错误为负的 errno 错误码。
