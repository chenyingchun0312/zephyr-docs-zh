加密能力标志

由 crypto_query_hwcaps() 返回的能力标志，在会话建立期间于 cipher_ctx::flags 或 hash_ctx::flags 中选择。

并非所有驱动都支持所有标志。将根据需要添加更多标志。

◆ crypto_query_hwcaps()

int crypto_query_hwcaps ( const struct device * dev)
inlinestatic

#include <zephyr/crypto/crypto.h>

查询加密硬件能力

此 API 供应用程序查询加密设备支持的能力。应用程序据此可指定在 cipher_begin_session() 期间会话要采用的支持选项子集。

参数
dev指向该驱动实例设备结构的指针。
返回
支持选项的位掩码。
