◆ bt_nxp_trigger_ir()

int bt_nxp_trigger_ir ( const struct device * dev)

在 NXP Bluetooth 控制器上触发独立复位（IR）。

本函数在 NXP Bluetooth 控制器上启动独立复位序列。独立复位允许在无需完整系统复位的情况下复位并重新初始化 Bluetooth 控制器。触发 IR 后，固件会被重新下载到控制器。

注解
仅当使能 CONFIG_HCI_NXP_CONFIG_IR 时该 API 才可用。
前置条件
调用本函数前必须禁用 Bluetooth。请在触发 IR 之前使用 bt_disable() 禁用 Bluetooth 协议栈。若未能禁用 Bluetooth，本函数会返回 -EAGAIN。
后置条件
成功完成后，Bluetooth 控制器已被复位且固件已重新下载。应用程序必须调用 bt_enable() 以重新激活 Bluetooth 接口。

用法示例：

int err;
// Step 1: Disable Bluetooth stack
err = bt_disable();
if (err) {
LOG_ERR("Failed to disable Bluetooth: %d", err);
return err;
}
// Step 2: Trigger Independent Reset
err = bt_nxp_trigger_ir(uart_dev);
if (err) {
LOG_ERR("Failed to trigger IR: %d", err);
return err;
}
// Step 3: Re-enable Bluetooth stack
err = bt_enable(NULL);
if (err) {
LOG_ERR("Failed to re-enable Bluetooth: %d", err);
return err;
}
