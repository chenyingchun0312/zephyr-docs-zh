净化数组索引，以防御绕过边界检查的攻击，即 Spectre V1 漏洞。

具有推测执行的 CPU 可能越过任何大小检查进行推测，并通过分析微架构特性泄露机密数据。此函数将在推测执行路径中使用位运算而非任何分支指令，无条件地将任何越界索引截断为零。

用法示例：

if (index < size) { index = k_array_index_sanitize(index, size); data = array[index]; }

参数
index已校验但尚未使用的不可信数组索引
array_size数组的大小
返回
若小于 size 则为原始索引值，否则为 0
