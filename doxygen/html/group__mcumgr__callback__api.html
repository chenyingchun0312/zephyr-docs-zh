◆ mgmt_cb

typedef enum mgmt_cb_return(*) mgmt_cb(uint32_t event, enum mgmt_cb_return prev_status, int32_t *rc, uint16_t *group, bool *abort_more, void *data, size_t data_size)

#include <zephyr/mgmt/mcumgr/mgmt/callbacks.h>

在 MGMT 通知/事件时调用的函数。

此回调函数用于向应用程序或系统通知 MCUmgr mgmt 事件。

参数
eventmcumgr_op_t.
prev_status先前处理程序调用的 #mgmt_cb_return，如果是错误，则为某个处理程序返回的第一个错误（即此处理程序只是因通知而被调用，其返回码将被忽略）。
rc如果 prev_status 为 #MGMT_CB_ERROR_RC，则这是第一个失败的处理程序返回的 SMP 错误。如果 prev_status 为 #MGMT_CB_ERROR_ERR，则这是第一个失败的处理程序返回的组错误 rc 码。如果处理程序希望抛出 SMP 错误，必须将其设为 mcumgr_err_t 状态，并由函数返回 #MGMT_CB_ERROR_RC；如果处理程序希望抛出 ret 错误，必须将其设为组 ret 状态，并由函数返回 #MGMT_CB_ERROR_ERR。
group如果 prev_status 为 #MGMT_CB_ERROR_ERR，则这是第一个失败的处理程序返回的 ret 错误所属的组。如果处理程序希望抛出 ret 错误，必须将其设为组 ret 状态，并由函数返回 #MGMT_CB_ERROR_ERR。
abort_more设为 true 可中止其他处理程序的后续处理。
data可选的事件参数。
data_size可选事件参数的大小（未提供数据时为 0）。
返回
#mgmt_cb_return，表示要返回给调用代码的状态（仅当这是处理程序上报的第一个失败时才检查）。

#include <zephyr/mgmt/mcumgr/mgmt/callbacks.h>

调用此函数以向已注册的回调通知 mcumgr 通知/事件。

参数
eventmcumgr_op_t.
data可选的事件参数。
data_size可选事件参数的大小（没有时为 0）。
err_rc指向 rc 值的指针。
err_group指向组值的指针。
返回
#mgmt_cb_return：如果所有处理程序都返回该值则为 #MGMT_CB_OK；如果第一个失败的处理程序返回 SMP 错误则为 #MGMT_CB_ERROR_RC（此时 err_rc 会被更新为该 SMP 错误）；如果第一个失败的处理程序返回了 ret 组和错误则为 #MGMT_CB_ERROR_ERR（此时 err_group 会被更新为失败的组 ID，err_rc 会被更新为该组特定的错误码）。
