◆ log_frontend_stmesp_demux_sname_get()

const char * log_frontend_stmesp_demux_sname_get ( uint32_t m_id,
uint16_t s_id )

#include <zephyr/logging/log_frontend_stmesp_demux.h>

获取 turbo 日志消息的源名称。

启动期间，协处理器（FLPR 和 PPR）会发送其源数据在内存中的存储位置。如果应用核心是这些核心的所有者，它可以访问该内存，并根据芯片 ID 和源 ID 获取源名称。

参数
m_id主 ID。
s_id源 ID。
返回
指向字符串的指针，该字符串为源名称，如果无法获取源名称则为未知名称。

◆ log_frontend_stmesp_demux_str_get()

const char * log_frontend_stmesp_demux_str_get ( uint32_t m_id,
uint16_t s_id )

#include <zephyr/logging/log_frontend_stmesp_demux.h>

获取 turbo 日志消息的格式字符串。

turbo 日志消息通过索引引用其格式字符串，而不是内联携带。此辅助函数使用发起核心共享的源数据将该索引解析回格式字符串。

参数
m_id主 ID。
s_id源 ID（字符串的索引）。
返回
指向格式字符串的指针，如果无法获取则为空字符串或 "unknown" 字符串。
