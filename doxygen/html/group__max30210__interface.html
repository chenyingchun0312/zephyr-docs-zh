◆ sensor_attribute_max30210

enum sensor_attribute_max30210

#include <zephyr/drivers/sensor/max30210.h>

MAX30210 的自定义传感器属性。

枚举值
SENSOR_ATTR_MAX30210_INTERRUPT_POLARITY 

中断极性（预留给将来使用）。

SENSOR_ATTR_MAX30210_CONTINUOUS_CONVERSION_MODE 

启用连续转换模式。

  • sensor_value.val1 和 sensor_value.val2 被忽略。
SENSOR_ATTR_MAX30210_TEMP_INC_FAST_THRESH 

用于快速变化检测的温度逐样本增量阈值（°C）。

  • sensor_value.val1 为阈值的整数部分（°C）。
  • sensor_value.val2 为小数部分（单位：百万分之一度）。
SENSOR_ATTR_MAX30210_TEMP_DEC_FAST_THRESH 

用于快速变化检测的温度逐样本减量阈值（°C）。

  • sensor_value.val1 为阈值的整数部分（°C）。
  • sensor_value.val2 为小数部分（单位：百万分之一度）。必须是 0.005 °C 的倍数。
SENSOR_ATTR_MAX30210_RATE_CHG_FILTER 

变化率滤波系数（0-7）。

  • sensor_value.val1 为滤波值。
  • sensor_value.val2 未使用（始终为 0）。
SENSOR_ATTR_MAX30210_HI_TRIP_COUNT 

高温告警触发计数（1-4）。

  • sensor_value.val1 为连续超过阈值的样本数。
  • sensor_value.val2 未使用（始终为 0）。
SENSOR_ATTR_MAX30210_LO_TRIP_COUNT 

低温告警触发计数（1-4）。

  • sensor_value.val1 为连续低于阈值的样本数。
  • sensor_value.val2 未使用（始终为 0）。
SENSOR_ATTR_MAX30210_HI_TRIP_COUNT_RESET 

复位高温触发计数器。

  • sensor_value.val1 为 0 表示保持计数器不变，为 1 表示复位。
  • sensor_value.val2 未使用（始终为 0）。
SENSOR_ATTR_MAX30210_LO_TRIP_COUNT_RESET 

复位低温触发计数器。

  • sensor_value.val1 为 0 表示保持计数器不变，为 1 表示复位。
  • sensor_value.val2 未使用（始终为 0）。
SENSOR_ATTR_MAX30210_HI_NON_CONSECUTIVE_MODE 

高温告警非连续模式。

  • sensor_value.val1 为 0 表示连续，为 1 表示非连续。
  • sensor_value.val2 未使用（始终为 0）。
SENSOR_ATTR_MAX30210_LO_NON_CONSECUTIVE_MODE 

低温告警非连续模式。

  • sensor_value.val1 为 0 表示连续，为 1 表示非连续。
  • sensor_value.val2 未使用（始终为 0）。
SENSOR_ATTR_MAX30210_ALERT_MODE 

告警模式（比较器还是中断）。

  • sensor_value.val1 为 0 表示比较器模式，为 1 表示中断模式。
  • sensor_value.val2 未使用（始终为 0）。
SENSOR_ATTR_MAX30210_SOFTWARE_RESET 

执行软件复位。

  • sensor_value.val1 和 sensor_value.val2 被忽略。
SENSOR_ATTR_MAX30210_TEMP_CONVERT 

触发单次温度转换（预留给将来使用）。

SENSOR_ATTR_MAX30210_AUTO_MODE 

启用自动模式（预留给将来使用）。
