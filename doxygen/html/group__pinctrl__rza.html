详细描述

用于配置 Renesas RZ/A SoC 引脚控制的宏

通用引脚由 RZA_PINMUX() 宏配置，该宏接受三个字段：

  • port —— 端口标识，取 PORT_* 之一。
  • pin —— 该端口内的引脚号。
  • func —— 备用功能编号，用于选择路由到该引脚的外设信号，取值来自 SoC 的引脚功能控制器表；它没有符号宏，以普通整数传入。

位于通用端口矩阵之外的专用功能引脚直接通过其 BSP_IO_* 标识引用，涵盖调试（BSP_IO_NMI、BSP_IO_TMS_SWDIO、BSP_IO_TDO）、音频时钟、SD/MMC、QSPI 与八线存储器 Flash、RIIC（I2C）以及看门狗溢出。

可用 RZA_FILTER_SET() 为引脚组施加可选的数字噪声滤波器，该宏由级数（RZA_FILNUM_*）和采样时钟分频（RZA_FILCLKSEL_*）构建。 @code {.dts} #include <zephyr/dt-bindings/pinctrl/renesas/pinctrl-rza-common.h>

&pinctrl { scif0_default: scif0_default { device-pinmux { pinmux = <RZA_PINMUX(PORT_08, 1, 5)>, <RZA_PINMUX(PORT_08, 2, 5)>; bias-pull-up; renesas,filter = RZA_FILTER_SET(RZA_FILNUM_8_STAGE, RZA_FILCLKSEL_DIV_18000); }; }; };

把滤波器级数和时钟选择编码为一个配置值。

  • bits [3:2] = FILNUM（掩码为 2 位）

编码后的滤波器配置值。
