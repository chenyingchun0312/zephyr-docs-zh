详细描述

把 shell 实例连接到通信通道的传输后端。

shell 实例由传输后端（UART、RTT、Telnet、MQTT、WebSocket、SSH、RPMsg 等）驱动。后端通常通过其 Kconfig 选项（例如 CONFIG_SHELL_BACKEND_SERIAL）选择和启用，shell 子系统会自动实例化所配置的后端。应用程序通常不直接引用本组中的符号。

因此，每个后端头文件暴露的接口很小，且大多是面向实现的：

  • 一个 SHELL_<name>_DEFINE() 宏，用于实例化一个传输层，由后端实现自身使用（也可用于自定义实例）；
  • 一个 shell_backend_<name>_get_ptr() 访问器，返回该后端的 shell 实例，供少数需要访问特定后端的调用方使用（例如测试中的 dummy 后端，或管理代码中的 UART）；
  • 偶尔出现的后端专用辅助函数。
