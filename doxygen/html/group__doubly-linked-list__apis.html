详细描述

双向链表实现

自从
1.0
版本
1.0.0

使用内联宏/函数实现的双向链表。此 API 不是线程安全的，因此若链表跨线程使用，对函数的调用必须用同步原语保护。

链表应按头和尾指针都指向链表自身的方式初始化。以此方式初始化链表可以简化向链表中添加节点和从链表中移除节点。
