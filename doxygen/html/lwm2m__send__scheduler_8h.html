◆ lwm2m_send_sched_cache_filter()

bool lwm2m_send_sched_cache_filter ( const struct lwm2m_obj_path * path,
const struct lwm2m_time_series_elem * element )

强制执行已配置的调度器规则的缓存过滤器。

对于你希望由调度器控制的每个缓存资源，通过 lwm2m_set_cache_filter 挂接此过滤器。

参数
path缓存资源的 LwM2M 路径。
element即将被缓存的候选样本。
返回
为 true 时将该样本保留在缓存中，为 false 时丢弃或延迟它。

◆ lwm2m_send_sched_handle_registration_event()

void lwm2m_send_sched_handle_registration_event ( void )

处理注册或注册更新完成事件。

当应用程序的 LwM2M RD 客户端报告注册或注册更新成功时，应用程序应调用此函数，以便发送调度器能够应用其“更新时刷新”策略。

◆ lwm2m_send_sched_init()

int lwm2m_send_sched_init ( void )

注册发送调度器的 LwM2M 对象并初始化状态。

它会安装调度器控制对象（10523）和采样规则对象（10524），并准备缓存过滤辅助函数所需的簿记信息。

返回
成功时为 0，对象注册失败时为负的 errno。
