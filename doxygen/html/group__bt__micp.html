◆ bt_micp_mic_ctlr_discover()

int bt_micp_mic_ctlr_discover ( struct bt_conn * conn,
struct bt_micp_mic_ctlr ** mic_ctlr )

#include <zephyr/bluetooth/audio/micp.h>

发现麦克风控制服务

这会启动 GATT 发现并设置句柄和订阅。应在对对端设备执行任何其他操作之前调用一次，bt_micp_mic_ctlr_cb::discover 回调会通知何时可以开始远程操作。*

参数
conn要为其初始化该配置文件的连接。
[out]mic_ctlr成功时为有效的远端实例对象。
返回
成功时为 0，失败时为 GATT 错误值。
