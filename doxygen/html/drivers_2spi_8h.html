SPI 数据字配置

SPI 数据字是移入/移出控制器硬件 FIFO 的值，是 SPI 总线上通信的原子单元。在本 API 中，字也称为“数据帧”。一次传输由任意数量的字组成。以下选项指定该操作中 SPI 字的配置。

#define SPI_TRANSFER_MSB   (0U)
 字为最高有效位在前，用于 spi_operation_t
#define SPI_TRANSFER_LSB   BIT(4)
 字为最低有效位在前，用于 spi_operation_t
#define SPI_WORD_SIZE_GET(operation)

SPI SDI 线 @{

某些控制器支持连接到外设的双线、四线或八线 SDI。默认是单线，大多数情况下都是如此。在未启用 CONFIG_SPI_EXTENDED_MODES 时，仅支持单线。

#define SPI_LINES_SINGLE   (0U << 16)

#define SPI_LINES_DUAL   (1U << 16)

#define SPI_LINES_QUAD   (2U << 16)

#define SPI_LINES_OCTAL   (3U << 16)
 八线
#define SPI_LINES_MASK   (0x3U << 16)

SPI 异步传输函数

使用此 API 时，传输函数在传输启动后就会返回，并通过通知机制（回调或信号）报告完成。

注解
注意，如果总线已经繁忙，异步 API 调用仍可能阻塞。这些函数会阻塞，直到总线可用于启动所请求的传输。
