详细描述

BL60x 上的性能问题相当复杂：BCLK 分频器是影响 BL60x 性能的最重要缩放因子，这似乎源于与向 CPU 馈送时钟相关的硬件设计问题；而在其他所有 BFLB SoC（包括使用相同缓存和 CPU 方案的 BL70x 与 BL70xL）上，BCLK 对原始 CPU 性能大多无关紧要。因此请记得调整分频器，同时记住 BFLB 建议 BCLK 不要超过 96MHz。以下是一些工作良好的示例配置：

基准：Root：192MHz（标准）BCLK：96MHz（Root / 2，标准）Flash CLK：48MHz（BCLK / 2，可能因模块或 PCB 而异，但这是稳妥的选择）性能 1（351 Cmrks），循环展开：1.125（395 Cmrks）

在较高电压下展开循环时最佳（非标准用法）：Root：200MHz（标准）BCLK：200MHz（超频）Flash CLK：66MHz（BCLK / 3）SoC 电压：1.25 V（提高）性能 1.52（534 Cmrks），循环展开：1.9（666 Cmrks）

展开循环时最佳（非标准用法，不提高电压下的最大 BCLK）：Root：150MHz（取自超频但仍在标准范围内）BCLK：150MHz（超频）Flash CLK：75MHz（BCLK / 2）性能 1.14（400 Cmrks），循环展开：1.42（500 Cmrks）

在较高电压下不展开循环时最佳：Root：320MHz（超频）BCLK：160MHz（Root / 2，超频）Flash CLK：80MHz（BCLK / 2）SoC 电压：1.25 V（提高）性能 1.67（585 Cmrks），循环展开：1.88（660 Cmrks）

不展开循环时最佳：Root：240MHz（超频）BCLK：120MHz（Root / 2，超频）Flash CLK：60MHz（BCLK / 2）性能 1.25（440 Cmrks），循环展开：1.41（494 Cmrks）

在此 SoC 上，主 CPU 可以运行在更高频率，但这并不重要，因为性能受 BCLK 速度限制，而 200 MHz BCLK 已接近其可达到的最高值。在 1.35v 下达到的最高稳定频率为 360MHz。相比 200/200 配置，使用 360/180 仅带来 10-22% 的提升（1.8（660 Cmrks），循环展开：2.1（740 Cmrks）），而且还需要对 SoC 施加尽可能高的电压。最后，由于 PLL 的要求，低于通常 40MHz 晶振的参考时钟可能无法使其锁定。

超频时，大多数复杂外设（Wifi）以及可将外设总线用作主设备的外设（DMA 及使用 DMA 的驱动）无法正常工作。
