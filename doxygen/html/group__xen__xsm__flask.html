详细描述

加载 Xen 安全策略、管理 FLASK 强制模式、将上下文转换为 SID、管理 ocontext 以及其他与 FLASK 相关的任务。

◆ flask_context_to_sid()

int flask_context_to_sid ( char * buf,
uint32_t size,
uint32_t * sid )

#include <zephyr/xen/flask.h>

将上下文字符串转换为数字 SID

该函数发出 FLASK_CONTEXT_TO_SID 超级调用，以获取与已加载策略中给定安全上下文对应的安全 ID。

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_FLASK.
参数
buf上下文字符串
size上下文字符串的长度
sid用于接收对应 SID 的输出指针。
返回值
0成功时
-errno失败时为负的 errno 错误码。
