◆ discovery_complete

void(*) bt_cap_commander_cb::discovery_complete(struct bt_conn *conn, int err, const struct bt_csip_set_coordinator_set_member *member, const struct bt_csip_set_coordinator_csis_inst *csis_inst)

bt_cap_commander_discover() 的回调。

参数
conn传给 bt_cap_commander_discover() 的连接指针。
err若找到通用音频服务则为 0，否则为 -ENODATA。
member指向集成员的指针。若 err != 0 则为 NULL。
csis_inst若找到通用音频服务且其中包含协调集标识服务，则为该协调集标识服务（Coordinated Set Identification Service）。出错或远端设备不含协调集标识服务时为 NULL。若 err != 0 则为 NULL。
