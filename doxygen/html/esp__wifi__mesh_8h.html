详细描述

ESP32 Wi-Fi mesh 公共 API。

ESP Wi-Fi mesh 栈的 Zephyr 原生接口：mesh 启动、应用事件回调、原始收发路径，以及状态与路由表查询。它隐藏了厂商 mesh 头文件，使应用程序只依赖此 API。
