Bluetooth API 概述

Bluetooth 子系统核心 API 提供使用和管理基于 Bluetooth 的通信所必需的功能。这些 API 包括 Bluetooth 协议栈初始化、设备发现、连接管理、数据传输以及配置文件和服务相关的 API。这些 API 同时支持经典 Bluetooth 和低功耗 Bluetooth（LE）操作。
