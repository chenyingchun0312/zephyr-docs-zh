详细描述

将向量乘以一个标量值。对于浮点数据，所用算法为： 

 dst[n] = src[n] * scale, 0 <= n < block_size.

在定点 Q7、Q15 和 Q31 函数中，scale 由小数乘法 scale_fract 和算术移位 shift 表示。移位可使缩放操作的增益超过 1.0。用于定点数据的算法为：

 dst[n] = (src[n] * scale_fract) << shift, 0 <= n < block_size.

应用于定点数据的总缩放因子为 

 scale = scale_fract * 2^shift.

这些函数支持原地计算，允许源指针和目标指针引用同一内存缓冲区。
