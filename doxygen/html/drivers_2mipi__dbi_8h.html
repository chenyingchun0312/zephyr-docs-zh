详细描述

MIPI-DBI（显示总线接口）驱动 API 的主头文件。

MIPI-DBI 定义了以下 3 种接口：

  • Type A：Motorola 6800 型并行总线
  • Type B：Intel 8080 型并行总线
  • Type C：SPI 型（1 位总线），有 3 个选项：
    1. 每字节 9 个写时钟，最后一位是命令/数据选择位
    2. 同上，但每字节 16 个写时钟
    3. 每字节 8 个写时钟。命令/数据由 GPIO 引脚选择 当前驱动接口不支持带 16 个写时钟的 Type C（选项 2）。
