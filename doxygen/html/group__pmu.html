◆ pmu_init()

int pmu_init ( void )

#include <zephyr/arch/pmu.h>

为当前逻辑 CPU 初始化 PMU。

硬件性能计数器的架构中立接口。后端为每种受支持的架构实现这些函数（例如 AArch64 上的 ARMv8-A PMUv3、未来的 ARMv8-R / Cortex-R52、RISC-V HPM CSR 等）。

架构事件码由架构补充定义（例如启用 CONFIG_ARM64 时 <zephyr/arch/arm64/pmuv3.h> 中的 pmu_evt_t）。

PMU 在内核启动期间不会被初始化。在此 CPU 上调用其他 pmu_*() 函数之前，请先调用 。

在每个将使用计数器的逻辑 CPU 上、在任何其他操作之前调用一次 pmu_*() API on that CPU. Idempotent on success: later calls return 0 if this CPU already initialized successfully, or -ENOTSUP if this CPU recorded that no PMU is available.

PMU 控制和计数器是按 CPU 独立的。在 SMP 上，仅在预期的 CPU 上运行时使用 PMU —— 例如用 k_thread_cpu_pin() 固定线程（需要 CONFIG_SCHED_CPU_MASK），或用以下方式限制其 CPU 亲和性 k_thread_cpu_mask_enable() / k_thread_cpu_mask_disable(), so it does not migrate during a measurement.

没有 SYS_INIT 钩子；由调用者决定何时探测（例如在基准测试开始时）。

返回值
0成功
-ENOTSUP此 CPU 上没有 PMU，或在此异常级别下不可用
