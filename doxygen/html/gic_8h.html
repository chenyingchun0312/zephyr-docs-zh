ARM 通用中断控制器驱动

通用中断控制器（GIC）是 ARM A 和 R 系列内核的默认中断控制器。ARM 架构实现使用此驱动来处理中断。

◆ arm_gic_irq_set_affinity()

void arm_gic_irq_set_affinity ( unsigned int irq,
uint64_t mpidr )

将 SPI/扩展 SPI 中断路由到特定内核

为 irq 配置 GICD_IROUTER，采用特定亲和性路由（IRM=0），目标为 mpidr 标识的内核，类似于用 k_thread_cpu_pin() 将线程绑定到某个 CPU。仅对 SPI/扩展 SPI 有效，且只有在 GICv3 亲和性路由本身启用后（GICD_CTLR.ARE_S/ARE_NS）才会生效 - 在启用 CONFIG_ARMV8_A_NS 或 CONFIG_GIC_SINGLE_SECURITY_STATE 的构建中默认为已启用，在自身 EL3/安全预初始化已启用该功能的任何 SoC 上也是如此。

可在中断连接后随时从任意内核调用 - 与 arm_gic_irq_enable() 隐式的自身亲和性（始终以调用它的内核为目标）不同，此函数可指定任意内核为目标。若在 arm_gic_irq_enable() 之后调用，则以此调用的目标为准。

参数
irq中断 ID（必须是 SPI 或扩展 SPI）
mpidr目标内核的 MPIDR 亲和性值。在 arm64 上，该值可来自特定 CPU 的设备树节点（DT_REG_ADDR(DT_NODELABEL(cpuX))），或对于调用者当前绑定的内核，来自 MPIDR_TO_CORE(GET_MPIDR())
