int sdmmc_erase_blocks ( struct sd_card * card,
uint32_t start_block,
uint32_t num_blocks )

从 SD 卡擦除块

参数
card要写入的 SD 卡
start_block要擦除的第一个块
num_blocks要擦除的块数量
返回值
0擦除成功
-EBUSY卡正忙于另一个请求
-EINVAL请求的擦除超出卡的范围
-ETIMEDOUT卡写入超时
-EIOI/O 错误
