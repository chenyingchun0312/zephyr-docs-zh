SPI 分散-聚集缓冲区数组结构体

spi_buf_set 是对整个单次 SPI 总线传输的灵活描述。

由于该集合是指向缓冲区的指针数组，这意味着 SPI 传输定义的各部分可在不同传输之间重复使用，无需每次都重新定义或为其分配新的内存。这就在驱动程序层面利用用户提供的缓冲区实现了所谓的“分散-聚集”缓冲区管理。
