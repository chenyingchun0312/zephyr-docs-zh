详细描述

配对请求和配对响应信息结构体。

此结构体对 smp_pairing_req 和 smp_pairing_rsp 相同，是数据包数据的子集，只是初始 Code 字节除外。相关文档见核心规范第 3 卷第 H 部分第 3.5.1 和 3.5.2 节。
