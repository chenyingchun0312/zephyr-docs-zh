详细描述

供 Zephyr 使用的 Renesas RZ/T、N GPIO 标志。

附加标志编码在 gpio_dt_flags_t 的高 8 位中，具体如下：

  • 位 [9:8] = 驱动能力控制（0=低，1=中，2=高，3=超高）
  • 位 [12] = 施密特触发器控制（0=禁用，1=启用）
  • 位 [13] = 压摆率控制（0=慢，1=快）
  • 位 [14] = 安全区域（0=安全，1=非安全）

DT 用法示例：

  • 驱动能力控制：中
  • 施密特触发器控制：启用
  • 压摆率控制：慢
  • 非安全
gpio-consumer {
out-gpios = <&port8 2 (GPIO_PULL_UP | RZTN_GPIO_CFG_SET(1, 1, 0) | RZTN_GPIO_NONSAFETY)>;
};
