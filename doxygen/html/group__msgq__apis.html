消息队列结构
定义 kernel.h:4503

静态定义并初始化消息队列。

消息队列的环形缓冲区包含可容纳 q_max_msgs 条消息的空间，每条消息长度为 q_msg_size 字节。消息队列的环形缓冲区无需对齐，将 q_align 设为 1 即可。

消息队列可在定义它的模块之外通过以下方式访问：

extern struct k_msgq <name>;
注解
This macro cannot be used together with a static keyword. If such a use-case is desired, use K_MSGQ_DEFINE_STATIC instead.
参数
q_nameName of the message queue.
q_msg_sizeMessage size (in bytes).
q_max_msgsMaximum number of messages that can be queued.
q_alignAlignment of the message queue's ring buffer (power of 2).

◆ k_msgq_alloc_init()

int k_msgq_alloc_init ( struct k_msgq * msgq,
size_t msg_size,
uint32_t max_msgs )

#include <zephyr/kernel.h>

初始化消息队列。

此例程在首次使用前初始化消息队列对象，并从调用线程的资源池中分配其内部环形缓冲区。

为环形缓冲区分配的内存可通过调用 k_msgq_cleanup() 释放；或者在启用用户模式且该 msgq 对象失去所有引用时释放。

参数
msgq消息队列的地址。
msg_size消息大小（以字节为单位）。
max_msgs可排队的最大消息数量。
返回
成功时为 0；如果线程资源池中的内存不足则为 -ENOMEM；如果大小参数导致整数溢出则为 -EINVAL。

◆ k_msgq_cleanup()

int k_msgq_cleanup ( struct k_msgq * msgq)

#include <zephyr/kernel.h>

释放为队列分配的缓冲区

释放为环形缓冲区分配的内存。仅当缓冲区由 k_msgq_alloc_init() 分配时才会被释放；对于调用者提供的缓冲区，调用会成功但不释放任何内容。队列中仍在的任何消息将随缓冲区一起丢弃。

参数
msgq要清理的消息队列
返回值
0成功时
-EBUSY有线程正在等待该消息队列

返回值

-ENOMSG未等待即返回，或队列已被清空。
-EAGAIN等待时间超时。

清空消息队列。

此例程丢弃消息队列环形缓冲区中所有未接收的消息。任何因等待向该消息队列发送消息而被阻塞的线程都将解除阻塞，并看到 -ENOMSG 错误码。

#include <zephyr/kernel.h>

将消息发送到消息队列前端。

此例程将消息发送到消息队列 q 的开头（头部）。以这种方式发送的消息将在队列中任何已有消息之前被取出。

注解
如果消息队列中没有空间，此函数的行为与 k_msgq_put 相同。
消息内容从 data 复制到 msgq，不保留 data 指针，因此此函数不会修改消息内容。
k_msgq_put_front() 不会阻塞。
参数
msgq消息队列的地址。
data指向消息的指针。
返回值
0已发送消息。
-ENOMSG未等待即返回，或队列已被清空。
