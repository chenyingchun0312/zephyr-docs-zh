初始化 RPMsg 实例。

初始化 RPMsg 实例。

参数
instance指向 RPMsg 实例结构体的指针。
role主机 / 远端角色。
buffer_size用于在主机和远端之间发送数据的缓冲区大小。
shm_ioSHM IO 区域指针。
vdevVirtIO 设备指针。
shb共享内存区域指针。
size共享内存区域的大小。
ns_bind_cb用于名称服务通告的回调处理函数，不等待本地端点绑定。如果为 NULL，实现会回退到内部实现。
返回值
-EINVAL当缺少某个参数时。
0If successful.
Other取决于 OpenAMP 实现的 errno 错误码。
