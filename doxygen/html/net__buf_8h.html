#define NET_BUF_EXTERNAL_DATA   BIT(0)
 该标志表示缓冲区关联的数据指针指向外部分配的内存。因此一旦 ref 降为零，所指数据无需被释放。net_buf API 用户永远不需要显式设置或清除此标志。此类 net_buf 仅通过 net_buf_alloc_with_data() 函数实例化。引用计数机制的行为仍然相同，ref 计数降为 0 时会释放 net_buf，但不会释放其中的数据指针。
