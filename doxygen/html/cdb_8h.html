◆ bt_mesh_cdb_app_key_export()

int bt_mesh_cdb_app_key_export ( const struct bt_mesh_cdb_app_key * key,
int key_idx,
uint8_t out[16] )

导出应用程序密钥。

使用采用 PSA 实现的安全库时，通过指针访问密钥不会得到有效值，因为密钥隐藏在库中。应用程序必须导出该密钥。

参数
keycdb 应用程序密钥结构。
key_idx0 或 1。如果正在进行密钥刷新过程，则有两个密钥可用。旧密钥索引为 0，新密钥索引为 1。否则只存在索引为 0 的密钥。
out密钥值。
返回
成功时返回 0，失败时返回负的错误码。

◆ bt_mesh_cdb_clear()

void bt_mesh_cdb_clear ( void )

清除 Mesh 配置数据库。

删除数据库中存储的所有节点、子网和 app-key，并将该数据库标记为无效。如果启用了 CONFIG_BT_SETTINGS，数据将从持久存储中清除。

◆ bt_mesh_cdb_iv_update()

void bt_mesh_cdb_iv_update ( uint32_t iv_index,
bool iv_update )

设置并存储 IV 索引和 IV 更新标志。

存储在 CDB 中的 IV 索引将用于新节点的配网。此函数通常仅在协议栈内部使用。

如果启用了 CONFIG_BT_SETTINGS，此函数会将数据存入持久存储。

参数
iv_index要使用的新 IV 索引。
iv_update如果存在正在进行的 IV 更新过程，则为 true。

◆ bt_mesh_cdb_node_alloc()

struct bt_mesh_cdb_node * bt_mesh_cdb_node_alloc ( const uint8_t uuid[16],
uint16_t addr,
uint8_t num_elem,
uint16_t net_idx )

分配节点。

在 CDB 中分配一个新节点。

如果 addr 为 0，将使用 bt_mesh_cdb_free_addr_get 分配一个空闲地址。

参数
uuid节点的 UUID。
addr节点主元素的地址。如果为 0，将为该节点分配可用的最低地址。
num_elem该节点拥有的元素数量。
net_idx该节点配网到的 NetIdx。
返回
新节点；如果 CDB 已分配了 :kconfig:option:CONFIG_BT_MESH_CDB_NODE_COUNT 个节点、或已到达单播地址范围末尾、或 addr 非零且小于最低可用地址或与已分配地址冲突，则为 NULL。

◆ bt_mesh_cdb_node_del()

void bt_mesh_cdb_node_del ( struct bt_mesh_cdb_node * node,
bool store )

删除节点。

从 CDB 中删除节点。删除节点时，如果被删除节点最后一个元素的地址大于最低可用地址，CDB 将更新最低可用地址。最低可用地址会被重置，已删除的地址只有在 IV 索引更新后才能重新使用。

参数
node要删除的节点。
store如果为 true，将从持久存储中清除该节点。
