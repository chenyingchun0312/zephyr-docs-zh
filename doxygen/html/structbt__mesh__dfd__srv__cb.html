void(*) bt_mesh_dfd_srv_cb::del(struct bt_mesh_dfd_srv *srv, const struct bt_mesh_dfu_slot *slot)

槽位删除回调。

在固件分发服务器即将删除某个 DFU 映像槽位时调用。与该固件槽位关联的所有已分配数据都应删除。

参数
srv固件更新服务器实例。
slot正在删除的 DFU 映像槽位。

阶段变更回调（可选）。

每当固件分发服务器的阶段发生变化时调用。

参数
srv固件分发服务器模型实例。
phase新的固件分发阶段。

◆ recv

int(*) bt_mesh_dfd_srv_cb::recv(struct bt_mesh_dfd_srv *srv, const struct bt_mesh_dfu_slot *slot, const struct bt_mesh_blob_io **io)

槽位接收回调。

在上传过程开始时调用。回调必须填充 io with a pointer to a writable BLOB stream for the Firmware Distribution Server to write the firmware image to.

参数
srv固件分发服务器模型实例。
slot正在接收的 DFU 映像槽位。
ioBLOB 流响应指针。
返回
成功时返回 0，否则返回（负的）错误码。

◆ send

int(*) bt_mesh_dfd_srv_cb::send(struct bt_mesh_dfd_srv *srv, const struct bt_mesh_dfu_slot *slot, const struct bt_mesh_blob_io **io)

槽位发送回调。

在分发过程开始时调用。回调必须将 io 设置为指向可读 BLOB 流的指针，供固件分发服务器读取固件映像。

参数
srv固件分发服务器模型实例。
slot正在发送的 DFU 映像槽位。
ioBLOB 流响应指针。
返回
成功时返回 0，否则返回（负的）错误码。
