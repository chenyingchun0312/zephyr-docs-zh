typedef uint32_t stm32_gpio_irq_line_t

用于 STM32 MCU 的 GPIO 中断控制器 API

此 API 用于与 STM32 微控制器的 GPIO 中断控制器交互。

表示 GPIO 中断线路的不透明类型
