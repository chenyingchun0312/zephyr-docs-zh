◆ modem_ubx_run_script()

int modem_ubx_run_script ( struct modem_ubx * ubx,
struct modem_ubx_script * script )

#include <zephyr/modem/ubx.h>

将 ubx 帧写入 script.request 并读回其响应（如果可用）

对于发送的每个 ubx 帧，设备会以以下方式中的 0 种、1 种或两种方式响应：

  1. 设备回送 UBX-ACK 帧以表示“确认”和“未确认”。注意：UBX-ACK 帧的消息 id 决定设备是否确认。例如：当我们发送 UBX-CFG 帧时，设备会以 UBX-ACK 帧响应。
  2. 设备回送我们发给它的同一个帧，并填充其载荷。它用于获取与我们发送的帧相对应的当前配置。例如：“get”或“poll”之类的 ubx 帧会以这种方式响应。此响应（如果收到）会写入 script.response。

此函数将 ubx 帧写入 script.request，然后读回其响应。如果 script.match 不为 NULL，则从设备收到的每个 ubx 帧都会与 script.match 比较以检查是否匹配。可以用它来匹配设备发送的 UBX-ACK 帧，方法是用脚本期望收到的 UBX-ACK 填充 script.match。

脚本在发生以下任一情况时终止：

  1. script.match 被成功接收并匹配。
  2. 发生超时（由 script.timeout 表示）。
    参数
    ubx调制解调器 Ubx 实例
    script要执行的脚本
    注解
    script.request 中 ubx 帧的长度不应超过 UBX_FRAME_SZ_MAX
    调制解调器 Ubx 实例必须已附加到某个管道实例
    返回
    成功时为 0
    失败时返回负的 errno 代码
