为带 GPIO 的 I2C 控制器定义 MCTP 总线绑定

与 MCTP 标准所期望的模式切换不同，这是一种自定义绑定。在控制器侧，每个邻居都有一个关联的 i2c 地址和 gpio，控制器会监听该 gpio 上的触发。收到触发后，控制器将读取目标设备。目标设备应具有相当于两个寄存器的内容：一个包含消息长度，另一个是类似 FIFO 的寄存器，用于产生消息字节。

因此，I2C 目标发送消息的步骤为……

  1. 设置长度值和消息值（伪寄存器）。
  2. 通过设置 GPIO 电平向控制器发出信号
  3. 随后控制器应读取长度（写地址 0 + 读 1 字节）
  4. 随后控制器应读取消息（写地址 1 + 读 N 字节）
  5. 目标清除引脚置位
  6. 控制器向 MCTP 报告收到消息
参数
_name总线绑定变量的符号名
_node_id包含此 MCTP 绑定配置的设备树节点
