宏定义

#define FS_MOUNT_FLAG_NO_FORMAT   BIT(0)
 如果找不到所请求的文件系统，此标志会阻止格式化设备
#define FS_MOUNT_FLAG_READ_ONLY   BIT(1)
 此标志使挂载的文件系统变为只读
#define FS_MOUNT_FLAG_AUTOMOUNT   BIT(2)
 用于将在启动时挂载的预定义挂载结构体的标志。
#define FS_MOUNT_FLAG_USE_DISK_ACCESS   BIT(3)
 此标志请求文件系统驱动程序使用磁盘访问 API。如果在调用 fs_mount 之前将该标志设置到 fs_mount_t.flags 中，则文件系统需要使用磁盘访问 API，否则该驱动程序的挂载回调应返回 -ENOTSUP；如果未设置该标志，则文件系统驱动程序默认应使用 Flash API，除非它只支持磁盘访问 API。如果文件系统将使用磁盘访问 API 而该标志未设置，则文件系统的挂载回调应在成功时设置该标志。
