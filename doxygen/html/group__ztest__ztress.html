定义 ztress.h:88

设置并运行压力测试。

它会初始化所有上下文并调用 ztress_execute。

参数
...上下文列表。上下文使用 ZTRESS_TIMER 和 ZTRESS_THREAD 宏配置。若使用 ZTRESS_TIMER，它必须是第一个参数。每个线程上下文都有分配的优先级。优先级按降序分配（最先列出的线程上下文优先级最高）。支持的线程上下文数量上限（包括定时器上下文）可在 Kconfig 中配置（ZTRESS_MAX_THREADS）。

定义 ztress.h:24

线程执行上下文的描述符。

处理程序在线程上下文中执行。线程的优先级根据上下文在 ZTRESS_EXECUTE 中列出的顺序确定。

注解
线程休眠随机时长。此外，线程还会忙等待随机时长，以进一步增强测试中的随机性。
参数
handler类型为 ztress_handler 的用户处理程序。
user_data传给 handler 的用户数据。
exec_cnt完成测试所需的处理程序执行次数。若为 0，则不计入完成条件。
preempt_cnt完成测试所需的该上下文被抢占次数。若为 0，则不计入完成条件。
init_timeout初始退避时间基准（以 k_timeout_t 给出）。测试期间会调整它以优化 CPU 负载。休眠实际使用的超时是随机的。

k_timer 处理程序执行上下文的描述符。

处理程序在 k_timer 处理程序上下文中执行，这通常意味着中断上下文。该上下文会抢占该集合中使用的任何其他上下文。

注解
集合中最多只能有一个 k_timer 上下文，且它必须是 ZTRESS_EXECUTE 的第一个参数。
参数
handler类型为 ztress_handler 的用户处理程序。
user_data传给 handler 的用户数据。
exec_cnt完成测试所需的处理程序执行次数。若为 0，则不计入完成条件。
init_timeout初始退避时间基准（以 k_timeout_t 给出）。测试期间会调整它以优化 CPU 负载。定时器实际使用的超时是随机的。

参数

cnt当前执行计数。从 0 开始。

◆ ztress_execute()

int ztress_execute ( struct ztress_context_data * timer_data,
struct ztress_context_data * thread_data,
size_t cnt )

#include <subsys/testsuite/ztest/include/zephyr/ztress.h>

执行上下文。

测试会一直运行，直到满足所有完成要求、测试超时（使用 ztress_set_timeout 配置超时）或测试被中止（ztress_abort）。

测试完成时会打印报告（内部会调用 ztress_report）。

参数
timer_data定时器上下文。未使用定时器上下文时为 NULL。
thread_data线程上下文描述符列表，按优先级降序排列。
cnt线程上下文数量。
返回值
-EINVAL若配置无效。
0若测试成功执行。
