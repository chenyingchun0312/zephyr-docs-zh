◆ bt_hrs_cb_register()

int bt_hrs_cb_register ( struct bt_hrs_cb * cb)

#include <zephyr/bluetooth/services/hrs.h>

心率服务回调注册

此函数将注册在与心率服务相关的特定事件中被调用的回调。

参数
cb指向回调结构体的指针。必须指向在注销之前始终有效的内存。
返回
成功时为 0
如果 cb 为 NULL 则为 -EINVAL

◆ bt_hrs_cb_unregister()

int bt_hrs_cb_unregister ( struct bt_hrs_cb * cb)

#include <zephyr/bluetooth/services/hrs.h>

心率服务回调注销

此函数将从心率服务注销回调。

参数
cb指向回调结构体的指针
返回
成功时为 0
如果 cb 为 NULL 则为 -EINVAL
如果在已注册的回调中未找到 cb 则为 -ENOENT

◆ bt_hrs_notify()

int bt_hrs_notify ( uint16_t heartrate)

#include <zephyr/bluetooth/services/hrs.h>

通知心率测量值。

这将向所有当前订阅者发送 GATT 通知。

参数
heartrate心率测量值，单位为每分钟搏动次数。
返回
成功时为零，出错时为错误码。
