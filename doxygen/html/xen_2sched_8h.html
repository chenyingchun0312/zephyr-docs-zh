◆ xen_sched_watchdog()

int xen_sched_watchdog ( uint32_t * id,
uint32_t timeout )

设置、更新或销毁 Xen 域的看门狗定时器。

当 id 指向零时，Xen 以 timeout 创建一个看门狗，并将新的看门狗 ID 作为超级调用返回值返回。该封装通过 id 存储新的 ID。当 id 指向非零值时， timeout updates that watchdog, and a zero timeout destroys it.

参数
[in,out]id看门狗标识符。
timeout传给 Xen 的看门狗超时值，以秒为单位。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-EINVALid 为 NULL，或 id 指向零且 timeout 为零。
