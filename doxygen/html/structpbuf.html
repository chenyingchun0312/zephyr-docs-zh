详细描述

安全打包缓冲区。

数据包缓冲区在读写双方共享的内存区域之上实现了具有读写语义的轻量级单向数据包缓冲区。它内置缓存和内存屏障管理，以确保正确的数据访问。

此结构体支持单个写入方和读取方。缓冲区中存储的数据会被封装成消息（带有长度头部）。读写 API 的编写方式可保护数据不被破坏。
