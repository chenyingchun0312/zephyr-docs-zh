◆ mpsc_pbuf_alloc()

union mpsc_pbuf_generic * mpsc_pbuf_alloc ( struct mpsc_pbuf_buffer * buffer,
size_t wlen,
k_timeout_t timeout )

分配一个包。

若缓冲区配置为覆盖模式，则在没有空间分配新缓冲区时丢弃最旧的包。否则分配失败并返回空指针。

参数
bufferBuffer.
wlen要分配的字数。
timeout超时时间。若在线程上下文中调用，则在丢弃最旧包或返回 null 之前无法分配包时，将按给定超时挂起。
返回
指向所分配空间的指针，若无法分配则为 null。
