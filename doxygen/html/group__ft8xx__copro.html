绘制十进制数字

默认情况下（x, y）为文本左上角像素。 FT8XX_OPT_CENTERX centers the text horizontally, FT8XX_OPT_CENTERY centers it vertically. FT8XX_OPT_CENTER centers the text in both directions. FT8XX_OPT_RIGHTX right-justifies the text, so that the x is the rightmost pixel. By default the number is displayed with no leading zeroes, but if a width 1-9 is specified in the options, then the number is padded if necessary with leading zeroes so that it has the given width. If FT8XX_OPT_SIGNED is given, the number is treated as signed, and prefixed by a minus sign if negative.

number要显示的数字。

跟踪图形对象上的触摸

此命令使协处理器引擎跟踪特定图形对象上的触摸，并分配一个有效标签值。随后协处理器引擎将按 LCD 显示面板的帧率周期性更新 REG_TRACKER。

协处理器引擎以旋转跟踪模式和线性跟踪模式跟踪图形对象：

  • 旋转跟踪模式。跟踪触摸点与 tag 值所指定图形对象中心之间的角度。该值以圆的 1/65536 为单位。0 表示角度正下方，0x4000 为左侧，0x8000 为正上方，0xC000 为右侧（相对中心）。
  • 线性跟踪模式。如果 width 大于 height，则跟踪触摸点相对于 tag 值所指定图形对象宽度的相对距离。如果 width 不大于 height，则跟踪触摸点相对于该图形对象高度的相对距离。该值以图形对象宽度或高度的 1/65536 为单位。触摸点的距离指从图形对象左上角像素到触摸点坐标的距离。

对于线性跟踪功能，x 表示跟踪区域左上角的 x 坐标，y 表示跟踪区域左上角的 y 坐标。两个参数均以像素为单位。

对于旋转跟踪功能，x 表示跟踪区域中心的 x 坐标，y 表示跟踪区域中心的 y 坐标。两个参数均以像素为单位。

注解
width 和 height 为 (1,1) 表示跟踪器为旋转式，并在 REG_TRACKER 中报告角度值。width 和 height 为 (0,0) 会禁用协处理器引擎的跟踪功能。
参数
dev设备结构体
xx 坐标
yy 坐标
width跟踪区域的宽度，单位为像素。
height跟踪区域的高度，单位为像素。
