◆ lockable

bool bt_csip_set_member_register_param::lockable

布尔值，用于设置该集是否可被客户端锁定

将其设为 false 将禁用锁定特征。若未启用 CONFIG_BT_CSIP_SET_MEMBER_LOCK_SUPPORT，则忽略此项。

◆ parent

const struct bt_gatt_service* bt_csip_set_member_register_param::parent

父服务指针

若此 CSIS 实例被其他服务包含，则为必需的父服务指针。所有 CSIS 实例在 CONFIG_BT_CSIP_SET_MEMBER_MAX_INSTANCE_COUNT is above 1 shall be included by another service, as per the Coordinated Set Identification Profile (CSIP).

◆ rank

uint8_t bt_csip_set_member_register_param::rank

本设备在该集中的等级。

若 lockable 参数为 true，则该值应 > 0 且 <= set_size（若启用了集大小支持）。若 lockable 参数为 false，可将其设为 0 以禁用等级特征。

若未启用 CONFIG_BT_CSIP_SET_MEMBER_RANK_SUPPORT，则忽略此项。

◆ set_size

uint8_t bt_csip_set_member_register_param::set_size

集的大小。

若设为 0，则不会初始化集大小特征。若未启用 CONFIG_BT_CSIP_SET_MEMBER_SIZE_SUPPORT，则忽略此项。

◆ sirk

uint8_t bt_csip_set_member_register_param::sirk[16U]

唯一的集标识解析密钥（SIRK）

不同集之间必须唯一，且对同一集的每个集成员都必须相同。
