◆ hwinfo_get_device_id()

ssize_t hwinfo_get_device_id ( uint8_t * buffer,
size_t length )

#include <zephyr/drivers/hwinfo.h>

将设备 ID 复制到缓冲区

此例程将 "length" 个字节的设备 ID 复制到缓冲区。如果设备 ID 短于 length，缓冲区其余部分保持不变。该 ID 取决于硬件，不保证唯一。

驱动负责确保 ID 数据结构是字节序列。返回的 ID 值不应基于厂商特定的字节序假设来解释。它应把标识符表达为原始字节序列，并进行必要的字节序转换，使这些字节的十六进制表示产生预期的序列号。

参数
buffer要写入 ID 的缓冲区。
length缓冲区的最大长度。
返回
复制的设备 ID 大小，失败时为负的 errno 值。
返回值
-ENOSYS该特定设备没有实现。

◆ hwinfo_get_reset_cause()

int hwinfo_get_reset_cause ( uint32_t * cause)

#include <zephyr/drivers/hwinfo.h>

获取设备复位的原因。

参数
cause按位或的 reset cause 标志

此例程获取指示设备为何被复位的标志。

在某些平台上，复位原因标志会在连续复位之间累积，此例程可能返回多个标志，指示设备上电以来的所有复位原因。如果你只需要最近一次复位的原因，请在调用此例程后调用 hwinfo_clear_reset_cause 清除硬件标志，以便在下次复位事件之前生效。

除非已调用 hwinfo_clear_reset_cause，连续调用此例程将返回相同的值。

返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENOSYS该特定设备没有实现。
