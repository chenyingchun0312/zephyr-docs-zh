创建一个设备对象并为其设置启动时初始化，且具备反初始化能力。

此宏定义一个由内核在系统初始化期间自动配置的 device。仅当设备不是从设备树节点分配时才应使用此宏。如果要从设备树节点分配设备，请改用 DEVICE_DT_DEINIT_DEFINE() 或 DEVICE_DT_INST_DEINIT_DEFINE()。

注意：仅当启用 CONFIG_DEVICE_DEINIT_SUPPORT 时才会使用 deinit_fn。

参数
dev_id一个唯一令牌，作为 C 标识符用在全局设备结构体的名称中。
name设备的字符串名称，将存储在 device::name. This name can be used to look up the device with device_get_binding(). This must be less than Z_DEVICE_MAX_NAME_LEN characters (including terminating NULL) in order to be looked up from user mode.
init_fn指向设备初始化函数的指针，该函数由内核在系统初始化期间运行。可以为 NULL。
deinit_fn指向设备反初始化函数的指针。可以为 NULL。它必须释放任何已获取的资源（例如引脚、总线、时钟……），并使设备处于复位状态。
pm指向设备电源管理资源的指针，是一个 pm_device, which will be stored in device.pm field. Use NULL if the device does not use PM.
data指向设备私有可变数据的指针，将存储在 device::data 中。
config指向设备私有常量数据的指针，将存储在 device::config 中。
level设备的初始化级别（PRE_KERNEL_1、PRE_KERNEL_2 或 POST_KERNEL）。
prio设备在其初始化级别内的优先级。详情参见 SYS_INIT()。
api指向设备 API 结构的指针。可以为 NULL。

从设备树节点标识符创建设备对象，并为其设置启动时初始化。

此宏定义一个由内核在系统初始化期间自动配置的 device。全局设备对象作为 C 标识符的名称派生自节点的依赖序号或哈希。 device::name is set to DEVICE_DT_NAME(node_id).

该设备以 extern 可见性声明，因此任何包含 <zephyr/device.h> 的源文件都可以用 DEVICE_DT_GET(node_id) 获取指向全局设备对象的指针（即使来自扩展，当 CONFIG_LLEXT_EXPORT_SYMBOL_GROUP_DEVICE is enabled). Before using the pointer, the referenced object should be checked using device_is_ready().

注意：仅当启用 CONFIG_DEVICE_DEINIT_SUPPORT 时才会使用 deinit_fn。

参数
node_id设备树节点标识符。
init_fn指向设备初始化函数的指针，该函数由内核在系统初始化期间运行。可以为 NULL。
deinit_fn指向设备反初始化函数的指针。可以为 NULL。它必须释放任何已获取的资源（例如引脚、总线、时钟……），并使设备处于复位状态。
pm指向设备电源管理资源的指针，是一个 pm_device, which will be stored in device.pm. Use NULL if the device does not use PM.
data指向设备私有可变数据的指针，将存储在 device::data 中。
config指向设备私有常量数据的指针，将存储在 device::config 字段中。
level设备的初始化级别（PRE_KERNEL_1、PRE_KERNEL_2 或 POST_KERNEL）。
prio设备在其初始化级别内的优先级。详情参见 SYS_INIT()。
api指向设备 API 结构的指针。可以为 NULL。

int device_required_foreach ( const struct device * dev,

#include <zephyr/device.h>

访问 dev 直接需要的每个设备。

Zephyr 维护关于哪些设备被另一设备直接需要的信息；例如，基于 I2C 的传感器驱动需要 I2C 控制器进行通信。被需要的设备可以来自静态定义的设备树关系，或在运行时注册的依赖项。

此 API 支持对所需设备集合进行操作。示例用途包括：在使用某个设备之前确保其所需设备已就绪，以及在不再需要该设备时释放它们。

如果 visitor_cb 函数返回负值，则中止迭代，并将访问函数的返回值从此函数返回。

注解
非特权线程无法使用此 API。
参数
dev关注的设备。此设备所依赖的设备将作为要访问的设备集合。此参数不得为空。
visitor_cb应对依赖集合中每个设备调用的函数。此参数不得为空。
context传递给访问函数的状态。如果 visitor_cb 能容忍为空的 context，此参数可以为空。
返回
如果所有访问都成功，则为已访问的设备数量；否则为第一次未成功的访问所返回的负值。
