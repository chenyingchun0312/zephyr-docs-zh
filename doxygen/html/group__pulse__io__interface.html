编码器辅助函数（预展开）

v1 仅提供预展开辅助函数：每次调用将协议有效载荷展开为完全解析的 pulse_symbol 数组，再由调用者通过 pulse_io_transmit_sync 或 RTIO 路径提交。

未来的修订可能增加流式变体，从发送 ISR 中增量消费有效载荷；该路径将是增量的，不会改变此处定义的入口点。

RTIO 集成

后端可以同时提供 RTIO 提交路径以及协议编码器与解码器 vtable，与传感器子系统类似。借助这些，用户空间和异步 I/O 机制由 RTIO 提供：客户端将有效载荷编码为符号缓冲区，通过 RTIO 队列提交，并解码任何捕获到的回复。

详细描述

脉冲 IO 接口

自从
4.4
版本
0.1.0

pulse_io 子系统对在单条 GPIO 线上生成和捕获带时序的数字边沿的硬件外设进行抽象。它旨在为多个 MCU 系列以不同名称提供的专用边沿时序外设提供公共 API。

该 API 支持两种提交模式，通过以下方式声明 capabilities:

  • PULSE_IO_MODE_SYMBOL - 任意 {level, duration} 对。
  • PULSE_IO_MODE_CELL - 周期固定、占空比或电平可变的单元（适合 PWM 式硬件）。

客户端在探测时查询 pulse_io_get_capabilities，以决定使用哪种模式及特性集。
