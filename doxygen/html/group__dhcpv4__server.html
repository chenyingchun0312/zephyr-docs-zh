typedef bool(*) net_dhcpv4_server_address_validator_cb_t(struct net_if *iface, const struct dhcpv4_client_id *client_id, const struct net_in_addr *addr, void *user_data)

#include <zephyr/net/dhcpv4_server.h>

用于让应用程序接受或拒绝所提议的 DHCP 地址的回调

该函数在为客户端接受地址之前调用，允许应用程序拒绝给定客户端的地址。若回调返回 0，则 addr 必须是有效地址，并将分配给该客户端。若回调返回任何非零值，则从地址池中为该客户端分配地址。

参数
iface指向网络接口的指针
client_id指向请求该地址的客户端的指针
addr要分配给客户端的地址
user_data指向用户数据的有效指针，或 NULL

◆ net_dhcpv4_server_start()

int net_dhcpv4_server_start ( struct net_if * iface,
struct net_in_addr * base_addr )

#include <zephyr/net/dhcpv4_server.h>

在 iface 上启动 DHCPv4 服务器实例

在给定接口上启动 DHCPv4 服务器。服务器将在该接口上开始监听 DHCPv4 Discover/Request 消息，并从配置的地址池中相应地分配 IPv4 地址。

参数
iface指向接口的有效指针
base_addrDHCPv4 地址池中的第一个 IPv4 地址。地址池中的地址数量通过 Kconfig（CONFIG_NET_DHCPV4_SERVER_ADDR_COUNT）静态配置。
返回
成功时返回 0，否则返回负的错误码。

◆ net_dhcpv4_server_stop()

int net_dhcpv4_server_stop ( struct net_if * iface)

#include <zephyr/net/dhcpv4_server.h>

停止 iface 上的 DHCPv4 服务器实例

停止给定接口上的 DHCPv4 服务器。该接口上不再处理 DHCPv4 请求，所有分配均被清除。

参数

返回
