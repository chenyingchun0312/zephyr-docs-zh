◆ uvc_device_init()

void uvc_device_init ( const struct device * uvc_dev,
const struct device * video_dev )

#include <zephyr/usb/class/usbd_uvc.h>

初始化视频设备类。

设置 UVC 实例将用于控制请求的视频设备。

它将查询其支持的视频控件和帧间隔，并使用这些信息生成呈现给主机的 USB 描述符。此外，对于主机发往此 uvc_dev 实例的每个受支持的 UVC 控制请求，它都会向 video_dev 发出对应的视频 API 控制请求。

注解
必须在 uvc_device_enable 之前调用此函数。
参数
uvc_dev指向要配置的 UVC 设备的指针
video_dev指向接收控制请求的视频设备的指针
