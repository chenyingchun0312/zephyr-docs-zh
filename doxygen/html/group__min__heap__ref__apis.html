详细描述

引用式（基于句柄的）最小堆实现

最小堆是一种基于二叉树的数据结构，其中最小元素始终位于根。与基于值的最小堆不同，此变体存储指向调用方所拥有节点的指针，节点内嵌 min_heap_handle，因此插入是零拷贝的，并且可以使用句柄在 O(log n) 时间内移除特定节点，无需搜索。

按内部存储数组顺序（广度优先层序）访问所有元素。这 不是 排序后的顺序

MIN_HEAP_REF_FOREACH(&heap, h) {
struct data *t = CONTAINER_OF(h, struct data, handle);

用于最小堆排序的比较函数类型。

此函数比较两个堆节点以确定它们的相对顺序。它必须由用户实现，并在初始化最小堆时提供。

参数
a用于比较的第一个句柄指针。
b用于比较的第二个句柄指针。
返回
若 a 小于 b 则为负值，若 a 大于 b 则为正值，若二者相等则为零。
