◆ KINETIS_SIM_CLOCK

#define KINETIS_SIM_CLOCK ( name,
offset,
bits )
值:
KINETIS_SIM_CLOCK_ID(name, offset, bits) offset bits

构建 3 单元 SIM 时钟说明符。

展开为 <id 偏移位>，其中 id 编码门控和速率信息，而 offset/bits 保持显式，以便于阅读以及供将其作为独立单元读取的使用者（例如 ADC16）使用。

参数
name时钟名称选择符（KINETIS_SIM_*_CLK）
offset门控寄存器偏移量（例如 0x1034）
bits门控位索引（0..31）

mux_shift,

值:
KINETIS_SIM_CLOCK_ID_MUX(name, offset, bits, mux_shift, mux_val) offset bits

构建带 mux 配置的 3 单元 SIM 时钟说明符。

类似 KINETIS_SIM_CLOCK，但还会编码 clock_control_configure() 支持所需的 mux 寄存器字段和值。

参数
name时钟名称选择符（KINETIS_SIM_*_CLK）
offset门控寄存器偏移量
bits门控位索引（0..31）
mux_shiftmux 字段在 mux 寄存器（例如 SOPT2）中的位偏移
mux_val要写入 mux 字段的值
