枚举类型说明

◆ os_mgmt_group_events

enum os_mgmt_group_events

#include <zephyr/mgmt/mcumgr/grp/os_mgmt/os_mgmt_callbacks.h>

操作系统管理组的 MGMT 事件操作码。

枚举值
MGMT_EVT_OP_OS_MGMT_RESET 

收到复位命令时调用的回调，数据为 os_mgmt_reset_data。

MGMT_EVT_OP_OS_MGMT_INFO_CHECK 

处理 info 命令时调用的回调，数据为 os_mgmt_info_check。

MGMT_EVT_OP_OS_MGMT_INFO_APPEND 

info 命令需要输出数据时调用的回调，数据为 os_mgmt_info_append。

MGMT_EVT_OP_OS_MGMT_DATETIME_GET 

收到 datetime get 命令时调用的回调。

MGMT_EVT_OP_OS_MGMT_DATETIME_SET 

收到 datetime set 命令时调用的回调，数据为 rtc_time。

MGMT_EVT_OP_OS_MGMT_BOOTLOADER_INFO 

收到 bootloader info 命令时调用的回调，数据为 os_mgmt_bootloader_info_data()。

MGMT_EVT_OP_OS_MGMT_ALL 

用于启用所有 os_mgmt_group 事件。
