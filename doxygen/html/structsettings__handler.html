详细描述

子树的配置处理函数实现了一组处理函数。它们通过调用 settings_register 注册。

结构体成员变量说明

◆ cprio

int settings_handler::cprio

提交的优先级，值越小优先级越高

◆ h_commit

int(*) settings_handler::h_commit(void)

此处理函数在设置完全加载后被调用。

用户可以用它将设置应用到应用程序。

返回
成功时为 0，失败时为非零。

◆ h_export

int(*) settings_handler::h_export(int(*export_func)(const char *name, const void *val, size_t val_len))

调用此处理函数可转储当前所有设置项。

当 settings_save 尝试保存设置时会发生此调用。

参数
[in]export_func指向内部函数的指针，该函数将单个键值对追加到已持久化的设置中。不要存储重复的值。name 为 subtree/key 字符串，val 为带值的字符串。
备注
用户可能限制处理函数的实现每次调用只处理一个关键字 - 这会限制使用完整 subtree/key 名称进行 get/set 值的操作。
返回
成功时为 0，失败时为非零。

◆ h_get

int(*) settings_handler::h_get(const char *key, char *val, int val_len_max)

获取由关键字名称标识的设置项的值的处理函数。

参数
[in]key跳过前缀部分后的名称，即注册处理函数时使用的名称
[out]val用于接收值的缓冲区。
[in]val_len_max该缓冲区的大小。
返回
成功时为读取数据的长度，失败时为负值。

int(*) settings_handler::h_set(const char *key, size_t len, settings_read_cb read_cb, void *cb_arg)

设置由关键字名称标识的设置项的值的处理函数。

参数
[in]key跳过前缀部分后的名称，即注册处理函数时使用的名称
[in]len后端中找到的数据大小。
[in]read_cb由后端提供的、用于从后端读取数据的函数。
[in]cb_arg由后端提供的读取函数参数。
返回
成功时为 0，失败时为非零。
