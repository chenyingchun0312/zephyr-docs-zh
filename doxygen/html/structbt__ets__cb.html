void(*) bt_ets_cb::indication_changed(bool enabled)

参数
enabled如果启用了指示则为 true，禁用则为 false。

◆ read_clock_status

int(*) bt_ets_cb::read_clock_status(uint8_t *status)

读取时钟状态（BT_ETS_CLOCK_STATUS）的回调（必需）。

当 BLE 客户端读取当前已用时间特征时调用。应用程序必须返回当前的时钟状态标志。

参数
status指向用于存放时钟状态字节的指针。
返回值
0成功时。
-errno失败时返回负的 errno。

◆ read_elapsed_time

int(*) bt_ets_cb::read_elapsed_time(struct bt_ets_elapsed_time *time)

读取已用时间的回调（必需）。

当 BLE 客户端读取当前已用时间特征时调用。应用程序必须用当前时间信息填充已用时间结构体。

参数
time要填充的已用时间结构体。
返回值
0成功时。
-errno失败时返回负的 errno。

◆ write_elapsed_time

enum bt_ets_write_result(*) bt_ets_cb::write_elapsed_time(const struct bt_ets_elapsed_time *time)

写入已用时间的回调（可选）。

当 BLE 客户端写入当前已用时间特征时调用。应用程序应校验时间源质量、范围及其他约束。

注意
Available only when the following Kconfig option is enabled: CONFIG_BT_ETS_CURRENT_ELAPSED_TIME_WRITABLE.
注解
根据规范，时钟状态和时钟能力不可写入。
参数
time由客户端写入的已用时间结构体。
返回
表示接受或具体拒绝原因的结果码。
