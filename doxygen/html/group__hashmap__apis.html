详细描述

哈希映射（哈希表）API

哈希映射（又称哈希表）以空间换速度。对哈希映射的所有操作（插入、删除、搜索）平均复杂度都是 O(1)。

判断哈希映射是否应调整大小

这是一个简单的机会式方法，实现可以选择使用。当插入/移除会超过/落入指定的装载因子时，它会以 2 为因子增大或缩小哈希映射。

注解
用户应在插入新的键值对之前、移除键值对之后调用它。
保留条目数由实现定义，但只有在扩容哈希表时才把它计入装载因子。
参数
map要检查的哈希映射
grow若要添加条目则为 true。若已移除条目则为 false
num_reserved保留条目数
[out]new_num_buckets可变的哈希映射大小
返回
若哈希映射应重新哈希则为 true
若哈希映射不应重新哈希则为 false
