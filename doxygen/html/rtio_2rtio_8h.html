详细描述

用于以低开销搬运字节的实时 IO 设备 API

RTIO 是使用提交队列和完成队列进行异步批量操作的上下文。

异步 I/O 操作在提交队列中设置。队列中的每个条目都描述了它希望执行的操作，并带有一些已约定的语义。

这些操作可以按这样的方式链式组织：只有当前操作完成后，下一个操作才会执行。如果当前操作失败，所有链式操作也会失败。

操作也可以作为一个事务提交，此时一组操作被视为一个操作。

这些操作的完成通常会提供一个或多个完成队列事件。
