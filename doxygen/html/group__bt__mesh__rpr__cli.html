#include <zephyr/bluetooth/mesh/rpr_cli.h>

开始扫描未配网设备。

告知 Remote Provisioning Server 开始扫描未配网设备。服务器将通过 bt_mesh_rpr_cli::scan_report 回调上报结果。

使用 uuid 参数扫描特定设备，或将其留为 NULL 以上报所有未配网设备。

服务器将忽略重复项，最多上报 max_devs 个设备。请求的 max_devs 数量高于服务器能力将导致错误。

参数
cli远程配网客户端。
srv远程配网服务器。
uuid要扫描的设备 UUID，或 NULL 表示上报所有设备。
timeout扫描超时时间（秒）。必须至少为 1 秒。
max_devs要上报的最大设备数量，或 0 表示尽可能多地上报。
status扫描状态响应缓冲区。
返回
成功时返回 0，否则返回（负的）错误码。

#include <zephyr/bluetooth/mesh/rpr_cli.h>

开始对未配网设备进行扩展扫描。

扩展扫描是对常规未配网扫描的补充，允许服务器上报特定设备的额外数据。如果支持，Remote Provisioning Server 将使用主动扫描向未配网设备请求扫描响应。如果未提供 UUID，服务器将上报对其自身带外信息和广播数据的扫描。

使用 ad_types 数组指定要包含在扫描报告中的 AD 类型。某些 AD 类型会触发特殊行为：

  • BT_DATA_NAME_COMPLETE 将同时上报完整名称和缩短名称。
  • BT_DATA_URI 如果未配网信标包含 URI 哈希，服务器将扩展扫描范围以包括扫描响应之外的数据包，以查找与 URI 哈希匹配的 URI。只有匹配的 URI 才会被上报。

不应使用以下 AD 类型：

  • BT_DATA_NAME_SHORTENED
  • BT_DATA_UUID16_SOME
  • BT_DATA_UUID32_SOME
  • BT_DATA_UUID128_SOME

此外，每种 AD 类型只能出现一次。

参数
cli远程配网客户端。
srv远程配网服务器。
uuid要开始扩展扫描的设备 UUID，或 NULL 表示扫描远程服务器。
timeout扫描超时时间（秒）。有效值从 BT_MESH_RPR_EXT_SCAN_TIME_MIN 到 BT_MESH_RPR_EXT_SCAN_TIME_MAX。如果 UUID 为 NULL 则忽略。
ad_types要包含在扫描报告中的 AD 类型列表。必须包含 1 到 CONFIG_BT_MESH_RPR_AD_TYPES_MAX 个条目。
ad_countad_types 中的 AD 类型数量。
返回
成功时返回 0，否则返回（负的）错误码。
