详细描述

架构特定的栈回溯 API

要为架构添加 API 支持，应实现 arch_stack_walk()，并在该架构的顶层 Kconfig 中创建一个非用户可配置、默认为 y 的 Kconfig 项 ARCH_HAS_STACKWALK，并包含所有相关依赖。

stack_trace_callback_fn - arch_stack_walk 的回调

参数
cookie由 arch_stack_walk 回传的调用者提供的指针
addr要消费的栈条目地址
返回
如果该条目已被消费或跳过则为 True。如果没有剩余空间可存储则为 False
