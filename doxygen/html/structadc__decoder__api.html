◆ decode

int(*) adc_decoder_api::decode(const uint8_t *buffer, uint32_t channel, uint32_t *fit, uint16_t max_count, void *data_out)

从缓冲区中解码最多 max_count 个采样

跨多帧解码通道的采样。若同一通道存在多个实例，则用 channel_index 区分它们。

参数
[in]bufferRTIO 上下文中提供的缓冲区
[in]channel要解码的通道
[in,out]fit当前帧迭代器
[in]max_count要解码的最大通道数。
[out]data_out解码后的数据
返回
0 没有更多可解码的采样
>0 已解码的帧数
<0 出错

◆ get_size_info

int(*) adc_decoder_api::get_size_info(struct adc_dt_spec adc_spec, uint32_t channel, size_t *base_size, size_t *frame_size)

获取解码给定通道所需的大小

解码单帧时使用 base_size。每增加一帧，再增加 frame_size. As an example, to decode 3 frames use: 'base_size + 2 * frame_size'.

参数
[in]adc_specADC 规格
[in]channel要查询的通道
[out]base_size解码第一帧的大小
[out]frame_size每增加一帧的额外大小
返回
成功时为 0
若不支持该通道则为 -ENOTSUP
