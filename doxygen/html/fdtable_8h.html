◆ anonymous enum

anonymous enum

fd_op_vtable.ioctl() 的请求码。

注意这些代码是 Zephyr 内部编号，用于 Zephyr 内部操作（可能随时更改而不另行通知，不属于 "stable ABI"）。但预期它们能与 "well-known" 的 POSIX/Linux ioctl 编号共存而不冲突。

◆ zvfs_get_fd_obj()

void * zvfs_get_fd_obj ( int fd,
const struct fd_op_vtable * vtable,
int err )

从文件描述符获取底层对象指针。

对于 read/write/ioctl 之外的函数，此函数可用于按 fd 查找底层 I/O 对象，并可选地检查其类型（使用 vtable 引用）。若 fd 指向无效条目，将返回 NULL，并把 errno 设为 EBADF。若 fd 有效，但 vtable 参数不为 NULL 且与该对象的 vtable 不匹配，则返回 NULL，并把 errno 设为 err 参数。

参数
fd先前由 zvfs_reserve_fd() 返回的文件描述符
vtable期望的对象 vtable 或 NULL
err对象 vtable 不匹配时要设置的 errno 值
返回
对象指针或 NULL，并已设置 errno

获取与给定对象和 vtable 关联的互斥量和条件变量。

成功时为 true，否则为 false。

◆ zvfs_reserve_fd()

int zvfs_reserve_fd ( void )

预留文件描述符。

此函数允许在底层表中为文件描述符条目预留空间，从而使调用方在无空闲描述符时能快速失败。若此函数成功，则必须调用 zvfs_finalize_fd() 或 zvfs_free_fd()。

返回
已分配的文件描述符，出错时为 -1（并设置 errno）
