◆ mqtt_sn_topic_type

enum mqtt_sn_topic_type

#include <zephyr/net/mqtt_sn.h>

MQTT-SN 主题类型。

枚举值
MQTT_SN_TOPIC_TYPE_NORMAL 

普通主题。它允许使用任何有效的 UTF-8 字符串作为主题名称。

MQTT_SN_TOPIC_TYPE_PREDEF 

预定义主题。它允许使用表示主题名称的两字节标识符，该主题名称由客户端和网关/服务器双方预先知晓。

MQTT_SN_TOPIC_TYPE_SHORT 

短主题。它允许使用两字节字符串作为主题名称。

◆ mqtt_sn_update_will_message()

int mqtt_sn_update_will_message ( struct mqtt_sn_client * client)

#include <zephyr/net/mqtt_sn.h>

向服务器发送遗嘱消息更新。

调用此函数可将存储在 client->will_msg 中的遗嘱消息发送到服务器。如果你在连接后更改了该值，则应使用它。

警告
由于遗嘱消息更新消息中没有消息 ID，因此无法在没有竞态条件的情况下完成。如果你希望改变这一点，请为规范的新版本做出贡献。
参数
[in]client用于发送更新的 MQTT-SN 客户端。
返回
0 或表示失败原因的负错误代码（errno.h）。
