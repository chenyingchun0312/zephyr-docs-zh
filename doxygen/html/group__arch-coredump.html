void arch_coredump_cpu_snapshot_dump ( unsigned int cpu)

#include <kernel/include/kernel_arch_interface.h>

输出为给定 CPU 索引捕获的实时寄存器快照

若该 CPU 从未成功冻结（自身、从未启动或超时），则什么也不做。只可在 arch_coredump_freeze_other_cpus() 与 arch_coredump_thaw_other_cpus() 之间调用。

参数
cpuCPU 索引（0..CONFIG_MP_MAX_NUM_CPUS-1）

◆ arch_coredump_freeze_other_cpus()

void arch_coredump_freeze_other_cpus ( void )

#include <kernel/include/kernel_arch_interface.h>

冻结其他所有在线 CPU 并捕获其实时寄存器状态

向除调用者之外的每个 CPU 发送架构特定的 IPI，并（在有限超时内）等待每个 CPU 报告已捕获的快照。未及时响应的 CPU（从未启动，或屏蔽 IRQ 后忙于其他事务）会被直接跳过——此操作绝不能无限期阻塞。

必须与之后对 arch_coredump_thaw_other_cpus() 的调用配对，以便被冻结的 CPU 恢复；不得同时从多个 CPU 调用。
