◆ boot_is_img_confirmed()

bool boot_is_img_confirmed ( void )

#include <zephyr/dfu/mcuboot.h>

检查当前运行的镜像是否已确认为 OK。

MCUboot 可以执行"测试"升级。发生这种升级时会安装并引导新的固件镜像，但除非新镜像显式将自身标记为 OK，否则旧版本将在下次复位时恢复。

该例程可用于检查当前运行的镜像是否已被标记为 OK。

返回
若镜像已确认为 OK 则为 true，否则为 false。
参见
boot_write_img_confirmed()

◆ boot_write_img_confirmed()

int boot_write_img_confirmed ( void )

#include <zephyr/dfu/mcuboot.h>

将当前运行的镜像标记为已确认。

该例程尝试将当前运行的固件镜像标记为 OK，从而将其永久安装，防止 MCUboot 在下次复位时将其回退为较旧的镜像。

若当前镜像已确认，调用该例程是安全的。这种情况下它会返回成功结果。

返回
成功时为 0，失败时为负的 errno 错误码。
