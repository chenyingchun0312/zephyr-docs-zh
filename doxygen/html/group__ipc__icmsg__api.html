◆ icmsg_state

enum icmsg_state

#include <zephyr/ipc/icmsg.h>

枚举值
ICMSG_STATE_OFF 

实例尚未初始化。在此状态下：发送会失败，允许打开。

ICMSG_STATE_INITIALIZING_SID_DISABLED 

实例正在初始化，未使用会话握手。在此状态下：发送会失败，打开会失败。

ICMSG_STATE_INITIALIZING_SID_ENABLED 

实例正在使用会话握手进行初始化。它正在等待远端确认本地会话 id。在此状态下：发送会失败，允许打开（本地会话 id 会改变，因此远端可能会收到 unbound() 回调）。

ICMSG_STATE_INITIALIZING_SID_DETECT 

实例正在初始化，并检测远端是否支持会话握手。它正在等待远端确认本地会话 id 或发送 magic 字节。在此状态下：发送会失败，允许打开（本地会话 id 会改变，因此如果远端支持，可能会收到 unbound() 回调）。

ICMSG_STATE_DISCONNECTED 

实例已在远端关闭。本地侧已发送 unbound() 回调。在此状态下：发送会被静默丢弃（可能存在过期的发送），允许打开。

ICMSG_STATE_CONNECTED_SID_DISABLED 

实例已连接，不支持会话握手。在此状态下：发送会成功，打开会失败。

ICMSG_STATE_CONNECTED_SID_ENABLED 

实例已连接，支持会话握手。在此状态下：发送会成功，允许打开（会话会改变，远端会收到 unbound() 回调）。

int icmsg_close ( const struct icmsg_config_t * conf,
struct icmsg_data_t * dev_data )

#include <zephyr/ipc/icmsg.h>

关闭 icmsg 实例

关闭 icmsg 实例会释放该实例使用的所有资源，包括共享内存区域和 mbox 设备。

参数
[in]conf包含要关闭的 icmsg 实例配置参数的结构体。其内容必须与使用 icmsg_open 创建此实例时所用的内容相同。
[in,out]dev_data包含 icmsg 实例使用的运行时数据的结构体。
返回值
0成功时。
other来自依赖模块的 errno 错误码。

#include <zephyr/ipc/icmsg.h>

打开 icmsg 实例

打开 icmsg 实例，以便向远端实例发送消息和接收消息。此函数会阻塞，直到与远端实例的握手完成。此函数应在初始化过程的后期调用，可能从某个线程调用，该线程在与远端实例执行握手期间可以安全地被阻塞。

参数
[in]conf包含 icmsg 实例配置参数的结构体。
[in,out]dev_data包含 icmsg 实例使用的运行时数据的结构体。
[in]cb包含在此 icmsg 实例产生的事件上要调用的回调函数的结构体。在 icmsg 实例活动期间，所指向的内存必须保持不变。
[in]ctx指向作为参数传递给回调的上下文的指针。
返回值
0成功时。
-EALREADY当实例已经打开时。
other来自依赖模块的 errno 错误码。

#include <zephyr/ipc/icmsg.h>

向远端 icmsg 实例发送消息。

参数
[in]conf包含 icmsg 实例配置参数的结构体。
[in,out]dev_data包含 icmsg 实例使用的运行时数据的结构体。
[in]msg指向包含要发送数据的缓冲区的指针。
[in]lenmsg 缓冲区中数据的大小。
返回值
Number已发送的字节数。
-EBUSY当实例尚未完成与远端实例的握手时。
-ENODATA当请求发送的数据为空时。
-EBADMSG当请求发送的数据过大时。
-ENOBUFS当没有可用的 TX 缓冲区时。
other来自依赖模块的 errno 错误码。
