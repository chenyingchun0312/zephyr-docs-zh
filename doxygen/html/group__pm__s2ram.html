◆ pm_s2ram_system_off_fn_t

typedef int(*) pm_s2ram_system_off_fn_t(void)

#include <zephyr/arch/common/pm_s2ram.h>

系统关机函数

此函数作为参数传入，由 arch_pm_s2ram_suspend 调用，用于在保存 CPU 上下文后关闭系统电源。

如果系统已关机，此函数不会返回。如果无法执行该操作，则返回适当的值，代码必须在返回之前负责将系统恢复到完全可运行状态。

返回值
none系统已关机。
-EBUSY系统忙，此时无法关机。
-errno其他错误码。

◆ arch_pm_s2ram_suspend()

int arch_pm_s2ram_suspend ( pm_s2ram_system_off_fn_t system_off)

#include <zephyr/arch/common/pm_s2ram.h>

在挂起时保存 CPU 上下文

此函数用于挂起到 RAM（S2RAM），在使用所提供的函数关闭系统电源之前将 CPU 上下文保存到（保留）RAM 中。此函数通常由 PM 子系统/钩子调用。

CPU 上下文通常是 CPU 寄存器的最小集合，必须在恢复时还原其内容，以使平台从挂起时所处的执行点继续执行。

参数
system_off用于关闭系统电源的函数。
返回值
0CPU 上下文已成功保存并恢复。
-EBUSY系统忙，此时无法挂起。
-errno失败时为负的 errno 码。

◆ pm_s2ram_mark_check_and_clear()

bool pm_s2ram_mark_check_and_clear ( void )

#include <zephyr/arch/common/pm_s2ram.h>

检查挂起到 RAM 标记并清除其状态。

此函数用于确定应执行挂起到 RAM 后的恢复，还是执行标准启动代码。

默认实现是检查 RAM 中的一个魔数，在未设置 CONFIG_HAS_PM_S2RAM_CUSTOM_MARKING 时使用。

返回值
true如果找到标记，表示挂起到 RAM 后恢复。
false如果未找到标记，表示标准启动。
