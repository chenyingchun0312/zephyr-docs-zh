详细描述

用于处理网络超时的通用结构体。

除链接节点外，对这些对象状态的所有访问都必须通过已定义的 API 进行。

结构体成员变量说明

◆ node

sys_snode_t net_timeout::node

用于链接共享同一套定时器基础设施的多个超时。

例如，一组相关的定时器可能使用单个延迟工作结构，该结构总是在距某个超时事件最短的时间点被调度。

◆ timer_start

uint32_t net_timeout::timer_start

定时器最后一次被设置的时间。

这通常对应 k_uptime_get() 的低 32 位。

◆ timer_timeout

uint32_t net_timeout::timer_timeout

剩余超时中不超过 NET_TIMEOUT_MAX_VALUE 的部分。

该值与 timer_start 和 wrap_counter 一起由 net_timeout_evaluate() 同步更新。

◆ wrap_counter

uint32_t net_timeout::wrap_counter

定时器环绕计数。

它跟踪尚未经过的 NET_TIMEOUT_MAX_VALUE 毫秒的整数倍。它也会与 timer_start 和 wrap_counter 一起由 net_timeout_evaluate() 更新。
