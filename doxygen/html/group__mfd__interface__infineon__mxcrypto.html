CRYPTO_Type * mfd_infineon_mxcrypto_get_base ( const struct device * dev)

#include <zephyr/drivers/mfd/infineon_mxcrypto.h>

获取 MXCRYPTO 寄存器基地址。

该基地址由 MXCRYPTO 块的 TRNG 和加密（AES / SHA）子功能共享。

参数
[in]dev指向父 MFD 设备的指针。
返回
指向 CRYPTO 寄存器块的指针。

◆ mfd_infineon_mxcrypto_lock()

int mfd_infineon_mxcrypto_lock ( const struct device * dev,
k_timeout_t timeout )

#include <zephyr/drivers/mfd/infineon_mxcrypto.h>

获取共享的 MXCRYPTO 访问互斥量。

TRNG 和加密子功能共享同一个硬件块，因此子功能在任何不得与兄弟功能交错的多步硬件操作期间都必须持有此锁。

参数
[in]dev指向父 MFD 设备的指针。
[in]timeout锁获取超时。
返回值
0成功时。
-EAGAIN若未能在 timeout 内获取锁。
