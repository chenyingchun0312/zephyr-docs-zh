◆ ec_host_cmd_backend_api_init

typedef int(*) ec_host_cmd_backend_api_init(const struct ec_host_cmd_backend *backend, struct ec_host_cmd_rx_ctx *rx_ctx, struct ec_host_cmd_tx_buf *tx)

#include <zephyr/mgmt/ec_host_cmd/backend.h>

初始化主机命令后端

此例程初始化主机命令后端，包括初始化用于通信的设备以及设置缓冲区。此函数由 ec_host_cmd_init 函数调用。

参数
[in]backend指向驱动实例后端结构体的指针。
[in,out]rx_ctx指向接收上下文对象的指针。这些对象用于在主机发送数据时从驱动接收数据。buf 成员可由后端赋值。
[in,out]tx指向发送缓冲区对象的指针。buf 和 len_max 成员可由后端赋值。这些对象用于后端通过 ec_host_cmd_backend_api_send 函数发送数据。
返回值
0成功时
