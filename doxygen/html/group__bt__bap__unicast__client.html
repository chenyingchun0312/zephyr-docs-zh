发现远程能力与端点

客户端使用此过程发现远程能力和端点，并通过参数回调进行通知。

参数
connACL 连接。该连接必须已满足基本音频配置文件的安全要求。
dir要发现的远程端点与能力的类型。
返回值
0成功
-EINVAL如果 conn 为 NULL、不是中心连接或不符合安全要求，或者 dir 无效。
-EBUSY此 conn 上已有另一操作正在进行
-ENOTCONNconn 未连接
-ENOMEM无法为请求分配内存
-ENOEXEC意外的 GATT 错误

◆ bt_bap_unicast_group_add_streams()

int bt_bap_unicast_group_add_streams ( struct bt_bap_unicast_group * unicast_group,
struct bt_bap_unicast_group_stream_pair_param params[],
size_t num_param )

#include <zephyr/bluetooth/audio/bap.h>

以单播客户端身份向单播组添加流

此函数可用于向 bt_bap_unicast_group 添加更多流。

可在组内任何流启动之前的任意时刻调用（参见 bt_bap_stream_ops.started()）。也可在这些流停止之后调用（参见 bt_bap_stream_ops.stopped()）。

流一旦被添加到单播组，便无法移除。要从组中移除流，必须用 bt_bap_unicast_group_delete() 删除该组，但这需要先释放组中的所有流。

参数
unicast_group指向单播组的指针
params要添加到组中的流的流参数数组。
num_paramparams 中参数的数量。
返回
成功时为 0，出错时为负值。

◆ bt_bap_unicast_group_create()

int bt_bap_unicast_group_create ( struct bt_bap_unicast_group_param * param,
struct bt_bap_unicast_group ** unicast_group )

#include <zephyr/bluetooth/audio/bap.h>

创建单播组。

以单播客户端身份创建一个包含一个或多个音频流的音频单播组。所有流应共用相同的组帧方式。同一方向上的所有流应共用相同的间隔和延迟（参见 bt_bap_qos_cfg).

参数
[in]param单播组创建参数。
[out]unicast_group指向所创建单播组的指针。
返回
成功时为零，否则为（负的）错误码。

#include <zephyr/bluetooth/audio/bap.h>

重配置单播组。

以单播客户端身份用一个或多个音频流重配置单播组。所有流应共用相同的组帧方式。同一方向上的所有流应共用相同的间隔和延迟（参见 bt_bap_qos_cfg). All streams in param shall already belong to unicast_group. Use bt_bap_unicast_group_add_streams() to add additional streams.

参数
unicast_group指向所创建单播组的指针。
param单播组重配置参数。
返回
成功时为零，否则为（负的）错误码。
