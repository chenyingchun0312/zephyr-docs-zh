详细描述

伪稳压器驱动

This is a Fake Function Framework (FFF) implementation of the 稳压器 API, provided for use in tests. It is enabled by CONFIG_REGULATOR_FAKE and instantiated from zephyr,fake-regulator devicetree nodes.

Each fake below is paired with an FFF control structure named after it with an additional _fake suffix, which tests use to set return values, install custom fakes, or inspect call counts and captured arguments. The control structures are not listed here; see mocking-fff.

Use return_val for fakes that only report status; a fake with output parameters must be driven with a custom_fake, as return_val leaves those parameters untouched.

When CONFIG_ZTEST is enabled, a ztest rule resets every fake before each test case.

zephyr,fake-regulator 节点被实例化为调节器父设备，其每个子节点被实例化为一个调节器设备。

regulator_fake_get_voltage() 获得一个返回 1 V 的默认 custom_fake，每次复位时都会重新安装。在测试用例中安装你自己的 custom_fake 以改变其报告的值。
