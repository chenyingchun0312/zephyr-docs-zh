typedef void(*) cipher_completion_cb(struct cipher_pkt *completed, int status)

#include <zephyr/crypto/cipher.h>

处理异步密码请求的完成。

应用程序可以从已完成数据包中获取会话上下文。 ctx field. For AEAD operations, the encompassing AEAD packet can be accessed with container_of(). The packet type can be determined from the session cipher mode.

参数
completed已完成的密码数据包。
status完成状态。值为 0 表示成功，负的 errno 错误码表示失败。

int cipher_begin_session ( const struct device * dev,
struct cipher_ctx * ctx,
enum cipher_algo algo,
enum cipher_mode mode,
enum cipher_op optype )
inlinestatic

#include <zephyr/crypto/crypto.h>

建立加密会话

初始化一次性参数，例如会话密钥、算法和密码模式，这些参数在会话的所有操作中可能保持不变。状态可缓存在硬件和/或驱动的数据状态变量中。

参数
dev指向该驱动实例设备结构的指针。
ctx指向上下文结构体的指针。密钥、密钥长度等各种一次性参数通过此结构体提供。结构体文档说明了哪些字段须由应用程序在调用前填充。
algo此会话中要使用的加密算法，例如 AES
mode此会话中要使用的密码模式，例如 CBC、CTR
optype此会话中应加密还是解密
返回
成功时为 0，失败时为负的 errno 错误码。

◆ cipher_callback_set()

int cipher_callback_set ( const struct device * dev,
cipher_completion_cb cb )
inlinestatic

#include <zephyr/crypto/crypto.h>

向驱动注册异步加密操作完成回调

应用程序可注册异步加密操作完成回调处理函数，由驱动在先前通过 cipher_do_op() 提交的请求完成时调用。根据加密设备硬件的语义，该回调很可能在 ISR 上下文中调用。

参数
dev指向该驱动实例设备结构的指针。
cb指向要由驱动调用的应用程序回调的指针。
返回
成功时为 0，若驱动不支持异步操作则为 -ENOTSUP，其他错误为负的 errno 错误码。

◆ cipher_ctr_op()

int cipher_ctr_op ( struct cipher_ctx * ctx,
struct cipher_pkt * pkt,
uint8_t * iv )
inlinestatic

#include <zephyr/crypto/crypto.h>

执行计数器（CTR）模式加密操作。

参数
ctx指向此操作的加密上下文的指针。
pkt保存输入/输出缓冲区指针的结构体。
iv此操作的初始化向量（IV）。我们使用由 IV 和 ctr 拼接而成的分离计数器，因此 ivlen = keylen - ctrlen。'ctrlen' 在会话建立时通过 'ctx.mode_params.ctr_params.ctr_len' 参数指定。出于安全考虑，不应在多个操作（同一会话上下文中）之间重用 IV。分离计数器中非 IV 的部分对调用者透明，完全由加密提供方管理。
返回
成功时为 0，失败时为负的 errno 错误码。
