与 SECTION_PROLOGUE() 相同，但此宏必须用于在 XIP 平台上虚拟地址与加载地址不同的数据段（即它们会在程序启动时被复制到 RAM 中）。这样的段还必须使用 GROUP_DATA_LINK_IN 指定正确的输出加载地址。

使用 LLD 链接时，这等同于 SECTION_PROLOGUE()。

options,
align )
值:
name options : align

SECTION_PROLOGUE() 宏用于定义段的起始部分。

当向 LLD 提供 –omagic（-N）选项时，只有给定区域的第一个输出段具有对齐的 LMA（默认情况下，不带 –omagic 时，LLD 将每个段的 LMA 和 VMA 对齐到相同的值），并加上 VMA 地址之间的差值（如果是第一个段则为 0）。LMA 与 VMA 之间的差值对每个段都是恒定的，因此这模拟了 GNU LD 中的 ALIGN_WITH_INPUT 选项（XIP 系统需要）。

–omagic 标志定义在 cmake/linker/lld/target_baremetal.cmake 中

参数
name输出段的名称
options段选项，例如 (NOLOAD)，或留空
align对齐指示，例如 SUBALIGN()。可以留空。
