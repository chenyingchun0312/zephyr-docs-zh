typedef bool(*) i2c_rtio_cb_run_sync_start_async(const struct device *dev, int *status)

用于启动待处理 I2C 操作的回调

参数
devI2C 总线
status若函数返回 false（即消息同步完成），则为该操作的输出返回码；否则输出值无意义
返回值
true若启动了异步操作则为 true，否则为 false
