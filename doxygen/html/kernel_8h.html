uint32_t cpu_bitmask,
k_ipi_func_t func )

将 IPI 工作项添加到 IPI 工作队列

将指定的 IPI 工作项添加到 cpu_bitmask 所标识的每个 CPU 的 IPI 工作队列中。当这些 CPU 处理收到的 IPI 时，指定的 IPI 工作项随后将在 ISR 级别执行。在该 IPI 工作项被所有标识的 CPU 处理完毕之前，请勿复用它。

注意
Available only when the following Kconfig option is enabled: CONFIG_SCHED_IPI_SUPPORTED.
参数
work指向 IPI 工作项的指针
cpu_bitmaskIPI 工作项将发送到的 CPU 集合
func在目标 CPU 上执行的函数
返回值
0成功时
-EBUSY如果指定的 IPI 工作项仍在处理中

等待 IPI 工作项被所有目标 CPU 处理完毕

此例程等待 IPI 工作项被发送到的所有 CPU 处理完毕。如果从 ISR 中调用，则 timeout 必须设为 K_NO_WAIT。为避免死锁，调用者在调用此函数时不得锁定 IRQ。

注解
在调用 CPU 无法处理 IPI 的 ISR 或锁定上下文中，通常无法安全地轮询此函数的完成情况（因为目标 CPU 本身可能在等待调用 CPU）。应用程序代码必须为失败做好准备，或从线程上下文进行轮询。
注意
