详细描述

一种无锁且类型安全的 2 的幂固定大小单生产者单消费者（SPSC）队列，使用环形缓冲区和原子操作来保证一致性。

此 SPSC 队列实现作用于一个以 2 的幂大小回绕的数组，并使用位掩码执行取模。使用原子操作来实现无需锁的单生产者单消费者安全语义。元素大小预期固定。由于底层缓冲区带类型且所有使用都通过宏完成，该 API 是类型安全的。

SPSC 队列可以声明在栈上或静态声明，只要其生命期长于任何使用即可正常工作。应优先采用静态声明而非栈。它旨在作为两个执行上下文（例如 ISR 和线程）之间的共享对象

SPSC 队列可在 ISR 中安全地生产或消费，push/pull 为 O(1)。

警告
SPSC 在多个执行上下文中生产或消费 不 安全。

安全的用法如下，其中 A 和 B 是唯一的执行上下文：

  1. ISR A 生产，线程 B 消费。
  2. 线程 A 生产，ISR B 消费。
  3. 线程 A 生产，线程 B 消费。
  4. ISR A 生产，ISR B 消费。
