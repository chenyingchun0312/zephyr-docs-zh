详细描述

Driver Operations LIN Controller driver operations

This is the driver API structure any LIN Controller driver needs to define. It contains function pointers to the operations the driver implements, as well as any other driver-specific constant data.

Members marked with REQ MUST be set by the driver, whereas those marked with OPT are optional.
