HTTP 请求上下文

注解
已捕获的请求头（headers、 header_count 和 headers_status) are only populated in the first dynamic resource callback of a request. In any subsequent callback for the same request, headers is NULL, header_count is 0 and headers_status is HTTP_HEADER_STATUS_NONE. The first callback may or may not also carry request body data, so do not condition header handling on the presence of data. Copy out any header values you need during that first callback.
