内核版本 API

内核版本已从字符串转换为一个四字节量，该量分为两部分。

第 1 部分：最高三个有效字节表示内核的数字版本 x.y.z。这些字段表示：x —— 主发布版本 y —— 次发布版本 z —— 补丁级别发布版本 因此，其中每个元素都必须在 0 到 255（含）的范围内。

第 2 部分：最低有效字节保留供将来使用。
