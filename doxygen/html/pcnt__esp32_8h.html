详细描述

ESP32 PCNT 驱动的公共扩展。

用于通过不原生携带通道索引的旧式 sensor_attr_set()/sensor_attr_get()/sensor_trigger_set() API 寻址特定 PCNT 单元的辅助函数。通过读并解码 API 进行多单元访问时直接使用 sensor_chan_spec.chan_idx，不需要这些辅助函数。
