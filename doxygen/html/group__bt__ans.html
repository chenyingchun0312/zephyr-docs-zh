int bt_ans_notify_new_alert ( struct bt_conn * conn,
enum bt_ans_cat category,
uint8_t num_new,
const char * text )

#include <zephyr/bluetooth/services/ans.h>

向远程设备发送新告警

如果启用了通知，新告警将被传输到远程设备。每个类别将保存对该函数的最新调用，以便通过 ANS 控制点请求立即重放。

注解
此函数使用 K_FOREVER 在互斥量上等待，以确保通知结构体的原子更新。为避免死锁，请勿在 BT RX 或系统工作队列线程中调用此函数。
参数
conn要向其发送告警的连接对象
category该通知所属的类别
num_new自上次告警以来的新告警数量
text告警的简要文本，以 null 结尾
返回
成功时为 0
失败时的负错误码
