◆ update

int(*) bt_mesh_model_pub::update(const struct bt_mesh_model *mod)

用于更新发布缓冲区的回调。

当设为 NULL 时，假定该模型不支持周期性发布。当设为非 NULL 时，将定期调用该回调，并期望它更新 bt_mesh_model_pub::msg with a valid publication message.

如果回调返回非零值，则跳过本次发布，并在下一个周期性发布间隔继续。

当 bt_mesh_model_pub::retr_update 设为 1 时，每次重传都会调用该回调。

参数
mod发布上下文所属的模型。
返回
成功时为零，否则为（负的）错误码。
