SPI 控制器节点是否配置了片选 GPIO？

SPI 总线控制器使用 "cs-gpios" 属性来配置片选 GPIO。其值是一个 phandle 数组，用于指定片选线。

设备树片段示例： 

spi1: spi@... {
        compatible = "vnd,spi";
        cs-gpios = <&gpio1 10 GPIO_ACTIVE_LOW>,
                   <&gpio2 20 GPIO_ACTIVE_LOW>;
};

spi2: spi@... {
        compatible = "vnd,spi";
};

用法示例： 

DT_SPI_HAS_CS_GPIOS(DT_NODELABEL(spi1)) // 1
DT_SPI_HAS_CS_GPIOS(DT_NODELABEL(spi2)) // 0
参数
spiSPI 总线控制器的节点标识符
返回
若 spi 具有 cs-gpios 属性则为 1，否则为 0
