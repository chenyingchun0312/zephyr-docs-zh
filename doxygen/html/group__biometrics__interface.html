◆ biometric_attribute

enum biometric_attribute

#include <zephyr/drivers/biometrics.h>

生物识别属性类型

枚举值
BIOMETRIC_ATTR_MATCH_THRESHOLD 

匹配被接受所需的最低置信度分数（范围取决于传感器）

BIOMETRIC_ATTR_ENROLLMENT_QUALITY 

注册被接受所需的最低质量分数（范围取决于传感器）

BIOMETRIC_ATTR_SECURITY_LEVEL 

安全级别（1-10），值越高误接受越少

BIOMETRIC_ATTR_TIMEOUT_MS 

默认操作超时（毫秒）

BIOMETRIC_ATTR_ANTI_SPOOF_LEVEL 

防欺骗检测灵敏度（1-10）

BIOMETRIC_ATTR_IMAGE_QUALITY 

最近捕获图像的质量分数（范围取决于传感器），只读

BIOMETRIC_ATTR_COMMON_COUNT 

所有通用生物识别属性的数量。

BIOMETRIC_ATTR_PRIV_START 

该值及更大的值由传感器特定实现定义。请参阅传感器头文件。

BIOMETRIC_ATTR_MAX 

描述生物识别属性类型的最大值。

int biometric_enroll_capture ( const struct device * dev,
k_timeout_t timeout,
struct biometric_capture_result * result )

#include <zephyr/drivers/biometrics.h>

采集注册采样

采集一个用于注册的采样。该函数会阻塞，直到采集到采样或超时。在完成注册前多次调用该函数（通常两次）以收集所有必需的采样。

参数
dev生物识别设备
timeout采样采集的超时时间
result可选指针，指向用于获取进度/质量信息的采集结果结构体。若不需要则传入 NULL。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-EINVAL未开始注册或已有足够的采样。
-ETIMEDOUT等待采样超时。

◆ biometric_match()

int biometric_match ( const struct device * dev,
enum biometric_match_mode mode,
uint16_t template_id,
k_timeout_t timeout,
struct biometric_match_result * result )

#include <zephyr/drivers/biometrics.h>

执行生物识别匹配

采集一个采样并执行匹配。该函数会阻塞，直到匹配完成或超时。对于 BIOMETRIC_MATCH_VERIFY，与 template_id 进行验证。对于 BIOMETRIC_MATCH_IDENTIFY，搜索所有模板。

参数
dev生物识别设备
mode验证或识别模式
template_id验证模式下的模板 ID（识别模式下忽略）
timeout采样采集和匹配的超时时间
result可选指针，指向用于获取详细信息的匹配结果结构体。若只需要匹配/不匹配状态则传入 NULL。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ETIMEDOUT等待采样超时。
-ENOENT未找到匹配。
