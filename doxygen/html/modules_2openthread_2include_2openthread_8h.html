◆ openthread_init()

int openthread_init ( void )

初始化 OpenThread 模块。

此函数：

  • 初始化 OpenThread 模块。
  • 创建 OpenThread 单实例。
  • 启动 shell。
  • 为协处理器用途启用 UART 和 NCP HDLC。
  • 初始化 NAT64 转换器。
  • 为 OpenThread 模块创建工作队列。
注解
此函数由 Zephyr 的网络层自动调用。若要独立初始化 OpenThread，请在应用程序初始化代码中调用此函数。
返回值
0成功时。
-EIO失败时。

◆ openthread_mutex_lock()

void openthread_mutex_lock ( void )

在访问 OpenThread API 之前锁定内部互斥量。

OpenThread API 不是线程安全的。因此，在访问任何 API 函数之前需要锁定内部互斥量，以防 OpenThread 线程抢占该 API 调用。

◆ openthread_mutex_try_lock()

int openthread_mutex_try_lock ( void )

在访问 OpenThread API 之前尝试锁定内部互斥量。

此函数行为与 openthread_mutex_lock() 类似，前提是内部互斥量未锁定。否则它不等待而直接返回负值。

◆ openthread_mutex_unlock()

void openthread_mutex_unlock ( void )

◆ openthread_run()

int openthread_run ( void )

运行 OpenThread 网络。

准备并启用 OpenThread 网络。取决于活动设置：使用已存储的网络配置、启动加入过程，或使用默认网络配置。此外，当设备为 MTD 时，它会设置 SED 模式以正确加入网络。

◆ openthread_set_nat64_receive_cb()

void openthread_set_nat64_receive_cb ( openthread_receive_cb cb,
void * context )

设置用于接收 NAT64 转换后包的附加回调。

收到来自 OpenThread NAT64 转换器的包后会调用此回调，可用于将包注入 Zephyr 网络栈。此回调为可选项。

注意
Available only when the following Kconfig option is enabled: CONFIG_OPENTHREAD_NAT64_TRANSLATOR.
参数
cb要设置的回调。
context传给回调的上下文。
