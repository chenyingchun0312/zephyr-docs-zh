视频控制 ID

自从
4.4
版本
0.0.1

视频控制 ID（CID）采用与 Linux V4L2 子系统相同的名称并处于相同的类下。这便于在 Linux 与 Zephyr 之间端到端地互操作和调试设备。

该列表与下列 Linux 内核定义保持兼容： linux/include/uapi/linux/v4l2-controls.h

#define VIDEO_CID_ANALOGUE_GAIN   (VIDEO_CID_IMAGE_SOURCE_CLASS_BASE + 3)

#include <zephyr/video/controls.h>

模拟增益控制

模拟增益是影响像素矩阵中所有颜色分量的增益。增益运算在 A/D 转换之前的模拟域中执行。

◆ VIDEO_CID_AUTO_EXPOSURE_BIAS

#define VIDEO_CID_AUTO_EXPOSURE_BIAS   (VIDEO_CID_CAMERA_CLASS_BASE + 19)

#include <zephyr/video/controls.h>

自动曝光补偿。

确定自动曝光补偿量。仅当 VIDEO_CID_EXPOSURE_AUTO 控制设为 AUTO、SHUTTER_PRIORITY 或 APERTURE_PRIORITY 时才有效。它以 EV 表示；驱动应将这些值解释为 0.001 EV 单位，其中值 1000 表示 +1 EV。

增大曝光补偿值等效于减小曝光值（EV），并会增加图像传感器处的光量。摄像头通过调整绝对曝光时间和/或光圈来执行曝光补偿。
