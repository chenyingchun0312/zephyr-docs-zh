◆ ssh_server_event_callback_t

typedef int(*) ssh_server_event_callback_t(struct ssh_server *sshd, const struct ssh_server_event *event, void *user_data)

#include <zephyr/net/ssh/server.h>

SSH 服务器事件的回调函数类型

SSH 服务器调用此回调，以向应用程序通知与客户端连接和断开连接相关的各种事件。回调接收 SSH 服务器实例指针、包含事件详细信息的事件结构，以及在服务器初始化时提供的用户数据。

参数
sshd指向正在调用该回调的 SSH 服务器实例的指针。
event指向包含所发生事件详细信息的结构的指针。
user_data指向启动服务器时提供的用户定义数据的指针，
返回
成功时为 0，非零值表示出错。

◆ ssh_server_register_transport_callback()

int ssh_server_register_transport_callback ( struct ssh_transport_conf * conf)

#include <zephyr/net/ssh/server.h>

注册用于获取与客户端连接关联的传输的回调函数。

所注册的回调会针对服务器侧的传输事件被调用。在服务器角色下只会发出以下事件类型：

  • 当客户端请求打开新通道时，发出 SSH_TRANSPORT_EVENT_CHANNEL_OPEN。
  • 当传输被拆除时，发出 SSH_TRANSPORT_EVENT_CLOSED。

回调的返回值被忽略；该回调只是观察者，无法影响传输流程。

参数
conf传输回调的配置数据。该结构在注销之前必须保持有效。
返回
成功时为 0，失败时为负的错误码。

◆ ssh_transport_get_server()

struct ssh_server * ssh_transport_get_server ( struct ssh_transport * transport)

#include <zephyr/net/ssh/server.h>

获取拥有给定传输的 SSH 服务器实例。

在已注册的传输回调内部，这很有用：该回调会针对所有服务器实例的事件全局调用，因此需要确定某个传输属于哪个服务器实例。它只能对从服务器传输回调获得的传输调用。

参数
transport要获取其所属服务器的传输。
返回
指向所属 SSH 服务器实例的指针，如果该传输为 NULL 则为 NULL。
