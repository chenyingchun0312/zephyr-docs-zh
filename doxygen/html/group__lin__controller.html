◆ lin_read()

int lin_read ( const struct device * dev,
struct lin_msg * msg,
k_timeout_t timeout )

#include <zephyr/drivers/lin.h>

开始接收数据（仅响应节点模式）

这是一个中断驱动的 API，响应节点用它发起对 LIN 消息数据的非阻塞接收。应在发生 LIN_EVT_RX_HEADER 事件时调用它，以接收相应报头的响应。

仅在已接收到报头时调用该 API。

参数
dev指向 LIN 设备结构体的指针
msg指向 LIN 消息结构体的指针
timeout等待接收完成超时
返回值
0成功时
-EPERM设备不处于响应节点模式时返回
-EFAULT未接收到报头时返回
negative失败时返回 errno 错误码

int lin_receive ( const struct device * dev,

#include <zephyr/drivers/lin.h>

接收 LIN 消息（仅命令节点模式）。

该函数以指定的 LIN 标识符建立一次异步 LIN 读事务。当设备工作于命令节点模式时：

  • 发送带指定 ID 的报头以请求数据。
  • 从响应节点读回数据。

#include <zephyr/drivers/lin.h>

启动 LIN 控制器。

该函数使 LIN 控制器进入活动状态，使其能够参与 LIN 通信，同时还会启用 LIN 收发器（若支持）。

参数
dev指向 LIN 设备结构体的指针
返回值
0If successful.
-EALREADYLIN 控制器已启动时返回。
negative失败时返回 errno 错误码。
