◆ bt_ccp_call_control_server_register_bearer()

int bt_ccp_call_control_server_register_bearer ( const struct bt_tbs_register_param * param,
struct bt_ccp_call_control_server_bearer ** bearer )

#include <zephyr/bluetooth/audio/ccp.h>

注册电话承载

这会用所提供的参数注册电话承载服务（TBS）（或通用电话承载服务（GTBS））。

根据 TBS 规范，该特性必须实例化 GTBS，因此 GTBS 必须始终先于任何 TBS 注册。同样，必须先注销所有 TBS，才能用 bt_ccp_call_control_server_unregister_bearer() 注销 GTBS。

参数
[in]param初始化该承载的参数。
[out]bearer指向已初始化承载的指针。
返回值
0成功
-EINVALparam 包含无效数据
-EALREADYparam.gtbs 为 true 且 GTBS 已注册
-EAGAINparam.gtbs 为 false 且 GTBS 尚未注册
-ENOMEMparam.gtbs 为 false 且无法再注册 TBS（参见 CONFIG_BT_TBS_BEARER_COUNT) or param.uri_schemes is larger than CONFIG_BT_CCP_CALL_CONTROL_SERVER_URI_SCHEMES_MAX_LENGTH
-ENOEXEC服务注册失败

int bt_ccp_call_control_server_unregister_bearer ( struct bt_ccp_call_control_server_bearer * bearer)

#include <zephyr/bluetooth/audio/ccp.h>

注销电话承载

这会用所提供的参数注销电话承载服务（TBS）（或通用电话承载服务（GTBS））。承载必须先由 bt_ccp_call_control_server_register_bearer() 注册后才能注销。

必须先注销所有 TBS，才能用其注销 GTBS。

参数
bearer要注销的承载。
返回值
0成功
-EINVALbearer 为 NULL
-EALREADY该承载未注册
-ENOEXEC服务注销失败
