typedef int(*) settings_load_direct_cb(const char *key, size_t len, settings_read_cb read_cb, void *cb_arg, void *param)

#include <zephyr/settings/settings.h>

用于直接加载的回调函数。由 settings_load_subtree_direct 函数使用。

参数
[in]key跳过前缀部分后的名称，即注册处理函数时使用的名称
[in]len后端中找到的数据大小。
[in]read_cb由后端提供的、用于从后端读取数据的函数。
[in,out]cb_arg由后端提供的读取函数参数。
[in,out]param传给回调函数的参数 settings_load_subtree_direct function.
返回
当返回非零值时，进一步的子树搜索将停止。

◆ settings_load_subtree_direct()

int settings_load_subtree_direct ( const char * subtree,
settings_load_direct_cb cb,
void * param )

#include <zephyr/settings/settings.h>

使用给定回调加载有限的序列化项集合。

此函数绕过 settings 模块中的正常数据流程。所有找到的设置值都会传给给定回调。

注解
此函数不调用 commit 函数。它作为阻塞函数工作，因此在此操作结束时调用何种 commit 函数由用户决定。
参数
[in]subtree要加载的子树的名称。
[in]cb指向回调函数的指针。
[in,out]param调用回调函数时要传递的参数。
返回
成功时为 0，失败时为非零。

#include <zephyr/settings/settings.h>

通过使用 get 函数读取值，将单个当前正在运行的序列化值保存到持久化存储（如果其值已变化），或者保存整个子树当前正在运行的序列化项。

参数

save_if_subtree如果该项应保存且它是一个子树，则设为 true。
save_if_single_setting如果该项应保存且它是单个设置项，则设为 true。
返回
成功时为 0，失败时为非零。
