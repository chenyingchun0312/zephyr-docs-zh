int bt_hid_device_connect ( struct bt_conn * conn,
struct bt_hid_device ** hid )

#include <zephyr/bluetooth/classic/hid_device.h>

在给定连接上发起呼出 HID 关联。

成功时，bt_hid_device 实例将存入 hid。调用方不得释放该对象。

参数
conn用于该关联的蓝牙连接。
hid成功时用于存放 HID 设备实例的指针。
返回
成功时为 0，失败时为负的 errno。

◆ bt_hid_device_create_pdu()

struct net_buf * bt_hid_device_create_pdu ( struct net_buf_pool * pool)

#include <zephyr/bluetooth/classic/hid_device.h>

分配或创建适用于 L2CAP 上的 HID 的 PDU 缓冲区。

如果 pool 为 NULL，实现可使用默认池。

注解
调用方应使用 net_buf_add_*() 将报告载荷追加到返回的缓冲区。
参数
pool用于分配的缓冲区池，或 NULL 表示使用默认连接 TX 池。
返回
新的 net_buf 实例，失败时为 NULL。

◆ bt_hid_device_disconnect()

int bt_hid_device_disconnect ( struct bt_hid_device * hid)

#include <zephyr/bluetooth/classic/hid_device.h>

断开先前已连接的 HID 关联。

断开是异步的。在 disconnected 回调被调用之前，调用方不应释放 hid 实例。

参数
hid要断开的 HID 设备实例。
返回
成功时为 0，失败时为负的 errno。

◆ bt_hid_device_get_conn()

struct bt_conn * bt_hid_device_get_conn ( struct bt_hid_device * hid)

#include <zephyr/bluetooth/classic/hid_device.h>

获取与 HID 设备关联的 ACL 连接。

适用于只接收到 HID 设备对象（例如 bt_hid_device_cb.vc_unplug）但需要获取对端标识（例如用于清除绑定信息）的回调。

参数
hidHID 设备对象。
返回
与 HID 设备关联的连接对象；如果设备未连接则为 NULL。调用方会获得该连接对象的一个新引用，使用完毕后必须用 bt_conn_unref() 释放。

◆ bt_hid_device_input_report()

int bt_hid_device_input_report ( struct bt_hid_device * hid,
struct net_buf * buf )

#include <zephyr/bluetooth/classic/hid_device.h>

向 HID 主机发送 HID 中断输入报告。

缓冲区应包含完整的报告载荷，如果描述符声明了 Report ID，还应包含 Report ID 字节（HID 规范 v1.1.2 第 3.1.2.8 节）。

HID 设备可随时向主机发送中断通道消息。

注解
必须使用 bt_hid_device_create_pdu() 分配缓冲区，以确保为 HID 和 L2CAP 报头预留足够的头部空间。
参数
hid用于发送数据的 HID 设备实例。
buf包含报告载荷的缓冲区（成功时被消耗）。
返回
成功时为 0，失败时为负的 errno。

◆ bt_hid_device_register()

int bt_hid_device_register ( const struct bt_hid_device_cb * cb)

#include <zephyr/bluetooth/classic/hid_device.h>

注册 HID 设备回调。

回调指针必须保持有效，直到调用 bt_hid_device_unregister()。如果在未注销的情况下再次注册，将以 -EALREADY 拒绝；回调不会被替换。

参数
cb要注册的回调。不得为 NULL，且必需的 bt_hid_device_cb::get_report and bt_hid_device_cb::set_report callbacks must be provided.
返回值
0成功时。
-EINVAL如果 cb 为 NULL 或缺少必需的回调。
-EALREADY如果已注册回调集。

◆ bt_hid_device_unregister()

int bt_hid_device_unregister ( void )

#include <zephyr/bluetooth/classic/hid_device.h>

注销 HID 设备回调并禁用 HID 服务。

这会清除回调并注销 L2CAP 服务端。调用方必须在调用此函数前断开任何活动的 HID 会话，否则将返回 -EBUSY 且不执行任何操作。

返回值
0成功时。
-EBUSY如果 HID 会话仍处于活动状态。
