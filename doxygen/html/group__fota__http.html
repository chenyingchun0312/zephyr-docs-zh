◆ fota_http_apply()

int fota_http_apply ( uint8_t image_index,
bool permanent )

#include <zephyr/mgmt/fota_http.h>

请求 MCUboot 在下次复位时启动已下载的映像。

次要槽中必须存有具有有效 MCUboot 头的映像，且自启动以来最近一次向其中的下载（如有）必须成功。签名仅由引导加载程序自身检查。

当需要一起更新多个映像时，应在重启前下载并应用其中每一个：MCUboot 会校验整个集合并一次性交换，因此若仅应用了集合的一部分就重启，则只会交换已标记的部分。

参数
image_index要启动的映像，只有一个映像时为 0。
permanent为 true 时映像立即被标记为已确认。为 false 时映像只启动一次以供评估，除非在下一次复位前调用 fota_http_confirm()，否则引导加载程序会回退到当前映像。回退需要支持该功能的 MCUboot 模式，例如 swap-using-move 或 swap-using-offset。
返回值
0升级已请求。
-ENODEVimage_index 不存在对应的槽。
-EBUSY下载正在进行。
-ENOEXEC次要槽中没有有效映像，或最近一次向其中的下载失败。
-errno任何 flash 或引导加载程序错误。

◆ fota_http_confirm()

int fota_http_confirm ( uint8_t image_index)

#include <zephyr/mgmt/fota_http.h>

确认运行中的映像，使引导加载程序不再回退它。

仅确认 image_index 指定的映像，因此携带第二台设备固件的布局只会确认本设备已校验的部分。对于必须一起运行的映像集合，请确认其中每个映像。

参数
image_index要确认的映像，只有一个映像时为 0。
返回值
0映像已确认。
-ENODEVimage_index 不存在对应的槽。
-errno任何 flash 或引导加载程序错误。

◆ fota_http_download()

int fota_http_download ( const struct fota_http_download_params * params)

#include <zephyr/mgmt/fota_http.h>

将固件映像下载到 MCUboot 次要槽。

阻塞直至整个映像写入完成或传输失败。下载失败会使槽保留部分写入状态，MCUboot 会拒绝该状态，且 fota_http_apply() 在后续下载成功前也会拒绝它。被 SHA-256 或降级检查拒绝的映像会被擦除。

仅存储映像。调用 fota_http_apply() 启动它。

当运行中的映像是测试映像时，次要槽保存的是 MCUboot 会回退到的映像，因此在调用 fota_http_confirm() 之前下载会被拒绝。

调用方的栈必须能容纳 HTTP 客户端，在 https 下还要容纳 TLS 握手；fota_http_download_async() 则改用库线程。

参数
params下载参数。指向的数据必须保持有效，直至调用返回。
返回值
0映像已写入且其头部有效。
-EINVAL无法解析 URL，或 URL 超出缓冲区大小。
-ENOTSUP不支持该 URL 协议。
-ENODEVimage_index 不存在对应的槽。
-EBUSY另一个下载正在进行。
-EBADMSG服务器返回了意外的状态。
-ELOOP重定向次数超过 CONFIG_FOTA_HTTP_MAX_REDIRECTS。
-ENODATA服务器发送了空正文。
-EMSGSIZE收到的字节数少于服务器通告的数量。
-ECANCELEDfota_http_cancel() 已被调用。
-EILSEQSHA-256 摘要不匹配，映像已被擦除。
-ENOEXEC写入的数据不是 MCUboot 映像。
-EPERM运行中的映像尚未确认，或该映像比运行中的映像更旧且已被擦除。
-errno任何 socket、HTTP 客户端或 flash 错误。

#include <zephyr/mgmt/fota_http.h>

在库线程中下载固件映像。

传输入队后立即返回。done_cb 会以 fota_http_download() 本应返回的结果被调用。

需要 CONFIG_FOTA_HTTP_ASYNC。

参数

返回值
0下载已入队。
-EINVALparams 或其 URL 为 NULL，或 URL 过长。
-ENOTSUP CONFIG_FOTA_HTTP_ASYNC is disabled.
-EPERM运行中的映像尚未确认。
-EBUSY另一个下载正在进行。

#include <zephyr/mgmt/fota_http.h>

注册用于认证 https 服务器的 CA 证书。

证书存储在 CONFIG_FOTA_HTTP_TLS_SEC_TAG 下。已通过 tls_credential_add() 在该标签下注册过证书的应用程序无需调用此函数。

certDER 或 PEM 编码的证书。不会被复制，因此在进行 https 下载期间必须保持有效。

返回
成功时为 0，失败时为负的 errno 码。
