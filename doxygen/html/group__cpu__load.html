详细描述

用于监视 CPU 负载的模块。

CPU 负载是 CPU 处于空闲状态之外的时间占比。有两种测量后端可用，通过 Kconfig 选择：

  • CONFIG_CPU_LOAD_BACKEND_RUNTIME_STATS 从调度器的各 CPU 运行时统计信息推导负载。它可跨架构移植，并支持多 CPU。
  • CONFIG_CPU_LOAD_BACKEND_IDLE_HOOK 使用架构空闲钩子测量负载。它开销更低，并可选择使用硬件计数器以获得更高精度（计数器路径仅支持单 CPU）。在任何产生空闲钩子的架构上可用（ CONFIG_ARCH_HAS_CPU_IDLE_HOOKS）。

无论使用哪种后端，负载都以千分比（0...1000）报告。

#include <zephyr/sys/cpu_load.h>

可选地注册一个在负载大于等于阈值时调用的回调。

参数
cb指向回调函数的指针。NULL 将取消该回调。

返回值
0- 回调已注册/已取消。
-EINVAL若阈值无效。
