◆ arch_k_cycle_get_32()

uint32_t arch_k_cycle_get_32 ( void )
inlinestatic

#include <zephyr/arch/arch_interface.h>

获取当前周期计数，单位由 CONFIG_SYS_CLOCK_HW_CYCLES_PER_SEC 指定。虽然传统上它被指定为架构 API 的一部分，但实际上几乎所有平台都将其转发到定时器驱动提供的 sys_clock_cycle_get_32() API。

参见
k_cycle_get_32()
返回
当前周期时间。它应在整个 32 位空间内单调递增，并在 0xffffffff 处回绕。精度低于 32 位的定时器硬件应合成为一个 32 位计数。

inlinestatic

#include <zephyr/arch/arch_interface.h>

与 arch_k_cycle_get_32() 相同，但返回值为 64 位。并非所有定时器硬件都有 64 位定时器，仅在设置了 CONFIG_TIMER_HAS_64BIT_CYCLE_COUNTER 时才需要实现此函数。

参见
arch_k_cycle_get_32()
返回
当前周期时间。它应在整个 64 位空间内单调递增，并在 2^64-1 处回绕。精度较低的定时器硬件通常不期望实现此 API。
