◆ i2c_nrfx_twim_exclusive_access_acquire()

int i2c_nrfx_twim_exclusive_access_acquire ( const struct device * dev,
k_timeout_t timeout )

获取对 I2C 总线控制器的独占访问。

参数
dev指向配置为控制器模式的 I2C 控制器驱动的设备结构体的指针。
timeout等待获取独占访问的超时时间。
返回值
0If successful.
-EBUSY未等待即返回。
-EAGAIN等待期超时，或底层信号量在等待期间被复位。
