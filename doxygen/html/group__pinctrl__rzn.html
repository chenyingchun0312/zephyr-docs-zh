详细描述

用于配置 Renesas RZ/N 系列引脚控制的宏

每个引脚配置由 RZN_PINMUX() 宏构建，该宏接受三个字段：

  • port —— 端口标识，取 PORT_* 之一。
  • pin —— 该端口内的引脚号。
  • func —— 备用功能编号，用于选择路由到该引脚的外设信号。它没有符号宏：func 是取自 SoC 引脚功能控制器表（硬件手册/引脚分配表中的多路复用表）的该引脚功能索引，以普通整数传入。

例如，RZN_PINMUX(PORT_16, 5, 1) 路由端口 16 引脚 5 的功能 1（在受支持的 SoC 上为 UART0 TXD）。

#include <zephyr/dt-bindings/pinctrl/renesas/pinctrl-rzn-common.h>
&pinctrl {
uart0_default: uart0_default {
group1 {
pinmux = <RZN_PINMUX(PORT_16, 5, 1)>;
};
group2 {
pinmux = <RZN_PINMUX(PORT_16, 6, 2)>;
input-enable;
};
};
};
