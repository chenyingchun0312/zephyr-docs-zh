详细描述

将应用程序数据注入管道的元素。

生产侧的应用边界。负载要么通过 mpipe_app_src_push 以复制方式传输，要么就地传输：mpipe_app_src_alloc 从该元素的池中取出一个缓冲区供应用程序填充，并 mpipe_app_src_push_buf queues it.

至少在管道处于 PAUSED 状态后再推送：管道启动时，READY 状态下排队的内容会被丢弃。流结束通过以下方式声明 mpipe_app_src_eos; alternatively MPIPE_PROP_SRC_NUM_BUFS ends the stream after a number of buffers.

MPIPE_PROP_BASE_APP_SRC_CAPS 

所产生流的能力，为 const struct mpipe_structure 指针，会被复制。它就是向下游协商时提供的能力；应用程序推送的内容必须与之匹配，该元素无法检查。在设置之前，该元素提供不约束任何内容的能力。

从该元素的池中取一个缓冲区以就地填充

该缓冲区最多可容纳 CONFIG_MPIPE_BASE_APP_SRC_BUF_SZ 字节。应用程序将负载写入缓冲区数据区，然后把缓冲区交给 mpipe_app_src_push_buf，如果改变主意则用 net_buf_unref() 释放。

参数
app_src应用程序源
size缓冲区必须容纳的负载字节数
timeout等待空闲缓冲区的时间
buf填入该缓冲区
返回值
0成功
-EINVALsize 为 0 或超出缓冲区大小
-ENOBUFS在 timeout 内没有缓冲区变为空闲
