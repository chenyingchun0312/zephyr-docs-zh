详细描述

描述支持 I2C 目标 API 的设备的结构体。

此结构体的实例被传给 i2c_target_register() 和 i2c_target_unregister() 函数，分别表示添加和移除目标设备。

除 node 之外的字段必须在将对象引用传给 i2c_target_register() 之前由实现该设备行为的模块初始化。
