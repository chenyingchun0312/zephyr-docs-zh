void k_mem_page_in ( void * addr,
size_t size )

#include <zephyr/kernel/mm/demand_paging.h>

将虚拟数据区域载入内存

函数完成后，与该函数关联的所有页帧都将被页入。但不能保证它们会一直保留在那里。当已知该区域很快会被使用时，这很有用。

如果启用了 CONFIG_DEMAND_PAGING_ALLOW_IRQ，则不能由 ISR 调用该函数，因为后备存储可能正在使用中。

参数
addr按页对齐的基虚拟地址
size按页对齐的数据区域大小

◆ k_mem_page_out()

int k_mem_page_out ( void * addr,
size_t size )

#include <zephyr/kernel/mm/demand_paging.h>

将按页对齐的虚拟内存区域换出到后备存储

当已知某个内存区域在一段时间内不会被使用时，这很有用。指定区域内的所有数据页（若尚未换出）都将被换出到后备存储，其关联的页帧被标记为可用于映射或页入。

映射到所提供区域的关联页帧都不应被固定。

注意，无法保证这些页会被换出多久，它们可能立即再次发生缺页。

如果启用了 CONFIG_DEMAND_PAGING_ALLOW_IRQ，则不能由 ISR 调用该函数，因为后备存储可能正在使用中。

参数
addr按页对齐的基虚拟地址
size按页对齐的数据区域大小
返回值
0成功
-ENOMEM后备存储空间不足，无法满足请求。该区域可能被部分换出。

◆ k_mem_pin()

void k_mem_pin ( void * addr,
size_t size )

#include <zephyr/kernel/mm/demand_paging.h>

固定一个已对齐的虚拟数据区域，并按需页入

函数完成后，与该区域关联的所有页帧都将驻留内存并被固定，从而保持该状态。这是 z_mem_page_in() 的更强版本。

如果启用了 CONFIG_DEMAND_PAGING_ALLOW_IRQ，则不能由 ISR 调用该函数，因为后备存储可能正在使用中。

参数
addr按页对齐的基虚拟地址
size按页对齐的数据区域大小

◆ k_mem_unpin()

void k_mem_unpin ( void * addr,
size_t size )

#include <zephyr/kernel/mm/demand_paging.h>

取消固定一个已对齐的虚拟数据区域

函数完成后，与该区域关联的所有页帧将不再被标记为已固定。这不会换出该区域，若需要请随后调用 z_mem_page_out()。

参数
addr按页对齐的基虚拟地址
size按页对齐的数据区域大小
