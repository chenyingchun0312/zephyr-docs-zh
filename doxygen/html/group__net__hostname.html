设置设备主机名后缀

将主机名后缀转换为十六进制值，并用转换后的值设置设备主机名。仅当设置了 CONFIG_NET_HOSTNAME_UNIQUE 时使用。

参数
hostname_postfix通常是链路地址。该函数会将其转换为十六进制字符串。
postfix_lenhostname_postfix 数组的长度。
返回
正常时为 0，出错时为负值

◆ net_hostname_set_postfix_str()

int net_hostname_set_postfix_str ( const uint8_t * hostname_postfix,
int postfix_len )
inlinestatic

#include <zephyr/net/hostname.h>

设置网络主机名的后缀字符串。

按原样设置网络主机名的后缀字符串，不做任何转换。仅当设置了 CONFIG_NET_HOSTNAME_UNIQUE 时使用。该函数会检查默认主机名（由 CONFIG_NET_HOSTNAME 定义）与后缀的组合长度是否超过 NET_HOSTNAME_MAX_LEN。若后缀过长，函数返回错误。

参数
hostname_postfix指向要追加到网络主机名的后缀字符串的指针。
postfix_lenhostname_postfix 数组的长度。
返回
正常时为 0，出错时为负值
