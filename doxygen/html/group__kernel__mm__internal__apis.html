永久虚拟映射相对于物理地址的地址偏移量。

这是从内核 RAM 永久映射中的虚拟地址中减去以得到其物理地址的偏移量。 

virt_addr = phys_addr + K_MEM_VIRT_OFFSET

这仅对区间 [CONFIG_KERNEL_VM_BASE, CONFIG_KERNEL_VM_BASE + DT_CHOSEN_SRAM_ADDR) 内的虚拟地址有效。

这些宏用于汇编、链接器代码和静态初始化。请谨慎使用。

注意，当按需分页处于活动状态时，这些宏仅适用于在启动时固定到其虚拟映射的页帧。

◆ k_mem_map_phys_bare()

void k_mem_map_phys_bare ( uint8_t ** virt_ptr,
uintptr_t phys,
size_t size,
uint32_t flags )

#include <zephyr/kernel/internal/mm.h>

将物理内存区域映射到内核的虚拟地址空间

该函数用于将内存映射 I/O 区域映射到虚拟地址空间。给定物理地址和大小，返回一个线性地址，表示该物理区域在 Zephyr 内核虚拟地址空间中映射的基址。

通过该函数映射的内存必须使用 k_mem_unmap_phys_bare() 取消映射。

该函数会修改内核保留区域中的活动页表。该函数将选择虚拟地址并将其返回给调用者。

可移植代码绝不应假定 phys_addr 与 linear_addr 相等。

缓存和访问属性由 'flags' 参数控制。'flags' 中未使用的位保留供将来扩展。必须选择一种缓存模式。默认情况下，该区域为只读，禁止用户访问和代码执行。通过向 'flags' 参数传入 K_MEM_CACHE_* 和 K_MEM_PERM_* 宏可改变该策略。

如果没有足够的虚拟地址空间用于映射，将产生内核 panic。

此 API 仅在启用 CONFIG_MMU 时可用。

强烈不建议使用该函数映射系统 RAM 页帧。它可能与匿名内存映射和按需分页冲突，并产生未定义行为。除非你完全清楚自己在做什么，否则不要将其用于 RAM。如果需要一块内存，请使用 k_mem_map()。如果需要物理内存的连续缓冲区，请静态声明它并在构建时固定，系统启动时它将被映射。

此 API 属于仍在开发中的基础设施，可能会发生变化。

参数
[out]virt_ptr输出虚拟地址的存储位置
[in]phys内存区域的物理基址
[in]size内存区域的大小
[in]flags缓存模式和访问标志，参见 K_MAP_* 宏

◆ k_mem_map_phys_guard()

void * k_mem_map_phys_guard ( uintptr_t phys,
size_t size,
uint32_t flags,
bool is_anon )

#include <zephyr/kernel/internal/mm.h>

带保护页地将内存映射到虚拟地址空间。

这将内存映射到虚拟地址空间，并在其前后各带一个保护页。通过该函数映射的内存必须使用 k_mem_unmap_phys_guard() 取消映射。

该函数将连续的物理内存区域映射到内核的虚拟地址空间，并在其前后各带一个保护页。给定物理地址和大小，返回一个线性地址，表示该物理区域在 Zephyr 内核虚拟地址空间中映射的基址。

该函数会修改内核保留区域中的活动页表。该函数将选择虚拟地址并将其返回给调用者。

如果需要以任何方式管理用户线程访问控制，请不要在此处启用 K_MEM_PERM_USER 标志；而应在建立映射后使用内存域 API 管理该区域的权限。在此处设置 K_MEM_PERM_USER 会允许所有用户线程访问此内存，这通常不可取。

除非使用 K_MEM_MAP_UNINIT，否则返回的内存将被清零。

返回的虚拟内存指针将按页对齐。size 参数以及用于重映射的任何基地址都必须按页对齐。

请注意，分配范围包括紧邻所请求区域之前和之后的两个保护页。分配的总大小将是所请求的大小加上这两个保护页的大小。

许多 K_MEM_MAP_* 标志已被实现用于改变此函数的行为，详情见这些标志的文档。

参见
如果通过该函数调用，请参阅 k_mem_map() 以获取附加信息。
参数
phys若不请求匿名内存，则为内存区域的物理基址。必须按页对齐。
size内存映射的大小。必须按页对齐。
flagsK_MEM_PERM_*、K_MEM_MAP_* 控制标志。
is_anon如果请求以匿名内存进行映射则为 true。
返回
映射的内存位置；如果虚拟地址空间不足、物理内存不足以建立映射，或分页结构内存不足，则为 NULL。

◆ k_mem_unmap_phys_bare()

void k_mem_unmap_phys_bare ( uint8_t * virt,
size_t size )

#include <zephyr/kernel/internal/mm.h>

从内核的虚拟地址空间取消映射虚拟内存区域。

该函数供驱动和早期启动例程在需要建立临时内存映射时使用。这样这些内存映射在不再需要时就可以被丢弃。

该函数会修改内核保留区域中的活动页表。

这会将输入参数对齐到页边界，以便可与 k_mem_map_phys_bare() 返回的虚拟地址一起使用。

此 API 仅在启用 CONFIG_MMU 时可用。

强烈不建议使用该函数取消内存映射。它可能与匿名内存映射和按需分页冲突，并产生未定义行为。除非你完全清楚自己在做什么，否则不要使用它。

此 API 属于仍在开发中的基础设施，可能会发生变化。

参数
virt要取消映射的虚拟地址区域的起始地址。
size虚拟地址区域的大小
