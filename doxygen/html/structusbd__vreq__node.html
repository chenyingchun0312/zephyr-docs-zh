USBD 厂商请求节点

厂商请求节点由厂商代码标识，用于注册回调以处理接收设备收到的厂商请求。当设备栈收到类型为 Vendor、接收者为 Device 且 bRequest 值等于厂商请求代码的请求时，会根据请求方向调用厂商回调。

示例回调代码片段：

static struct net_buf *foo_to_host_cb(const struct usbd_context *const ctx,
const struct usb_setup_packet *const setup)
{
if (setup->wIndex == WEBUSB_REQ_GET_URL) {
struct net_buf *buf;
uint16_t len;
uint8_t index = USB_GET_DESCRIPTOR_INDEX(setup->wValue);
if (index != SAMPLE_WEBUSB_LANDING_PAGE) {
return NULL;
}
len = MIN(setup->wLength, sizeof(webusb_origin_url));
buf = usbd_ep_ctrl_data_in_alloc(ctx, len);
if (buf == NULL) {
return NULL;
}
net_buf_add_mem(buf, &webusb_origin_url, len);
return buf;
}
return NULL;
}

主机到设备方向的厂商请求回调

对于带 Data OUT 阶段（wLength != 0）的请求，在接收 Data OUT 阶段之前会先以 NULL buf 调用回调，以检查是否应接收数据；收到数据后会再次以非 NULL buf 调用该回调。

对于没有 Data 阶段的请求（wLength == 0），回调仅以 NULL buf 调用一次。
