◆ sdio_enable_func()

int sdio_enable_func ( struct sdio_func * func)

启用 SDIO 功能

启用 SDIO 卡功能。必须先调用 sdio_init_func 初始化功能结构体，然后才能在卡中启用它。

参数
func要启用的功能
返回值
0功能启用成功
-ETIMEDOUT卡 I/O 超时
-EIOI/O 错误

◆ sdio_init_func()

int sdio_init_func ( struct sd_card * card,
struct sdio_func * func,
enum sdio_func_num num )

初始化 SDIO 功能。

初始化 SDIO 卡功能。该卡功能不会被启用，但此调用返回后，可使用该 SDIO 功能结构体从卡中读写数据。

参数
func要初始化的功能结构体
card要在其上启用功能的 SD 卡
num要初始化的功能编号
返回值
0功能初始化成功
-EIOI/O 错误
