typedef int(*) spi_emul_io_t(const struct emul *target, const struct spi_config *config, const struct spi_buf_set *tx_bufs, const struct spi_buf_set *rx_bufs)

#include <zephyr/drivers/spi_emul.h>

将 SPI 消息传递给仿真器。仿真器用读回的数据更新数据。

参数
target设备仿真器实例
config指向有效 spi_config 结构体实例的指针。可通过指针比较来检测与之前操作的变化。
tx_bufs待发送数据的来源缓冲区数组，如果没有则为 NULL。
rx_bufs待读取数据写入的目标缓冲区数组，如果没有则为 NULL。
返回值
0If successful.
-EIO通用输入/输出错误。
