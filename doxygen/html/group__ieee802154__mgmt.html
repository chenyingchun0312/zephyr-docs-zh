命令宏

IEEE 802.15.4 网络管理命令。

应用程序可通过 网络管理 宏调用这些 IEEE 802.15.4 子系统网络管理命令。

除非另有说明，所有属性和参数均以 CPU 字节序（标量）或大端序（字节数组）给出。

此枚举中引用了以下 IEEE 802.15.4 MAC 管理服务原语：

  • MLME-ASSOCIATE.request，参见第 8.2.3 节
  • MLME-DISASSOCIATE.request，参见第 8.2.4 节
  • MLME-SET/GET.request，参见第 8.2.6 节
  • MLME-SCAN.request，参见第 8.2.11 节

此枚举中引用了以下 IEEE 802.15.4 MAC 数据服务原语：

  • MLME-DATA.request，参见第 8.3.2 节

MAC PIB 属性（mac.../sec...）：参见第 8.4.3 和 9.5 节。PHY PIB 属性（phy...）：参见第 11.3 节。两者均通过 MLME-SET/GET 原语访问。

事件宏

应用程序可通过 net_mgmt_init_event_callback、 net_mgmt_add_event_callback 和 net_mgmt_del_event_callback 订阅这些 IEEE 802.15.4 子系统网络管理事件。

#define NET_EVENT_IEEE802154_SCAN_RESULT   (NET_IEEE802154_EVENT | NET_EVENT_IEEE802154_CMD_SCAN_RESULT)
 指示 NET_REQUEST_IEEE802154_ACTIVE_SCAN 或 NET_REQUEST_IEEE802154_PASSIVE_SCAN 网络管理命令的结果。

IEEE 802.15.4 网络管理库提供应用程序可直接使用的运行时配置功能。

这些命令大多也可通过 shell 命令访问。参见 shell 的帮助功能（shell> IEEE 802.15.4 与 Thread API help）。

注解
所有章节、表格和插图引用均指 IEEE 802.15.4-2020 标准。
