◆ syscon_update_bits()

int syscon_update_bits ( const struct device * dev,
uint32_t reg,
uint32_t mask,
uint32_t val )

#include <zephyr/drivers/syscon.h>

以原子方式更新 syscon 寄存器中的位

在驱动程序内部锁的保护下对寄存器执行读-改-写。由 mask 选中的位会被清除，并替换为 val 中对应的位。等价于： 

syscon_read_reg(dev, reg, &tmp);
tmp = (tmp & ~mask) | (val & mask);
syscon_write_reg(dev, reg, tmp);

但该操作相对于同一设备上的其他 syscon 操作是原子执行的。

参数
devsyscon 设备。
reg寄存器偏移量。
mask要修改的位的位掩码。
val由 mask 选中的位的新值。
返回值
0成功时。
-ENOSYS如果 API 或功能未实现。
