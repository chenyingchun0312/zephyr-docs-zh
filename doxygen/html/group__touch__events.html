从 display phandle 中选择输出尺寸，否则使用节点自身的属性。

优先使用 display phandle 所引用节点的宽度/高度；当未设置 display 时，回退到节点自身的 output-width / output-height；两者都不存在时回退到 0，即禁用缩放。

参数
node_id设备树节点标识符。
dim显示控制器的尺寸属性（宽度或高度）。
prop触摸屏的回退属性（output_width 或 output_height）。
