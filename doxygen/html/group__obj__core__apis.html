◆ k_obj_core_link()

void k_obj_core_link ( struct k_obj_core * obj_core)

#include <zephyr/kernel/obj_core.h>

将内核对象注册到其对象类型

可以选择注册内核对象，使其能被 k_obj_type_walk_locked() 和 k_obj_type_walk_unlocked() 报告。它必须先用 k_obj_core_init() 初始化。注册已注册的对象，或注册属于其类型永久范围的对象，不会产生任何效果。位于当前线程栈或中断栈中的对象不会被注册，且该类型的 skipped 计数会递增。注册表不在对象内部保存引用，因此对象可以在不注销的情况下被丢弃；当存储被重用或注册表已满时，过期条目会被丢弃。当注册表已满时，对象不会被注册，且该类型的 dropped 计数会递增。

参数
obj_core指向内核对象的指针

◆ k_obj_type_walk_locked()

int k_obj_type_walk_locked ( struct k_obj_type * type,
int(* func )(struct k_obj_core *obj_core, void *data),
void * data )

#include <zephyr/kernel/obj_core.h>

遍历对象类型的对象核心

此函数对对象类型的每个对象核心调用回调：先是该类型的永久对象，然后是运行时注册的对象。它获取注册表自旋锁读取每个条目，并在调用回调前释放锁，因此回调可以使用任何内核或对象核心函数。存储已被重用的已注册对象将从注册表中移除，而不是被报告。

回调函数应返回非零以停止继续遍历，或返回 0 以继续遍历。

参数
type指向对象类型的指针
func要对对象类型的每个对象核心调用的回调
data传递给回调的自定义数据
返回值
non-zero如果遍历被回调终止；否则为 0

遍历对象类型的对象核心

此函数与 k_obj_type_walk_locked() 类似，区别在于它读取注册表时不获取自旋锁，因此可用于无法加锁的场合。遍历期间注册或注销的对象可能被报告也可能不被报告，存储已被重用的已注册对象会被跳过而不是移除。

回调函数应返回非零以停止继续遍历，或返回 0 以继续遍历。

参数
type指向对象类型的指针
func要对对象类型的每个对象核心调用的回调
data传递给回调的自定义数据
返回值
non-zero如果遍历被回调终止；否则为 0
