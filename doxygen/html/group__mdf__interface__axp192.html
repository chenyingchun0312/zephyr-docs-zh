详细描述

AXP192 的引脚支持多种不同功能。mfd 接口提供 API 来配置和控制这些不同功能。

这 6 个 GPIO 的映射如下：[0]：GPIO0 [1]：GPIO1 [2]：GPIO2 [3]：GPIO3 [4]：GPIO4 [5]：EXTEN

int mfd_axp192_gpio_func_ctrl ( const struct device * dev,
const struct device * client_dev,

#include <zephyr/drivers/mfd/axp192.h>

请求将某个 GPIO 引脚配置为特定功能。AXP192 的 GPIO0..5 具有多种功能（详见 axp192_gpio_func）。一个 GPIO 只能由一个驱动实例使用。对同一 GPIO 的后续调用将覆盖相应功能。

参数
devaxp192 mfd 设备
client_dev使用该 gpio 的客户端设备
gpio要配置的 GPIO（0..5）
func要配置的功能（详见 axp192_gpio_func）
返回
成功时为 0，失败时为负的 errno 值。
返回值
-EINVAL传入了无效的 GPIO 编号。
-ENOTSUP给定 GPIO 不支持所请求的功能。

在指定 GPIO 引脚上启用下拉。AXP192 仅在 GPIO3..5 上支持下拉。不支持上拉。

参数
devaxp192 mfd 设备
gpio要控制下拉的 GPIO
enable为 true 时启用下拉，为 false 时禁用
返回
成功时为 0，失败时为负的 errno 值。
返回值
-EINVAL给出了无效参数（例如无效的 GPIO 编号）。
-ENOTSUP给定 GPIO 不支持下拉。
