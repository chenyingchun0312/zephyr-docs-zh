◆ anonymous enum

anonymous enum

#include <zephyr/net/quic.h>

用于在 ZSOCK_SOL_QUIC 级别调用 getsockopt/setsockopt 的 QUIC 套接字选项

枚举值
ZSOCK_QUIC_SO_STREAM_TYPE 

获取流类型（返回 direction | initiator 位的组合）

ZSOCK_QUIC_SO_CERT_CHAIN_ADD 

向证书链添加一个中间证书。选项值是指向 sec_tag_t 的指针，该 sec_tag_t 引用先前通过 tls_credential_add()（类型为 TLS_CREDENTIAL_CA_CERTIFICATE 或 TLS_CREDENTIAL_PUBLIC_CERTIFICATE）注册的凭据。选项长度必须是 sizeof(sec_tag_t)。可多次调用以添加多个中间证书。

ZSOCK_QUIC_SO_CERT_CHAIN_DEL 

从证书链中删除一个中间证书。选项值是指向 sec_tag_t 的指针，该 sec_tag_t 引用先前通过 ZSOCK_QUIC_SO_CERT_CHAIN_ADD 选项添加的凭据。选项长度必须是 sizeof(sec_tag_t) 或设为 0。若设为 0，可将选项值设为 NULL 以省略。若设为 0，则移除所有中间证书。

ZSOCK_QUIC_SO_STOP_SENDING_CODE 

设置流关闭时发送 STOP_SENDING 帧所用的错误码

ZSOCK_QUIC_SO_SESSION_STATE 

导出或导入可恢复的客户端会话状态。

选项值是指向 struct quic_session_state 的指针。在收到 NewSessionTicket 后，对已连接的客户端连接套接字调用 getsockopt()，然后在打开第一个流之前，把返回的状态传给新的客户端连接套接字的 setsockopt()，以尝试恢复会话，并在允许时使用 0-RTT。由于 0-RTT 数据可能被重放或被对端拒绝，应用程序只能发送可安全重放的早期数据，并应准备好在握手完成后重试。禁用 CONFIG_QUIC_0RTT 时，导入的会话状态仍可以 1-RTT 恢复，但不会启用早期数据。

ZSOCK_QUIC_SO_SESSION_TICKET_ENABLE 

启用或禁用服务器端的会话票据签发。

选项值是指向 int 的指针。在握手之前，在监听套接字或服务器端连接套接字上设置非零值，使服务器在握手完成后发送 NewSessionTicket。

ZSOCK_QUIC_SO_MAX_EARLY_DATA_SIZE 

为此服务器签发的票据启用 0-RTT 早期数据。

选项值是指向 uint32_t 的指针。在握手之前，在监听套接字或服务器端连接套接字上设置它。值为 0 表示新签发的票据保持禁用 0-RTT；任何非零值则启用。依据 RFC 9001, section-4.6.1，票据始终通告固定的 0xffffffff 哨兵值，恢复会话的客户端可发送的早期数据量受连接的流控（传输参数）限制约束，而不是由该值决定；因此该选项只是一个启用开关，不是字节上限。这仅影响新签发的票据；应用程序仍须在协议层面把已接受的早期数据视为可重放。非零值需要 CONFIG_QUIC_0RTT；否则 setsockopt() 将以 ENOTSUP 失败。

ZSOCK_QUIC_SO_STREAM_EARLY_DATA 

查询 QUIC 流是否已收到被接受的 0-RTT 数据。

选项值是指向 int 的指针，仅在 QUIC 流套接字上有效。结果非零表示该流的接收侧在此连接上已承载过被接受的早期数据。

const struct net_sockaddr * local_addr )

#include <zephyr/net/quic.h>

创建一个新的 QUIC 连接套接字。

创建一个新的 QUIC 连接上下文。它作为后续所有通信的基础。

参数
remote_addr远端连接端点地址。在客户端模式下，这是要连接的服务器地址。在服务器模式下，若绑定监听器，则为 NULL 或未指定。
local_addr本地连接端点地址。在客户端模式下，若设为 NULL，系统将自动把套接字绑定到临时端口并选择本地地址。在服务器模式下，这是要监听的地址。
返回
成功时返回新的 QUIC 连接套接字，失败时 <0。

◆ quic_stream_open()

int quic_stream_open ( int connection_sock,
enum quic_stream_initiator initiator,
enum quic_stream_direction direction,
uint8_t priority )

#include <zephyr/net/quic.h>

在已建立的 QUIC 连接中创建一个新的 QUIC 流套接字。

参数
connection_sock要在其上创建流的连接。这是 quic_connection_open() 返回的套接字 id。
initiator流的发起方（客户端或服务器）。取值为 QUIC_STREAM_CLIENT 或 QUIC_STREAM_SERVER。
direction流的方向（单向或双向）。若设为 QUIC_STREAM_BIDIRECTIONAL，则双方都可读写。若设为 QUIC_STREAM_UNIDIRECTIONAL，则只有发起方可写。
priority用于调度流数据的优先级（0-255）。
返回
成功时返回新的 QUIC 流套接字，失败时 <0。
