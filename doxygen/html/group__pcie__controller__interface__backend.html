◆ pcie_ctrl_region_allocate_t

typedef bool(*) pcie_ctrl_region_allocate_t(const struct device *dev, pcie_bdf_t bdf, bool mem, bool mem64, size_t bar_size, uintptr_t *bar_bus_addr)

#include <zephyr/drivers/pcie/controller.h>

用于为端点基址寄存器分配内存区域子集的函数。

枚举 PCIe 端点时，Type0 端点可能通过 I/O 或内存类型的基址寄存器需要最多 6 个内存区域。

如果这样的区域可用且仍有空间，该调用会在 PCI Express 控制器的内存区域中分配此类区域。

参数
devPCI Express 控制器设备指针
bdfPCI(e) 端点
mem如果该 BAR 为内存类型则为 true
mem64如果该 BAR 为 64 位内存类型则为 true
bar_size硬件返回的基址寄存器大小（字节）
bar_bus_addr要写入 BAR 寄存器的总线视角地址
返回
可以分配时为 true，分配失败时为 False

◆ pcie_ctrl_region_translate_t

typedef bool(*) pcie_ctrl_region_translate_t(const struct device *dev, pcie_bdf_t bdf, bool mem, bool mem64, uintptr_t bar_bus_addr, uintptr_t *bar_addr)

#include <zephyr/drivers/pcie/controller.h>

用于将端点基址寄存器的总线视角地址转换为物理地址的函数。

枚举 PCIe 端点时，Type0 端点可能通过 I/O 或内存类型的基址寄存器需要最多 6 个内存区域。

写入该 BAR 寄存器的总线视角地址不一定能由 CPU 访问，因此必须使用 PCI Express 控制器的内存区域转换范围进行转换，以便从 CPU 映射。

参数
devPCI Express 控制器设备指针
bdfPCI(e) 端点
mem如果该 BAR 为内存类型则为 true
mem64如果该 BAR 为 64 位内存类型则为 true
bar_bus_addr写入 BAR 寄存器的总线视角地址
bar_addr由总线视角地址转换得到的 CPU 视角地址
返回
转换成功时为 true，转换失败时为 False

启动 PCIe 端点枚举。

从某个总线号开始 PCIe 端点枚举。在非 x86 架构上，或固件未建立 PCIe 总线层级时，必须枚举 PCIe 总线复合体以设置端点的基址寄存器。
