◆ init

int(*const) bt_mesh_model_cb::init(const struct bt_mesh_model *model)

模型初始化回调。

在 Mesh 初始化期间对每个模型实例调用。

如果有任一模型初始化回调返回错误，则 Mesh 子系统初始化将中止，并将该错误返回给 bt_mesh_init 的调用方。

参数
model要初始化的模型。
返回
成功时返回 0，否则返回错误。

◆ pending_store

void(*const) bt_mesh_model_cb::pending_store(const struct bt_mesh_model *model)

用于存储模型待处理用户数据的回调。

由 bt_mesh_model_data_store_schedule 触发。

要存储用户数据，请调用 bt_mesh_model_data_store。

参数
model此回调所属的模型。

◆ reset

void(*const) bt_mesh_model_cb::reset(const struct bt_mesh_model *model)

模型重置回调。

在 Mesh 节点被重置时调用。重置时所有模型数据都会被删除，模型应清除其状态。

注解
如果模型存储了任何持久数据，需要手动擦除。
参数
model此回调所属的模型。

◆ start

int(*const) bt_mesh_model_cb::start(const struct bt_mesh_model *model)

Mesh 启动时调用的回调。

此处理函数在节点完成配网后，或从持久存储加载完所有 Mesh 数据后被调用。

当此回调触发时，Mesh 模型可以开始其行为，并且所有访问 API 都已就绪可用。

参数
model此回调所属的模型。
返回
成功时返回 0，否则返回错误。
