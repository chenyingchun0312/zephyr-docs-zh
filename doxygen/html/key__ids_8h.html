详细描述

此文件定义 PSA Crypto API 现有使用者的密钥 ID 范围。

除应用程序之外，不同子系统也会通过 PSA Crypto API 存储和使用持久化密钥。由于彼此并不了解，它们通过使用不同的 ID 范围来避免冲突。此文件充当 Zephyr 内所有已分配 PSA 密钥 ID 范围的登记表。

最终用户应用程序也有专用范围 ZEPHYR_PSA_APPLICATION_KEY_ID_RANGE_BEGIN。

下面的一些 ID 基于此前已存在并使用的值，而另一些则选择位于 PSA 用户密钥 ID 范围内的某个位置，以尽量避免冲突（例如避免使用该范围的最开头部分）。
