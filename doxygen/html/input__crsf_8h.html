详细描述

Crossfire（CRSF）协议定义与辅助工具

此模块提供常量、包类型定义、遥测负载结构体以及用于处理 RC 发射机和接收机所用 CRSF（Crossfire）协议的辅助 API。

它涵盖帧布局、遥测负载格式、RC 通道转换以及链路统计信息访问。

◆ input_crsf_send_telemetry()

int input_crsf_send_telemetry ( const struct device * dev,
uint8_t type,
uint8_t * payload,
size_t payload_len )

发送通用的 CRSF 遥测帧。

该帧会被复制并异步发送；此函数不等待传输完成。

参数
dev指向 CRSF 输入设备的指针
type包类型（参见 crsf_packet_type）
payload指向负载缓冲区的指针
payload_len负载长度，以字节为单位
返回值
0该帧已入队等待发送。
-EINVAL负载过大，或为 NULL 但长度非零。
-EBUSY上一帧仍在发送中。
<0uart_tx() 返回的其他负 errno。
