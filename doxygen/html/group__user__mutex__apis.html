初始化互斥量。

此例程在首次使用前初始化互斥量对象。

完成后，互斥量可用且没有所有者。

仅当用户空间被禁用且该互斥量不是用 SYS_MUTEX_DEFINE() 创建时，才需要调用此例程。

◆ sys_mutex_lock()

int sys_mutex_lock ( struct sys_mutex * mutex,
k_timeout_t timeout )
inlinestatic

#include <zephyr/sys/mutex.h>

锁定互斥量。

此例程锁定 mutex。如果该互斥量已被其他线程锁定，调用线程将等待，直到互斥量可用或发生超时。

允许线程锁定它已经锁定的互斥量。该操作立即完成，锁定计数加 1。

参数
mutex互斥量的地址，该地址可位于用户内存中
timeout锁定互斥量的等待时间，或特殊值 K_NO_WAIT 和 K_FOREVER 之一。
返回值
0已锁定互斥量。
-EBUSY未等待即返回。
-EAGAIN等待时间超时。
-EACCES调用方无权访问所提供的互斥量地址
-EINVAL所提供的互斥量未被内核识别

◆ sys_mutex_unlock()

int sys_mutex_unlock ( struct sys_mutex * mutex)
inlinestatic

#include <zephyr/sys/mutex.h>

解锁互斥量。

此例程解锁 mutex。该互斥量必须已由调用线程锁定。

在调用线程按其先前锁定的次数解锁该互斥量之前，其他线程无法获取该互斥量。

参数
mutex互斥量的地址，该地址可位于用户内存中
返回值
0互斥量已解锁
-EACCES调用方无权访问所提供的互斥量地址
-EINVAL所提供的互斥量未被内核识别，或该互斥量未处于锁定状态
-EPERM调用方不拥有该互斥量
