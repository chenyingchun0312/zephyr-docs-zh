◆ keep_section_info

bool llext_load_param::keep_section_info

在加载扩展后将 ELF 段数据保留在内存中。使用 ELF 检查 API 中的某些函数时需要这样做。

注解
相关内存必须由 llext_free_inspection_data 释放，之后才能通过 llext_unload 卸载扩展。

◆ pre_located

bool llext_load_param::pre_located

计算重定位目标时使用 ELF 中的虚拟符号地址，而不是内存缓冲区内的地址。这也意味着应用程序会负责将扩展放置在这些预定义的地址处，因此 LLEXT 核心不必在内部进行任何分配和复制。任何 MMU 权限调整也将由应用程序完成。
