声明运行时生成的参数集。

gen_cb_ is called once per invocation with the 0-based iteration index and a pointer to an aligned scratch buffer; it must write exactly sizeof(type_) bytes into that buffer. The callback may read any runtime state — random numbers, hardware registers, computed values, etc.

值从不存储在数组中；无论类型大小如何，count_ 次迭代都不会带来额外的 RAM 开销。

对于需要一次性初始化的生成器（例如为 PRNG 播种），请改用 ZTEST_DEFINE_PARAM_GENERATOR_WITH_SETUP()。

约束（在编译时检查）：sizeof(type_) 不得超过 16 字节。

定义在每个单元测试之前/之后运行的测试规则。

此处定义的函数会在每个测试套件的每个单元测试之前/之后运行。除回调外，测试函数还会收到指向正在运行的测试的指针和数据。这为测试提供了根据具体测试或数据执行自定义操作的机制（例如日志记录可以使用测试名称）。

顺序：

  • 测试规则的 before 函数先于套件的 before 函数运行。这样可让测试套件的定制优先于适用于所有套件的规则。
  • 测试规则的 after 函数不保证以任何特定顺序运行。
参数
name测试规则的名称（在编译单元内必须唯一）
before_each_fn每个测试之前要调用的回调函数（ztest_rule_cb）（可为 NULL）
after_each_fn每个测试之后要调用的回调函数（ztest_rule_cb）（可为 NULL）
