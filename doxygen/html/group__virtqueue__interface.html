◆ virtq_add_buffer_chain()

int virtq_add_buffer_chain ( struct virtq * v,
struct virtq_buf * bufs,
uint16_t bufs_size,
uint16_t device_readable_count,
virtq_receive_callback cb,
void * cb_opaque,
k_timeout_t timeout )

#include <zephyr/drivers/virtio/virtqueue.h>

将缓冲区链添加到 virtqueue

注意，根据规范 2.7.13.3，一旦 avail->idx 被递增，设备就可能访问这些缓冲区；该递增在本函数末尾完成，因此设备可能在未被 virtio_notify_virtqueue 通知的情况下访问缓冲区

参数
v其操作的 virtqueue
bufs要添加到 virtqueue 的缓冲区数组
bufs_size缓冲区数量
device_readable_count设备可读的缓冲区数量，前 device_readable_count 个缓冲区将被设为设备可读
cb设备归还缓冲区链后要调用的回调，可为 NULL
cb_opaque将传给该回调的不透明值
timeout等待空闲描述符的时间；使用 K_NO_WAIT 时可在 ISR 中调用
返回
成功时为 0，失败时为错误码
