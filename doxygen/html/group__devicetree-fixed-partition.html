获取固定分区的绝对地址

设备树片段示例： 

&flash_controller {
        flash@1000000 {
                compatible = "soc-nv-flash";
                partitions {
                        compatible = "fixed-partitions";
                        storage_partition: partition@3a000 {
                                label = "storage";
                        };
                };
        };
};

此处 "storage" 分区被认为属于起始地址为 0x1000000 的 Flash 存储器。该分区的单元地址 0x3a000 表示该 Flash 存储器内部的偏移。

用法示例： 

DT_FIXED_PARTITION_ADDR(DT_NODELABEL(storage_partition)) // 0x103a000

此宏只能用于 CPU 可寻址的内部存储器分区。否则可能产生编译时错误，例如：'__REG_IDX_0_VAL_ADDRESS' undeclared。

参数
node_idfixed-partitions 子节点的节点标识符
返回
分区的偏移加上包含它的 Flash 节点的基地址。

获取固定子分区的绝对地址

设备树片段示例： 

&flash_controller {
        flash@1000000 {
                compatible = "soc-nv-flash";

                partitions {
                        compatible = "fixed-partitions";

                        slot0_partition: partition@10000 {
                                compatible = "fixed-subpartitions";
                                reg = <0x00010000 0x40000>;
                                ranges = <0x0 0x10000 0x40000>;
                                #address-cells = <1>;
                                #size-cells = <1>;

                                storage_partition: partition@0 {
                                        label = "storage";
                                        reg = <0x00000000 0x40000>;
                                };
                        };
                };
        };
};

此处 "storage" 分区被认为属于起始地址为 0x1000000 的 Flash 存储器。该分区的单元地址 0x10000 表示该 Flash 存储器内部的偏移。

用法示例： 

DT_FIXED_SUBPARTITION_ADDR(DT_NODELABEL(storage_partition)) // 0x1010000

此宏只能用于 CPU 可寻址的内部存储器子分区。否则可能产生编译时错误，例如：'__REG_IDX_0_VAL_ADDRESS' undeclared。

参数
node_idfixed-subpartitions 子节点的节点标识符
返回
子分区的偏移加上包含它的 Flash 节点的基地址。
