详细描述

Nuvoton NuMaker 器件的外设复位单元标识符。

用于 Nuvoton NuMaker 器件外设复位单元的设备树宏，配合 nuvoton,numaker-rst 兼容的复位控制器使用。

每个 SoC 系列的头文件都定义了编码外设复位寄存器位置与位位置的标识符。该编码与系列相关；请直接使用提供的标识符，而不要手工构造复位单元值。

#include <zephyr/dt-bindings/reset/numaker_m031x_reset.h>
&uart0 {
// ...
resets = <&rst NUMAKER_UART0_RST>;
// ...
};
