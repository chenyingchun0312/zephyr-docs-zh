◆ hawkbit_autohandler_set_delay()

int hawkbit_autohandler_set_delay ( k_timeout_t timeout,
bool if_bigger )

#include <zephyr/mgmt/hawkbit/autohandler.h>

设置自动处理程序下一次运行的延迟。

此函数只会延迟自动处理程序的下一次运行。该延迟不会在自动处理程序运行后保留。

参数
timeout要设置的延迟。
if_bigger如果为 true，则仅当新延迟大于当前延迟时才设置该延迟。
返回值
0如果 if_bigger 为 true 且当前延迟大于新延迟。
otherwise,k_work_reschedule()的返回值。
