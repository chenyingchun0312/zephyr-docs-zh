◆ udc_ep_dequeue()

int udc_ep_dequeue ( const struct device * dev,
const uint8_t ep )

#include <zephyr/drivers/usb/udc.h>

从端点队列中移除所有 USB 设备控制器请求

当驱动释放已认领的缓冲区时会生成 UDC_EVT_EP_REQUEST 事件，此后不会认领新请求，队列中的所有请求将作为事件变量 buf 的链式列表传递。之后端点队列为空。

参数
[in]dev指向驱动实例 device 结构体的指针
[in]ep端点地址
返回
成功时为 0，所有其他值都应视为错误。
返回值
-ENODEV未找到端点配置
-EACCES端点未禁用
-EPERM控制器未初始化

int udc_ep_try_config ( const struct device * dev,
const uint8_t ep,
const uint8_t attributes,
uint16_t *const mps,
const uint8_t interval )

#include <zephyr/drivers/usb/udc.h>

尝试一种端点配置。

根据端点描述符尝试端点配置。此函数可能会修改端点的 wMaxPacketSize 描述符字段。描述符的所有属性（例如方向和传输类型）都应正确设置。如果 wMaxPacketSize 值为零，它将被更新为该端点的最大缓冲区大小。

参数
[in]dev指向驱动实例 device 结构体的指针
[in]ep端点地址（与 bEndpointAddress 相同）
[in]attributes端点属性（与 bmAttributes 相同）
[in]mps最大包大小（与 wMaxPacketSize 相同）
[in]interval轮询间隔（与 bInterval 相同）
返回
成功时为 0，所有其他值都应视为错误。
返回值
-EINVAL参数错误时
-ENOTSUP不支持该端点配置
-ENODEV没有可用端点
