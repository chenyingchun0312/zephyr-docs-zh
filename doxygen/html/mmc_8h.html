int mmc_ioctl ( struct sd_card * card,
uint8_t cmd,
void * buf )

从 MMC 卡获取 I/O 控制数据

向 MMC 卡发送 I/O 控制命令。

参数
cardMMC 卡
cmdI/O 控制命令。与磁盘子系统保持一致，可用命令列表参见 include/zephyr/drivers/disk.h。
bufI/O 控制缓冲区
返回值
0IOCTL 命令成功
-ENOTSUP不支持该 IOCTL 命令
-EIOI/O 失败

◆ mmc_read_blocks()

int mmc_read_blocks ( struct sd_card * card,
uint8_t * rbuf,
uint32_t start_block,
uint32_t num_blocks )

从 MMC 卡读取块到缓冲区

从 MMC 卡读取块到 MMC 缓冲区。为获得最佳性能，此缓冲区应与 CONFIG_SDHC_BUFFER_ALIGNMENT 对齐

参数
card要读取的 MMC 卡
rbuf读缓冲区
start_block要读取的第一个块
num_blocks要读取的块数量
返回值
0读取成功
-EBUSY卡正忙于另一个请求
-ETIMEDOUT卡读取超时
-EIOI/O 错误
