SMBus 协议命令 @{

SMBus 规范定义了以下 SMBus 协议操作

#define SMBUS_CMD_QUICK   0b000
 SMBus Quick 协议是一种非常简单的命令，不发送也不接收数据。外设可以只表示 R/W 位，这仍可用于外设管理，例如切换外设的开启/关闭。Quick 协议也可用于外设设备扫描。
#define SMBUS_CMD_BYTE   0b001
 SMBus Byte 协议可以发送或接收一个字节的数据。
#define SMBUS_CMD_BYTE_DATA   0b010
 SMBus Byte Data 协议先发送第一个字节（命令），随后读取或写入一个字节。
#define SMBUS_CMD_WORD_DATA   0b011
 SMBus Word Data 协议先发送第一个字节（命令），随后读取或写入两个字节。
#define SMBUS_CMD_PROC_CALL   0b100
 SMBus Process Call 协议是 Write Word 后接 Read Word。之所以这样命名，是因为该命令发送数据并等待外设返回应答。
#define SMBUS_CMD_BLOCK   0b101
 SMBus Block 协议读取或写入最多 32 字节的数据块。Count 字节指定数据量。
#define SMBUS_CMD_BLOCK_PROC   0b111
 SMBus Block Write - Block Read Process Call 协议是 Block Write 后接 Block Read。
