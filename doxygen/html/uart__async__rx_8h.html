宏定义说明

◆ UART_ASYNC_RX_BUF_OVERHEAD

#define UART_ASYNC_RX_BUF_OVERHEAD   offsetof(struct uart_async_rx_buf, buffer)

获取用于管理每个缓冲区状态的空间大小。

初始化时提供的用户缓冲区被划分为多个块，每个块都有开销。此开销可用于计算 UART 数据实际使用的空间。

返回
开销空间，单位为字节。

函数说明

◆ uart_async_rx_buf_req()

uint8_t * uart_async_rx_buf_req ( struct uart_async_rx * async_rx)

获取下一个 RX 缓冲区。

返回的指针应提供给 uart_rx_buf_rsp 或 uart_rx_enable。如果返回 null，则表示没有可用的缓冲区，因为所有缓冲区都被驱动占用或包含尚未消费的数据。

参数
async_rx指向辅助实例的指针。
返回
指向下一个 RX 缓冲区的指针；若无可用缓冲区则为 null。

◆ uart_async_rx_data_claim()

size_t uart_async_rx_data_claim ( struct uart_async_rx * async_rx,
uint8_t ** data,
size_t length )

认领已接收的数据以供处理。

辅助模块以零拷贝模式工作。它提供指向 UART 驱动直接使用的缓冲区的指针。由于接收到的数据分布在多个缓冲区中，无法一次读取全部数据，只能按块消费。数据处理完成后，使用 uart_async_rx_data_consume 指示数据已消费。

参数
async_rx指向辅助实例的指针。
data写入缓冲区地址的位置。若无数据可认领则保持不变。
length请求的数据量。
返回
data 缓冲区中有效的数据量。没有数据时返回 0。

bool uart_async_rx_data_consume ( struct uart_async_rx * async_rx,
size_t length )

消费已认领的数据。

它与 uart_async_rx_data_claim 配对使用。

参数
async_rx指向辅助实例的指针。
length要消费的数据量。它必须小于或等于已认领的数据量。
返回值

false没有空闲缓冲区。
