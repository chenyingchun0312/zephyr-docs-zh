 通道标识符。该值主要在 ADC API 内标识通道——当发起读请求时，必须将 "adc_sequence" 结构体中 "channels" 字段的对应位置位，以在采样中包含该通道。对于不允许为给定通道选择模拟输入、而是具有专用输入的硬件，该值还会选择采样中要使用的物理 ADC 输入。否则，当需要为通道显式选择模拟输入时，或当通道为差分通道而需要选择两个输入时，选择在 "input_positive" 和 "input_negative" 字段中完成。特定驱动通过是否选择名为 ADC_CONFIGURABLE_INPUTS 的特殊隐藏 Kconfig 选项来表明其支持上述两种情况中的哪一种。若未选择该选项，则宏 CONFIG_ADC_CONFIGURABLE_INPUTS 未定义，因此该结构体中不存在上述两个字段。该 API 允许 0-31 范围内的标识符，但特定驱动可能只支持有限数量的通道标识符（取决于底层硬件能力或通过专用 Kconfig 选项配置）。
