◆ k_mem_paging_eviction_accessed()

void k_mem_paging_eviction_accessed ( uintptr_t phys)

#include <zephyr/kernel/mm/demand_paging.h>

将页帧作为新近访问处理

架构相关的内存故障处理程序将调用该函数，告知换出算法所提供的物理地址属于正在被访问的页帧，这样的页帧应不太可能被视为下一个换出候选。

该函数在中断锁定的情况下被调用。

参数
[in]phys正在被访问的物理地址

◆ k_mem_paging_eviction_add()

void k_mem_paging_eviction_add ( struct k_mem_page_frame * pf)

#include <zephyr/kernel/mm/demand_paging.h>

提交页帧以进行换出候选跟踪

内核将调用该函数，告知换出算法所提供的页帧可被视为潜在的换出候选。

在内核首次调用 k_mem_paging_eviction_init() 之前，绝不会调用该函数。

该函数在中断锁定的情况下被调用。

参数
[in]pf要添加的页帧

◆ k_mem_paging_eviction_init()

void k_mem_paging_eviction_init ( void )

#include <zephyr/kernel/mm/demand_paging.h>

初始化函数

在 POST_KERNEL 阶段调用来执行换出算法所需的初始化任务。可保证在此函数返回前绝不会调用 k_mem_paging_eviction_select()，且该函数只会被调用一次。

◆ k_mem_paging_eviction_remove()

void k_mem_paging_eviction_remove ( struct k_mem_page_frame * pf)

#include <zephyr/kernel/mm/demand_paging.h>

将页帧从潜在的换出候选中移除

内核将调用该函数，告知换出算法所提供的页帧不再可被视为潜在的换出候选。

该函数只会针对先前通过 k_mem_paging_eviction_add() 提交的页帧被调用。

该函数在中断锁定的情况下被调用。

参数
[in]pf要移除的页帧

◆ k_mem_paging_eviction_select()

struct k_mem_page_frame * k_mem_paging_eviction_select ( bool * dirty)

#include <zephyr/kernel/mm/demand_paging.h>

选择一个页帧进行换出

当没有空闲页帧时，内核将调用该函数选择一个要换出的页帧。并不保证返回的页帧实际上会被换出。若被换出，内核将对其调用 k_mem_paging_eviction_remove()。

在内核首次调用 k_mem_paging_eviction_init() 之前，绝不会调用该函数。

该函数在中断锁定的情况下被调用。

参数
[out]dirty要换出的页是否为脏
返回
要换出的页帧
