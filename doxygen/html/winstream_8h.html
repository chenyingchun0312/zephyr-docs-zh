struct sys_winstream * sys_winstream_init ( void * buf,
int buflen )
inlinestatic

从一块内存区域构造 sys_winstream

此函数在任意大小的内存区域中初始化 sys_winstream，并返回所得对象（保证与缓冲区位于同一地址）。该内存必须（显然）由读取者和写入者共享，且对其的所有操作必须是一致的并按序进行。

参数
buf指向用于容纳该流的内存区域的指针
buflen缓冲区的长度，必须足够大以容纳 struct sys_winstream 和至少一个字节的数据。
返回
指向已初始化 sys_winstream 的指针（与 buf 参数地址相同）。

从 sys_winstream 读取字节

此函数将从 sys_winstream 读取字节到指定缓冲区。它总是在恒定时间内返回，不会阻塞，也不进行除内存顺序之外的任何同步。返回读入缓冲区的字节数，但请注意，如果写入者领先于我们的上下文，可能会发生下溢。该情况可通过指针返回的序列号检测（即若 "*seq != old_seq + return_value"，则发生了下溢并且字节被丢弃）。

参数
ws要从中读取的 sys_winstream
seq指向一个整数的指针，该整数包含从流中读取的最后一个序列号，或零表示“流的起始”。它会被就地更新并返回，供后续调用和检测下溢使用。
buf用于存储所读取数据的缓冲区
buflenbuf 的长度（字节）
返回
写入缓冲区的字节数

向 sys_winstream 写入字节

此函数将指定数量的字节写入该流。它总是同步返回，不会阻塞，也不进行除内存写顺序之外的任何同步。超出缓冲区可存储量的任何字节都会被静默丢弃，但读取者可以通过序列号察觉到它们的存在。

参数
ws要写入的 sys_winstream
data指向要写入的字节的指针
len要写入的字节数
