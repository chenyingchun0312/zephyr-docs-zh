详细描述

用于周期性广播同步事件的回调结构体。

此结构体定义了在各类周期性广播同步事件中调用的回调函数，包括同步成功建立、终止、收到数据、状态变化、BIGInfo 报告以及来自周期性广播的 IQ 采样。

注解
用于 bt_le_per_adv_sync_cb_register 函数。
这些回调在线程上下文中调用，绝不会在 ISR 中调用。回调是由协议栈内部上下文调用，还是由触发它的 API 调用同步调用，以及来自哪个上下文，不属于 API 的一部分，且可能随版本变化。参见 Callback execution contexts for the hazards of blocking in a callback and their mitigations.
