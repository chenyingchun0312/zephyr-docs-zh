◆ flash_copy()

int flash_copy ( const struct device * src_dev,
off_t src_offset,
const struct device * dst_dev,
off_t dst_offset,
off_t size,
uint8_t * buf,
size_t buf_size )

#include <zephyr/drivers/flash.h>

将 Flash 存储器从一个设备复制到另一个设备。

将 Flash 存储器的一个区域从一个位置复制到另一个位置。源和目标 Flash 设备可以相同也可以不同。但是，如果源和目标设备相同、存储区域重叠且不完全一致，此函数会失败。

调用方必须提供大小合适的缓冲区，并在必要时确保目标已事先擦除。

注解
如果源和目标设备相同，且源和目标偏移也相同，此函数不做任何复制操作直接成功。
参数
src_dev源 Flash 设备。
dst_dev目标 Flash 设备。
src_offset源 Flash 设备内的偏移。
dst_offset目标 Flash 设备内的偏移。
size要复制的区域大小（字节）。
[out]buf指向大小为 buf_size 的缓冲区的指针。
buf_size由 buf 指向的缓冲区的大小。
返回值
0成功时
-EINVAL若某个参数无效。
-EIO若发生 I/O 错误。
-ENODEV若 src_dev 或 dst_dev 未就绪。

int flash_erase ( const struct device * dev,
off_t offset,
size_t size )

#include <zephyr/drivers/flash.h>

擦除 Flash 存储器的部分或全部

可接受的擦除大小和偏移受硬件特定页大小和偏移倍数的约束。请查看底层子驱动实现的 API，例如若你的 Flash 驱动支持，可使用 flash_get_page_info_by_offs()。

任何必要的擦除保护管理都由驱动的擦除实现本身执行。

该函数只应用于真正的显式擦除设备；如果代码在某些操作前依赖擦除设备（即将其置为擦除值），但又需要同时适用于显式擦除设备和 RAM 非易失设备，则应改用 flash_flatten。

参数
dev：Flash 设备
offset：擦除区域的起始偏移
size：要擦除的区域大小
返回
成功时为 0，失败时为负的 errno 错误码。
参见
flash_flatten()
flash_get_page_info_by_offs()
flash_get_page_info_by_idx()

◆ flash_ex_op()

int flash_ex_op ( const struct device * dev,
uint16_t code,
const uintptr_t in,
void * out )

#include <zephyr/drivers/flash.h>

在给定设备上执行 Flash 扩展操作

除写、擦除等标准 Flash 操作外，Flash 控制器还支持写保护、读保护等附加特性。这些特性并非每个 Flash 控制器都具备，而且各控制器实现方式可能不同。

为每个 Flash 控制器特性都添加单独的 Flash API 函数并不合理，因为它可能是独有的（仅少数 Flash 控制器支持），或者该 API 无法在每个 Flash 控制器上表示同一特性。

注意
Available only when the following Kconfig option is enabled: CONFIG_FLASH_EX_OP_ENABLED.
参数
devFlash 设备
code将在设备上执行的操作。
in指向操作所用输入数据的指针。若操作不需要输入数据，可以为 NULL。
out指向操作输出数据的指针。若操作不产生输出，可以为 NULL。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENOTSUP给定设备不支持扩展操作。
-ENOSYSKconfig 中未使能扩展操作支持。

◆ flash_flatten()

int flash_flatten ( const struct device * dev,
off_t offset,
size_t size )

#include <zephyr/drivers/flash.h>

擦除 Flash 存储器的部分或全部，或将其置平

如果设备是显式擦除类型，或设备驱动提供擦除回调，则调用该设备的回调，其行为与 flash_erase 相同。如果设备不需要显式擦除（因为它根本没有擦除，或具有自动擦除/写时擦除），且未提供擦除回调，则通过将选定设备内存区域用赋给设备的 erase_value 置平来模拟擦除。

擦除页偏移和大小是分页显式擦除设备的约束，但对没有此要求的设备可以放宽；这意味着需要用户代码自行确保其正确，因为若不满足这些约束，函数对分页设备返回 -EINVAL，但在非显式擦除设备上可能成功。对于 RAM 非易失设备，目前会模拟擦除页，以便让依赖设备分页的代码平滑过渡并正常工作；但这完全是软件层约束。

通常：如果你的代码此前要求先擦除设备才能正常工作，请将 flash_erase 调用替换为此函数；但如果你的代码可以处理非易失 RAM 型设备而无需模拟擦除，则应改为对分页擦除设备（即 Flash）使用单独的执行路径并调用 flash_erase。

参数
dev：Flash 设备
offset：擦除区域的起始偏移
size：要擦除的区域大小
返回
成功时为 0，失败时为负的 errno 错误码。
参见
flash_erase()
