◆ eth_bridge_iface_add()

int eth_bridge_iface_add ( struct net_if * br,
struct net_if * iface )

#include <zephyr/net/ethernet_bridge.h>

将以太网网络接口添加到桥

这会将网络接口添加到桥。该接口随后进入混杂模式。当桥接口上添加了不止一个以太网接口后，桥接口即完成设置。设置完成后，可以启用桥接口，使其开始桥接 L2 流量。

参数
br指向桥接口的指针
iface要添加的接口
返回
成功时为 0，否则为负的错误码。

◆ eth_bridge_iface_remove()

int eth_bridge_iface_remove ( struct net_if * br,
struct net_if * iface )

#include <zephyr/net/ethernet_bridge.h>

从桥中移除以太网网络接口。

若此函数调用后桥接口设置中仅剩一个以太网接口，则桥被禁用，因为它已无法再桥接 L2 流量。在这种情况下桥接口仍保持 UP 状态。

参数
br指向桥接口的指针
iface要移除的接口
返回
成功时为 0，否则为负的错误码。
