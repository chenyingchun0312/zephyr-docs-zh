◆ scd4x_forced_recalibration()

int scd4x_forced_recalibration ( const struct device * dev,
uint16_t target_concentration,
uint16_t * frc_correction )

#include <zephyr/drivers/sensor/scd4x.h>

执行强制重新校准。

在 CO2 浓度均匀恒定的环境中，以该工作模式运行 SCD4x 至少 3 分钟。否则重新校准将失败。执行 FRC 序列时，传感器必须工作在应用所需的电压下。

参数
dev指向传感器设备的指针
target_concentration参考 CO2 浓度。
frc_correction先前与目标浓度的偏差
返回
如果成功则为 0，失败时为负的 errno 码。
