◆ NET_EVENT_DNS_SERVERS_RECONFIGURED

#define NET_EVENT_DNS_SERVERS_RECONFIGURED   (NET_EVENT_L4_BASE | NET_EVENT_L4_CMD_DNS_SERVERS_RECONFIGURED)

#include <zephyr/net/net_event.h>

当 DNS 服务器配置被刷新时发出的事件。

在每次成功重新配置时引发，包括新服务器集合与现有集合相同的情况（此时按槽位的 ADD/DEL 增量事件会被有意抑制，以避免在 DHCP 提供重传和 IPv6 RA 时取消正在进行的查询）。如果消费者需要网络事件之后的“DNS 配置再次就绪”信号，应监听此事件而不是 NET_EVENT_DNS_SERVER_ADD。

此事件携带 NULL 接口负载（系统级事件）。

◆ net_mgmt_event_wait()

int net_mgmt_event_wait ( uint64_t mgmt_event_mask,
uint64_t * raised_event,
struct net_if ** iface,
const void ** info,
size_t * info_length,
k_timeout_t timeout )

#include <zephyr/net/net_mgmt.h>

用于同步等待事件掩码

参数
mgmt_event_mask要等待的相关事件掩码。
raised_event指向 uint64_t 的指针，用于获取掩码中产生该事件的事件。若调用方不关心该信息，可为 NULL。
iface指向网络接口占位符的指针，该接口是事件的来源。仅当根据调用方要监听的事件，事件掩码相应设置了 NET_MGMT_IFACE_BIT 位时，该指针才有效。
info若用户想获取事件可能携带的信息，则为有效指针。否则为 NULL。
info_length说明 info 内存区域的长度。仅当 info 不为 NULL 时有效。
timeout超时延迟。可使用 K_FOREVER 无限等待。
返回
成功时为 0，否则为负的错误码。如果超时生效而非收到实际事件，将特别返回 -ETIMEDOUT。
