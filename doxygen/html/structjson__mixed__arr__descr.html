详细描述

混合类型 JSON 数组的描述符。

此结构体描述元素类型可以不同的顶层 JSON 数组（基本类型、对象、数组或嵌套混合数组）。数组中的每个元素由描述符数组中的一个条目描述。

混合数组可用于解析和编码元素类型不统一的 JSON 数组，例如：

[ "string", 42, { "foo": 1 }, [1,2,3], true ]

注解
此结构体及其相关宏用于混合数组的解析和编码 API（参见 json_mixed_arr_parse()）。
