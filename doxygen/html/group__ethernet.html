int net_eth_mac_filter ( struct net_if * iface,
struct net_eth_addr * mac,
enum ethernet_filter_type type,
bool enable )

#include <zephyr/net/ethernet.h>

设置或取消对 MAC 地址 mac 的硬件过滤。

多播目的地址与 IP 协议栈和报文套接字已加入的组共享，因此只有当第一个用户请求时才通知设备监听它，并在最后一个用户离开时才停止。因此每一次这样的地址设置都必须有一次对应的取消设置，而取消设置从未设置过的地址会失败并返回 -ENOENT。源地址和单播目的地址会按原样传给设备。

参数
iface网络接口
mac指向以太网 MAC 地址的指针
type过滤器类型，为源或目的
enable设置（true）或取消设置（false）
返回
设置或取消过滤器成功时为 0，否则 <0。
