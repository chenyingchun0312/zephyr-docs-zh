◆ sys_getopt_long()

int sys_getopt_long ( int nargc,
char *const * nargv,
const char * options,
const struct sys_getopt_option * long_options,
int * idx )

解析命令行参数。

sys_getopt_long() 函数的工作方式与 sys_getopt() 类似，但它还接受以两个短横线开头的长选项。

注解
此函数基于 FreeBSD 实现，但不支持环境变量 POSIXLY_CORRECT。
参数
[in]nargc参数个数。
[in]nargvArguments.
[in]options包含合法选项字符的字符串。
[in]long_options指向数组第一个元素的指针，该数组的元素类型为 struct sys_getopt_option.
[in]idx若 idx 不为 NULL，则它指向一个变量，该变量被设为长选项相对于 long_options 的索引。
返回
若成功找到选项，函数返回该选项字符。

◆ sys_getopt_long_only()

int sys_getopt_long_only ( int nargc,
char *const * nargv,
const char * options,
const struct sys_getopt_option * long_options,
int * idx )

解析命令行参数。

sys_getopt_long_only() 函数的工作方式与 sys_getopt_long() 类似，但 '-' 与 "--" 一样可以表示长选项。若以 '-'（而非 "--"）开头的选项不匹配长选项，却匹配短选项，则改为按短选项解析。

注解
此函数基于 FreeBSD 实现，但不支持环境变量 POSIXLY_CORRECT。
参数
[in]nargc参数个数。
[in]nargvArguments.
[in]options包含合法选项字符的字符串。
[in]long_options指向数组第一个元素的指针，该数组的元素类型为 struct sys_getopt_option.
[in]idx若 idx 不为 NULL，则它指向一个变量，该变量被设为长选项相对于 long_options 的索引。
返回
若成功找到选项，函数返回该选项字符。
