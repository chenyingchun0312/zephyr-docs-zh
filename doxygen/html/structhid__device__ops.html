 此回调在 HID Get Report 请求中调用，用于获取由参数 type 指定的特性报告、输入报告或输出报告。如果报告描述符中没有报告 ID，则 id 参数为零。回调实现必须校验参数，例如报告类型是否受支持以及报告长度，并返回负值表示类型不受支持或出现错误，或返回写入缓冲区的报告长度。

 此回调在 HID Set Report 请求中、实际接收报告负载之前调用。回调实现应校验参数，例如报告类型是否受支持，并返回非零值表示类型不受支持或出现错误。如果未实现回调，则将无条件接收报告负载。
int(*) set_report (const struct device *dev, const uint8_t type, const uint8_t id, const uint16_t len, const uint8_t *const buf)
 此回调在 HID Set Report 请求中调用，用于设置由参数 type 指定的特性报告、输入报告或输出报告。如果报告描述符中没有报告 ID，则 id 参数为零。回调实现必须校验参数，例如报告类型是否受支持，并返回非零值表示类型不受支持或出现错误。
void(*) set_idle (const struct device *dev, const uint8_t id, const uint32_t duration)
 用于限制输入报告频率的通知。设备应暂停提交输入报告，直到有新事件发生，或直到 duration 值指定的时间过去。如果报告描述符中使用了报告 ID，设备必须保存该持续时间并相应地处理指定报告。持续时间的时间分辨率为毫秒。

void(*) set_protocol (const struct device *dev, const uint8_t proto)
 主机已将协议从启动协议（0）改为报告协议（1）或反向改变的通知。
void(*) input_report_done (const struct device *dev, const uint8_t *const report)
 通过 hid_device_submit_report() 提交的输入报告已发送的通知。如果设备未使用该回调，hid_device_submit_report() 将被同步处理。
void(*) output_report (const struct device *dev, const uint16_t len, const uint8_t *const buf)
 新输出报告回调。该回调仅对通过可选的中断 OUT 管道接收到的报告调用。如果没有中断 OUT 管道，输出报告将通过 set_report() 接收。如果报告描述符中使用了报告 ID，主机会先把该 ID 放入缓冲区，随后是报告数据。
void(*) sof (const struct device *dev)
 可选的帧起始（SoF）事件回调。软件和硬件相关的抖动与延迟总是存在。应非常谨慎地使用，不得阻塞，且执行时间应相当短。

详细描述

HID 设备用户回调

每个设备都依赖一个用户部分，该部分根据报告描述符所描述的设备功能，处理特性报告、输入报告和输出报告。需要实现哪些回调取决于设备功能。HID 设备的 USB 设备部分无法解释设备特定的报告描述符，只处理 USB 相关部分、传输和请求校验，所有报告对它来说都是不透明的。回调从 USB 设备栈线程调用，不得阻塞。

◆ get_report_size

int(*) hid_device_ops::get_report_size(const struct device *dev, const uint8_t type, const uint8_t id)

可选回调，在分配用于处理 HID Get Report 请求的缓冲区之前调用。回调应校验请求参数（例如报告类型和报告 ID），并返回所请求报告的大小。如果报告类型不受支持或报告 ID 未知，应返回零或负值。

实现此回调后，协议栈可以将缓冲区分配限制为所请求报告的大小，而不必分配与主机提供的 wLength 一样大的缓冲区。如果未实现此回调，协议栈会分配大小为 wLength 的缓冲区。
