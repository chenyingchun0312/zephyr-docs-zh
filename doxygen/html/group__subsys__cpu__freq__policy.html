◆ cpu_freq_policy_pstate_set()

const struct pstate * cpu_freq_policy_pstate_set ( const struct pstate * state)

#include <zephyr/cpu_freq/policy.h>

按策略设置 CPU 频率缩放的 P 状态

此函数由通过 Kconfig 选择的 CPU 频率缩放策略实现。它接受之前通过调用 :c:func:cpu_freq_policy_select_pstate 获得的 P 状态，并尝试按策略应用它。策略可以选择应用所选的 P 状态、应用其他 P 状态，或完全忽略该请求。此函数由 CPU 频率缩架子系统自动调用，应用程序代码不应直接调用。

参数
state指向 P 状态的指针
返回
指向所应用 P 状态的指针，若未应用任何状态则为 NULL

◆ cpu_freq_policy_select_pstate()

int cpu_freq_policy_select_pstate ( const struct pstate ** pstate_out)

#include <zephyr/cpu_freq/policy.h>

从 CPU 频率缩放策略获取下一个 P 状态

此函数由通过 Kconfig 选择的 CPU 频率缩放策略实现。调用者必须确保当前 CPU 不发生变更。若从 ISR 或单 CPU 系统调用，该限制自动满足。若在 SMP 系统的线程中调用，则必须禁用中断或调度器，以确保当前 CPU 不发生变更。

参数
pstate_out指向用于返回下一个 P 状态的 P 状态结构体的指针。
返回
成功时为 0，失败时为非零值。
