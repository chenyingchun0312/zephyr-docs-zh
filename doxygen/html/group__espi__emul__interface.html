◆ emul_find_emul

typedef struct espi_emul *(*) emul_find_emul(const struct device *dev, unsigned int chipsel)

#include <zephyr/drivers/espi_emul.h>

查找 eSPI 总线上存在的仿真器

目前此函数仅用于查找主机设备的仿真器。在带有 SPI Flash 芯片的系统中可能有用。

参数
deveSPI 仿真控制器设备
chipsel片选值
返回
要使用的 espi_emul
未找到时为 NULL
