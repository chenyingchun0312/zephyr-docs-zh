◆ mcumgr_serial_process_frag()

struct net_buf * mcumgr_serial_process_frag ( struct mcumgr_serial_rx_ctxt * rx_ctxt,
const uint8_t * frag,
int frag_len )

#include <zephyr/mgmt/mcumgr/transport/serial.h>

处理通过串口传输收到的 mcumgr 请求分片。

处理通过串口传输收到的 mcumgr 请求分片。如果该分片是一个有效 mcumgr 请求的结尾，此函数将返回一个包含解码后请求的 net_buf。调用者负责在处理完毕后释放该 net_buf。

参数
rx_ctxt所用串口传输对应的接收上下文。
frag要处理的传入分片。
frag_len分片的长度，以字节为单位。
返回
如果已收到完整有效的请求，则返回包含解码后请求的 net_buf。如果数据包不完整或无效，则返回 NULL。
