详细描述

OSCORE 交换条目。

通过匹配客户端地址和请求令牌来跟踪哪些服务器响应需要 OSCORE 保护（RFC 8613, section-8.3）。用以下配置定义的 CoAP 服务 COAP_SERVICE_DEFINE_OSCORE owns a statically allocated cache of these entries.

注意
Available only when the following Kconfig option is enabled: CONFIG_COAP_OSCORE.
