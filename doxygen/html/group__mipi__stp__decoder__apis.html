◆ mipi_stp_decoder_cb

typedef bool(*) mipi_stp_decoder_cb(enum mipi_stp_decoder_ctrl_type type, union mipi_stp_decoder_data data, uint64_t *ts, bool marked)

#include <zephyr/debug/mipi_stp_decoder.h>

回调签名。

每当从 STPv2 流中解码出一个元素时就会调用该回调。

注解
调用回调时中断处于锁定状态。
参数
typeType. See mipi_stp_decoder_ctrl_type.
data数据。与给定 type 关联的数据。
ts时间戳。若非 NULL 则存在。
marked若操作码被标记则置为 true。
返回
若数据有效则为 true，若数据表明同步丢失则为 false。

◆ mipi_stp_decoder_sync_loss()

void mipi_stp_decoder_sync_loss ( void )

#include <zephyr/debug/mipi_stp_decoder.h>

表示同步丢失。

若检测到该情况，解码器开始查找 ASYNC 标记，并丢弃所有数据直到找到 ASYNC。当出现数据丢失（例如因溢出）时会丢失同步。
