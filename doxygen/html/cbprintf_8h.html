判断字符串是否必须在运行时打包。

若包的大小可在编译期确定，则可应用静态打包。一般而言，若没有任何字符串参数被视为临时字符串而被复制进包体，则包大小可在编译期确定。

◆ CBPRINTF_PACKAGE_CONVERT_PTR_CHECK

#define CBPRINTF_PACKAGE_CONVERT_PTR_CHECK   BIT(3)

检查格式字符串中 p 参数是否在包中被当作 s 处理。

静态打包仅根据格式字符串所用参数的类型完成，不会查看字符串中出现的格式说明符。因此，若把（unsigned）char 指针用于 p，它会被视为字符串位置，转换时可能尝试向包中附加字符串。这可能导致异常行为，最好情况下包会变大，最坏情况下可能出现内存错误或安全违规。

设置此标志时，会检查格式字符串，以检测字符串候选是用于 p 的指针的情况，避免从意外位置附加字符串。此外还会生成日志警告，建议用户把此类参数转换为 void *。之所以建议这样做，是因为在某些配置下字符串不可访问，无法进行检查。在这些情况下没有任何手段检测此类问题。

◆ CBPRINTF_PACKAGE_CONVERT_RO_STR

#define CBPRINTF_PACKAGE_CONVERT_RO_STR   BIT(0)

把源包中的只读字符串附加到目标包。

若包是用 CBPRINTF_PACKAGE_ADD_RO_STR_POS 或 CBPRINTF_PACKAGE_ADD_RW_STR_POS 创建的，则它包含可在包中找到字符串地址的索引数组。设置该标志时，只读字符串会被复制到目标包。标记为读写的字符串地址也会被检查，若判定为只读，它们同样会被复制。

把源包中的读写字符串附加到目标包。

align_offset输入缓冲区的对齐偏移量（字节）。偏移量为 0 表示缓冲区按 CBPRINTF_PACKAGE_ALIGNMENT 对齐。Xtensa 要求 packaged 按 CBPRINTF_PACKAGE_ALIGNMENT 对齐，因此它必须是 CBPRINTF_PACKAGE_ALIGNMENT 的整数倍或 0。

把包转换为完全自包含（fsc）包。

包可能不是自包含的，因为默认情况下字符串按地址存储。当临时（非只读）字符串被附加到包中时，包可以是部分自包含的。这种包只有在能够访问只读字符串时才能解码。

完全自包含（fsc）包含包中使用的所有字符串。若包是用 CBPRINTF_PACKAGE_ADD_RO_STR_POS 标志创建的，则可把它转换为 fsc 包。这种包会包含在包中查找只读字符串并把它们复制到包体所需的数据。

参数
in_packaged指向用以下标志创建的原始包的指针 CBPRINTF_PACKAGE_ADD_RO_STR_POS.
in_lenin_packaged length.
packaged指向将写入输入包完全自包含版本的位置的指针。传入空指针可计算所需空间。
len必须把它设为 packaged 处可用的字节数。若 packaged 为空则不使用。
返回值
>=0成功存储在 packaged 处的字节数。它不会超过 len。若 packaged 为空，则为计算出的长度。
-ENOSPC若 packaged 不为空且存储所需空间超过 len。
-EINVAL若 in_packaged 为空。

捕获稍后输出格式化数据所需的状态。

类似 cbprintf()，但它不立即处理参数并输出格式化结果，而是捕获所有参数，以便在其他上下文中完成输出，例如在输出函数可能阻塞时。

除从参数中提取的值外，这还会确保对任何未确认存储于只读内存（因而被视为以后可直接安全引用）的字符串参数的所需部分进行复制。

参数
packaged指向可存放打包数据的位置的指针。传入空指针则不存储任何内容，但仍计算所需的总空间。此处存储的数据是可重定位的，即可以移到另一块连续内存，但前提是保持对齐。它必须至少按指针的大小对齐。
len若 packaged 不为空，则必须把它设为 packaged 处可用的字节数。若 packaged 为空，则表示相对于 CBPRINTF_PACKAGE_ALIGNMENT 对齐的假想缓冲区对齐偏移量（字节）。缓冲区对齐偏移量会影响返回的包大小。Xtensa 要求缓冲区始终按 CBPRINTF_PACKAGE_ALIGNMENT 对齐，因此当 packaged 为空时，它必须是 CBPRINTF_PACKAGE_ALIGNMENT 的整数倍或 0。
flags选项标志。参见 CBPRINTF_PACKAGE_FLAGS。
format标准的 ISO C 格式字符串，包含字符和转换说明。
...与 format 中找到的转换说明相对应的参数。
返回值
>=0成功存储在 packaged 处的字节数。它不会超过 len。
-EINVAL若 format 不可接受
-EFAULT若 packaged 的对齐方式不可接受
-ENOSPC若 packaged 不为空且存储所需空间超过 len。

packaged指向可存放打包数据的位置的指针。传入空指针则不存储任何内容，但仍计算所需的总空间。此处存储的数据是可重定位的，即可以移到另一块连续内存。该指针必须按参数列表中最大元素大小的整数倍对齐。
len必须把它设为 packaged 处可用的字节数。若 packaged 为 NULL 则忽略。
flags选项标志。参见 CBPRINTF_PACKAGE_FLAGS。
format标准的 ISO C 格式字符串，包含字符和转换说明。
ap与 format 中找到的转换说明相对应的已捕获栈参数。
返回值
>=0成功存储在 packaged 处的字节数。它不会超过 len。
-EINVAL若 format 不可接受
-ENOSPC若 packaged 不为空且存储所需空间超过 len。

int cbvprintf_tagged_args ( cbprintf_cb out,
void * ctx,
const char * format,
va_list ap )
inlinestatic

通过回调实现的、支持可变参数且参数带标签的 *printf 类输出。

这本质上是 vsprintf()，只是输出是通过提供的 out 函数逐字符生成的。这样可以格式化任意长度的文本，而不必付出临时缓冲区的代价。

注意参数列表 ap 是带标签的。

注解
仅在以下情况下此函数才可用 CONFIG_CBPRINTF_LIBC_SUBSTS is selected.
在以下情况下此函数的功能会显著减少 CONFIG_CBPRINTF_NANO is selected.
参数
out用于输出每个生成字符的函数。
ctx调用 out 时提供的上下文
format标准的 ISO C 格式字符串，包含字符和转换说明。
ap对要转换的值的引用。
返回
已生成的字符数，或调用 out 返回的负错误值。
