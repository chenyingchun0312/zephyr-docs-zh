详细描述

传递给 clock_monitor_configure 的顶层配置。

回调（及其 user_data）与其余配置一起被原子地安装，并且是唯一的事件传递路径。传入 callback = NULL 会禁用事件传递；在 MEASURE 模式下，仍可通过轮询 clock_monitor_get_rate 获取最近的结果。
