按索引迭代 phandle 数组元素中的所有单元

此宏对索引 idx 处 phandle 数组元素中的每个单元值调用 fn(cell_value)。

一般而言，此宏展开为： 

fn(node_id, pha, idx, cell[0]) fn(node_id, pha, idx, cell[1]) [...]
fn(node_id, pha, idx, cell[n-1])

其中 n 是 pha 中的单元数（由 DT_PHA_NUM_CELLS_BY_IDX(node_id, pha, idx) 返回），cell[x] 是说明符中单元的 NAME。

参数
node_id节点标识符
pha类型为 phandle-array 的小写加下划线形式的属性
idxphandle 数组元素的索引
fn要对每个单元值调用的宏

设备树节点是否属于某个设备类？

当节点的绑定（或其包含的绑定）在其 class: 键中声明了某个类时，该节点属于该设备类。类名指明节点的驱动可以实现哪些设备 API 类别；实际为该节点构建哪个驱动是 Kconfig 的决定，此宏对此一无所知。

节点的 status 不影响该值。

参数
node_id节点标识符
_class小写加下划线形式的设备类名
返回
如果节点的绑定声明了该设备类则为 1，否则为 0

设备树节点是否匹配某个 compatible？

设备树片段示例：

n: node {
compatible = "vnd,specific-device", "generic-device";
}

Example usages which evaluate to 1:

DT_NODE_HAS_COMPAT(DT_NODELABEL(n), vnd_specific_device)
DT_NODE_HAS_COMPAT(DT_NODELABEL(n), generic_device)

This macro only uses the value of the compatible property. Whether or not a particular compatible has a matching binding has no effect on its value, nor does the node's status.

参数
node_idnode identifier
compatlowercase-and-underscores compatible, without quotes
返回
1 if the node's compatible property contains compat, 0 otherwise.
