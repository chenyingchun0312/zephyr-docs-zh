mDNS 响应程序 API

此文件包含 mDNS 响应程序 API。这些 API 用于注册 mDNS 记录。

◆ mdns_responder_disable_iface()

int mdns_responder_disable_iface ( struct net_if * iface)

在运行时在特定网络接口上禁用 mDNS 响应程序。

运行时设置会覆盖给定接口的构建时接口策略。绑定到该接口的监听套接字会被关闭，并退出其 mDNS 组播组，因此不再应答该接口上的查询。

注意
Available only when the following Kconfig option is enabled: CONFIG_MDNS_RESPONDER_RUNTIME_IFACE_CONTROL.
参数
iface要禁用响应程序的网络接口。
返回
0 表示正常；iface 为 NULL 时返回 -EINVAL；接口索引超出范围时返回 -ERANGE；未启用运行时控制时返回 -ENOTSUP。

◆ mdns_responder_enable_iface()

int mdns_responder_enable_iface ( struct net_if * iface)

在运行时在特定网络接口上启用 mDNS 响应程序。

运行时设置会覆盖给定接口的构建时接口策略（ CONFIG_MDNS_RESPONDER_IFACE_POLICY_ALL 等）。会重新配置响应程序监听套接字和组播组成员关系，以便应答到达该接口的查询。

注意
Available only when the following Kconfig option is enabled: CONFIG_MDNS_RESPONDER_RUNTIME_IFACE_CONTROL.
参数
iface要启用响应程序的网络接口。
返回
0 表示正常；iface 为 NULL 时返回 -EINVAL；接口索引超出范围时返回 -ERANGE；未启用运行时控制时返回 -ENOTSUP。

◆ mdns_responder_set_ext_records()

int mdns_responder_set_ext_records ( const struct dns_sd_rec * records,
size_t count )

注册 dns_sd_rec 记录的连续内存。

mDNS 响应程序启动时会遍历使用以下方式注册的 mDNS 记录 DNS_SD_REGISTER_SERVICE (if any) and then go over external records.

参数
records指向 mDNS 记录数组的指针。它被内部存储而不复制内容，因此必须保持有效。传入 NULL 并配合为 0 的 count 可注销这些记录，例如在释放内存块之前。该调用会等待正在进行的响应停止使用这些记录。
count元素数量，仅当 records 为 NULL 时为零。
返回
0 表示正常；如果 records 为 NULL 而 count 不为零，或者 records 不为 NULL 而 count 为零，则返回 -EINVAL。
