◆ dali_set_receive_callback()

int dali_set_receive_callback ( const struct device * dev,
dali_receive_callback_t callback,
void * user_data )

#include <zephyr/drivers/dali.h>

设置一个从 DALI 总线接收帧的回调函数。

为 DALI 驱动设置回调函数。每当 DALI 帧被完整接收，或检测到相关总线事件时，会在驱动的工作队列上下文中调用该回调函数。每个驱动实例只支持一个回调函数。

注解
该回调函数在停止条件结束时被调用。帧间时序需要考虑这一点。
参数
dev驱动实例的 DALI 设备结构体指针。
callback每当接收到帧或检测到相关事件时，DALI 驱动会调用该函数。
user_data传递给回调函数的用户数据。
返回值
0成功时
-ENOSYS若函数未实现

◆ dali_transmit()

int dali_transmit ( const struct device * dev,
const struct dali_frame * frame,
dali_transmit_callback_t callback,
void * user_data )

#include <zephyr/drivers/dali.h>

在 DALI 总线上发送一帧。

立即开始向 DALI 总线发送 DALI 帧。若发生错误，驱动不会自动尝试重发该帧。

参数
dev驱动实例的 DALI 设备结构体指针。
frame要发送的 DALI 帧
callback可选回调，在帧成功发送或检测到发送错误时调用。该回调函数在驱动的工作队列上下文中调用。回调的 err 参数含义参见 dali_transmit 的返回码。
user_data传递给回调函数的用户数据。
返回值
0成功时
-EBUSY若帧发送正在进行
-EINVAL若向函数传入了无效参数
-ECANCELED若发送因显性帧而让出总线
-ECOMM若发送期间发生冲突
-EAGAIN若总线不可用
-ENOSYS若函数未实现
