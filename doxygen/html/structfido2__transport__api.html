◆ init

int(*) fido2_transport_api::init(fido2_transport_recv_cb_t cb, fido2_transport_cancel_cb_t cancel_cb)

初始化传输。

在子系统启动期间调用一次。传输必须保存这些回调，并在每次收到 CBOR 消息或取消命令时调用它们。

参数
cb收到 CBOR 消息时要调用的回调。
cancel_cb收到取消命令时要调用的回调
返回值
0If successful.
-ENODEV如果硬件不可用。

◆ notify

void(*) fido2_transport_api::notify(uint32_t cid, enum fido2_wire_status status)

向传输通知操作进度变化。

由 FIDO2 核心在长时间运行操作期间调用，以指示状态转换。每种传输会将其转换为相应的线协议信令。

参数
cidChannel/connection identifier.
status表示核心正在执行何种操作的进度状态。
