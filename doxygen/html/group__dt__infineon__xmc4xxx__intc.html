详细描述

Infineon XMC4xxx 中断控制器的设备树宏。

用于编码 ERU（事件请求单元）线路映射单元的宏，与 infineon,xmc4xxx-intc 兼容中断控制器配合使用。XMC4XXX_INTC_SET_LINE_MAP() 将 GPIO port 与 pin、ERU 输入源 eru_src 和 ERU 输出 line 打包为单个映射值；对应的 XMC4XXX_INTC_GET_* 访问宏负责提取各个字段。

&some_device {
interrupt-names = "rx";
interrupts = <XMC4XXX_INTC_SET_LINE_MAP(0, 1, 0, 0) 0>;
};
