从选定的端点槽获取端点配置

当 icmsg_me 实例收到来自远端端点的数据时，它必须根据端点 id 获取端点配置。此函数就是为此目的而设计的。

如果获取到的端点配置未设置，则 ept_cfg 指向 NULL。

参数
[in,out]data包含 icmsg_me 实例使用的运行时数据的结构体。该结构体使用以下内容初始化。 icmsg_me_init and its content must be preserved while the icmsg_me instance is active.
[in]id唯一标识端点的值。
[in]ept_cfg具有给定 id 的端点的配置数据。
返回值
0成功时。
-ENOENT当 id 超出可用槽的范围时。

打开 icmsg_me 实例

打开 icmsg_me 实例，以便向远端实例发送消息和接收消息。此函数会阻塞，直到与远端实例的握手完成。此函数应在初始化过程的后期调用，可能从某个线程调用，该线程在与远端实例执行握手期间可以安全地被阻塞。

参数
[in]conf包含底层 icmsg 实例配置参数的结构体。
[in,out]data包含 icmsg_me 实例使用的运行时数据的结构体。该结构体使用以下内容初始化。 icmsg_me_init and its content must be preserved while the icmsg_me instance is active.
[in]cb包含在此 icmsg_me 实例产生的事件上要调用的回调函数的结构体。在 icmsg_me 实例活动期间，所指向的内存必须保持不变。
[in]ctx指向作为参数传递给回调的上下文的指针。
返回值
0成功时。
other来自依赖模块的 errno 错误码。

在空的端点槽中设置端点配置

在端点握手期间，握手发起方必须选择一个 id 号，并存储完成握手和维护连接所需的端点元数据。此函数是一个辅助函数，它将配置存储到空的配置槽中，并提供与所选槽关联的唯一 id 值。

注解
此函数对于单个 icmsg_me 实例不可重入。调用方必须使用互斥量、临界区、自旋锁或类似方案对其进行保护。此函数对于不同的 icmsg_me 实例可重入。保护范围可以仅限于单个实例。
参数
[in,out]data包含 icmsg_me 实例使用的运行时数据的结构体。该结构体使用以下内容初始化。 icmsg_me_init and its content must be preserved while the icmsg_me instance is active.
[in]ept_cfg正在发起握手过程的端点的配置数据。
[out]id唯一标识此端点的值。
返回值
0成功时。
-ENOMEM当没有更多空的端点配置槽时。

void icmsg_me_wait_for_icmsg_bind ( struct icmsg_me_data_t * data)

#include <zephyr/ipc/icmsg_me.h>

等待底层 icmsg 实例调用 bound 回调

此函数会阻塞调用线程，直到底层 icmsg 连接已绑定。如果连接在调用此函数之前就已绑定，则此函数会立即结束，没有任何延迟。

此函数应在端点握手过程中使用，以确保在 icmsg 通道准备好传递握手消息之前不执行握手。

参数
[in,out]data包含 icmsg_me 实例使用的运行时数据的结构体。该结构体使用以下内容初始化。 icmsg_me_init and its content must be preserved while the icmsg_me instance is active.
