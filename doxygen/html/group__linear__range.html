详细描述

自从
3.3
版本
1.0.0

线性范围 API 把线性范围内的值映射为范围索引。线性范围可由四个参数完整定义：

  • 最小值
  • 步长值
  • 最小索引值
  • 最大索引值

例如在电压调节器中，支持的电压通常这样映射到寄存器索引值：

  • 1000uV: 0x00
  • 1250uV: 0x01
  • 1500uV: 0x02
  • ...
  • 3000uV: 0x08

在这种情况下，我们有：

  • 最小值：1000uV
  • 步长值：250uV
  • 最小索引值：0x00
  • 最大索引值：0x08

线性范围也可以是恒定的，即步长设为零。

常见的情况是同一设备具有不连续的线性范围。此 API 也提供了处理线性范围组的工具函数。

实现使用定宽整数。范围限制在 [INT32_MIN, INT32_MAX]，而索引数限制为 UINT16_MAX。

最初的想法借鉴自 Linux。

int linear_range_get_index ( const struct linear_range * r,
int32_t val,

inlinestatic

#include <zephyr/sys/linear_range.h>

根据值获取索引。

若值落在范围之外，则存放最接近的索引并返回 -ERANGE。也就是说，若值低于或高于该范围，索引将分别取最小值或最大值。对于恒定范围，将返回最小索引。

参数
[in]r线性范围实例。
valValue.
[out]idx索引的存放位置。
返回值
0若值落在该范围内。
-ERANGE若值落在该范围之外。

◆ linear_range_get_win_index()

int linear_range_get_win_index ( const struct linear_range * r,
int32_t val_min,
int32_t val_max,
uint16_t * idx )
inlinestatic

#include <zephyr/sys/linear_range.h>

根据值的窗口获取索引。

若值的窗口与范围不相交，将返回 -EINVAL。若相交是部分的（任一窗口边界不相交），则存放最接近的索引并返回 -ERANGE。

参数
[in]r线性范围实例。
val_min窗口最小值。
val_max窗口最大值。
[out]idx索引的存放位置。
返回值
0若在线性范围内找到有效索引。
-ERANGE若给定的值窗口部分落在该线性范围之外。
-EINVAL若给定的值窗口与该线性范围不相交，或它们太窄。
