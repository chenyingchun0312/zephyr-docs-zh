◆ img_mgmt_client_state_write()

int img_mgmt_client_state_write ( struct img_mgmt_client * client,
const char * hash,
size_t hash_len,
bool confirm,
struct mcumgr_image_state * res_buf )

#include <zephyr/mgmt/mcumgr/grp/img_mgmt/img_mgmt_client.h>

写入映像的状态。

向目标发送映像状态写入请求。映像通过其摘要来选择，该摘要必须与 img_mgmt_client_state_read 报告的 hash 匹配。摘要可以使用 SHA-256 或 SHA-512，取决于目标配置。

所请求的操作取决于 hash 和 confirm：

  • 如果 hash 不为 NULL 且 confirm 为 false，则所选映像被标记为测试。取决于 MCUboot 模式，该映像会在下次启动时被换入或被选中，并且除非之后被确认，否则可以回退。
  • 如果 hash 不为 NULL 且 confirm 为 true，则请求确认所选映像。目标可以拒绝确认非活动映像。
  • 如果 hash 为 NULL 且 confirm 为 true，则确认当前活动映像。
  • 如果 hash 为 NULL 且 confirm 为 false，则该请求无效。
参数
clientIMG 管理客户端对象。
hash用于选择目标映像的映像摘要。设为 NULL 以选择当前活动映像。此参数仅在以下情况下有效 confirm is true.
hash_lenhash 的长度（字节）：SHA-256 为 32，SHA-512 为 64。当 hash 为 NULL 时设为 0。
confirm设为 false 以测试映像，设为 true 以确认映像。
res_buf命令响应结构体。请求成功时，目标返回的映像状态存放在此处。
返回值
0请求已成功完成。
返回
失败时为 mcumgr_err_t 错误码。
