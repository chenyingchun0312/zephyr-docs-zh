枚举类型说明

◆ img_mgmt_group_events

enum img_mgmt_group_events

#include <zephyr/mgmt/mcumgr/grp/img_mgmt/img_mgmt_callbacks.h>

映像管理组的 MGMT 事件操作码。

枚举值
MGMT_EVT_OP_IMG_MGMT_DFU_CHUNK 

客户端发送文件上传数据块时调用的回调，数据为 img_mgmt_upload_check。

MGMT_EVT_OP_IMG_MGMT_DFU_STOPPED 

DFU 操作被停止时调用的回调。

MGMT_EVT_OP_IMG_MGMT_DFU_STARTED 

DFU 操作启动时调用的回调。

MGMT_EVT_OP_IMG_MGMT_DFU_PENDING 

DFU 操作完成传输时调用的回调。

MGMT_EVT_OP_IMG_MGMT_DFU_CONFIRMED 

映像被确认时调用的回调。数据为 img_mgmt_image_confirmed。

MGMT_EVT_OP_IMG_MGMT_DFU_CHUNK_WRITE_COMPLETE 

映像写入命令完成向 Flash 写入时调用的回调。

MGMT_EVT_OP_IMG_MGMT_IMAGE_SLOT_STATE 

当映像槽的状态被编码用于响应时调用的回调，数据为 img_mgmt_state_slot_encode.

MGMT_EVT_OP_IMG_MGMT_SLOT_INFO_IMAGE 

当槽列表命令输出映像的字段时调用的回调，数据为 img_mgmt_slot_info_image.

MGMT_EVT_OP_IMG_MGMT_SLOT_INFO_SLOT 

当槽列表命令输出映像某个槽的字段时调用的回调，数据为 img_mgmt_slot_info_slot.

MGMT_EVT_OP_IMG_MGMT_ALL 

用于启用所有 img_mgmt_group 事件。
