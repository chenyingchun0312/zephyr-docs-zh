◆ mgmt_alloc_rsp_fn

typedef void *(*) mgmt_alloc_rsp_fn(const void *src_buf, void *arg)

#include <zephyr/mgmt/mcumgr/mgmt/mgmt.h>

分配适合存放响应的缓冲区。

如果提供了源缓冲区，其用户数据会被复制到新缓冲区中。

参数
src_buf可选的源缓冲区，用于复制用户数据。
arg可选的 streamer 参数。
返回
成功时返回新分配的缓冲区，失败时返回 NULL。

◆ mgmt_handler_fn

typedef int(*) mgmt_handler_fn(struct smp_streamer *ctxt)

#include <zephyr/mgmt/mcumgr/mgmt/mgmt.h>

处理请求并写入相应的响应。

每个受支持的操作 ID 对都需要单独的处理程序。

参数
ctxt要使用的 mcumgr 上下文。
返回
如果响应成功编码则为 0，失败时为 mcumgr_err_t 错误码。

◆ mcumgr_group_t

enum mcumgr_group_t

#include <zephyr/mgmt/mcumgr/mgmt/mgmt_defines.h>

MCUmgr 组。前 64 个组保留给系统级 mcumgr 命令。用户命令则在组 64 之后定义。

枚举值
MGMT_GROUP_ID_OS 

OS（操作系统）组

MGMT_GROUP_ID_IMAGE 

映像管理组，用于上传固件映像

MGMT_GROUP_ID_STAT 

统计管理组，用于获取统计数据

MGMT_GROUP_ID_SETTINGS 

设置管理（配置）组，用于读写设置

MGMT_GROUP_ID_LOG 

日志管理组（未使用）

MGMT_GROUP_ID_CRASH 

崩溃组（未使用）

MGMT_GROUP_ID_SPLIT 

拆分映像管理组（未使用）

MGMT_GROUP_ID_RUN 

运行组（未使用）

MGMT_GROUP_ID_FS 

FS（文件系统）组，用于执行文件 IO 操作

MGMT_GROUP_ID_SHELL 

Shell 管理组，用于执行 shell 命令

MGMT_GROUP_ID_ENUM 

枚举管理组，用于列出受支持的命令组

MGMT_GROUP_ID_TRANSPORT 

传输管理组（默认组 ID），用于桥接传输

MGMT_GROUP_ID_PERUSER 

从 64 开始定义的用户组

ZEPHYR_MGMT_GRP_BASIC 

Zephyr 专用组从 PERUSER 向下递减，以避免与上游和用户定义的组冲突。Zephyr 专用：Basic 组
