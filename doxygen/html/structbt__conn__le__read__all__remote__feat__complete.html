◆ features

const uint8_t* bt_conn_le_read_all_remote_feat_complete::features

指向大小为 248 的数组的指针，包含远端支持特性的特性位。

第 0 页为 8 字节，其后 10 页各为 24 字节。取值参见 BT_LE_FEAT_BIT_*。取值比较参见 BT_FEAT_LE_* 宏。参见 Bluetooth 核心规范第 6 卷第 B 部分第 4.6 节。

uint8_t bt_conn_le_read_all_remote_feat_complete::status

来自 LE Read All Remote Features Complete 事件的 HCI 状态。
