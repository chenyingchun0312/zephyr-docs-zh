◆ thread_analyzer_print()

void thread_analyzer_print ( unsigned int cpu)

#include <zephyr/debug/thread_analyzer.h>

运行线程分析器并打印栈大小统计。

此函数运行线程分析器并以标准形式打印输出。在设置了 Kconfig 选项 THREAD_ANALYZER_AUTO_SEPARATE_CORES 的特殊情况下，该函数仅分析运行在指定 cpu 上的线程。

参数
cpu要分析的 cpu，若 THREAD_ANALYZER_AUTO_SEPARATE_CORES=n 则忽略

◆ thread_analyzer_run()

void thread_analyzer_run ( thread_analyzer_cb cb,
unsigned int cpu )

#include <zephyr/debug/thread_analyzer.h>

运行线程分析器并向回调提供信息

此函数分析所有线程的当前状态，并对发现的每个线程调用给定的回调。在设置了 Kconfig 选项 THREAD_ANALYZER_AUTO_SEPARATE_CORES 的特殊情况下，该函数仅分析运行在指定 cpu 上的线程。

参数
cb回调函数处理函数
cpu要分析的 cpu，若 THREAD_ANALYZER_AUTO_SEPARATE_CORES=n 则忽略

◆ thread_analyzer_stack_safety_handler_set()

void thread_analyzer_stack_safety_handler_set ( thread_analyzer_stack_safety_handler handler)

#include <zephyr/debug/thread_analyzer.h>

更改线程分析器的栈安全回调函数

此函数更改线程分析器的栈安全处理函数。这使应用程序可以在线程的未使用栈低于配置阈值时定制行为。

参数
handler指向新处理函数的函数指针（NULL 表示默认）
