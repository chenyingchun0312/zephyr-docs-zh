静态定义并初始化管道。

管道可在定义它的模块之外通过以下方式访问：

extern struct k_pipe <name>;
参数
nameName of the pipe.
pipe_buffer_sizeSize of the pipe's ring buffer (in bytes) or zero if no ring buffer is used.
pipe_alignAlignment of the pipe's ring buffer (power of 2).

◆ k_pipe_close()

void k_pipe_close ( struct k_pipe * pipe)

#include <zephyr/kernel.h>

关闭管道

此例程关闭管道。阻塞在 k_pipe_read() 或 k_pipe_write() 中的线程将解除阻塞并收到错误。在 k_poll() 中等待 K_POLL_TYPE_PIPE_DATA_AVAILABLE 的线程也会被唤醒：已关闭的管道被视为可读，因此 k_pipe_read() 可以返回 -EPIPE。

参数
pipe管道的地址。

k_timeout_t timeout )

#include <zephyr/kernel.h>

从管道读取数据 此例程从 pipe 读取最多 len 字节的数据。如果管道为空，此例程将阻塞，直到数据可以读取或超时到期。

参数
pipe管道的地址。
data用于存放从管道读取的数据的地址。
len请求读取的字节数。
timeout等待数据被读取的等待时间。
返回值
>=0成功时返回读取的字节数
-EAGAIN如果超时到期前无法读取任何数据
-ECANCELED如果读取被 k_pipe_reset(..) 中断
-EPIPE如果管道已关闭
-EOVERFLOW如果 len 大于 INT_MAX

◆ k_pipe_reset()

void k_pipe_reset ( struct k_pipe * pipe)

#include <zephyr/kernel.h>

重置管道 此例程重置管道，丢弃所有未读数据并解除所有等待写入或读取的线程的阻塞，使这些等待线程返回 -ECANCELED。当管道正在重置但尚未完成重置时调用 k_pipe_read(..) 或 k_pipe_write(..) 将返回 -ECANCELED。重置后管道保持打开，可正常使用。

参数
pipe管道的地址。

向管道写入数据

此例程向 pipe 写入最多 len 字节的数据。如果管道已满，此例程将阻塞，直到数据可以写入或超时到期。

参数
pipe管道的地址。
data要写入数据的地址。
len数据大小（以字节为单位）。
timeout等待数据被写入的等待时间。
返回值
>=0成功时返回写入的字节数
-EAGAIN如果超时到期前无法写入任何数据
-ECANCELED如果写入被 k_pipe_reset(..) 中断
-EPIPE如果管道已关闭
-EOVERFLOW如果 len 大于 INT_MAX
