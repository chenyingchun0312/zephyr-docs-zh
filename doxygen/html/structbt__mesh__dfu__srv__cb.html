int(*) bt_mesh_dfu_srv_cb::apply(struct bt_mesh_dfu_srv *srv, const struct bt_mesh_dfu_img *img)

传输应用回调。

在传输通过校验后、更新方向目标节点发送应用消息时调用。

此处理函数是可选的。

参数
srv固件更新服务器实例。
img应应用的 DFU 映像。
返回
成功时返回 0，否则返回（负的）错误码。

◆ check

int(*) bt_mesh_dfu_srv_cb::check(struct bt_mesh_dfu_srv *srv, const struct bt_mesh_dfu_img *img, struct net_buf_simple *metadata, enum bt_mesh_dfu_effect *effect)

传输检查回调。

传输检查可用于在传入传输开始前对其进行校验。元数据的内容取决于具体实现，应包含应用程序判断是否应接受该映像以及传输将产生何种效果所需的全部信息。

如果应用该映像会影响 Mesh 协议栈的配网状态，可以通过 effect 返回参数来传达。

元数据检查既可作为启动新传输的一部分执行，也可作为独立过程执行。

此处理函数是可选的。

参数
srv固件更新服务器实例。
img要对其执行元数据检查的 DFU 映像。
metadata映像元数据。
effect用于返回该映像对 Mesh 协议栈配网状态影响的参数。
返回
成功时返回 0，否则返回（负的）错误码。

void(*) bt_mesh_dfu_srv_cb::end(struct bt_mesh_dfu_srv *srv, const struct bt_mesh_dfu_img *img, bool success)

传输结束回调。

此处理函数是可选的。

如果传输成功，应用程序应校验固件映像，并调用 bt_mesh_dfu_srv_verified 或 bt_mesh_dfu_srv_rejected depending on the outcome.

如果传输失败，固件更新服务器将在此函数返回后立即可用于新传输。

参数
srv固件更新服务器实例。
img更新失败的 DFU 映像。
successDFU 传输是否成功。

int(*) bt_mesh_dfu_srv_cb::recover(struct bt_mesh_dfu_srv *srv, const struct bt_mesh_dfu_img *img, const struct bt_mesh_blob_io **io)

传输恢复（recovery）回调。

如果设备在传输过程中重启，固件更新服务器将在 Bluetooth Mesh 子系统启动时调用此函数。

此回调是可选的，但没有它，重启后传输将无法恢复。

参数
srv固件更新服务器实例。
img正在更新的 DFU 映像。
ioBLOB 流返回参数。必须由回调设置为有效的 BLOB 流。
返回
成功时返回 0，或返回（负的）错误码以放弃该传输。

◆ start

int(*) bt_mesh_dfu_srv_cb::start(struct bt_mesh_dfu_srv *srv, const struct bt_mesh_dfu_img *img, struct net_buf_simple *metadata, const struct bt_mesh_blob_io **io)

传输开始回调。

在固件更新服务器准备好启动新的 DFU 传输时调用。应用程序必须提供一个已初始化的 BLOB 流，供 DFU 传输期间使用。

以下错误码有特殊处理，应用来传达这些问题：

  • -ENOMEM：设备无法容纳该映像。
  • -EBUSY：应用程序暂时无法接受该传输。
  • -EALREADY：设备已接收并校验过该映像，无需再次传输。固件更新模型将跳过传输阶段，并将该映像标记为已校验。

此处理函数是必需的。

参数
srv固件更新服务器实例。
img正在更新的 DFU 映像。
metadata映像元数据。
ioBLOB 流返回参数。必须由回调设置为有效的 BLOB 流。
返回
成功时返回 0，否则返回（负的）错误码。返回码 -ENOMEM、-EBUSY、-EALREADY 将传给更新方，其他错误码将作为内部错误报告。
