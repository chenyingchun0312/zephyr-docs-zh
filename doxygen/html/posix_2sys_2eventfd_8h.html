◆ eventfd()

int eventfd ( unsigned int initval,
int flags )

创建用于事件通知的文件描述符

返回的文件描述符可用于 POSIX read/write 调用，或用于 eventfd_read/eventfd_write 函数。

它还支持轮询：在调用 poll 时加入一个 eventfd，就可以简单地通过写入该 eventfd 来通知并唤醒轮询线程。

对 eventfd 使用 read() 和 write() 时，大小必须至少为 8 字节，否则操作将以 EINVAL 失败。

返回
成功时返回新的 eventfd 文件描述符，出错时返回 -1
