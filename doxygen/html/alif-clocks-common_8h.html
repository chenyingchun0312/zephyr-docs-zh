Alif Semiconductor SoC 系列的通用时钟定义

该头文件定义了时钟 ID 编码方案以及所有 Alif SoC 系列共享的通用定义。

该编码方案是通用的，支持：

  • 最多 8 个时钟模块（3 位字段）
  • 最多 32 个输入时钟源（5 位字段）
  • 每个时钟的父时钟源选择
  • 每个时钟的使能/禁用控制

ALIF 时钟配置位字段编码

该宏将所有时钟控制信息编码为单个 32 位值，可通过设备树传递给时钟驱动。

位字段布局：

  • module [ 0 : 2 ] - 时钟模块 ID（0-7，参见 ALIF_*_MODULE）
  • reg [ 3 : 10 ] - 模块内的寄存器偏移量（0-255）
  • en_bit [ 11 : 15 ] - 使能控制的位位置（0-31）
  • en_mask [ 16 ] - 存在使能控制时为 1，常开时为 0
  • src_val [ 17 : 18 ] - 要写入的时钟源选择值（0-3）
  • src_field_width [ 19 : 20 ] - 以位表示的时钟源字段宽度（0-3，0=不选择）
  • src_field_pos [ 21 : 25 ] - 时钟源字段的位位置（0-31）
  • parent_clk [ 26 : 30 ] - 父时钟源标识符（0-31）
  • reserved [ 31 ] - 保留供将来使用
参数
module时钟模块（CGU、CLKCTL_PER_MST、CLKCTL_PER_SLV 等）
reg寄存器名称（将展开为 ALIF_<reg>_REG）
en_bit时钟使能位位置（0-31）
en_mask时钟有使能控制时为 1，始终使能时为 0
src_val要写入的时钟源值（0-3）
src_field_width源选择字段宽度（0=不选择，1-3=以位表示的字段宽度）
src_field_pos时钟源选择字段的位位置（0-31）
parent_clk父时钟源标识符（0-31，参见 ALIF_PARENT_CLK_*）
