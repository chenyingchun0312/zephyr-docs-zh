详细描述

Arm 通用中断控制器（GIC）的设备树宏。

用于 arm,gic 和 arm,gic-v3 兼容中断控制器的中断单元编码宏。一个中断由三个单元描述：中断组（GIC_SPI 或 GIC_PPI）、该组内的中断号，以及触发类型（ IRQ_TYPE_LEVEL 或 IRQ_TYPE_EDGE）。

&i2c0 {
interrupts = <GIC_SPI 25 IRQ_TYPE_LEVEL>;
};
