详细描述

This group contains the API type definitions, callback signatures, and other helpers required to implement a GPIO driver.

枚举类型说明

◆ gpio_int_mode

enum gpio_int_mode

#include <zephyr/drivers/gpio.h>

pin_interrupt_configure 驱动操作的中断模式。

供驱动 API 函数 pin_interrupt_configure 使用，这些值按公共标志定义，因此可以直接掩码后传给驱动 API。

枚举值
GPIO_INT_MODE_DISABLED 

禁用引脚中断。

GPIO_INT_MODE_LEVEL 

使能电平触发引脚中断。

GPIO_INT_MODE_EDGE 

使能边沿触发引脚中断。

GPIO_INT_MODE_DISABLE_ONLY 

禁用先前配置的引脚中断而不取消其配置。

注意
Available only when the following Kconfig option is enabled: CONFIG_GPIO_ENABLE_DISABLE_INTERRUPT.
GPIO_INT_MODE_ENABLE_ONLY 

重新使能先前配置的引脚中断。

注意
Available only when the following Kconfig option is enabled: CONFIG_GPIO_ENABLE_DISABLE_INTERRUPT.

◆ gpio_int_trig

enum gpio_int_trig

#include <zephyr/drivers/gpio.h>

pin_interrupt_configure 驱动操作的中断触发方式。

枚举值
GPIO_INT_TRIG_LOW 

当输入状态为（或变为）物理低电平时触发检测。（下降沿或低有效）

GPIO_INT_TRIG_HIGH 

当输入状态为（或变为）物理高电平时触发检测。（上升沿或高有效）

GPIO_INT_TRIG_BOTH 

在引脚上升沿或下降沿触发检测。

GPIO_INT_TRIG_WAKE 

触发系统唤醒。

GPIO_INT_TRIG_WAKE_LOW 

当输入状态为（或变为）物理低电平时触发系统唤醒。（下降沿或低有效）

GPIO_INT_TRIG_WAKE_HIGH 

当输入状态为（或变为）物理高电平时触发系统唤醒。（上升沿或高有效）

GPIO_INT_TRIG_WAKE_BOTH 

在引脚上升沿或下降沿触发系统唤醒。
