详细描述

IEEE 802.15.4 L2 APIs

自从
1.0
版本
0.8.0

此 API 提供与 Zephyr 套接字及网络上下文的集成。**应用程序和驱动开发者绝不应直接使用此 API。** 它仅对子系统维护者有意义。

该 API 实现并扩展了以下结构体：

  • 实现 Zephyr 内部的 L2 层套接字与网络上下文抽象（上下文/套接字操作，参见 net_l2），
  • 对接口结构的协议特定扩展（参见 net_if）
  • 对网络报文结构的协议特定扩展（参见 net_pkt），
注解
所有章节、表格和插图引用均指 IEEE 802.15.4-2020 标准。

◆ IEEE802154_FCS_LENGTH

#define IEEE802154_FCS_LENGTH   2

#include <zephyr/net/ieee802154.h>

表示帧校验序列的长度，参见第 7.2.1.1 节。

注解
目前仅支持 2 字节 FCS，尽管某些 PHY（例如 SUN、TVWS 等）可选支持 4 字节 FCS。一旦需要完全支持这些 PHY，需修改此值。

◆ IEEE802154_MAX_ADDR_LENGTH

#define IEEE802154_MAX_ADDR_LENGTH   IEEE802154_EXT_ADDR_LENGTH

#include <zephyr/net/ieee802154.h>

IEEE 802.15.4 最大地址长度。

◆ IEEE802154_MAX_PHY_PACKET_SIZE

#define IEEE802154_MAX_PHY_PACKET_SIZE   127

#include <zephyr/net/ieee802154.h>

表示 PHY 常量 aMaxPhyPacketSize，参见第 11.3 节。

注解
目前仅支持 127 字节的报文，尽管某些 PHY（例如 SUN、MSK、LECIM 等）支持更大的报文。一旦需要完全支持这些 PHY，需修改此值。

◆ IEEE802154_MTU

#define IEEE802154_MTU   (IEEE802154_MAX_PHY_PACKET_SIZE - IEEE802154_FCS_LENGTH)

#include <zephyr/net/ieee802154.h>

IEEE 802.15.4 的 "硬件" MTU（不要与 L3/IP MTU 混淆），即下一更高层可用的实际载荷。

这等价于 IEEE 802.15.4 MAC 帧长度减去校验和字节，也等价于 PHY 载荷（即 PSDU）长度减去校验和字节。此定义是为了与 Linux 和 Zephyr L3 中的相同概念兼容。它不是 IEEE 802.15.4 标准中的概念。

注解
目前仅支持来自 2006 版及更早标准的原始帧大小。2015 及之后的标准引入了具有更大 PHY 载荷的 PHY。Zephyr 尚未支持这些。
