详细描述

模拟 ADC 后端 API

模拟 ADC 的行为由应用程序定义。因此，每个应用程序可以

  • 定义设备树覆盖文件，以指明 ADC 控制器的数量以及每个控制器的通道数
  • 在设备树中设置默认参考电压，或使用 adc_emul_ref_voltage_set
  • 异步调用 adc_emul_const_value_set，以在模拟 ADC 输入上设置恒定的 mV 值
  • 异步调用 adc_emul_value_func_set，以指定用于获取模拟 ADC 输入电压的函数

合适的设备树覆盖文件示例见 tests/drivers/adc/adc_api/boards/native_sim.overlay

使用模拟 ADC 后端 API 的示例见 tests/drivers/adc/adc_emul/src/main.c
