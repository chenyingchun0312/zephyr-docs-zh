◆ st87mxx_gnss_getfix()

int st87mxx_gnss_getfix ( uint32_t nb_position,
st87mxx_get_pos_callback_t * get_pos_callback_func,
uint32_t timeout )

#include <zephyr/drivers/modem/st87mxx_app_services.h>

获取 ST87Mxx GNSS 位置的 API。

回调返回的位置默认采用 ST_AT 格式，可通过修改 GNSS_CONSTELLATION_ID 常量将其设为 NMEA 格式。

例如对于 ST_AT：#GNSSFIX: 0,2291,461282763,48.15370,-01.56719,130.2, 33.6,00.0,00.0,52.2,2.4,9.5,7.7,5,11,2.4,30,-0.1,20,1.4,09,1.7,06,-0.3
详细说明：" #GNSSFIX: validity,week_number,time_of_week,latitude,longitude, altitude,accuracy [,std_dev_altitude,hdop,gdop,pdop] <- 若 GNSS_FORMAT_ST_ACCURACY 为 1
[,number_of_satellites,satellite1_id,satellite1_residual,...,
satelliten_id,satelliten_residual] <- 若 GNSS_FORMAT_ST_SATELLITES 为 1
[,orientation_degree,semi_major,semi_minor] <- 若 GNSS_FORMAT_ST_ORIENTATION 为 1
例如对于 NMEA：$GPGLL,4809.2231,N,00134.281,W,091218,A,A*6C
更多信息：https://en.wikipedia.org/wiki/NMEA_0183

参数
nb_position要采样的 GNSS 位置数量。值为 0 表示无限。
get_pos_callback_func指向输出回调函数的指针
timeout超时（秒），超过后请求将被取消
返回值
Execution状态

◆ st87mxx_wifiscan()

int st87mxx_wifiscan ( st87mxx_wifiscan_params * wscan_params)

#include <zephyr/drivers/modem/st87mxx_app_services.h>

启动用于定位的 WIFI 扫描（=WSCAN）功能的 API。

WIFI 扫描功能通常用于在 GNSS 不可用时（例如室内环境）确定粗略位置。
WIFI 扫描功能的主要目的是检测并列出附近所有可用的 WIFI 网络。
启动 WIFI 扫描后，ST87MXX 会发现附近的 WIFI 网络。
它监听 WIFI 接入点（AP）发出的、提供网络信息的信标。检测到的 WIFI 网络列表可发送给第三方定位服务器以获取位置。

参数
wscan_params包含启动 WSCAN 功能参数的结构体。
返回值
Execution状态
