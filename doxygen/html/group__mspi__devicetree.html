从设备树节点标识符初始化并获取指向 mspi_ce_control 的指针

该辅助函数适用于在 MSPI 总线上初始化设备。它初始化一个 struct mspi_ce_control 并返回指向它的指针。此处 node_id 是 MSPI 设备的节点标识符，而非 MSPI 控制器的。

设备树片段示例：

mspi@abcd0001 {
ce-gpios = <&gpio0 1 GPIO_ACTIVE_LOW>;
mspidev: mspi-device@0 { ... };
};

Example usage:

struct mspi_ce_control ctrl =
MSPI_CE_CONTROL_INIT(DT_NODELABEL(mspidev), 2);
DT_NODELABEL
#define DT_NODELABEL(label)
获取节点标签的节点标识符

设备树片段示例：

gpio1: gpio@abcd0001 { ... };
gpio2: gpio@abcd0002 { ... };
mspi@abcd0003 {
compatible = "ambiq,mspi";
ce-gpios = <&gpio1 10 GPIO_ACTIVE_LOW>,
<&gpio2 20 GPIO_ACTIVE_LOW>;
a: mspi-dev-a@0 {
reg = <0>;
};
b: mspi-dev-b@1 {
reg = <1>;
};
};

Example usage:

MSPI_DEV_CE_GPIOS_DT_SPEC_GET(DT_NODELABEL(a)) \
// { DEVICE_DT_GET(DT_NODELABEL(gpio1)), 10, GPIO_ACTIVE_LOW }
MSPI_DEV_CE_GPIOS_DT_SPEC_GET(DT_NODELABEL(b)) \
// { DEVICE_DT_GET(DT_NODELABEL(gpio2)), 20, GPIO_ACTIVE_LOW }
参数

返回
gpio_dt_spec struct corresponding with mspi_dev's chip enable
