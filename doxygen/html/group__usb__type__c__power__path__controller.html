◆ ppc_exit_dead_battery_mode()

int ppc_exit_dead_battery_mode ( const struct device * dev)
inlinestatic

#include <zephyr/drivers/usb_c/usbc_ppc.h>

请求 PPC 退出死电池模式。此调用返回并不表示 PPC 已不处于死电池模式。若出错，驱动应以 USBC_PPC_EVENT_DEAD_BATTERY_ERROR 枚举执行回调。要检查 PPC 是否已禁用死电池模式，应调用 ppc_is_dead_battery_mode。

参数
devPPC 设备结构体
返回值
0请求成功发出时
-EIOI2C 通信失败时
-ENOSYS驱动不支持此函数时
