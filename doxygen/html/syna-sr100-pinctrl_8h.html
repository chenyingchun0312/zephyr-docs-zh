引脚配置位字段。对固定引脚（XSPI）将掩码设为 0

字段：

  • ctrl 字段 [ 0 : 2 ]
  • bit 字段 [ 3 : 7 ]
  • mode 字段 [ 8 : 10 ]
  • mask 字段 [ 11 : 14 ]
  • reg 字段 [ 16 : 23 ]
  • cfg 字段 [ 24 : 31 ]
参数
ctrl控制器（0 = Global，1 = AON-Main，2 = LPS_Gear1，3 = SWIRE）
bit寄存器内的位偏移（0..27）
mode复用选项（0..7）
mask复用选项的位掩码（1..7）
reg相对于 pinmux 基址的寄存器偏移（0..255）
cfg相对于 pincfg 基址的寄存器偏移（0..255）
