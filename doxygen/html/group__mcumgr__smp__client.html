◆ smp_client_single_response()

int smp_client_single_response ( const struct smp_transport * smpt,
struct net_buf * nb,
const struct smp_hdr * res_hdr )

#include <zephyr/mgmt/mcumgr/smp/smp_client.h>

SMP 客户端响应处理程序。

只有当响应完成的是在 smpt 上发送且组和命令 ID 相同的待处理命令时，才会被处理。

参数
smpt接收到该响应的 SMP 传输。
nb响应 net_buf。
res_hdr解析后的 SMP 头部，按主机字节序。
返回值
MGMT_ERR_EOK该响应完成了一个待处理命令。
MGMT_ERR_ENOENT没有带回调的待处理命令与该响应匹配。
