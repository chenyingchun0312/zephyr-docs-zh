void(*) bt_map_mce_mns_cb::send_event(struct bt_map_mce_mns *mce_mns, bool final, struct net_buf *buf)

发送事件回调

当从远程 MSE 收到 SendEvent 请求时调用。如果请求被分片，可能多次调用。应用程序应使用 bt_map_mce_mns_send_event() 作出响应。

参数
mce_mnsMNS 服务端实例。
final若这是最后一个报文则为 true，若后面还有数据则为 false。
buf包含事件报告 XML 数据和头的缓冲区。
