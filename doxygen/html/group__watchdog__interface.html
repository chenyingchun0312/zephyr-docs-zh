◆ wdt_disable()

int wdt_disable ( const struct device * dev)

#include <zephyr/drivers/watchdog.h>

禁用看门狗实例。

此函数禁用看门狗实例并自动卸载所有超时。要设置新的看门狗，请安装超时并再次调用 wdt_setup()。并非所有看门狗都能在禁用后重新启动。

参数
dev看门狗设备实例。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-EFAULT看门狗实例未启用。
-EPERM应用程序代码不能直接禁用看门狗。

◆ wdt_install_timeout()

int wdt_install_timeout ( const struct device * dev,
const struct wdt_timeout_cfg * cfg )
inlinestatic

#include <zephyr/drivers/watchdog.h>

安装新超时。

注解
此函数必须在 wdt_setup() 之前使用。在调用 wdt_setup() 之前，此处所做的更改不会生效。
参数
dev看门狗设备实例。
[in]cfg超时配置。
返回
成功时为通道 ID（可用作调用 wdt_feed() 时的参数），失败时为负的 errno 值。
返回值
-EBUSY看门狗已设置后无法安装超时。
-ENOMEM无法再安装更多超时。
-ENOTSUP所设置的任一标志都不受支持。
-EINVAL任一窗口超时值超出可能的范围。如果看门狗对所有超时只支持一个超时值，且所提供的超时窗口与目前所安装警报的窗口不同，也会返回该值。

◆ wdt_setup()

int wdt_setup ( const struct device * dev,
uint8_t options )

#include <zephyr/drivers/watchdog.h>

设置看门狗实例。

此函数用于配置影响所有超时的全局看门狗设置。它应在安装超时之后调用。成功返回后，所有已安装的超时都有效，必须通过调用 wdt_feed() 定期喂狗。

参数
dev看门狗设备实例。
options配置选项（参见 WDT_OPT）。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENOTSUP所设置的任一选项都不受支持。
-EBUSY看门狗实例已设置。
