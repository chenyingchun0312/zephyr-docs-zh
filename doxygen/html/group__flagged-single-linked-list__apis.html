详细描述

带标志的单链表实现。

与 单链表 类似，但增加了为每个节点定义用户“标志”位的能力。可以使用 sys_sfnode_flags_get() 和 sys_sfnode_flags_set() API 访问和修改它们。

使用内联宏/函数实现的带标志单链表。此 API 不是线程安全的，因此若在多个线程间使用同一链表，对函数的调用必须用同步原语保护。

初始化 sflist 节点

为此 slist 节点设置初始标志值。该值必须能放入 SYS_SFLIST_FLAG_BITS 报告的位数中。即使节点在链表中移动、被移除或移植到另一个 slist，这些标志也会保留。
