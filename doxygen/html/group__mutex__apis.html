◆ k_mutex_lock()

int k_mutex_lock ( struct k_mutex * mutex,
k_timeout_t timeout )

#include <zephyr/kernel.h>

锁定互斥量。

此例程锁定 mutex。如果该互斥量已被其他线程锁定，调用线程将等待，直到互斥量可用或发生超时。

允许线程锁定它已经锁定的互斥量。该操作立即完成，锁定计数加 1。

互斥量不可在 ISR 中锁定。

互斥量在被锁定期间或有线程在其上等待期间，不得被释放，其内存也不得被重用。嵌入在动态分配对象中的互斥量必须在该对象被释放之前解锁；否则，持有线程将继续跟踪一个位于已不属于它的内存中的互斥量。

参数
mutex互斥量的地址。
timeout锁定互斥量的等待时间，或特殊值 K_NO_WAIT 和 K_FOREVER 之一。
返回值
0已锁定互斥量。
-EBUSY未等待即返回。
-EAGAIN等待时间超时。

◆ k_mutex_unlock()

int k_mutex_unlock ( struct k_mutex * mutex)

#include <zephyr/kernel.h>

解锁互斥量。

此例程解锁 mutex。该互斥量必须已由调用线程锁定。

在调用线程按其先前锁定的次数解锁该互斥量之前，其他线程无法获取该互斥量。

互斥量不可在 ISR 中解锁，因为出于所有权和优先级继承语义，互斥量只能在线程上下文中操作。

参数
mutex互斥量的地址。
返回值
0已解锁互斥量。
-EPERM当前线程不拥有该互斥量
-EINVAL该互斥量未锁定
