int(*) bt_l2cap_fixed_chan::accept(struct bt_conn *conn, struct bt_l2cap_chan **chan)

信道接受回调

此回调需要由应用程序提供，并在建立新连接时被调用。若接受该连接，用户应为 bt_l2cap_le_chan 类型的零初始化对象分配内存，并更新信道引用 chan 使其指向所分配对象的 bt_l2cap_le_chan::chan 成员。应通过将回调赋给 bt_l2cap_chan_ops field as follows:

static int accept(struct bt_conn *conn, struct bt_l2cap_chan **chan)
{
// Allocation of fixed_chan and definition of the ops are assumed done prior.
fixed_chan = (struct bt_l2cap_le_chan){
.chan.ops = &ops,
};
*chan = &fixed_chan.chan;
return 0;
}

The allocated context needs to be valid for the lifetime of the channel, i. e. freeing of the memory can be done in the bt_l2cap_chan_ops::released callback.

警告
Even though the reference passed back through chan is a bt_l2cap_chan, it must be the bt_l2cap_le_chan::chan member of a bt_l2cap_le_chan object. The stack uses the containing object, so returning a bare bt_l2cap_chan would result in out-of-bounds access.
参数
connThe connection that has been established.
chanL2CAP channel reference.
返回
0 to accept the channel connection, negative error code otherwise.

◆ cid

uint16_t bt_l2cap_fixed_chan::cid

信道标识符（CID）

注解
应位于 0x0001 至 0x003F 范围内（Core 3.A.2.1 v6.0）。该范围内的 CID 由协议栈保留，因此应用程序需要确保该 CID 尚未被使用。Core 3.A.2.1 中的表 2.1 和 L2CAP 信道标识符 列出了协议栈使用的 CID。
