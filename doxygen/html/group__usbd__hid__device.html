#include <zephyr/usb/class/usbd_hid.h>

注册 HID 设备报告描述符与用户回调

设备必须在 USB 设备支持初始化和启用之前注册报告描述符与用户回调。

参数
[in]dev指向 HID 设备的指针
[in]rdesc指向 HID 报告描述符的指针
[in]rsizeHID 报告描述符的大小
[in]ops指向 HID 设备回调的指针

◆ hid_device_set_in_polling()

int hid_device_set_in_polling ( const struct device * dev,
const unsigned int period_us )

#include <zephyr/usb/class/usbd_hid.h>

设置输入报告轮询周期

类似于设备树属性 in-polling-period-us，但允许在运行时设置不同的轮询周期。

注意
Available only when the following Kconfig option is enabled: CONFIG_USBD_HID_SET_POLLING_PERIOD.
参数
[in]dev指向 HID 设备的指针
[in]period_us以微秒为单位的轮询周期
返回
成功时为 0，失败时为负的 errno 码。
返回值
-ENOTSUP如果未启用该 API。

◆ hid_device_submit_report()

int hid_device_submit_report ( const struct device * dev,
const uint16_t size,
const uint8_t *const report )

#include <zephyr/usb/class/usbd_hid.h>

提交新的输入报告

提交新的输入报告以通过中断 IN 管道发送。如果 sync 为 true，函数将阻塞直到报告发送完成。如果设备未提供 input_report_done() 回调，hid_device_submit_report() 将被同步处理。

参数
[in]dev指向 HID 设备的指针
[in]size输入报告的大小
[in]report输入报告缓冲区。报告缓冲区必须对齐。
返回
成功时为 0，失败时为负的 errno 错误码。
