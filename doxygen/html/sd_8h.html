◆ sd_init()

int sd_init ( const struct device * sdhc_dev,
struct sd_card * card )

初始化 SD 设备

初始化一个供子系统使用的 SD 设备。此调用之后，只需 SD 卡结构体即可访问该卡。

参数
sdhc_dev此卡的 SD 主机控制器设备
card此卡的 SD 卡结构体
返回值
0卡已初始化
-ETIMEDOUT卡初始化超时
-EBUSY卡忙
-EIO启动卡时出现 IO 错误
