枚举类型说明

◆ w1_settings_type

enum w1_settings_type

#include <zephyr/drivers/w1.h>

定义 1-Wire 主机设置类型，这些类型可在运行时配置。

枚举值
W1_SETTING_SPEED 

传入值 1 时启用超速（overdrive），传入 0 时禁用。

W1_SETTING_STRONG_PULLUP 

传入值 1 时，强上拉电阻会在下一个写入数据块之后立即激活；传入 0 时则取消激活。

W1_SETINGS_TYPE_COUNT 

不同设置类型的数量。

◆ w1_lock_bus()

int w1_lock_bus ( const struct device * dev)
inlinestatic

#include <zephyr/drivers/w1.h>

锁定 1-wire 总线以防止同时访问。

此例程锁定总线，以防止不同线程同时访问。调用线程会等待直到总线可用。线程可以锁定它已经锁定的互斥量。

参数
[in]dev指向该驱动实例设备结构的指针。
返回
成功时为 0，失败时为负的 errno 值。
