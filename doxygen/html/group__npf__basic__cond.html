静态定义一个“ip address allowlist”数据包过滤条件

这测试数据包的源 IP 地址是否与所提供集合中的任一 IP 地址匹配。

参数
_name条件的名称
_ip_addr_array用于测试的 struct net_in_addr 或 struct net_in6_addr 项数组
_ip_addr_num数组中 IP 地址的数量
_af数组中地址的协议族类型（NET_AF_INET / NET_AF_INET6）
