#include <zephyr/net/lldp.h>

LLDP 接收报文回调

回调在收到报文时被调用。它负责释放报文，或通过返回正确的 net_verdict 告知协议栈需要释放报文。

返回值：

  • NET_DROP：若报文无效、被拒绝，或我们希望协议栈释放它。此时核心协议栈将释放该报文。
  • NET_OK：若报文被接受，此时 net_pkt 的所有权移交回调，核心网络协议栈不再管理它。

◆ net_lldp_register_callback()

int net_lldp_register_callback ( struct net_if * iface,
net_lldp_recv_cb_t cb )

#include <zephyr/net/lldp.h>

注册 LLDP RX 回调函数

注册回调时接口会加入 LLDP 多播组，回调设为 NULL 时离开该组，这样在硬件中过滤多播帧的设备在有接收者时会把 LLDP 帧上传。

参数
iface网络接口
cb回调函数，或 NULL 表示注销
返回
成功时为 0，出错时 < 0
