◆ net_dhcpv4_option_callback_handler_t

typedef void(*) net_dhcpv4_option_callback_handler_t(struct net_dhcpv4_option_callback *cb, size_t length, enum net_dhcpv4_msg_type msg_type, struct net_if *iface)

#include <zephyr/net/dhcpv4.h>

定义应用回调处理函数的签名

参数
cb拥有此处理程序的原始 net_dhcpv4_option_callback 结构体
length服务器返回的数据长度。若该值大于 cb->max_length，则 cb->data 中只有 cb->max_length 字节可用
msg_type触发该回调的 DHCP 消息类型
iface接收到该 DHCP 消息的接口

注意：若原始 net_dhcpv4_option_callback 结构体存放在其他私有结构体中，可通过 CONTAINER_OF() 用 cb 指针取出私有数据。

◆ net_dhcpv4_msg_type

enum net_dhcpv4_msg_type

#include <zephyr/net/dhcpv4.h>

DHCPv4 消息类型

这些枚举值表示定义于 RFC 2132, section-9.6, hence they should not be renumbered.

对此定义的增加、删除和重排必须体现在对 net_dhcpv4_msg_type_name 的相应修改中。

◆ net_dhcpv4_set_reboot_hint()

int net_dhcpv4_set_reboot_hint ( struct net_if * iface,
const struct net_in_addr * requested_ip )

#include <zephyr/net/dhcpv4.h>

设置在 INIT-REBOOT 中请求的地址。

用此前租用的地址（例如从非易失性存储中恢复的地址）为 DHCPv4 客户端提供初始地址，以便下一次 net_dhcpv4_start begins in INIT-REBOOT state and requests it directly instead of performing a full discovery. Must be called while the DHCPv4 client is stopped. Requires CONFIG_NET_DHCPV4_INIT_REBOOT.

参数
ifaceDHCPv4 interface.
requested_ip要请求的地址，或用于清除提示的未指定地址。
返回值
0成功时。
-EINVAL无效参数。
-EBUSYDHCPv4 客户端处于活动状态。
-ENOTSUPINIT-REBOOT 支持已禁用。

void net_dhcpv4_start ( struct net_if * iface)

#include <zephyr/net/dhcpv4.h>

在 iface 上启动 DHCPv4 客户端

在给定接口上启动 DHCPv4 客户端。DHCPv4 客户端将开始协商 IPv4 地址。协商成功后，IPv4 地址详细信息将添加到接口。

参数
iface指向接口的有效指针

◆ net_dhcpv4_stop()

void net_dhcpv4_stop ( struct net_if * iface)

#include <zephyr/net/dhcpv4.h>

停止 iface 上的 DHCPv4 客户端

停止给定接口上的 DHCPv4 客户端。DHCPv4 客户端将从该接口移除从 DHCP 服务器获得的所有配置，并停止与服务器的进一步协商。

参数
iface指向接口的有效指针
