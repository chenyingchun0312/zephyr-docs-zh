◆ stream_flash_callback_t

typedef int(*) stream_flash_callback_t(uint8_t *buf, size_t len, size_t offset)

#include <zephyr/storage/stream_flash.h>

Flash 写入完成后调用的回调的签名。

此类函数被调用时会收到一个缓冲区，其中含有 Flash 写入完成后回读的数据。这样可以验证数据是否被正确存储（例如使用 SHA 函数）。stream_flash_init 中提供的写缓冲区 'buf' 在此用作读缓冲区。

参数
buf指向所读取数据的指针。
len所读取数据的长度。
offset读取数据所在的偏移量。

◆ stream_flash_buffered_write()

int stream_flash_buffered_write ( struct stream_flash_ctx * ctx,
const uint8_t * data,
size_t len,
bool flush )

#include <zephyr/storage/stream_flash.h>

以单块为单位处理要写入 Flash 设备的输入缓冲区。剩余部分会在各次调用之间保存。

把 flush 设为 true 的写入必须作为给定上下文的最后一次写请求发出，因为它结束一个流的写入，并把缓冲区刷入存储设备。

警告
对已刷出的上下文不得再发出任何额外的写请求，除非它被重新初始化，因为此类写入尝试可能导致函数失败并返回错误。上下文一经刷出，即可重新初始化并复用于新的流式 Flash 会话。
参数
ctx上下文
data要写入的数据
len要写入的字节数
flush为 true 时强制将所有缓冲的数据写入 Flash
返回
成功时为非负数，失败时为负的 errno 码

◆ stream_flash_progress_load()

int stream_flash_progress_load ( struct stream_flash_ctx * ctx,
const char * settings_key )

#include <zephyr/storage/stream_flash.h>

加载以键存储的持久化流式写入进度 settings_key .

应在写入任何数据之前、紧接 stream_flash_init 之后调用此函数，以加载先前的流式写入进度。若所加载的进度已写入的字节数少于 ctx，则将忽略它。

参数
ctx上下文
settings_key用于配合设置模块加载流式写入进度的键
返回
成功时为非负数；当 off 超出为流指定的区域时为 -ERANGE；失败时为负的 errno 码
