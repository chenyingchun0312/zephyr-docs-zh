int(*) bt_goep_transport_l2cap_server::accept(struct bt_conn *conn, struct bt_goep_transport_l2cap_server *server, struct bt_goep **goep)

服务器接受回调

每当新的传入 GOEP 连接需要授权时，都会调用此回调。

在返回回调之前，应使用 bt_goep_transport_ops 类型对象的有效地址初始化 bt_goep::transport_ops。 bt_obex::rx 的 mtu 字段值将被忽略，取而代之的是根据 CONFIG_BT_GOEP_L2CAP_MTU 计算出的值。

警告
调用方负责将 GOEP 对象的父对象清零。
注解
accept 回调必须按如下方式初始化返回的 GOEP 实例：
  • 将 bt_goep::transport_ops 设置为有效的操作表。
  • bt_goep::v2 字段应传入所指向的 bt_goep_transport_v2 instance must remain valid (address stable) for the entire lifetime of the transport connection. And bt_goep::v1 should be set to NULL.
  • 初始化版本专属对象中的反向指针 bt_goep_transport_v2::goep to point at the parent 通用对象交换配置文件（GOEP）. The version-specific object must remain valid for the lifetime of the transport.
参数
conn请求授权的连接。
server指向此回调所关联的服务端结构的指针。
goep指向用于接收所分配 GOEP 对象的指针。
返回
成功时为 0，出错时为负值。
-ENOMEM 如果没有可用空间容纳新对象。
若应用程序未授权该连接，则为 -EACCES。
若加密密钥长度过短，则为 -EPERM。

◆ l2cap

struct bt_l2cap_server bt_goep_transport_l2cap_server::l2cap

用于 GOEP v2.0 及更高版本的 L2CAP PSM

bt_goep_transport_l2cap_server::l2cap 用于注册 l2cap 服务端。

bt_l2cap_server::psm 需要以预先设置的 psm 传入（但不推荐），或者赋值为 0，使 psm 在以下情况下自动分配 bt_goep_transport_l2cap_server_register is called. The bt_l2cap_server::sec_level is used to require minimum security level for l2cap server. The bt_l2cap_server::accept should be not used by GOEP application, and instead the bt_goep_transport_l2cap_server::accept will be used.
