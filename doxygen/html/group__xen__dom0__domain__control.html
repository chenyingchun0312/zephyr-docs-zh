◆ xen_domctl_assign_dt_device()

int xen_domctl_assign_dt_device ( int domid,
char * dtdev_path )

#include <zephyr/xen/dom0/domctl.h>

将设备树描述的设备分配给客户机域。

在 arm64 上，这主要用于可作为总线主控的设备（支持 DMA 的设备）。Xen 会在分配过程中配置 IOMMU。

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_DOM0.
参数
domid目标域标识符。
dtdev_path指向该设备的、以 NULL 结尾的设备树路径。
返回
成功时为 0，失败时为负的 errno 值。

#include <zephyr/xen/dom0/domctl.h>

将物理中断绑定到客户机域。

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_DOM0.
参数
domid目标域标识符。
machine_irq要绑定的机器 IRQ 号。
irq_typeXen 直通 IRQ 类型。
busPCI 直通模式下的 PCI 总线号。
devicePCI 直通模式下的 PCI 设备号。
intxPCI 直通模式下的 PCI INTx 线。
isa_irqISA 直通模式下的 ISA IRQ 号。
spi与 PT_IRQ_TYPE_SPI 一起使用的 SPI 编号。
返回
成功时为 0，失败时为负的 errno 值。
返回值
-ENOTSUPirq_type 不受当前实现支持。

int xen_domctl_createdomain ( int * domid,
struct xen_domctl_createdomain * config )

#include <zephyr/xen/dom0/domctl.h>

创建新域。

domid is an IN/OUT parameter. If it is specified as an invalid value (0 or >= DOMID_FIRST_RESERVED), Xen auto-allocates an identifier and returns it through domid.

config传递给 Xen 的域配置。

◆ xen_domctl_max_vcpus()

int xen_domctl_max_vcpus ( int domid,
int max_vcpus )

#include <zephyr/xen/dom0/domctl.h>

设置域可用的最大 vCPU 数量。

max_vcpus must match the value passed to XEN_DOMCTL_createdomain. This hypercall is in the process of being removed (once the failure paths in domain_create() have been improved), but is still required in the short term to allocate the vCPUs themselves.

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_DOM0.
参数
domid目标域标识符。
max_vcpus要分配的 Xen vCPU 最大数量。
返回
成功时为 0，失败时为负的 errno 值。

◆ xen_domctl_memory_mapping()

int xen_domctl_memory_mapping ( int domid,
uint64_t first_gfn,
uint64_t first_mfn,
uint64_t nr_mfns,
uint32_t add_mapping )

#include <zephyr/xen/dom0/domctl.h>

将机器内存范围映射到客户机帧范围，或取消该映射。

如果 Xen 报告请求过大，实现会自动改用更小的块重试该操作。

注意
Available only when the following Kconfig option is enabled: CONFIG_XEN_DOM0.
参数
domid目标域标识符。
first_gfn目标范围内的第一个客户机帧号。
first_mfn源范围内的第一个机器帧号。
nr_mfns要处理的帧数量。
add_mapping设为非零以添加映射，设为零以移除映射。
返回
成功时为 0，失败时为负的 errno 值。
