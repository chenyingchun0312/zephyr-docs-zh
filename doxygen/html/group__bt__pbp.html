公共广播配置文件（PBP）

自从
3.5
版本
0.8.0

公共广播配置文件（PBP）通过在广播数据中提供附加信息来支持公共广播。

宏定义说明

◆ BT_PBP_MIN_PBA_SIZE

#define BT_PBP_MIN_PBA_SIZE   (BT_UUID_SIZE_16 + 1 + 1)

#include <zephyr/bluetooth/audio/pbp.h>

公共广播通告的最小长度

它包含公共广播通告 UUID（2 字节）、公共广播通告特性（1 字节）以及元数据长度（1 字节）

#include <zephyr/bluetooth/audio/pbp.h>

根据 features 参数中收到的信息创建公共广播通告。

参数
meta要包含在广播数据中的元数据
meta_len要包含在广播数据中的元数据字段长度
features公共广播通告特性
pba_data_buf用于存放 PBA 广播数据的指针。缓冲区大小需为 meta_len + BT_PBP_MIN_PBA_SIZE。
返回
成功时为 0，否则为相应的错误码。

◆ bt_pbp_parse_announcement()

int bt_pbp_parse_announcement ( struct bt_data * data,
enum bt_pbp_announcement_feature * features,
uint8_t ** meta )

#include <zephyr/bluetooth/audio/pbp.h>

解析收到的、与公共广播通告对应的广播数据。返回通告的公共广播通告特性和元数据。

参数
[in]data要检查的广播数据
[out]features指向公共广播源特性的指针，用于存放解析出的特性
[out]meta指向广播数据中元数据的指针
返回
成功时为解析出的元数据长度。
返回值
-EINVAL若 data、features 或 meta 为 NULL。
-ENOENT若 data 的类型不是 BT_DATA_SVC_DATA16，或服务数据中的 UUID 不是 BT_UUID_PBA。
-EMSGSIZE若 data 不够大，无法容纳 PBP 通告。
-EBADMSG若 data 包含无效数据。
