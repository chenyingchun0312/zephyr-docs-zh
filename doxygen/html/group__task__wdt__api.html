◆ task_wdt_add()

int task_wdt_add ( uint32_t reload_period,
task_wdt_callback_t callback,
void * user_data )

#include <zephyr/task_wdt/task_wdt.h>

安装新的超时。

向任务看门狗通道列表中添加一个新的超时。

参数
reload_period用于重置该超时的周期（毫秒）
callback看门狗定时器到期时要调用的函数。传 NULL 以使用系统复位处理程序。
user_data要与该看门狗通道关联的用户数据。
返回值
channel_id若成功，则为非负值，表示该超时所分配到的通道索引。此 ID 应用作 task_wdt_feed() 调用中的参数。
-EINVAL若 reload_period 无效。
-ENOMEM若无法再安装更多超时。

◆ task_wdt_delete()

int task_wdt_delete ( int channel_id)

#include <zephyr/task_wdt/task_wdt.h>

删除任务看门狗通道。

从任务看门狗通道列表中删除指定通道。该通道随后可通过 task_wdt_add() 函数再次供其他任务使用。

参数
channel_id由 task_wdt_add() 返回的通道索引。
返回值
0If successful.
-EINVAL若所提供通道没有已安装的超时。

int task_wdt_feed ( int channel_id)

#include <zephyr/task_wdt/task_wdt.h>

喂指定的看门狗通道。

此函数遍历所有已安装的任务看门狗，并以下一个到期超时更新用作软件看门狗的内核定时器。

参数
channel_id由 task_wdt_add() 返回的被喂通道索引。
返回值
0If successful.
-EINVAL若所提供通道没有已安装的超时。

◆ task_wdt_init()

int task_wdt_init ( const struct device * hw_wdt)

#include <zephyr/task_wdt/task_wdt.h>

初始化任务看门狗。

此函数设置所需的内核定时器以及硬件看门狗（若需要作为后备）。它必须在 task_wdt_add() 和 task_wdt_feed() 之前调用。

参数
hw_wdt指向用作后备的硬件看门狗设备的指针。若不需要硬件看门狗后备，则传 NULL。
返回值
0If successful.
-ENOTSUP若不支持指定硬件看门狗。
-Errno若使用了后备 hw_wdt 且安装超时的 API 失败，则为负的 errno。可能的返回值参见 wdt_install_timeout() API。

◆ task_wdt_resume()

void task_wdt_resume ( void )

#include <zephyr/task_wdt/task_wdt.h>

恢复所有通道的执行。

恢复内部定时器并喂所有通道。同时喂硬件看门狗（若已启用），以使应用程序有足够时间恢复自行喂通道。

◆ task_wdt_suspend()

void task_wdt_suspend ( void )

#include <zephyr/task_wdt/task_wdt.h>

在更改系统电源模式之前暂停所有通道。

停止内部定时器，并最后一次喂硬件看门狗（若已启用）。预期系统在此调用后很快进入低功耗模式。

注解
要暂停硬件看门狗（若支持），请在配置中启用 CONFIG_TASK_WDT_HW_FALLBACK_PAUSE_IN_SLEEP。
