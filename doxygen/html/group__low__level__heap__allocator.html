从 sys_heap 分配对齐内存

在所有方面与 sys_heap_alloc() 行为相同，只是所返回的内存（若有可用内存）其起始地址将是所指定 2 的幂对齐值（以字节计）的整数倍。align=0 时行为与 sys_heap_alloc() 完全一致。所得内存可用 sys_heap_free() 归还给堆。

参数

align以字节为单位的对齐，必须是 2 的幂
bytes请求的字节数
返回

◆ sys_heap_alloc()

void * sys_heap_alloc ( struct sys_heap * heap,
size_t bytes )

#include <zephyr/sys/sys_heap.h>

从 sys_heap 分配内存

返回指向堆中一块未使用内存的指针。该内存在被 sys_heap_free() 释放之前不会用于其他目的。若无法分配内存，则返回 NULL。所分配内存的起始地址保证是 sizeof(void *) 的整数倍。若需要更大的对齐，则应改用 sys_heap_aligned_alloc()。

注解
sys_heap 实现内部不同步。不应有两个 sys_heap 函数同时操作同一个堆。所有加锁都必须由用户提供。
参数
heap要从中分配的堆
bytes请求的字节数
返回
指向调用方现在可以使用的内存的指针

◆ sys_heap_realloc()

void * sys_heap_realloc ( struct sys_heap * heap,
void * ptr,
size_t bytes )

#include <zephyr/sys/sys_heap.h>

扩大现有分配的大小

返回指向具有相同内容但分配大小不同的新内存区域的指针。如果新分配可以就地扩展，返回的指针将相同。否则，数据将被复制到新块，旧块将按 sys_heap_free() 释放。如果指定的大小小于原始大小，则该块将被就地截断，剩余内存归还给堆。如果新块的分配失败，则返回 NULL，旧块不会被释放或修改。

参数
heap要从中分配的堆
ptr先前分配返回的原始指针
bytes为新块请求的字节数
返回
指向调用者现在可以使用的内存的指针，或 NULL

sys_heap 压力测试架

用于堆分配验证的测试架。它将循环 op_count 次，每次迭代随机选择分配或释放一个随机（幂律）大小的指针，所用启发式策略旨在使堆保持在接近 target_percent 满的状态。分配和释放操作由调用方以回调形式提供（即理论上可测试任何堆）。结果（包括释放次数以及成功/失败的分配次数）通过 result 结构体返回。

参数
alloc_fn执行分配的回调。将 arg 参数作为上下文句柄传回。
free_fn执行释放的回调，释放由以下函数返回的指针 alloc_fn. Passes back the arg parameter as a context handle.
arg要传回给回调的上下文句柄
total_bytes堆初始化时所用字节数组的大小
op_count要测试的迭代次数
scratch_mem指向供测试使用的暂存内存的指针。对于需要压测碎片化的测试，应约为堆大小的一半。
scratch_bytesscratch_mem 所指向内存的大小
target_percent随机分配选择所追求的填充百分比（1-100）。高值会导致大量分配失败和高度碎片化的堆。
result用于存储测试结果的结构体。

返回已分配内存的大小

返回成功调用 sys_heap_alloc() 或 sys_heap_alloc_aligned() 所返回块的大小（字节）。所返回的值是堆管理的内存大小，由于分配粒度，它可能大于所请求的字节数。堆代码保证在对同一指针执行后续 sys_heap_free() 之前不会访问该内存区域。

参数

mem指向从该堆分配的内存的指针
返回

◆ sys_heap_validate()

bool sys_heap_validate ( struct sys_heap * heap)
inlinestatic

#include <zephyr/sys/sys_heap.h>

校验堆的完整性

校验 sys_heap 的内部完整性。面向单元测试和验证代码，但也可能对运行时可靠性要求复杂的应用作为用户 API 有用。注意：这无法捕获所有可能的错误，但只要它返回 true，堆就处于一致状态，能够正确处理任何 sys_heap_alloc() 请求并释放先前分配返回的任何活动指针。

参数
heap要校验的堆
返回
若堆有效则为 true，否则为 false
