#include <zephyr/drivers/mspi.h>

在不带命令或地址阶段的情况下通过 MSPI 传输数据。

它是 mspi_transceive() 的便捷封装，适用于仅含数据阶段的传输。它用调用者拥有的包构造 mspi_xfer，并强制满足仅含数据的约定（ mspi_xfer.cmd_length 和 mspi_xfer::addr_length 为 0）。驱动会忽略 mspi_xfer_packet::cmd 和 mspi_xfer_packet.address。

这是硬件无法区分命令字节与数据字节时的预期传输调用，此时只使用 mspi_xfer_packet.dir、 mspi_xfer_packet::num_bytes and mspi_xfer_packet::data_buf are significant. It may equally be used by a controller for data-only transactions.

这些包仍归调用者所有；当 async 为 true 时，它们必须保持有效直到传输完成。

参数
controller指向该驱动实例设备结构的指针。
dev_id指向设备 ID 结构体的指针。
packets传输包。
num_packet传输包数量。
xfer_mode传输模式（PIO/DMA）。
async异步或同步传输。
timeout传输超时值（毫秒）。
返回值
0If successful.
-ENOTSUP
-EIO通用输入/输出错误，未能通过总线发送。
