inlinestatic

#include <zephyr/drivers/counter.h>

配置捕获通道并注册其回调

为捕获通道配置边沿极性和捕获模式（单次还是连续），并注册用于传递捕获定时计数值的回调。

注意
Available only when the following Kconfig option is enabled: CONFIG_COUNTER_CAPTURE.
注解
捕获通道到其输入源（例如物理引脚或内部信号）的映射由厂商定义，不属于该 API 的一部分。在大多数 SoC 上，通道与引脚的关联由硬件固定，并通过设备树公开（通常通过 pinctrl 或计数器节点上的专用属性）。关于如何选择输入，请参阅你的计数器设备的绑定。若具有可配置输入互连的 SoC 有此需要，该 API 的未来版本可能会增加运行时源选择调用（例如 counter_capture_set_source，或为此函数添加 source 参数）。
参数
dev驱动实例的设备结构体指针
chan_id通道 ID
flags配置标志（COUNTER_CAPTURE_FLAGS）
cb回调函数引用
user_data传递给回调函数的参数
返回值
0If successful.
Negative失败时为错误码
