◆ k_float_disable()

int k_float_disable ( struct k_thread * thread)

#include <zephyr/kernel.h>

禁用浮点上下文信息的保存。

此例程通知内核，指定线程将不再使用浮点寄存器。

警告
某些架构对如何请求禁用浮点保存有所限制，请参阅 arch_float_disable。
此例程只应用于禁用当前已启用此类支持的线程的浮点支持。
参数
thread线程 ID。
返回值
0成功时。
-ENOTSUP如果未实现浮点禁用。
-EINVAL浮点禁用操作无法执行时。

◆ k_float_enable()

int k_float_enable ( struct k_thread * thread,
unsigned int options )

#include <zephyr/kernel.h>

启用浮点上下文信息的保存。

此例程通知内核，指定线程将使用浮点寄存器。

调用此例程会将线程的浮点上下文信息初始化为已重置的 FPU 的状态。下次由 z_swap() 调度该线程时，它要么继承一个保证处于“正常”状态的 FPU（如果最近使用 FPU 的线程是协作式换出的），要么加载该线程自己的浮点上下文（如果最近使用 FPU 的线程被抢占，或者该线程是 FPU 的第一个使用者）。此后，内核将保护该线程的 FP 上下文，使其在抢占式上下文切换期间不被改动。

options 参数指示指定线程将使用哪些浮点寄存器组。

对于 x86，选项为：

  • K_FP_REGS 仅表示 x87 FPU 和 MMX 寄存器
  • K_SSE_REGS 表示 SSE 寄存器（以及 x87 FPU 和 MMX 寄存器）
警告
某些架构对如何请求启用浮点保存有所限制，请参阅 arch_float_enable。
此例程只应用于为当前尚未启用此类支持的线程启用浮点支持。
参数
thread线程 ID。
options与架构相关的选项
返回值
0成功时。
-ENOTSUP如果未实现浮点使能。
-EINVAL浮点启用操作无法执行时。
