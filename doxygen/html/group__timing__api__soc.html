◆ soc_timing_counter_get()

timing_t soc_timing_counter_get ( void )

#include <zephyr/timing/timing.h>

返回计时计数器。

注解
并非所有 SoC 都具有 64 位精度的计时计数器。由于内部回绕，可能会看到该值“倒退”。计时代码必须准备好处理回绕（使用依赖 SoC 的代码，例如在相减前转换为 uint32_t），或使用 soc_timing_cycles_get()，该函数能理解这种区别。
返回
计时计数器。

timing_counter_get()

◆ soc_timing_cycles_get()

uint64_t soc_timing_cycles_get ( volatile timing_t *const start,
volatile timing_t *const end )

#include <zephyr/timing/timing.h>

获取 start 与 end 之间的周期数。

注解
来自计数器的原始数字需要缩放才能得到实际的周期数，或者可能发生内部回绕。此函数计算两个所返回周期值之间的正定区间。
参数
start指向被测执行开始时计数器的指针。
end指向被测执行停止时计数器的指针。
返回
开始与结束之间的周期数。
参见
timing_cycles_get()
