函数说明

◆ entropy_get_default_device()

const struct device * entropy_get_default_device ( void )
inlinestatic

#include <zephyr/drivers/entropy.h>

若可用，返回默认熵设备。

按以下顺序返回：

  • 若可用，选择为 "zephyr,entropy" 的设备。
  • 若已使能，架构熵设备。
  • NULL.
返回值
Pointer指向默认熵设备。
NULL若不可用。

◆ entropy_get_entropy()

int entropy_get_entropy ( const struct device * dev,
uint8_t * buffer,
uint16_t length )

#include <zephyr/drivers/entropy.h>

用熵填充缓冲区。为生成所需的随机数据，必要时会阻塞。

参数
dev指向熵设备的指针。
buffer要用熵填充的缓冲区。
length缓冲区长度。
返回值
0成功时。
-ERRNO出错时返回 errno 码。

uint8_t * buffer,
uint16_t length,
uint32_t flags )
inlinestatic

#include <zephyr/drivers/entropy.h>

以非阻塞或忙等待方式用熵填充缓冲区。可从 ISR 调用。

参数
dev指向设备结构体的指针。
buffer要用熵填充的缓冲区。
length缓冲区长度。
flags用于修改调用行为的标志：ENTROPY_BUSYWAIT。
返回
填充了熵的字节数，或 -error。
