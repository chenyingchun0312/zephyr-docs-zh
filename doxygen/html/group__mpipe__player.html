详细描述

管道之上的高层可复用控制层。

播放器是一个轻量辅助模块，负责管道的运行时生命周期：播放、暂停、停止、重播和退出。

所有状态转换都在专用工作线程上串行执行，以便：

  • 调用者（例如交互式控制台循环）永远不会因管道拆除而阻塞，并且
  • 来自管道线程的流结束/错误通知永远不会在该线程自身的上下文中触状态变化（否则会尝试 join 正在运行它的线程）。

调用者通过 mpipe_player_*() API 将命令入队；工作线程逐条应用。

int mpipe_player_deinit ( struct mpipe_player * player)

#include <zephyr/mpipe/utils/mpipe_player.h>

等待工作线程退出并释放播放器的资源。

如果尚未请求工作线程退出，此函数会先请求退出。调用之后，播放器必须重新初始化才能再次使用。

参数
player通过 mpipe_player_init 初始化的播放器。
返回值
0Success.

◆ mpipe_player_init()

int mpipe_player_init ( struct mpipe_player * player,
struct mpipe * pipeline )

#include <zephyr/mpipe/utils/mpipe_player.h>

初始化播放器并启动其工作线程。

注册总线监听器，在流结束或出错时自动停止管道。管道必须已经构建并链接，但应处于 READY 状态（尚未播放）。

注解
同一时间只能有一个播放器实例处于活动状态。
参数
player指向未初始化的 播放器 的指针。
pipeline指向要控制的管道的指针。
返回值
0Success.
-EBUSY已有另一个播放器实例处于活动状态。
-EIO无法附加总线观察者。

◆ mpipe_player_wait_quit()

int mpipe_player_wait_quit ( struct mpipe_player * player)

#include <zephyr/mpipe/utils/mpipe_player.h>

阻塞直到播放器工作线程退出。

在管道已停止且工作线程即将退出时返回，即在已请求退出之后（通常通过 "q" / "player quit" shell 命令或 mpipe_player_quit）。这让应用程序的主线程可以在 shell 驱动播放器的同时等待用户完成操作。

注解
此函数只负责等待；之后请调用 mpipe_player_deinit 来 join 工作线程并释放播放器的资源。
参数
player通过 mpipe_player_init 初始化的播放器。
返回值
0Success.
