从队列中获取元素。

从 FIFO 队列获取元素。

此例程以“先进先出”方式从 fifo 移除数据项。数据项的第一个指针大小的字段保留供内核使用。

注解
如果从 ISR 调用，timeout 必须设置为 K_NO_WAIT。
参数
fifoFIFO 队列的地址。
timeout获取数据项的等待时段，或特殊值 K_NO_WAIT 和 K_FOREVER 之一。
返回
成功时为数据项的地址；如果未等待即返回，或等待时段超时，则为 NULL。

查看队列头部的元素。

查看 FIFO 队列头部的元素。

返回 FIFO 队列头部的元素而不将其移除。一种用例是 FIFO 对象的元素本身即为容器。此时在每次处理迭代中，会查看头部容器并从中处理一些数据，仅当该容器为空时才将其从 FIFO 队列中完全移除。

参数
fifoFIFO 队列的地址。
返回
头部元素，如果 FIFO 队列为空则为 NULL。

以原子方式向 FIFO 添加一组元素。

此例程在一次操作中向 fifo 添加一组数据项。数据项必须位于单向链表中，每个数据项的第一个指针大小的字段指向下一个数据项；链表必须以 NULL 结尾。

参数
fifoFIFO 队列的地址。
head指向单向链表中第一个节点的指针。
tail指向单向链表中最后一个节点的指针。
返回值
0成功时
-EINVAL所提供的数据无效时

此例程在一次操作中向 fifo 添加一组数据项。数据项必须位于使用 sys_slist_t 对象实现的单向链表中。完成后，该 sys_slist_t 对象即失效，必须通过 sys_slist_init() 重新初始化。
