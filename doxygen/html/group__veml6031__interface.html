enum sensor_attribute_veml6031

#include <zephyr/drivers/sensor/veml6031.h>

VEML6031 传感器的自定义传感器属性。

高低阈值窗口设置（ALS_WH_L、ALS_WH_H、ALS_WL_L 和 ALS_WL_H）请使用通用属性 SENSOR_ATTR_UPPER_THRESH 和 SENSOR_ATTR_LOWER_THRESH with 16-bit unsigned integer values. Both threshold settings are in lux and converted by the driver to a value compatible with the sensor. This conversion depends on the current gain, integration time and effective photodiode size settings. So a change in gain, integration time or effective photodiode size usually requires an update of threshold window settings. To get the correct threshold values into the sensor update the thresholds -after- a change of gain or integration time.

SENSOR_CHAN_LIGHT 通道必须设置所有属性。

当传感器饱和时返回 -E2BIG。这发生在原始 ALS 值为最大值 0xFFFF 时。此时需要用户减小以下一个或多个属性，以回到传感器的最佳测量范围：

  • SENSOR_ATTR_VEML6031_GAIN（增益）
  • SENSOR_ATTR_VEML6031_IT（积分时间）
  • SENSOR_ATTR_VEML6031_DIV4（有效光电二极管尺寸）

enum sensor_channel_veml6031

#include <zephyr/drivers/sensor/veml6031.h>

VEML6031 传感器的自定义传感器通道。

枚举值
SENSOR_CHAN_VEML6031_ALS_RAW_COUNTS 

用于原始 ALS 传感器值的通道。

该通道表示传感器 ALS 寄存器提供的原始测量计数值。它可用于在 fetch 和 get 模式下估算积分时间、有效光电二极管尺寸与增益属性的合适取值。

对于将来带触发器的实现，它还可用于估算传感器中断处理的阈值窗口属性。

它不能被直接读取。该通道的值改为通过 SENSOR_CHAN_LIGHT 隐式读取。尝试调用 sensor_sample_fetch_chan with this enumerator as an argument will result in a -ENOTSUP.

SENSOR_CHAN_VEML6031_IR_RAW_COUNTS 

用于 IR 传感器值的通道。

该通道是传感器输出的原始 IR 通道计数值。读取方式同前述说明。 SENSOR_CHAN_VEML6031_ALS_RAW_COUNTS applies.
