添加静态通道观察。
定义 zbus.h:357

添加一个要由 Proxy Agent 转发的通道。

参数
_agent将转发该通道的 Proxy Agent 实例
_chan要由该 Proxy Agent 转发的通道
注解
该宏以优先级 "zz" 添加观察者。由于观察者优先级在可迭代段中按字典序排序，这可确保 Proxy Agent 监听者在通道的所有其他观察者之后被调用，从而避免潜在的阻塞行为。为同一通道添加其他观察者时，其优先级应设为按字典序小于 "zz" 的值，以确保它们在 Proxy Agent 监听者之前被调用。

Proxy Agent 接收回调函数的类型定义。
