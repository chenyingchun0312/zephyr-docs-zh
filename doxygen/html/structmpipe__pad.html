Pad 结构

pad 结构表示元素的一个连接点。pad 用于在元素之间协商能力并传输数据。

◆ enum_caps_fn

int(*) mpipe_pad::enum_caps_fn(struct mpipe_pad *pad, uint32_t index, const struct mpipe_structure *filter, struct mpipe_structure *out)

产生 pad 支持的某个能力

元素正是以这种方式说明它支持什么。框架会以 index 为 0、1、2 等依次调用它，每次调用一个能力，直到它报告 -ENOENT，因此多种格式存在于索引上而不是列表中。构建时已知的能力从静态结构复制而来；只有运行时才可知的能力则通过查询驱动构建。若给出了 filter，则产生被它收窄后的能力（这正是 mpipe_pad_enum_filter 所做的），并在该索引无法满足它时报告 -EAGAIN，以便遍历继续到下一个索引。默认实现在索引 0 处产生 pad 自身的能力，之后不再产生任何内容。

参数
pad要枚举的 pad
index能力的索引，从 0 开始
filter用于收窄的能力，可以为 NULL
[out]out调用方用于存放能力的存储
返回值
0Success.
-EAGAIN该索引无法满足 filter
-ENOENT已超过最后一个能力

◆ process_fn

int(*) mpipe_pad::process_fn(struct mpipe_pad *pad, struct net_buf *in_buf, struct net_buf **out_buf)

处理缓冲区

元素的处理函数，在其 sink pad 上针对每个推入的缓冲区调用。它拥有 in_buf，无论成功还是失败都要释放它，并交回它所产生的内容：来自其池的新缓冲区、就地转换或直接透传的同一缓冲区，或在它消费了输入时返回 NULL，此时推送结束。

参数
pad缓冲区到达的 sink pad
in_buf要处理的缓冲区
[out]out_buf所产出的缓冲区；输入被消费时为 NULL
返回
成功时为 0，失败时为负的 errno
