静态定义并注册主机命令处理程序。

辅助宏，用于静态定义并注册请求结构和响应结构大小均在编译期固定的主机命令处理程序。

参数
_id要处理其请求的主机命令 ID。
_function处理函数名称。
_version_mask_function 支持的所有版本的位域。例如 BIT(0) 对应版本 0。
_request_type_function 的请求参数数据类型。
_response_type响应参数的数据类型，用于 _function.

在返回 EC_HOST_CMD_IN_PROGRESS 之后，通过回调继续处理该处理程序。

主机命令处理程序可以返回 EC_HOST_CMD_IN_PROGRESS，但需要继续工作。应在返回 EC_HOST_CMD_IN_PROGRESS 之前调用此函数并提供一个将被执行的回调。该回调的返回状态会被保存，并可通过相应函数获取。 ec_host_cmd_send_in_progress_status function. The ec_host_cmd_send_in_progress_ended function can be used to check if the callback has ended.

注意
Available only when the following Kconfig option is enabled: CONFIG_EC_HOST_CMD_IN_PROGRESS_STATUS.
参数
[in]cb命令处理程序返回后要调用的回调。
[in]user_data传给回调的用户数据。
返回值
EC_HOST_CMD_BUSY如果已有命令正在处理，则返回该值，否则返回 EC_HOST_CMD_SUCCESS

◆ ec_host_cmd_send_in_progress_status()

enum ec_host_cmd_status ec_host_cmd_send_in_progress_status ( void )

#include <zephyr/mgmt/ec_host_cmd/ec_host_cmd.h>

获取已发送 EC_HOST_CMD_IN_PROGRESS 状态的最后一个主机命令的最终结果。

发送 EC_HOST_CMD_IN_PROGRESS 状态的主机命令不会发送最终结果。用此函数获取已保存的状态。该状态只能获取一次，后续调用将返回 EC_HOST_CMD_UNAVAILABLE。

不支持保存会发送响应数据的主机命令的状态。

注意
Available only when the following Kconfig option is enabled: CONFIG_EC_HOST_CMD_IN_PROGRESS_STATUS.
返回值
The最终状态；不可用时为 EC_HOST_CMD_UNAVAILABLE。
