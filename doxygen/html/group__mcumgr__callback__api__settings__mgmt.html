struct  settings_mgmt_access
 在 MGMT_EVT_OP_SETTINGS_MGMT_ACCESS 通知回调中提供的结构体。该回调函数用于就待处理的设置读取/写入/删除/加载/保存/提交请求通知应用程序，并批准或拒绝该请求。只要没有处理程序返回错误，访问就会被允许；如果其中一个返回错误，则访问将被拒绝。 更多...
