struct bt_goep* bt_goep_transport_v1::goep

指向父 GOEP 对象的反向指针

在调用任何 GOEP 传输连接或注册 API 之前，必须将其初始化为指向父 通用对象交换配置文件（GOEP） 结构。对于有效的 GOEP v1.1 会话，父 通用对象交换配置文件（GOEP） 的 bt_goep::v1 字段必须指向此结构，且 bt_goep::v2 必须设为 NULL。
