void k_mem_paging_backing_store_init ( void )

#include <zephyr/kernel/mm/demand_paging.h>

后备存储初始化函数。

实现方可以预期一旦该函数返回就会收到页入/页出调用，但在此之前不会。在 POST_KERNEL 阶段调用。

该函数预期完成两件事：

  • 初始化后备存储的任何内部数据结构和记账信息。
  • 如果启动时后备存储已包含全部或部分已加载的内核数据页，则应相应地为其关联页帧设置 K_MEM_PAGE_FRAME_BACKED，并相应地建立内部记账信息。

◆ k_mem_paging_backing_store_location_get()

int k_mem_paging_backing_store_location_get ( struct k_mem_page_frame * pf,
uintptr_t * location,
bool page_fault )

#include <zephyr/kernel/mm/demand_paging.h>

为载入页帧的数据页预留或获取存储位置

返回的位置令牌对于所映射的虚拟地址必须唯一。该位置将在后备存储中用于换出数据页内容以便后续取回。位置值必须按页对齐。

该函数可能对同一数据页被多次调用。如果其页帧设置了 K_MEM_PAGE_FRAME_BACKED 位，则应返回该数据页先前包含缓存干净副本的后备存储位置。该干净副本可在页出时更新，或用于丢弃干净页而无需写出其内容。

如果后备存储已满，可能会选择缓存了某个已加载数据页的其他后备存储位置，此时其关联页帧的 K_MEM_PAGE_FRAME_BACKED 位将被清除（因为它不再被缓存）。

k_mem_page_frame_to_virt(pf) 将指示该页当前映射到的虚拟地址。可以包含整个地址空间的大型稀疏后备存储可以直接根据该虚拟地址生成位置令牌，无需其他管理。

该函数区分它是否代表缺页处理而被调用。为了使缺页处理成功，必须始终预留一个空闲的后备存储位置。如果未设置 page_fault 参数，即使有一个位置可用，该函数也应返回 -ENOMEM。

该函数在中断锁定的情况下被调用。

参数
pf要为其获取存储位置的虚拟地址
[out]location存储位置令牌
page_fault该请求是否因缺页而产生
返回
0 成功
-ENOMEM 后备存储已满

◆ k_mem_paging_backing_store_location_query()

int k_mem_paging_backing_store_location_query ( void * addr,
uintptr_t * location )

#include <zephyr/kernel/mm/demand_paging.h>

获取按需内容的持久位置令牌

与 k_mem_paging_backing_store_location_get() 不同，该函数不会分配任何后备存储空间，而是返回一个与某个固定存储内容相对应的位置令牌，以便按需页入。它预期与 CONFIG_LINKER_USE_ONDEMAND_SECTION 和 K_MEM_MAP_UNPAGED 标志一起使用，以便在启动时创建按需映射。它也可用于实现基于文件的 mmap() 等。

参数
addr要为其获取位置令牌的虚拟地址
[out]location存储位置令牌
返回
成功时为 0，否则为负的错误码

◆ k_mem_paging_backing_store_page_finalize()

void k_mem_paging_backing_store_page_finalize ( struct k_mem_page_frame * pf,
uintptr_t location )

#include <zephyr/kernel/mm/demand_paging.h>

在页入之后更新内部记账信息

这在 k_mem_paging_backing_store_page_in() 之后、中断已被*重新锁定时调用，因此访问 k_mem_page_frame 数据是安全的。位置值将与传给 k_mem_paging_backing_store_page_in() 的值相同。

其主要用途是更新页帧中后备存储的自定义字段，以反映该数据再次被页出时应换出到哪里。在某些实现中这可以是空操作。

如果后备存储会缓存页入的数据页，则这是设置 K_MEM_PAGE_FRAME_BACKED 位的适当时机。只有当干净数据页在页表中被标记为干净且其关联页帧中设置了 K_MEM_PAGE_FRAME_BACKED 位时，内核才会跳过将其页出。

参数
pf被载入的页帧
location所载入数据页的取回位置

void k_mem_paging_backing_store_page_in ( uintptr_t location)

#include <zephyr/kernel/mm/demand_paging.h>

将数据页从所提供的位置复制到 K_MEM_SCRATCH_PAGE。

在调用该函数之前，K_MEM_SCRATCH_PAGE 会立即被读写映射到调用上下文的预期目标页帧。

对该函数和 k_mem_paging_backing_store_page_out() 的调用总是串行化的，但中断可能处于使能状态。

参数
location该数据页的位置令牌
