通用属性规范（GATT）

GATT 层通过提供服务注册和属性声明的 API 来管理服务数据库。更多信息请参见 GATT 客户端 API 和 bt_gatt_server。

◆ bt_gatt_attr_read_func_t

typedef ssize_t(*) bt_gatt_attr_read_func_t(struct bt_conn *conn, const struct bt_gatt_attr *attr, void *buf, uint16_t len, uint16_t offset)

#include <zephyr/bluetooth/gatt.h>

属性读回调

这是 bt_gatt_attr.read() 方法的类型。

此函数可以安全地假定本次读取已满足属性权限。这由调用方负责。

调用方可以设置 conn 来模拟 GATT 客户端读取，或者在本地读取时将其留为 NULL。

注解
GATT 服务器依赖此方法处理来自远程 GATT 客户端的读操作。但此方法并非 GATT 服务器专用。例如，可以在本地 ATT 数据库中查找属性并调用此方法。
GATT 服务器会将此方法的返回值传回远程客户端。
当协议栈调用此方法来服务远程操作时，它会在协议栈选择的线程上下文中执行，绝不会在 ISR 中执行，实现不应当阻塞。
参数
conn请求读取的连接。若为本地读取则为 NULL。
attr正在读取的属性
buf用于存放读取结果的缓冲区
len要读取的数据长度
offset开始读取的偏移
返回
读取的字节数，或者在出错时返回带特定 BT_ATT_ERR_* 错误码的 BT_GATT_ERR()。

◆ bt_gatt_attr_write_func_t

typedef ssize_t(*) bt_gatt_attr_write_func_t(struct bt_conn *conn, const struct bt_gatt_attr *attr, const void *buf, uint16_t len, uint16_t offset, uint8_t flags)

#include <zephyr/bluetooth/gatt.h>

属性值写入实现

这是 bt_gatt_attr.write() 方法的类型。

此函数可以安全地假定本次写入已满足属性权限。这由调用方负责。

调用方可以设置 conn 来模拟 GATT 客户端写入，或者在本地写入时将其留为 NULL。

若 flags 包含 BT_GATT_WRITE_FLAG_PREPARE，则该方法不得执行写入，而只应检查写入是否被授权，未授权则返回错误码。

属性值写入实现可以并且经常会带来潜在的存储值之外的副作用，例如切换 LED。

注解
GATT 服务器依赖此方法处理来自远程 GATT 客户端的写操作。但此方法并非 GATT 服务器专用。例如，可以在本地 ATT 数据库中查找属性并调用此方法。
GATT 服务器会将此方法的返回值传回远程客户端。
当协议栈调用此方法来服务远程操作时，它会在协议栈选择的线程上下文中执行，绝不会在 ISR 中执行，实现不应当阻塞。
参数
conn请求写入的连接
attr正在写入的属性
buf包含要写入数据的缓冲区
len缓冲区中的字节数
offset开始写入的偏移
flags类型为 bt_gatt_attr_write_flag 的标志
返回
写入的字节数，或者在出错时返回带特定 BT_ATT_ERR_* 错误码的 BT_GATT_ERR()。

◆ bt_gatt_attr_write_flag

enum bt_gatt_attr_write_flag

#include <zephyr/bluetooth/gatt.h>

GATT 属性写标志

枚举值
BT_GATT_WRITE_FLAG_PREPARE 

属性准备写标志

若置位，写回调只应检查设备是否已获授权，不应写入任何数据。

仅对设置了该标志的属性传递 BT_GATT_PERM_PREPARE_WRITE. See that permission for why its absence does not mean prepared writes are rejected.

BT_GATT_WRITE_FLAG_CMD 

属性写命令标志

若置位，表示写操作是命令（无响应写），不会产生任何响应。

BT_GATT_WRITE_FLAG_EXECUTE 

属性写执行标志

若置位，表示写操作是执行，即长写的结束，并且会出现在 1 个或多个之后 BT_GATT_WRITE_FLAG_PREPARE.

◆ bt_gatt_perm

enum bt_gatt_perm

#include <zephyr/bluetooth/gatt.h>

GATT 属性权限位字段值

枚举值
BT_GATT_PERM_NONE 

不支持任何操作，例如仅用于通知

BT_GATT_PERM_READ 

属性读权限。

BT_GATT_PERM_WRITE 

属性写权限。

BT_GATT_PERM_READ_ENCRYPT 

带加密的属性读权限。

若置位，则读访问需要加密。

BT_GATT_PERM_WRITE_ENCRYPT 

带加密的属性写权限。

若置位，则写访问需要加密。

BT_GATT_PERM_READ_AUTHEN 

带认证的属性读权限。

若置位，则读访问需要使用已认证链路密钥进行加密。

BT_GATT_PERM_WRITE_AUTHEN 

带认证的属性写权限。

若置位，则写访问需要使用已认证链路密钥进行加密。

BT_GATT_PERM_PREPARE_WRITE 

属性准备写权限。

此权限是 Zephyr 扩展，未在 Bluetooth Core Specification 中定义。

若置位，则准备写（用于长写和可靠写）会以如下方式调用属性写回调 BT_GATT_WRITE_FLAG_PREPARE before the value is queued. The callback must return 0 to accept the prepare write; any other return value is converted to an ATT error. If this permission is not set, prepare writes are accepted by default (subject to normal write permissions).

注解
与本枚举的其他值不同，这不是访问检查：清除它并不会让 GATT 层拒绝准备写。每个被排队的值都会在客户端执行写操作时传给写回调，因此无法接受准备写的属性必须在自己的写回调中拒绝它：若设置了此权限，则在准备时拒绝，否则在执行时拒绝。

不要将其与 BT_GATT_CEP_RELIABLE_WRITE 混淆，后者是规范中的特征扩展属性位。

BT_GATT_PERM_READ_LESC 

带 LE Secure Connection 加密的属性读权限。

若置位，则读访问要求使用 LE Secure Connections。

BT_GATT_PERM_WRITE_LESC 

带 LE Secure Connection 加密的属性写权限。

若置位，则写访问要求使用 LE Secure Connections。
