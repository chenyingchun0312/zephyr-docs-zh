◆ pbuf_get_initial_buf()

int pbuf_get_initial_buf ( struct pbuf * pb,
volatile char ** buf,
uint16_t * len )

#include <zephyr/ipc/pbuf.h>

从 pbuf 获取第一个缓冲区。

此函数获取位于队列起始处的缓冲区。由于它是第一个缓冲区，因此是连续的块。

参数
pb要从中读取数据的缓冲区。
[out]buf指向输出指针的指针，该输出指针指向第一个缓冲区的数据。
[out]len指向第一个缓冲区输出长度的指针。
返回值
0成功时。当队列起始处没有缓冲区时为 -EINVAL。

◆ pbuf_read()

int pbuf_read ( struct pbuf * pb,
char * buf,
uint16_t len )

#include <zephyr/ipc/pbuf.h>

从数据包缓冲区读取指定数量的数据。

单次读取可读取由单次写入发送的消息。提供的 p buf 必须足够大，以存储整条消息。

参数
pb要从中读取数据的缓冲区。
buf指向读取数据要写入的位置的数据指针。如果为 NULL，则返回所存储消息的长度。
len要从缓冲区读取的字节数。
返回值
int读取的字节数，失败时为负的错误码。如果 buf == NULL，则为要读取的字节数。-EINVAL，如果任一输入参数不正确。-ENOMEM，如果消息无法放入提供的 buf。-EAGAIN，如果整条消息尚未就绪。

#include <zephyr/ipc/pbuf.h>

将指定数量的数据写入数据包缓冲区。

如果缓冲区能容纳该数据，此函数调用会将指定数量的数据写入数据包缓冲区。

参数
pb要写入的缓冲区。
buf指向要写入缓冲区的数据的指针。
len要写入缓冲区的字节数。必须为正数。
返回值
int写入的字节数，失败时为负的错误码。-EINVAL，如果任一输入参数不正确。-ENOMEM，如果 len 大于缓冲区可容纳的大小。
