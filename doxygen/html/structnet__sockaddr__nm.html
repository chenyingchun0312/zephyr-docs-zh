详细描述

struct net_sockaddr_nm - 用于 NET_MGMT 套接字的 net_sockaddr 结构体

使用与 Linux AF_NETLINK 类似的概念。不使用 NETLINK 这个名称是为了避免 Zephyr 与 Linux 之间的混淆，因为两者的实现不同。

套接字域（地址族）为 AF_NET_MGMT，套接字类型为 NET_SOCK_RAW 或 NET_SOCK_DGRAM，因为这是面向数据报的服务。

协议（协议类型）选择该套接字用于哪种特性。

与 bind() 一起使用时，可以用调用线程自己的 ID 填充 net_sockaddr_nm 的 nm_pid 字段。nm_pid 在此充当此 net_mgmt 套接字的本地地址。应用程序负责选择一个唯一的整数值填入 nm_pid。
