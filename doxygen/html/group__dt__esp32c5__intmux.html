详细描述

Espressif ESP32-C5 的设备树中断源编号。

Espressif ESP32-C5 中断分配器的中断源编号，与 espressif,esp32-intc 兼容中断控制器配合使用。一个中断由三个单元描述：中断源、优先级和一个标志单元。中断源编号遵循以下模式 <SIGNAL>_INTR_SOURCE; IRQ_DEFAULT_PRIORITY selects the default priority.

&uart0 {
interrupts = <UART0_INTR_SOURCE IRQ_DEFAULT_PRIORITY 0>;
};
