◆ mem_attr_heap_aligned_alloc()

void * mem_attr_heap_aligned_alloc ( uint32_t attr,
size_t align,
size_t bytes )

#include <zephyr/mem_mgmt/mem_attr_heap.h>

按指定的属性、大小和对齐方式分配对齐内存。

分配一块具有指定大小（字节）和指定能力 / 属性的内存块。额外接受一个参数，指定以字节为单位的 2 的幂对齐。

参数
attr为内存块请求的能力 / 属性。
align返回指针的 2 的幂对齐（字节）。
bytes请求的分配大小（字节）。
返回值
ptr指向已分配内存的有效指针。
NULL如果没有具有该属性和大小的可用内存。

◆ mem_attr_heap_alloc()

void * mem_attr_heap_alloc ( uint32_t attr,
size_t bytes )

#include <zephyr/mem_mgmt/mem_attr_heap.h>

按指定的属性和大小分配内存。

分配一块具有指定大小（字节）和指定能力 / 属性的内存块。该属性用于选择从中分配内存的正确内存堆。

参数
attr为内存块请求的能力 / 属性。
bytes请求的分配大小（字节）。
返回值
ptr指向已分配内存的有效指针。
NULL如果没有具有该属性和大小的可用内存。

◆ mem_attr_heap_free()

void mem_attr_heap_free ( void * block)

#include <zephyr/mem_mgmt/mem_attr_heap.h>

释放已分配的内存

用于释放传入的内存块，该内存块必须是先前调用 mem_attr_heap_alloc 或 mem_attr_heap_aligned_alloc 的返回值。

参数
block要释放的块，必须是指向由以下接口分配的块的指针 mem_attr_heap_alloc or mem_attr_heap_aligned_alloc.

◆ mem_attr_heap_get_region()

const struct mem_attr_region_t * mem_attr_heap_get_region ( void * addr)

#include <zephyr/mem_mgmt/mem_attr_heap.h>

获取指定地址对应的特定内存区域描述符

查找管理所提供指针的内存区域描述符结构体。

参数
addr要查找的地址，必须是指向由以下接口分配的块的指针 mem_attr_heap_alloc or mem_attr_heap_aligned_alloc.
返回值
str指向该地址所属内存区域结构的指针。

◆ mem_attr_heap_pool_init()

int mem_attr_heap_pool_init ( void )

#include <zephyr/mem_mgmt/mem_attr_heap.h>

初始化内存池

这必须是用于从所有具有软件属性的内存区域初始化内存池时首先调用的函数。

返回值
0成功时。
-EALREADY如果内存池已初始化。
-ENOMEM已分配的区域过多。
