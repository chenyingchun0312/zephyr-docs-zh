◆ cs40l5x_configure_buzz()

int cs40l5x_configure_buzz ( const struct device *const dev,
const uint32_t frequency,
const uint8_t level,
const uint32_t duration )

#include <zephyr/drivers/haptics/cs40l5x.h>

配置 ROM buzz 以进行触觉播放

在大幅度且供电不足时（例如采用内部升压配置的情况），可能引发升压错误。

参数
[in]dev指向触觉设备实例的设备结构体的指针
[in]frequency触觉效果的频率，单位 Hz（默认值：0xF0）
[in]level触觉效果的幅度，其中 UINT8_MAX 表示 100（默认值：0x1B）
[in]duration播放时长（毫秒），其中 0 表示无限期（默认值：0x32）
返回
成功时为 0，失败时为负的 errno 值。
返回值
-EIO控制端口事务失败。
