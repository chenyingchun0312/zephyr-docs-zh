详细描述

SoC 和开发板钩子

此头文件包含 Zephyr 架构与初始化代码之间接口的函数原型，以及位于 boards/ 和 soc/ 下的 SoC/开发板特定逻辑。

注解
这些都是标准 SoC 和开发板接口，由 SoC/开发板特定逻辑导出给操作系统内部逻辑。绝不应当从应用程序代码直接访问它们，但可以在操作系统内部自由使用。

void board_early_init_hook ( void )

在内核启动之前执行的开发板钩子。

此钩子在内核启动之前被调用。它由开发板实现，可用于执行任何开发板特定的初始化。

void board_late_init_hook ( void )

此钩子在内核启动之后、main 函数被调用之前被调用。它由开发板实现，可用于执行任何开发板特定的初始化。
