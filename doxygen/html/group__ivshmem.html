◆ ivshmem_get_mem()

size_t ivshmem_get_mem ( const struct device * dev,
uintptr_t * memmap )

#include <zephyr/drivers/virtualization/ivshmem.h>

获取虚拟机间共享内存

注意：此 API 不受 ivshmem-v2 支持，因为 R/W 与 R/O 区域可能不会连续映射。对于 ivshmem-v2，请使用 ivshmem_get_rw_mem_section、ivshmem_get_output_mem_section 和 ivshmem_get_state API 访问共享内存。

参数
dev驱动实例的设备结构体指针
memmap用于填入内存地址的指针
返回
映射内存的大小，或 0

◆ ivshmem_register_handler()

int ivshmem_register_handler ( const struct device * dev,
struct k_poll_signal * signal,
uint16_t vector )

#include <zephyr/drivers/virtualization/ivshmem.h>

注册向量通知（中断）处理程序

参数
dev驱动实例的设备结构体指针
signal指向有效且可被触发的 struct k_poll_signal 的指针。若为 NULL，则取消注册该向量的任何处理程序。
vector要接收通知的中断向量

注意：返回的状态若为正，则被触发信号的值即产生该信号的向量。这样用户可以为所有向量使用一个信号，也可以为每个向量各用一个信号。

返回
成功时为 0，否则为负的 errno
