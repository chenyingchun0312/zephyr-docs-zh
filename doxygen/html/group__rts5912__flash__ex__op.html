enum flash_rts5912_ex_ops

#include <zephyr/drivers/flash/rts5912_flash_api_ex.h>

Realtek RTS5912 Flash 扩展操作的枚举。

枚举值
FLASH_RTS5912_EX_OP_WR_ENABLE 

向 Flash 芯片发送写使能（WREN）命令。

该操作置位 Flash 存储器状态寄存器中的写使能锁存（WEL）位，从而允许写入和擦除操作。

参数
inNot used.
outNot used.
FLASH_RTS5912_EX_OP_WR_DISABLE 

向 Flash 芯片发送写禁止（WRDI）命令。

该操作复位写使能锁存（WEL）位，保护存储器不被写入或擦除。

参数
inNot used.
outNot used.
FLASH_RTS5912_EX_OP_WR_SR 

写入 Flash 状态寄存器 1（SR1）。

该操作向主状态寄存器写入一个字节。

参数
inNot used.
out指向 uint8_t 的指针，其中包含要写入 SR1 的值。
FLASH_RTS5912_EX_OP_WR_SR2 

写入 Flash 状态寄存器 2（SR2）。

该操作向第二个状态寄存器写入一个字节。

参数
inNot used.
out指向 uint8_t 的指针，其中包含要写入 SR2 的值。
FLASH_RTS5912_EX_OP_RD_SR 

读取 Flash 状态寄存器 1（SR1）。

该操作从主状态寄存器读取一个字节。

参数
inNot used.
out指向 uint8_t 缓冲区的指针，SR1 的读取值将存放在其中。
FLASH_RTS5912_EX_OP_RD_SR2 

读取 Flash 状态寄存器 2（SR2）。

该操作从第二个状态寄存器读取一个字节。

参数
inNot used.
out指向 uint8_t 缓冲区的指针，SR2 的读取值将存放在其中。
FLASH_RTS5912_EX_OP_SET_WP 

设置硬件写保护（WP#）引脚状态。

该操作控制控制器的硬件 WP# 引脚输出。

参数
inNot used.
out指向 uint8_t 的指针。若值非零，则 WP# 引脚被断言（低电平有效）。若为零，则取消断言。
FLASH_RTS5912_EX_OP_GET_WP 

获取硬件写保护（WP#）引脚状态。

该操作读取控制器硬件 WP# 引脚设置的当前状态。

参数
inNot used.
out指向 uint8_t 缓冲区的指针，用于存放当前 WP# 引脚状态。非零值表示该引脚被配置为断言。
