◆ net_capture_data()

void net_capture_data ( struct net_capture_cooked * ctx,
const uint8_t * data,
size_t len,
enum net_capture_packet_type type,
uint16_t ptype )
inlinestatic

#include <zephyr/net/capture.h>

从没有接口的源捕获任意数据。当你要捕获的来源没有网络接口时可用。例如位于 PPP 之下、包含 HDLC 帧的低层调制解调器设备、CANBUS 数据或 Bluetooth 报文等。传给此函数的数据应只包含完整的链路层报文，以免丢失报文边界。

参数
ctxcooked 模式捕获上下文。
data要捕获的数据。
len数据的长度。
type报文的方向和类型（是否由我们发送等）。
ptype协议类型 ID。即 ethernet.h 中定义的 ETH_P_* 类型

◆ net_capture_enable()

int net_capture_enable ( const struct device * dev,
struct net_if * iface )
inlinestatic

#include <zephyr/net/capture.h>

启用网络报文捕获支持。

这会创建隧道网络接口，所有捕获的报文都被推送到那里。捕获的网络报文被放入发送给隧道对端的 UDP 报文中。

参数
dev网络捕获设备
iface我们开始捕获报文的网络接口。
返回
成功时为 0，网络报文捕获启用失败时小于 0

◆ net_capture_setup()

int net_capture_setup ( const char * remote_addr,
const char * my_local_addr,
const char * peer_addr,
const struct device ** dev )

#include <zephyr/net/capture.h>

设置网络报文捕获支持。

参数
remote_addr该值给出隧道远端/外层端点的 IP 地址。该 IP 地址可以是 IPv4 或 IPv6 地址。此地址用于选择创建隧道的网络接口。
my_local_addr隧道的本地/内层 IP 地址。还可包含用作 UDP 源端口的端口号。
peer_addr隧道的对端/内层 IP 地址。还可包含用作 UDP 目的端口的端口号。
dev网络捕获设备。它被返回给调用方。
返回
成功时为 0，网络报文捕获设置失败时小于 0
