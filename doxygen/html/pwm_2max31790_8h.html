MAX31790 的自定义 PWM 标志

这些标志可在 pwm_flags_t 的高 8 位中与 PWM API 一起使用。它们允许使用 RPM 模式，该模式会使 MAX31790 测量风扇的实际转速并将其自动控制到目标转速。

#define PWM_MAX31790_FLAG_RPM_MODE   (1 << PWM_MAX31790_FLAG_RPM_MODE_POS)
 RPM 模式

这表示 TACH 计数的乘数，应根据风扇的标称 RPM 选择。有关如何选择合适值的详细表格可参见 MAX31790 的数据手册。
