◆ fuel_gauge_set_buffer_prop()

int fuel_gauge_set_buffer_prop ( const struct device * dev,
fuel_gauge_prop_t prop_type,
const void * src,
size_t src_len )

#include <zephyr/drivers/fuel_gauge.h>

设置电池电量计缓冲区属性

向电量计设备写入可变长度的缓冲区属性，例如配置镜像或制造商定义的数据块。

源是不透明的、不含指针的字节缓冲区。从用户模式调用时，只有 src_len bytes starting at src are validated before they are handed to the driver, so the buffer must not contain pointers that the driver dereferences.

参数
dev指向电池电量计设备的指针
prop_type写入电量计设备的属性类型
src存放要写入电量计的数据的字节缓冲区
src_len源缓冲区的长度（字节）
返回
如果成功则为 0，失败时为负的 errno 码。
