详细描述

支持的最小连接间隔组

每组表示支持的连接间隔的等差数列：min、min + stride、min + 2 * stride……min + n * stride（其中 min + n * stride <= max）

示例：min = 10（1250 us）、max = 60（7500 us）、stride = 5（625 us）-> 支持：1250 us、1875 us、2500 us……6875 us、7500 us
