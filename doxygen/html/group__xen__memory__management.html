#include <zephyr/xen/memory.h>

为某个域获取由 Xen 管理的资源映射。

参数
domid目标域标识符。
typeXen 资源类型，例如 XENMEM_resource_ioreq_server。
id根据 type 解释的资源实例标识符。
frameXen 资源内的起始帧。当 *nr_frames 为 0（大小查询）时忽略。
[in,out]nr_frames输入时为要获取的帧数。返回时为 Xen 针对该请求报告的帧数。
[out]frame_list客户机帧列表缓冲区：对 HVM 客户机为输入 GFN，对 PV 客户机为输出 MFN。
返回
成功时为 0，失败时为负的 errno 值。

◆ xendom_decrease_reservation()

int xendom_decrease_reservation ( int domid,
unsigned int extent_order,
unsigned int nr_extents,
unsigned int mem_flags,
xen_pfn_t * extent_start )

#include <zephyr/xen/memory.h>

减少域的内存预留。

这会请求 Xen 从域的预留中释放客户机帧区段。

参数
domid其预留被减少的域。非特权调用者必须使用 DOMID_SELF。
extent_orderXen 使用的区段阶，每个区段覆盖 2^extent_order 个页。
nr_extents要释放的区段数量。
mem_flagsXen 内存标志，例如 XENMEMF_* 常量。
extent_start要释放的客户机帧基址数组。
返回
成功时为已释放的区段数量，失败时为负的 errno 值。

#include <zephyr/xen/memory.h>

增加域的内存预留。

这会请求 Xen 为某个域分配区段。成功后，Xen 将已分配的机器帧基址写入 extent_start。

参数
domid其预留被增加的域。非特权调用者必须使用 DOMID_SELF。
extent_orderXen 使用的区段阶，每个区段覆盖 2^extent_order 个页。
nr_extents请求的区段数量。
mem_flagsXen 内存标志，例如 XENMEMF_* 常量。
[out]extent_start接收已分配机器帧基址的数组。
返回
成功时为已分配的区段数量，失败时为负的 errno 值。
