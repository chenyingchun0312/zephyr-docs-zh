◆ obj_checksum_calculated

void(*) bt_ots_client_cb::obj_checksum_calculated(struct bt_ots_client *ots_inst, struct bt_conn *conn, int err, uint32_t checksum)

收到校验和指示时的回调函数。

当 oacp_ind_handler 收到 OP BT_GATT_OTS_OACP_PROC_CHECKSUM_CALC 的响应时调用。

参数
ots_inst指向 OTC 实例的指针。
conn与对端设备的连接。
err错误码（bt_gatt_ots_oacp_res_code）。
checksum如果错误码为 BT_GATT_OTS_OACP_RES_SUCCESS，则为校验和，否则为 0。

◆ obj_data_read

int(*) bt_ots_client_cb::obj_data_read(struct bt_ots_client *ots_inst, struct bt_conn *conn, uint32_t offset, uint32_t len, uint8_t *data_p, bool is_complete)

所选对象数据的回调函数。

当使用 bt_ots_client_read_object_data() 读取所选对象的数据时调用。

参数
ots_inst指向 OTC 实例的指针。
conn与对端设备的连接。
offset所接收数据的偏移。
len所接收数据的长度。
data_p指向所接收数据的指针。
is_complete指示是否已接收整个对象。
返回
int BT_OTS_STOP 或 BT_OTS_CONTINUE。可使用 BT_OTS_STOP 停止读取。

◆ obj_metadata_read

void(*) bt_ots_client_cb::obj_metadata_read(struct bt_ots_client *ots_inst, struct bt_conn *conn, int err, uint8_t metadata_read)

所选对象元数据的回调函数。

当使用 bt_ots_client_read_object_metadata() 读取所选对象的元数据时调用。并非所有元数据都可能已初始化。

参数
ots_inst指向 OTC 实例的指针。
conn与对端设备的连接。
err错误值。成功时为 0，失败时为 GATT 错误或 ERRNO。
metadata_read成功读取的元数据的位字段。

◆ obj_selected

void(*) bt_ots_client_cb::obj_selected(struct bt_ots_client *ots_inst, struct bt_conn *conn, int err)

选择新对象时的回调函数。

当选择新对象且当前对象已变化时调用。ots_inst 中的 cur_object 将被复位，应使用 bt_ots_client_read_object_metadata() 重新读取元数据。

参数
ots_inst指向 OTC 实例的指针。
conn与对端设备的连接。
err错误码（bt_ots_olcp_res_code）。
