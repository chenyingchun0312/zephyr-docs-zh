◆ rd

int(*) bt_mesh_blob_io::rd(const struct bt_mesh_blob_io *io, const struct bt_mesh_blob_xfer *xfer, const struct bt_mesh_blob_block *block, const struct bt_mesh_blob_chunk *chunk)

分块数据读回调。

由 BLOB 传输客户端用于获取出向数据。

客户端调用分块数据请求回调以填充发往目标节点的分块消息。数据请求回调可能被乱序调用，并且对每个偏移可能被调用多次，因此不能用作进度的指示。

在分块数据请求回调上返回非零状态码会导致传输终止。

参数
ioBLOB stream.
xferBLOB transfer.
block该分块所属的块。
chunk要获取其数据的分块。指向它的缓冲区指针 data member should be filled by the callback.
返回
成功时返回 0，否则返回（负的）错误码。

◆ wr

int(*) bt_mesh_blob_io::wr(const struct bt_mesh_blob_io *io, const struct bt_mesh_blob_xfer *xfer, const struct bt_mesh_blob_block *block, const struct bt_mesh_blob_chunk *chunk)

分块数据写回调。

由 BLOB 传输服务器在接收数据时使用。

每个块被划分为若干数据分块。收到新的数据分块时调用此回调。分块在其所属块内可以任意顺序接收。

如果回调成功返回，该分块将被标记为已接收，除非因传输挂起导致块重新开始，否则不会再次接收。如果回调返回非零值，该分块仍为未接收状态，BLOB 传输客户端稍后会尝试重发。

注意，客户端在从传输中移除某个目标节点之前，只会对分块投递进行有限次数的尝试。客户端执行的重试次数取决于具体实现。

参数
ioBLOB stream.
xferBLOB transfer.
block该分块所属的块。
chunk已接收的分块。
返回
成功时返回 0，否则返回（负的）错误码。
