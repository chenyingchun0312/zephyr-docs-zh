详细描述

单链表实现。

自从
1.2
版本
1.0.0

使用内联宏/函数实现的单链表。此 API 不是线程安全的，因此若在多个线程间使用同一链表，对函数的调用必须用同步原语保护。

__sn )

#include <zephyr/sys/slist.h>

值:
Z_GENLIST_ITERATE_FROM_NODE(slist, __sl, __sn)

提供从链表中某个节点开始在链表上迭代的原语 注意：该循环不安全，因此不应移除 __sn

用户_必须_加上包裹自身代码的循环语句花括号： 

SYS_SLIST_ITERATE_FROM_NODE(l, n) {
    <user code>
}

类似 SYS_SLIST_FOR_EACH_NODE()，但 __dn 已包含链表中的一个节点，用于从该节点开始搜索下一项。若为 NULL，则从头部开始。

此宏及其他 SYS_SLIST_*() 宏不是线程安全的。

参数
__sl指向要迭代的 sys_slist_t 的指针
__sn用于查看链表中每个节点的 sys_snode_t 指针，其中包含起始节点，若为 NULL 则从头部开始
