◆ coredump_cmd_id

enum coredump_cmd_id

#include <zephyr/debug/coredump.h>

Command ID

枚举值
COREDUMP_CMD_CLEAR_ERROR 

清除后端的错误码。

成功时返回 0，否则失败。

COREDUMP_CMD_VERIFY_STORED_DUMP 

验证已存储的 coredump 是否有效。

返回值：

  • 1 if valid.
  • 若无效或没有已存储的 coredump 则为 0。
  • 若不支持此命令则为 -ENOTSUP。
  • 否则为后端的错误码。
COREDUMP_CMD_ERASE_STORED_DUMP 

擦除已存储的 coredump。

返回值：

  • 0 if successful.
  • 若不支持此命令则为 -ENOTSUP。
  • 否则为后端的错误码。
COREDUMP_CMD_COPY_STORED_DUMP 

复制已存储的原始 coredump。

返回值：

  • 成功时为复制的长度
  • 若未找到已存储的 coredump 则为 0
  • 若不支持此命令则为 -ENOTSUP。
  • 否则为后端的错误码。
COREDUMP_CMD_INVALIDATE_STORED_DUMP 

使已存储的 coredump 失效。这比擦除整个分区更快。

返回值：

  • 0 if successful.
  • 若不支持此命令则为 -ENOTSUP。
  • 否则为后端的错误码。
COREDUMP_CMD_MAX 

命令 ID 的最大值。

◆ coredump_query_id

enum coredump_query_id

#include <zephyr/debug/coredump.h>

查询 ID

枚举值
COREDUMP_QUERY_GET_ERROR 

返回后端的错误码。

COREDUMP_QUERY_HAS_STORED_DUMP 

检查后端是否存在已存储的 coredump。

返回值：

  • 若存在已存储的 coredump 则为 1，否则为 0。
  • 若不支持此查询则为 -ENOTSUP。
  • 否则为后端的错误码。
COREDUMP_QUERY_GET_STORED_DUMP_SIZE 

返回值：

  • 来自后端的 coredump 原始大小，若不存在则为 0。
  • 若不支持此查询则为 -ENOTSUP。
  • 否则为后端的错误码。
COREDUMP_QUERY_MAX 

查询 ID 的最大值。
