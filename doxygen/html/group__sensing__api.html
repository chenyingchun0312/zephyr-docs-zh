详细描述

高层传感器框架。

Sensing 子系统提供高层 API，供应用程序发现传感器、打开传感器实例、配置报告行为，并通过回调接收采样数据。如需底层传感器访问，请参见 sensor_interface。

#include <zephyr/sensing/sensing.h>

获取所有受支持传感器实例的信息。

此 API 仅返回传感器实例的只读信息，信息指针直接指向内部缓冲区，调用方无需分配缓冲区，也不会对传感器实例产生副作用。

参数
num_sensors获取传感器实例数量。
info用于接收传感器实例信息数组的指针。
返回
成功时为 0，失败时为负的错误值。

◆ sensing_open_sensor()

int sensing_open_sensor ( const struct sensing_sensor_info * info,
struct sensing_callback_list * cb_list,
sensing_sensor_handle_t * handle )

#include <zephyr/sensing/sensing.h>

通过传感传感器信息打开传感器实例

应用程序客户端用它打开传感器实例并获取其句柄。支持多个应用程序客户端打开同一传感器实例，此时不同客户端返回的句柄不同。同时也会注册 sensing 回调列表

参数
info从 sensing_get_sensors 获取的传感器信息
cb_list要注册到 sensing 的回调列表，必须具有静态生命周期。
handle打开的实例句柄，失败时将置为 NULL。
返回
成功时为 0，失败时为负的错误值。
