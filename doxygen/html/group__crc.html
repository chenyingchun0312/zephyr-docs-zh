◆ crc16()

uint16_t crc16 ( uint16_t poly,
uint16_t seed,
const uint8_t * src,
size_t len )

#include <zephyr/sys/crc.h>

计算无输入或输出反转的 CRC-16 的通用函数。

通过传入输入地址、输入长度和所用多项式以及初始值来计算 CRC-16。复杂度为 O(n*8)，其中 n 是所提供缓冲区的长度。不执行任何反转。

注解
若计划使用基于多项式 0x1021 的 CRC，crc16_itu_t() 函数更快，因此推荐它而不是此函数。
参数
poly要使用的多项式，省略最高位的 x^16 系数
seedCRC 计算的初始值
src用于计算的输入字节
len输入的字节长度
返回
计算得到的 CRC16 值（未对其施加任何异或）

◆ crc16_ccitt()

uint16_t crc16_ccitt ( uint16_t seed,
const uint8_t * src,
size_t len )

#include <zephyr/sys/crc.h>

用多项式 0x1021 计算缓冲区的校验和，输入和输出均反转。

此函数能够计算任何以 0x1021 为多项式且需要对输入和输出都进行反转的 CRC。它是一个快速变体，以 O(n) 时间运行，其中 n 是输入缓冲区的长度。

根据提供给初始种子的值和最终计算得到的 CRC 所异或的值，此函数可以计算（但不限于）以下校验和：

  • CRC-16/CCITT、CRC-16/CCITT-TRUE、CRC-16/KERMIT https://reveng.sourceforge.io/crc-catalogue/16.htm#crc.cat.crc-16-kermit 初始种子：0x0000，输出异或：0x0000
  • CRC-16/X-25、CRC-16/IBM-SDLC、CRC-16/ISO-HDLC https://reveng.sourceforge.io/crc-catalogue/16.htm#crc.cat.crc-16-ibm-sdlc 初始种子：0xffff，输出异或：0xffff
注解
要跨非连续块计算 CRC，请把第 N-1 块的返回值用作第 N 块的种子。

参见 ITU-T 建议书 V.41（1988 年 11 月）。

参数
seed用于为 CRC 播种的值
src用于计算的输入字节
len输入的字节长度
返回
计算得到的 CRC16 值（未对其施加任何异或）

◆ crc16_reflect()

#include <zephyr/sys/crc.h>

计算带输入和输出反转的 CRC-16 的通用函数。

通过传入输入地址、输入长度和所用多项式以及初始值来计算 CRC-16。复杂度为 O(n*8)，其中 n 是所提供缓冲区的长度。输入和输出都会被反转。

注解
若计划使用基于多项式 0x1021 的 CRC，crc16_ccitt() 函数更快，因此推荐它而不是此函数。

根据提供给初始种子的值和最终计算得到的 CRC 所异或的值，此函数可以计算（但不限于）以下校验和：

  • CRC-16/ANSI、CRC-16/MODBUS、CRC-16/USB、CRC-16/IBM https://reveng.sourceforge.io/crc-catalogue/16.htm#crc.cat.crc-16-modbus 多项式：0x8005（0xA001）初始种子：0xffff，输出异或：0x0000
参数
poly要使用的多项式，省略最高位的 x^16 系数。重要：请反转多项式。例如对 CRC-16-MODBUS 使用 0xA001 而不是 0x8005。
seedCRC 计算的初始值
src用于计算的输入字节
len输入的字节长度
返回
计算得到的 CRC16 值（未对其施加任何异或）

◆ crc32_k_4_2_update()

uint32_t crc32_k_4_2_update ( uint32_t crc,
const uint8_t * data,
size_t len )

#include <zephyr/sys/crc.h>

更新 CRC-32K/4.2（*op）（Koopman）校验和。对于最长 2,147,483,615 位它可达到 HD=4，对于最长 6,167 位可达到 HD=5/6。

汉明距离与属性：

  • 多项式：0x93a409eb
  • 输入反转：否
  • 初始值（xor-in）：由调用方作为 crc 参数提供（0xFFFFFFFF 也可以）
  • 输出反转：否
  • 输出异或：0
  • HD=4 @ 2,147,483,615 位
  • HD=5 @ 6,167 位
  • HD=6 @ 6,167 位
  • HD=7 @ 148 位

参考：https://users.ece.cmu.edu/~koopman/crc/crc32.html

参数
crc需要更新的 CRC32 校验和。
data指向要计算 CRC 的数据的指针。
len数据长度。
返回
CRC32 value.

#include <zephyr/sys/crc.h>

以通用方式计算 CRC 校验和。

这是一个分发函数，它调用由 type 确定的各个 CRC 例程。

对于 7、8、16 和 24 位 CRC，相关的 seed 和 poly 值应通过最低有效字节传入。

类似地，对于 7、8、16 和 24 位 CRC，相关结果存放在返回值的低有效字节中。

参数
type要使用的 CRC 算法。
src用于计算的输入字节
len输入的字节长度
seed种子或要更新的现有 CRC 值
poly要使用的多项式，省略最高位系数
reflect是否使用反转/倒序的值
first这是否是流中的第一个包。
last这是否是流中的最后一个包。
返回
uint32_t 计算得到的 CRC 值
