◆ resume

bool fota_http_download_params::resume

继续此前被中断的下载。仅当 URL 和映像索引与中断的下载匹配时才使用已保存的偏移量；当服务器发送了 ETag 或 Last-Modified 头时，请求会携带 If-Range，因此服务器上已改变的文件会从头重新获取。仅在启用以下配置时存在 CONFIG_FOTA_HTTP_RESUME.
