const struct device *(*) ethernet_api::get_phy(const struct device *dev, struct net_if *iface)

当启用或禁用 VLAN 标签时，IP 协议栈会调用此函数。若 enable 设为 true，则表示添加了 VLAN 标签；若为 false，则表示移除了标签。驱动可按需利用此信息。

返回与此以太网设备关联的 ptp_clock 设备 返回与此以太网设备关联的 PHY 设备
