◆ serial_vnd_peek_out_data()

uint32_t serial_vnd_peek_out_data ( const struct device * dev,
unsigned char * data,
uint32_t size )

窥视写入虚拟串口的数据。

读取数据但不消费它。后续对 serial_vnd_peek_out_data() 或 serial_vnd_read_out_data() 的调用将再次返回这些数据。

警告
涉及多次读取数据的用例必须防止并发读操作，可以通过阻止所有读者被抢占或使用互斥量管理读取来实现。
参数
dev虚拟串口的地址。
data输出缓冲区的地址。不能为 NULL。
size数据大小（字节）。
返回值
Number写入输出缓冲区的字节数。
