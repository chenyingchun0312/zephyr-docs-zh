◆ ifx_cat1_utils_peri_is_fract_div()

bool ifx_cat1_utils_peri_is_fract_div ( const struct ifx_cat1_clock * peri_clock)
inlinestatic

#include <zephyr/drivers/clock_control/clock_control_ifx_cat1.h>

测试外设时钟是否使用小数（x.5 位）分频器。

16.5 位和 24.5 位分频器类型支持小数部分，而 8 位和 16 位类型只支持整数。调用方据此在 ifx_cat1_utils_peri_pclk_set_divider() 和 ifx_cat1_utils_peri_pclk_set_frac_divider() 之间选择。

参数
peri_clock时钟描述符。
返回
若分频器类型为小数则为 true，否则为 false。
