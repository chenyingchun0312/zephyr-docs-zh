发送 OBEX 中止请求

中止当前正在进行的操作。收到 OBEX 中止响应后，将调用中止回调 bt_map_mse_mns_cb::abort。

参数
mse_mnsMNS 客户端实例。
buf包含中止头（连接 ID 等）的缓冲区。如果为 NULL，则发送默认中止请求。如果返回成功，该函数已取得 buf 的所有权。
返回
成功时为 0，失败时为负的错误码。

◆ bt_map_mse_mns_send_event()

int bt_map_mse_mns_send_event ( struct bt_map_mse_mns * mse_mns,
bool final,
struct net_buf * buf )

#include <zephyr/bluetooth/classic/map.h>

发送事件通知请求

向远程 MCE 发送事件通知。可能多次调用以发送分片事件数据。收到 send_event 响应后，将调用 send_event 回调 bt_map_mse_mns_cb::send_event（可能多次）。

参数
mse_mnsMNS 客户端实例。
final若这是最后一个报文则为 true，若后面还有数据则为 false。
buf包含事件报告 XML 数据和头的缓冲区。初始请求必须包含连接 ID、Type 头和应用参数。当 final 为 true 时必须包含 body 结束头。如果返回成功，该函数已取得 buf 的所有权。
返回
成功时为 0，失败时为负的错误码。
