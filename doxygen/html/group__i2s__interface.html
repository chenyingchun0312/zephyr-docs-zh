标准 I2S 数据格式。

串行数据以二进制补码形式传输，MSB 在前。字选择（WS）和串行数据（SD）信号都在时钟信号（SCK）的上升沿采样。MSB 总是在 WS 变化后一个时钟周期发送。左声道数据先发送，由 WS = 0 指示，随后是由 WS = 1 指示的右声道数据。

◆ I2S_OPT_PINGPONG

#define I2S_OPT_PINGPONG   BIT(6)

#include <zephyr/drivers/i2s.h>

乒乓模式

在乒乓模式下，TX 输出将在 ping 缓冲区和 pong 缓冲区之间持续交替。通常用于音频流中，一个缓冲区正在被填充而另一个正在被播放（DMA 传输），反之亦然。因此，此模式使用两组固定大小的缓冲区。实现上使用静态数组，因此它们永不释放。

◆ i2s_trigger_cmd

enum i2s_trigger_cmd

#include <zephyr/drivers/i2s.h>

触发命令

枚举值
I2S_TRIGGER_START 

开始数据的发送/接收。

若设置了 I2S_DIR_TX，则必须通过 i2s_write() 函数将一些数据排入队列以待发送。此触发只能在 READY 状态下使用，并会将接口状态改为 RUNNING。

I2S_TRIGGER_STOP 

停止数据的发送/接收。

在当前内存块结束时停止数据的发送/接收。该触发只能在 RUNNING 状态下使用，并首先将接口状态改为 STOPPING。当当前 TX/RX 块发送/接收完毕时，状态改为 READY。后续的 START 触发将从停止处继续发送/接收。

I2S_TRIGGER_DRAIN 

清空发送队列。

发送发送队列中的所有数据并停止传输。若对 RX 队列施加此触发，其效果与 I2S_TRIGGER_STOP 相同。此触发只能在 RUNNING 状态下使用，并首先将接口状态改为 STOPPING。当所有 TX 块都发送完毕后，状态改为 READY。

I2S_TRIGGER_DROP 

丢弃发送/接收队列。

立即停止发送/接收并丢弃相应队列的内容。该触发可在除 NOT_READY 之外的任何状态下使用，并将接口状态改为 READY。

I2S_TRIGGER_PREPARE 

在发生欠载/溢出错误后准备队列。

该触发只能在 ERROR 状态下使用，并将接口状态改为 READY。

函数说明

◆ i2s_buf_read()

int i2s_buf_read ( const struct device * dev,
void * buf,
size_t * size )

#include <zephyr/drivers/i2s.h>

从 RX 队列读取数据到提供的缓冲区

I2S 接口接收的数据存储在 RX 队列中，该队列由本函数从 rx_mem_slab（由 i2s_configure 定义）预分配的内存块组成。调用此函数会从队列中取出一个块，复制到提供的缓冲区，然后释放该块。

提供的缓冲区必须足够大，以容纳一个完整内存块的数据，该大小通过 i2s_configure() 按通道参数化。

此函数在其他方面等同于 i2s_read()。

参数
dev指向该驱动实例设备结构的指针。
buf读数据的目标缓冲区，其大小至少应为 RX 通道所配置的内存块大小。
size指向存放读取字节数的变量的指针。
返回值
0成功时。
-EIO接口处于 NOT_READY 或 ERROR 状态，且 RX 队列中已没有更多数据块。

int i2s_read ( const struct device * dev,
void ** mem_block,
size_t * size )
inlinestatic

#include <zephyr/drivers/i2s.h>

从 RX 队列读取数据。

I2S 接口接收的数据存储在 RX 队列中，该队列由本函数从 rx_mem_slab（由 i2s_configure 定义）预分配的内存块组成。RX 内存块的所有权移交给用户应用程序，由用户释放。

数据按等于内存块大小的块读取。若接口处于 READY 状态，读取的字节数可能更少。

若 RX 队列中没有数据，函数将阻塞等待下一个 RX 内存块被填充。此操作可按 i2s_configure 定义的方式超时。若超时值设为 K_NO_WAIT，函数为非阻塞。

除 NOT_READY 之外的任何状态都可以从 RX 队列读取。若接口处于 ERROR 状态，仍可读取 RX 队列中存储的所有有效数据。之后函数将返回 -EIO 错误。

参数
dev指向该驱动实例设备结构的指针。
mem_block指向包含接收数据的 RX 内存块的指针。
size指向存放读取字节数的变量的指针。
返回值
0成功时。
-EIO接口处于 NOT_READY 或 ERROR 状态，且 RX 队列中已没有更多数据块。
-EBUSY未等待即返回。
-EAGAIN等待时间超时。

int i2s_write ( const struct device * dev,

inlinestatic

#include <zephyr/drivers/i2s.h>

向 TX 队列写入数据。

I2S 接口要发送的数据首先存储在 TX 队列中。TX 队列由用户从 tx_mem_slab（由 i2s_configure 定义）预分配的内存块组成。此函数取得该内存块的所有权，并在所有数据发送完毕后将其释放。

若 TX 队列中没有空闲槽位，函数将阻塞等待下一个 TX 内存块被发送并从队列中移除。此操作可按 i2s_configure 定义的方式超时。若超时值设为 K_NO_WAIT，函数为非阻塞。

只有当接口处于 READY 或 RUNNING 状态时才能向 TX 队列写入。

参数
dev指向该驱动实例设备结构的指针。
mem_block指向包含要发送数据的 TX 内存块的指针。
size要写入的字节数。该值必须等于或小于内存块的大小。
返回值
0成功时。
-EIO接口不处于 READY 或 RUNNING 状态。
-EBUSY未等待即返回。
-EAGAIN等待时间超时。
