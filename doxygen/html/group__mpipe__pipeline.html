详细描述

顶层 bin，也是真正运行图的东西。

管道是最外层的 mpipe_bin，这赋予它内部 bin 所没有的三项职责。它拥有运行该图的那一个线程：其状态变化会创建、暂停、恢复并汇合该线程，在线程上循环从 source 获取缓冲区，并将每个缓冲区依次推过每个元素的处理函数，直到某个 sink 消费它。队列元素为图的一部分提供自己的线程。它安排拆除顺序：仍在途的缓冲区会在子元素拆除各池之前被丢弃，线程只有在子元素排空后才汇合。暂停不是拆除，因此排队的内容会保留，恢复时继续而不丢失。它还合并流的结束：有多个 sink 的图会为每个 sink 产生一条流结束消息，而只有最后一条会到达应用程序。

◆ mpipe_push_buffer()

int mpipe_push_buffer ( struct mpipe_pad * src_pad,
struct net_buf * buffer )

#include <zephyr/mpipe/mpipe_pipeline.h>

从给定 source pad 开始向下游推送缓冲区

从元素的 src_pad 向下游遍历，调用每个下一个元素的 process_fn，直到到达 sink、某个 process_fn 失败，或输出缓冲区为 NULL。

处理函数拥有传给它的缓冲区，无论成功还是失败都会释放它，因此遍历在出现处理错误时不会释放它。在两种没有到达任何处理函数的情况下，遍历会自行释放缓冲区：source pad 没有对端，以及对端 pad 正在冲刷。

参数
src_pad要从中开始推送的 source pad（首先调用其对端的 process_fn）
buffer要推送的缓冲区（所有权转移）
返回
成功时为 0，失败时为负的 errno
