缺陷报告

为了保持提案、变更、功能和问题之间的可追溯性和关联关系，建议在源代码提交与相关的 GitHub issue 之间相互引用。任何源自已跟踪的功能或问题的变更，都应通过注明相应的 issue 或 PR 编号来引用该功能。

任何时候都应能通过代码中的引用，查明某个变更的来源及其背后的原因。

报告回归问题

所报告的问题可能会被确认为回归问题，即该用例已知在较早的提交或版本上是正常工作的。这种情况下，在提交缺陷时直接给出引入问题的提交，可以为最终修复缺陷节省大量时间。

定位导致回归的提交有多种方法，其中代码树二分查找（bisect）是一种高效的方法，不需要深厚的代码功底，任何人都可以使用。

为此，推荐使用的工具是 git bisect。

关于该过程的建议：

  • 在每个二分步骤中运行 west update。

  • 二分查找结束并找到引入问题的提交后，请手动验证结果。
